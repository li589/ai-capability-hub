# 快照与镜像

管理 Lighthouse 实例的快照和自定义镜像。

## 支持的操作

| 操作 | 风险 | 说明 |
|------|:----:|------|
| 查询快照列表 | 🟢 | 列出所有快照 |
| 创建快照 | 🟡 | 为指定实例创建系统盘快照 |
| 删除快照 | 🔴 | 删除快照（不可逆） |
| 回滚快照 | 🔴 | 用快照覆盖系统盘（不可逆） |
| 查询镜像列表 | 🟢 | 列出系统镜像和自定义镜像 |
| 创建自定义镜像 | 🟡 | 从实例创建镜像 |
| 删除自定义镜像 | 🔴 | 删除镜像（不可逆） |

## ID 格式

| 类型 | 格式 | 示例 |
|------|------|------|
| 快照 ID | `snap-xxxxxxxx` | `snap-abc12345` |
| 镜像 ID | `lhbp-xxxxxxxx` | `lhbp-abc12345` |

## 工作流程

### 创建快照

1. 查询实例列表 → 获取 InstanceId
2. 确认快照名称
3. 创建快照 → 获取快照 ID
4. 轮询快照状态直到 AVAILABLE

### 回滚快照（高风险）

1. **必须二次确认** — 回滚会覆盖系统盘当前数据
2. 确认实例已停止（回滚要求实例处于 STOPPED 状态）
3. 执行回滚
4. 启动实例
5. 验证实例状态

## 快照状态

| 状态 | 说明 |
|------|------|
| AVAILABLE | 可用 |
| CREATING | 创建中 |
| ROLLBACKING | 回滚中 |

## 安全规则

- 🔴 **回滚快照前必须确认实例已停止**
- 🔴 **回滚会覆盖系统盘所有数据** — 不可逆，必须二次确认
- 🔴 **删除快照前确认无关联的镜像依赖**
- 🟡 **创建快照期间不影响实例运行**
