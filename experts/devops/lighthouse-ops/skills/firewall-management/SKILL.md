# 防火墙管理

管理 Lighthouse 实例的防火墙规则。

## 支持的操作

| 操作 | 风险 | 说明 |
|------|:----:|------|
| 查询防火墙规则 | 🟢 | 列出实例当前规则 |
| 添加防火墙规则 | 🟡 | 开放指定端口 |
| 删除防火墙规则 | 🟡 | 关闭指定端口 |

## 规则参数

| 参数 | 说明 | 示例 |
|------|------|------|
| Protocol | 协议 | TCP / UDP / ICMP |
| Port | 端口 | 80 / 443 / 22 / ALL |
| CidrBlock | 来源 IP | 0.0.0.0/0（全部）/ 10.0.0.0/8 |
| Action | 动作 | ACCEPT / DROP |

## 工作流程

1. **查询现有规则** — 添加/删除前先查看当前规则
2. **确认变更** — 向用户展示变更内容，获得确认
3. **执行变更** — 添加或删除规则
4. **验证结果** — 重新查询确认规则已生效

## 安全规则

- 🔴 **不建议对 0.0.0.0/0 开放 SSH（22）端口** — 建议限制来源 IP
- 🔴 **不建议对 0.0.0.0/0 开放数据库端口**（3306/5432/6379 等）
- 🟡 **删除规则立即生效** — 可能中断现有连接
- 🟢 **查询操作无风险**

## 常见场景

```
用户：开放 80 端口
→ 查询现有规则
→ 确认添加 TCP:80 0.0.0.0/0 ACCEPT
→ 执行添加
→ 验证规则已生效

用户：关闭 22 端口的外部访问
→ 查询现有规则
→ 找到 22 端口的规则
→ 确认删除
→ 执行删除
→ 验证规则已删除
```
