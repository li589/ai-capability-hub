# 监控告警

查询 Lighthouse 实例的监控指标和流量使用情况。

## 支持的操作

| 操作 | 风险 | 说明 |
|------|:----:|------|
| 查询监控指标 | 🟢 | 获取 CPU/内存/带宽等指标数据 |
| 查询流量包使用 | 🟢 | 查看实例流量包余量 |
| 创建告警策略 | 🟡 | 设置指标告警阈值 |

## 监控指标

`Indicators` 参数**必须传中文**指标名：

| 指标名（中文） | 说明 | 单位 |
|--------|------|------|
| CPU利用率 | CPU 利用率 | % |
| 内存利用率 | 内存利用率 | % |
| 公网出带宽 | 公网出带宽 | bps |
| 公网入带宽 | 公网入带宽 | bps |
| 系统盘读IO | 系统盘读 IO | - |
| 系统盘写IO | 系统盘写 IO | - |
| 公网流量包 | 公网流量包使用 | - |

> **注意**：不支持内网带宽指标。指标名传英文（如 `CpuUsage`）将查询不到数据。

监控数据命名空间：`QCE/LIGHT_HOUSE`

## 查询监控数据

1. 查询实例列表 → 获取 InstanceId
2. 确认查询的指标和时间范围
3. 调用监控接口获取数据
4. 以易读格式展示（最近 1 小时 / 24 小时 / 7 天）

### 时间参数

| 参数 | 格式 | 示例 |
|------|------|------|
| StartTime | `YYYY-MM-DD HH:mm:ss` | `2026-08-11 12:00:00` |
| EndTime | `YYYY-MM-DD HH:mm:ss` | `2026-08-11 18:00:00` |

> 时间为本地时间（UTC+8），不要使用秒数或 ISO 8601 格式。

## 流量包管理

### 流量包字段说明

| 字段 | 说明 |
|------|------|
| TrafficPackageTotal | 流量包总量（字节） |
| TrafficUsed | 已用流量（字节） |
| TrafficPackageRemaining | 剩余流量（字节） |
| StartTime | 流量包开始时间 |
| EndTime | 流量包结束时间 |

### 查询流程

1. 查询实例列表 → 获取 InstanceId
2. 查询实例流量包信息
3. 展示总流量、已用流量、剩余流量
4. 如有多个流量包，分别展示

### 注意事项

- 流量包按月重置，重置周期与实例计费周期一致
- 超出流量包额度可能导致带宽限速或按量计费
- 高公网流量实例建议定期监控流量使用
- 可结合 `公网出带宽` / `公网入带宽` 指标实时监控带宽

## 告警策略

创建告警策略时需要指定：

| 配置项 | 类型 | 说明 |
|--------|------|------|
| 指标 | 字符串（中文） | 监控的指标名，如 `CPU利用率` |
| Threshold | 字符串 | 告警触发值，含百分号，如 `"85%"` |
| Level | 枚举 | 告警级别：`提示` / `严重` / `紧急` |
| Size | 字符串 | 持续时间，仅支持 `"60"` 或 `"300"` |

> **注意**：以上数值参数均为**字符串**类型，没有独立的"比较方式"参数。

## 注意事项

- 监控数据有 1-3 分钟延迟
- 流量包是套餐制，每月重置
- 告警策略需要指定通知渠道（短信/邮件/微信）
