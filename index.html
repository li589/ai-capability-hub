关于整合

methodology
01 · 归类

能力优先

统一为 skills / plugins / connectors / experts / mcps / canvas / design_libraries / knowledges / commands 九类，再按标准子类归置。

02 · 精选

只取高频

未搬运各工具的全部内容，仅收录其中下载量较高的通用能力包，剔除低频与私有项目能力。

03 · 清理

安全脱敏

扫描并移除机器绝对路径、密钥与令牌；跨工具重名包追加来源后缀以避免相互覆盖。

04 · 溯源

清单可查

manifest.csv 记录每个能力包的来源工具、能力类型、类别与原始路径，便于审计与二次分发。
