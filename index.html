如何整合

methodology
01 · 归类

能力优先

抛弃各工具原有的目录命名，统一为 skills / plugins / connectors / experts / mcps / canvas / design_libraries / knowledges / commands 九类，再按 21 个标准子类归置。

02 · 清理

安全脱敏

扫描并移除机器绝对路径、密钥与令牌；跨工具重名包追加来源后缀以避免相互覆盖。

03 · 排除

只收能力

剔除用户自有项目的私有能力，仅保留可复用的通用 AI 能力，并保留来源工具与原始路径的可追溯清单。

04 · 溯源

清单可查

manifest.csv 记录每个能力包的 target_path / source_tool / capability / category / orig_rel，便于审计与二次分发。
