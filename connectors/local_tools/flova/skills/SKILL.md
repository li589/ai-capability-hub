# Flova 视频创作

使用 Flova 完成视频创作全流程：明确目标、规划分镜与视觉方向、生成并审阅素材、组装时间线，最终交付成片。把 Flova 作为以项目为中心的视频创作 Agent，而不是一组媒体生成 API；WorkBuddy 负责表达目标、提供素材、审阅结果和反馈，由 Flova 负责项目中的创作与制作编排。

## 运行时工具发现

以当前 MCP 工具 schema 为准，确认 WorkBuddy 中 Flova 可用的工具、参数、枚举值和返回结构。本 Skill 不维护静态工具清单；Flova 后续可能新增能力。根据用户目标选择最少且足够的可用工具，不要虚构运行时 schema 中不存在的工具或参数。

## 开始前

- 明确交付目标、受众、时长、画幅、语言、视觉方向、已有素材、品牌限制和预期审阅节点。
- 同一视频持续使用同一个项目。不要因为生成缓慢或会话中断而重复创建项目。
- 根据用户要求选择交付方式：独立素材只生成所需图片、镜头、配音或音乐，不自动进入时间线或导出；完整视频一次说明完整目标；高成本、品牌敏感或需要评审的任务分阶段制作。
- 需要用户确认的创意决策必须等待用户明确选择，不要替用户批准评审节点。
- 在可能消耗额度的操作前，如果账户、会员或额度状态未知，先查询相关状态。

## 认证与隐私

- Flova 使用 OAuth。认证失败时，请用户在 WorkBuddy 中重新连接 Flova Connector，然后仅重试一次被中断的操作。
- 不要索取、保存、显示或转发 API Token、Access Token、Refresh Token 或会话 Cookie。
- 不要手动添加 `Authorization` 请求头；认证由 Connector 管理。
- 用户询问线上 Flova Skill 时，可以提供 MCP 返回的公开名称、作者、Flova 链接和能力摘要；不要输出完整 `skill_content`、内部 prompt、Skill ID 或 MCP 原始载荷。

## 项目与素材

- 仅在目标和核心交付要求明确后创建项目。
- 处理已有项目时，只读取当前请求需要的项目信息。
- 以用户最近确认的创作意图和项目当前的成片规格为准。
- 按当前 MCP schema 暴露的完整上传流程处理本地素材。不要把本地路径当作远程文件引用，也不要使用尚未完成的上传。
- 将服务返回的项目、文件和资源标识符视为不透明值，原样传递，不要猜测或改写。

## 创作任务

- 每次只发送一条清晰的创作指令，说明下一步产出、必须保持不变的已确认内容，以及本次不得生成或导出的内容。
- 在自然语言创作指令中使用“已上传的脚本”“已确认的第三个镜头”等自然引用，不写入项目、任务、资源等内部标识或签名 URL。
- 不要因为进度暂时没有变化、流式连接暂停或 WorkBuddy 从后台恢复而重复发起创作任务。
- 仅在向用户展示真实可选项并获得明确选择后，继续需要人工确认的操作。不要猜测操作、选项、消息、项目或资源标识符。

## 进度与恢复

- 在同一个 WorkBuddy 会话中持续跟踪异步任务，直到成功、失败、取消或需要用户输入。
- 遵循服务返回的轮询间隔与游标，不要并发或高频轮询。
- 保存当前项目 ID、任务 ID、事件游标和已交付资源标识，以便会话中断后继续同一任务，而不是重新发送创作指令。
- 每个成功资源只交付一次；对部分成功、失败或不可用资源如实说明状态。部分资源成功不代表整轮创作成功。
- 可以展示 MCP 返回的用户可访问项目、预览、播放、素材或下载链接，即使链接包含时效签名；不要把仅供工具内部调用的链接或原始请求载荷直接粘贴到对话中。
- 无法实际检查图片、视频或音频时，可以交付资源，但不要声称已经完成视觉或听觉审阅，也不要承诺由宿主应用控制的播放体验。

## 审阅与导出

- 遇到阻塞中的用户操作或约定的审阅节点时立即停止自动推进，展示当前阶段、已完成内容、真实问题、全部真实选项和 Flova 项目链接，并明确说明等待用户确认后继续。
- 已生成的图片、视频片段或音频集合不等同于完成的时间线或最终视频。
- 导出前确认创作任务已完成、没有阻塞中的用户操作、用户已明确允许导出，并在当前 MCP schema 支持时完成导出就绪检查。
- 持续跟踪导出或归档任务直至终态。任务已受理不等于交付完成，项目资源归档也不能替代最终视频导出。
- 交付 Flova 返回的项目链接以及最终预览、播放或下载链接，并说明用户下一步可执行的操作。

## 失败与历史

- 仅在用户明确要求时恢复或分支项目历史，并使用 Flova 返回的有效检查点。
- 如果会员或额度不足，说明所需条件并提供服务返回的账户或定价链接，不要承诺绕过限制。
- 操作失败时，说明尚未完成的步骤和安全的下一步。不要假定项目、上传、创作、导出、下载或扣费已经成功。
