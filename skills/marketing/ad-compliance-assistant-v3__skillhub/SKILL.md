## 零、法规时效性原则（动态版本确认铁律，必读）

本 Skill 的内化边界必须严格切分「知识层」与「法规版本层」——这是本 Skill 能否跨年度长期可用的核心，执行者被调用时务必遵守。

### 0.1 两层切分
- **知识层（Skill 内置，相对稳定）**：广告合规风险框架、载体识别边界、自查清单逻辑、行业关联法规梳理方法。这部分源于书籍内化，跨年度变化慢，可直接调用。
- **法规版本层（运行时确认，逐年剧变）**：具体法条文本、条文序号、施行日期、修订/修正/废止状态、罚则数额、司法解释、部门规章与地方性法规版本。**法律持续修订——广告法及 2025 年《反不正当竞争法》修订、2026 年《直播电商监督管理办法》等更新极快，内置年份仅为成书/核实时点快照。Skill 内置的年份/版本只是成书时点快照，绝不保证"现行有效"。**

### 0.2 版本确认铁律（最关键）
- 用户在 **N 年**调用本 Skill → 涉及的具体法规，必须确认其 **N 年（或最新）现行有效文本与修订状态**。
- 本 Skill 内化的书籍多为 **2024 年及以前**成书（已补充 2025-2026 最新动态并经 WebSearch 核实），其引用的法条版本可能已修订、已废止或已有新司法解释。**2025 年及以后调用，严禁直接引用内置年份版本作答具体条款，必须先在线确认。**

> 结论：执行者被调用时，**涉及具体法条/罚则/版本状态的问题，第一步先在线确认现行有效文本**，再作答。Skill 内置的任何法条年份、条文序号都只是"成书时点参考"，不是现行答案。

### 0.3 必须在线确认的情形（缺确认不可断言"现行/有效/已修订/未修订"）
1. 具体法条条文、序号、罚则数额（如赔偿金倍数、罚款区间、刑期）。
2. 法规的施行日期与修订/修正/废止状态（是否已被新法替代）。
3. 最新司法解释、部门规章、地方性法规版本。
4. 烟草/医药/医美/化妆品/电子烟等特殊行业配套规章。

### 0.4 推荐官方数据源（优先级从高到低）
- **全国人大法律法规数据库**（flk.npc.gov.cn）：法律、司法解释权威文本。
- **国务院政策文件库 / 司法部**：行政法规、部门规章。
- **最高人民法院**：司法解释与指导案例。
- **各部委官网**：市场监管总局、人社部、发改委、财政部等对应领域最新规定。

### 0.5 执行者动作规范
- 凡用户问"某法第 X 条怎么规定""罚多少""现在还有效吗""已经修订了吗"等，**必须先联网确认现行有效文本再作答**，不得以 Skill 内置年份版本断言"现行/已修订/未修订"。
- 若在线确认失败，必须明确告知"未核实最新版本、结论仅供参考"，并给出官方查询路径，**不得编造任何法条/罚则/版本状态**。
- Skill 内若引用具体法条年份，一律标注「成书时点版本，以官方最新文本为准」。

# 广告与营销合规风控助手

> ⚠️ **重要边界声明（必读）**
> 1. 本 Skill 是**知识辅助与自查工具**，不是广告内容审核工具，也不能替代执业律师、法务或合规人员的最终审查。
> 2. 本 Skill 基于截至书架书籍成书时（多为 2024 年及以前）的法规与案例，并已补充 2025-2026 年最新监管动态（详见第二节第 12-13 条，均经 WebSearch 核实）。**法律法规持续更新，用户应以国家市场监督管理总局、全国人大及其常委会、最高人民法院等官方最新文本为准。**
> 3. 若涉及重大营销投放、高额广告费、特殊行业（医疗/药品/医疗器械/保健食品/金融/房地产/教育培训等）或潜在投诉举报，**必须建议用户调用 contract-review-expert（合同审查专家）或 sme-legal-risk-scanner（中小企业法务风险扫描）做进一步把关，并咨询专业律师。**
> 4. 本 Skill 不保证覆盖全部法规、地方性规定或最新个案裁判口径，**输出结论不构成法律意见**。
> 5. **【载体识别能力边界·关键】** 本 Skill 以文本输入为主要处理对象。广告物料若以**视频（口播/字幕/画面帧）、动态 H5、交互式落地页、音频、图文混排**等载体呈现，其中大量信息（视频帧内文字、画面暗示、交互逻辑、动态数据）**超出当前人工智能 OCR/多模态辨识的技术极限**，本 Skill 无法保证识别完整。用户**不得**将本 Skill 视为对视频/动态/H5 物料的"全面审查"工具；此类物料必须由人工逐帧、逐态复核，并经执业律师/合规人员最终确认后方可发布。
> 6. **【行业法延展边界·关键】** 特殊行业广告**不仅受《广告法》约束，还受该行业专门法律/行政法规/部门规章约束**（如烟草受《烟草专卖法》、药品受《药品管理法》、医美受《医疗美容服务管理办法》等）。本 Skill 第五节B已逐项标注关联法规；因书籍可能滞后，**凡涉及行业专门法，必须提示用户以官方最新文本为准、必要时 WebSearch 核实或咨询该领域律师**。

## 三、工作流

1. **明确场景与物料**：请用户说明是广告文案、直播脚本、短视频口播、海报、落地页、电商详情页、种草笔记、促销话术、还是内部培训。
2. **明确行业**：是否属于医疗、药品、医疗器械、保健食品、特殊医学用途配方食品、农药、兽药、饲料添加剂、金融投资、房地产、教育培训、酒类、化妆品、食品、母婴、烟草/电子烟等敏感行业。**若为上述行业，必须同步提示其关联行业监管法规（见第五节B），并要求用户核实官方最新文本。**
3. **明确主体身份**：广告主、广告经营者、广告发布者、广告代言人、直播平台、直播间运营者、MCN 机构、电商经营者中的哪一类或哪几类。
4. **输出合规风险清单**：对照本章第四节"通用红线"、第五节"特殊行业"、第六节"互联网/直播特别规则"逐条提示风险。
5. **给出整改建议**：用"删除/修改/补充证据/增加显著标识/咨询专业人士"等可执行动作表达。
6. **输出自查表**：提供一份结构化的《广告合规自查表》，供用户内部流转。
7. **触发专业把关**：如涉及合同、重大投放、特殊行业或高罚款风险，提示调用 contract-review-expert 或 sme-legal-risk-scanner，并建议咨询执业律师。

## 四、通用红线清单（所有广告必看）

### 4.1 导向与政治红线
- 不得使用或变相使用国旗、国歌、国徽，军旗、军歌、军徽进行商业宣传。
- 不得使用或变相使用国家机关、国家机关工作人员名义或形象。
- 不得损害国家尊严或利益、泄露国家秘密。
- 不得妨碍社会安定、损害社会公共利益。
- 不得妨碍社会公共秩序或违背社会良好风尚（低俗、迷信、暴力、淫秽、赌博、恐怖血腥等）。
- 不得含有民族、宗教、性别、地域等歧视性内容。
- 不得妨碍环境、自然资源或文化遗产保护。
- 严禁借党和国家重要节日、重大活动进行不当商业营销宣传。

### 4.2 绝对化用语（广告法第九条第三项）
- 典型禁用词：国家级、最高级、最佳、第一、顶级、绝版、唯一、首选、销量冠军、遥遥领先（无证据时）等。
- **注意**："第一""领先"等若确有证据且引证内容真实、准确、有出处，并标明出处和适用范围，可能可以抗辩，但风险极高，建议谨慎。

### 4.3 虚假宣传与误导（广告法第四条、第二十八条）
- 不得对商品的性能、功能、产地、用途、质量、成分、价格、生产者、有效期限、销售状况、曾获荣誉等作虚假或引人误解的宣传。
- 常见高风险表述：
  - 无法验证的数据、排名、市场份额；
  - 虚构用户评价、销量、抢购氛围；
  - 夸大功效、治愈率、有效率；
  - 将普通食品/化妆品宣传为具有疾病预防/治疗功能。

### 4.4 引证内容合规（广告法第十一条）
- 引证内容必须真实、准确，并标明出处。
- 引证内容涉及数据、统计资料、调查结果、文摘、引用语等，应标明出处和有效期限（若有过期风险）。
- 不得引用无效、过期、无法验证或断章取义的内容。
- **2026 年重点**：市场监管总局拟出台《广告引证内容执法指南》，预计对数据引证、比较广告、行业排名等进一步收紧。

### 4.5 涉及专利/荣誉/许可
- 未取得专利权的，不得在广告中谎称取得专利权。
- 禁止使用未授予专利权的专利申请和已经终止、撤销、无效的专利作广告。
- 涉及行政许可、资质、荣誉、认证的，应确保真实有效，并建议保留证明文件备查。

### 4.6 贬低竞争对手
- 广告不得贬低其他生产经营者的商品或服务。
- 比较广告必须客观、真实、有依据，不得误导消费者。

### 4.7 未成年人与特殊群体保护
- 不得利用不满十周岁的未成年人作为广告代言人。
- 不得针对未成年人发布不利于其身心健康的广告（如酒类、博彩等）。
- 不得损害未成年人或残疾人的身心健康。

### 4.8 反不正当竞争（2025 年修订《反不正当竞争法》，2025-10-15 施行）
- **虚假宣传**：误导对象由"消费者"扩展为"消费者和其他经营者"；明确不得通过"虚假评价/刷单炒信"帮助他人虚假宣传。
- **商业诋毁**：对象由"竞争对手"扩展为"其他经营者"，禁止指使他人编造传播虚假信息损害他人商誉。
- **网络不正当竞争**：不得利用数据/算法/技术/平台规则实施不正当竞争；不得滥用平台规则指使他人虚假交易/虚假评价/恶意退货。
- **"内卷式"竞争规制**：平台不得强制平台内经营者低于成本销售。
- 促销/种草场景下的"刷评""恶意比价""虚构销量"均可能触发本条，与广告法虚假宣传竞合。

### 4.9 价格欺诈红线（2022 年《明码标价和禁止价格欺诈规定》，2022-07-01 施行）
- 禁止七类价格欺诈：谎称政府定价、低价诱骗高价结算、虚假折价/减价/价格比较、欺骗性语言文字数字图片视频标示价格、无正当理由拒绝履行价格承诺、**不标示或显著弱化标示不利价格条件**（如"最低消费才享折扣"结账才告知）、积分礼券拒不按约定折抵。
- **"原价/划线价"**：被比较价格须真实准确；未标明详细信息的，不得高于七日内最低成交价。
- 网络促销：首页标示价不得低于详情页；促销范围/规则须与实际一致。

## 五、特殊行业广告审查要点

### 5.1 医疗、药品、医疗器械
- **前置审查**：发布前须经广告审查机关审查，取得广告批准文号。
- **禁止内容**：不得含有表示功效、安全性的断言或保证；不得说明治愈率或有效率；不得与其他药品、医疗器械功效和安全性比较；不得利用广告代言人作推荐、证明。
- 处方药广告只能在国务院卫生行政部门和药品监管部门共同指定的医学、药学专业刊物上发布。
- 非处方药广告应显著标明"请按药品说明书或者在药师指导下购买和使用"。

### 5.2 保健食品
- 发布前须经审查，取得广告批准文号。
- 不得涉及疾病预防、治疗功能。
- 应显著标明"保健食品不是药物，不能代替药物治疗疾病"。
- 不得利用广告代言人作推荐、证明。

### 5.3 特殊医学用途配方食品
- 参照药品广告管理，发布前须经审查。
- 不得在大众传播媒介或公共场所发布面向大众的广告。

### 5.4 农药、兽药、饲料和饲料添加剂
- 发布前须经审查。
- 不得含有表示功效、安全性的断言或保证；不得说明有效率；不得与其他产品比较功效和安全性。

### 5.5 金融投资类广告
- 不得对未来效果、收益或相关情况作出保证性承诺，明示或暗示保本、无风险或保收益（国家另有规定的除外）。
- 应显著提示"投资有风险，入市需谨慎"等风险内容。
- 不得夸大过往业绩或收益情况。

### 5.6 房地产广告
- 不得含有升值或投资回报承诺。
- 不得以项目到达某一具体参照物的所需时间表示项目位置。
- 不得对规划或建设中的交通、商业、文化教育设施等作误导宣传。
- 涉及面积的，应标明为建筑面积或套内建筑面积。
- 不得含有封建迷信、有悖社会良好风尚的内容。

### 5.7 教育培训广告
- 不得对升学、通过考试、获得学位学历或合格证书，或对教育培训的效果作出明示或暗示的保证性承诺。
- 不得明示或暗示有相关考试机构或其工作人员、考试命题人员参与教育、培训。
- 不得利用科研单位、学术机构、教育机构、行业协会、专业人士、受益者的名义或形象作推荐、证明。
- **2026 年地方监管重点**：多地市场监管局将教育培训广告列为民生领域违法广告整治重点。

### 5.8 酒类广告
- 不得诱导、怂恿饮酒或宣传无节制饮酒。
- 不得出现饮酒动作。
- 不得表现驾驶车、船、飞机等活动。
- 不得明示或暗示饮酒有消除紧张和焦虑、增加体力等功效。

### 5.9 化妆品/食品
- 化妆品广告不得涉及产品功效的虚假或夸大宣传，不得明示或暗示产品具有医疗作用。
- 普通食品不得宣传疾病预防、治疗功能；不得借助"药食同源"概念暗示疗效。

### 5.10 烟草与电子烟
- 禁止在大众传播媒介或公共场所、公共交通工具、户外发布烟草广告。
- 禁止向未成年人发送任何形式的烟草广告。
- 电子烟参照卷烟有关规定执行。

## 五B、行业关联监管法规延展边界（关键：广告法不是唯一适用法）

> ⚠️ **本节是老板特别强调的风险防火墙。** 特殊行业广告**不仅受《广告法》约束，还受该行业专门法律/行政法规/部门规章约束**。书籍多为 2024 年及以前成书，部分延展法规为 2025-2026 年新修订或书里未覆盖，本 Skill 已通过 WebSearch 核实并在下方逐项标注，**但最终必须以官方最新文本为准，重大情形须咨询该领域执业律师。**

### 5B.1 烟草 / 电子烟（延展至烟草专卖体系）
- **《广告法》第22条**：禁止在大众传播媒介或公共场所、公共交通工具、户外发布烟草广告；禁止向未成年人发送任何形式的烟草广告。
- **《烟草专卖法》《烟草专卖法实施条例》**：烟草制品本身受专卖管理。
- **《电子烟管理办法》（国家烟草专卖局令第1号，2022-05-01 施行）+ 加强监管通知（2022-10-01）**：电子烟广告**全面参照卷烟**——禁止在大众传播媒介/公共场所/公共交通工具/户外发布；禁止向未成年人发送任何形式电子烟广告；禁止利用其他商品或服务广告、公益广告宣传电子烟名称/商标/包装/装潢；禁止举办推介电子烟产品的展会/论坛/博览会。
- **《电子烟警语标识规定》（2022-05）**：电子烟及其包装禁用"保健、疗效、安全、环保、低危害、减害、戒烟、替代、高品质、性能提升、过瘾、不伤身"等功效用语。
- **风险提示**：电子烟监管由烟草专卖行政主管部门（国家烟草专卖局）主导，违规后果不同于普通广告违法，且**电子烟≠普通商品广告**，边界更严。

### 5B.2 药品 / 医疗器械 / 保健食品 / 特殊医学用途配方食品（延展至药品/器械/食品安全体系）
- **《广告法》第16条（药品医疗器械）/ 第18条（保健食品）**：前置审查、禁功效断言、禁治愈率有效率、禁代言。
- **关联行业法（远超广告法）**：
  - 《药品管理法》《药品管理法实施条例》：药品全生命周期监管。
  - 《药品广告审查发布标准》《药品广告审查办法》《互联网药品信息服务管理办法》《药品网络销售监督管理办法》：药品广告审查与网络销售专门规则。
  - 《医疗器械监督管理条例》《医疗器械广告审查发布标准》：医疗器械分类监管与广告审查。
  - 《保健食品注册与备案管理办法》《保健食品标注警示用语指南》：注册备案与"保健食品不是药物，不能代替药物治疗疾病"警示用语。
- **风险提示**：上述行业广告批准文号由广告审查机关核发；未取得批文发布或广告内容与批准内容不一致，属严重违法。

### 5B.3 医疗 / 医疗美容（延展至医疗卫生体系）
- **《广告法》第16条 + 第17条**：医疗广告前置审查、禁功效断言、禁治愈率；非医疗广告不得涉疾病治疗功能、不得使用医疗用语。
- **《医疗广告管理办法》**：发布医疗广告须取得《医疗广告审查证明》，标注医疗机构第一名称与审查证明文号。
- **《医疗美容服务管理办法》（卫生部令第19号）+《医疗美容广告执法指南》（市场监管总局 2021-11）**：医美属医疗广告；禁保证性承诺（"100%安全/零风险"）、禁患者/代言人前后对比证明、禁变相发布；**生活美容机构不得发布医疗美容广告**。
- **地方新规**（如北京市朝阳区 2026-04《医疗美容行业广告宣传合规指引（试行）》）：视频广告须全程标识审查证明文号。

### 5B.4 食品 / 化妆品（延展至食品安全与化妆品监管体系）
- **《广告法》第17条 + 第18条**：普通食品不得宣传疾病预防治疗功能；化妆品不得涉医疗作用。
- **《食品安全法》及条例 +《食品标识管理规定》+《网络食品安全违法行为查处办法》**：食品标识与宣传边界。
- **《化妆品监督管理条例》（国务院令第727号，2021-01-01 施行）第43条**：化妆品广告不得明示暗示医疗作用、不得虚假误导。
- **《化妆品标签管理办法》（国家药监局 2021）**：13 项禁用标注语（医疗术语、承诺性语言"无效退款/保险公司承保"等）。
- **牙膏**：参照普通化妆品管理，可宣称防龋/抑牙菌斑等功效但须备案评价。

### 5B.5 房地产（延展至城市房地产管理法）
- **《广告法》第26条**：禁升值回报承诺、禁以时间表示位置、禁误导规划配套。
- **《房地产广告发布规定》**：证照公示、面积标注、周边设施表述等专门规则。

### 5B.6 金融投资（延展至分业金融监管体系）
- **《广告法》第25条**：禁保本保收益承诺，须显著提示风险。
- **关联监管（分业）**：银行（理财销售管理办法）、证券（基金/资管销售合规）、保险（《商业银行代理保险业务管理办法》）等均有专门规章；金融广告还受央行《金融消费者权益保护实施办法》约束。
- **风险提示**：金融广告违规可能涉及非法金融活动，后果远超行政处罚。

### 5B.7 教育培训（延展至民办教育法）
- **《广告法》第24条**：禁升学/考试/证书效果承诺，禁考试机构人员参与，禁受益者推荐证明。
- **《民办教育促进法》及实施条例**：培训机构设立与广告边界。

### 5B.8 酒类 / 农药 / 兽药 / 饲料（延展至专门审查标准）
- **《广告法》第23条（酒类）/ 第21条（农药兽药饲料）**：酒类禁诱导饮酒/饮酒动作/驾驶表现；农药兽药饲料须前置审查、禁功效断言。
- **《酒类广告管理办法》《农药广告审查发布标准》《兽药广告审查发布标准》**：专门审查规则。

### 5B.9 母乳代用品
- **《广告法》第20条**：禁止在大众传播媒介或公共场所发布声称替代母乳的婴儿乳制品/饮料和其他食品广告。
- **提示**：原《母乳代用品销售管理办法》已废止，现行以广告法第20条为主；不得暗示"更接近母乳""替代母乳"。

### 5B.10 互联网广告 / 精准营销的关联法（延展至个人信息保护体系）
- **《个人信息保护法》（2021-11-01 施行）第24条**：用户画像/精准营销/自动化决策推送，须提供不针对个人特征的选项或便捷拒绝方式；不得大数据杀熟；**敏感个人信息（医疗健康/金融账户/行踪轨迹/不满14周岁未成年人等）处理须单独同意**。
- **《数据安全法》《网络安全法》**：数据处理与网络安全底线。
- **指导性案例265号（最高法 2025）**：非服务必需强制收集用户画像侵害个人信息权益。
- **风险提示**：精准营销/用户画像的合规由网信与工信部门主导，与广告监管交叉，违规可触发个人信息保护责任。

## 六、互联网广告与直播电商特别规则

### 6.1 互联网广告可识别性（广告法第十四条、互联网广告管理办法）
- 通过知识介绍、体验分享、消费测评等形式推销商品或服务，并附加购物链接等购买方式的，**应显著标明"广告"**。
- 弹窗广告应显著标明关闭标志，确保一键关闭。
- 不得利用互联网发布影响用户正常使用网络的广告。

### 6.2 互联网广告主体义务
- **广告主**：对广告内容真实性负责。
- **广告经营者、发布者**：应建立、健全广告业务承接登记、审核、档案管理制度。
- **互联网信息服务提供者**：对利用其信息服务发布的违法广告，应予以制止；明知或应知违法的，不得提供信息服务。

### 6.3 直播电商新规（2026 年 2 月 1 日《直播电商监督管理办法》）
- **四类主体**：直播电商平台经营者、直播间运营者、直播营销人员、直播营销人员服务机构（MCN 机构）。
- **平台责任**：资质核验、信息报送、培训机制、分级分类管理、信用评价、违法处置、动态管控、投诉机制等。
- **直播间运营者**：对信息公示、商品核验、内容合规承担首要义务。
- **直播营销人员**：对宣传内容真实性负责。
- **MCN 机构**：严格核验主播身份、规范主播管理、做好选品核验并留存记录，严禁协助虚假宣传。
- **AI 数字人直播**：使用人工智能生成的人物图像、视频从事直播电商活动的，**应当进行标识，并持续向消费者提示**。
- **私域直播**：纳入调整范围，其他网络服务提供者根据具体服务内容依法履行相应平台经营者义务。
- **流量管控**：监管部门可将直播间运营者、直播营销人员、MCN 机构违法情况通报平台，平台应及时采取警示、限制功能、限制流量、暂停直播、关闭账号、列入黑名单等措施。

### 6.4 网络交易平台新规（2026 年《网络交易平台规则监督管理办法》）
- 平台不得利用规则不合理限制平台内经营者自主经营、收取不合理费用、不合理"罚款"、减损会员权益。
- 禁止"二选一"、只收费不服务、强迫低价倾销、强迫参与推广促销并收费。
- 限制消费者自主选择商品、限制消费者投诉举报权、"大数据杀熟"等被明确列为典型违法情形。
- 平台规则应清晰明了、便于阅读，并以显著方式提示收费、争议解决等重要内容。

### 6.5 广告代言与 KOL/KOC
- 广告代言人在广告中对商品、服务作推荐、证明，应依据事实，符合法律、行政法规规定，不得为其未使用过的商品或未接受过的服务作推荐、证明。
- 未满十周岁未成年人不得代言。
- 在虚假广告中作推荐、证明受到行政处罚未满三年的自然人、法人或其他组织，不得作为广告代言人。
- **KOL/KOC 种草**：若与品牌存在商业合作（收取费用或免费置换），构成商业广告的，必须显著标明"广告"；不能伪装成纯消费者体验分享。

| 场景 | 常见风险点 | 建议动作 |
|------|-----------|----------|

## 付费前置检查（微信 X402 协议）

调用本 Skill 前，先检查当前 Agent 是否已安装 `weixinpay` 插件（extension）：

- 已安装：可继续提供付费服务
- 未安装：向用户提示「当前 Agent 暂不支持微信支付付费能力」，终止流程

## 支付触发（首次请求收到 HTTP 402）

向本 Skill 的 `endpoint` 发起 POST 请求，若收到 HTTP 402 响应，`weixinpay` 插件会拦截并完成支付流程：

- Header `WeixinPay-Required`：支付凭证码（插件用于完成支付）
- Header `X-Out-Trade-No`：商户订单号

> 支付过程由 `weixinpay` 插件处理，Skill 无需关心支付细节。

## 重试机制（支付成功后必须重新请求）

支付成功后，**必须**重新发起请求获取付费内容：

- JSON body 与首次请求完全一致
- 通过 Header 携带支付信息：`WeixinPay-Required` 和 `X-Out-Trade-No` 原样带上

## 订单号传递规范

- 商户订单号通过 402 响应的 Header `X-Out-Trade-No` 返回
- 重试请求时通过同名 Header 原样回传，不得修改

## 异常处理

- 若重试返回 `"code": "NOT_PAID"`：支付尚未完成，等待后重试
- 若返回 `"code": "REFUNDED"`：服务异常已退款，告知用户并终止
- 若返回 `"code": "REFUND_FAILED"`：服务异常且退款失败，建议联系客服
