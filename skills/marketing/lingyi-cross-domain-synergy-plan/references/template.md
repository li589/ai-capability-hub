# 公私域联动方案生成模板

使用本模板来产出承接四件套：触点地图、承接链路图、渠道优先级、承接期触达 SOP。按业务选默认参数档填空，每件套后过质量检查。

> **四行业默认链路档**（按业务模式套用，再微调）：
> - **餐饮高频复购**（茶饮/快餐）：主入口=门店扫码 + 公域种草导活码；链路=抖音/小红书→活码→企微 7 天新客 SOP→小程序秒杀首单→复购券。社群 1v 多（秒杀/拼团），非 1v1 顾问。
> - **电商跨品类**（美妆/服饰 DTC）：主入口=包裹卡 + 公域种草；链路=线上店铺→包裹卡加 IP 企微→社群分层（促销群/种草群）→小程序复购。包裹卡 Effort 低 Impact 高。
> - **线下到店为主**（生鲜/商超/零售门店）：主入口=门店 POP/收银小票/导购码；链路=线下扫码→社群→周二会员日权益绑定→线上下单线下提货。总部定 SOP 门店最小执行。
> - **服务预约/高客单低频**（教培/SaaS/医美/汽车）：主入口=视频号+广告；链路=广告/视频号→企微 1v1 顾问→小程序不适用改表单/预约→线索培育 SOP（行业报告→沙龙→案例）。1v1 顾问式，非社群 1v 多。

## 模板

```markdown
### 口径与目标（前置）
- 业务模式：[餐饮高频复购 / 零售客单周期 / 电商跨品类 / 服务预约 / 线下到店]
- 私域载体：[企微 / 社群 / 小程序 / 公众号 / 个微（可多选）]
- 主要公域流量来源：[抖音 / 小红书 / 视频号 / 朋友圈广告 / 搜一搜 / 电商店铺 / 门店（可多选）]
- 首要运营目标：[公转私沉淀 / 首购转化 / 复购提升 / 门店导流 / 会员成长（排优先级）]
- 预算/人力约束：[月预算 X、N 名运营] 或 【待印证·按经验估】
- 现有数据源：[订单 / 互动 / 社群活跃 / 门店 POS] 或 【待印证·薄弱数据先用区间基准】

### 一、触点地图（13 列盘点表）

| # | 触点名称 | 所属平台载体 | 触点类型 | 生命周期阶段 | 承接动作(用户侧+运营侧) | 沉淀位置 | 参考指标 | 负责人 | 优先级 | 触达频次上限 | 引流诱饵 | 转化目标 KPI | 关联触点 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | [如 门店收银台扫码] | [线下/小程序] | [公域/半私域/私域/线下] | [引入期/成长期/成熟期/休眠期/流失期] | [用户:扫码支付 / 运营:推券+打标签] | [企微好友] | [支付后关注20-35%] | [导购] | [必做/优先/观察/暂缓] | [如每日1次] | [新人券] | [加粉率] | [小程序支付页] |
| 2 | [...] | | | | | | | | | | | | |

> 触点全枚举（按业务裁剪，不必全用）：
> - 公域：朋友圈广告 / 公众号文章广告 / 视频号原生广告 / 搜一搜 / 抖音·小红书种草 / 电商平台包裹
> - 半私域：公众号(关注自动回复/菜单栏/推文/模板消息) / 视频号(主页企微入口/直播间/私信) / 搜一搜品牌官方区
> - 私域：企微(1v1/朋友圈/社群/活码) / 导购个微 / 小程序(首页/详情页/支付成功页/订阅消息) / 社群(群公告/欢迎语) / 会员系统
> - 线下：门店(收银扫码/POP/导购码) / 包裹卡 / 线下活动 / 户外广告带码

**质量检查：** 核心触点四类（公域/半私域/私域/线下）每类≥1 个；触达频次上限标【待印证·按业务校准】；参考指标用区间（如公转私沉淀 5-15%）。

### 二、承接链路图（6 阶段）

| 阶段 | 节点(触点) | 用户动作 | 承接动作 | 沉淀位置 | 后续触达 |
|---|---|---|---|---|---|
| 1.公域种草 | [抖音/小红书/视频号/广告] | [浏览/点赞/评论] | [渠道活码自动打标] | [待沉淀] | [引流至沉淀触点] |
| 2.私域沉淀 | [公众号菜单/包裹卡/门店码/支付页] | [关注/扫码/加好友] | [欢迎语+新人礼+标签] | [企微+社群+小程序会员] | [7 天新客 SOP] |
| 3.活跃培育 | [企微1v1/社群/朋友圈/推文] | [阅读/互动/点击] | [内容种草+福利钩子] | [活跃用户] | [生命周期分层触达] |
| 4.转化变现 | [小程序商城/直播/社群秒杀] | [下单/支付] | [订单标签+复购券] | [成交会员] | [复购提醒+升单] |
| 5.会员成长 | [会员中心/积分商城] | [升级/兑换] | [等级权益匹配] | [高价值池] | [专属服务+裂变激励] |
| 6.流失召回 | [短信/AI外呼/企微1v1] | [唤醒/回流] | [召回券+调研] | [重新激活] | [二次培育] |

**质量检查：** 6 阶段每阶段≥1 个触点节点；每节点「沉淀位置」=下阶段「入口」（无断点）；断点标红补承接动作。

### 三、渠道优先级（RICE 评分表）

| 渠道 | 类型 | Reach(规模×漏斗) | Impact(3/2/1/0.5/0.25) | Confidence(100/80/50/20%) | Effort(人月) | Score=(R×I×C)÷E | 优先级档 |
|---|---|---|---|---|---|---|---|
| [门店扫码] | [线下] | [数值] | [数值] | [数值] | [数值] | [计算值] | [必做/优先/观察/暂缓] |
| [...] | | | | | | | |

> 评分量表：
> - Reach = 可承载规模 × 转化漏斗（如视频号 Reach 高但转企微 5-15%；企微 Reach 低但首购 20-35%）
> - Impact：3=直接影响付费/留存 / 2=中 / 1=轻 / 0.5/0.25=极低
> - Confidence：100%有数据 / 80%中等 / 50%估算 / 20%=登月
> - Effort：人月（研发+设计+运营），最小 0.5
> - 渠道类型按业务反推：高频高客单→1v1 顾问；高频低客单→社群 1v 多

**质量检查：** R/I/C/E 四维均给数值，禁「高/中/低」模糊词；Score 必须可计算；按业务反推链路类型（矛盾则异常 4）。

### 四、承接期触达 SOP（12 字段表）

| SOP 名称 | 适用阶段 | 触发条件(用户状态事件) | 触达渠道 | 触达时间间隔 | 文案模板(≤100字) | 内容类型 | 负责人 | 数据指标 | 异常处理 | 复盘节点 | 版本号 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| [新客7天承接SOP] | [新客承接] | [加好友通过时] | [企微1v1] | [Day1/3/7] | [钩子+价值点+CTA] | [品牌背书/产品教育/利益驱动] | [社群运营] | [打开率/互动率] | [回复→暂停;咨询→转人工] | [每周] | [V1.0] |
| [首购转化SOP] | [首购转化] | [浏览未购N天/首购后第3天] | [...] | [...] | [...] | [...] | [...] | [...] | [...] | [...] | [...] |
| [跨触点编排SOP] | [跨触点编排] | [公众号关注后/社群活跃后] | [...] | [...] | [...] | [...] | [...] | [...] | [...] | [...] | [...] |

> 承接期 SOP 三条主干：
> - **新客 7 天承接**：加好友通过→破冰 Day1-3（品牌背书类）→培育 Day4-7（产品教育类）→首单钩子
> - **首购转化**：浏览未购 N 天 / 加购未付 / 首购后第 3 天复购预埋
> - **跨触点编排**：公众号→企微活码→社群→小程序的跨触点状态流转
>
> 文案模板规则：≤100 字，一条一核心点；结构=钩子+价值点+CTA+素材。内容比例参考 营销:互动:关怀:日常=3:3:3:1。
> **边界：成熟期/沉睡召回的全生命周期分层触达归分层触达技能，不写进本技能 SOP。**

**质量检查：** 触发条件必须是用户状态事件（加好友通过/7 天未互动/首购后第 3 天），纯定时（每天 8 点发）→反模式要求改状态化（异常 5）。

### 五、承接 KPI（区间基准）

| KPI | 计算口径 | 行业基准 | 警戒 |
|---|---|---|---|
| 加粉率 | 触达→加企微好友比例 | 5-15% | <5% 链路或诱饵弱 |
| 沉淀率 | 加粉→进群/留资比例 | 50-70% | <40% 承接动作弱 |
| 首购转化率 | 加粉→首单比例 | 20-35%（企微） | <15% 培育 SOP 失效 |
| 7 天留存率 | 加粉 7 天仍活跃 | 60-75% | <50% 流失风险 |
| 消息打开率 | SOP 消息打开比例 | 30-50% | <30% SOP 时机/分层问题 |

**质量检查：** 基准一律用区间非点值，标【按业务校准】（异常 2）；无数据源标【待印证】。

### 六、迭代咬合

- 触达反馈回灌：SOP 打开率<30%→检查触达时机/分层；互动率<10%→检查内容价值点
- 渠道优先级重算：月度用真实 R/E 复算 RICE，淘汰末 20% 低效渠道
- 联动姊妹技能：承接用户→分层触达技能做 RFM 分群；首单用户→会员积分技能做会员成长
- 咬合点：本技能承接进来的用户 = 分层触达技能的分层对象

**质量检查：** 迭代节奏明确（月度 RICE + 每周 SOP 复盘）；姊妹技能咬合点明确。
```
