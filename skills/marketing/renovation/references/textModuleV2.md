# 文本组件字段速查表（moduleCode: `textModuleV2`）

> 本文件是 `textModuleV2` 组件**唯一合法的 fieldKey 来源**。设置 values 时 key 必须取自本文件，不得猜测、不得用 CSS 名。
> key 规则：非数组字段直接用叶子 key 名，**不要加 `style.`/`content.` 前缀**；颜色用十六进制 `#RRGGBB`；**枚举字段传整数，不传字符串**（如 `fontSize: 28` ✅，`fontSize: "28"` / `fontSize: "small"` ❌）。

---

## 组件整体效果 / 用途

**一段正文文字**：放大段文字内容（≤1000 字），可设字号/颜色/对齐/粗斜体下划线/背景。`displayStyle`：`0`=平铺（全文展开），`1`=折叠（超长收起，点击展开）。常用于活动说明、规则、品牌介绍等需要成段文字的地方。与"标题组件"区别：标题是一行短标题，文本是成段正文。

适合：活动说明、规则条款、品牌故事、图文页正文。

---

## 一、用户描述 → 字段key 速查表

| 用户可能说的 | 字段key | 合法值 |
|---|---|---|
| 文本内容 / 改文字 | `text` | 字符串，1–1000 字 |
| 展示样式 / 平铺或折叠 | `displayStyle` | `0`(平铺展示) / `1`(折叠展示) |
| 字号小 / 字体小 / 最小字号 / 字体调小一档 | `fontSize` | `28`（**integer**）（⚠️ 本组件最小是 `28`，不是 `16` 或其他数字；titleModuleV2 的最小值是 `30`，两组件枚举不同） |
| 字号中 / 字体中等 | `fontSize` | `32`（**integer**） |
| 字号大 / 字体最大 / 字体放到最大 / 最大字号 / 字体调大一档 | `fontSize` | `36`（**integer**） |
| 对齐方式（居左/居中/居右） | `textAlign` | `0`=居左 / `1`=居中 / `2`=居右（**"居中"是 `1`，不是 `2`**） |
| 文字颜色 | `color` | 十六进制色值，如 `#212121` |
| 背景色 | `bgColor` | 十六进制色值，如 `#FFFFFF` |
| 字体样式 / 加粗 / 斜体 / 下划线 | `fontWeight` | 数组，元素取 `1`(粗体)/`2`(斜体)/`3`(下划线)，可组合，如 `[1,3]`；都不要传 `[]` |
| 恢复字体样式 / 清除加粗斜体 / 去掉所有字体效果 | `fontWeight` | `[]`（空数组 = 全部清除） |
| 上间距小 / 上边距无 | `topMargin` | `0` |
| 上间距中 / 上边距中 | `topMargin` | `16` |
| 上间距大 / 上边距大 | `topMargin` | `24` |
| 下间距小 / 下边距无 | `bottomMargin` | `0` |
| 下间距中 / 下边距中 | `bottomMargin` | `16` |
| 下间距大 / 下边距大 | `bottomMargin` | `24` |
| 跳转链接 | `link` | **固定为空对象 `{}`，不支持配置跳转**（schema 已锁死） |

## 二、顶层字段

| 字段key | 类型 | 枚举 | 默认 | 说明 |
|---|---|---|---|---|
| `styleGroup` | integer | 固定 `1` | `1` | 只有一种样式，一般无需修改 |

---

## 三、内容字段（content，用叶子 key）

| 字段key | 类型 | 约束 | 说明 |
|---|---|---|---|
| `text` | string | 1–1000 字，必填 | 文本内容 |
| `link` | object | **恒为空对象 `{}`**（schema `const:{}`） | **不支持配置跳转链接** |

> ⛔ 用户若要求"给文本配点击跳转"→ 告知"WAI 暂不支持当前操作，请在编辑器内操作"，不自造、不调工具。

## 四、样式字段（style，用叶子 key，不要加 `style.` 前缀）

| 字段key | 类型 | 枚举/约束 | 默认 | 说明 |
|---|---|---|---|---|
| `displayStyle` | integer | `0` / `1` | `0` | 0平铺 1折叠 |
| `fontSize` | **integer** | `28`(小) / `32`(中) / `36`(大) | `28` | 字号(px)；只能取这三个值；**最小值是 `28`（⚠️ 不是 `16` 或其他数字；titleModuleV2 最小是 `30`，两组件枚举不同）**；必须传整数 |
| `textAlign` | integer | `0` / `1` / `2` | `0` | `0`=居左 `1`=居中 `2`=居右（居中=1） |
| `color` | string(color) | `#RRGGBB` | `#212121` | 文字颜色 |
| `bgColor` | string(color) | `#RRGGBB` | `#FFFFFF` | 背景色 |
| `fontWeight` | array | 元素 `1`/`2`/`3`，去重 | `[]` | 1粗体 2斜体 3下划线，可组合；**恢复默认/清除效果传 `[]`** |

> ⛔ 不存在 `fontStyle` 字段（CSS 属性名，本组件无此 key）。"恢复字体样式/去掉加粗"一律用 `fontWeight: []`。
> ⛔ `fontSize` 枚举只有 `28`/`32`/`36`，**不存在 `16`、`14`、`20` 等其他数字**。本组件与 titleModuleV2 枚举不同（titleModuleV2 最小是 `30`，本组件最小是 `28`）。
| `topMargin` | integer | `0`(无/小) / `16`(中) / `24`(大) | `24` | 上边距；只能取这三个值，不得传其他数字 |
| `bottomMargin` | integer | `0`(无/小) / `16`(中) / `24`(大) | `24` | 下边距；只能取这三个值，不得传其他数字 |
