# 整页搭建总览（组件目录 + 排布模型 + 页面模板）

> 整页搭建 / 组件选型与排序前，先读本文件确定"放哪些组件、什么顺序"；确定后再读各组件 `references/<moduleCode>.md` 字段表取 fieldKey 写初始 values。

---

## 一、排布模型（先理解这个）

> 📱 **这是移动端手机版页面（H5/小程序，竖屏窄屏）**，按手机屏宽展示，不是 PC 宽屏。所有衡量都用手机视角：单列、窄屏、竖向滚动，没有 PC 那种左右多栏。

页面是**一列从上到下顺序堆叠的组件**（纵向单列，类似一个竖向 flex 列）。`build` 的 `data` 数组**顺序就是页面从上到下的顺序**——数组第 1 个在最顶，最后一个在最底。**搭页 = 选一组组件 + 定它们的上下顺序。** 像写 HTML 一样，自上而下一块块往下铺。

```
┌──────────────────────────┐  ← 手机宽度，整页纵向滚动
│  data[0]  顶部组件         │
├──────────────────────────┤
│  data[1]                  │
├──────────────────────────┤
│  data[2]                  │
├──────────────────────────┤
│  data[n]  底部组件         │
└──────────────────────────┘
```

- 没有左右分栏、没有绝对定位；想要并排效果靠组件自身样式（如图片组件横向平铺、图文导航宫格）实现，组件之间永远是上下关系。
- 组件之间的间距由各组件自己的 `topMargin`/`bottomMargin` 控制。

## 二、组件目录（调色板）—— 选型时看这里

| 组件 | moduleCode | 一句话用途 | 页面效果 | 适合用来做 |
|---|---|---|---|---|
| 轮播图 | `advPlayModuleV2` | 一屏主视觉横幅，可多图自动轮播 | 顶部大图 banner，左右滑/自动播 | 首屏主视觉、活动主图、品牌大图 |
| 标题组件 | `titleModuleV2` | 一行小标题/栏目标题，可带右侧"查看更多"入口 | 一行加粗文字，左/中对齐，右侧可选入口 | 分区标题、栏目分隔、引导入口 |
| 图片组件 | `imgModuleV2` | 一组图片，纵向平铺/横向平铺/横向滚动 | 大图竖排、或两列、或横向滚动卡片 | 卖点长图、图片专区、多图陈列 |
| 图文导航 | `imgTextNaviModuleV2` | 图标+文字的入口宫格 | 一行或多行图标按钮宫格 | 分类入口、功能导航、活动入口 |
| 文本组件 | `textModuleV2` | 一段正文文字，可折叠 | 段落文本，左/中/右对齐 | 活动说明、规则、品牌介绍 |
| 搜索组件 | `searchModuleV2` | 顶部搜索栏，可吸顶 | 一条搜索框，可带扫一扫/门店切换/热词 | 导购型首页顶部搜索 |

> 目录是"有哪些块可用"；每个组件的详细样子和各 styleGroup 差异见对应 `references/<moduleCode>.md` 顶部「组件整体效果」小节，字段在其字段表。

## 三、页面骨架模板（起手配方，可增删改序）

模板是**起手参考**，不是死规定。按用户实际诉求增删组件、调整顺序、填入文案/图片。组件顺序即数组顺序。

### 1) 推广落地页（单品/活动推广，引导转化）
```
advPlayModuleV2(主视觉横幅)
→ titleModuleV2(一句主张/卖点标题)
→ imgModuleV2(卖点长图或多图陈列)
→ imgTextNaviModuleV2(领券/参与/查看等入口)
→ textModuleV2(活动说明/规则)
```
何时用：推广某活动/单品，需要主图抓眼球 + 卖点铺陈 + 行动入口。

### 2) 活动大促页（节日/大促氛围）
```
advPlayModuleV2(大促主视觉)
→ imgTextNaviModuleV2(会场/分类入口)
→ titleModuleV2(爆款专区)
→ imgModuleV2(商品/玩法长图)
→ titleModuleV2(更多专区)
→ imgModuleV2(更多陈列)
```
何时用：618/双11 等大促，多专区、强氛围、多入口。

### 3) 品牌/店铺首页（综合导购）
```
searchModuleV2(顶部搜索，可吸顶)
→ advPlayModuleV2(品牌主视觉)
→ imgTextNaviModuleV2(分类导航)
→ titleModuleV2(精选好物)
→ imgModuleV2(商品陈列)
→ textModuleV2(品牌故事/说明)
```
何时用：常规店铺首页，搜索+导航+分区陈列。

### 4) 简单图文页（说明/介绍）
```
titleModuleV2(标题)
→ imgModuleV2(配图)
→ textModuleV2(正文)
```
何时用：规则页、介绍页、轻量内容页。

## 四、整页搭建步骤（配合 SKILL.md Case B）

1. 读本文件，按用户诉求从「组件目录」选组件、定上下顺序（可套用上面某个模板再增删）。
2. 对需要写初始内容的组件，分别读其 `references/<moduleCode>.md` 字段表，按字段表取 fieldKey 构建该组件的初始 `values`（图片走图片字段 key、文案走 `text` 等；`imgModuleV2` 改图/带图须含 `items[N].imgType: 0`）；只搭骨架可 `values: {}`。
3. 一次 `build`，`data` 数组顺序 = 页面从上到下顺序。
4. 涉及图片的组件按 SKILL.md 图片规则生成图（普通正方形、风格化长图）。
