# 私域活动策划

> 版本：v0.2.0 · 作者：小风、CoderPig

## 目的

帮运营者把「私域会员促活」跑通一条可执行链路：**日常内容栏目 → 互动活动方案 → 玩法机制 → 物料清单**，产出四件套（月度内容排期表、活动方案、玩法机制设计、物料清单BOM）。本技能是纯方法论输出，免登录免 Key、由 agent 直接产出；四件套写完后把报告 Markdown 提交服务端登记（旁路、失败不阻塞交付）。

这不是「一堆活动点子」或「一张节日促销表」，而是「先用 4321 栏目矩阵把日常内容立起来、再用 3 段节奏出可过会活动方案、用 K系数自检设计可放量的玩法、最后清物料 BOM 前置拦截超预算」。可以把它看作会员促活的结构化占位框架——把散在各处的活动经验和拼凑模板，沉淀成可执行、可复盘的四件套。

> 核心信念（来自调研）：**日常内容 × 互动玩法 × 复购转化是「三咬合」**——日常内容栏栅解决"只节日促销日常荒"（诊断低成熟信号），互动玩法把内容流量承接成参与，复购转化把活跃接住留存。三者咬合才不止于活跃（"社群活跃不是目的，卖货才是"）；三者之上还要压一层合规与防刷：广告法/诱导分享判定/未成年人保护/抽奖5条 + 防刷四闸 + 超预算前置拦截，这层防得住限流、刷量、超预算、合规踩雷。

## 输入

**最佳搭配：** 业务模式 + 私域载体（企微/社群/小程序/公众号/个微）+ 当前用户分层（新客/活跃/沉睡/高价值/流失召回）+ 活跃运营目标（日常活跃率/UGC产出/任务完成/复购转化/裂变拉新）+ 月度预算或人力。

**也有用：** 任何已有信号——现有内容/活动资产、历史活动效果、竞品玩法、数据源（订单/互动/社群活跃/任务完成）。

调用时附带的所有内容——技能名后的文本、粘贴的上下文，或附加的 `ARGUMENTS:` 行——都视为已给出的回答。直接使用并跳过其已覆盖的部分，不要重复提问。

**手头没有任何数据？那也可以。** 技会会基于业务模式先套一版默认参数（餐饮高频/零售客单周期/电商跨品类三档），标 `[默认—需验证]`，后续用真实数据回填并滚动复盘。

**示例调用：** `为企微沉淀的 3 万茶饮复购客设计会员日+UGC晒单促活活动——月预算2万，目标提升日常活跃与复购。`

### 输入字段与异常处理

| 字段 | 必填 | 异常处理（缺失/错误时怎么回） |
|---|---|---|
| 业务模式 | 是 | 缺失→追问「高频复购/客单周期/跨品类/服务预约哪类？」不假设 |
| 私域载体 | 是 | 缺失→默认企微+社群，提示确认 |
| 当前用户分层 | 是 | 缺失→追问「用户分层有几档？」无分层则内容无精准投放对象 |
| 活跃运营目标 | 是 | 缺失→追问日常活跃/UGC/任务/复购/裂变，多目标要求排优先级 |
| 月度预算/人力 | 否 | 缺失→提示"无约束则物料BOM与活动规模按经验估，标【待校准】" |
| 现有内容/活动资产 | 否 | 缺失→继续，"有存量内容/活动经验请提供避免同质化重排" |
| 数据源 | 否 | 缺失→"无数据则活跃基准用行业区间，标【待印证】" |

输出标准：四件套字段见 [references/template.md](references/template.md)；判定规则全部可量化（「如果…则…」条件句，禁"较好/一般/适度"），K系数量化给数值≥1才放量，内容配比干货≥35%且促销≤15%，活动方案必含活跃→转化咬合，物料预算合计≤总预算。完整异常场景见下方「异常场景」节。

## 核心概念

### 什么是内容与互动活动促活
对私域沉淀的、可反复触达的会员，用「日常内容栏栅养活跃、互动玩法接参与、活动方案引爆转化、物料BOM兜底执行」的四件套体系，把会员从「日常沉睡、只节日促销」拉到「持续活跃并接住复购」。

### 三咬合（混淆点·核心立论柱）
```
        日常内容（4321栏目矩阵养活跃）
       ↗            ↘
  互动玩法（任务/裂变/UGC接参与） ←← 复购转化（活跃→复购咬合）
            ↑
      合规与防刷（广告法/诱导分享/未成年保护/抽奖5条/防刷四闸/超预算拦截）压在三者之上
```
- **日常内容**：定位"靠什么养活日常活跃"，用 4321 栏目矩阵（干货40%/生活30%/证言20%/促销10%）+ 固定栏目×变量栏目，解决"只节日促销日常荒"诊断低成熟断点。
- **互动玩法**：定位"靠什么把内容流量承接成参与"，用玩法选型矩阵（低客单助力拼团/中客单任务宝/高客单分销/日常打卡答题UGC）+ 任务三阶梯 + K系数自检。
- **复购转化**：定位"活跃怎么变成复购"，用活动方案的活跃→转化咬合映射（如互动率→复购券触发），防"为活跃而活跃"虚假繁荣。
- **三咬合**：只日常内容无玩法参与起不来；只玩法无日常栏栅无内容承接；只活跃无复购咬合为活跃而活跃。三者独立都失效，咬合才成促活体系。
- **合规防刷前置**：广告法极限词/诱导分享判定/未成年人代言禁令/抽奖5条 + 防刷四闸 + 超预算前置拦截，压在三者之上——不前置就限流、刷量、超预算、合规踩雷。

### 4321 法则（内容配比，混淆点）
| 比例 | 栏目 | 作用 |
|---|---|---|
| 40% | 干货价值 | 占心智、立专业 |
| 30% | 生活人设 | 立人设、养信任 |
| 20% | 客户证言 | 社会证明、种草 |
| 10% | 促销种草 | 收订单 |
> 广告类 >30% 易被屏蔽；促销种草单独撑不起转化，需干货+证言铺垫。互动型内容白天推送、促销型晚上推送。朋友圈人均打开 ≈10 次/天（零一裂变口径），据此定频次——每天3-5条、间隔≥2h、重质不重量【待印证·按业务校准】。

### 玩法选型矩阵（混淆点）
| 客单/决策成本 | 推荐玩法 | 适用 |
|---|---|---|
| 低客单消费品 | 助力砍价/拼团/步数商城 | 高频低客单，拉参与率 |
| 中客单 | 任务宝（邀X得Y，主推） | 平衡参与与裂变 |
| 高客单/决策型 | 老带新分销（佣金绑定） | 客单支撑佣金，决策型裂变 |
| 日常促活 | 打卡签到/答题/榜单/UGC征集 | 非裂变，养日常活跃 |
> 钩子决定参与率，阶梯门槛决定裂变系数K。选型错了（低客单强行分销/高客单强行拼团）会拉不动。

### 裂变 K系数（自检工具）
- K = 人均邀请数 × 邀请转化率
- K≥1 可放量自增长，K<1 不可放量需调激励/门槛/钩子
> 仅裂变类玩法（任务宝/助力/分销/拼团）适用K；非裂变玩法（打卡/答题/UGC晒单）K不适用，改用任务完成率/UGC产出率作主指标。禁"高/中/低"模糊替代K数值。

### 为何这么做
- **日常内容荒是低成熟根因**：会员运营诊断与增长建议「内容活动」维度低成熟=「只节日促销，日常内容弱」，高成熟=「有栏目任务互动UGC运营节奏」——日常栏栅是断点，活动都建在其上。
- **活动散装拼模板必同质化**：无四件套骨架导致散装拼凑，漏字段＋同质化＋审美疲劳，参与率断崖。
- **为活跃而活跃是虚假繁荣**：活跃不接复购（知乎"活跃不是目的卖货才是"），费时费力不赚钱，必须活跃→转化咬合。
- **合规与防刷不前置必踩雷**：UGC无审核肖像授权、诱导分享假促销、抽奖缺5条、裂变无防刷，轻则限流重则被罚（新华网童模肖像判例）。
- **物料不前置必超预算延误**：无BOM导致超预算到货延误（飞书案例），须前置拦截。

### 反模式（它不是什么）
- 不是一堆活动点子——是结构化四件套，每件套有固定字段与可量化判定。
- 不是只做节日促销——日常内容栏栅是主体，节日是变量栏目之一。
- 不是为活跃而活跃——每个活动必含活跃→转化咬合，热闹但无复购触发=反模式。
- 不是只给方案不给防御——合规/防刷/超预算/同质化四道拦截前置。
- 不是一次永久有效——内容排期月度滚动、活动机制按复盘迭代、K系数按真实数据校准。

### 何时使用
- 私域有会员沉淀（企微/社群几百人以上），要做日常促活内容或会员日/节日活动
- 活跃起不来只靠节日硬撑（诊断低成熟信号），要把日常活跃拉起来
- 活动散装拼模板同质化，要四件套骨架体系化
- UGC/裂变玩法想上但怕合规/刷量踩雷

### 何时不要使用
- 刚起步用户<500、数据极薄——先跑通基础触达与事实标签，别上裂变任务宝（种子不足K难达标，见异常10）
- 纯拉新阶段（公域获客为主）——先做公域承接（公私域联动方案生成技能），促活意义不大
- 要的是会员忠诚度体系（等级/积分/权益）——用「会员体系搭建」技能
- 要的是体系健康度诊断——用「会员运营诊断与增长建议」技能（本技能是诊断后建设方）

## 应用

使用 [references/template.md](references/template.md) 获取完整的填空式结构。先按业务模式套默认参数，再按 8 步产出四件套（含可选 Excel），交付后走第 9 步旁路提交服务端；每步都过质量检查。

### 第 1 步：定活跃目标与口径

先定业务模式 + 运营目标 + 用户分层 + 指标基线，决定四件套形态。

```markdown
### 口径与目标
- 业务模式：[餐饮高频复购 / 零售客单周期 / 电商跨品类 / 服务预约]
- 私域载体：[企微 / 社群 / 小程序 / 公众号 / 个微]
- 当前用户分层：[新客 / 活跃 / 沉睡 / 高价值 / 流失召回]
- 活跃运营目标：[日常活跃率 / UGC产出 / 任务完成 / 复购转化 / 裂变拉新]
- 促活核心指标与基线：[互动率 X%→Y%；基线标【待印证·按业务校准】]
- 月度预算：[金额]
- 当前阶段：[冷启动 / 成长期 / 成熟期]
```

**质量检查：**
- 目标具体可衡量，禁"提升活跃"空泛（缺则追问量化指标）
- 用户<500且目标含裂变→触发异常10，降级为日常内容栏栅+签到打卡

### 第 2 步：搭内容栏目矩阵（4321 + 固定×变量）

按 4321 法则定栏目类型与配比，分固定栏目与变量栏目。产出 [references/template.md](references/template.md)「一、月度内容排期表」栏目矩阵。

```markdown
### 内容栏目矩阵
- 干货 40%：[每日科普/教程/避坑，立专业]
- 生活人设 30%：[店长日常/团队故事/行业见闻，养信任]
- 客户证言 20%：[测评/复购故事/UGC精选，社会证明]
- 促销种草 10%：[会员日预告/限时活动，收订单]
- 固定栏目：[干货日/证言日/互动日/会员日，周覆盖]
- 变量栏目：[节气/热点/活动期/新品上市]
- 发布节奏：[早8干货(占心智)/午12互动(养关系)/晚8种草(收订单)，间隔≥2h]
```

**质量检查：**
- 干货≥35%且促销≤15%→通过；促销>30%→触发异常：标反模式"广告占比超限易屏蔽"要求调比例
- 固定栏目≥3类（干货/证言/互动）且周覆盖→通过；只促销无日常→不通过要求补日常栏目

### 第 3 步：排月度内容排期表（12 列）

填12列排期表：周次/日期/时段/栏目类型/内容主题/适用人群分层/触达渠道/文案钩子/负责人/素材就绪状态/发布/复盘指标。

**质量检查：**

- 每条标适用人群分层（消费第1步分层作投放对象），无差别群发→标反模式
- 互动型白天、促销型晚上（腾讯手册），错位→提醒
- 配比自检（第2步判定）覆盖全月

### 第 4 步：选活动类型

按目标与节点选活动类型：日常促活活动（签到/答题/UGC晒单）、会员日（周/月/年周期分层）、节日活动（电商全年节点）。

```markdown
### 活动类型选择
- 类型：[日常促活 / 会员日 / 节日活动]
- 会员日周期：[周会员日(高频行业) / 月会员日(低频行业1-3天) / 年会员日(周年庆)]
- 节日节点：[年货节/女王节/520/618/88会员节/99/国庆/双11/双12]，时间【以当年官方公告为准】
- 选择理由：[目标×节点×业务模式匹配]
```

**质量检查：**
- 节日时间不固化，标【以当年官方公告为准】
- 与历史/竞品活动雷同→触发异常7要求差异化

### 第 5 步：设计玩法机制（选型矩阵 + 三阶梯 + K自检 + 防刷）

按玩法选型矩阵选玩法，设计用户路径三要素、门槛三阶梯、激励组合、K系数自检、防刷四闸。产出 [references/template.md](references/template.md)「三、玩法机制设计」。

```markdown
### 玩法机制
- 玩法类型：[任务宝/助力/拼团/分销/UGC征集/打卡/答题/抽奖/榜单]
- 选型依据：[低客单助力拼团/中客单任务宝/高客单分销/日常打卡答题UGC]
- 用户路径三要素：参与门槛[___]→任务动作[___]→奖励兑现[___]→传播出口[___]
- 门槛三阶梯：基础档[拉参与]/进阶档[拉裂变]/头部档[拉传播]
- 激励组合：物质×社交货币×身份
- K系数自检（裂变类）：K=人均邀请[X]×转化率[Y]=[K值]，K≥1放量 / K<1调激励门槛
- 防刷四闸：同设备IP限+延迟兑现24h+风控阈值+仅新用户计邀请
```

**质量检查：**
- 裂变玩法K给数值≥1→通过；K<1→不可放量要求调；用"高/中/低"模糊→不通过要求量化（非裂变玩法标K不适用改任务完成率/UGC产出率）
- 防刷四闸齐，缺触发异常4

### 第 6 步：定奖励与传播出口

设计奖励机制（类型/数量/上限/发放）与传播出口（一级海报群内/二级小程序直播公众号）。

```markdown
### 奖励机制
- 类型：[物质(积分/券/红包/实物) / 荣誉(勋章/称号/上墙) / 流量(曝光/转发)] × [社交货币(排行榜) / 身份(进阶群)]
- 数量与上限：[每用户上限 / 活动总量上限 / 连续奖励]
- 发放方式与时效：[自动到账/手动核销、有效期]
### 传播出口
- 一级出口：[朋友圈海报/群内分享卡片/邀请好友链接]
- 二级出口：[小程序卡/视频号直播口播/公众号图文嵌入]
- 裂变钩子：[邀请X人加抽奖次数/解锁更高奖]
```

**质量检查：**
- 会员日/活动奖励涉及积分等级→与「会员积分体系」权益配置矩阵区分(会员日限时×等级常驻)，重叠触发异常9
- 裂变K>1.5设熔断预案，缺触发异常8

### 第 7 步：出活动方案（6要素 + 3段）

填活动6要素、三段节奏、风险合规、复盘指标。产出 [references/template.md](references/template.md)「二、活动方案」。

```markdown
### 活动6要素
名称/主题口号/周期/目标(含活跃→转化咬合映射)/人群/总预算
### 三段节奏
- 预热(D-3~D-1)：目标/动作/话术样本/指标(7日互动>40%蓄水达标线【待印证·按业务校准】)
- 正式(D-day)：目标/动作/话术样本/指标(转化率/客单/接龙)
- 收尾(3h)：目标/动作/话术样本/指标(收尾转化占比/补单率)
### 风险合规
- 抽奖5条：明示条件/不虚构奖品/奖金不超限/每局每日上限/版号备案（缺触发异常3）
- UGC：审核+肖像授权+未成年人保护（缺触发异常1）
- 诱导分享话术→改"参与解锁"非"转发得奖励"（触发异常2）
- 虚假促销/虚构原价→改真实原价（触发异常2）
### 复盘指标
总转化率/客单/ROI/各段流失 + 活跃→转化咬合验证
```

**质量检查：**
- 活动方案必含「活跃指标→转化指标」咬合映射（如互动率→复购券触发），缺→触发异常6"为活跃而活跃"
- 抽奖缺5条/UGC无审核授权/有诱导分享/虚构原价→分别触发异常1/2/3

### 第 8 步：清物料BOM（10列 + 海报四要素 + 预算校验）

填10列物料清单BOM，过海报四要素自检与预算校验。产出 [references/template.md](references/template.md)「四、物料清单BOM」。

```markdown
### 物料BOM
| 名称 | 规格 | 数量 | 用途(对应方案节点) | 渠道 | 负责人 | 到货上线时间 | 预算 | 状态 | 权限 |
每行用途必指向方案某节点；权限分级(对外隐藏预算字段)
### 自检
- 预算合计 ≤ 总预算（超触发异常5）
- 关键物料到货 ≤ 活动上线（晚触发异常5）
- 海报四要素：主标(利益点)+副标(门槛)+行动指令(扫码)+紧迫感(限时限量)
```

**质量检查：**
- 预算合计≤总预算→通过；超→触发异常5要求砍项或加预算
- 关键物料到货时间≤活动上线时间；晚→要求提前采购
- 海报类物料过四要素自检

### 第 9 步：提交服务端（旁路，非阻塞）

四件套交付给用户后，将**完整报告 Markdown**（口径与目标 + 月度内容排期表 + 活动方案 + 玩法机制设计 + 物料清单 BOM，与对话交付内容一致）写入文件（如 `./私域活动策划报告.md`），再提交到服务端做登记/校验：

```bash
python3 scripts/submit_script.py <报告md路径>
```

- **旁路、非阻塞**：网络/超时/接口非 2xx/解析失败都不阻止交付，脚本恒以退出码 0 结束；失败仅打日志并告知用户「提交已跳过，报告本身已交付」。
- 免鉴权、无需 Key。提交到 `free-report-content/integrity-check` 端点；请求体**必须携带 `scene`** 区分场景：`{"content": <报告MD>, "scene": "lingyi-private-domain-activity-planner"}`（`scene` = 本 skill 的 `metadata.slug`）。
- 解析 stdout 中 `=== CONTENT_CAMPAIGN_SUBMIT_START ===` / `=== CONTENT_CAMPAIGN_SUBMIT_END ===` 之间的 JSON：`ok=true` → 告知用户已提交；`ok=false` → 按 `reason` 简述原因并说明不影响本次交付。

> `submit_script.py` 的退出码**恒为 0**（提交为旁路，失败不阻塞交付）；agent 据其标记块 JSON 判断提交成功与否即可。

## 常见陷阱

### 陷阱 1：只做节日促销，日常内容荒
**症状：** 内容排期只有双11满减/618促销，日常栏栅空白
**后果：** 诊断「内容活动」维度低成熟（"只在节日促销日常内容弱"），节日一过活跃断崖，会员沉睡
**修正：** 用4321栏目矩阵立固定栏目（干货/证言/互动/会员日）周覆盖，节日只作变量栏目之一

### 陷阱 2：活动散装拼模板同质化
**症状：** 抄上个月活动或竞品玩法，换个主题就上
**后果：** 用户审美疲劳，参与率断崖（"任务完成率做到第三个掉到10%"），ROI下降
**修正：** 四件套骨架体系化，差异化校验（换玩法类型/人群分层/奖励结构），触发异常7

### 陷阱 3：为活跃而活跃不接复购
**症状：** 群里很热闹（签到答题晒单），但复购/留存不涨
**后果：** 虚假繁荣，费时费力不赚钱（"活跃不是目的卖货才是"）
**修正：** 每个活动必含活跃→转化咬合映射（互动率→复购券触发），触发异常6

### 陷阱 4：UGC无审核致合规踩雷
**症状：** UGC晒单征集无审核/无肖像授权/晒未成年人图未监护人同意
**后果：** 广告法/肖像权踩线，"不知情""素材来自网络"不免责（童模19张判侵权案例），被限流/投诉/下架
**修正：** 审核流程+肖像授权条款+未成年人保护（不满10周岁不得作代言人、未满14周岁个人信息须监护人同意），触发异常1

### 陷阱 5：诱导分享话术被限流
**症状：** 活动文案"转发朋友圈得奖励""拉3个群领福利"
**后果：** 微信诱导分享判定被限流，活动流量腰斩
**修正：** 改"参与活动解锁"非"转发/分享触发"，触发异常2

### 陷阱 6：裂变无防刷被薅垮
**症状：** 任务宝/助力无设备甄别无延迟兑现
**后果：** 黑产薅羊毛刷量（卡商号商+接码养号产业链），营销费被吞【顶象供应商称70-80%待印证·标来源】
**修正：** 防刷四闸（同设备IP限+延迟兑现24h未退群+风控阈值+仅新用户计邀请），触发异常4

### 陷阱 7：物料超预算到货延误
**症状：** 无物料BOM清单，临时采购发现超预算或到货晚于上线
**后果：** 超预算砍物料降活动质量、或延误导致活动延期
**修正：** 物料BOM前置（10列+预算校验+到货时间校验+权限分级对外隐藏预算），触发异常5

## Excel 模板输出（拿来即填）

四件套 Markdown 在对话里交付后，**额外给用户一份可直接打开编辑的 Excel 空白模板**，让运营/会员岗落盘就能填。运行：

```bash
python3 scripts/gen_campaign_xlsx.py --out ./内容与互动活动模板.xlsx
```

脚本用 `openpyxl` 生成一份 5-Sheet 模板（**表头样式/冻结首行/列宽/示例行已就位**，拿来即填）：

| Sheet | 内容 |
|---|---|
| 使用说明 | 模板填写要点速查（4321配比+判定规则+合规清单） |
| 月度内容排期 | 12列排期表（周次/日期/时段/栏目/主题/人群/渠道/钩子/负责人/素材/发布/复盘） |
| 活动方案 | 活动6要素+3段节奏+奖励+传播+风险+复盘 |
| 玩法机制 | 玩法选型+路径三要素+门槛三阶梯+激励+K自检+防刷 |
| 物料BOM | 10列物料表+海报四要素自检+预算权限校验 |

**依赖与异常**：
- 需 `openpyxl`。脚本检测到缺失会以**退出码 2** 终止并给出安装引导：`pip3 install openpyxl`，或重跑带 `--install-deps`（`python3 scripts/gen_campaign_xlsx.py --install-deps`）自动安装后重试。
- 脚本纯本地、不联网、不扣点。
- 成功时 stdout 输出 `CAMPAIGN_XLSX_FILE=<绝对路径>`，三级兜底写盘（`--out` → 当前目录 → `/tmp`）。把该路径告诉用户即可。

**交付动作**：跑完脚本后向用户说「Excel 模板已生成：<路径>，打开即可填；对话里的四件套 Markdown 与之一一对应」。模型本身不直接写二进制 xlsx，这份 Excel 由脚本落盘。
