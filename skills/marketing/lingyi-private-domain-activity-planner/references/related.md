# 内容与互动活动 — 相关技能边界与组合用法

> 厘清本技能与私域用户运营域内 5 个姊妹技能的边界划分、原语共享与组合 SOP，避免用户混用。正文 `## 参考` 的「相关技能」条目引用本文件。

「内容与互动活动」在私域用户运营域内是**活跃运营建设方**：诊断发现问题（日常内容弱/无运营节奏）→ 本技能产方案（内容栏栅+活动+玩法+物料）。它与会员积分体系、会员运营诊断与增长建议、分层触达、用户生命周期、公私域联动方案生成是同一私域链路的不同环节，咬合而非重叠。

## 边界划分矩阵

| 维度 | 内容与互动活动 | 会员体系搭建 | 会员运营诊断与增长建议 | 私域用户分层触达策略 | 用户生命周期旅程 | 公私域联动方案生成 |
|---|---|---|---|---|---|---|
| 回答的问题 | 拿什么内容与活动让会员活跃并接住复购 | 凭什么忠诚（等级/积分/权益） | 体系处在什么阶段、先改什么 | 进来后怎么分群差异化触达 | 用户走到哪、怎么推进 | 怎么从公域进来承接沉淀 |
| 产出 | 月度内容排期+活动方案+玩法机制+物料BOM | 等级/积分规则/权益矩阵/财务测算四件套 | 八维评分+项目清单 | 分层模型+触达矩阵 | 旅程图+阶段定义+触点 | 触点地图+承接链路+SOP |
| 内容栏栅/UGC/会员日的角色 | 主体（设计+物料） | 不涉及 | 诊断项之一 | 不涉及 | 阶段触发的活动之一 | 不涉及 |
| 任务/玩法的角色 | 主体（设计+K自检+防刷） | 积分获取行为枚举(被消费) | 诊断项之一 | 不涉及 | 阶段任务 | 不涉及 |
| 会员日权益的角色 | 主体(限时权益设计) | 权益配置矩阵的一列(被引用) | 诊断项"会员日机制" | 不涉及 | 不涉及 | 不涉及 |
| 独立可用 | 是 | 是 | 是 | 是 | 是 | 是 |

## 原语共享与咬合

- **会员日权益 ← 会员积分体系 action_type / 权益配置矩阵**：本技能在活动方案「奖励机制」消费会员积分体系的权益配置矩阵与积分行为枚举（如双倍积分=积分技能 action_type 触发）；咬合规则：会员日权益为**限时**（如会员日当天7折/双倍积分），会员等级权益为**常驻**（如金卡日常9折），两者重叠会稀释等级价值→触发异常9（见 SKILL.md）。
- **内容投放对象 ← 私域用户分层触达策略 / 用户生命周期旅程**：本技能在月度内容排期表「适用人群分层」字段消费分层技能的 RFM 分群结论与生命周期阶段（新客/活跃/沉睡/流失），作内容精准投放对象；分层技能的触达对象 = 本技能内容促活的对象。
- **诊断 → 建设**：会员运营诊断与增长建议「内容活动」维度低成熟信号（"只节日促销日常内容弱"）→ 触发本技能产出月度内容排期+活动机制+任务体系（诊断的审计项即本技能输出物）；诊断发现问题、本技能产方案，是上下游而非重叠。
- **承接 → 促活**：公私域联动方案生成把人接进来沉淀企微/社群 → 本技能用日内容栏栅+互动玩法促活承接来的人；承接期 SOP 收尾即本技能日常内容排期起点。

## 怎么组合（3 种用法）

1. **完整私域促活链路（先诊断→再建设）**：先「会员运营诊断与增长建议」查「内容活动」维度成熟度 → 若低成熟则用本技能产出四件套 → 期间咬合「会员积分体系」做会员日权益、「分层触达」做投放人群、「用户生命周期」做阶段任务。适用于体系不健康的存量盘活。
2. **只做内容活动（独立用本技能）**：已有积分/分层/诊断基础，仅缺日常内容与活动规划 → 直接用本技能产月度排期+活动+玩法+物料。适用于运营成熟但内容活动薄弱。
3. **已有回头补**：已做过零散活动但无体系 → 用本技能四件套骨架回填既有内容/活动资产（填入第4输入字段"现有内容/活动资产"），规范化并补日常栏栅与咬合校验。适用于从散装到体系化。

## 一句话区分用户该用哪个

- 想知道"体系健不健康、先改哪"→ **会员运营诊断与增长建议**
- 想知道"凭什么忠诚、怎么设等级积分权益"→ **会员体系搭建**
- 想知道"进来后怎么分群、差异化触达谁"→ **私域用户分层触达策略**
- 想知道"用户走到哪、怎么推进"→ **用户生命周期旅程**
- 想知道"怎么从公域接进来沉淀"→ **公私域联动方案生成**
- 想知道"拿什么内容与活动让会员活跃并接住复购"→ **内容与互动活动**（本技能）
