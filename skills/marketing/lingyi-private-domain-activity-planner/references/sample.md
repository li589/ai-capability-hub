## ✅ 优秀示例：茶饮连锁 · 周二会员日 + UGC 晒单促活

> 脱敏案例。茶饮连锁，企微沉淀 3 万复购客，社群活跃度持续走低（日均互动率 3%），诊断「内容活动」维度低成熟（只在双11做满减、日常内容弱）。目标：把日常活跃拉起来并接住复购。

## 二、活动方案（周二会员日 + UGC 晒单）

### 活动6要素
- 名称：悦茶周二会员日 · 晒单免单
- 主题&口号：会员日 · 喝好茶晒好图 / "晒出你的悦茶时刻"
- 周期：预热 D-1(周一) / 正式 D-day(周二) / 收尾 周二晚3h
- 目标：日常活跃率(主)+UGC产出+复购转化——咬合映射：晒单互动率 → 复购券触发（会员日消费满1杯赠晒单券，3日内核销记复购）
- 人群：全员会员（新客侧重入会钩子，沉睡侧重召回券）
- 总预算：2 万元（赠饮物料0.8万/榜单海报0.2万/复购券1.0万）

### 三段节奏
**预热 D-1**：目标建期待+引流到群｜动作：朋友圈剧透"明天会员日有免单"+社群发预告福利钩子｜话术「{行业}老客才知道的隐藏福利，明天会员日评论区晒图免单，群内专属{利益点}」｜指标：预告触达回复率
**正式 D-day**：目标引爆成交+UGC｜动作：早间开场+会员价7折 → 中段晒单接龙从众 → 晚8晒单榜Top免单｜话术「{产品}今天会员日7折，晒单接龙👇 Top3免单+额外送{赠品}」｜指标：晒单参与数/会员日GMV/UGC条数
**收尾 周二晚3h**：目标补单｜动作：倒计时免单名额+遗漏痛点再戳｜话术「剩最后{X}个免单名额，{利益点}即将关闭」｜指标：收尾段转化占比

### 奖励机制
- 物质（晒单Top3免单+会员价7折）× 社交货币（晒单榜公开排名）× 身份（晒单满5次进"悦茶品鉴群"）
- 上限：每用户晒单3次/日；免单名额Top3；复购券3日内核销
- 发放：自动到账（积分）+ 手动核销（免单+券）

### 传播出口
- 一级：朋友圈晒单海报（含二维码+会员日利益点）+ 群内晒单接龙卡片
- 二级：小程序晒单页 + 公众号会员日图文嵌入
- 裂变钩子：邀1位好友入会加1次免单抽奖机会（K自检见玩法机制，非主裂变）

### 人员分工
社群运营小林(内容排期+社群发售) / 店长(门店引流+晒单核销) / 设计小程序海报

### 风险合规
- 合规：无抽奖（晒单免单属促销非抽奖，免5条约束；但"免单"须真实原价不虚构）✓ / UGC晒单含审核(敏感词/违禁图)+肖像授权(晒图同意条款)+未成年人保护(晒未成年人须监护人同意)✓ / 无诱导分享话术（"晒图免单"非"转发得奖励"）✓
- 防刷：四闸齐（设备/IP限+延迟兑现24h未退群+风控阈值+仅会员享）✓
- 熔断：晒单量若超预期设限Top10封顶+负面舆情下架流程 ✓

### 复盘指标
总GMV/客单/ROI/各段流失 + 活跃→转化咬合（晒单互动率8%达成 → 复购券核销率验证复购）

## 三、玩法机制设计

### 玩法选型
玩法类型：UGC晒单征集（主）+ 邀请入会抽奖（辅）
选型依据：餐饮高频低客单 + 目标日常活跃+UGC → 选UGC晒单拉日常互动与内容沉淀，非重裂变（客单支撑不起任务宝分销）

### 用户路径三要素
- 参与门槛：下单1杯+社群晒图+话题#悦茶时刻
- 任务动作：群内晒图接龙 → 评Top榜 → 中奖领免单/券 → (分享晒单海报)
- 奖励兑现：Top3免单自动核销 + 晒单积分到账 + 满5次进品鉴群
- 传播出口：朋友圈晒单海报/群内接龙卡片/小程序晒单页

### 门槛三阶梯
- 基础档：晒1图 → 50积分+会员价，拉参与率（低门槛）
- 进阶档：连晒3图+好评 → 晒单榜加权+复购券，拉频次
- 头部档：连晒10图/月 → 进品鉴群+新品试饮，拉头部内容贡献者

### 激励组合
物质（免单/积分/券）× 社交货币（晒单榜公开排名）× 身份（品鉴群）

### K系数自检
UGC晒单为非裂变玩法，K不适用 → 主指标改用：任务完成率（晒单参与数/社群日活 ≥15%）+ UGC产出率（晒单条数/周 ≥30条）【按业务校准】
辅邀请入会抽奖裂变：K=人均邀请0.3 × 转化率0.4 = 0.12 <1 → 不依赖裂变放量（拉新非主目标，仅附赠提活跃）

### 防刷四闸
1.同设备/IP限1次免单 2.免单延迟兑现(24h未退群/退款才核销) 3.晒单图片风控(去重+敏感词) 4.仅会员享会员价

## 自检清单（全过）

### 分析
- **痛点命中**：①日常活跃起来（4321日常栏栅+周二会员日锚定，不再只双11满减）②晒单UGC反哺内容证言栏栅（证言20%有真实素材）③晒单→复购券咬合不"为活跃而活跃"④UGC审核+肖像授权+未成年保护合规⑤BOM预算前置拦截不超预算。
- **行业适配**：高频低客单→社群1v多+晒单打卡重于深度1v1（呼应会员积分技能模式适配）；周二会员日与积分技能咬合（双倍积分=会员积分action触发，会员日权益为限时、等级权益为常驻，不冲突见异常9）。
- **可量化达标**：咬合映射(互动率8%→复购核销率)可验证0.4d假设"日常内容排期提升活跃"。

## ❌ 反面示例 1：活动同质化（与上月满减雷同）

> 与上月双11满减活动同质化，触发异常7。

**场景**：10月直接复制9月满减玩法「满2杯减5元」做国庆活动。

**逐项点评**：
- **症状**：玩法类型(满减)与上月雷同，无差异化。
- **后果**：用户审美疲劳，参与率断崖（专家团"任务完成率做到第三个掉到10%"），二次活动ROI下降。
- **修正**：触发异常7「活动同质化」，要求差异化——换玩法类型(满减→UGC晒单或打卡签到)、换人群分层(全员→沉睡召回专档)、换奖励结构(单一满减→三阶梯门槛)。改法见正例玩法选型。

## ❌ 反面示例 2：UGC违规（无审核/无肖像授权）

> UGC晒单征集无审核流程与肖像授权条款，触发异常1。

**场景**：直接发「晒图+话题免单」，无审核、无授权、晒未成年人图未监护人同意。

**逐项点评**：
- **症状**：UGC征集无审核(敏感词/违禁图)/无肖像授权条款/无未成年人保护。
- **后果**：广告法/肖像权踩线——商业使用他人肖像须"先授权后使用"，"不知情""素材来自网络"不免责（吴兴区法院:网店擅用童模19张判侵权）；不得利用不满10周岁未成年人作广告代言人；处理未满14周岁个人信息须监护人同意（个人信息保护法）。被投诉/被限流/被下架。
- **修正**：触发异常1「UGC内容合规」，强制补：①审核流程(机器初审敏感词违禁图+人工复核)②肖像授权条款(晒图即同意商业使用)+未成年人特别条款（晒未成年人图须监护人同意+不满10周岁不得作代言人）③用户举报通道+快速处置。改法见正例风险合规节。
