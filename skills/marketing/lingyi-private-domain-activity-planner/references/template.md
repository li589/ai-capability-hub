# 内容与互动活动 四件套模板

> 填空式结构骨架，是 SKILL.md「应用」逐步指引产出的最终落版。用 `[占位符]` 标注结构，逐项填空。正例见 [sample.md](sample.md)，与兄弟技能边界见 [related.md](related.md)。

## 模板

```markdown
# [品牌/项目] 内容与互动活动方案 · [年月/活动名]

## 口径与目标
- 业务模式：[餐饮高频复购 / 零售客单周期 / 电商跨品类 / 服务预约]
- 私域载体：[企微 / 社群 / 小程序 / 公众号 / 个微]
- 当前用户分层：[新客 / 活跃 / 沉睡 / 高价值 / 流失召回]
- 活跃运营目标：[日常活跃率 / UGC产出 / 任务完成 / 复购转化 / 裂变拉新]（主选+可选）
- 促活核心指标与基线：[如 互动率 X% → 目标 Y%；复盘指标定 [待印证·按业务校准]]
- 月度预算：[金额]（无则标 [待校准]）
- 当前阶段：[冷启动 / 成长期 / 成熟期]

---

## 一、月度内容排期表（12 列）

> 栏目按 4321 配比：干货 40% / 生活人设 30% / 客户证言 20% / 促销种草 10%（广告>30% 易屏蔽）。
> 固定栏目（干货日/证言日/互动日）× 变量栏目（节气/热点/活动期）。
> 互动型内容白天推送、促销型内容晚上推送。

| 周次 | 日期 | 时段(早8·午12·晚8) | 栏目类型(干货/生活人设/客证言/促销种草) | 内容主题 | 适用人群分层 | 触达渠道(朋友圈/社群/公众号/私聊) | 文案钩子 | 负责人 | 素材就绪状态(待制作/制作中/就绪) | 发布(待发/已发) | 复盘指标(打开/互动/转化) |
|---|---|---|---|---|---|---|---|---|---|---|---|
| W1 | [YYYY-MM-DD] | [早8] | [干货] | [主题] | [活跃] | [社群] | [钩子] | [姓名] | [就绪] | [待发] | [打开X%·互动Y·转化Z] |
| ... | | | | | | | | | | | |

**栏目矩阵自检**：
- 干货占比 [ ]% ≥35% ｜ 促销占比 [ ]% ≤15% ｜ 广告合计 [ ]% <30%（>30% 触发异常：标反模式要求调比例）
- 固定栏目 [ ] 类（干货/证言/互动）≥3 且周覆盖（仅促销无日常→不通过，要求补日常栏目）

---

## 二、活动方案（活动6要素 + 3段节奏）

### 活动6要素
- 名称：[活动名]
- 主题&口号：[主题 / 口号，与目标一致·引起共鸣·简洁易记]
- 周期：[预热 D-3~D-1 / 正式 D-day / 收尾 3h]（日常/会员日/节日三类，时间按节点 [以当年官方公告为准]）
- 目标：[拉新/促活/转化/品牌，具体可衡量]——活跃→转化咬合映射：[互动率 → 复购率（缺咬合触发异常6"为活跃而活跃"）]
- 人群：[新/老用户、人群分层、规模]
- 总预算：[金额]

### 玩法概览
[一句话说明核心玩法与核心卖点]

### 三段节奏

**预热（D-3 ~ D-1）**
- 目标：[建信任/放大期待/筛高意向]
- 动作：[痛点种草 D-3 → 价值输出+案例证言 D-2 → 悬念剧透+预告福利 D-1]
- 话术样本：「[行业]里 80% 的人卡在 [痛点]，[D-day] 拆一个解法，群内专属 [利益点]」
- 指标：[7日互动率>40% 为蓄水达标线（标待印证·按业务校准）]

**正式（D-day）**
- 目标：[集中引爆成交]
- 动作：[早间开场+价值锚定 → 中段方案讲解+限时福利 → 群内晒单+从众 → 锁单指引]
- 话术样本：「[产品] 今天 [利益点]，仅 [名额] 个，晒单接龙👇 现在锁单额外送 [赠品]」
- 指标：[发售期转化率 / 客单价 / 接龙参与数]

**收尾（最后 3h）**
- 目标：[逼单补单/压榨剩余意向]
- 动作：[倒计时 3h/1h/30min → 名额即将售罄 → 遗漏痛点再戳 → 最后加赠收口]
- 话术样本：「剩最后 [X] 个名额，[利益点] 即将关闭，错过恢复原价，现在锁单」
- 指标：[收尾段转化占比 / 补单率]

### 奖励机制
- 类型：[物质(积分/券/红包/实物) / 荣誉(勋章/称号/上墙) / 流量(曝光/转发)] × [社交货币(排行榜) / 身份(进阶群)]
- 数量与上限：[每用户上限 / 活动总量上限 / 连续奖励规则]
- 发放方式与时效：[自动到账/手动核销、有效期]

### 传播出口
- 一级出口：[朋友圈海报 / 群内分享卡片 / 邀请好友链接]
- 二级出口：[小程序卡 / 视频号直播口播 / 公众号图文嵌入]
- 裂变钩子：[邀请 X 人加抽奖次数/解锁更高奖]（K≥1 见玩法机制自检）

### 人员分工
- [内容/活动/社群/设计 角色分工，任务细分至个人]

### 风险合规
- [合规自检：抽奖5条/UGC审核+肖像授权+未成年人保护/无诱导分享]（缺触发异常1-3）
- [防刷：四闸齐]（缺触发异常4）
- [熔断预案：K>1.5 暂停拉新/限制名额 + 负面舆情下架流程]（缺触发异常8）

### 复盘指标
- [总转化率/客单/ROI/各段流失归因 + 活跃→转化咬合验证]

## 三、玩法机制设计

### 玩法选型矩阵（按客单/决策成本）
- 玩法类型：[任务宝 / 助力砍价 / 拼团 / 分销 / UGC征集 / 打卡签到 / 答题 / 抽奖 / 榜单]
- 选型依据：[低客单消费品→助力/拼团；中客单→任务宝(邀X得Y)；高客单/决策型→老带新分销；日常促活→打卡/答题/榜单]
- 选择理由：[钩子决定参与率，门槛决定裂变系数]

### 用户路径三要素
- 参与门槛：[如 发图+话题 / 满299 / 邀1人]
- 任务动作：[触达→参与→行动→兑奖→(分享)]
- 奖励兑现：[领券/抽奖/积分到账 + 上限/时效]
- 传播出口：[朋友圈/群内分享/邀请好友/海报/小程序卡]

### 门槛三阶梯
- 基础档：[邀1-2人/满299] → 解锁 [基础奖励]，拉参与率（低门槛）
- 进阶档：[邀3-5人/拼团价] → 解锁 [进阶奖励]，拉裂变系数
- 头部档：[邀10人/老带新] → 解锁 [终极奖励]，拉头部传播者

### 激励组合
[物质(实物/券) × 社交货币(排行榜) × 身份(进阶群/勋章)]

### K系数自检（裂变类玩法必填）
- K = 人均邀请数 [X] × 邀请转化率 [Y] = [K值]
- 判定：[K≥1 可放量 / K<1 不可放量需调激励/门槛/钩子]（禁"高/中/低"模糊词，缺数值触发异常）
- 非裂变玩法（打卡/答题/UGC晒单）：K不适用，改用 [任务完成率/UGC产出率] 作主指标

### 防刷四闸
1. [同设备/IP限制]
2. [奖励延迟兑现（新增好友/达人 24h 未退群/退款才发）]
3. [风控阈值+人工抽检]
4. [仅新用户计入邀请数]

---

## 四、物料清单 BOM（10 列）

> 每行物料用途必指向活动方案某节点；预算合计 ≤ 总预算（超触发异常5）。
> 权限分级：对外版（隐藏预算字段）/ 内部版（全字段），各供应商不可见。
> 海报四要素自检：主标(利益点) + 副标(门槛) + 行动指令(扫码) + 紧迫感(限时限量)。

| 物料名称 | 规格 | 数量 | 用途(对应方案节点) | 渠道 | 负责人 | 到货·上线时间 | 预算 | 状态(待采/制作中/就绪) | 权限(对内/对外) |
|---|---|---|---|---|---|---|---|---|---|
| [海报] | [750×1334/材质] | [N张] | [预热D-3种草] | [朋友圈/社群] | [设计] | [YYYY-MM-DD] | [金额] | [就绪] | [对外] |
| ... | | | | | | | | | |

**BOM自检**：
- 预算合计 [金额] ≤ 总预算 [金额]（超→要求砍项或加预算）
- 关键物料到货时间 ≤ 活动上线时间（晚→要求提前采购）
- 海报类物料过四要素自检 [ ] 主标 [ ] 副标 [ ] 行动指令 [ ] 紧迫感

---

## 自检清单（四件套交付前过）
- [ ] 内容配比合规（干货≥35%·促销≤15%·广告<30%）
- [ ] 固定栏目≥3类且周覆盖
- [ ] 裂变玩法 K 给数值≥1（或非裂变玩法有任务完成率主指标）
- [ ] 活动方案有活跃→转化咬合映射
- [ ] 物料BOM预算≤总预算、关键物料不延误、海报四要素齐
- [ ] 合规：抽奖5条/UGC审核+肖像授权+未成年人保护/无诱导分享
- [ ] 防刷四闸齐 / 裂变K>1.5有熔断预案
- [ ] 平台规则项标【按2026规则核验·需复核】、行业基准标【待印证·按业务校准】
```

---

**占位符约定**：`[ ]` 为填空位；`{花括号}` 用于话术/文案内可替换变量（如 {行业}{客户昵称}{产品}{利益点}{名额}），替换即用。
