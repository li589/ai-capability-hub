# 活动权益配置与冲突校验规则

> 活动期限时权益配置 + 与等级常驻权益叠加互斥判定的依据与可量化规则。配权益前必读。

## 一、促销 5 要素（WHO/WHERE/CONDITION/ACTION/LIMIT，★已 extract 核验）
- WHO 适用人群：全体 / 新用户 / 会员 LvN+ / 黑卡 / 指定标签
- WHERE 商品范围：全店 / 品类(S2) / 品牌(S2) / 单品(S1) / 订单级(S3)
- CONDITION 触发门槛：无门槛 / 满 X 元 / 满 X 件 / 满 X 品类
- ACTION 优惠动作：比例折扣 / 价格减免 / 满折 / 赠品 / 积分倍率
- LIMIT 限制：能用几次 / 每日上限 / 每人上限 / 库存上限
> 出处：人人都是产品经理《促销体系一文讲透分类计算叠加三大内核》https://www.woshipm.com/operate/6409499.html

## 二、权益清单总表（10 列）
权益编号 / 权益项 / 权益类型(基础/增值/惊喜) / 权益性质(强/弱) / 适用会员等级 / 适用周期(限时/常驻) / 发放方式(自动/手动) / 成本单位 / ROI 测算。
- **权益类型**（晏涛三层，★已 extract）：基础(积分翻倍/专享券/限时兑换，促转化)／增值(专享折扣/秒杀，促客单)／惊喜(送礼品/试用/线下，促忠诚)。
- **权益性质**（携程口径）：强权益(影响决策，如免费早餐、专享价，核心节点重点展示) vs 弱权益(增值服务，如快速安检，提前轻量展示)。

## 三、三步叠加互斥判定（核心高价值，防折上折资损）
对每个活动期限时权益 A 与相关等级常驻权益 B 过三步：
1. **作用域重叠分析**：WHO 重叠(A⊃B/B⊃A/相交/无交集) + WHERE 重叠(包含/相交/互斥)
2. **判定冲突类型**：可叠加 / 互斥取最优 / 互斥取先入 / 需人工裁决
3. **叠加计算管线**：C1 商品优惠 → C2 订单优惠 → C3 券 → C4 权益，给实际叠加后价格

## 四、资损校验
- 叠加后毛利率 = (售价 - 成本 - 权益补贴) / 售价
- **阈值**：≥15%→通过；<15%→触发异常"资损风险"，要求调整叠加规则(改互斥取最优，限时权益仅对非常驻权益人群生效)
- 补贴预算：是否超线
- 校验结论：通过 / 调整

## 五、踩坑真实案例
- 跨境老陈 2025 黑五：Coupon 减 $8 + Prime 会员 15% 折扣在跑（系统自动报名，自己不知道）→ 折上折致亏。"折上折致亏、促销撞车、忘记取消，这些低级错误本来可以避免。"（datacaciques.com/blog/industry/102987）
- 平台"跨店满 300 减 40" + 商家"满 200 减 30"：商家以为互斥，平台默认叠加 → 同笔订单两层命中 → 毛利打穿。
> 这些案例是本技能做三步判定的立论依据——不配判定+资损校验必踩。

## 六、常驻 vs 限时权益（业界共识）
- 等级常驻权益：长期、稳定、身份绑定（管留存，归 member-benefits-points-system 设计）
- 会员日/活动期限时权益：限时、爆发型、节点绑定（管促活+复购，本技能配）
- 二者不替代：常驻权益让会员"平时不亏"，限时权益让会员"那天必来"。

## 七、权益设计五原则（附注）
穷举原则(权益分类齐全) / 区隔原则(免费等级权益 vs 付费权益要区隔) / 权益聚焦(忌上百项) / 成本控制(测算 ROI) / 简单原则(易理解易传播)。
> 出处：人人都是产品经理《2万字干货如何从0到1搭建用户会员体系》https://www.woshipm.com/pd/6055651.html

## 八、判定规则（全可量化）
- 权益清单每项填齐(类型/等级/周期/成本)→通过；缺→不通过。
- 叠加互斥判定走完三步→通过；未过→不通过。
- 资损校验毛利率 ≥15% 且补贴未超→通过；<15% 或超线→触发异常资损要求调整。
- 强弱权益标注齐全→通过；缺→警告(影响展示优先级)。
- 常驻权益表缺失→降级为只设计活动权益不做冲突校验(触发异常"成熟度不足")。
