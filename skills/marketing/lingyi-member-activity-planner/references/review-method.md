# 活动复盘方法与反模式自检

> GRAI 四步复盘 + 7 反模式自检 + ROI 归因的依据与可量化规则。做复盘前必读。

## 一、GRAI 四步（数据-洞察-行动-沉淀，多源印证共识）
- **Goal** 回顾目标：当初目标/期望是什么
- **Result** 评估结果：完成情况，亮点 keep / 不足 drop + 达成率
- **Analysis** 分析原因：成功/失败关键原因（主观+客观+归因验证）
- **Insight** 总结规律：得失体会、经验是否可复用、需实施新举措 vs 继续措施

> 口诀化表述："数据-洞察-行动-沉淀"四步闭环。
> 四步法变体多源印证：GRAI（目标导向+含沉淀，最贴合活动复盘）/ 联想四步法 / PDCA 戴明环 / KISS（Keep/Improve/Stop/Start，作行动项收尾子模板）。来源：boardmix《项目复盘流程全解》、runwise.co、禅道 zentao.net。

## 二、四步填写结构
| 步骤 | 核心问题 | 填写字段 |
|---|---|---|
| 1.数据 | 发生了什么？ | 指标名/目标值/实际值/达成率/对比基准(基期/竞品/同活动) |
| 2.洞察 | 为什么发生？ | 异常点描述/假设原因列表/假设验证证据/根因(含业务理解+假设验证) |
| 3.行动 | 我该做什么？ | 改进措施(具体到操作)/优先级(P0-P2)/负责人/预计完成时间 |
| 4.沉淀 | 方法论提炼 | 可复用规律/新SOP条款/下次必做清单/反模式警示 |

> 警示（woshipm 6389270）："分析终点不是报告而是改动""每个洞察必须转化为具体可落地行动""没有验证的优化本质是拍脑袋"。

## 三、量化判定标准
| 判定项 | 公式/阈值 | 来源 |
|---|---|---|
| 目标达成率 | 实际完成 ÷ 目标设定 ×100% | woshipm 4236185 |
| 活动 ROI | (收入−成本)/成本；**ROI>1 成功赚钱，<1 亏损须归因** | woshipm 669526 |
| 收入归因 | 末次点击/首次点击/线性/时间衰减四模型须匹配决策周期，否则 ROI 虚高虚低 | eshutong 52079 ★已核验 |
| 渠道 ROI | 渠道收入/渠道投入；>1 为有效 | woshipm 669526 |
| 客单价 AOV | 成交总额/订单数 | woshipm 6294062 |
| ARPU | 总收入/总用户数 | woshipm 6294062 |
| 1-5-10 标准 | 1 分钟发现/5 分钟定位/10 分钟处理(故障类复盘) | izxxz |

## 四、7 反模式自检清单（命中任一→复盘无效需返工）
1. **把复盘当总结做**：只罗列"做了什么"，不分析"为什么"，无法迭代成长
2. **甩锅式数字游戏**：立项时用数字自我催眠论证效果会好，结束后用数字论证"问题不在我"
3. **停在数据层不做归因**：只呈现绝对值不做对比；只描述不诊断；将相关性当因果性
4. **建议不具体**：写"提升转化率"不是建议，写"将注册流程 5 步精简 3 步"才是
5. **建议无优先级**：同时提十个建议等于没建议
6. **不追踪验证**：优化上线后不了了之；验证周期太短；把自然波动当优化效果
7. **拍脑袋下结论**：原因未经数据/佐证验证，相当然推断

> 补充反模式（长江商学院复盘四大误区）：报流水账/纠缠细节/只归因外部/经验不沉淀。

## 五、真实痛点佐证（调研线③★已核验原话）
- "相当多公司活动做得及其随意压根没有目标…做活动肯定要提升 GMV 呀——废话!"（woshipm 5921577）
- "活动复盘打着数据分析之名，行吹嘘拍马之实。好的要写好，坏的变着法写好。"（woshipm 5921577）
- "报流水账，或纠缠于细节"（长江商学院 ckgsb）
- "觉得活动结束就结束了"（知乎 p/27767405）
- 病根三连：没目标 → 没记录 → 没节操，两次活动同样错误反复犯（结构性病）。

## 六、判定规则（全可量化）
- 先理目标对照(目标值/实际值/达成率)→通过；未先理→触发异常"复盘无效需返工"。
- 归因模型注明→通过；未注明→警告"可能 ROI 虚高虚低"。ROI<1→判定亏损须归因。
- 每条行动有优先级+负责人+预计时间→通过；表述为"提升转化率"无具体操作→打回重写。
- 7 反模式自检全过(无命中)→通过；命中任一→判定复盘无效需返工。
- 沉淀闭环产出可复用规律/新 SOP→通过；缺→警告"经验不闭环"。
