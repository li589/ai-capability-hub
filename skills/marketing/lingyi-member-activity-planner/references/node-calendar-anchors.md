# 节点营销日历方法论锚点

> 年度节点编排的设计依据与可量化判定规则。设计年度日历前必读。

## 一、8 步定日历法（徐霄鹏，★已 extract 全文核验）
1. 定全年 S 级节点 → 2. 定 A/B 级容量与月份分布 → 3. 各业务线提报意向+营收目标 → 4. 逐月检查季节性匹配/合并 → 5. 按优先级排序 → 6. 跨月协调削峰填谷 → 7. 给定门槛动态调 A 级数量到最佳 → 8. 确定日历做资源分配计算。
> 出处：徐霄鹏《大促揭秘: 活动日历与大促规划》https://www.woshipm.com/marketing/4158516.html （亚马逊高级总监、前京东/携程高级产品总监）

## 二、三梯队 × S/A/B/C 双维度（核心双标签，正交）

**三梯队（投入重量，管资源分配百分比，有赞）**：
- 第一梯队（重点投入）：配人力物料全档，做完整活动链路。资源配比 70%。
- 第二梯队（常规跟进）：物料复用、轻量跟进。资源配比 20%。
- 第三梯队（内容借势）：只发图文/海报，不立项不做活动机制。资源配比 10%。
> 有赞原话：「70% 精力投入妇女节，20% 投入春夏新风尚，10% 跟进其他节点」。出处：有赞说《三月营销日历怎么布局？》https://www.youzan.com/blog/articles/75851

**S/A/B/C 量级（管预热时长公式，徐霄鹏）**：
| 级别 | 量级 | 预热 | 爆发 | 默认梯队 |
|---|---|---|---|---|
| SSS | 全民级爆发（春节/双11）| 2-3 周 | 3-5 天 | 第一梯队 70% |
| S | 高参与大节点（女神节/618）| 2-3 周 | 3-5 天 | 第一梯队 |
| A | 跨品类/核心品类大促（年货节）| 3-5 天 | 2-3 天 | 第二梯队 20% |
| B | 垂直类目/品牌活动（吃货节）| 品类预热 | 主站 1 天 | 第二梯队 |
| C | 业务内部策划不占公司资源 | 按业务线预算 | - | 第三梯队 10% |

**全年容量公式（徐霄鹏原文）**：S 级 3 场×3 周 + A 级 9 场×1 周 + B 级 27 场×1 天 = 153 天。据此反推年度活动容量基线。

## 三、造节逻辑（自造 IP 节点）
品牌主动打造专属营销 IP 节点（周年庆/品牌日），门槛高成本大，一旦教育成功即获源源不断自然流量。
> 三梯队节点分类：①老百姓节日节气②突发新闻事件(蹭热点)③品牌专属节日(自造 IP)。出处：人人都是产品经理《品牌借势营销，底层逻辑和案例拆解》https://www.woshipm.com/marketing/4736759.html
自造节点须与公共节点同表编排并标"自造 IP"，标注前期教育成本提示。

## 四、「用节点管理需求而非制造噪音」（立论柱，★已 extract 逐字核验）
> Morketing 原文：「2026 年，我们不能只"追节点"，而是需要"用节点管理需求"。抓住全年消费路径上的关键锚点，知道什么时候该冲量，什么时候该筛选用户，什么时候该放慢节奏、为下一次增长蓄水。当节点被用来管理节奏、而不是制造噪音，营销才不再是被动应对时间，而是主动塑造增长。」
出处：Morketing《2026 年营销日历》https://www.morketing.com/detail/28162

节点四功能：冲量锚点 / 用户筛选锚点 / 蓄水放慢锚点 / 节奏管理锚点。
反模式：把节点当噪音追——每个小节都追、追到受众不知所措（Shopify 同源印证）。

## 五、判定规则（全可量化，禁"较好/适度/一般"）
- 梯队判定：If 节点∈{SSS,S} then 第一梯队；If ∈{A,B} then 第二梯队；If =C then 第三梯队。
- 资源配比校验：第一梯队占比 60-80%→通过；<60% 或 >80%→警告偏离有赞 70/20/10。
- 容量校验：折算总天数 ≤153 天×1.3→通过；>→触发异常"超容量促后疲劳"；<80 天→警告产能闲置。
- 节点健康自检：全年有第一梯队→通过；无→不通过(纯撒胡椒面)；同月 ≥3 个第一梯队→警告撞月需削峰填谷。
- S 级通货膨胀校验：S 级 ≤4 且同档资源差 ≤3 倍→通过；>6 或资源差 >3 倍→要求重分级。
- 节点贪多校验：一二级梯队总数 ≤20 且第三梯队未立项→通过；>20→警告建议精简聚焦 3-5 个核心节点。

- 季节奏：Q1-Q4 主题（如 Q1 开年开门红、Q4 年终冲刺）
- 月清单：月度节点表 7 列（月份/关键节点/关键词/活动关键词/玩法/级别/目标人群）
