# 直播脚本创作模板

使用本模板来产出带货直播脚本四件套：整场节奏脚本表、单品讲解话术表、话术分类库、合规约束清单。按带货直播默认节奏套一档再微调，每张表后过质量检查。

> **带货直播默认节奏档**（4 小时抖音带货，按此套用再回填真实品类与排品）：
> - 开场 5-15min：聚人→留客（暖场问候+概括亮点+发福袋+剧透主推款）
> - 正式售卖：售卖初期低价引流 → 售卖高潮主推五款（每款走六阶段链路+单品七步，约 30-40min/款）→ 售卖后期返场秒杀
> - 收尾 15min：预告明日+引导关注+强调直播时间
> - 排品：主推 5-8 个 + 引流款 + 利润款 + 活动款，高低价交叉排序

## 模板
```markdown
### 口径与目标（前置）
- 带货品类/主题：[美妆精华 / 敏感肌 72h 保湿]
- 直播目标：[品种草 / 大促转化 / 清仓尾货 / 新品上市 / 老客复购]
- 直播时长：[4小时]
- 平台：[抖音 / 视频号 / 淘宝 / 快手 / 小红书]（决定憋单合规口径与违禁词特化）
- 主播配置：[单人 / 主播+副播+场控]
- 直播类型：[达人直播 / 品牌自播]

## 二、单品讲解话术表

每品一区，按七步结构填空。服饰类可套两公式（卖点+人群+折扣+逼单 / 细节+整体展示+穿搭场景+逼单）；高客单重④信任背书。

| 品名 | ①钩子/痛点 | ②引入产品 | ③卖点(FABE:特征-优势-利益-证据) | ④信任背书 | ⑤价格锚点(原价/门店价/直播价) | ⑥限时限量逼单(库存/倒计时/口令) | ⑦FAQ |
|---|---|---|---|---|---|---|---|
| [品名1] | [换季敏感泛红起皮] | [引入0添加玻尿酸精华] | [特征0添加玻尿酸/优势72h保湿实验/利益敏感肌可用不刺激/证据第三方检测报告] | [皮肤科医生推荐+品牌背书+专利] | [原价299/门店价299/直播价99] | [库存500件/倒数5个数/321上1号链接] | [敏感肌能用吗/孕妇可用吗/怎么用] |
| [品名2] | [痛点] | [引入产品] | [特征/优势/利益/证据] | [背书] | [原价/门店价/直播价] | [库存/倒计时/上链接口令] | [FAQ] |

FABE标准句式参考：因为（特征）……，从而有（优势）……，对您而言（利益）……，你看（证据）……
高客单策略：④重测评/参数/质保，⑥逼单用库存型+痛点型非纯价格型

**质量检查：** 七步每步有内容（空步标"无"+原因，空步>2不通过）；⑤价格锚点有原价对比数值（无依据触发异常10）；⑥含库存数+倒计时口令（如"321上链接/最后X单"）；卖点模糊触发异常12

## 三、话术分类库

12类，每类3-5条可直接照念的完整句。每句必须是照念句，禁指令式。

- 开场：「[欢迎XX来到直播间！点关注不迷路～每晚都有福利]」「[感谢来到直播间，今晚有重磅福利千万别走开]」「[我直播时间一般是X点-X点]」
- 留人：「[12点整最先抽免单，没关注的点关注加粉丝团，找客服领10元优惠券]」「[接下来这款是今晚重磅，别走开]」
- 互动（发问式/选择性/节奏型）：「[想要1号还是2号，扣1或2]」「[觉得划算的扣划算]」「[想要的扣想要，我看看人气]」
- 锁客（展示型/信任型/专业型）：「[先看成分表，0添加]」「[检测报告放大看]」「[这个工艺同级没有第二家]」
- 说服：「[和XX品牌比，我们…]」「[这个价位段没有第二家]」「[门店同款你要XXX]」
- 憋单：「[这款库存不多，我先讲完再上]」——⚠️必须配套：放单时间[X分]/库存[X件]/放单倒计时[倒数X个数]（无则异常6，禁"条件才上架"）
- 催单（讲时间/优惠/物流/自留四法）：「[库存不多时间紧迫过这波没了]」「[链接改过价放心拍先付先得最后2分钟]」「[有运费险]」「[这款我也买过门店要XXX今天才XX]」
- 逼单：「[所有宝宝准备，321，上链接！]」「[最后5单，手快有手慢无，刷新抢]」
- 成交：「[拍下的姐妹回来扣已拍优先发货]」「[没抢到的别急我再申请库存]」
- 活动（低价/买X送X/限时限量/差价补偿）：「[今晚加赠小样]」「[买2送1]」「[前100名额外赠]」「[买贵补差]」
- 感谢：「[感谢XX下单]」「[感谢大家支持]」
- 收尾：「[明天同一时间开播，剧透明天新款，点关注不错过]」「[没抢到的明天还有]」

**质量检查：** 12类齐全每类≥3条（缺类补）；每条照念完整句（禁"做暖场话术"指令式）；憋单话术配套放单时间+库存+倒计时（无触发异常6）

## 四、合规约束清单

填空式核查表，脚本产出后逐项过。

### 违禁词自查（四平台2025版）
- [ ] 绝对化用语：脚本无 最/第一/唯一/全网最低价/史无前例/顶级/万能（含谐音/简写/拆分变体）
- [ ] 医疗功效夸大（非医疗品）：无 防脱发/改善睡眠/一洗白/治愈率
- [ ] 虚假时限：限时/秒杀/抢疯了 均配明确时限，否则已改写
- [ ] 引导欺骗/第三方（抖音）：无 点击有惊喜/加V咨询/诱导第三方交易
- [ ] 平台特化：
  · 抖音：[已查] 无诱导第三方·加V
  · 视频号：[已查] 无"全国最低价"等虚假价格对比·非医疗品宣称功效
  · 小红书：[已查] 无虚构体验·拉踩·过度P图对比
- [ ] 改写原则应用（2026审核演进）：控制语速/制造停顿/用非绝对化表达/用画面场景代敏感词
  · 替代示例："全网最低价"→"今天直播间价格非常有优势，建议比价"

### 憋单合规（抖音官方 school.jinritemai.com）
- [ ] 每个憋单段单次放单≤10min
- [ ] 明确标注上架时间[X分]+库存量[X件]+福利发放时间[X分]
- [ ] 无"条件才上架""长时间才上架""满X人才上"

### 价格真实性
- [ ] 每个原价依据：[建议零售价 / 历史成交价 / 门店同款价]
- [ ] 无依据的原价已改标"建议零售价"或删原价列只留直播价
- [ ] 无虚假价格对比（视频号禁"全国最低价"式对比）

**质量检查：** 违禁词检出数=0通过（>0触发异常5逐条标红改写复检）；憋单段有放单时间+库存+倒计时（无触发异常6）；原价有依据（无触发异常10）

## 五、单品逐字讲稿（可选——仅场景命中时产出）
```
