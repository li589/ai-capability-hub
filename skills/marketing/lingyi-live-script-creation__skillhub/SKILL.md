# 直播脚本创作

> 版本：v0.2.0 · 作者：小风、CoderPig

## 目的

帮带货直播运营/编导/主播把一场直播跑通一条可执行链路：**整场节奏排期 → 单品话术结构化 → 话术分类库 → 合规校验**，产出四件套（整场节奏脚本表、单品讲解话术表、话术分类库、合规约束清单），外加可选的 Excel 空白模板；场景命中时再额外产出可选的**单品逐字讲稿**（第五件套）。本技能是纯方法论输出，免登录免 Key、不扣点，由 agent 直接产出；四件套写完后把报告 Markdown 提交服务端登记（旁路、失败不阻塞交付）。

这不是「一份开播提词器」或「一段口播稿」，而是「先看清楚整场六阶段节奏、每个主推品的卖点与逼单逻辑、各阶段该说什么话、哪里会踩违禁词，再决定怎么排品、怎么推进度、怎么倒计时上链接」。可以把它看作带货直播的结构化占位框架——把散在对标稿、个人经验和平台黑话里的感性话术，沉淀成可照念、可排期、可复用的执行脚本。

> 关于逐字稿的立场：直播是动态场域，默认**不**产整篇逐字稿——逼单数字（还剩 X 件、倒数 X 个数）随库存实时变、4h 逐字稿两三万字无人能照念不漏、逐字稿最易催生"照本宣科无紧迫感"反模式。但话术库的定式句（开场/逼单/催单口令）与单品⑥逼单口令本就逐字可照念，已是分层逐字；当主播是**新手首播**、**品牌自播要求话术多人统一**、**高客单或功效品怕说错踩词**时，才额外产出按场景分段的"单品逐字讲稿"兜底。逐字稿是安全垫不是默认件。

> 核心信念（来自调研）：整场靠**三阶段框架 × 六阶段链路**定节奏，单品靠**七步结构**讲透，转化靠**逼单心理学**驱动，安全靠**合规前置**兜底。三阶段框架（开场/售卖三期/收尾）管整场宏观节奏，六阶段链路（聚人→留客→锁客举证→说服→催单→逼单→下单）管每个品的微观成交动线，七步结构把单品从痛点讲到上链接填满，逼单三型（价格型/库存型/痛点型）激活损失厌恶、价格锚定、稀缺与登门槛这四条心理学杠杆，合规前置把违禁词与违规憋单挡在脚本阶段而不是下播后扣分。

## 输入

**最佳搭配：** 带货品类/主题 + 直播目标（品种草/大促转化/清仓尾货/新品上市/老客复购）+ 直播时长 + 主推品清单（品名+原价+直播价+核心卖点+库存）。

**也有用：** 平台（抖音/视频号/淘宝/快手/小红书）、主播配置（单人/主播+副播+场控）、直播类型（达人直播/品牌自播）、已有对标脚本/素材。

调用时附带的所有内容——技能名后的文本、粘贴的上下文，或附加的 `ARGUMENTS:` 行——都视为已给出的回答。直接使用并跳过其已覆盖的部分，不要重复提问。

**手头没有任何数据？那也可以。** 技能会基于带货直播通用节奏先套一版默认脚本（4 小时抖音带货默认档），标 `[默认—需验证]`，后续用真实品类与排品回填。

**示例调用：** `下周在抖音做一场美妆精华新品直播，4 小时，主推玻尿酸精华原价 299 直播价 99 卖点 72h 保湿 0 添加 库存 500，帮我写一整场脚本。`

### 输入字段与异常处理

| 字段 | 必填 | 异常处理（缺失/错误时怎么回） |
|---|---|---|
| 带货品类/主题 | 是 | 缺失/过泛→追问具体品类与主题，不假设；只给"带货"→追问具体品类（美妆/服饰/3C） |
| 直播目标 | 是 | 缺失→追问品种草/大促转化/清仓尾货/新品上市/老客复购之一，影响排品与逼单强度 |
| 直播时长 | 是 | 缺失→默认 4 小时并提示；>6h 提示拆场；<1h 提示偏短降级精简 |
| 主推品清单 | 是 | 缺失→追问至少 1 个主推品；只有品名无价格机制→追问原价/直播价/库存（逼单必需） |
| 平台 | 否 | 缺失→默认抖音并提示平台差异（憋单合规/违禁词特化）；非抖音平台标注对应违禁词特化 |
| 主播配置 | 否 | 缺失→默认主播+场控并提示；影响副播配合列 |
| 直播类型确认 | 否 | 缺失→默认达人直播带货（本版主形态）；明确自播→加自播差异提示 |
| 已有对标脚本/素材 | 否 | 缺失→正常；用户提供→作话术风格参考但不照搬（跨品类迁移） |

输出标准：四件套字段见 [references/template.md](references/template.md)；评分判定规则全部可量化（"如果…则…"条件句，禁"较好/一般/适度"），时间节点必须分钟级、直播价与库存必须具体数值、违禁词检出数为 0、憋单段必须含明确放单时间与库存。完整异常场景见下方「异常场景」节。

## 核心概念

### 什么是直播脚本

把一场带货直播从头到尾拆成"整场节奏（什么时间讲什么品、推进到什么阶段）+ 单品话术（每个品怎么从痛点讲到上链接）+ 话术库（开场/留人/逼单等可照念的句子）+ 合规备注（哪里踩违禁词、憋单合不合规）"的可执行脚本，让运营能排期、主播能照念、场控能配合。

### 直播脚本 vs 短视频脚本（混淆点）

| 直播脚本 | 短视频脚本 |
|---|---|
| 重逼单、互动、停留时长，目标是当场成交 | 重完播率、钩子、3 秒跳出，目标是点赞评论转发 |
| 多阶段长时间轴（4h 分钟级排期） | 单段短时长（15-60s 秒级分镜） |
| 话术可临场调整、场控配合发链接 | 逐字逐镜按本拍摄，不可临场改 |
| 逼单心理学驱动转化 | 钩子+情绪驱动传播 |

> 别把短视频的完播率三段结构套到直播。直播的核心指标是停留与转化，逼单话术的重量级远高于钩子。

### 整场三阶段框架 × 六阶段链路（混淆点，宏观节奏 × 微观动线）

```
整场三阶段框架（宏观，管一场直播）
  开场（5-15min 暖场/福利/概括亮点）
  正式售卖（售卖初期低价引流 → 售卖高潮黄金期 → 售卖后期疲乏期秒杀返场）
  收尾（15min 预告/关注/明日福利）

六阶段链路（微观，管每个品的成交动线）
  聚人 → 留客 → 锁客举证 → 说服 → 催单 → 逼单 → 下单
```
- **三阶段框架**：定一场直播的宏观节奏——开场留初始流量，售卖三期（初引流/高潮主推/尾返场）承接转化，收尾预告留存。
- **六阶段链路**：定每个品的微观成交动线——聚人（吸引眼球卖关子不讲品）→ 留客（宣布利好利益留人）→ 锁客举证（场景/卖点/背书/价格优势/现场体验）→ 说服（功效价位包装对比再强调）→ 催单（宣布价格限时折扣前 X 名）→ 逼单（倒计时下单流程引导）→ 下单（引导+感谢）。
- **两者咬合**：整场三阶段里塞多个"六阶段链路"，每个主推品跑一条完整链路，引流品跑缩略链路（聚人→催单→下单）。

### 单品讲解七步结构（讲透一个品）

钩子/痛点 → 引入产品 → 卖点（FABE：特征-优势-利益-证据）→ 信任背书 → 价格锚点 → 限时限量逼单 → FAQ。

### 逼单三型 × 心理学原理（转化驱动）

| 逼单型 | 手法 | 心理学杠杆 |
|---|---|---|
| 价格型 | 最低价/活动价/卖完涨价/同类对比 | 价格锚定（先报原价锚定，再看优惠觉得划算） |
| 库存型 | 限量/不断报剩余库存 | 稀缺效应（手慢则无，抢到就是赚到） |
| 痛点型 | 场景化"什么场景解决什么问题带来什么结果" | 损失厌恶（对失去恐惧>获得愉悦，把购买简化为止损） |

> 三型常组合使用，配"电商捧哏"（中控/助播组合拳重复制造抢购紧张感）。登门槛效应贯穿：先小折扣小甜头→现场沟通加大力度→引导接受更大要求。

### 为何这么做

- **脚本不是提词器是排期表**：直播是长时间轴多动线，没有整场节奏脚本会节奏乱、品讲不完、抽奖失误。
- **话术要结构化不是堆砌**：对标稿话术冗长、卖点分散、主播不知道哪些是开场卖点促单——七步结构把每个品填满，话术分类库给可照念完整句。
- **逼单是科学不是喊麦**：损失厌恶/价格锚定/稀缺/登门槛四条心理学杠杆是逼单有效的底层逻辑，按三型组合比纯靠情绪喊"快抢"转化更稳。
- **合规必须前置不能事后改**：抖音把"憋单"列违规营销、四平台禁绝对化用语与虚假价格对比，脚本阶段不卡掉，下播后扣分限流甚至封号。2026 审核不只听词还分析语调节奏，规避核心是改表达不是躲词。

### 反模式（它不是什么）

- 不是开播提词器——提词器只管念词，脚本要管整场节奏排期与单品成交动线。
- 不是话术堆砌——每条话术要落到具体阶段与品，七步结构与六阶段链路咬合。
- 不是照搬对标——跨品类迁移不通，对标仅作节奏参考，话术按自身品/卖点/人群重写。
- 不是赌一把转化——逼单要按三型与四条心理学杠杆组合，不是纯靠喊"快抢"。

### 何时使用

- 新品上市/大促/清仓前要从零写一整场带货脚本
- 已有脚本但留不住人/逼单不转化，要按六阶段链路与逼单三型重构
- 主播临场忘词/照本宣科无紧迫感，要一套可照念、有倒计时口令的话术库

### 何时不要使用

- 要做短视频脚本/口播稿分镜——那是另一套（重完播率钩子，轻逼单互动）
- 要做直播复盘/数据分析——本技能只产前瞻脚本，复盘建议另起
- v0.1.0 做品牌自播日播/知识内容直播/本地生活——结构差异大，本版只作差异提示，完整覆盖下版

## 应用

使用 [references/template.md](references/template.md) 获取完整的填空式结构。先按带货直播默认节奏套一版，再按 7 步产出四件套（含可选逐字稿与 Excel），交付后走第 8 步旁路提交服务端；每步过质量检查。

### 第 1 步：定直播口径与平台合规底色

先定品类/主题 + 目标 + 时长 + 平台 + 主播配置，决定四件套的整体形态与合规底色。

```markdown
### 口径与目标
- 带货品类/主题：[美妆精华 / 敏感肌 72h 保湿]
- 直播目标：[品种草 / 大促转化 / 清仓尾货 / 新品上市 / 老客复购]（影响排品与逼单强度）
- 直播时长：[4小时]；当前阶段：[新品上市首场]
- 平台：[抖音 / 视频号 / 淘宝 / 快手 / 小红书]（决定憋单合规口径与违禁词特化）
- 主播配置：[单人 / 主播+副播+场控]（决定副播配合列）
- 直播类型：[达人直播 / 品牌自播]（本版主聚焦达人带货；自播在节奏与差异处加提示）
```

**质量检查：**
- 品类具体到细分（美妆精华而非"美妆"），过泛触发异常 2
- 时长 1-6h 通过；>6h 触发异常 4；<1h 触发异常 9
- 平台明确；明确非抖音时按平台违禁词特化复检话术（异常 11）

### 第 2 步：排品与整场节奏脚本表

按三阶段框架 + 六阶段链路排整场分钟级节奏。产出 [references/template.md](references/template.md)「一、整场节奏脚本表」。

```markdown
### 排品结构
- 主推款（[5-8个，讲透七步]）/引流款（[低价拉升人气]）/利润款（[高毛利]）/活动款（[秒杀免单]）
- 排序：高低价交叉，售卖初期引流→高潮主推→后期返场秒杀

### 整场节奏脚本表（14列，分钟级）
| 时间节点 | 直播阶段 | 主播动作/口播 | 副播场控配合 | 商品/链接号 | 原价 | 直播价 | 优惠力度 | 赠品 | 库存 | 画面道具贴片 | 互动引导 | 话术类型 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 0-5min | 聚人 | 暖场问候概括本场亮点 | 场控发福袋 | - | - | - | - | - | - | 主播近景 | 签到抽奖 | 开场 | 暖场不能省 |
| 5-10min | 留客 | 剧透主推款+宣布福利 | 副播上同款照片 | 1号链接 | 299 | 99 | 7折+赠小样 | 试用装 | 500 | 贴片写卖点 | 点赞到1万发红包 | 留人 | - |
| 10-15min | 锁客举证 | FABE讲品+背书 | 场控上检测报告特写 | 1号链接 | 299 | 99 | - | - | 500 | 成分特写 | 设问互动 | 锁客 | - |
| ... | 说服/催单/逼单/下单/返场/收尾 | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |
```

**质量检查：**
- 阶段取枚举（聚人/留客/锁客举证/说服/催单/逼单/下单/返场/转场/收尾），开场-售卖-收尾三段+≥3 个售卖内阶段齐全
- 时间节点分钟级（如"0-5min"），占比 100%，禁"开场后"
- 直播价/优惠力度/库存必须具体数值，禁"有优惠"；缺价格机制触发异常 1
- 主推品 >20 触发异常 8（建议聚焦 5-8 个）

### 第 3 步：单品讲解话术表（七步）

按七步结构给每个主推品写讲解话术。产出 [references/template.md](references/template.md)「二、单品讲解话术表」。

```markdown
### 单品讲解话术表（七步，每品一区）
| 品名 | ①钩子/痛点 | ②引入产品 | ③卖点(FABE:特征-优势-利益-证据) | ④信任背书 | ⑤价格锚点(原价/门店价/直播价) | ⑥限时限量逼单(库存/倒计时/口令) | ⑦FAQ |
|---|---|---|---|---|---|---|---|
| [玻尿酸精华] | [换季敏感泛红起皮] | [引入0添加玻尿酸精华] | [特征:0添加玻尿酸/优势:72h保湿实验/利益:敏感肌可用不刺激/证据:第三方检测报告] | [皮肤科医生推荐+品牌背书] | [原价299/门店价299/直播价99] | [库存500件/倒数5个数/321上1号链接] | [敏感肌能用吗/孕妇可用吗] |
```

- 服饰类可套两公式：卖点+人群+折扣+逼单 / 细节+整体展示+穿搭场景+逼单。
- 高客单品七步重④信任背书（测评/参数/质保），⑥逼单用库存型+痛点型非纯价格型。

**质量检查：**
- 七步每步有内容；空步标"无"并说明为何无（如"本品无赠品主打价低"）；空步 >2 不通过
- ⑤价格锚点必须给原价对比数值；原价无依据触发异常 10
- ⑥必须含库存数+倒计时口令（如"321上链接/最后 X 单"）
- 卖点模糊不可提炼触发异常 12

## 常见陷阱

### 陷阱 1：暖场省略直接讲品
**症状：** 开播即讲品，没暖场没留人
**后果：** 初始流量流失，整场人气起不来；卖品时进人少成交低（蝉妈妈：很多团队不重视暖场是错误观念）
**修正：** 开场 5-15min 走聚人→留客，暖场问候+概括亮点+发福袋，先留人再讲品

### 陷阱 2：话术指令式而非照念句
**症状：** 话术库写"做暖场话术""引导下单"
**后果：** 主播照本宣科无紧迫感、临场忘词，照着念不出来
**修正：** 每条话术写成可照念完整句（"所有宝宝准备，321，上链接"），配倒计时口令

### 陷阱 3：逼单只剩"快抢"
**症状：** 逼单只喊"快抢""手慢无"，无价格锚点无库存无倒计时
**后果：** 转化低，损失厌恶与稀缺效应没激活
**修正：** 按逼单三型（价格型配价格锚点/库存型配报剩余/痛点型配场景化）组合，配倒计时与上链接口令

### 陷阱 4：憋单不放单或条件上架
**症状：** 憋单讲半小时才放单，或"满10人问价才上链接"
**后果：** 抖音判定违规营销扣分限流（school.jinritemai.com 实施细则）
**修正：** 单次憋单放单≤10min，明确放单时间+库存量+倒计时，禁"条件才上架"

### 陷阱 5：违禁词裸用
**症状：** 话术含"全网最低价""限时秒杀""防脱发""加V咨询"
**后果：** 四平台扣分限流甚至封号；2026 审核还分析语调节奏
**修正：** 改表达非躲词——"价格非常有优势建议比价"替代"全网最低价"；限时配明确时限；功效用"使用场景"替代医疗词

### 陷阱 6：跨品类照搬对标
**症状：** 拿别家脚本直接改品名用
**后果：** 话术与自身品/人群/卖点错位，转化更低
**修正：** 对标仅作节奏参考，话术按自身 FABE/人群/价格锚点重写

### 陷阱 7：原价虚标做虚假对比
**症状：** 标"原价599"但无历史成交或建议零售价依据
**后果：** 虚假价格对比，视频号等平台判定违规
**修正：** 原价须有依据（建议零售价/历史成交价），无依据标"建议零售价"或删原价列只留直播价

### 陷阱 8：整场无分钟级排期
**症状：** 脚本只写"开场""讲品""收尾"无具体时间
**后果：** 节奏乱、品讲不完、抽奖失误、场控跟不上
**修正：** 时间节点分钟级（"30-40min"），每个主推品标定讲品与逼单时段

### 陷阱 9：默认出整篇逐字稿当提词器用
**症状：** 不管场景默认产 4h 逐字稿，主播照念不漏
**后果：** 逐字稿两三万字无人能照念、逼单数字写死与实时库存不符、催生照本宣科无紧迫感反模式、丧失临场互动感染力
**修正：** 默认分层逐字（话术库定式句+单品⑥逼单口令逐字，排期与讲品逻辑保持结构化要点）；仅新手首播/品牌自播统一/高客单踩词场景才额外产单品逐字讲稿，且逼单数字用 [X] 占位实时改、按六阶段分段

## Excel 模板输出（拿来即填）

四件套 Markdown 在对话里交付后，**额外给用户一份可直接打开编辑的 Excel 空白模板**，让运营/编导落盘就能填。运行：

```bash
python3 scripts/gen_live_script_xlsx.py --out ./直播脚本模板.xlsx
```

脚本用 `openpyxl` 生成一份 6-Sheet 模板（**表头样式/冻结首行/列宽/示例行已就位**，拿来即填。其中"单品逐字讲稿"为可选 Sheet，仅场景命中时启用）：

| Sheet | 内容 |
|---|---|
| 使用说明 | 模板填写要点速查（四件套+可选逐字稿 评分规则 + 六阶段链路 + 单品七步 + 违禁词速查 + 逐字稿立场） |
| 整场节奏脚本表 | 时间节点/直播阶段/主播口播/副播场控/商品链接号/原价/直播价/优惠力度/赠品/库存/画面道具/互动引导/话术类型/备注（14列） |
| 单品讲解话术表 | 品名/七步（钩子痛点-引入产品-FABE卖点-信任背书-价格锚点-逼单-FAQ） |
| 话术分类库 | 12类话术（开场/留人/互动/锁客/说服/憋单/催单/逼单/成交/活动/感谢/收尾），每类预留3-5行 |
| 合规约束清单 | 违禁词分类自查 + 憋单合规 + 价格真实性，含改写替代表 |
| 单品逐字讲稿（可选） | 品名/时段/六阶段分段逐字（聚人留客·锁客举证·说服·催单·逼单·FAQ），逼单数字 [X] 占位 |

**依赖与异常**：
- 需 `openpyxl`。脚本检测到缺失会以**退出码 2** 终止并给出安装引导：`pip3 install openpyxl`，或重跑带 `--install-deps`（`python3 scripts/gen_live_script_xlsx.py --install-deps`）自动安装后重试。
- 脚本纯本地、不联网、不扣点（与报告提交无关）。
- 成功时 stdout 输出 `LIVE_SCRIPT_XLSX_FILE=<绝对路径>`，三级兜底写盘（`--out` → 当前目录 → `/tmp`）。把该路径告诉用户即可。

**交付动作**：跑完脚本后向用户说「Excel 模板已生成：<路径>，打开即可填；对话里的四件套 Markdown 与之一一对应」。模型本身不直接写二进制 xlsx，这份 Excel 由脚本落盘。

## 通用原则

- 引用 reference 用相对于 SKILL.md 的路径（如 [references/template.md](references/template.md)）。
- 纯方法论输出，免登录免 Key、不扣点，由 agent 直接产出四件套；交付后跑 [scripts/submit_report.py](scripts/submit_report.py) 做旁路登记；额外可用 [scripts/gen_live_script_xlsx.py](scripts/gen_live_script_xlsx.py) 生成 Excel 空白模板（依赖 openpyxl，缺失退出码 2 给安装引导；Excel 纯本地生成不上传）。
- 四件套骨架以 [references/template.md](references/template.md) 为准，照抄填空；正例见 [references/sample.md](references/sample.md)。
- 判定规则全部可量化（阶段枚举覆盖率/七步完整度/违禁词检出数=0/时间节点分钟级占比=100%/憋单有放单时间/逐字稿仅在场景命中时产出且逼单数字用[X]占位），禁"较好/适度/一般"模糊词。
- 必填输入缺失时按「异常场景」表对号入座；缺主推品价格机制/品类过泛/卖点模糊须追问、不自行假设。
- 本技能聚焦「带货直播脚本创作」（四件套）；若用户要的是「短视频脚本」或「直播复盘」，转对应技能，不强包。
- v0.1.0 聚焦带货直播为主；品牌自播日播/知识内容直播/本地生活在差异处加提示完整覆盖下版。
