# 摄影后期调色风格助手

帮助摄影师快速确定调色方向并落地执行的 Agent 技能。

## 功能

- 上传照片自动分析光线、色彩、氛围，推荐适合的调色风格
- 内置 15+ 经典风格（电影/摄影师/胶片/氛围四大类）
- 生成目标风格的预览图，调色前先看效果
- 输出 Lightroom 和 Photoshop 双版本的具体调色参数
- 解析调色思路，知其然也知其所以然

## 预设风格示例

电影风格：黑泽明、王家卫霓虹、韦斯·安德森糖果色、诺兰冷峻、赛博朋克

摄影师风格：滨田英明清透、森山大道粗粝、蜷川实花浓艳、Portra 胶片、Fuji 胶片

氛围风格：金色时刻、蓝调忧郁、复古褪色、高级灰、莫兰迪色

## 安装使用

将本目录中的 `SKILL.md` 文件放入你的 Agent 技能目录即可。
