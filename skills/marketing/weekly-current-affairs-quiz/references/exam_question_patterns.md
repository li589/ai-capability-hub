# 公考时政单选题出题规范

## 一、常见题型分类

### 1. 事实记忆型（简单）

直接考查对新闻事实的记忆，常见提问方式：
- "X年X月X日，XX会议在XX举行，会议主题是？"
- "XX政策/文件于X年X月X日发布，其主要内容不包括？"
- "近日，我国XX工程取得重大突破，下列说法正确的是？"

**出题要点**：题干提供背景，选项围绕具体事实（时间、地点、名称、数据）设计。

### 2. 政策理解型（中等）

考查对政策内涵的理解，常见提问方式：
- "关于XX政策/会议，下列表述正确的是？"
- "XX文件提出了一系列措施，其中属于XX方面的是？"
- "XX会议强调要XX，这体现了？"

**出题要点**：需理解政策核心要义，选项围绕政策要点和易混概念设计。

### 3. 综合分析型（较难）

需要结合多个信息进行综合分析，常见提问方式：
- "关于近期XX领域的系列举措，下列说法错误的是？"
- "XX事件与XX事件的共同点是？"
- "根据XX报告/讲话，下列推断正确的是？"

**出题要点**：选项涉及多个知识点交叉，需综合判断。

### 4. 排序/匹配型（中等）

考查事件先后顺序或对应关系，常见提问方式：
- "下列事件的先后顺序是？"
- "XX与XX的对应关系，正确的是？"

**出题要点**：选项为排列组合或匹配关系，需准确记忆时间线。

## 二、题干设计原则

1. **信息充分**：题干须包含足够背景信息，让用户能基于已知信息作答，不依赖题干之外的额外搜索。
2. **表述清晰**：避免歧义，一句话一个信息点，复杂政策可分号断句。
3. **公考风格**：使用正式书面语，避免口语化表达。
4. **设问明确**：明确问"正确的是""错误的是""不包括的是"等，让用户清楚答题方向。
5. **背景铺垫**：可先用1-2句交代新闻背景，再提出具体问题。

### 题干模板示例

```
2024年X月X日，国务院印发《关于XX的指导意见》。关于该文件，下列说法正确的是：

A. ...
B. ...
C. ...
D. ...
```

```
近日，我国XX取得重大进展。关于此事件，下列表述错误的是：

A. ...
B. ...
C. ...
D. ...
```

## 三、选项设计原则

### 正确选项设计

1. **基于事实**：严格依据新闻原文和官方表述，不自行延伸或解读。
2. **表述严谨**：使用"主要""核心""重点"等限定词时须与原文一致。
3. **长度适中**：正确选项字数与干扰项大致相当，避免明显过长或过短。
4. **避免绝对化**：慎用"完全""唯一""所有"等绝对化表述，除非原文确有此意。

### 干扰项设计

干扰项须有合理迷惑性，常见设计手法：

| 手法 | 说明 | 示例 |
|------|------|------|
| 时间错位 | 将事件时间改为相近但错误的日期 | 会议实际在15日召开，选项写"18日" |
| 数据偏差 | 将关键数据微调（±10%以内） | GDP增长5.2%改为"5.5%" |
| 张冠李戴 | 将A事件的内容安到B事件上 | 将甲政策的措施说成乙政策的 |
| 因果倒置 | 颠倒因果关系或目的与手段 | "为了实现A而采取B"改为"为了B而采取A" |
| 范围扩大/缩小 | 改变政策适用范围 | "全国"改为"部分省份"，或"试点"改为"全面推行" |
| 偷换概念 | 用近义但不同的概念替换 | "高质量发展"偷换为"高速发展" |
| 无中生有 | 编造看似合理的政策内容 | 原文未提及的措施，选项中凭空出现 |
| 混淆主体 | 将不同主体的行为混淆 | 将国务院的措施说成"中央政治局"的 |

### 选项设计注意事项

1. 四个选项须围绕同一知识点或同一事件的不同侧面展开，避免选项之间毫无关联。
2. 选项长度尽量接近，避免正确答案明显长于或短于干扰项。
3. 选项排列随机化，正确答案不要固定在某一位置。
4. 避免出现"以上都对""以上都错"这类选项，除非题目设计特殊需要。

## 四、难度分级标准

| 难度 | 占比 | 特征 | 适用场景 |
|------|------|------|----------|
| 简单 | ~30% | 直接记忆事实，选项区分度高 | 热身、建立信心 |
| 中等 | ~50% | 需理解政策要点，干扰项有一定迷惑性 | 核心练习 |
| 较难 | ~20% | 多知识点交叉，干扰项迷惑性强 | 挑战提升 |

## 五、解析撰写规范

每题须附详细解析，格式如下：

```
【答案】X

【解析】
正确选项X：（说明为什么正确，引用事实依据）

干扰项分析：
- A：（指出错误所在，如"时间错误，实际应为X月X日"）
- B：（指出错误所在，如"主体混淆，该措施由XX提出而非XX"）
- D：（指出错误所在，如"无中生有，原文未提及此项内容"）

【知识点速记】（一句话核心记忆点，便于用户快速回顾）
例："2024年X月X日，XX会议召开，核心议题是XX。"
```

### 解析撰写要点

1. **先说正确的**：先解释正确选项为何正确，给出事实依据。
2. **再逐个排除**：对每个干扰项明确指出错误所在，避免笼统说"不正确"。
3. **知识拓展**：在解析末尾可补充1-2句相关背景，帮助用户构建知识网络。
4. **速记精炼**：知识点速记控制在25字以内，突出时间+事件+核心要素。

## 六、易出错的题型雷区（高危翻车点）

> 以下题型是出题事故的高发区，**优先避开**或**格外小心**——一旦翻车，整道题作废，浪费用户答题时间且损害信任。

### 雷区 1："下列说法错误的是"+"4 个选项都对" 🚨

**翻车场景**：
题干问"下列说法错误的是"，但出题时基于的新闻事实本身包含多个正确要点，4 个选项全部是事实正确的表述，导致没有任何选项是"错误的"，整题无答案。

**为什么会翻车**：
- 这类"反向设问"（问错误/不包括）需要构造干扰项与正确项的角色互换，本质难度高。
- 模型容易只关注"正确选项要符合事实"，却忘了其余 3 个干扰项必须**确实错误**。

**防御策略**：
- **优先用正向设问**："下列说法正确的是" / "下列属于 XX 的是"——只需保证 1 个正确，其余 3 个明显错误即可，出错概率低。
- **必须用反向设问时**：构造完 4 个选项后，反向自证每个干扰项是否"确实有错"——把"明显错误"程度控制在用户能识别的范围内。
- **若新闻材料本身信息不足，无法构造 3 个明显的错误项**，放弃反向设问，改用正向设问。

### 雷区 2："不包括的是" + 范围模糊

**翻车场景**：题干问"下列不属于 XX 范围的是"，但 4 个选项都明显属于该范围（或都不属于），用户无法判断。

**防御策略**：这类题需要对"范围"有清晰定义。优先选择政策文件、官方报告中**明确列出条目**的内容（如"重点工作包括①②③④"），避免使用模糊的范围描述。

### 雷区 3：日期/数据记忆模糊

**翻车场景**：模型凭印象编写具体日期、百分比、金额，但与实际数据有出入，导致题目错误。

**防御策略**：
- **所有具体数据（时间、数字、百分比、排名）必须来自本次 WebSearch 的搜索结果**，不得用模型自身记忆填充。
- 搜索结果中若数据不一致或找不到，则改用模糊表述（"近期""近日"）或换题。

### 雷区 4：偷换概念过度

**翻车场景**：干扰项设计时把"高质量发展"写成"高速发展"、"试点"写成"全面推行"等，但与原文偏离太远反而一眼假，达不到考查效果；或偏离过小，干扰项本身也是对的。

**防御策略**：
- 干扰项的"错误程度"要适中——既能考查用户细心度，又不致于成为废题。
- 干扰项改写后，重新用题干设问校验一遍，确保确实错了。

### 雷区 5：跨年度事件混用

**翻车场景**：把 2024 年的事件说成 2025 年的，把去年数据说成今年的。

**防御策略**：
- 严格使用本次搜索得到的最近 1-2 周的新闻事实，避免使用去年同期的旧闻凑数。
- 若事件是历史性回顾（如"X 会议是 1949 年召开"），时间点需明确且非近一周时可考虑换题。

### 雷区 6：涉政涉主权表述偏差

**翻车场景**：涉及中国台湾、中国香港、中国澳门等表述错误，或涉领土主权问题立场模糊。

**防御策略**：
- 严格遵循官方表述规范：中国台湾 / 中国香港 / 中国澳门。
- 任何涉主权、民族、宗教议题，必须引用本次搜索的官方信源表述，不自行改写。
- 若搜索结果中没有明确官方表述，则换题或换角度。

### 雷区清单速记

出题前**默念一遍**：
1. ⭐ 优先用正向设问（"正确的是"），慎用反向设问（"错误的是"）。
2. ⭐ 所有数据从搜索结果拿，不用模型记忆。
3. ⭐ 4 个选项里**必须**只有 1 个能满足设问，其他 3 个**必须**明确不满足。
4. ⭐ 反向自证：把每个选项用题干设问过一遍。
5. ⭐ 涉政表述严格按官方信源。
