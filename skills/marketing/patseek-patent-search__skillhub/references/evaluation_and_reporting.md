# 候选评价与报告规范

## 1. 可解释排序

语义分仅用于召回。为每篇候选记录以下维度，不强制合成一个伪精确总分：

| 维度 | 记录方式 |
|---|---|
| 特征覆盖 | 已明确/隐含/未见的必要特征数量 |
| 关键关系 | 结构、步骤、因果、参数关系是否一致 |
| 日期 | 关键日前/抵触申请候选/关键日后/未知 |
| 来源 | Bool块、分类块、语义、引证、同族、非专利 |
| 多路命中 | 命中的独立检索切角数量 |
| 证据完整度 | 是否有权项、段落、附图和官方状态 |
| 任务适格 | 新颖性、创造性、FTO或仅背景参考 |

相同覆盖下优先：关键关系一致、日期适格、多路独立命中、证据完整的候选。

### X/Y候选输出

分别维护X、Y-Base、Y-Comp候选，不合并成一个“相关度Top榜”。X要求单篇覆盖全部必要特征及关系；Y-Base要求领域/问题接近且公开大部分特征；Y-Comp要求公开缺失区别特征并有待复核的结合理由。完整标准见 `adaptive_xy_search.md`。

## 2. 同族聚合

同族成员可得时，以最早优先权族聚合，并保留：最早公开文本、目标法域成员、当前有效授权文本、最完整语言文本。只有同族数量而没有成员时，输出“同族聚合未完成”。

## 3. 证据矩阵

| 文献 | 特征 | 位置 | 披露类型 | 原文要点 | 日期角色 | 复核状态 |
|---|---|---|---|---|---|---|
| CN… | F1 | 权1/段[0030]/图2 | 明确/隐含 | … | 关键日前 | 已复核/待复核 |

“未见”只表示在已核对文本中未发现，不等同于文献绝对没有。

## 4. 检索记录

| 路次 | 角色 | 市场/来源 | 检索式 | 命中数 | 条件可观察率 | 前10 H/M/N/D | 新X/Y | 调整理由 |
|---|---|---|---|---:|---|---|---|---|

H/M按角色定义：QX看整体覆盖与关系，QY-Base看最接近领域/问题，QY-Comp看是否明确命中指定缺失特征。报告QY-Comp时增加“目标缺失特征”列；没有明确命中时不得因总体相关而标H/M。

命中≥5,000条时在“是否继续”中标记“过宽—必须收窄”，并记录新增的关键区别特征、希望排除的噪声和收窄后命中数。显示10,000条时标记“达到上限—数量不可用于统计”。

逐条件报告前10可观察率；新增条件低于50%时标记“约束无效”，不得把总量下降写成精度改善。申请人/国家/日期/IPC字段必须另列字段反查通过率。申请人主题只有在字段反查和技术相关性均通过后才能进入主体统计。

QY-Comp另列目标缺失特征、功能/关系、二者同篇联合可观察率和结果规模；任一可观察率低于50%或结果≥5,000时标记“仅取词，不入Y候选”。FTO另列每个实施分支的目标E编号、权利要求命中位置、独立/从属关系和官方状态核验状态；说明书命中不能填写到权利要求覆盖列。

主体报告列出每个名称变体的原始命中、合并去重规则和联合精确率。名称变体的原始总量不得相加或互相比高低；联合精确率低于70%时不生成定量竞品排名。

记录 Skill 版本、脚本版本/哈希、检索日期和 API 返回状态。失败/超时单列，不能记为0条。

## 5. 中止说明

说明哪些检索块已达到饱和、哪些因权限/时间未覆盖。固定 Top N 只能控制人工核对批次，不能证明检索完成。

## 6. 报告附图展示规范

报告应尽量展示**重点专利**的附图，比文字描述更直观，特别是涉及部件结构、方法步骤、电路连接时。

### 何时展示附图

| 必须展示 | 建议展示 | 不必展示 |
|---|---|---|
| X 文献/Y 文献核心候选 | 高被引专利 | 仅作背景参考的专利 |
| 目标专利（查新/FTO/无效场景） | 典型实施例相关专利 | 低相关候选 |
| 技术路线代表专利 | | |

### 展示方法

1. 用 `patent <id> --figures-dir <目录>` 下载附图到本地
2. 报告中插入图片：`![](figures/CN217874688U/01.png)`
3. 每张附图配简短说明：什么图、对应什么技术特征、为什么引用
4. **优先展示剖视图/结构图**（展示部件关系）和**流程图**（展示方法步骤），其次电路图

### 附图来源可靠性（2026-08-08 实测）

| 项目 | 验证结果 |
|---|---|
| 来源 | Google Patents（patentimages.storage.googleapis.com） |
| US 附图覆盖 | 优，实测 US10234567B2 14 张全部成功下载 |
| CN 附图覆盖 | 部分覆盖，实测 CN217874688U 有 3 张 |
| EP/JP/KR/WO | 覆盖主要专利局 |
| URL 稳定性 | 长期有效，下载速度快（PNG 4KB-117KB） |
| 限制 | 少数专利（较老或非主要国家）可能没有附图 |

附图字段不统一：Bool 检索的 `figures` 字段可能为空，详情接口的 `figures` 字段更完整。下载前用 `patent` 命令的 `--show-figures` 查看是否有图。

### 重点专利快速阅读链接

报告中应为重点专利提供**快速阅读链接**，方便用户跳转查看专利全文（权利要求、说明书、附图、法律状态等）。

**链接格式**：

```
单篇：https://xinxin.chat/patent?pid=<公开号>
多篇对比：https://xinxin.chat/patent?pid=<公开号1>&pid2=<公开号2>
```

**报告中的推荐写法**：

```markdown
# 候选列表（每篇都带链接）
| 公开号 | 标题 | 申请人 | 链接 |
|---|---|---|---|
| CN217874688U | 过滤型浮动盲插流体连接器 | 中电科40所 | [查看](https://xinxin.chat/patent?pid=CN217874688U) |
| US12247685B2 | Self-centering blind mate fluid coupling | Parker Hannifin | [查看](https://xinxin.chat/patent?pid=US12247685B2) |

# 关键候选对比
[CN217874688U vs US12247685B2 对比阅读](https://xinxin.chat/patent?pid=CN217874688U&pid2=US12247685B2)
```

快速链接应与附图展示配合使用——附图展示技术方案细节，快速链接提供全文阅读入口。报告中**所有进入候选池的重点专利都必须提供快速链接**（硬性要求，缺链接视为报告不完整）：候选表、比对表、双导读中提到的具体文献公开号，一律附 xinxin.chat 链接。走 `report_guard.py` 渲染的报告，其"候选证据"表自动生成链接列，无需手工填写；手写报告须逐篇核对。

## 7. 报告结构

交付 Markdown 报告的结构（前置双导读 + 正文 + 结尾双建议，顺序固定为先发明人后代理人）：

**前置·双导读**（详见 `dual_summary.md`）
- 给发明人的导读：一句话结论 / 最接近几个方案差在哪 / 下一步 / 红线
- 给代理人的导读：检索范围与结论 / 最接近现有技术+缺失 / 权利要求建议+争点 / 待核验

**正文**
1. 任务、使用者、待支持的决策与结论摘要
2. 技术方案/实施方案及假设
3. 关键日期、国家和数据范围
4. 特征/权利要求要素表
5. 检索矩阵与执行记录
6. 同族和候选池说明
7. 关键文献证据矩阵（含附图展示）
8. 按任务类型的法律分析框架
9. 发明人待澄清问题或规避建议
10. 未覆盖项、限制和下一步

**结尾·双建议**（详见 `dual_summary.md`）
- 给发明人的建议：需进一步深挖的方向
- 给代理人的建议：需询问发明人的问题清单

> 前置双导读与结尾双建议共享同一组证据，不重复检索、不额外耗积分；用词与纪律规则见 `dual_summary.md`。`report_guard.py` 校验四个小节对应字段非空，缺则拒绝渲染。

## 8. 发明人问题

每个问题包含优先级、关联特征/文献和回答后的影响：

- P0：会改变必要特征、日期、FTO实施范围或关键结论；
- P1：会强化效果、参数依据、替代方案或从属保护；
- P2：产业化或报告完善信息。

把问题映射到交底书章节：背景问题、技术手段、部件/步骤关系、参数依据、实验数据、替代实施例和技术效果。

## 9. 限定结论模板

可专利性：

> 截至[日期]，在[范围]及所列检索式内，[发现/未发现]一篇关键日前公开并披露全部必要特征的文献。该结论受[未覆盖项]限制，不保证授权前景。

FTO：

> 识别出[数量]个需进一步核对的目标法域权利。风险等级基于当前取得的权项和状态；最终是否影响实施须由合格专业人员结合官方登记簿和具体方案判断。
