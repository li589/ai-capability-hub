# 相关技能与组合用法

本技能（转化与复购运营）是「私域用户运营」域的**执行漏斗轴**：父技能【私域用户运营】做**价值轴 RFM 分层 + 画像 + 触达方向**（问「谁值多少、怎么对待」，止于八象限触达方向不给话术）；【用户生命周期旅程】做**时间轴阶段 + 旅程诊断 + 策略**（问「走到哪、往哪引」，其 related.md 明确「成稿话术归父技能触达表、本技能不给话术」）；本技能做**执行漏斗轴**（问「这条漏斗怎么落地」）——把价值分层与生命周期阶段收敛到首购/复购/沉睡/高客单四类漏斗的**可执行话术套件 + 召回方案**，按五要素（人群包+触发条件+话术+权益+导购动作）落地。三者「价值轴→时间轴→执行漏斗轴」正交，本技能独立可用、RFM/阶段**正交引用不重算**。【私域标签体系搭建】搭标签底座供人群包筛选，【会员体系搭建】定等级权益供权益梯度引用。六者互补，可独立用、也可串成完整 SOP。

|---|---|---|---|---|---|

## 原语共享与咬合

- **RFM 结果 → 价值维度交叉**：本技能把首购/复购/沉睡漏斗人群 × 父技能 RFM 高/中/低价值做矩阵（高价值客走专属顾问1v1、长尾走自动化），不重算 RFM。父技能问「谁值多少」，本技能问「这个高价值客这条漏斗配什么话术动作」。
- **生命周期阶段 → 触发时间维度**：本技能复购漏斗的触发条件可引用【用户生命周期旅程】的阶段转换（如成熟期→休眠期的衰减信号触发沉睡召回），阶段不重定义。
- **标签 → 人群包筛选**：本技能五要素人群包的筛选条件（新粉/复购2次+/沉睡60天）消费【私域标签体系搭建】的事实/行为/预测标签。
- **会员等级/积分 → 权益梯度**：本技能权益梯度（复购券→2倍积分→会员升级奖励）可引用【会员体系搭建】的权益配置与积分汇率。

## 怎么组合

1. **先 RFM 价值分层、再生命周期分段、最后转化漏斗落地（推荐完整 SOP）**：
   - 用父技能【私域用户运营】做 RFM 价值分层，看清用户价值分布
   - 用【用户生命周期旅程】定义五阶段+转换条件，交叉成阶段×价值矩阵
   - 用本技能：把活跃→首购→复购→加购拆成四类漏斗，按五要素落地可执行话术套件+召回方案，正交引用前两者结果

2. **只做转化复购（用户目标明确是「提首购/提复购/沉睡召回/提客单价」）**：
   - 直接用本技能四件套即可
   - 价值/阶段维度可先用高/中/低简化档，后续接父技能/生命周期旅程结果做矩阵校准

3. **已有触达方向、补执行落地（父技能分了层但落不到话术）**：
   - 用本技能把父技能八象限触达方向收敛到四漏斗五要素话术套件
   - 补企微话术组五段式与沉睡召回方案，导购动作标准化

## 一句话区分用户该用哪个

- 用户说「帮我把用户按价值分层、做差异化触达方向」 → 父技能【私域用户运营】（RFM分层+触达方向）
- 用户说「分了层但每类配什么话术/权益/导购动作不知道」/「首购率/复购率怎么拉起来」/「沉睡用户怎么召回」 → 本技能（转化与复购运营，四漏斗×五要素执行套件）
- 用户说「做用户生命周期方案/定流失召回阈值/画旅程图」 → 【用户生命周期旅程】
- 用户说「帮我搭一套标签底座/治理乱标签」 → 【私域标签体系搭建】
- 用户说「帮我从0设计会员积分体系/定等级设权益/算积分汇率预算」 → 【会员体系搭建】
- 用户说「私域转化复购整套做一版」 → 先父技能 RFM 分层 → 再生命周期旅程分段 → 最后本技能四漏斗执行落地 → 按需叠标签底座与会员积分权益
