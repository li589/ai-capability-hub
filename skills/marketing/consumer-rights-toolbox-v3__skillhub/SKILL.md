## 零、法规时效性原则（动态版本确认铁律，必读）

本 Skill 的内化边界必须严格切分「知识层」与「法规版本层」——这是本 Skill 能否跨年度长期可用的核心，执行者被调用时务必遵守。

### 0.1 两层切分
- **知识层（Skill 内置，相对稳定）**：消费维权路径框架、证据清单逻辑、话术模板、高频场景识别。这部分源于书籍内化，跨年度变化慢，可直接调用。
- **法规版本层（运行时确认，逐年剧变）**：具体法条文本、条文序号、施行日期、修订/修正/废止状态、罚则数额、司法解释、部门规章与地方性法规版本。**法律持续修订——消保法及 2024 年《消费者权益保护法实施条例》本身可能再修订，且地方性法规与裁判口径持续更新。Skill 内置的年份/版本只是成书时点快照，绝不保证"现行有效"。**

- 用户在 **N 年**调用本 Skill → 涉及的具体法规，必须确认其 **N 年（或最新）现行有效文本与修订状态**。

> 结论：执行者被调用时，**涉及具体法条/罚则/版本状态的问题，第一步先在线确认现行有效文本**，再作答。Skill 内置的任何法条年份、条文序号都只是"成书时点参考"，不是现行答案。

## 二、消费者九大权利（消保法第2章）

1. **安全保障权**：人身、财产安全不受损害。
2. **知悉真情权**：知悉商品/服务真实情况（价格、产地、期限、风险等）。
3. **自主选择权**：自主选择商品/服务、自主比较鉴别，不受强制交易。
4. **公平交易权**：质量保障、价格合理、计量正确，有权拒绝强制交易、霸王条款。
5. **依法求偿权**：因消费受损依法获得赔偿。
6. **结社权**：依法成立维护自身合法权益的社会组织。
7. **获取知识权**：获得消费和消费者权益保护知识。
8. **受尊重权 + 个人信息受保护权**：人格尊严、民族风俗受尊重；个人信息依法保护（2021《个人信息保护法》强化）。
9. **监督权**：对商品/服务及保护工作批评、建议、举报。

> **关键判断**："消费者"指为生活消费需要购买、使用商品或接受服务（案例注释版第72人划线）。公共医疗卫生服务等非商业服务一般不适用消保法。

## 三、经营者核心义务（消保法第3章 + 2024条例）

- 保证商品/服务安全，危险商品/服务应作出真实说明和明确警示；
- 真实、全面告知商品/服务信息，不作虚假或引人误解宣传；
- 标明真实名称和标记；
- 出具购货凭证、服务单据；
- 保证质量，落实"三包"（修理、更换、退货）；
- 正确使用格式条款：**不得作出排除/限制消费者权利、减轻/免除经营者责任、加重消费者责任等对消费者不公平、不合理的规定**，此类条款无效（"禁止自带酒水"等店堂告示无效）；
- **2024条例新增**：不得利用技术手段强制/变相强制消费；不得"大数据杀熟"；自动续费须双重显著提示；网络直播须说清"谁在带、带谁的货"；预付式消费须签书面合同；不得过度收集个人信息、不得一次概括授权。

## 四、争议解决五路径

```
协商 → 消协调解 → 行政投诉(12315/市场监管) → 仲裁 → 诉讼
```

1. **协商**：最直接，保留沟通记录。
2. **消费者协会（12315 / 全国消协）**：投诉调解，不收费；消协可调查、约谈、支持起诉。
3. **行政投诉（12315 / 市场监管部门）**：有关行政部门应自收到投诉之日起 **7个工作日内** 处理并告知。适合经营者违法（虚假宣传、不合格商品、价格违法）。
4. **仲裁**：需双方有仲裁协议，一裁终局。
5. **诉讼**：无仲裁协议或对行政处理不服，向有管辖权法院起诉；小额诉讼程序可简化。

> **网络消费特别路径**：平台内经营者侵权，可要求平台提供经营者真实信息；平台不能提供的，消费者可要求平台赔偿（《电子商务法》第38条、最高法网络消费司法解释一）。

## 五、惩罚性赔偿速算

### 5.1 一般欺诈：退一赔三
经营者有欺诈行为（虚假宣传、以假充真、以次充好），消费者可要求**退还货款 + 增加赔偿三倍**；增加赔偿不足 **500元** 的，按 **500元** 计。

### 5.2 食品不安全：退一赔十
生产不符合安全标准食品或明知而不符合仍销售，消费者除赔偿损失外，可主张**价款十倍或损失三倍**赔偿金；增加赔偿不足 **1000元** 的，按 **1000元** 计（《食品安全法》第148条）。

### 5.3 商品房消费者特殊保护
符合"在查封前签订合法合同+合法占有+已付全部或50%以上房款+非因自身原因未过户"条件的，消费者权利优先于建设工程价款优先受偿权、抵押权（最高法商品房消费者权利保护批复）。

### 5.4 注意边界
- 标签标识等**不影响质量且不会误导的瑕疵**，不适用惩罚性赔偿（2024条例）；
- 通过夹带、掉包、造假、篡改生产日期等**骗取赔偿或敲诈勒索的，依法处理**——职业打假须守法。

## 六、特殊场景维权要点

### 6.1 网络购物 / 直播带货
- **7日无理由退货**：签收后7日内，无需说明理由（定作、鲜活易腐、拆封音像软件、报纸期刊、其他约定不适用）。
- **直播带货**：平台应提供直播间运营者、营销人员信息及经营记录；主播/平台责任依《条例》第14条。
- **刷单/虚假评价**：虚构交易、编造用户评价的合同无效（最高法网络消费司法解释一）。
- **奖品赠品不免责**：促销奖品/赠品造成损害的，经营者仍需赔偿。
- **大数据杀熟**：同物不同价可投诉，多设备比价取证。

### 6.2 预付式消费（健身/培训/美容/餐饮卡）
- 经营者应**订立书面合同**，约定内容、价款、退款方式、违约责任；
- 不得擅自降低质量、任意加价；
- 未按约定提供，应履行或退预付款；
- **重大经营风险应停止收款**；停业/迁移应提前告知并退余额（2024条例）。
- 维权：留好合同、付款记录、宣传承诺；跑路立即投诉+集体维权。

### 6.3 汽车消费
- **三包**：自购车60日内/3000公里内出现转向/制动/车身开裂/燃油泄漏，免费退换；2年内/5万公里内严重安全故障累计2次未排除可退换。
- **召回**：缺陷汽车产品召回，经营者免费消除缺陷。
- 保留购车合同、维修记录、故障证据。

### 6.4 食品安全
- 过期、变质、不符安全标准 → 退一赔十；
- 农药残留超标、虚假保健食品功能 → 投诉市场监管+索赔；
- 保留购物小票、问题食品照片/实物、就医记录。

### 6.5 老年人防骗（来源：《老年人防骗维权攻略》）
- 典型骗局：投资养老/以房养老非法集资、保健品"包治百病"、中奖缴税、冒充公检法、电信诈骗。
- 防骗原则：高息诱饵不信、陌生转账不办、保健品不等于药品、重大决策与家人商量。
- 被骗后：第一时间保留转账记录、聊天记录、宣传材料，立即报警（刑事）+ 市场监管投诉（行政）+ 消协（民事）。

### 6.6 金融消费
- 银行/保险/理财销售应如实告知风险，不得误导；
- 适当性义务：不得将高风险产品卖给不匹配的消费者；
- 争议可向金融机构投诉、金融监管消保部门、诉讼。

### 6.7 旅游 / 房产 / 服务消费
- 旅游：旅行社擅自改行程、减景点、拒载应承担违约责任（案例注释版）；
- 房产：商品房消费者权利优先保护（见5.3）；
- 餐饮/商超：就餐异物、人身损害、搜身扣留均属侵权。

## 七、2024《消费者权益保护法实施条例》新亮点（必读）

《条例》2024年7月1日施行，是消保法首部配套行政法规，填补多项空白：

1. **禁止大数据杀熟**（第9条）：同等交易条件下不得设不同价格。
2. **整治自动续费隐形陷阱**（第10条）：开通前+到期前双重显著提示。
3. **规范直播带货**（第14条）：平台须建消保制度、提供主播/直播间信息。
4. **强化预付式消费**（专条）：书面合同、质量不降、停业退余额。
5. **个人信息保护**（第23条）：不得过度收集、不得一次概括授权/默认授权。
6. **禁止强制消费**（第10条）：不得利用技术手段强制/变相强制购买、排除限制选择其他经营者。
7. **规范消费索赔**：反对滥用权利、恶意维权（夹带掉包造假敲诈勒索依法处理）。

## 九、文书模板

### 9.1 消费者投诉书（框架）

```
投诉人：____，联系电话：____，地址：____
被投诉方：____（名称/统一社会信用代码/地址，尽量齐全）
投诉请求：
1. 请求退还货款/服务费____元；
2. 请求依法赔偿____元（退一赔三/十倍，据实）；
3. 请求查处被投诉方违法行为。
事实与理由：
____年____月____日，投诉人在____（渠道）购买____（商品/服务），支付____元。
经查，该商品/服务存在____（虚假宣传/质量问题/不符安全标准/违约）情形，违反了《消费者权益保护法》第__条、《消费者权益保护法实施条例》第__条等规定，侵害投诉人合法权益。
附件：1.购买凭证 2.商品照片 3.沟通记录 4.其他证据
投诉人：____（签名）
____年____月____日
```

### 9.2 起诉状要素
原告/被告信息、诉讼请求、事实理由、证据清单、受诉法院、具状人签名。建议标的额较大或对方强硬时由律师代书。

## 十、避坑指南

1. **先取证再交涉**：拿到证据前不要打草惊蛇让对方销毁。
2. **别签"私了免责"空白协议**：对方可能借此免责。
3. **警惕"职业维权"中介收费**：正规消协、12315、法律援助不收费。
4. **老人消费先与家人商量**：多数骗局利用"怕麻烦/怕子女责怪"心理。
5. **网络纠纷保留平台工单号**：平台介入记录是强证据。
6. **时效意识**：民事诉讼一般3年时效，尽早主张。

## 付费前置检查（微信 X402 协议）

调用本 Skill 前，先检查当前 Agent 是否已安装 `weixinpay` 插件（extension）：

- 已安装：可继续提供付费服务
- 未安装：向用户提示「当前 Agent 暂不支持微信支付付费能力」，终止流程

## 支付触发（首次请求收到 HTTP 402）

向本 Skill 的 `endpoint` 发起 POST 请求，若收到 HTTP 402 响应，`weixinpay` 插件会拦截并完成支付流程：

- Header `WeixinPay-Required`：支付凭证码（插件用于完成支付）
- Header `X-Out-Trade-No`：商户订单号

> 支付过程由 `weixinpay` 插件处理，Skill 无需关心支付细节。

## 重试机制（支付成功后必须重新请求）

支付成功后，**必须**重新发起请求获取付费内容：

- JSON body 与首次请求完全一致
- 通过 Header 携带支付信息：`WeixinPay-Required` 和 `X-Out-Trade-No` 原样带上

## 订单号传递规范

- 商户订单号通过 402 响应的 Header `X-Out-Trade-No` 返回
- 重试请求时通过同名 Header 原样回传，不得修改

## 异常处理

- 若重试返回 `"code": "NOT_PAID"`：支付尚未完成，等待后重试
- 若返回 `"code": "REFUNDED"`：服务异常已退款，告知用户并终止
- 若返回 `"code": "REFUND_FAILED"`：服务异常且退款失败，建议联系客服
