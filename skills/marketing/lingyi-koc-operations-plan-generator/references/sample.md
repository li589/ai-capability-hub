# KOC 运营方案样例

> 一份填写完整的真实方案样例 + 一份糟糕反例对比。正例以美的U8空气净化器脱敏呈现（素材来源于本技能历史实跑产出），体现8章咬合、三层话题品牌IP真融入、4阶段节奏+三平台日历、5变量差异化矩阵、风控护栏齐全。反例展示常见错误及改进。

## 示例一：优秀填法（美的U8空气净化器·正例）

### 输入
- 产品名称：美的U8空气净化器 / 品类：空气净化器 / 功能：双风机净化·可组合滤芯·甲醛数显
- 核心卖点：双风机高效净化·可按需组合滤芯适配场景·低噪运行 / 定价：¥2999
- 目标人群：25-40岁女性，母婴家庭/新房业主/宠物家庭，担心空气质量影响家人健康
- 品牌：美的 / 预算：30万 / 周期：4周

### 一、项目背景与目标
- **point A**：U8是美的空净高端款，目标人群对甲醛焦虑但认知停留在"贵的不如小米性价比"，需打透真实场景建立高端心智。
- **point B**：声量55%（三平台累计曝光800万+品牌词搜索增长50%）/销售25%（ROI 1:3）/心智20%（占住"可组合滤芯=按需定制空气"认知）
- **核心任务**：用4周三平台KOC种草打透母婴家庭甲醛焦虑，以"可组合滤芯"差异化心智拦截小米性价比心智。
- **投放周期**：2026-09-01至09-28 / **总预算**：30万 / **KPI**：曝光800万+爆文率10%+ROI 1:3

### 二、卖点拆解与KOC拍摄建议
| 卖点 | 三层拆解 | 差异化强度 | KOC可拍画面 |
|---|---|---|---|
| 双风机高效净化 | 功能"两套风机一起干活净化速度翻倍"/情感"客厅开Party也不怕空气闷"/场景"宝宝房间空气稳了" | 强差异化 | 打开机盖特写双风机同时运转 |
| 可组合滤芯 | 功能"滤芯能换花样按场景配"/情感"我家需要哪种空气它就变哪种"/场景"新房除甲醛vs养宠除味换不同滤芯" | 强差异化（无竞品在打）| 甲醛数显录屏+换滤芯过程特写 |
| 低噪运行 | 功能"睡觉放着不吵"/情感"再不用和机器噪音共眠"/场景"深夜卧室分贝仪对比" | 品类通用 | 深夜卧室分贝仪对比录屏 |

- **备选**：①「双风机一起干活，净化快一倍」（优先级高）②「宝宝房间空气终于稳了」（母婴人群优先）③「新房除甲醛，换块滤芯就行」（新房人群优先）

### 三、竞品空位判断
- **3a内部自查**：美的自有中低端款H系列（¥899，此为演示占位），U8贵2.3倍——凭什么多花钱？答：H系列是固定滤芯不能按场景调，U8可组合是"按需定制空气"的升级，不是同一需求。
- **3b外部三平台宣传对标★**：小米（小红书主打性价比/抖音主打智能联动/视频号主打全屋净化）、飞利浦（高端进口主打抗敏）、舒尔茨（主打专业除醛）。> 注：本样例的竞品互动量/播放量为演示占位，实际产出须用 WebSearch/tavily 联网核验并标源，或标"暂无数据"，绝不编造——此处因样例无法实时联网故省略具体数字。
- **3c空位（多维交集）**：可组合滤芯 × 母婴场景 × ¥2999价位——无竞品同时覆盖这三维度。小米打性价比但滤芯固定，飞利浦打抗敏但价位¥4000+（演示占位）不带可组合，舒尔茨打除醛但不打母婴信任感。

## 示例二：糟糕填法（反例对比）

### 输入
某操盘手只说："美的U8空气净化器，找100个素人发100条种草笔记霸屏小红书。"

### 反例产出
- 方案=卖点罗列（双风机/滤芯/低噪）+ 话题清单（#空气净化器 #美的 #好物推荐）+ 排期表（100人一周发完）+ 文案模板（统一发给100人抄）。
- 无竞品空位判断、无人群矩阵、无差异化、无风控。

### 为什么失败
1. **同一brief下发100人** → 骨架层同质化触发算法降噪，整批限流，划走率90%。这正是"找100个素人发100条相似硬广笔记以为能霸屏"的反模式。
2. **话题#空气净化器#美的#好物推荐无人群搜索词** → 没人搜，无空位支撑，与小米性价比心智撞车无差异化。
3. **100人一周发完** → 日内商业占比远超40%限流阈值，且未报备+未错峰。
4. **无卖点三层拆解** → 传播信息散，KOC不知道拍什么。
5. **无竞品空位/人群矩阵** → 不知道主攻谁、差异化在哪。

### 如何改进（对应正例8章）
- 第2步拆卖点三层定核心传播信息"滤芯能换花样"；
- 第3步找可组合滤芯×母婴×¥2999空位（非和小米拼性价比）；
- 第4步锁定母婴小红书186万为主攻；
- 第5步三层话题含人群搜索词+品牌IP"小美"；
- 第6步4周排期非一周堆量，预算3:7；
- 第7步5变量矩阵让20人骨架全错开+3护栏+蒲公英报备+跑dedup；
- 第8步定复盘框架含下一轮建议。

> 核心区别：正例从"卖点→空位→人群→话题→节奏→风控"咬合推导，从源头防同质化；反例只想"铺量霸屏"，方向错了再努力也被限流。
