# 相关技能与边界划分

## 边界划分表

| 技能 | 所在阶段 | 与本技能边界 | 组合方式 |
|---|---|---|---|
| KOC运营方案生成（本技能） | 上线前·方案策划期 | 产KOC运营方案文档（8章），聚焦"推什么/对谁说/怎么排期/怎么执行/怎么收口" | 本表中心 |
| 选品策略与品类规划 | 本技能上游 | 决定"推什么产品"；本技能承接已选定的新品，不做选品决策 | 选品→本技能 |
| 爆款内容预检（付费版）| 发布前·质检下游 | 对成稿做合规+爆款潜力质检；本技能给brief框架不给成品，成品产出后交预检 | 本技能brief→KOC成稿→预检 |
| 违禁词检测+优化 | 发布前·质检下游 | 同上，发布前合规姊妹，可合并指向预检 | 同上 |
| 私域标签体系构建（免费版）| 跨公私域·底座 | KOC方案人群细分可消费标签体系的"人群标签"作输入；标签是私域底座，KOC是公域种草侧 | 标签人群→本技能第4步人群矩阵 |
| 公私域联动方案生成 | 公转私·承接 | KOC种草（公域）带来流量进私域后的承接链路；本技能产公域种草方案，联动方案做公转私 | 本技能→联动方案 |
| 企微运营方案生成 | 私域·触达下游 | KOC带来的流量进企微后的触达落版 | 本技能→企微运营 |
| 视频号达人筛选（付费版）| 视频号侧·执行补充 | 本技能第6/7步视频号KOC投放的达人筛选补充工具 | 本技能定视频号方向→达人筛选执行 |
| KOC账号诊断（待立项姊妹能力）| 执行中·账号体检 | 对单个具体KOC账号体检（5维评分+定位）；本技能用筛选三硬指标选人不诊断账号健康 | 方案并行本技能给方案，诊断对已合作KOC体检 |

## 原语共享

本技能与上述技能共享以下原语（方法论基础）：
- **不编造数据红线**：★联网或真实粘贴，搜无标"暂无数据"——所有运营类技能通用。
- **三平台累计口径**：小红书/抖音/视频号分别记录，最终看累计——本技能与达人筛选/数据监控共用。
- **口语化表达**：卖点/痛点/文案用真人分享口吻——本技能与内容质检/违禁词检测共用判定。
- **差异化防同质化**：骨架层而非词句层——本技能5变量矩阵与预检/dedup脚本共用判定逻辑。

## 怎么组合

- **先选品后种草**：选品策略与品类规划 → KOC运营方案生成（本技能）。先定推什么，再定怎么推。
- **只做方案不做执行**：本技能 → KOC自行产出成稿 → 爆款内容预检/违禁词检测质检 → 发布。本技能止于brief三卡占位，不代写成稿。
- **已有上游回头补**：若用户已有竞品分析/话题/人群画像，直接喂入本技能对应章节，不重跑。
- **公私域全链路**：选品 → 本技能公域种草方案 → 公私域联动方案（公转私）→ 企微运营方案（私域触达）→ 数据监控/复盘。
- **方案+账号诊断并行**：本技能给新品全套方案；同时用KOC账号诊断对候选KOC体检筛选——两者并行不冲突，诊断产出的KOC名单可喂入本技能第6步KOC分层。

## 一句话区分

要"出一份新品三平台KOC种草方案文档"→ 本技能；要"给某个KOC账号体检"→ 账号诊断（待立项）；要"发布前查成稿合规爆款"→ 爆款内容预检；要"公域种草流量进私域承接"→ 公私域联动方案；要"决定推哪个产品"→ 选品策略。
