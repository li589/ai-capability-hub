# 小红书渠道差异化参数

本文件记录 `channel=xhs` 时与小红书技能相关的差异化内容：标题、标签、文案美学、save 入参。

## 写作风格（6 选 1，按白名单或自由发挥）

小红书强制从以下 6 个风格中识别；用户传的单个风格若在白名单内直接使用，若不在白名单内**按用户输入自由发挥**（不向用户追问）：

- `种草测评风`
- `限时促销风`
- `故事代入风`
- `干货教程风`
- `真实分享风`
- `精致生活风`

**风格选择规则：**
- 用户传**单个字符串**：
  - 在白名单内 → 直接使用该风格
  - 不在白名单内 → **不向用户追问**，按用户输入风格自由发挥
- 用户传**字符串数组**：
  - 按主流程已有的“`randomSeed` 随机选一个”规则，从数组中**随机选一个**作为本次风格
  - **数组中的风格不进行白名单校验**：可以混合白名单内/外、自定义风格名
  - 选出的风格在后续 Step 4 中按其字面含义使用
- 用户**未传** `writingStyle`：
  - 默认走 `种草测评风`
  - 必须在执行 Step 4 之前向用户明确告知“本次使用风格：种草测评风”，避免歧义

## 标题

- 生成以下 5 类备选标题，从中选取与当前风格和人群最契合的一个：

  | 类型 | 原则 |
  |------|------|
  | 悬念型 | 制造好奇，引发点击 |
  | 痛点型 | 直击场景痛点 |
  | 反差型 | 制造认知反差 |
  | 利益型 | 明确读者得到什么 |
  | 情绪型 | 调动情绪认同 |

- **标题规则：**
  - 不超过 20 字，优先 18 字左右
  - 禁止 emoji 堆砌，最多 0～1 个
  - 标题要像小红书笔记标题，不要像公众号长标题

## 标签

- 生成 `content_tags`，默认 3～5 个
- 优先提取商品关键词、场景词、品类词
- 标签需与正文和图片内容一致，不得捏造夸张营销标签
- 写入 `save` 入参时去掉 `#`

## 文案美学

- 前 3 行必须建立场景、冲突、好奇或情绪认同
- 段落短，留白多，方便手机阅读
- 适度使用 emoji，但不能堆砌
- 好内容要让读者觉得“这篇像是为我写的”
- 正文字数必须控制在 800 字以内

## 写作禁区

- 禁止出现虚构价格、虚构满减、虚构销量、虚构库存
- 禁止出现与商品真实品类无关的功效和卖点
- 禁止明显公众号长文腔、新闻稿腔、品牌自夸腔
- 禁止每段都写成相同句式

## 图片质感

- 体现小红书商品图质感：清晰主体、生活场景、自然光、易理解
- 默认不要在图片中生成任何中文文案、标题字、装饰字或海报字
- 图片信息通过 `Step 4` 的标题和正文表达，不依赖图片内嵌文字

## save 入参差异

- **必传**：`title`、`content.title`、`content_tags`
- 内容标题与顶层 `title` 保持一致
- `content.image_url_list` 按商品顺序存放每张图
- `content.content_info` 放最终发布正文
