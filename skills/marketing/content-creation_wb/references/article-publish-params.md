# 发布文章固定参数说明

本文件记录创建公众号文章时的固定配置参数，不需要每次向用户询问，直接使用以下默认值。

## 固定参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `showCoverPic` | `1` | 显示封面图 |
| `needOpenComment` | `0` | 不开启评论 |
| `onlyFansCanComment` | `0` | 不限制仅粉丝评论 |
| `authorName` | 取公众号名称（channelName） | 作者名称，直接使用 Step 2 checkChannelBind 返回的 `channelName` |

## 内容创作规范

| 风格关键词 | 对应写作特征 |
|------------|-------------|
| 小红书种草 | 语气活泼，多用 emoji，突出使用感受，结尾引导分享 |
| 品牌正式风 | 措辞专业，强调品质与工艺，适合高客单价商品 |
| 朋友圈轻松风 | 口语化，短句，贴近生活场景，亲切感强 |
| 电商促销风 | 突出价格优惠和限时特卖，多用感叹号，紧迫感强 |
| 故事叙事风 | 以场景故事带入商品，情感共鸣，适合生活方式类商品 |

> 如用户提供的风格不在上表中，按照用户描述自由发挥，保持内容质量即可。
