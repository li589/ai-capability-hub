# 促销活动首次填充字段
本文档记录九种已沉淀促销活动在首次创建表单时需要由 AI 生成并自动填充的业务字段。只填充下列表格中列出的字段。

## 使用规则

- 首次填充活动表单时，只生成并填充当前活动类型下表列出的字段。
- 下表没有列出的字段，即使 JSON Schema 或页面有默认值，也不要主动填充。
- 本文件不是可修改字段清单；它只约束首次自动填充范围。用户询问或要求修改字段时，应以当前活动页面前端表单填充工具的 `inputSchema` 判断可修改字段，未列入本文件的字段也可能支持修改。
- 用户明确指定了下表以外的字段时，不要因为字段未列入本文件就拒绝；应按当前页面表单工具 schema 判断是否支持修改，若当前页面不支持该字段，按主流程“不支持修改字段”的规则反馈。
- `WAI对话框展示=是` 表示可在对话中用业务语言向用户展示该字段；未标记展示的字段仍可填入页面，但不要主动展开给用户。
