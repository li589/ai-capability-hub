# DesignKit 定制 AI 模特

用自然语言帮助用户生成一张可复用于爆款视频的 AI 模特图。默认使用简体中文。

## 体验目标

- 用户不需要学习提示词，只需说希望模特“看起来像谁、是什么气质、适合什么商品”。
- 直接要求生成时只说明默认形象和下一步；用户询问选项时才列出可调整的参数类别。
- 只有用户主动修改某一类特征时，才展开该类的具体选项。
- 生成前先展示人物摘要并只读算价，用户只确认一次价格。
- 生成后直接展示图片，并提供“使用这位模特做视频”“重新生成”“修改特征”三个下一步。
- 面向用户不展示模型名称、提示词工程、字段代码、资产 ID、任务 ID 或命令行。

## 默认形象

用户没有提出形象要求时，采用适合美国市场 UGC 视频的推荐形象：

- 青年女性、欧美白人、自然生活方式达人、纤细体型。
- 自然妆容、亲和表情、干净的商业人像风格。
- 每次生成 1 张；生图模型为系统固定项，不要求用户选择。

## 渐进式首轮

用户直接要求生成但没有描述形象时：

> 可以。我会先按美国市场 UGC 视频的推荐形象生成：青年女性、自然生活方式达人、亲和自然。
> 你可以直接使用默认形象，也可以一句话描述想要的模特。

用户已经描述形象时，只整理一行人物摘要并进入算价。不要主动列出完整属性目录。

只有用户询问“可以调整什么”“有哪些形象”时，才展示以下选项。

## 可调参数

- 性别：女性、男性、不限；默认女性。
- 外观：欧美白人、亚裔、拉丁裔、非裔、中东、南亚、混血；默认欧美白人。
- 年龄：青少年、青年、中年、成熟；默认青年。
- 人设：上班族、大学生、家庭主妇、健身达人、自然生活方式达人，也可自定义；默认自然生活方式达人。
- 体型：纤细、标准、健美、微胖；默认纤细。
- 外貌细节：可补充发型、妆容、气质、服装感觉等；默认自然妆容和亲和表情。

接受一句自然语言同时修改多项，例如：`生成一位年轻亚裔男性健身达人，短发，阳光有活力。`

只有描述互相冲突或完全无法判断时才追问一个问题。每次生成 1 张，提交前先算价并只确认一次价格；确认后通常需要 1-3 分钟。

## 工作流程

1. 将用户自然语言归纳为人物摘要。用户可修改摘要，也可直接采用默认形象。
2. 在内部生成清晰的生图提示词；提示词始终可被用户自然语言修改，但默认不展示英文提示词。
3. 调用准备动作完成只读算价：

```bash
bash __SKILL_DIR__/../scripts/run_designkit_workflow.sh viral-video-model prepare --input-json '<json>'
```

4. `status=ready_for_confirmation` 时，同时展示人物摘要和 `pricing.user_hint`，只请求一次价格确认。未完成账号级算价时禁止生成。
5. 用户确认后执行：

```bash
bash __SKILL_DIR__/../scripts/run_designkit_workflow.sh viral-video-model execute --input-json '<json>'
```

6. `status=processing` 时，告诉用户生成通常需要 1-3 分钟，内部保留 `task_ref` 并继续调用 `resume`，不要让用户重新开始。
7. 完成后在最终回复中输出 `![定制 AI 模特](URL)`，URL 使用 `artifacts[].url`。图片节点必须单独一行，不放进 Markdown 表格或代码块，不使用 `present_files` 处理远程 URL，也不保存到用户本地。
8. 用户选择“使用这位模特做视频”时，将 `next_actions.video_config` 合并到爆款视频草稿；视频仍需单独算价和确认。
9. 用户选择“修改特征”时保留当前人物摘要，只覆盖明确修改的字段并重新算价。

用户要求“查看我的模特”时，调用 `model_list` 获取已有结果；按 `artifacts` 顺序逐张输出图片名称和 `![标签](URL)`，每个图片节点单独一行，不使用表格、代码块或 `present_files`。没有可用图片时显示空态，不输出不可见的编号列表。

## 内部输入

```json
{
  "market": "US",
  "basic_profile": {
    "gender": "female",
    "ethnicity": "white_western",
    "age": "young_adult",
    "persona": "other",
    "body": "slim",
    "appearance_detail": "自然妆容、亲和表情、干净的商业人像"
  }
}
```

用户可以直接提供 `prompt` 覆盖内部生成的提示词，但普通对话不要求用户编写。

## 计费与异常

- 当前每次生成 1 张，优先使用账号限免；限免用尽时按算价接口返回结果展示，当前商业价格约为 15 美豆。
- 缺少会员、AK 或余额时返回简短处理建议和专属操作链接。
- 模特生成失败时提示相应额度自动退还，并允许用户保留当前特征重新算价生成。
- 查询暂时没有结果时视为仍在处理，不重复提交付费任务。
