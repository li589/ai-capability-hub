# 错误码与处理建议

接口：`POST https://sxsai.cn/skill/taobao-fetcher/api/resource`

## 状态码一览

| 状态码 | code | 含义 | 处理建议 |
|--------|------|------|----------|
| 200 | `SUCCESS` | 成功返回商品素材 | 从 `content` 取数据 |
| 400 | `INVALID_PARAM` | 参数错误 | 检查是否传入了有效的淘宝/天猫/1688 商品链接 |
| 402 | `PAYMENT_REQUIRED` | 首次请求，需要支付 | 按 X402 流程完成支付后携带 `out_trade_no` 重试 |
| 402 | `PAYMENT_NOT_COMPLETE` | 已带 `out_trade_no`，但尚未查到支付成功 | 等待 1-2 秒后用同一订单号重试，最多 3 次 |
| 404 | `ORDER_NOT_FOUND` | `out_trade_no` 对应订单不存在 | 订单号有误，从第一步重新发起 |
| 409 | `ORDER_REFUNDED` | 该订单此前履约失败已自动退款（终态） | 不要再重试此订单号，重新从第一步下单 |
| 410 | `ORDER_EXPIRED` | 支付授权超过 5 分钟未完成 | 从第一步重新发起，获取新的支付授权 |
| 502 | `UPSTREAM_ERROR` | 已确认支付，但采集商品失败 | **已自动退款**（见响应 `refunded` 字段），建议更换商品链接后重新下单 |

## 常见情况说明

### 402 `PAYMENT_NOT_COMPLETE` 连续出现

微信支付状态同步偶有延迟。用**同一个** `out_trade_no` 重试即可，不要重新下单——重新下单会产生新订单，可能导致用户重复付款。

### 502 `UPSTREAM_ERROR`

通常是商品已下架、链接受限或平台风控。响应中：

```json
{"code": "UPSTREAM_ERROR", "refunded": true, "message": "..."}
```

`refunded: true` 表示本次款项已原路退回，用户不会被扣费。应告知用户"该商品暂时无法采集，费用已退回"，并建议更换链接。

若 `refunded: false`，说明自动退款也失败了，需要提示用户联系客服处理。

### 409 `ORDER_REFUNDED`

这是**终态**，该订单号永久失效。继续用它重试没有意义，必须从第一步重新发起新请求。

## 需要用户配合的情况

| 现象 | 应向用户说明 |
|------|-------------|
| Agent 未安装 weixinpay 插件 | 请先安装 weixinpay 插件后再使用本技能 |
| 用户未在微信中确认支付 | 请在微信中完成支付确认 |
| 超过 5 分钟未支付（410） | 支付超时了，正在为你重新发起 |

> 本技能不需要用户提供任何 API 密钥或账号信息，用户只需完成微信支付确认。
