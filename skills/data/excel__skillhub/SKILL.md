# Excel

> Excel 表格处理与数据分析助手

## 一、这个技能解决什么（企业场景）

表格靠手填、公式不会写、数据对不齐、图表丑且慢；重复报表天天做，易错易漏。

## 二、什么时候用 / 什么时候不要用

### 适用
- 数据清洗与整理
- 公式与函数编写
- 图表可视化
- 数据透视表
- 报表自动化模板

### 不适用（请转专业渠道）
- 涉及官方大纲、最新政策或实时数据的，请以官方发布为准；
- 重要对外交付物请人工复核确认。

## 三、能力地图

| 模块 | 做什么 | 产出 |
|---|---|---|
| 结构规范 | 表头/类型/唯一键 | 表模板 |
| 公式编写 | 常用函数与嵌套 | 公式库 |
| 图表 | 选图与美化 | 图表 |
| 透视 | 多维汇总 | 透视表 |
| 自动化 | 模板+填充 | 报表 |
