# 数据备份方案

Use when 用户需要制定数据备份策略，了解3-2-1备份原则和云/本地/异地备份方案。

## 描述

本 Skill 提供个人和家庭数据备份的方案设计指导，涵盖3-2-1备份原则的实践、云端/本地/异地三种备份方式的选择和配置、自动备份的设置方法、备份验证和恢复测试，帮助用户建立可靠的数据保护体系防止数据丢失。

## 重要限制

- 备份方案需要根据数据重要性和预算灵活调整
- 不验证的备份等于没有备份
- 云服务依赖网络和服务商稳定性
- 不涉及企业级备份和灾难恢复系统
- 加密备份需妥善保管密钥/密码

## 能力

- 设计符合3-2-1原则的备份方案
- 推荐适合不同需求的备份工具和服务
- 指导自动备份的配置方法
- 制定备份验证和恢复测试计划
- 评估不同备份方案的可靠性和成本
- 指导加密备份保护隐私数据

## 执行步骤

1. **数据盘点**：梳理需备份的数据类型和大小
2. **策略设计**：基于3-2-1原则制定备份策略
3. **工具选择**：选择备份工具/服务/存储介质
4. **自动配置**：设置自动定期备份
5. **加密保护**：对敏感数据进行加密备份
6. **定期验证**：测试备份是否可成功恢复

## 输出原则

- 未经验证的备份等于没有备份
- 自动化是持续执行的关键
- 至少一份备份需在异地
- 方案要可执行——太复杂会放弃
- 根据数据重要性分级投入

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| 用户预算极低 | 利用免费云服务+手动USB备份 |
| 数据量极大（TB级） | 本地NAS为主+关键数据上云 |
| 用户技术水平低 | 推荐最简单的一键备份方案 |
| 备份已经丢失 | 指导数据恢复可能性评估 |

## FAQ

**Q: 3-2-1原则具体怎么做？**
A: 举例：照片原件在手机（1份）→自动同步到云端如iCloud/Google Photos（2份）→每月导出到移动硬盘（3份）。这样手机丢了有云端，云服务挂了有硬盘，家里发灾有云端异地保护。

**Q: 用什么云服务备份好？**
A: 手机照片：iCloud/Google Photos/百度网盘；文档：OneDrive/坚果云/Dropbox；全设备：Backblaze/iDrive。选择要点：可靠性>价格>空间。重要数据建议用两个不同的云服务。

**Q: 移动硬盘能用多久？**
A: 机械硬盘一般3-5年（不常用可更久但也有突然损坏风险）。SSD理论寿命更长但长期不通电可能丢失数据。建议：每2-3年更换备份硬盘，或多硬盘轮换使用。

**Q: 备份需要加密吗？**
A: 包含敏感数据（证件/财务/私密照片）的备份强烈建议加密。移动硬盘可用BitLocker/VeraCrypt加密；云备份选择提供端到端加密的服务；NAS开启加密文件夹。注意：密码丢了等于数据丢了。

## 最佳实践

- 备份设为自动化不依赖人工记忆
- 云+本地+异地三管齐下
- 定期测试恢复确认备份有效
- 敏感数据加密后再备份
- 多个备份不要放在同一物理位置
- 重要变更后手动触发一次备份
- 备份密码/密钥单独安全存储

## 不适用场景与常见误用

### 不适用场景
- 企业级备份和灾难恢复方案
- 数据中心存储架构设计
- 备份软件产品开发
- 数据合规和法律保存要求

### 常见误用
- 只在一个地方备份（硬盘坏了/云服务关了就全没了）
- 设了自动备份但从不检查是否在运行
- 备份文件从不测试能否恢复
- 加密备份后丢失了密码/密钥

## 安全与隐私

- 备份中可能包含敏感数据需要加密保护
- 选择信誉良好的云服务商
- 备份密码/密钥需要安全存储（不能只在被备份的设备上）
- 不推荐将敏感数据备份到不可信的第三方
- 处理旧备份介质时注意数据安全擦除
