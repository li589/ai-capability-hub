## v5.0.2 — 2026-08-16

**类型：PATCH（首轮全景图不自动渲染修复）**

### 问题描述

新会话首次调用律师助手时，右侧交互式能力导航目录（全景图）不自动挂载，需用户追问后才渲染。

### 根因分析

SKILL.md 作为唯一被自动加载到上下文的顶层入口文件，仅在"全景图"章节以子文件链接方式引用渲染指令（`agents/00-律师助手全景图.md`），实际执行编排埋在 `agents/31-总控路由.md` 的"三段式引导入口·开场动作"小节。AI 首轮加载 SKILL.md 后不会主动展开子文件链接，导致渲染指令被跳过。

### 修复内容

在 SKILL.md 主体新增「⚠️ 首轮必做动作清单（不可跳过）」，将完整执行链路直接写入顶层入口文件：

1. 运行 `python scripts/present_panorama.py` 发布全景图到工作区根目录；
2. 使用 `present_files` 渲染发布件（附 403 权限踩坑提醒）；
3. 输出固定开场白 + 高亮提示；
4. 输出示例区 + 案件提醒引导。

修复后，AI 加载 SKILL.md 后即可直接执行首轮渲染动作，不再依赖子文件展开。

- `SKILL.md`（新增首轮必做动作清单段落 + 版本号 5.0.1 → 5.0.2）
