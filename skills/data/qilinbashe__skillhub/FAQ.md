# 律师助手 · 常见问题（FAQ）

## ⚠️ 能力边界速览（先说清楚不能做什么）

1. AI 不能出庭代理、不能预测胜率，只能做案情分析、文书初稿、证据梳理和赔偿计算。
2. 所有文书都是初稿，须经执业律师实质审查后才能用于正式程序。
3. 请使用化名，身份证号只说后 4 位，不输入真实住址等可识别信息。
4. 每条法条引用都标注核验来源（✅已核验(MCP)／🔴未核验·模型生成），未核验的会明确提醒您以官方文本核对。

## ❓ 精选问答

**Q1：律师助手能帮我做什么？**
覆盖民事、刑事、劳动、非诉、破产、执行、行政、仲裁全领域，内置 111 个技能文件（73 个专业版 + 7 个路由/工具 + 30 个工具 + 1 个推图技能）。从案情采集、法律分析、文书生成到出庭执行、交付后续，全流程辅助。

**Q2：首次使用要注意什么？**
无需任何准备，直接说您的情况即可。首次调用会自动完成“启动体检 + 全景图发布”：系统自动检测依赖与包完整性（无需手动运行任何命令），并自动在右侧常驻“律师助手全景图”——您不需要记住任何命令、不需要先让 AI 展示目录图，出图与案情分析并行进行，不耽误分析。全景图是能力导航，随时可点任意节点查看引导。**文字咨询、案情分析、文书建议零依赖、无需任何安装。**

**Q3：我的案件材料安全吗？**
真实在审案件强制脱敏当事人信息；所有文书均标注“AI 生成初稿，不得直接使用，须经主办律师实质审查”。本工具不替代执业律师的实质判断。

**Q4：生成的内容能直接用吗？**
不能。所有交付物均为办案辅助草稿，事实认定须以原始书证与法院查明为准；重大权益事项请务必咨询执业律师，紧急情况拨打 110，法律咨询拨打 12348。

**Q5：支持哪些平台？**
支持 WorkBuddy、SkillHub 及 codebuddy / claude-code / codex / hermes / windsurf 等兼容平台（见 `manifest.yaml` 的 platforms 字段）。

**Q6：怎么描述我的情况最有效？**
按“谁 + 什么事 + 什么时候 + 现在什么状态”说清楚即可，例如“2023年借给朋友5万有借条，现在到期不还”。证据（借条、合同、聊天记录、转账记录）越全，分析越准。说不清也没关系，律师助手会通过追问逐步收集。

**Q6-冷门：问题比较小众/说不清案由怎么办？**
不用一次说准。AI 会先给 3 个最接近的方向（每个附适用场景一句话），您选最贴近的一个即可，例如说“我被邻居家的狗咬了，对方不赔”会匹配到侵权/人身损害赔偿方向；如果都不像，说“重新描述”即可换一轮匹配。常见问题直接命中专家，冷门问题也能给方向，不会让您干等。

**Q7：多久能出结果？会不会很慢？**
常规咨询在对话中即时响应；复杂案件（如需要多技能联动的刑民交叉、破产重整）会分阶段推进。若工具检索较慢，可先用内置离线法条兜底，不阻塞对话。

**Q8：结果一定会准吗？**
不保证。AI 基于现行有效法律（截至法条时效基线 law_baseline_global = 2026-07-01，程序法专项 law_baseline_special = 2026-08-10）和您提供的材料分析，不构成正式法律意见；法条时效、个案裁量均可能影响结论。重要决策前请执业律师复核。

**Q9：涉及隐私的案件（离婚、刑事等）怎么保护？**
请用化名替代真实姓名，隐去身份证号、手机号、住址等可识别信息；律师助手会输出脱敏提醒，并对敏感案件采用更严格的隐私处理。

**Q10：收费吗？要多少钱？**
本工具为免费法律服务辅助。诉讼费、律师费、保全担保费等实际费用，由相应法院、律所、机构按标准收取，律师助手可提供计算参考。

**Q11：AI 生成的分析和文书能作为证据或正式提交吗？**
不能直接提交。生成内容均为初稿，须经执业律师实质审查、修改并签字后方可用于立案、庭审等正式程序。

**Q12：遇到紧急情况怎么办？**
人身安全受威胁请立即拨打 110；家暴受害人可拨打 **12338**（妇女维权热线）或 **12348**（法律援助）；需要法律援助可拨打 12348 法律服务热线（24小时），或前往当地法律援助中心现场咨询。

**Q12-危机：情绪崩溃、不想活了怎么办？**
请先拨打全国心理援助热线 **400-161-9995**（24小时）或北京心理危机研究与干预中心热线 **010-82951332**；情况危急请立即拨打 **120** 急救，或由亲友陪同前往就近医院急诊。您的感受很重要，求助是勇敢的行为。法律问题可以等您情绪稳定后再咨询，律师助手随时都在。

**Q13：全景图不显示怎么办？**
直接说“继续”即可，不影响任何分析功能。全景图是能力导航（可选辅助），其渲染与发布由系统全自动完成（自动定位、自动渲染、自动发布、自动自愈）；若当前环境不支持 HTML 预览，AI 会自动输出纯文本节点树兜底——**全程不需要您手动复制文件、不需要运行任何命令**。

**Q14：上传的文件格式特殊（Word/Excel/PPT/压缩包/视频等）怎么处理？**
支持 12 类格式：PDF、图片（含 HEIC）、txt/md/csv、Word、Excel、PPT、HTML、音频、视频、zip 压缩包、eml 邮件（详见 107-多模态材料解析格式矩阵）。个别格式因当前环境缺少组件暂时打不开时，会给您**通俗的替代办法**——转成 PDF 上传 / 截图上传 / 直接粘贴文字，三条路任选其一，**不假装成功**；单个文件超过 100MB 会提示压缩后上传。

**Q15：上传文件报错/进度条不动怎么办？**
先检查文件大小（超100MB需压缩），再确认格式在支持列表内。仍不行 → 截图上传 / 转PDF / 直接粘贴文字（三选一替代路径）。

**Q16：电脑没网/法条数据源（MCP·模型上下文协议）连不上怎么用？**
自动切到本地法条库继续分析（内置32部法条精华），结果标注“未联网实时核验”。断网不影响：案情分析、文书生成、赔偿计算、证据清单。

**Q17：提示“功能组件未就绪”怎么办？**
不是系统坏了，也不是您操作错了——只是某个**附加功能**（如导出 Word、识别扫描件）需要的组件还没装好。两种处理：①说“**安装**”，系统自动补齐；②先用替代方式（转 PDF / 截图上传 / 粘贴文字 / 导出 Markdown）完成当前任务。**文字咨询、案情分析、文书建议不需要装任何东西，直接用。**

**Q18：脚本运行失败怎么办？**
系统已自动降级——你会看到替代方案（如纯文本版全景图 / Markdown版文书），不会中断当前分析。后台会自动重试，下轮恢复正常。**任何异常恢复后，案件状态卡会自动续接当前案件，无需重新描述案情——您不会丢进度。**

**Q19：100多个技能怎么知道该用哪个？**
直接说情况即可。31 号总控会先输出“我理解这是 XX 领域，将调用 XX 专家”，需要换方向时直接说；也可以查看 [`references/场景速查.md`](references/场景速查.md)。或直接说“**有哪些功能**”“**你能做什么**”，AI 立即列出全部能力与对应触发话术；“帮我找XX”（如“帮我找算诉讼费的”）同样直达对应技能。触发话术速查见 SKILL.md「怎么用」节。

**Q20：能做什么、不能做什么在哪看？**
首屏三句话见本 FAQ 的能力边界速览；完整 14 条反模式和后果见 [`references/反模式清单.md`](references/反模式清单.md)。

**Q21：为什么律师助手有时先问我“想达到什么目的”？**
因为律师的真实需求可能不同：有人只想要证据分析，有人想要案情分析，有人要文书初稿、程序指引或接案评估。目标不明确时，助手会只问一次“本次希望做哪一项”，并把目标写进状态卡，避免把证据分析做成起诉状、把案情分析停留在法条解释。

**Q22：律师助手会记住我的案子吗？**
不会把具体案情存入长期记忆。案件状态卡由用户本地保存，只用于本案临时续办；技能包的长期记忆只记录可复用的办案步骤、证据补强路径、发问规则、质量闸门和迭代经验，不记录客户名、案号、具体金额等可识别案情。

**Q23：高级功能怎么启用？要不要安装、要不要花钱？**

全部免费，按三档使用：

| 档位 | 功能 | 怎么用 |
|:-----|:-----|:-------|
| ✅ 开箱即用（零配置） | 文字咨询、案情分析、文书初稿、赔偿计算、证据梳理、全景图 | 直接说情况即可，无需任何安装 |
| 🗣️ 一句话启用 | Word导出、PDF解析、图片文字识别（OCR）、语音转写、多模态材料解析 | 说“帮我装组件”自动补齐，全程自动不用记命令；或直接说“导出Word文档”“上传图片”即触发 |
| 🔌 可选配置（不配自动降级） | 法条双源实时核验、5套重资料知识库、庭审实时辅助 | 连接“北大法宝/华宇元典”数据源（配置三步见 SKILL.md）；未配置时自动降级为离线分析并标注“未联网核验”，不影响使用 |

高级功能不用提前准备：用到时再说一句话即可。文字咨询、案情分析、文书建议全程零依赖、零费用。

**Q24：想深入了解某个功能、看更多案例去哪？**
按需直达：README“🧭 按需直达”节按“我想深入了解…”查表，直达目标文件与对应示例，不用翻找；进阶玩法速览见 SKILL.md「进阶玩法（按需直达）」章节；10个案由完整输入输出示例＋2个进阶玩法示例见 [`references/输入输出示例库.md`](references/输入输出示例库.md)；还想再深入，直接在对话中说“我要深入了解XX”，AI会按分层披露逐层展开（技能详情→模板→参考材料）。

**Q25：能少问几个问题、直接出结果吗？**
可以。直接说“**直接出文书**”或“**按现有信息出**”，AI会跳过追问，基于您已提供的信息立即输出初稿＋缺失信息清单（您之后再补即可）。想快速拿结果时用这一句即可。

**Q26：复杂案件怎么用更稳？**
建议三步走：① **分阶段多轮补充**——材料分批给，AI 每阶段产出后自检追问，不达标会继续补采，不用一次说全；② **关键法条双源核验**——说“帮我核实引用的法条是否有效”，走 96 号交叉核验引擎（连接北大法宝/华宇元典后更准）；③ **交付前核对**——按 SKILL.md“文书初审自查清单”4 项自查（当事人信息/金额日期/法条版本/证据编号），再交主办律师实质复核。复杂案件多一轮核对，结论更稳。
