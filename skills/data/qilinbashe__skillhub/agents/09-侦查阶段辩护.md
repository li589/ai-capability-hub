### 第三步：证据审查（侦查阶段）



**审查框架：**



```

┌─ ① 控方证据审查（侦查阶段）

│   ├─ 言词证据：口供/证人证言/被害人陈述

│   │   ├─ 证据能力：有无刑讯逼供/诱供？同步录音录像是否完整？

│   │   ├─ 证明力：口供是否前后一致？是否与在案证据印证？

│   │   └─ 非法证据排除：刑诉法第56条——刑讯逼供所得口供必须排除

│   │

│   ├─ 实物证据：物证/书证/鉴定意见/勘验笔录

│   │   ├─ 证据能力：提取程序是否合法？保管链条是否完整？

│   │   └─ 证明力：能否直接证明指控事实？

│   │

│   └─ 电子数据：微信记录/邮件/监控视频

│       ├─ 证据能力：提取过程是否合法？有无见证人？

│       └─ 证明力：内容真实性+完整性

│

├─ ② 辩方证据审查

│   ├─ 无罪证据：不在场证明/无作案时间/系他人所为

│   ├─ 罪轻证据：自首/立功/退赃/谅解/被害人过错

│   └─ 程序违法证据：超期羁押/违法取证/违规讯问

│

└─ ③ 逮捕必要性审查（侦查阶段重点）

    ├─ 是否有逮捕必要（刑诉法第81条）

    ├─ 取保候审是否足以防止社会危险性（刑诉法第67条）

    └─ 是否属于“径行逮捕”情形

│

└─ ④ 证明标准审查（刑诉法第55条）

    ├─ 定罪量刑的事实是否都有证据证明？

    ├─ 据以定案的证据是否均经法定程序查证属实？

    ├─ 综合全案证据，对所认定事实是否已排除合理怀疑？

    └─ 任一答案为“否” → 建议不批准逮捕/变更强制措施

```



**举证责任：控方举证，辩方不承担自证无罪义务（刑诉法第51条）。**

**阶段重点审查：** 逮捕必要性+非法证据+同步录音录像。

### ⏰ 时效提醒



在分析过程中自动检查以下时效事项：



**办案期限检查：**

- 拘留期限：3日→可延长至7日→流窜、结伙、多次作案可延至30日（刑诉法第91条）

- 提请批捕后：人民检察院7日内作出批准/不批准决定（刑诉法第91条）

- 侦查羁押期限：2+1+2+2个月（刑诉法第156-159条）

- 审查起诉期限：1个月，可延长15日（刑诉法第172条）



**证据固定提醒：**

- 电子证据（聊天记录/邮件/转账记录）——建议尽快截图或录屏保存

- 纸质文件（合同/借条/收据）——建议扫描备份，防止丢失

- 证人证言——建议尽早固定



**涉案财物处理提示：**

- 如发现查封、扣押、冻结不当，可依法申请变更或解除

- 与案件无关的财物应依法及时返还（刑诉法第145条）
