# 办案复盘与方法论沉淀（114）

> 铁律：只记方法，不记案情。

## 允许沉淀

- 案由类型（脱敏颗粒度）
- 走过的步骤序列
- 哪一问有效 / 哪一问白问
- 路由决策与理由
- 踩过的坑
- 律师的纠偏反馈

## 禁止沉淀

当事人姓名、身份证、住址、电话、金额明细、具体案号、纠纷细节、上传材料原文、商业秘密。

## 操作

```bash
python scripts/update_memory.py --check
python scripts/playbook_distill.py --check
python scripts/playbook_distill.py --entry "可复用方法：..."
```

## 复盘卡

- 本轮走完哪些闸门
- 每个闸门深挖到什么程度
- 哪个环节出现缺口
- 下次同类案件怎么更快更稳
- 是否升级为 SKILL.md 或 31 的强制规则

## 闸门

复盘卡必须通过 PII 校验；含具体案情标识的条目拒绝写入。

### 🛡️ 运行稳定性保障

**用户话术优先（遇异常先安抚，不念内部术语）：** 任何异常（断网、工具失败、文件打不开、服务超时）发生时，先查 `references/异常出口矩阵.md` 对应行，按“人话解释＋解决步骤＋替代方案”三件套给用户输出。例如“后台出了点小状况，我自动处理，您稍等”，或“这个文件暂时打不开，您可以转成PDF、截图或直接粘贴文字，三条路任选”。重试次数、降级模式、MCP、纯文本分析等内部机制仅在内部执行，绝不向用户转述。

**内部机制（AI自行执行，不向用户转述）：** ①工具调用/外部查询失败时自动重试最多3次（间隔递增）；②重试仍失败自动降级为纯文本分析模式；③降级后仍无法完成时，告知用户“当前服务不稳定，请稍后重试或拨打12348法律援助热线”。
