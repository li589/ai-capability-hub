# 重罪案件辩护技能（含死刑复核）



> 📌 本技能专为重罪案件设计，覆盖一审、二审死刑判决到死刑复核程序。

### 第三步：证据审查与死刑适用标准审查



**审查框架：**



```

┌─ ① 证据审查（死刑案件最高证明标准）

│   ├─ 定罪证据审查

│   │   ├─ 是否达到"排除合理怀疑"（死刑案件应当适用最高证明标准）

│   │   ├─ 是否存在证据链断裂/合理怀疑

│   │   ├─ 口供是否系唯一证据（只有口供不能定死罪）

│   │   └─ 是否有刑讯逼供/非法取证情形

│   │

│   └─ 量刑证据审查

│       ├─ 从重情节证据：是否确有证据证明"罪行极其严重"

│       ├─ 从轻情节证据：自首/立功/被害人过错/积极赔偿/谅解

│       └─ 酌定情节：犯罪动机/社会危害性/人身危险性

│

├─ ② 死刑适用标准审查（死刑案件核心）

│   ├─ 是否属于"罪行极其严重"（刑法第48条）

│   │   ├─ 犯罪性质：是否属于最严重的犯罪类型

│   │   ├─ 犯罪情节：手段是否特别残忍/后果是否特别严重

│   │   └─ 主观恶性：是否预谋犯罪/有无悔罪表现

│   │

│   ├─ 是否属于"必须立即执行"

│   │   ├─ 死缓制度的适用条件

│   │   ├─ 限制减刑的适用情形

│   │   └─ 有无从轻/减轻情节

│   │

│   └─ 不予核准的3种情形（最高法刑诉法解释）

│       ├─ 事实不清/证据不足→发回重审

│       ├─ 法律适用错误→改判

│       └─ 量刑不当→改判/发回重审

│

└─ ③ 程序合法性审查（死刑复核阶段重点）

    ├─ 一审/二审程序是否合法

    ├─ 死刑复核阶段辩护权是否保障（应当通知辩护律师）

    ├─ 是否已讯问被告人（死刑复核应当讯问）

    └─ 同案犯的量刑是否均衡

```

### 第四步：法律分析



**分析框架：**



```

┌─ ① 定罪层面分析

│   ├─ 事实认定是否清楚、证据是否确实充分

│   ├─ 是否达到死刑案件的最高证明标准

│   ├─ 是否存在合理怀疑

│   └─ 如事实不清→申请不予核准+发回重审

│

├─ ② 量刑层面分析（死刑案件核心）

│   ├─ 是否属于"罪行极其严重"（死刑适用前提）

│   ├─ 从轻/减轻情节的充分认定

│   ├─ 是否属于"可杀可不杀"→应当不杀

│   ├─ 是否适用死缓/限制减刑

│   └─ 同案犯的量刑是否均衡

│

├─ ③ 死刑复核辩护策略

│   ├─ 路径一：事实不清→发回重审

│   ├─ 路径二：法律适用错误→改判（死缓/无期）

│   ├─ 路径三：量刑不当→改判（死缓/限制减刑）

│   └─ 路径四：程序违法→发回重审

│

└─ ④ 风险提示

    ├─ 死刑复核期间的时间预期（无固定期限）

    ├─ 死刑复核后的可能结果（核准/不核准/发回）

    └─ 死刑执行前家属最后的会见权利

```

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如“借条：有/没有/丢了？”）
- 第3次追问：转场景选单（“您的情况更接近：A借钱不还 B被撞了 C被辞退”），提示可说“转接”换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：“您提供的信息还差关键一点，我先问一个最重要的问题：……”
- 信息矛盾：“您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？”
- 超出范围：“这个情况超出了本技能领域，说“转接”可转到更合适的专家，或拨打12348。”
