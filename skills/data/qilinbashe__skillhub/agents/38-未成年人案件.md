```

│   ├─ 讯问/询问时是否有法定代理人在场？

│   ├─ 如无法通知法定代理人，是否安排合适成年人？

│   ├─ 合适成年人是否具备资格？

│   └─ 未通知合适成年人到场所获证据的效力

│

├─ ③ 社会调查审查

│   ├─ 是否已开展社会调查？

│   ├─ 社会调查报告的内容：性格特点/家庭情况/社会交往/成长经历/监护条件

│   ├─ 社会调查报告对强制措施+处理决定的影响

│

├─ ④ 强制措施审查

│   ├─ 是否已优先适用取保候审/监视居住？

│   └─ 与成年人分案处理
```

### 第四步：法律分析



**分析框架：**



```

┌─ ① 刑事责任年龄分析

│   ├─ 未满14周岁→不负刑事责任→撤案/不起诉

│   ├─ 14-16周岁→仅对8类重罪负责（故意杀人/故意伤害致人重伤或死亡/强奸/抢劫/贩卖毒品/放火/爆炸/投放危险物质）

│   └─ 16-18周岁→应当负刑事责任，但应从轻或减轻处罚

│

├─ ② 附条件不起诉路径

│   ├─ 适用条件：涉嫌刑法分则第4-6章犯罪+可能判处1年以下+有悔罪表现

│   ├─ 考察期：6个月-1年

│   └─ 考察期满：表现良好→不起诉；违反条件→起诉

│

├─ ③ 量刑特殊规则（含认罪认罚从宽制度的特殊规定：刑诉法第2编第1章第12节+认罪认罚从宽指导意见）

│   ├─ 应当从轻/减轻处罚（刑诉法第280条）

│   ├─ 不构成累犯（刑法第65条）

│   ├─ 犯罪记录封存（刑诉法第286条）

│   └─ 缓刑适用条件相对宽松

│

└─ ④ 诉讼权利保障

    ├─ 不公开审理（刑诉法第285条）

    ├─ 法定代理人/合适成年人到场权

    ├─ 法律援助（应当提供法律援助）

    └─ 分案处理（与同案成年人分开）

│

├─ ⑤ 认罪认罚从宽制度的特殊适用（未成年人专属）

│   ├─ 与成年人认罪认罚的关键差异：

│   │   ├─ 签署具结书：成年人本人签署即可 → 未成年人需法定代理人/合适成年人到场并签字（刑诉法第281条）

│   │   ├─ 从宽幅度：成年人基准从宽10%-30% → 未成年人可进一步从宽，体现"教育为主、惩罚为辅"

│   │   ├─ 程序衔接：认罪认罚→速裁/简易程序 → 未成年人可衔接附条件不起诉（刑诉法第282条）

│   │   └─ 社会调查：成年人非强制 → 未成年人应当进行社会调查（刑诉法第279条）

│   └─ 辩护律师应特别注意：

│       ├─ 确认法定代理人是否同意认罪认罚，不同意时应充分解释利弊

│       ├─ 认罪认罚后积极争取附条件不起诉，考察期6个月至1年

│       └─ 社会调查报告是法院量刑的重要参考，应提前沟通社会调查机构

```
