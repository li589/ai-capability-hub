# 期限与时效计算器

> 输入案由+关键日期，输出时效核验表，风险一目了然。说"案件提醒"可批量扫描案件文件夹，自动提取开庭/查封/续封等关键期限并分档提醒。

## 一、触发方式

- 用户说“帮我算时效”“看看过期没有”“还有几天”自动激活
- 31-总控路由在案由匹配后提示用户进行时效核验
- 手动触发：说“时效计算”或“期限核验”

## 二、覆盖的时效/期限类型

| 类型 | 常见的相关案由 | 期间 |
|:-----|:--------------|:-----|
| 普通诉讼时效 | 民间借贷/合同/侵权/物权 | 3年（《民法典》第188条） |
| 劳动争议仲裁时效 | 劳动纠纷 | 1年（《劳动争议调解仲裁法》第27条） |
| 行政诉讼起诉期限 | 行政纠纷 | 6个月/15日（《行政诉讼法》） |
| 上诉期限（民事） | 一审判决 | 15日 |
| 上诉期限（刑事） | 一审判决/裁定 | 10日/5日 |
| 申请执行期限 | 执行程序 | 2年 |
| 保证期间 | 保证合同 | 6个月/约定（《民法典》第692条） |
| 离婚损害赔偿 | 婚姻纠纷 | 无过错方知道/应当知道之日起1年 |
| 工伤认定申请 | 劳动争议 | 事故伤害发生之日起1年 |
| 破产债权申报 | 破产程序 | 法院公告之日起30天-3个月 |

## 三B、刑事羁押与取保时限（2024新增）

```
侦查阶段羁押期限（刑事拘留→逮捕→侦查终结）：
- 刑事拘留：一般14日（流窜/多次/结伙作案最长37日，含检察院审查批捕7日）
- 逮捕后侦查羁押期限：一般2个月 → 案情复杂可延长1个月 → 重大复杂可再延长2个月
- 侦查终结后移送审查起诉

审查起诉阶段：
- 检察院审查起诉：一般1个月，可延长15日（速裁案件10日）
- 退回补充侦查：每次1个月，最多2次（每次退侦重新计算审查期限）

审判阶段：
- 一审：普通程序一般3个月（可延长），简易程序一般20日/1.5个月，速裁程序一般10日
- 二审：一般2个月（可延长）

取保候审：
- 最长不得超过12个月（同一阶段连续计算，跨阶段重新计算）
- 监视居住最长不得超过6个月
- 解除取保候审/监视居住的，应当及时通知被取保候审人、监视居住人

羁押必要性审查：
- 逮捕后，辩护律师可随时向检察院申请羁押必要性审查
- 检察院应当在收到申请后7日内作出是否立案审查的决定
```

## 四、特别提示

- 诉讼时效可因**催讨/起诉/部分履行/书面承认**而中断，中断后重新计算
- 除斥期间（如撤销权1年/继承权60日）**不适用中断/中止**，须严格注意
- 本计算基于通用法律规定，个案具体起算点可能因事实差异而不同
- 涉及重大权益建议结合具体案情由执业律师核定

## 五、案件提醒（批量扫描模式）

> 律师手头案子多，忘了续封/举证/开庭给当事人造成损失的案例不少见。说"案件提醒"+指定文件夹路径，自动扫描所有案件文档，列出近期要到期的事项，按急缓分四档着色。

### 交互流程

1. **问路径**：律师说"案件提醒"→问"案件文件存在哪个盘？"建议指定案件根目录（如 D:\案件\），自动递归扫描所有子文件夹
2. **温情过渡**："好的，我现在去您的案件文件夹看看……"
3. **执行扫描**：调用下方扫描脚本，递归扫描 `.docx/.pdf/.md/.txt` 文件
4. **输出清单**：按剩余天数排序，分四档着色输出（对话框文字列表 + 右侧全景图红色面板同步渲染）
5. **定时推送**（可选）：律师说"每天提醒我几次"，配置 automation 定时扫描 + 邮件推送（agent-mail 连接器）

### 扫描规则（关键词 + 日期正则双匹配）

**关键词库：**

| 类别 | 关键词 |
|:-----|:-------|
| 开庭 | 开庭、庭审、质证、开庭日期、庭审时间、休庭、宣判 |
| 查封/续封 | 查封、续封、保全、冻结、扣押、查封期限、续封申请 |
| 举证 | 举证、举证期限、证据交换、举证通知书 |
| 上诉 | 上诉、上诉期、上诉状、答辩期、答辩状 |
| 执行 | 执行、执行期限、申请执行、强制执行 |
| 时效 | 时效、诉讼时效、届满、过期、到期 |

**日期正则**（关键词附近 7 字符内出现才算一组提醒）：
- `2026-08-18` / `2026.08.18` / `2026/08/18`
- `2026年8月18日` / `8月18日`（当年补全）
- `08-18` / `08/18`（当年补全）

**分档标准：**

| 剩余天数 | 颜色 | 等级 |
|:---------|:-----|:-----|
| 0–3 天 | 🔴 红色 | 紧急 |
| 4–7 天 | 🟠 橙色 | 提醒 |
| 8–15 天 | 🟡 黄色 | 关注 |
| >15 天 | ⚪ 灰色 | 正常 |
| 已过期 | ⚫ 黑色 | 过期（红色加粗标注） |

> 本版为"80% 准确率版"——关键词+日期正则双匹配，能覆盖大多数案件文档的标准格式。律师在提醒清单里手动加减即可。

### 扫描脚本

将以下代码保存为临时 py 文件执行：`python case_alert_scanner.py "D:/案件/" --output alerts.json`

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""案件提醒扫描器 — 律师助手技能包 v5.0.1
用法：python case_alert_scanner.py "D:/案件/" [--output alerts.json]"""
import os, re, json, sys, argparse
from datetime import datetime, date

KEYWORDS = {
    "开庭": ["开庭", "庭审", "质证", "开庭日期", "庭审时间", "休庭", "宣判", "开庭通知"],
    "查封/续封": ["查封", "续封", "保全", "冻结", "扣押", "查封期限", "续封申请", "财产保全"],
    "举证": ["举证", "举证期限", "证据交换", "举证通知书", "举证责任"],
    "上诉": ["上诉", "上诉期", "上诉状", "答辩期", "答辩状"],
    "执行": ["执行", "执行期限", "申请执行", "强制执行", "执行通知书"],
    "时效": ["时效", "诉讼时效", "届满", "过期", "到期"],
}
DATE_PATTERNS = [
    re.compile(r'(20\d{2})[-./](\d{1,2})[-./](\d{1,2})'),
    re.compile(r'(20\d{2})年(\d{1,2})月(\d{1,2})日'),
    re.compile(r'(\d{1,2})月(\d{1,2})日'),
    re.compile(r'\b(\d{1,2})[-/](\d{1,2})\b'),
]

def get_level(days_left):
    if days_left < 0: return "red"
    if days_left <= 3: return "red"
    if days_left <= 7: return "amber"
    if days_left <= 15: return "yellow"
    return "normal"

def parse_date(text):
    today = date.today()
    for pat in DATE_PATTERNS:
        m = pat.search(text)
        if m:
            g = m.groups()
            try:
                if len(g) == 3 and g[0].startswith("20"):
                    y, mo, d = int(g[0]), int(g[1]), int(g[2])
                elif len(g) == 3:
                    y, mo, d = int(g[0]), int(g[1]), int(g[2])
                elif len(g) == 2:
                    y, mo, d = today.year, int(g[0]), int(g[1])
                else: continue
                return date(y, mo, d)
            except ValueError: continue
    return None

def read_txt(path):
    for enc in ["utf-8", "gbk", "gb2312", "latin-1"]:
        try:
            with open(path, "r", encoding=enc, errors="replace") as f: return f.read()
        except: continue
    return ""

def read_docx(path):
    try:
        from docx import Document
        doc = Document(path)
        return "\n".join(p.text for p in doc.paragraphs)
    except: pass
    try:
        import zipfile
        with zipfile.ZipFile(path, "r") as z:
            xml_files = [n for n in z.namelist() if n.startswith("word/document") and n.endswith(".xml")]
            if not xml_files: return ""
            xml_content = z.read(xml_files[0]).decode("utf-8", errors="replace")
            texts = re.findall(r'<w:t(?:\s[^>]*)?>([^<]*)</w:t>', xml_content)
            return "\n".join(texts)
    except: return ""

def read_pdf(path):
    try:
        import pdfplumber
        parts = []
        with pdfplumber.open(path) as pdf:
            for page in pdf.pages:
                t = page.extract_text()
                if t: parts.append(t)
        return "\n".join(parts)
    except: pass
    try:
        import PyPDF2
        parts = []
        with open(path, "rb") as f:
            reader = PyPDF2.PdfReader(f)
            for page in reader.pages:
                t = page.extract_text()
                if t: parts.append(t)
        return "\n".join(parts)
    except: pass
    return ""

def read_file(path):
    ext = os.path.splitext(path)[1].lower()
    if ext in (".txt", ".md", ".markdown"): return read_txt(path)
    elif ext == ".docx": return read_docx(path)
    elif ext == ".pdf": return read_pdf(path)
    elif ext == ".doc": return read_txt(path)
    return ""

def scan_file(path, today):
    alerts = []
    text = read_file(path)
    if not text: return alerts
    folder_name = os.path.basename(os.path.dirname(path))
    file_name = os.path.basename(path)
    for line in text.split("\n"):
        for category, words in KEYWORDS.items():
            for kw in words:
                kw_pos = line.find(kw)
                if kw_pos == -1: continue
                search_range = line[max(0, kw_pos - 7): kw_pos + len(kw) + 30]
                d = parse_date(search_range)
                if d:
                    days_left = (d - today).days
                    alert = {
                        "date": d.strftime("%Y-%m-%d"),
                        "event": f"{folder_name} · {category}（{kw}）",
                        "days": f"剩{days_left}天" if days_left >= 0 else f"已过期{abs(days_left)}天",
                        "level": get_level(days_left),
                        "days_left": days_left,
                        "source": file_name,
                        "category": category,
                        "detail": line.strip()[:100],
                    }
                    if not any(a["date"] == alert["date"] and a["category"] == category and a["source"] == file_name for a in alerts):
                        alerts.append(alert)
                    break
    return alerts

def scan_directory(root_path, today=None):
    if today is None: today = date.today()
    all_alerts, file_count, skip_count = [], 0, 0
    for dirpath, dirnames, filenames in os.walk(root_path):
        dirnames[:] = [d for d in dirnames if not d.startswith(".")]
        for fname in filenames:
            ext = os.path.splitext(fname)[1].lower()
            if ext not in (".docx", ".pdf", ".md", ".markdown", ".txt", ".doc"): continue
            fpath = os.path.join(dirpath, fname)
            try:
                all_alerts.extend(scan_file(fpath, today))
                file_count += 1
            except: skip_count += 1
    all_alerts.sort(key=lambda a: a["days_left"])
    return {"scan_date": today.strftime("%Y-%m-%d"), "root_path": root_path,
            "files_scanned": file_count, "files_skipped": skip_count,
            "total_alerts": len(all_alerts), "alerts": all_alerts}

def main():
    parser = argparse.ArgumentParser(description="案件提醒扫描器")
    parser.add_argument("path", help="案件根目录路径")
    parser.add_argument("--output", "-o", default=None, help="输出 JSON 文件路径")
    parser.add_argument("--today", default=None, help="指定今天日期（YYYY-MM-DD）")
    args = parser.parse_args()
    root = args.path.strip().strip('"').strip("'")
    if not os.path.isdir(root):
        print(f"错误：路径不存在 — {root}", file=sys.stderr); sys.exit(1)
    today = None
    if args.today:
        try: today = datetime.strptime(args.today, "%Y-%m-%d").date()
        except: today = date.today()
    else: today = date.today()
    print(f"扫描中：{root}", file=sys.stderr)
    result = scan_directory(root, today)
    print(f"完成：扫描 {result['files_scanned']} 个文件，找到 {result['total_alerts']} 条提醒", file=sys.stderr)
    output_json = json.dumps(result, ensure_ascii=False, indent=2)
    if args.output:
        with open(args.output, "w", encoding="utf-8") as f: f.write(output_json)
        print(f"结果已写入：{args.output}", file=sys.stderr)
    else: print(output_json)

if __name__ == "__main__":
    main()
```

### 异常处理

| 场景 | 处理方式 |
|:-----|:---------|
| 路径不存在 | "这个路径我没找到，请确认一下盘符或文件夹路径" |
| 文件夹为空 | "这个文件夹是空的，没有案件文档。请确认案件存在哪个盘" |
| 扫描无匹配 | "扫描完了，没找到带日期的期限信息。你可以手动告诉我几个关键日期，我帮你排提醒" |
| 脚本不可用 | 降级为"手动录入模式"——律师口述关键日期，AI 帮忙排序分档 |

### 隐私与安全

- 扫描只在律师本地电脑上执行，案件文档不上传、不外传
- 提醒清单中的案件名默认脱敏
- 邮件推送只含提醒摘要（日期+事件+剩余天数），不含案件详情

### 免责声明（案件提醒部分）

- **AI生成初稿**：扫描结果由脚本自动提取，可能存在误报漏报，提醒清单仅供参考，不得作为唯一依据。
- **须律师审查**：所有期限提醒须经主办律师核实确认后再行动，尤其续封、举证等关键期限，务必以法院通知书原件为准。
- **隐私脱敏**：扫描涉及律师本地案件文档，请确保文档不含无关第三人敏感信息；邮件推送内容已脱敏，但仍建议律师确认后再启用。

## 边界

- ✅ **本工具计算**：诉讼时效/仲裁时效/执行时效/刑事羁押期限/取保时限等法定期间
- ❌ **本工具不做**：预测案件结果、计算赔偿金额（见98号）、计算诉讼费（见77号）
- ⚠️ **注意**：期限起算点（知道或应当知道之日/履行期届满之日等）须结合具体案情确认；各地法院对时效中断证据认定有差异

## 格式依据（国家标准锚定）

本技能涉及的标准文书交付物，须严格遵循以下国家标准框架，不得使用自定义或已过时的格式：

- **文书类型**：本工具输出的期限/时效清单（附于各类申请书、起诉状）
