# 和解与调解策略

> 大量案件以调解/和解结案。输入双方信息，输出策略方案。

## 一、触发方式

- 用户说“调解方案”“谈判”“和解”自动激活
- 70-案件深度分析系统在策略阶段引导评估调解可行性
- 手动触发：说“调解策略”或“和解方案”

## 二、核心能力

### （甲）调解可行性评估

| 评估项 | 有利因素 | 不利因素 |
|:-------|:---------|:---------|
| 事实争议 | 事实清楚/证据充分 | 事实复杂/证据不足 |
| 法律适用 | 法律依据明确 | 法律有争议/无明确规定 |
| 对方意愿 | 对方有和解表示 | 对方拒不沟通 |
| 执行可能 | 对方有财产/稳定收入 | 对方无偿债能力 |
| 成本对比 | 诉讼成本高vs调解快速 | 对方要价过高 |

### （乙）谈判方案

- **最优方案（理想目标）**：我方期望的最有利条件
- **可接受方案（底线）**：我方能够接受的最低条件
- **让步空间**：分阶段让步的路径和幅度建议
- **交换条件**：可以用于交换的非核心诉求

### （乙2）让步底线量化测算（新增）

输入双方诉求与案件参数，输出谈判区间：

```
谈判区间设计：
　目标点（理想）：我方最优诉求
　保留点（底线）：我方绝对不让的金额/条件
　开局点（首次报价）：高于目标点、给对方砍价空间
　破裂点：对方低于保留点 → 终止谈判转入诉讼/执行

让步节奏（避免一次让到底）：
　第1轮让步：开局点 → 目标点（大让步，表诚意）
　第2轮让步：目标点 → 目标点与保留点中间（小让步，表为难）
　第3轮让步：接近保留点（极小步，换对方承诺）
　红线：低于保留点必须拒绝，宁可破裂

锚定参照：
　- 诉讼成本：上诉费+律师费+时间成本（6-12个月）→ 调解省下的成本可折算让步空间
　- 执行风险：对方财产状况 → 执行难则让步空间加大（拿得到比拿得多重要）
　- 类案赔付：同类案件判决/调解的常见区间 → 锚定对方预期
```

### （乙3）双赢方案设计（新增）

```
当双方诉求表面冲突、背后利益一致时，设计增值方案：
- 支付方式灵活化：分期/抵债/以物抵债（房产/车辆/股权折抵）
- 时间换空间：延期支付+担保（对方缓解资金压力，我方保债权）
- 范围交换：我方让金额、对方让时间/担保/放弃其他主张
- 结构创新：部分现金+部分期权/应收账款转让/第三方代偿
- 程序配合：撤诉+调解书确认（取得强制执行力）
示例：对方现金流紧张 → 方案B：首付30%+剩余分期12个月+房产抵押担保
　（我方拿到担保>纯判决，对方保住经营>破产）
```

**输入双方诉求+底线，自动生成完整调解方案（可提交法院/仲裁委/直接谈判）：**

```

  建议调解金额：____（占我方主张的__%）
  方案类型：□现金一次性 □分期 □以物抵债 □组合

二、方案内容
  1. 付款安排：首付____（__日内）→ 尾款____（__日内）
  2. 履行担保：□无 □保证人____ □抵押____ □质押____
  3. 其他条件：____（撤诉/解除保全/放弃其他主张/保密）

三、方案依据
  1. 我方底线测算：目标点____ / 保留点____ / 破裂点____
  2. 对方可能接受的理由：____（诉讼成本/执行风险/时间）
  3. 类案参照：同类案件调解/判决区间____

四、让步预案（对方还价时按序使用）
  第1轮：____ → 第2轮：____ → 第3轮：____（红线：____）

五、风险提示
  对方违约风险：□低 □中 □高 → 应对：____
  调解书确认建议：□是（取得执行力） □否（自行和解）
```

### （丙3）和解协议条款库（产出物②）

**和解协议生成时从条款库自动选用：**

```
【必备条款】
1. 和解金额与支付：明确总金额、支付节点、支付方式（账户信息）
2. 逾期违约责任：逾期按日万分之____支付违约金（不超30%红线）
3. 权利放弃：乙方放弃就本案（____）另行主张权利
4. 保密条款：双方对和解内容保密，不得对外披露（例外：法定义务）
5. 完整协议条款：本协议取代此前全部口头/书面约定

【可选条款】
6. 分期付款加速到期：任一逾期，全部未付款项立即到期
7. 担保条款：保证人连带责任/抵押登记（不动产须登记生效）
8. 撤诉/解除保全：甲方收到首付款后__日内申请撤诉/解除保全
9. 调解书确认：经____法院/仲裁委确认并制作调解书
10. 不履行救济：乙方不履行时甲方有权恢复原诉讼请求
11. 税费承担：____（约定明确，避免争议）

【风险提示】
- 放弃诉权条款须明确范围，避免放弃未到期权利
- 和解协议不履行时，调解书可直接申请强制执行（民诉法第247条）
- 涉及不动产抵押须办理登记（民法典第402条），未登记不产生抵押权
```

### （丁）程序出口提示（另诉/反诉路径）

调解/和解不成时，必须提示程序出口并核验其合法性：

- **反诉路径**：反诉对象必须是本诉原告；对案外人的责任追究应另案起诉，不得在本诉中提反诉。反诉应在法庭辩论结束前提出（民诉法解释第232条）。
- **另诉路径**：涉及案外人、关联合同、其他法律关系的争议，评估另案起诉的可行性（管辖、时效、案由）。
- **执行衔接**：已生效法律文书不履行的，提示申请强制执行（2年执行时效，民诉法第250条）。
- **程序障碍提示**：任一出口存在程序障碍（管辖不适、时效届满、主体不适格），必须如实标注并建议主办律师复核，不得引导当事人强行推进。

## 三、边界

- 本技能提供谈判策略框架，具体谈判由律师现场把控
- 和解协议的最终条款需双方确认后签署
- 涉及重大权益案件建议在协议中保留诉权
- 调解书经法院/仲裁委确认后具有强制执行力

## 格式依据（国家标准锚定）

本技能涉及的标准文书交付物，须严格遵循以下国家标准框架，不得使用自定义或已过时的格式：

- **文书类型**：和解协议、调解协议、和解协议书
- **国标依据**：最高法《民事诉讼文书样式》调解协议/和解协议书样式 + 《人民调解法》调解协议格式
- **强制要求**：凡输出正式文书（起诉状/答辩状/上诉状/申请书/代理词/证据清单/和解协议/裁决/判决等），一律按最高法《民事诉讼文书样式》（法〔2016〕221号 及后续修订）或对应专门样式（仲裁/行政/破产）的结构、要素、用语规范生成；当事人称谓、案由、法条引用格式均依国标。

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如“借条：有/没有/丢了？”）
- 第3次追问：转场景选单（“您的情况更接近：A借钱不还 B被撞了 C被辞退”），提示可说“转接”换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：“您提供的信息还差关键一点，我先问一个最重要的问题：……”
- 信息矛盾：“您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？”
- 超出范围：“这个情况超出了本技能领域，说“转接”可转到更合适的专家，或拨打12348。”

### ⚖️ 程序法五查（输出前强制核验）

任何涉及诉讼程序、程序路径、诉讼策略的输出，交付前必须逐项核验以下五项，并在输出末尾明示核验结论（如“五查通过：当事人适格、管辖有据、时效未过、路径合法、法条现行”）；任一核查不过，必须如实标注风险并建议主办律师复核：

① **当事人核查**：本案当事人是谁？拟起诉、应诉、反诉或追加的对象是否本案当事人？各方是否适格（自然人、法人、分公司、个体工商户字号、死者或清算中主体等）？
② **管辖核查**：管辖法院依据为何（级别管辖＋地域管辖，有无专属管辖或协议管辖）？有无管辖权异议风险？
③ **时效核查**：诉讼时效、除斥期间、保证期间、执行时效、上诉期、申请再审期是否届满？起算点是否准确（知道或应当知道之日、履行期届满之日、文书生效之日、送达之日）？
④ **路径核查**：程序路径是否合法可行？劳动仲裁、行政复议等前置程序是否满足？反诉对象必须是本诉原告——对案外人的责任追究应另案起诉，不得在本诉中提反诉；反诉应在法庭辩论结束前提出（民诉法解释第232条）。执行异议、执行异议之诉、再审的适用是否正确？是否符合一案一诉？
⑤ **新旧法核查**：所引法条是否现行有效？条文序号是否为最新修正版本（民事诉讼法2023年修正）？已废止法律（合同法、物权法、担保法、侵权责任法、婚姻法、继承法、民法通则等）是否已替换为民法典对应编章？
