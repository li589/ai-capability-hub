# 律师助手全景图（能力展示技能）

## 功能定位
律师助手会话的**常驻可点击目录**。**当用户明确表达法律咨询意图时**（描述了纠纷/案情/要写文书/要算赔偿等，而非打招呼/闲聊），由 `31-总控路由` 自动在右侧渲染该节点图；用户可点击右上角"收起"将其隐藏，并通过右下角常驻的"📑 目录"浮标随时唤回。

- 目录覆盖接案全流程 **12 大阶段 · 110 个关键节点**，默认全展开；
- 用户**不必按流程顺序**，随时点击任意子节点，图内反馈区即显示对应反问/引导语，并附“复制此提问”按钮；
- 收起后目录不消失，右下角浮标常驻，一键展开；
- 无需记忆关键词，也无需命中任何触发词。

目标：让用户一眼看清律师助手覆盖的法律领域与全流程节点，并能随时切换到任意想到的步骤。

## 展示与唤回规则（供 `31-总控路由` 引用）

- **用户明确表达法律咨询意图时触发（与首轮回复同步渲染、永久固定）**： 在"三段式引导入口"开场动作中，先输出固定开场白 **"我先给您一张能力导航图，同时开始分析您的问题。请把案情和现有证据尽量详细地告诉我，越详细越好，其他的，交给我来做！"**，其下方紧跟加粗高亮的提示 **👇 [ 查看目录 ]**（仅视觉提示，不可点击、非触发器）；**与此同时**在右侧渲染本目录，自本会话起**永久固定常驻右侧**，随时可点击任意节点查看引导；**出图与案情分析并行进行，不阻塞、不等待**；用户只是打招呼或未说具体事时，简短回应即可，不提前发全景图；

- **v5.0.1 默认收起成面包屑（降低首屏认知负荷）**：全景图渲染后**默认收起**为右下角面包屑条（显示"📍 当前案由：待识别"）+ "📑 目录"浮标——律师首屏不再面对一棵76节点大树，而是看到面包屑 + 对话框里的"你可以这样直接说"示例区。律师想看全局，点面包屑或浮标**一键展开**；

- **案由识别后反向上色高亮（图是"结果展示"不是"操作控件"）**：当模型识别出案由后（如律师说"租房押金不退"→ 识别为"房屋租赁合同纠纷"），调用 `setCasePath("房屋租赁合同纠纷")` 更新面包屑为"📍 当前案由：房屋租赁合同纠纷"，同时可选展开全景图、高亮对应节点——律师不需要先去图里点"侵权→机动车交通事故"，模型自己判完案由后反向上色，图是"结果展示"而非"操作控件"；

- **案件提醒面板（红色独立区块，v5.0.1 新增）**：全景图顶部常驻一个红色边框"🔔 案件提醒"面板，初始显示"暂无提醒"。律师说"案件提醒"并指定案件文件夹路径后，由 `76-期限与时效计算器` 的扫描脚本提取提醒列表，通过 `renderCaseAlerts(alerts)` 注入面板，按 🔴0–3天紧急 / 🟠4–7天提醒 / 🟡8–15天关注 / ⚪>15天正常 / ⚫已过期 五档着色呈现（与 SKILL.md / 76号 分档口径一致）。面板收起全景图时自动隐藏，展开时同步显示；

- **用户主动收起**：用户点击目录右上角"收起"按钮后，目录缩为右下角"📑 目录"浮标 + 面包屑条；
- **随时唤回**：用户点击"📑 目录"浮标或面包屑条，或说出"功能图""目录""能力图""全景图"等，目录立即重新展开，无需刻意命中关键词。

> **设计意图（v5.0.1 更新）**：参照元典 Amicus、通义法睿等国内跑通产品的"前端藏法学体系、只留动作+示例、案由后端自动判"模式——全景图从"默认全展开糊一脸"降级为"默认收起成面包屑 + 案由识别后反向上色"，降低律师首屏认知负荷；但保留常驻可看（浮标 + 面包屑条常驻），不丢"随时能看全局"的诉求。

> **设计意图**：目录常驻右侧，让用户感觉随时都在、随时可切换到任意步骤；同时通过收起按钮避免对熟手造成遮挡。关键词触发不再作为必要入口。

## 展示动作（核心）

> ⚠️ **【关键修复·必读】** 预览服务器（`present_files` 的静态托管）会拦截 `.workbuddy` 隐藏目录，直接渲染 `assets/` 下的 HTML 会返回 **403 Forbidden**。技能文件恰在 `.workbuddy/skills/.../assets/` 下，因此**必须先发布到工作区可访问目录再渲染**，否则所有人都会遇到 “Forbidden”。

**第 1 步：一键发布（自动渲染 + 发布到工作区，用户零手动）**

用 `scripts/present_panorama.py` 一键完成“渲染最新源图 → 原子发布到工作区”：

```bash
# 首选（自动定位技能包、自动渲染、自动发布到当前工作区根目录）：
python "<技能包目录>/scripts/present_panorama.py"
# 发布到指定目录（如 ./outputs/）：
# python "<技能包目录>/scripts/present_panorama.py" --to ./outputs
# 自检发布件（缺失/过期/位置异常时自动重发）：
# python "<技能包目录>/scripts/present_panorama.py" --check-present
```

- 脚本从自身位置自动推导技能包根目录（ 的上级），**无需记忆或解析绝对路径**；
- 发布件文件名固定为 ，默认写入当前工作区根目录（ 之外）；
- 发布目标若位于 `.workbuddy` 等隐藏目录内，脚本直接报错并打印纯文本节点树降级路径，**绝不要求用户手动复制文件**；
- 发布件被删除 / 过期（版本号、技能数、文件数、时间轴“今天”任一不一致）/ 位置异常时， 自动重新发布（自愈）。

**脚本不可用时的最后手段（仅当 `present_panorama.py` 无法运行时才用）**：
```bash

# cp (Get-ChildItem -Path $env:USERPROFILE -Recurse -Filter 律师助手节点树状图.html -ErrorAction SilentlyContinue | Select-Object -First 1).FullName "./律师助手节点树状图.html"
# macOS / Linux (bash)
# cp "$(find ~/.workbuddy -name 律师助手节点树状图.html 2>/dev/null | head -1)" "./律师助手节点树状图.html"
```

- 目标 `./律师助手节点树状图.html` 位于工作区根目录，预览服务器可正常托管；复制到 `./outputs/` 亦可。
- ⚠️ 发布件**必须成功且位于 `.workbuddy` 之外**，第 2 步才能渲染；若首选命令报错（路径不存在/权限不足），立即换用上方兜底命令重试，不要直接渲染源文件。

**第 2 步：渲染发布件**
