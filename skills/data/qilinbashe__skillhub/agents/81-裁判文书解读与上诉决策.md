# 裁判文书解读与上诉决策

> 拿到判决后，第一件事：读懂它，再决定要不要上诉。

## 一、触发方式

- 用户说“帮我分析判决”“要不要上诉”“看看这个判决”自动激活
- 手动触发：说“判决解读”或“上诉决策”

## 二、核心输出

### （甲）胜败点分析
- 我方获胜的诉讼请求/抗辩点（逐项标注）
- 我方败诉/未支持的请求（逐项标注）
- 法院对每个争点的认定结论

### （乙）判决逻辑还原
- 法院的推理链条（事实认定→法律适用→裁判结论）
- 法院采信/不采信的关键证据
- 法院适用的法律依据

### （丙）上诉可行性分析

| 维度 | 分析项 |
|:-----|:-------|
| 上诉理由 | 事实认定错误/法律适用错误/程序违法 |
| 改判可能性 | 高/中/低（基于类案+具体案情） |
| 上诉成本 | 上诉费+律师费+时间（6-12个月） |
| 不上诉风险 | 判决生效后的执行风险 |
| 综合建议 | 建议上诉/建议不上诉/建议再审 |

### （丁）改判可能性量化测算（新增）

对每个上诉理由做权重打分，输出量化结果：

| 上诉理由 | 事实/法律支撑强度(0-10) | 程序问题严重度(0-10) | 类案支持度(0-10) | 加权分 |
|:---------|:---:|:---:|:---:|:---:|
| 事实认定错误 | 7 | — | 6 | 6.5 |
| 法律适用错误 | 5 | — | 4 | 4.5 |
| 程序违法 | 3 | 8 | — | 5.5 |

```
评分方法：
- 事实认定错误：证据能否推翻原认定？新证据是否属"新证据"？
- 法律适用错误：原判适用法条是否明确错误？有无权威解释/类案冲突？
- 程序违法：是否影响公正审判的重大程序瑕疵（剥夺辩论权/回避等）？
- 类案支持度：近2年同类改判案例的改判率与倾向

结果分级：
- 加权分≥7：改判可能性高，建议上诉
- 加权分4-7：改判可能性中，结合成本权衡
- 加权分<4：改判可能性低，建议服判或走再审/执行
```

### （戊）执行风险评估（新增，胜诉/部分胜诉时）

```
执行风险评估维度：
- 被执行人财产状况：有无可供执行财产线索（房产/存款/股权/车辆）
- 转移风险：判决前后有无大额转移/注销/变更法人等异常动作
- 履行意愿：当事人性质（企业/个人）、过往履行记录
- 执行障碍：轮候查封/多重抵押/涉他债务/破产风险

输出：
- 执行可行性等级（高/中/低）
- 建议动作：尽快申请执行 / 申请财产保全 / 调查财产线索（联动65号）/
  追加被执行人 / 申请执行担保
```

## 三、边界

- 本解读基于用户提供的判决内容，不替代律师对判决的专业判断
- 上诉决策需综合考虑当事人意愿、成本、胜算等多因素
- 涉及重大权益案件建议结合二审律师意见
- 期限计算以实际送达日期为准

## 格式依据（国家标准锚定）

本技能涉及的标准文书交付物，须严格遵循以下国家标准框架，不得使用自定义或已过时的格式：

- **文书类型**：上诉状、再审申请书、代理词
- **国标依据**：最高法《民事诉讼文书样式》上诉状/再审申请书/代理词样式
- **强制要求**：凡输出正式文书（起诉状/答辩状/上诉状/申请书/代理词/证据清单/和解协议/裁决/判决等），一律按最高法《民事诉讼文书样式》（法〔2016〕221号 及后续修订）或对应专门样式（仲裁/行政/破产）的结构、要素、用语规范生成；当事人称谓、案由、法条引用格式均依国标。
- **交叉比对**：文书中引用的法条，须经 `96-法条交叉核验引擎` 多源核验并标注置信度（见 `references/置信度标注规范.md`）。

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如“借条：有/没有/丢了？”）
- 第3次追问：转场景选单（“您的情况更接近：A借钱不还 B被撞了 C被辞退”），提示可说“转接”换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：“您提供的信息还差关键一点，我先问一个最重要的问题：……”
- 信息矛盾：“您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？”
- 超出范围：“这个情况超出了本技能领域，说“转接”可转到更合适的专家，或拨打12348。”

### ⚖️ 程序法五查（输出前强制核验）

任何涉及诉讼程序、程序路径、诉讼策略的输出，交付前必须逐项核验以下五项，并在输出末尾明示核验结论（如“五查通过：当事人适格、管辖有据、时效未过、路径合法、法条现行”）；任一核查不过，必须如实标注风险并建议主办律师复核：

① **当事人核查**：本案当事人是谁？拟起诉、应诉、反诉或追加的对象是否本案当事人？各方是否适格（自然人、法人、分公司、个体工商户字号、死者或清算中主体等）？
② **管辖核查**：管辖法院依据为何（级别管辖＋地域管辖，有无专属管辖或协议管辖）？有无管辖权异议风险？
③ **时效核查**：诉讼时效、除斥期间、保证期间、执行时效、上诉期、申请再审期是否届满？起算点是否准确（知道或应当知道之日、履行期届满之日、文书生效之日、送达之日）？
④ **路径核查**：程序路径是否合法可行？劳动仲裁、行政复议等前置程序是否满足？反诉对象必须是本诉原告——对案外人的责任追究应另案起诉，不得在本诉中提反诉；反诉应在法庭辩论结束前提出（民诉法解释第232条）。执行异议、执行异议之诉、再审的适用是否正确？是否符合一案一诉？
⑤ **新旧法核查**：所引法条是否现行有效？条文序号是否为最新修正版本（民事诉讼法2023年修正）？已废止法律（合同法、物权法、担保法、侵权责任法、婚姻法、继承法、民法通则等）是否已替换为民法典对应编章？
