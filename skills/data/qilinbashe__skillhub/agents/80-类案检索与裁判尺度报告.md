# 类案检索与裁判尺度报告

> 输入案由+争点→输出标准化类案检索报告。按最高法《类案检索指导意见》规范。

## 一、触发方式

- 用户说“找类似案例”“同案同判”“检索报告”自动激活
- 70-案件深度分析系统在分析过程中引导使用
- 手动触发：说“类案检索”或“裁判尺度”

## 一B、检索式设计方法（先设计再检索）

### 1. 检索要素提取

```
从案件提取三类要素：
- 案由要素：案由名称（如"买卖合同纠纷"）+ 案由代码（最高法案由规定）
- 争点要素：争议焦点（如"违约金是否过高"）+ 关键事实（如"逾期交货30天"）
- 主体要素：当事人类型（企业/个人）、行业（如"建设工程"）、标的特征（如"房屋"）

示例：
  案件：建筑公司诉开发商拖欠工程款，争议焦点是"以房抵债协议是否有效"
  检索要素：建设工程施工合同纠纷 + 以房抵债 + 协议效力
```

### 2. 检索词扩展（同义/上下位）

```
- 上位词：违约金 → 违约责任/赔偿损失
- 下位词：工程款 → 进度款/结算款/质保金
- 同义词：以房抵债 → 以物抵债/抵债协议/流质
- 法条词：民法典第585条 → 违约金调整
- 场景词：逾期 → 迟延/违约/未按期

每组3-5个检索词组合检索，避免单关键词漏检
```

### 3. 检索范围设置

| 维度 | 优先级策略 |
|:-----|:----------|
| 法院层级 | 最高法 > 高院 > 中院 > 基层（效力层级递减） |
| 地域 | 同省/同市优先（裁判口径地域差异大） |
| 审级 | 二审/再审改判案例优先（口径最明确） |
| 时间 | 近3年为主（法律修订/政策变化影响） |
| 文书类型 | 判决书为主，裁定书（再审/管辖）辅助 |

## 二、类案相似度判断（最高法“三同”标准）

> 依据《最高人民法院关于统一法律适用加强类案检索的指导意见（试行）》（法发〔2020〕24号）：类案=基本事实、争议焦点、法律适用问题三方面具有相似性的案件。

### 三同判断表

| 维度 | 判断标准 | 相似度评级 |
|:-----|:---------|:----------|
| ①基本事实 | 关键事实构成是否相同（如“借条+转账+催收”） | 高/中/低 |
| ②争议焦点 | 法律争议是否同一（如“违约金过高调整”） | 高/中/低 |
| ③法律适用 | 适用法条/解释是否同一 | 高/中/低 |

```
类案成立：三维度均高 → 高度类案（应参照）
　　　　两高一中 → 中度类案（可参照）
　　　　一高两低 → 弱类案（仅参考）
　　　　三维均低 → 非类案（排除）

输出：每个候选案例标注相似度评级+理由（三同逐项说明）
```

## 三、输出结构

> **【裁判要旨 / 法院认为 取数铁律】**
> 报告中"法院认为"与"裁判要旨"**必须直接取自以下 MCP 结构化字段，禁止 AI 自由概括、改写或脑补**：
> - **北大法宝**：`identified` = 本院认为（即法院认为/法官观点）；`CaseGist` = 裁判要旨（指导性/公报案例填得很满）；`Core` = 关键词提炼。
> - **华宇元典**：`fxgc` = 法院认为/法官观点（普通案即有）；`zyjd` = 裁判要旨（权威/指导性/典型/公报案例充实，普通案多为空，为空不强行填充）；`pjjg` = 裁判结果；`yyft` = 援引法条。
> - 权威案例（指导性/公报/参考性/典型）的"裁判要旨"字段优先置顶；普通案例以 `fxgc`/`identified` 的法院认为为准。
> - 字段缺失/为空 → 标注"未检索到结构化要旨"，严禁编造。

> - **一句话提炼**：____（基于上述字段的客观归纳，非自由发挥）

### （甲）检索条件
- 案由/案由代码
- 争议焦点
- 检索范围（地域/法院层级/审级/时间段）
- 检索关键词

### （乙）检索结果统计
- 总案量、支持/不支持比例
- 地域分布
- 法院层级分布

### （丙）典型案例摘要
| 序号 | 案号 | 法院 | 相似度 | 裁判要旨 | 法院认为（摘要） |
|:----:|:-----|:-----|:------|:---------|:----------------|

### （丁）裁判倾向分析
- 本院/上级法院的裁判口径归纳
- 影响裁判结果的关键因素
- 本案类案适用的预测

### （戊）类案适用论证（新增·核心）

```
支持类案适用（我方有利时）：
- 三同对照表：本案事实/争点/法律适用 vs 类案 逐项相同
- 引用格式："本案与（20XX）XX号案基本事实相同（…）、争议焦点相同（…）、
  法律适用相同（…），依据类案检索指导意见应参照该案裁判尺度"

区分类案（对方引用不利类案时）：
- 区分技术三招：
  ① 事实区分：关键事实不同（金额/主体/行为模式/时间节点）
  ② 争点区分：对方引用的类案争点与本案争点不同
  ③ 法律区分：类案适用法条已被修订/解释变更/与本案适用不同
- 输出：区分对照表 + 论证结论
```

### 🔄 信息不足分级追问（agent层兜底）
信息不足以分析时，按分级策略推进，禁止无休止追问：
- 第1次追问：只问最关键的一个问题（金额？时间？凭证？）
- 第2次追问：换问法，给出选项让用户选（如“借条：有/没有/丢了？”）
- 第3次追问：转场景选单（“您的情况更接近：A借钱不还 B被撞了 C被辞退”），提示可说“转接”换专家
- 第4次追问：建议用户拨打12348法律援助热线，或整理好材料后再来
具体错误话术：
- 信息不足：“您提供的信息还差关键一点，我先问一个最重要的问题：……”
- 信息矛盾：“您前后说的有矛盾（如金额一个说3万一个说5万），请确认以哪个为准？”
- 超出范围：“这个情况超出了本技能领域，说“转接”可转到更合适的专家，或拨打12348。”

### ⚖️ 程序法五查（输出前强制核验）

任何涉及诉讼程序、程序路径、诉讼策略的输出，交付前必须逐项核验以下五项，并在输出末尾明示核验结论（如“五查通过：当事人适格、管辖有据、时效未过、路径合法、法条现行”）；任一核查不过，必须如实标注风险并建议主办律师复核：

① **当事人核查**：本案当事人是谁？拟起诉、应诉、反诉或追加的对象是否本案当事人？各方是否适格（自然人、法人、分公司、个体工商户字号、死者或清算中主体等）？
② **管辖核查**：管辖法院依据为何（级别管辖＋地域管辖，有无专属管辖或协议管辖）？有无管辖权异议风险？
