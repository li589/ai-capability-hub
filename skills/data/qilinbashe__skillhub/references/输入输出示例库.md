# 输入输出示例库（10个案由 · 完整三段式）

> 新手不知道“怎么说”？**照下面的示例说就行**——每个示例均为完整三段式：您的输入（大白话）→ AI追问（一次只问一个）→ 您得到的输出（领域确认+分析+文书初稿+三查交付尾）。
> 所有示例均为**脱敏虚拟案情**，仅作对话示范；实际输出会随您提供的案情个性化调整。
> README“完整对话演示”节收录本库前3个高频示例的精华版；本库为全量版。

## 示例一 · 民间借贷（41-民间借贷纠纷）

**您的输入：**
> “朋友2023年3月借了我5万块钱，写了借条，说好一年还。现在到期半年了，催了好几次都不还。我有转账记录和借条照片。”

**AI 追问（一次只问一个）：**
> “借条上写还款日期了吗？有没有约定利息？”

**您的补充：**
> “写了，2024年3月到期。没约定利息。”

**您得到的输出：**
```
✅ 领域确认：我理解这是民间借贷纠纷，将调用41-民间借贷纠纷专家。
【时效分析】2024年3月到期，2027年3月前起诉，诉讼时效未过（3年）。
【利息主张】未约定利息，可主张逾期利息（按LPR计算）。
【文书初稿】民事起诉状：
  1. 判令被告偿还借款本金50,000元；
  2. 判令被告支付逾期利息（以50,000元为基数，按LPR自2024年4月起算）；
  3. 本案诉讼费用由被告承担。
【证据清单】借条原件/照片、银行转账记录、微信催款记录。
【交付尾】🔴 未核验·模型生成（未连接法条源时标注）｜置信度：需复核｜已脱敏｜下一步：补充借条原件照片，或拨打12348核实管辖法院。
```

## 示例十一 · 模糊输入引导（“被人坑了”也能问）

**您的输入：**
> “我被人坑了，钱没了。”

**AI 回显 3 个候选方向（不催不问，给选项）：**
> “别急，您大概说就行。‘被人坑了、钱没了’可能是这几种，您选一个最接近的（回编号）：① 借钱/货款收不回来（民间借贷/合同纠纷）② 投资/理财被骗（诈骗嫌疑，涉及刑事报案）③ 购物/消费被宰（消费者权益）——都不像就说‘其他’，我继续引导。”

**您说：**
> “①吧，他欠我钱就是不还。”

**AI 一次一问补齐要素：**
> “好的。请问有没有借条或转账记录？有的话最好，没有也没关系，聊天记录、证人也可以。”

**您说：**
> “有转账记录，微信转的。”

**您得到的输出：**
```
✅ 领域确认：我理解这是民间借贷纠纷，将调用41-民间借贷纠纷专家。
【证据评估】微信转账记录可作为交付凭证（《民法典》第667条｜✅已核验(MCP: 北大法宝)），建议补充催款聊天记录。
【时效分析】未约定还款期限，可随时要求还款，诉讼时效自催告宽限期届满起算3年。
```
