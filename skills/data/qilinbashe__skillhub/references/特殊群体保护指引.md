# 特殊群体保护指引

> 用途：识别特殊群体当事人，落实法定代理人/监护人提示与权益保护，与 38-未成年人案件 共同构成特殊群体保护体系。
> 触发：用户自述或案情显示当事人为 限制行为能力人 / 老年人 / 残疾人 时，除常规流程外，按本指引附加保护动作。

## 一、限制行为能力人（民法典第22条）

**识别特征：**
- 8周岁以上未成年人（民法典第19条：独立实施纯获利益或与年龄智力相适应的行为，其余须法定代理人代理或同意）
- 不能完全辨认自己行为的成年人（精神障碍、智力障碍等，经宣告为限制民事行为能力人）

**保护要点：**
1. 涉及诉讼/仲裁/签署文书的，须由**法定代理人**（监护人）代为实施或追认；法定代理人顺序：配偶→父母/子女→其他近亲属→其他愿意担任的个人或组织（经法院指定）。
2. 对方以限制行为能力人为被告的，法院会通知其法定代理人应诉；AI辅助时主动提示补充法定代理人信息。
3. 纯获利益行为（接受赠与、奖励等）有效，无需代理；与其年龄智力相适应的日常小额行为有效。

**提示话术：**
“本案当事人属于限制民事行为能力人，相关文书与诉讼行为须由法定代理人（监护人）代为实施。请问法定代理人是否已确定？建议先确认监护关系再推进程序。”

**文书签署提示：** 起诉状/答辩状/委托书均须法定代理人签署并注明其身份；委托代理关系须同时提交监护关系证明。

## 二、老年人（老年人权益保障法）

**识别特征：** 60周岁以上当事人；独居、失能、认知能力下降或经济困难者需特别关注。

**保护要点：**
1. 涉老案件（赡养、继承、房产、人身损害等）可提示“优先立案、优先审理”通道（老年人权益保障法关于保障老年人诉讼权益的规定）。
2. 老年人单独诉讼的，提示是否申请法律援助（经济困难免/减诉讼费条件）。
3. 对高龄或认知能力不足的老年人，提示由其成年子女或其他近亲属陪同，必要时建议申请**意定监护**或法定监护人代理。
4. 防范针对老年人的欺诈/高利贷/保健品陷阱等特殊风险场景，反模式适用。

**提示话术：**
“请问老人家的身体状况和沟通情况如何？如由代理人处理，建议准备委托手续；如老人行动不便，可询问法院是否有上门立案或视频开庭安排。”

**文书签署提示：** 授权委托书须老人本人签名（无法签名的按手印并注明），附身份证明；必要时附监护/代理关系证明。

## 三、残疾人（残疾人保障法）

**识别特征：** 视力、听力、言语、肢体、智力等残疾当事人；使用无障碍辅助需求者。

**保护要点：**
1. 听力/言语残疾人：提示申请**手语翻译**或书面交流方式；法院应为其提供无障碍诉讼服务（残疾人保障法关于无障碍环境与诉讼便利的规定）。
2. 视力残疾人：文书可要求提供电子版/朗读版。
3. 智力/精神残疾（限制/无民事行为能力）：按第一条限制行为能力人规则处理，须法定代理人代理。
4. 涉及残疾赔偿纠纷（人身损害、工伤、交通事故）的，按各案由参数表计算残疾赔偿金，提示鉴定程序。

**提示话术：**
“我们会充分尊重您的诉讼权利。如有无障碍需求（手语、大字、辅助设备等），可以告知，也可以向法院申请无障碍服务。”

**文书签署提示：** 由本人签署或法定代理人代签；确认民事行为能力状态后再决定签署方式。

## 五、强制报告（v4.19.0 新增：发现侵害线索即触发，优先级最高）

> 依据：未成年人保护法第11条、反家庭暴力法第14条——发现未成年人/无民事行为能力人遭受**虐待、家暴、性侵**等侵害的，负有强制报告义务。

**触发条件**：用户自述或案情显示当事人（尤其未成年人、无/限制行为能力人）正在或曾经遭受虐待、家暴、性侵、人身伤害威胁。

**强制动作（命中即执行，暂停常规分析）：**
1. 输出报告路径：**110** 公安（紧急） / **12338** 妇女维权热线 / 当地未成年人保护中心（12345 转接）。
2. 明示提示：“根据《未成年人保护法》第11条，发现侵害线索负有强制报告义务——请立即通过上述渠道报告，切勿延误。”
3. 建议留存证据（伤情照片、就医记录、聊天记录），但**不得**指导“如何掩盖/私下解决”。
4. 状态卡打“强制报告”标记；报告义务履行后，再视情况提供后续法律咨询（监护权变更、人身安全保护令等）。
5. 与 38-未成年人案件、反模式清单 AP-013 联动。

## 六、通用强制动作（三类群体命中即执行）

1. 在案件状态卡标注“特殊群体标识”（类型 + 法定代理人是否到位）。
2. 输出涉诉程序提示：法定代理人/监护人代理关系、委托手续、可能需要的援助渠道（12348 法律援助热线）。
3. 涉老、涉残、涉限制行为能力人案件，凡涉及放弃权利、和解、撤诉等处分行为，强化“须法定代理人同意/法院审查”提示。
4. 涉及未成年人按 38-未成年人案件 专项技能处理。
