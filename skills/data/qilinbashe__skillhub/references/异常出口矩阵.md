# 异常出口矩阵

> 所有 Agent 遇到异常时，统一按本表给用户固定话术，不展示原始报错。
> 每条均为“人话解释 + 解决步骤 + 替代方案”三件套（v4.9.1 起扩充为 12 类技术异常，覆盖网络 / 组件 / 输入 / 服务四类场景；v4.19.0 新增“人身安全高危场景”出口，**优先级最高，先于一切技术异常处理**）。

> 🔒 **执行接线（v4.12.0 强制，全包 Agent 统一遵守）**：
> 1. 任何异常（断网、组件缺失、文件打不开、接口超时、脚本失败等）发生时，**先查本表对应行**，按“人话解释＋解决步骤＋替代方案”三件套输出给用户；
> 2. **禁止向用户转述内部机制**：自动重试次数、降级模式、MCP、纯文本分析、退出码、依赖组件等术语一律不出现，全部翻译成人话；
> 3. 内部机制（重试/降级/恢复）由 Agent 自行执行，用户侧只看到“人话解释＋下一步怎么做”；
> 4. 切换降级/恢复模式时，明示原因与恢复方式，绝不静默降级（示例见 `agents/31-总控路由.md`“用户话术示例”）。

| 异常 | 人话解释 | 解决步骤 | 替代方案 |
|------|---------|---------|---------|
| 断网 / MCP 不可用 | 当前没连上网，实时查法条的通道没开 | 稍等网络恢复，系统自动重连；重试期间对话不中断 | 自动降级离线法条，输出标注“离线模式·未联网核验”，提示律师复核 |
| 缺依赖 | 某个附加功能（导出Word、识别扫描件）需要的组件还没装好，不是系统坏了 | 说“安装”自动补齐；或运行 `python scripts/install_deps.py --word/--pdf/--ocr/--audio/--office/--all` | 转 PDF / 截图上传 / 粘贴文字（三选一）；文字咨询、案情分析无需任何安装 |
| 文件解析失败 | 这个文件暂时打不开 | 确认格式在支持列表（12类）内、大小未超100MB | 转 PDF 上传 / 截图上传 / 直接粘贴文字；不假装成功 |
| 模糊输入 | 没听懂您的具体案由 | 从3个候选案由中回复编号即可 | 12348 热线 / 重新描述一次 |
| 多轮无有效信息 | 连续几轮没拿到关键信息，不再追问 | 基于已有信息先出初稿，附缺失信息清单 | 转人工 / 补材料 / 出初稿（三选一出口） |
| 脚本失败 | 后台工具出了小状况 | 系统已自动降级，您看到替代方案（纯文本版/文字版）即属正常，后台自动重试 | 说“继续”重新尝试 |
| 模型无响应 / 接口超时 | 后台服务忙或临时出错 | 自动重试（最多3次），重试期间对话不中断 | 重试仍失败自动降级离线分析，输出标注“未联网核验”；说“继续”即恢复 |
| 上下文超长 | 本次对话内容太多，超出处理上限 | 建议开启新会话，粘贴案件状态卡即可恢复进度 | 分段提交：先给关键事实，再补证据材料 |
| 知识库未注入 | 5套可选增强资料（离线法条/案例库等）未导入 | 运行 `python scripts/check_knowledge_base.py` 查看缺失项及影响范围；按导入指引注入 | 不影响核心功能，直接用内置离线法条兜底 |
| 组件安装失败 | 附加功能组件装不上 | 说“安装”自动重试；或手动运行对应 `install_deps.py` 参数 | 换替代方式（转PDF/截图/粘贴文字/导出Markdown） |
| 权限不足 / 404 | 找不到资源或权限不足 | 换个说法重新描述一次 | 转人工 / 12348 |
| 文件过大 | 文件超过100MB | 压缩后重新上传 | 拆分上传 / 截图关键页 / 粘贴文字 |

## 人身安全高危场景（v4.19.0 新增：与上方 12 类技术异常并列，优先级最高）

> 检测到人身安全高危信号时，**先于一切异常处理与法律分析**执行下方动作，不追问案情细节、不评判、不说“想开点”。

| 场景 | 识别信号 | 干预动作（立即输出） |
|------|---------|---------------------|
| 自杀/自残 | “想死”“不想活”“割腕”“跳楼”“遗书”“结束生命”等 | 共情话术 + 全国心理援助热线 **400-161-9995**（24小时）/ **010-82951332** + 危急拨打 **120**，建议亲友陪同，暂停法律分析 |
| 家暴 | “家暴”“被打”“被家暴”“家暴求助”等 | 共情话术 + **110**（人身危险）/ **12338** 妇女维权热线 / **12348** 法律援助；提示先行脱离危险环境或寻求庇护，再议法律方案；涉未成年人同步强制报告 |
| 人身威胁/报复伤害 | “威胁我”“报复我”“要弄死我”“跟踪我”“尾随”等 | 共情话术 + **110** 报警 + 建议留存证据（短信/通话/监控）并避免单独行动；涉紧急危险优先报警 |
| 未成年人侵害 | 未成年人被虐待/性侵/家暴线索 | 共情 + 强制报告：**110** 公安 / **12338** 妇联 / 当地未成年人保护中心；提示“依法负有强制报告义务”，停止对侵害事实的继续分析 |

> 🔒 执行接线：命中上述任一场景 → 暂停法律分析 → 按上表输出干预话术 → 状态卡打“人身安全高危”标记 → 待安全确认后再议法律方案。

## 环境状态卡

首次体检或异常后，优先给用户三句话：

1. 当前文字咨询是否可用。
2. 图片、PDF、录音、Word 导出缺什么。
3. 缺的时候怎么装或怎么替代。

## 自动恢复机制（与 SKILL.md“故障自动恢复”联动）

统一走“自动重试（最多3次）→ 自动降级 → 替代路径 → 自动恢复”闭环：
- 断网：自动检测，网络恢复后下次调用自动恢复实时核验，无需重启、无需重新描述案情；
- 法条源断线：切离线分析并标注“未联网核验”，MCP 重连自动探测双前缀；
- 会话内警告仅首次出现，不重复刷屏。
- **恢复话术**：异常恢复后自动续接当前案件（状态卡），用户说“继续”即恢复，进度不丢；
- **切换可见性**：每次模式切换（降级/恢复）明示原因与恢复方式，绝不静默降级。
