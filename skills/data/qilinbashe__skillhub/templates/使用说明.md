# 使用说明（模板总索引与联动指引）

> 本文档为律师助手技能包的文书模板总索引：37 个模板按用途分类存放，供各 Agent 起草文书时按需调用；同时说明模板与技能（Agent）的联动方式、填写规范与版本管理要求。

---

## 一、模板与技能（Agent）联动方式

1. **按案由取模板**：Agent 起草文书时，先按下表定位对应模板，再按模板结构填充案件事实与诉请；模板中的“案由专属”片段按案由直接选用。
2. **案由专属内容已内嵌**：民事起诉状模板内嵌民间借贷（本金＋利息分段计算）/ 交通事故（法定赔偿项目与赔付顺序）/ 离婚（感情破裂法定情形与抚养权要素）/ 买卖合同（货款＋违约金＋逾期利息）四类专属诉请与证据片段，并在“尾部”前附4份完整版案由专属起诉状；劳动仲裁申请书模板内嵌违法解除 2N／被迫解除 N／拖欠工资／工伤待遇四场景专属请求，并附分场景完整版申请书。
3. **刑事文书走技能内嵌模板**：辩护词、取保候审申请书、不批准逮捕法律意见书等刑事文书模板内嵌于 01-一审阶段辩护 / 04-二审阶段辩护 / 09-侦查阶段辩护 / 14-刑事辩护总调度 四个技能正文，起草时直接调用技能内文书结构；通用骨架可参照 `templates/文书模板/法律意见书模板.md`“刑事辩护文书三件套”节。
4. **导出与排版**：初稿生成后说“导出Word文档”，调用 72-Word文档工程 按 GB/T 9704-2012 排版。
5. **隐私铁律**：模板填充一律使用化名，身份证号只写后 4 位，禁止落盘真实住址与联系信息。

## 三、模板填写与维护规则

1. 所有模板均为**初稿骨架**，须经执业律师实质审查、修改并签字后方可用于正式程序。
2. 模板中留空的当事人信息、日期、金额等，按案件实际填充，禁止编造。
3. 同一案件多次生成文书时，按 `文书版本管理说明` 记录版本变更。
4. 模板修改须同步核对引用该模板的 Agent 内指引，避免结构漂移。
5. 引用模板内案例时，按 `案例引用规范` 标注来源与核验状态。
