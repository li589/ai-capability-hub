## 🚀 四步体验

```
第1步：定目标 → "只要看证据/分析案情/出文书/接案评估/查法条类案/全流程"
第2步：说情况 → "朋友欠我5万不还，有借条" / "被车撞了，对方全责"
```

- 诉讼策略分析与接案评估（起诉/应诉前的可行性分析）
- 文书初稿（起诉状、答辩状、合同审查意见等）与证据梳理

## 🛡️ 运行保障速览（遇到报错不用慌）

1. **断网 / 缺组件自动降级**：网络不好或缺组件时自动切换备用方案（本地法条库 / 替代格式），分析不中断、不卡死；
2. **报错只说大白话**：任何报错都给您“哪里出了问题＋怎么解决＋三选一替代路径”（转PDF / 截图 / 粘贴文字），不甩技术术语；
3. **说“继续”即恢复**：遇到问题后说“继续”，自动切换备用方式并续接当前案件，进度不丢——您只需说“继续”，无需重新描述案情；
4. **降级透明**：每次切换都明示原因与恢复方式，绝不静默降级；
5. **全景图加载异常不影响使用**：能力导航图若当前环境显示不全，AI 自动输出纯文本节点树兜底，直接看本页“新手先用这 5 个”或 FAQ Q13 即可，无需任何手动操作。

> 完整机制见 FAQ“运行保障机制”＋“异常对话示例”；12 类异常话术见 `references/异常出口矩阵.md`。
>
> 🔒 **全包执行接线（v4.12.0 起强制）**：以上承诺不是文档摆设——全包 Agent 异常节统一执行异常出口矩阵接线，任何报错按"人话解释＋解决步骤＋替代方案"三件套输出，内部机制（重试次数/降级模式/MCP/退出码）一律不向用户转述，切换降级/恢复必明示原因与恢复方式。机制文档 `references/异常出口矩阵.md` 与 111 个 Agent 异常节同源同步。
