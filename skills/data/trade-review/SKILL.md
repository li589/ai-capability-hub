# 趋势短线复盘工作台

## 概述

本技能为A股短线交易者提供完整的复盘工作流，覆盖午盘快速决策和盘后深度复盘两个场景。通过通达信MCP实时获取行情数据，自动计算市场环境评分、情绪周期阶段、个股趋势评分，并生成可视化复盘页面。

核心理念：**复盘不是看数据，而是从数据中提炼交易决策**。本技能融合淘股吧7位大V的实战复盘心法，将情绪周期判断、持仓分级管理、止损纪律审计等方法论固化到可执行流程中。

## 权限声明

本技能涉及以下操作，特此声明：

| 权限类型 | 说明 |
|---------|------|
| 文件读取 | 读取项目目录下的 trade-review.html 复盘页面文件 |
| 文件写入 | 更新 trade-review.html 中的行情数据、评分、图表数据 |
| MCP调用 | 调用 tdx-connector（通达信MCP）获取实时行情、K线、选股数据 |
| 网络部署 | 调用 workbuddy_cloudstudio_deploy 部署复盘页面到公网 |

**安全说明**：本技能不硬编码任何API密钥。通达信MCP的OAuth认证由WorkBuddy连接器框架自动管理，技能本身不接触凭证信息。

## 能力边界

**能做的：**
- 从通达信MCP获取指数行情、个股行情、涨停跌停数据、K线数据
- 计算MA5/MA10/MA20均线位置，判断个股趋势强弱
- 计算市场环境评分（涨停跌停比+成交额）和情绪周期阶段
- 生成/更新双模式复盘页面（午盘+盘后）
- 部署复盘页面到公网（CloudStudio）
- 配置定时自动化任务（工作日11:35午盘+15:05盘后）

**不能做的：**
- 不能获取用户的真实持仓和账户数据（需用户手动填写）
- 不能提供买卖建议（仅提供数据分析和决策框架）
- 不能获取分时级别盘中数据（通达信MCP提供的是实时/收盘快照）

## 执行流程（盘后复盘详细步骤）

### 第一步：获取行情数据

使用通达信MCP（tdx-connector）获取以下数据：

**指数行情**（tdx_quotes）：
- 上证指数 999999、深成指 399001、创业板指 399006、科创50 000688、北证50 899050
- 需要字段：当前价格、涨跌幅、成交额

**涨停跌停数量**（tdx_screener）：
- 查询"涨停"获取涨停股数量
- 查询"跌停"获取跌停股数量

**个股行情和K线**（tdx_quotes + tdx_kline）：
- 默认监控5只个股：北方华创002371、长江电力600900、海光信息688041、中际旭创300308、寒武纪688256
- 用户可在对话中指定不同的个股列表
- 对每只个股获取25日日K线数据用于计算MA5/MA10/MA20

通达信MCP工具的详细参数说明见 `references/tdx-api.md`。

### 第二步：计算分析指标

**MA均线计算**：
- MA5 = 最近5个交易日收盘价的算术平均
- MA10 = 最近10个交易日收盘价的算术平均
- MA20 = 最近20个交易日收盘价的算术平均
- 均线位置判断：价格在MA5/MA10/MA20上方 = "5/10/20日线上方"，以此类推

**市场环境评分**（满分100）：
- 基础分50
- 涨停/跌停比 > 5：+20分；> 3：+15分；> 2：+10分；> 1.5：+5分；< 0.5：-20分；< 1：-10分
- 两市成交额 > 3.5万亿：+5分；< 2.5万亿：-5分
- 评分解读（5档）：≥ 70 强势；60-69 震荡偏强；50-59 震荡；40-49 震荡偏弱；< 40 弱势

**情绪周期判断**（按ratio = 涨停数/跌停数判断，注意elif顺序）：
- ratio > 3 → 高潮期（亢奋，注意风险）
- 2 < ratio ≤ 3 → 发酵期（情绪升温，可参与）
- 0.8 ≤ ratio ≤ 2 → 分歧期（多空均衡，观望为主）
- ratio < 0.5 → 冰点期（恐慌出清，等拐点）← 必须先于退潮期判断
- 0.5 ≤ ratio < 0.8 → 退潮期（情绪回落，控仓位）

**个股均线位置分**（满分65，用于判断趋势强弱）：
- 5/10/20日线上方 = 65分
- 5/10日线上方、20日线下 = 55分
- 20日线上方、5/10日线下 = 45分
- 全部线下 = 30分
- 5只个股取平均分 = 趋势均分

**个股综合评分**（满分100，用于雷达图和评分卡，与均线位置分不同）：
- 趋势维度（满分30）：均线位置分映射（65→30, 55→24, 45→18, 30→12）
- 量价维度（满分20）：放量上涨=20, 缩量上涨=15, 放量下跌=8, 缩量下跌=12
- 强度维度（满分20）：涨幅>5%=20, >2%=15, >0=10, <0=5
- 板块维度（满分15）：板块领涨=15, 跟涨=10, 板块弱=5
- 风险维度（满分15）：远离止损=15, 接近止损=10, 触及止损=5

**持仓分级标准**：
- A级（强势）：涨幅 > 2% 且均线上方 → 操作：持有/加仓
- B级（健康）：均线上方，涨幅平稳（-2%~+2%） → 操作：持有不动
- C级（关注）：均线下方但跌幅 < 2% → 操作：盯盘观察
- D级（处理）：跌幅 > 2% 且均线下方 → 操作：减仓/止损

**止损价规则**（3条，按均线位置选择）：
- 跌破20日线的个股：止损价 = 最近20日最低价
- 20日线上方但5/10日线下方的个股：止损价 = MA20价格
- 5/10日线上方的个股：止损价 = MA10价格（更紧的止损）

详细的评分标准和复盘框架见 `references/review-framework.md`。

### 第三步：更新复盘页面

用获取和计算的数据更新trade-review.html，需要更新的部分：

**topbar区域**：
- 日期改为今天（格式：YYYY-MM-DD 星期X 盘后）
- 市场环境评分、趋势均分、纪律评分

**总览页（Tab 1）**：
- 市场状态环（评分+状态标签：强势/震荡/弱势）
- 情绪周期标签和描述
- 指数概览表（5行：指数名/价格/涨跌幅/成交额）
- 涨停家数
- 两市合计成交额
- 明日一句话计划

**市场环境Tab**：
- 总分和5个子项评分
- 涨停/跌停数据和比值
- 成交额数据
- 情绪周期判断
- 15分钟复盘法数据

**趋势股票池Tab**：
- 5只个股的现价、涨跌幅、均线位置、PE、评分

**个股评分Tab**：
- 5个评分卡的评分环（SVG stroke-dashoffset）
- 现价、涨跌幅
- 5项子评分（趋势/量价/强度/板块/风险）
- 均线数据
- 分析描述

**持仓Tab**：
- 仓位诊断（根据环境评分给出仓位建议）
- 持仓分层（A级/B级/C级/D级分类）
- 调整优先级表

**纪律审计Tab**：
- 扣分项评分
- 止损审计（根据均线位置更新止损价）
- 错误清单

**明日计划Tab**：
- 执行表（股票/评分/止损价/操作）
- 明日剧本（乐观/中性/悲观三种情景）

**JS图表数据**：
- breadthChart：涨停/跌停柱状图数值（两处：initMarketCharts和window.load）
- volumeChart：xAxis日期改为最近5个交易日，series成交额数据更新
- radar：rd对象的s1~s5五组数据根据个股评分更新

**午盘模式4个模块**（用收盘数据回填）：
- 模块1 上午情绪温度：涨停数、跌停数、封板率、情绪温度标签
- 模块2 主线方向确认：4个板块的涨停数和判断
- 模块3 持仓快速体检：5只个股的涨跌幅、均线位置、量能、状态、操作建议
- 模块4 午盘结论：下午操作建议

**数据标注规则**：
- 来自通达信的数据标注 `<span class="real-tag">真实</span>`
- 分析判断的数据标注 `<span class="demo-tag">分析判断</span>`
- 需要用户手动填写的标注 `<span class="demo-tag">待填写</span>`

**涨跌颜色规则（A股惯例）**：
- 涨幅为正 → 红色（class="up" 或 style="color:var(--red-dark)"）
- 跌幅为负 → 绿色（class="down" 或 style="color:var(--green-dark)"）

### 第四步：部署到公网

更新完HTML后，使用workbuddy_cloudstudio_deploy工具重新部署：

- directory: 项目目录路径
- entry: trade-review.html
- port: 3000

### 第五步：配置定时自动化（可选）

## 注意事项

1. **通达信MCP必须已连接**：使用前确认tdx-connector已在连接器列表中显示"connected"。如果未连接，引导用户在连接器管理中启用通达信连接器。MCP未连接时，仅"复盘心法查询"场景可用（不依赖行情数据），其余场景无法执行。

2. **个股列表可自定义**：默认监控5只个股，用户可在对话中指定不同的个股。修改个股列表后，需要同步更新HTML中的个股评分卡、持仓体检、止损审计等所有相关部分。

3. **K线数据可能被截断**：通达信MCP的tdx_kline工具在返回数据量较大时可能被截断。建议count参数设为25（足够计算MA20），如果被截断则减少count重试。

4. **页面部署地址**：首次部署会生成公网地址，后续重新部署会更新同一地址的内容。地址格式为 `https://<sandbox-id>.tc-nanjing.share.codebuddy.woa.com`。

5. **A股涨跌颜色惯例**：涨=红色，跌=绿色，与美股相反。更新HTML时务必遵守此惯例。

6. **评分命名区分**：本skill涉及两种评分，不要混淆——"均线位置分"（满分65，仅基于均线位置判断趋势强弱）和"综合评分"（满分100，5维度雷达图，用于个股评分卡）。趋势均分是5只个股均线位置分的平均值。

7. **免责声明**：本skill提供的仓位建议、持仓分级、止损价等均为数据分析框架，不构成投资建议。用户应结合自身风险承受能力和投资经验做出独立判断。playbook案例中的个股操作仅为示例，不代表对具体股票的推荐。
