# 复盘框架

本文档定义复盘skill的完整分析框架，包括评分标准、情绪周期、持仓分级、止损规则等。

## 一、市场环境评分（满分100）

### 评分公式

```
基础分 = 50
涨停跌停比调整：
  比值 > 5.0 → +20
  比值 > 3.0 → +15
  比值 > 2.0 → +10
  比值 > 1.5 → +5
  比值 < 0.5 → -20
  比值 < 1.0 → -10
  其他 → 0

成交额调整：
  > 3.5万亿 → +5
  < 2.5万亿 → -5
  其他 → 0

总分 = 基础分 + 涨停跌停比调整 + 成交额调整
总分 = clamp(总分, 0, 100)
```

### 评分解读

| 评分区间 | 状态标签 | 仓位参考 |
|---------|---------|---------|
| ≥ 70 | 强势 | 仓位可较高，关注龙头 |
| 60-69 | 震荡偏强 | 仓位60-80%，持股为主 |
| 50-59 | 震荡 | 仓位40-60%，高抛低吸 |
| 40-49 | 震荡偏弱 | 仓位20-40%，控仓为主 |
| < 40 | 弱势 | 仓位<20%，空仓观望 |

> **免责声明**：以上仓位参考仅为数据分析框架的输出，不构成投资建议。实际仓位应根据个人风险承受能力、资金性质和投资经验独立判断。

## 二、情绪周期五阶段

基于养家心法，将市场情绪分为五个阶段：

### 高潮期

- **特征**：涨停 > 跌停 × 3，连板梯队完整，赚钱效应极强
- **心态**：市场亢奋，散户跑步入场
- **操作**：持有为主，不追高。注意高位股分歧信号
- **风险**：高潮之后必有分歧，准备减仓

### 发酵期

- **特征**：涨停 > 跌停 × 2，龙头走出，跟风盘涌现
- **心态**：情绪升温，资金积极做多
- **操作**：可积极参与，低吸龙头或埋伏补涨
- **风险**：中等，注意板块轮动节奏

### 分歧期

- **特征**：涨停/跌停比值在0.8~2倍区间，多空相对均衡，板块分化明显
- **心态**：犹豫不决，部分人开始兑现
- **操作**：观望为主，等分歧转一致再参与
- **风险**：较高，方向不明

### 退潮期

- **特征**：涨停/跌停比值在0.5~0.8倍区间，高位股集体回调，赚钱效应差
- **心态**：情绪回落，套牢盘增加
- **操作**：控仓位，回避高位股，等冰点拐点
- **风险**：高，管住手

### 冰点期

- **特征**：涨停/跌停比值 < 0.5倍，恐慌性杀跌，跌停潮
- **心态**：恐慌出清，割肉盘涌出
- **操作**：等跌停数回落确认拐点，可少量抄底
- **风险**：由高转低，拐点临近

### 情绪周期判断规则

注意：elif 分支必须按以下顺序判断——冰点期（< 0.5倍）必须在退潮期（0.5~0.8倍）之前判断，否则冰点期永远不会命中。

```
ratio = 涨停数 / 跌停数

if ratio > 3:
    情绪 = "高潮期"        # > 3倍
elif ratio > 2:
    情绪 = "发酵期"        # 2~3倍
elif ratio >= 0.8:
    情绪 = "分歧期"        # 0.8~2倍（含1.2~2倍区间）
elif ratio < 0.5:
    情绪 = "冰点期"        # < 0.5倍（必须先于退潮期判断）
else:
    情绪 = "退潮期"        # 0.5~0.8倍
```

## 三、个股均线位置分（满分65）

### 均线位置判断

使用MA5、MA10、MA20三条均线判断个股趋势强弱：

| 均线位置 | 评分 | 含义 |
|---------|------|------|
| 价格在5/10/20日线上方 | 65 | 强势趋势，可持有 |
| 价格在5/10日线上方，20日线下 | 55 | 短期偏强，中期待确认 |
| 价格在20日线上方，5/10日线下 | 45 | 中期趋势在，短期调整 |
| 价格在全部均线下方 | 30 | 弱势，需处理 |

### 趋势均分计算

```
趋势均分 = sum(5只个股均线位置分) / 5
```

## 四、个股综合评分（满分100，用于雷达图和评分卡）

> 注意：综合评分与第三节"均线位置分"是不同的评分体系。均线位置分（满分65）仅基于均线位置判断趋势强弱；综合评分（满分100）从5个维度评分，用于个股评分卡和雷达图展示。

每只个股从5个维度评分，构成雷达图：

| 维度 | 满分 | 评分依据 |
|------|------|---------|
| 趋势 | 30 | 均线位置（65分→30, 55分→24, 45分→18, 30分→12） |
| 量价 | 20 | 放量上涨=20, 缩量上涨=15, 放量下跌=8, 缩量下跌=12 |
| 强度 | 20 | 涨幅>5%=20, >2%=15, >0=10, <0=5 |
| 板块 | 15 | 板块领涨=15, 板块跟涨=10, 板块弱=5 |
| 风险 | 15 | 远离止损=15, 接近止损=10, 触及止损=5 |

## 五、持仓分级管理

### 四级分类标准

| 等级 | 条件 | 状态标签 | 操作参考 |
|------|------|---------|---------|
| A级 | 涨幅>2% 且 均线上方 | 强势 | 持有/加仓 |
| B级 | 均线上方，涨幅平稳（-2%~+2%） | 可持有 | 不动 |
| C级 | 均线下方但跌幅<2% | 需关注 | 盯盘 |
| D级 | 跌幅>2% 且 均线下方 | 需处理 | 减仓/止损 |

> **免责声明**：以上操作参考仅为分级框架的示例输出，不构成投资建议。

### 仓位诊断规则

根据市场环境评分给出总仓位参考（非投资建议，仅供分析框架参考）：

| 市场评分 | 仓位参考 | 操作策略参考 |
|---------|---------|---------|
| ≥ 70 | 较高仓位 | 关注龙头标的 |
| 60-69 | 60-80% | 重仓持有 |
| 50-59 | 40-60% | 半仓高抛低吸 |
| 40-49 | 20-40% | 轻仓控风险 |
| < 40 | <20% | 空仓或极轻仓 |

> **免责声明**：以上仓位百分比仅为基于市场环境评分的分析参考，不构成投资建议。用户应结合自身风险承受能力独立决策。

## 六、止损价规则

### 止损价计算

| 个股状态 | 止损价计算方式 |
|---------|-------------|
| 跌破20日线 | 止损价 = 最近20日最低价 |
| 20日线上方 | 止损价 = MA20价格 |
| 5/10日线上方 | 止损价 = MA10价格（更紧的止损） |

### 止损审计

每日盘后需检查：
1. 所有持仓是否设置了止损价
2. 是否有持仓触及止损价但未执行
3. 止损价是否需要根据最新均线位置调整

## 七、15分钟复盘法（午盘专用）

源自情绪流猛男的快速复盘法，用于午盘11:30-13:00的15分钟决策：

### 4步快速判断

1. **看涨停数**：涨停>100=情绪好，<50=情绪差
2. **看连板梯队**：高位连板是否断层，晋级率是否正常
3. **看持仓**：持仓股上午涨跌+分时均线位置+量能
4. **定操作**：根据以上3步决定下午操作

### 下午操作信号

| 信号 | 条件 | 操作 |
|------|------|------|
| 可加仓 | 情绪健康+主线延续+持仓走强 | 下午回踩低吸 |
| 持有不动 | 情绪正常+持仓未破位 | 不操作 |
| 减仓信号 | 情绪转弱+持仓走弱 | 下午反弹减 |
| 止损信号 | 持仓破位+逻辑失效 | 下午开盘即处理 |
