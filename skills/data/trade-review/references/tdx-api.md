# 通达信MCP工具参数说明

本文档详细说明复盘skill使用的通达信MCP工具的参数和返回格式。

## 工具总览

| 工具名 | 用途 | 关键参数 |
|--------|------|---------|
| tdx_quotes | 查询实时行情 | codes（证券代码列表） |
| tdx_kline | 查询K线数据 | code, period, count |
| tdx_screener | 自然语言条件选股 | query, limit |
| tdx_lookup_stock | 检索证券代码 | keyword, market |

## tdx_quotes — 查询实时行情

查询股票、指数、板块的实时行情数据。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| codes | string[] | 是 | 证券代码列表，如 ["000001", "600519"] |
| fields | string[] | 否 | 需要返回的字段列表，默认返回主要字段 |

**常用代码：**

指数：
- 999999 = 上证指数
- 399001 = 深成指
- 399006 = 创业板指
- 000688 = 科创50
- 899050 = 北证50

个股（示例）：
- 002371 = 北方华创
- 600900 = 长江电力
- 688041 = 海光信息
- 300308 = 中际旭创
- 688256 = 寒武纪

**返回格式：**

MCP返回的content中包含JSON文本，解析后包含以下字段（字段名可能因版本不同有差异）：
- price / zxj / close：当前/收盘价格
- change_pct / zdf / zhangfu：涨跌幅（%）
- volume / cje：成交额（元，需除以10000转为亿元）

**解析建议：**

```python
# MCP返回格式: { content: [{ type: 'text', text: '...' }] }
# text内容是JSON字符串，解析后可能是数组或对象
# 需要兼容多种字段名
```

## tdx_kline — 查询K线数据

查询股票、指数的K线历史数据。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| code | string | 是 | 证券代码，如 "600519" |
| period | string | 是 | K线周期：1m/5m/15m/30m/60m/day/week/month |
| count | number | 否 | 返回K线数量，默认120。建议设25（够算MA20） |

**返回格式：**

解析后为K线数据数组，每条包含：
- close / zxj / c：收盘价
- open / kpj / o：开盘价
- high / zgj / h：最高价
- low / zdj / l：最低价

**注意事项：**
- count参数设为25即可，设太大会导致返回数据被截断
- 如果返回被截断（数据不完整），减少count重试
- K线数据按时间正序排列（最早在前，最新在后）

## tdx_screener — 自然语言条件选股

使用自然语言描述筛选条件进行选股。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| query | string | 是 | 自然语言筛选条件，如"涨停"、"跌停" |
| limit | number | 否 | 返回数量上限，默认20。统计涨停数时建议设500 |

**使用示例：**
- 查询涨停数量：query="涨停", limit=500
- 查询跌停数量：query="跌停", limit=500
- 返回结果的数量即为涨停/跌停的股票数

**注意事项：**
- 返回的是符合条件的股票列表，统计数组长度即为数量
- 如果返回格式包含total或count字段，直接使用该字段

## tdx_lookup_stock — 检索证券代码

根据名称检索证券代码。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| keyword | string | 是 | 搜索关键词，支持股票名称、简称 |
| market | string | 否 | 市场筛选：SH/SZ/HK |

**使用场景：**
- 用户提到股票名称但不知道代码时使用
- 确认个股的市场归属

## MCP调用流程

通达信MCP使用streamable-http协议，调用流程：

1. **确认连接器状态**：在连接器列表中确认tdx-connector为"connected"
2. **使用ToolSearch加载工具schema**：如果工具schema未加载，先用ToolSearch搜索
3. **使用DeferExecuteTool调用工具**：传入工具名和参数
4. **解析返回结果**：MCP返回的content中包含text字段，解析为JSON

**注意事项：**
- 通达信MCP需要OAuth认证，认证由WorkBuddy连接器框架自动处理
- 如果连接器显示"disconnected"，引导用户在连接器管理中启用
- 工具调用可能因网络超时失败，建议重试1-2次
