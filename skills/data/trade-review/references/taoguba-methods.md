# 淘股吧大V复盘心法

本文档整理淘股吧7位大V的短线复盘方法论，供复盘skill在分析判断和生成结论时参考。

## 一、养家 — 情绪周期五阶段

### 核心理念

"买在分歧卖在一致"——市场情绪是短线交易的核心驱动力。情绪有周期，如同潮汐，高潮之后必有退潮，冰点之后必见回暖。

### 五阶段详解

1. **冰点期**：跌停潮涌现，恐慌盘出清。此时不应恐慌，而应观察跌停数是否开始回落。跌停数从高峰回落的那一天，就是冰点拐点。

2. **发酵期**：涨停数开始增加，龙头股走出连板。情绪从冰点开始升温，资金开始积极做多。这是最佳参与期。

3. **高潮期**：涨停数远超跌停（3倍以上），连板梯队完整，赚钱效应爆棚。此时应持有为主，不追高，准备在分歧信号出现时减仓。

4. **分歧期**：涨停数和跌停数接近，多空力量均衡。高位股开始回调，低位股补涨。此时应观望，等分歧转一致。

5. **退潮期**：涨停数少于跌停，高位股集体回调。此时应控仓位，管住手，等下一个冰点拐点。

### 复盘要点

- 每日记录涨停数、跌停数、连板数，画情绪曲线
- 判断当前处于哪个阶段，明日可能转向哪个阶段
- 根据情绪阶段决定仓位：高潮满仓→分歧半仓→退潮轻仓→冰点等拐点

## 二、乔帮主 — 低吸战法

### 核心理念

"低吸不是抄底，而是在强势股回调到支撑位时介入"。低吸的核心是选对股（必须是强势趋势股）+ 选对时机（回调到关键支撑位）。

### 低吸三要素

1. **选股**：必须是近期有过涨停或连续上涨的强势股，排除弱势股和下降趋势股
2. **等回调**：强势股回调到5日线或10日线附近，缩量企稳
3. **确认信号**：回调企稳后出现放量阳线或长下影线，确认支撑有效

### 复盘要点

- 每日筛选符合条件的低吸标的（强势股+回调到支撑+缩量）
- 记录低吸标的的后续表现，验证战法有效性
- 止损设在支撑位下方3-5%

## 三、胖刺猬 — N型主升

### 核心理念

"N型主升"是指股票上涨不是直线，而是N字形：第一段上涨→回调→第二段上涨（主升浪）。关键是在回调结束时介入，吃主升浪。

### N型识别

1. **第一段上涨**：连续上涨30%以上，确立上升趋势
2. **回调段**：回调幅度10-20%，回调到10日或20日线附近
3. **主升段**：回调企稳后再次启动，涨幅通常大于第一段

### 复盘要点

- 筛选处于N型回调段的个股（第一段涨30%+，回调到支撑位）
- 观察回调是否缩量，缩量=主力未出货
- 等待主升段启动信号（放量阳线突破回调高点）

## 四、情绪流猛男 — 15分钟复盘法

### 核心理念

"午盘15分钟定胜负"——不需要长时间复盘，关键信息15分钟就能提取完。

### 15分钟四步法

1. **3分钟看涨停**：涨停数、跌停数、连板数，判断情绪温度
2. **3分钟看梯队**：连板梯队是否完整，有无断层，高位股是否分歧
3. **5分钟看持仓**：每只持仓看3个信号（涨跌/分时均线/量能），快速分类
4. **4分钟定操作**：根据情绪+持仓状态，决定下午操作

### 持仓三信号

- **涨跌**：上午涨还是跌，涨幅/跌幅多少
- **分时均线**：股价在分时均线上方还是下方
- **量能**：上午成交量相比昨天是放量还是缩量

## 五、其他大V方法

### 龙头战法

- 只做市场最强龙头，不做跟风
- 龙头特征：最高连板、最大成交量、最强板块
- 龙头倒下意味着周期结束，及时撤退

### 连板梯队分析

- 完整梯队：5板→4板→3板→2板→首板，层级分明
- 梯队断层：高位连板但中间断档，情绪不稳
- 晋级率：昨日涨停今日继续涨停的比例，>50%为情绪健康

### 量价配合

- 放量上涨：健康，资金积极买入
- 缩量上涨：需警惕，可能是假突破
- 放量下跌：不健康，资金出逃
- 缩量下跌：可能是洗盘，待确认

## 六、复盘心法在skill中的应用

### 情绪周期 → 市场环境评分

skill在计算情绪周期时，直接使用养家的五阶段模型：
- 涨停/跌停比 > 3 → 高潮期
- 涨停/跌停比 > 2 → 发酵期
- 涨停 ≈ 跌停 → 分歧期
- 涨停 < 跌停 → 退潮期
- 涨停 < 跌停 × 0.5 → 冰点期

### 低吸战法 → 趋势股票池筛选

skill在筛选趋势股票池时，参考乔帮主的低吸标准：
- 均线位置判断（是否在5/10/20日线上方）
- 量价配合判断（放量/缩量）
- 回调幅度判断（从高点回调多少）

### 15分钟复盘法 → 午盘模式

skill的午盘模式直接采用情绪流猛男的15分钟四步法：
- 模块1 上午情绪温度 = 3分钟看涨停
- 模块2 主线方向确认 = 3分钟看梯队
- 模块3 持仓快速体检 = 5分钟看持仓
- 模块4 下午操作信号 = 4分钟定操作

### N型主升 → 个股分析描述

skill在生成个股分析描述时，参考胖刺猬的N型判断：
- 从高点回调幅度
- 是否在关键支撑位企稳
- 是否出现主升段启动信号
