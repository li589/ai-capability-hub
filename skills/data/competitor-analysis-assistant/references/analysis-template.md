# 单竞品分析输出模板

> 按此模板产出单竞品分析。使用 `{ }` 占位符填充。查不到的信息明确写"查不到"，推测信息标注"推测"。
>
> **产出默认形式**：单竞品模式默认生成独立HTML文档（`竞品分析_{竞品名}.html`，浅色主题、自包含单文件，章节结构与本模板一致），并对话中呈现要点；本模板的Markdown结构作为HTML各章节的内容基准。HTML样式规范见 SKILL.md Step 5「HTML输出规范」。

## 模板

```
## {竞品名}（{公司全称}）单竞品分析

### 基础信息
| 维度 | 内容 |
|------|------|
| 公司 | {公司全称} |
| 成立 | {年份}（{月份}） |
| 注册资本 | {金额} |
| 团队规模 | {人数}（推测/确认） |
| 融资 | {轮次+金额+投资方} |
| 诉讼/风险 | {案件数+性质} |
| 目标行业 | {行业列表} |
| 价格（{年份}查证） | {价格模式+区间+来源} |
| 部署方式 | {SaaS/本地/云原生} |
| 来源/渠道 | {伙伴/直销/渠道} |

### 核心功能模块（可查证）
- {功能模块及说明列表}
- ⚠️ 查不到：{未公开维度}

### 与eMES功能对比

|--------|------|--------|---------|

| 设备管理/OEE | ... | ... | ... |
| 质量检验 | ... | ... | ... |
| 异常管理 | ... | ... | ... |
| 模具管理 | ... | ... | ... |
| 库存/WMS | ... | ... | ... |

（对比结论需客观：谁强写谁强，查不到写"查不到"）

### 公司背景与风险
- 融资/股东/资质：{信息}
- 诉讼风险：{数量+性质+评价（如"员工规模大的正常现象"）}

### 用户评价/实施评论
- 正面：{评价+来源（官方案例/第三方评测）}
- 负面：{评价+来源}
- 暂无公开评价：{如有}

### eMES应对策略
- 短期攻击点：{基于事实的差异化优势}
- 长期补全方向：{竞品有而eMES缺的功能}
- 竞争注意点：{价格重叠/渠道冲突等}
```

## 客观性自查清单（输出前核对）

- [ ] 每一维度都有信息来源（官网/行业报告/工商查询/调研表）
- [ ] 查不到的信息明确标注"查不到/未公开"，未编造
- [ ] 推测信息标注"推测"
- [ ] 价格标注查证年份
- [ ] 承认竞品优势，未片面贬低
- [ ] 用户评价正负面并收，注明来源
- [ ] 诉讼表述客观（区分正常经营纠纷与重大风险）
- [ ] 应对策略基于事实，非虚构竞品短板

## 输出示例（节选）

```
### 基础信息
| 维度 | 内容 |
|------|------|
| 公司 | 上海黑湖网络科技有限公司 |
| 成立 | 2016年 |
| 注册资本 | 558万（港澳台投资） |
| 团队规模 | 500-999人（在职约550人） |
| 融资 | C轮近5亿，累计超8亿 |
| 诉讼/风险 | 开庭公告14条（劳动/合同纠纷为主） |
| 价格（2026查证） | 专业版10,800/年·旗舰版18,800/年（含50账号） |
| 部署方式 | SaaS（微信小程序） |

### 与eMES功能对比（节选）
| 功能域 | eMES | 黑湖小工单 | 对比结论 |
|--------|------|-----------|---------|
| 报工管理 | 开始/结束加工记录，关联设备/模具 | 仅汇报数量，手机端展示清晰 | 各有优势：eMES更深，小工单更简 |
| 异常管理 | 返工/暂停/工艺变更/跳站 | 无 | eMES优 |
```
