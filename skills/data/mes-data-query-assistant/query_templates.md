# 兜底生成规范与模板示例（query_templates）

> 定位：**主查询来源是系统已有 SQL 视图资产库**（`data/sql_assets/`，用户提供、业务口径已验证）。
> 本文件是「资产库未命中时的 Schema 兜底生成」规范 + 常见指标的 SQL 逻辑示例（当前为逻辑占位 `<表名>`/`<字段>`，待表结构确认后填充为真实列名）。
> 规则：LLM 解析四要素并填充参数；优先复用资产库视图，未命中才按本规范基于 schema 生成。

---

## 模板通用结构

```json
{
  "T1": {
    "metric": "产量",
    "params": ["product", "date_from", "date_to"],
    "sql": "SELECT ...",
    "columns": ["日期", "良品数", "不良数", "报废数"],
    "interpret": "产量 = 良品数（口径待确认）"
  }
}
```

## 参数定义

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `product` | string | 产品编码（MA_ID），可空=全部 | "M02" |
| `equipment` | string | 设备编码，可空 | "M01" |
| `line` | string | 产线/车间编码，可空 | "WS003" |
| `date_from` / `date_to` | date | 查询区间（含端点） | "2026-08-05" |
| `baseline` | date | 对比基准日（昨日/上周同日/去年同日） | "2026-08-04" |
| `shift` | string | 班次过滤，可空 | "早班" |

## T1 产量汇总（按日/班次）

```
SELECT <日期字段>, <班次字段>, SUM(<良品数>) AS 良品数,
       SUM(<不良数>) AS 不良数, SUM(<报废数>) AS 报废数
FROM <生产实绩表>
WHERE <日期字段> BETWEEN :date_from AND :date_to
  [AND <产品字段> = :product]
  [AND <产线字段> = :line]
GROUP BY <日期字段> [, <班次字段>]
ORDER BY <日期字段>
```

- 返回：每天 良品/不良/报废
- 解读：产量 = 良品数；产量下降时不良+报废作为归因线索

## T2 产量对比（当前 vs 基准）

```
-- 两次 T1 结果在应用层对比，或一次查询：
SELECT a.日期 AS 当日, b.日期 AS 基准日,
       a.良品数, b.良品数,
       ROUND((a.良品数 - b.良品数) * 100.0 / b.良品数, 2) AS 涨跌幅
FROM (<T1 当日>) a
JOIN (<T1 基准日>) b ON a.<产品/产线> = b.<产品/产线>
```

- 解读：|涨跌幅| ≥ 5% 判定明显波动，触发归因

## T3 设备稼动率 / OEE（按日）

```
SELECT <设备字段>, <日期字段>,
       SUM(<计划开机时长>) AS 计划时间,
       SUM(<实际稼动时长>) AS 稼动时间,
       SUM(<计划开机时长> - <停机时长>) * 100.0 / SUM(<计划开机时长>) AS 稼动率
FROM <设备运行记录表>
WHERE <日期字段> BETWEEN :date_from AND :date_to
  [AND <设备字段> = :equipment]
GROUP BY <设备字段>, <日期字段>
```

- 解读：稼动率公式、OEE 分解（时间×性能×合格）以口径确认为准

## T4 设备故障明细（归因/追问专用）

```
SELECT <设备字段>, <故障代码>, <故障描述>, <开始时间>, <结束时间>,
       TIMESTAMPDIFF(MINUTE, <开始时间>, <结束时间>) AS 停机时长, <处理人>
FROM <故障记录表>
WHERE <设备字段> = :equipment
  AND <开始时间> BETWEEN :date_from AND :date_to
ORDER BY <开始时间>
```

- 返回：故障代码、起止、停机时长、处理人 —— 即"原因1的具体数据"的答案

## T5 不良 / 缺陷统计

```
SELECT <缺陷代码>, SUM(<不良数>) AS 不良数,
       SUM(<不良数>) * 100.0 / NULLIF(SUM(<良品数> + <不良数>), 0) AS 不良率
FROM <质量检验表>
WHERE <日期字段> BETWEEN :date_from AND :date_to
  [AND <产品字段> = :product]
GROUP BY <缺陷代码>
ORDER BY 不良数 DESC
```

## T6 工单进度

```
SELECT <工单号>, <产品字段>, <计划数量>, <完工数量>, <工单状态>,
       ROUND(<完工数量> * 100.0 / <计划数量>, 2) AS 达成率
FROM <工单表>
WHERE <计划结束日期> BETWEEN :date_from AND :date_to
  [AND <产品字段> = :product]
ORDER BY <计划结束日期>
```

- 状态码映射：1=待加工, 2=加工中, 3=完工（以实际字典为准，参考 OAPI LOT_STATUS）

## 归因四维度 → 模板映射

| 维度 | 模板 | 命中条件 | 输出 |
|------|------|---------|------|
| A 设备故障 | T4 | 存在停机时长 ≥ 30min 记录 | 设备、时段、停机时长、产能损失估算 |
| B 停机稼动 | T3 | 稼动率较昨日下降 ≥ 10pp | 稼动率、OEE 变化 |
| C 工单状态 | T6 | 有延期/插单/未开工 | 工单号、状态、达成率 |
| D 质量不良 | T5 | 不良率较昨日上升 ≥ 2pp | 缺陷代码、不良数、占比 |
