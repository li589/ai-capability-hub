# Playbook：MES 智能问数助手

## 场景 1：产量查询
**用户输入**："M02今天的产量"
**产出**：M02 今日产量 + 口径说明（仅结束加工）+ 可追问提示

## 场景 2：对比分析
**用户输入**："今天产量和昨天比怎么样"
**产出**：今日 vs 昨日对比、涨跌幅、升降标注

## 场景 3：归因分析
**用户输入**："为什么今天的产量下降了"
**产出**：四维度归因（设备故障/状态切换/工单堆积/不良报废）+ 数据佐证 + 可追问问题

## 场景 4：报告输出
**用户输入**："输出一份报告"
**产出**：Word/HTML 汇总报告（封面+摘要+明细+附录）
