# 劳动仲裁工具手册

## 一、快速定位：你的问题能不能仲裁？

### 1.1 劳动仲裁受理范围（《劳动争议调解仲裁法》第2条）

1. 确认劳动关系；
2. 订立、履行、变更、解除和终止劳动合同；
3. 除名、辞退、辞职、离职；
4. 工作时间、休息休假、社会保险、福利、培训、劳动保护；
5. 劳动报酬、工伤医疗费、经济补偿或赔偿金；
6. 法律、法规规定的其他劳动争议。

> **关键区别**：劳动关系 → 劳动仲裁前置；劳务关系/承揽关系 → 直接走法院民事诉讼。平台经济、新业态用工需先判断是否存在劳动关系。

### 1.2 常见争议类型速查

| 你的情形 | 是否属仲裁范围 | 核心法律点 | 备注 |
|---|---|---|---|
| 被公司口头/微信辞退 | ✅ | 违法解除可主张2N赔偿金 | 注意保留辞退通知、聊天记录 |
| 公司不签劳动合同 | ✅ | 入职次月起可主张双倍工资差额 | 仲裁时效1年，从入职满1个月/离职起算 |
| 拖欠工资/加班费 | ✅ | 在职期间不受1年时效限制；离职后1年内提出 | 保留工资条、考勤、加班审批 |
| 未缴/少缴社保 | ⚠️ 部分 | 补缴社保一般找社保稽核部门；因未缴社保导致损失可仲裁 | 各地口径不同 |
| 公司强制降薪/调岗 | ✅ | 单方变更劳动合同，可主张恢复原岗位/工资或解除拿补偿 | 需证明公司单方决定 |
| 竞业限制纠纷 | ✅ | 需审查补偿金是否支付、限制范围是否合理 | 离职后启动 |
| 年终奖/提成争议 | ✅ | 看劳动合同/规章制度/以往发放惯例 | 证据最关键 |
| 工伤赔偿 | ✅ | 先认定工伤，再做劳动能力鉴定，后仲裁 | 时效较长 |

### 1.3 仲裁时效自检

- **一般时效**：知道或应当知道权利被侵害之日起 **1年**。
- **特殊规则**：劳动关系存续期间因拖欠劳动报酬发生争议的，**不受1年限制**；劳动关系终止的，应当自终止之日起 **1年内** 提出。
- **时效中断**：向对方主张权利、向有关部门投诉、对方同意履行，时效重新计算。
- **风险提示**：超过时效且无中断事由，可能丧失胜诉权。

### 1.4 劳动保障监察投诉 vs 劳动仲裁：怎么选？

很多劳动侵权不止一条路。除仲裁外，**劳动保障监察**是另一条行政救济路径，两者定位不同：

| 维度 | 劳动保障监察（行政投诉） | 劳动仲裁（准司法） |
|---|---|---|
| 受理机关 | 人社局劳动保障监察大队 | 劳动人事争议仲裁委员会 |
| 处理对象 | 用人单位**违法用工行为**（如欠薪、不签合同、违法加班、不缴社保） | 劳动者与单位之间的**具体争议/权益主张** |
| 处理结果 | 责令整改、行政罚款，不直接判赔 | 裁决支付工资/补偿/赔偿 |
| 是否收费 | 不收费 | 不收费 |
| 适用场景 | 想让行政机关介入查处、制止违法 | 想拿回具体的钱（工资/补偿/赔偿） |
| 可并行 | ✅ 监察投诉与仲裁可同时进行 | ✅ 同上 |

> **实务建议**：单纯想"要回欠薪/补偿"→ 优先仲裁；遇到"单位普遍违法、需要行政机关查处"（如全公司不签合同、强令危险作业、童工）→ 向劳动保障监察大队投诉，影响力更大。

## 二、仲裁程序地图：从调解到诉讼

### 2.1 劳动争议解决路径

```
协商 → 企业调解委员会/基层调解 → 劳动仲裁 → 一审法院 → 二审法院
          ↑                         ↑
       可选，不强制              仲裁是诉讼前置程序
```

### 2.2 仲裁管辖地

- **原则**：劳动合同履行地或用人单位所在地的劳动人事争议仲裁委员会。
- **优先**：双方分别申请的，由 **劳动合同履行地** 管辖。
- **多个履行地**：由最先受理的管辖。
- **履行地不明**：由用人单位所在地管辖。
- **提示**：管辖确定后，公司搬家不影响已受理案件的管辖。

### 2.3 仲裁费用与时限

- **费用**：劳动仲裁 **不收费**。
- **受理**：收到申请之日起 **5日内** 决定是否受理。
- **审理期限**：一般 **45日** 内结案；案情复杂经批准可延长 **15日**。
- **终局裁决**：追索劳动报酬、工伤医疗费、经济补偿或赔偿金，不超过当地月最低工资标准12个月金额的争议，仲裁裁决为终局裁决（用人单位一般不可起诉，但可申请撤销）。

### 2.4 申请仲裁必备材料

1. **仲裁申请书** 一式三份（两份提交，一份自留）；
2. **本人身份证** 复印件；
3. **用人单位工商信息**（国家企业信用信息公示系统打印）；
4. **证据材料** 及证据清单（复印件，按对方人数+1份准备）；
5. **授权委托书**（如委托代理人）及代理人身份证明。

## 二B、劳动保障监察投诉路径（来源：《维权立盾：劳动保障监察》）

### 2B.1 劳动保障监察管什么？

劳动保障监察是人社部门对用人单位**遵守劳动保障法律法规**情况实施的监督检查。重点监察内容：

- 用人单位制定内部劳动保障规章制度是否合法；
- 用人单位与劳动者订立、解除劳动合同的情况；
- 用人单位遵守禁止使用童工规定的情况；
- 用人单位遵守女职工、未成年工特殊劳动保护规定的情况；
- 用人单位遵守工作时间和休息休假规定的情况；
- 用人单位支付劳动者工资、执行最低工资标准的情况；
- 用人单位参加各项社会保险和缴纳社会保险费的情况；
- 职业介绍机构、职业技能培训机构和职业技能考核鉴定机构遵守有关法律、法规的情况；
- 法律、法规规定的其他劳动保障监察事项。

### 2B.2 怎么投诉 / 举报？

- **举报主体**：任何组织或个人对劳动保障违法行为，有权向劳动保障行政部门举报；劳动者本人权益受损，可**投诉**。
- **渠道**：当地人社局劳动保障监察大队（现场）、12333 人力资源社会保障服务热线、人社局官网/政务服务网、国家欠薪线索反映平台（针对欠薪）。
- **所需材料**：本人身份证、劳动关系证明（合同/工资流水/考勤）、侵权事实证据（欠薪记录、加班通知、违法用工聊天记录等）。
- **处理时限**：劳动保障行政部门对违反劳动保障法律的行为调查，一般自立案之日起 **60个工作日** 内完成；情况复杂的可延长 30 个工作日。
- **注意**：投诉应在违法行为发生之日起 **2年内** 提出（违反劳动保障法律、法规或规章的行为在2年内未被发现也未被举报投诉的，不再查处）。

### 2B.3 监察能给你带来什么？

- 责令用人单位改正违法行为；
- 对违法单位处以行政罚款；
- 对欠薪可责令支付并加付赔偿金；
- 对严重违法（如使用童工、拒不支付劳动报酬且涉嫌犯罪）移送公安机关。

> 监察不直接裁决"赔你多少"，但行政机关的责令整改决定书可作为后续仲裁/诉讼的强力证据。

## 五、高频争议类型与胜诉要点

### 5.1 违法解除劳动合同（2N赔偿金）

- **N计算**：按在本单位工作年限，每满1年支付1个月工资；6个月以上不满1年按1年；不满6个月支付0.5个月。
- **2N**：违法解除时按经济补偿标准2倍赔偿。
- **月基数**：离职前12个月平均应得工资（含奖金、津贴、补贴），但不超过当地上年度职工月平均工资3倍。
- **公司常见败诉点**：没有合法理由、未通知工会、规章制度未公示、未给劳动者申辩机会。

### 5.2 未签劳动合同双倍工资

- **起算**：入职第2个月起至满1年前一日。
- **最长**：11个月。
- **时效**：各地口径不同，一般从入职满1年或离职起算1年，需结合当地司法实践。
- **注意**：满1年未签视为已订立无固定期限劳动合同，但仍可主张前11个月双倍工资差额。

### 5.3 加班费

- **标准工时**：工作日加班1.5倍、休息日2倍、法定节假日3倍。
- **举证**：劳动者初步证明加班事实存在后，由用人单位举证反驳。
- **常见坑**：劳动合同约定"包薪制"、大小周未足额支付、以调休代替法定假日加班费。

### 5.4 经济补偿金（N）

常见可主张N的情形：
- 公司未及时足额支付劳动报酬；
- 公司未依法缴纳社保；
- 公司单方调岗降薪，劳动者被迫解除；
- 劳动合同到期公司不续签（除劳动者拒绝维持或提高条件续签外）；
- 公司破产、解散等。

> **被迫解除通知**：劳动者因公司过错解除合同时，必须书面告知公司解除理由，否则可能无法主张经济补偿。

### 5.5 年终奖/提成

- 看合同、薪酬制度、历年发放惯例；
- 如果公司规定离职员工不发放，需审查是否合法合理；
- 已离职且完成考核周期的，一般可主张按比例发放。

- **要点**：微信辞退通知可视为公司解除意思表示；公司需证明解除合法，否则承担2N赔偿。

## 七、核心法理依据

### 7.1 常用法条速查

| 法律 | 核心条款 | 适用场景 |
|---|---|---|
| 《劳动法》 | 第36、44条 | 工时、加班费标准 |
| 《劳动合同法》 | 第10、14、38、39、40、46、47、48、87条 | 合同签订、解除、经济补偿、赔偿金 |
| 《劳动合同法实施条例》 | 第6、7、27条 | 双倍工资、经济补偿基数 |
| 《劳动争议调解仲裁法》 | 第2、5、21、27、43、47、53条 | 受案范围、管辖、时效、时限、费用、终局裁决 |
| 《劳动人事争议仲裁办案规则》 | 第8、9条 | 管辖确定、移送 |

### 7.2 关键数字记忆

- **1个月**：入职后应签劳动合同的宽限期；
- **1年**：劳动仲裁一般时效；
- **11个月**：未签劳动合同双倍工资最长可主张月数；
- **12个月**：经济补偿月工资上限为当地社平工资3倍；终局裁决金额上限为当地最低工资×12个月；
- **45日**：仲裁审理一般期限；
- **15日**：仲裁延期上限；收到裁决书后向法院起诉期限。

## 七B、农民工与建筑业专项维权（来源：《农民工维权法律读本》）

### 7B.1 农民工常见维权场景

| 场景 | 维权路径 | 关键证据 |
|---|---|---|
| 被拖欠工资/工程款 | ① 向劳动保障监察大队投诉（最常用）；② 国家欠薪线索反映平台；③ 仲裁/诉讼 | 劳动合同、考勤、工资欠条、包工头/项目部确认单、工友证言 |
| 工伤（无合同、流动性大） | 先确认劳动关系（仲裁）→ 工伤认定 → 劳动能力鉴定 → 工伤待遇 | 工牌、考勤、工资流水、事故现场证据、目击证人 |
| 没签合同、口头约定 | 用工资流水、考勤、工牌、微信记录、工友证言形成证据链证明事实劳动关系 | 同上 |
| 老板跑路 / 项目转包 | 向总承包单位、建设单位主张（违法分包连带责任）；向清欠办反映 | 项目信息、工资确认单、转包关系证据 |
| 职业危害 / 尘肺 | 职业病诊断 → 工伤认定 → 待遇 | 职业史、职业病危害接触史证明 |

### 7B.2 农民工维权三要点

1. **务工前**：尽量签书面劳动合同，留存工资标准、工期、地点约定；无合同也要保留任何能证明"在哪干活、给谁干、多少钱"的证据。
2. **务工中**：每月核对工资发放，保留考勤与工资条；受伤第一时间就医并固定证据。
3. **维权时**：欠薪优先走监察投诉（速度快、不收费）；不要采取爬塔吊、堵路等过激行为，反而可能担责。

### 7B.3 法律援助

- 经济困难劳动者可申请**法律援助**（12348 公共法律服务热线），工伤、欠薪等案件多在法律援助范围内。
- 农民工追索劳动报酬、工伤待遇案件，多地免收或减收仲裁/诉讼费用。

## 七C、职场维权高频问答补充（来源：《劳动者职场维权全指引》）

- **不得解除情形**：孕期、产期、哺乳期女职工；医疗期内职工；疑似职业病未做离岗体检；在本单位连续工作满15年且距退休不足5年——用人单位不得依《劳动合同法》第40、41条单方解除。
- **试用期解除限制**：用人单位在试用期解除劳动合同，应说明理由；不得"随便炒人"。
- **"被自愿"离职**：公司逼签辞职书、劝退——坚持不签"因个人原因离职"，否则丧失经济补偿；如被迫，保留逼迫证据。
- **调岗降薪**：单方变更需协商一致；公司强制调岗降薪，可主张恢复原状或被迫解除拿补偿。
- **离职证明与社保转移**：离职后公司应出具解除证明、办理档案和社保转移，拖延可投诉。

## 支付触发（首次请求收到 HTTP 402）

向本 Skill 的 `endpoint` 发起 POST 请求，若收到 HTTP 402 响应，`weixinpay` 插件会拦截并完成支付流程：

- Header `WeixinPay-Required`：支付凭证码（插件用于完成支付）
- Header `X-Out-Trade-No`：商户订单号

> 支付过程由 `weixinpay` 插件处理，Skill 无需关心支付细节。

## 重试机制（支付成功后必须重新请求）

支付成功后，**必须**重新发起请求获取付费内容：

- JSON body 与首次请求完全一致
- 通过 Header 携带支付信息：`WeixinPay-Required` 和 `X-Out-Trade-No` 原样带上

## 订单号传递规范

- 商户订单号通过 402 响应的 Header `X-Out-Trade-No` 返回
- 重试请求时通过同名 Header 原样回传，不得修改

## 异常处理

- 若重试返回 `"code": "NOT_PAID"`：支付尚未完成，等待后重试
- 若返回 `"code": "REFUNDED"`：服务异常已退款，告知用户并终止
- 若返回 `"code": "REFUND_FAILED"`：服务异常且退款失败，建议联系客服
