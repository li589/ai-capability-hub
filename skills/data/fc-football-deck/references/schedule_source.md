# 赛程源用法（仅用于确认"今晚有哪几场对阵"）

## 定位
本 Skill 不绑定现实赛程（合规模式下是法务红线）。但在**开发者模式**或用户主动提供赛程源时，可以用外部赛程源解决一个纯粹的问题：**当用户说"预测今晚的几场比赛"却没列队名时，用赛程源拉出当天对阵列表，省去用户手动报队名。**

⚠️ 赛程源**只用来取"对阵双方队名"**，预测本身仍走 FC Online 卡组数据（query.py match）+ WebSearch 公开信号。**绝不直接抄赛程源里的盘口/赔率/AI 赛果数字**（那是博彩/赛果预测站的内容，与本 Skill 的"FC 卡组对位推演"定位不同）。

## 🚨 铁律：查对阵必须走 scripts/schedule.py，禁止凭印象编（v7.4）
任何"某队对手是谁 / 今晚哪几场"的问题，**必须经赛程源**，不准直接背对阵。优先级：
1. **在线源优先**：`WebFetch https://worldcup26.ir/get/games` → 存文件 → `schedule.py opponent/day/team --online-json <文件>`。
2. **静态兜底**：在线源失败才用 `schedule.py`（不带 --online-json，读包内 JSON）。包内 JSON 已据在线源回填全部附加赛真实归属，但可能滞后。
3. **占位符拦截**：`schedule.py` 输出 `has_placeholder=true` 时，对手是占位符（附加赛/胜者/TBD），**禁止直接用**，立即 WebSearch 核实真实球队。

### schedule.py 命令速查
- `schedule.py opponent --name 葡萄牙 --next [--online-json f]` → 某队下一场未开赛对手（自带占位符告警）
- `schedule.py day --date 2026-06-18 [--online-json f]` → 北京时间某天全部对阵
- `schedule.py team --name 葡萄牙 [--online-json f]` → 某队全部场次
- `schedule.py online --online-json f` → 在线源标准化全量

## ⚠️ 时区换算坑（必记）
`worldcup26.ir` 的 `local_date` 是**赛事当地时区（北美/美洲）**，不是北京时间。
- 美洲当地 6/13 的比赛 → 对应**北京时间 6/14 凌晨~上午**
- 所以用户问"北京时间今晚（6/14 凌晨）"的对阵时，要去接口里找 **`local_date = 当地 6/13`** 的那批，而不是 `06/14`。
- 通用规则：**北京时间日期 = 接口 local_date + 1 天**（取北京时间凌晨场次时，对应接口前一天的 local_date）。

## ⚠️ 已结束的比赛：返回现实结果，不做卡组推演（v7.2 新增）
赛程源返回的每场比赛有 `比赛状态`：`finished`（已完赛）/ `notstarted`（未开赛）。
- **已完赛（finished）**：**绝不再做卡组对位推演**（赛都踢完了，再推演毫无意义还显得不准）。直接返回**现实比分 + 一句简评**，口径如"这场已经踢完了，最终 X-Y，简评……"。可补一句轻量的"想用 FC 卡组复盘这套阵容怎么搭，可以告诉我"。
- **未开赛（notstarted）**：才走 FC 卡组对位推演（游戏阵容数据演绎）。
- 拿不准状态时，先看赛程源的状态字段；用户直接点名某场时，也可用 WebSearch 确认是否已赛完。

## 工作流
1. 用户说"预测今晚几场"但没给队名 → 合规模式下：告知不绑定赛程，请用户列对阵；开发者模式下：可走赛程源。
2. WebFetch `https://worldcup26.ir/get/games`，按时区换算取出目标日期的对阵列表 **+ 每场的比赛状态**。
3. **先按状态分流**：已完赛 → 返回现实比分+简评（不推演）；未开赛 → 继续下面的卡组推演。
4. 对未开赛对阵跑 `query.py match --engine X --home A --away B` 拿 FC 卡组数据（engine 用 Step 0 锁定的）。
5. 补 WebSearch 公开信号（伤停、状态、Opta 类公开倾向——作方向参考，不抄具体赔率）。
6. 逐场输出：**游戏阵容推演倾向**（明显占优/略优/接近）+ 胜负手/看点。
   - **禁止**用 0-100 倾向分位当比分（会被误读成"60:40"荒谬比分）。
   - **法务：禁止输出"预期比分 2-1 / 1-1"这种类猜球口径**——这和猜球无异，法务会被挑战。只给**文字倾向标签 + 战术看点**，包装为"游戏阵容/卡组强弱推演"，不落到具体足球比分数字。
