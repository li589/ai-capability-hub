# FC Online 特性目录与协同/克制矩阵

> **P0 状态**：本文件作为参考目录使用。特性能力字段尚未通过 OCR 接入到 player_ptg_cache，因此 P0 阶段 `query.py` 不会返回特性数据，评分不应用特性加权。等 P1 OCR 完成后启用。

## 一、特性三类

### A. 持有特性（球员卡自带）

**进攻类**
- 善于头球
- 善于搓射
- 善于远射
- 善于花式过人
- 速度盘带手
- 技术盘带手

**传球类**
- 传球大师
- 早期传中爱好者
- 长传爱好者

**通用**
- 钢铁身躯 / 玻璃身躯（互斥）
- 坚持位置偏好
- 长距界外球
- 激进型抢断爱好者
- 麻烦制造者

**门将**
- GK 出击参与
- GK 熟练击球
- GK 远距开球
- GK 沉着 1v1 防守
- 清道夫门将
- GK 主动十字防守 / GK 被动十字防守（互斥）

### B. 金特性（8 强解锁，加成型）

| 金特性 | 适用类型 | 效果 |
|---|---|---|
| 闪电突破 | 速度型前锋/边锋 | 慢速盘带后加速时瞬间向前拨球 |
| 渗透者 | 进攻 | 倾向停留越位线边缘，反越位跑位 |
| 偷猎者 | 抢点型前锋 | 接传中和倒三角时触发短时加速 |
| 灵巧致胜 | 高大型前锋 | 增加蝎子摆尾等花式凌空射门 |
| 精准输送 | 中场组织核心 | 优化过顶直塞球弧线和落点 |
| 空中堡垒 | 头球型球员 | 提前占据空中球落点 |
| 坚固壁垒 | 防守型 | 自动预判封堵中距离射门 |
| 破坏者 | 中后场 | 范围更大的站立抢断 |
| 捍卫者 | 防守型 | 失球后 10 秒回追加速 |
| 致高点 / 制高点 | 门将专属 | 出击稳健 |
| 决断出击 | 门将专属 | 出击速度提升 |
| 斗士 | 防守型 | 对抗强化 |
| 坚持不懈 | 全位置 | 大幅减少奔跑体力消耗 |

### C. 助教特性（P1 阶段补充）

提升远射、提升搓射、提升抢断、提升传中、停球后立即移动、关键传球大师、抢点意识强等。

## 四、Skill Runtime 应用方式（P1 启用）

1. 球员能力卡：以中文标签 + 图标展示持有/金特性
2. 关键连线分析：识别协同（如"精准输送 + 偷猎者"）→ 加分写入连线评分
3. 关键对位分析：识别克制（如"闪电突破 vs 捍卫者"）→ 进攻优势数值修正
4. 国家队套推荐：结合特性匹配阵容打法（如"善于头球"球员多 → 推荐边路传中战术）

## 五、维护流程（运营）

1. 每个 PTG 赛季更新后，运营校对一次特性图标库
2. 特性中文名变更时，同步更新本文件 + 协同/克制矩阵
3. 新增特性需评估对评分模型的影响（避免单一加分超过基础分 15% 上限）
