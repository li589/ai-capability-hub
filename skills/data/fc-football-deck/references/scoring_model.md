# 评分模型 v2（含平局概率 + 现实数据融合）

## 五条核心原则

1. **评分只用于解释倾向，不直接等同胜率**——绝不输出"法国胜率 63.7%"这类伪精确数字
2. **平局是合法赛果**——现实足球平局率约 25%，模型必须包含平局概率输出
3. **评分输出区间统一标准化到 0-100**（P0 简化阶段直接用 OVR 平均，区间 100-135）
4. **特性加分需设上限**（单球员特性总加分不超过基础分的 15%），避免堆叠后超过基础能力影响（P1 接入特性后启用）
5. **现实状态因子和 FC Online 能力因子分开展示**，让用户能看到推演链路

## 综合倾向公式（v2 · 🔒 用户确认锁定，禁止擅自改动权重）

> 🔒 **权重红线（2026-06-18 用户明确确认保留 v2）**：以下 5 个因子及其百分比是经用户认可的核心方法论，**任何迭代都不得擅自增删因子或调整百分比**。如需变更，必须先向用户说明并取得确认。历史：v1 为「现实45 + FC35 + 连线15 + 外部5」；v2 从 FC 与连线各挪 5% 新增「平局校准 10%」（因现实平局率约 25%，必须单独建模，避免强队一律算零封）。

```
综合倾向 =
  现实比赛因子 × 45%
+ FC Online 分组能力因子 × 30%
+ 平局校准因子 × 10%      ← v2 新增
+ 关键连线 / 对位因子 × 10%
+ 外部公开预测倾向（公开信号脱敏后） × 5%
```

### v2 新增：平局校准因子

基于 FC 卡组 OVR 差值 + 双方近期正式比赛结果综合计算：

| OVR 差值（FCO引擎） | 基础平局概率 | 现实数据校准后区间 |
|---------------------|-------------|-------------------|
| < 0.3 | ~32% | 25%~38% |
| 0.3 ~ 0.8 | ~27% | 20%~33% |
| 0.8 ~ 1.5 | ~22% | 15%~28% |
| 1.5 ~ 3.0 | ~14% | 8%~20% |
| > 3.0 | ~7% | 5%~12% |

**现实数据校准规则**：
- 双方近6场正式比赛平局率均 ≥ 30% → 基础概率上浮 +5%
- 双方近6场均"进球<1.2 + 丢球<1.0" → 基础概率上浮 +3%（低比分倾向）
- FC 卡组"明显占优"但现实近期连败 → 倾向下调一档
- FC 卡组"势均力敌"且现实近期状态差距大 → 倾向朝状态好的一方偏移

### 因子来源说明
- **现实比赛因子（含赛前公开预测信号 · 核心数据源）**：来自 WebSearch 获取的近期状态、伤停、首发完整度、战术匹配、赛程体能、近6场正式比赛结果。
  - **🎯 赛前公开预测信号是现实因子里信息质量最高的一块（v1.4.5 接入）**：公开赛前预测是经大数据综合定型的现实预判，比单纯的卡组数值更接近真实赛果分布。做法：把主胜/平/客胜三档强度值 → `1/值` 得原始权重 → 三项归一（去除冗余度）→ 得「现实倾向概率」。在 `query.py match` 里以 **现实信号 0.6 : FC 卡组 0.4** 融合三方概率，再据此重判倾向与比分。
  - **信号源**：公开赛前预测数据（新闻报道、公开赛事分析页等）。用 `--market "主胜,平,客胜"`（值越小越被看好）传入 `query.py match` / `run_match.py`。
  - **⚠️ 前端绝对脱敏（合规红线）**：该信号只做后端融合，**页面与回复里绝不出现任何外部数据来源相关字样**，统一外显为「综合卡组数据与现实信号」。详见 safety_policy.md。
- **FC Online 分组能力因子**：由 `query.py match` 输出的 `group_score_home/away` + `three_way_probs` 直接给出。
- **平局校准因子**：v2 新增，由 FC 卡组 OVR 差值算出基础平局概率，再用现实比赛数据校准。
- **关键连线 / 对位因子**：P0 简化为"同时存在两位 OVR ≥ 130 的核心连线"加分；P1 接入特性后启用协同/克制矩阵。
- **外部公开预测倾向**：通过 WebSearch 拉取媒体公开倾向。

### 现实信号融合实测（葡 vs 刚果金 · 手游 · v1.4.5）
| 场景 | 主胜倾向 | 倾向 | 推荐比分 |
|------|--------|------|----------|
| 纯卡组（手游低估，刚果金卡 OVR 偏高） | 44.2% | 葡萄牙略优 | 2:1 |
| 融合现实信号（公开预测强烈看好主队→主胜倾向 78%） | 64.7% | 葡萄牙明显占优 | **3:0** |

现实信号把手游卡组对弱队的系统性低估纠正了过来，结论更贴近现实——这正是它作为现实因子核心的价值。

## v2 评分模型（已固化在 query.py 中）

### 倾向档位 v2

```python
# v2: 五档倾向 + 三方概率
abs_diff = abs(home_fc - away_fc)

if abs_diff < 0.3 * scale:   → "势均力敌"   # 平局概率 ~32%
if abs_diff < 0.8 * scale:   → "X略优"      # 平局概率 ~27%
if abs_diff < 1.5 * scale:   → "X小优"      # 平局概率 ~22%
if abs_diff < 3.0 * scale:   → "X明显占优"  # 平局概率 ~14%
else:                         → "X碾压优势"  # 平局概率 ~7%
```

### 防守因子修正

双方后防+门将均OVR越高且接近 → 平局概率上浮：

```python
# 双方后防+门将平均 > 126 且差值 < 1.0 → 平局概率 +4%
# 双方后防+门将平均 > 125 且差值 < 1.5 → 平局概率 +2%
```

### 三方概率输出格式

```json
{
  "three_way_probs": {
    "home_win": 0.451,
    "draw": 0.261,
    "away_win": 0.288
  },
  "draw_probability": 0.261,
  "real_world_search_required": true
}
```

- `real_world_search_required: true` → 平局概率 ≥ 25% 或倾向为"势均力敌"，上层 Skill **必须** WebSearch 获取近6场正式比赛结果

### v1 → v2 变更对照

| 项目 | v1 | v2 |
|------|----|----|
| 倾向档位 | 4档（接近/略优/小优/明显占优） | 5档（势均力敌/略优/小优/明显占优/碾压优势） |
| 平局概率 | 无 | 有（5%~38%区间） |
| 三方概率 | 无 | 有（home_win/draw/away_win） |
| 现实数据触发 | 无明确触发条件 | `real_world_search_required` 标志 |
| 防守因子 | 不考虑 | 双方防守强→平局上浮 |
| 比分决策 | 无平局优先规则 | draw_prob≥28%→必须优先考虑平局比分 |

门将基础评分 =
  反应 × 30% + 扑救 × 25% + 站位 × 20% + 身高（标准化） × 15% + 出击/手控球 × 10%

特性加权（总上限：基础分 × 15%）：

### 连线评分

```
连线基础评分 =
  传球人传球 × 35%
+ 传球人（短传 + 控球 + 站位 平均） × 20%
+ 接球人射门 × 25%
+ 接球人（射术 + 头球 + 站位 平均） × 10%
+ 对手防守压制修正 × -10% 至 -30%

协同：
+ 传球人"精准输送" + 接球人"偷猎者" → +15
+ 传球人"传球大师" + 接球人"渗透者" → +12
+ 传球人"早期传中爱好者" + 接球人"善于头球" → +10

克制：
- 接球人侧出现对手"坚固壁垒" → 远射效率 -10
- 接球人侧出现对手"破坏者" → 持球时间 -8
```

### 对位评分

```
对位评分 = 进攻方关键能力 - 防守方关键能力

【速度型 vs 防守型后卫】
进攻 = 速度 × 50% + 加速 × 50%
防守 = 速度 × 40% + 加速 × 40% + 对抗 × 20%

特性克制：
- "闪电突破" vs "捍卫者" → 进攻优势 -5
- "渗透者" vs "坚固壁垒" → 进攻优势 -3
- "善于头球" vs "空中堡垒" → 接近平局
- "灵巧致胜" vs 普通中卫 → 进攻优势 +8
```
