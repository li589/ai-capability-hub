# ChatBI 支持的指标与维度

本文件是 ChatBI 智能问答的**能力清单**，用于在执行查询前确认用户请求的指标/维度是否落在支持范围内。

- 本清单描述的是「能不能问」，不是「一定有数」。某个指标/维度是否在具体业务域可用，仍以 `chatbi_ask` 的实际返回为准。
- 清单外的指标、维度、口径一律视为不支持，不得猜测或编造。

## 一、支持的数据类型

**仅支持历史汇总指标**：按维度聚合后的统计口径，以返回的 `columns`、`rows` 为准。

不支持原始列表、详情、逐笔记录、明细流水。

## 二、支持的分析形态

| 分析形态 | 说明 | 典型问法 |
|---|---|---|
| 汇总 | 指定时间范围的指标合计 | “上周销售额多少” |
| 趋势 | 按时间维度的变化曲线 | “近 30 天 GMV 趋势” |
| 对比 | 不同对象/时间段之间的横向比较 | “A 门店和 B 门店订单量对比” |
| 同比 / 环比 | 与去年同期 / 上一周期的比较 | “本月销售额环比” |
| 占比 | 各部分占整体的比例 | “各渠道销售额占比” |
| 结构拆分 | 按某维度拆解整体指标 | “销售额按类目拆分” |
| Top N / 排行 | 按销售额、销量等排序取前 N | “销量 Top 10 商品” |
| 多轮追问下钻 / 切换维度 | 在已有结果上继续细分或换维度 | “再按门店看一下” |

## 三、支持的主题域与常见指标

具体可用指标以对应业务域实际返回为准；下列为已支持主题域及其常见指标口径。

| 主题域 | 常见指标 |
|---|---|
| 经营 / 交易 | 销售额、支付金额、GMV、订单量、客单价、退款金额、售后单量 |
| 商品 | 商品/类目/SKU 维度的销量、销售额、Top N、趋势、对比 |
| 营销活动 | 活动维度的成交、参与、转化类汇总指标；促销类“库存消耗率” |
| 会员 / 客户 / 私域 | 会员数、新增会员、会员等级分布、客户相关汇总指标 |
| 门店 / 导购绩效 | 门店业绩、导购业绩、排行与对比 |
| 流量分析 | 访问、浏览等流量类汇总指标 |

**库存相关的边界**：仅当库存指标是某个已支持看板/数据集的指标时可查询（例如促销类“库存消耗率”）；不支持独立的库存域、仓储供应链分析。

## 四、支持的维度

下表用于把用户口语映射到字段。映射关系不表示这些维度在所有业务域都可用；真正能否使用以实际查询返回为准。

| 用户常见说法 | 映射字段 | 说明 |
|---|---|---|
| 日期、天、周、月、趋势 | `dd` | 常见时间维度 |
| 渠道、销售渠道 | `sale_channel_type` | 常见于交易、经营、客户等域 |
| 门店、组织 | `vid_name` | 常见于门店、经营、会员、导购等域 |
| 导购 | `guider_name` | 常见于导购业绩域 |
| 会员等级 | `member_level` | 常见于会员分析域 |
| 商品类目 | `cate_first_name` | 仅在实际业务域出现时才可使用 |

聚合维度总览：时间、门店、渠道、商品、会员、导购。

## 五、日报专用口径

- 日报基于历史已出数数据，通常为 T-1。
- 日报默认提供关键指标概览，可按用户问题做结构拆分、排行或趋势。
- **不支持当日实时口径**：“今日/当日/实时日报”不支持。
- 日报类问题不需要先比对本清单，可直接执行查询。

## 六、明确不支持

- **库存 / 仓储 / 供应链**：库存分析报告、库存周转/库龄、出入库、盘点、调拨、补货、采购、供货/履约等。
- **实时 / 当天**：当日实时数据或强实时看板刷新。
- **明细 / 原始记录**：订单/支付/退款等逐笔流水、订单明细、用户个人信息、商品列表/规格清单/明细等。
- **操作类诉求**：数据写入/修改、后台筛选排序、固定格式报表导出。
- **本清单未列出的字段/口径**：不要猜测或编造不存在的指标、维度、口径或结论。
