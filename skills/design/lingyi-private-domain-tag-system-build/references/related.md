# 相关技能与组合用法

本技能与两个姊妹技能构成「私域用户运营」三件套：本技能搭**体系底座**，画像技能产**人群画像**，分层触达技能做**按价值触达**。三者互补，可独立用、也可串成完整 SOP。

## 边界划分

| 维度 | 本技能（体系构建） | 画像技能 | 分层触达技能 |
|---|---|---|---|
| 回答的问题 | 怎么搭一套不腐烂的标签资产（企业级蓝图） | 用户是谁、行为偏好（人群级画像） | 对谁做、怎么触达（按价值分配资源） |
| 产出 | 标签体系四件套（架构+字典+治理+路线） | 用户画像与标签卡 | RFM 分层表 + 触达策略表 |
| 标签的角色 | 标签是治理对象+架构主体 | 标签是画像卡的填空字段 | 标签是分层的输入口（R/F/M 本是行为标签） |
| 独立可用 | 是 | 是 | 是 |

## 标签原语共享

三者共享标签三分类（事实/行为/预测）与预测标签三件套（得分+置信度+时间戳）原语。原语在画像技能里讲，本技能与分层触达技能引用不重复。

## 怎么组合

1. **先搭体系、再建画像、最后分层触达（推荐完整 SOP）**：
   - 用本技能搭出标签体系（架构+18字段字典+治理+落地路线）
   - 用画像技能：按本技能的标签字典，给某个人群填画像卡（标签是字典里的真实标签，不是臆造）
   - 用分层触达技能：按价值分层，触达内容引用画像结论

2. **只搭体系（用户目标明确是"建一套标签底座"）**：
   - 直接用本技能，四件套即可
   - 画像/分层触达是下游消费方，按需后续接

3. **已有画像/分层、回头补体系（标签乱要治理）**：
   - 用本技能盘点现有标签 → 去重/下线僵尸 → 补字典治理 SOP
   - 治理后把规整的标签字典反哺给画像/分层触达技能

## 一句话区分用户该用哪个

- 用户说"帮我从0搭一套标签体系/治理乱标签/做标签字典和打标方式" → 本技能（体系构建）
- 用户说"帮我搞清楚这些用户是谁、行为偏好、做画像卡" → 画像技能
- 用户说"帮我把用户按价值分层、做差异化触达" → 分层触达技能
- 用户说"私域用户运营整体做一版" → 三者串起来：体系底座 → 画像 → 分层触达
