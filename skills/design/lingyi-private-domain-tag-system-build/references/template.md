# 私域标签体系模板

使用本模板来产出私域标签体系四件套：标签分级架构、标签字典与元数据（18字段）、治理 SOP、落地实施路线（含打标矩阵、标签-活动关联）。

## 模板
```markdown
### 业务盘点（前置）
- 业务模式：[母婴复购/教育续费/SaaS/纸品/咖啡/...]
- 私域载体：[企微/个微/社群]
- 现有标签：[清单 或 "无/散乱"，带人数]
- 数据源：[埋点(可用?)/订单(可用?)/社群活跃(可用?)]（标注可用性）
- 是否有 owner：[是/否]
- 目标用途：[分层触达/推荐/防流失]

## 一、标签分级架构（一级域 7 个为基座，按业务增减）

- **一级业务域**：
  - 用户属性（基础：年龄/性别/地域/会员类型，定性·长期）
  - 渠道来源（公转私来源：包裹卡/AI外呼/公众号/小程序/裂变/直播/短信/异业）
  - 交易行为（公域购买：购买产品/下单频次/累计消费/复购/客单）
  - 行为统计（埋点衍生：登录/浏览/点击/加购/搜索/收藏/分享/参与/积分）
  - 偏好属性（产品偏好+行为偏好+促销敏感度）
  - 价值层级（用户分层 A+/A/B/C/D/S/T）
  - 关系链（社交/裂变/推荐人）
- **二级标签**（每域 3-5 个，按业务定）
- **三级标签值**（可量化枚举）

### 价值层级默认三级值（9 品牌强共识）
- A+ = 复购用户有频繁互动
- A = 首购成交有互动
- B = 有互动未下单有意向
- C = 有互动未下单无意向（发信息不回未删除）
- D = 不回复未删除
- S = 已删除（流失态）
- T = 同粉/内部账号

> 分桶适配原则：购买力/频次分桶按品类客单价定，不统一（美妆上限2000/纸品400/咖啡1000+）。

## 三、治理 SOP

- **打标主体制**：每标签执行 owner 到工具或人（网易云商渠道码/微盛CRM/SCRM批量/活动打标/导购手打/工具自动），非抽象双 owner
- **优先级与重要性**：建设优先级 P1-P4（P4范围外）；运营重要性 S/A/B/C
- **口径冲突仲裁**：同义标签按品类适配（消费金额分桶随客单价：美妆2000/纸品400/咖啡1000），非统一；定主源余者映射
- **上下线规则**：质量分≥0.6 且 人数>0（人数=0僵尸标签直接下线）上线；<阈值下线或重构
- **质量分**：覆盖率×0.4 + 准确率×0.4 + 时效性×0.2
- **标签-活动关联**：活动打标标签必关联 活动名+激励机制+更新方式
- **刷新节奏**：月度质量分复核 + 季度标签盘点
- **新标签准入**：业务需求+owner+口径+数据源+打标方式 齐全方可建

## 四、落地实施路线

| 阶段 | 动作 | 产出 | 验收标准 |
|---|---|---|---|
| 1 盘点 | 梳理现有标签+数据源，带人数 | 标签清单+数据源地图 | 人数=0 标僵尸待下线 |
| 2 设计 | 搭架构+字典+治理（一二三件套） | 四件套 | 口径三段式无模糊、有打标方式+优先级 |
| 3 打标 | 按标签类别定打标方式矩阵（见下） | 打标方式矩阵 | 每类别有打标方式+操作路径 |
| 4 验证 | 抽样校验准确率/覆盖率 | 质量分 | 质量分≥阈值、人数>0 |
| 5 上线 | 按 P1-P4+SABC 分批上线（非全上） | 上线标签集(分批) | 分批有排序 |
| 6 迭代 | 月度复核+季度盘点 | 复盘表 | 低分/僵尸下线、新需求补建 |
```
