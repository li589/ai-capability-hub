# 技能进化旁路 · 总则与边界

## 定位

本目录是 **模式 C · 技能进化旁路**：可选、默认关闭、须用户显式触发。  
**不**并入交底 Step 1–8，**不**并入通俗解读主流程。

目标：联网检索 + 官网抓取近期政策/审查动向 → 产出 **带时间戳的进化清单** → **人审确认后** 才允许改技能文件。

## 硬性禁止

- 无人值守自动改 `SKILL.md` / `prompts/**` / `references/**` 并提交。
- 产出或建议「欺骗审查系统 / 掩盖违法采集或歧视决策 / 对抗审查大模型提示词攻防」类内容。
- 把进化旁路挂进每次交底或解读的默认步骤。
- 仅凭自媒体、二手转述、无准确 URL 的传闻写入「建议改技能」项（证据等级须见 `research.md`）。

## 允许的进化方向（质量与合规硬化）

- 充分公开、创造性叙事、伦理/五条一款门禁
- 查新与差异化表述（假设智能语义检索更强）
- 附图/标记一致性、降低生成式套话观感
- 官方程序规则变更对交底/解读流程的影响

对外表述优先用 **「政策雷达 / 技能进化旁路」**，少用「规避对抗」。

交底定稿后的存在感：见同目录 **`soft_nudge.md`**（低频至多一句；不挂进默认 Step）。

## 人审闸门（所有进化 run 结束时必须出现）

```
本清单仅为草案，尚未改技能。
请回复其一：
- 「全部采纳」→ 再 Read apply_after_confirm.md，按勾选项改文件
- 「采纳 E10,E12,…」→ 只改对应编号
- 「全部搁置」→ 结束，不改技能
- 「沉淀到 docs/evolution/」→ 将本稿复制为可提交知识（仍不改 prompts）
```

未收到上述确认前：**禁止** Edit/Write 技能正文（清单落盘到 `outputs/evolution/` 除外）。
