# 技能进化旁路 · 检索与官网抓取

前置：已 Read `guardrails.md`、`intake.md`。

## 目标

收集 **近期**（默认近 12 个月）与专利审查相关的权威信息，尤其：

1. **审查工具**：国知局智能审查 / 大模型检索 / AI 助手等公开口径  
2. **申请客体与指南**：AI/大数据/算法特征、充分公开、创造性、伦理（五条一款）等  
3. **程序通识**：创造性评价、实用新型明显创造性等可能影响交底写法的规则  

每条进入清单的观点必须能对应到 **可点击的准确 URL**。

## 信源白名单（优先顺序）

| 优先级 | 域名/类型 | 说明 |
|--------|-----------|------|
| A | `cnipa.gov.cn` | 局令、公告、政策解读、媒体视点转载中的官方表述 |
| A | `gov.cn` 国务院公报等 | 转载的局令全文 |
| B | 国知局新闻发布会通稿（官网或新华社等权威转载且能核到原话） | 须保留原 URL |
| C | 律所/媒体解读 | **仅作线索**；采纳建议前须用 A/B 源复核；C 源不得单独支撑「改技能」 |

## 检索动作（须实际执行）

1. **`WebSearch`**：组合关键词，例如  
   - `国家知识产权局 专利审查指南 修改 人工智能`  
   - `国家知识产权局 大模型 智能审查`  
   - `CNIPA AI patent examination guidelines`  
   - 可加年份（当前年与上一年）  
2. **打开官网正文**：对候选 URL 用可用的页面抓取能力（如 WebFetch / `curl`）读取标题、发布/施行日期、关键段落。  
3. **拒绝**：无日期或明显过期且已被新局令替代、又无法说明仍有效的孤证；论坛帖、营销软文。

## 双轨标签（每条情报必标）

| 标签 | 含义 |
|------|------|
| `审查工具` | AI/大模型作为审查辅助 |
| `申请客体` | AI/算法相关发明的授权与撰写规则 |
| `程序通识` | 创造性、双申、实用新型审查等通用规则 |

## 证据等级

| 等级 | 定义 | 可否建议改技能 |
|------|------|----------------|
| A | 局令 /《专利审查指南》正文 / 官网公告 | 可以 |
| B | 国知局官网「政策解读」或负责人公开发言（可核 URL） | 可以（须注明解读非条文） |
| C | 媒体/律所二次解读 | 否（只可写在「背景」；须标「待官网复核」） |

## 抓取记录（内部可短记，清单正文用表）

对每个采用的 URL 记录：标题、发布或施行日、抓取日、标签、证据等级、一句话摘要。  
**摘要必须能被该 URL 正文支持**；不得脑补未出现的条款编号。
