# Playbook 案例

## 用户请求

“把我上传的 8 月工资表整理成正常工资薪金导入模板。没有的字段空着。”

## 虚构来源表头

`员工姓名｜证件类型｜证件号｜手机｜任职日期｜工资｜养老个人｜医疗个人｜失业个人｜个人公积金｜个人所得税`

## 执行

1. 读取 Excel 并识别人员行，排除合计行。
2. 将姓名、证件信息、手机、日期、工资和个人承担的养老、医疗、失业、公积金映射到模板。
3. 将来源不存在的大病医疗、免税收入、其他扣除等保持空白。
4. 因模板没有个人所得税列，不写入任何模板列，并在交付摘要中列为未映射字段。
5. 形成规范 JSON，运行 `scripts/validate_payroll_json.py`。
6. 复制模板，从 `Sheet1` 第 3 行写入人员数据，保持 `Sheet2` 不变。
7. 默认以源文件基础名追加 `-标准工资表.xlsx` 作为输出文件名。

## 预期交付摘要

“已生成 `8月工资表-标准工资表.xlsx`，共写入 2 名虚构人员。可选字段未提供的单元格均保持空白。来源字段‘个人所得税’在目标模板中没有对应列，未写入；未发现重复人员或无效金额。该文件仅完成格式转换，未重新计算工资或个税。”
