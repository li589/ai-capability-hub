# 测试案例与预期行为

开发和回归验证必须使用虚构人员与虚构证件号码，覆盖以下场景。

| 编号 | 场景 | 预期行为 |
| --- | --- | --- |
| T01 | Excel 使用模板原字段，所有必填项齐全 | 正确写入对应列，状态为 `ready` |
| T02 | 可确认的常见同义表头 | 按映射表写入并记录映射，不改变值 |
| T03 | 可读的单张工资表图片 | 仅用内置视觉能力提取并生成待复核数据 |
| T04 | 图片金额或证件号模糊 | 对疑似单元格留空并报告位置 |
| T05 | 只有个人社保合计 | K:N 保持空白，不拆分金额 |
| T06 | 只有实发工资 | G 列保持空白，实发工资列为未映射字段 |
| T07 | 缺少姓名、证件类型或证件号码 | 对应单元格留空并产生 `missing_required` |
| T08 | 证件类型不在模板枚举 | 保留原值并产生 `invalid_enum` |
| T09 | 减免事项不在 Sheet2 清单 | 保留原值并产生 `invalid_exemption_item` |
| T10 | 负数、非数字或超过上限的金额 | 保留原值并产生金额错误，不自动改写 |
| T11 | 同一姓名、证件类型和证件号码重复 | 两行均保留并产生 `duplicate_person` |
| T12 | 包含部门、工号和个人所得税 | 不新增模板列，列入未映射字段 |
| T13 | 文本以 `=、+、-、@` 开头 | 产生 `formula_like_text`，写入时强制文本格式 |
| T14 | 超过 3 名人员 | 扩展第 3 行格式和数据验证，模板结构不变 |
| T15 | 可选字段未提供 | 单元格保持空白，不填零或默认值 |
| T16 | 只有证件号码、没有证件类型 | C 列保持空白，不根据号码推断 |
| T17 | 姓名列为“合计”且证件标识为空 | 排除该汇总行，不计入人员数；产生 `summary_row_excluded` 信息 |
| T18 | 第二个非空工作表是加班表，主表外一人有非零加班补贴 | 扫描第二个工作表；新增该人员，将加班补贴写入“工资”，未提供字段留空并报告，不得漏人 |
| T19 | 主工资表标题明确“含加班”，补充表中同一人员也有加班金额 | 仅用于来源覆盖核验，不重复累计；匹配不确定时保留独立行并提示 |
| T20 | 上传文件名为 `工资表2.xlsx` | 默认输出文件名为 `工资表2-标准工资表.xlsx`；已带后缀时不重复追加 |
| T21 | 同一工作簿的主表和非零加班表属于不同工资期间 | 不跨期合并；分别生成对应期间的标准工资表，并确保加班人员未遗漏 |
| T22 | 证件类型为居民身份证，证件号码少于 18 位、前 17 位含字母、末位为小写 x 或中间含 X | 保留原值；产生 `invalid_resident_id_number`；D 列标黄；交付摘要说明格式要求 |
| T23 | 非空手机号码不是 11 位纯数字 | 保留原值；产生 `invalid_mobile`；E 列标黄；交付摘要说明格式要求 |
| T24 | 工资为非数字、负数或超过 99,999,999.99 | 保留原值；产生金额错误；G 列标黄；交付摘要说明格式要求 |
| T25 | 中国护照等非居民身份证类型的证件号码 | 不套用 18 位居民身份证规则；仍保留证件号码文本 |
| T26 | C 列为未知证件类型，D 列有证件号码 | C 列产生 `invalid_enum` 并标黄；D 列独立产生 `unverifiable_id_number` 并标黄，不因 C 列错误而跳过 |
| T27 | C 列为空，D 列有证件号码 | C 列产生 `missing_required` 并标黄；D 列独立产生 `unverifiable_id_number` 并标黄，不因 C 列缺失而跳过 |

## 交付验收

- 输出工作簿只有 `Sheet1` 和 `Sheet2`。
- `Sheet1` 前两行、21 列顺序及合并区域与模板一致。
- `Sheet2!A1:A25` 与模板一致。
- 规范 JSON 的人员数与输出人员行数一致。
- 每个非空来源工作表均已清点；来源覆盖清单中的非零工资性记录均已写入或列为待确认，不得静默遗漏。
- 所有缺失字段保持空白，所有来源零值仍为数值零。
- 证件号码和手机号码不使用科学计数法、不丢失前导零。
- 所有金额为数值单元格，日期显示为 `yyyy/mm/dd`。
- 所有 `level=error` 且可映射到模板列的字段均已在对应单元格标浅黄色 `#FFF2CC`，并在交付摘要中按行号、列名和原因列出。
- 无外部链接、宏、额外公式或第三方 OCR 请求。

- Python 语法编译通过。
