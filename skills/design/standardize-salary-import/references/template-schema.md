# 模板字段与格式

## 模板不变量

- 模板文件：`assets/normal-salary-import-template.xlsx`
- `Sheet1`：正常工资薪金明细。第 1—2 行为表头，第 3 行开始为人员数据。
- `Sheet2`：免税收入减免事项清单。保留 `A1:A25` 原值和原顺序，不得写入人员数据或修改清单。
- 保留工作表名称、顺序、合并单元格、列顺序、列宽、样式和数据验证。
- `Sheet1` 合并区域：`A1:A2`、`B1:B2`、`C1:C2`、`D1:D2`、`E1:E2`、`F1:F2`、`G1:G2`、`H1:H2`、`I1:I2`、`J1:J2`、`K1:N1`、`O1:O2`、`P1:T1`、`U1:U2`。
- 不新增“数据问题”“字段映射”等工作表；问题只在交付摘要中说明，以免破坏导入兼容性。

## 规范 JSON

输入校验脚本的顶层结构：

```json
{
  "rows": [
    {
      "name": "张三",
      "id_type": "居民身份证",
      "id_number": "11010119900101001X",
      "salary": "12000.00"
    }
  ]
}
```

未提供的键可以省略、写为 `null` 或空字符串。缺失与数值零含义不同；只有来源明确给出零时才写 `0`。

## 证件类型枚举

只接受以下原文：

- 居民身份证
- 中国护照
- 港澳居民来往内地通行证
- 中华人民共和国港澳居民居住证
- 台湾居民来往大陆通行证
- 中华人民共和国台湾居民居住证
- 外国护照
- 外国人永久居留身份证
- 外国人工作许可证（A类）
- 外国人工作许可证（B类）
- 外国人工作许可证（C类）

来源未明确证件类型时保持空白。即使证件号码看似居民身份证，也不得据此自动填写“居民身份证”。

## 写入规则

- 从 `Sheet1!A3` 开始按人员逐行写入，禁止写入第 1—2 行。
- 可解析金额写为真正的数值单元格，不写人民币符号或千分位文本。无法解析或不符合约束的来源值不得丢弃；保留为文本并在交付摘要中标记待确认。
- 证件号码、手机号码和其他标识写为文本。对以 `=、+、-、@` 开头的文本强制使用文本单元格，防止公式注入。
- 校验脚本返回的每个带 `field` 的 `level=error`，都必须标记对应模板单元格为浅黄色 `#FFF2CC`。不得用黄色替代交付说明；交付摘要必须列出输出行号、列名和错误原因。
- 超过预留的第 3—5 行时，把第 3 行的格式和数据验证复制到新增行，再写值；不得复制任何人员数据。
- 输出前确认只有 `Sheet1`、`Sheet2` 两个工作表，且 `Sheet2` 内容未变化。
