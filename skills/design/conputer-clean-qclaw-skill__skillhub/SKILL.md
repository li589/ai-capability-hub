# qclaw电脑清理技能
## 技能介绍
一款跨平台、高安全、全场景的电脑清理工具，专为qclaw平台开发，支持Windows、macOS、Linux三大系统，覆盖日常清理、开发工具清理、社交软件清理等全场景，敏感项增加二次确认机制，避免误删，同时实时计算并播报清理空间大小；适配qclaw文本交互，无需安装任何第三方依赖，开箱即用。

## 核心功能
### 一、安全清理（无需二次确认）
1. 系统临时文件：清理各系统临时目录，释放基础空间
2. 回收站/废纸篓：清空无用文件，不影响个人重要数据
3. 社交软件缓存：微信、QQ、钉钉缓存（图片、视频、文件缓存）
4. 浏览器缓存：Chrome、Edge、Safari、Firefox四大主流浏览器缓存
5. 迅雷缓存：清理迅雷下载缓存，释放存储空间
6. 开发工具缓存：pip、conda安装缓存，清理无用安装包

### 二、敏感清理（需二次确认，避免误删）
1. Docker清理：清理无用镜像、卷、构建缓存（可能删除未使用镜像，需确认）
2. Xcode缓存（macOS专属）：清理模拟器、构建文件、设备支持文件（巨占空间）
3. Homebrew缓存（macOS专属）：清理旧版本包、安装缓存
4. 桌面大文件：仅清理安装包、压缩包、镜像等临时文件，不删文档、图片

### 三、附加优势
- 跨平台适配：完美支持Windows、macOS、Linux，自动识别系统路径
- 安全无风险：仅清理垃圾文件，不触碰个人重要数据，权限不足自动跳过
- 文本交互：适配qclaw，全程文本提示、文本确认，无语音依赖
- 零依赖安装：基于Python标准库开发，无需安装任何第三方依赖，开箱即用
- 空间显示：实时计算清理大小，自动切换MB/GB单位，直观易懂


### 额外依赖（按需安装，非必需）
- Docker清理：需提前安装Docker并启动
- Xcode清理：仅macOS，需提前安装Xcode
- Homebrew清理：仅macOS，需提前安装Homebrew

## 安装方法（qclaw 用户使用说明）
1. 下载本技能包，解压后获取4个文件
2. 将 `computer_clean_skill.py` 文件复制到 qclaw 助手的 `skills` 文件夹中
3. 重启 qclaw 助手
4. 输入文本指令（如“帮我清理电脑垃圾”），即可启动清理，敏感项将提示输入“确认/取消”完成交互

## 文本指令大全
| 指令内容 | 功能说明 |
|----------|----------|
| 帮我清理电脑垃圾 | 执行全流程清理（安全项直接清，敏感项需文本确认） |
| 深度清理电脑 | 执行全流程清理，同“清理电脑垃圾” |
| 清理缓存 | 仅清理各类缓存（安全项，无需确认） |
| 清理Docker | 仅清理Docker相关垃圾（需文本二次确认） |
| 清理Xcode缓存 | 仅清理Xcode缓存（macOS专属，需文本确认） |
| 清理桌面文件 | 仅清理桌面临时大文件（需文本确认） |
| 清理浏览器缓存 | 仅清理四大浏览器缓存（无需确认） |
| 电脑加速 | 执行全流程清理，侧重释放空间、提升速度 |

## 安全说明
✅ 绝对安全：仅清理系统允许删除的垃圾文件，不删除个人文档、图片、视频、工作文件  
✅ 误删防护：敏感项强制文本二次确认，用户输入“取消”则跳过，避免误删重要内容  
✅ 权限容错：遇到权限不足的文件/目录自动跳过，不报错、不中断清理流程  
✅ 无后台常驻：仅在用户触发指令时运行，不常驻后台、不收集任何用户数据  
✅ 零依赖：无需安装任何第三方包，适配qclaw，开箱即用

## 常见问题
1. 清理失败？
   - 检查相关工具（如Docker、Xcode）是否安装并启动（按需）
   - 权限不足时，以管理员/root身份运行qclaw

2. 清理后软件无法使用？
   - 清理仅删除缓存，不影响软件本体，重启对应软件即可恢复

3. 如何查看清理详情？
   - 目前支持文本播报总清理空间，后续将新增明细播报功能
