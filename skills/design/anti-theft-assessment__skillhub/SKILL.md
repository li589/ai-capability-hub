# Anti-Theft Assessment — 防盗措施评估

Use when you need to evaluate home security weaknesses, get smart lock/camera recommendations, or design a burglar alarm system plan.
NOT for commercial security system design, law enforcement operations, or armored facility planning.

## 描述

评估家庭门窗等入侵薄弱点，根据户型、预算和风险等级推荐智能门锁、监控摄像头、报警系统等防盗方案，帮助用户构建分层次的居家安全防护体系，提升住宅安全等级。

## 重要限制（请提前告知用户）

- 安全评估基于用户描述，无法替代现场专业安防评估
- 设备推荐为通用方向性建议，具体品牌型号需用户结合市场情况选择
- 监控安装需遵守当地隐私法规（不可对准邻居/公共区域）
- 防盗措施降低风险但不能100%防止入侵，需结合保险等综合方案

**用户**: 经常出差，家里长时间没人怎么办？  
**助手**: 长期无人状态需要"存在感模拟+远程监控+报警联动"方案...

## 能力

- 评估门窗等物理入侵薄弱点并提出加固建议
- 推荐智能门锁（按预算/功能/安装条件分级）
- 规划监控摄像头布点方案
- 设计报警系统方案（本地报警/云端推送/联网报警）
- 提供长期离家的安全管理策略
- 推荐按预算分配的综合安防方案

## 执行步骤

### Step 1: 风险评估
了解楼层、户型、门窗类型、小区环境、过往安全事件，确定风险等级。

### Step 2: 薄弱点分析
逐一评估入户门、窗户、阳台、管道井等可能入侵点。

### Step 3: 方案设计
根据预算和风险等级推荐分层防护方案（物理防护+电子防护+管理措施）。

### Step 4: 实施指引
提供安装要点、注意事项和后续维护计划。

## 输出原则

- 按风险优先级排序建议，让用户知道先做什么
- 每个方案标注预算范围，便于用户量力而行
- 物理防护+电子防护+行为管理三层结合
- 兼顾安全性和便利性，过度防护影响日常生活
- 合法合规提醒贯穿始终

## 错误处理

| 异常场景 | 处理方式 |
|----------|----------|
| 用户描述不清楚门窗情况 | 提供自检方法引导用户补充信息 |
| 预算极低（<500元） | 推荐零成本行为措施+最低配置方案 |
| 出租房不能改装 | 推荐免安装/可拆卸设备方案 |
| 已发生被盗事件 | 建议先报警，再评估加固方案 |
| 监控涉及邻居隐私 | 明确告知法规要求，调整安装角度建议 |

## 常见问题（FAQ）

**Q: 智能锁安全吗？会不会被黑客攻击？**  
A: 正规品牌智能锁安全性优于A/B级机械锁。选购要点：C级锁芯+活体指纹+虚位密码。小黑盒问题主要影响早期低价产品。

**Q: 监控视频保存多久合适？**  
A: 家用建议7-30天循环。云存储方便但有月费；本地TF卡/NVR无月费但硬件可能被破坏。建议云端+本地双备份。

**Q: 一楼有必要装防盗窗吗？**  
A: 有必要，但注意：必须有逃生开口（消防要求），建议使用可内开式防盗窗或隐形防盗网。

**Q: 报警器误报太多怎么办？**  
A: 调低灵敏度、避免安装在风口/宠物活动区、选择双重触发机制（如红外+门磁同时触发才报警）。

**Q: 门锁换了但钥匙还给了中介/前任怎么办？**  
A: 换锁芯是最安全的做法（智能锁直接删除旧指纹/密码）。这是搬入新住所的第一件事。

**Q: 快递被偷怎么防？**  
A: 方案：可视门铃录像取证、设置快递柜代收、贵重包裹要求当面签收、和物业沟通放置位置。

## 最佳实践

- 构建"延迟+侦测+响应"三道防线，而非依赖单一设备
- 定期更换门锁密码（建议每3个月），智能锁定期查看开锁记录
- 离家前执行"关灯留灯-关窗锁门-开启布防"三步检查
- 与信任的邻居互留联系方式，异常情况互相通知
- 贵重物品分散存放，部分使用保险箱，办理家财险

## 不适用场景

| 场景 | 原因 | 建议替代 |
|------|------|----------|
| 商铺/仓库安防 | 需求和标准完全不同 | 联系专业安防公司 |
| 人身安全威胁 | 超出设备防护范围 | 立即报警，申请人身保护令 |
| 网络安全/信息防盗 | 非物理安防范畴 | 参考网络安全相关技能 |
| 公共区域监控 | 涉及公共隐私法规 | 物业/居委会统一规划 |

**常见误用**: 期望安装设备后绝对安全——防盗是系统工程，设备只是一环，需配合安全习惯和保险兜底。

## 安全与隐私

- 监控摄像头不得对准他人住宅或公共通道，遵守《个人信息保护法》
- 智能设备使用强密码，开启双因素认证，避免被远程控制
- 不在公开场合讨论自家安防配置细节
- 本评估不收集用户具体住址和户型图纸信息
