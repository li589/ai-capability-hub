# eMES 及配套系统服务器配置基线（知识库）

> 本文件为 `server-config-advisor` skill 的核心参考数据，包含：
> - 各系统单独安装的最低配置
> - 合装（同一台服务器）的配置叠加规则
> - 操作系统 / 数据库 / 磁盘 / 网络等硬性要求
> - 关键约束与注意项
>
> 数据来源：eMES《服务器配置.md》、鼎华《sMES7.0 项目服务器配置建议清单》（已脱敏）、飞书《部署要求-单机》，由产品团队确认。

## 一、涉及的系统

| 系统 | 说明 | 供应商 |
| --- | --- | --- |
| eMES | 制造执行系统（本系统） | 我方 |
| IIOT | 设备机联采集（配置数据 InfluxDB + 采集数据 PostgreSQL） | 鼎华 |
| ESB | 系统集成总线（自带 PostgreSQL） | 鼎华 |
| iPaaS | 低代码集成平台（单机部署，可用 PC） | 第三方/平台方 |

## 二、各系统单独安装最低配置

### 1. eMES（ap 与 db 不分离）

| 项目 | 配置 |
| --- | --- |
| 品牌 | DELL 或 Lenovo |
| 操作系统 | Window Server 2019R2 SP1 以上，或 Rocky 9（Linux） |
| 内存 | 32G 含以上（可扩充） |
| CPU | 8核16线程含以上，2GHz 含以上 |
| 硬盘 | 500G 及以上，转速 10Krpm，RAID 1 以上 |
| 网络 | 1GBits/sec |
| 磁盘规划(Windows) | C 盘＞128G（应用装非 C 盘）、D 盘≥500G、E 盘≥300G |
| 磁盘规划(Linux) | `/` ≥128G、`/opt` ≥500G、`/data` ≥300G |
| 数据库 | 低代码平台库 PostgreSQL + 业务库 MySQL 8.0+（utf8mb4、lower_case_table_names=0、mysql_native_password） |

**ap 与 db 分离时**：内存 16G、CPU 4核8线程，其余同。

### 2. IIOT（鼎华）

| 项目 | 配置 |
| --- | --- |
| 品牌 | DELL 或 Lenovo |
| 操作系统 | Windows 2019（64位）及以上；统一 Linux 方案时用 Rocky 9 |
| 内存 | 32G |
| CPU | 8核16线程，2GHz 以上 |
| 硬盘 | 1T 以上，10Krpm，RAID 1 以上 |
| 数据库 | 自带 InfluxDB（配置）+ PostgreSQL（采集），AP/DB 不分离 |

> 约束：设备＜50 台且采集频率＞3S 时，IIOT 可部署到 MES 的 AP 服务器（合装），否则单独部署。

### 3. ESB（鼎华）

| 项目 | 配置 |
| --- | --- |
| 品牌 | DELL 或 Lenovo |
| 操作系统 | 🔴 **仅 Windows 2019（64位）及以上，不支持 Linux** |
| 内存 | 32G |
| CPU | 8核16线程，2GHz 以上 |
| 硬盘 | 500G，10Krpm，RAID 1 以上 |
| 数据库 | 自带 PostgreSQL，AP/DB 不分离 |

> 约束：ESB 仅作 MES 与外部系统集成时，可部署在 MES 的 AP 服务器（合装）。

### 4. iPaaS（单机部署，可用 PC）

| 项目 | 配置 |
| --- | --- |
| 服务器【正式】 | 4核8线程（主频＞2.5GHz）+ 32G + 200G_SSD + 300G_SSD；推荐 6核12线程 + 64G |
| PC 机【正式/测试通用】 | Intel i5-9500 @ 3.0GHz（或同档）+ 16GB 内存 + 64 位系统 |
| 服务器【测试】 | 4核8线程（主频＞2.5GHz）+ 32G（最小 16G）+ 300G SSD |
| 操作系统 | Linux（CentOS 8 桌面版 或 Rocky 9）+ Docker + 向日葵 + 固定 IP |
| 网络 | 🔴 必须能访问公网 |

> 约束：
> - 🔴 300G SSD 是硬性下限，不能缩小
> - 🔴 不建议装虚拟机；ESXi 整机全虚拟化可考虑
> - 🔴 不建议与 eMES 同装一台服务器

## 三、合装方案（同一台服务器）

**叠加原则（产品团队确认）**：内存直接叠加，CPU 适当提升，硬盘适当提升。

| 方案 | 组合 | 内存 | CPU | 硬盘 |
| --- | --- | --- | --- | --- |
| A | 仅 eMES | 32G | 8核16线程 | 500G |
| B | eMES + IIOT | 64G | 16核32线程 | 2T |
| C | eMES + ESB | 64G | 16核32线程 | 1.5~2T |
| D | eMES + IIOT + ESB | 96G（建议 128G） | 24核48线程 | 4T |

**操作系统一致性**：
- 方案 A/B：Windows 或 Rocky 9 二选一
- 方案 C/D（含 ESB）：🔴 **必须整体采用 Windows**（ESB 不支持 Linux）

**合装适用前提**（不满足则建议独立部署）：
- IIOT：设备数量＜50 台且采集频率平均＞3S
- ESB：仅作为 MES 与外部系统集成使用

## 四、共享组件与数据库规划（合装时）

> 共用组件无需重复安装；独立数据库或独立实例隔离；账号密码可共用。详细安装步骤由实施文档另出。

| 组件 | 规划 |
| --- | --- |
| 操作系统 | 方案 A/B：Windows 或 Rocky 9 二选一；方案 C/D：仅 Windows |
| PostgreSQL（eMES 低代码库 / IIOT 采集 / ESB） | 共用一个引擎，建独立库：`db_emes`、`db_iiot`、`db_esb` |
| MySQL（eMES 业务库） | 单独实例（3306），账号密码可与 PG 共用 |
| InfluxDB（IIOT 配置） | 单独实例（8086） |
| Docker/向日葵/todesk（iPaaS） | iPaaS 不与 eMES 同装，不展开 |

**端口规划**：MySQL 3306、PostgreSQL 5432、InfluxDB 8086、iPaaS 操作页 8082（7003 回调 / 7004 测试 / 8085 连接流 / 9080 网关 / 7008 API 门户，视情况开放）。

## 五、注意事项（硬性约束）

1. 🔴 **ESB 不支持 Linux**：合装含 ESB 的方案必须 Windows
2. 🔴 **机器名不能含中文**：否则 MQ 安装失败
3. 🔴 **RAID 1 及以上**：10Krpm 转速（iPaaS 测试环境 300G SSD 不可缩减）
4. 🔴 **iPaaS 必须能访问公网**、固定 IP、不建议装虚拟机、不与 eMES 同装
5. 🔴 **同一台服务器内所有系统必须同一操作系统**，不可混装
6. 合装仅适用于中小规模（设备＜50 台、采集＞3S、ESB 仅集成），超出建议独立部署
