# 相关技能与组合用法

本技能（全量用户运营体系搭建）是「私域用户运营」域的时间轴经营层：父技能【私域用户运营】做**RFM 价值分层 + 画像 + 触达**（问「谁值多少、怎么对待」），本技能做**时间轴生命周期阶段 + 旅程 + 策略**（问「走到哪、往哪引」）。RFM 在本技能**正交引用、不重算**——R 仅作阶段转换的衰减信号，F/M 通过引用父技能结果进入价值维度，二者交叉成阶段×价值矩阵。【私域标签体系搭建】搭标签底座，【会员体系搭建】定等级权益。四者互补，可独立用、也可串成完整 SOP。

## 边界划分

| 维度 | 本技能（全量用户运营体系搭建） | 私域用户运营（父技能） | 私域标签体系搭建 | 会员体系搭建 |
|---|---|---|---|---|
| 回答的问题 | 用户走到哪、下一动作往哪引（时间轴阶段经营） | 谁是谁、值多少、怎么对待（价值分层与触达） | 怎么搭一套不腐烂的标签底座 | 怎么发积分、设几级、配什么权益、算不亏本 |
| 产出 | 阶段分层表 + 旅程图 + 阶段运营策略表（三件套） | RFM 分层表 + 画像卡 + 触达策略表（三件套） | 标签体系四件套（架构+字典+治理+路线） | 会员积分四件套（等级表+积分规则+权益矩阵+财务测算） |
| 分层维度 | **时间轴成熟度**（引入/成长/成熟/休眠/流失） | **价值轴**（RFM：最近消费/频率/金额） | 标签维度（事实/行为/预测） | 等级（成长值阶梯） |
| RFM 角色 | R 仅作阶段转换衰减信号；F/M **正交引用父技能结果不重算** | R/F/M 做分层算分主体 | RFM 是标签来源（行为/价值标签） | 等级门槛可引用 RFM 价值分层校准 |
| 新客处理 | 新客单独走引入期专属旅程，不并入 RFM 低价值（化解 RFM 对新客无效） | 新客无交易记录被 RFM 归低价值（局限） | 新客来源渠道是事实标签 | 新手积分（FIRST_PURCHASE 等）单独激励 |
| 独立可用 | 是 | 是 | 是 | 是 |

## 原语共享与咬合

- **RFM 结果 → 价值维度交叉**：本技能第 3 步引用父技能的 RFM 分层结果，交叉成阶段×价值矩阵（价值层收敛高/中/低三档），不重算 RFM。父技能问「谁值多少」，本技能问「这个高价值客现在走到哪个阶段、往哪引」。
- **阶段判定 ← 标签**：本技能阶段转换（R 超阈值→休眠/流失）可消费【私域标签体系搭建】的行为/预测标签（如活跃衰减、流失概率）。
- **成熟期高价值 ← 会员等级**：本技能成熟期高价值客的经营，可引用【会员积分体系】的等级与权益做权益配置（等级作价值维度引用）。
- **触达落地 → 父技能触达表**：本技能策略表给触点/内容/频次方向，成稿触达话术归父技能触达策略表（本技能不给话术）。

## 怎么组合

1. **先 RFM 价值分层、再生命周期分段、最后交叉（推荐完整 SOP）**：
   - 用父技能【私域用户运营】做 RFM 价值分层，看清用户价值分布
   - 用本技能：定义五阶段 + 转换条件，引用 RFM 结果交叉成阶段×价值矩阵
   - 用本技能旅程图 + 策略表：按阶段编排经营动作（成熟高价值防流失前置、休眠按 ROI 唤醒、流失仅高价值召回）

2. **只做生命周期（用户目标明确是「分阶段经营/定流失召回阈值」）**：
   - 直接用本技能三件套即可
   - 价值维度可先用高/中/低简化档，后续接父技能 RFM 结果校准

3. **已有体系、回流治理（流失率高/召回无 ROI/阶段定义一刀切）**：
   - 用本技能诊断现有方案（品类阈值错配/沉睡一刀切召回/三件套不咬合等异常）
   - 治理后把规整的阶段判定与召回漏斗反哺给父技能触达表与标签技能

## 一句话区分用户该用哪个

- 用户说「帮我把用户按价值分层、做差异化触达」 → 父技能【私域用户运营】（RFM 分层+触达）
- 用户说「分了层但每类挂什么指标、配什么权益、走什么触点不知道」/「做用户生命周期方案/定流失召回阈值」 → 本技能（全量用户运营体系搭建）
- 用户说「帮我搭一套标签底座/治理乱标签」 → 【私域标签体系搭建】
- 用户说「帮我从 0 设计会员积分体系/定等级设权益/算积分汇率预算」 → 【会员体系搭建】
- 用户说「私域用户经营整体做一版」 → 先父技能 RFM 分层 → 再本技能生命周期分段交叉 → 按需叠标签底座与会员体系
