# valuation-analysis 方法论

本文件是估值"内核"：反推当前股价 price in 的假设，并用历史分位校验估值锚。数据来源与停止规则见 SKILL.md。关键数据缺失时必须停止，不得用占位符、训练数据或外部搜索补齐。

## 估值分析

估值分析回答"现在贵不贵"。默认跑三件套：反向 DCF、历史估值分位、一致预期修正动量；用户只问其中一项时也要说明其它关键维度是否缺失。

### 反向 DCF

目的不是预测未来目标价，而是解出"要支撑当前市值，市场隐含了多高的 FCF / 净利复合增速"。

数据入口：

- `westock quote <code>`：当前市值、股本、PE/PB、股息率等。
- `westock finance <code> --limit 12`：经营现金流、资本开支、营收、净利、ROE、毛利率等。
- `westock consensus <code>`：A 股一致预期，用于对照隐含增速；港美股无数值化时降级。

计算骨架：

1. 取当前企业价值或市值作为现值 PV。
2. 固定 WACC（A 股权益成本默认 9%-11%，可按用户给定调整）与永续增长（默认 2.5%-3%）。
3. 反解未来 5-10 年 FCF 或净利需要的复合增速 `g_implied`，使 DCF 现值等于当前市值。
4. 对比 `g_implied`、近 3-5 年历史 CAGR 和可得一致预期增速。

判定：

- 🟢 **隐含低估**：`g_implied` 明显低于历史可持续增速，且基本面未恶化 → 市场预期保守。
- 🟡 **大致合理**：`g_implied` 接近历史或一致预期增速。
- 🟠 **预期偏高**：`g_implied` 高于行业可达增速，需要完美执行才能兑现。
- 🔴 **极端定价**：`g_implied` 远超历史峰值或行业天花板 → 高预期已透支。

净利为负、FCF 为负、现金流不稳或关键输入缺失时，标注"DCF 不适用"，切换相对估值或停止该项，不得硬套模型反推精确股价。WACC / 永续增长是假设，必须在产出中明示取值。

### 历史估值分位

目的：判断当前 PE/PB/EV band 在自身历史中处于什么位置。

优先数据入口：

- `westock quote <code> --date <历史日>`：多点取历史 PE/PB/股息率，覆盖近 3-5 年。
- `westock kline <code> --period day --start <日期> --end <日期>`：历史价格序列。
- `westock finance <code> --limit 12`：EPS、BVPS 或净利 / 净资产口径。

方法：

1. 优先用多个历史日期截面构建近 3-5 年 PE(TTM) / PB 序列。
2. 截面不足时，用 K 线价格配合对应报告期 EPS / BVPS 自算滚动 PE/PB。
3. 计算当前值所处分位：min、25%、中位、75%、max。
4. 分位必须与基本面配对看：低分位 + 基本面变差可能是价值陷阱，高分位 + 增速加速可能合理。

判定：

- 🟢 当前 PE/PB 处于近 5 年 **<25% 分位**，且 ROE / 增长未恶化 → 估值低估区。
- 🟡 25%-75% 分位 → 中性区。
- 🟠 / 🔴 **>75% / >90% 分位** → 估值偏高区，需有基本面加速支撑；>90% 为极端高位，需特别说明隐含预期。

关键校验：分位必须与基本面配对看——"低分位 + 基本面变差"是价值陷阱，"高分位 + 增速加速"可能合理。上市历史不足或样本覆盖不足时，可以给可得样本结论，但必须写明"历史样本不足、分位参考性有限"。

### 一致预期修正动量

目的：判断分析师预期是顺风还是逆风。

数据入口：

- `westock consensus <code>`：多期 EPS / 营收一致预期。
- `westock rating <code>`：评级和目标价趋势。
- `westock report list <code> --limit 10`：研报列表和密度。

方法：

1. 对比近 1 / 3 / 6 个月一致预期 EPS 或营收方向。
2. 统计评级上调 / 下调方向。
3. 临近或刚过财报时，提示一致预期可能尚未反映最新业绩。

判定：

- 🟢 **上修动量**：未来年度 EPS 一致预期持续调升、评级净上调 → 顺风。
- 🟡 预期走平。
- 🟠 / 🔴 **下修动量**：一致预期连续下调、评级净下调 → 逆风，谨慎抄底。

港美股无数值化 consensus 降级：用 `westock rating <code>` 和 `westock report list <code> --limit 10` 定性判断预期方向，禁止推算精确前瞻 PE。

### 估值分析交付物

1. 一句话定调：低估区 / 合理区 / 偏高区 / 极端定价。
2. 三件套结果表：

   | 工具 | 结果 | 关键数字 |
   |---|---|---|
   | 反向 DCF 隐含增速 | 🟢/🟡/🟠/🔴 | g_implied = X% vs 历史 CAGR = Y% |
   | 历史估值分位 | 🟢/🟡/🟠/🔴 | 当前 PE = X（近 5 年第 Z 分位） |
   | 预期修正动量（A 股） | 🟢/🟡/🟠/🔴 | 本年 EPS 一致预期近 3 月 +X% |

3. 假设披露：WACC、永续增长、分位区间、样本日期。
4. 数据来源和不构成投资建议声明。

## 估值修复

估值修复回答"低估值能不能向上 re-rating"。必须先确认估值处于历史低位；若低分位不成立，回退为普通估值分析。

### 三步判定

第 1 步：估值压制确认。

- 数据：`westock quote <code> --date <历史日>` 多点，必要时加 `westock kline <code> --period day --start <日期> --end <日期>` 和 `westock finance <code> --limit 12`。
- 低分位标准：当前 PE/PB 低于近 3-5 年 25% 分位，极端低位可看 10% 分位。
- 若当前分位大于 50% 或无法确认低分位，不适用估值修复，回退估值分析。

第 2 步：修复触发条件。

| 触发要素 | 数据入口 | 修复信号（🟢） | 陷阱信号（🔴） |
|---|---|---|---|
| 基本面拐点 | `westock finance <code> --limit 12` | 🟢 营收 / 利润环比回正，毛利率或 ROE 触底回升 | 🔴 持续恶化、亏损扩大 |
| 预期拐点 | `westock consensus <code>`、`westock rating <code>` | 🟢 一致预期由下修转走平 / 上修，评级净上调 | 🔴 一致预期持续下修，评级净下调 |
| 催化剂 | `westock notice list <code> --limit 10`、`westock report list <code> --limit 10`、`westock-finsearch query "<公司> 业绩预告 预增 预减 扭亏 首亏 催化剂"` | 🟢 有可核实的业绩、政策、订单、产品、回购等催化 | 🔴 只有传闻或无法核实正文 |

催化剂取证时，列表元数据只用于定位标题、时间和 ID；正文依据优先来自 `westock-finsearch query`，或 ID 已确认后的 `westock notice detail <id>` / `westock report detail <id>`。业绩预告必须保留预增、预减、扭亏、首亏等方向。

第 3 步：修复空间测算。

- 以历史中枢分位（中位数 PE/PB）或合理同业倍数作为修复目标。
- 修复幅度约等于（目标倍数 - 当前倍数）/ 当前倍数。
- 若盈利同步改善，单独列示 EPS 增长贡献，区分"仅估值回归"与"估值 + 盈利双击"。
- 必须披露目标分位或倍数的取值依据。

### 估值修复判定

- 🟢 **修复条件具备**：低分位 + 基本面拐点出现 + 预期由下修转上修 + 有明确催化 → 具备 re-rating 条件，标注修复空间区间。
- 🟡 **等待右侧信号**：低分位但拐点 / 预期尚未确认 → 估值便宜但缺催化，需等右侧信号。
- 🟠 / 🔴 **价值陷阱**：低分位但基本面持续恶化、预期持续下修 → 低估值是"应得的折价"，非修复机会。

### 估值修复交付物

1. 一句话定调：修复条件具备 / 等待右侧 / 价值陷阱。
2. 修复评估表：

   | 维度 | 信号 | 关键数字 |
   |---|---|---|
   | 估值压制 | 🟢/🟡/🔴 | 当前 PE/PB = X（近 5 年第 Z 分位） |
   | 基本面拐点 | 🟢/🟡/🔴 | 近 N 期营收 / 扣非净利 / 毛利率趋势 |
   | 预期拐点 | 🟢/🟡/🔴 | 一致预期近 3/6 月方向、评级净上调家数 |
   | 催化剂 | 🟢/🔴 | 具体催化事件 / 政策（引用 notice/report id） |

3. 修复空间：目标分位 / 倍数、修复幅度区间、是否叠加盈利增长（戴维斯双击）。
4. 假设披露、数据来源、日期范围和不构成投资建议声明。

## 工作流

1. 若用户给名称，先 `westock search <名称>` 拿 code；不唯一则让用户确认。
2. 按意图选择 `SKILL.md` 中的估值分析流程或估值修复流程。
3. code 确认后，并发拉当前行情、财务、一致预期、评级和历史分位样本。
4. 对每个工具 / 维度给 🟢/🟡/🟠/🔴 + 支撑数字；关键数据缺失则停止，不输出估值结论。
5. 汇总为估值定调或修复评估，不复述方法论全文。

## 使用示例

```bash
# 用户："茅台现在贵不贵，市场 price in 了多少增长？"
westock search 贵州茅台
westock quote sh600519
westock finance sh600519 --limit 12
westock quote sh600519 --date 2022-06-30
westock quote sh600519 --date 2023-06-30
westock quote sh600519 --date 2024-06-30
westock consensus sh600519
westock rating sh600519

# 用户："XX 估值被打到地板了，有没有修复空间，会不会戴维斯双击？"
westock search <名称>
westock quote <code>
westock quote <code> --date <历史日>
westock finance <code> --limit 12
westock consensus <code>
westock rating <code>
westock notice list <code> --limit 10
westock report list <code> --limit 10
westock-finsearch query "<公司> 业绩预告 预增 预减 扭亏 首亏 催化剂"
```

## 交付物规范

所有假设必须显式披露；分位、隐含增速、修复空间是客观锚，不是买卖信号。货币单位港美股不得用人民币符号。末尾标注"数据来源：westock-data（腾讯自选股行情数据接口）；非结构化内容：westock-finsearch"，并注明日期范围与报告期；输出必须包含不构成投资建议声明。
