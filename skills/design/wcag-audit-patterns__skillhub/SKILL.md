# WCAG 审计模式

遵循 WCAG 2.2 指南对 Web 内容进行审计的综合指南，附带可操作的修复策略。

## 使用此技能的时机

- 进行可访问性审计
- 修复 WCAG 违规问题
- 实现可访问性组件
- 为可访问性诉讼做准备
- 满足 ADA / Section 508 要求
- 达到 VPAT 合规标准

## 不要使用此技能的时机

- 需要法律建议或正式认证
- 只需要快速自动扫描而不需要人工验证
- 无法访问 UI 或源代码进行修复工作

## 操作说明

1. 运行自动扫描（axe、Lighthouse、WAVE）收集初步发现。
2. 执行人工检查（键盘导航、焦点顺序、屏幕阅读器流程）。
3. 将每个问题映射到 WCAG 标准、严重等级和修复指导。
4. 修复后重新测试，记录残余风险和合规状态。

详细模式、检查清单和模板请参考 `resources/implementation-playbook.md`。

## 安全注意事项

- 未经专家审查，避免声称法律合规性。
- 保留测试步骤和结果证据，以便审计追踪。
