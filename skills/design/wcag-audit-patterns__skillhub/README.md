# WCAG 无障碍审计

- 唯一标识：`hub-wcag-audit-patterns`
- 显示名称：WCAG 无障碍审计
- 能力摘要：结合自动扫描和键盘、焦点、读屏器等人工验证审计 WCAG 2.2，输出可修复问题、复测证据与剩余风险，不替代正式法律认证。

## 案例素材

1. 新结账页要满足键盘操作。该 skill 会测试焦点顺序、跳过链接、弹窗陷阱和提交错误提示，逐项对应 WCAG 条款。
2. 设计系统色彩对比不足。该 skill 会扫描后手工检查文本、状态和图标的对比度，修复令牌并复测不同主题。
3. 企业客户索要 VPAT 材料。该 skill 会保留测试步骤、问题状态和残余限制，为专业评估提供证据。
