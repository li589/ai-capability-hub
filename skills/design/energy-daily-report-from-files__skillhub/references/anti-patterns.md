# 反模式与正确做法

这些是生成能源管理系统时不能出现的典型错误。重点不是“代码长不长”，而是能力是否真实、状态是否诚实、数据是否可追溯。

## 一、交付形态错误

| 反模式 | ❌ 错误 | ✅ 正确 |
|---|---|---|
| 只分析不交付 | 用户明确要完整系统，最后只有字段分析报告 | 在同一次完整任务中继续完成映射、实现、测试和 ZIP |
| 只给静态 HTML | 页面按钮只做前端假交互，没有数据库和后端 | 交付可运行 Web/API + 数据库 + 完整源码 |
| 用桌面版冒充局域网 Web | 用户要多人局域网系统，却只给 Tkinter | Web 为主交付；桌面版只在明确要求时附加 |
| 用简化新程序替换旧系统 | 用户要求修改已有完整系统，却丢掉原备份、权限、历史兼容 | 做差异分析并在原完整能力上增量修改 |

## 二、状态与证据夸大

| 反模式 | ❌ 错误 | ✅ 正确 |
|---|---|---|
| 有构建脚本就说已有 EXE | 看到 `build_exe_windows.py` 就写“EXE 可直接双击” | 只有 ZIP 真有 EXE 才写“已包含”；真机运行后才写“已验证” |
| 未配置接口冒充实时 | 接口为空却显示“实时数据正常” | 明确显示“未配置” |
| 原型冒充正式系统 | 无真实文件却给出“历史趋势”“真实目标达成率” | 原型标记 demo/待确认，不伪造真实业务数值 |
| 模板验收当真实验收 | 验收 JSON 全部 passed，但无命令/退出码/证据 | 每个 passed 必须来自真实测试输出 |

## 三、业务数据与计算错误

| 反模式 | ❌ 错误 | ✅ 正确 |
|---|---|---|
| 写死业务值 | 在代码里直接写固定电价、目标、倍率 | 从用户资料映射并记录来源与版本 |
| 静默合并关键字段 | 把“产量”“合格产量”“入库量”都映成同一分母 | 关键冲突进入待确认，保留来源证据 |
| 重复导入 | 同一批数据中断重跑后重复写入 | 文件指纹 + 业务主键 + 批次幂等 |
| 零分母造假 | 产量 0 时把单耗显示为 0 | 显示“—/不可计算”，保留原始值 |
| 金额用 float | 产生二进制浮点尾差 | Decimal + 明确舍入规则 |
| 看板与导出口径不同 | 两处使用不同计算 SQL | 调用同一后端指标服务 |

## 四、权限、审批与审计错误

| 反模式 | ❌ 错误 | ✅ 正确 |
|---|---|---|
| 只在前端隐藏按钮 | 后端接口仍可越权访问 | 每次读写后端校验角色、动作和数据范围 |
| 固定套审批模板 | 所有业务都强制“管理员审批/退回” | 按用户真实蓝图配置，可无多人审批但保留必要审计 |
| 跳过状态追溯 | 直接改数据库状态，不记操作者 | 通过工作流/状态服务记录前后值、时间、理由 |

## 五、文件、安全与运行错误

| 反模式 | ❌ 错误 | ✅ 正确 |
|---|---|---|
| 参考 ZIP 不检查直接展开 | 压缩包损坏到一半才失败并留下半成品 | 先做 ZIP/CRC/路径/核心文件健康检查，再 staging 展开 |
| 绕过安全策略 | 关闭防火墙、UAC、Gatekeeper 或隐藏脚本窗口 | 只按企业 IT 规则配置本项目需要的权限/端口 |
| 全局结束 Python | 停止脚本用 `taskkill /IM python.exe` | 只停止本项目记录的 PID/实例 |
| 保留敏感密钥 | 把真实密码、token、secret 打进 ZIP | 排除凭据，使用配置位和首次设置流程 |
| 静默联网安装 | 运行时自动从公网下载依赖 | 离线依赖需显式提供并校验 SHA-256 |

## 六、源码完整性错误

独立程序或 Web 后端不能用“行数”作为唯一完整性标准。错误做法是规定某个文件必须超过固定行数；正确做法是验证所需能力是否存在且能通过自检，例如：数据库初始化、CRUD、计算、导入导出、备份、完整性检查、UI 启动入口等。

如果一个独立程序只有几百行但功能完整、测试真实，可以成立；如果有上万行但只是复制或占位，同样不合格。

## 七、版本和打包错误

| 反模式 | ❌ 错误 | ✅ 正确 |
|---|---|---|
| 版本号散落不一致 | 元数据、文档、构建状态使用不同版本 | 用 `validate_version_consistency.py` 做单一版本源校验 |
| 哈希清单过期 | 修改文件后未重算 `FILES_SHA256.txt` | 每次发布前重新生成并覆盖全部交付文件 |
| 最终 ZIP 未独立复测 | 目录里能运行，打包后丢了资源 | 解压到新目录复测核心源码、模板、静态资源和构建文件 |
