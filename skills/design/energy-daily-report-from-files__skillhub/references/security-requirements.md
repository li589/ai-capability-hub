# 安全要求

## 输入

原件只读；限制格式、大小和数量。ZIP 拒绝绝对路径、盘符和 `..`，限制成员数、单项大小、总解压量和压缩比。不执行宏、外链、嵌入对象、公式代码或用户脚本；禁止 `eval()`。

## Web 与数据库

- 随机临时管理员密码，首次登录强制改密；密码安全哈希。
- CSRF、HttpOnly、SameSite、登录限速和会话失效。
- 前后端权限与数据范围同时生效；403/409 语义稳定。
- 参数化 SQL、WAL、外键、短事务、迁移、备份和审计。
- 关闭 Flask Debug 和 Werkzeug 调试器，使用 Waitress。

## 运行时安装

运行时辅助采用 `verify-only`：只验证用户或 IT 预先放入的 Python 官方安装包文件名、SHA-256 和发布者签名，不联网下载、不启动安装器、不申请管理员权限。安装动作必须由用户或 IT 在系统标准界面中手动完成。依赖只从带哈希清单的离线 wheels 安装；获取 wheels 属于 IT 的受控准备工作，不由技能脚本执行。

## 故障

普通用户看到稳定错误码、中文原因、日志位置和解决步骤；日志可含技术详情但必须脱敏。安装或依赖失败不得修改业务数据库。
