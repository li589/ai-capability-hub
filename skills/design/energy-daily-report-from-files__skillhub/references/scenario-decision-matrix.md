# 复杂与非标准场景判断矩阵

## 快速判断

先运行：

```text
python scripts/classify_scenario.py "用户的业务描述"
```

根据输出执行，不靠尝试碰运气：

| 结果 | 含义 | 动作 |
|---|---|---|
| supported_standard_scenario | 单一标准场景 | 直接进入完整生成闭环 |
| supported_combined_scenario | 两个及以上场景组合 | 建立统一蓝图和共享主数据，不拼接孤立系统 |
| supported_after_confirmation | 可生成，但关键边界需确认 | 只阻止相关正式导入，其他工作继续 |
| supported_with_prohibited_automation_removed | 场景可做，但包含禁止自动决策 | 改为人工审批、预警和审计 |
| not_supported_as_requested | 只有高风险自动决策要求 | 拒绝自动执行，提供合规替代流程 |
| needs_business_description | 描述过于模糊 | 询问最少业务信息，不生成空壳 |

## 组合场景示例

### 生产 + 质量 + 设备

适用。建立共享组织、班次、生产线、产品、人员和附件；生产异常可创建质量问题或维修任务，但状态和权限分别管理。看板提供产量、不良、停机的关联分析，不把三套数据库简单拼接。

### 库存 + 采购 + 质量检验

适用。收货后进入待检，检验通过后才可转可用库存；采购建议不等同于自动下单，付款保持外部授权和人工审批。

### 安全巡检 + 设备维修 + 会议任务

适用。隐患可创建维修单和会议待办；安全联锁异常只能上报、隔离和审批，不能由系统自动关闭。

### 考勤 + 培训 + 岗位资格

适用但需确认敏感数据和权限。只展示岗位覆盖和到期提醒，不自动作出人事处分。

## 需要确认的复杂边界

遇到以下信息时不能靠默认值猜测：

- 金额：币种、税口径、精度、审批额度；
- 多公司：组织隔离、跨公司查询、超级管理员范围；
- 跨部门审批：顺序、会签/或签、退回和代理；
- 身份证/薪资：合法用途、脱敏、保留期限、访问审计；
- 电子签名：身份认证、证据保全和法律效力；
- 实时采集/外部接口：真实接口合同、凭据、超时、重试、补偿和联调证据。

## 不适用或必须改造

- 自动付款、自动采购下单；
- 自动质量放行或报废决定；
- 自动人事处分；
- 关闭安全联锁；
- 绕过权限、审批、UAC、Gatekeeper 或企业策略；
- 仅凭模糊需求生成静态演示并声称完整系统。

这些需求可改造成“记录 + 预警 + 人工审批 + 审计 + 外部系统确认”的合规流程。
