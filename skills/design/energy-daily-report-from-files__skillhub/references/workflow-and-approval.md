# 工作流与审批

## 状态机

每个流程明确起始状态、允许转换、终止状态、执行权限、必填理由和副作用。任何页面按钮和 API 都调用同一转换服务，禁止直接改状态字段。

## 审批规则

- 草稿可编辑；提交后按蓝图逐级审批。
- 退回必须填写原因并回到明确状态。
- 已批准记录再次修改时，保留修改前后值、原因和原审批链；需要时重新审批。
- 跳级、代审、撤回、加签必须由蓝图明确，不得自行推断。
- 越权返回 403，过期版本返回 409。

## 高风险边界

系统不得自动执行质量放行、安全许可、停线、报废、付款、采购下单、人事处分等具有审批效力的决定。可生成待审批记录和提醒，但最终决定须由授权人员完成并留下证据。
