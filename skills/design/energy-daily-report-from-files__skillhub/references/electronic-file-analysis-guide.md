# 电子档分析指南

## 支持格式

支持 xlsx、xlsm、csv、tsv、docx、pdf、txt、md 和 zip。先运行安全检查，再做结构识别；损坏、加密、空文件或不安全 ZIP 不计为有效输入。

## 分析层次

1. 文件层：路径、格式、大小、SHA-256、可读性、安全提示。
2. 结构层：工作表、表头、表格、段落、页码、字段、日期、单位、公式、合并单元格。
3. 业务层：实体、业务主键、组织范围、状态、审批、指标、导入关系。
4. 证据层：每个结论关联源文件和位置，标记 confirmed/candidate/derived/unknown。

## 格式注意

- Excel：读取公式和缓存值但不执行宏、外链或嵌入对象；保留编码前导零。
- CSV/TSV：识别 UTF-8/GB18030、分隔符、引号和列数变化。
- DOCX/PDF：区分正文、表格、页眉页脚和扫描图像；OCR 结果必须标记置信度。
- ZIP：只读取白名单电子档，不递归无限解压，不把程序文件当业务数据执行。

## 优先级

安全与真实证据高于便利。用户明确描述决定业务目标；电子档决定可验证字段与历史数据；两者冲突时列入待确认，不能静默覆盖。
