# 三分钟上手

这份文档只保留最短路径。需要完整触发规则看 `trigger-and-mode-guide.md`，需要故障处理看 `faq-and-troubleshooting.md`。

## 第一分钟：选模式

### 有真实资料，要完整系统

```text
根据我上传的文件生成完整能源日报本地部署 ZIP，保留完整源码、成对启停、备份恢复和 EXE 构建源码。
```

### 有旧系统，要在原系统上改

```text
以我上传的旧系统 ZIP 为基础，按新资料增量修改并重新交付完整 ZIP。
```

### 只想先分析

```text
只分析这些文件，先不要生成系统。
```

### 没有真实资料，只想先看原型

```text
先按我的业务描述生成可评审原型，未确认内容标记待确认，不要虚构真实历史数据。
```

## 第二分钟：技能会连续完成什么

完整系统模式默认执行：

`基线健康检查 → 用户文件安全分析 → 场景识别 → 字段映射 → 业务蓝图 → 完整 Web 系统改造 → 数据导入/初始化 → 测试 → 备份恢复自检 → 源码/EXE 构建源码校验 → ZIP → 独立解包复测`

用户不需要先理解内部脚本。无法确认的关键口径集中写入待确认项，其余继续完成。

## 第三分钟：拿到 ZIP 后怎么用

普通用户只看最终 ZIP 根目录：

1. `00_请先看_交付导航.md`
2. Windows 一键启动
3. Windows 一键停止

如果 ZIP 实际包含已验证 EXE，导航会明确写出；否则按 Python 启动或交给 IT 构建 EXE。

遇到问题时：

```text
python scripts/quick_check.py .
```

需要更详细恢复点时：

```text
python scripts/diagnose_and_resume.py .
```

## 发布前额外检查

技能包自身可先执行：

```text
python scripts/ensure_full_lan_energy_system.py --check-only
```

正式验收再执行深度校验，而不是让普通用户一开始面对全部脚本。
