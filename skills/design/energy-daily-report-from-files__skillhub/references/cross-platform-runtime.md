# 跨平台运行

生成系统的启停入口必须**成对交付**：Windows 同时提供 `start_windows.bat` 与 `stop_windows.bat`；macOS 若支持服务端运行，则同时提供启动与停止入口。停止器必须使用与启动器相同的 PID/状态记录，只停止当前项目实例，不得全局结束 Python 进程。

## 启动顺序

启动器应按顺序：

1. 检测 Python 3.10+ 或已验证 EXE；
2. 检查项目依赖是否可用；
3. 在需要时使用已准备、已校验的离线依赖，不得静默联网；
4. 执行启动前自检；
5. 检查/选择端口；
6. 启动正式服务并输出本机与局域网访问地址。

## Python 缺失

如果没有已验证 EXE，且电脑没有符合要求的 Python，技能只能提供**手工安装引导和安装包校验步骤**，不能自动下载、自动执行安装器、自动申请管理员权限或绕过企业策略。

如企业提供离线 Python 安装包，应核验文件名、SHA-256 和发布者签名；用户或 IT 在标准系统界面中完成安装。

## 真机证据

未在对应操作系统执行时不得写“已通过”。验收证据分别记录 Windows、macOS、WPS/Office、EXE 的环境、命令、退出码和日志摘要。

## 独立 PY 能源日报（按需）

只有用户明确要求桌面版时才附带 `standalone/energy_daily_report.py`。它使用 tkinter 与 SQLite，不依赖 Web 服务；Windows EXE 由 `standalone/build_exe_windows.py` 显式构建。未提供或未测试对应平台构建产物时不得声称已打包验证。
