# 用户提示词：按需求选择一种

## A. 生成完整本地部署能源日报系统

上传能源相关 Excel、CSV、Word、PDF、TXT 或已有资料后复制：

> 使用 `$energy-daily-report-from-files`。请读取我上传的全部能源业务文件，以这些文件中的真实字段、组织、产线、能源类型、表计、单位、倍率、目标、价格、计算规则和历史数据为准，生成一个**完整可本地部署的中文能源日报 Web 局域网系统**。
>
> 最终必须在本次任务中生成并交付一个可下载的**单根目录 ZIP**，不要只给代码片段、说明、HTML 或方案。ZIP 中必须保留完整 Python 源码、templates、static、数据库/业务计算、Excel 导入导出、端口配置、成对的一键启动/停止、备份恢复工具，以及把完整 Web 系统构建成 Windows EXE 的 `exe_entry.py`、`build_exe_windows.py`、spec 或等价源码。
>
> 生成前先只读检查技能内置完整局域网基线和我上传的文件。无法可靠判断的关键业务规则集中写入 `ASSUMPTIONS.md`，不要静默猜测。参考基线只用于完整代码架构，不能把其中的生产业务值复制成我的真实数据。
>
> 生成后执行语法、数据库完整性、关键接口、导入导出、幂等、权限/审计、备份恢复、启停与 ZIP 独立解包检查。ZIP 根目录生成 `00_请先看_交付导航.md`、`DELIVERY_STATUS.json`、`PY_SOURCE_MANIFEST.json` 和 `FILES_SHA256.txt`。
>
> 如果当前环境没有 Windows 真机构建和运行证据，只能写“提供了可构建 EXE 的源码”，不得声称“EXE 已验证”。

更短版本：

> 根据我上传的文件生成完整能源日报本地部署 ZIP，保留完整 Python 源码、成对一键启停、备份恢复和 Windows EXE 构建源码。

## B. 修改已有系统

> 使用 `$energy-daily-report-from-files`。以我上传的旧系统 ZIP 为基础，结合新的能源业务资料做**增量修改**。先比较旧系统和新需求，保留仍有效的原功能、历史兼容、启停、备份、Web 前端和完整源码；只修改、新增或删除确有依据的部分。不要用简化程序替换完整旧系统。完成迁移/兼容检查和测试后重新交付完整 ZIP，并附“保留 / 修改 / 新增 / 删除”的变更摘要。

> 使用 `$energy-daily-report-from-files`。只分析我上传的文件，输出字段字典、候选映射、业务规则、单耗/目标/成本口径、冲突、待确认项和数据质量问题，先不要生成系统 ZIP。
