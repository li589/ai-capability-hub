# 启动与离线安全模板

这些模板供技能生成最终 Python 项目时使用。默认原则是：启动器只运行本地代码，不下载解释器或依赖，不启动安装器，不申请管理员权限。

最终系统包含：

- Windows 和 macOS 成对的一键启动/停止脚本；
- Python 安装包只读验证脚本；
- `config/python-runtime.json` 验证配置；
- 离线依赖规划、安装和启动前自检脚本。

安全启动流程：

1. 检查本机是否已有 Python 3.10 或更高版本；
2. 若没有，显示中文提示并停止，由用户或 IT 手动安装；
3. 验证脚本只检查预置官方安装包的安全文件名、SHA-256 和发布者签名；
4. 创建项目虚拟环境；
5. 只从带 SHA-256 清单的本地 wheels 安装依赖；
6. 执行只读启动前自检，再启动系统。

联网准备离线 wheels 必须由用户在受控环境显式授权。任何网络失败、依赖缺失或校验失败都必须停止，不修改业务数据库。

- `stop_windows.txt`：Windows 一键停止模板；
- `stop_macos.txt`：macOS 双击停止入口模板；
- `stop_macos.sh`：macOS 停止实现模板。

要求：停止模板必须调用项目自身的 `stop_server.py`（或等价项目级停止逻辑），只停止本项目 PID，不得结束系统中的其他 Python 进程。
