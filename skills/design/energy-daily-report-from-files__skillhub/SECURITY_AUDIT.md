# V1.7.0 技能安全与专业性审计报告

## 结论

风险等级：**低风险（可交付）**。静态发布闸门目标是禁止联网下载、自动安装、提权、绕过企业安全策略和动态执行用户内容。

V1.7.0 在原有离线与真实性控制上新增“完整局域网基线生成前健康检查”：基线 ZIP 在写入业务项目之前先做可读性、CRC、安全路径、重复路径、符号链接样式成员和核心文件校验，并先展开到临时 staging 目录。这样可更早阻断损坏或异常基线，降低半成品写入风险。

## 已核验控制

- 支持 xlsx、xlsm、xls、ods、csv、tsv、docx、pdf、txt、md、zip；损坏、空白、加密或结构异常输入不能冒充有效数据。
- 用户 ZIP 拒绝路径穿越、绝对路径、盘符、异常成员、超大总量和危险压缩结构。
- 内置完整局域网基线可通过 `ensure_full_lan_energy_system.py --check-only` 做只读健康检查；实际展开先 staging 验证。
- 不执行宏、公式代码、外部链接、嵌入对象、用户脚本或任意表达式。
- 真实用户文件始终优先于参考基线业务值；原型模式的 demo 数据不得冒充真实生产数据。
- 能源蓝图校验覆盖表计主键、单位/倍率、单耗分母、目标、组织范围、权限、工作流、零分母、幂等和接口真实性。
- Python 依赖安装只允许已校验离线包；禁止静默在线回退、软件源切换、自动提权或关闭安全策略。
- EXE 构建源码与 EXE 二进制、Windows 真机构建、Windows 真机运行四种证据状态严格分离。
- 完整 Web 系统备份使用 SQLite backup API、完整性检查、恢复前停服确认和覆盖前回滚副本。
- 一键启动/停止必须使用同一项目 PID/状态，不得全局结束其他 Python 进程。
- 响应式 Web 是默认局域网主界面；Tkinter 独立程序仅按需附加，不作为 Web 主系统替代。
- 独立桌面模板仍保留参数化 SQLite、Decimal、业务主键、备份、完整性检查和 `--self-test`。
- 增值报告只读取真实蓝图和只读数据库；无真实数据时不制造指标数值或趋势结论。
- 明确禁止自动付款、自动采购下单、自动质量放行/报废、人事处分、安全联锁关闭和绕过企业安全策略。

## 专业边界

- 能源成本、目标、碳相关结果取决于用户确认的单位、倍率、价格、边界和口径。
- 本技能不构成法律、税务、会计、碳核算或电子签名合规意见。
- 外部接口未配置或未联调时必须明确写“未配置/未验证”。
- 无真实业务文件时可以做 prototype，但不能声称完成真实历史映射或生产验收。
- 未完成 Windows/macOS、WPS/Office、EXE 或外部接口真机测试时必须标记未执行。

## 发布前要求

1. `python scripts/validate_version_consistency.py .`
2. `python scripts/validate_security_posture.py .`
3. `python scripts/test_skill_scripts.py`
4. `python scripts/ensure_full_lan_energy_system.py --check-only`
5. 将完整局域网基线展开到临时目录并运行 `validate_full_lan_delivery.py`
6. 独立桌面模板运行 `--self-test`，仅用于验证保留的可选能力
7. 重新生成 `FILES_SHA256.txt`
8. 生成单根目录 ZIP，并在新目录独立解包复测
