# 平台评测针对性改进说明

本版本按平台反馈优先补强最低分的十项，同时保留原有完整 Web、源码、EXE 构建、备份恢复、安全和离线交付能力。

| 优先项 | 本次改进 |
|---|---|
| 文档质量 | 新增端到端案例、触发方式总表、能力边界总表、可靠性手册；统一 Web/桌面/EXE 表述 |
| 触发方式 | 新增 6 种模式和优先级，提供可直接复制的触发句，明确“分析后生成”和“只分析”的区别 |
| 反模式与 FAQ | 扩充用户常见启动、局域网、EXE、导入、备份、数据不足等问题；修正不合理示例 |
| 创造力与增值 | 新增旧系统差异摘要、原型模式、数据口径冲突输出、验收/迁移辅助输出 |
| 异常处理 | 增加内置局域网基线只读健康检查、明确恢复路径和错误级别 |
| 运行稳定性 | 基线展开前校验 CRC/安全路径/核心文件，并先展开到 staging 再复制；补可靠性运行手册 |
| 能力边界 | 将完整、原型、可构建 EXE、已验证 EXE、接口未配置等状态集中成表 |
| 渐进式披露 | START_HERE 改为“30 秒选入口 → 普通用户 → IT → 开发 → 深度文档”的分层结构 |
| 结构清晰 | 新增按角色文件地图，明确普通用户不需要阅读 vendor 和全部源码 |
| 开箱即用度 | 增加一句话入口、现有系统修改入口、无真实文件原型入口、基线健康检查和启动故障最短路径 |

## 兼容性原则

- 不删除原有脚本、模板、安全规则、完整源码基线或离线依赖；
- 默认主交付仍是中文浏览器 Web 局域网系统；
- 独立桌面版仍保留，但只在用户明确要求时附加；
- 真实用户文件始终优先于参考基线中的业务值；
- 没有真实文件时允许做评审原型，但禁止冒充真实生产数据；
- EXE 只按真实证据等级描述。
