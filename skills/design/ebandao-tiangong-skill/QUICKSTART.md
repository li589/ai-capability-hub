# QUICKSTART — 30 秒上手 天工.skill

## 30 秒示例：创建一个税务顾问

**用户输入**：

> "帮我创建一个税务顾问智能体"

**Agent 自动完成 J1→J5 全流程**：

| 步骤 | 动作 | 产出 |
|------|------|------|
| **J1 需求萃取** | 提取岗位名称、部门、核心职责 | 需求卡：税务顾问 / 财务部 / 筹划+合规+风险 |
| **J2 模板填充** | 套用 `examples/job-template.md`，逐字段填充身份5字段、DO/DON'T、KPI | 完整模板骨架 |
| **J3 技法注入** | 升级关键规则（合规/流程/质量/沟通四组）、沟通风格标签化 | 充实后的高质量内容 |
| **J4 质量内控** | 5维评估 + 2个压力场景验证 + `verify-skill.py` 结构校验 | 通过/回退标记 |
| **J5 交付** | 输出完整 SKILL.md 到 `output/` 目录 | 最终文件 |

最终产出包含：身份与记忆（"企业税务筹划与合规风险管理专家"）、核心使命+反使命、DO（标注税法条款、对比≥2路径）和 DON'T（不隐瞒收入、不拆分避税）、3 个结构化交付物模板、5 步工作流、3 个可量化 KPI、风险警示型+量化对比型沟通风格。

完整端到端示例（含需求卡、规则筛选矩阵、交付物）见 `examples/tax-advisor-example.md`。

## 两种范式：什么时候用哪个？

### 人物蒸馏 — 当你要"模仿一个人"

**触发条件**：用户提到了具体人名，要求创建"XX 风格的智能体"。

> "做一个芒格视角的投资分析助手"
> "帮我蒸馏乔布斯的产品思维"

**流程**：蒸馏 0（需求澄清）→ 蒸馏 1（多源信息采集）→ 蒸馏 2（心智模型提炼）→ 蒸馏 3（结构化构建）→ 蒸馏 4（质量验证 + 压力测试）→ 蒸馏 5（交付）。Gate 1/2/3 硬门禁在蒸馏 1/2/4 末端。

**核心产出**：3-7 个心智模型（必须有跨域复现+生成力+排他性）、5-10 条决策启发式、完整表达 DNA（7 维度）。

**模板**：`examples/persona-template.md`（16 个必选章节）

### 岗位型 — 当你要"定义一个专业角色"

**触发条件**：用户描述了具体岗位/职责，没有提到人名。

> "创建一个税务顾问"
> "帮我设计一个代码审查专家"
> "做一个 HR 招聘助手"

**流程**：J1 需求萃取 → J2 模板填充 → J3 技法注入 → J4 质量内控 → J5 交付（不经过蒸馏 0-5，即时生成）。

**核心产出**：身份5字段（角色/个性/价值观优先/记忆/经验）、使命+反使命、DO/DON'T 规则、可量化 KPI、极限行为设计。

**模板**：`examples/job-template.md`（12 个模块，内置快速启动默认值推导）

### 拿不准？2 分钟快速诊断

问自己 5 个问题：

| # | 问题 | 人格型 | 岗位型 |
|---|------|--------|--------|
| 1 | 用户是否提到了具体人名？ | 是 → 蒸馏 | 否 |
| 2 | 角色需要"人格魅力"还是"交付标准"？ | 人格魅力 | 交付标准 |
| 3 | 是否需要跨会话记忆用户偏好？ | 需要 | 可选 |
| 4 | 输出物是否可被模板完全描述？ | 否（需思维） | 是 |
| 5 | 输出行数预估 | >200 行 | 100-200 行 |

### 范式融合

先定义岗位（岗位型），再注入某位行业人物的思维特征（蒸馏），产出"有独特思维烙印的岗位专家"。详见 `references/job-details.md` §两种范式融合路径。

## 生成后如何验证

### 岗位型产出：用 verify-skill.py

```bash
python scripts/verify-skill.py --skill output/税务顾问.SKILL.md
```

校验内容：
- YAML frontmatter 完整性（name/description/version/domain/author）
- Gate 标记是否齐全
- DO/DON'T 规则冲突检测
- 岗位型深度结构 11 项（身份5字段、使命+反使命、回答工作流3步、交付物、工作流程 [3,5]、沟通风格3标签+拒绝方式、极限行为4场景、KPI ≥3、知识库3层、诚实边界 ≥5）

退出码 0 = PASS，可交付。

### 人物蒸馏产出：用 verify-persona.py

```bash
python scripts/verify-persona.py output/芒格-perspective.SKILL.md
```

校验内容：
- YAML frontmatter（name/description/color）
- 16 个必选章节全覆盖
- 心智模型数量 [3,7] 且有三重验证痕迹
- 决策启发式 [5,10]
- 表达DNA 7 维度完整
- 诚实边界 ≥5 条（含关键项检查）
- 退化行为 4 场景
- 一手来源占比检查（< 50% 警告）

退出码 0 = PASS，可交付。

### 两个脚本的职责边界

| | verify-persona.py | verify-skill.py |
|---|---|---|
| **专注范围** | 人格蒸馏产物 | 全技能结构（通用 + 岗位型深度） |
| **心智模型验证** | ✅ 数量 [3,7] + 三重验证痕迹 | — |
| **决策启发式验证** | ✅ 数量 [5,10] | — |
| **表达DNA验证** | ✅ 7 维度完整 | — |
| **身份5字段** | ✅ 身份卡5字段 | ✅（岗位型深度校验） |
| **DO/DON'T 冲突** | — | ✅ |
| **岗位型11项深度** | — | ✅ |
| **反模式索引** | — | ✅ |
| **引用文件完整性** | — | ✅ |

> 人格蒸馏产出建议**两个脚本都跑**：`verify-persona.py` 确保蒸馏质量，`verify-skill.py` 确保结构完整性和规则无冲突。
