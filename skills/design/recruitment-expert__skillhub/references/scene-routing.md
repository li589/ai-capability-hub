## 场景路由表

> 根据用户的角色和意图，快速判定从哪个步骤切入，以及 Agent 的交互策略。

### 用户角色判定

| 用户角色 | 典型信号 | 交互策略 |
|----------|----------|----------|
| **HR / 招聘专员** | "帮我筛简历""约个面试""发 Offer" | 执行导向——Agent 主导方法论，HR 负责执行。方法论分歧时 Agent 用证据和逻辑 push back |
| **业务负责人 / 用人经理** | "我要招一个总监""团队缺人" | 诊断导向——Agent 先做需求诊断（步骤 1），不直接接单。对伪需求敢于说"先不招" |
| **高管 / CEO** | "我们明年要进新赛道""组织能力跟不上" | 咨询导向——Agent 从战略层切入，对齐人才战略和业务战略的耦合度，再下沉到具体岗位 |
| **面试官** | "明天面试，帮我准备问题" | 赋能导向——Agent 交付个性化面试方案（含预埋追问 + 反事实 STAR + 黑暗面试题），不做事后 judge |

### 意图 → 步骤路由

| 用户意图 | 从哪个步骤切入 | 前置检查 |
|----------|---------------|----------|
| "帮我分析这个岗位该不该招" | 步骤 1（需求诊断） | 无前置依赖 |
| "帮我写一份人才画像" | 步骤 2（人才画像） | 需确认需求诊断已完成 |
| "怎么找到这样的人" | 步骤 3（渠道策略） | 需人才画像已确认 |
| "帮我评估这份简历" | 步骤 4（简历筛选） | 需人才画像已确认 |
| "帮我设计面试方案" | 步骤 5（面试评估） | 需简历筛选报告 + 画像 |
| "这个薪资怎么谈" | 步骤 6（薪酬谈判） | 需面试评估报告 |
| "入职前需要做背调" | 步骤 7（背景调查） | 需面试评估 + 黄线方向 |
| "发 Offer" | 步骤 8（录用通知） | 需薪酬确认 + 背调通过 |
| "复盘这次招聘" | 步骤 9（数据闭环） | 需入职 45 天以上 |
| "我有个招聘问题想请教" | 自由对话——Agent 判定问题类型后路由 | 无需前置 |

### 交互深度级别

| 级别 | 触发条件 | Agent 的交互深度 |
|------|----------|-----------------|
| **L1 快速问答** | 简单查询（"这个指标什么意思"） | 一句话定义 + 出处 |
| **L2 单步骤执行** | 明确执行某一步骤 | 严格按该步骤的核心任务清单执行，输出对应模板 |
| **L3 多步骤串联** | "帮我从筛简历开始到面试" | 按九步骤流程全链路执行，每步骤输出后确认再进入下一步 |
| **L4 战略咨询** | "我们要招一个合伙人""明年的人才策略" | 不急于进入单步骤，先做高层对齐（需求三角 + 人才池分析 + 人才地图），再给分阶段建议 |
