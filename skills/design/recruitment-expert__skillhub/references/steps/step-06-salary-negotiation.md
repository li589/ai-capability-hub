### 步骤 6：薪酬谈判 — 从"区间博弈"升级为"总价值锚定与风险对冲设计"

#### 道（根本原则）

**追求价值交换的"心理契约"，而非零和博弈。**

专家眼中的薪酬谈判只有一件事：**管理候选人的"参考点"（Reference Point，行为经济学中的前景理论）**。候选人的期望永远锚定在他看到的Offer或上份工资上。专家的任务不是"满足"期望，而是**"解构并重置"**他的参照系。

#### 🔄 补充方法论：薪酬结构设计工具箱（来源：recruitment-expert）

**薪酬不是"给多少钱"一个变量，而是固浮比、期权、竞业补偿、非现金杠杆四个维度的系统设计。**

**一、固浮比设计——按岗位性质而非职级决定**

| 岗位类型 | 建议固浮比 | 原因 |
|----------|-----------|------|
| 职能/支持岗 | 90:10 ~ 85:15 | 产出与个人决策的直接关联度低，高固薪稳定军心 |
| 技术/产品岗 | 80:20 ~ 70:30 | 产出可归因但周期长，浮动部分与项目里程碑挂钩 |
| 销售/商务岗 | 60:40 ~ 50:50 | 产出直接可量化，高浮动激发狼性 |
| 高管/合伙人 | 50:50 ~ 40:60 | 利益深度绑定，浮动与公司整体业绩强挂钩 |

**二、期权/股权设计——按融资阶段差异化**

| 阶段 | 期权占年薪包比例 | 关键话术 |
|------|-----------------|----------|
| 天使/A轮 | 50-200%（高风险高杠杆） | "现在加入，你拿的是创始团队的期权成本结构" |
| B轮 | 30-80% | "这轮估值还在合理区间，下一轮你的稀释空间有限" |
| C轮+ | 15-40% | "我们更接近流动性事件，折价换取确定性" |

> **铁律**：永远给候选人做"期权归零压力测试"——"如果这笔期权最后值0元，你还会来吗？"如果答案为否，他对公司的信心不够，入职后任何股价波动都会触发离职。

**三、竞业补偿——不回避，说清楚**

- 入职前主动问："你现在的竞业协议覆盖哪些公司？补偿金怎么算？"
- 如果需要候选人承担竞业风险，**必须在 Offer 中明确竞业补偿方案**——不能口头说"公司会处理"
- 行业惯例：竞业补偿 = 离职前12个月平均工资 × 竞业限制月数 ×（30%-50%），具体看城市和行业

**四、非现金杠杆——什么时候不靠加钱**

| 杠杆 | 适用场景 | 操作方式 |
|------|----------|----------|
| **Title 升级** | 候选人薪酬已触顶但职级有空间 | 给更高职级但不突破薪酬带宽上限 |
| **远程/弹性办公** | 候选人有家庭约束或通勤痛点 | 明确远程天数和核心协作时段 |
| **项目主权** | 候选人是高自主需求型（内部创业者） | "这个业务线你说了算，季度复盘但不微观管理" |
| **加速成长曲线** | 候选人是成长驱动型 | 展示具体培养路径：导师配对表 + 6个月后的能力增量 |
| **团队质量** | 候选人是"想跟牛人共事"型 | 安排与团队核心成员的非正式交流，让团队成员"卖"自己 |

> **判断原则**：谈判僵局时，先问"候选人真正想要的是什么"而非"我们还能加多少"。80%的薪酬谈判僵局不是钱的问题，是候选人觉得"不被理解"。

#### 法（方法论）

**一、"分割报价法"对抗"整数锚定"**

- 候选人说期望年薪100万 → 专家不反驳，而是反问：
  > "这100万里，您预期的**固浮比**是多少？如果固定部分比预期低10%，但浮动部分的触发条件从'公司总利润'改为'您个人主导项目的ROI'，您愿意接受吗？"
- **底层逻辑**：将单一的"总价博弈"拆解为**"风险偏好博弈"**，精准定位候选人的**"真实效用函数"**

| 候选人类型 | 策略 |
|------------|------|
| 风险厌恶者 | 高固定 + 低浮动 |
| 风险偏好者 | 低固定 + 高浮动（与个人ROI挂钩） |

**二、"竞争性沉默"与"认知失调"制造**

- 当候选人抛出竞品Offer（如70万）时，专家不急于匹配：
  > "非常优秀的Offer，但我有一点好奇。以您的资历，这家公司通常会给到75-80万这个带宽，他们给70万，是否意味着在**职级定岗**上打了折扣？如果职级没给到位，您后续的期权行权和晋升窗口期会被压缩，您评估过这个'隐形成本'吗？"
- **效应**：瞬间在候选人心中植入对竞品Offer的"瑕疵感知"，瓦解其锚点

**三、"期权/股票的风险中性定价"**

- 为未上市公司期权制定**"流动性折价系数"**（通常按0.3-0.5折现），并**明确告知**候选人：
  > "在我们账上，这部分的会计成本是X，但我建议你按0.4的系数折算为现金价值来评估。"
- 这种**"自曝其短"的超然坦诚**产生极强信任杠杆
- 随后话锋一转：
  > "但我司今年的退出路径有明确时间表，如果你愿意承受这0.6的折价风险，你在总包上会获得比竞争对手高20%的**风险溢价空间**。"
- **本质：把谈判升维为"共同投资决策"**

#### 术（终局神经链接）

**Offer签发后48小时内的"超预期交付"**：

薪酬签完不算结束。专家在Offer发出后**48小时内**发送一份非正式的**《前3个月关键资源清单》**：
- 内部关键协作者的联系方式（微信/飞书）
- 历史会议纪要脱敏版
- 供应商紧急联系人

附带一句话：
> "薪酬是我们合作的**物理契约**，这份清单是我个人为您准备的**心理契约**。我希望您在入职第一周不是迷茫的，而是直接能开火的。"

**效应**：这份"超预期交付"瞬间将谈判桌上的对立关系扭转为**"我们并肩作战"的革命情谊**，候选人在面对其他公司最后加价时产生强烈的"互惠性愧疚"——行为经济学证明，这种情感纽带的留任作用等效于**8%-12%的薪资涨幅**。

#### 术（实操层）— 谈薪十步法

> 源自成熟房企薪酬谈判培训体系，经通用化改造去除企业标识。十步法将薪酬谈判从"一场对话"升级为"系统化共识工程"。

##### 十步概览

| 步骤 | 名称 | 核心任务 |
|------|------|----------|
| 1 | 薪酬摸底 | 收集候选人薪酬数据与核心诉求 |
| 2 | 薪酬对标 | 与行业/内部对标，找到参照系 |
| 3 | 用人部门确认 | 与用人部门最终确认薪酬方案 |
| 4 | 拟定谈薪策略 | 基于差距制定针对性策略 |
| 5 | 初次沟通与报价 | 介绍薪酬方案，收集反馈 |
| 6 | 候选人反馈处理 | 三种反馈分支，分类处理 |
| 7 | 策略性吸引 | 全面薪酬+愿景，管理参照系 |
| 8 | 达成一致 | 锁定最终方案，确认接受 |
| 9 | 发送正式Offer | 邮件发送，约定回复时限 |
| 10 | 持续跟进 | 追踪离职/入职状态 |

##### 各步操作细则

**第一步：薪酬摸底**

1. 摸清对方的薪酬总额、结构及各个科目的组成
2. 掌握对方的期望薪酬、离职原因等有利于谈薪的关键因素
3. 了解行业内同职位的薪水情况，与行业对标（若需）

**第二步：薪酬对标**

1. 根据求职者的薪酬数据和结构，与行业及相关职位进行对比
2. 分析我司薪酬标准在该岗位上的定位
3. 预判对方可能提出的薪资预期范围

**第三步：与用人部门确认候选人薪酬**

再次与用人部门确认候选人薪酬，若时间允许，最好经过书面审批确认；若时间比较紧急，可以先口头沟通确认，之后再完成审批流程。

> 注：通常用人部门给出录用决策时，就会给出建议的薪酬，但是为确保万无一失，我们与候选人谈薪前一定要与用人部门再次沟通确认。

**第四步：拟定谈薪策略**

1. 根据录用决策确定的岗位、职级和薪酬（对照我司薪酬标准）制作初步的薪酬结构单
2. 测算我司给出的薪酬和候选人现有薪酬各个科目的涨幅比例及总额的涨幅比例
3. 测算我司给出的薪酬和候选人期望薪酬的差距
4. 基于以上关注点，制定针对性的谈薪策略（若差距太大，没有信心谈下，可召集团队其他成员一起商量策略）

**第五步：初次沟通与报价**

开场话术规范（通用化版本）：

> "XX，您好！我是[公司名]人力资源部XX。我们面试已经结束了，经过这段时间跟我们的接触，想听下您对我们公司的感觉怎么样？有什么想法？"

- 注意：不反馈面试评价
- 如候选人已在第一个问题中表达了认可和意向，可顺接进入下一步

接着确认：
1. 确认对方薪酬现状：跟候选人核对确认目前的薪酬现状，含薪酬总额、结构及各个科目的组成
2. 介绍我司薪酬结构：介绍各项组成，与对方目前薪酬结构的区别
3. 简要介绍我司目前给出的薪酬和职位
4. 询问候选人对于我司给出的薪酬和职位是否有问题

**第六步：候选人反馈处理（三种分支）**

| 反馈类型 | 处理方式 |
|----------|----------|
| ✅ 候选人同意 | 感谢候选人，说明之后将把正式的Offer发给他，请他及时查收。如没有问题，2天内邮件回复确认接受，并告知最早的入职时间。如有任何问题，可随时联系 |
| 🤔 候选人需考虑 | 说明之后将草拟一个Offer发给他，请他及时查收并认真考虑，并和候选人约定回复的时间。回复时间不能太长，2-3天为宜，侧面说明他如果不接受，我们还要跟另外的候选人谈 |
| ❌ 候选人不同意 | 请候选人提供薪酬证明，我们需提交至内部的薪酬小组进行审阅后回复（建议当天回复，最多隔天） |

**第七步：进行策略性吸引，树立愿景**

关键思维逻辑：

- 充分了解候选者的需求 — 他真正想要的是什么？他想通过跳槽解决什么问题？（需求）
- 留在原企业你会损失什么，离开原企业你会得到什么？（原企业不能满足）
- 不选择我们会损失什么，选择我们会得到什么？（我们能满足）

**薪酬有涨幅时：** 分析薪酬各个组成部分的涨幅情况，分享行业跳槽的涨幅比例等

**薪酬涨幅不大或无涨幅时 — 启动全面薪酬吸引：**

1. **全面薪酬**：公司战略、发展、稳定增长、团队、领导、文化、学习提升机会、职位的晋升（含区域到总部）、与行业标杆人物共事、职业化的工作方式
2. **职位预期**：职位管辖范畴、汇报关系、组织结构
3. **未来预期**：每年调薪机会、股权激励，获得高于行业平均速度的成长机会
4. **风险提示**：固浮比结构调整、固定比例提升；过高的薪酬意味着组织对其的期望过高，要考虑长期生存和可持续
5. **对标分析**：与行业比、与竞争对手比、与现任雇主比，替候选者分析
6. **职业发展**：分享职业发展方向和路径

> 技巧：越想要的候选人，我们越要表现冷静，掌控住谈薪的局面和主动权（欲擒故纵）。

**第八步：达成一致**

确认候选人已无顾虑，口头确认接受该职业机会和薪酬方案。记录确认时间与关键承诺。

**第九步：发送正式Offer**

邮件发送正式的Offer给候选人，邮件中约定回复的时间，并告知最早的入职日期。

**第十步：持续跟进**

持续跟进候选人的状态 — 是否提出离职、是否还有其他机会等，直到入职报到。

##### 十步法与薪酬谈判"道/法"对接

| 十步法步骤 | 对应上层框架 | 说明 |
|------------|-------------|------|
| 步骤1-2（摸底+对标） | 道 → 法一（分割报价法） | 收集数据为"解构整数锚定"做准备 |
| 步骤3-4（确认+策略） | 法一 → 法二 | 内部对齐，准备认知失调话术 |
| 步骤5-6（报价+反馈） | 法二（竞争性沉默） | 首次报价 + 三类反馈处理 |
| 步骤7（策略性吸引） | 法一 + 法三 | 全面薪酬 = 分割报价 + 风险定价 |
| 步骤8-9（达成+Offer） | 术（终局神经链接） | 锁定后48小时超预期交付 |
| 步骤10（持续跟进） | — | 防止Offer到入职之间发生变数 |

#### 核心任务清单

- [ ] 完成薪酬摸底（总额/结构/期望/离职原因/行业对标）
- [ ] 与用人部门最终确认薪酬方案
- [ ] 制作薪酬结构单 + 涨幅测算 + 差距测算
- [ ] 准备谈薪策略（含全面薪酬吸引清单）
- [ ] 执行初次沟通与报价
- [ ] 处理候选人反馈（三分支：同意/考虑/不同意）
- [ ] 如薪酬涨幅不足：启动策略性吸引（全面薪酬六维）
- [ ] 谈成 → 48小时内发送"超预期交付"（《前3个月关键资源清单》），锁死心理契约
- [ ] 发送正式Offer，约定回复时限
- [ ] 持续跟进候选人状态至入职
- [ ] 谈不成 → 评估：是核心需求不匹配还是方式问题，决定坚持/调整/放弃

#### 关键输出

- 薪酬结构单（含涨幅测算与差距测算）
- 薪酬谈判结论（达成 / 继续谈 / 放弃）
- 最终Offer薪酬方案（附固浮比、全面薪酬说明）
- 正式Offer邮件（含回复时限与入职日期）
- 《前3个月关键资源清单》（谈成时同步交付）
- 若谈不成：原因分析与替代方案建议

#### 检查点闸门（步骤 6）

> ⚠️ 薪酬方案输出后，Agent 必须暂停并请求用户确认，方可进入步骤 7（背景调查）。

**确认内容**：
1. 展示薪酬包设计（固定/浮动/股权/签字费）
2. 展示谈判策略（底线/锚点/让步空间）
3. **明确询问**："以上薪酬方案是否确认？请确认后进入步骤 7（背景调查）。"
4. 用户确认后，方可加载 `step-07-background-check.md`。
