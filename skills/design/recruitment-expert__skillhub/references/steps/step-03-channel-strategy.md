### 步骤 3：渠道策略 — 从"撒网捕鱼"升级为"特种作战的人才星链部署"

#### 道（根本原则）

**最好的候选人根本不在招聘网站上。**

招聘网站是"主动求职者"的市场，而主动求职者只占整个人才池的 20-25%。剩余的 75% 是**被动候选人在存量市场中**——他们在竞对的核心岗位上干得不错，没打算跳槽，但一个精准的触达信号能激活他们的"职业好奇心"。

专家的渠道策略是**"特种作战"而非"撒网捕鱼"**：不是广撒 JD 等简历，而是基于人才画像，精确部署"触点网络"——在被动候选人可能出现的每一个信息节点上埋下信号。

#### 🔄 补充方法论：渠道平台速查——什么平台吃哪碗饭（来源：recruitment-expert）

> **直觉级认知**：把 Boss 当猎聘用就是烧钱，把猎聘当 Boss 用就是浪费候选人。

| 平台 | 核心战场 | 最佳职级 | ROI 特征 |
|------|----------|----------|----------|
| **Boss直聘** | 初中级岗位 + 主动求职者 | 专员~经理 | 量大、快——适合跑量，但需大量筛选 |
| **猎聘** | 中高级岗位 + 被动候选人 | 经理~总监 | 质量高于 Boss，但简历新鲜度波动大——适合定点狙击 |
| **脉脉** | 社交招聘 + 雇主品牌内容 | 全层级 | 直接触达率高但转化周期长——适合长线养鱼 |
| **拉勾** | 互联网初中级 | 专员~经理 | 行业垂直但流量大幅下降——仅作补充 |
| **智联/前程无忧** | 传统行业/制造业/职能岗 | 全层级 | 覆盖广但活跃度下降——适合蓝领和传统行业 |
| **内推** | 全层级，质量最高 | 全层级 | ROI 最高——内推候选人的试用期通过率和留存率显著高于其他渠道 |
| **猎头** | 高管 + 稀缺技术岗 | 总监+ | 极高成本（年薪20-30%）——仅在常规渠道够不到时启用 |
| **LinkedIn** | 外企/海归/高端被动候选人 | 经理~VP | 触达精准但国内活跃度低——外企和出海岗优先 |

**渠道组合铁律**：
- **一个岗位至少 3 个渠道并行**（2 个主力 + 1 个测试），两周后用数据关停低效渠道
- **内推不是"发全员邮件"**——定向邀请最可能认识目标人才的内部员工，附画像中的 top 3 鉴别项
- **猎头是最后手段**——先用人才地图和社交工程触达验证市场供给，确认"市场上确实有但常规渠道够不到"再启用

---

#### 法（方法论）

**一、人才池四分法——决定打什么仗**

在启动渠道之前，先对目标人才池做分类：

| 人才池象限 | 定义 | 典型画像 | 渠道策略 |
|-----------|------|----------|----------|
| **活跃池** | 正在主动看机会，更新了简历 | 离职中 / 被裁员 / 应届 | Inbound 为主：招聘网站 + 校招 + 社群 |
| **潜伏池** | 没主动看，但对"更好的机会"敏感 | 核心岗位在职 2 年+，偶尔刷 LinkedIn | Outbound 为主：定向触达 + 内部推荐 |
| **冰封池** | 完全不考虑换工作，但可能在 6-12 个月内被某个事件触发 | 拿了期权未解禁 / 项目关键期 / 刚升职 | 长线培养：雇主品牌 + 行业内容输出 + 弱关系维护 |
| **禁入池** | 竞品竞业协议覆盖 / 行业声誉风险 / 地缘不可移动 | 竞业期内高管 / 行业争议人物 | 不投入资源，标注待竞业期满再评估 |

> **原则**：不同象限用不同的 ROI 公式。用猎头找活跃池候选人是浪费预算；用招聘网站找冰封池候选人是浪费生命。

**二、人才地图（Talent Mapping）——战前侦察系统**

在启动任何渠道之前，先绘制一张**目标组织的"人才地图"**：

**操作步骤**：

1. **锁定 5-8 家目标来源组织**：基于画像中"深海层终局项"挑选——不是最大的公司，而是"归因模式和认知弹性最接近画像"的组织
2. **绘制组织架构图**：通过 LinkedIn / 行业人脉 / 公开信息 → 画出目标公司该职能条线的 2-3 层结构
3. **标注"可迁移节点"**：标记以下特征的个体——
   - 在该岗位 ≥ 2 年（能力已被验证）
   - 最近 6 个月有组织变动（汇报线调整 / 业务方向变化 → 潜在不满信号）
   - 在行业会议/内容平台上活跃（有外部信号可供触达）
4. **建立触达路径**：为每个目标个体找到至少 2 个"自然触点"（共同人脉 / 行业社群 / 内容互动契机）

**人才地图交付物**：一张目标组织的组织结构图 + 10-20 个"高价值靶点"标注 + 每个靶点的触达路径。

**三、社交工程触达法（Social Engineering Outreach）——不说"我们"，说"你"**

传统的"猎头 cold call"已经失效。被动候选人的信息防御系统极高，任何带有"猎头味儿"的消息都会被 3 秒划走。

**触达话术三阶递进**：

| 阶段 | 目标 | 话术模板 | 黄金法则 |
|------|------|----------|----------|
| **第一触达** | 打开对话（不说"招人"） | "看到你在 [会议/文章/项目] 上关于 [具体观点] 的分享，我最近也在思考 [相关议题]。有个问题想请教：你觉得 [行业趋势/技术方向] 在接下来 12 个月最大的变量是什么？" | **价值先行**：你先给他一项认知增量，再问一个问题。不要索取、先给予 |
| **第二触达**（3-5 天后） | 植入"职业好奇心" | "上次你提到的 [那个观点]，我和我们团队聊了，大家很有共鸣。我们最近刚好在 [相关方向] 做一个挺难的事——[一句话说清楚挑战]。如果你哪天想聊聊怎么破这个局，我很乐意请你喝杯咖啡。" | **问题先行**：不是"我们有职位"，而是"我们有一个值得你来解决的问题" |
| **第三触达**（7-10 天后） | 软性邀请 | "对了，我们团队下周三有个内部分享会，主题是 [与他兴趣高度相关的议题]。如果你有兴趣，可以来旁听——没有 obligation，纯粹觉得你会对这个话题有独到见解。" | **参与先行**：不是"来面试"，而是"来看看我们对你在乎的东西是怎么思考的" |

**"猎人"触达效率指标**：
- 第一触达 → 回复率目标：≥ 25%
- 第一触达 → 第二触达转化率目标：≥ 60%（有回复的继续）
- 第三触达 → 面试邀请接受率目标：≥ 50%

**四、内部推荐升级法——从"发奖金"到"社交货币"**

内部推荐不是"HR 发全员邮件说推荐有奖"——那是用钱买简历。

专家将内推升级为**"社交货币系统"**：

| 升级维度 | 传统做法 | 专家做法 |
|----------|----------|----------|
| 触发方式 | 全员邮件："推荐成功奖励 X 元" | 定向激活：只向"最可能认识目标人才"的内部员工发送**个性化邀请**（附人才画像中的 3 个鉴别项） |
| 推荐理由 | "我们公司挺好的" | 给推荐人配备**"一句话推荐话术"**（不是夸公司，是"这个具体问题值得你来解决"） |
| 激励设计 | 入职后一次性奖金 | **三段式激励**：简历通过 → 小奖 + 进入终面 → 中奖 + 入职满 6 个月 → 大奖（把激励和推荐质量绑定） |
| 社交回报 | 无 | 推荐成功者在全员大会上获"人才猎手"称号 → 把推荐变成**职场社交炫耀资本** |

**五、渠道 ROI 量化与 A/B 测试框架**

每个渠道不是"用了就行"，必须持续测量和比较：

| 指标 | 定义 | 计算方式 |
|------|------|----------|
| **CPS**（单简历成本） | 获取一份有效简历的平均成本 | 该渠道总投入 ÷ 有效简历数 |
| **CPI**（单面试成本） | 推动一个候选人进入初面的平均成本 | 该渠道总投入 ÷ 进入初面人数 |
| **CPH**（单录用成本） | 每录用一个候选人的平均渠道成本 | 该渠道总投入 ÷ 最终录用人数 |
| **质量系数** | 该渠道入职候选人的 6 个月转正率 | 该渠道入职满 6 个月且转正人数 ÷ 该渠道总入职人数 |
| **时效系数** | 该渠道从启动到录用的平均周期 | 该渠道所有录用案例的"启动→Offer"天数均值 |

**A/B 测试框架**：

对每个关键岗位，同时启用 2-3 个渠道，用不同话术版本，对比：
- 哪种话术的回复率更高？
- 哪个渠道的候选人更接近画像？
- 哪个渠道的"面试到场率/Offer接受率"更高？

**两周后关停低效渠道，追加高效渠道预算**——不做"全渠道投放然后等结果"的被动策略。

**六、雇主品牌"暗线"铺设——让候选人自己找上门**

在被动的候选人的信息接触点上，预先铺设**"暗线"**：

| 触点 | 暗线铺设方式 | 目标 |
|------|------------|------|
| 行业会议 | 让你的骨干员工去演讲——不聊公司、只聊方法论 | 让被动候选人说："这个人思考很深，他的团队应该不错" |
| 技术博客/公众号 | 发表"做了 XX 决定后我们翻车了"类型复盘文章（不是成功案例） | 传递"我们允许犯错、坦诚复盘"的文化信号 |
| 开源/GitHub | 你的团队代码质量就是最好的 JD | 让技术候选人在研究代码时产生"我想和这群人一起写代码"的冲动 |
| 离职员工 | 善待离职员工（离职访谈 + 校友群）→ 他们是你最好的"潜伏招聘官" | 让离职员工在行业里说："那家公司确实有些问题，但人是真的厉害" |

#### 术（实操层）

**渠道策略四步启动法**（从画像到落地，不超过 3 个工作日）：

```
人才池分类（Day 1）→ 人才地图绘制（Day 1-2）→ 触达话术定制（Day 2）→ 渠道组合启动 + A/B 测试框架搭建（Day 3）
```

**渠道组合决策矩阵**：

| 岗位级别 | 活跃池渠道 | 潜伏池渠道 | 冰封池渠道 | 建议预算分配 |
|----------|-----------|-----------|-----------|-------------|
| 基层 | 招聘网站 + 校招（60%） | 垂直社群 + 内推（30%） | 雇主品牌内容（10%） | 低 |
| 中层 | 垂直平台 + 内推（40%） | 社交工程触达 + 猎头（40%） | 行业会议铺设（20%） | 中 |
| 高层/高管 | 猎头（30%） | 社交工程触达 + 人才地图精准打击（50%） | 董事会人脉 + 行业影响力铺设（20%） | 高 |

#### 核心任务清单

- [ ] 对目标人才池执行**四分法分类**（活跃/潜伏/冰封/禁入），确定主攻象限
- [ ] 绘制**人才地图**：锁定 5-8 家目标来源组织，标注 10-20 个高价值靶点
- [ ] 为高价值靶点设计**三阶社交工程触达话术**（第一触达 / 第二触达 / 第三触达）
- [ ] 定向激活**内部推荐系统**：向关键员工发送个性化推荐邀请 + 配备话术
- [ ] 确定渠道组合（见决策矩阵），分配预算
- [ ] 搭建 **A/B 测试框架**：每个关键岗位并行 2-3 渠道 + 多话术版本
- [ ] 设置渠道 **ROI 仪表盘**（CPS / CPI / CPH / 质量系数 / 时效系数）
- [ ] 检查雇主品牌"暗线"：行业内容 / GitHub / 离职员工触点的铺设状态
- [ ] 两周后执行第一次 A/B 测试复盘：关停低效渠道，追加高效渠道

#### 关键输出

**渠道策略文档**，包含：
- 人才池四分法分类结果及主攻象限
- 人才地图（目标组织架构 + 靶点标注 + 触达路径）
- 三阶社交工程触达话术（第一 / 第二 / 第三触达）
- 内部推荐定向激活名单 + 个性化话术
- 渠道组合方案 + 预算分配
- A/B 测试方案（渠道 / 话术 / 时间窗口 / 判定指标）
- ROI 仪表盘设计（5 项指标定义 + 采集方式）
- 雇主品牌"暗线"铺设清单

#### 黄线预警

> **渠道错配是 ROI 的黑洞。**
>
> 最常见的三种浪费：
> 1. 用猎头找"本来在招聘网站上就能找到的人"（为便利性付溢价）
> 2. 在招聘网站上等"永远不会主动投简历的人"（在错误的池子里钓鱼）
> 3. 内推机制形同虚设——发了一封全员邮件就以为激活了内推
>
> 专家不做渠道的"采购者"，做渠道的**"特种作战指挥官"**——对每个靶点设计触达路径，对每个渠道测量 ROI，对每一分预算负责。

#### 🔄 补充方法论：渠道 ROI 十二指标体系 + 六板块诊断报告（来源：recruitment-channel-roi-diagnoser）

**直觉级认知**：渠道投入必须有量化指标。每次渠道启动时挂 ROC 仪表盘——两周后用数据关停低效渠道，而非"用了就行"。

**12 项核心指标速查**：

| 类别 | 指标 | 公式 | 健康区间/基准 |
|------|------|------|--------------|
| 成本 | 单简历成本(CPS) | 花费÷简历数 | 招聘平台0.2-0.5万 |
| 成本 | 单面试成本(CPI) | 花费÷面试数 | — |
| 成本 | 单Offer成本 | 花费÷Offer数 | — |
| 成本 | **单Hire成本(CPH)** | 花费÷入职数 | 内推<0.3万 / Boss<1.0万 / 猎聘<1.2万 |
| 转化 | 简历→面试 | 面试÷简历 | 🟢15-25% / 🔴<8% |
| 转化 | 面试→Offer | Offer÷面试 | 🟢20-35% / 🔴<10% |
| 转化 | Offer→入职 | 入职÷Offer | 🟢50-80% / 🔴<30% |
| 质量 | 30天留存 | 30天在职÷入职 | 🟢≥85% / 🔴<60% |
| 质量 | 90天留存 | 90天在职÷入职 | 🟢≥75% / 🔴<50% |
| 质量 | 试用期通过 | 试用期通过÷入职 | 🟢≥80% / 🔴<60% |
| 综合 | 质量系数 | (留存率均值×0.7+绩效系数×0.3) | >0.85=优质 |
| 综合 | **质量加权ROI** | (入职数×质量系数)÷花费(万) | **最终排名依据** |

**性价比矩阵（2×2）**：
- 🟢 明星渠道（低成本高留存）→ 加大投入
- 🟡 主力渠道（高成本高留存）→ 维持
- 🟡 潜力渠道（低成本低留存）→ 分析留存低的原因
- 🔴 低效渠道（高成本低留存）→ 削减/停投

**预算重分配决策**：质量加权ROI>中位数×1.5→增投+30~100% / 在中位数±30%→保持 / <中位数×0.7→削减30-50% / <中位数×0.5且入职数<3→停投

**常见错误**：①只看每Hire成本不看质量（脉脉Hire 0.8万但90天留存60%→实际有效成本1.33万）②一次性调多渠道无法归因效果③猎头和平台计费模式不同直接对比④不看趋势只看总量

#### 检查点闸门（步骤 3）
