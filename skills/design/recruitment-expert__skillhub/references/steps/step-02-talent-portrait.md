### 步骤 2：人才画像 — 从"素质词典堆砌"升级为"业务战场的胜率预测模型"

#### 道（根本原则）

**画像不是描述"谁适合这个岗位"，而是回答"具备什么特征的人在什么条件下打赢这场仗的概率最高"。**

普通 HR 做画像：列出 10 条"良好的沟通能力、团队合作精神、学习能力强"——全是愿望清单，不是筛选工具。

专家做画像：为每一项素质加上**行为锚 + 战场条件 + 失败模式**，让画像成为**面试题生成器 + 简历过滤器 + 背调验证清单的三合一引擎**。

#### 法（方法论）

**一、"逆向塑模法"——从失败中雕刻成功画像**

大多数画像只问"什么样的人会成功"，忽略了更强大的信号源——**"什么样的人在这个岗位上失败了？"**

**操作流程**：

```
访谈最近 2 年内该岗位的 TOP 3 绩优者 → 提取成功行为模式（正向线索）
+
访谈该岗位最近 3 个离职/淘汰者 + 其直属上级 → 提取失败行为模式（负向线索）
↓
正反交叉 → 找出"绩优者独有、失败者缺失"的能力项 → 这些才是真正的鉴别项
```

**失败模式萃取话术**（对用人经理）：

> "回顾你带过的最让你失望的人，他入职时面试评分其实不低，但后来暴露了什么面试时没测出来的问题？你现在回头看，如果招聘时你能问一个问题就识破他，那个问题会是什么？"

> 把这个问题的答案**直接写进面试题库**——这是经过"鲜血验证"的鉴别项。

**二、"三眼共创法"——融入权力结构的对齐艺术**

画像不能闭门造车，但也不能变成"老板说了算"。专家的做法是在三眼交汇处找**"最大公约能力"**：

| 视角 | 来源 | 他们真实的诉求（不是嘴上说的，是行动上在意的） |
|------|------|-----------------------------------------------|
| 战略眼 | 高层 | 我需要这个人让我的战略叙事更可信（不是"帮我做事"，是"证明我选的这条路能走通"） |
| 专业眼 | 用人经理 | 我需要这个人帮我扛掉 60% 的跨部门撕扯（不是"专业能力"，是"替我消化组织摩擦力"） |
| 外部眼 | 市场对标 | 这个级别的人目前在市场上平均 45 天被抢走——你的画像能在他被抢走之前吸引到他吗？ |

**三眼对齐会议脚本**（30 分钟）：

1. **"如果只能保留 3 项要求"**（5min）：让三方各自从 10 项画像要求中删到只剩 3 项——暴露真实优先级
2. **"谁是最佳反面教材"**（10min）：让用人经理描述一个"最不该招的人"的具体行为特征
3. **"画像市场测试"**（10min）：将筛选出的 top 3 能力项套到 3 个真实市场候选人上进行模拟打分——如果三方打分差距 > 2 分，说明共识尚未达成
4. **"画像保质期约定"**（5min）：约定下次审视时间（业务战略调整 / 入职满 3 人 / 6 个月，以先到为准）

**三、"行为锚等级"法——让素质可观测、可测量、可对比**

**冰山层级模型**：

| 层级 | 类型 | 作用 | 测试方式 |
|------|------|------|----------|
| 冰山上 | 知识、经验、技能 | **门票项**（没票不让进场，有票不保证能演好） | 简历筛选 + 知识测试 |
| 冰山下 | 能力、个性、动机 | **鉴别项**（决定是群演还是主角） | BEI 行为事件访谈 + 反事实 STAR + 黑暗面试法 |
| 深海层 | 归因模式、认知弹性、道德直觉 | **终局项**（决定会不会在关键时刻炸掉） | 时光机映射法 + 价值排序剥离术 + 离职原因压力测试 |

**行为锚定级标准**（以"系统性解决问题"为例）：

| 等级 | 标签 | 行为锚 | 可观测信号 |
|------|------|--------|------------|
| L1 | 未达标 | 遇到问题只看表层，头痛医头 | 讲过往案例时无法说出问题的根因链 |
| L2 | 合格 | 能识别问题间的关联，找到根因 | 能说出"表面问题是 X，但深层原因是 Y" |
| L3 | 优秀 | 预先识别系统风险，建立预警机制 | 能举例"在问题爆发前 3 个月我就已经做了_______" |
| L4 | 卓越 | 重组系统设计，从源头消灭问题类别 | 能说出"我改变了流程/制度/架构，让这类问题不再发生" |

> **规则：每项素质必须有 L1-L4 四个等级的行为锚。没有行为锚的素质词 = 无效信息。**

**四、画像常见错误清单（5 大陷阱）**

| # | 错误 | 表现 | 修正方法 |
|---|------|------|----------|
| 1 | **超人谬误** | 画像要求 15 项素质全部 L3+，市场不存在 | 删到 top 5 必备项，其余标注"入职后可培养" |
| 2 | **后视镜偏差** | 画像完全基于现任绩优者的特征，忽略未来业务变化 | 加入"未来 18 个月新增挑战"维度，强制至少 1 项前瞻性能力 |
| 3 | **光环抄袭** | 直接复制竞对的 JD 措辞 | 从本公司"失败案例"中重新逆向建模 |
| 4 | **空洞素质** | "抗压能力强""沟通能力好"无行为锚 | 必须写出"在什么压力下、用什么方式、保持了多久的有效输出" |
| 5 | **隐性偏见** | "年龄 25-35 岁""男性优先"——非岗位必要条件 | 对照伦理清单逐项排查：①是否可被客观测量？②是否与绩效有统计显著相关性？③剔除该项后画像是否仍然完整？ |

#### 🔄 补充方法论：岗位画像三步法（来源：hr-jd-interview-kit）

在写 JD、出面试题之前，先完成岗位画像。按三层递推：

```
业务目标 → 关键产出 → 胜任力要求
```

**向业务方一次性收集四类信息：**

1. **业务目标**：这个岗位存在是为了达成什么业务目标？（如：一年内把私域 GMV 做到 500 万）
2. **关键产出**：达成目标需要哪些关键产出？（如：搭建社群运营 SOP、月活跃率 30%+、转化漏斗搭建）
3. **胜任力反推**：
   - 硬技能（工具/专业知识/经验年限）
   - 软素质（从沟通、抗压、学习、协作、领导力中选 2-3 项核心项，不要贪多）
   - 减分项/一票否决项
4. **约束条件**：预算薪资带宽、汇报关系、到岗时间、地点与出差、团队现状

**产出「岗位画像卡」（一页纸）**：
- 岗位使命一句话
- 3 个关键产出（可量化）
- 必备硬技能 3-5 条
- 核心软素质 2-3 项
- 一票否决项
- 薪资带宽与卖点

> 此卡是后续 JD 和面试题的唯一依据，保证招聘全程口径一致。

#### 🔄 补充方法论：JD 撰写规范与吸引力法则（来源：hr-jd-interview-kit）

**JD 四段式结构：**

1. **职位名称**（搜索友好，禁用「运营小天才」等内部黑话）
2. **一句话岗位使命**
3. **你将负责**（5-7 条，动词开头，写产出不写杂务）
4. **我们希望你**（必备项与加分项分开写，必备项克制在 5 条内）
5. **我们提供**（薪资范围+成长卖点+团队亮点，这是 JD 的「转化区」）

**吸引力三条法则：**
- 把「要求」翻译成「机会」
- 写真实的挑战比堆砌福利更能吸引强者
- 薪资写范围比「面议」的投递率显著更高

**歧视性表述红线自查**（JD 生成后必须自查）：
- 不得含有性别、民族、种族、宗教信仰等歧视性内容
- 不得将限制生育、婚姻状况作为条件
- 避免年龄、地域、院校出身、属相星座等不当限制表述
- 发布平台合规性由用户自行终审

#### 🔄 补充方法论：JD 瘦身 —「四不放」原则（来源：hr-screening-officer / 《人才画像》冰山模型）

在招聘启动前，检视 JD 冰山上条件是否合理，扩大人才喇叭口：

| 原则 | 判断方法 | 
|------|---------|
| 非必要不放 | 「没有这个条件，能不能做/做好？」 |
| 一年内可培养不放 | 企业能否 1 年内培养出这项技能？ |
| 优先条件不放 | 「优先」≠「必须」，后置到取舍环节 |
| 超三条不放 | 门槛条件上限 3 条 |

**执行方式**：JD 定稿前按「四不放」逐一审查每一条必备条件，建议削减非必要门槛（标注 💡）。超 3 条 → 标注 ⚠️ 由用户选择保留哪些。

#### 术（实操层）

**"画像压力测试"会签流程**：

画像草案完成后，发送给以下 3 人进行"盲测"：
1. **用人经理**（不告知是哪份简历）：用画像标准评估 3 份真实简历 → 打分一致率 ≥ 80% 通过
2. **一个外部同行**：用画像标准判断"你的前同事里有几个匹配"→ 如果回答"几乎没有"，画像可能太窄
3. **Agent 自身模拟**：将画像反向翻译为 5 道面试题 → 如果面试题问不出差异化信息，画像失效

#### 核心任务清单

- [ ] 执行**逆向塑模**：访谈 TOP 3 绩优者 + 最近 3 个失败/离职者的上级
- [ ] 萃取出"绩优者独有、失败者缺失"的鉴别项（≤5 项）
- [ ] 执行"三眼共创"30 分钟对齐会（4 步脚本）
- [ ] 为每项鉴别素质写出 L1-L4 四级行为锚
- [ ] 对照 5 大陷阱清单自检（超人谬误 / 后视镜偏差 / 光环抄袭 / 空洞素质 / 隐性偏见）
- [ ] 执行"画像压力测试"：盲测 3 份简历 + 外部同行验证 + 反向生成 5 道面试题
- [ ] 将逆向塑模中萃取出的面试问题写入面试题库
- [ ] 与三方对齐确认画像保质期（战略调整 / 满 3 人 / 6 个月）

#### 关键输出

**人才画像文档**，包含：
- 画像名称 + 版本号 + 保质期
- 业务战场描述（这个岗位要打什么仗）
- 逆向塑模摘要：绩优者独有特征 vs 失败者高频模式
- 冰山上门票项（知识/经验/技能——具体的，非泛化的）
- 冰山下鉴别项（能力/个性/动机 + 完整 L1-L4 行为锚）
- 深海层终局项（归因模式 / 认知弹性——面试中通过特定话术探测）
- 从失败案例萃取出的 3 个必问面试题
- 画像盲测结果（三位盲测者评分一致率）
- 画像共创参与方及对齐确认

#### 质量标准

> **画像应具体到：任意两个面试官独立评估同一份简历，打分差 ≤ 1 分。**
>
> 如果打完分还需要开会讨论"你觉得这个人怎么样"——说明画像的行为锚还没写到位。

#### 🔄 补充方法论：技能市场校验 — A+B 混合方案（来源：jd-resume-matcher）

**目的**：在确定 JD 技能清单后，校验其市场合理性——防止写出「市场不存在的技能组合」而浪费招聘周期。

**执行流程**：

```
岗位名称 + JD 技能清单
        ↓
步骤 0：岗位画像匹配
  → 在岗位画像库中精确匹配 + 模糊匹配
  → [兜底] 无匹配 → WebSearch 搜索，构建临时画像，置信度降一级
        ↓
步骤 1：A 方案 — 静态知识库校验
  → 对照技能分类库（15大类500+技能）检查
  → 输出：遗漏技能、过时技能、新兴技能（含热度标记）
        ↓
步骤 2（可选，深度分析时启用）：B 方案 — AI 语义推理
  → 用 AI 判断最新技术趋势下的技能合理性
  → 合并 A+B 结果
        ↓
步骤 3：输出结果
  → 🟢 合理区：市场有供给，招聘周期可预估
  → 🟡 警示区：技能组合稀缺，建议拆为两个岗位或放宽某维度
  → 🔴 高危区：技能要求存在矛盾或市场几乎无供给
```

**关键校验维度**：

| 校验项 | 检测内容 | 典型问题 |
|--------|---------|---------|
| 遗漏技能 | JD 缺失但岗位标配的核心技能 | 「招前端没写 JavaScript」 |
| 过时技能 | 已淘汰/被替代的技术栈 | 「要求精通 ActionScript 3.0」 |
| 新兴技能 | 市场需求快速增长但 JD 未提及的技能 | 「AI 产品经理没提 Prompt Engineering」 |
| 矛盾组合 | 不可共存的技能要求 | 「要求 10 年 Flutter 经验」(Flutter 2018 年才发布) |
| 供给预估 | 该技能组合在目标城市的供给量级 | 「深圳 Golang + Rust 双精通的分布式架构师」 |

**置信度说明**：
- 静态知识库命中 → 置信度：⭐⭐⭐（中等）
- AI 语义推理补充 → 置信度：⭐⭐⭐⭐（较高）
- 兜底 WebSearch → 置信度：⭐⭐（较低，报告中标注来源）

**使用时机**：每当用户提交 JD 或要求岗位画像时，在画像定稿前执行一次技能市场校验，降低「海投零收」的概率。

#### 🔄 补充方法论：JD → 人才画像 → 竞品公司清单三件套（来源：izw20269195）

**直觉级认知**：拿到新 JD，先做三件事：吃透在招什么 → 画出可寻访画像 → 列出竞品/同源人才方向。

**输出三件套**：

**① 职位吃透卡**：一句话职位 + 核心职责TOP3 + 硬性门槛 + 加分项 + 红线/慎招 + 薪酬/城市/到岗

**② 人才画像（可搜索标签）**：
- 主画像：职能/年限/行业/能力关键词（方便在猎聘/脉脉等人才库直接检索）
- 备选画像：降维版（年限放宽/行业放宽/职能可迁移）
- 推断项标注"推断"、硬约束标注"【用户确认】"、不编造JD没有的硬性要求

**③ 竞品公司清单**：
- 每家公司附一句"为何可能有同类人才"（如"B公司2024年拆分XX事业部，被动离职池"）
- 标注"待顾问核实"，禁止假装有内部名单
- 分类：T1（直接竞对，人才高度重叠）/ T2（同源人才，需培训转化）/ T3（上下游，技能可迁移）

#### 关键输出

完成步骤 2 后，必须产出以下结构化画像文档：

| 字段 | 必填 | 说明 |
|------|:--:|------|
| 岗位名称 + 级别 | ✅ | 如"技术 VP（合伙人-1 级别）" |
| 业务战场描述 | ✅ | 一句话：这个人在未来 18 个月要打赢的仗是什么 |
| Top 5 必备能力 + 行为锚等级 | ✅ | 每项附 L1-L4 行为锚，标明最低可接受等级 |
| Top 3 一票否决项 | ✅ | 不可妥协的最低门槛（如"必须带过 30+ 人团队"） |
| 逆向失败模式 | ✅ | 该岗位历史上最失败的人的具体行为特征（3 条以上） |
| 三眼对齐结论 | ✅ | 战略眼/专业眼/外部眼各自 top 3 及交叉最大公约 |
| 冰山模型映射 | ✅ | 门票项（冰山上的技能）、鉴别项（冰山下的能力）、终局项（深海层的归因模式） |
| 备选画像（降维版） | 按需 | 年限放宽/行业放宽/职能可迁移时的替代方案 |
| 竞品公司清单 | 按需 | T1-T3 分类 + "为何可能有同类人才" |
| 市场可实现性评级 | ✅ | 🔴 稀缺（<5 人）/ 🟡 有限（5-30 人）/ 🟢 充足（>30 人） |
| 画像保质期 | ✅ | 约定下次审视时间（业务战略调整 / 入职满 3 人 / 6 个月） |

> Agent 输出画像时，上表"必填"字段缺一不可。标注为"推断"的内容必须向用户确认后方可进入步骤 3。
