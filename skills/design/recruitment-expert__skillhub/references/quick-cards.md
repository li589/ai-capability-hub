## 快速作战卡

> 每个步骤的核心方法论浓缩为一张"输入 → 核心检查 → 输出 → 红线"的一页纸卡片。用于日常快速调用，无需翻看完整 WORKFLOW。

### 卡 1：需求诊断

| 字段 | 内容 |
|------|------|
| **一句话心法** | 不治炎症，阻断熵增 |
| **输入** | 业务方提出的招聘需求（一句话即可） |
| **核心检查** | 需求三角（来源-结构-风险） + 伪需求反模式库扫描 + "不投会死的赌注"测试 + 三个免招权信号 |
| **输出** | 需求诊断报告（裁决：启动 / 退回 / 不建议） |
| **红线** | 任一维度落在"伪装的招聘需求" → 不启动 |

### 卡 2：人才画像

| 字段 | 内容 |
|------|------|
| **一句话心法** | 从失败中雕刻成功画像 |
| **输入** | 已通过的需求诊断 + 岗位基本信息 |
| **核心检查** | 逆向塑模 + 三眼共创 30min 对齐会 + L1-L4 行为锚 + 5 大陷阱自检 + 画像盲测一致率 ≥ 80% |
| **输出** | 人才画像文档（门票项 + 鉴别项 + 终局项 + 行为锚） |
| **红线** | 画像盲测一致率 < 80% → 画像未达标，不可发布 |

### 卡 3：渠道策略

| 字段 | 内容 |
|------|------|
| **一句话心法** | 特种作战，不撒网捕鱼 |
| **输入** | 人才画像（已确认） |
| **核心检查** | 人才池四分法 + 人才地图 5-8 家目标组织 + 三阶社交工程触达话术 + 内部推荐定向激活 + A/B 测试框架 |
| **输出** | 渠道策略文档（人才地图 + 触达话术 + ROI 仪表盘） |
| **红线** | 渠道启动时未设 ROI 量化指标 → 不可进入执行 |

### 卡 4：简历筛选

| 字段 | 内容 |
|------|------|
| **一句话心法** | 去伪存真，找决策痕迹 |
| **输入** | 候选人简历 + 人才画像 |
| **核心检查** | 平台杠杆率分析 + 非连续性跳跃判定 + 空窗期二次微积分 + 动词密度扫描 + 预埋 3 个冲突追问 |
| **输出** | 简历筛选报告（含 3 个预埋追问交付面试官） |
| **红线** | 文化价值观不匹配 → 直接排除 |

### 卡 5：面试评估

| 字段 | 内容 |
|------|------|
| **一句话心法** | 穿透剧本，看即兴表演 |
| **输入** | 简历筛选报告 + 面试评价表模板 + BEI 题本 |
| **核心检查** | 三幕结构执行 + 反事实 STAR + 价值排序剥离术 + 黑暗面试法 + 三围独立评分 |
| **输出** | 面试评估报告 + 红黄绿裁决 |
| **红线** | 文化价值观 → 直接淘汰；动力适配性存疑 → 追加面试/背调 |

### 卡 6：薪酬谈判

| 字段 | 内容 |
|------|------|
| **一句话心法** | 反对价不谈钱，锁深层需求 |
| **输入** | 面试评估报告 + 薪酬带宽 |
| **核心检查** | 全面薪酬六维盘点 + 人岗深层需求诊断 + 谈薪十步法 + 三分支反馈处理 |
| **输出** | 薪酬方案 + 三方确认 |
| **红线** | 薪酬方案超出红线预算且无 VP 特批 → 不推进 |

### 卡 7：背景调查

| 字段 | 内容 |
|------|------|
| **一句话心法** | 画风险地形图，不求全好只求坏得可控 |
| **输入** | 候选人信息 + 证明人联系方式 + 黄线验证方向 |
| **核心检查** | 三角闭环（汇报线+协作线+管理线） + 时光机映射法三条话术 + 离职原因压力测试（沉默 ≥ 3s = 高危） |
| **输出** | 背景调查报告（三角印证结论 + 风险标志） |
| **红线** | 发现重大失实或归因偏差 → 重新评估，考虑终止 |

### 卡 8：录用通知

| 字段 | 内容 |
|------|------|
| **一句话心法** | 让候选人在入职前就开始投入沉没成本 |
| **输入** | 薪酬确认方案 + 背景调查结果 |
| **核心检查** | 承诺阶梯设计（第 1/7/20 天） + 红队对抗话术 + 72h 倒计时 + 避坑指南准备 |
| **输出** | Offer + 承诺阶梯执行清单 |
| **红线** | 无背调结论确认 → Offer 不发 |

### 卡 9：数据闭环

| 字段 | 内容 |
|------|------|
| **一句话心法** | 每一次错误都降低下一次犯错的概率 |
| **输入** | 入职候选人全流程记录 + 试用期绩效数据 |
| **核心检查** | 混淆矩阵更新 + 45 天/90 天快速复盘会 + TOP 3 有效/误导问题迭代 + JD 反灌 + 季度漏报率 |
| **输出** | 招聘数据闭环报告（含画像校准 + 题库迭代） |
| **红线** | 试用期触发红线或连续绩效不达标 → 果断止损 |

## 辅助资源卡

> 以下快速卡对应 references/ 目录中非步骤文件，在对应文件不可达时作为降级备份。

### 卡 10：反模式自检

| 字段 | 内容 |
|------|------|
| **一句话心法** | 人的判断是最不可靠的测量工具——用规则对抗偏误 |
| **输入** | Agent 正在执行的评估/建议 |
| **核心检查** | 8 大反模式：①光环效应 ②确认偏误 ③克隆人偏差 ④近因效应 ⑤锚定效应 ⑥群体思维 ⑦过度自信 ⑧沉没成本。每项问"如果判断是错的，第一个暴露的信号会是什么？" |
| **输出** | 自检结论（通过 / 命中反模式 → 回退修正） |
| **红线** | Agent 输出任何招聘评估前必须自检，命中任一反模式不得输出 |

### 卡 11：合规速查

| 字段 | 内容 |
|------|------|
| **一句话心法** | 踩一个坑就是真金白银的赔偿 |
| **输入** | 招聘全链路操作（从 JD 发布到离职） |
| **核心检查** | ①试用期合规（合同期限→试用期上限对应表） ②竞业限制合规 ③五险一金缴纳 ④Offer 撤回法律风险 ⑤离职补偿计算 ⑥招聘歧视红线（性别/年龄/婚育/地域） |
| **输出** | 合规定性裁决（合规 / 存在风险 → 标注法律依据） |
| **红线** | 涉及法律判断时不得替代律师意见——必须加注"建议咨询法务确认" |

### 卡 12：场景路由

| 字段 | 内容 |
|------|------|
| **一句话心法** | 先定角色再定步骤，不做万能客服 |
| **输入** | 用户模糊提问（未命中步骤 1-9 路由） |
| **核心检查** | ①角色判定（HR / 业务负责人 / 高管 / 面试官）→ 切换交互策略 ②意图→步骤路由（模糊→追问 2-3 个定位问题） ③高频场景→话术模板（"帮我筛简历"/"我们招错人了"/"候选人拒了 Offer"） |
| **输出** | 步骤定向 + 角色匹配的交互策略 |
| **红线** | 不确定用户角色时不假设——直接问"你的角色是 HR 还是业务负责人？" |
