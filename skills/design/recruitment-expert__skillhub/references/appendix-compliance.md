## 附录：劳动法与合规实操速查

> **合规是底线，不是可选项。** 踩一个坑就是真金白银的赔偿。本附录覆盖招聘全链路最高频的合规风险点。

### 一、试用期合规

| 合同期限 | 试用期上限 | 常见违规 |
|----------|-----------|----------|
| 3 个月 ≤ 合同期 < 1 年 | 1 个月 | 签 1 年合同设 3 个月试用期 |
| 1 年 ≤ 合同期 < 3 年 | 2 个月 | 签 3 年合同设 6 个月试用期 |
| 3 年及以上 / 无固定期限 | 6 个月 | 试用期到期后以"再观察"为由延长 |

> **铁律**：同一用人单位与同一劳动者只能约定一次试用期。试用期包含在劳动合同期内。试用期工资 ≥ 转正工资的 80% 且 ≥ 当地最低工资。

**HR 实操检查清单**：
- [ ] 试用期长度与合同期限匹配
- [ ] 试用期工资不低于转正工资 80%
- [ ] 试用期工资不低于当地最低工资标准
- [ ] 劳动合同在入职 1 个月内签订
- [ ] 试用期考核标准已在入职时书面告知

### 二、竞业限制合规

| 适用对象 | 限制期限 | 补偿标准 |
|----------|----------|----------|
| 高级管理人员、高级技术人员、其他负有保密义务的人员 | ≤ 2 年 | 月补偿 ≥ 离职前 12 个月平均工资的 30%，且 ≥ 当地最低工资 |

**高频踩坑点**：

| 坑 | 表现 | 正确做法 |
|----|------|----------|
| 全员签竞业 | 对前台/行政/初级岗位也签竞业协议 | 仅限"两高一密"人员（高管/高技/涉密） |
| 不付补偿金 | 签了竞业但不按月支付补偿 | 竞业补偿必须按月支付，3 个月未付 → 劳动者可解除竞业 |
| 违约金过高 | 违约金设为年薪 5-10 倍 | 违约金应与实际损失相匹配，过高可能被法院调减 |
| 竞业范围过宽 | "全国范围内同行业" | 应限定为"有竞争关系的具体企业和业务范围" |

**入职核查**：
- [ ] 候选人是否与前雇主签有竞业协议？
- [ ] 如有，竞业范围是否覆盖我司业务？
- [ ] 如有，竞业剩余期限？
- [ ] Offer 中是否已声明"候选人保证无竞业冲突"？

### 三、五险一金缴纳

| 险种 | 单位比例 | 个人比例 | 基数规则 |
|------|:--:|:--:|------|
| 养老保险 | 16% | 8% | 实际工资（上限 300% 社平，下限 60% 社平） |
| 医疗保险 | 8-10% | 2% | 同养老保险 |
| 失业保险 | 0.5-1% | 0.5% | 同养老保险 |
| 工伤保险 | 0.2-1.9% | 0 | 同养老保险（行业浮动费率） |
| 生育保险 | 0.5-1% | 0 | 同养老保险（已并入医保的地区按医保执行） |
| 住房公积金 | 5-12% | 5-12% | 实际工资（上下限各地不同） |

> **铁律**：入职 30 日内必须办理社保登记。试用期不交社保 = 违法。公积金缴存比例单位和个人必须一致。

### 四、Offer 撤回法律风险

| 场景 | 风险等级 | 法律后果 |
|------|:--:|------|
| Offer 发出后、候选人接受前撤回 | 🟢 低 | 一般不构成违约（要约未承诺），但损害雇主品牌 |
| Offer 发出并接受后撤回 | 🔴 高 | 可能构成缔约过失责任，赔偿候选人信赖利益损失（辞职损失、搬家费等） |
| 背调发现问题后撤回 | 🟡 中 | 须 Offer 中明确约定"以背调通过为前提条件" |
| 体检不合格后撤回 | 🟡 中 | 须 Offer 中明确约定"以体检合格为前提条件" |

> **保护动作**：Offer 中必须加入"本录用通知以背调通过、体检合格、学历验证通过为前提条件，任何一项不满足则 Offer 自动失效"。

### 五、离职补偿计算

| 情形 | N 计算 | 是否 +1 | 备注 |
|------|:--:|:--:|------|
| 协商一致解除 | N | 否 | 劳动者主动提出不补偿 |
| 不胜任工作解除 | N | +1 | 须经培训或调岗，仍不胜任 |
| 经济性裁员 | N | 否 | 须提前 30 日通知工会和全体职工 |
| 违法解除 | 2N | — | 不适用 +1 |
| 劳动合同期满不续签（单位） | N | 否 | 单位不续签才补偿 |
| 劳动合同期满不续签（员工） | 0 | — | 维持/提高条件不续签才不补 |

**N 的计算**：
- N = 在本单位工作年限（满半年算 1 年，不满半年算 0.5 年）
- 月工资基数 = 离职前 12 个月平均工资
- 月工资 > 当地社平工资 3 倍的，按 3 倍封顶，N 上限 12 年
- +1 = 代通知金（未提前 30 日通知时支付，= 1 个月工资）

### 六、招聘歧视红线

| 红线 | 典型违规表述 | 合法替代表述 |
|------|-------------|-------------|
| 性别歧视 | "男性优先""限男性" | "能适应不定期出差（约 X 天/月）" |
| 年龄歧视 | "35 岁以下" | 删除年龄要求，改能力要求 |
| 婚育歧视 | "未婚优先""3 年内不生育" | 删除——此类要求一律违法 |
| 地域歧视 | "XX 省人不招" | 删除——此类要求一律违法 |
| 健康歧视 | "乙肝携带者不招" | "身体状况能胜任岗位日常工作"（非特殊行业不得强制体检乙肝） |
| 学历歧视 | 非必要岗位要求"全日制本科" | 改为"本科及以上学历"或删除全日制限制 |

> **铁律**：凡是与岗位胜任力无直接关系的要求，一律不得出现在 JD 中。JD 发布前应由法务或上级审核措辞。

### 七、Offer 核心条款清单

Offer Letter 必须包含（不限于）：

| # | 条款 | 说明 |
|---|------|------|
| 1 | 岗位名称 + 部门 + 汇报关系 | 不可模糊 |
| 2 | 薪酬结构明细 | 固定工资 + 绩效/奖金 + 补贴 + 股权（如有），拆分到月 |
| 3 | 试用期长度及待遇 | 与合同期限对应的法定上限内 |
| 4 | 生效前置条件 | 背调通过 / 体检合格 / 学历验证 / 竞业无冲突 |
| 5 | 入职材料清单 | 离职证明 / 学历学位证 / 身份证 / 社保公积金账号 |
| 6 | 报到时间 + 失效条款 | "如未在本通知发出后 3 个工作日内书面确认接受，本 Offer 自动失效" |
| 7 | 免责声明 | "本通知不构成劳动合同，具体权利义务以正式签订的劳动合同为准" |
