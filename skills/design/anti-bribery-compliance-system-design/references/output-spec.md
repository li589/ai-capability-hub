> 版本：2.0.0 | 配套技能：anti-bribery-compliance-system-gen

## 1. 输出格式

**主格式**：DOCX（制度文件——合规手册/SOP/违规流程）+ XLSX（表格文件——表格模板/角色矩阵）

**输出形态**：多文件体系——每类文件独立输出，打包为文件夹交付

> ⚠️ v2.0.0 breaking change：从"单HTML/Markdown文件"重构为"多文件DOCX+XLSX体系"。制度文件天然是DOCX格式（正式制度文件行业标准），表格模板天然是XLSX格式（可填写可计算），且每类文件应独立输出便于企业实际使用。详见 `development/CHANGELOG.md`。

> compact 模式说明：O2 SOP（3套核心）+O3 表格（3份核心）+O4 角色职责+O5 违规流程均内联合规手册，不单独生成文件。

### 1.2 交付形态

- 输出为一个文件夹：`{企业名称}-反商业贿赂合规制度文件包/`
- 文件夹内含对应模式的全部文件，按上述清单命名
- 不再生成单一HTML/Markdown汇总文件

## 2. 各输出块详细规格

### O1 合规手册（DOCX）

**文件**：`{企业名称}-反商业贿赂合规手册.docx`

**行数范围**：800-2000行（视企业规模和generation_scope）

**DOCX结构**：

| 部分 | 内容 |
|------|------|
| 封面 | 企业名称+文件标题+版本号+发布日期+"内部底稿，不构成正式法律意见"水印 |
| 目录 | 14章自动目录 |
| 正文 | 14章制度正文（见下表） |
| 页眉 | 文件标题+版本号 |
| 页脚 | 页码+"内部底稿"标注 |

| 第9章 | 财务与非财务控制 | 8.7 财务与非财务控制 |

### O2 SOP文件集（每套独立DOCX）

**每套SOP统一结构**：

| 部分 | 内容 |
|------|------|
| 文件头 | SOP编号+名称+版本号+生效日期+"须结合企业实际情况调整"标注 |
| 正文 | 8段统一结构（见下） |
| 页脚 | 页码+SOP编号 |

**8段统一结构**：

```
1. 目的与适用范围
2. 法律依据
   2.1 FCPA 相关条款
   2.2 UKBA 相关条款
   2.3 中国法相关条款
   2.4 东道国法相关条款（如适用）
   2.5 ISO 37001 相关条款
3. 职责分工
4. 操作步骤（4.1 步骤一 / 4.2 步骤二 / ...）
5. 关联表格模板
6. 异常处理与升级
7. 记录保存要求
8. 修订记录
```

**SOP-05 加速费管控特殊要求**（full/standard模式）：
- 🔴 必须明确标注FCPA狭义例外（§78dd-1(b)）与UKBA无例外的法域差异
- 加速费定义：为加快政府例行非自由裁量行政行为的支付
- FCPA例外适用条件严格（须逐案评估，建议零容忍政策）
- UKBA管辖下执行零容忍

**SOP-01 第三方尽职调查特殊要求**（三模式共用）：
- 尽职调查分级：标准尽调（低风险代理）+ 增强尽调（高风险代理/政府关联）
- 红旗识别：无实际办公地址/受益人不透明/与政府官员有关联/佣金异常
- 调查范围：关联实体→最终受益人→制裁清单→PEP身份→过往合规记录

**SOP-02 礼品招待审批特殊要求**（三模式共用）：
- 限额标准须标注"[需结合企业行业惯例和当地市场标准确定]"
- 分级审批：低额（部门经理）→中额（合规官）→高额（首席合规官）
- 记录要求：金额/对象/事由/审批/时间/地点

**SOP-06 利益冲突申报特殊要求**（三模式共用）：
- 年度申报+重大事项即时申报
- 利益冲突类型：经济利益/雇佣关系/家庭关系/外部职务
- 处理方式：回避/限制/剥离/批准（附条件）

**TM-01 第三方尽职调查问卷关键字段**：
- 基础信息：公司名称/注册地/实际办公地址/成立年限
- 所有权结构：直接股东/间接股东/最终受益人/股权结构图
- 合规承诺：反贿赂合规承诺函签署情况/过往违规记录/正在进行的调查

### O4 角色与职责分配矩阵（full/standard模式，独立XLSX）

**文件**：`{企业名称}-角色职责矩阵.xlsx`

**格式**：矩阵表格

| 岗位 | 合规手册职责 | SOP职责 | 签字权限 | 上报权限 |
|------|-------------|---------|---------|---------|

**岗位层级**（按企业规模和模式调整）：
- full模式（大型企业）：首席合规官→合规经理→区域合规专员→部门合规接口人→业务操作员
- standard模式（中型企业）：合规官→关键部门接口人→业务操作员

**compact模式**：角色职责内联合规手册第3章，不单独生成矩阵文件。

### O5 违规上报与调查流程（full模式，独立DOCX）

**文件**：`{企业名称}-违规上报与调查流程.docx`

**必须包含**：
- 5级上报渠道：操作员→合规接口人→合规官→高管层→外部律师→DOJ/SFO自愿披露
- 调查程序：初步评估→正式调查→事实确认→处置决定→记录保存
- 处置措施分类：内部纪律处分/业务调整/自愿披露/外部报告
- FCPA自愿披露路径：DOJ FCPA Corporate Enforcement Policy——自愿披露+完全合作+及时适当补救→推定不起诉（presumption of declination）
- UKBA自我报告路径：SFO Guidance on Corporate Prosecutions——自我报告+合作是减轻因素
- 记录保存要求：调查全过程记录+5年保存（FCPA要求）+6年（UKBA §7证据保存）

**standard/compact模式**：违规上报内联合规手册第11章，不单独生成独立文件。

## 3. 写作红线

| ID | 红线 | 违反示例 |
|----|------|---------|
| WR-C01 | 合规手册封面必须标注"内部底稿，不构成正式法律意见" | 未标注免责声明 |
| WR-C02 | 每套SOP文件头必须标注"须结合企业实际情况调整" | SOP未标注调整提示 |
| WR-C03 | 东道国法引用如来自上游技能成果，必须标注引用来源 | 直接引用东道国法条文未标注来源 |
| WR-C04 | 加速费管控SOP须明确标注FCPA §78dd-1(b)狭义例外 vs UKBA无例外的法域差异 | 笼统描述"部分国家允许加速费" |
| WR-C05 | UKBA §7"充分预防程序"抗辩须在合规手册政策声明和SOP法律依据中引用 | 仅引用FCPA未提及UKBA §7 |
| WR-C06 | 礼品招待限额不得编造——不确定时标注"[需结合企业行业惯例和当地市场标准确定]" | 编造"礼品限额200美元" |
| WR-C07 | 红旗识别清单≥15条，覆盖五大维度（第三方异常/礼品超限/支付异常/捐赠关联/商业合理性存疑） | 仅列出3-4条红旗场景 |
| WR-C08 | 角色职责矩阵（如有）不得遗漏任何SOP中提及的岗位 | SOP提到"区域合规专员"但矩阵无此岗位 |
| WR-C09 | 违规上报流程须包含DOJ/SFO自愿披露路径选项 | 仅描述内部流程未涉及外部披露 |
| WR-C10 | 不得对合规制度的有效性做出绝对保证 | "本制度确保完全合规/零贿赂风险" |
| WR-C11 | ISO 37001映射须精确到条款号（如"ISO 37001:2016 §8.7"），不得笼统标注 | 笼统标注"符合ISO 37001要求" |
| WR-C12 | 第三方尽职调查SOP中的制裁清单名称须为现行有效版本 | 引用已过时的制裁清单名称 |
| WR-C13 | generation_scope差异须在每个输出块前标注适用的模式标签 | full模式输出包含compact专属限制语句 |
| WR-C14 | 每类文件必须独立输出为一个文件（full/standard模式），不得合并为单一文件 | 将合规手册+SOP+表格揉进一个文件 |
| WR-C15 | 制度文件必须为DOCX格式，表格文件必须为XLSX格式，不得输出为HTML/Markdown | 制度文件输出为HTML/Markdown |

## 4. SOFT_DEGRADED降级输出

当输入严重不足（如仅提供"反商业贿赂合规制度"7字）时，输出最小骨架：

**降级模式输出**：1个DOCX框架文件 + 1个XLSX目录索引

**DOCX框架文件**（`{企业名称}-反商业贿赂合规制度框架（降级模式）.docx`）：

| 部分 | 内容 |
|------|------|
| 封面 | 标注"内部底稿"+"输入不足，结构化框架" |
| 需补充信息 | 1. 企业类型（制造/贸易/能源/制药/金融/科技等） 2. 业务模式描述（销售渠道+客户类型+第三方使用情况） 3. 运营地域清单 4. 企业规模（large/medium/small） |
| 合规手册框架 | 14章框架，每章标注"待补充企业信息后详细展开" |
| SOP目录 | SOP-01~SOP-08名称和统一结构模板（按compact模式预填3套核心） |
| 表格模板目录 | TM-01~TM-08名称 |

**XLSX目录索引**（`{企业名称}-文件目录索引（降级模式）.xlsx`）：

| 文件编号 | 文件名 | 格式 | 状态 |
|---------|--------|------|------|

## 6. DOCX/XLSX生成规格

### 6.1 DOCX生成方式

**格式严肃度**：C-Professional（继承自 base/rule/format-docx/families/opinion/spec.md，合规手册/违规流程属意见书族C-Professional子类）

**生成工具**：python-docx（或调用docx skill）

> **SSOT 继承声明**：本技能 DOCX 排版参数继承 L1 opinion 族 C-Professional 规格（`base/rule/format-docx/families/opinion/spec.md`），未覆盖项自动继承族级默认值，仅声明以下覆盖项：
> - 页边距：上2.5cm/下2.0cm/左2.8cm/右2.6cm（族级默认，无覆盖）
> - 标题字号：一级小二号18pt/二级四号14pt/三级小四12pt（族级默认，无覆盖）
> - 封面："内部底稿"水印（本技能特有——合规制度文件专用标注）
> - SOP文件头：8段编号格式"4.1/4.2/..."（本技能SOP特有）

**DOCX排版规格**：

| 元素 | 规格 |
|------|------|
| 页面 | A4纵向，页边距上2.5cm/下2.0cm/左2.8cm/右2.6cm |
| 正文字体 | 宋体（中文）+ Times New Roman（英文），小四（12pt） |
| 首行缩进 | 2字符 |
| 正文对齐 | 两端对齐 |
| 标题字体 | 黑体（中文）+ Arial（英文） |
| 一级标题 | 小二号（18pt），加粗，居中 |
| 二级标题 | 四号（14pt），加粗，左对齐 |
| 三级标题 | 小四（12pt），加粗，左对齐 |
| 行距 | 1.5倍行距 |
| 段前段后 | 0.5行 |
| 页眉 | 文件标题+版本号，小五（9pt），居中 |
| 页脚 | 页码+"内部底稿"标注，小五（9pt），居中 |
| 封面 | 企业名称+文件标题+版本号+发布日期+"内部底稿"水印 |

**合规手册特殊规格**：
- 封面后插入自动目录（TOC）
- 章节编号采用"第X章"格式
- 法条引用采用脚注格式

**SOP特殊规格**：
- 文件头表格（SOP编号/名称/版本/生效日期/调整标注）
- 步骤编号采用"4.1/4.2/..."格式

### 6.2 XLSX生成方式

**生成工具**：openpyxl（或调用xlsx skill）

**XLSX排版规格**：

| 元素 | 规格 |
|------|------|
| 工作表 | 每份表格含2个Sheet（填写区+填写说明） |
| 表头行 | 冻结首行+首列 |
| 表头样式 | 深蓝底色+白字+加粗+居中 |
| 字段行 | 白底+黑字+左对齐 |
| 必填字段 | 浅黄底色标注 |
| 列宽 | 自适应内容宽度（最小10字符/最大40字符） |
| 字体 | 微软雅黑（中文）+ Calibri（英文），11pt |
| 边框 | 全表细线边框 |
| 数据验证 | 下拉选项/日期格式/数字范围（按字段类型） |
| 签字区 | 底部合并单元格，含填写人/复核人/日期 |

**角色职责矩阵特殊规格**：
- 岗位列冻结
- 职责单元格支持换行
- 权限层级用颜色区分（高=红/中=黄/低=绿）

### 6.3 文件打包

**打包方式**：
- 输出文件夹：`{企业名称}-反商业贿赂合规制度文件包/`
- 文件夹内含对应模式的全部文件（full=19/standard=12/compact=1）
- 可选：压缩为zip包 `{企业名称}-反商业贿赂合规制度文件包.zip`

**文件命名规则**：
- 中文文件名（企业名称部分使用实际企业名称，如未提供则用"XX企业"）
- SOP/表格编号固定（SOP-01~SOP-08 / TM-01~TM-08）
- 版本号体现在DOCX封面和XLSX表头，不体现在文件名中
