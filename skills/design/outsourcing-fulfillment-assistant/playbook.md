# Playbook：委外发货回货助手

## 场景 1：委外发货（供应商推荐）
**用户输入**："A产品、冲压工艺要委外，品质要求高"
**执行过程**：
1. 调用可委外清单接口，取 A 产品冲压工艺的可委外项
2. 调用供应商绩效接口，按良品率排序（品质要求高 → 良品率优先）
3. 向用户展示 Top 供应商及绩效数据，用户确认或改选
4. 调用接口自动生成委外单并执行委外
**产出**：委外单已生成、供应商、发货数量、预计回货日期

## 场景 2：拍照回货
**用户输入**：拍照上传回货单
**执行过程**：
1. OCR/识别回货单内容（委外单号、产品、数量）
2. 调用待回货清单接口核对
3. 按单执行回货
**产出**：回货完成确认 + 回货记录

## 场景 3：供应商绩效查询
**用户输入**："XX供应商的良品率和准交率怎么样"
**产出**：该供应商近一年良品率、准交率、在手委外单数
