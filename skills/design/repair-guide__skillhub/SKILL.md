# Repair Guide — 维修指南

Use when the user mentions 维修、家电故障、怎么修、repair guide、fix appliance、troubleshoot, or asks how to fix household items. NOT for 专业维修服务、电器购买、安全检测.

## 描述

针对常见家电和家居设施的小故障，提供系统化的排查步骤和简单维修指导，帮助用户快速定位问题、评估自修可行性，解决小问题不想花钱请人修、又不知从何下手的困扰。

## 重要限制（请提前告知用户）

- **仅限简单故障**：涉及电路板、压缩机等复杂部件请找专业人员
- **安全第一**：涉及强电（220V）、燃气、高处作业的维修务必谨慎，不确定就找专业人员
- **不承担责任**：所有指导仅供参考，自行维修风险自负
- **无法远程诊断**：只能根据描述推测原因，实际情况需现场判断

## 快速开始

```
用户：空调不制冷怎么办？
→ 提供排查步骤：滤网→制冷模式→遥控器→室外机→制冷剂

用户：洗衣机不排水
→ 分析可能原因（排水管堵/排水泵/程序），给出逐步排查方案

用户：马桶一直流水
→ 判断是浮球还是密封垫问题，提供简单修理步骤

用户：这个问题我能自己修吗？
→ 评估难度和安全性，建议是否需要专业维修

用户：灯泡怎么换？
→ 提供安全更换步骤（先断电等注意事项）
```

## 能力

- 根据故障现象推测可能原因
- 提供系统化的排查步骤（从简单到复杂）
- 评估自修难度和安全风险
- 指导简单维修操作步骤
- 判断是否需要专业维修
- 提供预防性维护建议

## 执行步骤

### Step 1: 了解故障
1. 确认故障设备和型号（如果知道）
2. 了解具体故障现象（什么情况/从什么时候开始）
3. 了解之前是否有异常（漏水/异响/烧焦味）
4. 确认设备是否在保修期

### Step 2: 故障分析
1. 列出可能原因（按可能性排序）
2. 提供逐步排查方法
3. 评估各原因的自修难度
4. 标注安全注意事项

### Step 3: 维修指导
1. 从最简单的检查开始
2. 提供详细操作步骤
3. 说明需要的工具
4. 给出预期效果

### Step 4: 后续建议
1. 预防措施避免再次故障
2. 何时该找专业维修
3. 维修费用参考

## 输出原则

1. **安全置顶**：任何有安全风险的操作都要先提醒
2. **从简到难**：先检查最简单、最可能的原因
3. **步骤具体**：每步操作都要明确到"做什么、看什么、判断什么"
4. **知进退**：明确告诉用户哪些能自己修、哪些必须找专业人员
5. **预防为主**：故障解决后给出预防建议

## 错误处理

| 异常场景 | 提示语 |
|----------|--------|
| 故障描述模糊 | "🔍 能具体描述一下吗？比如：什么时候开始的？有没有异响/漏水/报错代码？" |
| 涉及安全风险 | "⚠️ 这个涉及[高压电/燃气]，强烈建议找专业人员处理，不要自行操作" |

| 缺少工具 | "🧰 这个维修需要[工具名]，如果没有建议不要强行操作" |

## 常见问题（FAQ）

**Q: 我完全不懂维修，能看懂吗？**
A: 我会用最简单的语言描述，一步步来。如果某步不理解可以追问。

**Q: 自己修会不会搞坏？**
A: 简单检查（清洁滤网/检查插头）不会。如果需要拆机，不确定就别动。

**Q: 需要买什么工具？**
A: 大多数简单维修只需要螺丝刀、扳手、万用表。我会在步骤中标注需要的工具。

**Q: 修不好怎么办？**
A: 按我的排查做完还不行，基本可以确定需要专业维修了。至少你能准确描述问题给师傅。

**Q: 保修期内该自己修吗？**
A: 不建议。保修期内自行拆机可能丧失保修资格，直接联系售后更好。

**Q: 什么情况必须找专业人员？**
A: 涉及强电(220V)接线、燃气管道、制冷剂加注、高处作业的一律找专业人员。

## 最佳实践

1. **先查保修**：动手前确认是否还在保修期
2. **先断电/关阀**：任何维修操作前先切断电源或关闭水阀/气阀
3. **拍照记录**：拆任何东西前先拍照，方便恢复
4. **搜索型号**：知道具体型号的话，搜索该型号的常见问题会更有针对性
5. **准备好工具**：开始前确认工具齐全，避免中途尴尬

## 不适用场景

| 场景 | 原因 | 替代方案 |
|------|------|----------|
| 涉及强电接线 | 安全风险高 | 找持证电工 |
| 燃气设备维修 | 有爆炸风险 | 找燃气公司 |
| 家电购买选择 | 不做产品推荐 | 查看评测网站 |
| 装修改造 | 超出维修范畴 | 找装修公司 |

### 常见误用

- **误用 1**：带电操作 → 任何电器维修务必先拔插头或断开总闸
- **误用 2**：忽略安全提醒 → 安全提醒不是废话，请认真对待
- **误用 3**：超出能力硬修 → 判断自己搞不定时及时止损找专业人员
