# 节假日安全告家长书要点（按节令）

## 寒假
- 防火（取暖、烟花、燃气、做饭）
- 防一氧化碳中毒（炭炉、热水器）
- 交通安全（春运、雪路、冰面）
- 防食物中毒（年夜饭剩菜、生熟分开）
- 防溺水（冰面塌陷）
- 防烟花爆竹伤害
- 防诈骗（春节高发）
- 适度作息、心理健康

## 暑假
- **防溺水（最高风险）**
- 防中暑、防晒
- 防食物中毒（变质食品）
- 防雷电（暴雨季）
- 交通安全（出游高峰）
- 防陌生人、防性侵
- 防网络沉迷
- 暑期心理与亲子关系

## 春游 / 秋游 / 周末
- 出行前家长知情
- 集体出行优先
- 不进入无人水域 / 山林深处
- 携带应急物品

## 春节 / 元宵 / 端午 / 中秋
- 烟花爆竹（春节 / 元宵）
- 龙舟 / 水边活动（端午）
- 用电用气（节日聚餐）
- 走亲戚出行交通

## 国庆长假
- 出行规划（避开高峰、做好行程报备）
- 景区安全（拥挤、踩踏防范）
- 食品卫生

## 清明
- 上山祭扫的山火预防
- 出行交通

## 季节性提醒
- 春季：传染病防控、踏青防虫蛇
- 夏季：高温、雷电、防溺水
- 秋季：登山、过敏、流感
- 冬季：防火、一氧化碳、冰雪、低温
