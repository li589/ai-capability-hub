# 安全教育主题官方口径库（请勿擅自改写）

## 防溺水"六不一会"
**六不**：
1. 不私自下水游泳；
2. 不擅自与他人结伴游泳；
3. 不在无家长或老师带领的情况下游泳；
4. 不到无安全设施、无救援人员的水域游泳；
5. 不到不熟悉的水域游泳；
6. 不熟悉水性的学生不擅自下水施救。
**一会**：会基本的自护、自救方法。
**遇险时**：呼救、不手拉手救援，记住"叫叫伸抛"。

## 防欺凌"四不要"
1. 不要做欺凌者：不参与肢体、语言、网络欺凌他人；
2. 不要做受害者：被欺凌时勇敢说"不"，及时告诉师长；
3. 不要做附和者：不起哄、不传播、不孤立同学；
4. 不要做沉默者：发现欺凌主动告诉老师或拨打举报电话。
**全国学生欺凌防治举报电话：12345 / 当地教育部门**。

## 防诈骗"三不一多"
- 不轻信陌生电话 / 短信 / 链接；
- 不透露身份证、银行卡、验证码；
- 不汇款转账给"未见过面"的网友 / 主播；
- 多与父母、老师商量；
- 国家反诈中心 APP 必装。
- 报警："96110 反诈专线"。

## 网络与信息安全"四不"
1. 不沉迷网络游戏 / 短视频；
2. 不浏览传播不良信息；
3. 不轻信网络谣言；
4. 不向陌生人透露个人 / 家庭信息。
- 教育部要求：中小学生原则上不得将个人手机带入课堂。

## 交通安全"五不"
1. 不闯红灯；
2. 不在马路上嬉戏打闹；
3. 不乘坐"三无"车辆（无牌照、无驾驶证、超员）；
4. 未满 12 岁不骑自行车上路、未满 16 岁不骑电动自行车；
5. 不在车前车后突然横穿。
**乘车规范**：系安全带、不在车内打闹、不把头手伸出窗外。

## 消防 / 用电"四会"
- 会查找隐患（火源、燃气、插座过载）；
- 会扑救初起小火（家用灭火器、湿毛巾捂口鼻、贴地疏散）；
- 会逃生自救（楼道、紧急出口、低姿弯腰、湿巾捂口鼻、不乘电梯）；
- 会报警求救（拨打 119，说清楚位置）。

## 食品安全"五要"
1. 要洗净双手再进食；
2. 要选择正规渠道食品（生产日期、QS / SC 标识）；
3. 要避免暴饮暴食、生冷不洁食物；
4. 要远离三无食品；
5. 要警惕食物过敏。

## 自然灾害（地震 / 雷电 / 台风 / 洪水）
- **地震**：伏地、遮挡、抓牢；远离窗户、玻璃、外墙；震后有序疏散。
- **雷电**：不在大树、电线杆、空旷高地停留；不打电话；远离金属物品。
- **台风 / 暴雨**：减少外出；避开广告牌、临时建筑、低洼路段；不蹚未知积水。
- **极端天气停课**：以教育主管部门 / 学校通知为准，**不擅自返校**。

## 假期安全 "十注意"
1. 防溺水； 2. 防交通事故； 3. 防火防电防燃气； 4. 防食物中毒；
5. 防诈骗； 6. 防网络沉迷； 7. 防欺凌与性侵； 8. 防自然灾害；
9. 防极端情绪 / 心理问题； 10. 注意外出报备与同伴互助。

## 重要全国电话
- 110 报警 / 119 火警 / 120 急救 / 122 交通事故
- 12345 政务服务（含学生欺凌举报）
- 96110 反诈专线
- 12381 教育部学生资助热线

> 各类口径以教育部、公安部、卫健委等最新文件为准。如有不一致，以最新官方口径为准。
