# 安全教育通知

## 用途

为教师产出一份**主题明确、风险点清楚、家校行动具体**的安全教育通知。涵盖中小学生常见安全场景，遵循"教育部七大类安全教育内容"框架。

## 何时使用

- 季节性安全（防溺水、防滑、防火、防雷电、防中暑）。
- 节假日前安全告家长书。
- 校内 / 校外突发事件后的同类风险预防通知。
- 防欺凌、防性侵、防诈骗等专题。
- 极端天气、疫情、公共卫生事件。

## 七大类安全教育主题（教育部口径）

1. **交通安全**：行走、乘车、骑行、过马路。
2. **消防 / 用电安全**：火源、燃气、电器、易燃物。
3. **公共卫生 / 食品安全**：传染病、饮食、个人卫生。
4. **防溺水**：水域识别、救生、不野泳。
5. **校园安全 / 反欺凌**：肢体冲突、网络欺凌、求助渠道。
6. **网络与信息安全**：诈骗、个人信息、不良信息、过度使用。
7. **自然灾害与突发事件**：地震、台风、雷雨、洪水、疫情。

## 输入信息

1. **主题**（必填）：从七大类中选一项或多项。
2. **触发场景**（必填）：常规预防 / 节前提醒 / 突发事件后。
3. **学段 / 年级**（必填）。
4. **风险地域特点**（可选）：是否山区 / 沿海 / 北方寒冷 / 气候多雨。
5. **学校已采取措施**（必填）：教师可在通知中告知家长学校做了什么。
6. **家长 / 学生需做的关键动作**（必填）：3-5 条。
7. **是否需要回执**：默认安全教育通知**强烈建议**有回执（家长签收 + 与孩子共同学习反馈）。

## 工作流程

### Step 1：信息核对
- 风险点是否清楚 / 适合学段。
- 是否已与学校安全工作 / 德育处对齐口径。

### Step 2：按"五段式"成文

#### 1) 标题
- "关于做好__安全教育的告家长书" / "致家长一封信（防__专题）"
- 紧急情况："【紧急】关于__的安全提醒"

#### 2) 风险情境与必要性（让家长重视）
- 用近期 / 季节 / 区域真实数据，但**避免渲染血腥惨剧**。
- 引用权威依据（教育部 / 公安部 / 卫健委 / 当地气象等）。

#### 3) 学校已做的事
- 让家长看到学校的负责态度。

#### 4) 家长须配合（核心）
- 列条目（3-5 条），每条具体到行为。
- 涉及"四不、六不"等口径与教育部口径一致。
- 关键风险点用加粗强调。

#### 5) 回执 + 落款 + 紧急电话
- 必备：班主任 + 学校 + 110 / 119 / 120 / 全国学生欺凌举报电话等相应应急号码。
- 回执：家长 + 学生**共同签字**最佳，体现共同学习。

### Step 3：选用主题口径（不可篡改的官方表述）

下列内容必须严格符合官方口径，引用 `references/topic-bank.md`：
- 防溺水"六不一会"
- 反欺凌"四不要"
- 防诈骗"三不一多"
- 网络安全"四不"
- 假期安全告家长书"十注意"
- 等等

如果是节假日通知，参考 `references/holiday-safety.md` 各节令的具体提醒重点。

### Step 4：版本与格式
默认输出：
- **正式版**（PDF + 家长群文件）
- **群消息版**（≤ 300 字 + 1 张要点图建议）
- **学生口头版**（≤ 80 字，让低段学生能复述）

### Step 5：自检
- [ ] 主题与场景匹配，引用官方口径准确。
- [ ] 没有渲染血腥 / 制造恐慌。
- [ ] 没有把学校职责完全推给家长。
- [ ] 行动指引具体到行为。
- [ ] 应急电话齐全、正确。
- [ ] 适配学段（低段语言简明、配图建议）。
- [ ] 回执机制清晰。

## 输出格式

```
# 关于__安全教育的告家长书

## 一、正式版

## 二、群消息版（≤ 300 字）

## 三、学生口头版（≤ 80 字）

## 四、回执

## 五、合规自检
- 官方口径核对：✓
- 学段适配：✓
- 应急电话：✓
- 风险提示口径：✓
```

## 资源文件

- `references/topic-bank.md`：七大类安全教育主题官方口径库
- `references/holiday-safety.md`：节假日安全告家长书要点

## 禁止事项

- **绝对不要**渲染惨案细节、贴血腥图片。
- **绝对不要**把学校应尽的安保职责完全转嫁给家长（违反学校安全管理条例）。
- **避免**使用"必死""必残"等过激词汇。
- **避免**对孩子使用"羞辱式"安全教育（反而会让孩子隐瞒）。
- **不发布未经核实的"网传案件"**——必须引用官方信息源。
