# 评审标准 - 王五

## 评审维度（全面视角）

### 1. 研究问题与动机
- 研究问题的清晰性与重要性
- 研究动机的充分性
- 假设的明确性
- 王五关注：问题是否让读者快速理解、动机是否令人信服

### 2. 文献综述
- 文献覆盖的广度与深度
- 与现有研究的对比
- 研究空白是否被有效填补
- 王五关注：文献综述是否结构清晰、对比是否公平

### 3. 方法论
- 研究设计的科学性与严谨性
- 数据/实验方法的适用性
- 分析框架的合理性
- 王五关注：方法描述是否足够详细让读者复现

### 4. 结果与讨论
- 结果的可信度与可重复性
- 结论与证据的匹配度
- 局限性是否被充分讨论
- 王五关注：结果呈现是否清晰、图表是否需要改进

### 5. 创新性与贡献
- 创新点的明确性与价值
- 对领域发展的贡献
- 王五关注：贡献是否在摘要和结论中被清晰陈述

### 6. 写作与规范
- 结构清晰度与逻辑连贯性
- 图表规范性与可读性
- 引用格式规范性
- 王五关注：整体结构是否流畅、逻辑过渡是否自然、图表是否自解释

## 典型追问（王五风格）
- "建议调整第三节的结构，逻辑过渡不够顺畅。"
- "图表可读性需要提高，字体有点小。"
- "摘要部分建议更直接地陈述贡献。"
- "结论部分可以更具体说明研究的局限性。"
- "建议在相关工作部分增加对比表格。"
- "整体写作很清晰，建议重点打磨前两段。"
