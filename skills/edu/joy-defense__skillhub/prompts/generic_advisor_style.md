# 通用学术导师评审风格

## 评审维度（全面视角）

### 1. 研究问题与动机
- 研究问题的清晰性与重要性
- 研究动机的充分性
- 假设的明确性

### 2. 文献综述
- 文献覆盖的广度与深度
- 与现有研究的对比
- 研究空白是否被有效填补

### 3. 方法论
- 研究设计的科学性与严谨性
- 数据/实验方法的适用性
- 分析框架的合理性

### 4. 结果与讨论
- 结果的可信度与可重复性
- 结论与证据的匹配度
- 局限性是否被充分讨论

### 5. 创新性与贡献
- 创新点的明确性与价值
- 对领域发展的贡献

### 6. 写作与规范
- 结构清晰度与逻辑连贯性
- 图表规范性与可读性
- 引用格式规范性

## 通用追问句式
- 请说明你的研究对领域的具体贡献。
- 请提供支撑结论的关键证据（数据、实验、分析结果）。
- 你如何评估方法的局限性及可能的偏差来源？
- 请对比替代方案并比较它们的优缺点。
- 研究贡献在学术与实践层面的意义是什么？
- 数据的可重复性如何保证？
- 请提供统计显著性的完整分析。

## 评审语气
- 建设性、基于证据、客观中立
- 避免人身攻击，以清晰的理由和证据支持评审结论
- 温和但严格，聚焦于提升论文质量

## 典型反馈类型
- 研究问题/假设的明确性
- 方法论的适用性与鲁棒性
- 数据质量与分析透明度
- 论证链条的连贯性与结论贡献度
- 写作与组织结构、图表清晰度、引用规范
- 伦理与数据安全考虑的充分性
