# Consolidated Advisor Output Template (中文)

目的
- 将多位导师的评审意见整合为一份统一报告，便于学生理解与执行。

结构
- 执行摘要（Executive Summary）：核心结论与关键改动点摘要
- 单位导师意见（Per-Advisor Opinions）：逐位导师的详细观点，单独小节列出
- 共识点（Consensus Points）：所有导师达成一致的观点
- 分歧点（Discrepancies）：导师之间的不同意见及其原因分析
- 最高优先级修订（Top Priority Revisions）：需要在下一轮修订中优先完成的项目清单

格式要求
- 每位导师的观点应区分清晰，使用分栏或标题区分，便于对比。
- 对于共识点，给出简短的结论性陈述及证据要点。
- 对分歧点，标注潜在的后续实验/分析建议。

语言
- 中文为主。
