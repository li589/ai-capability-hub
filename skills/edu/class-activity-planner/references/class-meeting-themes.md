# 主题班会素材库

## 开学第一课
- 入学仪式（升旗、宣誓、班级公约）
- 自我介绍创意（三件事 / 一张照片 / 一首歌）
- 学期愿景：班级目标 + 个人目标

## 安全教育（必上）
- 交通、消防、防溺水、防欺凌、防诈骗、网络安全、食品安全
- 形式：情景剧 + 案例 + 演练（不只讲理论）

## 心理健康
- 情绪管理（识别 / 表达 / 调节）
- 压力应对、同伴关系、求助与边界
- 形式：绘本（小学）、短视频（初中）、辩论（高中）

## 学习方法 / 学习习惯
- 时间管理（番茄钟、四象限、周计划）
- 错题归因、阅读策略、高效笔记

## 班级文化建设
- 班徽 / 班歌 / 班训设计
- 班级公约共同制定
- 角色轮值

## 青春期教育（初中尤其重要）
- 身体变化的科学认知
- 情绪与冲突
- 异性交往的边界

## 生涯规划
- 兴趣 / 能力 / 价值观三圈
- 高中阶段重点：选科决策

## 反欺凌
- 欺凌的识别（含网络欺凌）
- 旁观者效应
- 求助渠道

## 网络与媒介素养
- 信息辨识、屏幕时间、网络人际边界、个人信息保护

## 责任与公民意识
- 班级集体荣誉、校园志愿服务

## 阅读与文化
- 共读一本书、文化探源、跨文化比较

## 复盘 / 期末班会
- 班级年度高光、个人成长盘点、下学期 commitment
