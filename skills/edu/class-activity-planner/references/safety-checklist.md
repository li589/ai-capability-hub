# 班级活动安全清单（必查）

## 通用安全
- [ ] 紧急联系人 + 备用联系人电话
- [ ] 校医 / 校园安保 联系方式
- [ ] 最近的医院 + 路线
- [ ] 学生过敏 / 慢性病登记
- [ ] 班级群应急联络通道（家长群 + 教师群）

## 室内活动
- [ ] 用电安全（多媒体设备、电线、插座）
- [ ] 桌椅摆放无棱角风险
- [ ] 通风（雾霾天、流感季注意）
- [ ] 食品来源（自制食品避免，统一采购更安全）
- [ ] 食物过敏调查（坚果、海鲜、乳制品、麸质）

## 室外活动
- [ ] 天气预报 + 雨天预案
- [ ] 紫外线 / 中暑预防（防晒、补水）
- [ ] 运动伤害预防（热身、护具、规范动作）
- [ ] 走失预案（编组 + 联络员 + 集合点）
- [ ] 防溺水（有水域时严禁脱队）

## 校外研学
- [ ] 校外审批 + 校长签字
- [ ] 家长知情同意书 + 应急授权书（每生 1 份）
- [ ] 班车 / 司机 / 行驶证 / 保险 资质核查
- [ ] 双教师带队（最少 1:15 师生比）
- [ ] 出发前点名 + 中途点名 + 返程点名（每段必做）
- [ ] 学生统一标识（帽子 / 手环）

## 心理安全
- [ ] 不强制学生公开分享隐私话题
- [ ] 不让学生独自承担情绪冲击
- [ ] 提供"暂停"机制

## 隐私与影像
- [ ] 拍照、录像、对外发布需家长签字同意
- [ ] 不公开班级排名、成绩、家庭情况
- [ ] 班级影像不得上传公网商业平台

## 应急通讯
- [ ] 教师手机充电 + 备用电源
- [ ] 大型活动配急救包（创可贴、消毒、止血、晕动药）
- [ ] 通知家长机制（事故 30 分钟内必须通知）

## 活动后
- [ ] 物品归位 + 场地清理
- [ ] 学生身体状况巡查
- [ ] 家长反馈通道开通 24h
