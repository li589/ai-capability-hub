# 班级活动方案

## 用途

为班主任生成一份**目标清晰、流程可执行、安全可控、有教育意义**的班级活动方案，避免"一玩了之"或"只走形式"。

## 何时使用

- 节日活动（中秋、国庆、元旦、教师节、母亲节、儿童节）
- 主题班会（开学第一课、安全教育、心理健康、青春期教育）
- 校园节日（读书节、艺术节、运动会、科技节、合唱比赛）
- 集体活动（生日会、毕业季、研学旅行、志愿服务）
- 学期初团建 / 学期末复盘

## 输入信息

1. **学段 / 年级 / 班级人数**（必填）
2. **活动类型与主题**（必填）：如"国庆主题班会——我和我的祖国"
3. **时间与时长**（必填）：日期、时长（30/45/60 min 或半天 / 一天）
4. **场地**（必填）：教室 / 操场 / 报告厅 / 校外
5. **预算**（必填）：班费 / 学校支持 / 0 预算
6. **关键限制**（如有）：人数限制、家长是否参与、是否需要校外审批
7. **教育目标**（必填，1-3 条）：希望学生从中收获什么

## 工作流程

### Step 1：明确教育目标 → 反推活动设计
- 不能"先想节目，再凑目标"。
- 把教师给的目标 1-3 条，**每一条都对应至少 1 个活动环节**。

### Step 2：加载学段特点
读取 `references/stage-*.md` 对应学段：
- 注意力时长 → 单环节时长上限（小学 ≤10-15min/环节，中学 ≤15-20min/环节）
- 心理特征 → 选择适合的互动形式

### Step 3：方案五要素

#### A. 活动基本信息
名称、主题、对象、时间、地点、负责人、分工。

#### B. 教育目标 + 预期成果
SMART 原则：具体、可衡量、可达成、相关、有时限。

#### C. 流程与时间表
按"暖场 → 主体 → 高潮 → 收束"四段式。

每个环节标注：
- 形式：讲述 / 游戏 / 表演 / 讨论 / 展示 / 体验
- 卷入度：**全员参与 > 部分参与 > 观众观看**

#### D. 资源清单
- **物资**：分类列出（场地布置、道具、奖品、食品、媒体设备）
- **人力**：班主任 / 学科老师 / 学生干部 / 家长志愿者 / 校外嘉宾
- **预算明细**：项目 / 数量 / 单价 / 合计 / 来源

#### E. 风险与应急
- 安全风险（场地、食品、运动伤害、过敏、走失）
- 应急流程（紧急联系人、就医路线、家长通知机制）
- 备选方案（雨天 / 设备故障 / 嘉宾失约）

### Step 4：班级特色化设计建议
基于人数、年龄、班级文化建议**至少 2 个有创意的环节**，避免"只朗诵 + 唱歌 + 拍照"老三样。

参考 `references/festival-themes.md` 与 `references/class-meeting-themes.md` 中的素材库。

### Step 5：活动后反思
**不写就不算完整方案。** 包含：
- 学生反馈表（3-5 个开放性问题）
- 教师复盘清单（达成度、亮点、改进点）
- 后续延伸（如"把同学留言整理成班刊""把视频剪辑成毕业纪念"）

### Step 6：自检
- [ ] 教育目标 → 每条都有对应环节
- [ ] 学段适配（注意力 / 体力 / 心理）
- [ ] 全员参与（避免少数人表演 + 多数人观看）
- [ ] 安全预案完整（参考 `references/safety-checklist.md`）
- [ ] 预算清楚、不依赖家长财力
- [ ] 不强制家长出钱出力
- [ ] 不涉及敏感主题（政治、宗教、家庭差异攀比）

## 输出格式

```
# {年级}{班级}{活动名称}方案

## 一、活动基本信息
## 二、教育目标 & 预期成果（SMART）
## 三、活动流程时间表
| 时间 | 时长 | 环节 | 内容 | 形式 | 负责人 | 物资 |
## 四、详细环节脚本（每环节 1-2 段）
## 五、资源与预算
## 六、安全与应急预案
## 七、备选方案
## 八、活动后反思框架
## 附：邀请函 / 家长告知书模板（如需要）
```

## 禁止事项

- **不要**让家长承担过重经济负担；预算应在班费内。
- **不要**强制学生表演 / 才艺展示，尊重内向学生。
- **不要**在活动中拍摄学生身体特征、家庭隐私上传社交媒体。
- **不要**包含与学段不符的内容（如让小学生讨论沉重的政治议题）。
- **不要**安排学生独自外出或脱离教师视线。
