# 特殊学生支持 · 学习障碍学生（学科性持续落后）

## 用途

为一线教师生成针对**学习障碍学生（学科性持续落后）**的**多维支持方案**——课堂支持、作业调整、家校沟通、个别化辅导计划（IEP-style）。

**重要**：本 Skill 不做任何医学/心理诊断性结论。所有"特殊需要"均按"教育层面观察 + 教师专业判断"组织，涉及医学诊断需转介专业机构。

## 何时使用

- 班级中存在 1-2 名表现符合本类画像的学生。
- 该学生的表现已持续 ≥ 4 周，影响学习或社交。
- 教师已与家长 / 学校沟通，需要落地方案。
- 班级"随班就读"学生（已确认有特殊教育需求 / 普特融合教育）。

## 输入信息

1. **学段 / 年级 / 学科背景**（必填）。
2. **观察到的具体表现**（必填，至少 3 条）：
   - 课堂上：……
   - 作业中：……
   - 同伴互动：……
3. **已有的医学 / 心理评估结果**（可选）：仅在家长授权且有正式报告时使用。
4. **家庭支持情况**（必填）：家长是否知情、是否配合、家庭语言。
5. **学校已有支持**（必填）：是否随班就读、是否有资源教室 / 心理老师、是否有助教或同伴支持。
6. **教师可投入资源**：每周可单独辅导时长 / 可调整的座位 / 可改的作业等。
7. **明确目标**：6-8 周内希望看到的具体改变（不要空泛）。

## 工作流程

### Step 1：信息核验 + 隐私保护
- 提醒教师：本方案文档涉及学生个体信息，需严格保密；不能在家长群、教师群外传。
- 学生姓名仅在内部版本使用，对外（家长沟通版）也建议谨慎。

### Step 2：加载学段要点
读取 `references/stage-*.md` 对应学段：注意力时长、心理特征、家校沟通基调。

### Step 3：加载本类专属策略
读取 `references/strategy-card.md` 中针对**学习障碍学生（学科性持续落后）**的画像、课堂 N 招、作业调整、家校建议、红线。

### Step 4：按四维方案输出

#### A. 课堂支持策略
按 `strategy-card.md` 的"课堂 N 招"展开，并结合该生具体表现做个性化适配。
每个策略都给出**具体的怎么做**（动作 + 频率 + 如何记录效果）。

#### B. 作业调整建议
- **量的调整**：减少题目数量，但保留覆盖核心知识点（不是简单"少做"）。
- **质的调整**：简化文本、提供脚手架（题目模板、范例）、允许多模态作答（口头、画图）。
- **时间的调整**：分次完成、给延迟提交空间。
- **形式的调整**：把"长篇阅读"换成"分段阅读 + 图示"等。
- **评价的调整**：关注进步而非排名；可设个人化目标。
- **注意**：调整不是降低期望，**不应让学生感到"被特殊化"**。

#### C. 家校沟通建议
- 与家长共建"共同语言"：用具体行为而非诊断术语描述。
- 明确边界：教师做什么、家长做什么、外部机构做什么（**三角支持**）。
- 沟通节奏：建议每周 1 次小反馈 + 每月 1 次深入对话。
- 涉及医学 / 心理诊断需求，引导家长**自愿地**寻求专业评估，不施压、不暗示孩子有"问题"。

#### D. 个别化辅导计划（IEP-style）

参考 `assets/iep-template.md` 模板填写：
- 学生画像（事实型）
- 优势 / 兴趣（至少 2 条）
- 6-8 周 SMART 支持目标 2-3 条
- 在校 / 在家 / 外部三方支持
- 评估节点（每周 / 每月 / 阶段末）
- 风险预案

### Step 5：输出多版本
- **教师版**（详细，带策略推理）
- **家长版**（语言更柔和、聚焦家庭可做的事，不出现诊断词）
- **学校归档版**（化名、规范）

### Step 6：自检
- [ ] 没有出现"该生有 ADHD / 自闭症 / 抑郁"等结论性诊断。
- [ ] 每条策略都对应具体可观察的行为。
- [ ] 不让学生在同伴面前显得"被区别对待"。
- [ ] 家长版无心理学专业术语。
- [ ] 目标 SMART 可检验。
- [ ] 评估节点清晰。
- [ ] 涉及医学评估只做"建议自愿评估"。

## 禁止事项

- **绝对禁止**作出医学 / 心理诊断（如说"他是 ADHD"）。
- **绝对禁止**在班级、同伴、其他家长面前公开学生的特殊需要。
- **绝对禁止**降低学生在同伴中的尊严（如让他做"特殊作业"被同学看见）。
- **绝对禁止**未经家长同意分享学生评估报告。
- **避免**把所有学习困难都归到"特殊需要"——很多孩子只是节奏慢，需要时间而非标签。
- **避免**把支持方案变成"惩罚方案"。
- **重要**：涉及自伤、伤人、欺凌、性安全等高敏感情况，**立即按学校危机干预流程处理**，不应仅以"支持方案"形式应对。
