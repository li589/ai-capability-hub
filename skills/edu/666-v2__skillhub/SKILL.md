# PPT 生成器

快速生成结构清晰、视觉专业的PowerPoint演示文稿。

## 核心工作流程

### 1. 需求收集

- **主题**：明确PPT的核心主题和目的
- **受众**：了解目标受众（管理层、客户、团队等）
- **页数**：建议8-15页为最佳
- **风格**：商务简约、学术严谨、创意活泼、科技感

### 2. 页面结构规划

标准PPT结构模板：

```
1. 封面页 - 标题、副标题、演讲者信息
2. 目录页 - 内容导航概览
3. 背景/问题页 (1-2页) - 为什么要做这件事
4. 核心内容页 (3-8页) - 主要信息和数据
5. 方案/成果页 (1-2页) - 具体措施或成果
6. 总结/行动页 - 核心结论和下一步
7. 致谢/Q&A页
```

### 3. 内容填充原则

- **一页一主题**：每页聚焦一个核心观点
- **数据可视化**：优先使用图表替代大段文字
- **3秒法则**：观众能在3秒内理解页面要点
- **视觉层次**：标题 > 副标题 > 核心内容 > 辅助说明

### 4. 输出格式

生成的PPT支持：
- `.pptx` 格式（兼容Microsoft PowerPoint/WPS）
- `.pdf` 格式（便于预览和打印）
- `.html` 格式（网页版本便于分享）

## 常用模板类型

### 工作汇报型
- 进度汇报、季度总结、年度汇报
- 强调数据成果、时间节点

### 商业提案型
- 项目提案、投资计划、商务合作
- 强调价值、收益、可行性

### 培训课件型
- 内部培训、知识分享、技能教学
- 强调结构清晰、易于理解

### 产品发布型
- 新品发布、功能介绍
- 强调亮点、差异化、用户体验
