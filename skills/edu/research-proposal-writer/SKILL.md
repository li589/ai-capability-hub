# 课题申报书

## 用途

为一线教师 / 教研员撰写一份**结构规范、问题真实、方法合理、可落地、有传播价值**的教育科研课题申报书。覆盖从校级到省级以上、各级别的常见格式。

## 何时使用

- 学校 / 区 / 市 / 省 / 国家级 教育科学规划 课题申报。
- 教师个人课题、教研组课题、名师工作室课题。
- 课题中期检查报告、结项报告（可衍生使用）。

## 输入信息

1. **课题级别**（必填）：校 / 区 / 市 / 省 / 国家、有无指定课题指南。
2. **课题类型**（必填）：一般 / 重点 / 青年 / 名师专项 / 委托。
3. **学段 / 学科 / 主题领域**（必填）。
4. **教师初步选题构想**（必填）。
5. **拟申报课题的关键限制 / 指南条目**（如有）。
6. **团队情况**：成员构成。
7. **学校支持条件**：经费、设备、合作单位、可获取的数据。
8. **研究周期**：通常 1-3 年。

## 工作流程

### Step 1：选题诊断（这步决定申报成败）

不要急着写。先帮教师做"选题三问"：
1. **真问题**：这是不是教学实践中的真问题？教师能否给出 2 个具体场景例子？
2. **小切口**：题目是否够"小"？建议把研究对象、范围、变量都收紧。
3. **可操作**：方法是否在该校条件下可落实？有没有可获取的数据 / 样本？

输出"选题优化建议"——通常需要把题目"再缩小一个粒度"。

参考 `references/topic-tips.md` 中的"四特征"和"陷阱选题"清单。

### Step 2：拟题
按"研究对象 + 研究问题 + 研究方法 / 视角"模式组装。

### Step 3：加载学段要点
读取 `references/stage-*.md` 对应学段，让"研究内容"与"预期成果"立足该学段真实的教学痛点。

### Step 4：按八章撰写

#### 1. 课题界定与核心概念
对题目里的 2-4 个关键术语下操作性定义。

#### 2. 研究背景与文献综述
- 政策背景（教育部 / 课标）+ 实践背景（学校现状）+ 学术背景（已有研究）。
- 文献综述：3-5 个相关研究脉络梳理，**指出已有研究的空白**。
- 引用至少 8-15 篇文献。

#### 3. 研究目标与研究问题
- 总目标 1 条 + 子目标 2-3 条。
- 研究问题：**疑问句式**，不要陈述句。

#### 4. 研究内容
按子目标拆解 3-5 个研究内容板块。

#### 5. 研究方法
推荐组合（教师课题不要只一种方法）。参考 `references/methods.md`。

#### 6. 研究计划（Gantt 表）
分准备期 / 实施期 / 总结期三阶段，给出**每月**的关键节点。

#### 7. 预期成果与传播
- **过程性成果**：教学案例集、模板、问卷数据。
- **标志性成果**：1-2 篇论文、1 份研究报告、若干公开课、校本课程或教师工作坊。
- **推广方式**：教研组分享、区级展示、期刊投稿、上线教师培训平台。
- **特色与创新点**：1-3 条。

#### 8. 研究团队、保障条件、经费预算、参考文献
- **团队**：分工 + 既有研究基础。
- **预算**：图书资料、调研、数据分析、专家咨询、会议、办公、印刷。
- **参考文献**：按 GB/T 7714 格式，10 篇以上。

### Step 5：质量自检
- [ ] 题目是否够"小"？能用一句话说清研究什么。
- [ ] 文献综述是否指出研究空白？
- [ ] 研究问题是疑问句、可被检验？
- [ ] 方法与问题匹配？
- [ ] 研究计划具体到月，有可观察的里程碑？
- [ ] 预期成果与团队人数 / 周期匹配（不夸大）？
- [ ] 经费分项合理、不超过该级课题上限。
- [ ] 字数符合申报指南要求。

## 输出格式

```
# 《___》课题申报书 · {级别}{类别}

## 一、课题概况
## 二、核心概念界定
## 三、研究背景与文献综述
## 四、研究目标与研究问题
## 五、研究内容
## 六、研究方法
## 七、研究计划（甘特表）
## 八、预期成果与推广
## 九、研究团队
## 十、保障条件
## 十一、经费预算
## 十二、参考文献（GB/T 7714）

## 附：选题优化说明（给教师的内部备忘）
```

## 资源文件

- `references/stage-primary.md`：小学学段教学要点
- `references/stage-junior.md`：初中学段教学要点
- `references/stage-senior.md`：高中学段教学要点
- `references/methods.md`：教育课题常用研究方法速查
- `references/topic-tips.md`：选题与拟题指南（含陷阱清单）

## 禁止事项

- **不要**虚构文献。所有引用必须真实可查；如不确定，标注"[待查]"让教师补。
- **不要**给教师拟"假大空"题目。
- **不要**抄袭已立项课题。
- **不要**让预期成果脱离教师周期与团队能力。
- **不要**承诺过强的因果性结论（教育研究多为相关与解释）。
