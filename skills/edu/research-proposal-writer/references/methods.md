# 教育课题常用研究方法速查

## 文献研究法
- 用途：理论基础、综述、概念界定。
- 来源：CNKI、万方、教育学核心期刊、专著、政策文件。
- 注意：综述要"评"不要"列"。

## 行动研究法（一线教师首选）
- 模型：计划 → 行动 → 观察 → 反思（多轮迭代）。
- 适合：解决具体教学问题。
- 数据：教学日志、学生作业、课堂观察、访谈。

## 个案研究法
- 适合：聚焦 1-2 个学生 / 班级 / 学校的深描。
- 注意：避免推广过度，只能"启示"不能"普适化"。

## 准实验研究
- 模型：对照组 + 实验组（前测 → 干预 → 后测）。
- 教师慎用：班级随机分配难、变量难控制。

## 问卷调查法
- 适合：现状调查、态度测量。
- 注意：样本代表性、问卷信效度。

## 访谈法
- 类型：结构化 / 半结构化 / 开放式。
- 数据：录音转写 + 编码（如三级编码 / 主题分析）。

## 课堂观察法
- 工具：观察量表、录像、师生话语统计。

## 内容分析法
- 适合：分析学生作品、错题、作文、教师板书、教材。
- 步骤：编码体系→ 双人编码→ 一致性检验。

## 数据分析法（量化）
- 工具：Excel、SPSS、Python。
- 常用统计：描述性统计、相关、t 检验、卡方、回归。
