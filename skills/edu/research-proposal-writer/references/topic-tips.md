# 选题与拟题指南

## 优秀课题的"四特征"
1. **真**：来自真实教学问题，不是为申报而申报。
2. **小**：研究对象 / 范围 / 变量足够具体。
3. **新**：在已有研究上有增量。
4. **可**：在教师本职 + 学校条件下能完成。

## 推荐题型套路

| 套路 | 示例 |
|---|---|
| 实践创新型 | "基于__的__教学策略实践研究" |
| 工具研发型 | "__量表 / __模板 / __体系的开发与应用研究" |
| 干预效果型 | "__干预对__学生__能力的实证研究" |
| 现状调查型 | "__学段__问题的现状调查及对策研究" |
| 案例深描型 | "__背景下__典型案例研究" |
| 课程开发型 | "面向__的__校本课程开发" |

## 高频"陷阱选题"（建议规避）

### 陷阱 1：题目太大
- "新课程理念下中学数学教学模式改革研究" → 大而无当。
- 改：聚焦 1 个具体教学环节。

### 陷阱 2：纯概念辨析、无实践抓手

### 陷阱 3：与教师本职无关

### 陷阱 4：因果声称过强
- "AI 写作助手能显著提升学生写作能力的研究" → 控制变量极难。
- 改："AI 写作助手在__情境下对学生__写作行为变化的探索研究"。

### 陷阱 5：方法与问题不匹配

## 题目语言"小手术"清单
- 加方法/视角："实证 / 行动 / 个案 / 对比"。
- 把对象写细："初一""七(3)班""学优生 vs 学困生"。
- 把变量写明："__ 对 __ 的影响"。
- 副标题："——以 __ 为例" 收紧适用范围。

## 课题级别建议
- **校级**：1 个教师 + 1 年 + 1-2 个班级即可完成。
- **区级**：跨班 / 跨年级、有 3-5 人团队。
- **市级以上**：需有跨校样本 / 较强方法支撑。

## 时政与前沿热点
- "双减"背景下作业设计 / 课后服务 / 学业评价
- 新课标 / 核心素养落地
- 教育数字化、AI 与教育融合
- 学习科学（深度学习、项目化学习、跨学科学习）
- 心理健康教育、家校共育、特殊需要学生支持
