# 场景疏导手册

本手册详细描述五种典型备考emo场景的识别要点、疏导策略、话术模板和注意事项。

---

## 一、模考失利型

### 识别要点
- 关键词："模考崩了"、"分数太低"、"又退步了"、"行测/申论才XX分"
- 情绪：挫败感 + 自我怀疑
- 隐含信念："模考分数 = 最终成绩"（这个信念需要被修正）

### 疏导策略

**第一步：接纳挫败感**
- 不要急于说"模考不代表真实水平"，考生此刻听不进去这种话
- 先共情："这个分数确实跟你付出的努力不成正比，难受是正常的"

**第二步：打破"模考=结局"的认知**
- 用事实说话："模考的作用是暴露问题，不是宣判结果"
- 可以提："很多人模考分数最低的时候，反而是最后上岸的时候——因为该踩的坑都在模考里踩完了"

**第三步：引导归因分析**
- 把"我考砸了"转化为"我哪些模块还没到位"
- 从笼统的自我否定 → 具体的模块问题 → 可执行的改进方案

### 话术模板
- "这次模考哪几个模块感觉最吃力？"
- "跟上次模考比，是整体退步了，还是某个模块突然掉了？"
- "错题集中在什么类型——是知识点盲区，还是时间不够做不完？"

### 注意事项
- 如果考生连续多次模考都退步，注意识别是否是方法出了问题，而非简单的"心态波动"
- 不要承诺"下次一定能考好"，用"把问题找到就能针对性提分"代替

## 二、进度焦虑型

### 识别要点
- 关键词："复习不完"、"来不及了"、"时间不够"、"还剩XX天"
- 情绪：失控感 + 紧迫感
- 隐含信念："必须复习完所有内容才能考"（需要被修正）

### 疏导策略

**第一步：共情紧迫感**
- "时间确实紧，这种'还有一堆没看'的感觉特别折磨人"

**第二步：重新定义"复习完"**
- 公考备考不是"复习完才能考"，而是"在有限时间里拿到最高性价比的分数"
- 引导考生区分"必须掌握的"和"可以放弃的"

**第三步：帮考生做减法**
- 梳理剩余时间 → 按模块性价比排序 → 砍掉低性价比内容
- 数量关系（性价比低，可战略性放弃部分）→ 常识（范围太广，不专门复习）→ 言语/判断/资料（核心提分区，必须拿稳）

### 话术模板
- "离考试还有多久？你现在每天能拿出多少小时复习？"
- "如果只能保三个模块，你会选哪三个？"
- "把'复习不完'拆开看——是知识点没过完，还是题没刷够？这两个的解决方法不一样"

### 注意事项
- 不要说"时间还够"——如果真的不够，这种话反而增加焦虑
- 帮考生做时间规划时，留出20%的弹性，不要把计划排满

---

## 三、对比自卑型

### 识别要点
- 关键词："别人都…我还没…"、"群里大神考了XX分"、"同学已经上岸了"
- 情绪：自我否定 + 社交焦虑
- 隐含信念："别人能做到=我做不到=我很差"

### 疏导策略

**第一步：承认比较的本能**
- "看到别人进度快、分数高，心里不舒服，这是人之常情，不用因此觉得自己心态不好"

**第二步：解构"别人"的形象**
- "你看到的别人，往往是他最光鲜的一面——没人会在群里说自己模考考了45分"
- "每个人的基础、备考时长、报考岗位都不一样，横向比较没有意义"

**第三步：建立纵向参照**
- 引导考生跟过去的自己比："跟上个月比，你的资料分析正确率是不是提高了？"
- 用自己的进步曲线替代与他人的横向比较

### 话术模板
- "那个'大神'的备考起点是什么？你们考的是同一个岗位吗？"
- "不看别人，就看你自己——一个月前你觉得最难的模块，现在是不是好一些了？"
- "考公不是选拔'最厉害的人'，是选拔'每个岗位最合适的人'——你的竞争对手没你想的那么多"

### 注意事项
- 不要贬低"别人"来安慰考生（"那些人也就那样"），这会让对话变得廉价
- 如果考生提到具体的社交场景（如备考群、培训班），可以建议适当减少信息摄入

## 四、瓶颈迷茫型

### 识别要点
- 关键词："刷题没用"、"怎么学都提不上来"、"卡住了"、"感觉遇到瓶颈了"
- 情绪：无力感 + 迷茫
- 隐含信念："努力=提分"（当努力不再带来提分时，信念崩塌）

### 疏导策略

**第一步：认可已有努力**
- "能感受到你真的很努力，而且是在认真思考怎么提分，不是盲目刷题"

**第二步：重新定义"瓶颈"**
- "瓶颈不是'你不行了'，而是'旧方法到极限了'——说明你需要换个打法"
- 区分两种瓶颈：知识点瓶颈（需要补盲区）vs 方法瓶颈（需要改变刷题策略）

**第三步：引导方法升级**
- 从"刷题量"转向"刷题质量"：不再追求做题数量，开始做错题归因
- 从"整体刷题"转向"薄弱点专攻"：找到得分率最低的模块集中突破
- 从"被动做题"转向"主动复盘"：每套题做完花30分钟分析错因

### 话术模板
- "你最近刷题的正确率大概在什么水平？哪个模块最低？"
- "做错的题，你一般会回头分析吗？还是对完答案就过了？"
- "你现在刷题是整套做，还是分模块练？"

### 注意事项
- 这类考生最容易从"迷茫"滑向"放弃"，要特别关注是否有放弃信号（"算了吧"、"考不上就考不上"）
- 如果出现放弃信号，先处理情绪，不要急于给方法

## 五、考前恐慌型

### 识别要点
- 关键词："马上考试了"、"怕考不上"、"紧张得睡不着"、"考前焦虑"
- 情绪：恐惧 + 躯体化反应（失眠、食欲变化等）
- 隐含信念："如果考不上=人生完蛋"（需要被修正，但方式要温和）

### 疏导策略

**第一步：正常化考前紧张**
- "考前紧张说明这件事对你重要，完全不紧张反而不正常"
- 避免说"别紧张"——这跟让溺水的人"别挣扎"一样无效

**第二步：把恐惧具体化**
- "你具体在怕什么？是怕某个模块，还是怕整体发挥失常？"
- 模糊的恐惧最折磨人，具体化之后往往发现"也没那么可怕"

**第三步：建立控制感**
- 引导考生关注"能控制的"：考试当天的流程、做题顺序、时间分配
- 减少"不能控制的"的权重：别人的水平、题目的难度、最终的结果

**第四步：降低赌注感**
- "这次考试很重要，但它不是人生的唯一出路——你还有下次，还有其他选择"
- 注意：这步要轻描淡写，不要变成"考不上也没关系"（考生会觉得你不理解他的付出）

### 话术模板
- "考前一周，与其再学新东西，不如把已经掌握的巩固好，确保考场不丢冤枉分"
- "考前可以模拟一下考试当天的流程——几点起床、怎么去考场、做题先做哪个模块，提前在脑子里过一遍"
- "紧张的时候试试4-7-8呼吸法：吸气4秒、屏住7秒、呼气8秒，做三轮就能平静不少"

### 注意事项
- 如果考生提到严重的躯体症状（连续失眠、恐慌发作），建议寻求专业帮助
- 考前最后几天不建议给太多新的学习任务，重心放在心态和状态调整
