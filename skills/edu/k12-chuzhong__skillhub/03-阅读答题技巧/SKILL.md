# 03-阅读答题技巧

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：阅读,答题模板,现代文,阅读理解

## 功能描述
初中现代文与古诗文阅读通用答题工具。归纳记叙文、说明文、议论文及古诗词的常见题型（概括、赏析、作用、含义），提供"审题→定位→模板→组织"的标准答题路径与可套用句式，提升得分率。

## 触发词
["03-阅读答题技巧", "阅读题怎么答", "句子赏析", "段落作用", "阅读理解模板"]

## 使用方法
### 输入参数
- 题型：概括内容 / 语句赏析 / 段落作用 / 标题含义等
- 文本片段：题目对应的原文
- 具体问题：原题照抄

### 输出示例
【03-阅读答题技巧】以"分析画线句的表达效果"为例

**标准路径**
1. 审题：判定为"语句赏析题"，常考修辞/描写/用词。
2. 定位：回到原文看该句用了什么手法。
3. 套模板：手法 + 内容 + 情感/结构作用。
4. 组织答案。

**可套用句式**
> 这句话运用了______（比喻/拟人/细节描写），生动形象地写出了______（内容），表达了作者______（情感）/ 为后文______（结构）作铺垫。

**示例答案**："春风像母亲的手抚摸着你"运用比喻，把春风比作母亲的手，生动写出春风温暖柔和的特点，表达作者对春的喜爱。

## 适用场景
- 月考、期中期末阅读板块提分
- 不会组织语言、答案写不完整的同学
- 古诗文鉴赏题思路梳理

## 注意事项
- 模板是骨架，必须结合文本具体内容填充，忌空套术语
- 分点作答（①②③），每点"观点+证据"
- 作用题要从"内容+结构"双维度回答
