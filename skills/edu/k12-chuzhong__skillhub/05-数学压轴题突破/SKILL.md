# 05-数学压轴题突破

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：压轴题,数学,综合题,二次函数

## 功能描述
初中数学压轴题（函数综合、几何综合、动点问题）解题策略工具。提供"审题分层→建模→分问突破→检验"的通用解法，并给出由易到难的变式训练，帮学生拿到压轴题前 2 问基础分、冲击第 3 问。

## 触发词
["05-数学压轴题突破", "压轴题", "数学最后一题", "动点问题", "二次函数综合"]

## 使用方法
### 输入参数
- 题目类型：二次函数综合 / 几何动点 / 几何代数综合
- 原题：完整题干（含图形条件）
- 卡点：第几问不会、卡在哪一步

### 输出示例
【05-数学压轴题突破】以"抛物线 y=ax²+bx+c 与 x 轴交于 A、B，与 y 轴交于 C，求四边形面积最大"为例

**解题策略**
1. 审题分层：第(1)问代点求解析式（必拿）；第(2)问求对称点/线段；第(3)问"面积最大"→设动点坐标，用含参面积公式求最值。
2. 建模：设动点 P(t, y(t))，把四边形拆成△+梯形，面积 S 表示为 t 的二次函数。
3. 分问突破：第(3)问用顶点公式 t=-b/2a 求最大值，注意 t 的取值范围（定义域）。
4. 检验：代入端点验证，确认在定义域内。

**变式训练（由易到难）**
- 变式1：求三角形面积最大（单图形，更简单）
- 变式2：增加动直线，求面积差最大
- 变式3：改为"周长最小"（需用对称转化）

## 适用场景
- 中考数学第24、25题专项训练
- 平时月考压轴题卡壳
- 冲击高分段的拔高练习

## 注意事项
- 压轴题第(1)问通常简单，先稳拿再攻后续
- 动点题务必先确定自变量取值范围（易丢分点）
- 计算量大，分步写过程，避免一步错满盘皆输
