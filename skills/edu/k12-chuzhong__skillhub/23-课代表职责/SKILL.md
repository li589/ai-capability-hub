# 23-课代表职责

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：课代表,职责,学科,沟通

## 功能描述
初中各科课代表工作清单工具。为语文、数学、英语、物理、化学、政史地生等学科课代表提供标准化职责清单与一日/一周工作流，明确"桥梁作用"，提升学科事务运转效率。

## 触发词
["23-课代表职责", "课代表", "课代表做什么", "学科代表", "课代表工作"]

## 使用方法
### 输入参数
- 学科：如"数学课代表"
- 输出形式：职责清单 / 工作流
- 关注点：收发作业 / 师生沟通

### 输出示例
【23-课代表职责】数学课代表工作清单

**日常职责**
1. 课前：提醒同学准备学具，协助黑板板书课题。
2. 课中：配合老师演示、发材料。
3. 课后：按时收齐作业，登记缺交名单交老师。
4. 反馈：收集同学共性疑问，定期转达老师。

**一周工作流**
| 时间 | 任务 |
|------|------|
| 周一 | 收周末作业，汇总易错点 |
| 周三 | 发批改后作业，督促订正 |
| 周五 | 预告下周预习内容 |

**素养要求**：责任心、公平公正、沟通主动，不做"只收作业"的传声筒。

## 适用场景
- 新当选课代表培训
- 班主任明确岗位要求
- 学科事务流程规范化

## 注意事项
- 课代表是"服务者"非"管理者"，态度要亲和
- 缺交记录客观公正，不包庇不针对
- 遇老师临时调课，第一时间通知全班
