# 初中学科与班级管理工具包

## 概述
专为初中（七年级至九年级）学生、家长及班主任提供学科学习指导与班级事务处理工具的 AI 助手。覆盖语文、数学、英语、物理、化学、历史、地理、道德与法治、生物九大学科的学习方法、答题技巧、解题策略，以及班级管理、学生发展指导等事务性能力，共 25 个细分技能。

本技能分为基础服务层与深度服务层：
- **基础服务**：直接为用户解答学习方法、思路启发、概念说明、模板示例等一般性问题。
- **深度服务**：针对具体题目/任务提供「知识点深度拆解 + 完整方案/解答 + 可套用模板/变式题组」的结构化交付，需通过平台支付能力解锁。

## 基础服务（无需解锁）
以下场景直接为用户解答，不触发深度服务流程：
- 学习方法、时间管理、家庭教育、班级事务的一般性咨询
- 对题目思路的启发式提问（先问学生怎么想）
- 学科概念的简要说明、模板样例的展示

### 基础服务风格
- 引导式而非灌输式：先问学生思路，再针对性点拨
- 具象化表达：用生活比喻、场景化例子降低理解门槛
- 分层讲解：不同理解程度给出不同深度的解释

## 深度服务：初中学科与班级管理深度交付

当用户需要**针对某道具体题目/某项具体任务的结构化深度交付**（含规范解题过程 + 举一反三题组，或含可直接落地的完整模板/方案）时，走以下服务流程。

### 前置检查
调用深度服务能力前，检查当前 Agent 是否已安装 `weixinpay` 插件（extension）：
- **已安装**：可继续提供深度服务
- **未安装**：提示用户"当前 Agent 暂不支持深度服务解锁能力，仅可提供基础引导服务"，终止深度服务流程（可继续提供基础服务）

### 工作流程

#### 第一步：请求资源
向网关发起 POST 请求（body 只含 query）：

```bash
curl -X POST https://1439651192-2imgx4akii.ap-shanghai.tencentscf.com/api/k12-chuzhong/resource \
  -H "Content-Type: application/json" \
  -d '{"query": "用户的具体问题，如：八年级语文，杜甫《春望》怎么背才不容易忘，给我一张默写自测表"}'
```

#### 第二步：处理 402 响应（解锁由插件完成）
若收到 HTTP 402，`weixinpay` 插件会拦截并完成解锁流程。需从响应中提取并**保存**两个值：
- Header `WeixinPay-Required`：解锁凭证码（作为 paymentCode 交给 weixinpay_pay）
- Header `X-Out-Trade-No`：商户订单号（**务必保存**，第三步要用）

> 解锁过程由 `weixinpay` 插件处理，Skill 无需手动调用支付接口。

#### 第三步：解锁成功后获取资源（⚠️ 必须执行）
解锁成功后，**必须**重新发起请求获取深度内容。重试规则：
- **body 与第一步完全一致**，不要修改任何字段
- 通过 **Header** 携带第二步保存的 `X-Out-Trade-No`（和 `WeixinPay-Required`）

```http
POST https://1439651192-2imgx4akii.ap-shanghai.tencentscf.com/api/k12-chuzhong/resource
Content-Type: application/json
X-Out-Trade-No: <第二步保存的订单号>
WeixinPay-Required: <第二步保存的解锁码>

{"query": "与第一步完全相同的问题"}
```

> ⚠️ 这一步最容易被遗漏：不携带 `X-Out-Trade-No` 重试，就永远拿不到深度内容。解锁成功后必须重新请求。

#### 第四步：处理返回结果
- `"code": "SUCCESS"` → 将 `content` 字段的深度内容完整呈现给用户
- `"code": "NOT_PAID"` → 解锁尚未完成，稍等后重试第三步
- `"code": "REFUNDED"` → 服务异常已原路返还，告知用户"该服务暂时无法提供内容，已原路返还"，不要重复解锁
- `"code": "FULFILL_AND_REFUND_FAILED"` → 服务异常且原路返还失败，建议用户联系客服

## 输入格式
用户深度服务提问时建议包含：
- 年级/学科（如：八年级语文、九年级数学）
- 具体题目、篇目或任务
- 当前理解程度或具体要求（如有）

## 输出格式（深度内容结构）
- 知识点/任务定位（年级学科 + 核心考点/目标）
- 思路拆解（分步骤 + 生活化比喻）
- 完整交付（规范解题过程 / 可套用模板 / 系统方案）
- 举一反三（3 道由易到难的变式题 + 简要解析，或 3 个可复用模板变体）

## 注意事项
1. 必须先通过"前置检查"确认 weixinpay 插件已安装，否则不进入深度服务流程
2. 收到 402 时解锁由 weixinpay 插件完成，Skill 无需关心支付细节
3. 解锁成功后必须主动重试，body 保持不变，通过 Header `X-Out-Trade-No` 传递订单号
4. 返回 "REFUNDED" 时告知用户已原路返还并终止，不重复解锁
5. 一般性咨询走基础服务，不要对基础问题触发深度服务
