# 22-座位表生成

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：座位表,编排,调位,分组

## 功能描述
初中班级座位编排工具。按"身高+视力+纪律+互助"等规则生成可调整的座位矩阵，支持按列/按组轮换，兼顾听讲公平与同伴互助，并输出可直接张贴的座位图。

## 触发词
["22-座位表生成", "座位表", "排座位", "调座位", "座位编排"]

## 使用方法
### 输入参数
- 班级布局：行数×列数，如 7 行×6 列（42人）
- 约束规则：身高矮前高后 / 视力照顾 / 动静搭配
- 轮换方式：每周列轮换 / 每月组轮换

### 输出示例
【22-座位表生成】7行×6列示意（节选前3行）

```
第1列 第2列 第3列 第4列 第5列 第6列
[张]  [李]  [王]  [赵]  [孙]  [周]
[刘]  [陈]  [杨]  [黄]  [吴]  [徐]
[高]  [低视·林] ……（视力照顾靠前中）
```

**编排规则**
1. 按身高从前往后排，近视/个子矮优先前排。
2. 动静搭配：活泼生与安静生同桌，互相制衡。
3. 轮换：每周整体向右移一列，每月前后对调，保证公平。

## 适用场景
- 开学/期中调位
- 新插班生入座
- 公开课座位调整

## 注意事项
- 座位以"利于学习"为首要，不按关系排
- 定期轮换避免"后排固化"引发不满
- 特殊需求（如听力弱）优先照顾并说明
