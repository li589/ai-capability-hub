# 16-错题本整理

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：错题本,归因,同类题,复习

## 功能描述
初中错题本规范化工具。提供"原题抄录→错误答案→正确解法→错因归类→同类变式"的五栏模板，引导学生从"改对"上升到"归因"（概念不清/计算失误/审题偏差/思路错误），并定期滚动重做。

## 触发词
["16-错题本整理", "错题本", "怎么整理错题", "错因分析", "错题归类"]

## 使用方法
### 输入参数
- 错题内容：原题与自己的错误解答
- 学科：数学/物理/英语等
- 输出要求：五栏模板 / 错因归类

### 输出示例
【16-错题本整理】五栏模板（以数学题为例）

| 栏目 | 内容 |
|------|------|
| 原题 | 解方程 2(x-1)=x+3，得 x=？ |
| 我的错解 | 2x-2=x+3 → x=5（漏移项变号） |
| 正确解法 | 2x-x=3+2 → x=5？复查：2×5-2=8，5+3=8 ✓（实际正确，属"虚惊"）改为示错：得 x=1（未移项） |
| 错因归类 | 计算失误（移项未变号） |
| 同类变式 | 3(x+2)=2x+7，先自查再对答案 |

**错因四分类**：①概念不清 ②审题偏差 ③计算失误 ④思路错误。
**滚动规则**：错题按"当天→3天后→一周后"三次重做，全对才可归档。

## 适用场景
- 建立个人错题体系
- 考试前针对性复习
- 家长/老师检查学习漏洞

## 注意事项
- 不抄整卷，只收"有价值"的题（非纯粗心可略）
- 同类题归一类，避免错题本变题海
- 重做比抄写重要，动手算才真掌握
