# 17-笔记方法指导

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：笔记,康奈尔,思维导图,学习方法

## 功能描述
初中生笔记方法教学工具。介绍康奈尔笔记法、思维导图法、提纲法、符号标记法等适合不同学科的记法，给出模板与适用场景，帮学生把"抄板书"升级为"结构化记忆"。

## 触发词
["17-笔记方法指导", "笔记方法", "康奈尔笔记", "思维导图", "怎么记笔记"]

## 使用方法
### 输入参数
- 学科/课型：如"历史课""数学复习"
- 偏好：图文结合 / 条理清晰
- 输出要求：方法讲解 + 模板

### 输出示例
【17-笔记方法指导】康奈尔笔记法（通用）

**版面划分**
```
┌─────────────┬──────────┐
│ 主栏（听课记录）│ 线索栏（关键词/问题）│
├─────────────┴──────────┤
│ 总结栏（课后一句话概括）      │
└────────────────────────┘
```
**用法**：课中填主栏；课后左侧写关键词/自测问题；底部写总结。复习时遮住主栏，看线索栏回忆。

**方法选择建议**
| 学科 | 推荐方法 |
|------|----------|
| 语文/道法 | 提纲法 + 符号标记 |
| 数学/物理 | 例题+错因批注 |
| 地理/生物 | 思维导图 |

## 适用场景
- 新生学习习惯养成
- 复习时笔记不会用
- 不同学科记法优化

## 注意事项
- 笔记是"思考记录"非"板书复印"，留白写疑问
- 当天整理胜过周末补，趁热打铁
- 思维导图重"层级关系"，别写成罗列
