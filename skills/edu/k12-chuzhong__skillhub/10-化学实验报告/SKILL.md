# 10-化学实验报告

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：化学,实验报告,现象,结论

## 功能描述
初中化学实验报告撰写工具。提供标准实验报告结构（目的、原理、用品、步骤、现象、结论、反思），指导学生规范记录实验现象、用化学语言表述结论，并避免"把结论当现象"等常见错误。

## 触发词
["10-化学实验报告", "化学实验", "实验报告怎么写", "实验现象", "探究报告"]

## 使用方法
### 输入参数
- 实验名称：如"制取氧气""探究酸碱中和"
- 实验类型：验证性 / 探究性
- 输出要求：完整报告框架 / 现象结论撰写

### 输出示例
【10-化学实验报告】以"实验室用高锰酸钾制氧气"为例

**标准结构**
| 栏目 | 填写要点 |
|------|----------|
| 实验目的 | 掌握加热固体制气方法与收集 |
| 实验原理 | 2KMnO₄ △ K₂MnO₄+MnO₂+O₂↑ |
| 实验用品 | 试管、酒精灯、水槽、集气瓶… |
| 实验步骤 | 查气密性→装药→固定→加热→收集→撤管→灭灯 |
| 实验现象 | 导管口有______（气泡）冒出，集气瓶水被排出 |
| 实验结论 | 高锰酸钾受热分解生成氧气 |

**现象 vs 结论区分**
- 现象：看到的、听到的、闻到的（如"带火星木条复燃"）
- 结论：推出来的（如"说明生成了氧气"）

## 适用场景
- 分组实验后撰写报告
- 实验操作考试答辩准备
- 探究性实验方案设计

## 注意事项
- 现象只写"可观测量"，不提前写结论
- 步骤用"动词开头"的祈使句，简洁可操作
- 药品用量、安全事项（如验纯）必须写明
