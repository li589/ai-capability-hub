# 12-地理读图训练

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：地理,读图,地图,图表

## 功能描述
初中地理图表信息提取工具。训练等高线图、气候类型图、人口柱状图、政区图等常见图件的读图步骤，教授"看图名→看图例→看坐标轴→提取结论"的方法，提升图表题得分。

## 触发词
["12-地理读图训练", "地理读图", "等高线", "气候类型图", "地理图表"]

## 使用方法
### 输入参数
- 图件类型：等高线 / 气候图 / 人口图表 / 政区图
- 读图任务：判断地形 / 判读气候 / 提取数据
- 输出要求：读图步骤 + 结论

### 输出示例
【12-地理读图训练】以"等高线图判地形"为例

**读图四步**
1. 看图名与比例尺：确认是什么区域、实际范围。
2. 看等高距：相邻线差值（如 100m）。
3. 看闭合与疏密：中心高四周低→山顶；等高线重合→陡崖；向高值凸→山谷（易发育河流）。
4. 提取结论：甲地坡度缓（线疏），乙地易发生河流（山谷）。

**气候图判读口诀**：
> 以"温"定带（最冷月均温>15℃为热带），以"水"定型（夏雨型/年雨型/冬雨型）。

## 适用场景
- 地理图表题专项训练
- 等高线、气候类型判读困难
- 中考地理读图提速

## 注意事项
- 任何图先读"图名+图例+单位"，再下结论
- 等高线"凸高为谷、凸低为脊"是高频考点
- 气候图先看最冷月温度定带，再看降水定类型
