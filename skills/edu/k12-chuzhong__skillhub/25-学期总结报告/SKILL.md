# 25-学期总结报告

## 基本信息
- 版本：1.0.0
- 分类：K12初中
- 标签：学期总结,班级总结,个人总结,复盘

## 功能描述
初中班级/个人学期总结报告工具。提供总结框架（成绩回顾、亮点与不足、原因分析、改进计划），支持班主任版（班级管理）与学生版（个人成长）两种模板，把"流水账"写成有反思、有行动的复盘。

## 触发词
["25-学期总结报告", "学期总结", "班级总结", "个人总结", "期末复盘"]

## 使用方法
### 输入参数
- 总结主体：班级 / 个人
- 关键数据：成绩、活动、出勤等
- 输出要求：完整框架 / 段落范例

### 输出示例
【25-学期总结报告】班主任版框架（节选）

| 模块 | 写法要点 |
|------|----------|
| 一、总体回顾 | 用数据说话：平均分、达标率、活动获奖 |
| 二、工作亮点 | 2-3 件做得好的事（如自主管理见效） |
| 三、存在不足 | 具体问题（如后进生掉队、卫生波动） |
| 四、原因分析 | 客观归因（方法/配合/习惯），不甩锅 |
| 五、改进计划 | 下学期 3 条可落地举措 + 时间节点 |

**学生版一句话范式**
> 本学期我在______有进步，但______仍薄弱；下学期计划通过______改善。

## 适用场景
- 期末班主任述职/汇报
- 学生素质评价自评
- 家长会材料准备

## 注意事项
- 总结重"反思+行动"，避免只罗列事件
- 数据真实，优点不足都要有，才可信
- 改进计划要具体（谁、做什么、何时），不写空话
