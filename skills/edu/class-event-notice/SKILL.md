# 班级活动通知

## 用途

为班级层面的活动（区别于学校全员通知）生成一份**让家长安心、学生兴奋、教师省心**的通知文本，含活动目标、流程、装备清单、安全提示、家长配合事项与回执。

## 何时使用

- 班级出游 / 研学 / 秋游 / 春游
- 亲子活动 / 家长开放日（班级层面）
- 班级演出 / 文艺汇演 / 比赛
- 公益志愿活动
- 主题班会需要家长准备物品
- 班级生日会、毕业季活动

## 输入信息

1. **学段 / 年级 / 班级 / 人数**（必填）
2. **活动名称 / 主题**（必填）
3. **时间 / 时长**（必填）
4. **地点 / 形式**（必填）：校内 / 校外、室内 / 户外
5. **活动目标**（必填，1-2 条）
6. **学生需准备**（必填）：着装、文具、食物、零钱、电子设备等
7. **是否需要家长参与**：参与方式 / 工作量
8. **费用**（如有）：金额、用途、收款方式（**严禁教师代收**）
9. **风险与应急**：是否离校、是否有过敏 / 慢病关注、是否需保险
10. **回执需求**：是否需要签字、截止时间

## 工作流程

### Step 1：确认要素 + 安全审核
- 校外活动必须有学校审批 + 双教师带队 + 应急预案。
- 涉及水域、山地、夜间活动，建议教师重新评估。

### Step 2：加载学段特点
读取 `references/stage-*.md` 对应学段。

### Step 3：按"七要素"成文

1) **标题**：清晰、不超 25 字。
2) **活动主旨**：50-80 字描述意义。
3) **活动安排**：精确到分钟的时间表。
4) **学生准备清单**：穿、装、食、用、记 五类。
5) **家长配合**：必填或选填，避免过重负担。
6) **安全提示与应急联系**：班主任 + 副带队 + 学校应急。
7) **回执**：学生姓名 / 班级 / 是否参加 / 过敏 / 紧急联系人 / 家长签字。

### Step 4：默认产出 3 版
- **正式版**（家长群发图 + 群文件 PDF 用）
- **群消息精简版**（≤ 300 字）
- **学生口头通知版**（教师在班里念，≤ 100 字）

### Step 5：合规性自检（参考 `references/safety-checklist.md`）

- [ ] 校外活动是否已学校审批
- [ ] 双教师 + 师生比 ≤ 1:15（小学），≤ 1:20（中学）
- [ ] 不强制收费、不通过教师私人账户收款
- [ ] 不涉及商业推广 / 第三方培训机构
- [ ] 应急联系 + 备用渠道
- [ ] 学生 / 家长隐私 / 影像授权说明
- [ ] 时间 / 路线 / 集合点准确无歧义
- [ ] 学生 / 家长可选择不参加，无歧视

## 输出格式

```
# 关于__活动的通知

## 一、正式版
（标题 + 称呼 + 主旨 + 安排 + 准备 + 家长配合 + 安全 + 回执 + 落款）

## 二、群消息精简版（≤ 300 字）

## 三、班内口头通知版（≤ 100 字）

## 四、回执表
- 学生：__ 班级：__
- [ ] 参加  [ ] 不参加（原因可选填）
- 过敏 / 慢病信息：__
- 紧急联系人：__ 电话：__
- 家长签字：__ 日期：__

## 五、合规自检报告
```

## 禁止事项

- **不要**强制学生参加非学校核心安排的活动。
- **不要**让活动通知变成"自费购物清单"。
- **不要**未经审批安排校外活动。
- **不要**通过班级群索取学生身份证号、家长银行卡等敏感信息。
- **不要**通过家长群发布未经家长同意的学生影像。
