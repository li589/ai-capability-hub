# 家长会发言稿 · 班主任版

## 用途

为教师（班主任）输出一份**有逻辑、有数据、有方法、有温度**的家长会发言稿，含开场、班情/学情通报、典型问题与对策、家庭教育建议、Q&A 应对、结束语，以及配套 PPT 大纲。

适用范围：面向班主任主导的全班家长会：开学动员 / 期中分析 / 期末汇报 / 主题班会等。

发言重心：班级整体氛围、班级文化、共性问题、家校共育节奏。

## 何时使用

- 学期初 / 期中 / 期末家长会
- 月考后家长沟通会
- 升学衔接家长会（小升初、初升高、高三动员）
- 主题家长会（青春期、网络使用、心理健康）

## 输入信息

按下列顺序确认；缺关键项必须先问：

1. **学段 / 年级 / 班级 / 学科**（必填）
2. **会议主题**（必填）：开学动员 / 期中分析 / 期末汇报 / 升学衔接 / 专项主题（如手机管理、青春期）
3. **时长**（必填）：通常 30 / 45 / 60 / 90 分钟
4. **班级核心数据**：人数、最近一次大型考试均分 / 排位 / 显著进退、出勤、典型表现
5. **本学期重大事件 / 亮点**（活动、比赛、研学等）
6. **当前最希望家长配合的 2-3 件事**（必填）
7. **听众构成**：父母占比、隔代占比、是否有家长存在沟通障碍历史
8. **是否需要 PPT 大纲**

## 工作流程

### Step 1：确认信息 + 计算"内容预算"

按时长换算可承载的字数：
- 30 min ≈ 4000-5000 字（含互动）
- 45 min ≈ 6000-7000 字
- 60 min ≈ 8000-9000 字

如果教师主题过多，主动建议"砍 1-2 个、留 3 个"。**家长会最忌大而全。**

### Step 2：加载学段基调

根据教师指定的学段，读取对应 `references/stage-*.md` 的"家校沟通基调"与"特别注意"。

### Step 3：按"五段式"结构成稿

#### 1) 开场（占总时长 ~5%）
- 真诚致谢家长出席（不空话）
- 一句有共鸣的金句或近期班级小故事切入
- 介绍流程与时间安排

#### 2) 班情通报（~20%）
- 本学期班级走过的足迹（用 3-5 个具体事例：而非"学风浓厚"）
- 给家长"看得见"的画面感

#### 3) 学情分析（~30%）
- 总体数据：均分、各分段、与年级 / 上次比较（**不点名学生**）
- 总结突出表现 / 主要问题（每条都有数据 + 教学诊断）
- 关键学科或薄弱环节通报

#### 4) 家庭教育建议 / 家校配合（~30%）
- 围绕教师在 Step 1 中列出的 2-3 件事展开。
- 每件事包含：**为什么重要 → 在校怎么做 → 家庭怎么配合 → 具体可执行动作**。
- **避免说教**：尽量用"我观察到的现象"开头。

#### 5) Q&A + 结束（~15%）
- 列出 5-8 个**家长可能现场提问**的预案（参考 `references/qa-bank.md`）。
- 结束语：1 个具体的近期行动号召。

### Step 4：生成配套 PPT 大纲（如要求）

每章节 1-3 张 PPT 标题 + 要点（每张不超过 5 行字 / 1 张图）。
**禁忌**：把发言稿原文塞 PPT。

### Step 5：自检

- [ ] 全程不出现学生姓名（仅在表扬亮点时教师可用，但需提前征得家长同意；在公开场合点名批评学生**绝对禁止**）。
- [ ] 数据真实、可溯源；不编造排名 / 分数。
- [ ] 教育建议**具体到周内可执行的动作**，避免空话。
- [ ] 语气尊重家长、不居高临下。
- [ ] 时间预算合理：朗读测算（按 200 字/分钟）。
- [ ] 没有横向比较其他班级 / 学校（除非校方明确要求）。

## 禁止事项

- **绝对禁止**在家长会中点名批评具体学生。
- **绝对禁止**公布排名、点名报分数。
- **避免**横向比较其他班级、其他孩子。
- **避免**把家长会开成"控诉会"——每个问题都要给方法。
- **避免**强行要求家长承诺过分负担（如"每天家长批改作业 1 小时"），违反"双减"要求。
