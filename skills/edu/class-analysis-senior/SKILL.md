# 学情分析报告 · 高中

## 用途

把高中教师上传的"考试成绩 / 题目得分明细 / 知识点掌握表"等原始数据，转化为一份**多维度、可执行**的班级学情诊断报告，输出包含：

1. 班级整体表现
2. 分段画像（高 / 中 / 低）
3. 易错题深度分析
4. 薄弱知识点 Top 3
5. 3-2-1 教学建议（3 项立即行动 + 2 项中期调整 + 1 项长期机制）

高中应特别关注新高考赋分制对原始分排名的影响，报告中需区分'原始分位次'与'赋分等级'。

## 何时使用

- 月考、期中、期末考试后做班级分析。
- 单元测验后查找教学薄弱点。
- 期初学情摸底、备课组教研。
- 学校要求提交学情分析报告或质量分析。

## 输入信息（必须确认）

按下列顺序确认；若教师只给了一部分，应先询问其余：

1. **年级 / 学科**（必填）
2. **数据形式**（必填）：
   - A. 学生姓名 + 总分
   - B. 学生姓名 + 各题得分明细（最佳）
   - C. 知识点掌握情况表（教师自评的掌握度，如 OK / 一般 / 不会）
   - D. 多维（A+B+C 都有）
3. **班级人数**（必填）
4. **本次考试基本信息**：考试名称、试卷满分、考试范围（章节/单元）
5. **对照数据**（可选但强烈建议）：
   - 同年级其他班均分、年级整体均分
   - 上一次考试均分（用于趋势对比）
6. **教师重点关注问题**（可选）：如"我担心 A 班尖子生不够拔尖" / "想知道哪些知识点需要重讲"

## 工作流程

### Step 1：数据预处理与确认
- 复述教师提供的数据（条数、字段），让教师确认无误。
- 如果数据缺失关键字段（如题目分布），明确告知"由于无题目级数据，'易错题分析'部分将无法生成"。
- 检查异常值：如 0 分、缺考、成绩超过满分等，与教师确认处理方式。

### Step 2：加载学段要点
读取 `references/stage.md`，了解该学段的评价原则、关注点。
读取 `references/statistics.md`，按其中的指标定义计算。

### Step 3：统计指标计算

按"统计参考"章节计算并输出以下指标。能算的全部算出，不能算的说明原因：

#### 必算指标
- 平均分、最高分、最低分、中位数、众数
- 标准差（衡量班级离散度）
- 及格率（≥60%）、优秀率（≥85%）
- 高分段（前 27%）、中分段（中间 46%）、低分段（后 27%）人数与均分
- 难度系数（每题得分率）
- 区分度（高低分组得分率之差）

#### 趋势指标（如有上次考试数据）
- 班级均分变化、各分段流动情况、退步/进步显著学生名单（变化 > ±10% 或 ±15%，按学段）

### Step 4：分段画像（高 / 中 / 低）

为三个分段分别画像：

- **高分段**：失分主要在哪？是否存在"会而不对、对而不全"？是否有拔尖空间？
- **中分段**：基础是否扎实？哪类题型成为"提分突破口"？
- **低分段**：是基础不牢、习惯不好、还是动力不足？哪些是"重点帮扶对象"（指出具体人数与建议）。

### Step 5：易错题分析

对得分率 < 60% 的题目逐题分析（最多列前 5 题）：
- 题目考查的知识点
- 失分类型分布
- 教学建议（重讲策略、变式训练、错题归因表）

### Step 6：薄弱知识点定位
- 横向：哪些知识点 / 章节 / 题型整体得分率低？
- 纵向：是单点薄弱，还是知识链断层？
- 给出 **Top 3 薄弱点** + **每个薄弱点的补救方案**。

### Step 7：后续教学建议（3-2-1 结构）

- **3 项立即行动**（下一周内可做：如重讲某题、布置错题归因作业）。
- **2 项中期调整**（本月内：如分层辅导、专项练习）。
- **1 项长期机制**（本学期：如建立错题档案、双周质量监测）。

每项建议须包含：**做什么、谁来做、什么时候、怎么衡量效果**。

### Step 8：自检
- [ ] 所有结论都有数据支撑（"约 30% 学生……" 而非"很多学生……"）。
- [ ] 教学建议具体到可操作动作，不出现"加强薄弱环节"等空话。
- [ ] 不点名批评学生（涉及具体学生时使用学号或编号）。

## 资源文件

- `references/stage.md`：高中学段教学要点
- `references/statistics.md`：学情统计指标速查
- `assets/score-template.csv`：成绩录入模板（如教师没有现成数据）

## 禁止事项

- 不要发明数据。如果原始数据不足以得出某结论，明确说明"数据不足"。
- 不要在公开报告中点名批评学生；进步/退步名单只作为给教师的"内部建议"。
- 不要使用"差生 / 学渣"等贬义词；统一使用"学习困难学生 / 重点帮扶学生"。
- 不要凭印象给建议；每条建议都应有数据或学段要点支撑。
