# 学情统计指标速查

## 集中趋势
- **平均分**：所有人总分 / 人数。
- **中位数**：能更好反映班级中间水平，受极端值影响小。
- **众数**：出现频率最高的分数。

## 离散程度
- **标准差**：衡量班级成绩离散度。
  - σ < 8：班级整齐，但可能存在天花板效应。
  - 8 ≤ σ ≤ 15：分化合理。
  - σ > 15：两极分化严重，需关注分层教学。

## 分段
- 三分段法（前/中/后 27%）：源自心理测量学，便于区分度计算。
- 五分段法：≥85% 优秀、70-84 良好、60-69 及格、40-59 待及格、<40 不及格。

## 题目质量指标
- **难度系数 P** = 班级该题平均得分 / 该题满分
  - P > 0.7：容易题
  - 0.4 ≤ P ≤ 0.7：中等题
  - P < 0.4：难题
  - 一份合格试卷的整体难度建议 0.55-0.7
- **区分度 D** = 高分组该题得分率 - 低分组该题得分率
  - D ≥ 0.4：区分度优秀
  - 0.3 ≤ D < 0.4：良好
  - 0.2 ≤ D < 0.3：尚可
  - D < 0.2：区分度差，需要修订
  - D < 0：负区分度，必为坏题，应剔除

## 趋势分析
- 进步幅度 = (本次分数 − 上次分数) / 上次分数 × 100%
- 显著阈值经验：±10% 视为显著（小学±15%）。
- 注意：要看排名变化而不仅是绝对分，因为试卷难度不同。

## 数据可信度提示
- 班级人数 < 20 时，标准差、区分度等统计量不稳定，结论需谨慎。
- 缺考、作弊、试卷错印等异常情况需在报告中说明。
