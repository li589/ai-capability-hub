# 13-班会活动设计

## 基本信息
- 版本：1.0.0
- 分类：K12小学
- 标签：班会,活动,班级

## 功能描述
提供小学主题班会的标准化设计方案，含主题选定、目标、流程、人员分工、互动环节与总结，覆盖常规养成、节日、安全、心理健康等类型。

## 触发词
["13-班会活动设计", "班会", "主题班会", "班级活动", "班队会"]

## 使用方法
### 输入参数
- 年级：一至六年级
- 主题：如 "我爱我班"、"节约粮食"、"防溺水"
- 时长：一般35-40分钟（可选）

### 输出示例
【13-班会活动设计】

**班会：争做时间小主人（四年级，40分钟）**
- 目标：认识时间宝贵，学会做计划
- 流程：
  1. 视频导入《一分钟能做什么》（5分）
  2. 小组讨论：我的一天时间都去哪了（10分）
  3. 制作"课间10分钟计划表"（12分）
  4. 代表分享（8分）
  5. 班主任小结 + 颁发"守时星"（5分）
- 分工：主持人1、记录1、计时1
- 物料：彩纸、计时器

## 适用场景
- 每周例行班会
- 专项教育班会
- 班级文化建设

## 注意事项
- 学生主体，教师引导，避免变成训话
- 流程时间可控，留互动空间
- 主题贴近班级实际痛点
