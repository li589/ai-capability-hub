# 03-看图写话指导

## 基本信息
- 版本：1.0.0
- 分类：K12小学
- 标签：写话,写作,低年级

## 功能描述
面向小学低中年级的看图写话训练，引导学生按顺序观察图画、提取要素、组织语言，完成"谁+在哪里+做什么+怎么样"的基础写话，并逐步加入时间与心情。

## 触发词
["03-看图写话指导", "看图写话", "写话", "看图说话", "低年级作文"]

## 使用方法
### 输入参数
- 年级：一般一至三年级
- 图画要素：人物、地点、事件、时间等已知信息（或请助手虚构合理要素）
- 字数目标：如 "不少于3句 / 50字"（可选）

### 输出示例
【03-看图写话指导】

**一、四步观察法**
1. 看整体：图上有什么人、在什么地方
2. 看细节：他们在做什么、表情怎样
3. 想前后：之前发生了什么、之后会怎样
4. 加修饰：什么时间、天气如何、心情怎样

**二、写话公式**
> 时间 + 谁 + 在哪里 + 干什么 + 结果/心情。
> 例：放学后，小明在操场上拍皮球，他玩得可开心了。

**三、范文（图：女孩浇花）**
春天到了，小红在阳台上给小花浇水。她小心地提着水壶，花儿喝饱了水，张开了笑脸。小红笑了，妈妈说她真是个爱劳动的好孩子。

**四、提升支架**
- 用上"先……再……最后……"写顺序
- 加一个比喻句（像小喇叭一样的牵牛花）
- 结尾写一句想法或感受

## 适用场景
- 一二年级写话起步
- 中年级看图作文铺垫
- 家庭亲子写话练习

## 注意事项
- 不替学生编造违背图意的情节
- 先说后写，口头通顺再落笔
- 鼓励用标点（，。？！），少写错别字优先于华丽辞藻
