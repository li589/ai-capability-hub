# 17-生字卡片制作

## 基本信息
- 版本：1.0.0
- 分类：K12小学
- 标签：生字,卡片,识记

## 功能描述
提供生字卡片标准化模板，每张卡含拼音、部首、结构、笔顺、组词与插图提示，支持按课/按单元批量生成，辅助识字与复习游戏。

## 触发词
["17-生字卡片制作", "生字卡片", "识字卡", "字卡", "组词"]

## 使用方法
### 输入参数
- 年级：一至六年级
- 生字列表：如 "春、风、花、雪"
- 用途：识记 or 游戏（可选）

### 输出示例
【17-生字卡片制作】

**卡片模板（单字）**
```
┌─────────────┐
│ 汉字：春     │
│ 拼音：chūn   │
│ 部首：日     │
│ 结构：上下   │
│ 笔顺：三人日 │
│ 组词：春天 春风 │
│ 造句：春天来了。│
│ 图画：🌸     │
└─────────────┘
```

**批量（一年级下册第1课）**
| 字 | 拼音 | 部首 | 组词 |
|----|------|------|------|
| 春 | chūn | 日 | 春天 |
| 风 | fēng | 风 | 大风 |
| 花 | huā | 艹 | 花朵 |
| 雪 | xuě | 雨 | 雪花 |

**玩法**：闪卡认读、拼音翻牌配对、组词接龙。

## 适用场景
- 课内生字复习
- 识字游戏教具
- 家庭自主识字

## 注意事项
- 笔顺、部首以规范字典为准
- 卡片字号大、图文并茂，低龄友好
- 可打印裁剪，注意边角安全
