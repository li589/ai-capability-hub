# 22-家长沟通记录

## 基本信息
- 版本：1.0.0
- 分类：K12小学
- 标签：家长,沟通,家校

## 功能描述
提供家校沟通的记录模板与话术框架，覆盖日常反馈、问题约谈、表扬通报等场景，帮助教师高效、专业地与家长沟通并留痕。

## 触发词
["22-家长沟通记录", "家长沟通", "家校沟通", "家访", "约谈话术"]

## 使用方法
### 输入参数
- 场景：如 "进步反馈"、"作业拖拉约谈"、"表扬"
- 学生情况：简要背景
- 沟通方式：面谈/电话/微信（可选）

### 输出示例
【22-家长沟通记录】

**记录模板**
| 项目 | 内容 |
|------|------|
| 学生 | 小明（三2班） |
| 日期/方式 | 6.10 电话 |
| 沟通要点 | 近期上课专注度提升，作业正确率提高 |
| 家长反馈 | 在家也愿意先写作业了 |
| 后续跟进 | 保持每周反馈，巩固习惯 |

**话术（表扬型）**
"家长好，想跟您分享个好消息：小明这周上课举手3次，口算全对！看得出他在努力，您在家也可以多夸夸他的细心～"

**话术（问题型，先肯定）**
"小明很有想法，但最近作业漏题较多。我们一起帮他养成'做完检查'的小习惯，您在家提醒他清点题号，我在校也盯一下，好吗？"

## 适用场景
- 班主任日常家校联系
- 问题学生约谈
- 沟通留痕归档

## 注意事项
- 先肯定后建议，语气平等尊重
- 聚焦行为不改人格，不评判家长
- 敏感事项留书面记录，保护双方
