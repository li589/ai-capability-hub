# 20-暑期学习规划

## 基本信息
- 版本：1.0.0
- 分类：K12小学
- 标签：暑期,规划,复习

## 功能描述
为学生定制暑期学习与生活规划，平衡复习巩固、预习提升、阅读与运动，含周计划表、每日作息与学科任务清单，避免"假期滑坡"。

## 触发词
["20-暑期学习规划", "暑期规划", "暑假计划", "假期安排", "作息表"]

## 使用方法
### 输入参数
- 年级：一至六年级（含升年级）
- 重点：如 "补口算"、"预习三年级"、"多阅读"
- 周期：如 "8周"（可选）

### 输出示例
【20-暑期学习规划】

**每日作息（建议）**
| 时段 | 内容 |
|------|------|
| 8:00-8:30 | 晨读（语文/英语） |
| 9:00-10:00 | 数学复习（口算+应用题） |
| 10:30-11:30 | 阅读/练字 |
| 14:30-15:30 | 兴趣/预习新课 |
| 16:00-17:00 | 运动 |
| 20:30 | 亲子共读+熄灯 |

**周任务清单（第1周）**
- 语文：复习一年级生字2课 + 写话2篇
- 数学：口算每日1页 + 错题整理
- 阅读：完成1本绘本/桥梁书

## 适用场景
- 寒暑假学习安排
- 小升初衔接
- 家庭自我管理

## 注意事项
- 留白与弹性，不排满
- 劳逸结合，保证运动与睡眠
- 每周一次小结调整，不僵化执行
