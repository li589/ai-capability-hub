# Thesis Tutor v4.0

> AI论文辅导助手 | 多语言支持 | 本地+云端双引擎

## 简介

Thesis Tutor 是一款智能论文辅导系统，帮助学生从选题到定稿的全流程写作。支持7种语言，覆盖15个学科，结合本地快速响应与AI深度分析，提供专业、高效的论文指导。

## 触发条件

当用户提出以下类型的问题时激活此技能：
- 论文写作相关问题（选题、开题、写作、修改、答辩）
- 学术研究方法咨询
- 文献综述、数据分析指导
- 论文格式、引用规范问题
- 学术英语写作问题
- 使用以下语言：中文、English、日本語、한국어、Français、Deutsch、Español

## 功能特性

### 1. 多语言支持
支持7种语言的论文辅导：
- 🇨🇳 中文 (zh)
- 🇬🇧 English (en)
- 🇯🇵 日本語 (ja)
- 🇰🇷 한국어 (ko)
- 🇫🇷 Français (fr)
- 🇩🇪 Deutsch (de)
- 🇪🇸 Español (es)

### 2. 学科覆盖
覆盖15个主要学科领域：
- 计算机科学、经济学、教育学、工程学
- 法学、文学、管理学、医学
- 心理学、艺术学、理学、农学
- 图书馆学、考古学、体育学

### 3. 双引擎架构
- **本地引擎**：快速响应常见问题，零延迟
- **AI引擎**：深度分析复杂问题（需配置API Key）

### 4. 全流程辅导
- 选题建议与评估
- 开题报告撰写指导
- 文献综述方法
- 研究方法选择
- 论文写作规范
- 修改润色建议
- 答辩准备指导

## 使用方式

### 基本对话
直接输入您的论文问题，系统会自动识别意图并回复：

```
用户：如何选择一个好的论文题目？
助手：选题是论文成功的关键，建议从以下维度考虑...
```

### 配置API Key（可选）
解锁AI深度分析能力：
```
Configure API Key: <YOUR_API_KEY>
```

### 切换语言
```
Switch language to English
切換語言為日本語
```

### 切换学科
```
我的专业是计算机科学
I'm studying Economics
```

## 命令列表

## 知识库结构

```
knowledge_base/
├── {lang}/                    # 语言目录(zh/en/ja/ko/fr/de/es)
│   ├── disciplines/           # 15个学科知识文件
│   ├── academic_writing.md    # 学术写作指南
│   ├── research_methods.md    # 研究方法指南
│   ├── research_tools.md      # 研究工具指南
│   ├── faq.md                 # 常见问题
│   └── thesis_stages.md       # 论文各阶段指南
└── _shared/                   # 共享配置
    └── disciplines.json       # 学科配置
```

## 适用场景

1. **论文选题**：不确定研究方向时获取建议
2. **开题报告**：撰写开题报告的结构和内容指导
3. **文献综述**：学习如何系统性地综述文献
4. **研究设计**：选择合适的研究方法
5. **论文写作**：各章节的写作技巧和规范
6. **格式排版**：引用格式、排版要求
7. **论文修改**：初稿完成后的修改建议
8. **降重技巧**：降低查重率的方法
9. **学术英语**：英文论文写作指导
10. **答辩准备**：答辩PPT和演讲技巧

## 注意事项

- 本地引擎无需网络，可离线使用
- API功能需要网络连接和有效的DeepSeek API Key
- 系统会根据用户语言自动切换回复语言
- 学科信息会影响专业术语和建议的准确性
