# 论文写作阶段指南

## 阶段1：选题诊断

### 选题原则
- **价值性**：学术价值或实践价值
- **创新性**：新视角、新方法、新材料、新结论
- **可行性**：时间、资源、能力匹配
- **明确性**：问题具体，边界清晰

### 选题方法
1. **文献驱动**：发现Gap、矛盾、空白
2. **问题驱动**：实践中遇到的问题
3. **方法驱动**：新方法应用于旧问题
4. **交叉驱动**：跨学科视角

### 选题评估清单
- [ ] 能否用一句话清晰表述研究问题？
- [ ] 是否有相关文献支撑？
- [ ] 数据/材料是否可获取？
- [ ] 6-12个月内能否完成？
- [ ] 导师是否认可？
- [ ] 是否符合专业培养方向？

## 阶段2：开题报告

### 标准结构
1. **研究背景**
   - 宏观背景（社会/学术）
   - 微观背景（具体现象）
   - 问题提出（从背景到问题）

2. **文献综述**
   - 研究脉络（时间/主题/方法）
   - 主要观点（分类梳理）
   - 研究不足（Gap分析）
   - 本文定位（贡献声明）

3. **研究内容**
   - 研究目标（总体+具体）
   - 研究问题（3-5个具体问题）
   - 研究假设（如适用）
   - 技术路线（流程图）

4. **研究方法**
   - 方法论（实证/规范/诠释）
   - 具体方法（定量/定性/混合）
   - 数据来源
   - 分析工具

5. **创新点**
   - 理论创新
   - 方法创新
   - 材料创新
   - 观点创新

6. **研究计划**
   - 时间节点（甘特图）
   - 预期成果
   - 风险与应对

### 开题答辩准备
- 10-15分钟陈述
- 准备回答：为什么选这个题？为什么用这个方法？可行性？
- 记录评委意见，会后修改

## 阶段3：大纲构建

### 大纲类型
- **目录式**：章节标题层级
- **逻辑式**：论点递进关系
- **卡片式**：每段核心内容

### 大纲要素
- 每章核心论点
- 论据/材料/数据
- 与前后章的逻辑关系
- 预计字数

### 大纲检查
- [ ] 逻辑是否连贯？
- [ ] 层级是否清晰？
- [ ] 比例是否均衡？
- [ ] 是否有冗余？
- [ ] 是否覆盖所有研究问题？

## 阶段4：逐章写作

### 写作顺序建议
1. **先写**：文献综述、研究方法（相对独立）
2. **再写**：数据分析、案例研究（核心工作）
3. **后写**：引言、结论（需要全文视角）
4. **最后**：摘要、关键词

### 每章结构
- **引言段**：本章目的、与全文关系、核心内容预告
- **主体段**：论点+论据+分析（PEEL结构）
  - Point：论点
  - Evidence：证据
  - Explanation：解释
  - Link：回到论点/过渡到下一论点
- **结论段**：总结发现、承上启下

### 写作技巧
- **每天定时**：固定时间写作，形成习惯
- **先完成再完美**：初稿不求完美，先写出来
- **段落为单位**：一次写一个段落，降低压力
- **标记待完善**：用TODO标记不确定处

## 阶段5：修改完善

### 自我检查清单
- [ ] 论点是否清晰？
- [ ] 论据是否充分？
- [ ] 逻辑是否严密？
- [ ] 语言是否准确？
- [ ] 格式是否规范？
- [ ] 引用是否完整？

### 修改层次
1. **宏观**：结构调整、章节增删、逻辑重组
2. **中观**：段落重组、过渡优化、论证强化
3. **微观**：词句润色、标点规范、格式统一

### 导师反馈处理
- 区分"必须改"和"建议改"
- 不理解的地方主动沟通
- 修改后标注变化
- 保留修改记录

## 阶段6：格式规范

### 常见格式要求
- **封面**：学校统一格式
- **摘要**：中英文，300-500字
- **目录**：自动生成，三级标题
- **正文**：
  - 字体：宋体/Times New Roman
  - 字号：小四（12pt）
  - 行距：1.5倍或固定值20磅
  - 页边距：上下2.54cm，左右3.17cm
- **图表**：
  - 图题在下，表题在上
  - 编号：图1-1，表2-1
  - 来源标注
- **参考文献**：
  - 格式：GB/T 7714-2015
  - 类型：专著[M]、期刊[J]、学位论文[D]、会议[C]、电子文献[EB/OL]

### 排版工具
- **Word**：样式功能、多级列表、题注
- **LaTeX**：Overleaf、模板
- **参考文献**：EndNote、Zotero、NoteExpress

## 阶段7：查重与答辩

### 查重准备
- **自查**：知网、维普、万方（学校指定系统）
- **降重策略**：
  - 同义替换（保持学术准确）
  - 句式重组（主动被动转换）
  - 图表化（文字转表格/图）
  - 引用规范（直接引用标注）
- **注意事项**：
  - 专业术语保留
  - 公式描述改写
  - 法条/古诗原文不计入（但标注）
  - 参考文献列表不计入

### 答辩准备
- **PPT制作**：
  - 15-20页
  - 研究问题、方法、发现、贡献
  - 图表为主，文字精简
  - 准备讲稿（不是念PPT）

- **答辩问题**：
  - 为什么选这个题？
  - 创新点在哪里？
  - 方法有什么局限？
  - 某个结果怎么解释？
  - 如果重做会怎么改进？

- **答辩礼仪**：
  - 着装正式
  - 时间控制（陈述15-20分钟）
  - 谦虚回应批评
  - 记录修改意见

### 答辩后
- 整理修改意见
- 与导师确认修改范围
- 按时提交修改稿
- 最终格式检查
- 提交电子版和纸质版
