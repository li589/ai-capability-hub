# Guide spécifique à la revue de littérature

## Objectifs de la revue de littérature

### Ce que ce n'est pas
- Une liste de références (qui a fait quoi)
- Un résumé de lectures (présentation article par article)
- Un empilement de citations (montrer qu'on a beaucoup lu)

### Ce que c'est
- Une carte de recherche (panorama du domaine)
- Une participation au dialogue (dialoguer avec la littérature)
- Identification des lacunes (trouver un point d'entrée)
- Cadre théorique (soutenir votre recherche)
- Emprunt méthodologique (apprendre les méthodes de recherche)

## Types de littérature

### Par contenu
- **Littérature théorique** : concepts, modèles, cadres
- **Littérature empirique** : résultats de recherche, jeux de données
- **Littérature méthodologique** : méthodes de recherche, techniques
- **Littérature de synthèse** : méta-analyses, revues systématiques
- **Littérature politique** : rapports, livres blancs

### Par importance
- **Fondatrice (Foundational)** : fondateurs du domaine, citation obligatoire
- **Jalon (Milestone)** : avancées majeures, fréquemment citée
- **État de l'art (State-of-the-art)** : 3-5 dernières années, montrer le front de la recherche
- **Directement pertinente (Directly relevant)** : la plus liée à votre recherche
- **Méthodologique (Methodological)** : emprunt de méthodes

## Stratégies de recherche documentaire

### Choix des bases de données
- **Chinois** : CNKI, Wanfang, VIP, Duxiu
- **Anglais** :
  - Général : Web of Science, Scopus, Google Scholar
  - Sciences sociales : SSCI, PsycINFO, ERIC
  - Médecine : PubMed, Cochrane
  - Ingénierie : IEEE Xplore, ACM Digital Library
  - Économie : EconLit, NBER
  - Droit : HeinOnline, Westlaw

### Techniques de recherche
- **Logique booléenne** : AND (intersection), OR (union), NOT (exclusion)
- **Troncature** : * (joker), ? (caractère unique)
- **Expression exacte** : « expression exacte »
- **Champs** : title:, author:, journal:
- **Piste de citation** : avant (citant), arrière (cité)

### Construction de la stratégie de recherche
1. **Décomposer la question de recherche** : PICO (Population, Intervention, Comparaison, Résultat)
2. **Extraire les mots-clés** : synonymes, quasi-synonymes, termes génériques/spécifiques
3. **Construire l'équation de recherche** : (A OU B OU C) ET (D OU E) ET F
4. **Ajuster et optimiser** : ajuster selon les résultats préliminaires

## Gestion de la littérature

### Outils
- **Zotero** : gratuit, open source, riche en plugins
- **EndNote** : complet, bonne intégration avec Word
- **Mendeley** : fonctionnalités sociales, gestion de PDF
- **NoteExpress** : bon support du chinois
- **Citavi** : gestion des connaissances puissante

### Stratégies de gestion
- **Classification** : par thème, méthode, théorie
- **Étiquettes** : marquage multidimensionnel
- **Notes** : prise de notes pendant la lecture (résumé, évaluation, liens)
- **Synchronisation** : sauvegarde dans le cloud

## Stratégies de lecture

### Lecture par niveaux
1. **Titre + résumé** : juger la pertinence (2 minutes)
2. **Introduction + conclusion** : comprendre la contribution principale (5 minutes)
3. **Lecture approfondie du texte intégral** : littérature clé (30-60 minutes)
4. **Lecture critique** : questionner, évaluer, relier

### Modèle de notes de lecture
`
- Informations de base : auteur, année, revue, titre
- Question de recherche : quelle est la question centrale ?
- Cadre théorique : quelle théorie a été utilisée ?
- Méthodologie : comment l'étude a-t-elle été menée ?
- Principaux résultats : quelles sont les conclusions ?
- Évaluation : avantages, inconvénients, limites
- Lien : relation avec ma recherche
- Valeur de citation : vaut-il la peine d'être cité ?
`

## Structure de la revue de littérature

### Structure chronologique
- Selon l'évolution temporelle
- Montrer la trajectoire de développement
- Adaptée à : recherche historique, développement technologique

### Structure thématique
- Organisation par thème/sujet
- La plus courante
- Adaptée à : la plupart des recherches

### Structure méthodologique
- Organisation par méthode de recherche
- Comparaison de différentes méthodes
- Adaptée à : articles méthodologiques

### Structure théorique
- Organisation par courant théorique
- Comparaison de différentes théories
- Adaptée à : articles théoriques

### Structure par problème (Problème-Cause-Solution)
- Problème → Cause → Solution
- Adaptée à : recherche appliquée

## Techniques de rédaction

### Structure des paragraphes (recommandée)
`
Phrase thématique : cette section discute de...
Présentation de la littérature : A(2010) a constaté... ; B(2012) a souligné...
Analyse comparative : cependant, C(2015) a remis en question...
Synthèse et évaluation : ces études suggèrent...
Transition : mais il reste les lacunes suivantes...
`

### Modes de citation
- **Information mise en avant** : Les recherches ont montré... (Smith, 2010)
- **Auteur mis en avant** : Smith (2010) a constaté...
- **Plusieurs auteurs** : Smith and Jones (2012) / Smith et al. (2013)
- **Plusieurs références** : Several studies (Smith, 2010 ; Jones, 2012 ; Lee, 2015)

### Rédaction critique
- Ce n'est pas « A dit... B dit... C dit... »
- Mais plutôt « A et B soutiennent tous deux le point de vue X, mais C le conteste sur la base de Y, et cet article se range du côté de C, parce que... »
- Utilisation des connecteurs :
  - Accord : Similarly, In line with, Consistent with
  - Contraste : However, In contrast, Conversely
  - Ajout : Moreover, Furthermore, Additionally
  - Résumé : In summary, Taken together, Overall

### Modèles de phrases courants
- **Présenter une recherche** : « In a seminal study, Smith (2010) demonstrated that... »
- **Identifier les limites** : « However, this study was limited by... »
- **Établir des liens** : « Building on this work, Jones (2012) extended... »
- **Identifier les lacunes** : « Despite these advances, little is known about... »
- **Positionner la recherche** : « The present study addresses this gap by... »

## Éviter le plagiat

### Bonnes pratiques
- **Citation directe** : entre guillemets + numéro de page + source
- **Reformulation (Paraphrase)** : avec ses propres mots + source
- **Synthèse (Summarize)** : résumer l'idée principale + source
- **Intégration (Synthesize)** : synthèse de plusieurs sources + sources multiples

### Techniques de reformulation
- Modifier la structure de la phrase (actif/passif)
- Remplacer les synonymes (maintenir la précision académique)
- Changer de perspective (du point de vue de l'auteur)
- Ajouter ses propres explications

### Exemples erronés
- Modifier seulement quelques mots (toujours considéré comme du plagiat)
- Changer l'ordre des mots mais conserver la structure d'origine
- Omettre la citation

## Contrôle de qualité

### Exhaustivité
- [ ] Couvre la littérature fondatrice
- [ ] Inclut les avancées récentes (3-5 dernières années)
- [ ] Inclut la littérature directement pertinente
- [ ] Inclut la littérature méthodologique
- [ ] Équilibre entre littérature chinoise et anglaise (le cas échéant)

### Esprit critique
- [ ] Ce n'est pas une simple énumération
- [ ] Il y a une analyse comparative
- [ ] Il y a un jugement évaluatif
- [ ] Les lacunes sont identifiées
- [ ] Un cadre théorique est établi

### Logique
- [ ] Structure claire
- [ ] Transitions naturelles
- [ ] Argumentation cohérente
- [ ] Cohérence avec l'ensemble du texte

## Questions fréquentes

**Q : Combien d'articles faut-il lire ?**
R : Master 30-50 articles, Doctorat 100-200 articles, Licence 15-30 articles. La qualité prime sur la quantité.

**Q : Quelle longueur pour la revue de littérature ?**
R : Licence 3 000-5 000 mots, Master 5 000-10 000 mots, Doctorat 10 000-20 000 mots. Représente 10-20% du texte total.

**Q : Combien de citations ?**
R : Licence 15-30 citations, Master 30-60 citations, Doctorat 60-120 citations. Selon les conventions disciplinaires.

**Q : Comment identifier les lacunes ?**
R : 1) Limites méthodologiques ; 2) Limites de l'échantillon ; 3) Lacunes contextuelles ; 4) Résultats contradictoires ; 5) Variables inexplorées.

**Q : Quelle différence entre la revue de littérature et l'introduction ?**
R : L'introduction comprend le contexte de recherche, la formulation du problème et la signification de la recherche ; la revue de littérature en fait partie, spécifiquement consacrée à l'analyse de la littérature.

# Guide de détection de plagiat et d'IA

## Principes des systèmes de détection de plagiat

### Algorithmes de correspondance textuelle
- **Correspondance de caractères consécutifs** : 13 caractères identiques consécutifs signalés en rouge (CNKI)
- **Correspondance sémantique** : la reformulation synonyme peut toujours être détectée (Turnitin)
- **Correspondance interlinguistique** : le plagiat par traduction est détectable
- **Formules/code** : certains systèmes ne les comptent pas, d'autres les incluent

### Principaux systèmes de détection de plagiat

| Système | Caractéristiques | Application |
|---------|-----------------|-------------|
| CNKI | Littérature chinoise la plus complète, standard universitaire | Thèses de master et doctorat |
| VIP | Nombreux articles de revues, strict | Licence/revues |
| Wanfang | Fort en littérature médicale | Domaine médical |
| Turnitin | Standard anglophone, international | Articles en anglais |
| iThenticate | Soumission aux revues, rapport détaillé | SCI/SSCI |
| PaperPass | Gratuit/peu coûteux, vérification préliminaire | Auto-vérification du brouillon |
| Daya | Associé à XueXiTong, gratuit | Vérification préliminaire |

## Interprétation du rapport de détection

### Indicateurs clés
- **Taux global de répétition textuelle** : taux de répétition sur l'ensemble du texte
- **Taux hors citations** : taux de répétition après suppression des citations référencées
- **Taux hors propres publications** : suppression de vos propres publications
- **Répétition maximale d'une source unique** : la source avec le plus de répétitions
- **Nombre de mots répétés** : nombre exact de mots répétés

### Marquage coloré (CNKI)
- Rouge : répétition élevée (> 75%)
- Orange : répétition moyenne (50%-75%)
- Jaune : répétition faible (25%-50%)
- Vert : répétition très faible (< 25%)

### Exigences universitaires (référence)
- Licence : généralement < 20%-30%
- Master : généralement < 10%-15%
- Doctorat : généralement < 5%-10%
- Revues : généralement < 10%-20% (selon les exigences de la revue)

## Stratégies de réduction du taux de répétition

### Stratégies légitimes
1. **Substitution synonymique**
   - Maintenir la précision académique
   - Éviter le langage familier
   - Exemple : « important » → « crucial »/« central »/« significatif »

2. **Restructuration des phrases**
   - Transformation actif/passif
   - Alternance phrases longues/courtes
   - Réagencement de l'ordre des mots (en préservant la logique)

3. **Transformation en graphiques**
   - Conversion des descriptions textuelles en tableaux
   - Remplacement du texte par des organigrammes
   - Visualisation des données

4. **Ajout, suppression et reformulation**
   - Ajouter ses propres analyses
   - Supprimer les citations redondantes
   - Résumer avec ses propres mots

5. **Normes de citation**
   - Citations directes annotées (guillemets + source)
   - Citations indirectes reformulées (annotation toujours requise)
   - Contrôler la proportion de citations

### Stratégies risquées (déconseillées)
- Réduction par traduction : chinois → anglais → japonais → chinois (phrases incohérentes)
- Réduction par IA : peut être détectée par les outils de détection d'IA
- Remplacement par images : certains systèmes effectuent une reconnaissance OCR
- Espaces/caractères spéciaux : les systèmes savent déjà les détecter
- Insertion de caractères aléatoires : triche manifeste

### Notes spécifiques par discipline
- **Sciences et ingénierie** : descriptions de formules, étapes d'expérimentation peuvent être standardisées, mais doivent être reformulées avec ses propres mots
- **Sciences humaines** : la synthèse théorique est la plus sujette aux répétitions, nécessite une reformulation critique
- **Droit** : les textes de loi originaux ne sont pas comptabilisés, mais doivent être référencés ; les résumés de cas doivent être reformulés
- **Médecine** : descriptions de cas cliniques, protocoles de traitement peuvent être standardisés
- **Informatique** : les extraits de code ne sont pas comptabilisés dans certains systèmes

## Détection de l'IA

### Principes de détection
- **Perplexité** : le texte généré par IA a une perplexité faible
- **Burstiness (caractère sporadique)** : l'écriture humaine présente une grande variabilité
- **Caractéristiques statistiques** : distribution des fréquences de mots, distribution des longueurs de phrases
- **Détection de filigrane** : certains générateurs d'IA intègrent un filigrane

### Principaux outils de détection

| Outil | Caractéristiques | Limites |
|-------|-----------------|---------|
| GPTZero | Gratuit, populaire | Taux élevé de faux positifs |
| Turnitin AI | Intégré à la détection de plagiat | Principalement pour l'anglais |
| CNKI AIGC | Détection en chinois | Récemment lancé, critères peu clairs |
| VIP AIGC | Détection en chinois | Idem |
| Originality.ai | Professionnel, payant | Principalement pour l'anglais |
| ZeroGPT | Gratuit | Faux positifs |

### Tendances des politiques universitaires
- Depuis 2024, de nombreuses universités exigent la détection du taux d'IA
- Les critères ne sont pas uniformes (de 0% à 30%)
- La précision des outils de détection est contestée
- Le mécanisme d'appel est insuffisant

### Réduire le risque de détection d'IA (méthodes conformes)
1. **Renforcer la voix personnelle**
   - Intégrer des expériences de recherche et des réflexions
   - Utiliser la première personne (le cas échéant)
   - Ajouter des détails concrets (temps, lieu, impressions)

2. **Écriture mixte**
   - Rédiger soi-même le brouillon, l'IA assiste pour la révision
   - Écrire par paragraphes, ne pas générer l'ensemble avec l'IA
   - Organiser soi-même les arguments clés

3. **Édition approfondie**
   - Reformuler les expressions plates générées par l'IA
   - Ajouter des phrases de transition et des connecteurs
   - Ajuster la structure des paragraphes

4. **Citer des références réelles**
   - L'IA peut inventer des citations
   - Vérifier chaque citation
   - Intégrer des références récentes

5. **Auto-vérification avec des outils de détection**
   - Utiliser plusieurs outils de détection avant la soumission
   - Marquer les passages à haut risque
   - Reformuler en priorité

## Intégrité académique

### Types de plagiat
- **Plagiat direct** : copier-coller sans référence
- **Plagiat en mosaïque** : assemblage de multiples sources sans référence
- **Plagiat par reformulation** : reformulation mais reprise des idées/structure
- **Auto-plagiat** : republication de contenu déjà publié par soi-même
- **Fabrication de données** : invention ou falsification de données
- **Commande** : faire rédiger par une personne/une IA

### Conséquences
- Rejet du mémoire
- Révocation du diplôme (déjà décerné)
- Sanctions académiques (avertissement, blâme, exclusion)
- Atteinte à la réputation académique
- Responsabilité juridique (cas graves)

### Bonnes pratiques
- Toutes les citations sont référencées
- Les citations directes sont entre guillemets
- Les citations indirectes sont reformulées avec référence
- La bibliographie est complète
- Utilisation d'un outil de gestion bibliographique
- Conservation des traces du processus rédactionnel

## Liste de vérification
- [ ] Utiliser le système de détection prescrit par l'université
- [ ] Le taux global de répétition est conforme
- [ ] Le taux de répétition maximal par source est raisonnable
- [ ] Le format des citations est correct
- [ ] La bibliographie est complète
- [ ] Les figures et tableaux sont référencés
- [ ] La source du code est indiquée (le cas échéant)
- [ ] La détection d'IA est réussie (si exigée)
- [ ] Le rapport de détection est conservé
- [ ] Connaissance du processus d'appel de l'université

## Outils recommandés
- **Détection de plagiat** : système prescrit par l'université (le plus précis)
- **Vérification préliminaire** : PaperPass, Daya (gratuit/peu coûteux)
- **Détection d'IA** : GPTZero, Turnitin (référence)
- **Gestion bibliographique** : Zotero, EndNote
- **Aide à la rédaction** : Grammarly (grammaire), DeepL (référence de traduction)

## Questions fréquentes

**Q : Citer ses propres publications est-il comptabilisé comme répétition ?**
R : Oui, mais la plupart des universités autorisent une certaine proportion (avec mention « propre publication »).

**Q : La bibliographie est-elle comptabilisée dans les répétitions ?**
R : Généralement non, mais le format doit être correct.

**Q : Les annexes sont-elles comptabilisées dans les répétitions ?**
R : Généralement incluses dans le texte total, mais certaines universités comptent les annexes séparément.

**Q : Utiliser l'IA pour assister la rédaction constitue-t-il une faute académique ?**
R : Cela dépend de la politique de l'université. La plupart autorisent l'assistance (révision, traduction), mais interdisent la rédaction complète (génération du contenu principal).

**Q : Un taux de détection de plagiat plus bas est-il toujours mieux ?**
R : Non. 0% pourrait signifier l'absence de soutien bibliographique ; les citations raisonnables sont nécessaires.

**Q : Les résultats diffèrent-ils considérablement entre systèmes de détection ?**
R : Oui. Les bases de données et les algorithmes diffèrent. Se fier au système prescrit par l'université.


# Chaîne d'outils pour la rédaction de thèses

## Environnement de rédaction

### Rédaction locale
- **Word** : le plus couramment utilisé, bonne compatibilité
  - Fonctionnalité de styles : définir les styles de titre, texte, citation
  - Listes multiniveaux : numérotation automatique
  - Légendes : numérotation automatique des figures et tableaux
  - Renvois : référence aux figures, tableaux, chapitres
  - Table des matières : génération automatique
  - Modèles : modèles universitaires

- **WPS** : alternative chinoise, compatible avec Word
  - Version gratuite suffisante
  - Synchronisation cloud
  - Richesse des modèles

### Rédaction en ligne
- **Overleaf** : collaboration LaTeX en ligne
  - Adapté aux : sciences et ingénierie, nombreuses formules mathématiques
  - Modèles : modèles de revues, modèles universitaires
  - Collaboration : édition simultanée par plusieurs personnes
  - Version : contrôle de version Git

- **Tencent Docs / Shimo Docs** : collaboration légère
  - Adapté aux : plans, notes, collaboration
  - Non adapté à : la mise en page d'articles formels

- **Notion / Yuque** : gestion des connaissances
  - Adapté aux : notes de littérature, plan de rédaction
  - Non adapté aux : articles formels

## Analyse de données

### Logiciels statistiques

  - Reproductibilité : le code est reproductible

- **Python** : programmation générale
  - Bibliothèques : pandas, scipy, statsmodels, pingouin
  - Adapté aux : big data, apprentissage automatique, automatisation

- **Stata** : couramment utilisé en économie
  - Commandes concises
  - Données de panel, variables instrumentales
  - Payant

- **JASP** : gratuit, alternative à SPSS
  - Interface similaire à SPSS
  - Statistiques bayésiennes

### Analyse qualitative

  - Intégration statistique
  - Payant

- **Taguette** : gratuit et open source
  - Fonctionnalités de base suffisantes
  - Adapté aux : étudiants, petits projets

## Guide d'évitement des pièges

1. **Ne pas utiliser de logiciels piratés** : l'université fournit généralement des versions officielles
2. **Ne pas trop dépendre de la traduction** : la rédaction académique doit être organisée soi-même
3. **Ne pas négliger la sauvegarde** : synchronisation cloud + sauvegarde locale
4. **Ne pas apprendre les outils au dernier moment** : se familiariser à l'avance, éviter la panique avant la date limite
5. **Ne pas négliger la mise en forme** : la mise en page fait partie des normes académiques
