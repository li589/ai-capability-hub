# Guide de rédaction des thèses en sciences exactes

## Caractéristiques de la discipline
- Accent sur la vérification expérimentale, la dérivation mathématique, l'innovation théorique
- Importance accordée à la précision des données, la reproductibilité, la révision par les pairs
- Égale considération pour les articles de conférence et de journal
- Exigences élevées en matière de qualité graphique (graphiques de données, formules, schémas d'appareils expérimentaux)

## Types de recherche

### 1. Recherche expérimentale
- **Applicable** : expériences en physique, chimie, biologie
- **Éléments clés** :
  - Conception expérimentale (contrôle des variables, répétition des expériences)
  - Acquisition de données (précision des instruments, analyse des erreurs)
  - Analyse des résultats (tests statistiques, incertitude)
- **Structure de la thèse** : objectifs → méthodes → expériences → résultats → analyse

### 2. Recherche théorique
- **Applicable** : mathématiques, physique théorique, chimie théorique
- **Éléments clés** :
  - Formulation du problème (conjectures, hypothèses)
  - Dérivation théorique (preuves, calculs)
  - Discussion des résultats (signification, applications)
- **Structure de la thèse** : problème → préliminaires → résultats principaux → preuve → discussion

### 3. Recherche computationnelle
- **Applicable** : physique computationnelle, chimie computationnelle, bioinformatique
- **Éléments clés** :
  - Établissement du modèle (algorithmes, méthodes numériques)
  - Implémentation du programme (code, validation)
  - Analyse des résultats (convergence, précision)
- **Structure de la thèse** : problème → méthode → implémentation → résultats → discussion

## Sous-disciplines

### Mathématiques
- **Mathématiques pures** : algèbre, géométrie, analyse, théorie des nombres
- **Mathématiques appliquées** : probabilités et statistiques, recherche opérationnelle, mathématiques computationnelles
- **Enseignement des mathématiques** : méthodes pédagogiques, conception de programmes

### Physique
- **Physique de la matière condensée** : matériaux, supraconductivité, semi-conducteurs
- **Physique des particules** : physique des hautes énergies, physique nucléaire
- **Optique** : lasers, fibres optiques, optoélectronique
- **Astrophysique** : cosmologie, galaxies, trous noirs

### Chimie
- **Chimie organique** : synthèse, mécanismes réactionnels
- **Chimie inorganique** : chimie de coordination, chimie des matériaux
- **Chimie analytique** : analyse instrumentale, spectroscopie
- **Chimie physique** : thermodynamique, cinétique

### Biologie
- **Biologie moléculaire** : gènes, protéines
- **Biologie cellulaire** : signalisation cellulaire, cycle cellulaire
- **Écologie** : populations, communautés, écosystèmes
- **Bioinformatique** : analyse de séquences, prédiction de structures

## Modèles de structure de thèse

### Type recherche expérimentale
```
1. Introduction (contexte de recherche, problématique, objectifs)
2. Partie expérimentale (matériaux, méthodes, instruments)
3. Résultats et discussion (données, analyse, comparaison)
4. Conclusion (découvertes, signification, perspectives)
```

### Type recherche théorique
```
1. Introduction (contexte du problème, revue de littérature)
2. Préliminaires (définitions, lemmes)
3. Résultats principaux (théorèmes, preuves)
4. Discussion (applications, généralisations)
5. Conclusion (contributions, perspectives)
```

## Points clés de rédaction

### Description expérimentale
- Suffisamment détaillée pour permettre la reproduction
- Inclure tous les paramètres
- Spécifier les modèles d'instruments
- Indiquer les sources des réactifs

### Présentation des données
- Utiliser des chiffres significatifs
- Rapporter les plages d'erreur
- Indiquer les unités
- Graphiques clairs et standardisés

### Mise en page des formules
- Utiliser un éditeur de formules
- Système de symboles cohérent
- Numérotation continue
- Expliquer chaque symbole

## Problèmes courants

1. **Expériences insuffisantes** : nombre de répétitions faible, manque de contrôles
2. **Traitement inadéquat des données** : méthodes statistiques erronées, analyse des erreurs insuffisante
3. **Revue de littérature faible** : manque de développements récents, revue pas assez complète
4. **Discussion peu approfondie** : simple énumération des résultats, manque d'analyse approfondie
5. **Rédaction non standardisée** : terminologie incohérente, formatage désordonné

- Electronic Lab Notebook (ELN)

### Journaux spécialisés
- Journaux spécialisés par discipline
- Journaux régionaux
- Journaux en accès libre

## Précautions pour la vérification d'originalité
- Les descriptions de méthodes expérimentales peuvent être standardisées
- Les dérivations de formules doivent être originales
- L'analyse des données nécessite votre propre interprétation
- Les conclusions doivent être basées sur vos propres résultats
