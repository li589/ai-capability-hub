# Foire aux questions sur la rédaction académique

## Phase de choix du sujet

**Q : Je ne veux pas traiter le sujet proposé par mon directeur de thèse, que faire ?**
R :
1. Commencez par vous renseigner en profondeur, le sujet n'est peut-être pas ce que vous imaginez
2. Préparez des sujets alternatifs (2-3 propositions) en expliquant vos raisons
3. Lors de la discussion, insistez sur le fait que la motivation personnelle favorise de meilleurs résultats
4. Si votre directeur maintient sa position, évaluez si le sujet est acceptable ou envisagez un changement de directeur

**Q : Comment déterminer si un sujet est trop large ou trop restreint ?**
R :
- Trop large : « Étude sur le développement économique de la Chine » (champ trop vaste)
- Trop restreint : « Enquête auprès d'un ménage d'un village » (non généralisable)
- Approprié : « L'impact de la finance numérique sur la consommation des résidents ruraux — basé sur les données d'enquête de la province XX »
- Vérification : Peut-on le formuler clairement en une seule phrase ? Peut-on le mener à bien en 6 à 12 mois ?

**Q : Quelqu'un a déjà traité un sujet similaire, puis-je quand même le faire ?**
R : Oui, l'essentiel est de trouver un angle différent :
- Perspective différente (cadre théorique distinct)
- Méthode différente (quantitative vs qualitative)
- Contexte différent (région/période/population différente)
- Variables différentes (ajout de modération/médiation)
- Données différentes (plus récentes, plus détaillées)

## Phase de revue de littérature

**Q : Je n'arrive pas à lire toute la littérature, que faire ?**
R :
- Lecture stratifiée : lisez d'abord les résumés, puis décidez des lectures approfondies
- Commencez par les revues de littérature : pour une vue d'ensemble rapide du domaine
- Concentrez-vous sur l'essentiel : textes fondateurs + publications marquantes + avancées récentes
- Utilisez des outils : Zotero pour la gestion, étiquetage et classification
- Fixez-vous des limites : 2-3 articles par jour, évitez le perfectionnisme

**Q : Ma revue de littérature ressemble à une simple liste, que faire ?**
R :
- Organisez par thème, pas par auteur
- Chaque paragraphe doit avoir une thèse : « Ces études montrent que... »
- Utilisez des connecteurs logiques : Cependant, De même, En revanche
- Évaluez de manière critique : « L'avantage de A est... mais sa limite réside dans... »
- Identifiez les lacunes : « Bien que... mais... reste encore à résoudre »

**Q : J'ai peur que trop de citations augmentent le taux de similarité ?**
R :
- Citation indirecte : reformulez avec vos propres mots + attribution
- Limitez les citations directes (< 10 %)
- Organisez la section de synthèse avec votre propre cadre
- Évitez les longues citations textuelles

## Phase de rédaction

**Q : Je n'arrive pas à écrire / je suis bloqué, que faire ?**
R :
- Abaissez vos attentes : écrivez d'abord un brouillon médiocre, puis révisez
- Changez de section : commencez par les parties les plus faciles (méthodologie, données)
- Écriture programmée : consacrez un créneau quotidien fixe pour créer une habitude
- Dictée enregistrez : formulez vos idées à l'oral, puis mettez-les par écrit
- Discutez avec quelqu'un : échangez avec votre directeur ou vos camarades pour stimuler vos idées
- Relisez des articles : relisez la littérature pertinente pour trouver l'inspiration

**Q : Mon directeur dit que mon travail « manque d'innovation », que faire ?**
R :
- Identifiez clairement le type d'innovation : théorique / méthodologique / empirique / perspective
- Comparez avec les études existantes : en quoi votre approche diffère-t-elle ?
- Renforcez l'argumentation : l'innovation doit être présente tout au long du texte, pas seulement mentionnée dans l'introduction
- Complétez la bibliographie : peut-être n'avez-vous pas assez lu pour identifier votre positionnement

**Q : Les données/résultats expérimentaux ne sont pas satisfaisants, que faire ?**
R :
- Vérifiez d'abord : y a-t-il des erreurs dans le traitement des données ?
- Rapportez honnêtement : les résultats négatifs sont aussi des résultats
- Discutez les causes : pourquoi les résultats ne sont-ils pas satisfaisants ?
- Ajustez les hypothèses : vos hypothèses posent-elles problème ?
- Complétez les analyses : sous-échantillons, variables alternatives
- Ne falsifiez jamais : c'est une ligne rouge éthique en recherche

**Q : Ma thèse est trop mauvaise, je n'ose pas la montrer à mon directeur ?**
R :
- Votre directeur en a vu de pires, n'ayez pas honte
- Plus tôt vous la montrerez, plus vite les problèmes seront détectés
- Formulez clairement votre demande : « Je suis bloqué sur cette partie, j'ai besoin de conseils »
- Arrivez avec des questions précises : ne dites pas seulement « regardez mon travail », soyez spécifique

## Mise en forme et normes

**Q : Les exigences de mise en forme de mon université ne sont pas claires ?**
R :
- Cherchez le modèle officiel (site de l'école doctorale)
- Demandez les normes les plus récentes au service de la scolarité
- Consultez les thèses des promotions précédentes
- Faites attention aux détails : en-têtes, pieds de page, numérotation, légendes des figures et tableaux

**Q : Le format des références bibliographiques est désordonné ?**
R :
- Utilisez un outil : Zotero/EndNote pour la génération automatique
- Uniformisez le format : ISO 690 (français) ou APA (anglais)
- Vérifiez les détails : nom des auteurs, année, pages, DOI
- Vérifiez l'original : assurez-vous que les citations sont exactes

**Q : Comment mettre en forme les figures et tableaux ?**
R :
- Légende des figures en dessous, légende des tableaux au-dessus
- Numérotation : Figure 1-1, Tableau 2-1 (chapitre-numéro)
- Source : indiquez la source des données
- Lisibilité : résolution suffisante, taille de police lisible
- Cohérence : style uniforme (couleurs, polices)

## Vérification de plagiat et réduction de similarité

**Q : Le taux de similarité dépasse le seuil autorisé, que faire ?**
R :
- Analysez d'abord : quelles parties sont concernées ?
- Terminologie spécialisée : conservez-la, elle est irremplaçable
- Section de synthèse : réécrivez avec votre propre cadre analytique
- Description des méthodes : les descriptions standardisées sont acceptables
- Remplacement par synonymes : maintenez la précision académique
- Restructuration des phrases : alternance voix active/passive
- Visualisation : transformez le texte en tableaux/schémas

**Q : La détection d'IA n'est pas validée, que faire ?**
R :
- Auto-vérification : utilisez des outils comme GPTZero pour détecter
- Reformulation : ajoutez votre voix personnelle, des détails concrets
- Approche hybride : rédaction personnelle + assistance IA pour la relecture
- Transparence : si votre université l'exige, indiquez dans quelle mesure l'IA a été utilisée
- Recours : en cas de faux positif, conservez les preuves de votre processus d'écriture

**Q : Le système de vérification de l'université donne un résultat différent de ma propre vérification ?**
R :
- Le système de l'université fait foi
- Les bases de données diffèrent selon les systèmes
- Il est recommandé d'utiliser le système désigné par l'université pour la pré-vérification
- Attention : les services de vérification en ligne peuvent compromettre la confidentialité de votre thèse

## Phase de soutenance

**Q : Je suis stressé à l'idée de la soutenance, que faire ?**
R :
- Préparation approfondie : maîtrisez chaque partie
- Soutenance simulée : entraînez-vous avec des camarades
- Préparez un plan de présentation : ne lisez pas les diaporamas, expliquez-les
- Respiration profonde : pratiquez quelques respirations profondes avant d'entrer
- Acceptez le stress : un niveau modéré de stress est normal

**Q : Le jury pose des questions auxquelles je ne sais pas répondre ?**
R :
- Reconnaissez honnêtement : « Je n'ai pas assez approfondi cette question »
- Essayez de répondre : « D'après ma compréhension... »
- Notez les questions : étudiez-les après la soutenance
- Ne contestez pas : acceptez les critiques avec humilité
- Ne faites pas semblant de savoir : les membres du jury s'en rendront compte

**Q : Des modifications importantes sont demandées après la soutenance, que faire ?**
R :
- C'est normal : la plupart des thèses nécessitent des révisions
- Classez : modifications obligatoires vs recommandations
- Communiquez : confirmez l'étendue des modifications avec votre directeur
- Planifiez : établissez un calendrier de révision
- Exécutez : traitez chaque point, sans en omettre

## Gestion du stress et de la motivation

**Q : Je suis anxieux en voyant les thèses des autres, que faire ?**
R :
- Piège de la comparaison : chaque personne a son propre rythme
- Concentrez-vous sur vous-même : terminer est plus important que la perfection
- Cherchez du soutien : parlez-en à des amis ou à votre directeur
- Décomposez les tâches : divisez les grands objectifs en petites tâches
- Célébrez les progrès : récompensez-vous pour chaque objectif atteint

**Q : J'ai envie d'abandonner / de reporter ma soutenance ?**
R :
- Évaluez la cause : est-ce un problème de compétence ou de motivation ?
- Cherchez de l'aide : directeur de thèse, soutien psychologique
- Considérez les conséquences : l'impact d'un report (emploi, bien-être)
- Pause temporaire : prenez quelques jours de repos avant de décider
- Si vous décidez de reporter : établissez un plan, ne remettez pas indéfiniment

**Q : J'ai terminé ma thèse mais je la trouve insuffisante ?**
R :
- Terminer > la perfection : soumettez-la d'abord, vous pourrez l'améliorer plus tard
- Acceptez les limites : chaque thèse a ses limites
- Perspectives futures : mentionnez les orientations possibles dans la conclusion
- Évitez les révisions excessives : modifier sans cesse peut empirer le résultat

## Autres questions

**Q : Puis-je citer des mémoires de master ou de doctorat ?**
R : Ois, mais avec précaution :
- La qualité des thèses non publiées est variable
- Privilégiez les articles publiés dans des revues ou conférences
- Si vous les citez, précisez qu'il s'agit d'un mémoire de thèse
- La proportion de ces citations ne doit pas être trop élevée

**Q : Puis-je citer des sources de Wikipédia ou de forums en ligne ?**
R : Ce n'est pas recommandé :
- Sources non académiques, fiabilité incertaine
- Risque d'être détecté par le logiciel de similarité
- Si nécessaire, retrouvez la source académique d'origine
- Les sources en ligne utilisent le type [EB/OL], indiquez la date d'accès

**Q : Peut-on utiliser « je » dans un mémoire ?**
R : Cela dépend de la discipline :
- Sciences et ingénierie : on utilise généralement la voix passive ou « ce travail »
- Sciences sociales : l'usage du « je » est possible (recherche réflexive)
- Consultez les exigences de votre université : certaines ont des règles précises
- Cohérence : adoptez un style uniforme tout au long du document

**Q : Que mettre en annexe ?**
R :
- Questionnaires / guides d'entretien
- Données brutes (le cas échéant)
- Code source (le cas échéant)
- Figures et tableaux complémentaires
- Dérivations de formules longues
- Note : les annexes sont parfois incluses dans la vérification de similarité (selon les universités)

**Q : Comment rédiger les remerciements ?**
R :
- Soyez sincère : évitez les formules toutes faites
- Soyez précis : mentionnez l'aide concrète apportée
- Soyez modéré : ne dépassez pas une page en général
- Vérifiez : n'oubliez pas les personnes importantes
- Note : les remerciements ne sont pas comptabilisés dans la vérification de similarité

## Ressources d'aide
- **Directeur de thèse** : premier choix, entretiens réguliers
- **Aînés et diplômés** : transmission d'expérience
- **Camarades** : discussions mutuelles, soutenances simulées
- **Bibliothèque** : formation à la recherche documentaire
- **Centre d'écriture** : proposé par certaines universités
- **Soutien psychologique** : en cas d'anxiété intense
- **Ressources en ligne** : forums, chaînes YouTube, blogs académiques

## Rappels importants
- La thèse n'est qu'une petite partie de votre vie
- Terminer est plus important que la perfection
- Demander de l'aide n'est pas un signe de faiblesse
- Prenez soin de votre santé (sommeil, exercice, vie sociale)
- Ayez confiance en votre capacité à mener ce projet à bien
# Foire aux questions spécifiques aux disciplines

## Informatique

**Q : Comment intégrer du code dans un mémoire ?**
R :
1. **Pseudo-code** : utilisez l'environnement algorithme (LaTeX algorithmic/algorithm2e), mettant l'accent sur la logique plutôt que la syntaxe
2. **Extraits de code** : fonctions clés (< 20 lignes), en expliquant l'idée centrale
3. **Code complet** : en annexe ou via un lien GitHub, avec référence dans le corps du texte
4. **Format** : police à chasse fixe (Courier New), numéros de ligne, coloration syntaxique (minted/listings)
5. **Commentaires** : expliquez les étapes clés, ne traduisez pas le code mot à mot
6. **Open source** : lien GitHub avec README et instructions d'exécution

**Q : Comment rédiger un pseudo-code d'algorithme ?**
R :
```
Algorithme 1 : Tri rapide
Entrée : tableau A, longueur n
Sortie : tableau trié
1.  si n ≤ 1 alors retourner A
2.  pivot ← A[n/2]
3.  gauche ← {x ∈ A | x < pivot}
4.  droite ← {x ∈ A | x > pivot}
5.  retourner TriRapide(gauche) + {pivot} + TriRapide(droite)

Points clés :
- Entrée/sortie explicitement définies
- Structures de contrôle claires (indentation)
- Commentaires sur les étapes essentielles
- Indication de la complexité (temps O(n log n), espace O(log n))
```

**Q : Comment garantir la reproductibilité des expériences ?**
R :
1. **Environnement documenté** : système d'exploitation, version de Python, versions des bibliothèques (requirements.txt)
2. **Graine aléatoire** : fixez la graine (np.random.seed(42))
3. **Jeux de données** : jeux de données publics + code de prétraitement
4. **Hyperparamètres** : liste complète (en annexe ou fichier de configuration)
5. **Matériel** : modèle de GPU, mémoire vidéo, temps d'entraînement
6. **Open source** : GitHub + README + image Docker

**Q : Comment dessiner un schéma d'architecture système ?**
R :
1. **Couches** : couche utilisateur → couche applicative → couche de service → couche de données
2. **Composants** : rectangles (services), cylindres (bases de données), flux (flèches de données)
3. **Outils** : Visio, Draw.io, ProcessOn, LaTeX TikZ
4. **Convention** : couleurs uniformes (entrée/traitement/sortie/stockage)
5. **Annotations** : noms d'interfaces, protocoles, formats de données

## Économie

**Q : Comment indiquer les sources de données ?**
R :
1. **Données officielles** : bureau national des statistiques, banque centrale, ministère des finances (avec URL et date d'accès)
2. **Bases de données** : CSMAR, Wind, CEIC (en indiquant la version et la date de téléchargement)
3. **Données d'enquête** : CFPS, CHARLS (en indiquant l'année et la version)
4. **Données web** : collectées par web scraping (en indiquant la période et la date de collecte)
5. **Format** : « Les données proviennent de la base CSMAR (téléchargées en décembre 2023) »

**Q : Comment formuler un modèle économétrique ?**
R :
1. **Modèle de base** : Y = α + βX + γContrôles + ε (présentation sous forme de formule)
2. **Définition des variables** : pour chaque variable, indiquez la signification, l'unité, le signe attendu
3. **Choix du modèle** : justification théorique pour OLS/FE/RE/DID/IV
4. **Robustesse** : variables alternatives, modèles alternatifs, sous-échantillons
5. **Endogénéité** : justification du choix des variables instrumentales, DID, RDD

**Q : Comment traiter l'endogénéité ?**
R :
1. **Variables omises** : effets fixes, variables instrumentales, fonction de contrôle
2. **Causalité inverse** : variables retardées, GMM, DID
3. **Erreur de mesure** : variables instrumentales, méthode des indicateurs multiples
4. **Sélection d'échantillon** : modèle de Heckman en deux étapes, PSM
5. **Rapport** : indiquez la source d'endogénéité, la méthode de traitement et la comparaison des résultats

**Q : Comment effectuer des tests de robustesse ?**
R :
1. **Variables alternatives** : changer la mesure de la variable clé (par ex. ROA remplacé par ROE)
2. **Modèles alternatifs** : OLS remplacé par Tobit/Probit/Logit
3. **Sous-échantillons** : par année/par secteur/par région
4. **Exclusion des valeurs aberrantes** : troncature à 1 %, exclusion des entreprises ST
5. **Test placebo** : attribution aléatoire du groupe de traitement
6. **Variables instrumentales** : changer d'IV, test de variable instrumentale faible

## Sciences de l'éducation

**Q : Quel est le processus d'examen éthique ?**
R :
1. **Documents à soumettre** : protocole de recherche, formulaire de consentement éclairé, questionnaire/guide d'entretien, qualifications du chercheur
2. **Types d'examen** :
   - Exemption : enquêtes anonymes, données publiques
   - Examen accéléré : recherches à faible risque (observation en classe)
   - Examen en commission : impliquant des mineurs, sujets sensibles
3. **Comité d'éthique de l'université** : faculté des sciences de l'éducation / comité d'éthique de l'établissement
4. **Délai d'approbation** : 1 à 4 semaines (prévoyez à l'avance)
5. **Suivi** : rapport d'avancement annuel, rapport d'événements indésirables graves

**Q : Comment établir une collaboration avec une école ?**
R :
1. **Canaux de contact** : rectorat → direction d'école → chef de niveau → professeur principal
2. **Lettre d'introduction** : cachet de l'université/faculté, expliquant l'objectif de la recherche et les mesures de confidentialité
3. **Modèles de collaboration** :
   - Modèle de réciprocité : fournir des ressources pédagogiques/formations
   - Modèle participatif : inviter les enseignants à participer à la conception de la recherche
   - Modèle de commande : l'école mandate des questions de recherche
4. **Accord** : préciser les responsabilités, l'utilisation des données, la propriété des résultats
5. **Remerciement** : communiquer les résultats à la fin de l'étude, offrir un rapport

**Q : Comment rédiger un formulaire de consentement parental ?**
R :
1. **Titre** : « Notification et formulaire de consentement pour la participation à l'étude XX »
2. **Objectif de la recherche** : expliquer en termes simples (par ex. « comprendre les méthodes d'apprentissage des élèves »)
3. **Procédure** : quoi faire, combien de temps, où
4. **Risques** : risque minimal (par ex. « aucun risque physique, possibilité de fatigue »)
5. **Confidentialité** : anonymisation, données utilisées uniquement pour la recherche
6. **Volontariat** : possibilité de se retirer à tout moment, sans impact sur les notes
7. **Coordonnées** : nom du chercheur, téléphone, e-mail
8. **Signature** : signature du parent + date + nom de l'élève

## Droit

**Q : Quel est le format de citation des articles de loi ?**
R :
1. **Droit chinois** :
   - Première citation : « Code civil de la République populaire de Chine, article 1165 (ci-après « Code civil ») »
   - Citations suivantes : « Code civil, article 1165 »
   - Format en note de bas de page : « Code civil, article 1165, alinéa 1 »
2. **Interprétations judiciaires** :
   - « Interprétation de la Cour populaire suprême sur certaines questions relatives à l'application de la partie générale du Code civil, article 1 »
3. **Règlements administratifs** : « Règlement XX, article X »
4. **Réglementations locales** : « Règlement de la province XX, article X »
5. **Traités internationaux** : « Convention XX, article X »

**Q : Comment rechercher et citer la jurisprudence ?**
R :
1. **Plateformes de recherche** :
   - Site officiel des décisions judiciaires de Chine
   - Chinalawinfo (plateforme professionnelle)
   - Autres bases de données juridiques
2. **Techniques de recherche** :
   - Mots-clés : cause, article de loi, point de litige
   - Recherche avancée : niveau de juridiction, année, type d'affaire
   - Recherche d'affaires similaires : faits similaires, application similaire du droit
3. **Format de citation** :
   - Jugement : « Affaire XX c. XX, Tribunal de XX (20XX) No. X »
   - Affaire directrice : « Affaire directrice No. X : Affaire XX »
   - Affaire au bulletin : « Bulletin de la Cour populaire suprême, 20XX, No. X »

**Q : Comment mener une recherche de droit comparé ?**
R :
1. **Fonctionnalisme** : comparer les différentes solutions apportées à un même problème (par ex. comparaison internationale du « délai de réflexion pour le divorce »)
2. **Choix des systèmes juridiques** : droit civil, common law, systèmes mixtes
3. **Dimensions de comparaison** :
   - Mode de législation : codification/loi spéciale/jurisprudence
   - Conception institutionnelle : éléments constitutifs, effets juridiques
   - Pratique judiciaire : statistiques jurisprudentielles, fréquence d'application
4. **Sources** :
   - Droit étranger : codes officiels, ouvrages académiques, bases de données jurisprudentielles
   - Traductions : traductions officielles, traductions de juristes reconnus
5. **Précautions** :
   - Évitez les comparaisons simplistes (avantages/inconvénients)
   - Tenez compte du contexte institutionnel (social, culturel, historique)
   - Proposez des recommandations transposables (analyse de faisabilité)

## Littérature

**Q : Quel est le format de citation des textes ?**
R :
1. **Citation directe** :
   - Courte (< 4 lignes) : intégrée dans le texte, avec guillemets et numéro de page
   - Longue (≥ 4 lignes) : paragraphe indépendant, en retrait, sans guillemets
2. **Citation indirecte** :
   - Résumé des idées : « Lu Xun considère que... (Préface de *Cris*, p. X) »
   - Évitez les citations excessives : analysez avec vos propres mots
3. **Versions multiples** :
   - Textes anciens : indiquez l'édition (par ex. « *Le Rêve dans le pavillon rouge*, Éditions de littérature populaire, 1982, p. X »)
   - Textes étrangers : indiquez le traducteur (par ex. « [USA] Hemingway, traduit par X »)
4. **Principes de citation** :
   - Concepts/termes clés : citation directe
   - Résumé de l'intrigue : citation indirecte
   - Points de vue critiques : indiquez la source

**Q : Comment choisir un cadre théorique ?**
R :
1. **Théories classiques** :
   - Formalisme : lecture attentive du texte, analyse structurelle
   - New Criticism : paradoxe, ironie, tension
   - Structuralisme : narratologie, sémiologie, archétypes mythiques
   - Post-structuralisme : déconstruction, différence, différance
2. **Théories contemporaines** :
   - Féminisme : perspective de genre, politique du corps
   - Postcolonialisme : orientalisme, hybridité
   - Écocritique : environnement, nature, animalité
   - Études culturelles : pouvoir, idéologie, représentation
3. **Principes de sélection** :
   - Adéquation avec le texte : la théorie doit pouvoir expliquer les caractéristiques du texte
   - Adéquation avec la problématique : la théorie doit pouvoir répondre aux questions de recherche
   - Évitez l'accumulation : 1 ou 2 théories centrales suffisent
   - Usage critique : ne suivez pas aveuglément, identifiez les limites

**Q : Comment appliquer les méthodes critiques ?**
R :
1. **Lecture attentive** :
   - Niveau linguistique : choix lexicaux, figures de style, structure syntaxique
   - Niveau formel : point de vue narratif, structure temporelle, cadre spatial
   - Niveau thématique : images centrales, système symbolique, conflits de valeurs
2. **Études comparatives** :
   - Études d'influence : influence de A sur B (matériel empirique)
   - Études parallèles : similarités/différences entre A et B (sans relation d'influence)
   - Interdisciplinarité : littérature et philosophie/histoire/psychologie
3. **Études culturelles** :
   - Contextualisation : contexte historique, conditions sociales
   - Analyse du pouvoir : quelle voix est entendue/réprimée
   - Études de réception : réactions des lecteurs, effets de diffusion
4. **Précautions** :
   - Évitez les spéculations subjectives : appuyez-vous sur des preuves textuelles
   - Évitez la surinterprétation : distinguez l'interprétation raisonnable de l'extrapolation forcée
   - Maintenez une distance critique : ne projetez pas vos émotions personnelles

## Médecine

**Q : Comment mentionner le numéro d'approbation éthique ?**
R :
1. **Format** : « Cette étude a été approuvée par le comité d'éthique de l'université XX (No. : XXXX-2023-001) »
2. **Emplacement** : au début de la section Méthodes ou en note de bas de page
3. **Enregistrement** : les essais cliniques doivent être enregistrés (ClinicalTrials.gov : NCTXXXXXXXX)
4. **Consentement éclairé** : « Tous les participants ont signé un formulaire de consentement éclairé »
5. **Exception** : « En raison de la nature rétrospective de l'étude, le comité d'éthique a exempté le consentement éclairé (No. : XXXX) »

**Q : Comment décrire les méthodes statistiques ?**
R :
1. **Logiciel** : « Les analyses statistiques ont été réalisées avec SPSS 26.0 et R 4.2.1 »
2. **Seuil de significativité** : « Test bilatéral, α = 0,05 »
3. **Statistiques descriptives** : « Les données quantitatives sont exprimées en moyenne ± écart-type (x̄ ± s), les données qualitatives en effectif (%) »
4. **Comparaison intergroupe** : « La comparaison entre deux groupes a été réalisée par test t pour échantillons indépendants ou test de Mann-Whitney U »
5. **Comparaison multi-groupes** : « La comparaison multi-groupes a été réalisée par analyse de variance à un facteur, les comparaisons deux à deux par méthode LSD ou correction de Bonferroni »
6. **Analyse de corrélation** : « La corrélation a été analysée par corrélation de Pearson ou Spearman »
7. **Analyse de régression** : « L'analyse multivariée a été réalisée par régression linéaire multiple/Logistique/Cox »
8. **Analyse de survie** : « Les courbes de survie ont été estimées par la méthode de Kaplan-Meier, la comparaison intergroupe par test de Log-rank »

**Q : Comment réaliser un diagramme de flux CONSORT ?**
R :
1. **Point de départ** : « Participants évalués pour l'éligibilité (n = XXX) »
2. **Exclusions** : « Exclus (n = XX) : ne remplissant pas les critères d'inclusion (n = XX), refus de participer (n = XX), autres raisons (n = XX) »
3. **Randomisation** : « Randomisation (n = XXX) »
4. **Groupes** : « Groupe d'intervention (n = XXX) », « Groupe contrôle (n = XXX) »
5. **Suivi** : « Perdus de vue (n = XX) », « Abandons (n = XX) »
6. **Analyse** : « Inclus dans l'analyse (n = XXX) », « Exclus de l'analyse (n = XX, raison) »
7. **Outils** : Word SmartArt, Visio, outils en ligne (comme Lucidchart)

## Psychologie

**Q : Comment rapporter la fidélité d'une échelle ?**
R :
1. **Alpha de Cronbach** :
   - Format de rapport : « Alpha de Cronbach = 0,85 »
   - Critères : ≥ 0,70 acceptable, ≥ 0,80 bon, ≥ 0,90 excellent
   - Emplacement : section Méthodes ou Résultats (avant le modèle de mesure)
2. **Fidélité split-half** :
   - Rapport : « Fidélité split-half de Spearman-Brown = 0,82 »
3. **Fidélité test-retest** :
   - Rapport : « Fidélité test-retest à 4 semaines r = 0,78, P < 0,001 »
4. **Fiabilité composite (CR)** :
   - Rapport SEM : « Fiabilité composite CR = 0,86, AVE = 0,55 »

**Q : Comment calculer et rapporter la taille de l'effet ?**
R :
1. **Test t** : d de Cohen = (M1 - M2) / SDcombiné
   - Rapport : « d = 0,65, IC à 95 % [0,32 ; 0,98] »
2. **Analyse de variance** : η²p (êta-carré partiel)
   - Rapport : « η²p = 0,14, IC à 95 % [0,05 ; 0,25] »
3. **Corrélation** : r (Pearson)
   - Rapport : « r = 0,45, IC à 95 % [0,28 ; 0,60] »
4. **Régression** : R² ou ΔR²
   - Rapport : « R² = 0,25, f² = 0,33 »
5. **Classification** : petit (0,2/0,01/0,02), moyen (0,5/0,06/0,15), grand (0,8/0,14/0,35)

**Q : Comment annexer les supports expérimentaux ?**
R :
1. **Questionnaire complet** : items + options + méthode de notation (Annexe A)
2. **Stimuli expérimentaux** : images/textes (Annexe B ou matériel supplémentaire en ligne)
3. **Procédure expérimentale** : étapes détaillées (durée, touches, retours)
4. **Formulaire de consentement éclairé** : modèle (Annexe C)
5. **Données désidentifiées** : lien OSF/Figshare
6. **Code d'analyse** : GitHub/R Markdown
# Foire aux questions sur la gestion du stress et du temps

## Anxiété liée à l'écriture

**Q : Je n'arrive pas à écrire, que faire ?**
R :
1. **Abaissez vos attentes** : écrivez d'abord une version médiocre, autorisez-vous à mal écrire
2. **Écriture libre** : fixez 15 minutes, n'arrêtez pas, ne corrigez pas, ne supprimez pas
3. **Commencez par le plus facile** : la section méthodologie est généralement la plus simple, commencez par là
4. **Décomposez la tâche** : « aujourd'hui, écris seulement le premier paragraphe de l'introduction » plutôt que « écris l'introduction aujourd'hui »
5. **Changez d'environnement** : bibliothèque, café, changez de place
6. **Bougez d'abord** : marchez, faites du sport, prenez une douche (active le réseau neuronal par défaut)
7. **Écriture dialoguée** : imaginez expliquer votre recherche à un camarade, enregistrez puis transcrivez

**Q : Le perfectionnisme me fait procrastiner ?**
R :
1. **Acceptez le brouillon** : toutes les bonnes thèses sont le fruit de révisions, le premier brouillon est forcément médiocre
2. **Fixez une échéance** : « ce paragraphe doit être terminé dans 30 minutes »
3. **Interdisez les corrections** : pendant la phase de brouillon, ne revenez pas en arrière, marquez [À RÉVISER]
4. **Apprenez par comparaison** : consultez les brouillons d'auteurs célèbres
5. **Quantifiez vos objectifs** : « écrire 500 mots aujourd'hui » plutôt que « écrire une bonne introduction »
6. **Acceptez l'échec** : cette thèse n'est pas parfaite, mais suffisante pour l'obtention du diplôme/la publication

**Q : Comment surmonter la peur d'écrire ?**
R :
1. **Thérapie d'exposition** : écrivez un peu chaque jour, augmentez progressivement la difficulté
2. **Visualisation positive** : imaginez la satisfaction d'avoir terminé, plutôt que les difficultés du processus
3. **Engagement social** : dites à vos camarades/directeur votre plan, ajoutez une pression externe
4. **Système de récompenses** : récompensez-vous après avoir écrit un paragraphe (café, vidéo, jeu)
5. **Écriture en pleine conscience** : concentrez-vous sur la phrase en cours, ne vous souciez pas de la qualité globale
6. **Cherchez du soutien** : groupe d'écriture, soutien psychologique, encouragement du directeur

## Gestion du temps

**Q : Comment élaborer un plan de rédaction ?**
R :
1. **Planification rétrograde** : partez de la date limite et rétrogradez, répartissez le temps pour chaque phase
   - Exemple (3 mois pour terminer) :
     - Semaines 1-2 : revue de littérature + plan
     - Semaines 3-6 : brouillon (2 chapitres par semaine)
     - Semaines 7-8 : révision + retour du directeur
     - Semaines 9-10 : finalisation + ajustement de la mise en forme
     - Semaines 11-12 : vérification de similarité + vérification finale
2. **Diagramme de Gantt** : Excel ou outils en ligne (comme TeamGantt) pour visualiser la progression
3. **Marge de manœuvre** : prévoyez 20 % de marge pour chaque phase (faire face aux imprévus)
4. **Jalons** : fixez des étapes clés (par ex. « revue de littérature terminée à la semaine 3 »)
5. **Plan quotidien** : rédigez la veille au soir une liste de tâches (3-5 éléments, réalisables)

**Q : Comment utiliser la technique Pomodoro ?**
R :
1. **Procédure standard** :
   - 25 minutes de concentration sur l'écriture (téléphone en silencieux, réseaux sociaux fermés)
   - 5 minutes de pause (boire de l'eau, s'étirer, regarder au loin)
   - Après 4 pomodoros, pause longue de 15-30 minutes
2. **Ajustements** :
   - Début de rédaction : pomodoro de 15 minutes (phase d'adaptation)
   - Rédaction avancée : pomodoro de 45-50 minutes (état de flux)
3. **Outils** :
   - Forest (plantez des arbres, l'arbre grandit quand le téléphone est posé)
   - TomatoToDo (statistiques, bruit blanc)
   - Minuteur physique (réduire la dépendance au téléphone)
4. **Suivi** : notez le nombre de pomodoros quotidiens, suivez l'évolution de votre efficacité

**Q : Comment utiliser la méthode des blocs de temps ?**
R :
1. **Découpage en blocs** :
   - Matin (9h-12h) : rédaction profonde (parties les plus difficiles)
   - Après-midi (14h-17h) : lecture, organisation, révision
   - Soir (19h-21h) : tâches légères (mise en forme, références bibliographiques)
2. **Protéger les blocs** :
   - Bloc de rédaction profonde : fermez les e-mails, téléphone en silencieux, panneau « ne pas déranger »
   - Bloc de communication : répondez aux e-mails et messages de manière groupée (par ex. à 11h et 16h)
3. **Planification flexible** :
   - Réservez 20 % de temps libre (faire face aux urgences)
   - Bilan hebdomadaire : quels blocs étaient efficaces/non efficaces, ajustez la semaine suivante

**Q : La date limite approche, que faire ?**
R :
1. **Priorisation** :
   - Doit être terminé : chapitres clés (introduction, méthodes, résultats)
   - Devrait être terminé : discussion, conclusion
   - Peut être simplifié : revue de littérature (compressée), remerciements (brefs)
2. **Techniques d'écriture rapide** :
   - Désactivez le mode correction : écrivez d'abord, corrigez ensuite
   - Utilisez la saisie vocale : parler est plus rapide que taper
   - Écriture par modèle : copiez la structure d'une bonne thèse, remplissez le contenu
3. **Cherchez de l'aide** :
   - Entraide entre camarades : vérifications croisées, partage des tâches
   - Communication avec le directeur : expliquez les difficultés, demandez un report (communiquez à l'avance)
   - Services professionnels : mise en forme, vérification de similarité (choisissez avec prudence)
4. **Préservez votre santé** :
   - Dormez au moins 6 heures par nuit (efficacité > temps passé)
   - Pause de 10 minutes toutes les 2 heures (prévenir l'épuisement)
   - Exercices légers : étirements, marche rapide, exercices pour les yeux

## Relation avec le directeur de thèse

**Q : Mon directeur ne répond pas, que faire ?**
R :
1. **Vérifiez votre moyen de communication** :
   - E-mail : objet clair (« Demande de relecture du chapitre 3 »), pièces jointes complètes
   - WeChat : messages courts et polis, ne harcelez pas (1-2 fois par semaine)
   - Entretien en personne : prenez rendez-vous à l'avance, préparez une liste de questions
2. **Choisissez le bon moment** :
   - À éviter : début de semestre, fin de semestre, avant les échéances de projets
   - Privilégié : mercredi-vendredi matin (relativement plus libre)
3. **Stratégie de relance** :
   - Premier contact : attendez 3 à 5 jours
   - Deuxième contact : rappel poli (« Professeur, mon dernier e-mail a peut-être été oublié, je me permets de le renvoyer »)
   - Troisième contact : via un aîné ou par téléphone au bureau
4. **Préparation du contenu** :
   - Joignez une note de modifications : « Suite à vos remarques, j'ai modifié X, Y, Z »
   - Questions précises : ne demandez pas « comment va ma thèse ? », mais « la section 2 est-elle suffisamment argumentée ? »

**Q : Je ne suis pas d'accord avec mon directeur ?**
R :
1. **Comprenez les positions** :
   - Perspective du directeur : normes académiques, faisabilité, exigences d'obtention du diplôme
   - Perspective de l'étudiant : intérêt personnel, innovation, développement personnel
2. **Stratégie de communication** :
   - Commencez par reconnaître : « Vos suggestions sont très précieuses... »
   - Puis exprimez : « Ce que j'envisageais, c'est... »
   - Cherchez un compromis : « Pourrions-nous trouver un terrain d'entente... »
3. **Appuyez-vous sur les données** :
   - « J'ai consulté 10 articles de revues de premier rang, et tous procèdent ainsi... »
   - « Les résultats de l'expérience préliminaire montrent que... »
4. **Acceptez la réalité** :
   - La diplomation d'abord : sur les questions non fondamentales, acceptez le compromis
   - Conservez votre opinion : remerciez votre directeur dans les remerciements, exprimez vos réelles pensées dans une postface
   - Vision à long terme : après l'obtention du diplôme, vous pourrez explorer librement

**Q : Comment solliciter l'aide de son directeur ?**
R :
1. **Préparation minutieuse** :
   - Questions précises : « les résultats de régression du chapitre 3 ne sont pas significatifs » plutôt que « je n'arrive plus à avancer »
   - Solutions essayées : « j'ai essayé les méthodes A et B, les résultats sont respectivement... »
   - Besoin de soutien : « j'ai besoin de votre aide pour établir une collaboration avec l'hôpital XX »
2. **Respectez son temps** :
   - Prenez rendez-vous : « Professeur, êtes-vous disponible mercredi après-midi ? 15 minutes suffiraient »
   - Soyez efficace : envoyez le matériel à l'avance, allez droit au but lors de l'entretien
   - Prenez des notes : apportez un carnet, notez les points essentiels, envoyez un e-mail de confirmation après
3. **Boucle de rétroaction** :
   - Après la demande : rapportez les progrès dans la semaine
   - Après modification : marquez les modifications pour faciliter la relecture du directeur
   - Remerciements : à l'oral + à l'écrit (e-mail/WeChat)

## Soutien entre pairs

**Q : Comment former un groupe d'écriture ?**
R :
1. **Sélection des membres** :
   - 3 à 5 personnes : trop peu manque de dynamisme, trop rend la coordination difficile
   - Même niveau d'avancement : évitez la pression entre « déjà terminé » et « vient de commencer »
   - Disciplines complémentaires : échanges interdisciplinaires pour élargir les perspectives
2. **Mode de fonctionnement** :
   - Fréquence : 1 fois par semaine, 2 heures par session
   - Structure : 30 minutes de rapport d'avancement + 60 minutes de relecture croisée + 30 minutes de discussion
   - Règles : confidentialité, retour constructif, assiduité
3. **Outils en ligne** :
   - Tencent Meeting/Zoom : partage d'écran pour discussion
   - Documents collaboratifs : annotations en ligne
   - Groupe WeChat : pointage quotidien, partage de ressources

**Q : Comment donner un retour à un pair ?**
R :
1. **Méthode du sandwich** :
   - Commencez par le positif : « cette partie de la revue de littérature est très complète... »
   - Puis les suggestions : « l'ajout d'une comparaison XX rendrait cela plus clair... »
   - Terminez par l'encouragement : « la logique globale est bonne, ce sera encore meilleur après révision »
2. **Soyez précis** :
   - Évitez : « c'est mal écrit »
   - Préférez : « le paragraphe 2 manque de clarté dans l'argumentation, je suggère d'ajouter une phrase de transition »
3. **Priorité** :
   - Haute : failles logiques, erreurs factuelles, problèmes de structure
   - Moyenne : expression peu claire, arguments insuffisants, problèmes de mise en forme
   - Basse : amélioration du style, ponctuation
4. **Respectez l'autonomie** :
   - Suggestion et non ordre : « vous pourriez envisager... » plutôt que « vous devez... »
   - Acceptez les refus : l'auteur a le droit de ne pas accepter certaines suggestions

## Préservation de la santé

**Q : Comment atténuer les effets de la sédentarité ?**
R :
1. **Activité régulière** :
   - Toutes les 45 minutes : levez-vous 2 minutes, étirez-vous, regardez au loin
   - Toutes les 2 heures : marchez 5 minutes, allez chercher de l'eau, allez aux toilettes
   - Chaque demi-journée : 15 minutes d'activité en extérieur (marche, exposition au soleil)
2. **Aménagement du poste de travail** :
   - Écran : le haut à hauteur des yeux, distance de 50-70 cm
   - Chaise : soutien lombaire, pieds à plat sur le sol
   - Clavier : coudes à 90°, poignets naturels
3. **Exercices simples** :
   - Cou : rotation gauche/droite, hochement avant/arrière (5 fois dans chaque direction)
   - Épaules : haussement → relâchement, rotation des épaules (5 fois avant et arrière)
   - Dos : torsion assise, flexion debout
   - Jambes : extension assise, montée sur la pointe des pieds debout
4. **Aides matérielles** :
   - Bureau réglable en hauteur : alternance debout/assis (30 % debout + 70 % assis)
   - Ballon de gymnastique : remplace la chaise, active les muscles profonds
   - Repose-pieds : évite de croiser les jambes

**Q : Hygiène visuelle ?**
R :
1. **Règle 20-20-20** : toutes les 20 minutes, regardez un objet à 20 pieds (6 mètres) pendant 20 secondes
2. **Paramètres de l'écran** :
   - Luminosité : cohérente avec la lumière ambiante, sans éblouissement
   - Température de couleur : réduisez la lumière bleue la nuit (f.lux/mode protection des yeux)
   - Police : ≥ 12 points, contraste modéré
3. **Larmes artificielles** : utilisez-les en cas de sécheresse oculaire (sans conservateurs)
4. **Contrôles réguliers** : examen de la vue annuel, ajustement rapide de la correction
5. **Compléments alimentaires** : vitamine A (carottes, épinards), lutéine (maïs, jaune d'œuf)

**Q : Équilibre psychologique ?**
R :
1. **Acceptez vos émotions** :
   - L'anxiété liée à l'écriture est normale, ne vous jugez pas
   - Autorisez-vous à vous reposer : 1 jour par semaine sans toucher à la thèse
2. **Techniques de relaxation** :
   - Respiration profonde : 4 secondes d'inspiration - 7 secondes de rétention - 8 secondes d'expiration
   - Relaxation musculaire progressive : relâchez groupe musculaire par groupe musculaire, de la tête aux pieds
   - Méditation : applications comme Headspace ou Petit Bambou, 10 minutes par jour
3. **Soutien social** :
   - Confiez-vous à votre famille et vos amis (pas uniquement sur la thèse)
   - Participez à des activités qui vous plaisent (sport, musique, dessin)
   - Si nécessaire : centre de counseling de l'université (gratuit, confidentiel)
4. **Restructuration cognitive** :
   - « Je dois absolument faire un travail parfait » → « Je fais de mon mieux, j'accepte l'imperfection »
   - « Cette thèse déterminera toute ma vie » → « Ce n'est qu'une étape »
   - « Les autres sont tous plus compétents que moi » → « Chacun a son propre rythme »
5. **Intervention d'urgence** :
   - Si insomnie persistante, changement d'appétit, baisse de moral ≥ 2 semaines
   - Cherchez une aide professionnelle : centre psychologique de l'université, service de psychiatrie
   - Ligne d'aide psychologique : consultez les numéros d'urgence de votre pays

## Autres conseils pratiques

**Q : Comment maintenir sa motivation pour l'écriture ?**
R :
1. **Visualisez vos progrès** :
   - Barre de progression : Excel ou dessinée à la main, coloriez chaque jour
   - Compteur de mots : Word → Révision → Comptage de mots, enregistrez l'incrément quotidien
   - Liste de contrôle : cochez chaque chapitre terminé, accumulez le sentiment d'accomplissement
2. **Motivation externe** :
   - Engagement-récompense : voyagez ou achetez ce que vous désirez une fois terminé
   - Engagement public : annoncez votre objectif sur les réseaux sociaux, la pression sociale aide
   - Partenaire d'écriture : surveillance mutuelle, pointage quotidien
3. **Sens intrinsèque** :
   - Reliez à l'objectif : « thèse terminée → diplôme obtenu → emploi idéal »
   - Identification à la valeur : « ma recherche peut aider... »
   - Perspective de croissance : « la compétence rédactionnelle est un savoir-faire pour la vie »

**Q : Comment gérer les distractions pendant l'écriture ?**
R :
1. **Déconnexion numérique** :
   - Téléphone : Forest/minuteur, bloquez les applications de divertissement
   - Ordinateur : bloquez les sites distrayants (Cold Turkey/StayFocusd)
   - Notifications : fermez les fenêtres contextuelles e-mail/WeChat, consultez à des heures fixes
2. **Gestion de l'environnement** :
   - Bibliothèque : apportez votre gourde, écouteurs (bruit blanc)
   - Chambre/maison : dégagez le bureau, ne gardez que l'essentiel
   - Café : choisissez un coin calme, évitez les heures de pointe
3. **Gestion des tâches** :
   - Règle des deux minutes : ce qui prend moins de 2 minutes, faites-le immédiatement
   - Traitement par lots : répondez aux e-mails en une fois, recherchez la littérature en une fois
   - Déléguez : ce qui peut être confié à un camarade/assistant, ne le faites pas vous-même

**Q : Comment débloquer une impasse dans l'écriture ?**
R :
1. **Changez de tâche** :
   - N'arrivez pas à écrire le corps du texte → organisez les références bibliographiques
   - N'arrivez pas à écrire la méthode → dessinez des graphiques/schémas
   - N'arrivez pas à écrire la discussion → lisez des articles pertinents pour trouver l'inspiration
2. **Réduisez la difficulté** :
   - Du paragraphe → à la phrase → au mot-clé → à la carte mentale
   - Saisie vocale : enregistrez avec le téléphone, transcrivez puis éditez
3. **Cherchez la stimulation** :
   - Lisez un bon article : imitez la structure, apprenez les expressions
   - Participez à des conférences académiques : écoutez les autres, stimulez vos idées
   - Discutez avec des camarades : exprimez-vous à l'oral, clarifiez vos pensées
4. **Mise de côté temporaire** :
   - Règle des 24 heures : laissez reposer un jour, reprenez le lendemain
   - Effet du sommeil : pensez au problème avant de dormir, vous aurez peut-être de nouvelles idées au réveil
   - Activation par l'exercice : après une course ou une natation, le cerveau est plus actif
# Foire aux questions techniques et opérationnelles

## Mise en forme dans Word

**Q : Comment configurer les en-têtes et pieds de page ?**
R :
1. **Sauts de section** : pour des en-têtes différents selon les chapitres, insérez un « saut de section » (Mise en page → Sauts → Page suivante)
2. **Désactiver le lien** : double-cliquez sur l'en-tête → décochez « Lier au précédent » pour une configuration indépendante
3. **Pages paires/impaires différentes** : outils d'en-tête/pied de page → cochez « Pages paires et impaires différentes »
4. **Première page différente** : la page de couverture n'affiche pas d'en-tête → cochez « Première page différente »
5. **Format de numérotation** : Insertion → Numéro de page → Format des numéros de page (page de début, style de numérotation)
6. **Ligne d'en-tête** : sélectionnez le texte d'en-tête → Accueil → Bordures → Pas de bordure (ou Ctrl+Maj+N pour effacer le format)

**Q : Comment générer et mettre à jour automatiquement une table des matières ?**
R :
1. **Appliquer les styles de titre** : sélectionnez le titre → Accueil → Titre 1/2/3 (il faut d'abord utiliser les styles, ne pas ajuster manuellement la taille)
2. **Insérer la table** : Références → Table des matières → Table automatique 1/2
3. **Mettre à jour** : clic droit sur la table → Mettre à jour la zone → Mettre à jour toute la table (ou F9)
4. **Format de la table** : Références → Table des matières → Table personnalisée → Modifier (ajuster la police, le retrait)
5. **Erreur « Entrée de table introuvable »** : vérifiez que les titres utilisent bien les styles et non un formatage manuel

**Q : Comment utiliser les renvois (références croisées) ?**
R :
1. **Renvoi vers un graphique/tableau** : Références → Renvoi → Type de référence (Figure/Tableau) → Sélectionnez le numéro → Insérer
2. **Renvoi vers une section** : Références → Renvoi → Type de référence (Titre) → Sélectionnez la section → Insérer
3. **Renvoi vers un numéro de page** : Références → Renvoi → Contenu du renvoi (Numéro de page)
4. **Mettre à jour les renvois** : Ctrl+A pour tout sélectionner → F9 pour mettre à jour les zones (ou clic droit → Mettre à jour la zone)
5. **Basculer code/affichage** : Alt+F9 (afficher le code de zone)

**Q : Comment ajuster le format des références bibliographiques ?**
R :
1. **Utiliser les notes de fin** : Références → Insérer une note de fin (format de numérotation : [1])
2. **Utiliser les renvois** : Références → Renvoi → Type de référence (Note de fin)
3. **Ajustement par lot** : Rechercher/Remplacer (^e remplacé par [^&])
4. **Retrait pendulaire** : sélectionnez les références → Paragraphe → Retrait pendulaire 2 caractères
5. **Ajustement de l'espacement** : Paragraphe → avant 0 après 0, interligne fixe 18 points

**Q : Comment créer un tableau à trois lignes (tableau académique) ?**
R :
1. Insérez un tableau → sélectionnez le tableau → Conception de tableau → Bordures → Pas de bordure
2. Sélectionnez la première ligne → Bordures → Bordure supérieure + bordure inférieure (1,5 point)
3. Sélectionnez la dernière ligne → Bordures → Bordure inférieure (1,5 point)
4. Ligne fine sous l'en-tête (0,75 point)
5. Propriétés du tableau → Habillage du texte → Aucun (évite les déplacements intempestifs)

## Conversion de fichiers

**Q : Comment convertir un PDF en Word modifiable ?**
R :
1. **Adobe Acrobat** : Fichier → Exporter vers → Microsoft Word (meilleure conservation de la mise en forme)
2. **WPS** : PDF → clic droit → Convertir PDF en Word (version gratuite avec filigrane)
3. **Outils en ligne** : iLovePDF, Smallpdf (attention à la confidentialité)
4. **Problèmes de reconnaissance** : les PDF scannés nécessitent d'abord une OCR (Adobe/ABBYY)
5. **Correction du format** : après conversion, vérifiez : sauts de page, en-têtes, formules, graphiques

**Q : Comment convertir un fichier LaTeX en Word ?**
R :
1. **Pandoc** : `pandoc input.tex -o output.docx --bibliography=refs.bib`
2. **TeX4ht** : `make4ht file.tex "docx"`
3. **Copie manuelle** : PDF → copier le texte → coller dans Word (les formules doivent être rééditées)
4. **Graphiques** : générez les figures en PDF depuis LaTeX → insérez dans Word
5. **Références** : exportez le fichier BibTeX → importez dans EndNote/Zotero → Word

**Q : Le format change après conversion Word en PDF ?**
R :
1. **Intégration des polices** : Fichier → Options → Enregistrement → Intégrer les polices dans le fichier
2. **Impression en PDF** : Fichier → Imprimer → Microsoft Print to PDF (plus stable que Enregistrer sous)
3. **Vérification des marges** : Mise en page → Marges → Personnalisées (assurez-vous de la cohérence avec Word)
4. **Vérification des graphiques** : dans Word, graphiques → Groupez → puis convertissez en PDF (évite le décalage)
5. **Vérification de la table des matières** : mettez à jour la table avant la conversion en PDF (évite les erreurs de pagination)

## Autres problèmes techniques

**Q : La résolution des images de la thèse est insuffisante ?**
R :
1. **Images vectorielles** : privilégiez PDF/EPS/EMF/SVG (zoom illimité)
2. **Images matricielles** : ≥ 300 dpi (norme d'impression), ≥ 150 dpi (version numérique)
3. **Captures d'écran** : zoomez à 200 % avant de capturer (augmente la résolution)
4. **Exportation depuis un logiciel** : Origin/Visio → Exporter → PDF/EMF (vectoriel)
5. **Photoshop** : Image → Taille de l'image → résolution 300 → Rééchantillonnage

**Q : Comment redimensionner les images par lot ?**
R :
1. **Word** : sélectionnez l'image → Format → Taille → hauteur/largeur uniforme
2. **Photoshop** : Fichier → Automatisation → Présentation PDF → taille uniforme
3. **Python** :
```python
from PIL import Image
img = Image.open('input.jpg')
img = img.resize((width, height), Image.Resampling.LANCZOS)
img.save('output.jpg', dpi=(300, 300))
```
4. **Outils en ligne** : iLoveIMG pour le redimensionnement par lot (attention à la confidentialité)

**Q : Le fichier de la thèse est trop volumineux, comment le compresser ?**
R :
1. **Compression des images** : sélectionnez l'image → Format → Compresser les images → 150 ppi (impression) / 96 ppi (écran)
2. **Compression PDF** : Adobe Acrobat → Fichier → Enregistrer sous → PDF réduit
3. **Compression en ligne** : Smallpdf, iLovePDF (attention à la confidentialité)
4. **Compression en volumes** : séparez le corps du texte et les annexes
5. **Suppression du contenu masqué** : Fichier → Informations → Vérifier les problèmes → Inspecter le document → Supprimer le contenu masqué
