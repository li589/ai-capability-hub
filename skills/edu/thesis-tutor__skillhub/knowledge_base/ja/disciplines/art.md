# 芸術学 - 論文作成ガイド

## 学科の特徴
- 創造的表現、美的分析、文化解釈を重視
- 研究方法は多様：作品分析、インタビュー、民族誌、実践研究
- 論文形式は柔軟：伝統的論文、制作說明、展覧会企画
- 視覚材料を重視：作品集、展覧会記録、設計図面

## 研究タイプ

### 1. 理論研究
- **適用**：美術史、美学理論、芸術批評
- **核心要素**：
  - 文献整理（美術史、理論著作）
  - 作品分析（形式分析、図像学）
  - 理論構築（概念解釈、価値判断）
- **論文構成**：問題→文献→分析→理論→結論

### 2. 実践研究
- **適用**：制作系学位（MFA、芸術修士）
- **核心要素**：
  - 制作過程記録
  - 作品解釈
  - 理論的反省
- **論文構成**：背景→制作→展示→反省→結論

### 3. ケーススタディ
- **適用**：芸術家研究、展覧会分析、芸術教育
- **核心要素**：
  - ケース選定と記述
  - 深度分析
  - 理論的高揚
- **論文構成**：背景→ケース→分析→考察→結論

## 研究方法

### 質的方法（主要）
- **作品分析**：形式分析、図像学、記号学
- **インタビュー**：芸術家インタビュー、観客インタビュー
- **民族誌**：芸術コミュニティ、アトリエ観察
- **現象学**：美的体験、芸術知覚

### 量的方法（補助）
- **アンケート調査**：観客研究、芸術市場
- **コンテンツ分析**：メディア呈現、芸術報道
- **統計分析**：オークションデータ、展覧会データ

### 実践研究方法
- **制作日誌**：制作過程の記録
- **作品解釈**：自己分析と反省
- **展覧会企画**：空間設計、物語構築

## 研究テーマの方向性

### 美術学

   - 時代研究（宋代絵画、ルネサンス）

2. **美術理論**
   - 美学理論（美的経験、芸術の本質）
   - 批評方法（形式主義、図像学）

3. **美術教育**
   - 教授法研究
   - カリキュラム設計
   - 創造性育成

### デザイン学

   - ブランドデザイン

2. **環境デザイン**
   - インテリアデザイン

3. **プロダクトデザイン**
   - インダストリアルデザイン
   - インタラクションデザイン
   - サービスデザイン

### 音楽学

   - 作曲家研究
   - 時代研究
   - 流派研究

   - 和声分析
   - 曲式構造

3. **音楽教育**
   - 教授法
   - カリキュラム設計
   - 技能育成

## 論文構成テンプレート

### 理論研究型
```
1. 序論（研究背景、問題、意義）
2. 文献綜述（研究現状、理論的枠組み）
3. 分析（作品分析、理論解釈）
4. 考察（発見、比較、理論的高揚）
5. 結論（貢献、限界、展望）
```

### 実践研究型
```
1. 序論（制作背景、問題意識）
2. 文献と理論（関連研究、理論的枠組み）
3. 制作過程（材料、方法、実験）
4. 作品解釈（形式分析、意義解読）
5. 反省と結論（収穫、限界、展望）
```

## 執筆のポイント

### 視覚材料の処理
- 高品質画像（300 DPI以上）
- 規範的な注記（著者、タイトル、年代、素材、サイズ）
- 適切な使用（著作権問題）
- 図文結合（分析の裏付け）

### 理論の運用
- 適切な理論的枠組みの選択
- 理論の内涵の深い理解
- 柔軟な運用而非生硬な套用
- 批判的思考

### 学術規範
- 引用フォーマット（MLAまたはシカゴ形式）
- 注釈の使用（脚注、末尾注）
- 参考文献の規範
- 図版説明

## よくある問題

1. **理論と実践の乖離**：制作と論文の有機的つながりの欠如
2. **記述が分析を上回る**：記述レベルに留まり、深度分析の欠如
3. **理論運用が不自然**：理論の套用而非真正的理解
4. **視覚材料品質が低い**：画像の不鮮明さ、注記の不規範さ
5. **文献綜述が弱い**：系統的整理の欠如
