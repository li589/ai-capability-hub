# 図書館学 - 論文作成ガイド

## 学科の特徴
- 情報サービス、知識管理、文献組織を重視
- ユーザー研究、技術応用、実践革新を重視
- 研究方法は多様：調査、実験、ケース、システム開発
- 学際的特性が顕著（コンピュータ、管理、伝播）

## 研究タイプ

### 1. ユーザー研究
- **適用**：情報行動、ユーザー需要、サービス評価
- **核心要素**：
  - ユーザープロファイル（年齢、職業、需要）
  - 行動分析（検索、利用、共有）
  - 満足度評価（サービス品質、改善方向）
- **論文構成**：背景→方法→調査→分析→提案

### 2. 技術研究
- **適用**：デジタル図書館、情報システム、データ管理
- **核心要素**：
  - システム設計（アーキテクチャ、機能、技術）
  - 開発実装（プログラミング、テスト、デプロイ）
  - 効果評価（性能、ユーザーフィードバック）
- **論文構成**：需要→設計→実装→評価→結論

### 3. 理論研究
- **適用**：情報組織、知識管理、図書館学理論
- **核心要素**：
  - 文献整理（理論発展、研究現状）
  - 概念分析（定義、内包、外延）
  - 理論構築（モデル、枠組み、原則）
- **論文構成**：問題→文献→分析→理論→結論

## 学科の細分

### 図書館学
- **文献資源建設**：収集・編目、館蔵発展、資源評価
- **情報サービス**：参考相談、学科サービス、知識サービス
- **読書推進**：読書活動、読書療法、児童読書
- **図書館管理**：戦略計画、人的資源、業績評価

### アーカイブズ学
- **アーカイブ管理**：収集、整理、鑑定、保管
- **アーカイブ情報化**：デジタル化、電子ファイル、デジタルアーカイブ
- **アーカイブ利用**：編纂、展覧、公開
- **アーカイブ保護**：修復、複製、環境制御

### 情報資源管理
- **知識管理**：知識組織、知識グラフ、知識サービス
- **データ管理**：データガバナンス、データ品質、データセキュリティ
- **競合情報**：情報収集、分析、応用
- **デジタル humanities**：テキスト分析、データ可視化、デジタル出版

## 論文構成テンプレート

### 調査研究型
```
1. 序論（研究背景、問題、意義）
2. 文献綜述（研究現状、理論的基盤）
3. 研究設計（対象、方法、ツール）
4. 調査結果（データ、グラフ）
5. 分析と考察（発見、比較、解釈）
6. 結論と提案（貢献、限界、改善）
```

### システム開発型
```
1. 序論（需要背景、目標）
2. 需要分析（ユーザー需要、機能需要）
3. システム設計（アーキテクチャ、データベース、インターフェース）
4. システム実装（技術選定、主要コード）
5. システムテスト（機能テスト、性能テスト）
6. 結論（まとめ、展望）
```

## 執筆のポイント

### 調査研究
- 標本選択（ランダム、層別、便宜）
- アンケート設計（信頼性、妥当性）
- データ分析（記述統計、推測統計）
- 結果提示（グラフ、テキスト結合）

### システム開発
- 需要分析（ユーザーインタビュー、ユースケース分析）
- システム設計（アーキテクチャ図、ER図、フローチャート）
- 主要技術（アルゴリズム、実装詳細）
- テスト検証（テストケース、結果分析）

### 理論研究
- 文献整理（系統的、批判的）
- 概念定義（明確、正確）
- 論理推理（厳密、根拠あり）
- 理論貢献（革新、実用）

## よくある問題

1. **テーマが広すぎる**：範囲が広すぎて深入しにくい
2. **文献綜述が弱い**：系統的整理の欠如、重要文献の遺漏
3. **研究方法が不適切**：方法と問題の不一致
4. **データ分析が浅い**：記述統計のみ、深入分析の欠如
5. **実践価値が不明確**：提案が抽象的、操作可能性の欠如
