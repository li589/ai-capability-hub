# 考古学 - 論文作成ガイド

## 学科の特徴
- 田野発掘、実物研究、歴史再構築を重視
- 地層学、類型学、科技考古を重視
- 研究期間が長い（発掘、整理、研究）
- 学際的特性が顕著（歴史、地質、生物、化学）

## 研究タイプ

### 1. 田野考古報告
- **適用**：遺跡発掘、調査報告
- **核心要素**：
  - 地層記述（土質、土色、包含物）
  - 遺構記述（灰坑、住居址、墓葬）
  - 遺物記述（土器、石器、骨器）
- **論文構成**：概況→地層→遺構→遺物→編年→結語

### 2. 专题研究
- **適用**：器物研究、文化研究、年代学
- **核心要素**：
  - 資料収集（考古資料、文献）
  - 類型学分析（型式分類、変遷序列）
  - 文化解釈（機能、意義、交流）
- **論文構成**：序論→資料→分析→考察→結論

### 3. 科技考古
- **適用**：年代測定、成分分析、残留物分析
- **核心要素**：
  - 標本採取（代表性、保存状態）
  - 分析方法（C14、熱ルミネッセンス、XRF）
  - データ解釈（年代、産地、技法）
- **論文構成**：背景→標本→方法→結果→考察

## 学科の細分

### 先史考古
- **旧石器時代**：人類起源、石器技術
- **新石器時代**：農業起源、文明起源
- **青銅器時代**：国家形成、初期文明

### 歴史考古
- **夏商周考古**：都城、青銅器、甲骨文字
- **秦漢考古**：帝陵、簡牘、シルクロード
- **魏晋南北朝考古**：墓葬、仏教遺構
- **隋唐宋元考古**：都市、陶磁器、対外交流

### 専門考古
- **環境考古**：古環境、古気候、人と環境の関係
- **動物考古**：動物骨、家畜化、祭祀
- **植物考古**：植物遺存、農業、食生活
- **冶金考古**：鉱冶遺跡、金属器、技術

## 論文構成テンプレート

### 田野報告型
```
1. 概況（地理位置、発掘経緯）
2. 地層堆積（地層関係、編年根拠）
3. 遺構（灰坑、住居址、墓葬など）
4. 遺物（土器、石器、骨器など）
5. 編年と年代（文化序列、絶対年代）
6. 結語（主な収穫、学術的意義）
```

### 专题研究型
```
1. 序論（研究史、目的、方法）
2. 資料（由来、数量、状態）
3. 分析（類型学、統計、比較）
4. 考察（機能、意義、交流）
5. 結論（主な見解、学術的貢献）
```

## 執筆のポイント

### 田野記録
- 地層関係図
- 遺構平面図・断面図
- 遺物線画
- 写真記録

### 類型学分析
- 型式分類基準
- 変遷序列
- 典型的器物
- 比較資料

### 年代学
- 地層根拠
- 器物類型
- 年代測定データ
- 文献記載

## よくある問題

1. **地層記述が不明確**：土質、土色、包含物の詳細不足
2. **類型学が不規範**：型式分類基準の不統一
3. **年代判断が独断的**：多重証拠の欠如
4. **文化解釈が表面的**：深い分析の欠如
5. **図版品質が低い**：写真の不鮮明さ、線画の不規範さ
