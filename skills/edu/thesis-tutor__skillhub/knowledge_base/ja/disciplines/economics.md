# 経済学 - 論文作成ガイド

## 概要
経済学の論文作成は、理論的厳密性、実証検証、政策的関連性を重視します。主要な評価基準は：研究問題の重要性、理論的フレームワーク、計量経済学的方法論、実践的含意です。

## 研究タイプ

### 1. 実証研究
- **特徴**: 実データを使用して経して経済理論を検証
- **構成**: 文献レビュー → 理論モデル → データと方法論 → 結果 → 政策的含意
- **要点**: 因果関係の識別、ロバスト性検査、内生性の考慮

### 2. 理論研究
- **特徴**: 新しい経済モデルの開発または既存モデルの拡張
- **構成**: 動機 → モデル設定 → 均衡分析 → 比較静学 → 拡張
- **要点**: 数学的厳密性、経済的直感、検証可能な予測

### 3. 政策分析
- **特徴**: 定量的手法を使用して経済政策を評価
- **構成**: 政策背景 → 理論的フレームワーク → 実証戦略 → 発見 → 提言
- **要点**: 反事実分析、厚生評価、実装の実現可能性

## 章構成

### 第1章：序論（8-10ページ）
1. 研究背景と動機
2. 研究問題と目的
3. 文献への貢献
4. 論文構成

### 第2章：文献レビュー（15-20ページ）
1. 理論的基盤
2. 実証的証拠（テーマ別に整理）
3. 文献で使用されている識別戦略
4. 研究ギャップとあなたの貢献

### 第3章：理論的フレームワーク（10-15ページ）
1. モデルの仮定
2. エージェントの最適化問題
3. 均衡の特徴付け
4. 比較静学
5. 検証可能な仮説

### 第4章：データと方法論（10-15ページ）
1. データソースと説明
2. 変数の構築
3. 計量経済モデルの仕様
4. 識別戦略
5. ロバスト性検査

### 第5章：結果（15-20ページ）
1. 記述統計
2. 主要回帰結果
3. ロバスト性検査
4. 異質性分析
5. メカニズム分析

### 第6章：結論（3-5ページ）
1. 発見の要約
2. 政策的含意
3. 限界
4. 今後の研究方向

## 基本的な作成手順

### 1. 選題（研究テーマの選定）
- 経済学のトレンドを調査
- 政策的関心のあるテーマを選択
- データの入手可能性を確認

### 2. 文献調査
- 主要データベース：EconLit、JSTOR、NBER
- 理論文献と実証文献の整理
- 識別戦略の文献を重点的に調査

### 3. 理論モデルの構築
- 経済的直感の明確化
- 数学的モデルの定式化
- 検証可能な仮説の導出

### 4. 実証分析
- データの前処理
- 推定手法の選択
- ロバスト性検査の実施

### 5. 結果の解釈
- 経済的意味の考察
- 政策的含意の議論
- 限界と今後の課題

## 方法論

### 主な計量経済学的手法
- **横断データ**: OLS、IV、Probit/Logit
- **パネルデータ**: 固定効果、ランダム効果、差の差（DID）、RDD
- **時系列**: VAR、ARIMA、共和分
- **構造推定**: GMM、MLE、シミュレーション法

### 識別戦略
- 無作為化比較試験（RCT）
- 自然実験
- 操作変数法（IV）
- 回帰不連続デザイン（RDD）
- 差の差法（DID）
- 合成コントロール法

### ソフトウェアツール
- **Stata**: 応用経済学の業界標準
- **R**: オープンソース、可視化に優れる
- **Python**: 機械学習との統合
- **Matlab**: 構造モデリング
- **Julia**: 高性能コンピューティング

## よくある問題

1. **内生性**: 省略変数、逆因果関係、測定誤差
2. **サンプル選択バイアス**: 非ランダムサンプル、生存バイアス
3. **弱い操作変数**: IV回帰での低いF統計量
4. **P-hacking**: 事前登録、多重検定補正
5. **外部妥当性**: 一般化可能性の限界
