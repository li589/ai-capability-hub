# 理学 - 論文作成ガイド

## 学科の特徴
- 実験検証、数学的導出、理論革新を重視
- データの正確性、再現性、査読を重視
- 会議論文とジャーナル論文を equally 重視
- グラフ品質の要求が高い（データ図、数式、実験装置図）

## 研究タイプ

### 1. 実験研究
- **適用**：物理、化学、生物実験
- **核心要素**：
  - 実験設計（変数制御、反復実験）
  - データ収集（機器精度、誤差分析）
  - 結果分析（統計検定、不確実性）
- **論文構成**：目的→方法→実験→結果→分析

### 2. 理論研究
- **適用**：数学、理論物理、理論化学
- **核心要素**：
  - 問題提起（仮説、推測）
  - 理論導出（証明、計算）
  - 結果考察（意義、応用）
- **論文構成**：問題→準備→主要結果→証明→考察

### 3. 計算研究
- **適用**：計算物理、計算化学、生物情報学
- **核心要素**：
  - モデル構築（アルゴリズム、数値方法）
  - プログラム実装（コード、検証）
  - 結果分析（収束性、精度）
- **論文構成**：問題→方法→実装→結果→考察

## 学科の細分

### 数学
- **純粋数学**：代数、幾何、解析、整数論
- **応用数学**：確率統計、オペレーションズリサーチ、計算数学
- **数学教育**：教授法、カリキュラム設計

### 物理学
- **凝縮態物理**：材料、超伝導、半導体
- **素粒子物理**：高エネルギー物理、核物理
- **光学**：レーザー、光ファイバー、光エレクトロニクス
- **天体物理学**：宇宙論、銀河、ブラックホール

### 化学
- **有機化学**：合成、反応メカニズム
- **無機化学**：錯体化学、材料化学
- **分析化学**：機器分析、分光学
- **物理化学**：熱力学、速度論

### 生物学
- **分子生物学**：遺伝子、タンパク質
- **細胞生物学**：細胞シグナル、細胞周期
- **生態学**：個体群、群集、生態系
- **生物情報学**：配列分析、構造予測

## 論文構成テンプレート

### 実験研究型
```
1. 序論（研究背景、問題、目的）
2. 実験部分（材料、方法、機器）
3. 結果と考察（データ、分析、比較）
4. 結論（発見、意義、展望）
```

### 理論研究型
```
1. 序論（問題背景、文献綜述）
2. 準備知識（定義、補題）
3. 主要結果（定理、証明）
4. 考察（応用、一般化）
5. 結論（貢献、展望）
```

## 執筆のポイント

### 実験記述
- 再現可能なまで詳細
- すべてのパラメータを含む
- 機器の型式を説明
- 試薬の出所を明記

### データ提示
- 有効数字を使用
- 誤差範囲を報告
- 単位を注記
- グラフは明瞭で規範的

### 数式組版
- 数式エディタを使用
- 記号体系を統一
- 番号を連続
- 各記号を説明

## よくある問題

1. **実験が不十分**：反復回数が少なく、対照区の欠如
2. **データ処理が不適切**：統計方法の誤り、誤差分析の不足
3. **文献綜述が弱い**：最新の進展の欠如、綜述の不十分さ
4. **考察が浅い**：結果の羅列のみ、深入分析の欠如
5. **執筆が不規範**：用語の不統一、フォーマットの混乱
