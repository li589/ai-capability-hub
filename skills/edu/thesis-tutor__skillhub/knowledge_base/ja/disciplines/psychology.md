# 心理学 - 論文作成ガイド

## 概要
心理学の論文作成は、実証研究、理論的基盤、方法論的厳密性を重視します。主要な評価基準は：研究問題の重要性、理論的貢献、方法論的健全性、実践的含意です。

## 研究タイプ

### 1. 実験研究
- **特徴**: 変数を操作して因果関係を確立
- **構成**: 序論 → 方法 → 結果 → 考察
- **要点**: 無作為割り当て、対照条件、操作チェック

### 2. 相関研究
- **特徴**: 変数間の関係を検討
- **構成**: 序論 → 方法 → 結果 → 考察
- **要点**: 適切な測定、統計的検出力

### 3. 縦断研究
- **特徴**: 時間的変化の研究
- **構成**: 序論 → 方法 → 結果 → 考察
- **要点**: アトリション、コホート効果、練習効果

### 4. 質的研究
- **特徴**: 主観的体験の探索
- **構成**: 序論 → 方法 → 発見 → 考察
- **要点**: 信頼性、再帰性、飽和

### 5. メタ分析
- **特徴**: 既存研究の定量的統合
- **構成**: 序論 → 方法 → 結果 → 考察
- **要点**: 包含基準、効果量の計算、異質性

## 章構成

### 第1章：序論（10-15ページ）
1. 心理学的問題または現象
2. 文献レビュー
3. 理論的フレームワーク
4. 研究問題と仮説
5. 研究の意義

### 第2章：文献レビュー（20-30ページ）
1. 理論的基盤
2. 実証的証拠
3. 調節変数と媒介変数
4. 研究ギャップ

### 第3章：方法論（15-25ページ）
1. 参加者
2. 測定と計器
3. 手順
4. データ分析計画
5. 倫理的考慮

### 第4章：結果（15-25ページ）
1. 予備分析
2. 記述統計
3. 主要分析
4. 追加分析

### 第5章：考察（15-20ページ）
1. 発見の要約
2. 理論的含意
3. 実践的含意
4. 限界
5. 今後の方向

### 第6章：結論（3-5ページ）
1. 主要貢献
2. 最終考察

## 基本的な作成手順

### 1. 選題（研究テーマの選定）
- 心理学分野の課題を特定
- 理論的に意義のあるテーマを選択
- 研究の実現可能性を評価

### 2. 文献調査
- 主要データベース：PsycINFO、J-STAGE
- 関連研究の整理
- 理論的フレームワークの調査

### 3. 研究設計
- 研究方法の選択
- 参加者の選定
- 倫理審査の申請

### 4. データ収集と分析
- データの収集
- 統計分析の実施
- 結果の解釈

### 5. 結果の報告
- 発見の明確な記述
- 理論的貢献の強調
- 実践的含意の議論

## 方法論

### 研究設計
- **被験者間設計**: 条件ごとに異なる参加者
- **被験者内設計**: 同じ参加者が全条件に参加
- **混合設計**: 両者の組み合わせ
- **因子計画**: 複数の独立変数

### データ収集
- **調査**: 自己報告測定
- **行動測定**: 反応時間、精度
- **生理測定**: EEG、fMRI、コルチゾール
- **観察**: 行動コーディング
- **インタビュー**: 構造化、半構造化

### 分析手法
- **ANOVA**: 群平均の比較
- **回帰分析**: 転帰の予測
- **因子分析**: 潜在構成概念の特定
- **SEM**: 複雑なモデルの検証
- **マルチレベルモデリング**: ネストされたデータ
- **ベイズ分析**: 事前知識の統合

### 主要測定
- **性格**: ビッグファイブ、MBTI
- **知能**: WAIS、Raven's
- **気分**: PANAS、BDI、STAI
- **認知**: ワーキングメモリ、注意課題

## よくある問題

1. **要求特性**: 参加者の期待
2. **実験者バイアス**: 意図しない影響
3. **サンプルバイアス**: WEIRDサンプル（西洋、教育、工業化、裕福、民主主義）
4. **再現性の危機**: P-hacking、出版バイアス
5. **倫理的問題**: 欺瞞、デブリーフィング
