# 文学 - 論文作成ガイド

## 概要
文学の論文作成は、テクスト分析、理論的解釈、文学作品への批判的関与を重視します。主要な評価基準は：分析の深さ、理論的洗練、テクスト的証拠、独創的解釈です。

## 研究タイプ

### 1. 精読
- **特徴**: 特定のテクストの詳細な分析
- **構成**: テクスト選択 → 分析フレームワーク → 精読 → 解釈 → 結論
- **要点**: 言語、形式、意味への注意

### 2. 比較分析
- **特徴**: 2つ以上の文学作品の比較
- **構成**: 作品選択 → 比較フレームワーク → 分析 → 統合 → 結論
- **要点**: 体系的な比較、意味のある関連

### 3. 理論応用
- **特徴**: 文学理論をテクストに適用
- **構成**: 理論概要 → テクスト選択 → 応用 → 発見 → 含意
- **要点**: 理論的理解、厳密な適用

### 4. 歴史的文脈化
- **特徴**: 歴史的文脈における文学研究
- **構成**: 歴史的背景 → テクスト分析 → 文脈-テクスト関係 → 意義
- **要点**: 歴史的正確性、文化的理解

## 章構成

### 第1章：序論（8-12ページ）
1. 文学的問題または問い
2. 検討対象のテクスト
3. 理論的フレームワーク
4. 研究目的
5. 論文構成

### 第2章：文献レビュー（15-25ページ）
1. テクストに関する先行研究
2. 使用された理論的アプローチ
3. 批判的議論
4. 研究ギャップ

### 第3章：理論的フレームワーク（10-15ページ）
1. 理論の概要
2. 主要概念と用語
3. 応用方法論
4. 理論選択の正当化

### 第4章：分析（25-40ページ）
1. テクスト1の分析
2. テクスト2の分析（比較の場合）
3. テーマ的探索
4. 形式的分析
5. テクスト間の関連

### 第5章：考察（10-15ページ）
1. 発見の統合
2. 文学批評への貢献
3. より広い含意
4. 限界

### 第6章：結論（3-5ページ）
1. 主要洞察の要約
2. 独創的貢献
3. 今後の研究方向

## 基本的な作成手順

### 1. 選題（研究テーマの選定）
- 文学分野の課題を特定
- 研究価値のあるテーマを選択
- 研究の実現可能性を評価

### 2. 文献調査
- 主要データベース：MLA International Bibliography、J-STAGE
- 関連研究の整理
- 理論的アプローチの調査

### 3. テクストの選定と分析
- 分析対象のテクスト選択
- 理論的フレームワークの適用
- テクストの精読

### 4. 解釈の展開
- 独創的解釈の提示
- 既存研究との関連付け
- 文学的意義の強調

### 5. 結論の作成
- 主要洞察の要約
- 文学研究への貢献
- 今後の研究方向

## 方法論

### 分析アプローチ
- **形式主義/ニュークリティシズム**: テクスト自体に焦点
- **構造主義**: 基盤となる構造とコード
- **脱構築主義**: 二項対立の解体
- **新歴史主義**: テクストと歴史的文脈
- **ポストコロニアリズム**: 権力、帝国、抵抗
- **フェミニズム/ジェンダー研究**: ジェンダー表現
- **精神分析批評**: 無意識の欲求
- **エコクリティシズム**: 環境と自然

### テクスト分析
- **精読**: 行ごとの分析
- **レトリック分析**: 言語と説得
- **物語分析**: 物語と談話
- **文体分析**: 言語と形式

### 研究手法
- **アーカイブ研究**: 原稿、手紙、書評
- **デジタル人文**: テクストマイニング、コーパス分析
- **受容研究**: 読者反応

## よくある問題

1. **弱いテーゼ**: 明確な論証や解釈がない
2. **テクスト的証拠の不足**: テクストによって支持されていない主張
3. **理論の誤用**: 表面的または不正確な理論の使用
4. **構成の不備**: 論理的進行の欠如
5. **批評家への過度の依存**: 要約が多すぎ、分析が少なすぎ
