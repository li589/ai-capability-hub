# 経営学 - 論文作成ガイド

## 概要
経営学の論文作成は、理論的基盤、実証的厳密性、組織への実践的関連性を重視します。主要な評価基準は：研究問題の重要性、理論的貢献、方法論的健全性、経営的含意です。

## 研究タイプ

### 1. 量的研究
- **特徴**: 調査やアーカイブデータを用いた仮説検証
- **構成**: 文献レビュー → 仮説 → 方法論 → 結果 → 考察
- **要点**: 妥当な測定、適切なサンプル、統計的厳密性

### 2. 質的研究
- **特徴**: インタビュー/ケースによる経営現象の探索
- **構成**: 研究問題 → 理論的フレームワーク → データ収集 → 分析 → 発見
- **要点**: 理論的サンプリング、分析的厳密性

### 3. 混合研究法
- **特徴**: 量的アプローチと質的アプローチの組み合わせ
- **構成**: 研究問題 → 設計 → データ収集 → 統合 → 推論
- **要点**: 目的のある統合、補完的な洞察

### 4. 概念研究
- **特徴**: 新しい理論やフレームワークの開発
- **構成**: 問題特定 → 文献統合 → フレームワーク開発 → 命題 → 含意
- **要点**: 論理的一貫性、理論的貢献

## 章構成

### 第1章：序論（8-12ページ）
1. 経営的問題または現象
2. 研究問題
3. 理論と実践への貢献
4. 論文構成

### 第2章：文献レビュー（20-30ページ）
1. 理論的基盤
2. 実証的証拠
3. 概念的フレームワーク
4. 研究ギャップ

### 第3章：理論的フレームワーク（10-15ページ）
1. 理論選択と正当化
2. 概念モデル
3. 仮説の開発
4. 境界条件

### 第4章：方法論（15-20ページ）
1. 研究設計
2. サンプルとデータ収集
3. 測定と計器
4. 分析技法
5. 妥当性と信頼性

### 第5章：結果（15-25ページ）
1. 記述統計
2. 測定モデル評価
3. 構造モデル結果
4. 仮説検定
5. 事後分析

### 第6章：考察（15-20ページ）
1. 発見の要約
2. 理論的含意
3. 経営的含意
4. 限界
5. 今後の研究方向

### 第7章：結論（3-5ページ）
1. 主要貢献
2. 実践的推奨事項
3. 最終的考察

## 基本的な作成手順

### 1. 選題（研究テーマの選定）
- 経営分野の課題を特定
- 実務上有意義なテーマを選択
- 研究の実現可能性を評価

### 2. 文献調査
- 主要データベース：Business Source Complete、J-STAGE
- 関連研究の整理
- 理論的フレームワークの調査

### 3. 研究設計
- 研究方法の選択
- データ収集方法の決定
- サンプルの選定

### 4. データ分析
- データの前処理
- 分析手法の適用
- 結果の解釈

### 5. 結果の報告
- 発見の明確な記述
- 理論的貢献の強調
- 経営的含意の提示

## 方法論

### 量的研究法
- **調査研究**: 質問票設計、パイロットテスト
- **アーカイブ研究**: 二次データ分析
- **実験設計**: 室内実験とフィールド実験
- **メタ分析**: 既存研究の統合

### 質的研究法
- **ケーススタディ**: 単一ケースと複数ケース
- **グラウンデデオリ**: データからの理論構築
- **エスノグラフィ**: 組織文化研究
- **アクションリサーチ**: 協働的探究

### 分析技法
- **SEM**: 構造方程式モデリング（AMOS、LISREL、Mplus）
- **回帰分析**: OLS、ロジスティック、階層型
- **HLM**: 階層線形モデリング
- **fsQCA**: ファジーセット質的比較分析
- **コンテンツ分析**: コーディングと分類

### 主要構成概念
- 職務満足
- 組織コミットメント
- リーダーシップ効果
- チームパフォーマンス
- イノベーション
- 戦略的志向

## よくある問題

1. **共通方法バイアス**: 単一ソース、同時測定
2. **内生性**: 逆因果関係、省略変数
3. **サンプルサイズ**: 複雑なモデルに対する検出力不足
4. **構成概念妥当性**: 測定特性の不備
5. **弱い理論**: 理論的基盤の不足
