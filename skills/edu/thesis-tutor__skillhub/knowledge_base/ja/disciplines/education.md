# 教育学 - 論文作成ガイド

## 概要
教育学の論文作成は、教育理論、研究方法論、教学と学習への実践的含意を重視します。主要な評価基準は：研究問題の重要性、理論的基盤、方法論的厳密性、教育的影響です。

## 研究タイプ

### 1. 量的研究
- **特徴**: 数値データを使用して教育現象を測定
- **構成**: 文献レビュー → 研究問題 → 方法 → 結果 → 考察
- **要点**: 妥当な測定ツール、適切なサンプルサイズ、統計的検出力

### 2. 質的研究
- **特徴**: インタビュー、観察を通じて教育体験を探索
- **構成**: 研究問題 → 理論的フレームワーク → データ収集 → 分析 → 発見
- **要点**: 信頼性、再帰性、厚い記述

### 3. 混合研究法
- **特徴**: 量的アプローチと質的アプローチの組み合わせ
- **構成**: 根拠 → 設計 → データ収集 → 統合 → 推論
- **要点**: タイミング、優先順位、統合戦略

### 4. 設計ベース研究
- **特徴**: 教育介入の反復的設計とテスト
- **構成**: 問題分析 → 設計 → 実装 → 評価 → 改善
- **要点**: 生態学的妥当性、反復サイクル、実践的関連性

## 章構成

### 第1章：序論（8-12ページ）
1. 教育的問題または機会
2. 研究目的と問題
3. 研究の意義
4. 主要用語の定義
5. 論文構成

### 第2章：文献レビュー（20-30ページ）
1. 理論的フレームワーク
2. 歴史的文脈
3. 現在の研究テーマ
4. 使用された方法論的アプローチ
5. 文献のギャップ

### 第3章：方法論（15-20ページ）
1. 研究パラダイム（実証主義、解釈主義、実用主義）
2. 研究設計
3. 参加者とサンプリング
4. データ収集方法
5. データ分析手順
6. 信頼性/妥当性の測定

### 第4章：発見/結果（15-25ページ）
1. 量的：表、グラフ、統計検定
2. 質的：テーマ、カテゴリー、物語
3. 混合：発見の統合

### 第5章：考察（10-15ページ）
1. 発見の解釈
2. 文献との関連
3. 実践への含意
4. 限界
5. 今後の研究

### 第6章：結論（3-5ページ）
1. 主要発見の要約
2. 知識への貢献
3. 推奨事項

## 基本的な作成手順

### 1. 選題（研究テーマの選定）
- 教育分野の課題を特定
- 実践的価値のあるテーマを選択
- 研究の実現可能性を評価

### 2. 文献調査
- 主要データベース：ERIC、J-STAGE、CiNii
- 教育理論と実証研究の整理
- 研究方法論の文献を調査

### 3. 研究設計
- 研究パラダイムの選択
- データ収集方法の決定
- 参加者の選定

### 4. データ収集と分析
- 倫理審査の申請
- データの収集
- 分析手法の適用

### 5. 結果の報告
- 発見の明確な記述
- 文献との関連付け
- 実践的含意の議論

## 方法論

### 量的研究法
- **調査研究**: 質問票設計、リッカート尺度
- **実験デザイン**: 事前テスト/事後テスト、対照群
- **相関研究**: 変数間の関係
- **因果推論**: 傾向スコアマッチング、RCT

### 質的研究法
- **事例研究**: 限定されたシステムの詳細探索
- **現象学**: 参加者の生きた体験
- **グラウンデデオリ**: データからの理論開発
- **エスノグラフィ**: 文化的浸透と観察
- **ナラティブ探究**: 物語と生活史

### データ収集ツール
- **調査**: Qualtrics、Google Forms、SurveyMonkey
- **インタビュー**: 半構造化、フォーカスグループ
- **観察**: 参加観察、非参加観察
- **文書**: カリキュラム教材、学生作品

### 分析ソフトウェア
- **量的**: SPSS、R、Stata、SAS
- **質的**: NVivo、Atlas.ti、MAXQDA
- **混合**: 統合フレームワーク

## よくある問題

1. **妥当性の脅威**: 選択バイアス、成熟、テスト効果
2. **信頼性**: 評定者間一致、再テスト
3. **一般化可能性**: 限定的なサンプル、文脈特有
4. **研究者バイアス**: 再帰性、メンバーチェッキング
5. **倫理的考慮**: 知的同意、機密性
