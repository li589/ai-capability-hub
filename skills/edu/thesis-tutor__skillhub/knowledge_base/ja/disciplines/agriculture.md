# 農学 - 論文作成ガイド

## 学科の特徴
- 実践応用、圃場試験、収量向上を重視
- 実験設計、統計分析、普及応用を重視
- 研究期間が長い（作物の生育周期）
- 地域性が強い（気候、土壌の差異）

## 研究タイプ

### 1. 圃場試験
- **適用**：作物栽培、品種選育、植物保護
- **核心要素**：
  - 試験設計（ランダム化ブロック、分割区設計）
  - データ収集（収量、品質、抵抗性）
  - 統計分析（分散分析、多重比較）
- **論文構成**：目的→材料→方法→結果→考察

### 2. 室内研究
- **適用**：分子生物学、生理生化学、土壌分析
- **核心要素**：
  - 実験方法（抽出、検出、分析）
  - データ処理（統計検定、グラフ）
  - 結果検証（反復、対照）
- **論文構成**：序論→材料→方法→結果→考察

### 3. 調査研究
- **適用**：農業経済、農村発展、農業政策
- **核心要素**：
  - 調査設計（アンケート、インタビュー）
  - データ収集（標本、サンプリング方法）
  - 分析方法（記述統計、回帰分析）
- **論文構成**：背景→方法→調査→分析→結論

## 学科の細分

### 作物学
- **作物栽培**：作付体系、施肥技術、水分管理
- **作物遺伝育種**：品種改良、交配育種、分子育種
- **作物生理**：光合成、栄養代謝、ストレス生理

### 植物保護
- **植物病理**：病害診断、防除技術、耐病性育種
- **農業昆虫**：害虫防除、天敵利用、総合防除
- **農薬学**：薬効試験、残留分析、安全評価

### 園芸学
- **果樹学**：品種選育、栽培技術、収穫後処理
- **野菜学**：施設栽培、品質制御、安全生産
- **花卉学**：品種資源、繁殖技術、開花期制御

### 農業資源と環境
- **土壌学**：土壌肥沃度、土壌改良、土壌汚染
- **農業気象**：気候資源、災害警報、気候変動
- **農業生態**：エコ農業、循環型農業、持続可能な発展

## 論文構成テンプレート

### 圃場試験型
```
1. 序論（研究背景、目的、意義）
2. 材料と方法（試験区、材料、設計、測定）
3. 結果と分析（収量、品質、抵抗性など）
4. 考察（メカニズム、比較、応用）
5. 結論（主な発見、提言）
```

### 室内研究型
```
1. 序論（研究現状、目的）
2. 材料と方法（材料、試薬、方法）
3. 結果（データ、グラフ）
4. 考察（メカニズム、意義）
5. 結論（貢献、展望）
```

## 執筆のポイント

### 圃場試験の記述
- 試験地点（緯度経度、標高、気候）
- 土壌条件（タイプ、肥沃度、pH）
- 試験材料（品種、由来、特性）
- 試験設計（処理、反復、小区面積）

### データ提示
- 収量データ（kg/亩またはt/ha）
- 品質指標（タンパク質、でんぷんなど）
- 統計分析（F検定、LSD、Duncan）
- グラフ規範（誤差線、有意性マーカー）

### 普及価値
- 経済効果分析
- 技術実現可能性
- 地域適応性
- 普及提言

## よくある問題

1. **試験設計が不規範**：対照区の欠如、反復不足
2. **データ処理が不適切**：統計方法の誤り、有意性マーカーの混乱
3. **考察が浅い**：結果の羅列のみ、メカニズム分析の欠如
4. **普及価値が不明確**：経済効果分析の欠如
5. **執筆が不規範**：用語の不統一、フォーマットの混乱
