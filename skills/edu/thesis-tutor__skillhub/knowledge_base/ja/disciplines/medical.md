# 医学 - 論文作成ガイド

## 概要
医学の論文作成は、臨床的関連性、方法論的厳密性、エビデンスに基づく実践を重視します。主要な評価基準は：臨床的意義、研究設計の質、統計的妥当性、トランスレーショナル potential です。

## 研究タイプ

### 1. 臨床研究
- **特徴**: 疾患、治療、患者転帰の研究
- **構成**: 背景 → 方法 → 結果 → 考察 → 結論
- **要点**: 患者安全、倫理審査、CONSORTガイドライン

### 2. 疫学研究
- **特徴**: 疾患の分布と決定要因の研究
- **構成**: 序論 → 方法 → 結果 → 考察 → 公衆衛生への含意
- **要点**: 研究設計、交絡制御、母集団の代表性

### 3. 実験室研究
- **特徴**: 基礎科学とトランスレーショナル研究
- **構成**: 序論 → 材料と方法 → 結果 → 考察
- **要点**: 再現性、対照、検証

### 4. システマティックレビュー/メタ分析
- **特徴**: 既存のエビデンスの統合
- **構成**: 序論 → 方法 → 結果 → 考察 → 結論
- **要点**: PRISMAガイドライン、質の評価、異質性

## 章構成

### 第1章：序論（8-12ページ）
1. 臨床的問題と意義
2. 現在の知識とギャップ
3. 研究目的と仮説
4. 論文構成

### 第2章：文献レビュー（20-30ページ）
1. 疾患の背景
2. 病態生理
3. 現在の治療法
4. エビデンスのギャップ

### 第3章：方法（15-25ページ）
1. 研究設計
2. 参加者と設定
3. データ収集
4. 転帰測定
5. 統計分析計画
6. 倫理的考慮

### 第4章：結果（15-25ページ）
1. 参加者の特性
2. 主要転帰
3. 副次的転帰
4. サブグループ分析
5. 有害事象

### 第5章：考察（15-20ページ）
1. 主要発見
2. 文献との比較
3. 臨床的含意
4. 限界
5. 今後の方向

### 第6章：結論（3-5ページ）
1. 発見の要約
2. 臨床的意義
3. 推奨事項

## 基本的な作成手順

### 1. 選題（研究テーマの選定）
- 医学分野の課題を特定
- 臨床的に意義のあるテーマを選択
- 研究の実現可能性を評価

### 2. 文献調査
- 主要データベース：PubMed、MEDLINE、J-STAGE
- 関連研究の整理
- エビデンスの評価

### 3. 研究設計
- 研究方法の選択
- サンプルサイズの計算
- 倫理審査の申請

### 4. データ収集と分析
- データの収集
- 統計分析の実施
- 結果の解釈

### 5. 結果の報告
- 発見の明確な記述
- 臨床的含意の議論
- 限界の認識

## 方法論

### 研究デザイン
- **無作為化比較試験（RCT）**: 治療効果のゴールドスタンダード
- **コホート研究**: 前向きまたは後ろ向き
- **症例対照研究**: 稀な疾患
- **横断研究**: 有病率
- **ケースシリーズ/レポート**: 新しい観察

### データ収集
- **臨床データ**: 医療記録、検査
- **患者報告転帰**: 質問票
- **実験室データ**: バイオマーカー、画像
- **管理データ**: 病院記録

### 統計手法
- **記述統計**: 人口統計、ベースライン特性
- **推測統計**: 仮説検定、信頼区間
- **生存分析**: カプランマイヤー、コックス回帰
- **多変量回帰**: 交絡要因の調整
- **診断テスト**: 感度、特異度、ROC曲線

### 報告ガイドライン
- **CONSORT**: 無作為化試験
- **STROBE**: 観察研究
- **PRISMA**: システマティックレビュー
- **STARD**: 診断研究
- **CARE**: 症例報告

## よくある問題

1. **選択バイアス**: 代表的でないサンプル
2. **情報バイアス**: 測定誤差、リコールバイアス
3. **交絡**: 制御されていない変数
4. **小さなサンプルサイズ**: 検出力の低い研究
5. **多重比較**: 第1種の過誤の増大

## 基本的な作成手順

### バンクーバースタイル
- 番号付き引用
- 著者名：姓＋イニシャル
- ジャーナル略語
- 標準フォーマット

### 医学用語
- 標準的な医学用語を使用
- 初出時に略語を定義
- 測定値に単位を含める
- 信頼区間とp値を報告

### 倫理的要件
- IRB/倫理委員会の承認
- 知的同意の文書化
- 患者プライバシーの保護
- 利益相反の開示
