# 論文作成よくある質問 FAQ

## テーマ選定段階

**Q：指導教員が指定したテーマがやりたくない場合はどうすればいいですか？**
A：
1. まず深く理解する。思っているのと違うかもしれない
2. 代替案を用意する（2-3つのテーマ）、理由を説明する
3. コミュニケーション時に強調する：興味駆動の方が成果を出しやすい
4. 指導教員が堅持する場合、受け入れ可能か評価するか、指導教員の変更を検討する

**Q：テーマが大きすぎる/小さすぎるかどうかはどう判断しますか？**
A：
- 大きすぎる："中国の経済発展研究"（範囲が広すぎる）
- 小さすぎる："ある村のある世帯の調査"（一般化できない）
- 適切："デジタル金融が農村住民の消費に与える影響——XX省の調査データに基づく"
- テスト：一文で明確に表現できるか？6-12ヶ月で完了できるか？

**Q：他の人が似たテーマを研究していたら、私もうできますか？**
A：できます。关键是差異点を見つけることです：
- 異なる視点（理論的枠組みが異なる）
- 異なる方法（量的 vs 質的）
- 異なる状況（異なる地域/時期/グループ）
- 異なる変数（調整変数/中介変数を追加）
- 異なるデータ（より新しい、より詳細なデータ）

## 文献綜述段階

**Q：文献が読みきれない場合はどうすればいいですか？**
A：
- 階層的読書：まず抄読を読み、精読を決定する
- 綜述を読む：まず分野の綜述を読み、全体像を素早く把握する
- 核心を掴む：基盤的+マイルストーン+最新の進展
- ツールを使用：Zoteroで管理、タグで分類
- 時間制限を設定：毎日2-3編、完璧主義にならない

**Q：文献綜述が羅列になってしまいました**
A：
- テーマ別に組織する、著者別ではない
- 各段落に論点を持たせる："これらの研究は...を示している"
- 接続詞を使用：However、Similarly、In contrast
- 批判的評価："Aの長所は...しかし限界は..."
- Gapを特定する："尽管...但...尚未解決"

**Q：引用が多すぎて重複率が高くなる心配があります**
A：
- 間接引用：自分の言葉で概括+注記
- 直接引用の割合を制限（<10%）
- 綜述部分は自分の枠組みで組織する
- 大段落の引用を避ける

## 執筆段階

**Q：書けない/詰まってしまいました**
A：
- 期待を下げる：まずゴミのような初稿を書き、後から修正する
- 章を変える：まず簡単な部分（方法、データ）を書く
- 定時執筆：毎日決まった時間、習慣にする
- 口述録音：まず話して、後からテキストに整理する
- 人に相談：指導教員/クラスメイトと話して、アイデアを刺激する
- 文献を読む：関連文献を再読し、インスピレーションを見つける

**Q：指導教員に"革新性がない"と言われました**
A：
- 革新性のタイプを明確にする：理論/方法/材料/視点
- 既存研究と比較する：あなたの違いはどこか？
- 証明を強化する：革新性は全文に貫かれる必要がある、序論で一言述べるだけでは不十分
- 文献を補充する：文献が足りず、位置づけを見つけられていない可能性

**Q：データ/実験結果が理想的でない場合はどうすればいいですか？**
A：
- まずチェックする：データ処理に誤りがないか？
- 誠実に報告する：陰性結果も結果である
- 原因を考察する：なぜ結果が理想的でないのか？
- 仮説を調整する：仮説に問題がないか？
- 分析を補充する：サブサンプル、代替変数
- 詐偽しない：学術誠実性のレッドライン

**Q：論文がひどすぎて指導教員に見せられない**
A：
- 指導教員はもっとひどい論文を見たことがある、恥ずかしがる必要はない
- 早ければ早いほど良い、早ければ問題を早く発見できる
- 明確に助けを求める："この部分で詰まっています、アドバイスが必要です"
- 問題を持っていく："帮我看看"だけでなく、具体的に

## フォーマットと規範

**Q：学校のフォーマット要件が不明確です**
A：
- 学校のテンプレートを探す（大学院サイト）
- 教務の先生に最新の規範を確認する
- 先輩の論文を参考にする
- 細部に注意する：ヘッダー/フッター、ページ番号、図表番号

**Q：参考文献のフォーマットが混乱しています**
A：
- ツールを使用：Zotero/EndNoteで自動生成
- フォーマットを統一：GB/T 7714-2015（中文）またはAPA（英文）
- 細部をチェック：著者名、年、ページ、DOI
- 原文と照合：引用の正確性を確保

**Q：図表のレイアウトはどうすればいいですか？**
A：
- 図の題名は下、表の題名は上
- 番号：図1-1、表2-1（章-連番）
- 出典：データの出所を明記
- 明瞭：解像度が十分、フォントが読みやすい
- 一貫性：スタイルを統一（色、フォント）

## 重複チェックと低減

**Q：重複率が基準を超えてしまいました**
A：
- まず分析する：どの部分が重複しているか？
- 専門用語：保持、置換できない
- 綜述部分：自分の枠組みで書き直す
- 実験記述：標準的な記述は受け入れ可能
- 同義語置換：学術的正確さを保つ
- 文構造の再構成：能動/受動の転換
- グラフ化：テキストを表/フローチャートに変換

**Q：AI検出に合格しません**
A：
- 自己チェック：GPTZeroなどのツールで検出
- 書き直し：個人の声、具体的な詳細を追加
- 混合：自分で書く+AI支援の校正
- 注記：学校が要求する場合、AIの使用範囲を説明
- 訴訟：誤判の場合、執筆過程の証拠を保存

**Q：学校の重複チェックシステムと自分のチェック結果が異なります**
A：
- 学校のシステムを基準とする
- 異なるシステムのデータベースが異なる
- 学校の指定システムで予備チェックすることを推奨
- 注意：淘宝の重複チェックは論文を漏洩する可能性がある

## 答弁段階

**Q：答弁で緊張してしまいます**
A：
- 十分な準備：各部分に精通する
- 模擬答弁：クラスメイトに模擬答弁を依頼
- 講演原稿を用意：PPTを読むのではなく、説明する
- 深呼吸：登場前に数回深呼吸する
- 緊張を受け入れる：適度な緊張は正常

**Q：答弁の先生の質問に答えられません**
A：
- 誠実に認める："この問題について十分に考察していませんでした"
- 答えようとする："私の理解に基づくと..."
- 問題を記録：答弁後に研究する
- 争わない：虚心に批評を受け入れる
- 知ったかぶりをしない：先生にはわかる

**Q：答弁後に大幅な修正が必要です**
A：
- 正常：ほとんどの論文に修正が必要
- 分類：必須修正 vs 推奨修正
- コミュニケーション：指導教員と修正範囲を確認
- 計画：修正スケジュールを策定
- 実行：一条ずつ実施、漏れがないように

## メンタル調整

**Q：他人の論文が良くて、自分が不安です**
A：
- 比較の罠：それぞれのペースが異なる
- 自分に集中する：完成は完璧より重要
- サポートを求める：友人/指導教員と話す
- タスクを分解：大きな目標を小さなタスクに分ける
- 進歩を祝う：小さな目標を達成したら自分にご褒美

**Q：諦めたい/延期したい**
A：
- 原因を評価：能力の問題かメンタルの問題か？
- ヘルプを求める：指導教員、心理カウンセリング
- 結果を考える：延期の影響（就職、心理）
- 短期休憩：数日休んでから決定
- 延期を決定した場合：計画を立て、無期限に拖延しない

**Q：論文は書いたが、十分に良いと感じない**
A：
- 完成 > 完璧：まず提出し、後から改善する機会がある
- 限界を受け入れる：すべての論文に限界がある
- 未来の研究：結論で今後の方向を説明
- 過度な修正を避ける：修正を繰り返すとかえって悪くなる可能性

## その他の質問

**Q：修士/博士論文を引用できますか？**
A：できますが、注意が必要です：
- 未公開の学位論文は品質がまちまち
- 優先的に公開済みのジャーナル/会議論文を引用
- 引用する場合は、学位論文であることを明記
- 引用割合は高くすべきではない

**Q：百度百科/知乎を引用できますか？**
A：推奨されません：
- 非学術来源、信頼性が不確実
- 重複チェックで赤くマークされる可能性
- 必ず引用する場合、 original の学術来源を探す
- ネット来源は[EB/OL]タイプを使用、アクセス日を明記

**Q：論文で"私"と書けますか？**
A：学科によります：
- 理工系：通常受動態/"本文"を使用
- 社会科学："私"を使用できる（反省的研究）
- 学校の要件を確認：明确规定がある学校も
- 一貫性：全文で統一、混用しない

**Q：付録には何を入れますか？**
A：
- アンケート/インタビューガイド
- 原始データ（該当する場合）
- コード（該当する場合）
- 補充グラフ
- 長い数式の導出
- 注意：付録も重複チェックにカウント（一部の学校）

**Q：謝辞はどう書きますか？**
A：
- 誠実：定型文を使わない
- 具体的：具体的な助けに言及
- 適度：長すぎない（通常1ページ）
- チェック：重要な人を漏らさない
- 注意：謝辞は重複チェックにカウントされない

## 助けを求める渠道
- **指導教員**：第一の選択、定期的なコミュニケーション
- **先輩**：経験の伝承
- **クラスメイト**：互相討論、模擬答弁
- **図書館**：文献検索トレーニング
- **ライティングセンター**：一部の学校が提供
- **心理カウンセリング**：深刻な不安がある場合
- **ネット**：知乎、B站、学術公式アカウント

## 最後の注意
- 論文は人生のごく一部
- 完成は完璧より重要
- 助けを求めることは弱さではない
- 健康を維持する（睡眠、運動、社交）
- 自分が完成できると信じる

# 学科別質問 FAQ

## コンピュータサイエンス

**Q：コードを論文に入れるにはどうすればいいですか？**
A：
1. **擬似コード**：アルゴリズム環境（LaTeX algorithmic/algorithm2e）を使用、構文よりロジックを強調
2. **コードスニペット**：主要な関数（<20行）、核心的なアイデアを説明
3. **完全なコード**：付録またはGitHubリンクに配置、本文で引用
4. **フォーマット**：等幅フォント（Courier New）、行番号、シンタックスハイライト（minted/listings）
5. **コメント**：主要なステップを説明、コードの翻訳ではない
6. **オープンソース**：GitHubリンク、READMEと実行手順を添付

**Q：アルゴリズムの擬似コードはどう書きますか？**
A：
```
アルゴリズム1：クイックソート
入力：配列A、長さn
出力：ソートされた配列
1.  if n ≤ 1 then return A
2.  pivot ← A[n/2]
3.  left ← {x ∈ A | x < pivot}
4.  right ← {x ∈ A | x > pivot}
5.  return QuickSort(left) + {pivot} + QuickSort(right)

要点：
- 入力/出力は明確に
- 制御構造は明瞭に（インデント）
- 主要なステップにコメント
- 計算量を注記（時間O(n log n)、空間O(log n)）
```

**Q：実験の再現性はどう保証しますか？**
A：
1. **環境記録**：OS、Pythonバージョン、ライブラリバージョン（requirements.txt）
2. **ランダムシード**：seedを固定（np.random.seed(42)）
3. **データセット**：公開データセット+前処理コード
4. **ハイパーパラメータ**：完全なリスト（付録または設定ファイル）
5. **ハードウェア**：GPU型式、メモリ、トレーニング時間
6. **オープンソース**：GitHub+README+Dockerイメージ

**Q：システムアーキテクチャ図はどう描きますか？**
A：
1. **階層**：ユーザー層→アプリケーション層→サービス層→データ層
2. **コンポーネント**：矩形（サービス）、円柱（データベース）、矢印（データフロー）
3. **ツール**：Visio、Draw.io、ProcessOn、LaTeX TikZ
4. **規範**：色を統一（入力/処理/出力/保存）
5. **注記**：インターフェース名、プロトコル、データ形式

## 経済学

**Q：データの出所はどう注記しますか？**
A：
1. **公式データ**：国家統計局、中央銀行、財政部（URLとアクセス日を添付）
2. **データベース**：CSMAR、Wind、CEIC（バージョンとダウンロード日を明記）
3. **調査データ**：CFPS、CHARLS（年とバージョンを明記）
4. **ネットデータ**：クローラーで取得（時間範囲とクロール日を明記）
5. **フォーマット**："データはCSMARデータベース（2023年12月ダウンロード）からのもの"

**Q：計量モデルの設定はどう書きますか？**
A：
1. **ベンチマークモデル**：Y = α + βX + γControls + ε（数式で提示）
2. **変数定義**：各変数の意味、単位、予想符号を説明
3. **モデル選択**：OLS/FE/RE/DID/IVの理論的根拠
4. **堅牢性**：変数の置換、モデルの置換、サブサンプル
5. **内生性**：操作変数、DID、RDDの選択理由

**Q：内生性はどう処理しますか？**
A：
1. **遺漏変数**：固定効果、操作変数、制御関数
2. **逆因果**：ラグ変数、GMM、DID
3. **測定誤差**：操作変数、多重指標法
4. **サンプル選択**：Heckman二段階、PSM
5. **報告**：内生性の来源、処理方法、結果の比較を説明

**Q：堅牢性検定はどう行いますか？**
A：
1. **変数の置換**：主要変数の測定方法を変更（例：ROAをROEに）
2. **モデルの置換**：OLSをTobit/Probit/Logitに
3. **サブサンプル**：年度別/業界別/地域別
4. **外れ値の排除**：1%Winsorize、ST企業を除外
5. **安慰剤検定**：処理群をランダムに割り当て
6. **操作変数**：IVを変更、弱い操作変数検定

## 教育学

**Q：倫理審査のプロセスは何ですか？**
A：
1. **提出材料**：研究計画、インフォームドコンセント、アンケート/インタビューガイド、研究者の資格
2. **審査タイプ**：
   - 免除審査：匿名調査、公開データ
   - 迅速審査：低リスク研究（教室観察など）
   - 会議審査：未成年者、センシティブな話題
3. **学校倫理委員会**：教育学部/学校倫理委員会
4. **承認期間**：1-4週間（前もって準備）
5. **フォローアップ審査**：年次進捗報告、重篤な有害事象報告

**Q：学校との協力はどう進めますか？**
A：
1. **連絡渠道**：教育局→学校指導部→学年主任→クラス担任
2. **紹介状**：学校/学部の印章、研究目的と秘密保持措置を説明
3. **協力モデル**：
   - 互恵モデル：教育リソース/トレーニングを提供
   - 参加モデル：教師を研究設計に招待
   - 委託モデル：学校が研究問題を委託
4. **協定**：責任、データ使用、成果の帰属を明確化
5. **感謝**：研究終了後に結果をフィードバック、報告書を贈呈

**Q：保護者同意書はどう書きますか？**
A：
1. **タイトル**："XX研究への参加に関する通知と同意書"
2. **研究目的**：平易な言葉で説明（例："学生の学習方法を理解する"）
3. **手順**：何をするか、どのくらい時間がかかるか、どこで
4. **リスク**：最小リスク（例："身体的リスクはなく、疲労を感じる可能性あり"）
5. **秘密保持**：匿名処理、データは研究のみに使用
6. **自発性**：いつでも退出可能、成績に影響しない
7. **連絡先**：研究者名、電話番号、メールアドレス
8. **署名**：保護者署名+日付+学生氏名

## 法学

**Q：法条の引用フォーマットは何ですか？**
A：
1. **中国法律**：
   - 初回引用：《中華人民共和国民法典》第1165条（以下"《民法典》"と略称）
   - 再引用：《民法典》第1165条
   - 脚注フォーマット：民法典第1165条第1項
2. **司法解釈**：
   - 《最高人民法院关于〈中華人民共和国民法典〉総則編若干問題的解釈》第1条
3. **行政法規**：《XX条例》第X条
4. **地方法規**：《XX省XX条例》第X条
5. **国際条約**：《XX公约》第X条

**Q：判例の検索と引用はどうしますか？**
A：
1. **検索プラットフォーム**：
   - 中国裁判文書網（公式）
   - 北大法宝（専門）
   - 無訟、聚法案例
2. **検索技巧**：
   - キーワード：案由、法条、争点
   - 高度な検索：裁判所のレベル、裁判年、事件タイプ
   - 類似事件検索：類似の事案、類似の法条適用
3. **引用フォーマット**：
   - 判決書："XX訴XX案、XX法院（20XX）X民初字第X号"
   - 指導性案例："指導案例X号：XX案"
   - 公報案例："《最高人民法院公報》20XX年第X期"

**Q：比較法研究はどう行いますか？**
A：
1. **機能主義**：同じ問題を解決する異なる解決策を比較（例："離婚冷静期"の各国比較）
2. **法系選択**：大陸法系、英米法系、混合法系
3. **比較维度**：
   - 立法モデル：法典化/単行法/判例法
   - 制度設計：構成要件、法的効果
   - 司法実践：判例統計、適用頻度
4. **資料来源**：
   - 外国法：公式法典、学術著作、判例データベース
   - 翻訳：公式翻訳、権威ある学者の翻訳
5. **注意事項**：
   - 簡単な優劣比較を避ける
   - 制度背景に注目（社会、文化、歴史）
   - 借鑑提案を提起（実現可能性分析）

## 文学

**Q：テキストの引用フォーマットは何ですか？**
A：
1. **直接引用**：
   - 短い引用（<4行）：本文に融合、引用符付き、ページ番号を注記
   - 長い引用（≥4行）：独立段落、インデント、引用符なし
2. **間接引用**：
   - 観点を概述："鲁迅は...と考えている（《吶喊》序文、第Xページ）"
   - 過度な引用を避ける：自分の言葉で分析
3. **複数バージョン**：
   - 古典：バージョンを注記（例："《紅楼夢》、人民文学出版社、1982年、第Xページ"）
   - 外国語：翻訳者を明記（例："[米]ヘミングウェイ著、X訳"）
4. **引用原則**：
   - 核心概念/用語：直接引用
   - あらすじ概述：間接引用
   - 批評観点：出所を明記

**Q：理論的枠組みはどう選択しますか？**
A：
1. **古典理論**：
   - 形式主義：テキスト精読、構造分析
   - 新批評：逆説、皮肉、緊張
   - 構造主義：物語学、記号学、神話原型
   - 後構造主義：解構、差異、差延
2. **現代理論**：
   - フェミニズム：ジェンダー視点、身体政治
   - 後植民主義：オリエンタリズム、hybridity
   - 生態批評：環境、自然、動物
   - 文化研究：権力、イデオロギー、表象
3. **選択原則**：
   - テキストとの適合：理論がテキストの特徴を説明できる
   - 問題との適合：理論が研究問題に答えられる
   - 詰め込みを避ける：1-2つの核心理論で十分
   - 批判的使用：盲従せず、限界を指摘

**Q：批評方法はどう運用しますか？**
A：
1. **テキスト精読**：
   - 言語レベル：語彙選択、修辞技法、文構造
   - 形式レベル：物語視点、時間構造、空間設定
   - テーマレベル：核心意象、象徴システム、価値衝突
2. **比較研究**：
   - 影響研究：AがBに与えた影響（実証材料）
   - 並行研究：AとBの類似/差異（影響関係なし）
   - 学際的：文学と哲学/歴史/心理学
3. **文化研究**：
   - 文脈還原：歴史背景、社会条件
   - 権力分析：誰の声が聞こえる/压制されるか
   - 受容研究：読者反応、伝播効果
4. **注意事項**：
   - 主観的推測を避ける：テキストの証拠で裏付け
   - 過度な解釈を避ける：合理的な解釈とこじつけを区別
   - 批判的距離を保つ：個人的な感情を代入しない

## 医学

**Q：倫理批号はどう書きますか？**
A：
1. **フォーマット**："本研究はXX大学倫理委員会の承認を受けた（批号：XXXX-2023-001）"
2. **位置**：方法部分の冒頭または脚注
3. **登録**：臨床試験は登録が必要（ClinicalTrials.gov：NCTXXXXXXXX）
4. **インフォームドコンセント**："すべての被験者がインフォームドコンセントに署名した"
5. **例外**："後ろ向き研究のため、倫理委員会がインフォームドコンセントを免除（批号：XXXX）"

**Q：統計方法はどう記述しますか？**
A：
1. **ソフトウェア**："SPSS 26.0とR 4.2.1を用いて統計分析を行った"
2. **検定水準**："両側検定、α=0.05"
3. **記述統計**："計量資料は平均±標準偏差（x̄±s）で表し、計数資料は頻度（%）で表した"
4. **群間比較**："二群の比較には独立標本t検定またはMann-Whitney U検定を用いた"
5. **多重比較**："多重比較には一元配置分散分析を用い、多重比較にはLSD法またはBonferroni補正を用いた"
6. **相関分析**："相関性にはPearsonまたはSpearman相関分析を用いた"
7. **回帰分析**："多変量分析には多変量線形/Logistic/Cox回帰を用いた"
8. **生存分析**："生存曲線にはKaplan-Meier法を用い、群間比較にはLog-rank検定を用いた"

**Q：CONSORTフローチャートはどう作りますか？**
A：
1. **開始点**："スクリーニング評価された被験者（n=XXX）"
2. **除外**："除外（n=XX）：組入れ基準に合致しない（n=XX）、参加拒否（n=XX）、その他の理由（n=XX）"
3. **無作為化**："無作為割り付け（n=XXX）"
4. **グループ分け**："介入群（n=XXX）"、"対照群（n=XXX）"
5. **フォローアップ**："脱落（n=XX）"、"中止（n=XX）"
6. **分析**："分析に組入れ（n=XXX）"、"分析から除外（n=XX、理由）"
7. **ツール**：Word SmartArt、Visio、オンラインツール（Lucidchartなど）

## 心理学

**Q：尺度の信頼性はどう報告しますか？**
A：
1. **Cronbach's α**：
   - 報告フォーマット："Cronbach's α = 0.85"
   - 基準：≥0.70で受容可能、≥0.80で良好、≥0.90で優秀
   - 位置：方法部分または結果部分（測定モデルの前）
2. **分半信頼性**：
   - 報告："Spearman-Brown分半信頼性 = 0.82"
3. **再テスト信頼性**：
   - 報告："4週間間隔の再テスト信頼性r = 0.78、P < 0.001"
4. **構成信頼性（CR）**：
   - SEM報告："構成信頼性CR = 0.86、AVE = 0.55"

**Q：効果量はどう計算し、報告しますか？**
A：
1. **t検定**：Cohen's d = (M1 - M2) / SDpooled
   - 報告："d = 0.65、95% CI [0.32, 0.98]"
2. **分散分析**：η²p（偏イータ二乗）
   - 報告："η²p = 0.14、95% CI [0.05, 0.25]"
3. **相関**：r（Pearson）
   - 報告："r = 0.45、95% CI [0.28, 0.60]"
4. **回帰**：R²またはΔR²
   - 報告："R² = 0.25、f² = 0.33"
5. **分類**：小（0.2/0.01/0.02）、中（0.5/0.06/0.15）、大（0.8/0.14/0.35）

**Q：実験材料の付録はどうしますか？**
A：
1. **完全なアンケート**：質問+選択肢+採点方法（付録A）
2. **実験刺激**：画像/テキスト材料（付録Bまたはオンライン補足材料）
3. **実験手順**：詳細な手順（時間、キー押し、フィードバック）
4. **インフォームドコンセント**：テンプレート（付録C）
5. **匿名化データ**：OSF/Figshareリンク
6. **分析コード**：GitHub/R Markdown

# メンタルと時間管理 FAQ

## 執筆不安

**Q：書けない場合はどうすればいいですか？**
A：
1. **ハードルを下げる**：まずゴミのようなバージョンを書き、ひどい文章を許す
2. **フリーライティング**：15分間設定、ペンを止めない、修正しない、削除しない
3. **最も簡単なものから始める**：方法部分が最も簡単、まず方法を書く
4. **タスクを分割する**："今日は序論の第一段落だけ書く"而非"今日は序論を書く"
5. **環境を変える**：図書館、カフェ、席を変える
6. **身体を先に動かす**：散歩、運動、入浴（デフォルトモードネットワークを活性化）
7. **対話執筆**：クラスメイトに研究を説明すると想像し、録音をテキストに変換

**Q：完璧主義が原因で拖延してしまいます**
A：
1. **初稿を受け入れる**：すべての良い論文は修正から生まれる、初稿は必然的にひどい
2. **締め切りを設定する**："この段落は30分以内に完成させる"
3. **修正を禁止する**：初稿段階では戻って修正しない、【要修正】マークを使用
4. **比較学習**：大家の初稿を見る（例：《朱自清全集》手稿）
5. **量化目標**："今日は500文字書く"而非"今日は序論を上手く書く"
6. **失敗を許す**：この論文は完璧ではないが、卒業/発表には十分

**Q：執筆恐怖を克服するにはどうすればいいですか？**
A：
1. **暴露療法**：毎日少し書き、徐々に難易度を上げる
2. **ポジティブイメージ**：達成感を想像する、困難な過程ではない
3. **社会的コミットメント**：クラスメイト/指導教員に計画を伝え、外部圧力を増す
4. **報酬メカニズム**：一段落書いたら自分にご褒美（コーヒー、動画、ゲーム）
5. **マインドフルネス執筆**：現在の文に集中、全体の品質を心配しない
6. **サポートを求める**：執筆グループ、心理カウンセリング、指導教員の励まし

## 時間管理

**Q：執筆計画はどう立てますか？**
A：
1. **逆算方法**：締め切りから逆算し、各段階の時間を配分
   - 例（3ヶ月で完成）：
     - 第1-2週：文献綜述+アウトライン
     - 第3-6週：初稿（週2章）
     - 第7-8週：修正+指導教員フィードバック
     - 第9-10週：改善+フォーマット調整
     - 第11-12週：重複チェック+最終確認
2. **ガントチャート**：Excelまたはオンラインツール（TeamGanttなど）で進捗を可視化
3. **バッファ時間**：各段階に20%のバッファを確保（予測不能な事態に対応）
4. **マイルストーン**：重要なノードを設定（例："第3週で文献綜述を完了"）
5. **毎日の計画**：前日の夜にTODOリストを作成（3-5項目、達成可能）

**Q：ポモドーロ・テクニックはどう使いますか？**
A：
1. **標準プロセス**：
   - 25分間集中執筆（携帯をマナーモード、SNSソフトを閉じる）
   - 5分間休憩（水を飲む、ストレッチ、遠くを見る）
   - 4つのポモドーロ後、15-30分の長休憩
2. **調整**：
   - 執筆初期：15分ポモドーロ（適応期間）
   - 執筆熟练：45-50分ポモドーロ（フロー状態）
3. **ツール**：
   - Forest（木を植える、携帯が画面を離れると木が成長）
   - 番茄ToDo（統計、ホワイトノイズ）
   - 物理的なポモドーロタイマー（携帯依存を減らす）
4. **記録**：毎日完了したポモドーロ数、効率のトレンドを追跡

**Q：時間ブロック管理法？**
A：
1. **時間ブロックを划分**：
   - 午前（9-12時）：深い執筆（最も難しい部分）
   - 午後（2-5時）：読書、整理、修正
   - 夜（7-9時）：軽いタスク（フォーマット、参考文献）
2. **時間ブロックを保護**：
   - 深い執筆ブロック：メールを閉じ、携帯をマナーモード、ドアに"邪魔しないで"と表示
   - コミュニケーションブロック：メール、微信の返信を集中（毎日11時、16時など）
3. **柔軟なスケジュール**：
   - 20%の空白時間を確保（突発的なタスクに対応）
   - 毎週振り返り：どの時間ブロックの効率が高い/低いか、来週を調整

**Q：締め切りが迫っています**
A：
1. **優先順位付け**：
   - 必須：核心章（序論、方法、結果）
   - すべき：考察、結論
   - 簡略化可能：文献綜述（圧縮）、謝辞（簡潔）
2. **素早い執筆技巧**：
   - 修正モードをオフ：まず書き終えてから修正
   - 音声入力を使用：話すのはタイピングより速い
   - テンプレート執筆：優秀な論文の構造をコピーし、内容を充填
3. **助けを求める**：
   - クラスメイトの互助：互相チェック、タスク分担
   - 指導教員とのコミュニケーション：困難を説明、延期を申請（前もって相談）
   - 専門サービス：フォーマット調整、重複チェック低減（慎重に選択）
4. **健康を維持**：
   - 毎日睡眠≥6時間（効率>時間）
   - 2時間ごとに10分休憩（バーンアウト防止）
   - 簡単な運動：ストレッチ、速歩き、眼体操

## 指導教員との関係

**Q：指導教員が返信してくれません**
A：
1. **コミュニケーション方法をチェック**：
   - メール：件名を明確に（"論文第3章の校閲依頼"）、添付ファイルを完全に
   - 微信：簡潔で礼儀正しく、頻繁に邪魔しない（週1-2回）
   - 面談：前もって予約、質問リストを用意
2. **タイミングを選択**：
   - 避ける：学期初め、期末、プロジェクト締め切り前
   - 優先：水曜-金曜の午前（比較的空いている）
3. **フォローアップ戦略**：
   - 初回連絡：3-5日待つ
   - 再連絡：礼儀正しくリマインド（"先生、先日のメールが見落とされたかもしれないので、再送します"）
   - 三回目：先輩またはオフィスの電話を通じて
4. **内容準備**：
   - 修正説明を添付："前回の意見に基づき、X、Y、Zを修正しました"
   - 具体的な質問："論文はどうですか？"ではなく"第2節の論証は十分ですか？"

**Q：指導教員と意見が一致しません**
A：
1. **立場を理解**：
   - 指導教員の視点：学術規範、実現可能性、卒業要件
   - 学生の視点：興味、革新、個人の発展
2. **コミュニケーション戦略**：
   - まず肯定："ご提案は非常に価値があります..."
   - 次に表現："私が考えているのは..."
   - 合意を求める："折衷案は可能でしょうか..."
3. **データで話す**：
   - "トップジャーナル10編を調査しましたが、すべてこのようにしています..."
   - "予備実験の結果は..."
4. **現実を受け入れる**：
   - 卒業を優先：原則問題でなければ妥協可能
   - 意見を保留：謝辞で指導教員に感謝し、後記で本音を書く
   - 長期的視点：卒業後は自由に探索可能

**Q：指導教員に助けを求めるにはどうすればいいですか？**
A：
1. **十分な準備**：
   - 具体的な質問："第3章の回帰結果が有意でない"而非"論文が書けない"
   - 試行した解決策："A、Bの二つの方法を試しましたが、結果はそれぞれ..."
   - 必要なサポート："XX病院との協力を取り付けていただく必要があります"
2. **時間を尊重**：
   - 予約："先生、水曜日の午後はお時間ありますか？15分で結構です"
   - 効率的：前もって資料を送り、面談では本題に入る
   - 記録：ノートを持ち、要点を記録、事後にメールで確認
3. **フィードバックループ**：
   - 助けを求めた後：1週間以内に進捗を報告
   - 修正後：修正箇所をマーク、指導教員が素早く確認できるように
   - 感謝：口頭+書面（メール/微信）

## 同僚のサポート

**Q：執筆グループはどう結成しますか？**
A：
1. **メンバー選択**：
   - 3-5人：少なすぎると動機が不足、多すぎると調整が困難
   - 類似の段階："完了済み"と"始めたばかり"のプレッシャーを避ける
   - 補完的な学科：学際的な交流で視野を広げる
2. **運営方式**：
   - 頻度：週1回、2時間ずつ
   - 構造：30分の進捗報告+60分の互相校閲+30分の討論
   - ルール：秘密保持、建設的フィードバック、欠席しない
3. **オンラインツール**：
   - テンセント会議/Zoom：画面共有で討論
   - 石墨文档/テンセント文档：共同で注釈
   - 微信グループ：日常の打卡、リソース共有

**Q：同僚にフィードバックするにはどうすればいいですか？**
A：
1. **サンドイッチ法則**：
   - まず肯定："この部分の文献綜述は非常に包括的です..."
   - 次に提案："XX比較を追加すればより明確になります..."
   - 後に励まし："全体的なロジックは良好、修正後さらに良くなります"
2. **具体化**：
   - 避ける："上手く書けていない"
   - 変更："第2段落の論点が明確ではありません、接続文の追加を提案します"
3. **優先順位**：
   - 高：論理的な欠陥、事実誤認、構造問題
   - 中：表現の不明確さ、論拠不足、フォーマット問題
   - 低：表現の最適化、句読点
4. **主権を尊重**：
   - 提案而非命令："考慮できます..."而非"必ず..."
   - 拒否を受け入れる：著者は提案を受け入れない権利がある

## 健康維持

**Q：長時間座る危害はどう緩和しますか？**
A：
1. **定期的な活動**：
   - 45分ごとに：2分間立つ、ストレッチ、遠くを見る
   - 2時間ごとに：5分間歩く、水を飲みに行く、トイレに行く
   - 半日ごとに：戸外活動15分（散歩、日光浴）
2. **ワークステーション設定**：
   - ディスプレイ：上部が目と水平、距離50-70cm
   - 椅子：腰にサポートがあり、足が床に平らに
   - キーボード：肘が90°、手首が自然
3. **簡単な運動**：
   - 首：左右回転、前後うなずき（各方向5回）
   - 肩：肩をすくめる→リラックス、肩を回す（前後各5回）
   - 腰：座位でひねり、立位で前屈
   - 脚：座位で脚を上げ、立位でつま先立ち
4. **ツール補助**：
   - 昇降デスク：立位と座位を交互（立位30%+座位70%）
   - フィットボール：椅子の代わり、コアを活性化
   - 足踏み台：足を組むのを防止

**Q：目の衛生？**
A：
1. **20-20-20法則**：20分ごとに、20フィート（6メートル）先を20秒見る

# 技術操作類よくある質問 FAQ

## Word レイアウト問題

**Q：ヘッダーとフッターの設定はどうすればいいですか？**
A：
1. **セクション分割設定**：異なる章に異なるヘッダーが必要な場合、"セクション区切り"を挿入（レイアウト→区切り記号→次ページ）
2. **リンクを解除**：ヘッダーをダブルクリック→"前のセクションへのリンク"を解除、独立設定可能
3. **奇偶ページの違い**：ヘッダー/フッターツール→"奇偶ページの違い"にチェック
4. **最初のページの違い**：表紙ページにヘッダーを表示しない→"最初のページの違い"にチェック
5. **ページ番号形式**：挿入→ページ番号→ページ番号形式を設定（開始ページ、番号スタイル）
6. **ヘッダーの横線**：ヘッダーテキストを選択→ホーム→罫線→罫線なし（またはCtrl+Shift+Nでフォーマットをクリア）

**Q：目次は自動生成と更新はどうしますか？**
A：
1. **タイトルスタイルを設定**：タイトルを選択→ホーム→タイトル1/2/3（最初にスタイルを使用する必要があり、手動でフォントサイズを調整してはいけない）
2. **目次を挿入**：参照→目次→自動目次1/2
3. **目次を更新**：目次を右クリック→フィールドの更新→目次全体を更新（またはF9）
4. **目次形式**：参照→目次→ユーザー設定目次→変更（フォント、インデントを調整）
5. **目次エラー"目次項目が見つかりません"**：タイトルにスタイルが適用されているか確認、手動フォーマットではない

**Q：相互参照はどう使いますか？**
A：
1. **図表を参照**：参照→相互参照→参照タイプ（図/表）→番号を選択→挿入
2. **章を参照**：参照→相互参照→参照タイプ（タイトル）→章を選択→挿入
3. **ページ番号を参照**：参照→相互参照→参照内容（ページ番号）
4. **参照を更新**：Ctrl+Aで全選択→F9でフィールドを更新（または右クリック→フィールドの更新）
5. **コード/表示を切り替え**：Alt+F9（フィールドコードを表示）

**Q：参考文献のフォーマットはどう調整しますか？**
A：
1. **脚注を使用**：参照→脚注を挿入（番号形式：[1]）
2. **相互参照を使用**：参照→相互参照→参照タイプ（脚注）
3. **一括調整**：検索と置換（^eを[^&]に置換）
4. **ぶら下げインデント**：参考文献を選択→段落→ぶら下げインデント2文字
5. **間隔調整**：段落→段落前0段落後0、行間隔固定値18ポント

**Q：三線表はどう作りますか？**
A：
1. 表を挿入→表を選択→テーブルデザイン→罫線→罫線なし
2. 最初の行を選択→罫線→上罫線+下罫線（1.5ポント）
3. 最後の行を選択→罫線→下罫線（1.5ポント）
4. タイトル行の下に細線を追加（0.75ポント）
5. 表のプロパティ→テキストの折り返し→なし（位置がずれるのを防止）

## 参考文献管理

**Q：ZoteroとWordの連携はどうしますか？**
A：
1. **プラグインをインストール**：Zotero→ツール→プラグイン→Wordプラグインをインストール
2. **引用を挿入**：Word→Zotero→Add/Edit Citation→文献を検索→Enter
3. **参考文献を生成**：Zotero→Add/Edit Bibliography
4. **形式を切り替え**：Zotero→Document Preferences→形式を選択（GB/T 7714）
5. **更新**：修正後にRefreshをクリック
6. **リンク解除**：最終版後にUnlink Citationsをクリック（フィールドリンクを解除、プレーンテキストに変換）

**Q：EndNoteで中国語文献が文字化けします**
A：
1. **エクスポート形式**：知网からエクスポート→EndNote形式（.enw）
2. **エンコーディング設定**：Edit→Preferences→Display Fonts→宋体/UTF-8
3. **フィルター**：インポート時に正しいImport Optionを選択（Reference Manager(RIS)）
4. **手動修正**：文献をダブルクリック→Author/Titleフィールドを手動で修正
5. **一括置換**：Edit→Change/Move/Copy Fields

**Q：複数の文献库を統合するには？**
A：
1. **Zotero**：ファイル→インポート→別のZotero库を選択（自動重複排除）
2. **EndNote**：File→Import→File→.enlファイルを選択
3. **重複排除**：Zotero→ツール→重複項目を統合；EndNote→Library→Find Duplicates
4. **タグ整理**：インポート後に統一してタグを分類
5. **バックアップ**：統合前に元の库をバックアップ（エクスポート→Zotero RDF）

**Q：PDFをWordで編集可能にするにはどうしますか？**

## その他の技術問題

**Q：論文画像の解像度が足りません**
A：
1. **ベクター画像**：優先的にPDF/EPS/EMF/SVGを使用（無限に拡大可能）

4. **ソフトウェアエクスポート**：Origin/Visio→エクスポート→PDF/EMF（ベクター）
5. **Photoshop**：画像→画像サイズ→解像度300→再サンプリング

**Q：画像サイズを一括調整するにはどうしますか？**
A：
1. **Word**：画像を選択→フォーマット→サイズ→高さ/幅を統一
2. **Photoshop**：ファイル→自動→PDFプレゼンテーション→統一サイズ
3. **Python**：
```python
from PIL import Image
img = Image.open('input.jpg')
img = img.resize((width, height), Image.Resampling.LANCZOS)
img.save('output.jpg', dpi=(300, 300))
```
4. **オンラインツール**：iLoveIMGで一括調整（プライバシーに注意）

1. **画像圧縮**：画像を選：画像を選択→フォーマット→画像の圧縮→150ppi（印刷）/96ppi（画面）
