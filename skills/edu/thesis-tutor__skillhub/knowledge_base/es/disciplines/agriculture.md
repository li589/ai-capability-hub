# Guía para la Redacción de Trabajos de Agronomía

## Características de la Disciplina
- Énfasis en aplicaciones prácticas, experimentos de campo y mejora de rendimientos
- Importancia del diseño experimental, análisis estadístico y transferencia tecnológica
- Ciclos de investigación largos (ciclos de crecimiento de cultivos)
- Alta especificidad regional (diferencias climáticas y edáficas)

## Tipos de Investigación

### 1. Experimentos de Campo
- **Aplicación**: Cultivo de variedades, mejoramiento genético, protección vegetal
- **Elementos clave**:
  - Diseño experimental (bloques aleatorios, diseños de parcelas divididas)
  - Recolección de datos (rendimiento, calidad, resistencia)
  - Análisis estadístico (ANOVA, comparaciones múltiples)
- **Estructura del trabajo**: Objetivo → Materiales → Métodos → Resultados → Discusión

### 2. Investigación de Laboratorio
- **Aplicación**: Biología molecular, fisiología y bioquímica, análisis de suelos
- **Elementos clave**:
  - Métodos experimentales (extracción, detección, análisis)
  - Procesamiento de datos (pruebas estadísticas, gráficos)
  - Validación de resultados (repeticiones, controles)
- **Estructura del trabajo**: Introducción → Materiales → Métodos → Resultados → Discusión

### 3. Investigación por Encuestas
- **Aplicación**: Economía agrícola, desarrollo rural, políticas agrícolas
- **Elementos clave**:
  - Diseño de encuestas (cuestionarios, entrevistas)
  - Recolección de datos (muestreo, métodos de selección)
  - Métodos de análisis (estadística descriptiva, análisis de regresión)
- **Estructura del trabajo**: Contexto → Métodos → Encuesta → Análisis → Conclusiones

## Subdivisiones de la Disciplina

### Agronomía
- **Cultivo de cultivos**: Sistemas de cultivo, técnicas de fertilización, gestión del riego
- **Mejoramiento genético de cultivos**: Mejora de variedades, hibridación, mejoramiento molecular
- **Fisiología de cultivos**: Fotosíntesis, metabolismo de nutrientes, fisiología del estrés

### Protección Vegetal
- **Patología vegetal**: Diagnóstico de enfermedades, técnicas de control, mejoramiento resistente
- **Entomología agrícola**: Control de plagas, uso de enemigos naturales, manejo integrado
- **Pesticidas**: Evaluación de eficacia, análisis de residuos, evaluación de seguridad

### Horticultura
- **Fruticultura**: Mejoramiento de variedades, técnicas de cultivo, poscosecha
- **Olericultura**: Cultivo bajo cubierta, control de calidad, producción segura
- **Floricultura**: Recursos genéticos, técnicas de propagación, control de floración

### Recursos Agrícolas y Medio Ambiente
- **Edafología**: Fertilidad del suelo, mejora del suelo, contaminación del suelo
- **Meteorología agrícola**: Recursos climáticos, alerta de desastres, cambio climático
- **Agroecología**: Agricultura ecológica, agricultura circular, desarrollo sostenible

## Plantillas de Estructura del Trabajo

### Tipo Experimento de Campo
```
1. Introducción (contexto de investigación, objetivo, significado)
2. Materiales y métodos (zona experimental, materiales, diseño, mediciones)
3. Resultados y análisis (rendimiento, calidad, resistencia, etc.)
4. Discusión (mecanismos, comparación, aplicación)
5. Conclusiones (hallazgos principales, recomendaciones)
```

### Tipo Investigación de Laboratorio
```
1. Introducción (estado de la investigación, objetivo)
2. Materiales y métodos (materiales, reactivos, métodos)
3. Resultados (datos, gráficos)
4. Discusión (mecanismos, significado)
5. Conclusiones (contribución, perspectivas)
```

## Puntos Clave de la Escritura

### Descripción de Experimentos de Campo
- Ubicación del experimento (latitud, longitud, altitud, clima)
- Condiciones del suelo (tipo, fertilidad, pH)
- Materiales experimentales (variedad, origen, características)
- Diseño experimental (tratamientos, repeticiones, tamaño de parcela)

### Presentación de Datos
- Datos de rendimiento (kg/mu o t/ha)
- Indicadores de calidad (proteínas, almidón, etc.)
- Análisis estadístico (F-test, LSD, Duncan)
- Gráficos estandarizados (líneas de error, marcadores de significancia)

### Valor de Transferencia
- Análisis de beneficios económicos
- Viabilidad técnica
- Adaptabilidad regional
- Recomendaciones para transferencia

## Problemas Comunes

1. **Diseño experimental no estandarizado**: Falta de controles, repeticiones insuficientes
2. **Tratamiento de datos inadecuado**: Métodos estadísticos erróneos, marcadores de significancia confusos
3. **Discusión poco profunda**: Solo listar resultados, falta de análisis de mecanismos
4. **Valor de transferencia no claro**: Falta de análisis de beneficios económicos
5. **Escritura no estandarizada**: Terminología inconsistente, formato desordenado

## Consideraciones para la Verificación de Originalidad
- La descripción de métodos experimentales puede ser estandarizada
- El análisis de datos requiere originalidad
- Las conclusiones deben basarse en resultados propios
- Las recomendaciones de transferencia requieren reflexión propia
