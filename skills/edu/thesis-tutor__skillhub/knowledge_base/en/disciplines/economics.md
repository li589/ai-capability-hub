# Economics - Thesis Writing Guide

## Overview
Economics thesis writing emphasizes theoretical rigor, empirical validation, and policy relevance. The core assessment criteria are: research question significance, theoretical framework, econometric methodology, and practical implications.

## Research Types

### 1. Empirical Research
- **Features**: Test economic theories using real-world data
- **Structure**: Literature Review → Theoretical Model → Data & Methodology → Results → Policy Implications
- **Key Points**: Causal identification, robustness checks, endogeneity concerns

### 2. Theoretical Research
- **Features**: Develop new economic models or extend existing ones
- **Structure**: Motivation → Model Setup → Equilibrium Analysis → Comparative Statics → Extensions
- **Key Points**: Mathematical rigor, economic intuition, testable predictions

### 3. Policy Analysis
- **Features**: Evaluate economic policies using quantitative methods
- **Structure**: Policy Background → Theoretical Framework → Empirical Strategy → Findings → Recommendations
- **Key Points**: Counterfactual analysis, welfare evaluation, implementation feasibility

## Chapter Structure

### Chapter 1: Introduction (8-10 pages)
1. Research background and motivation
2. Research question and objectives
3. Contribution to the literature
4. Thesis structure

### Chapter 2: Literature Review (15-20 pages)
1. Theoretical foundations
2. Empirical evidence (organized by theme)
3. Identification strategies used in the literature
4. Research gaps and your contribution

### Chapter 3: Theoretical Framework (10-15 pages)
1. Model assumptions
2. Agent optimization problems
3. Equilibrium characterization
4. Comparative statics
5. Testable hypotheses

### Chapter 4: Data and Methodology (10-15 pages)
1. Data source and description
2. Variable construction
3. Econometric model specification
4. Identification strategy
5. Robustness checks

### Chapter 5: Results (15-20 pages)
1. Descriptive statistics
2. Main regression results
3. Robustness checks
4. Heterogeneity analysis
5. Mechanism analysis

### Chapter 6: Conclusion (3-5 pages)
1. Summary of findings
2. Policy implications
3. Limitations
4. Future research directions

## Methodology

### Common Econometric Methods
- **Cross-sectional**: OLS, IV, Probit/Logit
- **Panel data**: Fixed Effects, Random Effects, Diff-in-Diff, RDD
- **Time series**: VAR, ARIMA, Cointegration
- **Structural estimation**: GMM, MLE, Simulated Method of Moments

### Identification Strategies
- Randomized Controlled Trials (RCT)
- Natural experiments
- Instrumental Variables (IV)
- Regression Discontinuity Design (RDD)
- Difference-in-Differences (DID)
- Synthetic Control Method

### Software Tools
- **Stata**: Industry standard for applied economics
- **R**: Open-source, great for visualization
- **Python**: Machine learning integration
- **Matlab**: Structural modeling
- **Julia**: High-performance computing

## Common Issues

1. **Endogeneity**: Omitted variables, reverse causality, measurement error
2. **Sample selection bias**: Non-random sample, survivorship bias
3. **Weak instruments**: Low F-statistic in IV regressions
4. **P-hacking**: Pre-registration, multiple testing corrections
5. **External validity**: Limited generalizability

## Writing Standards

### Data Presentation
- Report summary statistics table
- Show correlation matrix
- Present regression results with standard errors
- Include robustness checks

### Mathematical Notation
- Define all variables clearly
- Use consistent notation throughout
- Provide economic intuition for equations

## Citation Format
- APA 7th Edition (common in economics)
- AEA (American Economic Review) style for top journals

## Quality Checklist
- [ ] Is the research question clearly defined?
- [ ] Is the identification strategy convincing?
- [ ] Are robustness checks sufficient?
- [ ] Are standard errors clustered appropriately?
- [ ] Is the economic interpretation clear?
- [ ] Are policy implications well-justified?
