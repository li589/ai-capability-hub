# Library Science Thesis Writing Guide

## Discipline Characteristics
- Emphasis on information services, knowledge management, document organization
- Strong focus on user research, technology application, practical innovation
- Diverse research methods: surveys, experiments, cases, system development
- Strong interdisciplinary nature (computer science, management, communication)

## Research Types

### 1. User Research
- **Applicable to**: Information behavior, user needs, service evaluation
- **Key elements**:
  - User profiles (age, occupation, needs)
  - Behavior analysis (retrieval, utilization, sharing)
  - Satisfaction evaluation (service quality, improvement directions)
- **Thesis structure**: Background → Method → Survey → Analysis → Recommendations

### 2. Technology Research
- **Applicable to**: Digital libraries, information systems, data management
- **Key elements**:
  - System design (architecture, functions, technology)
  - Development implementation (programming, testing, deployment)
  - Effect evaluation (performance, user feedback)
- **Thesis structure**: Requirements → Design → Implementation → Evaluation → Conclusion

### 3. Theoretical Research
- **Applicable to**: Information organization, knowledge management, library science theory
- **Key elements**:
  - Literature review (theoretical development, research status)
  - Concept analysis (definition, connotation, extension)
  - Theoretical construction (models, frameworks, principles)
- **Thesis structure**: Problem → Literature → Analysis → Theory → Conclusion

## Discipline Subdivisions

### Library Science
- **Document resource construction**: Collection development, collection evaluation
- **Information services**: Reference consultation, subject services, knowledge services
- **Reading promotion**: Reading activities, bibliotherapy, children's reading
- **Library management**: Strategic planning, human resources, performance evaluation

### Archival Science
- **Archives management**: Collection, organization, appraisal, preservation
- **Archives informatization**: Digitization, electronic records, digital archives
- **Archives utilization**: Compilation, exhibition, access
- **Archives preservation**: Restoration, reproduction, environmental control

### Information Resource Management
- **Knowledge management**: Knowledge organization, knowledge graphs, knowledge services
- **Data management**: Data governance, data quality, data security
- **Competitive intelligence**: Information collection, analysis, application
- **Digital humanities**: Text analysis, data visualization, digital publishing

## Thesis Structure Template

### Survey Research Type
```
1. Introduction (background, problem, significance)
2. Literature Review (research status, theoretical basis)
3. Research Design (subjects, methods, tools)
4. Survey Results (data, charts)
5. Analysis and Discussion (findings, comparison, explanation)
6. Conclusion and Recommendations (contributions, limitations, improvements)
```

### System Development Type
```
1. Introduction (requirement background, objectives)
2. Requirement Analysis (user needs, functional requirements)
3. System Design (architecture, database, interface)
4. System Implementation (technology selection, key code)
5. System Testing (functional testing, performance testing)
6. Conclusion (summary, future directions)
```

## Writing Tips

### Survey Research
- Sample selection (random, stratified, convenience)
- Questionnaire design (reliability, validity)
- Data analysis (descriptive statistics, inferential statistics)
- Result presentation (charts combined with text)

### System Development
- Requirement analysis (user interviews, use case analysis)
- System design (architecture diagrams, ER diagrams, flowcharts)
- Key technologies (algorithms, implementation details)
- Test verification (test cases, result analysis)

### Theoretical Research
- Literature review (systematic, critical)
- Concept definition (clear, accurate)
- Logical reasoning (rigorous, evidence-based)
- Theoretical contribution (innovative, practical)

## Common Issues

1. **Too broad topic**: Too wide scope, difficult to go deep
2. **Weak literature review**: Lack of systematic review, missing important literature
3. **Improper research methods**: Methods don't match the problem
4. **Superficial data analysis**: Only descriptive statistics, lack of deep analysis
5. **Unclear practical value**: Recommendations vague, lack of operability
