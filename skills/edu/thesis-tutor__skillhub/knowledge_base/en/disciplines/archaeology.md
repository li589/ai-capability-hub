# Archaeology Thesis Writing Guide

## Discipline Characteristics
- Emphasis on field excavation, material culture study, historical reconstruction
- Strong focus on stratigraphy, typology, archaeological science
- Long research cycles (excavation, processing, research)
- Strong interdisciplinary nature (history, geology, biology, chemistry)

## Research Types

### 1. Field Archaeology Report
- **Applicable to**: Site excavation, survey reports
- **Key elements**:
  - Stratigraphic description (soil texture, color, inclusions)
  - Feature description (pits, houses, burials)
  - Artifact description (pottery, stone tools, bone tools)
- **Thesis structure**: Overview → Stratigraphy → Features → Artifacts → Periodization → Conclusion

### 2. Specialized Research
- **Applicable to**: Artifact studies, cultural studies, chronology
- **Key elements**:
  - Material collection (archaeological materials, documents)
  - Typological analysis (type-variety classification, evolution sequences)
  - Cultural interpretation (function, significance, exchange)
- **Thesis structure**: Introduction → Materials → Analysis → Discussion → Conclusion

### 3. Archaeological Science
- **Applicable to**: Dating, compositional analysis, residue analysis
- **Key elements**:
  - Sample collection (representative, preservation condition)
  - Analytical methods (C14, thermoluminescence, XRF)
  - Data interpretation (chronology, provenance, technology)
- **Thesis structure**: Background → Samples → Methods → Results → Discussion

## Discipline Subdivisions

### Prehistoric Archaeology
- **Paleolithic**: Human origins, stone tool technology
- **Neolithic**: Agricultural origins, civilization origins
- **Bronze Age**: State formation, early civilizations

### Historical Archaeology
- **Xia-Shang-Zhou archaeology**: Capitals, bronze vessels, oracle bones
- **Qin-Han archaeology**: Imperial tombs, bamboo slips, Silk Road
- **Wei-Jin-Southern & Northern Dynasties**: Tombs, Buddhist remains
- **Sui-Tang-Song-Yuan archaeology**: Cities, ceramics, foreign exchange

### Specialized Archaeology
- **Environmental archaeology**: Paleo-environment, paleoclimate, human-environment relations
- **Zooarchaeology**: Animal bones, domestication, sacrifice
- **Paleoethnobotany**: Plant remains, agriculture, diet
- **Archaeometallurgy**: Mining sites, metal artifacts, technology

## Thesis Structure Template

### Field Report Type
```
1. Overview (geographical location, excavation history)
2. Stratigraphic Sequence (stratigraphic relationships, periodization basis)
3. Features (pits, houses, burials, etc.)
4. Artifacts (pottery, stone tools, bone tools, etc.)
5. Periodization and Chronology (cultural sequence, absolute dates)
6. Conclusion (main findings, academic significance)
```

### Specialized Research Type
```
1. Introduction (research history, objectives, methods)
2. Materials (source, quantity, condition)
3. Analysis (typology, statistics, comparison)
4. Discussion (function, significance, exchange)
5. Conclusion (main viewpoints, academic contribution)
```

## Writing Tips

### Field Recording
- Stratigraphic relationship diagrams
- Feature plans and sections
- Artifact line drawings
- Photographic records

### Typological Analysis
- Type-variety classification standards
- Evolution sequences
- Diagnostic artifacts
- Comparative materials

### Chronology
- Stratigraphic evidence
- Artifact typology
- Dating data
- Historical records

## Common Issues

1. **Unclear stratigraphic description**: Soil texture, color, inclusions not detailed
2. **Non-standard typology**: Inconsistent type-variety classification standards
3. **Rash chronological judgments**: Lack of multiple evidence
4. **Superficial cultural interpretation**: Lack of deep analysis
5. **Poor plate quality**: Blurry photos, non-standard line drawings
