# Science Thesis Writing Guide

## Discipline Characteristics
- Emphasis on experimental verification, mathematical derivation, theoretical innovation
- Strong focus on data precision, reproducibility, peer review
- Conference papers and journal papers equally important
- High quality requirements for figures (data plots, formulas, experimental apparatus)

## Research Types

### 1. Experimental Research
- **Applicable to**: Physics, chemistry, biology experiments
- **Key elements**:
  - Experimental design (variable control, repeated experiments)
  - Data collection (instrument precision, error analysis)
  - Result analysis (statistical testing, uncertainty)
- **Thesis structure**: Objective → Method → Experiment → Results → Analysis

### 2. Theoretical Research
- **Applicable to**: Mathematics, theoretical physics, theoretical chemistry
- **Key elements**:
  - Problem formulation (conjectures, hypotheses)
  - Theoretical derivation (proofs, calculations)
  - Result discussion (significance, applications)
- **Thesis structure**: Problem → Preliminaries → Main Results → Proofs → Discussion

### 3. Computational Research
- **Applicable to**: Computational physics, computational chemistry, bioinformatics
- **Key elements**:
  - Model building (algorithms, numerical methods)
  - Program implementation (code, verification)
  - Result analysis (convergence, accuracy)
- **Thesis structure**: Problem → Method → Implementation → Results → Discussion

## Discipline Subdivisions

### Mathematics
- **Pure mathematics**: Algebra, geometry, analysis, number theory
- **Applied mathematics**: Probability and statistics, operations research, computational mathematics
- **Mathematics education**: Teaching methods, curriculum design

### Physics
- **Condensed matter physics**: Materials, superconductivity, semiconductors
- **Particle physics**: High energy physics, nuclear physics
- **Optics**: Lasers, fiber optics, optoelectronics
- **Astrophysics**: Cosmology, galaxies, black holes

### Chemistry
- **Organic chemistry**: Synthesis, reaction mechanisms
- **Inorganic chemistry**: Coordination chemistry, materials chemistry
- **Analytical chemistry**: Instrumental analysis, spectroscopy
- **Physical chemistry**: Thermodynamics, kinetics

### Biology
- **Molecular biology**: Genes, proteins
- **Cell biology**: Cell signaling, cell cycle
- **Ecology**: Populations, communities, ecosystems
- **Bioinformatics**: Sequence analysis, structure prediction

## Thesis Structure Template

### Experimental Research Type
```
1. Introduction (background, problem, objectives)
2. Experimental Section (materials, methods, instruments)
3. Results and Discussion (data, analysis, comparison)
4. Conclusion (findings, significance, future directions)
```

### Theoretical Research Type
```
1. Introduction (problem background, literature review)
2. Preliminaries (definitions, lemmas)
3. Main Results (theorems, proofs)
4. Discussion (applications, generalizations)
5. Conclusion (contributions, future directions)
```

## Writing Tips

### Experimental Description
- Detailed enough for reproducibility
- Include all parameters
- Specify instrument models
- Note reagent sources

### Data Presentation
- Use significant figures
- Report error ranges
- Label units
- Clear and standardized figures

### Formula Formatting
- Use equation editor
- Consistent notation system
- Continuous numbering
- Explain each symbol

## Common Issues

1. **Insufficient experiments**: Few repetitions, lack of controls
2. **Improper data processing**: Wrong statistical methods, insufficient error analysis
3. **Weak literature review**: Lack of recent developments, incomplete review
4. **Shallow discussion**: Only listing results without deep analysis
5. **Non-standard writing**: Inconsistent terminology, messy formatting

## Plagiarism Considerations
- Experimental method descriptions can be standardized
- Formula derivations must be original
- Data analysis requires your own interpretation
- Conclusions must be based on your own results
