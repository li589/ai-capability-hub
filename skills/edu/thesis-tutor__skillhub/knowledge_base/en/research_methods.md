# Qualitative Research Guide

## Overview
Qualitative research explores human experiences, behaviors, and social phenomena through non-numerical data. This guide covers methodologies, data collection, analysis, and quality standards.

## Qualitative Methodologies

### 1. Case Study
- **Purpose**: In-depth exploration of bounded system
- **Types**: Single case, multiple cases, intrinsic, instrumental
- **Data sources**: Interviews, documents, observations, artifacts
- **Analysis**: Pattern matching, explanation building, cross-case synthesis

### 2. Ethnography
- **Purpose**: Understand culture and social practices
- **Features**: Extended fieldwork, participant observation
- **Data sources**: Field notes, interviews, artifacts
- **Analysis**: Thick description, cultural interpretation

### 3. Grounded Theory
- **Purpose**: Develop theory from data
- **Features**: Constant comparison, theoretical sampling
- **Data sources**: Interviews, observations, documents
- **Analysis**: Open coding, axial coding, selective coding

### 4. Phenomenology
- **Purpose**: Understand lived experiences
- **Features**: Focus on meaning and essence
- **Data sources**: In-depth interviews
- **Analysis**: Horizontalization, invariant constituents, textural description

### 5. Narrative Inquiry
- **Purpose**: Understand stories and life histories
- **Features**: Focus on personal narratives
- **Data sources**: Interviews, diaries, letters
- **Analysis**: Plot, character, theme, context

### 6. Action Research
- **Purpose**: Solve problems through collaboration
- **Features**: Iterative cycles, participatory
- **Data sources**: Multiple methods
- **Analysis**: Reflection, planning, action, evaluation

# Quantitative Research Guide

## Overview
Quantitative research uses numerical data to test hypotheses, establish patterns, and make predictions. This guide covers research design, data collection, statistical analysis, and reporting.

## Research Design

### Types of Quantitative Research

**Descriptive Research**
- Describe characteristics of population
- Surveys, observational studies
- No manipulation of variables
- Cross-sectional or longitudinal

**Correlational Research**
- Examine relationships between variables
- No causation implied
- Correlation coefficients
- Prediction models

**Experimental Research**
- Establish鍥犳灉鍏崇郴
- Random assignment
- Control groups
- Manipulation of variables

**Quasi-Experimental Research**
- Similar to experimental
- No random assignment
- Natural groups
- Field settings

### Variables

**Independent Variables**
- Manipulated or observed
- Predictor variables
- Cause or influence
- Categorical or continuous

**Dependent Variables**
- Outcome variables
- Measured responses
- Effect or result
- Categorical or continuous

**Control Variables**
- Held constant
- Reduce confounding
- Statistical control
- Extraneous factors

**Moderating Variables**
- Affect strength/direction
- Interaction effects
- Subgroup differences
- Conditional relationships

**Mediating Variables**
- Explain mechanism
- Intervening variables
- Path analysis
- Indirect effects

## Sampling

### Probability Sampling
- **Simple random**: Equal chance for all
- **Systematic**: Every nth element
- **Stratified**: Proportional subgroups
- **Cluster**: Groups or clusters

### Non-Probability Sampling
- **Convenience**: Available participants
- **Purposive**: Specific criteria
- **Snowball**: Referral chains
- **Quota**: Predetermined groups

### Sample Size Considerations
- Effect size
- Power level
- Significance level
- Population variance
- Expected attrition

### Power Analysis
- Determine minimum sample size
- Balance Type I and Type II errors
- Use software (G*Power, R)
- Report in methods section

## Data Collection

### Surveys

**Question Types**:
- Closed-ended: Fixed responses
- Likert scales: Agreement levels
- Rating scales: Numerical ratings
- Multiple choice: Select options

**Design Principles**:
- Clear and concise questions
- Avoid leading questions
- Use appropriate scales
- Pilot test instruments
- Consider response burden

**Administration**:
- Online: Qualtrics, SurveyMonkey
- Paper: In-person distribution
- Telephone: Structured interviews
- Mixed: Multiple modes

### Experiments

**Design Elements**:
- Random assignment
- Control conditions
- Manipulation checks
- Blinding procedures

**Types**:
- Between-subjects: Different groups
- Within-subjects: Same participants
- Factorial: Multiple variables
- Repeated measures: Multiple time points

### Secondary Data

**Sources**:
- Government databases
- Organizational records
- Public datasets
- Previous research

**Considerations**:
- Data quality
- Missing data
- Variable definitions
- Time period

## Measurement

### Scales of Measurement

**Nominal**: Categories without order
- Examples: Gender, color, type
- Statistics: Frequency, mode

**Ordinal**: Ordered categories
- Examples: Likert scales, rankings
- Statistics: Median, percentiles

**Interval**: Equal intervals, no true zero
- Examples: Temperature, IQ scores
- Statistics: Mean, standard deviation

**Ratio**: Equal intervals with true zero
- Examples: Height, weight, time
- Statistics: All statistics

### Reliability

**Types**:
- Test-retest: Stability over time
- Inter-rater: Consistency between raters
- Internal consistency: Item homogeneity
- Split-half: Half-test correlation

**Measures**:
- Cronbach's alpha: Internal consistency
- ICC: Intraclass correlation
- Cohen's kappa: Inter-rater agreement
- KR-20: Dichotomous items

### Validity

**Types**:
- Content: Measures intended construct
- Criterion: Predicts outcomes
- Construct: Theoretical consistency
- Face: Appears to measure

**Assessment**:
- Expert review
- Factor analysis
- Convergent validity
- Discriminant validity

## Statistical Analysis

### Descriptive Statistics

**Central Tendency**:
- Mean: Average value
- Median: Middle value
- Mode: Most frequent value

**Variability**:
- Range: Maximum minus minimum
- Variance: Squared deviations
- Standard deviation: Square root of variance
- IQR: Interquartile range

**Distribution**:
- Skewness: Asymmetry
- Kurtosis: Tail heaviness
- Normality tests: Shapiro-Wilk, Kolmogorov-Smirnov

### Inferential Statistics

**t-tests**:
- Independent samples: Compare two groups
- Paired samples: Same participants
- One-sample: Compare to population

**ANOVA**:
- One-way: One factor
- Two-way: Two factors
- Repeated measures: Within-subjects
- MANOVA: Multiple dependent variables

**Regression**:
- Simple: One predictor
- Multiple: Multiple predictors
- Hierarchical: Sequential entry
- Logistic: Binary outcome

**Non-parametric**:
- Mann-Whitney U: Two groups
- Kruskal-Wallis: Multiple groups
- Wilcoxon: Paired samples
- Chi-square: Categorical data

### Advanced Methods

**Factor Analysis**:
- Exploratory: Discover structure
- Confirmatory: Test structure
- Principal components
- Maximum likelihood

**Structural Equation Modeling**:
- Path analysis
- Latent variables
- Model fit indices
- Modification indices

**Multilevel Modeling**:
- Nested data
- Random effects
- Cross-level interactions
- Hierarchical structure

**Time Series Analysis**:
- Trend analysis
- Seasonality
- Autocorrelation
- Forecasting
