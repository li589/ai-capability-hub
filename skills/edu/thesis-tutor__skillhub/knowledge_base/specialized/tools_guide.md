# 论文写作工具链

## 写作环境

### 本地写作
- **Word**：最常用，兼容性好
  - 样式功能：定义标题、正文、引用样式
  - 多级列表：自动编号
  - 题注：图表自动编号
  - 交叉引用：引用图表、章节
  - 目录：自动生成
  - 模板：学校模板

- **WPS**：国产替代，兼容Word
  - 免费版功能足够
  - 云同步
  - 模板丰富

### 在线写作
- **Overleaf**：LaTeX在线协作
  - 适合：理工科、数学公式多
  - 模板：期刊模板、学校模板
  - 协作：多人实时编辑
  - 版本：Git版本控制

- **腾讯文档/石墨文档**：轻量协作
  - 适合：大纲、笔记、协作
  - 不适合：正式论文排版

- **Notion/语雀**：知识管理
  - 适合：文献笔记、写作计划
  - 不适合：正式论文

## 文献管理

### Zotero（推荐）
- **免费开源**
- **功能**：
  - 浏览器插件一键保存
  - PDF自动识别元数据
  - 标签、笔记、关联
  - Word插件一键引用
  - 样式：GB/T 7714、APA、MLA等
  - 协作：群组图书馆
  - 同步：300MB免费，可自建

- **插件推荐**：
  - Better BibTeX：生成Citation Key
  - ZotFile：PDF管理
  - DOI Manager：自动获取DOI
  - Jasminum：中文文献支持

### EndNote
- **功能全面**
- **与Word集成好**
- **收费**：机构版免费
- **适合**：大规模文献管理

### Mendeley
- **Elsevier出品**
- **PDF阅读+笔记**
- **社交功能**：推荐文献
- **免费**

### NoteExpress
- **中文支持好**
- **知网、万方直接导入**
- **收费**：机构版免费
- **适合**：中文文献为主

## 数据分析

### 统计软件
- **SPSS**：入门友好，菜单操作
  - 适合：描述统计、T检验、ANOVA、回归
  - 缺点：高级功能弱，收费

- **R**：免费，功能强大
  - 包：tidyverse（数据处理）、ggplot2（绘图）、lme4（多层模型）
  - 学习曲线：陡峭但值得
  - 可重复：代码可复现

- **Python**：通用编程
  - 库：pandas、scipy、statsmodels、pingouin
  - 适合：大数据、机器学习、自动化

- **Stata**：经济学常用
  - 命令简洁
  - 面板数据、工具变量
  - 收费

- **JASP**：免费，SPSS替代
  - 界面类似SPSS
  - 贝叶斯统计

### 质性分析
- **NVivo**：功能全面
  - 编码、查询、可视化
  - 多媒体支持
  - 收费

- **Atlas.ti**：可视化强
  - 网络视图
  - 协作功能
  - 收费

- **MAXQDA**：混合方法
  - 量化+质性
  - 统计集成
  - 收费

- **Taguette**：免费开源
  - 基础功能足够
  - 适合：学生、小项目

## 绘图工具

### 统计图表
- **R ggplot2**：最灵活
  - 出版级质量
  - 可重复
  - 学习曲线陡峭

- **Python matplotlib/seaborn**：灵活
  - 与数据分析集成
  - 可重复

- **Excel**：简单快速
  - 不适合：复杂统计图
  - 注意：默认样式需调整

- **Origin**：理工科常用
  - 专业绘图
  - 收费

### 流程图/架构图
- **draw.io/diagrams.net**：免费在线
  - 流程图、UML、架构图
  - 导出：PNG、PDF、SVG

- **ProcessOn**：国产在线
  - 协作功能
  - 模板丰富

- **Visio**：专业流程图
  - 功能全面
  - 收费

- **PowerPoint**：简单图形
  - 人人会用的底线选择

### 思维导图
- **XMind**：经典
  - 免费版够用
  - 美观

- **MindMaster**：国产
  - 功能丰富
  - 云同步

- **幕布**：大纲+思维导图
  - 一键转换
  - 适合：论文大纲

## 避坑指南

1. **不要用盗版软件**：学校通常提供正版
2. **不要过度依赖翻译**：学术写作需自己组织
3. **不要忽视备份**：云同步+本地备份
4. **不要临时学工具**：提前熟悉，避免 deadline 前手忙脚乱
5. **不要忽视格式**：排版也是学术规范的一部分
