# 查重与 AI 检测指南

## 查重系统原理

### 文本匹配算法
- **连续字符匹配**：13字连续相同即标红（知网）
- **语义匹配**：同义改写仍可能识别（Turnitin）
- **跨语言匹配**：翻译后抄袭可检测
- **公式/代码**：部分系统不计入，部分计入

### 主要查重系统
| 系统 | 特点 | 适用 |
|------|------|------|
| 知网（CNKI） | 中文文献最全，高校主流 | 硕博论文 |
| 维普 | 期刊文献多，严格 | 本科/期刊 |
| 万方 | 医学文献强 | 医学领域 |
| Turnitin | 英文主流，国际通用 | 英文论文 |
| iThenticate | 期刊投稿，详细报告 | SCI/SSCI |
| PaperPass | 免费/低价，初查 | 初稿自查 |
| 大雅 | 学习通关联，免费 | 初查 |

## 查重报告解读

### 关键指标
- **总文字复制比**：全文重复率
- **去除引用复制比**：去掉标注引用后的重复率
- **去除本人文献**：去掉自己已发表文献
- **单篇最大重复**：重复最多的单篇来源
- **重复字数**：具体重复字数

### 颜色标记（知网）
- 红色：重度重复（>75%）
- 橙色：中度重复（50%-75%）
- 黄色：轻度重复（25%-50%）
- 绿色：低度重复（<25%）

### 学校要求（参考）
- 本科：通常 < 20%-30%
- 硕士：通常 < 10%-15%
- 博士：通常 < 5%-10%
- 期刊：通常 < 10%-20%（看期刊要求）

## 降重策略

### 合法策略
1. **同义替换**
   - 保持学术准确
   - 避免口语化
   - 例："重要"→"关键"/"核心"/"显著"

2. **句式重组**
   - 主动被动转换
   - 长短句变换
   - 语序调整（保持逻辑）

3. **图表化**
   - 文字描述转表格
   - 流程图替代文字
   - 数据可视化

4. **增删改写**
   - 增加自己的分析
   - 删除冗余引用
   - 用自己的话概括

5. **引用规范**
   - 直接引用标注（引号+出处）
   - 间接引用改写（仍需标注）
   - 控制引用比例

### 危险策略（不推荐）
- 翻译降重：中→英→日→中（语句不通）
- AI降重：可能被AI检测识别
- 图片替代：部分系统OCR识别
- 空格/特殊字符：系统已能识别
- 乱码插入：明显作弊

### 各学科注意事项
- **理工科**：公式描述、实验步骤可标准化，但需用自己的话
- **文科**：理论综述最易重复，需批判性改写
- **法学**：法条原文不计入，但需标注；案例概括用自己的话
- **医学**：病历描述、治疗方案可标准化
- **计算机**：代码片段部分系统不计入

## AI 检测

### 检测原理
- **困惑度（Perplexity）**：AI文本困惑度低
- **突发性（Burstiness）**：人类写作波动性大
- **统计特征**：词频分布、句长分布
- **水印检测**：部分AI生成器嵌入水印

### 主要检测工具
| 工具 | 特点 | 局限 |
|------|------|------|
| GPTZero | 免费，流行 | 误判率高 |
| Turnitin AI | 集成查重 | 英文为主 |
| 知网AIGC | 中文检测 | 新推出，标准不明 |
| 维普AIGC | 中文检测 | 同上 |
| Originality.ai | 专业，付费 | 英文为主 |
| ZeroGPT | 免费 | 误判 |

### 学校政策趋势
- 2024年起多校要求检测AI率
- 标准不统一（0%-30%都有）
- 检测工具准确性存争议
- 申诉机制不完善

### 降低AI检测风险（合规方式）
1. **增加个人声音**
   - 加入研究经历、反思
   - 使用第一人称（如适用）
   - 加入具体细节（时间、地点、感受）

2. **混合写作**
   - 自己写初稿，AI辅助润色
   - 分段写作，不要整篇AI生成
   - 关键论点自己组织

3. **深度编辑**
   - 改写AI生成的平淡表达
   - 增加过渡句、连接词
   - 调整段落结构

4. **引用真实文献**
   - AI可能编造引用
   - 核实每条引用
   - 加入最新文献

5. **使用检测工具自查**
   - 提交前用多个工具检测
   - 标记高风险段落
   - 重点改写

## 学术诚信

### 抄袭类型
- **直接抄袭**：复制粘贴，不标注
- **马赛克抄袭**：拼接多来源，不标注
- **改写抄袭**：改写但观点/结构照搬
- **自我抄袭**：重复发表自己已发表内容
- **数据造假**：编造、篡改数据
- **代写**：请人/AI代写

### 后果
- 论文不通过
- 学位撤销（已授予）
- 学术处分（警告、记过、开除）
- 学术声誉损失
- 法律责任（严重情况）

### 正确做法
- 所有引用标注来源
- 直接引用用引号
- 间接引用用自己的话+标注
- 参考文献完整列出
- 使用引文管理工具
- 保留写作过程记录

## 工具推荐
- **查重**：学校指定系统（最准确）
- **初查**：PaperPass、大雅（免费/低价）
- **AI检测**：GPTZero、Turnitin（参考）
- **引文管理**：Zotero、EndNote
- **写作辅助**：Grammarly（语法）、DeepL（翻译参考）

## 常见问题

**Q：引用自己已发表的论文算重复吗？**
A：算，但多数学校允许一定比例（需标注"本人论文"）。

**Q：参考文献列表算重复吗？**
A：通常不计入，但格式要正确。

**Q：附录算重复吗？**
A：通常计入全文，但部分学校附录单独计算。

**Q：使用AI辅助写作算学术不端吗？**
A：看学校政策。多数允许辅助（润色、翻译），禁止代写（生成核心内容）。

**Q：查重率越低越好吗？**
A：不是。0%可能意味着没有文献支撑，合理引用是必要的。

**Q：不同查重系统结果差异大吗？**
A：大。数据库不同，算法不同。以学校指定系统为准。
