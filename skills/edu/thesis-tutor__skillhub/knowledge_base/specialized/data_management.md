# 数据管理与共享指南

## FAIR原则

### 1. 什么是FAIR？
FAIR是数据管理的黄金标准，由FORCE11组织提出，被全球科研机构和资助者广泛采纳。

- **F**indable（可发现）：数据有唯一标识，可被检索
- **A**ccessible（可获取）：数据可被访问，有明确的使用协议
- **I**nteroperable（可互操作）：数据格式标准化，可与其他数据整合
- **R**eusable（可重用）：数据有充分的描述信息，可被他人理解和使用

### 2. Findable（可发现）

**实践要点**：
- [ ] 数据有持久标识符（DOI、Handle、URL）
- [ ] 数据有详细的元数据描述（标题、作者、时间、主题）
- [ ] 数据注册到可检索的存储库或数据库
- [ ] 元数据包含关键词和分类标签

**工具**：
- DataCite：DOI注册服务
- Zenodo：通用存储库，自动分配DOI
- Figshare：数据、图表、代码存储
- 国家数据中心：国内学科数据存储

**元数据标准**：
- Dublin Core：通用标准（标题、创建者、主题、描述等15个元素）
- DataCite Metadata Schema：科研数据专用
- ISO 19115：地理空间数据
- DDI（Data Documentation Initiative）：社会科学数据

### 3. Accessible（可获取）

**开放程度选择**：
- 完全开放：任何人可下载（CC0或CC-BY许可）
- 条件开放：需注册、签署协议、或用于非商业目的
- 受控访问：需申请，有审批流程（敏感数据）
- 封闭访问：仅作者和合作者可访问（ embargop期后开放）

**访问协议**：
- 明确说明如何获取数据（下载链接、申请流程）
- 提供联系信息（数据管理员邮箱）
- 说明数据使用条款（引用要求、禁止行为）
- 长期保存承诺（存储库协议）

** embargo（延迟开放）**：
- 适用：论文发表前保护优先权
- 时长：通常6-24个月
- 设置：投稿时或数据上传时设定
- 注意：部分期刊要求数据立即开放，需提前确认

### 4. Interoperable（可互操作）

**数据格式标准**：
- 表格数据：CSV（推荐）、TSV、JSON
- 避免：Excel专有格式（.xlsx）、PDF中的表格
- 文本数据：TXT、XML、JSON
- 图像数据：TIFF（无损）、PNG（推荐）、JPEG（仅照片）
- 避免：PSD、AI等专有格式
- 地理数据：Shapefile、GeoJSON、GeoTIFF
- 序列数据：FASTA、FASTQ、VCF（生物信息学）

**元数据标准**：
- 使用领域标准词汇表（ontology）
- 生物：Gene Ontology (GO)、NCBI Taxonomy
- 社会科学：DDI Controlled Vocabulary
- 地理：ISO 19115、INSPIRE
- 通用：Schema.org、Dublin Core

**数据整合**：
- 提供数据字典（变量名、类型、取值范围、编码说明）
- 使用标准编码（如性别：ISO 5218）
- 提供跨数据集映射关系
- 记录数据转换过程（provenance）

### 5. Reusable（可重用）

**数据文档**：
- README文件：数据概述、文件结构、使用说明
- 数据字典：每个变量的详细说明
- 代码本（Codebook）：编码规则、缺失值定义
- 方法文档：数据收集、处理、清洗流程

**许可协议**：
- CC0：无限制，推荐用于数据
- CC-BY：需署名
- CC-BY-SA：需署名+相同方式共享
- CC-BY-NC：需署名+非商业用途
- ODbL：开放数据库许可（专门用于数据库）
- 自定义：机构/项目特定协议

**引用要求**：
- 提供推荐引用格式
- 包含DOI、作者、标题、存储库、年份
- 示例："Smith, J. (2023). Dataset Title. Repository Name. https://doi.org/10.xxxx/xxxxx"

## 数据清洗规范

### 1. 原始数据保护

**原则**：
- 永远保留原始数据（raw data），不做任何修改
- 清洗过程可重复、可记录
- 使用脚本而非手动修改（可审计）

**文件组织**：
```
data/
├── raw/              # 原始数据（只读，永不修改）
│   ├── survey_raw.csv
│   ├── interview_recordings/
│   └── experiment_logs/
├── processed/        # 清洗后数据（版本控制）
│   ├── survey_cleaned_v1.csv
│   ├── survey_cleaned_v2.csv
│   └── README.md
├── derived/          # 分析用数据（从processed生成）
│   ├── analysis_dataset.csv
│   └── variables_documentation.md
└── scripts/          # 清洗脚本
    ├── clean_survey.R
    ├── clean_survey.py
    └── README.md
```

### 2. 数据清洗步骤

**步骤1：数据导入与检查**
- 检查文件编码（UTF-8推荐）
- 检查行列数是否与预期一致
- 查看数据类型（数值/文本/日期）
- 识别缺失值表示方式（空值、NA、-999、"无"）

**步骤2：缺失值处理**
- 识别：计算每个变量的缺失比例
- 记录：记录缺失原因（未回答、不适用、数据错误）
- 处理策略：
  - 删除：缺失比例>50%或样本量充足时
  - 插补：均值/中位数/众数插补（简单）
  - 多重插补：MICE、 Amelia（复杂，更优）
  - 保留：标记缺失，分析时处理
- 注意：报告缺失值处理方式，敏感性分析

**步骤3：异常值检测**
- 统计方法：
  - 箱线图（IQR的1.5倍外）
  - Z-score（|z|>3）
  - 马氏距离（多变量）
- 领域知识：
  - 年龄>120岁
  - 收入为负数
  - 日期在未来
- 处理：
  - 核实：检查原始记录
  - 修正：如有明确错误
  - 保留：如为真实极端值，报告敏感性分析
  - 删除：如为录入错误且无法核实

**步骤4：数据一致性检查**
- 逻辑检查：
  - 出生日期 < 入学日期
  - 收入 >= 支出（除非有负债）
  - 子问题与母问题一致（如"是否吸烟"=否，但"每天吸烟量"=20）
- 范围检查：
  - 性别编码：1/2而非男/女（或统一）
  -  Likert量表：1-5而非1-5+0
- 重复检查：
  - 同一受访者多次提交
  - 完全相同的记录

**步骤5：数据转换**
- 变量重编码：
  - 反向计分（如1→5, 2→4, 3→3, 4→2, 5→1）
  - 分类变量虚拟化
  - 连续变量分组（谨慎，损失信息）
- 变量计算：
  - 生成新变量（如BMI = 体重/身高²）
  - 标准化/归一化（Z-score、Min-Max）
  - 对数转换（右偏分布）
- 时间变量：
  - 统一日期格式（YYYY-MM-DD）
  - 计算时间差（如年龄、病程）

**步骤6：数据验证**
- 与原始数据对比：抽样检查
- 统计摘要：均值、标准差、分布，与预期对比
- 交叉验证：与已发表数据对比（如有）
- 可视化：直方图、散点图，直观检查

### 3. 数据清洗记录

**记录内容**：
- 每一步的操作（代码+注释）
- 修改了哪些数据（行号、原值、新值）
- 删除的数据（原因、数量）
- 生成的变量（公式、来源）
- 处理时间、处理人

**示例记录**：
```
数据清洗日志
日期：2023-06-15
处理人：张三

1. 缺失值处理
   - 变量"income"：缺失率12%，使用中位数插补（median=5000）
   - 变量"education"：缺失率3%，删除对应样本（n=15）

2. 异常值处理
   - 样本ID=1023：年龄=150岁，核实为录入错误，修正为50岁
   - 样本ID=2056：收入=9999999，疑似错误，标记为缺失

3. 变量生成
   - 新增"bmi" = weight / (height/100)^2
   - 新增"age_group"：cut(age, breaks=c(0,30,50,70,100))

4. 数据导出
   - 文件名：survey_cleaned_v2.csv
   - 样本量：985（原始1000，删除15）
   - 变量数：45（原始42，新增3）
```

## 数据可视化规范

### 1. 图表设计原则

**清晰性**：
- 一个图表传达一个核心信息
- 避免3D效果、不必要的装饰
- 数据-墨水比最大化（Tufte原则）

**完整性**：
- 标题：说明图表内容（非结论）
- 坐标轴：标签+单位
- 图例：清晰、位置合理
- 注释：必要的数据来源、说明

**准确性**：
- 坐标轴从0开始（除非对数尺度）
- 误差线：标准差、标准误、置信区间
- 样本量：标注n=XX
- 统计显著性：*p<0.05, **p<0.01, ***p<0.001

### 2. 常用图表类型

**比较**：
- 柱状图：分类数据比较
- 箱线图：分布比较（含中位数、四分位、异常值）
- 小提琴图：分布形状比较
- 雷达图：多维度比较（谨慎使用）

**关系**：
- 散点图：两个连续变量关系
- 气泡图：加第三个变量（大小）
- 热力图：矩阵数据模式
- 网络图：节点关系

**趋势**：
- 折线图：时间序列
- 面积图：累积趋势
- 阶梯图：离散变化

**构成**：
- 饼图：简单构成（≤5类）
- 堆叠柱状图：多类别构成
- 树状图：层次构成

**地理**：
-  choropleth map：区域填充
- 点地图：位置标记
- 热力地图：密度分布

### 3. 配色规范

**原则**：
- 色盲友好：避免红绿组合（8%男性色盲）
- 黑白打印友好：图案+颜色双重编码
- 文化敏感：颜色含义因文化而异

**推荐配色方案**：
- ColorBrewer：专业配色工具（colorbrewer2.org）
- 单色系：同一色相不同明度（连续数据）
- 双色系：两个色相（正负、前后对比）
- 多色系：区分类别（≤7类）

**避免**：
- 彩虹色（rainbow colormap）：感知不均匀
- 高饱和度：刺眼、不专业
- 过多颜色：>7类难以区分

### 4. 图表分辨率与格式

**分辨率**：
- 屏幕展示：150 dpi足够
- 打印/发表：300 dpi（最低），600 dpi（推荐）
- 线图：1200 dpi（避免锯齿）

**格式选择**：
- 矢量图（推荐）：PDF、EPS、SVG、EMF
  - 优点：无限放大、文件小、可编辑
  - 适用：线图、流程图、示意图
- 位图：PNG（推荐）、TIFF
  - 优点：照片、复杂图像
  - 缺点：放大失真
- 避免：JPEG（有损压缩）、BMP（文件大）

**导出设置**：
- 字体嵌入：确保跨平台显示一致
- 裁剪：去除多余白边（tight bbox）
- 尺寸：按期刊要求（通常单栏8cm，双栏17cm）

### 5. 可视化工具

**编程工具**：
- Python：matplotlib、seaborn、plotly、bokeh
- R：ggplot2、lattice、plotly、shiny
- JavaScript：D3.js、ECharts、Highcharts

**交互工具**：
- Tableau：拖拽式，适合探索性分析
- Power BI：微软生态，企业常用
- Flourish：在线，适合新闻可视化
- Datawrapper：在线，简单快捷

**学术专用**：
- Origin：理工科常用，图表专业
- SigmaPlot：生物统计图表
- GraphPad Prism：医学/生物统计
- MATLAB：工程/数学可视化

## 数据存储与备份

### 1. 存储策略

**3-2-1原则**：
- 3份副本：原始+本地备份+远程备份
- 2种介质：硬盘+云/磁带/光盘
- 1份异地：防止火灾、盗窃等本地灾难

**存储介质**：
- 本地：外置硬盘（SSD推荐，速度快、抗震）
- 网络：云存储（OneDrive、Google Drive、Dropbox）
- 机构：学校/研究所服务器（通常有备份）
- 专业：Figshare、Zenodo、Dryad（科研专用）

### 2. 版本控制

**命名规范**：
- 日期：data_2023-06-15.csv
- 版本：data_v1.2.csv
- 内容：survey_cleaned_n1000.csv
- 避免：data_final.csv、data_final_final.csv、data_really_final.csv

**版本控制工具**：
- Git/GitHub：代码+小数据（<100MB）
- Git LFS：大数据版本控制
- DVC（Data Version Control）：机器学习专用
- 手动：日期+版本号，变更日志

### 3. 长期保存

**格式选择**：
- 优先开放格式（CSV、TXT、PDF/A、TIFF）
- 避免专有格式（.xlsx、.docx、.psd）
- 定期迁移（每5-10年检查格式可用性）

**存储库选择**：
- 学科存储库：GenBank（基因）、PDB（蛋白质）、ICPSR（社科）
- 通用存储库：Zenodo、Figshare、Dryad、Mendeley Data
- 机构存储库：大学/研究所机构库
- 国家存储库：国家数据中心、国家科技基础条件平台

## 数据伦理与隐私

### 1. 敏感数据识别

**个人身份信息（PII）**：
- 直接标识：姓名、身份证号、手机号、地址
- 准标识：邮编、生日、性别、种族（组合可识别）
- 敏感属性：健康、财务、性取向、政治观点

**特殊类别**：
- 人类遗传数据：需额外保护
- 未成年人数据：需监护人同意
- 土著/少数民族：需社区同意
- 濒危物种：位置信息需模糊化

### 2. 匿名化处理

**匿名化（Anonymization）**：
- 删除：直接标识符
- 泛化：年龄→年龄段，邮编→前3位
- 扰动：添加随机噪声（差分隐私）
- 合成数据：生成统计特征相似的假数据

**假名化（Pseudonymization）**：
- 用编码替代标识符（ID001, ID002）
- 保留密钥映射表（单独安全存储）
- 可逆：需要时可重新识别

**k-匿名**：
- 每个准标识符组合至少出现k次
- 示例：k=5，则每个[性别, 年龄组, 邮编前3位]组合≥5人
- 工具：ARX Data Anonymization Tool

### 3. 知情同意

**数据使用同意**：
- 收集时明确告知数据用途
- 是否用于未来研究（需 broad consent）
- 是否共享（去标识化后）
- 是否商业使用
- 撤回权利：参与者可随时撤回数据

**二次使用**：
- 超出原同意范围：需重新获得同意
- 或：使用完全匿名化数据（无法重新识别）
- 或：伦理委员会豁免（公共利益）

### 4. 数据安全

**传输安全**：
- 加密传输：HTTPS、SFTP、VPN
- 避免：未加密邮件发送敏感数据
- 大文件：加密压缩包+密码单独发送

**存储安全**：
- 加密存储：BitLocker（Windows）、FileVault（Mac）
- 访问控制：最小权限原则
- 审计日志：记录谁访问了哪些数据

**销毁**：
- 研究结束后：按协议销毁或归档
- 安全删除：物理销毁硬盘、消磁、多次覆盖
- 云数据：确认彻底删除（不仅是"放入回收站"）

## 数据管理计划（DMP）

### 1. 什么是DMP？
数据管理计划是研究开始前制定的文档，说明数据如何收集、管理、存储、共享。

**要求来源**：
- 资助机构：国家自然科学基金、社科基金、欧盟Horizon Europe
- 期刊：Nature、Science、PLOS等要求投稿时提交
- 机构：大学/研究所的数据政策

### 2. DMP内容

**1. 数据描述**：
- 数据类型：定量、定性、图像、音频、视频
- 数据量：预计文件数、总大小
- 数据格式：CSV、JSON、MP3、MP4等
- 数据来源：自行收集、公开数据、合作获取

**2. 文档与元数据**：
- 元数据标准：Dublin Core、DDI、ISO 19115
- 文档计划：README、数据字典、代码本
- 质量控制：数据验证、清洗流程

**3. 存储与备份**：
- 存储位置：本地、服务器、云端
- 备份策略：频率、介质、异地
- 安全措施：加密、访问控制

**4. 法律与伦理**：
- 知识产权：数据归属、许可协议
- 隐私保护：匿名化、知情同意
- 敏感数据：特殊处理措施

**5. 数据共享**：
- 共享计划：何时、何地、如何共享
- 限制条件：embargo、访问控制
- 长期保存：存储库选择、格式迁移

**6. 责任与资源**：
- 数据管理员：姓名、职责
- 预算：存储费用、人员时间
- 培训：数据管理技能培训

### 3. DMP工具

**在线工具**：
- DMPonline（英国）：dmponline.dcc.ac.uk
- DMPTool（美国）：dmptool.org
- 中国：部分机构提供模板

**模板资源**：
- 中国科学院：数据管理计划模板
- 国家自然科学基金：项目数据管理要求
- 欧盟Horizon Europe：DMP模板（机器可读）

## 数据引用与论文关联

### 1. 数据引用格式

**标准格式**：
- 作者. (年份). 数据集标题 [数据类型]. 存储库名称. 标识符

**示例**：
- Smith, J., & Jones, M. (2023). Survey on Online Learning Behaviors [Dataset]. Zenodo. https://doi.org/10.5281/zenodo.1234567
- 中国科学院. (2022). 中国陆地生态系统碳汇数据集 [Data set]. 国家生态科学数据中心. http://www.nesdc.org.cn/

### 2. 论文中的数据声明

**位置**：
- 方法部分："数据收集于2022年3-6月..."
- 可用性声明（Availability Statement）：
  - 独立段落（通常在方法末尾或参考文献前）
  - 或：脚注、附录

**模板**：
```
Data Availability Statement:
The data that support the findings of this study are openly available in 
[Repository Name] at [DOI/URL], reference number [accession number].

The data are available on reasonable request from the corresponding author.
[Contact email] due to [ethical/commercial/privacy restrictions].

The data are not publicly available due to [reason]. 
Access can be requested through [process].
```

### 3. 数据论文（Data Paper）

**定义**：
- 专门描述数据集的论文，不分析数据，只描述数据
- 发表在数据期刊（如Scientific Data、Data in Brief、China Scientific Data）

**内容**：
- 数据收集背景与目的
- 数据描述（变量、样本、时间、地点）
- 数据质量与验证
- 数据使用说明
- 数据获取方式

**优势**：
- 获得正式引用和学术认可
- 提高数据可见度
- 满足资助者数据共享要求

## 推荐资源

1. **FAIR原则官方**：
   - FORCE11：www.force11.org
   - GO FAIR：www.go-fair.org
   - FAIRsharing：fairsharing.org（标准、数据库、政策目录）

2. **数据存储库**：
   - re3data.org：全球科研数据存储库目录
   - 中国科技资源共享网：www.escience.org.cn

3. **数据管理工具**：
   - Open Science Framework (OSF)：项目管理+数据存储
   - Zenodo：通用存储，与GitHub集成
   - Figshare：数据、图表、代码
   - Dryad：生物/医学数据

4. **数据清洗工具**：
   - OpenRefine：免费，强大的数据清洗
   - Trifacta Wrangler：可视化清洗
   - Python：pandas, numpy, scipy
   - R：tidyverse, dplyr, tidyr

5. **学习资源**：
   - DataONE：数据管理技能培养（dataone.org/education）
   - 中国科学院：科学数据管理培训课程
   - Coursera：Research Data Management and Sharing（北卡罗来纳大学）

6. **中国资源**：
   - 国家科技基础条件平台：www.nstip.cn
   - 国家数据中心体系：各学科的国家级数据中心
   - 中国科学院数据云：www.csdb.cn
