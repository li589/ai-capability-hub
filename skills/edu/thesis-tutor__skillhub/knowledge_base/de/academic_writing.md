# Leitfaden für akademisches Schreiben auf Englisch

## Häufige Fehler bei der englischen Wissenschaftssprache und deren Korrektur

### 1. Redundante Ausdrücke (Redundanz)

| Chinglisch | Akademisches Englisch | Erläuterung |
|---------|---------|------|
| in the year of 2023 | in 2023 | Vor Jahreszahlen kein „the year of nötig |
| at the present time | currently / now | Redundanz vermeiden |
| due to the fact that | because / since | „the fact that ist überflüssig |
| in spite of the fact that | although / though | Vereinfachen |
| in the event that | if | Konditionalsatz direkt formulieren |
| for the purpose of | to / for | Infinitiv ist prägnanter |
| in order to | to | „in order ist überflüssig |
| it is important to note that | note that / importantly | Füllphrasen vermeiden |
| there is no doubt that | undoubtedly / clearly | Direkt ausdrücken |
| it goes without saying that | [streichen] | Was nicht gesagt werden muss, nicht schreiben |

**Beispielsatz-Korrektur**:
- Original: „Due to the fact that the sample size was small, the results may not be generalizable.
- Korrektur: „Because the sample size was small, the results may not be generalizable.

### 2. Vage Modifikatoren (Vague Modifiers)

| Vager Ausdruck | Akademische Alternative | Empfehlung |
|---------|---------|------|
| very important | critical / crucial / essential | Starke Adjektive statt „very + Adjektiv |
| very big | substantial / considerable / significant | Konkretisieren |
| very small | minimal / negligible / marginal | Konkretisieren |
| very good | excellent / robust / effective | Konkretisieren |
| very bad | poor / inadequate / deficient | Konkretisieren |
| quite / rather / pretty | [streichen oder ersetzen] | Im akademischen Schreiben vermeiden |
| etc. / and so on | Vollständig aufzählen oder „including X, Y, and Z | Präzision wahren |
| some / a lot of / many | several / numerous / a total of X | Quantifizieren |
| things / stuff | factors / variables / elements / aspects | Konkretisieren |
| people / someone | participants / respondents / subjects | Konkretisieren |

**Beispielsatz-Korrektur**:
- Original: „The results are very good and very important for the field.
- Korrektur: „The results are robust and carry significant implications for the field.

### 3. Fehlgebrauch logischer Konnektoren

| Falsche Verwendung | Richtige Verwendung | Kontext |
|---------|---------|------|
| Because... so... | Because... / ...; therefore,... | Englisch verwendet nur eine Verbindungsart |
| Although... but... | Although... / ...; however,... | Dasselbe |
| Since... therefore... | Since... / ...; thus,... | Dasselbe |
| On the one hand... on the other hand... | Nur für den Gegensatz zweier Seiten verwenden | Nicht für einfache Aufzählungen |
| Firstly... secondly... finally... | First... second... third... / First... next... finally... | „ly-Suffix ist unnötig |
| Last but not least... | Finally / Lastly / Most importantly | Klischees vermeiden |

**Beispielsatz-Korrektur**:
- Original: „Because the data was incomplete, so we excluded these cases.
- Korrektur: „Because the data was incomplete, we excluded these cases.
- Alternativ: „The data was incomplete; therefore, we excluded these cases.

### 4. Subjekt-Verb-Kongruenz und Artikelprobleme

**Subjekt-Verb-Kongruenz**:
- Falsch: „The number of participants are 100.
- Richtig: „The number of participants is 100. („number ist Singular)
- Falsch: „A total of 50 participants was recruited.
- Richtig: „A total of 50 participants were recruited. („participants ist das Subjekt)

**Artikelgebrauch**:
- Falsch: „The society is changing rapidly. (Generell ohne „the)
- Richtig: „Society is changing rapidly.
- Falsch: „I conducted research on the online learning.
- Richtig: „I conducted research on online learning. (Abstrakte Konzepte ohne „the)
- Falsch: „This is a important finding.
- Richtig: „This is an important finding. (Vor Vokalen „an)

### 5. Tempusprobleme

| Abschnitt | Tempus | Beispielsatz |
|------|------|------|
| Literaturübersicht | Präsens (allgemeine Wahrheiten) / Präteritum (konkrete Studien) | „Smith (2020) found that... / „Previous studies show that... |
| Methodik | Präteritum | „We recruited 100 participants... |
| Ergebnisse | Präteritum | „The results indicated that... |
| Diskussion/Fazit | Präsens (Bedeutung erklären) / Präteritum (Einschränkungen) | „These findings suggest that... / „The study was limited by... |
| Abbildungsbeschreibungen | Präsens | „Figure 1 shows the relationship... |

## Hedging-Sprache (Abschwächungsstrategien)

### 1. Was ist Hedging?
Hedging ist eine sprachliche Strategie im akademischen Schreiben, um Vorsicht, Unsicherheit auszudrücken oder Absolute zu vermeiden. Es spiegelt die wissenschaftliche Strenge wider – Schlussfolgerungen nicht übertrieben darzustellen und die Grenzen der Forschung anzuerkennen.

### 2. Arten von Hedging

**Modalverben**:
- may / might / could (Möglichkeit)
- can / would / should (Bedingung/Empfehlung)
- seem / appear to (Oberflächenerscheinung)

**Adverbien**:
- possibly / probably / likely (Wahrscheinlichkeit)
- generally / typically / usually (Allgemeingültigkeit)
- relatively / comparatively (Relativität)
- approximately / roughly / about (Annäherung)

**Adjektive**:
- possible / probable / likely (Möglichkeit)
- tentative / preliminary / potential (Vorläufig/Potenziell)
- partial / limited / restricted (Eingeschränkt)

**Substantive**:
- possibility / probability / likelihood (Möglichkeit)
- suggestion / indication / implication (Andeutung)
- assumption / hypothesis / claim (Annahme/Behauptung)

**Phrasen**:
- to some extent / to a certain degree (in gewissem Maße)
- in most cases / under certain conditions (bedingt)
- based on the available evidence (auf Basis verfügbarer Evidenz)
- it is possible that / it seems that (indirekter Ausdruck)

### 3. Anwendungsszenarien

**Hedging ist obligatorisch**:
- Korrelation ≠ Kausalität: „X is associated with Y (nicht „X causes Y)
- Stichprobenbeschränkung: „These findings may not generalize to...
- Vorläufige Ergebnisse: „The data suggest a possible trend...
- Spekulation: „This might be explained by...
- Zukünftige Forschung: „Further research is needed to...

**Übermäßiges Hedging vermeiden**:
- Schwach: „It might perhaps be possible that the results could potentially suggest...
- Stark: „The results suggest...
- Prinzip: Einen Grad auf einmal ausdrücken, nicht kumulieren

### 4. Fachspezifische Unterschiede

| Fachgebiet | Hedging-Grad | Beispielsatz |
|------|------------|------|
| Geistes- und Sozialwissenschaften | Stark | „This interpretation is arguably... |
| Naturwissenschaften | Mittel | „The data suggest that... |
| Medizin/Gesundheit | Vorsichtig | „These findings may have implications for... |
| Ingenieurwesen/Technik | Schwächer | „The results demonstrate that... |

## Academic Phrasebank (Akademische Phrasesammlung)

### 1. Einleitung

**Forschungsfeld etablieren**:
- In recent years, there has been growing interest in...
- The past decade has seen a rapid increase in...
- X has become a central issue in...
- There is an increasing body of literature on...

**Forschungslücke aufzeigen**:
- However, little research has been conducted on...
- Despite the growing interest in X, few studies have examined...
- While considerable research has focused on X, less attention has been paid to...
- To date, no study has investigated...

**Forschungsziel formulieren**:
- The primary aim of this study is to...
- This study seeks to address the following research questions:...
- The present research was designed to investigate...
- This paper attempts to examine...

### 2. Literaturübersicht

**Vorherige Forschung zusammenfassen**:
- A substantial body of research has examined...
- Previous studies have investigated...
- Smith (2020) conducted a study on...
- In a seminal work, Jones (2019) argued that...

**Studien vergleichen**:
- While Smith (2020) found that..., Jones (2019) reported...
- In contrast to earlier findings, recent studies suggest...
- Similarly, Lee (2021) demonstrated that...
- Conversely, Wang (2022) argued that...

**Kritische Bewertung**:
- However, these studies are limited by...
- A major limitation of this approach is...
- These findings should be interpreted with caution because...
- It is worth noting that these studies did not account for...

### 3. Methodik

**Forschungsdesign beschreiben**:
- This study adopted a mixed-methods approach...
- A qualitative design was employed to explore...
- The research was conducted in two phases...
- Data were collected using a combination of...

**Stichprobe beschreiben**:
- The sample comprised 100 participants recruited from...
- Participants were selected using purposive sampling...
- The inclusion criteria were as follows:...
- A total of 50 students (25 males, 25 females) participated in...

**Datenerhebung beschreiben**:
- Semi-structured interviews were conducted with...
- A questionnaire consisting of 20 items was administered to...
- Data were gathered through document analysis and observation...
- The survey was distributed online via...

**Datenanalyse beschreiben**:
- Quantitative data were analyzed using SPSS 26.0...
- Thematic analysis was conducted following Braun and Clarke's (2006) framework...
- Descriptive statistics were computed for all variables...
- A multiple regression analysis was performed to examine...

### 4. Ergebnisse

**Hauptbefunde präsentieren**:
- The results revealed that...
- Analysis of the data showed that...
- The findings indicated a significant relationship between...
- Descriptive statistics are presented in Table 1...

**Abbildungen und Tabellen referenzieren**:
- As shown in Figure 1,...
- Table 2 presents the results of...
- The data in Figure 3 clearly demonstrate...
- A summary of the main findings is provided in Table 4...

**Wichtige Befunde hervorheben**:
- Notably, the results revealed that...
- The most striking finding was that...
- Interestingly, the data showed that...
- Unexpectedly, the analysis revealed that...

### 5. Diskussion

**Ergebnisse interpretieren**:
- These findings suggest that...
- One possible explanation for this result is...
- This finding is consistent with Smith's (2020) theory that...
- The observed effect may be attributed to...

**Vergleich mit der Literatur**:
- The present findings align with previous research (Smith, 2020; Jones, 2019)...
- In contrast to earlier studies, the current research found...
- These results corroborate the findings of Lee (2021)...
- This discrepancy may be explained by differences in...

**Einschränkungen benennen**:
- Several limitations of this study should be acknowledged...
- First, the sample was limited to...
- Second, the cross-sectional design precludes causal inferences...
- Third, the reliance on self-report measures may have introduced bias...

**Zukünftige Forschung vorschlagen**:
- Future research should examine...
- It would be valuable to investigate...
- Longitudinal studies are needed to establish...
- Future studies could benefit from incorporating...

### 6. Fazit

**Hauptbeiträge zusammenfassen**:
- This study has provided new insights into...
- The findings contribute to the growing body of literature on...
- The present research extends previous work by...
- These results have several theoretical and practical implications...

**Praktische Empfehlungen**:
- Based on these findings, practitioners should consider...
- The results suggest that policymakers need to...
- These findings have important implications for practice, including...
- Organizations may benefit from implementing...

**Abschluss**:
- In conclusion, this study has demonstrated that...
- Taken together, these findings highlight the importance of...
- Overall, the present research contributes to our understanding of...
- This study represents an initial step toward...

﻿# Leitfaden für Publikation und Veröffentlichung

## Zeitschriftenauswahl-Strategie

### 1. Einordnung der Studie

**Forschungstyp abgleichen**:
- Empirische Studie: Zeitschrift mit Fokus auf Daten und Methoden wählen
- Theoretische Übersicht: Zeitschrift für konzeptionelle Beiträge wählen
- Fallstudie: Zeitschrift mit Akzeptanz qualitativer Methoden wählen
- Methodik: Spezialzeitschrift für Methodeninnovation wählen

**Innovationsgrad einschätzen**:
- Bahnbrechende Innovation: Top-Journal (hoher Impact Factor, gute Reputation)
- Inkrementelle Innovation: Fachspezifische Zeitschrift
- Replikation/Validierung: Open-Access-Journal, Datenjournal
- Negative Ergebnisse: Spezialjournal für negative Ergebnisse (z. B. Journal of Negative Results)

### 2. Zeitschriften-Auswahlhilfen

**Datenbanken**:
- Web of Science: Impact Factor, Quartilseinstufung
- Scopus: CiteScore, SJR
- CNKI: Chinesische Impact-Faktoren

**Zeitschriften-Matching-Tools**:
- Journal Finder (Elsevier): Titel/Abstract eingeben, Zeitschriftenempfehlung
- Journal Suggester (Springer): Ähnliche Funktion
- Jane (Biosemantics): Biomedizinischer Bereich
- Edanz Journal Selector: Fächerübergreifend

**Zeitschriften-Bewertungsindizes**:
- Impact Factor (IF): 2-Jahres-Zitationsmittel, Trend beachten
- 5-Jahres-Impact Factor: Stabiler
- CiteScore: Scopus-Indikator, andere Berechnungsmethode
- SJR (SCImago Journal Rank): Berücksichtigt Zitationsgewichtung
- SNIP (Source Normalized Impact per Paper): Berücksichtigt Fächerunterschiede
- CAS-Zoneneinteilung: Zone 1 (Top 5%), Zone 2 (6-20%), Zone 3 (21-50%), Zone 4 (untere 50%)
- JCR-Quartilseinteilung: Q1 (Top 25%), Q2 (26-50%), Q3 (51-75%), Q4 (untere 25%)

### 3. Recherche-Checkliste für Zeitschriften

**Basisinformationen**:
- [ ] Verlag: Elsevier, Springer, Wiley, SAGE, Taylor & Francis, IEEE usw.
- [ ] Erscheinungsfrequenz: Monatlich, zweimonatlich, vierteljährlich (beeinflusst Begutachtungsdauer)
- [ ] Open-Access-Optionen: Vollständig OA, Hybrid OA, Abonnement
- [ ] APC (Article Processing Charge): 0-, Rabattaktionen beachten

**Einreichungsanforderungen**:
- [ ] Wortlimit: Üblicherweise 4000-8000 Wörter
- [ ] Formatvorgaben: APA, MLA, Chicago
- [ ] Literaturangaben: Üblicherweise 30-50 Quellen
- [ ] Abbildungslimit: Üblicherweise 5-8
- [ ] Zusatzmaterialien: Akzeptiert Daten, Code, Anhänge?

**Begutachtungsinformationen**:
- [ ] Begutachtungsdauer: Durchschnitt 1-3 Monate (Website oder Autorenrichtlinien)
- [ ] Akzeptanzrate: Üblicherweise 10-30% (je niedriger, desto schwieriger)
- [ ] Begutachtungsart: Einfach-blind, doppelt-blind, offene Begutachtung
- [ ] Erste Entscheidungszeit: Durchschnittliche Tage

**Weitere Faktoren**:
- [ ] Indexierung: SCI/SSCI
- [ ] Redaktionsmitglieder: Namhafte Wissenschaftler im Fachgebiet?
- [ ] Aktuelle Artikel: Letzte 3 Ausgaben lesen, Stilvorlieben verstehen
- [ ] Sonderhefte: Call for Papers beachten

### 4. Einreichungsstrategie

**Gestufte Einreichung**:
1. Erste Wahl: Wunschzeitschrift (höchster IF, schwierigste)
2. Zweite Wahl: Passende Zeitschrift (mittlerer IF, angemessene Akzeptanzrate)
3. Dritte Wahl: Auffangzeitschrift (Veröffentlichung sichergestellt)

**Zeitplanung**:
- 6-12 Monate Einreichungszeitraum einplanen
- Berücksichtigen: Begutachtung + Revision + Wiederbegutachtung + Annahme + Online-Veröffentlichung + Druck
- Mindestens 1 Jahr vor Abschluss/Projektende mit Einreichung beginnen

**Raubjournale vermeiden**:
- Merkmale: Schnelle Annahme (<1 Woche), hohe APC, keine substantielle Begutachtung, unklare Redaktionsmitglieder
- Prüfen: Beall's List (nicht mehr aktualisiert, aber historisch nutzbar), DOAJ (legitimes OA-Verzeichnis)
- Prinzip: Unbekannte Zeitschriften unbedingt recherchieren, nicht von „schneller Veröffentlichung locken lassen

## Cover Letter verfassen

### 1. Grundstruktur

`
An die/den Redakteur/in

Sehr geehrte/r Redakteur/in,

hiermit reichen wir den Originalartikel „[Titel] zur Publikation ein.

【Forschungshintergrund】(2-3 Sätze)
Kurze Darstellung des Forschungsfeldes und seiner Bedeutung.

【Forschungsbeitrag】(3-4 Sätze)
1. Kerntes Ergebnis oder Innovationspunkt
2. Abgrenzung von bestehender Forschung
3. Theoretische oder praktische Bedeutung

【Zeitschriften-Passung】(2-3 Sätze)
Warum ist der Artikel geeignet für diese Zeitschrift:
- Passt zum Scope (Aim & Scope)
- Zitation relevanter Artikel dieser Zeitschrift
- Zielgruppen-Match

【Erklärungen】(1-2 Sätze)
- Originalitätserklärung
- Keine Interessenkonflikte
- Alle Autoren stimmen der Einreichung zu

【Empfohlene Gutachter】(optional)
3-5 Gutachter vorschlagen (Name, Institution, E-Mail, Begründung)

【Gutachter ausschließen】(optional)
Wissenschaftler mit Interessenkonflikten auflisten

Mit freundlichen Grüßen

[Unterschrift Korrespondenzautor]
[Institution]
[Kontaktinformationen]
`

### 2. Schreibempfehlungen

**Muss enthalten**:
- Titel und Art des Artikels (Originalforschung/Review/Kurzmitteilung)
- Kernbeitrag (1-2 Sätze)
- Zeitschriften-Passungsbegründung (2-3 Artikel dieser Zeitschrift zitieren)
- Originalitätserklärung
- Erklärung zu Interessenkonflikten

**Vermeiden**:
- Abstract-Inhalte wiederholen
- Übertriebene Eigenwerbung („bahnbrechend, „revolutionär)
- Andere Studien abwerten
- Zu lang (maximal 1 Seite)

**Beispielabsatz**:
`
This study makes three key contributions to the literature on X. 
First, we develop a novel theoretical framework that integrates A and B. 
Second, our empirical analysis, based on a sample of 500 firms, 
provides the first large-scale evidence of Y in the context of Z. 
Third, our findings have direct implications for policymakers seeking to...

We believe this manuscript is particularly suitable for [Journal Name] 
given the journal's focus on [specific area]. Our work aligns with recent 
articles published in your journal, such as Smith (2022) and Jones (2023), 
which examine related aspects of...
`

### 3. Gutachter empfehlen

**Auswahlkriterien**:
- Fachexperten (Veröffentlichungen zu verwandten Themen in den letzten 5 Jahren)
- Verschiedene Regionen (internationale Perspektive)
- Verschiedene Karrierestufen (Erfahrene + Nachwuchs)
- Keine Interessenkonflikte (keine Kooperationspartner, Betreuer, Studierende)

**Bereitzustellende Informationen**:
- Name, Position, Institution
- E-Mail (Dienstadresse bevorzugt)
- Empfehlungsbegründung (1 Satz)
- Repräsentative Publikationen (1-2)

**Gutachter ausschließen**:
- Direkte Konkurrenten (ähnliche Forschung zur gleichen Zeit)
- Akademische Konflikte
- Private Beziehungen (Familie, enge Kooperationspartner)
- Interessengebundene (Begutachtung von Projekten, Fördermitteln)

## Antwort auf Gutachter (Response to Reviewers)

### 1. Grundprinzipien

**Haltung**:
- Höflich, professionell, nicht rechtfertigend
- Den Gutachtern für Zeit und Empfehlungen danken
- Auch bei Uneinigung respektvoll formulieren

**Struktur**:
`
Sehr geehrte/r Redakteur/in und Gutachter/innen,

vielen Dank für die wertvollen Kommentare zum Manuskript „[Titel]. 
Wir haben die vorgeschlagenen Änderungen umfassend umgesetzt.
Nachfolgend finden Sie die Antwort zu jedem einzelnen Kommentar.

Zusammenfassung der Änderungen:
1. XX-Analyse ergänzt (Gutachter 1, Kommentar 3)
2. YY-Befunde neu interpretiert (Gutachter 2, Kommentar 1)
3. ZZ-Diskussion hinzugefügt (Gutachter 1, Kommentar 5)

---

Gutachter/in 1:

Kommentar 1: [Originalzitat]
Antwort: Vielen Dank für die Anregung. Wir haben... [konkrete Änderung]
Änderungsort: Seite X, Zeile Y

Kommentar 2: ...
`

### 2. Antwortstrategien

**Empfehlung annehmen**:
`
We thank the reviewer for this insightful suggestion. 
We have now added the requested analysis in Section 3.2 (page 8, lines 45-60). 
The new results confirm our main findings and strengthen the paper's conclusions.
`

**Teilweise annehmen**:
`
We appreciate the reviewer's concern. While we agree that X is important, 
our current data do not allow us to fully address this issue. 
We have now added a discussion of this limitation on page 12, lines 30-40, 
and suggest it as a direction for future research.
`

**Nicht einverstanden (begründen)**:
`
We thank the reviewer for raising this point. After careful consideration, 
we respectfully disagree for the following reasons: 
First, [reason 1]. Second, [reason 2]. 
However, to address the reviewer's underlying concern, 
we have clarified our argument on page 9, lines 15-20.
`

**Zusätzliche Experimente/Analysen**:
`
We agree that this additional analysis would strengthen the paper. 
We have now conducted [specific analysis] and added the results in 
Table 3 (page 10) and discussed them on page 11, lines 25-35. 
These new findings support our main conclusion that...
`

### 3. Gängige Kommentartypen und Antworten

**Literatur ergänzen**:
- Antwort: Zitationen nachholen und erklären, wie sie in die Argumentation eingebunden werden
- Beispiel: „We have added citations to Smith (2022) and Jones (2023) on page 5, 
 lines 20-25, to support our claim that...

**Methodik hinterfragen**:
- Antwort: Methodenwahl begründen oder Robustheitsprüfungen ergänzen
- Beispiel: „We have added a robustness check using [alternative method] 
  in Appendix B. The results remain consistent with our main findings.

**Kürzung verlangen**:
- Antwort: Empfehlung akzeptieren, Inhalt straffen
- Beispiel: „We have condensed the literature review from 1500 to 1000 words, 
 focusing on the most directly relevant studies (page 3-4).

**Sprachprobleme**:
- Antwort: Dank für den Hinweis, professionelle Überarbeitung oder Muttersprachler-Korrektur
- Beispiel: „We have thoroughly revised the manuscript for language and style. 
  The paper has been professionally proofread by [service/native speaker].

### 4. Änderungsmarkierungen

**Versionskontrolle**:
- Originalversion aufbewahren (Original Submission)
- Änderungsversion mit „Änderungen nachverfolgen oder Hervorhebung markieren
- „Saubere Version bereitstellen (ohne Markierungen, für nach Annahme)

**Markierungsstandards**:
- Neue Inhalte: Gelbe Hervorhebung oder Unterstreichung
- Gelöschte Inhalte: Durchstreichung
- Wesentliche Änderungen: Im Antwortbrief ausführlich erläutern
- Abbildungs-/Tabellenänderungen: Vorher/Nachher-Vergleich

## Umgang mit Ablehnung

### 1. Arten der Ablehnung

**Desk Reject (Ablehnung vor Begutachtung)**:
- Gründe: Nicht im Scope der Zeitschrift, Formatabweichung, offensichtliche Mängel
- Handlung: Scope sorgfältig lesen, andere Zeitschrift wählen
- Zeitraum: Üblicherweise 1-2 Wochen

**Ablehnung nach Begutachtung (Reject after Review)**:
- Gründe: Methodische Mängel, mangelnde Innovativität, Zeitschriften-Passung
- Handlung: Nach Überarbeitung basierend auf Gutachterkommentaren andere Zeitschrift wählen
- Hinweis: Auch bei Ablehnung sind Gutachterkommentare wertvoll

**Ablehnung mit Wiedereinladung (Reject & Resubmit)**:
- Wesentliche: Major Revision, höhere Akzeptanzrate
- Handlung: Alle Kommentare ernst nehmen, umfassend überarbeiten und erneut einreichen
- Hinweis: Im Cover Letter der Wiedereinreichung darauf hinweisen

### 2. Maßnahmen nach Ablehnung

**Schritt 1: Emotionale Verarbeitung**
- Normale Reaktion: Enttäuschung, Wut, Selbstzweifel
- Empfehlung: 1-2 Tage Abstand, dann sachliche Analyse
- Merken: Ablehnung ist normal, selbst Nobelpreisträger wurden abgelehnt

**Schritt 2: Ursachenanalyse**
- Redaktionelle Kommentare: Werden Gründe genannt?
- Gutachterkommentare: Was sind die Hauptprobleme?
- Selbstbewertung: Falsche Zeitschrift gewählt? Mangelnde Vorbereitung?

**Schritt 3: Plan entwickeln**
- Bei Scope-Abweichung: Passendere Zeitschrift wählen
- Bei Methodikproblemen: Experimente/Analysen ergänzen und erneut einreichen
- Bei mangelnder Innovation: Beitrag neu positionieren, Alleinstellungsmerkmale betonen
- Bei Schreibproblemen: Muttersprachler-Korrektur oder Schreibtraining

**Schritt 4: Überarbeitung und Wiedereinreichung**
- Umfassende Überarbeitung basierend auf Gutachterkommentaren
- Auch bei anderer Zeitschrift: Wertvolle Kommentare einarbeiten
- Im neuen Cover Letter erwähnen: „Basierend auf vorherigen Gutachterkommentaren überarbeitet

### 3. Einspruch (mit Vorsicht einzusetzen)

**Anwendungsfälle**:
- Offensichtlicher Begutachtungsfehler (z. B. Methodik missverstanden)
- Gutachter hat Interessenkonflikt
- Redaktionelle Entscheidung widerspricht deutlich den Gutachterkommentaren

**Einspruchsbrief-Prinzipien**:
- Höflich, sachlich, nicht emotional
- Konkrete Probleme benennen (Originaltext zitieren)
- Belege anführen
- Überprüfung oder andere Gutachter erbitten

**Hinweise**:
- Erfolgsquote niedrig (<10%)
- Könnte Redaktion verärgern, zukünftige Einreichungen beeinträchtigen
- Meist effizienter: Andere Zeitschrift wählen

## Tätigkeiten nach der Veröffentlichung

### 1. Artikel bewerben

**Akademische soziale Medien**:
- ResearchGate: Volltext hochladen, Fragen beantworten
- Academia.edu: Ähnliche Funktionen
- LinkedIn: Berufliches Netzwerk teilen
- Twitter/X: In akademischen Kreisen verbreitet, #AcademicTwitter

**Institutionelle Speicherung**:
- Hochschulrepositorium (IR): Akzeptierte Version (Accepted Manuscript) hochladen
- Preprint-Server: arXiv, bioRxiv, SSRN
- Hinweis: Selbstarchivierungsrichtlinien des Verlags beachten (SHERPA/RoMEO prüfen)

**Akademische Präsentationen**:
- Konferenzvortrag: Einreichung bei relevanten Fachkonferenzen
- Gastvorträge: Eingeladene Vorträge, Workshops
- Populärwissenschaftliche Artikel: Forschung in allgemeinverständliche Inhalte umwandeln

### 2. Zitationen verfolgen

**Tools**:
- Google Scholar: Kostenlos, Zitationsalarme
- Web of Science: Genau, aber Abonnement erforderlich
- Scopus: Ähnliche Funktionen
- CNKI: Chinesische Zitationen
- Altmetric: Soziale Medien-Erwähnungen, Presseberichterstattung

**Strategien**:
- Zitationsalarme einrichten (Google Scholar Alerts)
- Regelmäßig prüfen, wer die eigene Arbeit zitiert
- Zitierende Arbeiten lesen, um Folgeforschung zu verstehen
- Kontakt mit Zitierenden aufnehmen (E-Mail, Kooperationsmöglichkeiten)

### 3. Auf Kritik reagieren

**Arten**:
- Methodenkritik: Daten, Analyse, Schlussfolgerungen
- Ethische Kritik: Informierte Zustimmung, Datenschutz
- Originalitätskritik: Plagiat, Doppelveröffentlichung

**Prinzipien**:
- Zeitnahe Reaktion: Akademische Integrität erfordert es
- Transparent und offen: Daten, Code, Zusatzmaterialien bereitstellen
- Fehler anerkennen: Falls Fehler vorliegen, Korrektur (Erratum/Corrigendum) veröffentlichen
- Unterstützung suchen: Betreuer, Institution, Verlag kontaktieren

## Besondere Hinweise für die Einreichung bei chinesischen Zeitschriften

### 1. Zeitschriftenstufen
- CSSCI (Nanjing-Universität-Kern): Geistes- und Sozialwissenschaften
- PKU-Kern: Allgemeine Kernzeitschrift
- CSCD: Naturwissenschaftliche Kernzeitschrift
- Statistikquelle-Kern (Technologie-Kern): Medizin, MINT-Fächer
- Normale Provinzzeitschrift: Nicht Kern, aber regulär

### 2. Einreichungswege
- Website: Die meisten Zeitschriften nutzen Online-Systeme
- E-Mail: Einige Zeitschriften akzeptieren noch
- CNKI-Plattform: Manche Zeitschriften über CNKI
- Warnung: Vermittler, Beziehungen, Expressveröffentlichung (meist Betrug)

### 3. Formatanforderungen
- Literaturverzeichnis: GB/T 7714-2015 Standard
- Autoreninfo: Vollständige Angaben (Geburtsjahr, Geschlecht, Institution, Position, Forschungsgebiet)
- Förderprojekt: Förderquelle und Projektnummer angeben
- Abstracts auf Deutsch und Englisch: Üblicherweise beide erforderlich
- Umfang: Üblicherweise 8000-15000 Wörter

### 4. Begutachtungszeiträume
- Erstprüfung: 1-2 Wochen
- Externe Begutachtung: 1-3 Monate
- Endprüfung: 1-2 Wochen
- Gesamt: 2-6 Monate
- Express: Manche Zeitschriften bieten es an (zusätzliche Kosten, Vorsicht)

## Zeitmanagement und psychische Anpassung

### 1. Einreichungs-Zeitplan
`
Monat 1-2: Zeitschriftenauswahl, Manuskript vorbereiten, Cover Letter schreiben
Monat 3: Einreichung, Erstprüfung abwarten
Monat 4-5: Externe Begutachtung (möglicherweise 1-3 Runden)
Monat 6: Entscheidung erhalten (Annahme/Minor Revision/Major Revision/Ablehnung)
Monat 7-8: Überarbeitung, Wiedereinreichung, erneute Begutachtung
Monat 9-10: Annahme, Copyrightvereinbarung, Korrekturlesen
Monat 11-12: Online-Veröffentlichung, Druck
`

### 2. Multiprojekt-Management
- Mehrere Arbeiten gleichzeitig vorbereiten (verschiedene Phasen)
- Eine in Begutachtung, eine wird geschrieben, eine wird konzipiert
- Vermeiden: „Alle Eier in einen Korb legen

### 3. Psychische Stärkung
- Ablehnungsrate: Gute Zeitschriften lehnen üblicherweise 80-90% ab
- Durchschnittliche Einreichungen: 3-5 bis zur Annahme (Geistes-/Sozialwissenschaften evtl. mehr)
- Unterstützungssystem aufbauen: Betreuer, Kommilitonen, Schreibgruppen
- Kleine Erfolge feiern: Einreichung abgeschlossen, Änderungskommentare erhalten, Annahme
