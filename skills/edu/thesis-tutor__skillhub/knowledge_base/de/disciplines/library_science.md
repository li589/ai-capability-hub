# Leitfaden für das Schreiben bibliothekswissenschaftlicher Arbeiten

## Merkmale des Fachgebiets
- Betonung von Informationsdiensten, Wissensmanagement und Dokumentenorganisation
- Wert auf Nutzerforschung, Technologieanwendung und Praxisinnovation
- Vielfältige Forschungsmethoden: Umfragen, Experimente, Fallstudien, Systementwicklung
- Deutliche interdisziplinäre Charakteristik (Informatik, Management, Kommunikationswissenschaft)

## Forschungstypen

### 1. Nutzerforschung
- **Anwendung**: Informationsverhalten, Nutzerbedürfnisse, Dienstleistungsbewertung
- **Kernelemente**:
  - Nutzerprofil (Alter, Beruf, Bedürfnisse)
  - Verhaltensanalyse (Recherche, Nutzung, Teilen)
  - Zufriedenheitsbewertung (Servicequalität, Verbesserungsrichtungen)
- **Aufbau der Arbeit**: Hintergrund → Methode → Umfrage → Analyse → Empfehlungen

### 2. Technologische Forschung
- **Anwendung**: Digitale Bibliotheken, Informationssysteme, Datenmanagement
- **Kernelemente**:
  - Systemdesign (Architektur, Funktionen, Technologie)
  - Entwicklungsimplementierung (Programmierung, Testing, Deployment)
  - Leistungsbewertung (Performance, Nutzerfeedback)
- **Aufbau der Arbeit**: Anforderungen → Design → Implementierung → Bewertung → Fazit

### 3. Theoretische Forschung
- **Anwendung**: Informationsorganisation, Wissensmanagement, bibliothekswissenschaftliche Theorie
- **Kernelemente**:
  - Literaturanalyse (Theorieentwicklung, Forschungsstand)
  - Begriffsanalyse (Definitionen, Intension, Extension)
  - Theoriekonstruktion (Modelle, Rahmenwerke, Prinzipien)
- **Aufbau der Arbeit**: Problem → Literatur → Analyse → Theorie → Fazit

## Fachgebietsspezialisierungen

### Bibliothekswissenschaft
- **Bestandsaufbau**: Erwerbung, Katalogisierung, Sammlungsentwicklung, Ressourcenbewertung
- **Informationsdienste**: Auskunftsdienst, Fachreferate, Wissensdienste
- **Leseförderung**: Leseveranstaltungen, Bibliotherapie, Kinderlektüre
- **Bibliotheksmanagement**: Strategische Planung, Personalwesen, Leistungsbewertung

### Archivwissenschaft
- **Archivverwaltung**: Sammlung, Ordnung, Bewertung, Erhaltung
- **Archivinformatisierung**: Digitalisierung, elektronische Unterlagen, digitale Archive
- **Archivnutzung**: Editionswissenschaft, Ausstellungen, Zugänglichkeit
- **Archivschutz**: Restaurierung, Reproduktion, Umweltkontrolle

### Informationsressourcenmanagement
- **Wissensmanagement**: Wissensorganisation, Knowledge Graph, Wissensdienste
- **Datenmanagement**: Data Governance, Datenqualität, Datensicherheit
- **Wettbewerbsintelligenz**: Informationserfassung, Analyse, Anwendung
- **Digital Humanities**: Textanalyse, Datenvisualisierung, digitales Publizieren

## Vorlagen für die Gliederung

### Umfrageforschung
`
1. Einleitung (Forschungshintergrund, Problemstellung, Bedeutung)
2. Literaturübersicht (Forschungsstand, theoretische Grundlagen)
3. Forschungsdesign (Untersuchungsgegenstand, Methoden, Instrumente)
4. Umfrageergebnisse (Daten, Diagramme)
5. Analyse und Diskussion (Erkenntnisse, Vergleich, Interpretation)
6. Fazit und Empfehlungen (Beitrag, Grenzen, Verbesserungen)
`

### Systementwicklung
`
1. Einleitung (Anforderungshintergrund, Ziele)
2. Anforderungsanalyse (Nutzerbedürfnisse, Funktionsanforderungen)
3. Systemdesign (Architektur, Datenbank, Benutzeroberfläche)
4. Systemimplementierung (Technologieauswahl, Schlüsselcode)
5. Systemtest (Funktionstest, Performancetest)
6. Fazit (Zusammenfassung, Ausblick)
`

## Schreibhinweise

### Umfrageforschung
- Stichprobenauswahl (zufällig, geschichtet, bequem)
- Fragebogendesign (Reliabilität, Validität)
- Datenanalyse (Deskriptive Statistik, Inferenzstatistik)
- Ergebnisdarstellung (Kombination von Diagrammen und Text)

### Systementwicklung
- Anforderungsanalyse (Nutzerinterviews, Use-Case-Analyse)
- Systemdesign (Architekturdiagramm, ER-Diagramm, Flussdiagramm)
- Schlüsseltechnologien (Algorithmen, Implementierungsdetails)
- Testverifizierung (Testfälle, Ergebnisanalyse)

### Theoretische Forschung
- Literaturanalyse (systematisch, kritisch)
- Begriffsdefinition (klar, präzise)
- Logische Argumentation (stichhaltig, fundiert)
- Theoretischer Beitrag (innovativ, praxisrelevant)

## Häufige Probleme

1. **Zu großes Thema**: Umfang zu breit, schwer zu vertiefen
2. **Schwache Literaturübersicht**: Fehlende systematische Aufarbeitung, wichtige Literatur übersehen
3. **Unangemessene Forschungsmethoden**: Methoden passen nicht zum Problem
4. **Oberflächliche Datenanalyse**: Nur deskriptive Statistik, keine vertiefte Analyse
5. **Unklarer Praxisbezug**: Allgemeine Empfehlungen, fehlende Umsetzbarkeit
