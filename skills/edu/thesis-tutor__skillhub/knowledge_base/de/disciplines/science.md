# Leitfaden für das Schreiben naturwissenschaftlicher Arbeiten

## Merkmale des Fachgebiets
- Betonung von experimenteller Überprüfung, mathematischer Herleitung und theoretischer Innovation
- Wert auf Datenpräzision, Reproduzierbarkeit und Peer-Review
- Tagungs- und Zeitschriftenaufsätze gleichwertig
- Hohe Anforderungen an die Qualität von Abbildungen (Datendiagramme, Formeln, experimentelle Aufbauten)

## Forschungstypen

### 1. Experimentelle Forschung
- **Anwendung**: Physik-, Chemie- und Biologieexperimente
- **Kernelemente**:
  - Versuchsplanung (Variablenkontrolle, Wiederholungsexperimente)
  - Datenerhebung (Instrumentenpräzision, Fehleranalyse)
  - Ergebnisanalyse (statistische Tests, Unsicherheitsanalyse)
- **Aufbau der Arbeit**: Ziel → Methode → Experiment → Ergebnisse → Analyse

### 2. Theoretische Forschung
- **Anwendung**: Mathematik, theoretische Physik, theoretische Chemie
- **Kernelemente**:
  - Problemstellung (Vermutungen, Hypothesen)
  - Theoretische Herleitung (Beweise, Berechnungen)
  - Ergebnisdiskussion (Bedeutung, Anwendung)
- **Aufbau der Arbeit**: Problem → Vorbereitung → Hauptergebnisse → Beweis → Diskussion

### 3. Computerbasierte Forschung
- **Anwendung**: Rechnergestützte Physik, Rechnergestützte Chemie, Bioinformatik
- **Kernelemente**:
  - Modellerstellung (Algorithmen, numerische Methoden)
  - Programmentwicklung (Code, Verifizierung)
  - Ergebnisanalyse (Konvergenz, Genauigkeit)
- **Aufbau der Arbeit**: Problem → Methode → Implementierung → Ergebnisse → Diskussion

## Fachgebietsspezialisierungen

### Mathematik
- **Reine Mathematik**: Algebra, Geometrie, Analysis, Zahlentheorie
- **Angewandte Mathematik**: Wahrscheinlichkeitsrechnung und Statistik, Operations Research, numerische Mathematik
- **Mathematikdidaktik**: Unterrichtsmethoden, Curriculumdesign

### Physik
- **Kondensierte Materie**: Materialien, Supraleitung, Halbleiter
- **Teilchenphysik**: Hochenergiephysik, Kernphysik
- **Optik**: Laser, Glasfaser, Optoelektronik
- **Astrophysik**: Kosmologie, Galaxien, Schwarze Löcher

### Chemie
- **Organische Chemie**: Synthese, Reaktionsmechanismen
- **Anorganische Chemie**: Koordinationschemie, Materialchemie
- **Analytische Chemie**: Instrumentelle Analytik, Spektroskopie
- **Physikalische Chemie**: Thermodynamik, Kinetik

### Biologie
- **Molekularbiologie**: Gene, Proteine
- **Zellbiologie**: Zellsignalgebung, Zellzyklus
- **Ökologie**: Populationen, Gemeinschaften, Ökosysteme
- **Bioinformatik**: Sequenzanalyse, Strukturvorhersage

## Vorlagen für die Gliederung

### Experimentelle Forschung
`
1. Einleitung (Forschungshintergrund, Problemstellung, Zielsetzung)
2. Experimenteller Teil (Materialien, Methoden, Geräte)
3. Ergebnisse und Diskussion (Daten, Analyse, Vergleich)
4. Fazit (Erkenntnisse, Bedeutung, Ausblick)
`

### Theoretische Forschung
`
1. Einleitung (Problemmhintergrund, Literaturübersicht)
2. Vorkenntnisse (Definitionen, Lemmata)
3. Hauptergebnisse (Theoreme, Beweise)
4. Diskussion (Anwendung, Verallgemeinerung)
5. Fazit (Beitrag, Ausblick)
`

## Schreibhinweise

### Experimentelle Beschreibung
- Detailliert genug für Reproduzierbarkeit
- Alle Parameter angeben
- Gerätemodell spezifizieren
- Quellen der Reagenzien angeben

### Datenpräsentation
- Signifikante Ziffern verwenden
- Fehlerbereiche angeben
- Einheiten kennzeichnen
- Klare und standardisierte Abbildungen

### Formelsatz
- Formeleditor verwenden
- Einheitliches Symbolsystem
- Fortlaufende Nummerierung
- Jedes Symbol erklären

## Häufige Probleme

1. **Unzureichende Experimente**: Zu wenige Wiederholungen, fehlende Kontrollen
2. **Unangemessene Datenverarbeitung**: Fehlerhafte statistische Methoden, unzureichende Fehleranalyse
3. **Schwache Literaturübersicht**: Fehlende aktuelle Entwicklungen, unvollständige Übersicht
4. **Oberflächliche Diskussion**: Nur Ergebnisse auflisten, keine tiefgehende Analyse
5. **Nicht standardisiertes Schreiben**: Inkonsistente Terminologie, chaotisches Format

## Hinweise zur Plagiatsprüfung
- Experimentelle Methodenbeschreibungen können standardisiert werden
- Formelherleitungen müssen originell sein
- Datenanalyse erfordert eigene Interpretation
- Fazit muss auf eigenen Ergebnissen basieren
