# 도서관학 논문 작성 가이드

## 학과 특징
- 정보 서비스, 지식 관리, 문헌 조직을 강조
- 사용자 연구, 기술 활용, 실천 혁신을 중시
- 연구 방법론 다양: 조사, 실험, 사례, 시스템 개발
- 학제적 특성 뚜렷 (컴퓨터, 경영, 커뮤니케이션)

## 연구 유형

### 1. 사용자 연구
- **적용 분야**: 정보 행동, 사용자 요구, 서비스 평가
- **핵심 요소**:
  - 사용자 프로파일 (연령, 직업, 요구)
  - 행동 분석 (검색, 활용, 공유)
  - 만족도 평가 (서비스 품질, 개선 방향)
- **논문 구조**: 배경→방법→조사→분석→제안

### 2. 기술 연구
- **적용 분야**: 디지털 도서관, 정보 시스템, 데이터 관리
- **핵심 요소**:
  - 시스템 설계 (아키텍처, 기능, 기술)
  - 개발 구현 (프로그래밍, 테스트, 배포)
  - 효과 평가 (성능, 사용자 피드백)
- **논문 구조**: 요구→설계→구현→평가→결론

### 3. 이론 연구
- **적용 분야**: 정보 조직, 지식 관리, 도서관학 이론
- **핵심 요소**:
  - 문헌 정리 (이론 발전, 연구 현황)
  - 개념 분석 (정의, 내포, 외연)
  - 이론 구축 (모델, 틀, 원칙)
- **논문 구조**: 문제→문헌→분석→이론→결론

## 학과 세분화

### 도서관학
- **문헌자원 건설**: 수서편목, 장서 발전, 자원 평가
- **정보 서비스**: 참고 봉사, 학과 서비스, 지식 서비스
- **독서 진흥**: 독서 활동, 독서 요법, 아동 독서
- **도서관 경영**: 전략 기획, 인적 자원, 성과 평가

### 기록학
- **기록 관리**: 수집, 정리, 감정, 보존
- **기록 정보화**: 디지털화, 전자 문서, 디지털 기록관
- **기록 활용**: 편찬, 전시, 공개
- **기록 보호**: 복원, 복제, 환경 관리

### 정보자원관리
- **지식 관리**: 지식 조직, 지식 그래프, 지식 서비스
- **데이터 관리**: 데이터 거버넌스, 데이터 품질, 데이터 보안
- **경쟁 정보**: 정보 수집, 분석, 활용
- **디지털 인문학**: 텍스트 분석, 데이터 시각화, 디지털 출판

## 논문 구조 템플릿

### 조사 연구형
```
1. 서론 (연구 배경, 문제, 의의)
2. 문헌 연구 (연구 현황, 이론적 기초)
3. 연구 설계 (대상, 방법, 도구)
4. 조사 결과 (데이터, 도표)
5. 분석 및 토론 (발견, 비교, 해석)
6. 결론 및 제안 (기여, 한계, 개선)
```

### 시스템 개발형
```
1. 서론 (요구 배경, 목표)
2. 요구 분석 (사용자 요구, 기능 요구)
3. 시스템 설계 (아키텍처, 데이터베이스, 인터페이스)
4. 시스템 구현 (기술 선정, 핵심 코드)
5. 시스템 테스트 (기능 테스트, 성능 테스트)
6. 결론 (요약, 전망)
```

## 작성 요점

### 조사 연구
- 표본 선택 (확률, 층별, 편의)
- 설문 설계 (신뢰도, 타당도)
- 데이터 분석 (기술통계, 추론통계)
- 결과 제시 (도표, 문자 결합)

### 시스템 개발
- 요구 분석 (사용자 인터뷰, 유스케이스 분석)
- 시스템 설계 (아키텍처도, ER 다이어그램, 흐름도)
- 핵심 기술 (알고리즘, 구현 세부사항)
- 테스트 검증 (테스트 케이스, 결과 분석)

### 이론 연구
- 문헌 정리 (체계적, 비판적)
- 개념 정의 (명확, 정확)
- 논리적 추론 (엄밀, 근거 있는)
- 이론적 기여 (혁신, 실용)

## 흔한 문제점

1. **주제의 과도한 범위**: 범위가 너무 넓어 심층 연구 어려움
2. **문헌 연구의 취약성**: 체계적 정리 부족, 중요 문헌 누락
3. **연구 방법의 부적절성**: 방법과 문제의 불일치
4. **데이터 분석의 피상성**: 기술 통계에만 머무르고 심층 분석 부족
5. **실천 가치의 불명확성**: 제안이 막연하고 실행 가능성 부족
