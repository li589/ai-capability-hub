# 문학 (Literature) 논문 작성 가이드

## 학과 특징
- 텍스트 정밀 독해, 이론적 틀, 비평적 관점 강조
- 원전 독서, 판본 고증, 상호텍스트성 중시
- 논증은 해석 위주로, 논리는 점진적 전개가 바람직

## 주제 선정 방향

### 중국 고전 문학
1. **시가 연구**
   - 당송사 수용사
   - 시적 이미지 체계
   - 판본과 텍스트 변이

2. **소설 연구**
   - 명청소설 서사 모형
   - 정전화 과정 (예:『홍루몽』)
   - 소설과 지역 문화

3. **문론 연구**
   - 고대 비평 용어의 현대적 해석
   - 중서시학 비교
   - 문체 변천

### 현대문학
- 작가 작품 재독 (정전화/비정전화)
- 문학 사조와 제도 (예: "17년 문학")
- 매체와 문학 (네트워크 문학, SF)
- 젠더와 문학
- 지역성과 세계성

### 비교문학과 세계문학
- 번역과 수용 (역의학)
- 이미지학 (이국적 이미지 구축)
- 세계문학 체계
- 디지털 인문학과 문학 연구

### 문예 이론
- 서양 이론의 중국화
- 신매체 문예 이론
- 생태비평
- 포스트휴머니즘

## 논문 구조 템플릿

### 텍스트 분석 논문
```
1. 서론 (문제의 발단, 텍스트 선택, 방법론)
2. 문헌 검토 (연구사, 논쟁 쟁점, 본 논문의 접근점)
3. 이론적 틀 (개념 정의, 분석 도구)
4. 텍스트 정밀 독해 (구조, 이미지, 서사, 언어)
5. 심층 해석 (문화, 역사, 철학적 차원)
6. 결론 (새로운 견해, 한계, 확장)
```

### 문학사 논문
```
1. 문제와 관점
2. 역사적 맥락 재구성
3. 작가/작품 위치 설정
4. 문학 현상 분석
5. 문학사적 의의
6. 결론
```

### 비교문학 논문
```
1. 비교 가능성 논증
2. 영향 연구/평행 연구/문명 간 연구
3. 구체적 비교 (주제, 이미지, 문체)
4. 이론적 심화
5. 결론
```

## 작성 요점

### 텍스트 정밀 독해
- **언어 층위**: 수사, 리듬, 상징, 상호텍스트성
- **구조 층위**: 서사 시점, 시간 처리, 공간 구축
- **심층 층위**: 이데올로기, 문화적 기억, 주체 형성

### 이론 활용
- "이론 + 예시"의 단순 대입을 피할 것
- 이론은 텍스트 해석에 봉사해야 함
- 이론과의 대화, 수정, 도전 가능
- 중서 이론 결합 시 자각적 접근 필요

### 문헌 검토
- 연구사 정리 (누가, 언제, 어떤 견해)
- 미해결 문제나 맹점 지적
- 자기 위치 설명 (발전/수정/반박)

### 논증 방식
- 점진식: 표면에서 내면으로, 작은 것에서 큰 것으로
- 대비식: 병렬 대조를 통한 특질 부각
- 역사식: 통시적 정리, 공시적 위치 설정

## 흔한 오류
1. **과도한 해석**: 텍스트를 이탈한 지나친 발휘
2. **이론 선행**: 이론으로 텍스트를 재단
3. **감상식 비평**: 분석 없이 느낌만 존재
4. **사료 나열**: 문제의식 결여
5. **개념 모호**: 핵심 용어 미정의

## 도구 추천
- **고전**: 중국기본고적고, 아이루성, 한적 전문
- **현대문학**: 중국현대문학관, CNKI
- **외국어**: JSTOR, Project MUSE, MLA International Bibliography
- **이론**: Stanford Encyclopedia of Philosophy
- **작성**: Word (문학 분야에서 일반적)

## 투고 조언
- **최상위 학술지**:『문학평론(文学评论)』,『문예연구(文艺研究)』,『중국사회과학(中国社会科学)』
- **전문 학술지**: 시대/분야에 따라 선택
- **이론 학술지**:『문예이론연구(文艺理论研究)』,『문화와시학(文化与诗学)』
- **해외 학술지**: Modern Chinese Literature and Culture

## 중복 검사 주의사항
- 고시 인용은 중복에 포함되지 않음 (단, 판본 표기 필요)
- 이론가 견해 인용은 개작 필요
- 작품 줄거리 요약은 자기 언어로
- 연구사 부분이 가장 중복되기 쉬움, 재구성 필요
- 대량 인용 지양 (표기하더라도)
