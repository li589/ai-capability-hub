# 경영학/경영관리 논문 작성 가이드

## 학과 특징
- 이론적 틀, 실증 검증, 관리적 시사점 강조
- 데이터 출처, 변수 측정, 내생성 처리 중시
- 학술지 논문 위주 (최상위 학술지: AMJ/SMJ/JOM/OS/MS)
- 사례 연구 환영 (이론 구축/검증)

## 연구 유형

### 1. 사례 연구
- **적용**: 신현상 탐색, 이론 구축, 복잡한 과정
- **유형**:
  - 단일 사례 (극단적/전형적/종단)
  - 다중 사례 (복제/대비/보완)
- **설계 요점**:
  - 사례 선택 (이론적 표본추출, 비무작위)
  - 데이터 수집 (면담/기록/관찰/다중 출처)
  - 분석 전략 (패턴 매칭/해석 구축/시계열)
  - 신뢰도 확보 (삼각 검증/구성원 검토/감사 추적)
- **보고 규범**:
  - 배경 묘사가 풍부할 것 (맥락화)
  - 증거 사슬이 명확할 것 (데이터→도표→결론)
  - 문헌과의 대화 (확인/확장/도전)

### 2. 조사 연구
- **적용**: 대표본 가설 검증, 변수 관계
- **유형**: 횡단면/종단/패널
- **설계 요점**:
  - 표본 틀 (목표 모집단 접근성)
  - 설문지 설계 (기존 척도+자체 문항)
  - 데이터 수집 (온라인/종이/혼합)
  - 공통방법 편향 (Harman 단일요인/절차 통제)
- **분석 방법**:
  - 구조방정식 모형 (SEM): AMOS/PLS/Mplus
  - 다층 선형 모형 (HLM): 교차 수준 데이터
  - 잠재성장 모형 (LGM): 종단 추적

### 3. 실험 연구
- **적용**: 인과관계, 행동 메커니즘
- **유형**: 실험실/현장/준실험/자연실험
- **설계 요점**:
  - 무작위 배정 (진짜 무작위/쌍별 무작위)
  - 조작 검사 (독립변수가 효과적으로 조작되었는지)
  - 종속변수 측정 (객관/주관/행동)
  - 통제변수 (교란요인 배제)
- **분석 방법**:
  - ANOVA/ANCOVA: 집단 간 비교
  - 매개/조절: PROCESS 매크로
  - 다수준: HLM

### 4. 2차 데이터 분석
- **적용**: 거시 연구, 패널 데이터, 사건 연구
- **데이터 출처**:
  - 상장기업: CSMAR, Wind, 국태안(国泰安)
  - 특허 데이터: 중국 국가지식재산권국, Derwent
  - 채용 데이터: 즈롄자오파오(智联招聘), 첸청우요우(前程无忧)
  - 소셜 미디어: 웨이보, 즈후, 마이마이 (크롤링)
- **분석 방법**:
  - 패널 데이터 모형: 고정효과/확률효과/GMM
  - DID/PSM: 인과 추론
  - 사건 연구: CAR 계산
  - 텍스트 분석: 단어 빈도, 토픽 모형, 감정 분석

## 이론적 틀

### 주요 이론
- **자원기반관 (RBV)**: VRIN 자원→경쟁우위
- **제도이론**: 규범/인지 제도 압력
- **대리인이론**: 위임-대리 충돌→지배구조 메커니즘
- **이해관계자 이론**: 다주체 균형
- **역량 이론**: 감지/포착/재구성
- **조직 학습**: 탐색/활용, 지식 전환 (SECI)
- **고위이론**: 경영진 특성→전략 선택→조직 결과
- **사회 네트워크**: 구조적 공백/중심성/내포성
- **신호이론**: 신호 전송→신호 해석→결과
- **정당성 이론**: 실용적/도덕적/인지적 정당성

### 이론 사용 조언
1. **이론 나열 금지**: 1-2개 핵심 이론이면 충분
2. **이론 관점 명확화**: 무엇을 설명하고, 무엇을 예측하는지
3. **이론과 가설 연결**: 각 가설에 이론적 근거 필요
4. **이론 대화**: 결과가 이론적 예측과 일치/모순/확장하는지

## 데이터 출처와 측정

### 설문지 설계
- **척도 출처**: 기존 척도 우선 사용 (타당도 검증 완료)
- **번역 역번역**: 영어 척도→한국어→역번역→비교
- **문항 수**: 구성개념당 3-7문항 (피로도 방지)
- **역채점**: 2-3문항 혼입 (기본 반응 방지)
- **예비 조사**: 30-50명, CITC<0.4 삭제

### 주요 데이터베이스
- **CSMAR**: 상장기업 재무, 지배구조, 지분
- **Wind**: 금융, 거시, 산업
- **국태안(国泰安)**: 경제금융, 지역경제
- **CEIC**: 거시경제, 산업 데이터
- **세계은행**: 국가 간 비교, 발전 지표
- **중국가족추적조사 (CFPS)**: 미시적 개인
- **중국건강및노후추적조사 (CHARLS)**: 고령화

### 변수 측정
- **독립변수**: 명확한 조작화 정의
- **종속변수**: 다차원 측정 (객관+주관)
- **매개변수**: 메커니즘 설명
- **조절변수**: 경계 조건
- **통제변수**: 대안 설명 배제

## 분석 방법

### 구조방정식 모형 (SEM)
- **CB-SEM (AMOS/Mplus)**:
  - 대표본 (>200)
  - 확인적 분석
  - 엄격한 모형 적합 (CFI>0.9, RMSEA<0.08, SRMR<0.08)
- **PLS-SEM (SmartPLS)**:
  - 소표본 허용
  - 탐색적 분석
  - 예측 지향 (PLSpredict)

### 다층 선형 모형 (HLM)
- **적용**: 중첩 데이터 (직원→팀→조직)
- **소프트웨어**: HLM, Mplus, R (lme4)
- **보고**: ICC(1), ICC(2), rwg, 교차수준 효과

### 질적 비교 분석 (QCA)
- **적용**: 인과 복잡성, 다요인 조합
- **유형**: crisp-set / fuzzy-set / mvQCA
- **소프트웨어**: fsQCA, R (QCA 패키지)
- **보고**: 진리표, 일치도, 커버리지, 중간해

### 내생성 처리
- **출처**: 누락 변수, 역인과, 측정 오차, 표본 선택
- **방법**:
  - 도구변수 (IV): 2SLS
  - 이중차분 (DID): 정책 충격
  - 성향점수매칭 (PSM): 표본 매칭
  - 단절회귀 (RDD): 임계값 부근
  - Heckman 모형: 표본 선택

## 논문 구조 템플릿

### 실증 연구 (양적)
```
1. 서론
   - 현실 배경 (관리 현상)
   - 이론적 공백 (문헌 대화)
   - 연구 문제
   - 이론적 기여
   - 실천적 의의

2. 문헌 검토와 가설
   - 핵심 구성개념 정의
   - 주효과 문헌 (A→B)
   - 매개 메커니즘 (A→M→B)
   - 조절 경계 (W가 A→B에 미치는 영향)
   - 가설 요약표

3. 연구 설계
   - 표본과 절차
   - 변수 측정 (척도 출처+신뢰도)
   - 분석 전략
   - 공통방법 편향 통제

4. 결과
   - 기술통계+상관행렬
   - 측정 모형 (CFA/타당도)
   - 구조 모형 (경로계수+유의성)
   - 매개효과 (Bootstrap)
   - 조절효과 (교호작용항/단순기울기)
   - 강건성 검증 (대체 측정/부표본)

5. 논의
   - 가설 검증 요약
   - 이론적 기여 (대화)
   - 관리적 시사점 (실행 가능)
   - 한계 (표본/방법/인과)
   - 향후 연구 (구체적 방향)
```

### 사례 연구 (질적)
```
1. 서론: 현상→문제→방법→기여
2. 문헌 검토: 이론적 관점→공백→틀
3. 방법:
   - 사례 선택 (이론적 표본추출 논리)
   - 데이터 수집 (다중 출처 증거 행렬)
   - 데이터 분석 (코딩 전략)
   - 신뢰도 확보 (삼각 검증 등)
4. 사례 서술: 배경→과정→핵심 사건
5. 교차 사례 분석: 패턴→명제→이론
6. 논의: 기여→시사점→한계→향후
```

## 흔한 오류
1. 이론적 틀 취약 (가설에 이론적 근거 부재)
2. 내생성 무시 (인과 추론 불신)
3. 공통방법 편향 (동일 출처 데이터 미처리)
4. 척도 임의 수정 (타당도 훼손)
5. 매개효과 해석 오류 (완전매개≠매개)
6. 조절효과 그래프 오류 (단순기울기 방향)
7. 표본 선택 편향 (편의 표본추출 일반화)
8. 과도한 통제변수 (매개/조절변수 통제)
9. 결과 선택적 보고 (유의한 결과만 보고)
10. 관리적 시사점 공허 (실행 가능성 결여)
