# 심리학 논문 작성 가이드

## 학과 특징
- 실험 설계, 통계적 엄밀성, 이론 검증을 중시
- 윤리 심사, 사전 동의, 동물 복지를 중요시
- 저널 논문 위주 (최고급 저널: Psychological Science/JPSP/JEP/Developmental Psychology)
- 사전 등록(Preregistration)이 점점 더 중요해짐
- 오픈 사이언스(Open Science) 추세: 데이터/코드/자료 공유

## 연구 유형

### 1. 실험 심리학
- **적용**: 인과 관계, 인지 메커니즘, 행동 실험
- **설계 유형**:
  - 피험자간 설계 (Between-subjects): 다른 피험자가 다른 처치를 받음
  - 피험자내 설계 (Within-subjects): 동일한 피험자가 모든 처치를 받음
  - 혼합 설계 (Mixed): 피험자간 및 피험자내 변수 모두 포함
- **핵심 요소**:
  - 독립변수 조작 (명확하고, 효과적이고, 재현 가능)
  - 종속변수 측정 (반응시간, 정답률, 안구추적, ERP, fMRI)
  - 교란 요인 통제 (무작위화, 균형, 마스킹)
  - 검정력 분석 (G*Power: f=0.25 중간 효과, α=0.05, 1-β=0.80)
- **보고 규범**:
  - 가설 사전 등록 (OSF, AsPredicted)
  - 실험 절차 완전한 기술 (재현 가능)
  - 제외 기준 투명하게 공개 (예: 반응시간 <200ms)
  - 베이지안 분석 보완 (BF10)

### 2. 발달 심리학
- **적용**: 평생 발달, 연령 차이, 종단 추적
- **설계 유형**:
  - 횡단 설계: 다른 연령 집단을 동시에 측정
  - 종단 설계: 동일 집단을 여러 번 측정
  - 순차 설계: 횡단+종단 결합
- **핵심 요소**:
  - 연령 분류 (이론 기반: 예: 피아제 단계)
  - 측정 동등성 (다른 연령 도구 간 비교 가능성)
  - 탈락 처리 (MAR/MCAR 검정, 다중 대체)
  - 코호트 효과 (시대적 배경 차이)
- **특별 고려사항**:
  - 아동 윤리: 부모 동의+아동 동의 (7세 이상)
  - 발달 적합성: 과제 난이도, 주의력 유지
  - 사회적 바람직성: 아동은 더 쉽게迎合하는 경향

### 3. 사회 심리학
- **적용**: 사회 인지, 태도, 집단 과정, 대인 관계
- **常用 방법**:
  - 설문법: 척도 측정 (리커트 5/7점)
  - 실험법: 상황 조작 (예: 아쉬 동조 실험 변형)
  - 현장 실험: 자연 상황 중재
  - 기록 분석: 역사적 데이터, 미디어 내용
- **핵심 요소**:
  - 사회적 바람직성 편향 통제 (익명, 간접 측정, IAT)
  - 표본 대표성 (WEIRD 문제: 서구, 교육받은, 산업화, 부유, 민주주의)
  - 효과 크기 관심 (소 효과 d=0.2, 중 d=0.5, 대 d=0.8)
  - 반복 실험 (직접/개념/체계적 반복)

### 4. 임상 심리학
- **적용**: 심리 장애, 중재 효과, 평가 도구
- **설계 유형**:
  - RCT: 금표준, 무작위 배정 치료군/대조군
  - 단일 피험자 실험: ABA/다중 기준선 설계
  - 준실험: 자연 분류, 전후 측정
- **핵심 요소**:
  - 진단 기준 (DSM-5/ICD-11)
  - 중재 계획 (매뉴얼화, 충실도 검사)
  - 결과 지표 (증상, 기능, 삶의 질)
  - 탈락 처리 (ITT/PP 분석)
- **윤리 특이사항**:
  - 취약 집단 보호 (환자, 아동, 노인)
  - 최소 위험 원칙
  - 데이터 비밀 보장 (HIPAA/사이버보안법)

## 실험 설계

### 피험자간 vs 피험자내
| 차원 | 피험자간 | 피험자내 |
|------|--------|--------|
| 장점 | 순서 효과 없음, 연습 효과 없음 | 개인차 통제, 통계적 검정력 높음 |
| 단점 | 더 많은 피험자 필요, 개인차混淆 | 순서 효과, 연습 효과, 피로 |
| 적용 | 다른 처치가永久적 영향 | 처치可逆, 높은 통계적 검정력 필요 |
| 표본 크기 | 각 집단≥30 (대 효과) | 총 표본≥20 (대 효과) |

### 준실험 설계
- **불균등 집단 전후 측정**: 무작위 분류 없음, 통계적 통제 필요
- **중단 시계열**:多次 관찰, 중재 전후 비교
- **회귀 불연속**: 연속 변수의 임계값 기반 분류
- **비동등 대조군**: 무작위가 아닌 매칭

### 통계적 검정력
- **계산 도구**: G*Power, pwr 패키지, WebPower
- **모수**:
  - 효과 크기 (d=0.2 소/0.5 중/0.8 대; f=0.1 소/0.25 중/0.4 대)
  - α 수준 (0.05 또는 0.01)
  - 통계적 검정력 (1-β=0.80 또는 0.90)
  - 검정 유형 (양측/단측)
- **제안**:
  - 소 효과: 각 집단≥64 (검정력 0.80)
  - 중 효과: 각 집단≥26
  - 대 효과: 각 집단≥16

## 통계 방법

### 기초 분석
- **t검정**: 두 집단 비교 (독립/대응)
- **분산분석 (ANOVA)**: 다수 집단 비교
  - 단일 요인: 하나의 독립변수
  - 다중 요인:多个 독립변수+상호작용 효과
  - 반복 측정: 피험자내 변수
  - MANOVA:多个 종속변수
- **카이제곱검정**: 범주형 변수 연관성
- **상관 분석**: Pearson/Spearman

### 고급 분석
- **회귀 분석**:
  - 선형 회귀: 연속 예측→연속 결과
  - 로지스틱 회귀: 범주형 결과
  - 포아송 회귀: 카운트 결과
  - 다층 회귀: 중첩 데이터 (피험자→반→학교)
- **구조방정식모형 (SEM)**:
  - 확인적 요인분석 (CFA): 측정 모형
  - 경로 분석: 구조 모형
  - 다집단 비교: 측정 동등성 (configural/metric/scalar)
- **다층 선형 모형 (HLM/MLM)**:
  - 무작위 절편/기울기 모형
  - 교차 수준 상호작용
  - 3수준 이상 중첩
- **잠재성장모형 (LGM)**:
  - 선형/비선형 성장
  - 성장 예측 변수
  - 병렬 과정 모형
- **생존 분석**: 사건 발생 시간

### 효과 크기 보고
- **Cohen's d**: 두 집단 평균차 (소 0.2/중 0.5/대 0.8)
- **η² (eta-squared)**: 분산 설명 비율 (소 0.01/중 0.06/대 0.14)
- **ω² (omega-squared)**: 편향 없는 추정량
- **r²**: 결정 계수
- **Odds Ratio (OR)**: 로지스틱 회귀
- **신뢰구간**: 95% CI가 P값보다 더 중요

## 척도 사용

###常用 척도 출처
- **APA PsycTests**: 공식 심리검사 데이터베이스
- **Mental Measurements Yearbook**: 검사 평가
- **저널 부록**: 원래 논문에完整한 척도 첨부
- **매뉴얼**: 예: BFI Big Five 인격 매뉴얼

### 번역-역번역 절차
1. 영어→한국어 (이중언어자 번역)
2. 한국어→영어 (독립적 이중언어자 역번역)
3. 원문과 역번역 버전 비교
4. 전문가위원회 차이점讨论
5. 사전 테스트 (30-50명)
6. 신뢰도 및 타당도 검증

### 신뢰도 및 타당도 요구사항
- **신뢰도**:
  - Cronbach's α ≥ 0.70 (수용 가능)
  - 반분 신뢰도 ≥ 0.70
  - 재검사 신뢰도 (2-4주 간격) r ≥ 0.70
- **타당도**:
  - 내용 타당도: 전문가 평정
  - 구인 타당도: EFA/CFA, 요인 적재량 ≥0.50
  - 준거 타당도: 외부 기준과 상관
  - 변별 타당도: AVE>상관계수²

## 윤리 요구사항

### APA 윤리 원칙 (5가지 원칙)
1. **이익과 무해**: 이익最大化, 해最小化
2. **충성과 책임**: 전문적 기준, 사회적 책임
3. **정직**: 성실, 정확, 사기 없음
4. **공정**: 공평한 대우, 편향 회피
5. **존중**: 자율성, 프라이버시, 존엄

### 사전 동의 (Informed Consent)
- **필수 요소**: 연구 목적, 절차, 위험, 이익, 비밀 보장, 자발성, 연락처
- **특별 집단**:
  - 아동: 부모 동의+아동 동의 (7세 이상)
  - 인지 장애: 법정 대리인
  - 수감자: 추가 보호
- **속임수 연구**: 사후 설명 (debriefing)

### 동물 실험 윤리
- **3R 원칙**: 대체 (Replacement), 감소 (Reduction), 개선 (Refinement)
- **IACUC 심사**: 계획서 승인, 수의사 감독
- **사육 조건**: 환경丰富化, 사회적需求
- **종료점 설정**: 인도적 종료점, 안락사 기준

1. 서론
   - 이론적 배경 (핵심 개념)

   - 피험자 (모집, 선별, 표본 크기, 보상)

   - 자극/소재 (출처, 개발, 사전 테스트)
   - 절차 (단계, 무작위화, 마스킹)
   - 데이터 분석 계획 (사전 등록 링크)

3. 결과
   - 기술 통계 (M, SD, n)
   - 조작 검사 (독립변수 효과적)
   - 가설 검정 (ANOVA 표, 효과 크기, CI)
   - 추가 분석 (탐색적, 베이지안)
   - 그림/표 (평균 그래프, 상호작용 그래프)

4. 고찰
   - 가설 검증 요약
   - 이론적 설명 (메커니즘)
   - 선행 연구와의 비교
   - 한계점 (표본, 방법, 일반화)
   - 향후 연구 방향 (구체적 가설)
   - 결론 (간결하게)

5. 보충 자료 (온라인)
   -完整한 설문/자극
   - 원시 데이터 (OSF)
   - 분석 코드 (R/Python)

## 오픈 사이언스 실천

### 사전 등록
- **플랫폼**: OSF, AsPredicted, ClinicalTrials.gov
- **내용**: 가설, 설계, 표본 크기, 분석 계획
- **유형**:
  - 표준 사전 등록: 데이터 수집 전
  - 등록 보고서: 저널이发表 약속 (결과 무관)
- **이점**: HARKing 방지 (가설 후置), 신뢰도 향상

### 데이터 공유
- **플랫폼**: OSF, Figshare, Zenodo, GitHub
- **내용**:
  - 원시 데이터 (비식별화)
  - 분석 코드 (재현 가능)
  - 연구 자료 (설문, 자극)
- **라이선스**: CC0 (추천), CC-BY

### 코드 공유
- **요구사항**: 실행 가능, 주석 포함, README 포함
- **도구**: R Markdown, Jupyter Notebook
- **버전 관리**: Git/GitHub

## 흔한 오류
1. 표본 크기 부족 (검정력 <0.80)
2. 다중비교 미보정 (Bonferroni/FDR)
3. 피험자내 설계에 순서 통제 없음 (라틴방/무작위)
4. 효과 크기 미보고 (P값만 보고)
5. 사후 가설 (HARKing)
6. 공통방법 편향 (동일 출처 데이터)
7. 척도 신뢰도 낮음 (α<0.70인데仍 사용)
8. 인과 관계 과도 추론 (상관 설계)
9. 문화 차이 무시 (WEIRD 표본)
10. 윤리 설명 누락 (심사 통과 불가)
