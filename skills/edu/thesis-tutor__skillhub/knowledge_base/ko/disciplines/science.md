# 이과학 논문 작성 가이드

## 학과 특징
- 실험 검증, 수학적 유도, 이론 혁신을 강조
- 데이터 정확성, 재현성, 동료 심사를 중시
- 학술지 논문과 학회 논문을 모두 중시
- 그림·표 품질 요구사항이 높음 (데이터 그래프, 공식, 실험 장치 도면)

## 연구 유형

### 1. 실험 연구
- **적용 분야**: 물리, 화학, 생물 실험
- **핵심 요소**:
  - 실험 설계 (변수 통제, 반복 실험)
  - 데이터 수집 (기기 정밀도, 오차 분석)
  - 결과 분석 (통계 검정, 불확실성)
- **논문 구조**: 목적→방법→실험→결과→분석

### 2. 이론 연구
- **적용 분야**: 수학, 이론물리, 이론화학
- **핵심 요소**:
  - 문제 제기 (추측, 가설)
  - 이론적 유도 (증명, 계산)
  - 결과 토론 (의의, 응용)
- **논문 구조**: 문제→예비→주요 결과→증명→토론

### 3. 계산 연구
- **적용 분야**: 계산물리, 계산화학, 생물정보학
- **핵심 요소**:
  - 모델 구축 (알고리즘, 수치 해석법)
  - 프로그램 구현 (코드, 검증)
  - 결과 분석 (수렴성, 정밀도)
- **논문 구조**: 문제→방법→구현→결과→토론

## 학과 세부 분야

### 수학
- **순수수학**: 대수학, 기하학, 해석학, 정수론
- **응용수학**: 확률통계, 운영연구, 계산수학
- **수학교육**: 교수법, 교육과정 설계

### 물리학
- **응집 물질 물리**: 재료, 초전도체, 반도체
- **입자 물리**: 고에너지 물리, 핵물리
- **광학**: 레이저, 광섬유, 광전자
- **천체물리**: 우주론, 은하, 블랙홀

### 화학
- **유기화학**: 합성, 반응 메커니즘
- **무기화학**: 배위화학, 재료화학
- **분석화학**: 기기 분석, 분광학
- **물리화학**: 열역학, 반응 속도론

### 생물학
- **분자생물학**: 유전자, 단백질
- **세포생물학**: 세포 신호, 세포 주기
- **생태학**: 개체군, 군락, 생태계
- **생물정보학**: 서열 분석, 구조 예측

## 논문 구조 템플릿

### 실험 연구형
`
1. 서론 (연구 배경, 문제, 목적)
2. 실험 부분 (재료, 방법, 기기)
3. 결과 및 토론 (데이터, 분석, 비교)
4. 결론 (발견, 의의, 전망)
`

### 이론 연구형
`
1. 서론 (문제 배경, 문헌 고찰)
2. 예비 지식 (정의, 보조정리)
3. 주요 결과 (정리, 증명)
4. 토론 (응용, 일반화)
5. 결론 (기여, 전망)
`

## 작성 요점

### 실험 기술
- 재현 가능하도록 상세하게 기술
- 모든 매개변수 포함
- 기기 모델명 기재
- 시약 출처 명시

### 데이터 제시
- 유효숫자 사용
- 오차 범위 보고
- 단위 표기
- 그림·표가 명확하고 규범적

### 공식 편집
- 수식 편집기 사용
- 기호 체계 통일
- 번호 연속 부여
- 각 기호 설명

## 일반적인 문제점

1. **실험 부족**: 반복 횟수 부족, 대조군 결여
2. **데이터 처리 부적절**: 통계 방법 오류, 오차 분석 부족
3. **문헌 고찰 부실**: 최신 연구 동향 부족, 고찰 불충분
4. **토론 미흡**: 결과 나열에 그침, 심층 분석 부족
5. **작성 비규범적**: 용어 불일치, 서식 혼란
