# 고고학 논문 작성 가이드

## 학문 특성
- 발굴 조사, 실물 연구, 역사 복원을 강조
- 층위학, 유형학, 과학 고고학을 중시
- 연구 주기가 긺 (발굴, 정리, 연구)
- 학제적 특성이 뚜렷함 (역사, 지질, 생물, 화학)

## 연구 유형

### 1. 발굴 보고서
- **적용 분야**: 유적 발굴, 조사 보고
- **핵심 요소**:
  - 층위 기술 (토질, 토색, 포함물)
  - 유적 기술 (환호, 주거지, 묘葬)
  - 유물 기술 (토기, 석기, 골기)
- **논문 구조**: 개요→층위→유적→유물→편년→결어

### 2. 전제 연구
- **적용 분야**: 기물 연구, 문화 연구, 연대학
- **핵심 요소**:
  - 자료 수집 (고고 자료, 문헌)
  - 유형학 분석 (형식 분류, 변천 계열)
  - 문화 해석 (기능, 의의, 교류)
- **논문 구조**: 서론→자료→분석→고찰→결론

### 3. 과학 고고학
- **적용 분야**: 연대 측정, 성분 분석, 잔류물 분석
- **핵심 요소**:
  - 시료 채취 (대표성, 보존 상태)
  - 분석 방법 (C14, 열발광, XRF)
  - 데이터 해석 (연대, 산지, 기술)
- **논문 구조**: 배경→시료→방법→결과→고찰

## 세부 전공

### 선사 고고학
- **구석기 시대**: 인류 기원, 석기 기술
- **신석기 시대**: 농업 기원, 문명 기원
- **청동기 시대**: 국가 형성, 초기 문명

### 역사 고고학
- **하상주 고고학**: 도성, 청동기, 갑골문
- **진한 고고학**: 제릉, 간독, 실크로드
- **위진남북조 고고학**: 묘葬, 불교 유적
- **수당송원 고고학**: 도시, 자기, 대외 교류

### 전문 고고학
- **환경 고고학**: 고환경, 고기후, 인지 관계
- **동물 고고학**: 동물 뼈, 가축화, 제사
- **식물 고고학**: 식물 유존, 농업, 식단
- **야금 고고학**: 광야 유적, 금속기, 기술

## 논문 구조 템플릿

### 발굴 보고형
```
1. 개요 (지리적 위치, 발굴 경과)
2. 층위 적층 (층위 관계, 편년 근거)
3. 유적 (환호, 주거지, 묘葬 등)
4. 유물 (토기, 석기, 골기 등)
5. 편년 및 연대 (문화 계열, 절대 연대)
6. 결어 (주요 수확, 학술적 의의)
```

### 전제 연구형
```
1. 서론 (연구사, 목적, 방법)
2. 자료 (출처, 수량, 상태)
3. 분석 (유형학, 통계, 비교)
4. 고찰 (기능, 의의, 교류)
5. 결론 (주요 견해, 학술적 기여)
```

## 작성 요점

### 현장 기록
- 층위 관계도
- 유적 평단면도
- 유물 선도
- 사진 기록

### 유형학 분석
- 형식 분류 기준
- 변천 계열
- 전형적 기물
- 비교 자료

### 연대학
- 층위 근거
- 기물 유형
- 연대 측정 데이터
- 문헌 기록

## 흔한 실수

1. **층위 기술 불명확**: 토질, 토색, 포함물이 상세하지 않음
2. **유형학 불규범**: 형식 분류 기준이 통일되지 않음
3. **연대 판단 자의적**: 다중 증거 부재
4. **문화 해석 공허**: 심층 분석 부재
5. **도판 품질 불량**: 사진 흐릿, 선도 불규범

## 유사도 검사 주의사항

- 문화 해석은 심층적 고찰이 필요
