# 농학 논문 작성 가이드

## 학문 특성
- 실용 응용, 포장 실험, 수량 증대를 강조
- 실험 설계, 통계 분석, 보급 응용을 중시
- 연구 주기가 긺 (작물 생장 주기)
- 지역성이 강함 (기후, 토양 차이)

## 연구 유형

### 1. 포장 실험
- **적용 분야**: 작물 재배, 품종 육종, 식물 보호
- **핵심 요소**:
  - 실험 설계 (난괴법, 분할구 설계)
  - 데이터 수집 (수량, 품질, 저항성)
  - 통계 분석 (분산 분석, 다중 비교)
- **논문 구조**: 목적→재료→방법→결과→고찰

### 2. 실험실 연구
- **적용 분야**: 분자생물학, 생리생화학, 토양 분석
- **핵심 요소**:
  - 실험 방법 (추출, 검출, 분석)
  - 데이터 처리 (통계 검정, 차트)
  - 결과 검증 (반복, 대조)
- **논문 구조**: 서론→재료→방법→결과→고찰

### 3. 조사 연구
- **적용 분야**: 농업 경제, 농촌 발전, 농업 정책
- **핵심 요소**:
  - 조사 설계 (설문지, 인터뷰)
  - 데이터 수집 (표본, 표본 추출 방법)
  - 분석 방법 (기술통계, 회귀 분석)
- **논문 구조**: 배경→방법→조사→분석→결론

## 세부 전공

### 작물학
- **작물 재배**: 경작 제도, 시비 기술, 수분 관리
- **작물 유전육종**: 품종 개량, 교배 육종, 분자 육종
- **작물 생리**: 광합성, 영양 대사, 스트레스 생리

### 식물 보호
- **식물 병리**: 병해 진단, 방제 기술, 내병성 육종
- **농업 곤충학**: 해충 방제, 천적 이용, 종합 관리
- **농약학**: 약효 실험, 잔류 분석, 안전성 평가

### 원예학
- **과수학**: 품종 육종, 재배 기술, 수확 후 처리
- **채소학**: 시설 재배, 품질 관리, 안전 생산
- **화훼학**: 품종 자원, 번식 기술, 개화 조절

### 농업 자원 및 환경
- **토양학**: 토양 비옥도, 토양 개량, 토양 오염
- **농업 기상**: 기후 자원, 재해 예보, 기후 변화
- **농업 생태**: 생태 농업, 순환 농업, 지속가능한 발전

## 논문 구조 템플릿

### 포장 실험형
```
1. 서론 (연구 배경, 목적, 의의)
2. 재료 및 방법 (시험지, 재료, 설계, 측정)
3. 결과 및 분석 (수량, 품질, 저항성 등)
4. 고찰 (기작, 비교, 응용)
5. 결론 (주요 발견, 제언)
```

### 실험실 연구형
```
1. 서론 (연구 현황, 목적)
2. 재료 및 방법 (재료, 시약, 방법)
3. 결과 (데이터, 차트)
4. 고찰 (기작, 의의)
5. 결론 (기여, 전망)
```

## 작성 요점

### 포장 실험 기술
- 시험지 조건 (경위도, 해발, 기후)
- 토양 조건 (유형, 비옥도, pH)
- 실험 재료 (품종, 출처, 특성)
- 실험 설계 (처리, 반복, 구면적)

### 데이터 제시
- 수량 데이터 (kg/亩 또는 t/ha)
- 품질 지표 (단백질, 전분 등)
- 통계 분석 (F-검정, LSD, Duncan)
- 차트 규범 (오차 막대, 유의성 기호)

### 보급 가치
- 경제적 효익 분석
- 기술적 실현 가능성
- 지역 적응성
- 보급 제언

## 흔한 실수

1. **실험 설계 불량**: 대조구 부재, 반복 부족
2. **데이터 처리 부적절**: 통계 방법 오류, 유의성 기호 혼란
3. **고찰 부족**: 결과 단순 나열, 기작 분석 결여
4. **보급 가치 불명확**: 경제적 효익 분석 부재
5. **작성 불규범**: 용어 불일치, 형식 혼란
