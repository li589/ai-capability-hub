# 공과 범용 논문 작성 가이드

## 학과 특성
- 문제 해결 지향, 방안 혁신, 실험 검증 강조
- 재현성, 매개변수 완전성, 경계 조건 중시
- 학술대회 논문 + 저널 논문 병행 (최상위 학술대회: IEEE 시리즈/ACM 시리즈)
- 도표 품질 요구사항 높음 (공학 도면, 시뮬레이션 그림, 실물 사진)

## 연구 유형

### 1. 설계 연구
- **적용 대상**: 새로운 시스템/새로운 구조/새로운 알고리즘 설계
- **핵심 요소**:
  - 요구사항 분석 (기능/성능/제약)
  - 방안 설계 (아키텍처/모듈/인터페이스)
  - 타당성 검증 (이론/시뮬레이션/프로토타입)
  - 성능 평가 (비교/벤치마크 테스트)
- **논문 구조**: 문제→방안→구현→검증→토론

### 2. 실험 연구
- **적용 대상**: 물리 실험, 성능 테스트, 신뢰성 검증
- **핵심 요소**:
  - 실험 플랫폼 (장비/환경/조건)
  - 실험 설계 (변수/수준/반복)
  - 데이터 수집 (센서/샘플링 속도/정확도)
  - 결과 분석 (오차/불확실성/통계)
- **논문 구조**: 목적→방법→실험→결과→분석

### 3. 시뮬레이션 연구
- **적용 대상**: 수치 시뮬레이션, 계산 분석, 가상 검증
- **핵심 요소**:
  - 모델 구축 (기하/물리/수학)
  - 메시 분할 (유형/밀도/품질)
  - 경계 조건 (하중/제약/접촉)
  - 솔버 설정 (알고리즘/수렴/정확도)
  - 결과 검증 (실험 비교/문헌 비교)
- **논문 구조**: 문제→모델링→솔버→검증→응용

### 4. 최적화 연구
- **적용 대상**: 매개변수 최적화, 구조 최적화, 스케줄링 최적화
- **핵심 요소**:
  - 최적화 목표 (단일 목표/다중 목표)
  - 설계 변수 (연속/이산/혼합)
  - 제약 조건 (등식/부등식)
  - 최적화 알고리즘 (그래디언트/휴리스틱/메타휴리스틱)
  - 수렴성 분석 (반복 곡선/안정성)
- **논문 구조**: 문제→모델링→알고리즘→실험→비교

## 논문 구조 템플릿

### 학사 학위 논문
```
1. 서론
   - 연구 배경 (공학적 요구, 기술 현황)
   - 국내외 연구 현황 (분류별 문헌 검토)
   - 연구 목적과 의의
   - 논문 구성

2. 이론적 배경/관련 연구
   - 핵심 개념 정의
   - 기본 이론 유도
   - 기존 방법 요약 (장단점 비교표)

3. 방안 설계/방법 제안
   - 전체 아키텍처 (시스템 블록 다이어그램)
   - 상세 설계 (모듈 분해도)
   - 핵심 알고리즘 (의사코드/플로차트)
   - 혁신점 설명

4. 실험/시뮬레이션/구현
   - 실험 플랫폼/시뮬레이션 환경
   - 매개변수 설정 (전체 목록)
   - 실험 설계 (대조군 설계)
   - 구현 과정 (핵심 단계)

5. 결과와 분석
   - 주요 결과 (도표 우선)
   - 비교 분석 (기존 방법과)
   - 매개변수 민감도 분석
   - 오차/불확실성 분석
   - 토론 (메커니즘 해석)

6. 결론과 전망
   - 주요 기여 (1.2.3.)
   - 한계점
   - 향후 연구
```

### 석사/저널 논문
추가:
- 더 상세한 이론 유도
- 더 충분한 실험 검증 (다중 시나리오/다중 데이터셋)
- 더 심층적인 메커니즘 분석
- 더 광범위한 비교 (SOTA 방법)
- 복잡도 분석 (시간/공간)

## 도표 규범

### 공학 도면
- **CAD 도면**: 선형 규범 (굵은 실선/가는 실선/점선/중심선)
- **치수 기입**: 완전하고, 명확하고, 누락 없음
- **공차 조합**: 적절한 기입 (IT 등급)
- **재료 기입**: 강종, 상태, 열처리
- **기술 요구사항**: 표면 거칠기, 형상 공차

### 시뮬레이션 결과 그래프
- **클라우드 맵**: 컬러바 명확, 범위 적절, 단위 기입
- **곡선 그래프**: 축 레이블, 단위, 범례, 격자
- **벡터 그래프**: 화살표 방향, 크기 비율, 핵심 영역 확대
- **비교 그래프**: 동일 스케일, 동일 시점, 동일 매개변수

### 실물 사진
- **해상도**: 300dpi 이상
- **배경**: 간결하고, 주체를 방해하지 않음
- **기입**: 핵심 부품 표시, 치수 참조
- **다각도**: 전체+부분+세부

### 시스템 블록 다이어그램/플로차트
- **계층 명확**: 시스템 레벨→모듈 레벨→유닛 레벨
- **인터페이스 명확**: 신호 흐름, 데이터 흐름, 제어 흐름
- **표준 기호**: IEEE/GB 표준 준수
- **색상 규범**: 기능 구분 (입력/처리/출력/피드백)

## 공식과 알고리즘

### 공식 규범
- **번호**: (1), (2), (3)..., 우측 정렬
- **인용**: "공식 (3)과 같이"
- **유도**: 핵심 단계 생략 불가, 정리 인용 시 표기
- **기호**: 첫 등장 시 정의, 전문 통일
- **단위**: SI 단위, 차원 일관성

### 알고리즘 의사코드
- **형식**: 구조화, 들여쓰기, 주석
- **입력/출력**: 매개변수 명확, 반환값
- **복잡도**: 시간/공간 복잡도 기입
- **핵심 단계**: 굵게/주석 설명

```
알고리즘 1: XXX 알고리즘
입력: 매개변수1, 매개변수2, ...
출력: 결과
1. 초기화...
2. for i = 1 to n do
3.   계산...
4.   if 조건 then
5.     갱신...
6.   end if
7. end for
8. return 결과
```

## 도구 추천

### 모델링과 시뮬레이션
- **MATLAB/Simulink**: 제어, 신호, 수치 계산
- **ANSYS**: 구조, 유체, 전자기, 다중 물리장
- **SolidWorks/CATIA**: 3D 모델링, 조립, 공학 도면
- **AutoCAD**: 2D 공학 도면, 전기 도면
- **COMSOL**: 다중 물리장 커플링 시뮬레이션
- **ABAQUS**: 비선형 해석, 재료 역학

### 프로그래밍과 알고리즘
- **Python**: 데이터 분석, 기계 학습, 자동화
- **C/C++**: 고성능 계산, 실시간 시스템
- **LabVIEW**: 측정 제어 시스템, 가상 계측기
- **PLC 프로그래밍**: 산업 제어, 자동화

### 데이터 시각화
- **Origin**: 과학 그래프, 곡선 피팅
- **Tecplot**: CFD 후처리, 클라우드 맵
- **Paraview**: 오픈소스 시각화, 대규모 데이터
- **MATLAB**: 내장 그래프, 사용자 정의

## 흔한 실수
1. 매개변수 설정 불완전 (핵심 매개변수 누락)
2. 경계 조건 불명확 (결과 재현에 영향)
3. 도표 품질 나쁨 (해상도 낮음, 기입 불명확)
4. 비교 불공정 (다른 조건, 다른 데이터셋)
5. 오차 분석 누락 (불확실성 미평가)
6. 혁신점 설명 모호 (기존 방법과 비교 없음)
7. 이론 유도 점프 (핵심 단계 생략)
8. 실험 재현성 나쁨 (환경/장비 미기록)
9. 결론 과도한 일반화 (실험 조건 초과)
10. 공학 도면 비규범 (선형/기입/공차 오류)
