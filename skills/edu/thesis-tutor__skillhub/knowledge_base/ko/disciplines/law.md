# 법학 (Law) 논문 작성 가이드

## 학과 특성
- 규범 분석, 사례 연구, 비교 방법 강조
- 법률 조문, 사법 해석, 판례 중시
- 논증 논리가 치밀하고 '삼단논법' 중시

## 주제 방향

### 민법 분야
1. **계약법**
   - 전자계약 효력
   - 형식조항 규제
   - 정세변경 원칙 적용

2. **물권법**
   - 거주권 제도 시행
   - 농촌 토지 경영권
   - 담보 제도 현대화

3. **불법행위 책임**
   - 네트워크 불법행위 책임
   - 생태환경 손해
   - 자율주행 책임

### 형법 분야
- 인공지능 형사책임
- 사이버 범죄 규제
- 기업 컴플라이언스 불기소
- 경범죄 규제와 전과 소멸

### 상법/경제법
- 플랫폼 경제 독점금지
- 데이터 재산권 보호
- 증권 집단소송
- 파산 회생 제도

### 국제법
- 디지털 무역 규칙
- 국제투자 중재
- 기후변화 국제책임
- 사이버 공간 국제법

### 이론법학
- 디지털 법치 이론
- 알고리즘 거버넌스
- 법률과 인공지능
- 법전화 연구

## 논문 구조 템플릿

### 규범 분석 논문 (가장 흔함)
```
1. 서론 (문제의식, 연구 의의, 방법론)
2. 현황 서술 (규범 현황, 사법 실무, 존재 문제)
3. 비교 연구 (해외 입법, 국제조약, 시사점)
4. 이론 분석 (법리 기반, 가치 형량, 원칙 충돌)
5. 제도 설계 (구체적 제안, 조문 설계, 부대 조치)
6. 결론
```

### 실증 연구 논문
```
1. 서론
2. 연구 가설 (이론적 유도)
3. 연구 설계 (사례 선택, 데이터 출처, 변수)
4. 실증 결과 (기술 통계, 회귀 분석, 강건성)
5. 토론 (이론과의 대화, 정책 함의)
6. 결론
```

### 사례 연구 논문
```
1. 사례 선택과 의의
2. 사건 사실 정리
3. 쟁점 초점 귀납
4. 판결 이유 평석
5. 유사 사례 비교
6. 규범적 제안
```

## 작법 요점

### 법학 논증
- **삼단논법**: 대전제 (규범) → 소전제 (사실) → 결론
- **목적 해석**: 입법 목적, 체계적 해석, 역사적 해석
- **비교 방법**: 기능주의 비교 (동일 문제 해결)
- **경제 분석**: 효율, 비용편익, 유인 효과

### 문헌 인용
- **법률 조문**: 전칭 + 조항번호 (예: 《민법전》 제1165조)
- **판례**: 사건번호 + 법원 + 판결 요지
- **학설**: 학자 + 견해 + 출처
- **국제**: 조약명 + 조항 + 해석 문서

### 사례 분석
- 소송 원고, 피고, 심급
- 판결 취지 (법원 견해)
- 학리적 평석 (지지/반대/수정)
- 유사 사례 검색 (지도 사례, 공보 사례)

## 데이터 출처
- **법규**: 국가 법률법규 데이터베이스, 베이파바오
- **사례**: 중국 재판문서망, 베이파바오, 웨이커셴싱
- **학설**: CNKI, 만방, HeinOnline (영문)
- **입법 자료**: 법률 초안, 심의 보고서, 입법 설명

## 흔한 실수
1. **법률 조문 인용 오류**: 조항번호, 판본 (개정 여부)
2. **사례 시대착오**: 이미 파기되거나 새 법률로 대체
3. **비교법 오용**: 단순 이식, 제도적 배경 무시
4. **가치 판단 공허**: "불공평", "불합리" (구체적 논증 필요)
5. **실무 무시**: 순수 이론적 유도, 사법 실무와 유리

## 도구 추천
- **법규 검색**: 베이파바오, 웨이커셴싱, 법률지싱
- **사례 검색**: 중국 재판문서망, 쥐파안리, 무쑹
- **문헌 관리**: Zotero (법률 조문, 사례 유형 지원)
- **작성**: Word (법학에서 자주 사용) 또는 LaTeX
- **형식**: 《법학 인용 매뉴얼》 (2020)

## 투고 조언
- **법학 3대 저널**: 《중국법학》, 《법학연구》, 《중국사회과학》 (법학)
- **전문 저널**: 분야별 선택 (《법상연구》, 《정법논단》, 《법제와 사회발전》)
- **실무 저널**: 《인민사법》, 《법률적용》 (판사 대상)

## 중복검사 주의사항
- 법률 조문 원문은 중복검사에 포함되지 않음 (단, 표기 필요)
- 사법 해석 원문은 표기 필요
- 사례 서술은 자신의 말로 요약
- 비교법 소개 (외국법) 일정 정도의 반복은 허용
- 이론 학설 인용은 개작하고 표기
