# 컴퓨터 과학(CS) 논문 작성 가이드

## 학문 특성
- 알고리즘 혁신, 시스템 구현, 실험 검증을 강조
- 코드 오픈소스, 데이터셋, 재현성 중시
- 학회 논문 > 저널 논문 (최우수 학회: CVPR/ICML/NeurIPS/SIGCOMM/SOSP)

## 주제 선택 방향

### 인기 분야
1. **인공지능/기계학습**
   - 대형 모델 효율 최적화 (추론 가속, 모델 압축)
   - 다중 모달 학습 (시각-언어-오디오 융합)
   - AI 안전성 및 정렬 (RLHF, 레드팀 테스트)
   - 연합 학습과 프라이버시 컴퓨팅

2. **시스템 및 네트워크**
   - 클라우드 네이티브 시스템 (서버리스, 마이크로서비스)
   - 엣지 컴퓨팅과 IoT
   - 네트워크 보안 (제로 트러스트 아키텍처, 위협 탐지)
   - 분산 시스템 일관성

3. **소프트웨어 엔지니어링**
   - 코드 인텔리전스 (코드 생성, 결함 탐지)
   - DevOps와 AIOps
   - 소프트웨어 공급망 보안
   - 로우코드/노코드 플랫폼

4. **데이터 과학**
   - 시계열 데이터 분석
   - 그래프 신경망 응용
   - 데이터 거버넌스 및 품질
   - 실시간 스트림 처리

### 주제 평가 기준
- **혁신성**: 새로운 문제 또는 새로운 해결법 또는 새로운 관점
- **실현 가능성**: 6-12개월 내 완성 가능
- **가치성**: 학계 또는 산업계에서 인정
- **데이터/코드**: 공개 자원이 있는지 여부

## 논문 구조 템플릿

### 학부 졸업논문
``
1. 서론 (연구 배경, 문제 정의, 기여 요약)
2. 관련 연구 (분류별 서베이, 갭 제시)
3. 방법/시스템 설계 (아키텍처 다이어그램, 알고리즘 의사코드, 흐름도)
4. 실험/구현 (데이터셋, 지표, 비교 실험, 어블레이션 실험)
5. 결과 분석 (차트, 통계적 유의성, 케이스 스터디)
6. 논의 (한계점, 미래 연구)
7. 결론
``

### 석사 논문
추가 요소:
- 이론적 기반 (형식적 정의, 정리 증명)
- 보다 완전한 실험 (다중 데이터셋, 다중 베이스라인, 장시간 실행)
- 시스템 배포 (실제 환경 테스트, 사용자 연구)

## 작성 요점

### 알고리즘 서술
- 의사코드 사용 (실제 코드 아님)
- 시간/공간 복잡도 분석
- 수렴성 증명 (최적화 관련)

### 실험 설계
- 베이스라인 선택: 고전 방법 + SOTA (최신 기술)
- 평가 지표: 정확도/F1/지연 시간/처리량
- 유의성 검정: t-test 또는 Wilcoxon
- 어블레이션 실험: 각 구성 요소의 필요성 검증

### 차트 규범
- 벡터 이미지 사용 (PDF/SVG)
- 색맹 친화적 색상 사용
- 오차 막대 (다중 실행)
- 표는 삼선 표 형식

## 흔한 실수
1. **불충분한 실험**: 1-2개 데이터셋만 사용, 비교 실흠 부족
2. **과도한 주장**: "최초 제안", "최고 성능" (증명 필요)
3. **비재현 가능한 코드**: 환경 설정, 랜덤 시드 누락
4. **관련 연구 단순 나열**: 비판적 분석 필요
5. **서론의 공허함**: 구체적으로 어떤 문제를 해결했는지 명시

## 도구 추천
- **실험 관리**: Weights & Biases, MLflow
- **차트 작성**: Matplotlib, Seaborn, Plotly
- **코드 버전 관리**: Git + GitHub
- **논문 작성**: Overleaf (LaTeX)
- **참고문헌 관리**: Zotero + Better BibTeX

## 투고 조언
- **학회**: 마감일(deadline) 확인, 2개월 전 완성 권장
- **저널**: 심사 기간이 길어 체계적 연구에 적합
- **arXiv**: 신속한 게재로 우선권 확립

## 유사도 검사 주의사항
- 코드 조각은 유사도 검사에서 제외됨 (대부분 시스템)
- 공식 설명은 자기 말로 표현
- 알고리즘 의사코드는一定程度의 중복 허용 가능
- 실험 설정 설명은 표준화 가능
