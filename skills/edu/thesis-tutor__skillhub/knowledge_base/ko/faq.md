# 논문 작성 FAQ

## 주제 선정 단계

**Q: 지도교수님이 정해 주신 주제를 하고 싶지 않으면 어떻게 하나요?**
A:
1. 먼저 깊이 이해해 보세요. 생각과 다를 수 있습니다.
2. 대안 주제(2-3개)를 준비하고, 이유를 설명하세요.
3. 소통할 때 강조할 점: 흥미가 동기부여가 되면 성과가 더 잘 나온다는 점입니다.
4. 지도교수님이 고집하신다면, 수용 가능한지 평가하거나 지도교수 변경을 고려하세요.

**Q: 주제가 너무 크거나 너무 작은지 어떻게 판단하나요?**
A:
- 너무 큰 예: "중국 경제 발전 연구" (범위가 너무 넓음)
- 너무 작은 예: "어느 마을 어느 가구의 조사" (일반화 불가)
- 적절한 예: "디지털 금융이 농촌 주민 소비에 미치는 영향 - XX성 조사 데이터 기반"
- 검정 방법: 한 문장으로 명확하게 서술 가능한가? 6-12개월 내에 완료 가능한가?

**Q: 다른 사람이 이미 유사한 주제를 했는데, 그래도 할 수 있나요?**
A: 가능합니다. 핵심은 차별점을 찾는 것입니다:
- 다른 관점 (이론적 프레임워크가 다름)
- 다른 방법 (양적 vs 질적)
- 다른 상황 (지역/시기/집단이 다름)
- 다른 변수 (조절변수/매개변수 추가)
- 다른 데이터 (더 최신, 더 세밀한)

## 문헌 검토 단계

**Q: 문헌을 다 읽을 수 없으면 어떻게 하나요?**
A:
- 분류 독서: 먼저 초록을 읽고 정독 여부를 결정하세요.
- 리뷰 문헌: 해당 분야의 리뷰 논문을 먼저 읽어 전체 윤곽을 파악하세요.
- 핵심 파악: 기초적 논문 + 이정표 논문 + 최신 연구에 집중하세요.
- 도구 활용: Zotero로 관리하고, 태그로 분류하세요.
- 시간 제한: 매일 2-3편, 완벽주의를 버리세요.

**Q: 문헌 검토가 단순 나열이 되어버리면 어떻게 하나요?**
A:
- 저자별이 아닌 주제별로 구성하세요.
- 각 단락에는 논점이 있어야 합니다: "이러한 연구들은 보여준다..."
- 접속사를 활용하세요: However, Similarly, In contrast
- 비판적 평가: "A의 장점은...그러나 한계는..."
- Gap 식별: "...에도 불구하고 ...는 아직 해결되지 않았다"

**Q: 인용이 너무 많아 표절률이 높아질까 걱정됩니다.**
A:
- 간접 인용: 자신의 말로 요약 + 출처 표시
- 직접 인용 비율 통제 (<10%)
- 검토 부분은 자신의 프레임워크로 구성
- 장문의 인용은 피하세요

## 작성 단계

**Q: 글이 안 쓰여지고 막히면 어떻게 하나요?**
A:
- 기대치를 낮추세요: 먼저 초안을 쓰고, 나중에 수정하세요.
- 장을 바꾸세요: 쉬운 부분(방법, 데이터)부터 쓰세요.
- 정기적 집필: 매일 고정 시간에 쓰기, 습관을 만드세요.
- 구술 녹음: 먼저 말로 풀어놓고, 텍스트로 정리하세요.
- 토론: 지도교수/동료와 대화하여 아이디어를 얻으세요.
- 문헌 읽기: 관련 문헌을 다시 읽어 영감을 찾으세요.

**Q: 지도교수님이 "혁신점이 없다"고 하면 어떻게 하나요?**
A:
- 혁신 유형을 명확히 하세요: 이론/방법/소재/관점
- 기존 연구와 비교: 무엇이 다른가요?
- 논증 강화: 혁신점은 논문 전체에 관통해야 합니다. 서론에서만 한 줄 언급하는 것이 아닙니다.
- 문헌 보완: 문헌을 충분히 읽지 않아서 위치를 못 찾았을 수 있습니다.

**Q: 데이터/실험 결과가 이상적이지 않으면 어떻게 하나요?**
A:
- 먼저 확인: 데이터 처리에 오류는 없었나요?
- 솔직하게 보고: 음성 결과도 결과입니다.
- 원인 논의: 왜 결과가 이상적이지 않은가?
- 가정 수정: 가정에 문제가 있었나요?
- 보충 분석: 하위 표본, 대체 변수
- 절대 조작하지 마세요: 학술 윤리의 레드라인입니다.

**Q: 논문이 너무 형편없어서 지도교수님께 보여드리기 겁나요.**
A:
- 지도교수님은 더 형편없는 논문도 보셨습니다. 부끄러워하지 마세요.
- 일찍 보여드릴수록 문제를 일찍 발견할 수 있습니다.
- 명확한 도움 요청: "이 부분에서 막혔습니다. 조언이 필요합니다."
- 문제를 가지고 가세요: "봐주세요"가 아니라 구체적으로 질문하세요.

## 서식 및 규범

**Q: 학교 서식 요구사항이 불명확하면 어떻게 하나요?**
A:
- 학교 템플릿을 찾으세요 (대학원 웹사이트)
- 교무처 선생님에게 최신 규범을 문의하세요.
- 선배 논문을 참고하세요.
- 세부 사항에 주의: 머리글/바닥글, 페이지 번호, 그림/표 번호

**Q: 참고문헌 서식이 엉망이면 어떻게 하나요?**
A:
- 도구 사용: Zotero/EndNote로 자동 생성
- 통일된 서식: GB/T 7714-2015 (중국어) 또는 APA (영어)
- 세부 확인: 저자명, 연도, 페이지, DOI
- 원본 대조: 인용이 정확한지 확인

**Q: 그림/표는 어떻게 배치하나요?**
A:
- 그림 제목은 아래, 표 제목은 위에 둡니다.
- 번호: 그림 1-1, 표 2-1 (장-순번)
- 출처: 데이터 출처를 명시하세요.
- 선명도: 해상도가 충분하고, 글씨가 읽을 수 있어야 합니다.
- 일관성: 스타일 통일 (색상, 글꼴)

## 표절 검사 및 수정

**Q: 표절률이 기준을 초과하면 어떻게 하나요?**
A:
- 먼저 분석: 어떤 부분이 중복되는지 확인
- 전문 용어: 보존, 대체 불가
- 검토 부분: 자신의 프레임워크로 재작성
- 실험 설명: 표준화된 설명은 허용됨
- 동의어 대체: 학술적 정확성 유지
- 문장 구조 변경: 능동/수동 전환
- 그림/표화: 텍스트를 표/흐름도로 변환

**Q: AI 검출을 통과하지 못하면 어떻게 하나요?**
A:
- 자기 검토: GPTZero 등 도구로 검출
- 재작성: 개인적 목소리, 구체적 세부사항 추가
- 혼합: 자기 작성 + AI 보조 첨삭
- 표기: 학교에서 요구하면 AI 사용 범위를 설명
- 이의제기: 오류 판정이면, 작성 과정 증거를 보존

**Q: 학교 표절 검사 시스템과 자기가 검사한 결과가 다르면 어떻게 하나요?**
A:
- 학교 시스템을 기준으로 합니다.
- 시스템마다 데이터베이스가 다릅니다.
- 학교 지정 시스템으로 사전 검사하는 것을 권장합니다.
- 주의: 타오바오 표절 검사는 논문이 유출될 수 있습니다.

## 구술시험(논문 심사) 단계

**Q: 구술시험에 긴장하면 어떻게 하나요?**
A:
- 충분한 준비: 모든 부분을 숙지하세요.
- 모의 구술시험: 동료와 연습하세요.
- 강의안 준비: PPT를 읽는 것이 아니라 설명하는 것입니다.
- 심호흡: 입장 전 심호흡을 몇 번 하세요.
- 긴장 수용: 적당한 긴장은 정상입니다.

**Q: 심사위원 선생님의 질문에 답을 못하면 어떻게 하나요?**
A:
- 솔직하게 인정: "이 문제에 대해 깊이 고려하지 못했습니다."
- 답변 시도: "제 이해에 기반하면..."
- 문제 기록: 구술시험 후 연구하세요.
- 논쟁하지 마세요: 비판을 겸허히 수용하세요.
- 모르는 척하지 마세요: 선생님들은 알아보실 수 있습니다.

**Q: 구술시험 후 대폭 수정해야 하면 어떻게 하나요?**
A:
- 정상: 대부분의 논문은 수정이 필요합니다.
- 분류: 반드시 수정해야 할 것 vs 수정이 권장되는 것
- 소통: 지도교수님과 수정 범위를 확인하세요.
- 계획: 수정 일정을 수립하세요.
- 실행: 하나씩 빠짐없이 수정하세요.

## 심리 조절

**Q: 다른 사람의 논문이 좋아 보여서 불안하면 어떻게 하나요?**
A:
- 비교의 함정: 모든 사람의 속도는 다릅니다.
- 자기 집중: 완성이 완벽보다 중요합니다.
- 지원 요청: 친구/지도교수와 대화하세요.
- 과업 분해: 큰 목표를 작은 과업으로 나누세요.
- 진전 축하: 작은 목표를 완성하면 자신에게 보상하세요.

**Q: 포기하고 싶거나 연기하고 싶으면 어떻게 하나요?**
A:
- 원인 평가: 능력 문제인가, 심리 문제인가?
- 도움 요청: 지도교수, 상담센터
- 결과 고려: 연기의 영향 (취업, 심리)
- 단기 휴식: 며칠 쉬고 다시 결정
- 연기를 결정하면: 계획을 세우고, 무기한 연기하지 마세요.

**Q: 논문을 다 썼는데, 충분하지 않다고 느끼면 어떻게 하나요?**
A:
- 완성 > 완벽: 먼저 제출하고, 기회가 있으면 다시 완성하세요.
- 한계 수용: 모든 논문에는 한계가 있습니다.
- 향후 연구: 결론에서 향후 연구 방향을 서술하세요.
- 과도한 수정은 피하세요: 계속 고치면 더 나빠질 수 있습니다.

## 기타 문제

**Q: 석사/박사 논문을 인용할 수 있나요?**
A: 가능하지만, 주의하세요:
- 미공개 학위논문의 질은 들쭉날쭉합니다.
- 이미 발표된 학술지/학회논문을 우선 인용하세요.
- 인용할 경우, 학위논문임을 명시하세요.
- 인용 비율이 너무 높지 않도록 주의하세요.

**Q: 바이두백과/지후를 인용할 수 있나요?**
A: 권장하지 않습니다:
- 비학술적 출처, 신뢰도가 불확실합니다.
- 표절 검사에서 표시될 수 있습니다.
- 반드시 인용해야 한다면, 원본 학술 출처를 찾으세요.
- 웹 출처는 [EB/OL] 유형으로, 접속일을 명시하세요.

**Q: 논문에 "나"를 쓸 수 있나요?**
A: 학과에 따라 다릅니다:
- 이공계: 일반적으로 능동태/"본 논문" 사용
- 사회과학: "나" 사용 가능 (반성적 연구)
- 학교 규정 확인: 일부 학교는 명확한 규정이 있습니다.
- 일관성: 논문 전체 통일, 섞어 쓰지 마세요.

**Q: 부록에는 무엇을 넣나요?**
A:
- 설문지/인터뷰 가이드
- 원시 데이터 (해당 시)
- 코드 (해당 시)
- 보충 그림/표
- 긴 공식 유도
- 주의: 부록도 표절 검사에 포함됩니다 (일부 학교).

**Q: 감사의 글은 어떻게 쓰나요?**
A:
- 진솔하게: 상투적인 표현을 피하세요.
- 구체적으로: 구체적인 도움을 언급하세요.
- 적당히: 너무 길지 않게 (보통 1페이지)
- 확인: 중요한 사람을 빠뜨리지 마세요.
- 주의: 감사의 글은 표절 검사에 포함되지 않습니다.

## 도움 요청 채널
- **지도교수**: 최우선 선택, 정기적 소통
- **선후배**: 경험 전수
- **동료**: 상호 토론, 모의 구술시험
- **도서관**: 문헌 검색 교육
- **쓰기 센터**: 일부 학교에서 제공
- **상담센터**: 불안이 심할 때
- **인터넷**: 지후, B스테이션, 학술 공중계정

## 마지막 안내
- 논문은 인생의 일부분일 뿐입니다.
- 완성이 완벽보다 중요합니다.
- 도움을 요청하는 것은 약함이 아닙니다.
- 건강 유지 (수면, 운동, 사회활동)
- 자신이 완성할 수 있다고 믿으세요.

# 학문 분야별 FAQ

## 컴퓨터 과학

**Q: 논문에 코드를 어떻게 포함시키나요?**
A:
1. **의사코드(Pseudocode)**: 알고리즘 환경(LaTeX algorithmic/algorithm2e)을 사용하여 구문이 아닌 논리를 강조합니다.
2. **코드 조각**: 핵심 함수(<20줄), 핵심 아이디어를 설명합니다.
3. **전체 코드**: 부록이나 GitHub 링크에 넣고, 본문에서 인용합니다.
4. **서식**: 고정폭 글꼴(Courier New), 줄 번호, 구문 강조(minted/listings)
5. **주석**: 코드를 번역하는 것이 아닌, 핵심 단계를 설명합니다.
6. **오픈소스**: GitHub 링크에 README와 실행 설명을 첨부합니다.

**Q: 알고리즘 의사코드는 어떻게 작성하나요?**
A:

`
알고리즘 1: 퀵소트
입력: 배열 A, 길이 n
출력: 정렬된 배열
1.  if n <= 1 then return A
2.  pivot <- A[n/2]
3.  left <- {x in A | x < pivot}
4.  right <- {x in A | x > pivot}
5.  return QuickSort(left) + {pivot} + QuickSort(right)

핵심:
- 입력/출력이 명확할 것
- 제어 구조가 명확할 것 (들여쓰기)
- 핵심 단계에 주석 달기
- 복잡도 표기 (시간 O(n log n), 공간 O(log n))
`

**Q: 실험 재현성은 어떻게 보장하나요?**
A:

## 심리학

**Q: 척도 신뢰도는 어떻게 보고하나요?**
A:
1. **Cronbach's alpha**:
   - 보고 서식: "Cronbach's alpha = 0.85"
   - 기준: >=0.70 수용 가능, >=0.80 양호, >=0.90 우수
   - 위치: 방법 부분 또는 결과 부분 (측정 모형 앞)
2. **반분 신뢰도**:
   - 보고: "Spearman-Brown 반분 신뢰도 = 0.82"
3. **재검사 신뢰도**:
   - 보고: "4주 간격의 재검사 신뢰도 r = 0.78, P < 0.001"
4. **합성 신뢰도(CR)**:
   - SEM 보고: "합성 신뢰도 CR = 0.86, AVE = 0.55"

**Q: 효과 크기는 어떻게 산출하고 보고하나요?**
A:
1. **t검정**: Cohen's d = (M1 - M2) / SDpooled
   - 보고: "d = 0.65, 95% CI [0.32, 0.98]"
2. **분산분석**: eta-squared-p (편eta 제곱)
   - 보고: "eta-squared-p = 0.14, 95% CI [0.05, 0.25]"
3. **상관**: r (Pearson)
   - 보고: "r = 0.45, 95% CI [0.28, 0.60]"
4. **회귀**: R-squared 또는 delta-R-squared
   - 보고: "R-squared = 0.25, f-squared = 0.33"
5. **분류**: 소(0.2/0.01/0.02), 중(0.5/0.06/0.15), 대(0.8/0.14/0.35)

**Q: 실험 자료는 어떻게 부록에 넣나요?**
A:
1. **완전한 설문지**: 문항 + 선택지 + 채점 방식 (부록 A)
2. **실험 자극물**: 이미지/텍스트 자료 (부록 B 또는 온라인 보충 자료)
3. **실험 절차**: 상세 단계 (시간, 키 입력, 피드백)
4. **동의서**: 양식 (부록 C)
5. **비식별화 데이터**: OSF/Figshare 링크
6. **분석 코드**: GitHub/R Markdown

# 심리 관리 및 시간 관리 FAQ

## 집필 불안

**Q: 글이 써지지 않으면 어떻게 하나요?**
A:
1. **기준을 낮추기**: 먼저 나쁜 초안을 쓰세요. 못 쓰는 것을 허용하세요.
2. **자유 쓰기**: 15분을 설정하고, 펜을 멈추지 말고, 수정하지 말고, 삭제하지 마세요.
3. **가장 쉬운 것부터**: 방법 부분이 보통 가장 쉽습니다. 방법부터 쓰세요.
4. **과업 분할**: "오늘 서론 첫 단락만 쓴다"가 아닌 "오늘 서론을 쓴다"
5. **환경 변경**: 도서관, 카페, 좌석 변경
6. **신체 활동 선행**: 산책, 운동, 샤워 (기본 모드 네트워크 활성화)
7. **대화형 쓰기**: 동료에게 연구를 설명한다고 상상하고, 녹음 후 텍스트 변환

**Q: 완벽주의로 인한 미루기?**
A:
1. **초안 수용**: 모든 좋은 논문은 고쳐서 만들어집니다. 초안은 반드시 나쁩니다.
2. **마감 시간 설정**: "이 단락은 반드시 30분 안에 완성"
3. **수정 금지**: 초안 단계에서는 되돌아가 수정하지 않고 【수정 필요】로 표시
4. **비교 학습**: 대가의 초안을 살펴보기 (예: 「주자청 전집」 원고)
5. **정량적 목표**: "오늘 500자를 쓴다"가 아닌 "오늘 서론을 잘 쓴다"
6. **실패 허용**: 이 논문은 완벽하지 않지만, 졸업/게재에 충분하면 됩니다.

**Q: 집필 공포는 어떻게 극복하나요?**
A:
1. **노출 요법**: 매일 조금씩 쓰고, 난이도를 점차 올리기
2. **긍정적 시각화**: 완성 후의 성취감을 상상而非 과정의 어려움
3. **사회적 약속**: 동료/지도교수에게 계획을 말해 외부 압력 높이기
4. **보상 메커니즘**: 한 단락 쓸 때마다 자신에게 보상 (커피, 영상, 게임)
5. **마음챙김 집필**: 현재 문장에 집중, 전체 품질 걱정하지 않기
6. **지원 요청**: 집필 모임, 상담, 지도교수 격려

## 시간 관리

**Q: 집필 계획은 어떻게 세우나요?**
A:
1. **역산법**: 마감일로부터 역산하여 각 단계에 시간 배분
   - 예시 (3개월 완성):
     - 1-2주차: 문헌 검토 + 개요
     - 3-6주차: 초안 (매주 2장)
     - 7-8주차: 수정 + 지도교수 피드백
     - 9-10주차: 보완 + 서식 조정
     - 11-12주차: 표절 검사 + 최종 점검
2. **간트 차트**: Excel 또는 온라인 도구(예: TeamGantt)로 진행 상황 시각화
3. **버퍼 시간**: 각 단계마다 20% 버퍼 확보 (예상치 못한 상황 대비)
4. **마일스톤**: 핵심 노드 설정 (예: "3주차에 문헌 검토 완료")
5. **일일 계획**: 전날 저녁에 TODO 목록 작성 (3-5개, 완료 가능한 것)

**Q: 포모도로 기법은 어떻게 활용하나요?**
A:
1. **표준 절차**:
   - 25분 집중 집필 (핸드폰 무음, SNS 앱 닫기)
   - 5분 휴식 (물 마시기, 스트레칭, 먼 곳 보기)
   - 4개 포모도로 후 15-30분 긴 휴식
2. **조정**:
   - 집필 초기: 15분 포모도로 (적응기)
   - 집필 숙련기: 45-50분 포모도로 (몰입 상태)
3. **도구**:
   - Forest (나무 심기, 화면을 떠나면 나무가 자람)
   - 포모도로 ToDo (통계, 백색 소음)
   - 실물 포모도로 타이머 (핸드폰 의존 감소)
4. **기록**: 매일 완료한 포모도로 수, 효율 추세 추적

**Q: 시간 블록 관리법?**
A:
1. **시간 블록 구분**:
   - 오전 (9-12시): 심층 집필 (가장 어려운 부분)
   - 오후 (2-5시): 읽기, 정리, 수정
   - 저녁 (7-9시): 간단한 작업 (서식, 참고문헌)
2. **시간 블록 보호**:
   - 심층 집필 블록: 이메일 닫기, 핸드폰 무음, 문에 "방해 금지" 표시
   - 소통 블록: 이메일, WeChat 집중 회신 (예: 매일 11시, 16시)
3. **탄력적 운영**:
   - 20% 여유 시간 확보 (예상치 못한 과업 대비)
   - 주간 복기: 어떤 시간 블록의 효율이 높은지/낮은지, 다음 주 조정

**Q: 마감일이 다가오면 어떻게 하나요?**
A:
1. **우선순위 설정**:
   - 반드시 완료: 핵심 장 (서론, 방법, 결과)
   - 완료 권장: 토론, 결론
   - 간소화 가능: 문헌 검토 (압축), 감사의 글 (간략)
2. **빠른 집필 기법**:
   - 수정 모드 끄기: 다 쓴 후에 고치기
   - 음성 입력 사용: 말이 타이핑보다 빠름
   - 템플릿 집필: 우수 논문 구조를 복사하고 내용 채우기
3. **도움 요청**:
   - 동료 상호 지원: 상호 점검, 과업 분담
   - 지도교수 소통: 어려움 설명, 연기 신청 (사전 소통)
   - 전문 서비스: 서식 조정, 표절 검사/중복률 감소 (신중한 선택)
4. **건강 유지**:
   - 매일 수면 >=6시간 (효율 > 시간)
   - 2시간마다 10분 휴식 (번아웃 방지)
   - 간단한 운동: 스트레칭, 빠른 걷기, 눈 체조

## 지도교수 관계

**Q: 지도교수님이 답변을 안 주시면 어떻게 하나요?**
A:
1. **소통 방식 확인**:
   - 이메일: 제목 명확 ("논문 3장 검토 요청"), 첨부 완비
   - WeChat: 간결하고 정중, 빈번한 방해 금지 (주 1-2회)
   - 면담: 사전 약속, 문제 목록 준비
2. **시기 선택**:
   - 피해야 할 시기: 학기 초, 기말, 프로젝트 마감 전
   - 적합한 시기: 수-금요일 오전 (상대적 여유)
3. **후속 전략**:
   - 첫 연락: 3-5일 대기
   - 재연락: 정중한 알림 ("선생님, 지난 이메일이 누락되었을 수 있어 다시 보냅니다")
   - 3회차: 선배나 사무실 전화를 통해 연락
4. **내용 준비**:
   - 수정 설명 첨부: "지난 의견에 따라 X, Y, Z를 수정했습니다"
   - 구체적 문제: "논문이 어떤가요?"가 아닌 "2절의 논증이 충분한가요?"

**Q: 지도교수님과 의견이 다르면 어떻게 하나요?**
A:
1. **입장 이해**:
   - 지도교수 관점: 학술 규범, 실현 가능성, 졸업 요건
   - 학생 관점: 흥미, 혁신, 개인 발전
2. **소통 전략**:
   - 먼저 긍정: "선생님의 조언은 매우 가치있습니다..."
   - 그다음 표현: "제가 고려한 것은..."
   - 공통점 모색: "타협할 수 있을까요..."
3. **데이터로 설득**:
   - "상위 학술지 10편을 확인했는데, 모두 이렇게 했습니다..."
   - "사전 실험 결과가 보여줍니다..."
4. **현실 수용**:
   - 졸업 우선: 원칙적 문제가 아니면 타협 가능
   - 의견 보존: 감사의 글에 지도교수에게 감사, 후기에 진심 기록
   - 장기적 관점: 졸업 후 자유롭게 탐구 가능

**Q: 지도교수님에게 어떻게 도움을 요청하나요?**
A:
1. **충분한 준비**:
   - 구체적 문제: "3장의 회귀 결과가 유의하지 않습니다"가 아닌 "논문이 안 써집니다"
   - 시도한 방법: "A, B 두 가지 방법을 시도했는데, 결과는 각각..."
   - 필요 지원: "XX 병원의 협조 연락을 도와주십시오"
2. **시간 존중**:
   - 약속: "선생님, 수요일 오후에 시간 되시나요? 15분이면 됩니다"
   - 효율적: 사전 자료 발송, 면담 시 직설적 접근
   - 기록: 노트북 지참, 핵심 사항 기록, 사후 정리하여 이메일 확인
3. **피드백 폐쇄**:
   - 도움 요청 후: 1주 이내에 진행 상황 보고
   - 수정 후: 수정 부분을 표시하여 지도교수가 빠르게 확인할 수 있게
   - 감사 표현: 구두 + 서면 (이메일/WeChat)

## 동료 지원

**Q: 집필 모임은 어떻게 구성하나요?**
A:
1. **구성원 선택**:
   - 3-5명: 너무 적으면 동력 부족, 너무 많으면 조율 어려움
   - 유사 단계: "완료"와 "시작" 간의 압력 방지
   - 보완적 학문: 학제간 교류, 시야 확장
2. **운영 방식**:
   - 빈도: 주 1회,每次 2시간
   - 구조: 30분 진행 상황 보고 + 60분 상호 검토 + 30분 토론
   - 규칙: 비밀 유지, 건설적 피드백, 불참 없음
3. **온라인 도구**:
   - Tencent Meeting/Zoom: 화면 공유 토론
   - 시마 문서/Tencent 문서: 협업 주석
   - WeChat 그룹: 일상 체크인, 자료 공유

**Q: 동료에게 어떻게 피드백을 주나요?**
A:
1. **샌드위치 법칙**:
   - 먼저 긍정: "이 부분의 문헌 검토는 매우 포괄적입니다..."
   - 그다음 제안: "XX 비교를 추가하면 더 명확해질 것입니다..."
   - 마지막 격려: "전체 논리가 좋습니다. 수정 후 더 훌륭해질 것입니다"
2. **구체화**:
   - 회피: "못 썼다"
   - 대체: "2단락의 논점이 명확하지 않습니다. 전환 문장을 추가하는 것을 권합니다"
3. **우선순위**:
   - 높음: 논리적 허점, 사실 오류, 구조 문제
   - 중간: 표현 불명확, 근거 부족, 서식 문제
   - 낮음: 어구 최적화, 구두점
4. **주권 존중**:
   - 제안而非 명령: "고려해 볼 수 있습니다..."而非 "반드시..."
   - 거부 수용: 저자는某些 제안을 수용하지 않을 권리가 있음

## 건강 관리

**Q: 오래 앉아 있는危害은 어떻게 완화하나요?**
A:
1. **정기적 활동**:
   - 45분마다: 2분 서기, 스트레칭, 먼 곳 보기
   - 2시간마다: 5분 걷기, 물 받기, 화장실
   -半天마다: 15분户外活动 (산책, 일광욕)
2. **작업대 설정**:
   - 모니터: 상단이 눈높이와 일치, 거리 50-70cm
   - 의자: 허리 지지,双脚平放地面
   - 키보드: 팔꿈치 90도, 손목 자연스럽게
3. **간단한 운동**:
   - 목: 좌우 회전,前后点头 (각 방향 5회)
   - 어깨: 으쓱->이완, 어깨 돌리기 (前后 각 5회)
   - 허리: 앉은 자세 비틀기, 서서 앞으로 숙이기
   - 다리: 앉은 자세 다리 들기, 서서 발끝 들기
4. **도구辅助**:
   - 높낮이 조절 책상: 서기와 앉기 교대 (서기 30% + 앉기 70%)
   - 짐볼: 의자 대용,核心 활성화
   - 발판: 다리 꼬기 방지

**Q: 눈 건강 관리?**

2. **화면 설정**:
   - 밝기: 주변 광선과 일치, 눈부시지 않게
   - 색온도: 야간에는 청색광 감소 (f.lux/눈 보호 모드)
   - 글꼴: >=12포인트, 적절한 대비
3. **인공눈물**: 건조할 때 사용 (무보존제 타입)
4. **정기 검진**: 매년 시력 검사, 안경 도수及时 조정
5. **식단 보충**: 비타민A (당근, 시금치), 루테인 (옥수수, 노른자)

**Q: 심리 조절?**
A:

2. **이완技巧**:
   - 심호흡: 4초 들이쉬기-7초 참기-8초 내쉬기

# 기술 조작 FAQ

## Word 레이아웃 문제

**Q: 머리글/바닥글은 어떻게 설정하나요?**
A:
1. **절 설정**: 다른 장에 다른 머리글이 필요하면 "나누기 기호" 삽입 (레이아웃->구분 기호->다음 페이지)
2. **링크 해제**: 머리글 더블 클릭 -> "이전 섹션에 연결" 해제, 독립 설정 가능
3. **홀수/짝수 페이지 다름**: 머리글/바닥글 도구 -> "홀짝 페이지 다름" 체크
4. **첫 페이지 다름**: 표지 페이지에 머리글 미표시 -> "첫 페이지 다름" 체크
5. **쪽번호 서식**: 삽입->쪽번호->쪽번호 서식 설정 (시작 페이지, 번호 스타일)
6. **머리글 수평선**: 머리글 문자 선택 -> 시작->테두리->테두리 없음 (또는 Ctrl+Shift+N으로 서식 삭제)

**Q: 목차는 어떻게 자동 생성하고 업데이트하나요?**
A:
1. **제목 스타일 설정**: 제목 선택 -> 시작->제목 1/2/3 (반드시 스타일을 먼저 사용, 수동 크기 조절 불가)
2. **목차 삽입**: 인용->목차->자동 목차 1/2
3. **목차 업데이트**: 목차 우클릭->필드 업데이트->전체 목차 업데이트 (또는 F9)
4. **목차 서식**: 인용->목차->사용자 정의 목차->수정 (글꼴, 들여쓰기 조정)
5. **목차 오류 "목차 항목을 찾을 수 없음"**: 제목에 스타일이 적용되었는지 확인, 수동 서식이 아닌

**Q: 상호 참조는 어떻게 사용하나요?**
A:
1. **그림/표 참조**: 인용->상호 참조->참조 유형(그림/표)->번호 선택->삽입
2. **장 참조**: 인용->상호 참조->참조 유형(제목)->장 선택->삽입
3. **쪽번호 참조**: 인용->상호 참조->참조 내용(쪽번호)
4. **참조 업데이트**: Ctrl+A 전체 선택->F9 필드 업데이트 (또는 우클릭->필드 업데이트)
5. **코드/표시 전환**: Alt+F9 (필드 코드 보기)

**Q: 참고문헌 서식은 어떻게 조정하나요?**
A:
1. **미주 사용**: 인용->미주 삽입 (번호 서식: [1])
2. **상호 참조 사용**: 인용->상호 참조->참조 유형(미주)
3. **일괄 조정**: 찾기 및 바꾸기 (^e를 [^&]로 대체)
4. **내어쓰기**: 참고문헌 선택->단락->내어쓰기 2자
5. **간격 조정**: 단락->앞 0 뒤 0, 줄 간격 고정값 18포인트

**Q: 삼선표는 어떻게 만드나요?**
A:
1. 표 삽입 -> 표 선택 -> 표 디자인 -> 테두리 -> 테두리 없음
2. 첫 번째 행 선택 -> 테두리 -> 상단 테두리 + 하단 테두리 (1.5포인트)
3. 마지막 행 선택 -> 테두리 -> 하단 테두리 (1.5포인트)
4. 제목 행 아래에 가는 선 (0.75포인트)
5. 표 속성 -> 텍스트 줄 바꿈 -> 없음 (위치 어긋남 방지)

## 참고문헌 관리

**Q: Zotero는 Word와 어떻게 연동하나요?**
A:
1. **플러그인 설치**: Zotero->도구->플러그인->Word 플러그인 설치
2. **인용 삽입**: Word->Zotero->Add/Edit Citation->문헌 검색->Enter
3. **참고문헌 생성**: Zotero->Add/Edit Bibliography
4. **서식 전환**: Zotero->Document Preferences->서식 선택 (GB/T 7714)
5. **새로고침**: 수정 후 Refresh 클릭
6. **링크 해제**: 최종 확정 후 Unlink Citations 클릭 (필드 링크 해제, 일반 텍스트 변환)

**Q: EndNote에서 중국어 문헌이 깨지면 어떻게 하나요?**
A:
1. **내보내기 서식**: CNKI 내보내기->EndNote 서식 (.enw)
2. **인코딩 설정**: Edit->Preferences->Display Fonts->송체/UTF-8
3. **필터**: 가져올 때 올바른 Import Option 선택 (Reference Manager(RIS))
4. **수동 수정**: 문헌 더블 클릭->Author/Title 필드 수동 수정
5. **일괄 대체**: Edit->Change/Move/Copy Fields

**Q: 여러 문헌 데이터베이스를 어떻게 병합하나요?**
A:
1. **Zotero**: 파일->가져오기->다른 Zotero 라이브러리 선택 (자동 중복 제거)
2. **EndNote**: File->Import->File->.enl 파일 선택
3. **중복 제거**: Zotero->도구->중복 항목 병합; EndNote->Library->Find Duplicates
4. **태그 정리**: 가져온 후 통일된 태그로 분류
5. **백업**: 병합 전 원본 라이브러리 백업 (내보내기->Zotero RDF)

## 기타 기술 문제

**Q: 논문 그림의 해상도가 부족하면 어떻게 하나요?**
A:
1. **벡터 이미지**: PDF/EPS/EMF/SVG 우선 사용 (무한 확대 가능)
2. **비트맵**: >=300 dpi (인쇄 기준), >=150 dpi (전자판)
3. **스크린샷**: 200% 확대 후 스크린샷 (해상도 향상)
4. **소프트웨어 내보내기**: Origin/Visio->내보내기->PDF/EMF (벡터)
5. **Photoshop**: 이미지->이미지 크기->해상도 300->리샘플링

**Q: 그림 크기는 어떻게 일괄 조정하나요?**
A:
1. **Word**: 그림 선택->서식->크기->통일 높이/너비
2. **Photoshop**: 파일->자동->PDF 프레젠테이션->통일 크기
3. **Python**:

from PIL import Image

4. **온라인 도구**: iLoveIMG 일괄 조정 (프라이버시 주의)

**Q: 논문 파일이 너무 크면 어떻게 압축하나요?**
A:
1. **이미지 압축**: 그림 선택->서식->그림 압축->150ppi (인쇄)/96ppi (화면)
2. **PDF 압축**: Adobe Acrobat->파일->다른 이름으로 저장->PDF 크기 줄이기
3. **온라인 압축**: Smallpdf, iLovePDF (프라이버시 주의)
4. **분할 압축**: 논문 본문 + 부록 분리
5. **숨겨진 내용 삭제**: 파일->정보->문제점 검사->문서 검사->숨겨진 내용 삭제
