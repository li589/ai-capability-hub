# 개제 보고서 상세 가이드

## 기술 로드맵

### 1. 기술 로드맵이란?
기술 로드맵은 연구가 문제에서 해결책으로 나아가는 전체 경로를 시각화하는 도구이다. 심사 위원이 연구의 논리를 빠르게 이해할 수 있도록 도와줄 뿐만 아니라, 연구자 자신의 사고를 정리하는 데에도 도움이 된다.

### 2. 기술 로드맵 유형

**유형1: 순서도형 (실험/공학 연구에 적합)**
```
연구 문제
    |
    v
문헌 리뷰 → 이론적 프레임워크
    |
    v
연구 가설
    |
    v
실험 설계/자료 수집
    |
    v
자료 분석
    |
    v
결과 검증
    |
    v
결론 및 제언
```

**유형2: 타임라인형 (종단/발전 연구에 적합)**
```
Phase 1 (Month 1-3)    Phase 2 (Month 4-6)    Phase 3 (Month 7-9)
    |                       |                       |
    v                       v                       v
문헌 조사               자료 수집               논문 집필
이론 구축               실험 실시               수정 보완
```

**유형3: 순환 반복형 (행동 연구/설계 연구에 적합)**
```
       계획(Plan)
          |
          v
    실행(Do)
    /        \
확인(Check)  성찰(Reflect)
    \        /
      조정(Adjust)
          |
          v
      새로운 계획
```

**유형4: 가지 분기형 (다중 방법/다중 사례 연구에 적합)**
```
              핵심 문제
                 |
    +------------+------------+
    |            |            |
양적 연구     질적 연구     혼합 연구
    |            |            |
설문 조사     심층 인터뷰     삼각 검증
    |            |            |
통계 분석     주제 분석     통합 분석
```

### 3. 기술 로드맵 제작 도구

**전문 도구**：
- Visio：가장 완전한 기능, 복잡한 프로세스에 적합
- ProcessOn：온라인, 템플릿이 풍부
- Draw.io（diagrams.net）：무료, 강력한 기능
- Lucidchart：온라인 협업, 팀에 적합

**범용 도구**：
- PowerPoint：간단한 프로세스에 충분
- Word：SmartArt 기능
- LaTeX：TikZ 패키지（학술 조판에 적합）

**코드 도구**：
- Python：matplotlib, graphviz
- R：DiagrammeR, ggplot2
- Mermaid：Markdown 스타일, 문서 삽입에 적합

### 4. 기술 로드맵 설계 원칙

**명확성**：
- 각 노드에 명확한 라벨（동사+명사）
- 화살표 방향 명확（단방향, 양방향, 순환）
- 교차선 회피（계층 또는 색상 구분 사용）

**완전성**：
- 문제에서 결론까지의 완전한 체인 포함
- 핵심 노드 표시（마일스톤）
- 의사결정 지점 표시（예: "가설 검증 통과?"）

**계층성**：
- 주 프로세스：굵은 선, 큰 노드
- 하위 프로세스：가는 선, 작은 노드
- 비고：점선, 회색

**미관**：
- 통일된 색상 구성（3-5색）
- 정렬（그리드 정렬）
- 여백（과밀하지 않게）

### 5. 예시：양적 연구 기술 로드맵

```
[연구 배경]
온라인 교육이 빠르게 발전하고 있으나 학습 효과가 불균일
         |
         v
[문헌 리뷰] → 연구 공백 식별：상호작용 메커니즘에 대한 체계적 연구 부족
         |
         v
[이론적 프레임워크] → 사회적 구성주의 + 인지 부하 이론
         |
         v
[연구 가설]
H1: 교사-학생 상호작용 빈도와 학업 성취도 간 정적 상관
H2: 학생-학생 상호작용 깊이와 비판적 사고 간 정적 상관
H3: 상호작용 질이 플랫폼 기능과 학습 효과 사이에서 매개
         |
         v
[연구 설계]
  |
  +-- 실험군：신형 상호작용 플랫폼 사용（n=150）
  |
  +-- 대조군：기존 플랫폼 사용（n=150）
  |
  +-- 사전 검사：학습 동기, 선행 지식
  |
  +-- 사후 검사：학업 성취도, 비판적 사고, 만족도
         |
         v
[자료 수집]
  |
  +-- 플랫폼 로그：상호작용 빈도, 시간, 유형
  |
  +-- 설문 조사：상호작용 질 인식, 학습 경험
  |
  +-- 시험 성적：객관식+주관식
  |
  +-- 인터뷰：메커니즘 심층 이해（n=20）
         |
         v
[자료 분석]
  |
  +-- 기술 통계：표본 특성, 변수 분포
  |
  +-- 추론 통계：t-검정, 분산 분석, 회귀 분석
  |
  +-- 매개 분석：Bootstrap 방법
  |
  +-- 질적 분석：주제 코딩
         |
         v
[결과 검증]
  |
  +-- 가설 검정：H1/H2/H3 성립 여부
  |
  +-- 강건성 검정：변수 대체, 하위 표본
  |
  +-- 삼각 검증：양적+질적 결과 일치성
         |
         v
[결론 및 제언]
  |
  +-- 이론적 기여：온라인 학습 상호작용 이론 보완
  |
  +-- 실천적 제언：플랫폼 설계, 교수 전략
  |
  +-- 한계 및 향후 연구
```

## 타당성 분석

### 1. 연구 타당성 차원

**이론적 타당성**：
- 연구 문제가 이론적 근거를 갖는가?
- 이론적 프레임워크가 성숙한가?
- 연구 가설이 도출 가능한가?

**방법론적 타당성**：
- 연구 방법이 연구 문제에 적합한가?
- 자료를 확보할 수 있는가?
- 분석 기술을 보유하고 있는가?

**자원 타당성**：
- 시간：연구 주기가 합리적인가?
- 예산：추가 자금이 필요한가?
- 장비：특수 장비가 필요한가?
- 인력：협력자가 필요한가?
- 자료：자료 확보 경로가 있는가?

**개인 타당성**：
- 지식 축적：관련 이론적 기반을 갖추고 있는가?
- 기술 축적：연구 방법을 보유하고 있는가?
- 지도 교수 지원：지도 교수가 해당 분야에 익숙한가?
- 시간 투입：충분한 시간을 확보할 수 있는가?

### 2. 타당성 분석 프레임워크

```
타당성 분석

1. 이론적 타당성
   - 이론적 기반：[이론명]이 [분야]에 널리 적용되어 본 연구에 확고한 근거를 제공
   - 연구 공백：기존 연구는 주로 X에 초점을 맞추고 있으나 Y에 대한 관심이 부족하며, 본 연구는 이 공백을 메움
   - 타당성 결론：이론적 프레임워크가 성숙하고, 연구 가설이 도출 가능하며, 이론적으로 타당

2. 방법론적 타당성
   - 연구 방법：[방법명]은 [연구 문제]를 해결하는 표준 방법
   - 자료 확보：[자료 출처]가 자료 제공이 확인되었거나, [자료 수집 방식]이 실현 가능함이 검증됨
   - 분석 기술：[분석 도구]를 보유하고 있거나, [교육 과정]이 계획되어 있음
   - 타당성 결론：방법이 성숙하고, 자료를 확보할 수 있으며, 기술을 습득할 수 있어 방법적으로 타당

3. 자원 타당성
   - 시간：연구 주기 [X개월], 상세 일정이 수립되어 있음
   - 예산：[예산 출처]가 확보되어 있거나, 추가 예산 불필요
   - 장비：[장비명]을 보유하고 있거나, [장비 출처]가 확인됨
   - 인력：지도교수 [성명]이 해당 분야에 정통하며, [협력자]와 협력이 합의됨
   - 자료：[자료 확보 경로]가 확인되었거나, [조사 대상자]의 참여 동의가 확보됨
   - 타당성 결론：자원이 충분하거나 대체 방안이 마련되어 있어 자원적으로 타당

4. 개인 타당성
   - 지식 축적：[교과목명]을 수강하여 [이론적 기반]을 갖춤
   - 기술 축적：[기술]을 보유하고 있으며, [교육/과정]을 이수함
   - 지도 교수 지원：지도교수의 연구 방향이 [방향]이며 본 연구와 밀접하게 관련
   - 시간 투입：주당 [X시간] 투입 가능, 시간 관리 계획이 수립되어 있음
   - 타당성 결론：개인 조건이 연구 요건을 충족하여 개인적으로 타당

종합 결론：본 연구는 이론, 방법, 자원, 개인의 네 가지 차원에서 모두 타당성을 갖추고 있다.
```

### 3. 타당성 분석 예시

**예시：온라인 교육 상호작용 연구**

```
1. 이론적 타당성
   - 이론적 기반：사회적 구성주의（Vygotsky）와 인지 부하 이론（Sweller）이
     교육공학 연구에 널리 적용되어 본 연구에 확고한 이론적 근거를 제공함.
   - 연구 공백：기존 연구는 주로 온라인 학습 플랫폼의 기능 설계에 초점을 맞추고 있으나,
     상호작용 메커니즘이 학습 효과에 미치는 영향에 대한 체계적 연구가 부족함.
   - 타당성 결론：이론적 프레임워크가 성숙하고, 연구 가설이 도출 가능하며, 이론적으로 타당.

2. 방법론적 타당성
   - 연구 방법：준실험 설계（실험군 vs 대조군）는 인과관계를 검증하는
     표준 방법으로 본 연구 문제에 적합함.
   - 자료 확보：XX 온라인 교육 플랫폼과 협력이 체결되어 학습 로그 자료를 확보할 수 있으며;
     설문 조사는 플랫폼을 통해 배포하여 예상 회수율 70% 이상.
   - 분석 기술：SPSS와 Mplus를 보유하고 있으며, AMOS 구조방정식 모델 교육이 계획되어 있음.
   - 타당성 결론：방법이 성숙하고, 자료를 확보할 수 있으며, 기술을 습득할 수 있어 방법적으로 타당.

3. 자원 타당성
   - 시간：연구 주기 12개월（2023.9-2024.8）, 상세 일정이 수립되어 있음.
   - 예산：XX 기금 지원 확보（5만위안）, 설문, 인터뷰, 교육 비용을 충당함.
   - 장비：컴퓨터, SPSS 소프트웨어를 보유하고 있으며 추가 장비 불필요.
   - 인력：지도교수 XX교수는 교육공학 분야의 연구 방향으로 관련 논문 10여 편을 게재하였으며;
     XX대학교 교육학과와의 협력이 확정되어 대조군 학급을 제공하기로 합의함.
   - 자료：플랫폼 측의 자료 사용 계약이 체결되었고, 윤리위원회의 승인이 완료됨.
   - 타당성 결론：자원이 충분하며, 자원적으로 타당.

4. 개인 타당성
   - 지식 축적：교육심리학, 교육통계학, 교육공학을 수강하여
     탄탄한 이론적 기반을 갖춤.
   - 기술 축적：SPSS 고급 활용 교육을 이수하고 기술 통계, 추론 통계,
     회귀 분석을 보유하고 있으며 구조방정식 모델을 학습 중임.
   - 지도 교수 지원：지도교수 XX교수는 교육공학 분야의 저명한 학자로
     연구 방향이 본 연구와 밀접하게 관련되어 지도를 수락함.
   - 시간 투입：주당 20시간 투입 가능하며 상세한 시간 관리 계획이 수립되어 있음.
   - 타당성 결론：개인 조건이 연구 요건을 충족하여 개인적으로 타당.

종합 결론：본 연구는 이론, 방법, 자원, 개인의 네 가지 차원에서 모두 타당성을 갖추고 있어
계획대로 진행할 수 있다.
```

## 위험 대응 계획

### 1. 일반적인 위험 식별

**자료 위험**：
- 위험：자료 수집 곤란（회수율 저조, 표본 부족）
- 위험：자료 품질 문제（결측값 다수, 이상치 다수）
- 위험：자료 확보 권한 변경（협력 철회, 플랫폼 폐쇄）

**방법론적 위험**：
- 위험：방법 부적합（가설 성립 안 됨, 모형 적합도 저조）
- 위험：기술적 난관（소프트웨어 오류, 분석 실패）
- 위험：시간 부족（새로운 방법 학습에 과도한 시간 소요）

**자원 위험**：
- 위험：예산 부족（초과 지출, 추가 비용）
- 위험：장비 고장（컴퓨터 파손, 소프트웨어 만료）
- 위험：인력 변동（지도교수 출장, 협력자 이탈）

**개인 위험**：
- 위험：건강 문제（질병, 피로）
- 위험：시간 충돌（수업, 시험, 실습）
- 위험：동기 부족（정체기, 지연）

**외부 위험**：
- 위험：정책 변화（학교 요건 변경, 윤리新规）
- 위험：돌발 사건（팬데믹, 자연재해）
- 위험：기술 변화（플랫폼 업데이트, 자료 형식 변경）

### 2. 위험 평가 매트릭스

```
위험 평가 매트릭스

위험 항목          확률(1-5)  영향(1-5)  위험 등급  대응 전략
------------------------------------------------------------
자료 회수율 저조      3         4         고      다채널 배포, 인센티브
표본량 부족          2         5         고      표본 범위 확대, 설계 조정
방법 부적합          2         4         중      대체 방법, 예비 실험
예산 초과            2         3         중      예산 완충, 추가 신청
지도교수 출장        3         2         저      온라인 소통, 사전 일정
건강 문제            2         3         중      건강 관리, 시간 예비
정책 변화            1         4         저      동태 파악, 유연한 조정
```

### 3. 위험 대응 전략

**예방 전략（확률 감소）**：
- 자료 회수：사전 설문 테스트, 다채널 배포, 알림 설정
- 표본량：표본 프레임 확대, 최소 표본 기준 설정
- 방법 적합：문헌 검증, 예비 실험, 전문가 자문
- 예산：상세 예산, 10-20% 완충 확보
- 건강：규칙적인 생활, 정기 운동, 탄력적 시간 확보

**완화 전략（영향 감소）**：
- 자료 회수율 저조：표본량 증가, 가중치 조정 사용
- 방법 부적합：대체 방법 준비, 모형 단순화
- 예산 초과：핵심 지출 우선 보장, 추가 지원 요청
- 지도교수 출장：온라인 회의, 핵심 문제 사전 논의
- 건강 문제：단계별 추진, 동료 도움 요청

**비상 전략（위험 발생 후）**：
- 자료 회수율 <50%：표본 범위 확대, 질적 연구로 전환
- 표본량 부족：Bootstrap, 베이지안 방법 사용
- 방법 완전 실패：기술적 연구, 사례 연구로 전환
- 예산 소진：긴급 지원 신청, 지도교수 지원 요청
- 장기 질병：연기 신청, 연구 계획 조정

**이전 전략**：
- 자료 수집：전문 기관에 위탁（예산 필요）
- 자료 분석：통계 자문 요청（학교에서 보통 무료）
- 기술 문제：기술 지원 서비스 구매

### 4. 위험 대응 계획 예시

**예시：자료 회수율 저조**

```
위험：설문 조사 회수율이 예상보다 낮은 경우（<50%）

예방 조치：
- 설문 설계：10명 대상 예비 테스트, 5분 이내 완료 확인
- 배포 채널：이메일+위챗+수업+플랫폼 푸시, 다채널 커버
- 인센티브：선착순 100명 XX 보상（학습 자료, 소정 선물）
- 알림 메커니즘：배포 후 3일, 7일, 14일 각각 알림

비상 조치：
- 회수율 40-50%：표본 프레임 확대, 200명 추가
- 회수율 30-40%：인센티브 증가, 추첨제 변경（100% 당첨）
- 회수율 <30%：질적 연구로 전환（심층 인터뷰 20명）
- 회수율 <20%：지도교수와 논의, 연구 설계 조정

모니터링 지표：
- 일별 회수 건수
- 회수율 추세
- 표본 대표성（모집단과 비교）
```

```

본 연구는 다음과 같은 주요 위험을 식별하고 이에 대응하는 계획을 수립하였다：

1. 자료 수집 위험
   위험 서술：설문 조사 회수율이 예상보다 낮을 수 있음.
   예방 조치：다채널 배포（이메일+위챗+수업）, 알림 설정, 인센티브 제공.

2. 방법론적 위험
   위험 서술：구조방정식 모형의 적합도가 낮을 수 있음.
   예방 조치：예비 실험으로 모형 검증, 통계 전문가 자문.
   비상 조치：모형 적합도 저조 시, 대체 방법（회귀 분석, 분산 분석）사용
             또는 모형 단순화.

3. 시간 위험
   위험 서술：자료 수집이 지연되어 후속 분석에 영향을 줄 수 있음.
   예방 조치：상세 일정 수립, 2개월 완충 시간 확보.
   비상 조치：지연 >1개월 시, 논문 연기 신청 또는 분석 단순화.

4. 자원 위험
   위험 서술：예산이 초과될 수 있음.
   예방 조치：상세 예산, 20% 완충 확보, 핵심 지출 우선 보장.
   비상 조치：초과 시, 추가 지원 신청 또는 지도교수 지원 요청.

위와 같은 대응 계획을 통해 본 연구는 잠재적 위험에 효과적으로 대응하고
연구의 원활한 완수를 보장할 수 있다.
```

## 자주 묻는 질문 및 해결

### Q：기술 로드맵이 너무 단순하거나 너무 복잡한 경우?
- 단순：하위 프로세스, 의사결정 지점, 순환 피드백 추가
- 복잡：동류 항목 병합, 상위 수준 추상화, 부록에 세부 사항 배치

### Q：타당성 분석이 자화자찬처럼 보이는 경우?
- 객관적 서술："이미 갖추고 있다""확인되었다" 등으로 표현, "나는 우수하다"는 표현 지양
- 한계 인정："X 측면의 경험은 부족하지만 Y 방식으로 보완하였다"
- 증거 인용：수업 성적, 교육 수증서, 지도교수 논문

### Q：위험 대응 계획이 형식적으로 보이는 경우?
- 구체화："문제가 발생할 수 있다"가 아닌 "회수율이 <50%일 수 있다"로 서술
- 정량화：확률, 영향, 임계값
- 실행 가능："관리를 강화한다"가 아닌 "3일 후 알림 이메일 발송"으로 서술

### Q：혁신점이 부족한 경우?
- 재정의："완전히 새로운 것"이 아닌 "새로운 조합""새로운 응용""새로운 관점"
- 비교 설명：기존 연구와의 구체적 차이점
- 적절한 표현："시도""탐구""보완"으로 표현, "최초""혁명적"은 지양

# 논문 수정 및 교정 가이드

## 자기 수정

### 1. 수정 단계

**냉각 기간（1-3일）**：
- 초안 작성 후 1-3일간 방치한 후 수정
- 이유：거리가 객관성을 부여하고 문제를 발견하기 쉬움
- 활동：문헌 읽기, 자료 처리, 휴식

**1차：구조 수정（거시）**
- 논리 체인 점검：서론→방법→결과→토론→결론
- 장 균형 점검：각 장 분량이 합리적인지 확인
- 제목 계층 점검：명확하고 일관적인지 확인
- 전환 확인：장과 장, 절과 절 사이의 연속성 확인

**2차：내용 수정（중시）**
- 논점 점검：각 단락에 명확한 논점이 있는지 확인
- 근거 점검：근거가 논점을 뒷받침하는지 확인
- 논증 점검：논리가 엄밀한지 확인
- 중복 점검：중복 내용이 있는지 확인
- 누락 점검：중요한 내용 누락이 있는지 확인

**3차：언어 수정（미시）**
- 문법 점검：주어-서술어 일치, 시제, 관사
- 맞춤법 점검：오탈자, 전문 용어
- 구두점 점검：한글/영문 구두점 혼용 여부
- 서식 점검：글꼴, 글자 크기, 줄 간격
- 인용 점검：형식 통일, 대응 관계

**4차：세부 다듬기（정교）**
- 그림/표 점검：번호, 제목, 선명도
- 자료 점검：숫자, 단위, 백분율
- 참고문헌 점검：완전성, 형식
- 부록 점검：번호, 대응 관계

### 2. 자기 수정 체크리스트

**구조 체크리스트**：
- [ ] 초록에 연구 목적, 방법, 결과, 결론이 포함되어 있는가?
- [ ] 서론이 거시에서 미시로, 마지막에 연구 문제를 명확히 하고 있는가?
- [ ] 문헌 리뷰가 분류가 명확하고 서평이 결합되어 있는가?
- [ ] 방법 부분이 재현 가능한 수준으로 상세한가?
- [ ] 결과 부분이 객관적으로 제시되고 해석이 포함되지 않았는가?
- [ ] 토론 부분이 결과를 해석하고, 문헌과 비교하며, 한계를 지적하고 있는가?
- [ ] 결론이 연구 문제에 응답하고 새로운 내용을 도입하지 않았는가?
- [ ] 각 장 비율이 합리적인가（서론 10%, 문헌 20%, 방법 15%, 결과 20%, 토론 25%, 결론 10%）?

**내용 체크리스트**：
- [ ] 각 단락에 주제 문장이 있는가?
- [ ] 단락 간 전환이 있는가?
- [ ] 무관한 내용이 있는가?
- [ ] 중복 내용이 있는가?
- [ ] 누락된 중요 문헌이 있는가?
- [ ] 자료가 최신인가?
- [ ] 결론이 과도하게 추론되었는가?

**언어 체크리스트**：
- [ ] 구어체 표현이 있는가?
- [ ] 모호한 표현이 있는가?
- [ ] 절대적 표현이 있는가?
- [ ] 장문（>30자）이 있는가?
- [ ] 수동태의 과도한 사용이 있는가?
- [ ] 어색한 외국어 표현이 있는가?
- [ ] 용어가 통일되어 있는가?

### 3. 낭독법

**방법**：
- 논문 전문을 큰 소리로 읽기
- 또는：텍스트 음성 변환 도구 사용（Word 낭독, Edge 브라우저）

**발견되는 문제**：
- 어색한 문장：읽기 부드럽지 않은 경우, 다시 작성 필요
- 반복 어휘：같은 어휘가 연속으로 나타나는 경우, 대체 필요
- 논리 도약：단락을 읽은 후 이유를 알 수 없는 경우
- 어조 문제：너무 강하거나, 너무 약하거나, 객관적이지 않은 경우

### 4. 역提纲法

**방법**：
- 단락을 읽은 후, 한 문장으로 핵심 내용 요약
- 메모지나 문서 여백에 기록
- 전체 완료 후, 요약문만 확인

**점검**：
- 요약문이 논리 체인을 형성하는가?
- 제목과 불일치하는 요약문이 있는가?
- 연속된 여러 단락의 요약문 내용이 중복되는가?
- 요약할 수 없는 단락이 있는가（내용이 혼란스러움을 의미）?

## 지도교수 피드백 처리

### 1. 피드백 수용 자세

**올바른 자세**：
- 지도교수는 도움을 주는 분이지 비판하는 분이 아님
- 피드백은 무료 전문가 상담
- 모든 수정이 논문 품질을 향상시킴
- 지도교수의 "이해할 수 없다"는 독자의 "이해할 수 없다"와 동일

**피해야 할 자세**：
- 방어적："내가 틀리지 않았다, 지도교수가 이해 못 한 것이다"
- 저항적："이렇게 많이 고칠 바에야 다시 쓰겠다"
- 지연적："일단 두고 나중에 말하자"
- 선별적："쉬운 것만 고치고 어려운 것은 무시"

### 2. 피드백 유형과 대응

**유형1：방향성 피드백**
- 특징："연구 프레임워크 조정 제안""XX 이론 보충 제안"
- 대응：지도교수와 면담, 구체적 방향 확인, 수정 계획 수립
- 주의：대량 재작성이 필요할 수 있으므로 조속히 처리

**유형2：내용성 피드백**
- 특징："여기 근거가 부족하다""XX 자료 보충 제안"
- 대응：문헌, 자료, 사례 보충 또는 해당 논점 삭제
- 주의：자료 출처를 확인하여 신뢰성 보장 필요

**유형3：구조성 피드백**
- 특징："2, 3장 병합 제안""장 순서 조정 제안"
- 대응：구조 조정 방안 작성, 지도교수 확인 후 실행
- 주의：개요 보기 기능 사용, 내용 유실 방지

**유형4：언어성 피드백**
- 특징："표현이 불분명하다""간결하게 제안""문법 오류"
- 대응：조목별 수정, 원어민 또는 교정 서비스 도움 요청 가능
- 주의：수정 스타일 통일, 전후 불일치 방지

**유형5：서식 피드백**
- 특징："그림/표가 비규범적이다""인용 형식 오류"
- 대응：학교 템플릿과 대조, 항목별 수정
- 주의：스타일 기능 사용, 수동 조정 지양

### 3. 피드백 처리 절차

**단계1：피드백 정리**
- 피드백 분류：방향/내용/구조/언어/서식
- 우선순위 표시：필수 수정/권장 수정/선택 수정
- 난이도 표시：쉬움/보통/어려움
- 표 작성：피드백 내용|유형|우선순위|난이도|수정 방안|상태

**단계2：계획 수립**
- 우선순위에 따라 정렬：방향성 먼저, 그다음 내용성, 마지막으로 서식성
- 난이도에 따라 배치：쉬운 것+어려운 것 교대로, 번아웃 방지
- 시간 설정：각 유형별 피드백 시간 확보
- 버퍼 확보：총 시간의 20%를 예외 상황에 대비

**단계3：수정 실행**
- 한 가지 유형에 집중：한 번에 한 유형만 처리
- 완료 표시：수정 후 "완료"로 표시
- 문제 기록：수정 불가 사항은 사유 기록
- 버전 유지：매 수정마다 새 버전 저장

**단계4：재확인**
- 피드백 대조：수정 여부 조목별 점검
- 교차 검증：수정된 부분에서 새로운 문제가 발생했는지 확인
- 전체 점검：수정 후 전문이 일관적인지 확인
- 지도교수 제출：수정 설명서 첨부

## 언어 교정

### 1. 자기 교정 기법

**간결화**：
- 중복 삭제："very" "quite" "rather" "really"
- 불필요한 표현 삭제："it is important to note that" "there is no doubt that"
- 반복 삭제：같은 절 내에서 용어를 반복 정의하지 않음
- 구어체 삭제："get" "big" "good" "bad" "thing" "stuff"

**강화**：
- 동사로 명사 대체："make an analysis" → "analyze"
- 능동태로 수동태 대체（적절히）："It was found that" → "We found that"
- 구체적 표현으로 추상적 표현 대체："good results" → "results improved by 25%"
- 강한 형용사로 "very + 형용사" 대체

**연결성**：
- 전환어 추가："Furthermore" "However" "Therefore" "In contrast"
- 지시어 추가："This finding" "These results" "That approach"
- 요약 추가：단락末 요약문, 장末 전환문

## 자주 묻는 질문

### Q：수정할수록 나빠지는 경우?
- 원인：과도한 수정, 전체적 시각 상실
- 해결：전문 인쇄, 오프라인 읽기; 또는 전문 낭독
- 예방：매 수정마다 한 가지 유형의 문제에 집중

### Q：지도교수 의견이 상반되는 경우?
- 해결：지도교수와 소통, 우선순위 확인
- 전략：자신의 연구 문제를 기준으로 선택 설명
- 주의：소통 결과 기록, 반복 수정 방지

### Q：시간이 부족하여 충분히 수정할 수 없는 경우?
- 우선순위：구조>내용>언어>서식
- 전략：먼저 결점（논리 결함, 사실 오류）수정, 그다음 세련（언어 교정）
- 도움：서식 조정, 언어 검사를 동료에게 부탁

### Q：여러 번 수정했는데도 불만족스러운 경우?
- 수용：논문은 완벽할 수 없고 충분히 좋으면 됨
- 기준：졸업 요건 충족, 심사 통과하면 됨
- 향후：졸업 후에도 계속 보완하여 투고 게재 가능

# 논문 집필 단계 가이드

## 단계1：주제 진단

### 주제 선정 원칙
- **가치성**：학술적 가치 또는 실천적 가치
- **혁신성**：새로운 관점, 새로운 방법, 새로운 자료, 새로운 결론
- **실현 가능성**：시간, 자원, 역량과의 매칭
- **명확성**：문제가 구체적이고 경계가 명확

### 주제 선정 방법
1. **문헌 기반**：공백(Gap), 모순, 미개척 분야 발견
2. **문제 기반**：실천 과정에서 직면한 문제
3. **방법 기반**：새로운 방법을 기존 문제에 적용
4. **교차 기반**：다학제적 관점

### 주제 평가 체크리스트
- [ ] 연구 문제를 한 문장으로 명확하게 표현할 수 있는가?
- [ ] 관련 문헌이 뒷받침하는가?
- [ ] 자료/데이터를 확보할 수 있는가?
- [ ] 6-12개월 내에 완성할 수 있는가?
- [ ] 지도교수가 승인하는가?
- [ ] 전공 교육 방향에 부합하는가?

## 단계2：개제 보고서

### 표준 구조
1. **연구 배경**
   - 거시적 배경（사회/학술）
   - 미시적 배경（구체적 현상）
   - 문제 제기（배경에서 문제로）

2. **문헌 리뷰**
   - 연구 흐름（시간/주제/방법）
   - 주요 관점（분류별 정리）
   - 연구 부족（Gap 분석）
   - 본문의定位（기여 선언）

3. **연구 내용**
   - 연구 목표（총괄+구체）
   - 연구 문제（구체적 문제 3-5개）
   - 연구 가설（해당 시）
   - 기술 경로（순서도）

4. **연구 방법**
   - 방법론（실증/규범/해석）
   - 구체적 방법（양적/질적/혼합）
   - 자료 출처
   - 분석 도구

5. **혁신점**
   - 이론적 혁신
   - 방법론적 혁신
   - 자료적 혁신
   - 관점의 혁신

6. **연구 계획**
   - 시점（간트 차트）
   - 예상 성과
   - 위험과 대응

### 개제 심사 준비
- 10-15분 발표
- 예상 질문 준비：왜 이 주제를 선택했는가? 왜 이 방법을 사용하는가? 실현 가능성은?
- 심사 위원 의견 기록, 회의 후 수정

## 단계3：개요 작성

### 개요 유형
- **목차형**：장 제목 계층
- **논리형**：논점의 점진적 관계
- **카드형**：각 단락의 핵심 내용

### 개요 구성 요소
- 각 장의 핵심 논점
- 근거/자료/데이터
- 전후 장과의 논리적 관계
- 예상 분량

### 개요 점검
- [ ] 논리가 일관되는가?
- [ ] 계층이 명확한가?
- [ ] 비율이 균형 있는가?
- [ ] 중복이 있는가?
- [ ] 모든 연구 문제를 포괄하는가?

## 단계4：장별 집필

### 집필 순서 제안
1. **먼저 작성**：문헌 리뷰, 연구 방법（상대적으로 독립적）
2. **다음 작성**：자료 분석, 사례 연구（핵심 작업）
3. **나중 작성**：서론, 결론（전문적 시각 필요）
4. **마지막**：초록, 키워드

### 각 장 구조
- **서론 단락**：본 장의 목적, 전문과의 관계, 핵심 내용 예고
- **본론 단락**：논점+근거+분석（PEEL 구조）
  - Point：논점
  - Evidence：근거
  - Explanation：설명
  - Link：논점으로 회귀/다음 논점으로의 전환
- **결론 단락**：발견 요약, 상하 연결

### 집필 기법
- **매일 정해진 시간**：고정된 시간에 집필하여 습관 형성
- **먼저 완성, 그다음 완벽**：초안은 완벽을 추구하지 않고 먼저 작성
- **단락 단위**：한 번에 하나의 단락을 작성하여 부담 감소
- **미완성 표시**：TODO로 불확실한 부분 표시

## 단계5：수정 보완

### 자기 점검 체크리스트
- [ ] 논점이 명확한가?
- [ ] 근거가 충분한가?
- [ ] 논리가 엄밀한가?
- [ ] 언어가 정확한가?
- [ ] 서식이 규범적인가?
- [ ] 인용이 완전한가?

### 수정 계층
1. **거시**：结构调整, 장 증감, 논리 재구성
2. **중시**：단락 재구성, 전환 최적화, 논증 강화
3. **미시**：어구 교정, 구두점 규범, 서식 통일

### 지도교수 피드백 처리
- "필수 수정"과 "권장 수정"을 구분
- 이해하지 못하는 부분은 적극적으로 소통
- 수정 후 변화를 표시
- 수정 기록을 보존

## 단계6：서식 규범

### 일반 서식 요건
- **표지**：학교 통일 형식
- **초록**：중문/영문, 300-500자
- **목차**：자동 생성, 3급 제목
- **본문**：
  - 글꼴：宋体/Times New Roman
  - 글자 크기：소4（12pt）
  - 줄 간격：1.5배 또는 고정값 20pt
  - 여백：상하 2.54cm, 좌우 3.17cm
- **그림/표**：
  - 그림 제목은 하단, 표 제목은 상단
  - 번호：그림 1-1, 표 2-1
  - 출처 표시
- **참고문헌**：
  - 형식：GB/T 7714-2015
  - 유형：저서[M], 정기간행물[J], 학위논문[D], 학회[C], 전자문헌[EB/OL]

### 조판 도구
- **Word**：스타일 기능, 다단계 목록, 캡션
- **LaTeX**：Overleaf, 템플릿
- **참고문헌 관리**：EndNote, Zotero, NoteExpress

## 단계7：유사도 검사 및 심사

### 유사도 검사 준비
- **자가 검사**：知网, 维普, 万方（학교 지정 시스템）
- **유사도 저감 전략**：
  - 동의어 대체（학술적 정확성 유지）
  - 문장 구조 재편（능동/수동 전환）
  - 표/그림化（텍스트를 표/그림으로 전환）
  - 인용 규범（직접 인용 표시）
- **주의 사항**：
  - 전문 용어는 보존
  - 공식 서술은 개작
  - 법조문/고시 원문은 제외（단, 표시）
  - 참고문헌 목록은 제외

### 심사 준비
- **PPT 제작**：
  - 15-20매
  - 연구 문제, 방법, 발견, 기여
  - 그림/표 위주, 텍스트 간결
  - 원고 준비（PPT를 읽지 않기）

- **심사 질문**：
  - 왜 이 주제를 선택했는가?
  - 혁신점은 무엇인가?
  - 방법의 한계는 무엇인가?
  - 특정 결과를 어떻게 해석하는가?
  - 다시 한다면 어떻게 개선하겠는가?

- **심사 매너**：
  - 정장 착용
  - 시간 조절（발표 15-20분）
  - 비판에 겸손하게 대응
  - 수정 의견 기록

### 심사 후
- 수정 의견 정리
- 지도교수와 수정 범위 확인
- 기한 내 수정본 제출
- 최종 서식 점검
- 전자본과 인쇄본 제출
