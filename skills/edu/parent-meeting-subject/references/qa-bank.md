# 家长会高频提问与教师应对话术库

## 学业类

**Q1：我家孩子成绩为什么进步 / 退步这么明显？**
- 不要在公开场合给单个孩子下定论。
- 应答："这个问题涉及孩子具体情况，会后我们一对一聊更有效，我会今天加你的微信。"

**Q2：能不能告诉我孩子在班里第几名？**
- 应答（义务教育阶段，按教育部要求不公布排名）："学校规定不公布个人排名，我可以告诉你他/她所处的分段（高/中/中下），更重要的是这次和上次相比的变化，会后我们详谈。"

**Q3：孩子不学习 / 写作业拖拉怎么办？**
- 不要急着给"标准答案"。
- 应答 3 步：先共情（"这是这个年龄段普遍现象"）→ 再追问（"通常什么时候开始拖拉？"）→ 给方法（番茄钟、先易后难、固定时段）。

## 教师与教学类

**Q4：为什么这次考试这么难 / 老师讲得太快？**
- 应答："试题难度由教研组共同把关，您看到的低分背后我们也在做归因（数据 + 教学反思）。如果具体到某节课，欢迎随时来听课或一对一沟通。"

**Q5：能不能给我家孩子多布置点 / 少布置点作业？**
- 应答："总量有政策要求，但'分层作业'已经允许差异化。基础不牢的孩子，我们会增加 A 层练习；学有余力的，C 层挑战是选做，您也可以反馈孩子的实际情况。"

## 心理与人际

**Q6：孩子在班里有没有被孤立 / 被欺负？**
- 应答："这是我特别重视的问题，咱们会后一定单独聊。如果您观察到任何苗头，越早告诉我越好。"

**Q7：我感觉孩子最近情绪不对 / 不愿上学。**
- 应答："这是很关键的信号。建议三步走：1）我们再观察 1-2 周课堂表现并记录；2）建议您带孩子去学校心理老师做一次轻量沟通；3）如果持续 4 周以上，建议到正规医院儿童青少年心理科。我们会和您保持沟通。"
- **不要**自行下心理诊断。

## 升学与生涯

**Q8：直升 / 派位 / 中考 / 选科怎么准备？**
- 给原则，不给确定性预测。
- 应答："政策每年微调，最权威的口径以学校通知为准。我可以分享给您一些备考节奏建议……（具体）"

## 投诉与冲突

**Q9（家长当场情绪激动 / 指责教师）：**
- 三步缓冲：1）真诚倾听不打断；2）共情但不立刻让步（"我理解您的担心"）；3）建议私下深谈。
- 注意：**会场不是辩论场**，不要当众反驳家长。

## 家长之间引发的话题

**Q10：xx 家孩子参加 ___ 班 / 培训，我们孩子要不要也报？**
- 应答："教育有不同节奏，最关键是孩子'吃得下'什么。建议您先观察孩子的疲劳度和兴趣点，然后再决定，不必随大流。"
