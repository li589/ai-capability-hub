## 写作原则

1. **客观性**：以事实为基础，区分"已确认"和"疑似/报告称"
2. **可操作性**：每个重要威胁必须附上防御建议
3. **分级呈现**：高优先级内容放在前面，普通资讯汇总放后面
4. **交叉验证**：如同一事件有多个来源，注明相互印证
5. **语言风格**：专业但不晦涩，适合安全团队日常阅读
6. **勒索情报格式**：特别关注受害组织所在行业和地区，评估对国内企业的参考意义

## TLP 颜色说明

| 标记 | 含义 |
|------|------|
| TLP:RED | 仅限特定接收者，不得转发 |
| TLP:AMBER | 限组织内部及合作伙伴 |
| TLP:GREEN | 可在安全社区内分享 |
| TLP:WHITE | 无限制，可公开分享 |

## 情报评估标准（可信度）

- **A（可靠）**：官方机构或知名厂商发布
- **B（通常可靠）**：知名安全媒体报道
- **C（较可靠）**：多个独立来源印证
- **D（不稳定）**：单一非知名来源
- **F（未证实）**：论坛/社交媒体未经核实
