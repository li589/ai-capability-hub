# 防骗大师.Skill（anti-fraud）

你身边的防骗专家。当用户贴来可疑的短信、聊天记录、邮件、链接、App 或电话转述，询问是否为骗局时，本技能负责识别、定级并给出应对；当对话中出现转账、验证码、屏幕共享、陌生链接、安全账户、冒充公检法等风险信号时，主动介入守护；同时支持防诈骗知识科普、话术识别与模拟演练。

## 能力概览

- **风险识别与定级**：基于 36 类骗局知识库 + 22 条红色谓词（R1-R22）+ 12 条黄色谓词（Y1-Y12）进行可观察特征判定，输出 红 / 黄 / 绿 三级结论并附命中特征清单
- **反向证伪**：定级前先做"非骗局假设检验"，有正常解释且无风险要求则判绿，避免误伤正常业务
- **主动守护者**：对话中出现转账、验证码、屏幕共享、远程控制等触发词即插入风险嗅探；命中红色必出强提醒卡，输出强度与直接判定一致
- **知识科普**：36 类骗局均含典型话术 / 判定特征 / 高发人群 / 应对 / 铁律，可随时讲解
- **模拟演练**：workflows/anti-fraud-drill.yaml 提供角色扮演演练，通过 user / fraudster / mentor / evaluator 四角色闭环训练识别能力
- **真伪辨别链**：在判定辩证链之上强化 L3 外部证据核验 / L4 交叉印证 / L5 置信度标定 / L6 人工复核闸门（见 references/verification-chain.md），把"内部命中谓词"升级为"可外部验证的真伪结论"——置信度可量化、高危结论有人工兜底、内部判定与外部核验冲突即降级待核实
- **完整判定示例对照**：references/walkthrough-examples.md 提供 8 个自包含端到端走查示例（W4-W11：冒充老板转账·财务 / 杀猪盘 / 刷单返利·学生 / 保健品会销·老年升红 / 低价旅游·老年 / 持牌理财·绿承接 / 已转账止损 / 未收录新型兜底），每个示例单文件走完判定五步 + L1–L6 全链 + 人群话术 + 止损 + 知识复盘；另有 golden-cases.md 第六节 W1-W3（红·自动核验升档 / 绿承接 / 内外部冲突降级）作回归基线，合计 11 个端到端走查，回应"想看完整判定过程"的需求

## 维护约定（单一事实源）

为避免多文件重复维护导致漂移（曾于 v2.0.0 去除类目时出现对齐问题）：
- **类目计数**：以 references/scam-knowledge.md 标题（#1–#N）与 workflows/anti-fraud-drill.yaml 的 `scam_type` 枚举为准；README / SKILL 仅引用，不另行写死数字
- **求助渠道**：以 references/emergency-sop.md「求助渠道总表」为准；其余文件只指向该表，不重复列号码
- **红/黄谓词**：以 references/risk-levels.md 为准；新增/调整谓词须同步该表与 SKILL 引用
- 任何一处新增骗局类目，须同步三处（知识库标题 + yaml 枚举 + 本文计数）并跑一致性校验

## 使用方式

- **被动问答**：用户贴来可疑内容，直接按判定流程输出 红 / 黄 / 绿 与应对
- **主动守护**：对话中出现风险触发词，自动插入嗅探并在命中后补提醒
- **演练模式**：运行 anti-fraud-drill.yaml，指定骗局类型进行对抗演练；无 workflow-runner 时降级为手工按流程演练
