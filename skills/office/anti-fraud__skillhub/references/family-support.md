# 家属介入机制（家人 / 身边人视角）

当用户是家属、同事、朋友，替当事人咨询"ta 是不是被骗了 / 怎么劝 ta"时启用。定位：帮助介入者判断当事人处于被骗的哪个阶段，选择正确的干预方式与话术。**重心是关系与沟通，不是技术拦截。**

## 一、三阶段识别与干预

老人/亲友被骗是渐进过程。干预成功率与阶段成反比——越早干预越有效。

### 阶段一：情感培植期（1-4 周，干预成功率 85%+）

骗子嘘寒问暖、送小礼品、陪伴聊天建立信任，尚无经济损失。

**前兆信号**：频繁接电话且避开家人；常提某个"新朋友"；对健康/投资话题异常兴奋；热衷"免费讲座/免费旅游"；频繁收快递/小礼品；手机装不明 APP；开始囤保健品。

**有效干预**：设家庭暗号；装国家反诈中心 APP；开通转账提醒；聊天式分享反诈新闻不说教；填补孤独（常回家、多打电话）；关闭免密支付。

### 阶段二：利益诱导期（1-2 周，干预成功率 50-60%）

骗子引导小额投入、先给甜头，建立"这人靠谱"的信任。

**前兆信号**：小额频繁转账/取现；定期存款提前支取；购买大量购物卡；账户现陌生收款方；突然"没钱"买日常品；拒绝子女看银行流水；对某"投资机会"异常兴奋但不透露细节。

**有效干预**：不指责，用"我们"语言；说"我看看这个靠谱不"而非"你别被骗了"；用同龄人案例引导；带正规产品替代假货；让权威说话（医生、《今日说法》）；给老人安排"任务"填补被需要感；不强迫承认被骗，允许反复。

### 阶段三：深度控制期（干预成功率 <30%，需紧急行动）

骗子已获大额资金，要求保密、隔绝家人。老人陷入沉没成本+维护形象的双重锁死。

**前兆信号**：大额转账/取现；拒绝接子女电话；神色慌张外出取钱；陌生人上门取现金；坚持保密；以房抵押/改遗嘱/改受益人；借高利贷"投资"；情绪崩溃/自我封闭。

**有效干预**：立即 110 或 96110 报警；联系银行紧急止付/冻卡；保留全部记录；切断骗子联系；暂管财务（非指责式："我先帮您管几天，怕再有骗子找您"）；心理安抚重于追责（"不是你的错，骗子太狡猾，我们一起想办法"）。

## 二、沟通话术：该说 vs 绝不能说

### 该说

| 场景 | 推荐话术 | 原理 |
|---|---|---|
| 日常预防 | "最近新闻说好多老人被骗，咱打个预防针一起看看" | 不针对个人，降低防御 |
| 发现苗头 | "我朋友说他爸妈也遇到类似情况，后来发现是骗局" | 第三方视角，不否定当事人 |
| 劝阻购买 | "听说你们买了好东西，也让我试试看" | 不否定，先共情再替代 |
| 涉及转账 | "这么大笔钱，咱商量商量，我也想学学理财" | 让当事人感觉自己有价值 |
| 已被骗 | "不是你的错，骗子专门研究怎么骗人，我们一起想办法" | 消除羞耻感，建立同盟 |

### 绝不能说

| 禁忌话术 | 后果 |
|---|---|
| "你怎么这么傻" | 当事人更封闭，拒绝沟通 |
| "说了多少遍了别信" | 产生防御心理，更亲近骗子 |
| "这么明显的骗局都看不出来" | 因羞耻而隐瞒，不再求助 |
| "你再买我就不管你了" | 当事人选择骗子而非家人 |
| "让我看看你的银行流水" | 感到被控制，更封闭、更不愿透露 |
| "你是不是脑子糊涂了" | 彻底破坏信任关系 |

**关键认知**：当事人"固执听不进劝"不是态度问题，是认知失调 + 沉没成本 + 确认偏差 + 维护形象四重心理锁死；硬劝无效。不强迫承认被骗——很多当事人宁愿继续被骗也不愿承认自己错了。

## 三、介入三步法（先站队 → 再断联 → 后核验）

1. **先站队**："我们先把钱保住，不是怪你"——先站到当事人一边，再谈止损
2. **再断联**：协助挂断电话、退出群聊、停止转账
3. **后核验**：陪同拨打官方电话、去银行网点或派出所

## 四、介入者边界

- 介入者不是执法者，不搜证、不审讯、不监视；只做提醒与陪同
- 当事人拒绝介入时，保留求助通道（96110/110/社区民警），不强压
- 怀疑已大额受损时，直接建议报警，不自行"追款"
- 当事人出现严重情绪危机、自伤风险或强烈羞耻封闭时，转介 **12356 心理援助热线** 进行专业情绪疏导（与 SKILL「不适用场景」、emergency-sop 渠道总表一致）；心理干预优先于追责
