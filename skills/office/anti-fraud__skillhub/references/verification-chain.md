# 真伪辨别链（Verification Chain）

> 目的：把技能从「纯内部知识判定」升级为「有外部核验、可交叉印证、置信度可量化、高危结论有人工复核兜底」的真伪辨别能力。
> 本文是 SKILL.md / risk-levels.md / hallucination-guard.md 共用的**单一事实源**；三处只引用，不另写规则。
> 衔接：本链是 risk-levels.md「判定辩证链」的下游强化层——辩证链负责 ①正向扫描 ②反向证伪 ③交叉升红 ④存疑升级 ⑤证据锚定；本链在其第 ⑤ 步之后/之中接入 **L3 外部核验 / L4 交叉印证 / L5 置信度标定 / L6 人工闸门**，构成完整闭环。

## 总览：七层辨别链

| 层 | 名称 | 责任 | 是否新增 |
|---|---|---|---|
| L0 | 信号采集 | 提取五要素（谁/事/钱/链/急） | 既有（SKILL 判定五步第1步） |
| L1 | 内部特征判定 | R/Y 谓词扫描 + 预检路由 | 既有（risk-levels.md） |
| L2 | 反向证伪 | 非骗局假设检验，有正常解释即绿 | 既有（risk-levels 定级注意#3） |
| **L3** | **外部证据核验（默认自动）** | 命中任一 R 谓词即自动发起可溯源外部核验，无需等 [待核实] | **新增** |
| **L4** | **交叉印证** | ≥2 独立来源/方法一致才升档，冲突则降级 | **新增** |
| **L5** | **置信度标定** | 按证据强度量化 高/中/低，替换占位 | **新增** |
| **L6** | **人工复核闸门** | 高危结论只作警示，最终动作由用户确认 | **新增** |

> 铁律：**内部判定 ≠ 外部核验**。L1/L2 的"命中谓词"只是"疑似线索"，不等于"已证实为骗局"；只有经 L3 外部核验 + L4 交叉印证后，结论才进入 L5 标定。

## L3 外部证据核验（默认自动触发）

**默认自动发起（命中即核验）**：凡进入判定五步，只要命中任一红色谓词（R 系）、涉及具体主体、属擦边球/灰色地带、或用户明确要求查真假，**一律先核验再给结论**，不再等待 [待核实] 项显式出现。自动核验不因工具缺失而降级风险提醒——工具不可用时标 `[核验未达]` 并仍出强提醒卡。

触发范围（任一即自动核验）：
- 命中任意红色谓词（R 系），无论是否立即出现 [待核实] 项；
- 涉及具体主体（如"某投资平台""某客服热线""某 APP"）需确认真实性；
- 擦边球/灰色地带判定（需确认主体真实性与合规披露）；
- 用户明确要求"帮我查查这是不是真的"。
- **未知模式兜底**：内容语义明显异常（陌生但高压/胁迫/要求保密/要求非常规操作，或呈现未见过的套路机制）却**未命中任何 R/Y 谓词**时——不默认判绿，主动以描述的核心机制为关键词发起 `web_search` / `RAG_search` 广谱检索，核验是否存在同类公开预警；输出标注"疑似新型骗局 / 知识库未收录，建议以官方渠道（96110 / 110）核实"，结论标 `[待核实]` 或 `[推断]`，禁止静默放过或编造类型名。

**可用核验工具（按环境可用性降级）**：
1. `web_search` / `web_fetch`：核对官方通报、监管公示、权威媒体报道、机构官网；
2. `RAG_search`：命中已连接的反诈知识库/案例库时优先使用（比联网更权威、更聚焦）；
3. **官方渠道冻结清单**：求助/核实号码只来自 `references/emergency-sop.md` 求助渠道总表，不临时编造；
4. 工具均不可用 → 显式标 `[核验未达]`，只给官方核验渠道，不自行断言。

**核验结果分级（输出必带）**：
| 结果 | 含义 | 处置 |
|---|---|---|
| [已核验-假] | 外部权威源确认该主体/话术为骗局或冒用 | 直接支撑红色定级，L5 置信度升档 |
| [已核验-真] | 外部权威源确认主体真实/持牌/话术为官方正常业务 | 反向证伪通过，可降级为黄/绿核实而非红色定性 |
| [核验未达] | 工具不可用，或暂无权威源可证真/证伪 | 维持 [待核实]，给官方渠道，不升不降 |

**引用闸门（L3 专用）**：
- 外部核验源**必须可溯源**（给出来源名称/机构，不写"网上说"）；
- 单次搜索结果**不得当权威定论**，至少 L4 交叉印证或标注 [待核实]；
- 禁止把对方提供的"官网/证件截图"当核验依据——只信独立第三方权威源。

## L4 交叉印证（新增核心层）

- 同一结论须有 **≥2 个独立来源/方法** 支撑才升档：
  - 例：内部谓词命中（L1） + 外部核验-假（L3） → 红，置信度高；
  - 例：外部核验-真（L3） + 反向证伪通过（L2） → 绿/黄，置信度中低。
- **冲突处理**：内部判定与外部核验结论冲突（如谓词命中但官方渠道显示主体真实）→ 一律降级为 `[待核实]` + 走 L6 人工复核，禁止硬下定论。
- 单一来源（仅 L1 谓词、无 L3/L4）时，结论置信度上限为"中"，且必须标 [推断]/[待核实]。

## L5 置信度标定（新增核心层）

替换强提醒卡占位 `{高}`。置信度按证据强度量化，禁止"一定/绝对/百分之百"，用"极大概率/很可能/可疑/低风险"。

**标定 rubric**：

| 情形 | 标定 | 表述 |
|---|---|---|
| 红 + R≥2 或 红 + [已核验-假] | **高** | "极大概率（已外部核验）" |
| 红 + 仅单 R 且无 L3 核验 | **高** | "很可能"（标 [推断]） |
| 黄 + [已核验-真] 或 反向证伪通过 | **中→可降级** | "可疑，核实后或降绿" |
| 黄 + 无 L3 核验 | **中** | "可疑，待核实" |
| 绿 + 反向证伪通过 +（可选）[已核验-真] | **低** | "低风险" |
| 任一冲突 / [核验未达] | **待核实** | 不标定高低，给官方渠道 |

- 强提醒卡字段改为：`置信度：{高/中/低}，依据：{L3/L4 证据摘要}`
- 黄色/绿色输出同样在证据标签后附置信度档（如 `[待核实] / 中 / 低`）。

## L6 人工复核闸门（新增核心层）

- **红/高危结论只作"警示与建议"，不作"定论"**：最终是否转账/挂断/报警由**用户本人**确认，技能不代位决定（与 SKILL 红线一致）。
- 输出须显式标注："本判定基于可观察特征与可用核验，**未经公检法/监管机构作最终认定**"。
- 涉及具体机构"是否正规/是否持牌"：永远标 [待核实] + 官方核验渠道，不替用户下"合法/非法"终局结论（合法性交由监管/司法）。
- 高 stakes（已转账/已泄露/房产抵押）场景：L6 闸门前必须已出强提醒卡 + 止损 SOP，闸门只负责"不代位行动"。

## 与既有规则的衔接

- **反向证伪（L2）前置不变**：L3-L6 在 L2 之后执行，不替代反向证伪。
- **证据标签（hallucination-guard 一）**：L3-L5 的 `[已核验-真/假]/[核验未达]` 与既有 `[已验证]/[推断]/[待核实]` 并存——优先标 L3/L4/L5 结果，无法核验时回落到 `[待核实]`。
- **擦边球推路（risk-levels 五步判定推路）**：其第3步"查主体真实性"即调用本链 L3；命中真实主体 + L3 核验-真 → 黄色擦边球，不升红。
- **引用闸门（hallucination-guard 二）**：L3 外部核验源受同一闸门约束（只信可溯源权威源 + 官方冻结清单）。
