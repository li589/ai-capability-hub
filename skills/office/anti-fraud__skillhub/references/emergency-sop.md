# 紧急止损 SOP（已受损 / 正在被骗）

判定为红色或用户明确表示已转账/已泄露信息时启用。目标：停损优先，追责其次。所有步骤按顺序执行，先保住资金与账户，再谈其他。

## 一、正在被骗时：5 步止损

| 步骤 | 动作 | 说明 |
|---|---|---|
| 停 | 立即停止转账、取现、扫码、下载、共享屏幕、提供验证码 | 一切危险动作立刻中止 |
| 断 | 挂断电话，退出会议/远程软件，关闭屏幕共享，断开远程控制 | 切断骗子继续指挥的通道 |
| 核 | 通过 110、96110、银行官方客服电话、线下网点核实 | 只用自己存过的号码，不用对方给的号码 |
| 冻 | 已泄露账户或已转账 → 立即联系银行/支付平台挂失、冻结、止付 | 越早冻结，追回概率越大 |
| 报 | 拨打 110 报警，保留转账记录、聊天记录、通话记录、短信 | 证据完整才能立案追损 |

## 二、已泄露个人信息或账号

1. 修改银行卡、支付平台、社交账号等关键密码（先改与泄露信息关联的账户）
2. 联系银行做账户风险管控，必要时挂失补卡
3. 查询名下电话卡、银行卡和互联网账号，发现异常及时注销
4. 关闭陌生设备登录，检查是否安装远程控制或可疑 APP
5. 联系反诈中心做涉诈预警登记

## 三、二次诈骗预警（必防）

**凡是"能帮你追回钱款"的，都是骗子。** 已受损用户是二次诈骗的高危目标：

- 冒充警察/律师/平台客服，称"已锁定骗子、需交保证金/手续费解冻资金" → 一律拒绝
- 冒充反诈中心"指导追损"，要求开启屏幕共享或提供验证码 → 一律拒绝
- 声称"内幕渠道能回本"拉你继续投资 → 一律拒绝

唯一追损路径：110 报警 + 银行止付 + 司法途径。

## 四、求助渠道总表

| 渠道 | 号码/方式 | 适用场景 |
|---|---|---|
| 96110 | 反诈专线 | 预警劝阻、防骗咨询、涉诈举报；来电务必接听，但绝不会要求转账或索要验证码 |
| 110 | 报警电话 | 正在被骗、已转账、人身安全受威胁 |
| 银行客服 | 卡面电话/线下网点 | 挂失、冻结、止付、账户风险管控 |
| 12333 | 人社热线 | 社保/医保问题核实 |
| 12315 | 市场监管热线 | 保健品、药品、价格欺诈、虚假宣传投诉 |
| 12345 | 市民服务热线 | 各类政策核实、活动真伪咨询 |
| 国家反诈中心 APP | 应用商店下载 | 来电预警、短信预警、APP 预警、在线举报 |
| 12356 | 心理援助热线 | 心理危机干预、情绪疏导（非反诈场景） |

## 五、家庭防骗设置（一次性完成）

- 安装"国家反诈中心"APP，开启来电预警
- 关闭境外来电接听功能（联系运营商）
- 关闭免密支付；开通大额转账短信提醒并同步家人
- 设置银行"可信联系人"
- 设家庭暗号：涉及"子女出事""急用钱"先对暗号或视频确认
- 大额转账冷静期：超过约定金额，隔天且至少两名家属确认
- 定期家庭反诈例会：每月一次，分享近期高发骗局，更新家庭密语
