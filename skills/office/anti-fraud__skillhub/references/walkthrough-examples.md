# 完整判定走查示例集（Walkthrough Examples）

> 目的：回应"想看完整判定过程"——本文件每个示例在**单文件内**走完「判定五步 + 真伪辨别链 L1→L6 + 人群话术 + 止损衔接 + 知识复盘」全部环节，无需再对照其它文件。
> 定位：教学/演练/回归共用。`golden-cases.md` 第六节仅保留 W1-W3 作为回归基线；本文件承接 **W4-W11** 八个扩展示例，覆盖红/黄/绿/待核实/止损/未收录/演练对抗，并补一张「示例→环节」速查表。
> 与既有文件的关系：示例中的谓词编号以 `risk-levels.md` 为准；骗局类型名与特征以 `scam-knowledge.md` 为准；真伪链 L1-L6 规范以 `verification-chain.md` 为准；人群话术以 `response-scripts.md` 为准；止损/渠道以 `emergency-sop.md` 为准；本文件只演示过程，不另立规则。

### 示例 W4（红色·冒充老板紧急转账·财务人群·L3 自动核验）

**用户输入**：
> 我是李总，换新号了加一下。公司有个急事，你先把 20 万货款转给客户王总，我这边在开会不方便打电话，回头补手续，你先垫付。

**① 信息收集（五要素）**：谁=自称李总（新号）｜事=紧急转货款垫付｜钱=20 万（垫付）｜链=无｜急=限时、不便电话。

**② 风险扫描 + 预检路由**：命中预检（冒充老板+紧急转账+不便电话）→ 升级头脑风暴分析。

**③ 谓词判定**：
- **L1**：R10（冒充领导/老板，要求紧急转账且"不方便电话"）。
- **L2 反向证伪**：无正常解释（真实老板转账走财务审批，不会私加新号口头垫付）→ 证伪不通过，维持疑似。

**④ L3 外部证据核验（命中即自动发起）**：命中 R10 红色硬指标 → 自动 `web_search "冒充老板 财务 QQ 转账 诈骗 预警"` → 命中多地反诈中心 2024-2026 通报（财务人员被"假老板"诱导转账案例）→ 来源可溯源（公安反诈中心通报）→ 标注 `[已核验-假]`。

**⑤ L4 交叉印证**：内部 R10 命中 + 外部核验-假（双源一致）→ 升档成立。

**⑥ L5 置信度标定**：红 + R≥2（R10+外部核验-假）→ **高（极大概率，已外部核验）**。

**⑦ L6 人工复核闸门 + 输出（强提醒卡全文）**：
```
🚨 高危诈骗预警（红色）
骗局类型：冒充熟人/领导/老板（#3）
置信度：高（极大概率，已外部核验）
依据：内部命中 R10（冒充老板+紧急转账+不便电话）；外部核验[已核验-假]——多地反诈中心通报同类"假老板"骗局。
⚠️ 立即停止：不转账、不回复、不垫付！先按财务制度走审批。
✅ 正确动作：用手机通讯录里**存过的**李总号码回拨核实（不用对方给的新号）；或当面/企业 OA 确认；20 万垫付违反财务双人复核制度，任何"不方便电话"的紧急转账都是诈骗信号。
ℹ️ 本判定基于可观察特征与公开权威核验，未经公检法/监管机构作最终认定；是否转账由您和财务制度决定。
```

**⑧ 人群适配话术（财务人员）**：对接制度流程——"紧急转账不核实 = 违反财务制度"；必须电话/当面核实 + 走审批流程，不私加 QQ/微信执行转账；大额转账双人复核、电话回拨用存过的号码，不用对方给的号码（references/response-scripts.md 财务人群）。

**⑨ 止损衔接**：本次未转账 → 按上面核实即可；若已转账 → 立即 110 报警 + 联系银行紧急止付（emergency-sop 求助渠道总表）。

**⑩ 知识复盘**：#3 冒充熟人/领导/老板，判定特征 R10（紧急转账 + 不便电话/视频）；高发人群含财务人员；应对必须通过原联系方式二次核实。一句话口诀："老板换号急转钱，先回拨旧号再谈钱。"

### 示例 W5（红色·杀猪盘·网恋诱导投资·L3 自动核验）

**用户输入**：
> 在网上认识一个半月了，聊得挺好，他说带我投资稳赚，说平台有内部消息，让我下载他发的 App 注册入金，先投一万试水。

**① 信息收集（五要素）**：谁=网恋对象｜事=带投资、内部消息｜钱=入金 1 万｜链=下载非官方 App｜急="内部消息"暗示限时名额。

**② 风险扫描 + 预检路由**：命中预检（网恋+投资+非官方 App）→ 升级头脑风暴分析。

**③ 谓词判定**：
- **L1**：R5（承诺稳赚/内部渠道）+ R8（要求下载非官方渠道 App）+ Y5（网恋对象提及投资）。
- **L2 反向证伪**：无正常解释（真正投资导师不会在网恋中发非官方 App）→ 证伪不通过。

**④ L3 外部证据核验（命中即自动发起）**：命中 R5/R8 红色硬指标 → 自动 `web_search "杀猪盘 网恋 下载App 诈骗 预警"` → 命中公安部/多地反诈中心通报（"杀猪盘"套路：网恋→荐股→App 入金→提现失败）→ 来源可溯源 → 标注 `[已核验-假]`。

**⑤ L4 交叉印证**：内部 R5+R8+Y5 多谓词命中 + 外部核验-假（双源一致）→ 升档成立。

**⑥ L5 置信度标定**：红 + R≥2 + [已核验-假] → **高（极大概率，已外部核验）**。

**⑦ L6 人工复核闸门 + 输出（强提醒卡全文）**：
```

骗局类型：杀猪盘（网恋诱导投资，#5）
置信度：高（极大概率，已外部核验）
依据：内部命中 R5（稳赚/内部渠道）+ R8（非官方 App）+ Y5（网恋对象提投资）；外部核验[已核验-假]——"杀猪盘"系公安部通报高发套路。

**⑧ 人群适配话术（通用/单身人群）**：直白点破——"真带你赚钱的人不会在你还没见面的网恋期就催你投钱"；提示"见面要路费/签证费"是同一套路的后续；建议设置"网恋对象提钱 = 拉黑"的行为规则。

### 示例 W7（黄色升红·免费诱饵引流→保健品会销·老年人群·擦边球推路+交叉升红）

**① 信息收集（五要素）**：谁=会销组织者（"专家"）｜事=免费引流推销保健品｜钱=2980 元｜链=无｜急=限时促销（今天买三送一）。

**② 风险扫描 + 预检路由**：命中预检（免费引流+高价保健品+神奇功效）→ 升级头脑风暴分析。

**③ 谓词判定**：

- **L2 反向证伪**：无正常解释（保健食品不能治病，宣称"包治/无效退款"是典型会销话术）→ 证伪不通过。
- **交叉升红判定**：Y9 免费引流 + R13 高价保健品 = 交叉升红组合清单命中（risk-levels 定级注意第 4 条）→ **升红**。

**④ L3 外部证据核验（命中即自动发起）**：命中 R13 红色硬指标 → 自动 `web_search "免费领鸡蛋 保健品会销 诈骗"` → 命中市场监管总局/多地消协通报（免费讲座引流高价保健品会销骗局）→ 来源可溯源 → 标注 `[已核验-假]`。

**⑤ L4 交叉印证**：内部 Y9+R13 交叉升红 + 外部核验-假（双源一致）→ 升档成立。

**⑥ L5 置信度标定**：红 + R13 命中 + [已核验-假] → **高（极大概率，已外部核验）**。

**⑦ L6 人工复核闸门 + 输出（强提醒卡全文）**：
```

### 示例 W8（黄色·免费/低价旅游骗局·老年人群·核实清单）

**用户输入**：
> 小区门口发传单，99 元桂林 6 日游包吃包住，还送鸡蛋大米，让我爸报名，说名额有限先交 100 元定金。

**① 信息收集（五要素）**：谁=传单组织者（疑似旅行社）｜事=低价旅游招揽｜钱=99 元团费 + 100 元定金｜链=无｜急=名额有限。

**② 风险扫描 + 预检路由**：命中预检（低价旅游+送大礼+收定金）→ 升级头脑风暴分析。

**③ 谓词判定**：
- **L1**：Y11（以免费/超低价旅游+送大礼为饵招揽参团，行程实为购物点/会销）。
- **L2 反向证伪**：无正常解释（99 元含机票酒店全程低于成本，必然靠购物回扣补亏；《旅游法》第 35 条禁止不合理低价游）→ 证伪不通过。
- **交叉升红检查**：当前仅 Y11 单谓词，无 R 硬指标（未要求向个人账户转大额、无投资返利承诺）→ 维持黄色核实，不升红。

**④ L3 外部证据核验（擦边球/涉及具体主体自动核验）**：属擦边球范畴 → 自动 `web_search "99元桂林6日游 低价购物团 投诉"` → 命中文旅部门/媒体多次曝光"低价购物团"案例（强制购物、质次价高）→ 标注 `[已核验-真]`（该玩法真实存在且是典型陷阱）。

**⑤ L4 交叉印证**：内部 Y11 + 外部核验-真（低价购物团确实存在）→ 双源一致，维持黄色核实，不升红不降绿。

**⑥ L5 置信度标定**：黄 + 无 R 硬指标 + L3 核验支撑 → **中（可疑，待核实）**。

**⑦ L6 人工复核闸门 + 输出（黄色核实清单）**：
```
【提醒】该内容存在可疑特征，建议核实：
1. 查组织方"三证"：营业执照、旅行社业务经营许可证、出境游业务经营许可证（低价出境游尤其要查）。
2. 对比行程单：是否频繁出现"文化馆/博物馆/特色商场/养生基地"——那都是购物点。
3. 确认收费账户：团费/定金是否要求转个人账户？正常旅行社收对公账户。
4. 查《旅游法》第 35 条：低于成本价的团必靠购物回扣补亏。
在核实前，请不要转账、不点链接、不提供验证码。
```

**⑧ 人群适配话术（老年人）**：话术短、一次讲一件事；强调"免费/超低价不是真便宜，是要带你去花钱"；行动引导：查三证、签全国统一旅游合同、口头承诺写进合同、不向个人账户转账（response-scripts 老年人群 + scam-knowledge #31 应对）。

**⑨ 止损衔接**：未交定金 → 先核实三证再决定；已交定金 → 保留收据，若组织方无资质可 12345/12315 投诉；出行途中"不听讲座、不扫码、不跟风购物"。

**⑩ 知识复盘**：#31 免费/低价旅游骗局判定特征 Y11（低价+送大礼+购物点）；变异形态含低价购物团、免费养生一日游会销、中奖免费游、旅游+理财非法集资、旅游+杀猪盘；铁律《旅游法》第 35 条禁止不合理低价游。一句话口诀："九块九游桂林，路上全是购物坑。"

### 示例 W9（绿色承接·持牌理财推销·擦边球·L3 核验-真阻止误升红）

**用户输入**：
> 接到 953XX 来电，对方称是 XX 证券客服，推荐一款基金，全程提示"基金有风险，过往业绩不代表未来"，未要求转账给个人，只说去官方 App 操作。

**① 信息收集（五要素）**：谁=XX 证券 953XX 客服｜事=推荐基金并做风险揭示｜钱=未要求转个人｜链=官方 App｜急=无。

**② 风险扫描 + 预检路由**：嗅到"推荐理财"信号，但无转账/验证码/屏幕共享硬指标 → 进入判定五步正常定级。

**③ 谓词判定**：
- **L1**：无 R 硬指标；仅 Y10（熟人/推荐"内测名额"项目需核实）线索。
- **L2 反向证伪**：有正常解释（持牌券商电话推销+风险揭示是正常业务）→ 证伪通过，不升红。

**④ L3 外部证据核验（涉及具体主体自动核验）**：`web_search "953XX XX证券 官方客服号"` → 命中该券商官网公布的客服短号 → `[已核验-真]`。

**⑤ L4 交叉印证**：L2 证伪通过 + L3 核验-真 → 双源一致，维持非红。

**⑥ L5 置信度标定**：绿 + 反向证伪通过 + [已核验-真] → **低（低风险）**。

**⑦ L6 人工复核闸门 + 输出（绿色正常回应）**：`判定：绿色（合法理财推销）。置信度：低。依据：L2 反向证伪通过 + L3 核验[已核验-真]确认 953XX 为该券商官方号；未命中任何 R 违法硬指标，禁定性"诈骗"。建议：投资仍走官方 App，任何"稳赚不赔/要求转个人"立即拉黑。`（绿色场景同样过 L6 人工复核闸门——核验-真不误升红，与 W1/W7 升档形成对照。）

**⑧ 人群适配话术（通用）**：正常回应 + 一句话安全提醒——"如后续出现索要验证码/转账/点击链接要求，务必先核实"（response-scripts 通用人群）。

**⑨ 止损衔接**：无风险动作，无需止损；保留"基金有风险"的风险披露作为核验依据。

**⑩ 知识复盘**：擦边球判定推路第 3 步"查主体真实性"即调用 L3；有真实主体 + 有风险披露 + 未要求转个人 → 黄色擦边球不升红（risk-levels 擦边球判定 + golden-cases B01/V01 对照）。一句话口诀："持牌有披露，核验能放行；稳赚要转个人，必是骗子。"

### 示例 W10（已转账止损·红色优先·不进入判定五步·二次诈骗预警）

**用户输入**：
> 我刚按"安全账户"转了三万，现在他又说系统要再转五万解冻才能一起返还，我是不是被骗了，还能要回来吗？

**① 状态判定（前置分流）**：用户明确已转账 3 万且正被要求再转 5 万 → **已转账/正在被骗，不进入判定五步**，先共情安抚（"不是你的错，骗子专门研究怎么骗人"），立即走止损 SOP（SKILL 判定五步前置 + emergency-sop）。

**② 谓词快照（用于归因，不阻塞止损）**：R3（安全账户）+ R9（解冻费）+ R21（转账给陌生账户）——典型冒充公检法/虚假投资提现套路，止损后再补完整定级与归因。

**③ 紧急止损 SOP（停→断→核→冻→报）**：
| 步骤 | 动作 |
|---|---|
| 停 | 立即停止转账！再转 5 万"解冻"必是二次收割，钱不会"解冻返还" |
| 断 | 挂断电话，退出远程/会议软件，关闭屏幕共享，断开与对方的任何沟通 |
| 核 | 拨打 110 / 96110 或银行官方客服（用自己存过的号码，不用对方给的）核实 |
| 冻 | 立即联系转账银行/支付平台挂失、冻结、止付——越早冻结，追回概率越大 |
| 报 | 拨打 110 报警，保留转账记录、聊天记录、通话记录、短信等全部证据 |

**④ 二次诈骗预警（必防）**：凡是"能帮你追回钱款"的（假警察/假律师/假客服要求交保证金/手续费解冻、要求开启屏幕共享、拉你继续投资回本）**一律拒绝**；唯一追损路径：110 报警 + 银行止付 + 司法途径（emergency-sop 二次诈骗预警）。

**⑤ 人群适配话术（通用）**：先安抚情绪（"不是你笨，骗子专门设计话术"），再给止损清单；强调"钱能追回的窗口期在前几分钟，先行动再复盘"。

**⑥ 归因与复盘（脱离危险动作后补充）**：类型冒充公检法/虚假投资（#1/#6），判定特征 R3 安全账户 + R9 解冻费 + R21 转陌生账户；一句话口诀："安全账户是假的，解冻费是二次收割，唯一出路是 110+银行止付。"

**⑦ 止损衔接（已内嵌于③，此处为收尾确认）**：确认已执行 停→断→核→冻→报 五步；核对是否已联系银行止付、是否已拨打 110 并保留证据；未完成任一步则立即补做。

**⑧ 知识复盘**：红色已受损场景**止损优先于定级**；凡"再转一笔才能解冻/返还/提现"一律是继续行骗；后续收到"追损专家/内幕回本渠道"全部拉黑。一句话口诀："止损窗口按分钟算，先报警止付再谈复盘。"

### 示例 W11（待核实·未收录新型·L3 广谱兜底·[推断]·禁止编造类型）

**用户输入**：
> 有个网友说帮我把手机寄到某地址"做数据修复"，说寄回来就给我 200 元补偿，运费他们出，还让我先扫码付 30 元"材料费"。我听着有点怪但不确定是不是骗局。

**① 信息收集（五要素）**：谁=陌生网友｜事=寄手机"数据修复"返补偿｜钱=先付 30 元材料费（对方承诺返 200）｜链=寄件 + 扫码付款｜急=无。

**② 风险扫描 + 预检路由**：语义明显异常（寄手机+返补偿+运费对方出）却**未命中标准 R/Y 谓词**（无安全账户/无验证码/无冒充）→ **不默认判绿**，触发 **L3 未知模式兜底**主动核验（verification-chain L3 未知模式兜底）。

**③ 谓词判定**：
- **L1**：未命中标准 R 系；仅部分接近 Y2（主动联系"返补偿"）与 R21 线索（扫码向个人账户付款）。
- **L2 反向证伪**：无正常解释（正规数据修复不会要求寄手机+先付材料费+承诺返补偿）→ 证伪不通过。

**④ L3 外部证据核验（未知模式兜底，广谱检索）**：自动 `web_search "寄手机 数据修复 返补偿 诈骗"` → 暂未命中高度匹配的公开预警 → 检索不足 → 标注 `[核验未达]`；同时检索"手机寄修 诈骗 个人信息"命中"寄修手机被盗用信息/机卡分离风险"类提醒 → 维持 `[待核实]`。

**⑤ L4 交叉印证**：内部 L1+L2 指向疑似但无标准谓词 + 外部核验未达 → 无法升档，维持 `[待核实]`，不硬下定论。

**⑥ L5 置信度标定**：[核验未达] 情形 → **不标定高低**，标 `[待核实]`。

**⑦ L6 人工复核闸门 + 输出（黄色「暂无法判定」卡 + 未收录标注）**：
```
【提醒】该内容存在可疑特征（语义异常：寄手机+返补偿+先付材料费），知识库未收录同类标准套路，按特征判定为疑似新型/变种，建议：
1. 不寄手机——手机含通讯录、短信、支付 App、验证码通道，脱离控制风险极高；
2. 不扫"材料费"二维码——扫码付款即 R21 转账信号；
3. 拨打 96110 反诈专线核实"寄手机返补偿"是否为已知套路；
4. 在此前：不转账、不点链接、不提供验证码、不寄任何物品。
结论：待核实 / [推断]（疑似新型，未收录类型，不编造类型名）
```

**⑧ 人群适配话术（通用）**：直白解释为什么怪（"寄手机 = 把银行卡和通讯录一起寄走"）；给出官方核实通道 96110；提示这类"占小便宜反失大物"套路的共同点。

**⑨ 止损衔接**：未扫码/未寄件 → 停止即可；已扫码付款 → 联系支付平台 + 金额小可 110 咨询；已寄出手机 → 立即 110 + 联系物流拦截 + 冻结手机号绑定账户（emergency-sop 已泄露账号处理）。

**⑩ 知识复盘**：未收录推理——五要（要钱 30 元 + 要控寄手机）→ 映射 R21/R9 线索，不编造类型名；输出标 [推断]/[待核实] + 官方渠道；语义异常不静默判绿（golden-cases U01-U03/F02 同规则）。一句话口诀："怪套路先别上头，96110 一问便知；手机要寄走，通讯录钱包全带走。"
