## 回归判定规则
1. 命中「期望类型 + 期望谓词 + 期望风险级」三者全部一致 = 通过。
2. 未收录样例（U 系列）必须：①先反向证伪；②输出挂标准 R/Y 谓词；③标 [推断]；④不编造类型名。
3. 绿色样例（G 系列）必须判绿或黄色核实，严禁因敏感词误判红（验证反向证伪前置生效）。
4. 任一失败 → 回 Plan/2 或对应源文件修复逻辑，重跑本集直至全绿。

### 示例 W1（红色·冒充公检法·含 L3 自动核验）

**用户输入**：
> 妈，我是市反诈中心民警，系统监测到你名下的银行卡涉嫌洗钱，现在要把资金转到"保护账户"做资金清查，全程保密别告诉任何人，加我发的会议链接开屏幕共享帮你操作。

**① 信息收集（五要素）**：谁=自称反诈中心民警｜事=银行卡涉嫌洗钱需资金清查｜钱=转到"保护账户"｜链=会议链接屏幕共享｜急=全程保密、限时。

**② 风险扫描 + 预检路由**：命中预检（冒充官方+安全账户+屏幕共享）→ 升级头脑风暴分析。

**③ 谓词判定**：
- **L1**：R15（冒充反诈/官方以"保护账户"为由要求转账/远程控制）+ R3（安全账户）+ R4（保密施压）+ R2（屏幕共享）+ R6（威胁时限）。
- **L2 反向证伪**：无正常解释（真实民警不会电话要求转账、不会要屏幕共享）；→ 证伪不通过，维持疑似。

**④ L3 外部证据核验（命中即自动发起）**：命中 R15/R3 红色硬指标 → 自动 `web_search "96110 反诈中心 要求转账"` → 命中公安部刑侦局官网与漳州政务 2026-05 解答：**"96110 绝不会索要验证码、密码或要求转账"** → 来源可溯源（公安部/地方政府官网）→ 标注 `[已核验-假]`。

**⑤ L4 交叉印证**：内部 R15 命中 + 外部核验-假（双源一致）→ 升档成立。

**⑥ L5 置信度标定**：红 + R≥2 + [已核验-假] → **高（极大概率，已外部核验）**。

