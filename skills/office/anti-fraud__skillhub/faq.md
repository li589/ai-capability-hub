# 防骗大师.Skill 常见问题（FAQ）

## 使用相关

**Q1：什么样的内容可以发来判定？**
短信、聊天记录截图或文字转述、邮件、链接、App 名称/界面、电话内容转述、二维码场景描述均可。贴原文越完整，判定越准。

**Q2：判定结果有哪几级？**
红 / 黄 / 绿 三级。红色=极大概率诈骗，必须立即停止转账/共享屏幕/提供验证码；黄色=可疑需核实，按核实清单先查证；绿色=有正常解释且无风险要求，正常处理。

**Q3：为什么有时不直接回答，先问几个问题？**
命中黄色或信息不足时会进入澄清/头脑风暴环节，先补齐可观察事实再定级，避免误判。

**Q4：能科普防骗知识吗？**
可以。36 类骗局均覆盖典型话术、判定特征、高发人群、应对与铁律，可直接询问任意一类。

## 判定机制

**Q5：什么是"反向证伪"？**
定级前先假设"这不是骗局"，检查内容是否有正常解释（官方提醒、真实订单、正常社交）。有正常解释且无风险要求→绿色；无正常解释且命中风险谓词→定级。避免"看到敏感词就喊诈骗"。

**Q6：红色和黄色怎么升/降级？**
命中任一红色谓词（R1-R22）直接定红；多条黄/红谓词交叉命中直接升红；涉及向个人/陌生账户转账（R21）、验证码、房产抵押，无论其他信息如何直接升红。黄色核实无异常→按绿色收尾并保留一句安全提醒；核实未反馈最多跟进 3 轮，之后维持黄色提醒。

**Q7：知识库没收录的骗局怎么办？**
如实说明"未收录类型，按特征判定"，用通用特征速记"五要"信号逐条说明命中/未命中，定级依据引用 risk-levels 谓词，结论标注 [推断]，禁止编造类型名；并走头脑风暴流程深挖沉淀。

## 主动守护

**Q8：哪些词会触发主动守护？**
转账、汇款、验证码、屏幕共享、远程控制、安全账户、保证金、解冻、刷单、投资稳赚、贷款、退款、理赔、中奖、银行卡、密码、FaceTime、屏幕录制等。命中红色谓词必须强制出强提醒卡，不得弱化为"顺带提醒"。

**Q9：强提醒卡长什么样？**
固定格式卡片，包含风险定级、命中特征、立即行动（停止转账/挂断/不共享屏幕）、核实渠道，红色命中后每轮回答前置一句话摘要，直至用户确认已脱离危险动作。

## 核实渠道

**Q10：96110 能主动来电要求转账吗？**
不能。96110 来电务必接听（预警劝阻），但它绝不会在电话中要求转账或索要验证码。任何"安全账户""反诈核查转账"都是诈骗，挂断后自行拨打 96110/110 核实。

**Q11：收到可疑电话/短信如何核实？**
只用自己存过的官方号码回拨（110、96110、银行卡面电话），不用对方提供的号码；涉及钱款先与本人/官方当面或电话确认。

## 演练

**Q12：怎么进行防骗演练？**
运行 workflows/anti-fraud-drill.yaml，指定 36 类中的任意骗局类型，由 fraudster 扮演骗子、user 练习应对、mentor 指导、evaluator 评估。无 workflow-runner 时按 SKILL.md 流程手工演练。

## 边界与安全

**Q13：可以帮用户直接操作转账/汇款吗？**
不代用户执行任何转账、汇款、支付操作。技能负责识别风险、给出建议与话术，最终动作由用户自行决定。

**Q14：遇到受害者情绪激动怎么办？**
先情绪安抚（family-support.md），再给行动清单，避免说教；涉及已转账的引导立即报警并联系银行止付。

**Q15：可疑链接能点开验证吗？**
不能点开。按链接安全边界处理：解析域名、比对官方渠道、不输入任何个人信息，必要时用浏览器安全打开但绝不提交数据。

**Q16：技能不适用哪些场景？**
不代替报警立案、不代理维权追款、不给法律/投资/医疗专业结论、不做心理危机干预（可转介 12356）。已进入司法程序的案件只给官方通道；涉及专业结论请咨询律师、持牌机构与医生。

**Q17：什么是"真伪辨别链"？为什么红色结论不再是固定"高"？**
真伪辨别链（references/verification-chain.md）把判定从"内部命中谓词"升级为"可外部验证的结论"：L3 对 [待核实] 项或具体主体用 web_search/RAG/官方清单发起可溯源核验；L4 要求 ≥2 独立来源一致才升档，冲突即降级待核实；L5 按证据强度把置信度量化为 高/中/低（不再写固定占位）；L6 高危结论只作警示、最终动作由你本人确认。这样既能借外部权威源降误判，又避免把"内部怀疑"当成"已证实"。

## 判定增强（v2.0.12）

**Q18：我描述得很模糊，技能会怎么处理？**
不再逐条追问。技能会一次性抛出一张澄清清单（对方身份 / 要求你做什么 / 是否涉及钱 / 是否点链接下载 / 是否施压 / 是否已付款或泄露信息），你一次补齐即可定级。若补齐后仍关键信息不足，**不会硬判红或绿**，而是给一张黄色「暂无法判定」卡：写明还缺什么、标 [待核实]、附官方核验渠道（96110 / 110 / 官方 App），并提示"补齐前不转账、不点链接、不提供验证码"。

**Q19：遇到没见过的新骗术怎么办？**
即便内容没命中已知的 36 类套路，只要语义明显异常（陌生但高压 / 胁迫 / 要求保密 / 要求非常规操作），技能会主动发起外部广谱检索核验是否存在同类公开预警，并明确标注"疑似新型骗局 / 未收录，建议以官方渠道核实"，结论标 [待核实] 或 [推断]；不会静默放过，也不会编造骗局类型名。
