# 中文十三辙韵律体系

押韵是中文歌词「可唱可记」的骨架。本技能采用传统十三辙归类句末韵母，便于统一韵脚与换韵设计。

|------|------|------|--------|
| 发花辙 | a, ia, ua | 花、家、夏、下、霞 | 高（开口亮） |
| 梭波辙 | o, e, uo | 波、歌、火、错、落 | 中 |
| 乜斜辙 | ie, üe | 月、雪、别、裂、缺 | 中（古风常用） |
| 一七辙 | i, ü | 一、里、雨、去、你 | 极高 |
| 姑苏辙 | u | 苦、路、住、输、舞 | 中 |
| 怀来辙 | ai, uai | 来、开、在、外、怀 | 高 |
| 灰堆辙 | ei, uei(ui) | 飞、回、泪、醉、谁 | 高 |
| 遥条辙 | ao, iao | 早、角、了、桥、笑 | 高（开口高音好唱） |

## 落音规则

- **句末落音要清晰**：避免连续同声调，否则旋律「平」
- **副歌高音落开口呼**：发花/遥条/江阳辙开口大，便于高音延展与传唱
- **窄韵慎用于高潮**：一七/姑苏辙口型窄，高音易「闷」，多用于主歌铺陈
- **避免「倒字」**：句末字的本音调与旋律走向冲突时听感别扭，必要时换同韵字

## 各曲风押韵策略

| 曲风 | 策略 |
|------|------|
| 流行 | 主歌偶数句押韵，副歌句句押强化记忆；主副歌换韵 |
| 民谣 | 宽韵即可（偶数句押），叙事重于押韵，可跨宽韵 |
| 说唱 | 句句押、多押（双押/三押）、内部押韵；Hook 旋律化押韵 |
| 古风 | 一韵到底或换韵对仗；多用江阳/言前/中东辙 |
| 摇滚 | 情绪驱动，不刻意，偶数句落韵即可 |
| 电子 | 循环句押韵，Drop 段一两句循环押死 |
| R&B | 转音处落韵，句末开口呼便于拖音 |

## 换韵设计

换韵制造段落反差与记忆点：

- **主歌 A 韵 -> 副歌 B 韵**：最常见，主歌铺陈用窄韵，副歌爆发换开口韵
- **桥段换 C 韵**：制造转折新鲜感，再回副歌 B 韵收束
- **全曲一韵**：仅古风刻意为之，其他曲风避免（易单调）

## 多押（说唱专用）

- **双押**：句末两字同韵，如「散场 / 看穿」（an-ang / an-uan 视具体）
- **三押**：句末三字同韵，难度高、记忆强
- **内部押韵**：句中非句末字也押，制造 Flow 律动
- **三连音**：三个短句同韵密集排列，强化节奏

## 宽韵与窄韵

- **宽韵**：言前/人辰/江阳/中东辙字数多，易押，适合长篇
- **窄韵**：乜斜/姑苏辙字数少，易重复，慎用于大段
- 创作中若窄韵卡壳，果断换宽韵，勿为押韵牺牲语义
