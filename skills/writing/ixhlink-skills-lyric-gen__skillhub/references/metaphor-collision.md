# 隐喻碰撞技术 (Metaphor Collision)

源自 Pat Pattison。核心：**新鲜比喻来自两个具象事物的碰撞，而非一个抽象概念配一个常见喻体。** 「爱是火」「时间如水」之所以陈旧，因为抽象+公共喻体；「告别像散场电影」新鲜，因为具象+具象碰撞。

## 碰撞公式

```
[载体：你想表达的抽象/情感] + [喻体：另一个感官域的具体事物] = 碰撞句
```

关键：载体和喻体都要**具象化**。先把抽象情感转成一个具体场景（用感官写作法），再找喻体。

## 四步流程

### 第 1 步：具象化载体

把主题/情感转成一个可感知的场景或物体。

- 主题「暗恋」-> 载体场景「偷偷记住他点过的每一首歌」
- 主题「遗忘」-> 载体场景「相册里被抽掉的那一页」

### 第 2 步：从另一感官域选喻体

喻体必须来自与载体**不同的感官域或生活领域**，制造陌生感。

- 载体是「听觉域（歌）」-> 喻体选「自然/机械/物理现象」
- 候选喻体池：退潮、停电、散场、断网、融雪、锈蚀、错版、过期、调频失准

### 第 3 步：写出碰撞句

格式：`[载体场景] 像/是 [喻体]，[碰撞后的结果]`

生成 3 个以上候选，全部写出再筛：

```
暗恋像调频失准的电台，信号满格却听不清歌词
暗恋像过期未拆的礼物，拆开才发现已经不属于这个季节
暗恋像散场后的字幕，没有人留下来看
```

### 第 4 步：筛选标准

挑进歌词的比喻需满足：

- **新鲜**：喻体不常见（淘汰 火/水/刀/风/雨 单独使用）
- **贴题**：碰撞结果与主题情绪一致
- **可唱**：字数节奏能落进旋律
- **有结果**：不止「A 像 B」，要写出「像 B 之后怎样」（碰撞的后果才是金句）

## 陈词淘汰清单（一律不用）

爱是火、爱如潮水、时间如水、心如刀割、泪如雨下、情比金坚、如沐春风、梨花带雨、往事如烟、岁月如歌、思念如风、痛彻心扉。

> 若主题天然指向这些，必须换喻体角度（如「思念」不用风，用「冰箱里多买的那份酸奶过期了」）。

## 喻体域库（按载体类型推荐跨界方向）

| 载体类型 | 推荐喻体域 | 示例 |
|----------|------------|------|
| 听觉（歌/声音） | 物理/机械 | 调频失准、回声延迟、磁带卡带 |
| 时间（等待/遗忘） | 食物/生物 | 过期、发酵、脱水、冬眠 |
| 距离（分离/思念） | 信号/交通 | 断网、晚点、错站、调频 |
| 关系（暗恋/分手） | 场所/仪式 | 散场、停业、撤展、关门 |
| 自我（迷茫/成长） | 地理/天气 | 迷航、倒春寒、汛期、断流 |

## 示例库

| 主题 | 载体场景 | 喻体 | 碰撞句 |
|------|----------|------|--------|
| 告别 | 散场不走 | 电影散场灯亮 | 告别像散场电影的灯，亮得太早 |
| 暗恋 | 偷记歌单 | 调频失准 | 暗恋像调频失准的电台，满格信号听不清词 |
| 遗忘 | 抽掉的相册页 | 断更的连载 | 遗忘像断更的连载，没人等得到下回 |
| 迷茫 | 天桥看车流 | 三岔路口 | 迷茫像站在三岔路口，三条都像又都不像 |
| 和解 | 没发出的道歉 | 退潮 | 和解像退潮，沙滩上终于露出没被带走的东西 |

## 禁忌

- 抽象配公共喻体（爱是火）
- 只有「A 像 B」没有碰撞后果（缺金句）
- 一首歌堆砌超过 3 个不同比喻（散焦，听众记不住）
- 比喻与曲风违和（古风慎用现代机械喻体，电子慎用古典意象，除非刻意混搭）
