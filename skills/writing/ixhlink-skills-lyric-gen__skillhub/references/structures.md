# 歌曲结构设计

结构决定听众的注意力曲线。好歌词 = 每段有明确任务 + 段间有情绪起伏。

## 各段任务

| 段落 | 任务 | 长度 | 情绪 |
|------|------|------|------|
| Intro 引 | 建立时空/氛围，可纯意象无叙事 | 2-4 句 | 低、定调 |
| Verse 主歌 | 叙事铺垫，场景+人物+冲突伏笔 | 4-8 句 | 中低，递进 |
| Pre-Chorus 预副歌 | 情绪升温，引向副歌核心感受 | 2-4 句 | 升 |
| Chorus 副歌 | 金句记忆点 + 主题宣言，全曲最高传播 | 4-8 句 | 高、爆发 |
| Bridge 桥段 | 视角/情绪反转，制造惊喜，常换韵 | 2-6 句 | 转折 |
| Outro 尾奏 | 淡出收尾，呼应开篇意象 | 2-4 句 | 落、回旋 |

## 情绪曲线

```
低 ────────────────────────── 高
Intro ─ Verse ─ PreChorus ─ Chorus ╲ Bridge ╱ Chorus(顶) ─ Outro
```

- 主歌铺场景，预副歌升温，副歌顶点
- 第二遍主歌推进或转折，不能重复第一遍
- 桥段是「意料之外」，换视角/换时态/换人称皆可
- 末副歌是全曲最高点，可升调/加和声/改首句

## 重复与变体

- **副歌重复**：核心句可重复 2-3 次强化记忆，但首句可微调避免雷同
- **动机重复**：一个核心意象/短语贯穿全曲（民谣常用），如「散场」在主副桥尾反复出现
- **避免照搬**：第二遍主歌须有新信息，不能是第一遍的换词重复

## 转调与升腾

- 末副歌可升半音/全音，制造最终爆发
- 桥段转调后回副歌，落差感放大高潮
- 词作者标注「升调处」提示曲作者/演唱者

## 结构选择

- **短版**（主+副）：demo/片段，2 段
- **标准版**（V-PC-C-V-C-B-C）：主流流行，6-7 段
- **完整版**（含双主歌+预副+桥段+尾奏）：专辑收录，8-10 段
- 说唱用 Intro-Verse-Hook-Verse-Hook-Bridge-Hook
- 电子用 Build-Drop 循环结构

## 段间衔接

- 主歌末句留「钩」引向预副歌（悬念/未完成动作）
- 预副歌末句落韵引向副歌首句同韵
- 副歌首句即金句，不等铺垫
- 桥段首句制造反差（换人称/换时态/换意象域）
