# 交付质检清单

成稿交付前逐项自检。可唱性优先于文学性。

## 一、意象与表达

- [ ] 每段至少 1 个具体感官意象（非抽象情感词）
- [ ] 比喻新鲜，无陈词（爱是火/时间如水/心如刀割等已淘汰）
- [ ] 抽象情感已感官化（「孤独」->具体画面）
- [ ] 核心意象/动机贯穿全曲或重复强化

## 二、结构与记忆

- [ ] 结构符合曲风（查 genre-profiles.md）
- [ ] 副歌有 1 句可被记住的金句
- [ ] 第二遍主歌有新信息，非换词重复
- [ ] 桥段有反转（换视角/时态/人称/意象域）
- [ ] 段间衔接有钩，预副歌引向副歌同韵

## 三、韵律与可唱性

- [ ] 主歌/副歌换韵（除古风一韵到底）
- [ ] 句末落音清晰，无连续同声调
- [ ] 副歌高音处落开口呼（发花/遥条/江阳辙）
- [ ] 韵脚密度符合曲风（说唱高、民谣低）
- [ ] 无「倒字」（句末字调与旋律冲突）
- [ ] 朗读通顺，换气点合理

## 四、人味去 AI

- [ ] 无四字格律堆砌
- [ ] 无过度对仗
- [ ] 句长长短交替，无连续等长
- [ ] 无冗余连接词（于是/因此/然而）
- [ ] 无书面体腔调

## 五、意图与格式

- [ ] 用户给定的主题/故事/核心词已保留
- [ ] 按固定输出格式交付全部区块
- [ ] 韵律/金句/可唱性/质检说明完整

## 评分

每项 1 分，满分约 22 分。

- ≥ 18：可交付
- 14-17：需局部润色
- < 14：返工意象与结构

不达标项在「质检报告」中标注，并在能力范围内优化后再交付。
