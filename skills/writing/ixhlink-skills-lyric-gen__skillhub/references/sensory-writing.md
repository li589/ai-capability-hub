# 感官写作法 (Object Writing)

源自伯克利音乐学院 Pat Pattison《Songwriting Without Boundaries》。核心信条：**抽象情感无法被「听」到，只有具体意象能进耳朵、进画面。** 写歌词前先做感官挖掘，把「主题」变成可看可触的「物体/动作」。

## 为什么先挖意象

- 「我很孤独」是告知，听众无感
- 「外卖单上只有一份」是画面，听众有画面
- 告知词（快乐/悲伤/孤独/幸福）一律降级为「待感官化」标记，必须改写

## 六感挖掘流程

围绕主题，限时 5 分钟，从六感各挖 3-5 个**具体名词或动作**。规则：

1. 只写名词或动词短语，**禁止形容词概括**（❌「美好的」✅「发烫的跑道」）
2. 越具体越好（❌「车」✅「末班地铁」）
3. 越私人越好，私人=独特=不 AI
4. 不评判，先堆量再筛选

### 六感提问表

| 感官 | 提问 | 产出类型 |
|------|------|----------|
| 视觉 | 看见什么颜色/形状/光影/物品？ | 颜色+物体名词 |
| 听觉 | 什么声音/语调/节奏？ | 拟声词+声音名词 |
| 触觉 | 什么温度/质感/重量？ | 质感形容词+触感动作 |
| 嗅觉 | 什么气味？ | 气味名词 |
| 味觉 | 什么味道？ | 味道名词 |
| 动觉 | 什么动作/运动/方向？ | 动词短语 |

### 示例：主题「北漂漂泊」

| 感官 | 挖掘 |
|------|------|
| 视觉 | 合租房的隔断墙、地铁口的早高峰、便利店凌晨的灯 |
| 听觉 | 地铁报站、楼上拖椅子、洗衣机半夜转 |
| 触觉 | 潮湿的被角、冰凉的钥匙、挤到变形的背包 |
| 嗅觉 | 隔夜外卖、地铁人群的汗、樟脑丸 |
| 味觉 | 廉价咖啡的苦、泡面的咸、想家时嘴里的发酸 |
| 动觉 | 赶车奔跑、刷卡进站、站在天桥往下看 |

## 从意象到句子的三步

1. **选 1-2 个最强意象**做开篇（视觉优先，建立画面）
2. **加一个动作**让画面动起来（动觉入场）
3. **情绪藏在动作里**，不直说（「我没接住夏天」而非「我好难过」）

### 改写对照

| 告知（AI 味） | 感官化（人味） |
|---------------|----------------|
| 我很想念你 | 你的杯子还在窗台，水渍干了一圈 |
| 这段感情结束了 | 门关上，钥匙留在锁孔里 |
| 我很迷茫 | 站在天桥上，车流分成了三个方向 |
| 我们回不去了 | 旧磁带卡在第二首，再也转不动 |

## 练习模板（限时训练）

每天选一个主题词（如「等待」「初雪」「失业」），按六感表各写 5 条，连续 90 天。Pat Pattison 称之为 Object Writing，是作词人的基本功。本技能创作时即用此法即时挖掘，不依赖训练积累。

## 禁忌

- 用「美好的/痛苦的/难忘的」等评价形容词替代具体物
- 意象过于公共化（月亮代表思念已被用烂，除非有新角度）
- 一段塞满六感，反而失去焦点--每段聚焦 1-2 个感官即可
