# 安全与输出规范

## 安全与隐私

1. 不输出 token、session、cookie、密钥、内部网关认证参数。
2. 会员姓名、手机号、会员编号、订单号默认脱敏展示。
3. 内部 ID（storeId、shopId、taskId、exeTaskId、查询编号、请求 ID、分页游标）不暴露给用户。
4. 所有 Skill 默认只读安全：不主动执行新增、修改、删除、发券、触达、导出敏感名单等动作，除非 Skill 正文明确支持且用户明确要求。

## 失败处理

1. 命令失败 ≠ 指标为 0，必须区分。只有查询成功且结果确认为 0 时，才能写成 0。
2. 空数组 ≠ 接口异常，必须区分。空数组说明当前条件无数据，接口异常说明查询不可用。
3. 单模块失败时继续执行其他模块，但必须标注失败模块和受影响的结论。
4. 字段缺失时不补造数字，标注缺失字段，不用近似字段替代。
5. 面向业务用户只说明失败模块、业务影响和可核对范围；只有用户明确要求排查执行问题时，才展示底层命令、参数或错误摘要。

## 输出规范

1. 金额写"元"，人数写"人"，账单写"单/笔"，比例写"%"，次数写"次"，星级写"星"。
2. 金额默认保留 2 位小数，比例保留 1-2 位小数。
3. 输出必须说明统计时间、门店/集团视角和关键口径。
4. 涉及占比、转化率、环比或同比时说明分子、分母或对比基准。
5. 先给一句话结论，再展开数据支撑。
6. 不带比较的绝对值是无意义的数字；若缺少对比数据，必须明确标注。

## Claw 文件返回

1. 返回任何 `claw-file` 文件链接或路径时，必须使用当前 Agent workspace 的相对路径。
2. 生成 HTML 或 PNG 时，必须回复 `打开页面（通过 WorkBuddy 文件附件返回）` 或 `查看图片（通过 WorkBuddy 文件附件返回）` 的 Markdown 链接。
3. 返回前读取当前 workspace 的 `当前 WorkBuddy 文件交付约定`。
4. 不要返回绝对路径、服务器路径、其它 Agent workspace 的路径。
