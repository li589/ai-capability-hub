# 业绩点评（精简版）说明书

本目录是 `业绩点评` skill 的完整说明书，仅实现"精简版"业绩点评效果，按 `产业链速览` skill 的分层范式封装。固定提示词逐字取自《业绩点评》需求文档的"精简版"提示词，**不做任何修改，直接使用**。

## 文件说明

- [SKILL.md](SKILL.md)：主说明，定义触发场景、输入识别、固定提示词、执行节奏、MCP 召回规则、用户可见提问组装、输出目录、最终报告结构、异常处理与质量红线。
- [full-mode.md](full-mode.md)：执行流程，细化请求解析、主体与报告期确认、分线召回、变量填充与精简版写作、中间稿与交付前校验。
- [user_guide.md](user_guide.md)：面向使用者的说明（能做什么、怎么用、生成什么、注意事项）。

固定提示词（执行时按"关注点是否为空"二选一，填入变量后直接使用）：

- `精简版_有关注点提示词.txt`：用户给出 `关注点` 时使用，变量 `{{focusText}}`、`{{companyText}}`、`{{reportText}}`
- `精简版_无关注点提示词.txt`：用户未给出 `关注点` 时使用，变量 `{{companyText}}`、`{{reportText}}`

## 分支与提示词对应关系

| 场景 | 使用提示词 | 变量 |
|---|---|---|
| 有关注点 | `精简版_有关注点提示词.txt` | `{{companyText}}` ← 公司名称；`{{reportText}}` ← 报告期；`{{focusText}}` ← 关注点 |
| 无关注点 | `精简版_无关注点提示词.txt` | `{{companyText}}` ← 公司名称；`{{reportText}}` ← 报告期 |

## 变量约定

填充提示词时只替换以下变量，不改动提示词其它任何文字：

- `{{companyText}}`：上市公司名称
- `{{reportText}}`：报告期（如 `2025Q1`、`2024年报`、`2025半年报`）
- `{{focusText}}`：用户关注点（仅有关注点版本）

## 完整性说明

本说明书是自包含版本，仅覆盖"精简版"。完整版（财务风险识别 / 盈利预测 / 投资总结等模块化输出）不在本 skill 范围内。如需注册为正式 skill，可直接采用本目录。
