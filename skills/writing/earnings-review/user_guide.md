# 业绩点评（精简版）

> 给它一家公司和一个报告期——它自动翻遍定期公告、纪要、点评、研报和财务数据，把"这期业绩怎么样、为什么、有哪些重要经营变化、估值贵不贵、市场在分歧什么"一次性串成一份能直接读的精简版业绩点评。

**这是一个 AI 投研助手，在对话框里说一句"点评下某公司某报告期的业绩"就能用，不用自己扒财报、算同环比、查研报盈利预测。**

---

## 1、能做什么？

聚焦"精简版"——一份高密度、可读、带批判性的业绩点评：先用一句话 + 3-5 个核心看点让你 30 秒抓住结论，再依次讲清业绩事件、同环比变化原因、历史与单季度对比、分业务拆解、重要经营变化、经营展望，最后给出基于券商盈利预测与实时市值的投资建议和市场分歧点。看的是**业绩背后的经营真相与定价逻辑**，而不是一堆数字罗列。

具体会自动做这几件事：

- **锁主体**：确认公司唯一主体（全称 + 市场 + 代码），数据精确匹配到对应报告期
- **拉数据**：按优先级（用户上传 > 公告库 > 纪要 > 点评 > 研报 > 互联网）召回业绩、财务、主营业务分拆、最新市值
- **写点评**：按精简版固定模版成稿，含必要表格，结合你的关注点展开
- **给结论**：盈利预测 + PE/PS 测算 + 投资逻辑 + 市场潜在分歧点

> 本助手只产出"精简版"。完整版（更长的财务风险识别 / 盈利预测 / 投资总结分模块）不在范围内。

---

## 2、怎么用？

在对话框里给"公司 + 报告期"即可——

```
帮我点评一下宁德时代2024年报的业绩
```

想特别关注某个角度，就加一句关注点：

```
紫金矿业2025Q1业绩点评，重点关注铜金量价齐升
```

> **你只需准备**：公司名称（必填）、报告期（必填）、关注点（选填）。其余交给 AI。
> 公司或报告期没说清时，AI 会先找你确认，不会瞎猜。

---

## 3、多久跑一次？

**按需触发**，通常在某公司财报/业绩预告披露后、做个股研究或持仓跟踪时跑一次。

---

## 4、生成什么？

`{公司名称}{报告期}业绩点评_{日期}.md` — 精简版业绩点评：

| 章节 | 内容 |
|:---|:---|
| 📋 精简版 | 业绩一句话总结 + 3-5 个核心看点 |
| 1、事件：业绩情况 | 整体 / 单季度业绩，按报告期口径的同环比 |
| 2、点评要点 | 同环比原因 / 历史对比 / 业务拆解（含表格）/ 重要经营变化 / 经营展望 |
| 3、投资建议 | 盈利预测 + 实时市值 PE/PS 测算 + 投资逻辑 + 市场分歧点 |

---

## 5、输出在哪？

- 最终报告保存到 `{输出目录}/{公司名称}/业绩点评/{公司名称}{报告期}业绩点评_{日期}.md`，首次运行自动逐级创建目录

---

## 6、注意事项

- **必填两项**：公司名称、报告期缺一不可，缺了会先找你补
- **精确匹配业绩期**：所有数据严格对应该公司该报告期，不会拿相邻报告期凑数
- **观点全部有来源**：业绩数据、经营变化、盈利预测、市值都来自检索，不编造
- **不输出"没找到"**：缺数据就跳过该项，绝不出现"没有找到相关数据/暂不列示"等影响阅读的字样
- **专业口吻**：以资深券商分析师视角、带批判性地叙述，不暴露 AI 身份
- **合规红线**：不引导披露未公开订单、未公告财务数据、内部目标或非公开信息
- **找不到资料时**：会明确告知暂时无法输出，并建议你换公司或换业绩期，而不是硬编
