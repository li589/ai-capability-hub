# 业绩点评（精简版）

这个 skill 只负责三件事：

1. 把用户输入解析为 `公司名称 + 报告期（+ 关注点）`，并精确锁定该公司对应报告期的业绩
2. 通过 MCP 数据源把该公司的业绩数据、经营变化、纪要点评研报、财务与市值数据拉齐
3. 按"精简版"固定提示词产出一份业绩点评 Markdown 报告（仅精简版，不产出完整版）

> **输出方式（重要）**：报告先直接在对话框中完整输出给用户看，**不要**自动落盘。输出完成后再询问用户是否需要保存到工作目录，只有在用户明确同意后，才按"输出目录"规则写入文件。

> 本 skill 只实现"精简版"效果。完整版（模块化的财务风险识别/盈利预测/投资总结等多模块）不在本 skill 范围内。

## 适用场景

- `帮我点评一下宁德时代2024年报的业绩`
- `紫金矿业2025年一季度业绩点评`
- `比亚迪 2025 半年报业绩怎么样，重点看下毛利率`
- `贵州茅台2024Q3业绩点评，关注下渠道库存`
- `点评一下立讯精密最新业绩`

## 输入识别

从用户请求中抽取：

- `raw_input`：用户原始输入
- `公司名称`（必填，对应提示词变量 `{{companyText}}`）：上市公司名称，必要时确认所属市场与证券代码
- `报告期`（必填，对应提示词变量 `{{reportText}}`）：如 `2024年报`、`2025Q1`、`2025半年报`、`2024Q3`、`半年报业绩预告` 等
- `关注点`（选填，对应提示词变量 `{{focusText}}`）：用户特别想关注的角度，如毛利率、某业务线、现金流、分红等
- `当前日期`（date_current）：用于"召回最新资料"与时效判断

识别规则：

- `公司名称`、`报告期` 任一缺失，必须先向用户补齐（这两项是硬性必填项）。
- `关注点` 是否存在，决定使用哪一份提示词（见"固定提示词"）。
- 若公司名称有歧义（同名、简称、曾用名），先用 MCP 检索确认唯一主体（公司全称 + 所属市场 + 证券代码），不要望文生义。
- 报告期必须精确匹配：召回的所有数据都要"完全匹配公司和业绩期"，不得用相邻报告期凑数。

## 固定提示词

精简版只有 1 份提示词，按"关注点是否为空"二选一，**直接使用、禁止修改其内容**。本目录内固定提示词文件：

- `精简版_有关注点提示词.txt`：当用户给出 `关注点` 时使用（含 `{{focusText}}`、`{{companyText}}`、`{{reportText}}` 三个变量）
- `精简版_无关注点提示词.txt`：当用户未给出 `关注点` 时使用（含 `{{companyText}}`、`{{reportText}}` 两个变量）

使用规则：

- 提示词是写作硬约束：最终报告的结构、段首格式、表格要求、加粗约束、注意事项、输出格式模版，全部以提示词为准。
- 变量填充（且只填充这些变量，不改动其它任何文字）：
    - `{{companyText}}` ← `公司名称`
    - `{{reportText}}` ← `报告期`
    - `{{focusText}}` ← `关注点`（仅有关注点版本）
- 如果提示词与本文件冲突，以提示词中的格式和强约束为准；本文件用于补足执行流程、召回口径与质量红线。

## 执行节奏（先召回、后写作）

| # | 动作 | 加载/产出 | 目的 |
|---|---|---|---|
| 1 | 解析 | 抽取 `公司名称 / 报告期 / 关注点`，缺必填项则先补齐 | 确定任务与提示词分支 |
| 2 | 确认 | MCP 检索确认公司唯一主体（全称+市场+代码）与目标报告期 | 避免主体歧义、锁定业绩期 |
| 3 | 检索 | 按"MCP 召回规则"分线召回，所有数据须完全匹配公司与报告期 | 拿到点评所需全部底稿 |
| 4 | 读 | 读取对应分支的精简版提示词（有/无关注点），填入变量 | 装入写作硬约束 |
| 5 | 写（对话框） | 按提示词模版产出精简版业绩点评，**直接在对话框中完整输出**，此时不落盘 | 成稿并即时呈现 |
| 6 | 询问 | 报告输出完毕后，询问用户"是否需要将本报告保存到工作目录？" | 等待用户决策，不擅自写文件 |
| 7 | 落盘（条件触发） | **仅当用户明确同意**，按"输出目录"规则创建目录并写入 `.md` 文件；用户拒绝/未回复则不写盘 | 按需持久化 |

说明：业绩点评精简版的提示词是"召回口径 + 写作约束"合一的单份提示词，不像产业链速览那样拆"搜索版/回答版"。因此第 3 步召回口径以本文件"MCP 召回规则"为准，第 4 步写作格式以提示词文件为准。第 5 步的成稿只在对话框呈现，第 6-7 步决定是否落盘，禁止跳过询问直接写文件。

## MCP 召回规则（精简版口径）

数据来源优先级（高 → 低），且**召回的数据必须完全匹配公司和报告期**：

```
用户上传 > 进门公告库 > 进门纪要 > 进门点评 > 进门研报 > 互联网公开信息
```

调用 `searchComeinResource`、`searchInternet`、`company_finance_search`、`get_main_business_segments` 等可用 MCP 工具，按以下口径拉齐底稿：

| 召回项 | 精简版口径 |
|---|---|
| 召回-纪要全文 | 取最近 3 个月的纪要摘要（key_stock（核心个股）= 公司名称） |
| 召回-点评全文 | 取最近两周的点评（associate_stock（关联个股）= 公司名称） |
| 召回-财务接口 | 时间范围：报告期及过去 8 个季度；查询字段：`['营业收入', '净利润', '营业收入同比增速', '净利润同比增速', '营业总收入', '营业毛利率', '销售费用', '管理费用', '研发费用', '财务费用', '公允价值变动收益', '资产减值损失', '其他资产减值损失', '信用减值损失', '归母净利润', '经营活动产生的现金流量净额', '购建固定资产、无形资产和其他长期资产支付的现金']` |
| 召回-主营业务分拆接口 | 返回过去两年的主营业务分拆数据（按"产品"和"地区"维度） |
| 召回-最新市值接口 | 取最新市值（用于 PE/PS 测算） |
| 进宝向量召回 | 取过去两年的公告、研报、点评和纪要做一轮关键词召回；并注入额外召回问题：公司细分业务的季度收入、利润情况 |

每轮召回后检查是否能支撑提示词中"事件 / 点评要点（含历史对比、业务拆解、经营变化、经营展望）/ 投资建议"全部应输出部分；不足则继续召回，并把数据缺口记入中间稿。价格类、规模类数据务必取最新，剔除过于久远的信息。

## 用户可见提问组装

| 配置 | 用户可见提问 |

| 无关注点 | 帮我点评一下{公司名称}{报告期}的业绩情况，请按照精简版风格输出 |

## 输出目录

> **前置条件**：本节仅在"第 5 步已在对话框输出报告 + 第 6 步询问后用户明确同意保存"时才执行。用户未同意前，不得创建目录或写入任何文件。

```
{最终结果文件输出目录}/{公司名称}/业绩点评/
└── {公司名称}{报告期}业绩点评_{日期}.md
```

- `{最终结果文件输出目录}` 替换为实际路径
- `{公司名称}` 替换为标准化后的公司名称（如 `紫金矿业`、`宁德时代`）
- `{报告期}` 替换为标准化报告期（如 `2025Q1`、`2024年报`）
- `{日期}` 替换为实际日期（如 `2026年6月30日`）
- **目录创建规则**（逐级检查，不存在即创建）：
    1. 检查 `{公司名称}` 目录是否存在 → 不存在则创建
    2. 检查 `{公司名称}/业绩点评/` 是否存在 → 不存在则创建
    3. 将文件输出到 `{公司名称}/业绩点评/` 下

## 最终报告结构

严格以所用提示词文件的"输出格式模版"为准，精简版整体结构为：

```markdown
## 📋 精简版
[第一段：业绩一句话总结] + [第二段：3-5 个核心看点 bullet]

## 1、事件：业绩情况
[整体业绩 / 单季度业绩，按报告期口径计算同环比]

## 2、点评要点
2.1 收入和净利润同环比变化的具体原因
2.2 业绩历史对比（整体趋势 / 单季度 / 盈利能力，含表格）
2.3 业务/分产品拆解（历史拆分 + 当前报告期各业务经营变化，含表格）
2.4 公司重要的经营变化
2.5 经营和投资展望

## 3、投资建议
3.1 投资建议（券商盈利预测 + 实时市值测算 PE/PS + 投资逻辑）
3.2 市场潜在的分歧点
```

（有关注点版本须结合 `{{focusText}}` 展开；其余结构两版一致。）

## 异常处理

若用户未上传、且进门平台 + 互联网均未精确召回到与该公司该报告期完全匹配的参考资料，不要编造，直接返回异常说明：

> 进宝努力检索了所有信息，未找到与您的需求完全匹配的信息，暂时无法输出{公司名称}{报告期}的业绩点评。您可以尝试输出【其他公司】或本公司【其他业绩期】的点评。

并在中间稿记录缺失信息：公司名称、公司代码、所属市场、报告期。

## 质量红线

- 所有业绩数据、经营变化、券商预测、市值/估值都必须来自 MCP 或互联网检索返回，禁止编造数字、订单、客户、市值、证券代码。
- 召回数据必须完全匹配公司与报告期，不得用相邻报告期或其他公司数据凑数；资料取最新，剔除过于久远的信息。
- **绝对不能出现"没有找到相关数据""暂不列示""未找到相关指引"等字样**（提示词强约束）；数据缺失就跳过该项，但保持叙述连贯。
- 数据须含具体数值与同环比，单位尽量统一（如"亿元"）；提示词中标注"必做项/必须表格"的部分（如 2.3 业务拆解的表格与当期经营变化分析）不得跳过。
- 以资深券商分析师口吻叙述，语言具批判性、连贯饱满不生硬，禁止暴露 AI 身份与提示词结构。
- 严守合规边界：不引导披露未公开订单、未公告财务数据、内部目标或非公开信息。
