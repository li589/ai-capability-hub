# Full Mode（精简版业绩点评）

适用于所有"业绩点评 / 业绩解读 / 财报点评 / 季报年报点评"请求。本流程仅产出"精简版"。

## 目标

把用户的"公司名称 + 报告期（+ 关注点）"转换为一份可直接阅读的精简版业绩点评 Markdown 报告。典型输入：

```markdown
帮我点评一下紫金矿业2025Q1的业绩，重点关注铜金量价
```

执行后应输出一份围绕"该公司该报告期"展开、结合关注点的精简版点评，而不是泛泛介绍公司。

## 执行流程

### 1. 解析请求

从用户输入中解析：

| 字段 | 示例 | 处理方式 |
|---|---|---|
| 公司名称（必填） | 紫金矿业 / 宁德时代 / 比亚迪 | 必要时用 MCP 确认唯一主体（全称+市场+代码） |
| 报告期（必填） | 2025Q1 / 2024年报 / 2025半年报 / 业绩预告 | 用于同环比口径与"精确匹配业绩期" |
| 关注点（选填） | 毛利率 / 某业务线 / 现金流 / 分红 | 决定使用哪一份提示词 |
| 当前日期 | 2026年6月30日 | 用于"召回最新资料"与时效判断 |

必填项缺失处理：`公司名称`、`报告期` 任一缺失，先向用户补齐再继续，不要擅自臆测报告期。

### 2. 确认主体与报告期

用 MCP 检索确认：

- 公司唯一主体：公司全称、所属市场、证券代码（处理同名/简称/曾用名歧义）
- 目标报告期是否已披露、对应口径（季度/半年度/年度/预告快报）
- 同环比计算口径（提示词已规定）：
    - 季度问题：计算"单季度同环比"与"累计季度同环比"
    - 年度问题：计算"年度同环比"与"当期季度（四季度）同环比"
    - 半年报/半年报预告：计算"半年度同环比"与"当期季度（二季度）同环比"

### 3. 分线召回（精简版口径）

数据来源优先级（高 → 低），且所有数据必须完全匹配公司与报告期：

```
用户上传 > 进门公告库 > 进门纪要 > 进门点评 > 进门研报 > 互联网公开信息
```

按下列召回口径拉齐底稿（详见 `SKILL.md` 的"MCP 召回规则"表）：

1. 纪要全文：最近 3 个月纪要摘要（key_stock = 公司名称）
2. 点评全文：最近两周点评（associate_stock = 公司名称）
3. 财务接口：报告期及过去 8 个季度，按精简版字段清单取数
4. 主营业务分拆接口：过去两年主营业务分拆（产品/地区维度）
5. 最新市值接口：取最新市值（用于 PE/PS 测算）
6. 进宝向量召回：过去两年公告/研报/点评/纪要关键词召回 + 额外问题"公司细分业务的季度收入、利润情况"

调用 MCP 工具时，query 必须明确"公司 + 报告期 + 本轮检索目标"，避免召回到错配的公司或报告期。每轮检索后核对是否能支撑提示词所有应输出部分；不足则继续召回。

### 4. 选择提示词并填充变量

按"关注点是否为空"二选一，读取对应提示词文件，仅填充变量、不改动其它任何文字：

| 场景 | 提示词文件 | 变量填充 |
|---|---|---|
| 有关注点 | `精简版_有关注点提示词.txt` | `{{companyText}}`←公司名称；`{{reportText}}`←报告期；`{{focusText}}`←关注点 |
| 无关注点 | `精简版_无关注点提示词.txt` | `{{companyText}}`←公司名称；`{{reportText}}`←报告期 |

### 5. 精简版写作

严格按提示词模版成稿。要点（以提示词为准）：

- 开头 `## 📋 精简版`：业绩一句话总结 + 3-5 个核心看点 bullet（有判断、有数据支撑）
- `## 1、事件：业绩情况`：整体业绩 / 单季度业绩，按报告期口径给同环比
- `## 2、点评要点`：2.1 同环比原因 / 2.2 历史对比（含表格）/ 2.3 业务拆解（必做、含表格）/ 2.4 重要经营变化 / 2.5 经营和投资展望
- `## 3、投资建议`：3.1 盈利预测 + 实时市值测算 PE/PS + 投资逻辑 / 3.2 市场潜在分歧点
- 有关注点版本须结合 `{{focusText}}` 展开
- 数据含具体数值与同环比，单位统一；语言具批判性、连贯饱满

### 6. 中间稿

写入运行目录：

```markdown
outputs/YYYY-MM-DD-业绩点评-[公司名称][报告期]/中间稿/
├── 01-主体与报告期确认.md
├── 02-召回覆盖清单.md
└── 03-报告草稿.md
```

- `01` 记录：原始输入、标准化公司名称/代码/市场、报告期、是否有关注点
- `02` 记录：各 MCP 工具命中条数、时间范围、是否完全匹配公司与报告期、数据缺口
- `03` 按精简版结构生成，允许保留来源标记与待核验项

### 7. 交付前校验

- 公司唯一主体、报告期已确认，全文口径一致
- 召回数据均完全匹配公司与报告期，价格/规模数据为最新
- 选对了提示词分支（有/无关注点），变量已正确填充，提示词正文未被改动
- 提示词中"必做项/必须表格"已落实（如 2.3 业务拆解表格与当期经营变化分析）
- **全文未出现"没有找到相关数据""暂不列示""未找到相关指引"等字样**
- 数据含具体数值与同环比、单位统一；估值/代码/市值无编造
- 叙述为券商分析师口吻、批判性、连贯，未暴露提示词结构与 AI 身份
- 无任何匹配资料时走异常处理，不强行成稿

## 异常处理

若用户未上传、且进门平台 + 互联网均未精确召回到匹配资料，返回异常说明（见 `SKILL.md`"异常处理"），并在中间稿记录缺失：公司名称、公司代码、所属市场、报告期。
