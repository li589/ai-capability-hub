# 兴业证券智达平台智能搜索技能

## 技能简介

本技能用于在兴业证券智达平台上搜索各类信息，包括研报、活动、专题、研究员、项目、公告、文章、资讯和标的等。支持通过关键词进行精准搜索，返回结构化的搜索结果并保存到文件。

## 触发条件

当用户输入包含以下关键词时触发：
- "搜索" + 关键词（如：搜索兴业证券）
- "查询" + 关键词（如：查询科技股）
- "查找" + 关键词（如：查找研报）
- 直接输入关键词（如：兴业证券）

## 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| keyword | string | 是 | - | 搜索关键词 |
| requestNum | int | 否 | 20 | 返回数量，范围 1-20 |

## 功能特性

- **研报搜索**：获取研究报告列表
- **活动搜索**：获取线上会议、调研活动等列表
- **专题搜索**：获取行业专题、研究合集等列表
- **研究员搜索**：获取研究员信息列表
- **项目搜索**：获取投行业务项目列表
- **公告搜索**：获取兴证期货公告列表
- **文章搜索**：获取研究文章列表
- **资讯搜索**：获取市场资讯列表
- **标的搜索**：获取股票标的列表

## 环境配置

### 环境变量

在运行脚本前，需配置环境变量 `process.env.XYZD_APIKEY`：

```bash
# Windows
set XYZD_APIKEY=your_api_key_here

# Linux/Mac
export XYZD_APIKEY=your_api_key_here
```

或者在系统环境变量中永久配置 `XYZD_APIKEY`。

脚本内部通过 `os.environ.get('XYZD_APIKEY')` 获取该环境变量。

### 错误响应

当 API 调用失败时，会抛出异常并显示错误信息。

## 错误处理

| 错误类型 | 说明 | 处理方式 |
|----------|------|----------|
| API Key 未配置 | 环境变量 XYZD_APIKEY 未设置 | 提示错误信息，终止执行 |
| 搜索关键词为空 | keyword 参数为空 | 提示错误信息，终止执行 |
| userId 为空 | searchinfo 接口的 userId 参数为空 | 抛出 ValueError 异常 |
| 网络请求失败 | 无法连接到 API 服务器 | 显示网络错误信息 |
| 技能未启用 | 平台返回技能禁用错误 | 显示平台返回的错误信息 |
| 搜索失败 | 平台返回搜索错误 | 显示平台返回的错误信息 |

## 执行规则

### 1. 脚本修改限制
- **禁止**大模型重新生成或修改 `script/search.py` 脚本
- 技能执行应直接调用现有脚本，不得修改代码逻辑

### 2. userId 必填约束
- `https://ics.xyzq.cn/icsapp/ai/skill/search/searchinfo` 接口的 `userId` 参数**必须**非空
- userId 由 `get-user-info` 接口获取，获取失败时禁止继续执行搜索

### 3. 错误立即返回
- 当 `https://ics.xyzq.cn/icsapp/ai/skill/account/get-user-info` 接口报错时，立即返回错误信息
- 禁止在用户信息获取失败后执行任何后续操作
