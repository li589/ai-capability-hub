# AGENTS.md 输出模板

以下为 AGENTS.md 的标准输出模板。生成时根据实际项目填充占位符。

```markdown
## 编写规则

本说明文档仅记录AGENT容易出错的场景或当前工程定制规则，经验需抽象精炼沉淀到「最佳实践」章节（一行一条），通用知识无需沉淀（基模能力会提升）

## 技术栈

**后端**: {语言} {版本} | {框架1} {版本} | {框架2} {版本} | {数据库} {版本} | {缓存} ({客户端库} {版本})
**前端**: {框架} {版本} | {语言} {版本} | {UI库} {版本} | {构建工具} {版本} | {状态管理} {版本}
**测试**: {后端测试框架} {版本} + {Mock库} {版本} | {前端测试框架} {版本} + {E2E框架} {版本}

## 最佳实践

- {沟通语言约定}
- {工具使用限制}
- {数据库查询命令}
- {DDL变更/迁移流程}
- {数据库设计规范}（tenant_id、deleted、BaseEntity）
- {API响应格式约定}
- {数据转换约定}
- {类型约定}（ID类型、日期类型）
- {上下文管理规范}（租户、安全）
- {领域事件/模块解耦}

```

## 模板说明

### 章节组织

- **编写规则**：固定文案，直接复制。作用是防止 Agent 后续修改时添加无用内容。
- **技术栈**：按 `后端 / 前端 / 测试` 三行组织（如有基础设施可加第四行），每行内用 `|` 分隔。
- **最佳实践**：按优先级排列，高优先级在前。

### 最佳实践优先级

1. 沟通与语言
2. 工具使用限制
3. 数据库操作（查询命令、迁移流程）
4. 数据库设计规范
5. API 规范
6. 编码约定（类型、转换、日期）
7. 上下文与安全
8. 架构约束（事件、模块通信、框架限制）
9. 前端规范（组件复用）
10. 构建与部署
11. 运维与调试（日志、错误排查）
12. 禁止事项

### 条目质量标准

- 每条一行，不超过两行
- 有具体类名/方法名/命令（非泛泛而谈）
- 无"建议""尽量""考虑"等模糊词
- 不含通用编程知识
- 总条目 ≤ 100 条
