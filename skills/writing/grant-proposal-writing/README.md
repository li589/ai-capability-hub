# 公益申报写作助手

一个给公益机构用的 AI 技能包。帮你把口语化的项目想法写成合格的申报材料，或者对照资助方要求诊断已经写好的稿子。

适用于向政府、基金会、企业申请资助，覆盖政府购买服务、公募基金会、企业基金会、社区基金会、企业 CSR、境外资助方六类常见资助方。

---

## 安装

支持 Skills / 技能包的 AI 客户端都能用（Cursor、Claude 等，具体以你所用客户端为准）：把整个 `grant-proposal-writing` 文件夹放到该客户端的**技能目录**下即可。

不同客户端的技能目录位置不一样，一般有两种范围：

| 范围 | 大致位置 |
|------|------|
| 只在某个项目里用 | 项目目录下的技能文件夹（如 `<项目目录>/.cursor/skills/grant-proposal-writing/`） |
| 所有项目都能用 | 用户主目录下的技能文件夹（如 `~/.cursor/skills/grant-proposal-writing/`） |

> 上面以 Cursor 为例。如果你用的是别的客户端，**具体目录名请查该客户端关于「Skills / 技能」的文档**，把文件夹放进去即可，用法完全一样。

放好后重启客户端，正常提问即可，会自动触发。

## 怎么用

### 最简单的开始方式

直接说你想做什么，不需要先准备任何材料：

```
我想申请一笔资助，做乡村儿童阅读，帮我写一份申请书
```

它会先问三个问题（做什么帮谁、多少钱多久、投给谁），然后就开始起草。

> 想先看一份写完的长什么样？打开 `examples/lightweight-proposal-sample.md`，那是一份 5 万元社区项目的完整两页纸小样，可以对照着套。

### 有材料的话，一起给它

方案 PPT、预算草稿、往年结项报告、对方的申请指南，能给的都给，能省很多问答。

```
按这份申请指南写一份申请书（附指南 PDF + 我们的项目方案）
```

### 已经写好了，想知道行不行

```
帮我诊断这份申请书（附文件）
```

会输出四份东西：对标差异报告、内容质量诊断、评审视角的意见、待确认清单。

## 建议做的两件事

这两件事做了，之后每写一份材料都能省几个小时。

### 1. 建一份机构档案

第一次用完之后，让它帮你整理一份机构档案，存在自己的工作目录里（如 `机构档案/我方机构档案.md`）。里面放机构基本信息、资质证书、财务数据、团队、往期项目成果。

下次写申报材料，机构介绍、团队、审计报告这些都不用再问一遍。模板见 `references/applicant-profile-template.md`。

### 2. 每投一家就存一份资助方档案

摸清一家资助方的要求（章节结构、周期上限、管理费比例、附件清单）之后，让它整理成 `资助方档案/funder-<简称>.md`。同一家再投的时候直接复用。

## 它不会做的事

| 不会 | 为什么 |
|------|-------|
| 编数据 | 没有数据会标 `【待补充】`，不会替你造一个 |
| 猜阈值 | 管理费上限、周期上限、分类选项这些填错代价很大，不确定就留空并提示你去确认 |
| 替你定稿 | 交付稿必须你自己通读确认后才能提交 |
| 保证通过 | 它能帮你避开高频错误，但项目本身好不好是另一回事 |

## 文件说明

| 文件 | 内容 |
|------|------|
| `SKILL.md` | 主流程。AI 读这个 |
| `references/funder-types.md` | 六类资助方的典型要求与高频退回原因 |
| `references/funder-profile-template.md` | 资助方档案模板 |
| `references/applicant-profile-template.md` | 我方机构档案模板 |
| `references/writing-rules.md` | 各模块怎么写、写作禁忌表 |
| `references/goal-frameworks.md` | OKR / 逻辑模型 / 变革理论 / SMART 四种目标写法与互转 |
| `references/budget-and-compliance.md` | 预算编制与合规底线 |
| `references/review-checklists.md` | 形式审查、模块预检、一致性、评审视角四组检查清单 |
| `references/glossary.md` | 申报术语表。看不懂的词先查这里 |
| `examples/lightweight-proposal-sample.md` | 一份 5 万元社区项目的完整两页纸小样，第一次写可对照套用 |
| `examples/` | 一份被退回的申请书改到通过的全过程；差目标改成好目标的对照集 |

这些文件都是纯文本，可以按自己机构的情况直接改。

## 免责说明

`references/funder-types.md` 里的所有数字是**公益行业常见做法，不是任何一家资助方的规定**。正式提交前，必须核对该资助方的官方申请指南，尤其是管理费上限、执行周期上限、分类选项和附件清单这四项。
