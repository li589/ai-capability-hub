# 术语表

申报材料里绕不开、但没人正式解释过的词。第一次写申报材料的人可以先扫一遍这份表。

---

## 文书名称：其实是同一件事

不同资助方对「申请材料」的叫法不一样，看到陌生名字先别慌。

| 叫法 | 谁在用 | 说明 |
|------|-------|------|
| 项目申请书 / 资助申请书 | 多数基金会 | 最通用的叫法 |
| 立项书 / 立项申请书 | 企业基金会、部分基金会 | **是资助方内部走审批流程的叫法**。你交的材料会成为对方立项审批的依据 |
| 项目建议书 / 合作方案 | 企业 CSR、无模板的资助方 | 通常更灵活，可以自己定结构 |
| 项目申报书 / 服务方案 | 政府购买服务 | 常附评分表 |
| 微项目申请表 / 小额资助申请表 | 社区基金会 | 篇幅短 |
| Concept Note | 境外资助方 | 初筛用的短版，2–4 页，过了才交全案 |
| Full Proposal / Application | 境外资助方 | 全案 |

**它们的内核是一样的**：为什么做、做什么、做成什么样、花多少钱、谁来做、有什么风险。换个模板只是重新排列这些内容。

## 角色

| 术语 | 含义 | 注意 |
|------|------|------|
| 资助方 / 出资方 / 捐赠方 / funder | 给钱的一方 | 有些材料里叫「甲方」，但这是合同术语，正文里少用 |
| 申请方 | 提交申请的机构 | 你 |
| 执行方 / 承接方 / 受赠方 / grantee | 实际执行项目的机构 | 多数情况下申请方就是执行方，但也有申请方转委托的情况，要写清 |
| 合作方 | 参与执行但不直接受资的机构 | 资质也常被审查 |
| 受益人 / 服务对象 | 项目服务的人 | 区分直接受益人和间接受益人 |
| 主管部门 / 登记管理机关 | 民政等负责社会组织登记管理的机关 | 与资助方无关，别混 |

## 目标与成效

这几个词是申报材料里最容易搞混、也最影响评审判断的。

| 术语 | 含义 | 例子 |
|------|------|------|
| 活动 / Activity | 你做的事 | 开展 20 场阅读课 |
| 产出 / Output | 做完直接得到的东西，可清点 | 20 场课完成，覆盖 300 名学生 |
| 成效 / Outcome | 服务对象身上发生的变化 | 学生月均阅读量从 0.8 本提升到 2.5 本 |
| 影响 / Impact | 更长期、更大范围的改变 | 区域内乡村儿童阅读习惯改善 |

**最常见的错误是把活动写成目标。**「开展 20 场课」不是目标，是手段；目标是这 20 场课让谁发生了什么变化。详见 [goal-frameworks.md](goal-frameworks.md)。

| 术语 | 含义 |
|------|------|
| 指标 / Indicator | 用来衡量目标是否达成的可测量项 |
| 基线 / Baseline | 项目开始前的现状值。没有基线，「提升 30%」无从比较 |
| 目标值 / Target | 项目结束时希望达到的值 |
| 验证方式 / Means of Verification | 这个数据从哪来、谁收集、怎么核实 |
| 前提假设 / Assumptions | 不受项目控制但影响成败的外部条件（如学校继续配合）。**不等于风险** |
| M&E / 监测评估 | Monitoring & Evaluation，执行过程中怎么跟踪、结束时怎么评估 |

## 目标范式

| 术语 | 全称 | 特点 | 谁常用 |
|------|------|------|-------|
| OKR | Objectives and Key Results | 目标 + 关键结果，结果须可量化 | 企业基金会 |
| SMART | Specific, Measurable, Achievable, Relevant, Time-bound | 单条目标的五项检验标准 | 通用，小额项目 |
| 逻辑模型 / Logframe | Logical Framework | 投入→活动→产出→成效→影响的矩阵，带指标与假设 | 境外资助方、大额项目 |
| 变革理论 / ToC | Theory of Change | 论证从活动到影响的因果链条，说明「为什么这样做会有用」 | 境外资助方、创新型项目 |

四者内核相同，都是同一条结果链的不同表达方式，可以互转。详见 [goal-frameworks.md](goal-frameworks.md)。

## 预算与财务

| 术语 | 含义 | 坑在哪 |
|------|------|-------|
| 管理费 / 行政费 / indirect cost | 机构为执行项目产生的间接成本（行政人员、办公、审计等） | **上限比例和分母口径必须问清**。「10% 管理费」的分母是项目总额还是执行支出，差别很大 |
| 直接成本 / direct cost | 直接用于项目活动的支出 | |
| 配套资金 / matching fund | 要求申请方自己或第三方投入一部分 | 承诺了就要能兑现，会被核查 |
| 分期拨付 | 资金按节点分次到账 | 前期垫资压力要提前评估 |
| 尾款 | 最后一笔款，常与验收或审计挂钩 | 达不到目标可能扣尾款 |
| 结余资金 | 项目结束后没花完的钱 | 政府购买服务**通常要求退回**，社会资助按约定 |
| 专账管理 | 项目资金单独建账核算 | 多数资助方的硬性要求 |
| 捐赠票据 | 公益事业捐赠统一票据 | 与增值税发票不是一回事，企业捐赠方常关心 |
| 关联交易 | 与本机构有关联关系的主体之间的交易 | **须主动声明**，隐瞒被查出的代价远大于披露 |

## 流程

| 术语 | 含义 |
|------|------|
| 形式审查 | 先查材料是否齐全、资质是否有效，不看内容质量。**这一关淘汰的项目最多，也最不该被淘汰** |
| 尽职调查 / due diligence | 资助方对申请方的资质、财务、声誉进行核查 |
| 合规评议 | 财务、法务、税务、风控等部门分别审查 |
| 立项 | 资助方内部批准这个项目 |
| 拨付 | 打款 |
| 中期检查 / 进展反馈 | 执行过程中按约定提交进展 |
| 结项 / 验收 | 按当初写的目标核对完成情况 |
| 专项审计 | 针对项目资金的第三方审计 |
| 绩效评价 | 政府项目常用，按绩效指标表打分 |

**关键认知**：结项验收对照的就是你在申请书里写的目标。所以**写目标时就要想清楚将来怎么证明达成了**。写得漂亮但无法验证，最后麻烦是自己的。

## 特殊模式

| 术语 | 含义 | 注意 |
|------|------|------|
| 再资助 / regranting | 你拿到钱后再筛选和资助末端项目 | 申报时末端项目常还没定，须写清遴选标准与流程，详见 [writing-rules.md](writing-rules.md) |
| 联合资助 | 多个资助方共同出资 | 各方要求可能冲突，须协调口径 |
| 公开募捐 | 面向不特定公众募捐，须有资格 | 无资格的须与有资格的组织合作 |
| 定向募捐 | 面向特定对象募捐 | 要求低于公开募捐 |
| 脱敏 | 处理个人信息使其无法识别到具体个人 | 受益人材料公开前必做 |
| 转包 / 分包 | 把执行工作转给其他机构 | 政府项目多数禁止，社会资助也常需报备 |
