# 资助方类型档案库

六类常见资助方的典型要求。**用途是让你在拿不到具体申请指南时也能起草**，而不是替代官方要求。

**怎么用**

1. 判断这次要投的属于哪一类（下面有判断表）
2. 按该类型的典型要求起草
3. 交付稿里逐条标注哪些是按类型推断的，提交前核对官方文件

**重要**：本文件里所有数字都写了「常见」「多为」，意思是**行业里常见的做法，不是任何一家的规定**。落到具体机构一定有差别，尤其是管理费比例和执行周期，必须核对。拿到官方文件后，把这一节复制出来改成 `funder-<机构简称>.md`，按 [funder-profile-template.md](funder-profile-template.md) 的九项结构补全。

---

## 快速判断

| 如果对方是 | 看哪一节 |
|-----------|---------|
| 民政、残联、妇联、街道、财政等政府部门，或走政府采购平台 | 一、政府购买服务 |
| 有公开募捐资格的基金会，或要在互联网筹款平台上线 | 二、公募基金会 |
| 企业发起的基金会（多为非公募），如各类企业公益基金会 | 三、企业基金会 |
| 本地的社区基金会、社区发展基金、街道微创投 | 四、社区基金会与小额资助 |
| 企业的 CSR / 品牌 / 工会部门直接出资，不经基金会 | 五、企业 CSR 与直接捐赠 |
| 国际组织、境外基金会、驻华使馆小额项目 | 六、境外资助方 |

一个项目可能同时涉及两类（如公募基金会承接政府购买服务再转资助），这时以**直接给你钱的那一方**的要求为准，同时注意上游要求会穿透下来。

## 一、政府购买服务

| 项 | 典型情况 |
|----|---------|
| 文书名称 | 项目申报书 / 服务方案 / 投标文件（走采购流程时） |
| 目标体系 | **绩效指标表**为主：服务内容 + 数量指标 + 质量指标 + 服务对象满意度。少用 OKR |
| 目标重点 | 服务人数、服务人次、服务频次；质量指标常要求量化到满意度百分比 |
| 执行周期 | 多受**财政年度**约束，须在年度内执行完毕 |
| 管理费 | 口径受财政规定限制，常见上限低于社会资助（须查当地政府购买服务管理办法） |
| 结余资金 | **通常要求退回**，这点与社会资助差别很大 |
| 预算特点 | 科目须对齐财政支出口径；不得列支利润；人员费常有编制或标准限制 |
| 附件 | 法人登记证书、社会组织等级评估证明、上年度审计报告、纳税或免税证明、无重大违法记录证明、承接主体资格材料 |
| 评审方式 | 评审委员会按**评分表**打分，常见维度：服务方案、机构能力、团队配置、预算合理性、以往业绩 |
| 提交 | 政府采购平台或社会组织服务平台，**截止时间刚性，逾期不受理** |

**写作要点**

- 评分表就是写作大纲。能拿到评分表的，按分值权重分配篇幅。
- 强调**服务的可及性与覆盖面**，政府最关心「服务了多少人、是不是真正的目标人群」。
- 明确不得转包分包（多数政府项目有此要求），团队章节要体现自有执行能力。
- 信息公开与档案留存要求通常高于社会资助，服务记录、签到、满意度问卷都要说明如何留档。

**高频退回原因**：绩效指标不可量化；预算科目不符合财政口径；资质材料过期；超出财政年度；缺少服务对象真实性的核验方式。

## 二、公募基金会

分两种合作形态，要求差别大。

### 形态 A：向公募基金会申请资助

| 项 | 典型情况 |
|----|---------|
| 文书名称 | 项目申请书 / 资助申请表 |
| 目标体系 | 产出指标 + 受益人数为核心，逐渐要求成效指标 |
| 执行周期 | 常见 1 年，部分支持多年期 |
| 管理费 | 常见允许一定比例，须查该基金会资助管理办法 |
| 附件 | 法人登记证书、章程、审计报告、项目预算、团队说明 |
| 评审 | 项目评审 + 财务合规审核 |

### 形态 B：与公募基金会合作在互联网平台筹款

| 项 | 典型情况 |
|----|---------|
| 文书名称 | 项目立项申请 + 上线申请 + 公开募捐方案 |
| 额外要求 | **面向公众的表达**：一句话文案、项目故事、预算科普化说明、受益人形象材料 |
| 法定要求 | 须符合《慈善法》公开募捐规定；执行方须是慈善组织，或与有公开募捐资格的组织合作 |
| 信息披露 | **强制且高频**，常见要求每 3 个月至少披露一次进展与财务 |
| 平台费用 | 平台通常收取技术服务费或规定管理费上限（须查平台规则） |
| 附件 | 慈善组织证书或公开募捐资格证明、法人证书、章程、审计报告、受益人授权与证明材料模板 |
| 评审 | 项目审核 + 合规审核 + 平台上线审核，三道 |

**写作要点**

- 形态 B 要写**两套语言**：给评审看的专业版，和给公众看的通俗版。两套的数字必须一致。
- 受益人信息披露与隐私保护的平衡是最高频问题。既要让公众相信钱花到了真人身上，又不能泄露个人信息。事先说明授权机制和脱敏方式。
- 筹款项目要写清**筹款目标未达成时怎么办**（缩减规模、延期、还是转其他项目），这是必答项。

**高频退回原因**：执行方无公开募捐资格且未说明合作方式；预算科普化程度不足公众看不懂；信息披露计划缺失；受益人材料无授权。

## 三、企业基金会

| 项 | 典型情况 |
|----|---------|
| 文书名称 | 立项申请书 / 资助申请书 / 项目建议书 |
| 目标体系 | **OKR 或 KPI 表**常见，强调可量化交付与验收 |
| 目标是否作为验收依据 | **常常是**。写什么将来就验收什么，措辞要能验收 |
| 执行周期 | 常见限 1 年，长周期项目分年签协议 |
| 管理费 | 常见有明确上限，且规定分母口径（执行支出总额 vs 总金额），**必须确认** |
| 资金拨付 | 常见分期拨付，尾款与验收或审计挂钩 |
| 预算变更 | 常见按变更比例分档报备 |
| 主体表述 | **基金会与其关联企业是独立主体，通常要求分开表述**，且不得论证项目给企业带来的商业回报 |
| 附件 | 法人登记证书、章程、审计报告（常与金额阈值挂钩）、合作方资质表、关联交易声明 |
| 评审 | 业务审批 + 多部门合规评议（常见财务、法务、税务、风控、业务管理并行） |
| 尾款前审计 | 常见要求第三方审计 |

**写作要点**

- 从**基金会的公益目的**论证，不要论证对企业的价值。企业员工参与、企业资源投入可以作为执行方式写，但不能写成项目目的。
- 关联交易须主动声明。存在关联关系而不声明，被查出来的代价远大于主动披露。
- 多部门并行评议意味着**每个专业口径都会被单独挑**：财务挑测算依据、法务挑主体资质、税务挑票据、风控挑背景与舆情。写的时候按这几条各自过一遍。

**高频退回原因**：周期超上限且无分年说明；目标不可验收；预算缺测算依据被评估调减；出现禁止科目；附件不全；主体表述混同。

## 四、社区基金会与小额资助

| 项 | 典型情况 |
|----|---------|
| 文书名称 | 小额资助申请表 / 微项目申请书 / 微创投方案 |
| 金额量级 | 几千元到几十万元 |
| 目标体系 | **SMART 简表，3–5 条**，不要求复杂分层 |
| 篇幅 | **短。多数只要 2–5 页，写长了反而不利** |
| 执行周期 | 常见 3–12 个月 |
| 管理费 | 常见极低或不允许列支 |
| 配套要求 | 常要求本地注册或本地服务，部分要求配套资金、志愿者投入或社区参与度 |
| 附件 | 机构证明、简要预算、社区需求证明或居民签名 |
| 评审 | **社区代表或居民参与评审**是这类资助的特色，有时还有路演环节 |
| 结项 | 材料要求简化，但票据仍必须齐全 |

**写作要点**

- 用**轻量路径**（见 SKILL.md），不要套大项目的完整结构。
- 重点写**本地相关性**和**居民参与**：谁提出的需求、居民怎么参与设计、怎么参与执行。这两点的权重常常高于专业性。
- 语言要能让非专业的社区评委听懂，避免行业术语。
- 有路演环节的，准备一段 3 分钟口头版本。

**高频退回原因**：写得太长太专业社区评委看不懂；本地相关性不足；预算不合量级（申请金额与项目内容明显不匹配）；缺社区需求依据。

## 五、企业 CSR 与直接捐赠

| 项 | 典型情况 |
|----|---------|
| 文书名称 | 合作方案 / 项目建议书 / 捐赠方案，多数**无统一模板** |
| 目标体系 | 产出指标 + **传播与参与指标并重**，这是与基金会资助最大的差别 |
| 特有关注点 | 品牌契合度、员工参与机会、传播露出、ESG 报告可引用的数据 |
| 执行周期 | 灵活，常与企业财年或营销节点绑定 |
| 付款方式 | 常与合同节点绑定；须明确捐赠票据开具方式 |
| 非资金投入 | 员工志愿服务、物资捐赠、场地、技术资源等要单独说明如何使用与计价 |
| 附件 | 机构资质、捐赠票据开具资质、往期案例、传播方案 |
| 评审 | CSR 或品牌部门主导，法务与财务参与；决策周期差异极大 |

**写作要点**

- 企业关心「这个项目和我们有什么关系」。可以单列一节**合作价值**，写清品牌契合点、员工参与设计、可传播的内容素材、可写进 ESG 报告的量化数据。
- 但要注意分界：**合作价值可以单列，不能把商业回报写成项目目的**。项目目标章节仍须是纯公益指标。
- 企业没有模板时，主动给结构反而是优势。用通用基线结构 + 合作价值一节。
- 员工志愿服务这类非资金投入，要写清怎么安排、需要多少人、什么时段，企业最怕承诺了执行不了。

**高频退回原因**：没有回答「为什么找我们」；传播价值说不清；捐赠票据与发票口径没谈清；对企业资源的依赖写得太重导致执行风险高。

## 六、境外资助方

| 项 | 典型情况 |
|----|---------|
| 文书名称 | Concept Note（初筛）→ Full Proposal（全案），**两阶段申请常见** |
| 目标体系 | **Logframe 或 Theory of Change**，必带 Indicator、Means of Verification、Assumptions |
| 额外必备章节 | M&E 监测评估计划、性别与包容视角、风险矩阵、可持续性与退出策略 |
| 法定要求 | 境外资金须符合《境外非政府组织境内活动管理法》，需依法登记或办理临时活动备案 |
| 预算特点 | 常要求分币种、分年度、区分 direct cost 与 indirect cost；indirect cost rate 有明确上限 |
| 机构政策文件 | **常为硬性淘汰项**：儿童与弱势群体保护政策、反腐败政策、性别平等政策、利益冲突政策 |
| 附件 | 机构注册文件、审计报告（常要求英文）、组织架构图、上述政策文件、往期同类项目清单 |
| 评审 | 技术评审 + 财务评审，常有公开的评分权重 |
| 语言 | 多要求英文，或中英双语 |

**写作要点**

- Concept Note 阶段**不要写全案**，通常只要 2–4 页讲清问题、方案、预期变化、预算量级。
- Assumptions（前提假设）是中文申报里最容易漏的一栏。写的是不受项目控制但影响成败的外部条件，不是风险。
- Means of Verification 要具体到数据从哪来、谁收集、多久收一次。
- 机构政策文件没有就先做，这类文件的缺失往往在形式审查阶段就被淘汰，写得再好也没用。
- 境外资金的合规登记要提前办，不要等拿到资助再办。

**高频退回原因**：机构政策文件缺失；Logframe 逻辑层级混乱（把活动写在产出行）；缺 M&E 计划；境外资金合规路径不清；英文表述影响评审理解。

## 跨类型对照

| 维度 | 政府购买 | 公募基金会 | 企业基金会 | 社区小额 | 企业 CSR | 境外 |
|------|---------|-----------|-----------|---------|---------|------|
| 目标范式 | 绩效指标表 | 产出 + 受益人数 | OKR / KPI | SMART 简表 | 产出 + 传播 | Logframe / ToC |
| 篇幅 | 中到长 | 中 | 中到长 | **短** | 中 | **长（全案）** |
| 最看重 | 服务覆盖与合规 | 公信力与披露 | 可验收与合规 | 本地相关性 | 契合度与传播 | 逻辑严谨与合规文件 |
| 结余资金 | **通常退回** | 按约定 | 按约定 | 按约定 | 按约定 | 按约定 |
| 特有硬门槛 | 财政年度 | 公开募捐资格 | 关联交易声明 | 本地属性 | 票据口径 | 境外资金备案 + 政策文件 |

## 用完之后

按类型起草只是权宜之计。**拿到官方申请指南或空白模板后，一定要回头核对**，尤其这四项：

1. 管理费上限与分母口径
2. 执行周期上限
3. 分类选项的原文（自创分类一定被退回）
4. 附件清单与触发条件

核对完就把它落成正式档案 `funder-<机构简称>.md`，下次投同一家直接复用。
