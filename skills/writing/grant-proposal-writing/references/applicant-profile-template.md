# 我方机构档案模板

**解决的问题**：每写一份申报材料，机构介绍、团队、资质、审计报告、往期成果都要重新问一遍、重新找一遍。这份档案填一次，之后每份材料直接调用。

**放在哪**：你自己的工作目录，不要放在 skill 目录里（skill 通常是只读的，而且换机器就丢了）。建议 `机构档案/我方机构档案.md`。

**填多少**：第一次填 1–4 节（基本信息、资质、财务、团队）就够用了。第 5 节往期项目库随每个项目结项慢慢积累，越攒越值钱。

## 5. 往期项目库

**这是整份档案里最有价值的部分。** 每个项目结项时补一行，写申报材料时直接调用作为执行能力证明。

| 项目名称 | 资助方 | 金额 | 周期 | 服务规模 | 核心成果（可引用的数字） | 结项状态 | 材料位置 |
|---------|-------|------|------|---------|---------------------|---------|---------|
| | | | | | | | |

**可引用数据池**（把往期项目里最有力的数字单独摘出来）

| 数据 | 来源项目 | 采集时间 | 样本量 | 可用于论证什么 |
|------|---------|---------|-------|--------------|
| | | | | |

一线调研数据是中小机构的独有优势。公开数据谁都能引，只有你有的数据才能证明你懂这个领域。注明时间和样本量，否则评审无法采信。
