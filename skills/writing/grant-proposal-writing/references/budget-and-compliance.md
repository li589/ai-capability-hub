# 预算编制与公益合规底线

预算是申报被退回的重灾区。**具体比例阈值（管理费上限、变更报备线、比价起点）一律查资助方档案，本文件只讲通用做法。** 只知道资助方类型时，参考 [funder-types.md](funder-types.md) 里该类型的常见口径，并标注为待核对。

---

## 预算编制四原则

1. **与方案匹配** —— 每个科目对应到实施方案里的具体活动。方案里没提的活动不能有钱，有活动没预算也要解释。
2. **有测算依据** —— 每笔钱都要说清怎么算出来的，单价符合市场公允价格。
3. **不列无关费用** —— 与项目目标无关的费用（日常办公、非项目人员薪酬）不得进入项目预算。
4. **最小颗粒度填报** —— 不要用「活动费一批 50 万」这种笼统写法，拆到可核对的单项。

## 预算科目与佐证

### 项目执行支出

| 科目大类 | 常见子项 | 测算要求 | 佐证材料 |
|---------|---------|---------|---------|
| 人力费（外聘） | 专家指导费、教师授课费、讲师费 | 岗位必要性推导 + 工作量测算（天数 × 单价） | 职称或专业资质证明、工作量计划 |
| 人力费（项目团队） | 项目经理、执行人员 | 岗位职责说明 + 投入比例测算 | 岗位说明书、工时安排 |
| 物料/设备费 | 教具、器材、办公设备 | 品牌型号 + 单价 + 数量 | **三方比价单**（通常至少 3 家） |
| 版权费 | 原创版权、授权使用 | 合同约定价格 | 版权合同或授权协议 |
| 活动费 | 场地租赁、现场执行、餐饮住宿 | 历史费用参考或供应商报价 | 场地合同、报价单 |
| 传播费 | 视频制作、媒体投放、物料设计 | 传播方案：平台 + 形式 + 频次 + 预期覆盖 | 制作合同、报价单、渠道说明 |
| 差旅费 | 交通、住宿、市内交通 | 出差计划 + 执行标准 | 出差计划表、差旅标准依据 |
| 补贴与资助 | 受益人补助、奖助学金 | 发放标准 + 人数 + 频次 | 发放标准依据、受益人名册模板 |
| 评估费 | 第三方评估、审计 | 评估方案 + 报价 | 报价单 |
| 其他直接费用 | 印刷、通讯、保险 | 明确用途和单价 | 报价单 |

### 管理费

| 项 | 说明 |
|----|------|
| 是否必须列支 | 通常非必须 |
| 上限 | **查资助方档案**。行业实际区间跨度很大，不许按别家经验填 |
| 分母口径 | 两种算法差别很大：`管理费 ÷ 项目执行支出总额` 或 `管理费 ÷ 项目总金额`。**必须确认资助方用哪种** |
| 通常包含 | 机构管理人员费用分摊、办公场地与水电分摊、财务与行政成本 |

档案里没写上限时，预算表里管理费一栏标 `【需向资助方确认上限】`，不要先填一个数。

## 测算依据怎么写

评审看的不是金额，是**这个金额怎么来的**。合格的测算依据是一个能复算的算式加一句必要性说明。

| 科目 | 不合格 | 合格 |
|------|--------|------|
| 专家费 | 专家指导费 6 万元 | 因课程研发需声乐专业指导，聘请 2 名副高及以上专家，各 15 天 × 2000 元/天 = 6 万元 |
| 物料费 | 图书采购 25 万元 | 50 个图书角 × 500 册 × 均价 10 元/册 = 25 万元，书单与三家供应商比价见附件 |
| 活动费 | 活动执行费 18 万元 | 12 场活动 × 1.5 万元/场（场地 6000 + 物料 4000 + 现场执行 5000），单价参考 2025 年同类活动实际支出 |
| 差旅费 | 差旅费 8 万元 | 5 县 × 4 次督导 × 2 人 × 2000 元/人次（高铁往返 800 + 住宿 2 晚 600 + 市内交通餐饮 600） |

## 禁止科目

| 禁止内容 | 说明 |
|---------|------|
| 不可预计费用 | 绝对禁止，出现即退回 |
| 其他不明费用 / 杂项 | 绝对禁止 |
| 机动经费 / 备用金 | 绝对禁止 |
| 与项目无关的费用 | 日常办公费、非项目人员薪酬、机构固定资产购置 |
| 无测算依据的整数大项 | 如「宣传费 10 万元」无任何拆分 |

预算里需要留弹性时，正确做法是把可能的支出**写成具体科目并说明触发条件**，而不是留一笔不明费用。

## 按资助方类型的预算差异

同一份预算换个资助方类型可能就不合格了，这几条差别最大：

| 类型 | 预算上的特殊要求 |
|------|---------------|
| 政府购买服务 | 科目须对齐财政支出口径；不得列支利润；**结余资金通常要求退回**；须在财政年度内执行完毕 |
| 公募基金会（筹款型） | 预算要写成**公众能看懂的版本**，「每 100 元能做什么」比科目表更重要；平台费用另计 |
| 企业基金会 | 分期拨付 + 尾款与验收挂钩；预算变更按比例分档报备；常要求尾款前第三方审计 |
| 社区小额资助 | 管理费常极低或不允许；可能要求配套资金或志愿者投入折算 |
| 企业 CSR | 需明确捐赠票据与发票口径；非资金投入（员工志愿服务、物资、场地）要单独说明如何计价 |
| 境外资助方 | 分币种、分年度编制；区分 direct 与 indirect cost，indirect cost rate 有明确上限；审计要求高 |

详见 [funder-types.md](funder-types.md)。

## 金额一致性

三处金额必须完全一致，精确到小数点后两位：

```
概要里的预算金额 = 实施方案表格合计 = 预算明细表合计
```

这是最容易被机械核对出来的错误，也是最没必要犯的错误。改了任何一处，回头把三处都改。

## 公益合规底线（行业通用）

具体审核标准各机构不同，但下面这些是中国境内公益项目的共同底线。

### 主体合法性

受赠或执行主体须是可依法接受捐赠、开展公益活动的合法主体，符合《慈善法》《公益事业捐赠法》，涉救灾的还须符合《救灾捐赠管理办法》。

非常规主体（企业、个人工作室、未登记的社群）作为执行方时，须在申报材料里专门论证其承接公益项目的适格性与能力。

**附件通常要**：法人登记证书、机构章程。

### 业务范围匹配

项目内容须落在资助方章程规定的业务范围内，也须落在执行机构章程规定的业务范围内。两头都要对得上。

不好归类时，在材料里写明项目与双方宗旨的关联性，不要硬套。

### 关联交易

须主动声明是否存在关联交易。常见的关联情形包括：资助方或其关联方的利害关系人是受赠人、受益人、供应商、担保方，或存在非公允价格交易。

存在关联交易时通常要走额外的内部决策与信息披露流程，**主动声明比被查出来代价小得多**。

### 合作背景

如与资助方有过历史合作，建议主动说明合作情况；有过审计问题的，主动说明整改情况和结果。

多数资助方有「不予合作清单」，触发情形通常包括：未按期执行项目、财务管理混乱、拒绝审计或不配合整改、挪用套取资金、伪造材料、未披露关联交易、引发负面舆情未妥善处理。

### 受益人公平

涉及定向受益人时的三条底线：招募渠道公开、筛选标准与流程透明、不因户籍性别学校等设置无关限制。向困难群体倾斜的规则要明确写出。执行机构推荐名额如有，须设上限并公开。

### 资金与票据

- 资金拨付方式看资助方档案，多数资助方**不允许一次性拨付**全款
- 每期付款通常需要完整的执行反馈材料（财务票据、采购文件、物资记录、劳务签收、签到清单、资助签收单、验收确认单）
- 不合规、超标准、超范围的支出不予确认列支
- 预算变更须按资助方档案的阈值报备，**先获批再执行**

### 信息与隐私

受益人个人信息、财务凭证、内部人事信息在申报材料里应脱敏。涉及儿童、患者、受灾群体的照片和案例，须有授权。

---

## 预算与合规自检

- [ ] 每个科目对应到实施方案里的具体活动
- [ ] 每笔费用有可复算的测算依据
- [ ] 需要比价的科目已附比价材料
- [ ] 无禁止科目
- [ ] 管理费比例符合资助方档案，或已标注待确认
- [ ] 三处金额完全一致
- [ ] 执行主体资质材料齐全
- [ ] 已声明关联交易情况
- [ ] 涉定向受益人的已写完整筛选流程
- [ ] 无绝对化的费用承诺（如「全程免费」）
- [ ] 个人信息已脱敏
