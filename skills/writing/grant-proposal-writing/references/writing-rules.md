# 各模块撰写规则（行业通用）

这些规则不随资助方变化。章节命名和顺序按资助方档案，**内容质量标准按本文件**。

如果资助方把几个模块合并成一章（比如「项目背景与必要性」合并了「为什么做」和「帮助谁」），把对应模块的要素合并写进去，不要漏要素。

---

## 项目概要

审批人第一眼看的东西，很多人在手机上只看这一段就做判断。写不好，后面写得再好也会被拖累。

**6 要素公式**（申请方写法）

```
本项目申请 [金额] 元，由 [执行机构] 在 [周期] 内开展 [项目名]，
[面向/聚焦] [受益群体] [规模]，
通过 [核心活动]，[实现什么目的]。
[已有进展]。[计划达成的影响]。
```

资助方内部做初审或立项时，同样的内容改成第三人称即可：「拟资助 [机构] 开展…」。要素不变。

| 要素 | 必须有 |
|------|--------|
| 申请金额 | 是 |
| 执行机构 | 是 |
| 做什么 | 是 |
| 受益群体及规模数字 | 是 |
| 要实现什么目的 | 是 |
| 已有进展 / 计划影响 | 续期项目必须有，新项目写计划影响 |

**质量标准**：150–300 字 | 有具体数字 | 无虚话 | 主体不混同 | 从公益角度论证

**常见错误**

| 问题 | 例子 | 改法 |
|------|------|------|
| 写成流水账 | 「本项目分三个阶段，第一阶段…第二阶段…」 | 概要不写实施步骤，写价值和规模 |
| 没有数字 | 「资助若干乡村学校」 | 「资助广东 5 个县 50 所学校」 |
| 堆形容词 | 「意义重大、影响深远的公益项目」 | 删掉，换成可核查的事实 |
| 目的写成活动 | 「开展 200 场读书会」 | 「让 3000 名乡村儿童形成稳定的课外阅读习惯」 |

## 为什么做（Why / 项目背景）

**核心问题**：为什么这件事非做不可，而且非现在做不可。

**三层结构**

| 层 | 写什么 | 硬要求 |
|----|--------|--------|
| 第 1 层 | 问题是什么 —— 社会需求或痛点 | **至少 1 处数据**，标明来源 |
| 第 2 层 | 为什么现在做 —— 紧迫性 | 政策导向、服务缺口、趋势变化任选 |
| 第 3 层 | 为什么是这个项目 —— 定位 | 一句话说明本项目填补哪个缺口 |

**数据规则**：找不到数据就标 `【待补充】`，**严禁编造**。可用的数据来源包括政府统计公报、行业蓝皮书、权威机构调研报告、机构自己的一线调研数据（注明样本量和时间）。

**论断也要有出处，不只是数字。** 「研究证实」「实践表明」「已被验证有效」这类表述属于借权威背书，和引用数据一样需要出处。写不出具体研究或案例的，降级成「参考同类实践」或直接删掉。评审对无出处的权威背书比对缺数据更敏感，因为它看起来像有依据。

**注意**：数据要和受益群体对得上。写乡村儿童阅读，引用的是「全国儿童阅读量」这种全口径数据，说服力很弱；引用「农村小学生均图书拥有量」才切题。

**常见错误**：只有定性描述（「XX 问题日益突出」「需求日益迫切」）；数据和项目无关；把行业规模当问题严重性；论证给资助方带来什么好处。

## 帮助谁（Who / 受益人）

必须回答两问：

1. **受益人是谁** —— 具体群体 + 规模数字。多类受益人分别列出各自规模。
2. **为什么选这个群体** —— 需求紧迫性、服务可及性、社会意义至少覆盖一条。

区分**直接受益人**和**间接受益人**，规模数字不要混在一起算。培训 100 名教师从而影响 3000 名学生，直接受益人是 100 名教师，不能写「受益人 3100 人」。

**涉及定向受益人时必须写筛选流程**，这是最容易被要求整改的地方。建议 4–6 步写清：

```
发布公开招募信息 → 收集申请 → 初筛（标准是什么）→
复筛（标准是什么）→ 结果公示 → 确定录取
```

三条底线：不能只靠执行机构内部推荐；不因户籍、性别、学校等设置无关限制；向低收入或特殊困难群体倾斜的规则要写明。

---

## 在哪做（Where / 实施区域）

两问：**在哪里**（具体到市/县/区，不要只写「西部地区」）+ **为什么选这里**（需求集中度、资源可及性、已有合作基础）。

多个实施地的，说明谁统筹管理。跨省项目说明各地的分工和进度协调方式。

---

## 做多久（When / 项目周期）

三个要素：

1. **精确起止时间**，到年月日
2. **分阶段说明** —— 每阶段做什么、达成什么
3. **资金拨付节奏** —— 分期比例和触发条件

**周期上限看资助方档案**。超过上限的必须附合理性说明，回答「为什么不能拆成分年申请」。合理的理由：建设周期客观不可压缩、成效观察需要跨年、与学制/农时/汛期绑定。不合理的理由：想省事、怕后续申请麻烦。

---

## 怎么做（What / 实施方式）

按板块或方面组织，每块 1–2 句说明做什么。这是**概述**，详细计划放在实施方案和目标章节里。

与目标章节的关系：方向必须一致，粒度不同。这里说「建图书角并培训教师」，目标章节说「建 50 个、培训 100 名、6 月前完成」。

## 公益属性与社会价值

两个维度都要写，很多人只写了后半截。

**维度一：公益属性 —— 这是不是真公益**

| 角度 | 要说明 |
|------|--------|
| 资金用途 | 全额用于公益目的，不产生商业回报 |
| 服务性质 | 公益或低偿，不设经济门槛 |
| 面向对象 | 弱势群体或特定困难人群 |
| 公平性 | 公开招募、困难群体优先、过程透明 |

**维度二：社会价值 —— 能带来什么改变**，分三层递进：

| 层 | 写什么 | 例子 |
|----|--------|------|
| 个体层面 | 受助者个人发生的改变 | 儿童养成阅读习惯，阅读理解能力提升 |
| 群体层面 | 受助群体的整体影响 | 项目校形成课外阅读的教学常规 |
| 社会层面 | 更广泛的意义或可复制性 | 沉淀可复制的乡村阅读推广模式 |

至少覆盖个体和群体两层，三层最佳。

**还要有独特性论述**：与同类项目的差异在哪（方法创新、技术手段、模式特色、合作网络）。

**禁止**：写成资助方或其关联企业的品牌价值、产品价值；用「免费」「无偿」这类绝对化表述。

企业 CSR 与直接捐赠是唯一例外：可以另设「合作价值」一节谈品牌契合与员工参与，但公益属性与项目目标这两节仍须是纯公益口径。

## 可持续性

回答一个问题：**项目结束后，成果怎么持续？**

| 维度 | 说明 | 例子 |
|------|------|------|
| 成果持续 | 产出在项目结束后如何继续发挥作用 | 图书角产权归学校，受训教师持续运营 |
| 模式可复制 | 经验能否推广到其他地区或群体 | 沉淀工具包与操作手册供其他机构使用 |
| 资金可持续 | 是否完全依赖单一资助方 | 探索公益 + 低偿混合模式，引入本地配套资源 |

至少覆盖 2 个维度。2–3 句话就够，不用长篇。

**必须有具体措施**。「我们会继续做」「希望持续获得资助」这两种写法都会被扣分 —— 后者尤其糟，等于承认项目没有自立能力。

## 实施方案、产出与预算

通常是一张表，四件事必须一一对应：

```
实施方案 → 项目产出/效果 → 验收标准/交付物 → 预算金额
```

**四条对齐规则**

1. 每个方案都有对应产出，不能有做了不产出的活动
2. 每个产出都有验收标准，且是**可留存的证据**
3. 每笔预算都对应到具体方案，方案里没提的活动不能有钱
4. 各方案预算之和 = 总预算 = 概要里的金额

**验收标准怎么写**

| 不合格 | 合格 |
|--------|------|
| 专家认可 | 提交 3 份专家评审意见书 |
| 效果良好 | 参与者满意度测评 ≥90%，附问卷原始数据 |
| 社会反响好 | 3 家市级以上媒体报道，附链接 |
| 完成培训 | 提交 12 期培训签到表与 12 份教案 |
| 参加国家级演出 | 至少参加 1 次省级或以上展演，附主办方证明 |

判断标准很简单：**验收标准 = 能留档的实物证据**。想一想项目结束时能交给审计的是什么。

预算科目与测算依据见 [budget-and-compliance.md](budget-and-compliance.md)。

## 项目团队

每人写清：姓名、岗位、职责范围（3–5 条）、在项目中的分工。本机构人员与合作方人员分开列；资助方也派人参与的，单独说明其角色。

**项目负责人必须写相关经验** —— 做过哪些类似项目、取得什么成果。这是评审判断执行能力的主要依据，一句话带过会被要求补充。

团队规模要和项目体量匹配。200 万的项目配 2 个兼职人员，或者 20 万的项目配 8 人团队，都会被质疑。

## 风险和预案

每条写「风险描述 + 应对措施」，不要只列风险不给对策。

建议覆盖的类型：

| 类型 | 常见风险 |
|------|---------|
| 人身安全 | 活动中的意外伤害，尤其涉及儿童、老人、户外活动 |
| 专业水准 | 服务质量不达预期、专业人员流失 |
| 运营管理 | 进度延误、合作方配合不足、场地或资质变动 |
| 资金使用 | 预算超支、票据不合规、采购价格波动 |
| 舆情 | 受益人隐私泄露、执行争议引发负面报道 |

写真实的风险。把「可能下雨」当主要风险，说明没认真想过。

## 特殊项目类型：再资助（资助方 → 中间机构 → 末端项目）

有一类项目的执行方是另一家基金会或支持型机构，拿到钱后再去筛选和资助末端项目。这类项目在申报时最容易出问题，因为**末端项目在提交申请时还没确定**。

必须额外写清五件事：

| # | 要写什么 | 不写会怎样 |
|---|---------|-----------|
| 1 | 末端项目的**遴选标准与流程** | 评审无法判断钱最终会给谁，等于开空白支票 |
| 2 | 末端执行机构的**资质门槛与审查方式** | 二次分配的合规责任不清 |
| 3 | 资金**流向如何追溯到末端** | 审计穿透不下去 |
| 4 | 末端项目确定后**如何补充产出与验收标准** | 目标章节里的「其他 1–3 个项目」永远无法验收 |
| 5 | 中间机构收取的**管理费与末端机构管理费是否叠加** | 双重管理费是常见退回原因 |

**目标章节的写法**：已确定的末端项目按正常规则写具体指标；未确定的部分写成**过程型可验收指标**，而不是留一个模糊数量。

| 不合格 | 合格 |
|--------|------|
| 完成其他 1 至 3 个青少年项目的资助 | 2026 年 8 月前完成公开征集与评审，资助不少于 2 个项目；每个项目在立项后 30 日内向资助方提交产出指标与验收标准，经确认后纳入本项目验收范围 |

**风险章节必须包含二次分配风险**：末端机构执行偏差、资金使用不规范、末端项目与本项目目标偏离，以及各自的控制措施（分期拨付、尾款与验收挂钩、定期跟踪）。

## 通用写作禁忌

**本表是全 skill 唯一的禁忌清单**，其他文件只引用不复制。起草和诊断时都对照这里。

### 一、不可量化的空话

| 禁忌 | 为什么不行 | 换成 |
|------|-----------|------|
| 提升影响力 / 扩大覆盖面 | 没有可测量的对象 | 具体数字目标 |
| 推动 XX 发展 / 促进 XX 进步 | 太泛，看不出到底做什么 | 具体要让什么发生 |
| 提高意识 / 增强能力 / 改善状况 | 无法衡量 | 可衡量的行为改变指标 |
| 建立长效机制 / 完善体系 | 不知道什么算建成 | 具体产出物 + 验收标准 |

### 二、绝对化与承诺过度

| 禁忌 | 为什么不行 | 换成 |
|------|-----------|------|
| 免费 / 无偿 / 不收取任何费用 | 后续任何收费都构成违约 | 公益性质 / 低偿 / 不设经济门槛 |
| 确保 / 保证 / 100% 达成 | 做不到时无退路 | 力争 / 预计 + 具体数值区间 |
| 全覆盖 / 零遗漏 | 极难验证，易被抓 | 覆盖 XX 个，占目标群体 XX% |
| 全国首创 / 唯一 | 无法证明，且易被反驳 | 在 XX 地区尚无同类服务（附依据） |

### 三、不可验收的主观描述

| 禁忌 | 为什么不行 | 换成 |
|------|-----------|------|
| 效果良好 / 社会反响热烈 | 主观，审计无从核对 | 可查证的客观证据 |
| 专家高度评价 / 各方一致好评 | 不可审计 | 提交 N 份专家评审意见书 |
| 广受欢迎 / 深受好评 | 同上 | 满意度测评 ≥X%，附问卷原始数据 |
| 积累了丰富经验 | 无法核实 | 完成 N 个同类项目，服务 N 人 |

### 四、立场与主体错位

| 禁忌 | 为什么不行 | 换成 |
|------|-----------|------|
| 为 XX 企业带来品牌价值 | 申报材料不能把商业回报写成项目目的 | 聚焦公益效果与社会价值；企业 CSR 项目可单列「合作价值」一节 |
| 提升企业产品销量 / 拉动业务 | 同上，且触碰公益性质红线 | 删除 |
| 把基金会与关联企业混着写 | 独立法律主体，混同会被要求整改 | 分开表述 |
| 希望持续获得资助 | 等于承认项目没有自立能力 | 具体的成果延续与资源多元化措施 |

### 五、活动当目标

| 禁忌 | 为什么不行 | 换成 |
|------|-----------|------|
| 开展 20 场活动 / 举办 5 次培训 | 这是手段，不是结果 | 这些活动让谁发生了什么可测量的变化 |
| 完成 XX 平台搭建 | 建成不等于有用 | 平台上线并有 N 个机构实际使用 |
| 印发 1 万份手册 | 发出去不等于起作用 | N 所学校将手册纳入常规使用 |

### 六、预算禁止表述

| 禁忌 | 为什么不行 | 换成 |
|------|-----------|------|
| 不可预计费用 / 杂项 / 机动经费 | 用途不明，多数资助方明确禁止 | 拆成明确用途的科目 |
| 其他费用（无说明） | 同上 | 列明具体内容 |
| 只有总价没有测算依据 | 无法判断合理性，常被直接调减 | 单价 × 数量 × 频次 |

预算科目的完整规则见 [budget-and-compliance.md](budget-and-compliance.md)。

## 通用质量口径

写完任何一段，用这三条自查：

1. **有没有数字** —— 能量化的地方是否都量化了
2. **能不能验收** —— 第三方拿着这句话能判断做到没做到吗
3. **是不是在说人话** —— 删掉所有形容词后，还剩下信息吗
