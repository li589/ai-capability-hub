# 文案去 AI 味改写规则（后端 rewrite mode 行为规格参考）

> **定位说明（v0.2.0）**：从 v0.2.0 起，改写能力走后端异步任务（`mode=rewrite`），agent 不再本地执行改写。本文件作为后端 rewrite prompt 的行为规格参考保留——后端改写 prompt 可能参考了本文件中的社媒平台语感矩阵、体裁决策矩阵、高频 AI 模式检测与修复规则等。agent 无需直接读取本文件执行改写，但可在需要向用户解释改写规则或自定义改写偏好时参考。
>
> 与开源 `humanizer-zh` 的差异：本规则**专为社媒文案体裁定制**（小红书/视频号/公众号/抖音），改写目标是「发出去被真实读者看、像真人写的社媒文案」，而非通用中文润色；并新增「爆款视角的真人化」原则与全平台语感差异。

---

## 0. 一句话目标

在**保留事实、卖点、作者立场与发布用途**前提下，把 AI 腔社媒文案改写成「读起来像真人发的、符合该平台语感、能被目标读者看下去」的文案。**改写而非删除、等量覆盖**——原文五段改完仍五段，不压缩成梗概。

---

## 1. 社媒平台语感矩阵（先判平台，再动笔）

不同平台的「人味」标准不同，按用户声明的平台套用：

| 平台 | 默认人味基调 | 允许的语感 | 慎用 |
|------|--------------|------------|------|
| **小红书** |种草口吻、第一人称体验、真实吐槽 |emoji 适度、口语词(咱/姐妹/真的)、短句分段、有「缺点/槽点」才像真 |过度加粗、标题党堆名词、无脑接「绝绝子yyds」 |
| **视频号(口播/字幕)** |口说感、有节奏停顿、像对镜头说话 |短句、省略主语、口语连接词、可重复强调 |书面长句、嵌套从句、四字成语堆砌 |
| **公众号** |克制、有观点、段落有呼吸 |长短句交替、可直接给判断带态度、可有个人夹叙 |营销通稿腔、宣传形容词堆叠 |
| **抖音(口播/标题)** |强钩子、信息密度高、说人话 |开头 3 秒抓人、一句一信息、口语化 |书面化、铺垫太长、金句堆叠成戏剧化 |

未声明平台时，回退「自然、参差、有观点」的通用社媒人味。

## 2. 社媒文案体裁决策矩阵

社媒文案基本不触学术/法律体裁，但仍需区分：

| 体裁 | 默认处理 | 是否可补细节 | 必须保留 |
|------|----------|--------------|----------|
| **种草/测评(个人体验)** |保留第一人称、补真实摩擦与混合情绪；可加场景细节 |仅作者自身体验可补低风险细节，逐项计入「待核实」 |真实体验、使用场景、立场 |
| **口播脚本/口播文案** |改成口说感，加节奏停顿；信息点不丢 |不得虚构功效、数据、用户反馈 |核心卖点、行动号召、信息点顺序 |
| **标题/封面文案** |写具体对象，砍掉抽象名词堆叠 |不得虚构数字、排名 |要表达的卖点、平台字数限制 |
| **活动/促销文案** |删空泛夸张，保留合理促销语气 |不得虚构指标、限时紧迫感的虚假依据 |价格、规则、时间、适用条件 |
| **品牌/官宣文案** |克制有观点，删宣传腔 |不得虚构背书、媒体引用 |品牌定位、限定条件、可验证主张 |

### 事实与新增细节（硬规则）

- **不得补写原文没有的事实**：功效数据、对比排名、奖项、用户反馈、媒体报道、销量——一律不加。
- **种草个人体验**可补**低风险场景细节**(使用时机、身体感受、使用摩擦)，但须逐项列入终稿后的「待核实内容」。
- 不得把 AI 评估/真人评估的结论写进文案正文(那是评估环节的事)。

## 3. 识别 & 修复：社媒文案高频 AI 模式

扫描以下模式，**用自然表达替换、覆盖原文全部信息点**，不删除信息。

### 3.1 内容与套路层

**P1 营销通稿腔 / 宣传形容词堆叠**
- 观察：领先、卓越、极致、革命性、全方位、赋能、护航、匠心、沉浸式；「打造了一套卓越的智能解决方案，全面赋能」。
- 修复：换成可验证的具体描述。「我们做了 X，让 Y 从 A 变成 B」。

**P2 意义拔高 / 趋势包装**
- 观察：开启新篇章、推动行业变革、标志着关键时刻、为……奠定基础、代表一个转变。
- 修复：写它具体改变了什么、影响谁、影响程度。

**P3 公式化「挑战与展望」收尾**
- 观察：机遇与挑战并存、未来可期、前景值得期待、将持续探索。
- 修复：用具体的下一步、限制或判断收尾。社媒文案直接砍掉这种结尾多半更好。

**P4 模糊归因 / 虚假权威**
- 观察：有人认为、业内普遍认为、专家指出、越来越多的人开始关注。
- 修复：能指明来源就指明；不能就改成谨慎的事实陈述，或直接删。

**P5 三段式凑数**
- 观察：更快、更稳、更智能；效率、体验、价值；看得见、摸得着、用得上。
- 修复：保留最重要一两个点，补具体说明。

### 3.2 语言与句式层

**P6 AI 高频词扎堆**
- 观察：赋能、生态、闭环、抓手、底层逻辑、价值沉淀、全链路、颗粒度、场景化、范式、跃迁；英文 moreover/delve/tapestry 等。
- 修复：问「这词具体指什么」，用答案替换。

**P7 回避「是」与明确判断**
- 观察：可视为、呈现出、体现了、彰显了、具备……属性、充当……。
- 修复：能用「是」就用「是」；能说人话就别写鉴定报告。

**P8 否定式排比 / 句尾否定碎片**
- 观察：不是……而是……、不只是……更是……；句尾挂「无需猜测、不留死角」。
- 修复：直接写正面判断；把碎片还原成完整句子。

**P9 虚假范围**
- 观察：从 A 到 B、覆盖 X、Y、Z 等多个方面、贯穿全生命周期。
- 修复：写真实范围，删装饰性全覆盖。

**P10 无主句 / 被动 / 抽象名词行动**
- 观察：无需配置、结果会被自动保存、已完成优化、数据告诉我们、市场会奖励。
- 修复：补主语改主动句；点名人/团队/用户，别让抽象名词替人行动。

### 3.3 风格与节奏层

**P11 破折号戏剧停顿**
- 观察：连续「——」制造转折/揭示感；中英混排 ` — ` / ` -- `。
- 修复：按优先级替换——句号起新句、逗号紧插、括号旁白，或重构。单个破折号不算痕迹，修成串戏剧化用法。

**P12 加粗过度 / 内联标题列表**
- 观察：每段都加粗；「**效率：**…… **体验：**…… **成本：**……」连续排列。
- 修复：只保留真正需加粗的关键词；内联标题列表能合并就合并。

**P13 标题党式并列名词**
- 观察：标题堆抽象名词「效率、体验与增长」「认知、策略与未来」。
- 修复：标题写具体问题或具体对象。

**P14 emoji 与格式模板化**
- 观察：✨🚀✅📌 满屏、每项前装饰 emoji。
- 修复：社媒平台允许适度 emoji(尤其小红书)，但别模板化堆砌；非活泼场景删减。

**P15 人造金句 / 短句戏剧化堆叠**
- 观察：连续短句「然后，一切改变了。没有预兆。没有退路。」；段尾 pull-quote 式标语。
- 修复：合并句子降戏剧化，补具体变化；检查每段末句是否只为「落点漂亮」。

**P16 格言化公式**
- 观察：X 是 Y 的语言、X 不是工具而是镜子、效率会成为陷阱。
- 修复：把格言换成它真正想说的具体论点。

**P17 伪口语化钩子开场**
- 观察：「说实话？」「讲真，」「重点来了，」单独当钩子再抛普通观点。
- 修复：非作者真实口头风格就删钩子，直接写观点。(注：小红书/抖音真实口语开场可保留，看是否戏剧化「停顿—揭示」。)

**P18 导览式开场 / 过程宣告**
- 观察：让我们深入探讨、下面我们来拆解、本文将带你了解。
- 修复：删宣告，直接写正文。

**P19 协作交流痕迹混入正文**
- 观察：当然可以、下面是一份……、希望这对你有帮助、需要我展开吗——整段粘进正文。
- 修复：删除元对话，保留正文。

**P20 谄媚语气**
- 观察：这是一个非常棒的问题、你的想法非常有价值、你说得太对了。
- 修复：删奉承，直接回应。

### 3.4 填充与回避层

**P21 填充短语**
- 观察：值得注意的是、不可否认的是、在某种程度上、总体而言、说在前面、重点来了。
- 修复：删后看句子是否成立，成立就删；冗长说法换短。

**P22 过度限定 / 绝对化**
- 观察：可能、或许、一定程度上、相对来说堆叠；或所有、总是、从不、没有人。
- 修复：保留必要限定，删重复保险；绝对化改可验证范围。

**P23 通用积极结论**
- 观察：未来可期、值得期待、具有广阔前景、将创造更大价值。
- 修复：用具体下一步、风险或判断收尾。

**P24 中英文术语堆砌 / 复合词滥用**
- 观察：AI-native、data-driven、end-to-end、real-time、全链路机械堆叠。
- 修复：保留必要术语，解释它在本文具体含义。

**P25 权威姿态 / 伪洞察**
- 观察：真正的问题是、归根结底、本质上、底层逻辑是、关键不在于……而在于……。
- 修复：直接写判断和依据，别先否定稻草人再揭示「真正答案」。

**P26 同义词循环 / 刻意换词**
- 观察：同一物被换成平台、系统、工具、方案、能力、模块。
- 修复：同一个东西用同一个词，必要时重复。

## 4. 检测校准（避免误伤好文案）

单个信号几乎说明不了问题，找**信号成簇**。以下**单独出现时不该当成 AI 信号**：

- 完美语法/一致文风(专业写手也这样)
- 平淡或干燥的文风(AI 破绽是特定几种，干燥不等于 AI)
- 偶尔连接词「此外、因此、然而」(只有扎堆才是信号)
- 单个破折号、单个 emoji、单句短句
- 书信体称呼/落款、行业规定套话、被引用的固定说法

判断要看特征是否**成片出现**，且让文本**空泛、虚高、模板化或不像当前作者**。

### 优先保留的人类写作迹象

- 难以编造的具体细节(真实地名、价格、一句奇怪的引语、当事人小事)
- 未化解的混合情绪(「大体不错但有地方不舒服，又说不清」)
- 有年代感的圈层引用/梗
- 具体的限制、例外和个人判断(带取舍而非四平八稳)
- 明确主语和动作
- 句长参差
- 真实旁白、括号插话、当场自我修正

## 5. 改写流程（初稿 → 自检 → 终稿）

1. **通读判平台与体裁**：按平台语感矩阵 + 体裁决策矩阵定基调；标出命中的模式簇。
2. **写初稿**：先处理空泛/虚高/模板化(P1-P5)，再理句式标点(P6-P13)，再清填充与伪洞察(P21-P25)；信息点等量覆盖，能「是」就「是」，口播文案改口说感。种草体验若补细节，同步记录。
3. **自问：「是什么让这段还像 AI？」** 列一两条残留痕迹。
4. **改出终稿**：消除残留；扫事实保留、语气自然、破折号未成串、短句未堆戏剧化、所有新增已计入「待核实」。

### 六维自检（1-10 分，总分低于 42 再改一轮）

| 维度 | 自检问题 |
|------|----------|
| 直接性 | 在陈述事实，还是在宣布「接下来要说什么」？ |
| 节奏 | 句长有变化，还是像节拍器整齐？ |
| 读者信任 | 删掉不必要的安抚、铺垫、手把手了吗？ |
| 真实感 | 有具体行动者、具体细节、真实取舍吗？ |
| 信息密度 | 每句都增加信息，还是重复/缓冲/装饰？ |
| 事实边界 | 遵守体裁新增规则？新增项已列入待核实？ |

## 6. 交付物

默认直接交付终稿。用户要求展示过程时按序：初稿 → 「仍像 AI」要点(一两条) → 终稿 → 改动小结。

**改动小结**说明：改掉哪些 AI 腔、保留哪些事实与语气、哪些地方因用途未改。

种草/个人体验终稿若加了原文没有的内容，在终稿后、改动小结前追加：

```markdown
**待核实内容**
- 新增：[具体内容]（原文未提供）
- 新增：[具体内容]（原文仅说明了……）
```

无新增不输出此段。**不得声称「无法被 AI 检测器识别」**——本能力只做写作编辑与风格修复。

## 7. 与开源 humanizer-zh 的差异小结

- 体裁：本规则聚焦社媒文案(种草/口播/标题/促销/官宣)，非通用中文润色。
- 平台：新增四平台语感矩阵，按平台套不同「人味」标准。
- 爆款视角：删公式化「挑战展望」、戏剧化金句堆叠——这些是社媒 AI 文案典型痕迹且损害真实感。
- 评估闭环：改写后接入「真人评估」环节(见 SKILL.md)，由模拟读者检验残留人味，闭环不在本文件。
