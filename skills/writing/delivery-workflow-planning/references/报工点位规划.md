# 报工点位与现场硬件规划（方法论 3.4 报工点位硬件部署）

> 对应方法论任务 **3.4 报工点位硬件部署确认**（乙方输出：报工点位规划，甲方输出：采购硬件完成清单）。
> 输入：调研掌握的车间结构 / 人员数量 / 设备布局；输出：每车间的点位类型、数量、硬件清单与采购建议。
> 联动：调研问卷（阶段一）须采集点位规划所需的车间/人数/设备布局信息；蓝图助手 2.5 报工点位规划页引用本规划结果。

---

## 一、现场硬件选型原则（决策规则）

| 场景特征 | 推荐模式 | 说明 |
|---|---|---|
| **固定生产设备为主**（设备密集、机台固定） | **工位机 + 扫码枪** | 按设备密度布点，一般 **1 台工位机覆盖 4-6 台设备**；设备越多密度越大，越倾向工位机（减少走动、报工即设备绑定） |
| **有明确车间界限**（车间/产线物理边界清晰） | **按车间设定工位机** | 车间入口/中央布 1 台工位机 + 扫码枪，车间内人员就近报工；设备特别多时按 4-6 台/台 叠加 |
| **流水线/组装车间**（产线连续流转） | **工位机** | 按产线布点（一般每产线 1-2 台），扫码枪扫工单/序列号流转 |
| **人员多且需单独报工**（个人计件/独立任务） | **移动端（手机/PDA）** | 每人配移动端独立报工，避免排队；报工粒度到人 |
| **质检人员** | **移动端（手机/PDA）** | 质检员流动性强（跨工位检验/不良登记），标配移动端 |

### 决策优先级
1. 先判断车间生产方式：**固定设备 → 工位机为主**；**流水线 → 工位机按产线**；**人员独立报工 → 移动端**
2. 质检人员一律移动端（不占用工位机）
3. 设备密度与车间界限共同决定工位机数量：`台数 = max(车间界限基数 1 台, ceil(设备数 / 5))`（默认 5 台/台，可调 4-6）

## 二、调研采集项（阶段一问卷加入，点位规划输入）

在调研问卷「现场参观 / 生产部门」模块补充采集：

| 采集项 | 问卷问题示例 | 用途 |
|---|---|---|
| 车间/产线清单 | 本次上线涉及哪些车间/产线？物理界限是否清晰？ | 按车间/产线布点 |

## 三、点位规划输出（阶段三随实施流程规划输出）

### 3.1 输出方式

```bash
PY="{{HOME}}/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
# 按车间/产线参数生成点位规划表（xlsx）
"$PY" scripts/gen_point_plan.py --client "<客户名>" \
  --plan "PVC车间:fixed:8:6:1,拉丝车间:fixed:12:4:1,组装线1:line:0:10:0,质检科:qc:0:0:3" \
  --out "<输出目录>/{客户名}_报工点位规划.xlsx"
```

`--plan` 格式：`车间名:模式:设备数:操作工人数:质检人数`（逗号分隔多个车间）
模式：`fixed`（固定设备）/ `line`（流水线）/ `mobile`（人员独立报工）/ `qc`（质检）/ `zone`（车间界限明确）

### 3.2 生成规则（与选型原则一致）

| 模式 | 点位类型 | 数量规则 |
|---|---|---|
| `fixed` 固定设备 | 工位机+扫码枪 | `max(1, ceil(设备数/5))`（4-6 台/台） |
| `zone` 车间界限 | 工位机+扫码枪 | 每车间 1 台起步，设备密集再按 `ceil(设备数/5)` 叠加 |
| `line` 流水线 | 工位机 | 每产线 1-2 台（默认 1 台/线） |
| `mobile` 人员独立报工 | 移动端（手机/PDA） | 按操作工人数 1:1 |
| `qc` 质检 | 移动端（手机/PDA） | 按质检人数 1:1 |

### 3.3 输出表结构（xlsx，Sheet1 点位规划 + Sheet2 硬件采购清单）

**Sheet1 报工点位规划**：车间/产线 | 生产方式 | 点位类型 | 点位数量 | 覆盖设备/人员 | 备注
**Sheet2 硬件采购清单**：硬件 | 数量 | 用途 | 客户利旧项（平板/电脑/扫码枪）

### 3.4 规划写入实施流程规划 docx

阶段三生成 `{客户名}_实施流程规划.docx` 时，新增章节「报工点位规划」：
1. 每车间/产线：生产方式判定 → 点位类型与数量 → 布局说明（工位机放哪、覆盖哪些设备）
2. 硬件采购清单汇总（区分新购/利旧）
3. 联动说明：与报工记录模式（设备/派工/人员）对应，移动端点位对应人员报工模式
