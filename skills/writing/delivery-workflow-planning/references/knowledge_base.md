## 四、跨客户流程设计模式库

### 通用主流程（8+1 节点，各车间复用）
工单下发 → 产前准备（派工/上工/SOP/点检/上料）→ 生产派工 → 开始加工 → 过程检验（首/自/巡）→ 结束加工（报工+标签）→ 例外处理（暂停/返工/报废）→ 生产入库（扫码抛转）→ 工单结案。

### 车间差异化设计模式
| 模式 | 适用场景 | 处理要点 |
|---|---|---|
| 设备密集型工序 | 设备为主的生产（PVC/拉丝/编链/包塑；打标/焊前焊后/SPC/气密） | 设备报工台+点检+稼动卡控 |
| 人工组装工序 | 配件包装类、清洗/GP12/外观检 | 生产报工台+按班组/人员明细 |
| 非工序化环节 | 拉丝（仅信息记录）；焊前清洗（不记录） | 不作为工序，扫码记录+出标签 或 配置免报 |
| 全检关键环节 | 安全拉力测试（客户重点关注） | 独立检验节点+异常登记 |
| 特殊计量单位 | 双单位/多单位产品 | 报工前确认主计量单位 |
| **单件序列号追溯** | 汽配/高价值单件（客户B：一物一码） | 打标生成序列号→扫码单件报工→序列号冻结/校验/状态管理 |
| **设备反向控制** | CNC 可联网客户 | IIOT 数采+反向指令（首检异常锁机/停机） |
| **工序报工合并** | 相邻工序一人操作（10+20序合并） | 支持多工序合并报工，免报工序配置 |
| **工价双轨** | 计件+计时混合（90序前后分界） | 工价方案按车间/工艺/物料/设备+计件计时双轨维护 |
| **工单类型驱动** | 多工单类型客户（宇牌：7种） | 先建"工单类型→派工→报工"映射矩阵再设计流程 |
| **产线即设备** | 流水线组装客户（裸机/电池包/包装线） | 产线以设备形式维护+点检，报工台按产线 |
| **虚拟产线** | 半成品/小批量（小组件1-2人组装） | 创建虚拟产线报工，记录大致工时 |
| **低成本数采** | 无硬件预算客户 | 固扫+现有产线工位电脑，仅关键线数采 |
| **换线首检** | 频繁换线组装线 | 换线触发首检规则，巡检时机按产品可配置 |

## 五、蓝图输出结构模板（规划文档标准章节）

概述（背景/目标/范围）→ MES 主流程总览 → 各车间主流程 → 核心子流程（派工/报工/质量/设备）→ 报工点位规划 → 关键差异说明 → 效益概述（As Is→To Be）→ 下阶段工作。
