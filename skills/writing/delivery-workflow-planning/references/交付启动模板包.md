## 一、初访 PPT 骨架（1.2 共识目标）

面向客户初访/现场参观的高阶沟通演示，**8-10 页**，目的：对齐目标、建立信任、收集信息。

| # | 页面 | 内容要点 |
|---|------|---------|
| 1 | 封面 | 客户名 + 鼎华 eMES + 初访交流 |
| 2 | 公司简介与实施方法论 | 5 大阶段（规划启航→蓝图设计→构建验证→上线赋能→优化升华）总览 |
| 3 | 8 大透明预期 | 派工/进度/设备/质量/人员/资料/不良/产能透明——**展示系统现有报表/看板清单，请客户圈选关注项** |
| 4 | 调研提纲 | 按人机料法环测 6 维度列现场参观重点（产线布局/设备清单/单据流/检验环节/标签打印） |
| 5 | 项目组织建议 | 双方 PM、关键用户、顾问团队分工建议 |
| 6 | 实施计划草案 | 从任务表生成的首版甘特（辅导天数 + 间隔周期倒排） |
| 7 | 数据收集要求 | 基础资料清单预览（工厂→车间→工艺→设备→物料→工单→工艺路线→订单→领料→仓库） |
| 8 | 沟通机制 | 周报/月报、问题管制表、变更管理 |
| 9 | 下一步 | 确认上线日期 → 项目计划制定 → 启动会 |

### 共识目标确认（1.2，初访+调研后确认，蓝图体现）

**原则：不扩充表格，以 eMES 现有报表/看板/数据为基础和依据。**

1. **8 大透明目标圈选**：根据**调研掌握的客户痛点**，在 8 大透明中圈选本期透明化目标（一般 3-5 项），每项写清"客户关注的原因"。
2. **验收 = 报表**：每个选定的透明目标，落到**具体可见的报表/看板**——即"看到哪几张报表就算上线/达成"，作为验收依据。
   - 例：产能透明 → 生产日报表、车间产量看板；设备透明 → 稼动率报表、点检完成率。
   - **不要自造报表需求**：以 eMES 现有报表清单为准，缺的走二开评估。
3. **物理范围确认**：同步确认实施物理范围——覆盖哪些厂区/车间/产线/工序，一期纳入哪些设备与物料。
4. 确认结果记录在《实施进度确认表》首版，蓝图报告会（2.7）正式签字体现。

### 目标选择库（顾问圈选参考，报表以系统现有为准）

| 目标 | 说明 | 常见验收报表/看板（以系统现有为准） |
|------|------|------------|
| 追溯透明 | 批次/单件全链路可追（来源-过程-流向） | 序列号追溯查询、领料/耗料报表 |
| 产能透明 | 车间实时产量、计划达成可视化 | 生产日报表、产量看板 |
| 设备透明 | 稼动率/停机/点检实时掌握 | 稼动率报表、设备状态看板、点检报表 |
| 质量透明 | 首自巡检闭环、不良及时登记评审 | 检验报表、不良登记表、不良评审单 |
| 人员透明 | 报工与人员绑定、工时统计提效 | 报工明细报表、工时统计表 |
| 任务透明 | 派工到人、任务优先级清晰 | 派工看板、任务执行情况查询 |
| 进度透明 | 工单/订单进度实时可见 | 工单进度查询、订单进度看板 |
| 不良透明 | 不良品流向清晰、处置闭环 | 不良报表、报废/返工记录 |

## 二、项目实施计划（1.3 项目计划制定）

### 生成方式（强制用脚本，不手工排）

```bash
PY="{{HOME}}/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
# 倒排（推荐）：锚定上线日期，按方法论建议间隔反推
"$PY" scripts/gen_project_plan.py --client "客户名" \
  --online-date 2026/08/01 \
  --adjust "1.4:2,3.5:3" \                        # 按调研实施范围/功能范围调整辅导天数（可选）
  --out-format both --out "输出目录/{客户名}_项目实施计划"
# 正排：从项目启动日开始
"$PY" scripts/gen_project_plan.py --client "客户名" \
  --launch-date 2026/06/01 --out "输出目录/{客户名}_项目实施计划.html"
```

- 读取 `references/实施计划任务表.json`（27 项任务标准参数）
- **正排模式**：从 `--launch-date`（项目启动日）向后推，任务开始 = 前一任务完成日 + 前一任务 interval（阶段安排间隔周期）
- **倒排模式**（默认，推荐）：先按正排生成全表，再整体平移使 **4.2 系统正式切换锚定上线日**——间隔完全遵循《实施方法论》建议
- **时数调整** `--adjust "编码:天数,..."`：按调研的实施范围（车间数/产线数）与功能范围（模块覆盖）调整对应任务辅导天数，如调研范围大则 1.4 调研、3.5 模拟验证加天
- **输出格式**：`--out-format html / xlsx / both`——**Excel 输出**（甘特：里程碑一览 + 分阶段计划）供客户/项目例会直接使用
- 里程碑任务（☆）单独标记，并在计划头部生成「里程碑一览」

### 实施计划章节结构（docx）

1. 项目概述（客户/范围/目标选择）
2. 里程碑一览表（7 个 ☆：1.4/2.1/2.2/2.7/3.6/4.3/5.2）
3. 分阶段甘特表（5 阶段逐表）
4. 双方交付物清单（每任务 乙方产出/甲方产出 两列）
5. 沟通与变更机制（周报/问题管制表/需求变更流程）

辅导内容：
  1. ____________________
  2. ____________________
需要客户提前准备：
  □ 参与人员名单  □ 相关数据/单据样本  □ Demo 环境可用
辅导顾问：__________  联系方式：__________
请于 ____ 前回复确认。谢谢！
