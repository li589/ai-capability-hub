## 搜索建议

- **语言策略**：A股/港股相关用中文，全球市场/美股用英文
- **时效性**：盘前搜索 24h 内内容，盘后搜索当天内容
- **具体性**：关键词尽量具体，避免过泛返回无关结果
- **批量输入**：同一次报告优先合并为一条 `westock-finsearch query "关键词组1" "关键词组2" "关键词组3"`，避免逐主题串行
- **多来源**：首次结果不足时最多补查 1 轮不同关键词组合，交叉验证
- **动态扩展**：根据 config 中 `focusAreas` 和 `userNotes` 动态追加搜索

## 可复制示例

```bash
# 盘前至少 3 个主题
westock-finsearch query "A股 盘前 利好 利空" "美股收盘 今日" "人民币汇率 美元指数 离岸"

# 盘后至少 3 个主题
westock-finsearch query "A股 收盘 今日行情" "今日板块涨幅 主力资金 北向资金" "龙虎榜 今日 机构 游资 净买入"
```
