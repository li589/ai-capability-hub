# 用户偏好与配置迭代

westock-brief 会根据用户偏好调整搜索主题、市场权重、自选股筛选和输出重点。偏好变更必须具体确认，不能只说“记住了”。

## 默认配置

| 配置项 | 默认值 | 用户表达示例 |
|---|---|---|
| 关注市场 | A 股、港股、美股 | “不看美股了”“加上日股” |
| 主要市场 | A 股 | “以港股为主” |
| 关注领域 | 宏观政策、地缘政治、大宗商品、北向资金、板块轮动 | “最近关注 AI 和半导体” |
| 异动阈值 | 涨跌幅 5%、成交量 2 倍 | “涨跌超过 3% 就提醒我” |
| 定时时间 | 盘前 8:30、盘后 16:30 | “把盘前分析改到 8 点” |
| 重点关注 | 无 | “我重仓了腾讯”“茅台重点看” |
| 排除主题 | 无 | “不需要加密货币” |

## 偏好变更流程

1. 解析用户要改的配置项。
2. 判断是否涉及 cron（定时任务）：
   - 涉及推送时间、频率或任务启停：读取 `references/cron-management.md`，先 `openclaw cron list`。
   - 不涉及 cron：只更新对话中的偏好记忆。
3. 具体确认变更结果。
4. 说明后续盘前 / 盘后分析会如何变化。
5. 说明生效范围：当前会话、后续定时推送，或二者都有。

## 路由边界

- “涨跌超过 X% 就提醒我”在 westock-brief 语境下表示调整早晚报异动阈值，不转到 westock-watch。
- 只有用户明确要求“实时监控”“盯盘”“立刻通知”“到价提醒”时，才转到 westock-watch。

## 常见反馈处理

| 用户说 | 操作 | 确认时必须说明的影响 |
|---|---|---|
| “多关注新能源” | 记住关注领域 | 后续分析将针对新能源生成搜索关键词，新能源涨跌和资金动向会优先进入板块分析 |
| “不需要加密货币” | 记住排除偏好 | 后续隔夜要闻和关注领域中过滤加密货币相关内容 |
| “涨跌 3% 就提醒” | 异动阈值改为 3% | 自选股涨跌幅超过 ±3% 即标记异动并重点分析 |
| “盘前改到 7:45” | `openclaw cron list` 后执行 `openclaw cron edit <job-id> --cron "45 7 * * 1-5"` | 盘前推送时间从 08:30 调整为 07:45 |
| “我重仓了腾讯” | 记住重点关注 `hk00700` | 腾讯优先进入核心自选股，每次分析重点展示走势、消息面和资金面 |
| “以港股为主” | 主要市场改为港股 | 恒生 / 恒生科技优先展示，港股搜索权重提升；A 股精简为指数速览；美股搜索和指数查询按需跳过 |

## 确认话术

好的确认：

> 已调整：后续盘前分析将优先展示恒生指数和恒生科技行情，港股搜索权重提升；A 股仅保留上证 / 沪深 300 速览；美股相关搜索和指数查询将跳过。下次推送即生效。

> 异动阈值已从 5% 调整为 3%。后续盘前 / 盘后分析中，自选股涨跌幅超过 ±3% 即标记为异动并重点分析，当前会话和后续定时推送都生效。

不合格确认：

- “记住了，以后主看港股。”
- “好的，已记录。”
- “没问题。”

## 生效范围

- 对话内偏好：当前会话立即生效；如系统支持记忆，可用于后续会话。
- 定时任务偏好：如果偏好影响 cron message（消息）或 cron 表达式，必须编辑任务后才对定时推送生效。
- 一次性分析偏好：用户只说“这次先看港股”，只影响本次 Dashboard，不写成长期偏好。
