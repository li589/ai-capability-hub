# Dashboard 输出模板

westock-brief 输出给用户的唯一文本必须是 Dashboard。标题必须是第一行，标题前不得有任何说明、状态播报或分隔线。

## 全局格式

- 盘前标题：`🌅 盘前简报 | 2026年3月31日 周一`
- 盘后标题：`🌆 盘后简报 | 2026年3月31日 周一`
- 标题格式：`{emoji} 盘前/盘后简报 | {年}年{月}月{日}日 {星期}`
- 日期后禁止附加任何说明文字，包括“非交易日”“对应 X 月 X 日交易日数据”。
- 正文中可用 `---` 或 `━━━` 分隔板块，但标题前禁止分隔线。
- 中国市场使用红涨绿跌。
- 无数据区块可跳过；不要用“暂无消息”“无明显变化”填充版面。
- 除 Dashboard 外，不输出“正在分析”“数据已到位”“以下是报告”等文字。
- Dashboard 末尾必须保留声明：`声明：本内容仅为市场信息整理，不构成投资建议；数据可能延迟或缺失，请以交易所和上市公司公告为准。`

## 盘前模板

```markdown
🌅 盘前简报 | {日期} {星期}

👤 核心自选股（2-3 只）
  {股票1}：{仅展示有变化的维度，无变化的完全省略}
    {如有异动 → 竞价前瞻：高开/低开/平开}
  {股票2}：...
  📋 其余自选股：{仅列有隔夜新闻的，无则省略本行}

📡 隔夜要闻
  1. [事件标题]
     [2-3 句展开：关键数据、背景、对 A 股 / 港股的影响评估]
  2. [事件标题]
     [展开说明]
  3. ...

📅 今日关注（无事件则跳过此区块）
  {经济数据公布 / 新股申购 / 央行讲话 / 重要会议等}

🌍 全球市场速览

  | 市场/品种 | 最新价 | 涨跌幅 |
  |----------|--------|--------|
  | S&P 500  | {price} | {pct}  |
  | Nasdaq   | {price} | {pct}  |
  | 道琼斯    | {price} | {pct}  |
  | 美元指数  | {price} | {pct}  |
  | 离岸人民币 | {price} | {pct}  |
  | 原油(WTI) | {price} | {pct}  |
  | 黄金      | {price} | {pct}  |

  📝 {1-2 句快速结论，如“美股三大指数齐涨，科技股领涨；黄金创新高反映避险情绪升温”}

🔮 今日预判
  A股：{偏多/偏空/中性} — {一句话理由}（置信度：{高/中/低}）
  港股：{偏多/偏空/中性} — {一句话理由}（置信度：{高/中/低}）
  关注板块：{利好板块} ↑ | {利空板块} ↓

🎯 你的关注领域（来自配置）
  {根据 focusAreas 的针对性分析}

💡 {根据当天分析内容动态生成 1-2 个引导问题}

声明：本内容仅为市场信息整理，不构成投资建议；数据可能延迟或缺失，请以交易所和上市公司公告为准。
```

盘前区块规则：

- 无自选股时跳过“核心自选股”区块，提示用户添加自选股。
- 核心自选股分析总计不超过 10 行。
- “其余自选股”只列有隔夜重大新闻的个股；无新闻则省略。
- 搜索全部失败时，在相关资讯区块标注“资讯搜索暂不可用，本期仅基于行情数据”。

## 盘后模板

```markdown
🌆 盘后简报 | {日期} {星期}

👤 自选股复盘
  {股票1} {收盘价} ({涨跌幅})
    {仅展示有变化的维度，无变化的完全省略}
    {如有异动：→ 若 {条件} → {观察要点}}
  {股票2} ...
  📋 其余自选股：{1-2 句话总结，如“其余 8 只普涨，均涨 1.2%”。禁止表格、禁止逐个列举}

📈 今日市场：{一句话定性}
  情绪：{恐慌/谨慎/平稳/乐观/亢奋}
  涨跌比：{上涨家数}/{下跌家数} | 涨停 {n} 跌停 {n}

📊 指数收盘（仅显示有数据的指数，无数据则跳过整个区块）
  上证 {price} ({pct}) | 深成指 {price} ({pct}) | 沪深300 {price} ({pct})
  创业板 {price} ({pct}) | 科创50 {price} ({pct})
  恒生 {price} ({pct}) | 恒生科技 {price} ({pct})

🏭 板块表现
  领涨：{板块1} +{pct}% | {板块2} +{pct}% | {板块3} +{pct}%
  领跌：{板块1} -{pct}% | {板块2} -{pct}% | {板块3} -{pct}%
  📝 {2-3 句分析：为什么涨/跌、驱动因素、板块轮动方向、是否延续前日主线}

🐲 龙虎榜速览（有数据时展示，无则跳过此区块）
  自选股：{上榜的自选股分析，无则写“核心自选股今日未上榜”}
  市场热点：{2-3 只代表性上榜股，按主题归类}
    {个股1}：{机构/游资方向}，{净买入金额}
    {个股2}：...
  📝 {资金方向洞察：今日龙虎榜资金主攻什么主题？机构在布局什么方向？游资在追什么热点？}

💰 资金面
  北向 / 板块偏好：{来自 `westock sector ranking` 的北向热门板块或资金流入板块；无数据则省略本行，不写净流入金额}
  杠杆资金：{来自 `westock market-overview --type trade,updown,margin` 的两融余额变化；无数据则省略本行}
  📝 {解读：板块资金与市场涨跌统计是否一致？是否出现背离信号？杠杆资金情绪如何？}

🎯 关注领域（来自配置，取最相关的 1-2 个）
  {针对性分析：今日该领域发生了什么、资金动向、核心个股表现、后续催化剂}

🔮 明日展望
  方向：{偏多/偏空/震荡} — {一句话核心逻辑}（置信度：{高/中/低}）
  主线：{1-2 个明日可能延续的板块主线及逻辑}
  关注：{关键事件/数据发布}
  风险：{核心风险点}

💡 {根据当天分析内容动态生成 1-2 个引导问题}

声明：本内容仅为市场信息整理，不构成投资建议；数据可能延迟或缺失，请以交易所和上市公司公告为准。
```

盘后区块规则：

- 无自选股时跳过“自选股复盘”区块。
- 自选股复盘总计不超过 15 行。
- 其余自选股只能 1-2 句话总结，禁止表格、逐股列举、分“强势股 / 调整股”两段列举，禁止列出超过 3 只个股名称。
- 指数数据不可用时跳过指数区块。

## 失败示例

以下输出都视为失败：

- 标题前写“当前时间是...”或“数据已拿到，开始输出...”。
- 标题前出现 `---`、`***`、`━━━`。
- 标题写成 `🌆 盘后简报 | 2026年4月19日 周六（对应4月17日最新交易日数据）`。
- 盘后“其余自选股”用表格逐行列举。
