# 公文国标（GB/T 9704-2012）完整规则

## 一、页面设置

### 1.1 纸张
- 尺寸：A4（210mm × 297mm）
- 重量：60~80g/㎡

### 1.2 页边距
```
上：37mm ± 1mm（白边）
下：35mm ± 1mm
左：28mm ± 1mm（订口）
右：26mm ± 1mm
```

### 1.3 版心
- 宽度：156mm（210 - 28 - 26）
- 高度：225mm（297 - 37 - 35）

### 1.4 行字数
- 每行：28 字
- 每页：22 行

## 二、字体规范

### 2.1 公文各要素字体表

| 要素 | 字体 | 字号 | 颜色 | 备注 |
|------|------|------|------|------|
| 份号 | 宋体 | 4 号（14pt） | 黑色 | 阿拉伯数字 |
| 密级和保密期限 | 黑体 | 3 号（16pt） | 黑色 | 如："秘密★1年" |
| 紧急程度 | 黑体 | 3 号（16pt） | 黑色 | "特急"/"加急" |
| 发文机关标志 | 方正小标宋简体 | 推荐高度 ≤22mm | 红色 | 居中排列 |
| 发文字号 | 仿宋_GB2312 | 3 号（16pt） | 黑色 | 居中 |
| 签发人 | 仿宋_GB2312 + 黑体(姓名) | 3 号（16pt） | 黑色 | 上报公文用 |
| 标题 | 方正小标宋简体 | 2 号（22pt） | 黑色 | 居中 |
| 主送机关 | 仿宋_GB2312 | 3 号（16pt） | 黑色 | 顶格 |
| 正文 | 仿宋_GB2312 | 3 号（16pt） | 黑色 | 首行缩进 2 字符 |
| 一级标题 | 黑体 | 3 号（16pt） | 黑色 | "一、二、三、" |
| 二级标题 | 楷体_GB2312 | 3 号（16pt） | 黑色 | "（一）（二）（三）" |
| 三级标题 | 仿宋_GB2312 加粗 | 3 号（16pt） | 黑色 | "1. 2. 3." |
| 四级标题 | 仿宋_GB2312 | 3 号（16pt） | 黑色 | "（1）（2）（3）" |
| 附件说明 | 仿宋_GB2312 | 3 号（16pt） | 黑色 | 正文下空一行 |
| 发文机关署名 | 仿宋_GB2312 | 3 号（16pt） | 黑色 | 右对齐 |
| 成文日期 | 仿宋_GB2312 | 3 号（16pt） | 黑色 | 阿拉伯数字 |
| 印章 | - | - | 红色 | 骑年盖月 |
| 附注 | 仿宋_GB2312 | 3 号（16pt） | 黑色 | 左对齐 |
| 抄送机关 | 仿宋_GB2312 | 4 号（14pt） | 黑色 | 左对齐 |
| 印发机关和日期 | 仿宋_GB2312 | 4 号（14pt） | 黑色 | 左/右对齐 |
| 页码 | 宋体 | 4 号半角（14pt） | 黑色 | "— 1 —"格式 |

### 2.3 字体替换规则

当系统缺少公文专用字体时，自动替换：
```
方正小标宋简体 → 华文中宋 → 宋体
仿宋_GB2312     → 仿宋        → 宋体
楷体_GB2312      → 楷体        → 宋体
黑体              → 微软雅黑     → 宋体
```

## 三、段落规范

### 3.1 正文段落

```yaml
对齐方式: 两端对齐
缩进:
  左: 0 字符
  右: 0 字符
  首行: 2 字符
行距: 28磅 固定值
段前: 0 磅
段后: 0 磅
```

### 3.2 标题段落

一级标题（一、二、三、）：
```yaml
对齐方式: 左对齐
缩进: 0 字符
行距: 28磅 固定值
段前: 0.5 行
段后: 0.5 行
```

二级标题（一）（二）（三）：
```yaml
对齐方式: 左对齐
缩进: 0 字符
行距: 28磅 固定值
段前: 0.5 行
段后: 0.5 行
```

### 3.3 特殊段落

页码：
```yaml
位置: 版心下边缘之下一行
奇数页: 右空一字
偶数页: 左空一字
空白页: 不标页码
格式: "— 数字 —"
```

附件标识：
```yaml
位置: 正文下空一行，左空二字
格式: "附件：1. ××××"
```

## 四、红头规范

### 4.1 发文机关标志
- 字体：方正小标宋简体
- 颜色：红色
- 大小：推荐高度不大于 22mm
- 位置：居中，上边缘至版心上边缘 35mm

### 4.2 发文字号
- 字体：仿宋_GB2312 3 号
- 位置：发文机关标志下空二行
- 格式：×××〔2026〕×号
- 排列：居中

### 4.3 武文线
- 颜色：红色
- 宽度：0.35mm
- 长度：156mm（等于版心宽度）
- 位置：发文字号下空一行

## 五、印章规范

### 5.1 位置
- 成文日期处

### 5.2 规则
- 骑年盖月（印章盖在发文机关署名和成文日期上）
- 上不压正文，下压成文日期 4~7 个字

## 六、页码规范

### 6.1 格式
- 格式："— 1 —"
- 字体：宋体 4 号半角（14pt）
- 数字两侧各插入一条一字线

### 6.2 位置
- 奇数页：右空一字
- 偶数页：左空一字
- 空白页：不标页码

## 七、公文校验清单

### 7.1 必检项（15 项）

```yaml
1. 页边距: 3.7/3.5/2.8/2.6 cm ✅/❌
2. 正文字体: 仿宋 3 号 ✅/❌
3. 行距: 28pt 固定值 ✅/❌
4. 标题字体: 小标宋 2 号 ✅/❌
5. 一级标题: 黑体 3 号 ✅/❌
6. 二级标题: 楷体 3 号 ✅/❌
7. 三级标题: 仿宋 3 号 加粗 ✅/❌
8. 首行缩进: 2 字符 ✅/❌
9. 页码格式: — 1 — ✅/❌
10. 红头: 红色发文机关 ✅/❌
11. 武文线: 红色 0.35mm ✅/❌
12. 附件: 另起页 ✅/❌
13. 抄送: 仿宋 4 号 ✅/❌
14. 成文日期: 阿拉伯数字 ✅/❌
15. 印章占位: 红色占位 ✅/❌
```
