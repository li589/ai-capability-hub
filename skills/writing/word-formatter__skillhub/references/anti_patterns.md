# 常见错误与改进示例

## 错误 1：字体不统一

### ❌ 错误示例
```
标题用宋体，正文用微软雅黑，引用用楷体
整个文档字体混乱，缺乏一致性
```

### ✅ 改进方案
```
标题用微软雅黑 Bold 24pt
正文用微软雅黑 Regular 11pt
引用用微软雅黑 Italic 10pt
保持字体家族一致
```

### 建议
- 全文使用同一字体家族（如微软雅黑、思源黑体）
- 通过字号、粗细区分层次
- 避免使用超过 3 种字体

## 错误 2：行距不合适

### ❌ 错误示例
```
正文行距为单倍行距
阅读时视觉疲劳，段落拥挤
```

### ✅ 改进方案
```
正文行距 1.5~1.8 倍
根据排版场景调整：
- 商务报告：1.5 倍
- 学术论文：1.25 倍
- 极简风格：1.8 倍
```

### 建议
- 正文行距不低于 1.25 倍
- 长文建议 1.5 倍以上
- 配合段间距使用效果更好

## 错误 3：标题层级混乱

### ❌ 错误示例
```
一、第一章（一级标题）
  （一）第一节（二级标题？还是三级？）
    1. 段落（三级标题？还是正文？）
```

### ✅ 改进方案
```
一、一级标题（黑体 16pt）
  （一）二级标题（楷体 16pt）
    1. 三级标题（仿宋 16pt 加粗）
      （1）四级标题（仿宋 16pt）
```

### 建议
- 严格遵循标题层级：一、→ （一）→ 1. → （1）
- 公文必须用国标标题层级
- 商务文档可用 H1/H2/H3 样式

## 错误 4：中英文混排无空格

### ❌ 错误示例
```
使用Word进行智能排版时需要注意字体设置
这篇文章讨论了AI在排版中的应用
```

### ✅ 改进方案
```
使用 Word 进行智能排版时需要注意字体设置
这篇文章讨论了 AI 在排版中的应用
```

### 建议
- 中文和英文之间自动加空格
- 中文和数字之间自动加空格
- 使用正则表达式自动处理

## 错误 5：段落对齐不当

### ❌ 错误示例
```
正文用左对齐，标题用居中
导致段落参差不齐，视觉效果差
```

### ✅ 改进方案
```
正文用两端对齐（Justify）
标题用左对齐或居中
引用用左缩进
```

### 建议
- 正文优先使用两端对齐
- 标题根据风格选择左对齐或居中
- 避免出现过多的对齐方式

## 错误 6：页边距设置不当

### ❌ 错误示例
```
所有文档都用默认页边距（2.54cm）
导致某些文档（如公文）不符合规范
```

### ✅ 改进方案
```
公文：3.7/3.5/2.8/2.6 cm（GB/T 9704-2012）
商务：2.5/2.5/2.5/2.5 cm
学术：2.54/2.54/2.54/2.54 cm
极简：3.0/3.0/3.5/3.5 cm（大量留白）
```

### 建议
- 根据文档类型设置页边距
- 公文必须严格遵循国标
- 留白设计需根据整体风格调整

## 错误 7：忽略打印机兼容性

### ❌ 错误示例
```
使用鲜艳的配色（如红色背景 + 白色文字）
导致打印效果差，甚至无法打印
```

### ✅ 改进方案
```
使用适合打印的配色：
- 正文用黑色/深灰
- 强调用深蓝/深红
- 表格用浅灰底
```

### 建议
- 打印文档用黑白/灰阶友好的配色
- 电子版可用更丰富的配色
- 提供打印版和电子版两种方案

## 错误 8：模板选择不当

### ❌ 错误示例
```
政府公文用了商务报告模板
导致排版不符合国标要求
```

### ✅ 改进方案
```
政府公文 → gov_tongzhi（通知模板）
商务报告 → biz_report（商务报告模板）
学术论文 → acad_paper_cn（中文论文模板）
日常文档 → simple_minimal（极简白模板）
```

### 建议
- 根据文档类型选择合适的模板
- 不了解时使用 simple_minimal（通用）
- 公文必须用 gov_ 系列模板

## 错误 9：忽略版本控制

### ❌ 错误示例
```
每次排版都覆盖原文件
无法回退到之前版本
```

### ✅ 改进方案
```
history/YYYY-MM-DD/
  ├── 原文件_排版前.docx
  ├── 原文件_排版后.docx
  └── diff_report.md
```

### 建议
- 保留排版前文件
- 生成差异对比报告
- 定期清理历史文件
