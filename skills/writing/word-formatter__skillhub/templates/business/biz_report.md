# 商务报告模板

## 适用场景
企业年度报告、项目总结报告、市场分析报告

## 整体风格
- 主色：深蓝 #1F4E79
- 辅色：浅蓝 #E9EFF5
- 强调色：橙色 #C55A11
- 专业感、数据驱动、清晰易读

## 页面设置

```yaml
paper: A4
margin:
  top: 25mm
  bottom: 25mm
  left: 25mm
  right: 25mm
header: 公司 Logo + 报告标题
footer: 页码 + 保密等级
```

## 字体规范

```yaml
封面标题: 微软雅黑 Bold 36pt
封面副标题: 微软雅黑 20pt
一级标题: 微软雅黑 Bold 24pt 深蓝
二级标题: 微软雅黑 Bold 16pt
三级标题: 微软雅黑 Bold 14pt
正文: 微软雅黑 11pt 行距 1.5
图表标题: 微软雅黑 10pt 深蓝
图表标签: 微软雅黑 9pt 灰色
引用: 楷体 10pt 灰色 左缩进 2cm
代码: Consolas 10pt 浅灰底
```

## 段落规范

```yaml
line_spacing: 1.5  # 1.5 倍行距
first_line_indent: 0  # 正文不缩进
alignment: justify  # 两端对齐
space_before: 6pt  # 段前 6pt
space_after: 6pt   # 段后 6pt
```

## 表格样式

```yaml
table_style: Table Grid
border: 单线 0.5pt
header_bg: "#1F4E79"  # 深蓝
header_text: "#FFFFFF"   # 白色
stripe_bg: "#F2F2F2"   # 浅灰
first_col_bold: true
```

## 图表规范

- 图表标题：图表 1-1：市场规模（10pt 深蓝）
- 图表标签：数据来源：×××  （9pt 灰色）
- 图表编号：按章节自动编号
- 图表位置：尽量在提及段落之后

## 注意事项

1. **数据准确性**：所有数据需标注来源
2. **保密等级**：根据公司规定标注保密等级
3. **版本控制**：封面标注版本号和日期
4. **图表质量**：使用高清图表（300dpi 以上）

## 常见错误

❌ **错误 1**：正文缩进  
✅ **正确**：商务报告正文一般不缩进

❌ **错误 2**：使用宋体  
✅ **正确**：使用微软雅黑等无衬线字体

❌ **错误 3**：行距过小  
✅ **正确**：行距 1.5 倍，保证可读性

## 自定义建议

- 调整主色：修改 `primary` 字段为公司品牌色
- 调整字体：修改对应字体字段
- 调整页边距：修改 `margin` 字段
- 添加水印：在 `header` 中添加水印文本
