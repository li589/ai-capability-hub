# 白皮书模板

## 适用场景
行业研究报告、技术白皮书、市场分析报告

## 整体风格
- 主色：深夜蓝 #1A1A2E
- 强调色：玫红 #E94560
- 高级感、专业感、深度感

## 页面设置

```yaml
paper: A4
margin:
  top: 25mm
  bottom: 25mm
  left: 25mm
  right: 25mm
header: 章节名 + Logo
footer: 页码 + 公司名
```

## 字体规范

```yaml
封面标题: 微软雅黑 Light 48pt
封面副标题: 微软雅黑 24pt
一级章节: 微软雅黑 Bold 28pt 深蓝
二级标题: 微软雅黑 Bold 20pt
三级标题: 微软雅黑 Bold 16pt
正文: 思源宋体 11pt 行距 1.8
引用: 思源宋体 Italic 10pt 灰色
代码: Consolas 10pt 浅灰底
```

## 特殊元素

### 章节扉页
- 大留白 + 大字号章节号 + 装饰线

### 引用块
- 左侧粗线 + 浅灰底

### 数据卡片
- 圆角矩形 + 强调色边框

### 章节分隔
- 横线 + 主色装饰

## 自动生成

- [x] 封面页
- [x] 目录（带页码引导线）
- [x] 章节扉页
- [x] 页眉（章节名 + Logo）
- [x] 页脚（页码居中 / 公司信息）

## 配色方案

```yaml
primary: "#1A1A2E"    # 深夜蓝
secondary: "#16213E"    # 深蓝
accent: "#E94560"       # 玫红
text: "#FFFFFF"          # 白色
background: "#0F3460"   # 中蓝
```

## 示例结构

```
封面页
  - 标题（48pt Light）
  - 副标题（24pt）
  - 公司 Logo
  - 日期

目录（自动生成）
  - 第一章 行业概况 ...... 3
  - 第二章 技术趋势 ...... 8

第一章 [章节扉页]
  - 大字号章节号
  - 章节标题
  - 装饰线

1.1 二级标题
  正文内容...
  
  > 引用块：左侧粗线 + 浅灰底
  
  数据卡片：
  ┌─────────────────┐
  │ 市场规模：XXX 亿 │
  └─────────────────┘

1.2 二级标题
  [代码块示例]
```

## 注意事项

1. **封面设计**：建议使用专业设计工具制作高质量封面
2. **图表规范**：所有图表使用统一配色方案
3. **数据来源**：引用数据需标注来源
4. **版权声明**：白皮书末尾添加版权声明

## 自定义建议

- 调整主色：修改 `primary` 字段
- 调整强调色：修改 `accent` 字段
- 调整字体：修改对应的字体字段
- 调整行距：修改正文字体后的行距值

## 模板继承说明

本模板可被子模板继承，例如：
- `tech_white_paper.md` 继承本模板，覆盖技术类专属样式
- `market_white_paper.md` 继承本模板，覆盖市场类专属样式
