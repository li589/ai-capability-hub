# 中文论文模板

## 适用场景
中文期刊论文、学术论文、科技报告

## 整体风格
- 主色：黑色 #000000
- 辅色：浅灰 #F2F2F2
- 强调色：深蓝 #C00000
- 学术严谨、格式规范、引文严谨

## 页面设置

```yaml
paper: A4
margin:
  top: 25mm
  bottom: 25mm
  left: 25mm
  right: 25mm
header: 论文标题（奇数页）+ 作者（偶数页）
footer: 页码居中
```

## 字体规范

```yaml
论文标题: 宋体 16pt 加粗 居中
作者: 宋体 14pt 居中
单位: 宋体 12pt 居中
摘要标题: 黑体 14pt 加粗
摘要正文: 宋体 10pt
关键词: 宋体 10pt
一级标题: 黑体 14pt 加粗  # 一、二、三、
二级标题: 黑体 12pt 加粗  # 1.1 1.2
三级标题: 宋体 11pt  # 1.1.1 1.1.2
正文: 宋体 10pt 行距 1.5
引用: 宋体 10pt 左缩进 2cm
参考文献: 宋体 9pt
脚注: 宋体 8pt
图表标题: 宋体 9pt 加粗
图表标签: 宋体 8pt
```

## 段落规范

```yaml
line_spacing: 1.5  # 1.5 倍行距
first_line_indent: 2 字符  # 正文首行缩进
alignment: justify  # 两端对齐
space_before: 0
space_after: 0
```

## 配色方案

```yaml
text: "#000000"    # 纯黑
heading: "#000000"   # 纯黑
accent: "#C00000"    # 深红（强调）
background: "#FFFFFF"  # 纯白
table_header: "#F2F2F2"  # 表头浅灰
```

## 论文结构

1. **标题**：论文标题（宋体 16pt 加粗 居中）
2. **作者**：作者姓名（宋体 14pt 居中）
3. **单位**：作者单位（宋体 12pt 居中）
4. **摘要**：摘要标题 + 摘要正文 + 关键词
5. **引言**：研究背景、问题、意义
6. **正文**：研究方法、数据分析、讨论
7. **结论**：研究结论、创新点、展望
8. **参考文献**：引文列表
9. **附录**（如需要）

## 摘要格式

```
摘要（黑体 14pt 加粗）

摘要正文摘要正文摘要正文摘要正文
摘要正文摘要正文...（宋体 10pt）

关键词：关键词1；关键词2；关键词3（宋体 10pt）
```

## 参考文献格式

```yaml
# GB/T 7714-2015 参考文献著录规则
期刊: [序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
图书: [序号] 作者. 书名[M]. 出版地: 出版社, 年.
学位论文: [序号] 作者. 题名[D]. 保存地点: 保存单位, 年.
会议论文: [序号] 作者. 题名[C]. 会议名, 地点, 年.
在线资源: [序号] 作者. 题名[EB/OL]. (出版日期)[引用日期]. URL.
```

## 表格样式

```yaml
table_style: 三线表
border: 顶线 1.5pt + 表头底线 0.5pt + 底线 1.5pt
no_vertical_border: true
no_horizontal_border_except_three_lines: true
```

## 图表规范

- 图表编号：图表 1/图 1（按出现顺序）
- 图表标题：图表标题（9pt 加粗 居中）
- 图表标签：数据来源（8pt）
- 图表位置：尽量在提及段落之后

## 注意事项

1. **字体安装**：需安装"黑体"和"楷体"（系统自带）
2. **引文规范**：遵循 GB/T 7714-2015 标准
3. **图表清晰**：图表分辨率 ≥ 300dpi
4. **排版一致**：全文字体、字号、行距保持一致

## 常见错误

❌ **错误 1**：正文不缩进  
✅ **正确**：正文首行缩进 2 字符

❌ **错误 2**：图表无标题  
✅ **正确**：每个图表都有编号和标题

❌ **错误 3**：参考文献格式不统一  
✅ **正确**：严格遵循 GB/T 7714-2015 标准

## 自定义建议

- 调整字体：修改对应字体字段（如 毕业论文用"小四号"）
- 调整行距：修改 `line_spacing` 字段（如 毕业论文用 1.25）
- 调整页边距：修改 `margin` 字段（如 毕业论文用 2.54cm）
- 添加致谢：在结论后参考文献前添加致谢页

## 模板继承说明

本模板可被子模板继承，例如：
- `acad_thesis.md` 继承本模板，调整为毕业论文格式
- `acad_paper_en.md` 继承本模板，调整为英文论文格式
