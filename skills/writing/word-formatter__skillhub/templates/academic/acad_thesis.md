# 毕业论文模板

## 适用场景
本科毕业论文、硕士论文、博士论文

## 整体风格
- 继承自中文论文模板，但更加严谨
- 字号更大（小四号）
- 行距更紧凑（1.25）
- 页边距更大（2.54cm）

## 页面设置

```yaml
paper: A4
margin:
  top: 2.54cm   # 标准页边距
  bottom: 2.54cm
  left: 3.17cm   # 左侧装订线
  right: 2.54cm
header: 论文标题（奇数页）+ 作者（偶数页）
footer: 页码居中
```

## 字体规范

```yaml
论文题目: 黑体 16pt 加粗 居中
作者: 宋体 14pt 居中
导师: 宋体 12pt 居中
专业: 宋体 12pt 居中
摘要标题: 黑体 14pt 加粗  # 小四号
摘要正文: 宋体 12pt  # 小四号
关键词: 宋体 12pt
一级标题: 黑体 14pt 加粗  # 一、二、三、
二级标题: 黑体 12pt 加粗  # 1.1 1.2
三级标题: 宋体 12pt 加粗  # 1.1.1
正文: 宋体 12pt 行距 1.25  # 小四号
引用: 宋体 12pt 左缩进 2cm
参考文献: 宋体 9pt  # 五号
表格标题: 宋体 9pt 居中
表格正文: 宋体 9pt
图表标题: 宋体 9pt 居中
脚注: 宋体 8pt  # 小五号
附录: 黑体 14pt 加粗 居中
```

## 段落规范

```yaml
line_spacing: 1.25  # 1.25 倍行距
first_line_indent: 2 字符  # 正文首行缩进
alignment: justify  # 两端对齐
space_before: 0
space_after: 0
```

## 论文结构

1. **封面**（学校统一格式）
2. **独创性声明**（学校统一格式）
3. **中文摘要**（含关键词）
4. **英文摘要**（含 Keywords）
5. **目录**（自动生成）
6. **第一章 绪论**
   - 1.1 研究背景
   - 1.2 研究意义
   - 1.3 研究现状
   - 1.4 研究内容和方法
7. **第二章至第N章 正文**
8. **结论与展望**
9. **致谢**
10. **参考文献**
11. **附录**（如需要）

## 封面格式

```yaml
题目: 黑体 16pt 加粗 居中
副标题: 黑体 14pt 居中
作者: 宋体 14pt 居中
学号: 宋体 12pt 居中
专业: 宋体 12pt 居中
导师: 宋体 12pt 居中
日期: 宋体 12pt 居中
```

## 摘要格式

```
中文摘要（黑体 14pt 加粗 居中）

摘要正文摘要正文摘要正文...（宋体 12pt，首行缩进 2 字符）

关键词：关键词1；关键词2；关键词3（宋体 12pt）
```

## 目录格式

```yaml
# 目录自动生成
标题: 目录（黑体 16pt 加粗 居中）
一级标题: 黑体 12pt 左对齐
二级标题: 宋体 12pt 缩进 1 格
三级标题: 宋体 12pt 缩进 2 格
页码: 宋体 12pt 右对齐
引导线: 有（点线）
```

## 参考文献格式

遵循 GB/T 7714-2015 参考文献著录规则。

## 表格样式

```yaml
table_style: 三线表
border: 顶线 1.5pt + 表头底线 0.5pt + 底线 1.5pt
no_vertical_border: true
title_above: true  # 标题在表上方
```

## 与学术论文的区别

| 项目 | 毕业论文 | 中文论文 |
|------|----------|----------|
| 页边距 | 3.17/2.54/2.54/2.54 | 2.54/2.54/2.54/2.54 |
| 正文字号 | 小四号（12pt） | 五号（10pt） |
| 行距 | 1.25 倍 | 1.5 倍 |
| 结构 | 更丰富（致谢、声明） | 更简洁 |
| 图表位置 | 图表标题在表上方 | 图表标题在表下方 |

## 注意事项

1. **字体安装**：需安装"黑体"、"宋体"、"楷体"（系统自带）
2. **封面格式**：封面格式由学校提供，本模板仅作参考
3. **字数要求**：本科 1.5-2 万字、硕士 3-5 万字、博士 5-10 万字
4. **查重要求**：确保重复率低于学校要求（通常 20% 以下）

## 常见错误

❌ **错误 1**：正文行距不合适  
✅ **正确**：毕业论文一般用 1.25 倍行距

❌ **错误 2**：图表标题位置错误  
✅ **正确**：表标题在表上方，图标题在图下方

❌ **错误 3**：目录手动生成  
✅ **正确**：使用 Word 自动生成目录功能

❌ **错误 4**：参考文献格式不统一  
✅ **正确**：严格遵循 GB/T 7714-2015 标准

## 自定义建议

- 调整字号：修改 `font_size` 字段（硕士/博士论文可能需要更大字号）
- 调整行距：修改 `line_spacing` 字段
- 添加致谢：在结论后参考文献前添加致谢页
- 添加声明：在封面后添加独创性声明页
