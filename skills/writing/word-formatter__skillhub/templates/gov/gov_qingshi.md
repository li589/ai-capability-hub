# 请示模板（GB/T 9704-2012）

## 适用场景
向上级机关请求指示、批准

## 页面设置

```yaml
paper: A4
margin:
  top: 37mm
  bottom: 35mm
  left: 28mm
  right: 26mm
```

## 格式规范
与通知模板相同，仅结尾用语不同。

## 格式示例

```
××××人民政府
××政发〔2026〕×号
─────────────────────────────────────────

关于×××的请示

市政府：

正文内容首行缩进 2 字符...

妥否，请批示。

×××人民政府
2026年6月8日
```

## 结尾用语规范

| 用语 | 使用场景 |
|------|----------|
| 妥否，请批示。 | 常规请示 |
| 以上请示妥否，请批示。 | 较正式 |
| 特此请示，请批复。 | 强调事项 |
| 如无不妥，请批转×××执行。 | 需要批转 |

## 与"报告"的区别

| 项目 | 报告 | 请示 |
|------|------|------|
| 行文目的 | 汇报工作、反映情况 | 请求指示、批准 |
| 结尾用语 | 特此报告 | 妥否，请批示 |
| 上级处理 | 可不批复 | 必须批复 |
| 事前/事后 | 可事前、可事后 | 必须事前 |

## 常见错误

❌ **错误 1**：请示结尾写"特此报告"  
✅ **正确**：必须用"妥否，请批示"

❌ **错误 2**：在报告中夹带请示事项  
✅ **正确**：请示事项必须单独行文

❌ **错误 3**：多头主送  
✅ **正确**：请示只能主送一个机关

## 注意事项

1. **一文一事**：一份请示只写一个事项
2. **不得越级**：一般不得越级请示
3. **不得抄送下级**：请示不得同时抄送下级机关
4. **附注联系人**：如有必要，可在附注注明联系人及电话
