# 通知模板（GB/T 9704-2012）

## 适用场景
党政机关下发通知、转发文件、人事任免

## 页面设置

```yaml
paper: A4
margin:
  top: 37mm    # 上 3.7cm
  bottom: 35mm  # 下 3.5cm
  left: 28mm    # 左 2.8cm（订口）
  right: 26mm   # 右 2.6cm
header_distance: 0
footer_distance: 0
```

## 字体规范

```yaml
红头_发文机关: 方正小标宋简体 22pt 红色
发文字号: 仿宋_GB2312 16pt
武文线: 红色 0.35mm 156mm
标题: 方正小标宋简体 22pt 黑色 居中
主送机关: 仿宋_GB2312 16pt
正文: 仿宋_GB2312 16pt
一级标题: 黑体 16pt  # 一、二、三、
二级标题: 楷体_GB2312 16pt  # （一）（二）
三级标题: 仿宋_GB2312 16pt 加粗  # 1. 2. 3.
落款: 仿宋_GB2312 16pt
版记: 仿宋_GB2312 14pt
页码: 宋体 14pt  # — 1 —
```

## 段落规范

```yaml
line_spacing: 28pt  # 固定值
first_line_indent: 2 字符
alignment: justify  # 两端对齐
space_before: 0
space_after: 0
```

```

××政发〔2026〕8 号

（红色武文线，0.35mm，156mm 宽）
```

## 页码格式

- 奇数页：右空一字（— 1 —）
- 偶数页：左空一字（— 2 —）
- 空白页不标页码

## 附件格式

```

      2. ××××实施方案
```

（附件另起页）

```
———————————————————
```

```
×××办公室               2026年6月8日印发
```

## 注意事项

1. **字体安装**：确保系统已安装"方正小标宋简体"和"仿宋_GB2312"
2. **红头制作**：发文机关标志推荐使用 Photoshop/Illustrator 制作
3. **印章**：成文日期处需加盖红色印章（骑年盖月）
4. **密级**：如文档涉密，需在版心左上角标注份号、密级和保密期限

## 常见错误

❌ **错误 1**：页边距不正确  
✅ **正确**：严格按 3.7/3.5/2.8/2.6 cm 设置

❌ **错误 2**：标题字体错误  
✅ **正确**：必须用"方正小标宋简体"，不能用"宋体"或"小标宋"代替

❌ **错误 3**：页码格式错误  
✅ **正确**：必须用"— 1 —"格式，不能用"第 1 页"或"1"

## 自动识别规则

- **标题**：包含"关于"和"通知"关键词
- **主送机关**：以"："结尾的段落
- **一级标题**：以"一、"、"二、"、"三、"开头
- **二级标题**：以"（一）"、"（二）"、"(三）"开头
- **附件**：以"附件："开头的段落
- **落款**：文档末尾的机关名 + 日期
