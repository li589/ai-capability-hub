# 批复模板（GB/T 9704-2012）

## 适用场景
答复下级机关请示事项

## 页面设置

```yaml
paper: A4
margin:
  top: 37mm
  bottom: 35mm
  left: 28mm
  right: 26mm
```

## 格式规范
与通知模板相同。

## 格式示例

```
××××人民政府
××政发〔2026〕×号
─────────────────────────────────────

关于×××的批复

××县人民政府：

你县《关于×××的请示》（×政发〔2026〕×号）收悉。经研究，现批复如下：

一、同意×××
二、×××
三、×××

此复。

××××人民政府
2026年6月8日
```

## 批复结构

1. **引语**：引述下级请示标题和文号
2. **批复意见**：明确答复意见
3. **执行要求**：提出执行要求（可选）
4. **结尾**：此复。/特此批复。

## 常见错误

❌ **错误 1**：批复意见不明确  
✅ **正确**：必须明确写明"同意"、"不同意"或具体意见

❌ **错误 2**：漏引下级请示  
✅ **正确**：必须引述下级请示标题和文号

❌ **错误 3**：多头批复  
✅ **正确**：批复只主送请示机关

## 与"通知"的区别

| 项目 | 批复 | 通知 |
|------|------|------|
| 行文关系 | 下行文 | 下行文 |
| 行文目的 | 答复请示 | 部署工作、告知事项 |
| 被动/主动 | 被动（先有请示） | 主动 |
| 主送机关 | 请示机关 | 多个机关 |
