# 报告模板（GB/T 9704-2012）

## 适用场景
工作汇报、情况反映、答复上级询问

## 页面设置

```yaml
paper: A4
margin:
  top: 37mm
  bottom: 35mm
  left: 28mm
  right: 26mm
```

## 字体规范

与通知模板相同，仅内容上略有差异：
- 报告一般用于向上级汇报工作、反映情况、答复上级询问
- 结尾常用"特此报告"、"以上报告，请审阅"等

## 格式示例

```
××××人民政府
××政发〔2026〕×号
─────────────────────────────────────────

关于×××的报告

市政府：

正文内容首行缩进 2 字符...

特此报告。

×××人民政府
2026年6月8日
```

## 与"请示"的区别

| 项目 | 报告 | 请示 |
|------|------|------|
| 行文目的 | 汇报工作、反映情况 | 请求指示、批准 |
| 结尾用语 | 特此报告 | 妥否，请批示 |
| 上级处理 | 可不批复 | 必须批复 |
| 事前/事后 | 可事前、可事后 | 必须事前 |

## 常见错误

❌ **错误**：报告结尾写"妥否，请批示"  
✅ **正确**：报告结尾用"特此报告"、"以上报告，请审阅"

❌ **错误**：报告中夹带请示事项  
✅ **正确**：报告与请示分开，确需请示的事项另外行文
