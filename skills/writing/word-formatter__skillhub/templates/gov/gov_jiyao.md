# 会议纪要模板（GB/T 9704-2012）

## 适用场景
记载会议主要情况和议定事项

## 页面设置

```yaml
paper: A4
margin:
  top: 37mm
  bottom: 35mm
  left: 28mm
  right: 26mm
```

## 格式规范
与通知模板相似，但有以下特点：
- 标题一般为"会议纪要"或"×××会议纪要"
- 不需要主送机关
- 正文直接记述会议情况和议定事项

## 格式示例

```
××××会议纪要
（××政纪〔2026〕×号）

时间：2026年6月8日
地点：××会议室
主持人：×××
出席：×××、×××、×××
列席：×××、×××

一、会议情况

会议听取了×××关于×××的情况汇报...

二、议定事项

（一）×××

（二）×××

三、工作要求

（一）各相关部门要×××

（二）×××

特此纪要。

×××办公室
2026年6月8日
```

## 纪要结构

1. **标题**：会议纪要或×××会议纪要
2. **文号**：××政纪〔2026〕×号（如有）
3. **会议基本信息**：时间、地点、主持人、出席、列席
4. **正文**：会议情况、议定事项、工作要求
5. **结尾**：特此纪要。
6. **落款**：办公××办公室 + 日期

## 与"通知"的区别

| 项目 | 会议纪要 | 通知 |
|------|----------|------|
| 行文目的 | 记载会议情况 | 部署工作 |
| 主送机关 | 一般不需要 | 必须有 |
| 行文方向 | 下行/平行 | 下行 |
| 约束力 | 较弱 | 较强 |

## 常见错误

❌ **错误 1**：纪要写成会议记录  
✅ **正确**：纪要只记议定事项，不记讨论过程

❌ **错误 2**：缺少议定事项  
✅ **正确**：议定事项是纪要的核心，必须明确具体

❌ **错误 3**：纪要没有约束力  
✅ **正确**：纪要具有行政约束力，相关部门必须执行

## 注意事项

1. **实事求是**：如实反映会议情况
2. **突出重点**：重点记议定事项
3. **文字简洁**：避免冗长
4. **及时印发**：一般应在会议结束后3个工作日内印发
