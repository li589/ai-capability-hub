# 21 — 资料库使用指南（5.3.11 新增）

> **用途**：讲清 WorkBuddy 5.3.11 原生「资料库」——内容管理、多人多Agent协作、轻量发布的一体化中枢。
> **适配版本**：客户端 5.3.11 及以上。

---

## ⚠️ 先划界：两个「资料库」别搞混

WorkBuddy 里有两个都叫「资料库」的入口，内涵完全不同：

| 名称 | 是什么 | 在哪查 |
|------|--------|--------|
| **资料库（原生，本篇）** | 5.3.11 新增的内容管理中枢，含「我的文档」+「团队空间」，沉淀你和 Agent 的产物 | **本篇（21）** |
| **资料库-IMA 知识库** | 接入第三方 ima 知识库的入口（连接/引用/存回/解绑） | `16-ima-knowledge-base-guide.md` |

> 一句话：**原生资料库是 WorkBuddy 自己的"云文档+协作空间"；IMA 是外挂的第三方知识库。** 本篇只讲前者。

---

## 一、资料库是什么

WorkBuddy 原生的内容管理 + 多人多Agent协作 + 轻量发布中枢。核心定位：**让每次任务产物都沉淀、管理、流转、复用，形成闭环**——从"超级个体"到"超级团队"。

三大能力域：

| 能力域 | 解决的问题 |
|--------|-----------|
| **01 内容管理** | 团队里人和 Agent 的产物一起管，共享上下文；零散资料进同一棵目录树 |
| **02 多人多Agent协作** | 多人多 Agent 在同一份资料上协作，权限可控，修订可审阅 |
| **03 轻量发布** | 本地 HTML 一键发成在线链接，HTML+CSV 搭轻应用 |

---

## 二、内容管理：我的文档 vs 团队空间

资料库左栏分两块，归属清晰：

| 分区 | 用途 | 谁能看 |
|------|------|--------|
| **我的文档**（个人空间） | Agent 生成的文档、个人创建/收藏/整理的资料，默认落脚点 | 仅自己 |
| **团队空间**（多人协作） | 项目文档、数据、过程资料，成员共享 | 团队成员（按权限） |

**支持的资料类型**（都能进同一棵目录树）：
- **AI 三件套**：MD · CSV · HTML
- **办公/本地文件**：PDF · Word · PPT · Excel
- **多媒体**：PNG · JPG · MP3 · MOV

**任务中直接用**：在资料库目录选整个空间或单篇文档 → 点「添加到任务」→ Agent 直接读取/修改（Agent 与人同权限）→ 成果可再存回资料库。资料不是一次性上传，而是进入持续工作的闭环。

---

## 三、三种载体，一套数据（核心机制）

这是资料库区别于普通网盘的核心：**MD、CSV、HTML 不是孤立文件，而是同一份数据的三种形态**。

| 载体 | 角色 | 干什么 |
|------|------|--------|
| **MD · 文档** | 叙事 / 内容 | 方案、周报、说明——承载文字与结构，是内容主体 |
| **CSV · 数据表** | 数据源（SSOT） | 清单、排期、库存、业绩——唯一数据源，改一行处处跟着变 |
| **HTML · 页面** | 呈现 / 表达 | 读 CSV 渲染成图表与列表，把静态网页升级成「数据驱动页面」 |

> **改一处、处处生效**：CSV 由 WorkBuddy 在线表格承载（多人可同时维护），HTML 通过表格 ID 实时读取渲染。换内容、改数据、重做视觉各自处理，不必推倒重来。

> **CSV 还能存文件**：除了文本数据，CSV 也支持存储文件——轻应用的附件/素材也能进数据表统一管理，形态更完整（5.3.11 起）。

**典型场景**：动态看板（改 CSV 一行，看板立刻刷新）、数据驱动页面、多人多 Agent 协同。

---

## 四、多人多Agent协作：人机共同书写文档

资料库里，人和 AI 在同一份文档里自然协作——**AI 是协作者，不是代笔**。改哪里你说了算，改完要不要生效也你说了算。在线文档（MD）和 HTML 页面通用。

**三大能力**：

| 能力 | 说明 |
|------|------|
| **划词修订** | 选中一段文字 → 输入修改诉求 → AI 只在选区内改，不碰其他内容（选区即上下文，省去重复描述） |
| **修订卡片** | AI 每处改动生成独立卡片悬停在原文旁，原文不动；点开「查看更改」逐字对比，接受/拒绝/批量处理由你定 |
| **按评论修订** | 每条评论是讨论线程；一键「按评论修订」，AI 读懂评论+正文自动产修订建议，改完通知评论者复核 |

**四步闭环**：提诉求（划词/评论）→ AI 精准修订 → 卡片对比 → 你来定夺。

### ⚠️ 划界：资料库修订 vs 人机双写

两者都能"划词让 AI 改文档"，但入口和底层不同：

| 对比项 | 资料库修订（本篇） | 人机双写 |
|--------|-------------------|---------|
| 入口 | 资料库内的 MD / HTML | 右侧边栏文件预览区 |
| 底层 | 资料库原生协作 | 腾讯文档编辑支持 |
| 适用 | 资料库里的文档和网页 | Word/Excel/PPT/MD/腾讯文档 |

> 详见 `12-faq.md` 人机双写 Q&A。两者并存，按需选用。

## 五、团队空间：4 步上手

团队空间是资料库里供**多人多 Agent 共享、协作与长期沉淀**的地方。

```
第1步 · 找到团队空间
  左栏「团队空间」区（与「我的」分开），点标题旁「+」新建空间
  空间下可像文件夹一样嵌套整理文档树

第2步 · 把资料放进来
  选中空间点「+」：新建文档/表格、上传文件、剪藏网页，
  或对 Agent 说"生成到某团队空间"，产物即刻落进来

第3步 · 邀请成员、设权限
  点「复制邀请链接」发给伙伴；按角色分四档权限：
  查看 / 编辑 / 管理 / 无权限
  「互联网公开可见」默认关闭，确需对外再开启

第4步 · 协作、沉淀与复用
  全员共享同一上下文，历史产物随时找回，
  成为下一次 Agent 任务的共同背景
```

> **权限即 Agent 权限**：权限不只决定谁能看，也决定 Agent 能用什么。

### ⚠️ 划界：团队空间 vs Teams 协作

| 对比项 | 团队空间（资料库） | Teams 协作 |
|--------|-------------------|-----------|
| 定位 | 资料/文档的共享与沉淀 | 项目/看板/任务流转 |
| 查哪 | 本篇 | `13-teams-collaboration.md` |

## 六、轻量发布：本地 HTML 发成在线链接

**痛点**：本地做好的 HTML 发给同事打不开——发出去的是本地路径（`file:///…`）或 `localhost`，只指向你自己的电脑。轻量发布把本地 HTML 上传成在线链接。

**操作（发布为网站）**：
1. 页面右上角点 **分享** → 切到 **发布** 页签 → 打开 **发布为网站** 开关
2. 页面即发布为在线链接，任何拿到链接的人都能打开
3. 开关下方显示链接，点右侧按钮复制；底部可分享到微信或生成二维码
4. 链接用 `workbuddy.link` 域名，形如 `https://workbuddy.link/p/{页面ID}`

> **「发布」和「邀请协作」是两回事**：发布为网站 = 只读访问（给别人看）；邀请协作 = 参与编辑（让别人进来改）。弹窗两个页签别搞混。发布动作同时会把内容存入资料库，随时找回继续改。

**发布前注意**：开关默认关闭，开启后任何拿到链接的人都可访问，不再需要时随时关掉；发布前确认页面及引用数据适合对外公开；页面内容由发布者负责。

**进阶：HTML + CSV 搭轻应用**——普通 HTML 内容是写死的；资料库的 HTML 可引入 CSV 作数据源，数据在线存储、双向同步，改一次页面自动更新。HTML 做经营工作台/操作页面（面向人），CSV 做业务数据底座（商品/订单/库存，面向数据），不用搭数据库就能跑。典型：项目管理看板、电商管理系统、生活工作台。

**两类场景怎么选**：把资料**变好看**（数据不常变）→ 一个 HTML 就够（汇报/复盘/作品集）；把资料**变能用**（需持续记录更新）→ 用 HTML+CSV（客户跟进/任务看板/记账）。

**5.3.11 新增**：资料库支持 **deeplink 直接打开指定文档**。

## 七、存储与积分（费用相关，必看）

**存储按类型分开**：
- 上传的办公/本地文件（PDF/Word/PPT/Excel、图片、音视频）→ 由**腾讯网盘**提供存储
- 在 WorkBuddy 中创建的 MD/CSV/HTML → 存 **WorkBuddy 云端**

容量：资料库可看已用/总容量；上传前校验剩余空间，不足会提示，可清理或扩容后重试。

**积分消耗**：
- **不消耗**：存储、目录组织、检索、手动编辑
- **消耗**：对内容做加工/分析/生成新产物，及 AI 修订、按评论修订、HTML 划词修改

**多人协作同一份文档，积分按"实际发起 AI 操作的人"算**——谁点了发送 AI 指令就扣谁的。以「按评论修订」为例：评论只是 AI 的参考上下文，**积分由点「按评论修订」并发送的人承担，不扣写评论的人**；接受/拒绝修订建议本身不消耗积分。

## 八、快速上手（一分钟三步）

```
Step 1 · 把成果存进资料库
  打开历史任务 → 一句话把成果存进资料库 → 在「我的文档」查看

Step 2 · 让 Agent 接着做
  指定一份资料 → Agent 读取 → 继续补充、压缩或重写

Step 3 · 创建团队空间
  新建命名 → 邀请协作者设权限 → 移入要共用的文档/网页
```

## 九、注意事项

1. **版本要求**：资料库为 5.3.11 新增，旧版本客户端无此入口
2. **互联网公开默认关闭**：团队空间对外公开需手动开启，公开范围自己掌握
3. **发布为网站默认关闭**：开启后任何拿到链接的人都能访问，不再需要时及时关闭
4. **Agent 集成细节**：Agent 在任务中读/写资料库的具体交互以客户端实际为准（官方进阶文档需登录查看）
5. **与 IMA 的关系**：原生资料库和 IMA 知识库相互独立，可同时在任务中引用；产物存回时按需选择落到哪边
