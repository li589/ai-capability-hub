## 🔌 IMA 知识库集成（知识→调用→回传闭环）

### 案例19：基于历史资料写方案 🆕

**用户原话**：「写一份新季度的市场推广方案，参考之前的历史方案和 Q1 复盘」

**对应卡片**：卡片4（提示词优化）+ IMA 知识库集成

**核心闭环**：知识沉淀(IMA) → 跨产品调用(WorkBuddy) → AI执行 → 产物回传(IMA)

**处理流程**：

```
Step 1: 前置准备（一次性）
  将历史方案、数据报表、复盘文档存入 IMA 知识库
  → 个人资料 / 共享文档 / 订阅知识库均可

Step 2: 调用 IMA 知识库
  WorkBuddy 中点击「+」→「ima知识库」→ 选择对应知识库
  → 输入指令：
  「参考『XX知识库』里的历史方案和Q1复盘，写一份新季度推广方案：
   ## 回顾（基于历史数据）
   ## 策略调整（基于Q1复盘发现）
   ## 执行计划（时间线+资源分配+预期指标）
   每部分引用知识库中的具体数据」

Step 3: 产物回传
  生成结果 → 点击「上传到云端」→ 选择「ima知识库」
  → 方案自动归档，下次可直接复用
```

**预期输出**：
- 基于真实历史的方案（非通用模板）
- 每项建议可追溯到知识库中的具体数据源
- 生成结果已归档回 IMA，完成知识循环

### 案例20：碎片信息整理成知识资产 🆕

**用户原话**：「帮我整理知识库里关于『AI应用』的文章和会议记录，结合近期趋势做个分析报告」

**对应卡片**：卡片4（提示词优化）+ IMA 知识库集成

**处理流程**：

```
Step 1: 碎片收集
  把所有零散资料存入 IMA：
  - 会议记录 → 存入 IMA
  - 零散文章/链接 → 存入 IMA
  - 临时笔记 → 存入 IMA

Step 2: 整理与分析
  WorkBuddy 「+」→「ima知识库」→ 选择对应知识库
  → 输入指令：
  「整理知识库里关于『AI应用』的内容：
   ## 信息归类（按主题分：工具类/趋势类/案例类）
   ## 趋势提炼（按时间线，标注关键节点）
   ## 分析报告（结合近期AI热点，输出500字分析）
   标注每条的来源和日期」

Step 3: 存回 IMA
  报告生成 → 「上传到云端」→「ima知识库」
  → 碎片信息变成了可复用的知识资产
```

**预期输出**：
- 碎片信息按主题归类的整理报告
- 趋势分析 + 热点结合
- 存入 IMA 后，下次相关任务可直接调用

---

**IMA 知识库核心价值**：
> 你的知识库每被调用一次，就完成了一次自我迭代。知识在使用中生长，而非沉睡在文件夹里。

## 📄 腾讯文档集成（资料库 + 产物上传）

### 案例21：一键添加腾讯文档到工作空间 🆕

**用户原话**：「把这篇腾讯文档加到工作空间，帮我基于内容做个分析」

**平台版本**：v4.21.0+

**处理流程**：

```
Step 1: 添加文档到资料库
  WorkBuddy 中点击「+」→「腾讯文档」→ 选择文档
  → 支持在线文档、表格、幻灯片等格式
  → 一次可添加多篇，作为工作空间的知识源

Step 2: 基于文档内容提问
  「基于刚才添加的腾讯文档，帮我：
   ## 提取核心要点（3-5条）
   ## 按主题分类整理
   ## 输出一份结构化总结」
  → WorkBuddy 自动读取文档内容，无需手动复制粘贴

Step 3: 产物回传
  分析结果 → 「上传到云端」→「腾讯文档」→ 自动保存
  → 下次打开腾讯文档即可看到分析产物
```

**预期输出**：
- 文档内容自动提取，无需手动搬运
- 分析结果结构化输出
- 产物归档回腾讯文档

### 案例22：产物分享到微信（扫码即看） 🆕

**用户原话**：「刚生成的这份报告，帮我分享给同事看一下」

**平台版本**：v4.22.14+ / v4.24.2

**处理流程**：

```
Step 1: 生成报告/产物
  通过 WorkBuddy 完成分析、PPT、图表等任一任务
  → 确认产物满意

Step 2: 分享产物
  方式一：微信分享
    产物 → 点击「分享」→「微信」→ 生成二维码
    → 同事扫码即可在线查看（无需安装 WorkBuddy）

  方式二：HTML 分享
    产物 → 「导出为 HTML」→ 生成可分享链接
    → 浏览器直接打开，样式完整保留

Step 3: OAuth 应用管理（进阶）
  如需长期协作 → 配置 OAuth 应用
  → 头像 → 设置 → OAuth 应用管理
  → 授权后团队成员可访问指定内容
```

**预期输出**：
- 二维码分享，扫码即看
- HTML 链接可直接转发
- 适合跨团队协作、客户交付、领导审批

**适用场景**：周报分享、方案评审、客户交付物、团队协作

## 🔗 端到端深度案例（跨工具闭环）

> 与单点案例不同，这 3 条案例演示「多工具串联 + 产物交付」的完整闭环，适合已跑通基础功能的用户进阶参考。更系统的端到端案例库见蓝皮书：https://workbuddy.homes/cases/

### 深度案例A：全自动日报流水线

**💬 对话示例**
- 用户："帮我搞个每天自动发日报的东西，下班前把今天干的活汇总发飞书群"
- Skill 思路：识别为「自动化 + 连接器 + 模板」闭环，先确认数据源与推送目标
- 最终回答要点：
  1. 建 recurring 自动化，18:30 触发
  2. prompt 写死日报格式（指标表 + 异常标注）
  3. 首轮手动跑通后保持 ACTIVE，观察 3 天

**场景目标**：每天下班前自动汇总当日工作数据 → 生成结构化日报 → 推送到飞书群，全程零手动。

**涉及工具**：自动化定时任务 + 连接器（数据源）+ 提示词模板

**关键步骤**：
1. 建自动化任务：`scheduleType=recurring`，`rrule=FREQ=DAILY;BYHOUR=18;BYMINUTE=30`，`status=ACTIVE`
2. prompt 写死输出格式（核心指标表格 + 异常标注 + 明日重点），并注明"无对话历史，所有数据需自行获取"
3. 首次创建后手动触发一轮，检查数据获取是否成功、格式是否符合预期
4. 格式满意后保持 ACTIVE，连续观察 3 天确认稳定

**验收标准**：连续 3 天 18:30 准时触发；日报含数据表格且异常项有标注；推送成功无遗漏。

### 深度案例B：公众号文章从选题到发布

**💬 对话示例**
- 用户："我想每周发一篇行业公众号，从找选题到排版发布都能在 WorkBuddy 里搞定吗？"
- Skill 思路：识别为「文案专家 + 绘图 + 发布连接器 + IMA 复用」流水线，强调人工润色节点
- 最终回答要点：
  1. 热点监控自动化收集选题
  2. 文案专家出结构化初稿（给调性/字数/格式）
  3. AI 绘图生成封面，发布后回传 IMA 归档

**场景目标**：热点选题 → AI 初稿 → 人工润色 → 封面图生成 → 发布，全流程在 WorkBuddy 内完成。

**涉及工具**：文案专家 + AI 绘图 + 公众号发布连接器 + IMA 知识库（素材复用）

**关键步骤**：
1. 用每日热点监控自动化收集选题（参考深度案例A的模式）
2. 对文案专家下达结构化指令：选题 + 目标读者 + 字数 + 调性要求 + 排版格式
3. 初稿出来后人工润色关键段落（标题、开头、结尾），AI 味重的句子重写
4. 用 AI 绘图生成封面图（配色/比例/文案/字体要求写死）
5. 通过公众号发布连接器一键群发；发布后的文章回传 IMA 知识库归档，供下次复用

**验收标准**：从选题到发布全程不离开 WorkBuddy；历史文章可在 IMA 中检索复用；封面图风格与账号调性一致。

### 深度案例C：团队知识库沉淀与复用闭环

**💬 对话示例**
- 用户："我们团队每次做新项目都从头搞，以前写的方案全散在各处，能不能让 WorkBuddy 帮我们攒起来复用？"
- Skill 思路：识别为「IMA 知识库 + 腾讯文档 + 定期归档」沉淀闭环，重点在归档习惯与检索动作
- 最终回答要点：
  1. 存量资产统一导入 IMA 并写 100 字摘要
  2. 项目结束自动提醒归档
  3. 新项目先 `@ima` 检索历史资产再动手

**场景目标**：把分散在聊天记录、会议、文档中的团队知识沉淀到 IMA，新项目直接调用历史资产，避免重复造轮子。

**涉及工具**：IMA 知识库 + 腾讯文档 + 自动化定期归档

**关键步骤**：
1. 盘点存量资产：历史方案、复盘文档、会议纪要有多少存多少，统一导入 IMA 知识库
2. 建立归档习惯：每次项目结束后，产物「上传到云端」→「ima知识库」，并写一段 100 字摘要
3. 建一个周期性自动化（如每周五），提醒本周新增产物未归档的成员
4. 新项目启动时，先 `@ima:关键词` 检索历史资产，再决定哪些复用、哪些新建

**验收标准**：知识库每周有新增条目；新项目方案中能引用到至少 1 条历史资产；团队成员会主动 `@ima` 检索而非重新提问。

### 深度案例D：HTML+CSV 搭轻应用（数据看板）🆕 5.3.11

**💬 对话示例**
- 用户："我想把渠道销售数据做成一个能实时刷新的看板，不想搭数据库，能在 WorkBuddy 里搞定吗？"
- Skill 思路：识别为「资料库三种载体」场景——CSV 做数据源、HTML 做呈现页，改数据页面自动刷新
- 最终回答要点：
  1. 用 CSV 在线表格维护渠道数据（唯一数据源）
  2. 让 Agent 生成 HTML 看板，通过表格 ID 读取 CSV 渲染图表
  3. 改 CSV 一行，看板立刻刷新；可一键发成在线链接分享

**场景目标**：不搭数据库，用「CSV 管数据 + HTML 做页面」搭一个数据驱动的轻应用（看板/库存/经营工作台）。

**涉及工具**：资料库（三种载体）+ CSV 在线表格 + HTML 页面 + 轻量发布

**关键步骤**：
1. 在资料库建一张 CSV（如 channels.csv），维护清单/业绩/库存数据，多人可同时编辑
2. 对 Agent 说"基于这张 CSV 生成一个数据看板 HTML"，页面通过表格 ID 实时读取渲染
3. 业务数据变化时只改 CSV，HTML 看板自动刷新，无需重新导出
4. 做好后用轻量发布「以链接分享」生成在线链接，发给团队直接打开

**验收标准**：改 CSV 任意数字，HTML 看板立即重算刷新；页面可发布成在线链接；数据与视觉分离，改内容/改数据/重做视觉互不影响。

> 📚 机制详解见 `21-ziliaoku-guide.md` 第三节（三种载体一套数据）、第六节（轻量发布）。
