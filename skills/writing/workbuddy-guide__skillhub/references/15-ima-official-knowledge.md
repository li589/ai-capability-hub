# 15 — IMA 官方知识库（可选兜底）

> **版本**：v1.0 (2026-06-23)
> **用途**：在 skill 内文档和官方文档都无法覆盖时，通过 IMA 官方知识库兜底检索
> **前置条件**：IMA 连接器处于 connected 状态

---

## 知识库定位

- **知识库名称**：WorkBuddy 官方知识库
- **知识库 ID**：`7472132158135857`
- **内容范围**：官方教程、常见问题、功能说明、入门指南、使用教程、版本特定问题
- **内容形式**：公众号文章、网页教程、PDF/Word/Excel 文档等

## 适用场景

| 场景 | 说明 |
|------|------|
| skill 未覆盖的最新功能 | 版本更新快于 skill 迭代时 |
| 版本特定问题 | 某版本独有的行为或配置 |
| 官方教程细节 | 需要引用官方原文说明 |
| 入门指南 | 用户需要官方视角的新手引导 |

## 不适用的场景

- 未连接 IMA 时 → 自动跳过，不阻断流程
- skill 已有明确答案 → 不额外检索，节省资源
- 需要实时最新内容 → 优先用 WebFetch 查官方 Changelog

## 使用方式

### 调用方法

```
mcp__ima-mcp__search_knowledge
├── knowledge_base_id: "7472132158135857"
├── query: "用户原始问题关键词"
└── filters: 可选（按媒体类型、标签、解析状态过滤）
```

### 检索策略

```
用户问题
    │
    ▼
第1层（速查卡）+ 第2层（深度文档）有答案？
    │ Yes → 直接回复
    │ No
    ▼
第3层 WebFetch 有明确答案？
    │ Yes → 整理回复，注明来源为官方文档
    │ No
    ▼
IMA 连接器 connected？
    │ No → 进入第4层兜底建议
    │ Yes
    ▼
调用 IMA 搜索官方知识库
    │
    ▼
有答案 → 整理回复，注明来源为「WorkBuddy 官方知识库」
无答案 → 进入第4层兜底建议
```

## 内容示例

根据搜索结果，知识库包含但不限于：

- **WorkBuddy 使用教程**（公众号文章）：从表达目标到安全边界，建立 AI 工作方式
- **一键直达 WorkBuddy 官网教程**：快速入门、任务管理、助理专家技能、连接器、腾讯文档、IMA 知识库等
- **入门指南系列**：安装、功能说明、创建任务、任务对话、结果查看等

## 注意事项

1. **可选层**：IMA 检索是第3.5层，不是必须步骤
2. **连接器状态检查**：执行前确认 IMA 连接器是否 connected
3. **资源消耗**：仅在前面层级无答案时触发，避免过度检索
4. **引用规范**：回复中注明来源为「WorkBuddy 官方知识库」，提升可信度

## 与其他检索层的关系

```
第1层：速查卡（7张卡片）
    ↓ 无匹配
第2层：深度文档（references/ 目录）
    ↓ 无匹配
第3层：官方文档（WebFetch）
    ↓ 仍无明确答案
第3.5层：IMA 官方知识库（可选，需 connected）
    ↓ 无答案或未连接
第4层：兜底建议（指引用户查阅其他渠道）
```
