# 17 — 腾讯会议 Skill 实践指南

> **用途**：在 WorkBuddy 中安装腾讯会议 Skill，通过自然语言完成会议预约、修改、取消、查询，以及录制、转写和 AI 纪要整理
> **适用场景**：需要频繁开会、又不想在编辑器、会议软件与笔记工具之间反复切换

---

## 一、安装腾讯会议 Skill

### 1. 获取个人 Token

1. 打开腾讯会议 Skill 官方页面：`https://meeting.tencent.com/ai-skill.html`
2. 使用腾讯会议账号完成登录
3. 在授权页面获取并复制个人专属 Token

> **注意**：Token 属个人凭证，妥善保管。如 Token 失效，重新访问授权页面获取新凭证。

### 2. 在 WorkBuddy 中安装

1. 复制授权页面中第 1 步的安装指令
2. 回到 WorkBuddy 对话窗口，直接粘贴安装指令
3. WorkBuddy 自动创建任务，完成下载、解析和配置
4. 安装完成后，在已安装技能列表中可见腾讯会议 Skill

---

## 二、会议管理

安装完成后，用自然语言直接管理会议，无需记忆命令格式：

| 操作 | 示例指令 |
|------|---------|
| 创建普通会议 | 帮我创建一个腾讯会议，主题是技术方案讨论，今天下午 3 点到 4 点 |
| 创建周期会议 | 安排一个周期性会议，每周一上午 10 点，主题是团队周会 |
| 修改会议 | 把会议 450-743-140 的时间改到下午 4 点 |
| 取消会议 | 取消会议号 450-743-140 的会议 |
| 查询日程 | 查一下我今天有哪些会议 |

## 四、录制、转写与智能纪要

会议结束后，继续在 WorkBuddy 中查询录制和纪要：

| 操作 | 示例指令 |
|------|---------|
| 查询录制 | 帮我查一下最近的会议录制 |
| 获取下载链接 | 获取上次会议的录制下载链接 |
| 查看转写 | 帮我看看上次会议的转写内容 |
| 搜索转写 | 在会议转写里搜索"技术方案" |
| 获取智能纪要 | 帮我获取这个会议的智能纪要 |

> **典型流程**：会后直接让 WorkBuddy 查询转写 → 获取智能纪要 → 整理为结构化纪要文档 → 存回 IMA 知识库。

---

## 五、使用建议

1. **先说清主题与时间**：创建会议时一次说明主题、时间范围与是否重复
2. **修改前先确认会议编号**：涉及改期、取消时，明确提供会议号或会议名称
3. **会后直接接上纪要整理**：会议结束后继续让 WorkBuddy 查询录制、转写并总结重点
4. **时间可直接自然表达**：如"今天下午 3 点到 4 点""明早 9 点半"，无需手动换算格式
5. **密码建议提前说明**：若会议需要自定义密码，创建时一并提出（常见规则为 4-6 位数字）
6. **周期规则要说清楚**：每天 / 工作日 / 每周 / 每两周 / 每月
7. **重要操作先核对信息**：涉及修改与取消时，先查看当前会议信息再执行
8. **Token 时效注意**：如安装或调用失败，优先检查 Token 是否已过期
