# 14 — 场景模式与工作界面（Scene Modes）

> **版本**：v1.0 (2026-06-12)
> **用途**：理解 WorkBuddy 的三大场景模式和工作界面布局，快速上手
> **来源**：WorkBuddy 官方教程 + 公众号实践文章

---

## 概述

WorkBuddy 不是单一的对话窗口，而是按使用场景分了三种模式，每种模式对应不同的快捷方式和工具集，让你不用每次从头配置。

---

## 三大场景模式

| 模式 | 定位 | 快捷方式内容 |
|------|------|-------------|
| **代码开发** | 编程相关任务 | 日常开发、网站开发、Agent应用、Skill开发 |
| **日常办公** | 文档和数据处理 | 文档处理、数据分析及可视化、深度研究、幻灯片 |
| **设计创意** | 视觉和交互设计 | 网站设计、移动端App、PPT设计、交互原型、品牌设计 |

> 设计创意模式深度集成腾讯设计 Ardot，一句话生成 UI/PPT/海报并可对话修改、跳转精修、生成代码，详见 `22-design-creative-guide.md`。

### 如何切换

对话区顶部可切换场景模式。切换后，快捷方式面板会随之变化。

### 场景与快捷方式联动

选好场景 → 点击对应的快捷方式 → WorkBuddy 自动加载该场景的最佳配置（模型、技能、专家）。

> 不需要知道用什么模型、什么技能——系统和场景快捷方式已全部关联好。

---

## 工作模式（Ask / Plan / Craft）

三种模式能力逐级递增：

| 模式 | 权限 | 适用场景 |
|------|------|---------|
| **Ask** | 只看不动，纯聊天问答 | 只想问问题、查资料 |
| **Plan** | 先出方案再执行 | 新手、对AI不放心时 |
| **Craft** | 默认模式，直接干活 | 日常使用（⚠️ 发消息即消耗积分） |

> **快速选择**：问问题切 Ask，不确定切 Plan，做事用 Craft。

## 工作界面布局

```
┌─────────────────────────────────────────────────────┐
│  顶部栏：场景切换 + 模型选择 + 工作空间                │
├──────────────┬──────────────────┬───────────────────┤
│  快捷方式面板  │                  │                   │
│  （场景关联）  │    对话区         │   右侧边栏         │
│              │  （中间主区域）    │  · 产出文件        │
│              │                  │  · 变更记录        │
│              │                  │  · 预览窗口        │
└──────────────┴──────────────────┴───────────────────┘
```

### 对话区

与 WorkBuddy 交互的主要区域。支持：
- 自然语言输入
- 文件上传（本地/腾讯文档/ima 知识库）
- **优化提示词按钮**：点击自动将自然语言转为结构化提示词

### 右侧边栏

任务进行中实时展示：
- **Todo 清单**：当前任务进度，已完成步骤自动打勾
- **产出文件**：生成的所有文件列表
- **变更记录**：文件修改记录
- **预览窗口**：HTML/图片/视频产物直接预览

### 工作空间

右下角可切换当前工作空间（对应电脑上的项目文件夹）。任务完成后文件自动存入对应空间。

## 新手推荐配置

1. **场景模式**：日常先用「日常办公」，写代码时切「代码开发」
2. **工作模式**：默认 Craft（第一次用可先用 Plan 看方案）
3. **模型**：不确定选 Auto，日常推荐 DeepSeek V4 Pro（性价比高）
4. **权限**：默认权限即可（高风险操作会弹框确认）
5. **文件管理**：前期做好工作空间分类，避免后期任务堆多了难找
