# 10 — 交互模式与通道（Interaction Modes）

> **版本**：v1.1 (2026-08-13)
> **用途**：理解 WorkBuddy 的三种工作模式、三条交互通道与多端同步，选对方式提效
> **来源**：WorkBuddy 官方教程 — Interaction 章节 + 多端同步官方公众号文章（2026-08-11）

---

## 三种工作模式（按权限递进）

把 WorkBuddy 当作新来的助手，三档放权范围：

```
Ask（问一问）→ Plan（想一想）→ Craft（做一做）
权限递增：只读 → 方案 → 直接动手
```

### Ask — 问一问（只看不动）

| 维度 | 说明 |
|------|------|
| **权限** | 仅查看文件并回答问题 |
| **可做** | 读取文件、分析数据、搜索信息、回答问题 |
| **不可做** | 修改文件、执行命令、写入任何内容 |
| **适合** | 调研阶段、阅读分析、确认理解、不熟悉的任务探索 |

### Plan — 想一想（先方案后执行）

| 维度 | 说明 |
|------|------|
| **权限** | 写分步计划，确认后再动手 |
| **可做** | 分析需求、设计方案、分解步骤 |
| **不可做** | 未经确认直接修改文件或执行命令 |
| **适合** | 复杂任务、高风险操作、需要对齐方案、多人协作 |

### Craft — 做一做（直接动手）

| 维度 | 说明 |
|------|------|
| **权限** | 拥有最大权限，直接操作文件、生成产物 |
| **可做** | 读写文件、执行命令、调用外部工具、生成成果物 |
| **注意** | 受权限模式约束（见下方），高风险操作仍需确认 |
| **适合** | 信任度高、任务明确、需要快速产出的场景 |

## 新手路径

```
Ask 熟悉功能 → Plan 看方案思路 → Craft 放手干
```

## 两种权限模式

控制 WorkBuddy 什么时候直接做、什么时候先问你。

### 默认权限（推荐）

| 操作类型 | 行为 |
|---------|------|
| 工作空间内读写 | 自动完成 |
| 写工作空间外文件 | 暂停确认 |
| 删除文件 | 暂停确认 |
| 执行脚本 | 暂停确认 |
| 调用系统级 API | 暂停确认 |

### 完全访问（谨慎使用）

- 减少弹窗确认，AI 自主决策增加
- ✅ 适合：可信、隔离、可恢复的环境，短时间使用
- ❌ 不建议：处理客户/财务/生产资料时开启

## 三条交互通道

交互不限于桌面端，三种通道按需选用，不互斥。

```
桌面端 Chat ──── 最完整：Ask/Plan/Craft 三档随手切
助理模式 IM ──── 人不在电脑前，手机一句话遥控本地
小程序 ──────── 云上常驻，电脑可关机
```

### 1. 桌面端（最完整）

在电脑前时的主力通道：
- 三档工作模式随意切换
- 可以使用所有文件、工具、连接器
- 完整上下文支持

### 2. 助理模式（IM 远程触发）

人不在电脑前时，从手机 IM 下指令，让本地电脑替你干活。

```
手机 IM → 服务端转发 → 本地电脑执行 → 产物回推 IM
```

| 关键点 | 说明 |
|--------|------|
| **本地必须开机** | 任务始终在本地电脑跑 |
| **工作目录固定** | 所有 IM 指令落在「助理」专属文件夹 |
| **单对话累积** | 同一通道所有远程指令在一个会话里 |

### 3. 微信小程序（口袋里的 AI）

和助理模式是扩展关系——多了一条云端常驻通道。

| 模式 | 特点 |
|------|------|
| **云上模式** | 任务在云端常驻执行，不依赖电脑开机 |
| **电脑模式** | 保留远程调用本地电脑的能力 |
| **定时任务** | 在小程序内创建/查看/暂停 Automations |
| **Skills + 专家** | 已安装 Skill / Experts / Expert Teams 能力对齐桌面端 |

### 助理 vs 小程序：二选一指南

| 对比 | 助理模式 | 小程序 |
|------|---------|--------|
| 执行位置 | 本地电脑 | 云端 / 本地 |
| 电脑要求 | 必须开机在线 | 云上模式可关机 |
| 核心价值 | 遥控本地资源 | 云上常驻 + 移动便携 |
| 选择标准 | **任务依赖本地资源** | **不需要本地资源 / 电脑关机时** |

## 三条通道怎么搭配

按任务依赖什么资源，选对应通道：

| 场景 | 用哪个 | 为什么 |
|------|--------|--------|
| 在电脑前 + 本地资源 | 桌面端 | Ask/Plan/Craft 三档随手切 |
| 出门临时来活儿 | 助理模式 | 手机 IM 一句话遥控本地电脑 |
| 长期定时 / 电脑关机 | 小程序 | 云上常驻，电脑无需开机 |

三档不互斥，按场景叠加用最顺手。

## 助理面板（v5.0.0+）

独立的面板，用于创建和管理自定义助理。

| 功能 | 说明 |
|------|------|
| **创建助理** | 为不同场景创建专属助理（如「客服助理」「数据助理」） |
| **切换助理** | 在不同助理之间快速切换 |
| **独立配置** | 每个助理可配置独立的 Prompt、技能、连接器 |

> 助理面板是更细粒度的专家管理方式——一个助理 = 一个角色 + 一套工具 + 一段独立的对话上下文。

## 多端同步（v5.3.8+，含锁屏远程）

PC、APP、小程序三端的任务、对话记录与产物实时同步，支持在手机上远程对电脑端任务授权与停止——**突破设备边界，跨设备切换不打断工作流**。

**开通（零配置）**：移动端和桌面端登录**同一账号**即可，不用扫码、配对、手动授权——账号一致就默认打开桌面端「允许移动端连接」开关，任务和工作空间自动同步。
> 版本要求：APP ≥ 1.2.0，PC ≥ 5.3.8。设备区域「绿色圆点」= 连接中 + Agent 在工作。

**五大能力**：

| 能力 | 说明 |
|------|------|
| **远程看状态** | 点进任意对话，能看到 Agent 正在读哪些文件、下一步要做什么，远程遥控授权与操作 |
| **跨项目切换** | 桌面端的任务列表 + 工作空间结构原样搬到手机，按空间分组查看，多项目互不串扰 |
| **双端协同** | 手机拍照/传文档（采集），电脑 Agent 识别归档/录入表格（处理），中间不用来回传文件 |
| **多设备切换** | 一台手机连多台电脑，切设备分别拉取各机器的任务与工作空间 |
| **远程急停** | 对话运行中点「停止」即终止电脑端 Agent 当前执行；停在哪步、已产出什么完整留痕，改指令后可重新出发 |

**锁屏远程**：桌面端打开「允许锁屏远程」开关后，电脑不自动休眠、屏幕不自动关闭，手机锁屏状态下仍可远程操控——不用一直亮屏盯着，也不怕中途断连。

> 锁屏 ≠ 休眠。锁屏后 WorkBuddy 继续工作，休眠则所有进程挂起。
