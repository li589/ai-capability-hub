# 16 — IMA 知识库操作指南

> **用途**：WorkBuddy 接入 ima 知识库后的基础操作（连接、引用、存回、解绑）
> **与 15-ima-official-knowledge.md 的区别**：本篇讲"如何使用 IMA 知识库功能"，15 讲"IMA 官方知识库作为兜底检索源"
> **⚠️ 术语划界**：本篇的「资料库」指左侧边栏接入第三方 **ima 知识库** 的入口；5.3.11 新增的 WorkBuddy **原生资料库**（我的文档/团队空间/三种载体/轻量发布）是另一个功能，见 `21-ziliaoku-guide.md`。两者独立，可同时使用。

---

## 一、连接授权

1. 左侧边栏点击 **资料库**，选择 **ima 知识库**
2. 点击 **立即前往授权**，使用微信扫码登录 ima 知识库
3. 再次点击 **确认授权**

授权后 WorkBuddy 获得以下权限：

| 权限 | 说明 |
|------|------|
| 查看知识库列表 | 获取登录用户的 ima 知识库列表 |
| 搜索知识库资料 | 检索知识库中的文件内容 |
| 添加文件到任务 | 将知识库文件作为上下文引入对话 |
| 保存文件到 ima | 将 WorkBuddy 产物存回知识库 |

> **注意**：授权后获得的是**登录用户**的 ima 知识库权限。支持 **个人 / 共享 / 订阅** 三类知识库。

---

## 二、在对话中引用 IMA 知识库

两种方式，效果相同：

### 方式 A：从资料库添加

1. 打开 资料库 → ima 知识库
2. 选中目标文件
3. 点击 **添加到任务**

### 方式 B：在对话框添加

1. 在任务输入框上方点击 **上传文件** 图标
2. 选择打开 ima 知识库
3. 勾选整个知识库或选择具体文件
4. 点击 **确定** 添加到对话

> **提示**：勾选整个知识库时，AI 会自动检索相关内容；选择具体文件时，AI 直接读取文件全文。

---

## 三、产物存回 IMA 知识库

WorkBuddy 生成的文件可一键存回 ima：

1. 在右侧产物区找到目标文件
2. 点击 **上传到云端**
3. 选择 **ima 知识库**
4. 选择存储位置：个人 / 共享 / 订阅知识库

> **典型场景**：AI 生成的会议纪要、分析报告、复盘文档存回知识库，形成知识沉淀闭环。

---

## 四、解除绑定

需要换绑账号或关闭连接时：

1. 打开 资料库 → ima 知识库
2. 右上角点击 **解除绑定**

> 解绑后 WorkBuddy 不再访问该 ima 账号的知识库，已添加到对话的文件不受影响。

---

## 五、注意事项

1. **授权范围**：仅获得登录用户的 ima 知识库权限，不含其他用户的知识库
2. **三类知识库**：个人（私有）、共享（团队）、订阅（付费内容），存回时按需选择
3. **隐私处理**：涉及客户隐私的内容（姓名、手机号、合同金额等），建议先脱敏再存回
4. **检索效率**：引用整个知识库时 AI 自动检索，可能比指定文件慢；优先指定文件以提速
