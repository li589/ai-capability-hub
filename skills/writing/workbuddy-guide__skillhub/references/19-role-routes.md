# 19 — 按角色快速上手路线图

> **版本**：v1.0 (2026-07-28)
> **用途**：不同岗位的新手不用通读全手册，按角色选路线，30 分钟内跑通自己最高频的 3 个场景
> **使用方式**：找到你的角色 → 按推荐顺序配置 → 遇到具体问题再回查速查卡/深度文档

---

## 通用职场人（行政/助理/职能支持）

**画像**：日常被会议纪要、周报、定时提醒、文件整理包围，追求"少动手、不遗漏"。

**高频场景**：
1. 会议纪要自动整理 → `06-scenario-examples.md` 案例14
2. 定时提醒与周期任务 → `04-automation-patterns.md` 4.4 节拿来即用模板（定时提醒/每日晨报）
3. 周报自动汇总 → `06-scenario-examples.md` 案例14 进阶部分
4. 文件批量整理 → `07-advanced-practice.md` 工作空间分区

**配置顺序**：Soul.md 立规矩 → 装 1 个连接器（飞书/邮箱）→ 建第一个自动化（每日提醒）→ 跑 `check_env.py` 验证

**关键提醒**：自动化任务创建后先手动触发一次验证输出格式，满意再开 ACTIVE；格式不对改 prompt 而不是重建任务。

---

## HR / 招聘

**画像**：简历筛选、面试安排、制度解答、培训材料制作，重复性文书工作多。

**高频场景**：
1. 简历批量筛选评分 → `06-scenario-examples.md` 案例11
2. 培训大纲与 PPT 生成 → `06-scenario-examples.md` 案例15
3. 搭建 HR 专家（制度问答/招聘助手）→ `03-expert-workflow.md` Prompt 设计模式 A
4. 员工问题自动答疑（IMA 知识库沉淀制度文档）→ `16-ima-knowledge-base-guide.md`

**配置顺序**：Soul.md → 创建 HR 筛选专家 → 用 50 份简历实测一轮 → 视频率决定是否升级专家团

**关键提醒**：简历评分一定要在 prompt 里写死评分维度和权重（技能40%/经验30%/项目20%/表达10%），否则 AI 每次口径不一；涉及候选人隐私的文件处理完及时移出工作空间。

---

## 开发 / 技术

**画像**：写代码、查文档、做 review，关心工具链能不能接上 GitHub/终端。

**高频场景**：
1. 代码审查工作流 → `06-scenario-examples.md` 案例12
2. GitHub 连接器（查 issue/PR/代码）→ `02-connector-troubleshooting.md`
3. 脚本自动化（定时巡检/日志分析）→ `04-automation-patterns.md` 周期巡检模板
4. 技术方案调研 → `09-prompting-best-practices.md` 任务交代五要素

**配置顺序**：Soul.md → 配 GitHub 连接器 → 创建代码审查专家 → 跑一次真实 PR review 验证

**关键提醒**：复杂大工程不要用 WorkBuddy 硬扛（国产模型代码能力与 Claude Code 有差距，见 `12-faq.md` 能力边界）；网页、小工具、脚本自动化才是它的甜区。

---

## 内容运营 / 自媒体

**画像**：日更压力大，选题、写稿、排版、发布、数据分析一条龙。

**高频场景**：
1. 公众号/小红书文案生成 → 创建文案专家（`03-expert-workflow.md`）
2. 海报/封面图生成 → `06-scenario-examples.md` 案例18
3. 每日热点监控 → `04-automation-patterns.md` 每日晨报模板
4. 历史素材复用（IMA 知识库归档爆文）→ `06-scenario-examples.md` 案例20

**配置顺序**：Soul.md → 创建 1 个平台文案专家 → 建热点监控自动化 → 跑通「生成→导出→发布」闭环

**关键提醒**：文案专家的人设里必须写死你的账号调性（语气/禁用词/排版偏好），否则每次输出风格飘忽；AI 生成图涉及商用前确认版权口径。

---

## 投资 / 财务分析

**画像**：盯行情、读财报、写研报，数据准确性和来源可追溯是底线。

**高频场景**：
1. 个股行情与财报查询 → `06-scenario-examples.md` 案例6（neodata-financial-search / westock-data）
2. 费用报表异常检测 → `06-scenario-examples.md` 案例16
3. 行业数据监控自动化 → `04-automation-patterns.md` 数据同步模板
4. 研报撰写（历史报告复用）→ `06-scenario-examples.md` 案例19

**配置顺序**：Soul.md → 配金融数据连接器 → 验证一次完整「查行情→读财报→输出表格」→ 建每日监控自动化

**关键提醒**：金融数据务必在 prompt 里要求标注数据来源和货币单位；AI 分析结论只做参考，投资决策前人工复核关键数字，异常波动 ±20% 以上的指标要二次确认。

---

## 项目管理 / 团队负责人

**画像**：跨部门协调、进度跟踪、会议多，关心团队资产沉淀和任务不落地。

**高频场景**：
1. Teams 项目与看板管理 → `13-teams-collaboration.md`
2. 会议纪要→待办分发闭环 → `06-scenario-examples.md` 案例14
3. 任务移交给同事 → `12-faq.md` Teams 章节
4. 定时汇报（项目周报自动化）→ `04-automation-patterns.md` 定时汇报模板

**配置顺序**：Soul.md → 创建 Teams 项目 → 邀请成员 → 建项目周报自动化 → 跑一次任务移交流程

**关键提醒**：Teams 资产库与个人工作空间独立，团队共享文件放资产库；任务移交后在消息中心确认对方已接收，关键节点不要只依赖系统通知。

---

## 通用提醒（所有角色适用）

- 以上路线只是入口，跑通 3 个高频场景后再按兴趣探索其他章节
- 任何角色都建议先完成 `SKILL.md` 的新手 6 步路径（约 45 分钟），再进入角色路线
- 遇到角色路线没覆盖的问题 → 回 `12-faq.md`（41 条）→ `troubleshooting.md` 速查表 → `check_env.py` 诊断
