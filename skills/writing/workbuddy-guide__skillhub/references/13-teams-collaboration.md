# 13 — Teams 团队协作（v5.0.0+）

> **版本**：v1.0 (2026-06-09)
> **用途**：理解 WorkBuddy 的团队协作能力，从单人使用到多人协同
> **来源**：WorkBuddy v5.0.0 Changelog + 官方文档

---

## 概述

WorkBuddy v5.0.0 引入了 Teams 团队协作能力，支持创建项目、邀请成员、任务协同与权限管理。不再只是个人助手，而是团队的生产力中心。

---

## 核心能力一览

| 能力 | 说明 | 一句话 |
|------|------|--------|
| **项目创建** | 创建团队项目，邀请成员加入 | 搭一个共享工作台 |
| **计划看板** | 待办创建、状态流转、批量操作 | 项目进度一目了然 |
| **资产库（网盘）** | 文件上传、文件夹管理、版本历史、任务引用 | 项目文件集中存放 |
| **外部数据源** | 定时导入 + Webhook 事件触发 | 外部系统数据自动进项目 |
| **动态时间线** | 成员操作记录与待办状态变更 | 谁干了什么都看得到 |
| **项目级配置** | 技能、专家、连接器按角色权限管控 | 不同角色用不同工具 |
| **协作对话** | 多成员实时协同、队列派发、排序 | 多人同在一个任务对话 |
| **任务流转** | 将任务移交给其他成员 | 我做一半你接着做 |
| **消息中心** | 邀请、审批、动态等通知聚合 | 项目消息不遗漏 |

## 1. 项目创建与成员管理

### 创建项目

1. 左侧导航栏 → **项目** → 创建新项目
2. 填写项目名称和描述
3. 项目创建后自动生成独立的工作空间

### 邀请成员

- 项目设置 → 成员管理 → 邀请
- 支持按角色分配权限（管理员 / 编辑者 / 查看者）
- 被邀请者在消息中心收到通知

### 权限模型

| 角色 | 可做 |
|------|------|
| **管理员** | 邀请/移除成员、修改项目设置、编辑所有内容 |
| **编辑者** | 创建任务、编辑资产、使用项目级资源 |
| **查看者** | 查看项目内容，不可修改 |

---

## 2. 项目计划看板

### 看板功能

- **待办创建**：在看板中直接创建任务卡片
- **状态流转**：拖拽卡片在「待办 → 进行中 → 已完成」之间移动
- **批量操作**：多选卡片统一修改状态、指派、截止日期

### 使用场景

```
周一站会 → 打开看板 → 每个人看到自己的待办 → 
拖拽更新进度 → 全队同步，无需额外汇报
```

---

## 3. 项目资产库（网盘）

### 核心能力

- **文件上传**：直接拖拽上传任意类型文件
- **文件夹管理**：创建文件夹结构组织项目资料
- **版本历史**：文件修改后保留历史版本，可回滚
- **任务内引用**：在对话中 `@` 引用资产库文件

### 与工作空间文件的区别

| | 资产库（网盘） | 工作空间 |
|--|-------------|---------|
| **可见范围** | 项目全部成员 | 仅自己 |
| **版本管理** | ✅ 版本历史 | ❌ 无 |
| **协作** | 多人共同编辑 | 单人使用 |

---

## 4. 外部数据源接入

让外部系统的数据自动流入项目。

### 两种接入方式

| 方式 | 说明 | 适合 |
|------|------|------|
| **定时导入** | 按固定周期自动拉取外部数据 | 日报、周报数据源 |
| **Webhook 触发** | 外部事件发生时自动推送 | 工单系统、CI/CD 通知 |

---

## 5. 项目动态时间线

记录项目内所有成员的操作：

- 谁创建/完成了什么任务
- 谁上传/修改了什么文件
- 待办状态变更
- 成员加入/离开

**价值**：不需要 @所有人 问进度，打开时间线就知道项目在发生什么。

---

## 6. 项目级技能/专家/连接器

在项目级别配置可用的技能、专家和连接器，按角色权限管控。

```
管理员配置：
  √ 项目可用技能：PPT生成、PDF处理、数据分析
  √ 项目专家：产品评审专家、代码审查专家
  √ 项目连接器：腾讯文档、GitHub

编辑者使用时：
  只能使用管理员配置好的资源，不能自行安装新技能
```

### 与个人配置的区别

| | 个人配置 | 项目级配置 |
|--|---------|----------|
| **生效范围** | 所有个人会话 | 仅该项目 |
| **管理方式** | 个人自行管理 | 管理员统一配置 |
| **权限** | 完全自由 | 按角色管控 |

---

## 7. 任务协作对话

### 队列派发

- 成员创建任务后，任务进入队列
- 空闲成员自动领取（或手动指派）
- 队列支持排序和优先级

### 多成员协同

- 多个成员可以在同一任务对话中协作
- 每人发送的消息对其他成员可见
- 适合需要多人 Review 的任务

---

## 8. 任务流转（Handoff）

任务做到一半，移交给其他成员继续。

```
流转流程：
  我的任务 → 点击「移交」→ 选择接收人 → 
  对方在消息中心收到通知 → 打开任务继续处理

适用场景：
  - 跨时区协作（我下班你接着做）
  - 需要特定专业角色介入的任务
  - 审批流（提交 → 审核 → 通过）
```

---

## 9. 消息中心

聚合所有项目相关通知：

| 通知类型 | 示例 |
|---------|------|
| **邀请** | 「张三邀请你加入项目 X」 |
| **审批** | 「你的任务流转请求已通过」 |
| **动态** | 「李四完成了待办：需求评审」 |
| **系统** | 「项目资产库空间即将满」 |

## 常见问题

### Q: Teams 和个人版有什么区别？
A: 个人版 = 你一个人用的 WorkBuddy。Teams = 团队共享的工作空间，有看板、资产库、权限管理。两者不互斥，你可以在个人版和 Teams 之间切换。

### Q: 项目资产库文件会不会占用我的个人空间？
A: 不会。项目资产库独立于个人工作空间，空间配额由团队管理员管理。

### Q: 外部数据源支持哪些系统？
A: 目前支持通过 Webhook 接入任意支持 HTTP 回调的外部系统。定时导入支持标准 API 数据源。
