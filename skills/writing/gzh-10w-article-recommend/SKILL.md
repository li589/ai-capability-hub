# 公众号爆款文章推荐（每日更新）

## 任务目标
- 本Skill用于：调用脚本获取公众号爆款内容数据，生成TOP10榜单，并自动生成HTML展示文件
- 能力包含：爆款数据获取、互动数排序、TOP10榜单生成、HTML可视化展示
- 触发条件：用户需要查看公众号爆款文章榜单

## 前置准备
- 依赖说明：脚本使用 Python 标准库和 requests（已预装）
- Python 路径：`/Users/luyuanyi/.workbuddy/binaries/python/versions/3.13.12/bin/python3`
- 无需额外配置

## 操作步骤

**严格按照以下步骤执行，不可跳过任何环节：**

### 步骤1：接收用户输入
- 智能体直接接收用户的原始输入内容
- 示例：用户输入"AI编程"、"健康饮食"、"职场技能"等

### 步骤2：智能分词处理
- 智能体对用户输入进行分词，生成关键词数组
- 示例：
  - 输入"AI编程" → 分词结果：["AI", "编程"]
  - 输入"健康饮食" → 分词结果：["健康", "饮食"]
  - 输入"职场技能提升" → 分词结果：["职场", "技能", "提升"]

### 步骤3：调用脚本获取数据
- **必须**调用 `scripts/fetch_explosive_articles.py` 脚本
- 参数说明：
  - `origin_word`: 用户原始输入
  - `spit_words`: 分词结果（JSON数组字符串）
  - `expansion_words`: 拓展词（JSON数组字符串，可传空数组`[]`）
- 调用示例：
  ```bash
  /Users/luyuanyi/.workbuddy/binaries/python/versions/3.13.12/bin/python3 scripts/fetch_explosive_articles.py --origin_word "AI编程" --spit_words '["AI","编程"]' --expansion_words '[]'
  ```

### 步骤4：脚本自动执行
脚本会自动完成以下处理：
1. 调用API获取爆款内容数据
2. 按阅读数排序，取前10条
3. 自检互动数据完整性（点赞、评论、分享）
4. 输出文本格式的TOP10榜单

### 步骤5：文本输出榜单内容
**文本榜单和HTML展示必须同时展示给用户，不可隐藏任何一方！**

智能体必须以段落形式完整输出TOP10榜单，每个条目的格式如下：
```
**1. [文章标题](链接)**
👤 作者名   📅 2026-04-10   👁 阅读数
❤️ 点赞数   💬 评论数   ↗️ 分享数

**2. [文章标题](链接)**
...
```
- 文章标题使用Markdown加粗+链接格式，点击可跳转
- 必须完整输出所有10条数据
- 使用 Emoji 图标增加可读性

### 步骤6：生成HTML榜单文件
**必须生成HTML文件！**

智能体调用脚本生成的HTML文件具有优化的卡片布局：
1. **整体布局**：白色背景，Grid 布局自适应 2-4 列
2. **卡片结构**（从上到下）：
   - 排名数字（渐变紫色圆形）+ 文章标题（可点击）
   - 作者 + 发布日期 + 阅读数（一行）
   - **底部一行**：点赞/评论/分享数据 + 右侧「查看作品」渐变按钮

### 步骤7：展示HTML文件
- **文本榜单输出后，立即展示HTML预览**
- 使用 `preview_url` 工具打开HTML文件
- 告知用户HTML文件路径

### 步骤8：询问用户是否订阅
- **必须**在展示后询问用户："是否订阅该榜单？"
- 用户回复"订阅"：智能体记录订阅信息并确认
- 用户回复"不订阅"：智能体确认并结束流程

## 资源索引

## 注意事项
- **严格按照步骤执行**，不可跳过任何环节
- **步骤5和步骤7必须同时执行**，文本榜单和HTML都要展示给用户
- **步骤6必须执行**，生成HTML文件
- 榜单数据为实时获取，可能因网络或API状态有所延迟
- **榜单展示阅读数最高的前10篇文章**
- HTML卡片按钮不再遮挡标题，放置在底部与互动数据同行
- 数据非实时，为入库快照
- 订阅服务由智能体在对话中完成
