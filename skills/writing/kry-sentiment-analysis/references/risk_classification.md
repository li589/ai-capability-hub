# 客如云评价风险分类体系

> 本文件定义差评的6大分类、关键词、风险等级和茶饮行业专属关键词。

---

## 差评关键词分类

### 1. 食品安全（最高优先级 🔴）
- **通用关键词**：不新鲜、变质、异物、虫子、头发、苍蝇、食品安全、拉肚子、吃坏
- **茶饮专属**：沉淀物、絮状物、异味、发霉、过期、加料变质、珍珠硬心、水果烂
- **严重程度分级**：
  - 🔴 **高风险**：食物中毒症状（拉肚子、呕吐、腹泻）、异物（虫子、头发、苍蝇）、变质发霉、过期食品 — **2小时内必须响应**
  - 🟠 **中风险**：食材不新鲜、异味、肉质异常 — **4小时内必须响应**
  - 🟡 **低风险**：外观异常、沉淀物、絮状物（未确认是否变质）— **24小时内必须排查**
- **风险等级**：🚨 紧急
- **处理**：立即排查食材采购、储存、加工全流程；高风险问题须立即下架相关产品、封存可疑食材

### 2. 口味问题（高优先级 🟠）
- **通用关键词**：难吃、味道差、口味差、油腻、偏重、没味道、肉质差、肉不新鲜
- **茶饮专属**：太甜、太淡、没奶味、茶味重、甜度不准、分层、水水的、齁甜、不齁但寡、糖没搅匀
- **风险等级**：🔴 高
- **处理**：收集反馈调整配方，建立试菜机制

### 3. 服务问题（高优先级 🟠）
- **通用关键词**：速度慢、出餐慢、服务差、态度差
- **茶饮专属**：少冰做成、做错了、加料漏了、等太久、叫号听不到、备注没看、没给吸管
- **风险等级**：🔴 高
- **处理**：优化流程，高峰期增派人手

### 4. 包装问题（中优先级 🟡）
- **通用关键词**：汤汁撒漏、汤汁渗漏、包装不紧、包装差、洒了、漏了
- **茶饮专属**：杯盖没盖紧、杯底漏、袋子里都是水、吸管戳不破、封口膜破了
- **风险等级**：🟡 中
- **处理**：升级包装材料，增加出餐检查

### 5. 分量问题（中优先级 🟡）
- **通用关键词**：分量少、分量不足、菜量少、菜量稀少
- **茶饮专属**：杯量少、没满、半杯冰、加料少、料不够、冰太多液太少
- **风险等级**：🟡 中
- **处理**：制定标准分量，使用标准量具

### 6. 保温问题（低优先级 🟢）
- **通用关键词**：保温不足、凉了、冷了
- **茶饮专属**：冰化了、不冰了、热饮变温
- **风险等级**：🟢 低
- **处理**：配置保温设备，缩短出餐到配送时间

## 风险分计算

| 指标 | 阈值 | 加分 |
|------|------|------|
| 差评率 | >40% | +3 |
| 差评率 | 25-40% | +2 |
| 差评率 | 15-25% | +1 |
| 平均评分 | <2.5 | +3 |
| 平均评分 | 2.5-3.0 | +2 |
| 平均评分 | 3.0-3.5 | +1 |
| 食品安全问题 | >0条 | +3 |

**满分9分**，风险评级：

| 风险分 | 评级 | 条件 |
|--------|------|------|
| 0 | ✅ 安全 | 差评率≤15% 且 均分≥3.5 且 无食安问题 |
| 1-2 | 🟢 低风险 | 差评率15-25% 或 均分3.0-3.5 |
| 3-4 | 🟡 中风险 | 差评率25-40% 或 均分2.5-3.0 |
| ≥5 | 🔴 高风险 | 差评率>40% 或 均分<2.5 或 有食安问题 |
