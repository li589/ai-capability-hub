# 客如云舆情分析技能

主从架构：主 SKILL 负责数据源判断和任务路由，子 SKILL 负责具体业务执行。

---

## 目录结构

```
kry-sentiment-analysis/
  init.md               <- 初始化流程
  SKILL.md              <- 主入口（当前文件）
  skills/
    kry-risk-analysis/    <- 风险定位 + 情感分析
    kry-reply-suggestion/ <- 差评回复建议
    kry-weibo-analysis/   <- 微博舆情分析
    kry-meituan-analysis/ <- 美团、大众点评舆情分析
  references/            <- 报告模板、风险分类
```

---

## 概念定义

| 概念    | 说明                                        | 示例         |
| ----- | ----------------------------------------- | ---------- |
| 品牌关键词 | 用于门店招牌、宣传物料等的对外名称，可用于搜索舆情                 | 蜜雪冰城、星巴克   |
| 品牌名   | 机构的注册名称，一般是公司在客如云中的配置名，或者在工商的登记名，不可用于搜索舆情 | 蜜雪冰城股份有限公司 |

> 品牌关键词 ≠ 品牌名。微博/小红书数据获取需要的是「品牌关键词」，不是「品牌名」。

## 执行流程

收到用户提问后，按以下步骤**顺序执行**：

### 步骤一：初始化（首次执行必须完成）

读取 [初始化](init.md) 的内容并按其步骤执行。

### 步骤二：判断数据源

根据用户意图，确定需要的数据源：

| 数据源            | 触发条件                                                      | 执行动作                                                          |
| ----------------- | ------------------------------------------------------------- | ----------------------------------------------------------------- |
| **客如云**        | 默认（评价/差评/食安/小程序等）                                      | 加载 [kry-comment-query](skills/kry-comment-query/SKILL.md)       |
| **微博**          | 用户提到「微博/微博舆情」                                     | 加载 [kry-weibo-analysis](skills/kry-weibo-analysis/SKILL.md)     |
| **小红书**        | 用户提到「小红书/小红书舆情/小红书笔记」                      | 加载 [kry-xhs-analysis](skills/kry-xhs-analysis/SKILL.md)         |
| **美团/大众点评** | 用户提到「美团/大众点评/点评/经营宝/登录/退登/重新登录/注销」 | 加载 [kry-meituan-analysis](skills/kry-meituan-analysis/SKILL.md) |

**多渠道综合**：用户提到「综合/全面/所有渠道」，或同时提到「评价」与「微博」「小红书」「美团/大众点评」中的任意两个及以上，执行上面对应动作，获取数据并分析。

### 步骤三：获取品牌关键词，用于搜索（仅微博/小红书需要）

**适用条件**：步骤二判断的数据源包含「微博」或「小红书」时，**必须**先完成本步骤，再执行数据获取。

**执行命令**：

```bash
kry-cli comment brandKey -b <brandId>
```

- `<brandId>`：初始化阶段获取的品牌 ID

**结果处理**：

| 情况                       | 处理方式                                                              |
| -------------------------- | --------------------------------------------------------------------- |
| 命令返回了品牌关键词       | 使用返回的品牌关键词，继续步骤四                                      |
| 命令未返回（空值或报错）   | **必须**询问用户提供品牌关键词（提示示例：蜜雪冰城、星巴克），不得提供默认值，等待用户回复后继续步骤四 |

> **禁止**在未获得品牌关键词的情况下执行 `comment weibo` 或 `comment xiaohongshu` 命令。

### 步骤四：获取数据

根据步骤二确定的数据源，加载对应子 SKILL 执行数据获取

### 步骤五：生成报告

- 客如云评价参考 [template_keruyun.md](references/template_keruyun.md)
- 微博舆情参考 [template_weibo.md](references/template_weibo.md)
- 美团/大众点评参考 [template_meituan.md](references/template_meituan.md)
- 综合分析：依次输出「客如云评价分析」「微博舆情分析」「小红书舆情分析」「美团/大众点评舆情分析」（仅输出涉及到的渠道），最后「综合结论与建议」
- 如需筛选食安问题，加载 [[risk_classification]]
- 格式要求：按照模板的内容，生成单文件、交互式 HTML
