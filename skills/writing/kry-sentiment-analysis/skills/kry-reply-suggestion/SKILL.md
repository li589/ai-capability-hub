# kry-reply-suggestion 差评回复建议

负责"行动层"，基于已有评价数据生成回复话术和处理建议。

---

## 核心职责

| 职责      | 说明                   |
| ------- | -------------------- |
| 差评回复话术  | 根据差评分类生成针对性回复模板      |
| 处理优先级建议 | 按食安>口味>服务>包装>分量>保温排序 |
| 补偿方案建议  | 根据问题严重程度推荐补偿方案       |
| 改进措施建议  | 给出短期+长期改进建议          |

---

## 数据来源

本子 SKILL 不调用任何接口，基于已获取的评价数据（来自 kry-comment-query / kry-risk-analysis）做规则匹配和话术生成。

---

## 执行流程

```
获取差评数据 + 分类结果（来自前置子 SKILL）
  ↓
按分类匹配回复模板
  ├─ 食品安全 → 紧急处理模板
  ├─ 口味问题 → 口味改进模板
  ├─ 服务问题 → 服务提升模板
  ├─ 包装问题 → 包装升级模板
  ├─ 分量问题 → 分量标准化模板
  ├─ 保温问题 → 保温改善模板
  └─ 未分类 → 通用回复模板
  ↓
生成处理建议（紧急/短期/长期）
  ↓
输出回复话术 + 处理建议
```

---

## 回复时效要求

| 评价类型     | 回复时效 | 优先级 |
| ------------ | -------- | ------ |
| 食品安全问题 | 2小时内  | 紧急   |
| 差评         | 24小时内 | 高     |
| 中评         | 48小时内 | 中     |
| 好评         | 72小时内 | 低     |

## 回复话术模板

### 食品安全 → 紧急处理

```
尊敬的顾客，非常抱歉给您带来不好的体验。我们对食品安全问题零容忍，已立即启动核查程序：

1. 门店已暂停相关产品的供应，进行全流程排查
2. 我们将在24小时内完成调查并给出处理结果
3. 请私信我们联系方式，我们将提供[补偿方案]

— {品牌名}客服团队
```

### 口味问题 → 改进承诺

```
尊敬的顾客，感谢您的反馈。关于您提到的口味问题，我们非常重视：

1. 我们已将您的反馈转达给产品研发团队
2. 将在近期调整配方/甜度标准
3. 欢迎您再次品鉴并给出宝贵意见

— {品牌名}客服团队
```

### 服务问题 → 流程优化

```
尊敬的顾客，非常抱歉给您带来不便。关于您提到的服务问题：

1. 我们已对该门店进行服务培训强化
2. 高峰期将增派人手，缩短等待时间
3. 如遇问题可直接联系门店经理：{电话}

— {品牌名}客服团队
```

### 包装问题 → 升级承诺

```
尊敬的顾客，非常抱歉出现包装问题。我们已：

1. 升级该门店的包装材料
2. 增加出餐时的包装检查环节
3. 请私信我们联系方式，我们将补发/退款

— {品牌名}客服团队
```

### 分量问题 → 标准化

```
尊敬的顾客，感谢您的反馈。关于分量问题：

1. 我们已统一制定标准分量和量具
2. 将对该门店进行分量抽查
3. 如确实存在不足，请联系我们补发

— {品牌名}客服团队
```

### 保温问题 → 设备改善

```
尊敬的顾客，感谢您的反馈。关于温度问题：

1. 我们已为门店配置保温袋/保温箱
2. 优化出餐到配送的时间管控
3. 下次点餐可选择"保温包装"选项

— {品牌名}客服团队
```

### 通用回复

```
尊敬的顾客，感谢您的反馈！我们会持续改进，为您提供更好的体验。欢迎再次光临！

— {品牌名}客服团队
```

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 无差评数据 | 告知"当前暂无差评，无需生成回复建议" |
| 分类不明确 | 使用通用回复模板，并标注"建议人工审核" |
| 补偿方案 | 仅提供范围建议（如退款/补发/优惠券），具体金额需商户自行决定 |
