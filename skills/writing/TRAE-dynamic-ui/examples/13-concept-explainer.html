Consistent Hashing

How distributed systems map keys to nodes without rehashing everything when topology changes.

A hash ring maps both nodes and keys onto a circular space. Each key is served by the first node encountered clockwise — its successor. When a node joins or leaves, only keys in its partition are remapped.

Glossary
Hash Ring
A circular space [0, 2³²) where both nodes and keys are positioned via a hash function.
Node
A server or process responsible for a range of the hash ring.
Key
A data identifier (e.g., cache key, row ID) hashed onto the ring.
Successor
The first node clockwise from a key's position — the node responsible for that key.
Partition
The arc of the ring between two consecutive nodes; all keys in this arc belong to the clockwise node.
Virtual Node
Multiple hash positions per physical node for better load distribution.
