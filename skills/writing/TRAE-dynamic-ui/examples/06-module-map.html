Public API Surface

POST /api/auth/login
Primary login flow. Accepts email+password, returns JWT access & refresh tokens. Hot path — 12k rpm peak.
POST /api/auth/register
User registration with email verification. Sends async verification email via job queue.
POST /api/oauth/authorize
OAuth2 authorization code flow. Supports Google, GitHub, GitLab providers.
POST /api/auth/refresh
Token refresh using rotating refresh tokens. Invalidates old token on use.
SessionMiddleware
Express middleware. Validates JWT on every request, attaches req.user context.
Hot Path

The login flow (AuthController → AuthService → TokenService → SessionStore) handles 12k rpm at peak. The Redis session store is the bottleneck — p99 latency spikes to 45ms under load.
