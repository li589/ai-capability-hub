Design Decision · Ghost

35% opacity + 2° rotation

The dragged item fades to opacity: 0.35 in-place and tilts 2deg clockwise. This signals "I've been picked up" without the jarring flash of a fully-invisible source. The slight tilt adds physicality — it feels like lifting a sticky note off a board.

Design Decision · Drop Indicator

Indigo line + dot endpoint

A 2px indigo-5 line appears between items to show exactly where the drop will land. The dot on the left end anchors the eye. We avoid highlighting the entire gap (too heavy) or using a border on the target item (ambiguous direction).

Design Decision · Snap Behavior

Items reflow instantly, no animation

During drag, items shift position without transition. Animated reflows during drag feel "laggy" — the user is already focused on their cursor, so instant snaps feel more responsive. The final drop does get a subtle 120ms ease-out.

Design Decision · Drag Threshold

No hold delay, immediate grab

We use the native HTML5 drag API with no artificial delay. The 6-dot grip pattern on hover signals draggability. On touch devices we'd add a 150ms long-press threshold, but this prototype targets desktop cursor interaction only.

Open Questions

Unresolved Design Decisions

1
Should reordering persist immediately or require a save action?

Auto-save feels modern but could frustrate users who accidentally drag. A "Reset to default" option in Settings might be enough of a safety net.

2
Keyboard-accessible reorder?

Power users expect Alt+↑/↓ to move items. This is straightforward to implement but needs clear focus styling that doesn't conflict with the drag states.

3
Pin/lock items to prevent accidental moves?

Dashboard and Settings feel like fixtures. Should we allow pinning items so they can't be dragged? This adds UI complexity (pin icon, locked state styling).

4
Mobile touch behavior?

HTML5 Drag and Drop has spotty mobile support. If mobile matters, we'd need a touch-based implementation with long-press activation. Should we scope this prototype to desktop only?
