# 📋 文档一致性校对助手

> 智能检测报告、文档中的数据矛盾、术语不统一、逻辑错误

[![Version](https://img.shields.io/badge/Version-2.4.6-blue.svg)](./SKILL.md)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## 🎯 功能简介

自动校对文档中的上下文不一致问题，适用于：

- 📄 政府规划报告（水利、农业、发改等）
- 📊 数据报表（Excel 表格一致性检测）
- 📝 学术论文（术语统一、数值一致）
- 📋 合同文档（关键条款前后一致）

---

## ✨ 核心特性

### 1. 智能标注
- **原文问题** → 黄色高亮标记
- **问题说明** → 橙色文字，一目了然
- **位置对比** → 第X页第Y段 ↔ 第X页第Y段，快速定位

### 2. 多种格式支持
| 格式 | 支持 |
|------|------|
| `.docx` | ✅ |
| `.pdf` | ✅ |
| `.xlsx` | ✅ |
| `.txt/.md` | ✅ |

### 3. 高兼容性
- 使用段落高亮文字，**100% 兼容** Word/WPS
- ⚠️ 建议使用 **Microsoft Office Word** 打开

### 4. 高效率
- 模型自主分析，无需预设规则
- 只标记明显矛盾，不地毯式搜索
- 直接输出报告，减少中间步骤

---

## 🚀 使用方式

在 WorkBuddy 中直接说：

```
帮我校对这份报告
检查文档前后是否一致
找出报告里的低级错误
文档一致性检查
```

---

## 📦 输出文件

1. **校对报告（.md）** - 问题清单 + 修正建议
2. **带批注文件（_annotated.docx）** - 原文档高亮标注

---

## ⚠️ 注意事项

- 标注文件请用 **Microsoft Office Word** 打开（避免 WPS 渲染差异）
- 首次检测为快速筛查，如需深度检测请明确说明
