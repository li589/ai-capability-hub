# 日报模式执行流程

> 成文时必须同时遵守 [writing-style.md](writing-style.md)。编排与多行业并行见 [SKILL.md](SKILL.md)。

## 第零步：决定是否启用并行 Subagent

- **1 个行业**：主 agent 直接执行下列步骤一至四
- **≥2 个行业**：先确认保存位置并建好 `日报分行业_{日期}/`，再按 SKILL.md「并行 Subagent 编排」启动 Task；**各 subagent 自己写入对应子文件**，主 agent **只拼总文件**。以下步骤一至三是**单行业**（主 agent 或某个 subagent）的标准作业。

## 第一步：查询该行业当日纪要

**单行业内**：发出查询；勿串行等待可并行的请求。

```
research_query(
    type="minutes", industryName="{行业名}",
    startTime="YYYY-MM-DD 00:00:00", endTime="YYYY-MM-DD 23:59:59",
    pageSize=50, page=1
)
```

- 日期默认今天，用户可指定
- 返回空则该行业标注「当日无纪要」
- 总数超过 50 则翻页补全
- 出现 `persisted-output` 时必须读完整 JSON，禁止只用预览



## 第二步：撰写行业综合总结

> ⚠️ **如实记录原则（最高优先级）**：`research_query` 已按 `industryName` 过滤，返回的每条纪要都属于该行业。**禁止对 API 返回结果做任何二次筛选或主观排除**——不能因为标题中没有显性行业关键词、公司知名度不高、或者是看似平淡的"业绩说明会"就跳过。**API 返回多少条，报告就必须覆盖多少条。**

### 结构与取舍规则

1. **先排序，再写作**：先把全部纪要归并为 2-5 条主题，并按重要性排序；不能按 API 返回顺序逐篇复述。
2. **重点有限**：根据当天信息量写 **2-5 个编号主题**，通常以 3-5 个为宜；纪要很多也不得无限增加编号，应合并同类项。
3. **每点只讲一条主线**：每个编号必须有明确判断标题；正文只解释该判断，不能同时塞入无关公司、产品和宏观观点。
4. **纪要总结是正文主体**：主题判断只用 1-2 句话搭建阅读框架，随后立即展开「相关纪要观点总结」。每篇总结通常写 2-5 个完整句，覆盖该纪要与当前项目相关的核心主张、逻辑依据、关键数字和边际判断；不得把纪要压缩成一句出处说明。
5. **共识与分歧要显性写出**：两篇及以上支持同一判断时写明「多方一致」及依据；观点不一致时单列分歧，不能强行合并。
6. **必须指出分化**：若同日同时出现高景气与承压方向，单独用一个编号说明板块内部分化及原因。
7. **标的不能裸列**：提到公司时必须说明「受益于什么 / 承压于什么 / 哪个数据值得跟踪」。
8. **突出纪要但避免机械重复**：「相关纪要观点总结」是读者在综合章节获取纪要内容的主要入口，应有足够信息密度；「逐篇摘要」再按原文结构完整还原。两部分可以共享关键结论和数字，但不得大段复制。
9. **主题、标的、催化分层**：编号主题只归纳行业讨论；公司集中放入「重点标的」；未来事件集中放入「催化展望」。主题正文可引用公司作为证据，但不能演变成公司名单。
10. **重点标的与催化展望均须逐项写**：两个栏目都使用 `1、2、3、` 编号。每个标的或催化只先写一句定位，主要篇幅用于逐篇展开「相关纪要观点总结」。两类信息不得混写。
11. **不强行补齐**：没有明确标的或催化时写「当日纪要未形成明确标的/催化共识」，不得臆造；风险仅在纪要明确讨论且对结论重要时自然写入相关主题，不设固定风险栏目。
12. **来源必须可追溯且醒目**：相关纪要统一写成 `（序号）**[纪要标题](链接)：** 观点总结`，纪要标题必须加粗。不得只写机构名、公司名或「某纪要」；若接口确实没有链接，则保留准确标题但不得编造链接。
13. **按相关性挂载**：同一篇纪要如果同时讨论多个主题、标的或催化，可以在不同项目下重复出现，但每次只总结与当前项目直接相关的内容；不能把整篇摘要原样粘贴到多个位置。
14. **不遗漏也不硬挂**：每篇纪要至少应在一个主题的「相关纪要观点总结」中得到实质性总结；只有明确讨论某个标的或催化的纪要，才挂到相应项目下。不得仅凭标题猜测归属。
15. **序号层级固定**：主题、重点标的、催化展望的项目统一使用 `1、2、3、`；每个项目下的相关纪要统一使用 `（1）（2）（3）`；单篇纪要内部确需再拆分时才使用 `a. b. c.`，通常优先写成连贯段落。逐篇摘要标题使用 `第1篇｜纪要标题`，不得再使用 `1.`。不同层级禁止复用同一种序号。
16. **视觉缩进固定**：主题、标的和催化项目顶格书写；每个项目下的「相关纪要观点总结」必须整体使用 Markdown 引用块 `>`，形成一级缩进和左侧竖线。单篇纪要内部如使用 `a. b. c.`，写成 `> > a.` 形成二级缩进。禁止使用行首空格或全角空格伪造缩进。



### 禁止的写法

- 禁止一段到底，连续堆叠十几家公司和数字
- 禁止取消主题框架、直接按 API 顺序堆砌纪要；「相关纪要观点总结」必须放在相应主题、标的或催化之下，并按相关性组织
- 禁止把「主题、标的、催化」全部塞进同一个自然段
- 禁止只列纪要标题或用一句空泛话带过；也禁止综合判断写得很长、纪要总结反而沦为附注
- 禁止编号标题只写名词，如「1、氨纶」「2、染料」；应写成判断，如「1、氨纶供需反转已从预期进入价差兑现阶段」
- 禁止主题与对应纪要都使用 `（1）`，或在同一层级混用 `1、`、`（1）`、`a.`
- 禁止相关纪要与所属项目顶格混排，也禁止用四个空格缩进导致 Markdown 将正文渲染成代码块
- 禁止为了全量覆盖而在综合总结平均用力；**全量覆盖由综合归类 + 逐篇摘要共同保证，不等于每篇在综合总结中占相同篇幅**



### 详细示例

> 以下公司、价格和经营数据仅用于演示写法。正式报告必须以当日 `research_query` 返回的纪要为依据，不得复用示例事实。

```markdown
### 行业综合总结

**总判断：** 今日基础化工纪要的核心讨论集中在纺织化学品涨价、氨纶盈利修复和纯碱去库存三条主线。染料与氨纶已经从预期改善进入价格或价差验证阶段，纯碱则仍受高库存压制，板块内部的景气分化进一步扩大。

**1、染料涨价已从厂商试探性报价转向中间体紧缺支撑下的实际成交**

当天三场染料相关纪要都认为，本轮涨价的主要驱动力不是单纯的旺季预期，而是还原物、H 酸等中间体有效供给收缩。部分中小厂因环保检查和原料不足降低开工，龙头企业的库存也处于近三年偏低水平，供给端已经难以通过短期提产快速补足缺口。

价格传导已经出现初步验证。分散黑主流成交价由每吨 2.2 万元升至 2.4 万元，约一半下游客户接受了新价格；H 酸报价同期上涨约 8%，说明染料涨价并非只有成本推动，也有供给约束支撑。多方观点的分歧主要在持续时间：企业纪要认为旺季订单可以支撑价格至少一个季度，渠道纪要则提示终端坯布订单尚未全面恢复，后续仍需观察印染厂开工率。

> **相关纪要观点总结：**
>
> （1）**[染料龙头经营交流纪要](https://example.com/dye-company)：** 公司认为中间体紧缺已经传导至实际成交，分散黑约一半客户接受每吨 2.4 万元的新价格。管理层据此判断，旺季订单有望支撑价格至少一个季度。
>
> （2）**[华东染料渠道调研纪要](https://example.com/dye-channel)：** 渠道确认 H 酸报价同期上涨约 8%，说明供给收缩正在向下游传导。不过，终端坯布订单尚未全面恢复，本轮涨价持续性仍需观察印染厂开工率。
>
> （3）**[染料中间体供需专家会纪要](https://example.com/dye-intermediate)：** 专家将涨价主因归结为还原物、H 酸的有效供给收缩。环保检查和原料不足使中小厂短期难以提产，因此供给缺口并非短期报价扰动。

**2、氨纶供需改善开始转化为价差扩张，但行业尚未进入全面高景气阶段**

两场氨纶纪要都将近期变化概括为“售价小幅上调、成本明显回落”。40D 氨纶成交价一个月内上涨约每吨 1,000 元，主要原料 PTMEG 价格同期下降约每吨 800 元，吨产品价差因此扩大约 1,800 元。龙头企业凭借较低能耗和较高开工率，利润改善幅度预计快于行业平均水平。

不过，纪要并未形成需求已经全面复苏的共识。经销商反馈运动服饰订单有所回暖，但常规纺织品订单仍以小单、短单为主，行业库存只是从高位回到正常区间。因此，当前更准确的判断是龙头盈利率先修复，而不是全行业重新进入供不应求。

> **相关纪要观点总结：**
>
> （1）**[氨纶龙头经营交流纪要](https://example.com/spandex-company)：** 公司认为产品提价与 PTMEG 成本回落正在同步扩大吨盈利。龙头凭借能耗和开工率优势，将率先把价差改善兑现为利润。
>
> （2）**[纺织原料经销商电话会纪要](https://example.com/spandex-channel)：** 经销商观察到运动服饰订单回暖，但常规品仍以小单、短单为主。渠道因此不认同行业已全面进入高景气，后续需要继续跟踪订单持续性。

**3、纯碱高库存尚未有效化解，低成本企业只能体现相对优势**

纯碱纪要的共识仍然偏谨慎。行业总库存约 165 万吨，虽然较前一周下降 4 万吨，但绝对水平仍明显高于过去三年同期；重碱现货价格接近每吨 1,450 元，出口报价也已接近部分联碱企业的现金成本。短期检修带来的供给收缩可以减缓库存累积，却不足以证明行业已经反转。

企业之间的分化主要来自成本。天然碱企业的完全成本显著低于联碱和氨碱企业，即使现货价格继续承压，仍能保持正向现金利润。多场纪要因此更看好低成本企业的相对收益，但没有给出纯碱价格趋势性上行的判断。

> **相关纪要观点总结：**
>
> （1）**[纯碱行业供需专家会纪要](https://example.com/soda-ash)：** 专家认为约 165 万吨的行业库存仍然偏高。短期检修只能减缓累库，尚不足以证明行业反转。
>
> （2）**[天然碱企业交流纪要](https://example.com/natural-soda)：** 公司强调天然碱的成本曲线优势。即使重碱价格接近每吨 1,450 元，低成本装置仍能维持正向现金利润，因此公司的机会主要来自相对韧性。

**4、基础化工各子行业处于不同阶段，投资线索应从行业普涨转向个股盈利验证**

染料处于供给收缩推动价格上涨的阶段，氨纶处于价差修复向利润兑现过渡的阶段，纯碱则仍在消化过剩产能和高库存。三条主线同时出现，说明基础化工不能再用统一的需求复苏逻辑概括。

当天纪要的共同特征是更重视盈利验证。市场关注点已经从“产品是否涨价”进一步转向“成交是否接受新价格、价差是否扩大、季度利润能否兑现”。因此，后续判断板块强弱时，应优先比较企业成本曲线、订单兑现和利润弹性，而不是只观察产品报价。

> **相关纪要观点总结：**
>
> （1）**[基础化工策略交流纪要](https://example.com/chemical-strategy)：** 策略观点认为染料、氨纶和纯碱处于不同景气阶段，板块普涨逻辑已经弱化。选股应转向成本曲线、订单兑现和季度利润验证。
>
> （2）**[化工产品价格跟踪电话会纪要](https://example.com/chemical-price)：** 价格跟踪显示，报价上涨并不等于盈利兑现。实际成交比例和产品价差才是区分公司表现的关键。

**重点标的：**

1、**浙江龙盛：** 纪要重点讨论了公司在还原物和 H 酸上的一体化能力。中间体供给收缩既能推动染料价格上涨，也会扩大一体化企业与外购原料企业之间的成本差距，因此公司被视为本轮染料涨价中盈利确定性较高的标的。

> **相关纪要观点总结：**
>
> （1）**[染料龙头经营交流纪要](https://example.com/dye-company)：** 纪要认为公司的一体化能力可以放大染料涨价的利润弹性。后续应重点观察新价格成交比例与中间体外销量。
>
> （2）**[染料中间体供需专家会纪要](https://example.com/dye-intermediate)：** 专家认为中间体紧缺会拉大一体化龙头与外购原料企业的成本差距。浙江龙盛因此具备更高的盈利确定性。

2、**华峰化学：** 产品提价与 PTMEG 成本回落同时发生，使公司的吨盈利具备改善基础；较高开工率也有助于摊薄固定成本，但利润弹性仍需结合销量判断。

> **相关纪要观点总结：**
>
> （1）**[氨纶龙头经营交流纪要](https://example.com/spandex-company)：** 纪要认为公司将凭借成本和开工率优势率先兑现价差扩张。季度利润是核心验证指标。
>
> （2）**[纺织原料经销商电话会纪要](https://example.com/spandex-channel)：** 渠道提示终端订单尚未全面回暖。公司利润弹性仍面临销量约束，不能只根据价格上涨判断业绩。

3、**远兴能源：** 当前逻辑并不是纯碱行业反转，而是公司凭借天然碱低成本优势，在纯碱高库存和低价格环境中仍能维持现金利润。

> **相关纪要观点总结：**
>
> （1）**[天然碱企业交流纪要](https://example.com/natural-soda)：** 纪要强调公司在低价环境中的相对韧性。天然碱装置负荷、行业库存和现货价格是判断利润持续性的核心指标。

4、**新乡化纤：** 公司被视为氨纶价格和价差变化的高弹性标的；若旺季订单推动继续提价，利润弹性可能高于行业平均，需求不及预期时也会反向体现。

> **相关纪要观点总结：**
>
> （1）**[纺织原料经销商电话会纪要](https://example.com/spandex-channel)：** 渠道认为公司对氨纶价格变化更敏感，理论利润弹性高于行业平均。但订单持续性决定盈利弹性最终能否兑现。

**催化展望：**

1、**染料方向：** 未来两周首先关注龙头是否发布新一轮报价，以及本轮提价的实际成交比例。如果印染开工率回升、渠道库存仍处低位，染料价格可能继续向下游传导。

> **相关纪要观点总结：**
>
> （1）**[染料龙头经营交流纪要](https://example.com/dye-company)：** 公司把新一轮报价与成交接受度视为未来两周的核心催化。若多数客户接受新价格，涨价将从预期进入兑现阶段。
>
> （2）**[华东染料渠道调研纪要](https://example.com/dye-channel)：** 渠道认为印染开工率和渠道库存将决定涨价能否继续传导。这两个指标也是判断催化持续性的验证条件。

2、**氨纶方向：** 关注纺织旺季补库、月度价差和龙头季度利润。如果订单恢复与成本下降同时延续，季度利润改善将进一步验证行业景气修复。

> **相关纪要观点总结：**
>
> （1）**[氨纶龙头经营交流纪要](https://example.com/spandex-company)：** 公司预计成本回落将先体现在月度价差，随后由季度利润确认。利润兑现将是景气修复最直接的催化。

> （2）**[纺织原料经销商电话会纪要](https://example.com/spandex-channel)：** 渠道认为旺季补库强度是判断订单恢复持续性的关键。若补库偏弱，价差改善可能难以转化为销量增长。

3、**纯碱方向：** 需要等待周度库存连续下降和高成本产能减产。在这两个条件出现之前，短期检修更可能带来交易性催化，而不是行业反转信号。

> **相关纪要观点总结：**
>
> （1）**[纯碱行业供需专家会纪要](https://example.com/soda-ash)：** 专家将周度库存连续下降与高成本产能减产列为反转前置条件。只有两项条件同时出现，价格修复才可能具备持续性。
>
> （2）**[天然碱企业交流纪要](https://example.com/natural-soda)：** 公司认为短期检修会改善交易情绪，但不足以单独改变中期供需判断。催化能否升级为反转信号，仍取决于实际去库。
```

## 第三步：逐篇写摘要

> ⚠️ **核心原则：忠实还原，不预设框架。** 摘要任务是把原始内容完整、不失真地压缩记录，而不是套入固定模板。

**唯一硬性要求：**

1. **不丢失信息**：原文所有关键数字、明确提到的股票标的、边际判断（超预期/低于预期/拐点/首次等）必须保留
2. **忠实原文结构**：原文分几个板块就记几个板块；按公司逐一讨论就按公司逐一记录，不要自己重新归类或合并
3. **长度匹配原文信息量**：内容丰富就记长一些，简短就短一些；绝不能把几千字电话会压成两三句话

**格式：**

```markdown
**第{序号}篇｜[{纪要标题}]({链接})** · `MM-DD HH:mm`

{按原文结构逐段记录，保留所有关键信息}
```
