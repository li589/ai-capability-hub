# 查询模式与闲聊模式

> 行业标准名、模式识别见 [SKILL.md](SKILL.md)。闲聊成文时遵守 [writing-style.md](writing-style.md)。

统一查询工具：

```
research_query(
    type="minutes",
    industryName="{行业名}",      # 可选；标准名称，不要带「行业」后缀
    keywords="{主题或公司关键词}", # 可选；精确问题保持 divergenceLevel=low
    stockCode="{代码}",           # 可选
    startTime="YYYY-MM-DD 00:00:00",
    endTime="YYYY-MM-DD 23:59:59",
    pageSize=50, page=1,
    divergenceLevel="low"
)
```

---

## 查询模式

面向「先看有哪些会」：**只输出纪要名称（标题）与日期（时间）列表**，可选附进门链接。**禁止**写行业综合总结、逐篇内容摘要、边际变化分析；**默认不落盘**。

### 第一步：解析条件并检索

从用户话里抽出时间 / 行业 / 公司 / 关键词后调用上方接口。

- 时间未指定：默认**最近 7 天**；用户说「今天/昨天/某日」则按该日
- 多行业、多关键词：同一消息内并行查询，单轮建议不超过 **7** 个请求
- 总数超过 pageSize：必须翻页，直到拿全列表
- 出现 `persisted-output`：必须读完整 JSON，抽出**全部**标题与时间

### 第二步：输出清单（全量、不筛）

> ⚠️ **必须列出 API 返回的全部命中条目**，不得因「看起来不重要」丢弃。同一 `id` / 同一链接只保留一条。

```markdown
## 纪要查询结果
> 条件：{行业/关键词/个股} · {startTime} — {endTime}
> 共 N 条

| # | 纪要名称 | 日期 |
|---|----------|------|
| 1 | [标题](链接) | YYYY-MM-DD HH:mm |
| 2 | [标题](链接) | YYYY-MM-DD HH:mm |
```

- 按日期从新到旧排序
- 0 条时说明检索条件，并询问是否放宽
- 末尾可引导：「需要某几条内容解读可直接说标题，或改用闲聊/日报/周报。」

### 第三步：模式切换

- 点名某几条「详细说说」→ 切闲聊
- 「做成日报/周报」→ 切对应成文模式（走 SKILL.md 并行分治）
- 「保存列表」→ 询问路径；未指定则默认当前工作空间 `纪要查询_{YYYY-MM-DD}.md`

### 示例

**列出今天基础化工有哪些电话会纪要**

```
research_query(type="minutes", industryName="基础化工", startTime="今天 00:00:00", endTime="今天 23:59:59", pageSize=50)
```

**最近一周华峰化学相关纪要，只要名称和日期**

```
research_query(type="minutes", keywords="华峰化学", startTime=最近7天起点, endTime=今天末, pageSize=50)
research_query(type="minutes", industryName="基础化工", keywords="华峰化学", startTime=最近7天起点, endTime=今天末, pageSize=50)
```

## 闲聊模式

面向任意内容问答。**默认不生成日报/周报文件**；在对话里直接给出有依据的回答。

### 第一步：解析问题，规划查询

| 维度 | 来源示例 | 默认 |
|------|----------|------|
| 时间 | 「今天」「这周」「最近」、具体日期 | 未提及时默认最近 7 天；单点事实核对可放宽到 30 天 |
| 行业 | 标准行业名 | 未提及时可不传 `industryName` |
| 个股/公司 | 公司名、代码 | 有则优先 `stockCode` 或关键词含公司名 |
| 主题词 | 「氨纶」「还原物」等 | 填入 `keywords` |
| 对比范围 | 「多方怎么看」「有没有分歧」 | 可能需要多路并行 |

### 第二步：自主调度（可多轮、可并行）

> 模型必须自己决定查什么、查几次，不要让用户拼 API 参数。

1. **先窄后宽**：最贴题条件优先；空结果再放宽时间/去掉行业/改关键词
2. **能并行就并行**：互不依赖的查询同一消息发出
3. **单轮建议 ≤7 个** `research_query`；更多则分批
4. **溢出必读全量**；超 pageSize 必须翻页
5. **禁止臆造**：观点/数字/机构/日期必须能在当次结果中找到；查不到就说明已用条件

### 第三步：组织回答

遵循 writing-style：先结论后证据。

1. **直接答**：一句话结论
2. **证据**：1–3 条最相关纪要要点（机构/标题、时间、关键数字）；附链接
3. **边界**：未覆盖部分、时间窗、是否建议改用日报/周报

**边界：**

- 闲聊只取与问题相关的纪要，**不要求**全量覆盖
- 用户要「整理成日报/周报」再切成文模式并遵守全量覆盖
- 「保存这次问答」时询问路径；未指定则默认当前工作空间 `纪要问答_{YYYY-MM-DD}.md`

### 示例调度

**华峰化学最近电话会怎么说氨纶价差？**

```
research_query(type="minutes", keywords="华峰化学 氨纶", startTime=最近7天起点, endTime=今天末, pageSize=50)
research_query(type="minutes", industryName="基础化工", keywords="华峰化学", startTime=最近7天起点, endTime=今天末, pageSize=50)
```

**染料还原物现在纪要里什么价？**

```
research_query(type="minutes", industryName="基础化工", keywords="还原物", startTime=最近14天起点, endTime=今天末, pageSize=50)
```
