# 电话会纪要助手

> 从进门财经自动拉取电话会纪要：可生成日报/周报，可先查标题列表，也可直接问答。多行业日报/周报用并行 subagent 分治，不设行业数量硬上限。

**一个 AI 投研助手，对话框里说句话就能用。**

---

## 1、能做什么？

自动检索进门财经的电话会纪要，按需求输出清单、问答或结构化报告。

- **检索**：按日期和行业拉取电话会纪要，覆盖 37 个行业；也可按公司、主题词调度接口
- **查询**：只返回命中纪要的名称与日期列表（可附链接），方便先扫目录
- **并行分治**：多行业时每个行业一个 subagent——子代理写好该行业子文件并只回报短状态；主助手用磁盘上的子文件拼总文件
- **对比**：跨纪要横向比对多方观点，识别共识、分歧和观点转向
- **写入**：日报以纪要观点总结为正文主体，按主题、标的和催化组织，并保留逐篇完整摘要；周报含主题演变+边际变化方向
- **问答**：闲聊模式自主调用纪要接口，回答「某公司最近怎么说」「某主题什么价」等问题

---

## 2、怎么用？

**第 1 步**：在对话框说——

```
帮我查今天 电子、医药生物、公用事业、计算机 的电话会纪要
看一下 基础化工、电子 这周的主题变化
列出今天 基础化工 有哪些电话会纪要
华峰化学最近电话会怎么说氨纶景气？
```

四种模式：

| 模式 | 用途 | 行业数量 |
| ---- | ---- | ---- |
| 日报 | 按日成文（总结+逐篇摘要） | 不设硬上限；≥2 行业并行 subagent，**子文件+总文件** |
| 周报 | 过去 7 天主题演变成文 | 不设硬上限；≥2 行业并行 subagent，**子文件+总文件** |
| 查询 | 只要标题+日期列表 | 无硬上限 |
| 闲聊 | 对话里答内容观点 | 无硬上限 |

**第 2 步**：技能自动拉取相关纪要；多行业成文时分行业并行，再汇总

**第 3 步**：日报/周报生成报告文件；查询/闲聊默认在对话中输出，需要保存时再说一声

---

## 3、多久跑一次？

日报盘后每天一次，周报每周一次。查询与闲聊随时用。也可触发定时任务，说"设为每天下午 5 点自动生成"即可。

---

## 4、生成什么？

| 产物 | 内容 |
| -------- | -------- |
| `电话会纪要日报_日期.md` | 日报总文件：项目顶格，相关纪要用引用块缩进，纪要内分点再缩一级；序号依次为 `1、`—`（1）`—`a.` |
| `日报分行业_日期/行业.md` | 日报子文件：突出展示各篇纪要观点的分层式单行业总结 + 逐篇摘要 |
| `行业主题周报汇总_日期.md` | 周报总文件：索引 + 各行业周报全文拼接 |
| `行业主题周报_行业_日期.md` | 周报子文件：单行业完整周报 |
| 查询清单（可选落盘） | 纪要名称 + 日期（可附链接）表格 |
| 闲聊对话答疑（可选落盘） | 针对问题的结论 + 纪要证据；默认不写文件 |

周报用标记区分主题变化：

| 标记 | 含义 |
| -------- | -------- |
| 🔥 | 持续主线，热度未减 |
| 🆕 | 本周新出现的主题 |
| ❄️ | 此前热门，本周降温 |
| 🔄 | 同一主题的观点显著转向 |

**查询列表示意：**

```
| # | 纪要名称 | 日期 |
| 1 | 天风化工 \| 华峰化学深度路演… | 2026-07-24 07:30 |
| 2 | 国投证券 \| 染料产业链更新… | 2026-07-28 21:00 |
```

---

## 5、输出在哪？

成文前会先问保存位置；未指定则输出到**当前工作空间**：

```
{当前工作空间}/
├── 电话会纪要日报_日期.md
├── 日报分行业_日期/{行业}.md
├── 行业主题周报汇总_日期.md
└── 行业主题周报_{行业}_日期.md
```

目录自动创建，文件生成后对话里直接点链接打开。查询/闲聊默认只在对话里回答。

---

## 6、注意事项

- 数据来源为进门财经电话会纪要，含实时非公开信息，但也可能夹杂非官方判断
- 日报/周报不再限制「最多 3 个 / 只能 1 个」；行业很多时会更耗时，但仍可跑（建议每批并行不超过 8 个行业）
- 「列出有哪些」走查询；「怎么说/什么价」走闲聊；「生成日报/周报」走成文
- 只做信息汇总和观点梳理，不构成投资建议
