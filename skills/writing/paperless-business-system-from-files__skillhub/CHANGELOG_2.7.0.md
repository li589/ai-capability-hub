# 2.7.0 升级说明

本版本重点把 2.6.0 的“业务理解 + 自动生成”补成“生成 + 真实测试 + 严格验收 + 安全升级”的闭环。

## 新增

- `run_skill.py test`：隔离副本真实运行 E2E，覆盖健康检查、登录、CRUD、类型校验、CSV 导入、XLSX 导出、安全停止、SQLite 备份恢复。
- `run_skill.py upgrade`：旧/新 `system-spec` 差异分析，分类为安全新增、需复核、破坏性变化；默认阻断删除字段/对象与字段改类型。
- 新增 `references/runtime-e2e-and-upgrade.md`。
- 生成字段加入 `ui_control`、`validation`、`enum_candidates` 等元数据。
- SQLite 运行时迁移支持对既有表非破坏式补齐新增字段。

## 改进

- 跨表关系识别从“同名字段”提升为“字段语义 + 样本值重合 + 候选唯一性”。
- 修复表头候选同分时偏向后面数据行的问题，同分时优先更早的行。
- 数字、整数、日期、日期时间、布尔、枚举统一服务器端严格校验；非法数字不再原样写入 SQLite。
- 业务表单自动使用数字、日期、日期时间、布尔、枚举控件。
- CSV/XLSX 导入增加逐行校验；存在错误行时默认阻止提交。
- 计算字段导入时不再要求原文件提供，由服务器端重新计算。
- 关系推断用到的较大值域样本仅在内存中使用，生成业务模型前移除，减少业务数据暴露。

## 验收变化

- `validate --strict` 现在要求：`tests_executed` 非空、`runtime_e2e_verified=true`、有运行环境记录、`TEST_REPORT.md` 不得仍为“未执行”。
- 因此“静态结构完整”不再能被误判为“系统已经实际可用”。

## 自测

技能包自身冒烟测试覆盖 7 项：版本一致、统一入口、关系增强、智能表单/严格校验/增量迁移、未测试阻断、非破坏式升级与数据保留、E2E 测试器可调用。
