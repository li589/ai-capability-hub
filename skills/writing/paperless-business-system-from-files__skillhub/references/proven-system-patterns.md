# 三套成熟系统反向验证出的通用模式

本文件记录的是工程模式，不是用户业务数据。不得把参考系统里的真实人员、产品、密码或历史数据复制到新项目。

## 1. 能源日报类

验证能力：多能源类型、日报/月报、产量与单耗、年度/月度目标、同比/环比、目标方向、历史补录/剔除、双阶段确认、权限覆盖、Excel 导入导出、数据库迁移。

可复用模式：`daily_report + line_entries` 主从结构；目标/标准独立版本表；确认后修改需专项权限；统计口径放后端函数并测试零分母、目标方向和历史周期。

## 2. 运营记录类

验证能力：人工工时、机器工时、原料损耗、化学品/油品、能耗、物料损耗、动态基础字段、两级表头、历史字段兼容、复杂 Excel 复刻、纸面签字空白区、记录所有者权限。

可复用模式：基础字段数据化 + 每条记录保存 schema snapshot；旧字段到新字段显式映射；两级表头父子结构；废弃流程只清理权限/状态影响，不破坏历史字段。

## 3. 点工/考勤类

验证能力：26～25 日考勤月、员工/工号、线别/班组/排班、正工与加班公式、生产/非生产工时、跨线支援、请假/加班申请、打卡导入核对、双审核、字段级权限、日报锁定、驾驶舱筛选、安全启停生命周期。

可复用模式：计算字段后端锁定；专项审核位可以并行并要求不同账号；打卡核对保留自动结果 + 人工确认；驾驶舱筛选维度由组织主数据驱动；停止/重启必须有“正在停止”状态避免端口竞态。

## 4. 三套系统共同工程模式

### RBAC + 用户覆盖

角色提供默认权限；用户可选择继承角色或启用自定义权限。服务端每次写操作重新校验权限。数据范围另行判断“本人/他人/组织范围”，不能只靠菜单隐藏。

### SQLite 长期演进

启用 WAL、外键、事务。迁移前备份；显式 migration id；迁移完成后记录；失败回滚。禁止升级程序启动时无条件覆盖历史数据。

### Excel 是正式输出，不是装饰

Excel 模板样式要测试：关键标题、合并区域、列顺序、签字区、打印区域。网页正确不代表 Excel 正确。

### 生命周期

启动状态至少包含 app_id、pid、port、start_time；推荐增加随机 shutdown_token。停止只作用于本项目。停止后立即重启时先等待旧实例退出与端口释放。

### 回归测试跟版本修复绑定

每个用户反馈的修复应留下最小回归测试，例如“目标达成升降百分比”“人工工时两级表头”“看板线别筛选”“安全启停”。技能生成新系统时也应采用同样原则。
