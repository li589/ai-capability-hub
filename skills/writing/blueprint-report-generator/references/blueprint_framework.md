# eMES 蓝图报告章节框架与撰写要点

> 23 页标准结构（动量守恒 2026.08 交付件为基准）。每页的"撰写要点"来自客户A/客户B/宇牌三项目实战 + 用户原始 9 点要求。

## 三大硬要点（贯穿全篇）

1. **进度对齐**：本期蓝图所有工作节点必须与 eMES 实施主计划同步（规划与启航/蓝图与设计/构建与验证/上线与赋能/优化与升华），并在第 4 页标"I am here!"。
2. **范围界定**：物理区域 + 涉及产品系列 + 本次上线 eMES 模块（含暂缓项，标琥珀色）。
3. **验收条件**：围绕 8 大透明列四类依据（报表/看板/无纸化覆盖/数采指标），**不可空泛**。

## 八大透明（按客户实际选择）

派工透明 / 进度透明 / 设备透明 / 质量透明 / 人员透明 / 资料透明 / 不良透明 / 产能透明

| 透明目标 | 含义 | 验收依据样例 |
|:-|:-|:-|
| 派工透明 | 派工日期、设备线体、进度可视 | 派工执行查询报表 + 派工负荷 + 派工到人通知触达率 |
| 进度透明 | 工单进度实时呈现 | 进度查询 + 工序在制 + 加压长度/切片进度实时率 |
| 设备透明 | 稼动/点检/保养可视 | 设备状态/稼动/点检记录 + 稼动率 |
| 质量透明 | 首检/自检/巡检/末检无纸化 | 检验结果查询 + 不良原因查询 + 检验完成率 |
| 人员透明 | 上工/报工/工价记录 | 人员工价明细 + 上下工数据完整率 |
| 资料透明 | SOP/图纸电子化 | SOP 调阅记录 + SOP 绑定覆盖率 |
| 不良透明 | 不良/报废分库 | 不良原因分析 + 不良登记及时率 |
| 产能透明 | 设备负荷评估 | 产能负荷 + 产能利用率 |

## 撰写时易踩的坑

1. **不要虚构设备数据**：所有数采设备、采集内容、点位数量都必须从调研/实施报告原数据来
2. **个案/二开/待确认必须区分**：个案=调研中已明确的特殊需求（标琥珀）；二开=需要新开发的功能（标琥珀加粗）；待确认=蓝图中需客户拍板的事项（标琥珀色 +【待确认】前缀）
3. **验收条件不能空泛**：每个透明目标的"四类依据"必须可查证（具体报表名/具体无纸化覆盖点/具体数采指标）
4. **不要把所有内容塞进一页**：动量守恒 23 页是底线，工艺多/差异多时扩到 28 页也是合理的（用额外核心子流程页）
5. **保留「I am here」标记**：进度对齐硬要求，必须在第 4 页明确标出当前阶段
