# 资源类型工时模型 v4.1

基于 SMC/DTS/Terraform 等现代迁移工具链的实际项目经验，工时 = 人工决策和验证时间（不含工具自动运行的等待时间）。

## 14 种资源类型

### 1. 云服务器（CVM/ECS/EC2/VM）
- **关键词**：CVM, ECS, 云主机, 云服务器, vCPU, EC2, VM, 虚拟机, BMS, 裸金属, 物理机
- **默认复杂度**：中
- **单台工时**：0.72 人天
- **六阶段分配**：
  | 阶段 | 人天 | 说明 |
  |------|------|------|
  | 规划设计 | 0.05 | 批量规划，单台分摊极少 |
  | 基础环境 | 0.02 | 网络/安全组是项目级 |
  | 资源开通 | 0.10 | SMC/镜像导入自动化 |
  | 数据迁移 | 0.30 | SMC在线迁移，等待+验证 |
  | 业务部署 | 0.15 | 配置调整（IP/DNS/连接串）|
  | 测试割接 | 0.10 | 基础功能验证 |

## 复杂度系数

| 等级 | 系数 | 典型场景 |
|------|------|---------|
| 低 | ×0.8 | 标准配置、开箱即用 |
| 中 | ×1.0 | 常规配置 |
| 高 | ×1.3 | 集群架构、跨版本、异构场景 |

## 规格权重

从规格字符串中解析 vCPU 数量：
| 规格 | 权重 | 说明 |
|------|------|------|
| <16C | ×1.0 | 不加权 |
| >=16C | ×1.1 | 中大规格轻微加权 |
| >=32C | ×1.25 | 大规格 |
| >=64C | ×1.4 | 超大规格 |
