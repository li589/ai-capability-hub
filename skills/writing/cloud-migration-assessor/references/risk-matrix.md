# 风险矩阵 v4.1

## 7 类迁移风险模板

根据用户的资源清单自动匹配适用的风险项。

### 1. 数据一致性风险
- **等级**：高
- **触发条件**：存在数据库类资源（MySQL/Redis/MongoDB/ES等）
- **发生概率**：中
- **影响程度**：高
- **应对措施**：采用DTS/数据同步工具进行双向同步；迁移后进行全量数据校验；制定数据回滚方案

### 2. 业务中断风险
- **等级**：高
- **触发条件**：核心业务系统迁移、割接窗口<4小时
- **发生概率**：中
- **影响程度**：高
- **应对措施**：制定详细割接方案与回滚方案；分批次迁移、灰度切流；至少进行2次割接演练

### 3. 应用兼容性风险
- **等级**：中
- **触发条件**：跨版本升级（如MySQL 5.7→8.0）、跨云平台迁移
- **发生概率**：中
- **影响程度**：中
- **应对措施**：提前进行兼容性测试；建立测试环境充分验证；准备兼容性适配方案

### 4. 网络性能风险
- **等级**：中
- **触发条件**：跨地域迁移、大数据量传输
- **发生概率**：低
- **影响程度**：高
- **应对措施**：提前进行网络压力测试；准备专线/VPN双通道冗余；优化网络架构

### 5. 安全合规风险
- **等级**：中
- **触发条件**：涉及敏感数据、跨域迁移、等保要求
- **发生概率**：中
- **影响程度**：中
- **应对措施**：提前梳理安全合规要求；配置安全基线；进行安全扫描评估

### 6. 第三方对接风险
- **等级**：低
- **触发条件**：存在外部系统依赖
- **发生概率**：中
- **影响程度**：中
- **应对措施**：提前盘点第三方接口清单；预留联调时间；准备降级方案

### 7. 团队能力风险
- **等级**：低
- **触发条件**：团队对目标平台不熟悉
- **发生概率**：低
- **影响程度**：中
- **应对措施**：提前进行培训；引入有经验的外部顾问；使用AI辅助工具降低技术门槛
