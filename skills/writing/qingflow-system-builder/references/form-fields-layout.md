## 3. 表单排版

### 3.1 普通字段

- 普通字段默认一行四个。
- 按业务阅读顺序排列，不把无关字段强行放在一起。
- 长文本、附件、地址、说明、子表、Q-Linker 和代码块单独占行或使用宽行。
- “一行四个字段”要转换为实际 `rows` 矩阵，不作为不存在的顶层 `columns` 参数。

示例：

```json
{
  "rows": [
    ["负责人", "业务日期", "业务状态", "业务类型"],
    ["客户名称", "联系人", "联系电话", "所属区域"],
    ["关联核心记录", "引用金额"],
    ["业务明细"],
    ["备注"],
    ["附件"]
  ]
}
```

### 3.2 写入后检查

- 回读实际行分组和字段顺序。
- 检查复杂组件是否单独占行。
- 检查隐藏字段、系统字段和已删除字段是否污染布局。

## 4. 引用与关联字段

- 一行最多放两个引用或关联字段。
- 复杂引用字段优先单独一行。
- 不把多个引用字段和其他普通字段混在同一行。
- 关联字段与其关键引用摘要可以相邻，但必须保持视觉清晰。
- 下游应用使用真实单选关联字段指向核心应用。
- 选择关联记录后自动带出至少三个关键字段，例如客户、负责人、日期、状态、金额。
- 需要筛选、流程或报表使用的引用值必须配置为可使用的引用填充字段。
