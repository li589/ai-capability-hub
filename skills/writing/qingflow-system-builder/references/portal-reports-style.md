## 本模块职责

本文件只负责“门户报表选择、指标卡、标题与视觉样式”相关的详细规则、示例与验收点。执行其他路径时从总地图直接加载对应模块，不从本文件递归加载。

## 报表选择

| 业务问题 | 优先类型 |
| --- | --- |
| 数量、金额、次数 | 指标卡 |
| 明细、汇总、多字段库存或订单 | 全宽汇总表 |
| 日、周、月变化 | 折线图或面积图 |
| 人员、部门、工序、品类排行 | 横向条形图 |
| 状态或类别分布 | 条形图、柱状图；类别很少时可用环形图 |
| 到货率、达成率、完成进度 | 进度图或仪表图 |
| 需要进入详情或执行操作 | 全宽表格视图 |

选择约束：

1. 优先使用指标卡、汇总表、折线图、条形图和进度图等容易理解的类型。
2. 雷达图、玫瑰图、复杂环形图只在业务语义确实需要时使用，不得为了视觉效果增加。
3. 同一维度不得同时用多种图表重复表达。
4. 场景简单时可以只保留“筛选 + 一个全宽汇总表”，参考 `离散制造管理2.0 / 库存看板`。
5. 场景完整时可使用“核心指标 + 筛选 + 明细 + 趋势 + 排行/分布”，参考 `生产ERP2.0 / 生产薪酬看板`。
6. 采购场景可采用“采购指标 + 到货进度 + 全宽订单明细”的结构；只学习 `采购部工作台` 的信息节奏，不复制其中的快捷入口。

## 视觉与配色

1. 默认主题使用 `themeId=4`。
2. 普通图表和汇总表使用白色背景 `#FFFFFF`、浅灰边框及网格线 `#E6EAF0`，辅助文字使用 `#767E89` 或 `#494F57`，主体数据使用 `#121315`。
3. 汇总表表头使用 `#EFF2F8`；表头和表体字号默认 13，单元格垂直居中。
4. 指标卡设置 `indicatorAlignment.align=center`、`contentMiddle.switchOn=true`、`indicatorPrimary.displayName=true`；背景色和边框色必须一致。
5. 同一指标行只使用一个色组，并严格按组内顺序从左到右取色，不跨组、不乱序。
6. 默认优先使用青蓝渐进组，并从左到右依次取色：`#e3fdfd`、`#cbf1f5`、`#a6e3e9`、`#71c9ce`。
7. 只有跨主题综合经营场景或用户明确需要多彩表达时，才使用次选多彩柔和组：`#ffb3ba`、`#ffdfba`、`#ffffba`、`#baffc9`、`#baeffe`、`#b3cde0`、`#ff677d`、`#d4a5a5`。
8. 其他场景色组仅在用户明确指定或参考门户必须复刻时使用，不替代上述默认优先级。
9. 普通图表不沿用指标卡彩色背景；统一白底，并使用一个主色系表达数据。

## 标题

1. 所有图表门户组件必须设置 `config.beingShowTitle=false`，回读值为 `chartConfig.beingShowTitle=false`。这是门户编辑器“轻析报表 -> 标题”开关。
2. 不得用清空组件 `title` 或修改底层 `title.switchOn` 代替关闭门户标题开关。
3. 指标卡设置 `title.switchOn=false`、`indicatorPrimary.displayName=true`，显示内部主指标名称。主指标的 `selectedMetrics[].fieldName` 必须改为明确的业务名称；使用 `count(*)` 时尤其要覆盖系统默认“数据总量”，禁止显示“数据总量”“数据数量”“汇总值”等默认字样。
4. 普通图表设置 `title.switchOn=true`，显示底层 `chartName`。
5. 每个图表最终只显示一个内部业务标题；报表 `chartName` 正确但主指标仍是默认名称，视为标题验收失败。

## 执行与验收

1. 读取目标和参考门户的草稿态、发布态、组件、筛选、底层图表和真实视图类型。
2. 输出业务问题与组件清单，删除重复或装饰性报表。
3. 设计 PC 24 栅格与移动端 6 栅格，创建唯一全宽筛选组件并配置“包含”。
4. 创建或更新报表、场景色组、表格样式和标题开关；逐张设置并回读指标卡主指标显示名。
5. 回读草稿态，确认无 `grid`、视图均为 `table`、筛选唯一且绑定去重、布局无重叠、报表业务含义明确。
6. 发布后回读正式版，确认与草稿态一致。

完成前必须同时满足：

- 筛选组件数量为 1，PC 为 `24x3`、移动端为 `6x1`。
- 默认筛选判断为 `dftJudgeType=2`，每个兼容目标只绑定一次。
- 顶部指标卡默认不超过 4 张且 PC 单行；默认按青蓝渐进组从左到右配色，跨主题场景才使用多彩柔和组。
- 报表类型和数量适合场景，没有重复问题或装饰性堆叠。
- 普通报表白底浅边框，表格与文字样式统一。
- 所有图表为 `chartConfig.beingShowTitle=false`，每张图表只显示一个内部标题；指标卡 `selectedMetrics[].fieldName` 与业务名称一致且不含系统默认字样。
- PC 与移动端无重叠、无遮挡，草稿态与发布态一致。
