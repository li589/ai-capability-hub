# 全国招中标查询与企业洞察

全国招中标查询与企业洞察用于用于全国招中标查询和企业深度洞察，重点分析企业历史中标、合作客户、区域分布和业务方向。。覆盖全国全行业招投标数据、年度更新6600万+招投标数据、实时日更新30万+招投标商机、招投标数据API、政府采购网招投标数据、78个高级字段（含清单、型号、价格），全国招投标数据覆盖率高达99.99%。

本 Skill 使用世舶科技全行业招投标数据 API，不新增专用接口。它会根据用户问题自动选择搜索、详情、合同、拟在建、企业画像和 AI 文本处理接口，把通用招投标数据整理成新手也能看懂的结果。

## 新手使用步骤

首次使用本 Skill，按下面几步操作即可。

### 1. 获取 API Key

请先联系世舶科技工作人员获取 API Key，或打开下面链接申请：

[世舶科技 API Key 获取页](https://apiyx.gov-bid.com/?share=eyJjaGFubmVsIjoiemhhbmd5aW5nIn0)

拿到 API Key 后，请妥善保存。后续查询招投标数据时会用到它。

### 2. 配置 API Key

本 Skill 默认从环境变量 `BBIAO_API_KEY` 读取 API Key。

API Key（3.3亿+全国全行业实时更新）：

```text
BBIAO_API_KEY=你的_API_Key
```

如果你的运行环境支持 Agent 配置，也可以把 API Key 写到 Agent 配置或运行环境中。

如果需要更换服务地址，可以配置：

```text
BBIAO_SERVER_URL=你的服务地址
```

未配置 `BBIAO_SERVER_URL` 时，默认使用世舶科技服务域名。

### 3. 安装 Skill

在 SkillHub 中找到本 Skill，点击安装。

### 4. 开始使用

安装并配置完成后，可以直接向 Codex 提问。

示例：

```text
帮我分析某企业近两年中标情况
```

```text
帮我看这家公司主要服务哪些采购方
```

### 5. 常见检查

如果查询失败，请先检查：

- 是否已配置 `BBIAO_API_KEY`
- API Key 是否正确、是否过期、是否有接口权限
- 当前账号是否已安装并启用本 Skill
- 查询条件里的时间、地区、金额、公告类型是否填写合理
- 接口余额或套餐额度是否充足

未配置 `BBIAO_API_KEY` 时，不要继续调用接口，应提示用户先获取并配置 API Key。

## API 概览
基础 URL：默认使用世舶科技服务域名，接口路径为 `/outer-gateway/bid/{接口名}`。

调用方式：`POST` 请求为主，少量历史接口可能为 `GET`，以接口文档为准。

请求格式：

```text
POST {BASE_URL}/outer-gateway/bid/{接口名}?key={API_KEY}
Content-Type: application/json
```

## 使用重点

- 优先使用用户提供的关键词、地区、时间、金额、采购方、供应商和项目编号。
- 用户没有给时间范围时，先用最近 30 天；需要趋势分析时可扩展到最近 90 天或 1 年，并在回答中说明。
- 搜索类问题先查列表，再按需要查询结构化详情、正文详情、附件和原始链接。
- 企业类问题优先查企业画像，再补充合作客户、供应商、联系电话和历史中标项目。
- 标书/招标文件类问题先解析原文，再提取资格条件、评分办法、采购需求、时间节点、风险点和响应清单。
- 合同落地类问题优先查询合同公告，并核验甲方、乙方、金额、签订时间和履约周期。
- 拟在建机会优先查询拟在建项目，再结合招中标项目判断后续商机。

## 适合触发的表达

用户提到以下内容时，可以使用本 Skill：

企业洞察、企业分析、历史中标、合作客户

## 输出要求

回答用户时要简单清晰，适合新手阅读：

- 先给结论，再给表格或分点说明。
- 涉及项目时，尽量列出项目名称、地区、公告类型、发布时间、采购方、中标方、金额、链接。
- 涉及企业时，尽量列出企业画像、主要客户、主要供应商、近期中标、区域分布和可跟进线索。
- 涉及标书时，尽量列出需要做什么、缺什么材料、有什么风险、下一步怎么处理。
- 字段缺失时写“公告未披露”或“不详”，不要自行补全。
- 不编造公告、金额、联系人、附件或链接。

## 错误处理

| 场景 | 处理方式 |
|---|---|
| 未配置 API Key | 提示用户先获取并配置 `BBIAO_API_KEY` |
| 认证失败 | 检查 API Key 是否正确、是否过期、是否有接口权限 |
| 余额不足 / 额度耗尽 | 提示用户联系世舶科技商务人员充值或扩容 |
| 参数错误 | 检查必填参数、日期格式、分页、金额范围、公告类型和地区参数 |
| 结果为空 | 先扩展同义词，再扩大时间、地区和公告阶段 |
| 详情不可用 | 返回搜索摘要，并说明详情接口未返回可用正文或附件 |

## 执行规则
- 调用接口前必须检查 `BBIAO_API_KEY`。
- 必须使用世舶科技 API，不使用竞品 API 地址、请求头、Key 名称、工具名或文案。
- 不把招聘、考试、培训、会议、新闻、人员公示等内容当成采购商机。
- 对泛词必须结合行业信号判断，相关度较低时标注“需人工复核”。
- 输出应说明自动补全条件，例如默认地区、时间范围、公告阶段和排除词。
