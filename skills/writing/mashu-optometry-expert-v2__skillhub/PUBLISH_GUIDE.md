## 二、3 个效果案例素材（发布成功后补充，建议补满）

### 案例 1 — 核心能力：验光单 / 眼生物测量单解读
- **场景标题**：验光单一键解读
- **场景描述**：家长上传孩子验光单或眼轴测量单，技能自动提取球镜/柱镜/轴位/眼轴等数据，翻译成大白话并给出初步屈光状态判断。
- **示例问题**：「这是我家孩子 8 岁的验光单，右眼 -2.00/-0.50×180，眼轴 24.3mm，算严重吗？」
- **触发条件**：用户上传图片或输入验光数据，且含「验光单 / 眼轴 / 度数」等关键词。

### 案例 2 — 典型行业场景：离焦镜片 / OK 镜验配方案
- **场景标题**：多点离焦镜片验配与禁忌筛查
- **场景描述**：视光师输入患者屈光与双眼视数据，技能按 MPMVA 原则给出离焦镜片验配规范、镜架参数、随访周期，并强制筛查禁忌证（如显性斜视、弱视）。
- **示例问题**：「9 岁，近视 -3.00D/年进展 0.8D，外隐斜 4△，能配新乐学吗？要注意什么？」
- **触发条件**：用户询问「离焦镜片 / OK镜 / 验配 / 禁忌」且提供屈光或双眼视数据。

### 案例 3 — 边界说明：病理性问题转诊 + 数据缺失阻断
- **场景标题**：该转诊就转诊，不瞎猜
- **场景描述**：遇到眼底病变、麻痹性斜视等病理性信号，或数据不足无法匹配诊断时，技能强制给出转诊建议或追问缺失数据，绝不臆测；付费前会先触发微信支付授权。
- **示例问题**：「孩子说看东西有重影，验光单我发你了，还需要查什么？」
- **触发条件**：用户描述复视/斜视/眼底异常，或数据缺失（缺 AC/A、MEM、Flipper 等）。
