## 二、通用金句模板（按使用场景）

### 开头点题型

- 「XX是国之大者，关系国家发展全局和人民根本利益。」
- 「站在新的历史起点上，XX既面临难得机遇，也面临严峻挑战。」
- 「XX是一篇大文章，需要久久为功、持续用力。」

### 论证分析型

- 「XX不是一朝一夕之功，需要以"功成不必在我"的境界和"功成必定有我"的担当，一茬接着一茬干。」
- 「XX的关键在于"实"——出实招、求实效，不搞花架子、不摆虚把式。」
- 「XX的成效如何，最终要由人民群众来评判，要看人民群众的获得感、幸福感、安全感是否真正得到了提升。」

### 对策建议型

- 「要坚持问题导向，从群众最急最忧最盼的问题入手，精准施策、靶向发力。」
- 「要以改革创新的办法破解难题，以制度机制的建设巩固成果，实现XX的长效长治。」
- 「做好XX工作，关键在党、关键在人、关键在落实。」

### 结尾升华型

- 「征途漫漫，惟有奋斗。XX任重道远，需要我们以永不懈怠的精神状态和一往无前的奋斗姿态，书写新时代的精彩答卷。」
- 「蓝图已经绘就，号角已经吹响。让我们以更加坚定的信心、更加昂扬的斗志、更加务实的作风，把XX的宏伟目标一步步变为美好现实。」

## 五、排比句式模板库

以下为通用排比句模板，使用时将 `[XX]` 替换为具体主题词：

### "是…是…是…"式

```
[主题词]，是XX的基石，是XX的引擎，是XX的底色。
```

### "从…到…"式

```
从[起点]到[现状]，变的是[表象]，不变的是[本质]；
从[旧态]到[新态]，变的是[方式]，不变的是[初心]。
```

### "需要…需要…需要…"式

```
做好[主题]工作，需要以改革创新的勇气破难题，
需要以久久为功的韧劲抓落实，
需要以人民至上的情怀守初心。
```

### "没有…就没有…"式

```
没有[条件A]，就没有[结果A]；
没有[条件B]，就没有[结果B]；
没有[条件C]，就没有[结果C]。
```

### "既是…也是…更是…"式

```
[主题]既是一场攻坚战，也是一场持久战，
更是一场必须打赢的硬仗。
```

## 七、金句与案例使用技巧参考

> 以下技巧在生成"使用技巧"板块时参考选用，并根据具体主题做适配改写。

### 通用技巧

1. **金句的使用位置有讲究**：政策金句适合放在文章开头（引出主题）和结尾（升华主题）；古文引用适合放在分论点开头（增加文化底蕴）；排比句式适合放在论述段落中增强气势。

2. **案例使用要"精"不要"多"**：一篇文章用2-3个案例即可，关键是用到位——先讲案例事实，再提炼启示，最后回扣论点。切忌"堆砌案例"而缺乏分析，申论考的是分析能力不是背诵能力。

3. **金句与案例要"配对"使用**：每个案例最好搭配一句对应主题的金句作为收束，形成"案例+金句+启示"的完整论证链条，既有事实支撑又有理论高度。

4. **注意金句的"原创性"**：政策原文和古文引用可以原样使用，但"申论写作常用精炼表述"类金句可以根据题目灵活改写，避免与他人雷同。改写时保持句式结构和核心意思不变即可。

5. **案例要"新鲜"**：尽量使用近3年的新案例，避免使用过于陈旧的案例。如果案例有最新进展（如品牌价值更新、获得新荣誉等），在文中提及能体现你对时事的关注。

6. **古文引用要"自然化用"**：不要生硬地把古文塞进去，最好用"古人云……""正如XX所言……"等过渡句衔接，或者化用其意而不照搬原文，做到"你中有我、我中有你"。

### 主题专属技巧

| 主题 | 专属技巧 |
|------|---------|
| 乡村振兴 | 以"五个振兴"为框架组织分论点：产业是基础、人才是关键、文化是灵魂、生态是底色、组织是保障 |
| 科技创新 | 注意区分"自主创新"和"开放合作"两个维度，避免只谈一面；用"卡脖子"案例时要有正面突破的呼应 |
| 基层治理 | "三治融合"（自治法治德治）是万能框架；枫桥经验案例要突出"新时代"发展 |
| 生态文明 | "两山"理论是核心金句，几乎万能；案例选择注意"保护"与"发展"的辩证关系 |
