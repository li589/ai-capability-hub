## 使用场景

当用户提出以下类型需求时，应该触发此技能：

- **Word 文档排版**：撰写报告、排版标书、制作简历、编辑论文、设计公文模板、目录生成、页眉页脚设置
- **Excel 数据处理**：表格美化、公式计算、数据透视表、图表制作、条件格式、数据验证、打印设置
- **PPT 演示制作**：制作汇报PPT、路演材料、培训课件、幻灯片排版、动画设置、演讲备注

## 核心原则

### 1. 先理解需求场景，再选工具

- 正式公文 → Word 排版
- 数据报告 → Excel + Word 协同
- 演示汇报 → PPT
- 确定文档用途（打印/电子版/投影展示）之后再动手，输出格式和排版策略完全不同

### 2. 样式驱动设计，而非手动格式

- 始终使用样式（Style）而非手动加粗/改字号/改颜色
- 修改一处样式 = 更新全文，手动格式改 50 处还容易漏
- 正文、标题、列表使用不同的样式层级，便于后期生成目录和自动编号

### 3. 模板复用优于从零开始

- 对于重复性工作（周报、月报、标书），建立模板一次，后续只替换内容
- 模板包含预设样式、页眉页脚、页码、配色方案，大幅减少重复劳动
- 在 PPT 中，使用母版（Slide Master）统一管理字体、配色和占位符

### 4. 排版三要素：对齐、对比、一致性

- **对齐**：同一层级的内容对齐，避免随意拖拽
- **对比**：标题/正文、重点/常规通过字号、颜色、加粗区分
- **一致性**：全文同级别标题格式一致，段落间距一致，图表风格一致

### 5. 协同意识：数据→表格→图表→报告

- Excel 做数据整理和计算
- 图表在 Excel 中生成后嵌入 Word/PPT
- Word 做最终报告排版
- PPT 从 Word 大纲一键生成幻灯片
- 数据源变更时，只需更新 Excel，关联的图表和报告自动刷新

## Word 文档排版

### 快速排版流程

1. **清理原始格式**：粘贴文本时选"只保留文本"（Ctrl+V → 粘贴选项 → 只保留文本），清除冗余格式
2. **应用样式**：标题 1/2/3 → 正文 → 逐级套用
3. **调整样式**：修改样式 → 全文自动更新
4. **生成目录**：引用 → 目录（基于已应用的标题样式自动生成）
5. **页眉页脚**：插入 → 页眉/页脚 → 页码
6. **打印预览**：确认分页正确、无孤立行

### 常用快捷键

| 操作 | 快捷键 |
|------|--------|
| 清除格式 | Ctrl + Space（清除字符格式），Ctrl + Q（清除段落格式） |
| 增加/减少缩进 | Ctrl + M / Ctrl + Shift + M |
| 段落设置 | Alt + H, PG |
| 样式面板 | Alt + Ctrl + Shift + S |
| 转到页眉/页脚 | Alt + N, H / Alt + N, F |

### 排版要点

**标题层级**：
- 标题 1：文档最高层级（章/部分），自动入目录
- 标题 2：次级标题（节），缩进一级
- 标题 3：小节标题，缩进两级
- 不要跳级使用（标题 1 后直接标题 3）

**段落设置**：
- 正文首行缩进 2 字符（段落 → 特殊格式 → 首行缩进）
- 标题和列表段前/段后间距统一
- 行距：正式文档 1.25-1.5 倍行距，草稿可单倍行距
- 避免使用连续空行代替段间距（应通过段落间距设置）

**页面设置**：
- 页边距：Word 默认即可，正式文档上下 2.54cm，左右 3.17cm
- 装订线位置和宽度按需设置
- 分节符用于不同章节独立页码/页眉

**表格美化**：
- 套用表格样式（设计 → 表格样式）
- 标题行加粗，斑马纹行便于阅读
- 表头和正文使用不同的样式区分

### 自动化技巧

- **域代码**：插入自动更新的日期、页码、文件路径
- **邮件合并**：批量生成通知书、证书、标签
- **交叉引用**：引用图表编号、章节号，内容变化时自动更新
- **多级列表**：关联标题样式，实现"第1章 1.1 1.1.1"自动编号

## Excel 数据处理

### 表格高效操作

**快捷键**：

| 操作 | 快捷键 |
|------|--------|
| 跳到数据末尾 | Ctrl + 方向键 |
| 选择连续区域 | Ctrl + Shift + 方向键 |
| 快速求和 | Alt + = |
| 插入当前日期 | Ctrl + ; |
| 插入当前时间 | Ctrl + Shift + ; |
| 重复上一步操作 | F4 |
| 切换绝对/相对引用 | F4（公式编辑时） |
| 创建表格 | Ctrl + T |
| 数据透视表 | Alt + N, V |

**表格设计原则**：
- 第一行为列标题，不要合并单元格做标题
- 一列一种数据类型（避免文字数字混排）
- 原始数据和计算分开存放
- 使用 Excel 表格（Ctrl+T）而非普通区域 —— 公式自动扩展，筛选自动包含新行

### 常用公式分类

**查找引用**：
```
VLOOKUP(lookup_value, table_array, col_index, [range_lookup])
XLOOKUP(lookup_value, lookup_array, return_array)       -- 推荐，更灵活
INDEX(array, row_num, [column_num])
MATCH(lookup_value, lookup_array, [match_type])
```

**逻辑判断**：
```
IF(logical_test, value_if_true, value_if_false)
IFS(logical_test1, value1, logical_test2, value2, ...)  -- 多条件
IFERROR(value, value_if_error)
```

**文本处理**：
```
LEFT(text, num_chars)   /   RIGHT(text, num_chars)
MID(text, start_num, num_chars)
TEXT(value, format_text)                                 -- 格式化数字/日期
TEXTJOIN(delimiter, ignore_empty, text1, [text2], ...)
```

**日期计算**：
```
DATEDIF(start_date, end_date, "Y")                       -- 年差
NETWORKDAYS(start_date, end_date, [holidays])            -- 工作日
EOMONTH(start_date, months)                              -- 月末日期
```

### 数据透视表快速指南

1. 选中数据区域 → 插入 → 数据透视表
2. 行标签：分类字段（如部门、月份）
3. 列标签：需要对比的分类
4. 值：需要汇总的数值字段
5. 筛选器：全局筛选条件

常见字段配置：
- 计数项 → 改值字段设置为"求和"或"平均值"
- 日期字段 → 自动分组（年/季/月）
- 值显示方式 → 总计的百分比、差异、排名

### 图表制作建议

- **柱状图**：对比各分类的数值大小（如各部门销售额）
- **折线图**：展示数据随时间的趋势变化
- **饼图**：展示各部分占比（不超过 5 项）
- **条形图**：分类名称较长时替代柱状图
- **散点图**：展示两个变量的相关性

图表美化要点：
- 删除默认图例若只有一个系列
- 调整坐标轴起始值避免误导性缩放
- 数据标签清晰可读
- 配色保持专业统一（建议使用公司或主题配色）

## PPT 演示制作

### 制作流程

1. **确定结构**：先写大纲（标题列表），再填充内容
2. **选择模板**：使用公司模板或创建统一母版
3. **逐页制作**：标题页 → 目录页 → 章节页 → 内容页 → 总结页
4. **统一美化**：全局统一字体、配色、间距
5. **动画设置**：克制使用，仅在需要强调时添加
6. **检查备注**：演讲备注写好讲稿要点

### 页面类型与设计要点

**封面页**：
- 标题 + 副标题 + 演讲人 + 日期
- 背景简洁，突出主题

**目录页**：
- 3-5 个核心章节
- 可配合图标增强视觉

**章节过渡页**：
- 放大章节标题
- 提示听众进入新模块

**内容页**：
- 一个页面一个核心观点
- 标题提炼结论，正文提供支撑
- 能上图别写字，能列表别用段落
- 文字控制在 7 行以内，每行不超过 15 字

**总结页**：
- 回顾核心要点
- 下一步行动或 Q&A 提示

### 排版规范

- **字体**：标题微软雅黑/思源黑体，正文等线/微软雅黑 Light；正文字号不小于 18pt
- **配色**：全文不超过 3 种主色（主色/辅色/强调色），使用取色器统一
- **间距**：标题和正文间距明确，列表项间距一致
- **图片**：统一大小、对齐，使用图片样式保持风格一致
- **SmartArt**：用于流程、层次、循环关系的可视化

### 动画使用原则

- **入场动画**：逐条出现（淡入/擦除），配合演讲节奏
- **强调动画**：仅用于需要特别关注的数据或关键词
- **退场动画**：一般不使用
- **翻页动画**：全文统一，建议使用淡入淡出或推入
- **核心原则**：动画服务于内容表达，不要为了动画而动画

### 与 Word 协同

- Word 大纲直接导入 PPT：文件 → 导入 → 大纲
- 粘贴 Excel 图表时选"保留源格式和链接数据"
- 从 Word 复制文本用"保留源格式"避免字体错乱

## 三件套协同技巧

### 数据流转链路

```
Excel 数据整理 → Excel 图表生成 → 图表嵌入 Word/PPT（保持链接）
Word 撰写报告 → 大纲导出 → PPT 自动生成幻灯片
PPT 演示完成 → 讲义导出 → Word 打印版讲义
```

### 常见协作场景

- **月度报告**：Excel 出数据图表 → Word 出文字分析报告
- **项目汇报**：Excel 跟踪项目进度 → PPT 做演示
- **标书制作**：Word 排版 + Excel 报价单嵌入
- **培训材料**：Word 编写讲义 → PPT 提炼课件

---

## 常见陷阱

- Word 中混用手动格式和样式 → 修改时一致性问题，应统一使用样式
- Excel 中合并单元格 → 妨碍排序、筛选和透视表，用"跨列居中"替代
- PPT 中一页塞入过多内容 → 重点被稀释，一页只讲一个核心观点
- 图表直接截图粘贴 → 数据无法更新，应嵌入可编辑的图表对象
- 忽略打印设置 → 屏幕上看很好，打印出来分页错乱，始终先打印预览
