# 办公高效技能

熟练使用 Word、Excel、PPT 三件套，快速完成文档排版、数据处理和演示文档制作。

## 技能定位

本技能面向日常办公场景，帮助快速完成：
- **Word 文档排版**：报告、标书、论文、公文等长文档的专业排版
- **Excel 数据处理**：表格美化、公式计算、数据分析、图表制作
- **PPT 演示制作**：汇报材料、路演 PPT、课件等专业演示设计

## 核心能力

| 模块 | 能力 | 关键技能点 |
|------|------|-----------|
| Word | 文档排版 | 样式系统、目录生成、页眉页脚、邮件合并、域代码、长文档管理 |
| Excel | 数据处理 | 公式函数、数据透视表、条件格式、图表制作、数据验证、打印设置 |
| PPT | 演示制作 | 母版管理、图文排版、配色方案、图表展示、动画控制、演讲备注 |

## 三件套协同

本技能强调三个软件之间的数据流转：

```
Excel 数据整理 → Excel 图表生成 → 图表嵌入 Word/PPT（保持链接）
Word 撰写报告 → 大纲导出 → PPT 自动生成幻灯片
PPT 演示完成 → 讲义导出 → Word 打印版讲义
```

## 使用方式

当提出涉及以下内容的需求时，本技能会被自动激活：

1. **Word 相关**："排版这份报告"、"做目录"、"弄个标书模板"、"设置页码"
2. **Excel 相关**："整理这份数据"、"做个数据透视表"、"画个图表"、"公式计算"
3. **PPT 相关**："做个汇报 PPT"、"美化这页幻灯片"、"弄个演示模板"
4. **协同场景**："把 Excel 图表放到 Word 里"、"从 Word 大纲生成 PPT"
