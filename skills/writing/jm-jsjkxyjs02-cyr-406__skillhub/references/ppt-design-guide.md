# PPT 演示文稿设计指南

## 演示结构模板

### 标准汇报结构（10-15 页）

```
1. 封面页                  — 标题 + 副标题 + 演讲人
2. 目录页                  — 3-5 个章节概览
3. 项目背景 / 现状分析     — 1-2 页
4. 核心发现 / 关键数据     — 2-3 页（数据页 + 分析页）
5. 方案建议 / 解决方案     — 2-3 页
6. 实施计划 / 时间线       — 1-2 页
7. 资源需求 / 风险         — 1 页
8. 总结与下一步            — 1 页
9. Q&A / 附录              — 1 页
```

## 幻灯片母版使用

### 为什么要用母版

- 统一所有幻灯片字体、配色、背景、页脚
- 修改母版 = 全局生效，无需逐页修改
- 预设多种版式（标题页、内容页、空白页、图片页）

### 操作步骤

1. 视图 → 幻灯片母版
2. 左侧列表最上方为总母版，下方为各版式
3. 设置总母版字体主题、背景色
4. 为不同版式设置不同的占位符布局
5. 关闭母版视图，新建幻灯片即可选择版式

### 母版设置要点

- 总母版设置：统一字体主题、背景样式、配色方案
- 版式设置：调整占位符大小和位置（标题框、文本框、图片框）
- 页脚设置：日期、页码、公司名称尽量放在母版中
- 不要在单张幻灯片中覆盖母版设置，除非确实需要

## 图文排版布局

### 常见页面布局

| 布局类型 | 适用场景 | 图文比例 |
|----------|----------|----------|
| 全屏图+叠字 | 封面、章节过渡 | 图 100% + 文字叠加 |
| 左图右文 | 产品展示、案例说明 | 50%-60% 图 |
| 左文右图 | 数据分析、概念解释 | 40%-50% 图 |
| 上图下文 | 流程图、截图展示 | 60%-70% 图 |
| 三列/四列 | 并列对比、团队介绍 | 均分 |
| 全文字 | 条款、引用、代码 | 0% 图 |

### 对齐技巧

- 使用参考线（视图 → 参考线）辅助对齐
- 多个对象选中后：格式 → 对齐 → 左对齐/居中对齐/顶端对齐
- 均匀分布：对齐 → 横向分布/纵向分布
- 图片统一大小：选中多张图片 → 格式 → 高度/宽度输入统一数值

## 配色方案

### 安全配色推荐

| 风格 | 主色 | 辅色 | 强调色 |
|------|------|------|--------|
| 商务蓝 | #2B579A | #E8EFF7 | #F4B942 |
| 深色科技 | #1E1E1E | #F5F5F5 | #00BCF2 |
| 清新绿 | #2E7D32 | #E8F5E9 | #FF6F00 |
| 简约灰 | #424242 | #FAFAFA | #1565C0 |

### 配色原则

- 全文不超过 3 种主色
- 背景色和文字色保持高对比度（浅底深字或深底浅字）
- 强调色仅用于关键数据或重点，不宜大面积使用
- 使用取色器（吸管工具）从公司 Logo 中提取配色

## 图表数据展示

### 数据类型 vs 图表选择

| 数据类型 | 推荐图表 | 不推荐 |
|----------|----------|--------|
| 趋势变化 | 折线图、面积图 | 饼图 |
| 占比构成 | 饼图（≤5项）、环形图 | 折线图 |
| 排名对比 | 条形图（横向） | 饼图 |
| 多维度对比 | 簇状柱形图 | 雷达图（不易读） |
| 相关性 | 散点图 + 趋势线 | 饼图 |
| 流程步骤 | SmartArt 流程 | 纯文字描述 |

### 图表在 PPT 中的处理

- **推荐**：Excel 图表复制 → PPT 中选"保留源格式和链接数据"
- **可选**：嵌入 Excel 对象（可双击编辑源数据）
- **避免**：截图粘贴（数据无法更新，缩放会模糊）

## 动画与切换

### 动画分类

| 类型 | 用途 | 常见效果 |
|------|------|----------|
| 入场 | 元素出现时 | 淡入、擦除、飞入（从左侧） |
| 强调 | 吸引注意 | 脉冲、变色、陀螺旋 |
| 退出 | 元素消失 | 淡出、消失 |
| 路径 | 沿路径移动 | 直线、弧形、自定义路径 |

### 动画使用准则

- 全文使用 1-2 种入场效果即可（推荐：淡入和擦除）
- 动画时长控制在 0.3-0.75 秒
- 使用"与上一动画同时"或"在上一动画之后"而非"单击时"
- 用动画强调数据变化（如数字递增、柱状图增长）
- **不要**：每页都用不同动画、文字逐字飞入、过度旋转缩放

## 演讲备注使用

- 每页幻灯片都应填写备注
- 备注内容：该页的核心信息、关键数据、演讲提示
- 备注不是脚本逐字稿，而是关键词和框架
- 使用演示者视图（Alt + F5）排练时只看到备注
- 讲义导出时备注可一并打印（文件 → 导出 → 创建讲义）

## 常见错误与修正

| 问题 | 原因 | 修正方法 |
|------|------|----------|
| 文字太小 | 正文字号 < 16pt | 控制每页字数，字号不低于 18pt |
| 图片变形 | 未锁定纵横比缩放 | 按住 Shift 缩放或锁定纵横比 |
| 配色混乱 | 每页用不同颜色 | 使用母版统一配色 |
| 信息过载 | 一页塞了太多内容 | 拆成多页，一页一个核心观点 |
| 对齐混乱 | 手动拖拽不整齐 | 使用对齐工具 + 参考线 |
| 字体丢失 | 使用了特殊字体 | 使用常见字体或嵌入字体 |
| 图表模糊 | 截图图表 | 重新嵌入可编辑图表对象 |
