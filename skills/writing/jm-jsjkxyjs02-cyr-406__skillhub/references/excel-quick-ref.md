# Excel 高效操作速查

## 数据清理常用技巧

### 快速处理

| 问题 | 解决方案 |
|------|----------|
| 删除多余空格 | `=TRIM(A1)` 或 查找替换（Ctrl+H） |
| 统一大小写 | `=UPPER(A1)`, `=LOWER(A1)`, `=PROPER(A1)` |
| 去除重复值 | 数据 → 删除重复值 |
| 拆分合并列 | 数据 → 分列 或 `=TEXTSPLIT()` |
| 合并多列 | `=A1&B1`, `=TEXTJOIN(" ",TRUE,A1,B1)` |
| 查找替换通配符 | `~` 转义（如查找 `*` 输入 `~*`） |
| 快速填充 | Ctrl + E（智能识别模式并填充下方单元格） |

## 高级公式组合

### INDEX + MATCH（VLOOKUP 的灵活替代）

```
=INDEX(返回列, MATCH(查找值, 查找列, 0))
```

优点：支持向左查找，插入/删除列不影响公式

### SUMPRODUCT 多条件求和

```
=SUMPRODUCT((条件区域1=条件1)*(条件区域2=条件2)*求和区域)
```

### 动态数组公式（Office 365）

```
=FILTER(数据区域, 条件区域=条件, "无结果")    -- 筛选
=SORT(数据区域, 排序列, 排序方向)               -- 排序
=UNIQUE(数据区域)                               -- 去重
=SEQUENCE(行数, 列数, 起始值, 步长)             -- 生成序列
```

## 数据验证（下拉菜单）

1. 选中目标单元格 → 数据 → 数据验证 → 设置
2. 允许 → 序列
3. 来源输入选项（逗号分隔）或选择单元格区域
4. 可设置输入提示和出错警告

## 条件格式使用场景

| 场景 | 操作路径 |
|------|----------|
| 高亮重复值 | 条件格式 → 突出显示单元格规则 → 重复值 |
| 前 N 项/后 N 项 | 条件格式 → 最前/最后规则 |
| 数据条（进度条效果） | 条件格式 → 数据条 |
| 色阶（热力图） | 条件格式 → 色阶 |
| 图标集（红绿灯） | 条件格式 → 图标集 |
| 用公式自定义规则 | 条件格式 → 新建规则 → 使用公式确定要设置格式的单元格 |

### 常用自定义公式规则

```
=ISNUMBER(SEARCH("关键词", A1))    -- 单元格包含特定文本
=A1>B1                             -- 两列对比
=AND(A1>100, A1<200)               -- 数值在区间内
=$A1="已完成"                       -- 基于另一列的值（注意列绝对引用）
```

## 数据透视表进阶

### 字段设置

- **值字段设置** → 值显示方式：可设为"总计的百分比"、"列汇总的百分比"、"差异"、"运行总和"等
- **分组**：日期自动分年/季/月；数值可指定步长分组
- **切片器**：插入切片器作为可视化筛选器，可同时关联多个透视表
- **日程表**：专门用于日期范围筛选的交互控件

### 计算字段和计算项

- 分析 → 字段、项目和集 → 计算字段（基于已有字段的公式生成新字段）
- 注意：计算字段在总计时可能产生重复计算

## 图表进阶

### 常用组合图表

需要在一张图中展示两种度量（如金额和完成率）时：
1. 选中数据 → 插入图表 → 所有图表 → 组合
2. 一个系列用柱状图，另一个系列用折线图
3. 勾选"次坐标轴"让两个度量各自有独立的轴

### 迷你图（Sparkline）

插入 → 迷你图 → 在单元格内显示数据的趋势线
- 折线图：展示趋势
- 柱状图：展示对比
- 盈亏图：展示正负

## 打印设置

| 需求 | 设置位置 |
|------|----------|
| 每页都打印标题行 | 页面布局 → 打印标题 → 顶端标题行 |
| 缩放到一页宽 | 页面布局 → 宽度 → 1 页 |
| 居中打印 | 页面设置 → 页边距 → 居中方式 → 水平 |
| 添加页眉页脚 | 页面设置 → 页眉/页脚 |
| 设置打印区域 | 页面布局 → 打印区域 → 设置打印区域 |
| 分页预览调整 | 视图 → 分页预览（拖拽蓝色分页线） |

## 模板文件结构建议

```
日报模板/
├── 数据录入表   (原始数据，不要在这里做计算)
├── 计算表       (公式和中间计算，隐藏或保护)
├── 报表输出     (数据透视表+图表，打印区域)
└── 参数配置     (下拉选项源、阈值、VLOOKUP表)
```

- 使用单元格样式区分：蓝色背景=输入区，灰色背景=公式区，白色=输出区
- 保护公式单元格：选中输入区取消锁定 → 审阅 → 保护工作表
