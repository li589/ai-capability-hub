# Word 排版深度指南

## 样式系统详解

### 内置样式层级

| 样式 | 用途 | 默认快捷键 |
|------|------|-----------|
| 正文 | 绝大多数内容 | Ctrl + Shift + N |
| 标题 1 | 章/一级标题 | Alt + Ctrl + 1 |
| 标题 2 | 节/二级标题 | Alt + Ctrl + 2 |
| 标题 3 | 小节/三级标题 | Alt + Ctrl + 3 |
| 列表段落 | 带项目符号/编号的段落 | — |
| 引用 | 引用块内容 | — |

### 创建新样式

1. 在样式面板（Alt + Ctrl + Shift + S）中点击"新建样式"
2. 设置名称、样式类型（段落/字符/链接段落和字符）
3. 设定格式：字体、字号、颜色、段落间距
4. 选择"基于该模板的新文档"以保存到模板

### 修改现有样式

1. 右键样式 → 修改
2. 点击左下角"格式"可以设置字体、段落、制表位、边框等
3. 勾选"自动更新"后，手动调整任意应用该样式的段落会自动更新样式定义（慎用）

## 目录操作

### 插入目录

引用 → 目录 → 自动目录（基于标题 1/2/3 自动生成）

### 自定义目录

1. 引用 → 目录 → 自定义目录
2. 调整显示层级（默认 3 级）
3. 修改目录样式（目录 1/2/3 的字体和格式）
4. 制表符前导符（点线/实线/无）

### 更新目录

- 右键目录 → 更新域 → 更新整个目录
- 快捷键：F9（选中目录后）

## 页眉页脚与页码

### 奇偶页不同

- 页面设置 → 版式 → 勾选"奇偶页不同"
- 奇数页页眉：文档标题
- 偶数页页眉：章节名（需链接到章节标题）

### 从正文开始编号

1. 在封面和目录后插入分节符（布局 → 分隔符 → 分节符 → 下一页）
2. 双击页脚区域 → 取消"链接到前一节"
3. 插入页码 → 设置起始页码为 1

## 邮件合并批量操作

适用场景：批量制作证书、工资单、录取通知书、邀请函

### 步骤

1. 准备数据源：Excel 表格（第一行为字段名）
2. Word 中：邮件 → 选择收件人 → 使用现有列表
3. 插入合并域：逐个插入姓名、部门、金额等
4. 预览结果：检查数据映射是否正确
5. 完成并合并：编辑单个信函/打印/发送电子邮件

## 自动化与域代码

### 常用域代码

| 域代码 | 功能 |
|--------|------|
| `{ DATE \@ "yyyy年M月d日" }` | 插入当前日期，指定格式 |
| `{ PAGE } / { NUMPAGES }` | 当前页码 / 总页数 |
| `{ FILENAME \p }` | 文件路径+名称 |
| `{ TOC \o "1-3" }` | 目录，显示 1-3 级标题 |

### 域代码操作

- 插入：Ctrl + F9 插入空白域，手动输入代码
- 更新：选中后按 F9
- 切换显示：Alt + F9（显示域代码/结果切换）
- 锁定/解锁：Ctrl + F11 / Ctrl + Shift + F11

## 长文档管理

- **导航窗格**：视图 → 导航窗格，通过标题快速跳转
- **大纲视图**：视图 → 大纲，便于拖动重排章节顺序
- **主控文档**：视图 → 大纲 → 显示文档，将多个文档合并管理
- **书签**：插入 → 书签，长文档内快速定位
- **交叉引用**：引用 → 交叉引用，引用图表编号、章节号

---

## 打印注意事项

- 打印前始终先打印预览（Ctrl + F2）
- 检查是否有孤立行（段落在两页间只有一行）
- 表格跨页时设置标题行重复（表格工具 → 布局 → 重复标题行）
- 设置打印缩放（无缩放/按纸张大小缩放）
- 正式文档建议转 PDF 后再打印
