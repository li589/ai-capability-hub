# 相关技能与组合用法

本技能（一键改稿多平台分发）与同分类「内容创作方向」下三个姊妹技能构成内容生产+发布前合规协同链：本技能产**多平台分版本文案**（一稿四发），违禁词检测+优化查**文本合规**，短视频内容审核查**画面合规**，直播脚本创作产**单平台深度带货脚本**。四者可独立用，也可组合成"创作→质检"发布前闭环。

## 边界划分

| 维度 | 本技能（一键改稿多平台分发）| 违禁词检测+优化 | 短视频内容审核 | 直播脚本创作 |
|---|---|---|---|---|
| 回答的问题 | 一篇原稿怎么改成四平台可直发的差异化版本（多平台生产）| 这段文案文本能不能发、哪里违规（文本合规）| 这条视频画面能不能发、画面哪里违规（视觉合规）| 一场直播怎么写脚本、话术节奏怎么排（单平台脚本生产）|
| 产物 | 多平台分版本交付物（核心信息拆解 + 四平台分版本 + 自检清单 + 免责声明）| 违禁词检测+优化报告（三层结构+逐条三栏+发布判定）| 视频画面质检报告（画面水印/医疗对比图/AI未标识等视觉项）| 带货直播脚本四件套（整场节奏+单品话术+话术库+合规清单）|
| 跨平台 | 是（一次产四平台）| 否（针对单段文案）| 否（针对单条视频）| 否（针对单场直播，通常单平台）|
| 合规的角色 | 自检清单子集（导流容忍度+违禁词类别提醒，不替代终审）| 主体产出（三层三栏逐条）| 主体产出（视觉项逐条）| 四件套之一的合规约束清单子集 |
| 独立可用 | 是 | 是 | 是 | 是 |

## 原语共享与咬合

- **平台调性规范 ←→ 质检依据**：本技能的 [platform-specs.md](platform-specs.md)（四平台调性/篇幅/导流容忍度）是改写时的适配依据；违禁词检测+优化与短视频内容审核在判定"是否水土不服/导流是否合规"时共享同一套平台规则立论地基——即本技能产出的分版本天然更贴合质检的合规基线。
- **导流容忍度 ←→ 违禁词清单**：本技能的 [compliance-checklist.md](compliance-checklist.md)（导流容忍度表+违禁词类别）与违禁词检测+优化的违禁词分类、直播脚本创作的合规约束清单共享同一广告法+平台规则地基；本技能做"改写时主动规避"，质检技能做"产出后被动复核"。
- **多平台分版本 vs 单平台深度脚本**：本技能的目标是"一稿四发、各平台可直发"，颗粒度是平台级的差异化文案；直播脚本创作的颗粒度是一场直播的话术+节奏+单品，远比本技能的视频号/抖音口播版本深。同一段素材要做直播，用直播脚本创作而非本技能。

## 怎么组合

1. **创作 → 质检发布前闭环（推荐 SOP·多平台分发时）**：
   - 用本技能：一篇原稿改写成四平台分版本（含自检清单初筛）
   - 用「违禁词检测+优化」技能：对每个平台版本的标题/正文/标签/导流文案做文本三层三栏质检复核
   - 若含视频：再用「短视频内容审核」对画面做视觉合规质检
   - 全过 → 可发布

2. **只做多平台改写（用户明确只要分版本、自己复核合规）**：
   - 直接用本技能，四平台分版本 + 自检清单即可
   - 提示用户：发布前建议补做文案/短视频内容审核，尤其敏感行业

3. **直播场景分流**：
   - 要"一篇内容发四平台" → 本技能
   - 要"写一整场直播带货脚本" → 直播脚本创作（不要用本技能的抖音/视频号口播版本凑直播脚本）

## 一句话区分用户该用哪个

- 用户说"帮我把这篇稿子改成小红书/抖音/视频号/公众号四个版本" → 本技能（一键改稿多平台分发）
- 用户说"帮我看这篇笔记/口播稿能不能发、有没有违规词" → 违禁词检测+优化
- 用户说"帮我查这条视频画面有没有问题（水印/对比图/AI未标识）" → 短视频内容审核
- 用户说"帮我写一整场直播脚本/带货话术" → 直播脚本创作
- 用户说"我多平台版本改好了，帮我各平台再审一遍合规" → 本技能产分版本 + 违禁词检测+优化逐平台复核
