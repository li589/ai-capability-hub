# 图片生成提示词指南

提示词应使用自然语言完成生成、语义编辑和多图融合，像给设计师的制作简报，而不是逗号分隔的标签集合。

## 通用公式

只加入与任务有关的字段：

```text
创作一张用于[用途]的[画幅/构图]图片。
主体：[人物/物体的数量、外观、材质、关键身份特征]。
动作与关系：[谁在做什么、主体之间的位置或互动]。
场景：[地点、时间、前中后景、必要道具]。
视觉呈现：[景别、视角、焦段感、构图、留白]。
光色与风格：[主光方向、色调、媒介或明确风格特征]。
必须满足：[精确文字、品牌色、必须保留内容]。
不要出现：[少量具体禁项]。
```

描述“看得见的特征”，少用“高级感、震撼、最好看”等无法验证的词。质量词最多保留一两个，不要重复写高清、8K、杰作、超细节。

## 从零生成

把用户的短请求扩写成具体画面，但不得替用户发明关键创意。若用户没有指定，可做保守默认：单一主体、清晰视觉中心、协调光线、无文字、无水印。

示例：

```text
创作一张 4:5 竖版咖啡新品社交媒体主视觉。画面中央是一只透明玻璃杯装冰拿铁，杯壁有自然冷凝水珠，放在浅灰洞石桌面上。背景为柔和的暖米色，右上方晨光斜射，在桌面形成干净阴影。中近景，略低机位，产品占画面约三分之一，下方和左上方保留排版留白。写实商业摄影，克制的奶油棕配色。不要人物、文字、Logo 或额外饮品。
```

## 单图编辑与风格转换

编辑提示词使用“编辑目标 + 保持清单 + 禁止改动”的结构。不要重新描述整张图，以免模型重绘无关区域。

```text
编辑这张图片：只把人物的白色夹克改成哑光墨绿色飞行夹克，保留原有衣服轮廓和褶皱。人物身份、面部特征、发型、身体姿势、手部、背景、构图、相机视角和光线全部保持不变。不要添加配饰、文字或其他人物。
```

风格转换时区分内容与风格：

```text
将这张照片转换为手绘水粉旅行海报。保留建筑的结构、街道透视、人物位置和原始画幅；只改变材质、笔触、色彩归纳和纸张肌理。不要改变主体数量，不要添加文字。
```

## 多图融合

最多只使用接口允许且确有必要的参考图。为每张图绑定职责，说明最终场景与融合规则：

```text
以第一张图的人物作为唯一角色，保持其脸部、发型和体型；采用第二张图中的蓝色礼服款式与面料；把人物放入第三张图的酒店大堂环境。生成一张统一光源、真实比例、自然接触阴影的全身时尚照片。不要复制参考图中的其他人物或文字。
```

## 文字与版式

必须逐字提供最终文案并约束文字范围：

```text
制作一张 9:16 竖版夏日促销海报。顶部仅出现中文标题“清凉一夏”，中部仅出现“全场第二件半价”，底部仅出现“7月20日—8月5日”。文字逐字准确，不增删标点，不出现其他文字。标题使用粗圆体视觉风格，白字蓝色细描边，居中对齐；促销信息字号次一级。为文字保留干净、低细节背景。
```

Logo 是需要可编辑矢量交付的任务时，不承诺模型直接产出可用商标文件；可生成概念稿，并提醒用户后续矢量化和人工校字。

## 提交前自检

- 主体数量、身份和关系是否明确且无冲突？
- 用户指定的画幅、用途、风格、文案是否完整保留？
- 构图、光线和背景是否服务于主体，而非互相打架？
- 编辑任务是否明确列出必须保持不变的内容？
- 每张参考图是否只有清楚的职责？
- 是否删掉了空泛质量词、重复形容词和冗长负面词表？
- 是否没有擅自添加用户未要求的文字、Logo、人物或品牌？
