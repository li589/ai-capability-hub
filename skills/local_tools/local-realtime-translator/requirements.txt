# PyTorch (CPU build is sufficient: VAD + MeloTTS run on CPU)
# Pinned to 2.4.1: an unbounded `torch>=2.0.0` resolves to the newest release
# (e.g. 2.12.0), whose native DLLs failed to initialize on a clean Intel AIPC
# (`import torch` -> WinError 1114, c10.dll init failure) despite a present
# VC++ runtime. 2.4.1+cpu loads reliably there. torch and torchaudio versions
# must stay in lockstep (2.4.1 <-> 2.4.1).
# Full investigation: docs/torch-winerror-1114调查.md (local-only, gitignored).
--extra-index-url https://download.pytorch.org/whl/cpu
