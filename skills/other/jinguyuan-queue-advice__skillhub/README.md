# 金谷园 AI 排队建议发布说明

## 基本信息

- Slug：`jinguyuan-queue-advice`
- 显示名称：金谷园 AI 排队建议
- 版本号：`1.0.0`
- 计费模式：按调用量计费
- 价格：0.01 元/次
- 服务地址：`POST https://mcp.jinguyuan.cloud/pay/api/play`

## 服务边界

本 Skill 提供一次金谷园 AI 排队建议。用户支付成功后，获得到店建议、排队风险、推荐时间段和简短理由。

本 Skill 不保证现场等待时长，不生成现场排队凭证，不替代门店现场安排。建议仅供参考，实际情况以门店现场为准。

## 输入与输出

输入：

- 用户想了解今天或某个时段是否适合到店；
- 可选门店：北邮店或五道口店；
- 用户的自然语言问题。

输出：

- 到店建议；
- 排队风险；
- 推荐时间段；
- 简短理由；
- 现场情况免责声明。

## 支付与履约

商户后端通过微信 Agent Pay X402 协议完成支付触发。首次请求返回 `HTTP 402 Payment Required` 和 `WeixinPay-Required`，WorkBuddy 支付层完成用户授权支付后，Agent 使用相同请求重试，后端确认支付成功后返回建议内容。

支付失败或未完成时不返回付费建议。已支付但无法履约时，商户后端进入退款处理。

## 审核说明

本 Skill 售卖的是一次 AI 排队建议服务，不售卖现场排队凭证或随机权益。所有排队建议仅用于辅助用户规划到店时间，不构成到店承诺。
