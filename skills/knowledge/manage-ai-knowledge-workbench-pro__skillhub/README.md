# AI 自动知识工作台 Pro

这是 SkillHub SkillPay 的本地优先收费候选：先在用户设备上免费诊断和生成不含路径、名称与正文的结构清单；用户确认并完成 Agent Pay 后，云端固定规则生成一份结构绑定方案；本地确定性引擎据此生成知识索引和离线 HTML 驾驶舱。

> 候选版本：`1.0.2`  
> 默认隐私：结构清单上云、笔记正文不上云  
> 云端模型：首版不调用，模型 Token 为 0  
> 更新：普通增量更新在本地完成，不重复收费

## 使用前提

- 已安装并可正常工作的 Agent 宿主；
- 完整付费方案应用、HTML 构建和增量更新需要 Python 3.10 或以上；
- SkillHub 云端案例沙箱若没有 Python，可使用随包 POSIX Shell 兼容层完成免费预检和结构清单；该兼容层不负责上传、支付或完整构建；
- 用户对目标目录具有合法访问和处理权限；
- 正式候选配置的境内可访问 HTTPS 服务；
- SkillHub Agent Pay 支持的支付环境。

## 典型使用

```text
请把这个授权目录建成 AI 知识工作台。先免费检查环境，向我展示将要发送的脱敏结构清单，得到我确认后再发起 1 次付费方案请求；不要上传笔记正文。
```

AI 会依次完成免费诊断、本地结构清单、稳定请求状态、单次上传确认、服务端返回 402 支付要求、微信 Agent Pay、携带同一 `request_id` 与 `X-Out-Trade-No` 的单次重试、方案交付、本地构建和结果校验。首次与重试的请求体保持一致，订单号只由商户服务创建；首次 402 回执即使在网络中丢失，同一请求号也只能映射到同一订单。任何支付、上传、安装、删除、正文处理或后台服务都必须单独确认。

在 SkillHub 云端案例编辑器中，若 Python 不存在，AI 只运行 `scripts/skillhub_compat.sh` 的 `doctor` 与 `manifest` 两个免费动作。它生成与 Python 主路径相同契约的结构清单并报告 `uploaded=false`；随后必须停止并明确说明完整付费交付仍需要 Python 3.10+，不得把免费兼容预检写成 HTML 已生成。

- `AI-Dashboard/index.html`：离线 HTML 驾驶舱；

## 隐私与安全边界

允许发送的只有文件/目录数量、文件类别数量、大小和深度区间、Obsidian 结构标记等聚合信息。不会发送绝对路径、文件名、标题、正文、标签值、链接值、账号身份、凭证或精确文件哈希。详情见 `references/PRIVACY.md`。

事实源默认只读；HTML 不嵌入原始正文、密钥或绝对源路径；不会自动安装依赖、提权、创建后台常驻项或监听公网地址。

## 计费、失败与退款

计费单元是一份结构绑定的工作台方案。免费预检不收费；首次请求按稳定 `request_id` 幂等创建订单，支付后同一订单重复请求只返回同一方案；网络结果不明时锁定本地状态且不自动重试；普通本地更新不收费。生产商品页必须展示最终单价、失败处理、退款方式、售后和开票安排，详情见 `references/BILLING_AND_REFUND.md`。

## 支付服务契约与验证边界

付费服务采用 SkillHub 开发者 RSA 签名、微信支付 Agent Pay X402 AI 预下单、`WeixinPay-Required` 支付触发返回和 `X-Out-Trade-No` 支付后重试。受控生产验证已覆盖微信下单、支付回调验签、主动查单、方案交付和同订单幂等；每次发布仍必须保证 X402 `skill_info` 中的 Skill ID 与版本和待审包完全一致。

本地确定性工作台已在明确版本的 macOS Codex 和 OpenClaw 路径验证。平台审核通过、公开可发现、外部买家购买、Windows 和 Hermes 兼容仍是独立回执，不因服务验证自动成立。

SkillHub Shell 兼容层只证明免费预检和结构清单在无 Python 的 POSIX 沙箱可执行；完整买家生命周期仍按商品页列出的 Python 运行条件验收。详见 `references/RUNTIME_COMPATIBILITY.md`。
