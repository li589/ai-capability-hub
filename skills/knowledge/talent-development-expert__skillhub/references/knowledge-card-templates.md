# 组织知识沉淀：情境卡片模板 + 标签体系 + 运维规则

> 来源：WORKFLOW.md §5.10
> 用途：项目评估阶段的横向溢出——将项目经验转化为可复用的组织知识资产

## 双通道评估产出模型

| | 通道1：项目级（纵向） | 通道2：组织级（横向） |
|---|---|---|
| 受众 | 本项目干系人 | 其他项目/未来项目干系人 |
| 核心问题 | 下期怎么做得更好？ | 别人能从这里学到什么？ |
| 输出 | 评估报告、ROI分析、改进清单 | 情境卡片、可复用模板、避坑指南 |
| 评估方式 | 柯氏四级+ROI | 模式提炼+标签化+知识库检索 |

## 模板A：成功模式卡

```markdown
# 模式卡：[一句话命名，如"提前30天预发预习材料显著提升出勤率"]

## 基本信息
| 字段 | 内容 |
|------|------|
| 来源项目 | [项目名称] |
| 项目类型 | [新人培训/领导力/专业技能/...] |
| 目标人群 | [角色/职级/人数] |
| 沉淀人 | [姓名] |
| 沉淀日期 | [YYYY-MM-DD] |

## 情境 (Context)
> 当时面临什么情况？为什么必须解决？

## 做法 (Action)
> 具体做了什么？步骤是什么？资源投入多少？

## 结果 (Result)
> 带来了什么改变？量化数据+定性反馈

## 可迁移模式 (Pattern)
> 这件事能抽象成什么通用原则？什么条件下可复用？

## 复用边界
| 维度 | 判断 |
|------|------|
| 适用场景 | [什么场景建议复用] |
| 不适用场景 | [什么场景不建议] |
| 关键前置条件 | [必须具备什么前提] |
| 常见坑 | [别人最容易踩的坑] |

## 标签
`#领导力` `#混合式学习` `#课前激活` `#出勤率提升`
```

## 模板B：避坑指南卡

```markdown
# 避坑：[一句话描述坑，如"线上+线下同步直播，线上学员几乎全部流失"]

## 基本信息
| 字段 | 内容 |
|------|------|
| 来源项目 | [项目名称] |

## 实际影响 + 补救措施 + 预防建议

```

## 三维检索标签体系

### 维度一：能力域
```
#领导力  #专业力  #通用力  #新人融入  #文化价值观
#数字化技能  #合规安全  #创新思维
```

### 维度二：项目阶段
```
#需求诊断  #方案设计  #内容开发  #项目实施  #效果评估
#供应商管理  #预算管理  #干系人管理
```

### 维度三：关键变量
```
#混合式学习  #纯线上  #面授  #行动学习  #导师制  #轮岗
#大规模（>100人） #小班（≤30人） #高管层 #中基层 #一线
#跨部门 #单部门
```

### 检索方式
- 单维度：`#领导力` → 所有领导力项目经验
- 双维度交叉：`#领导力` + `#混合式学习`
- 三维精准：`#领导力` + `#效果评估` + `#高管层`

## 嵌入项目管控

在 §4.1 的12个里程碑中增补 **M12（T+30 ~ T+45）**：
- 项目复盘工作坊 → 填写情境卡片 → 存入组织知识库
- 每个项目至少产出 1 张模式卡 + 1 张避坑卡（如有）
- 与 L3 行为评估并行运行，不增加额外工作量

## 知识库运维规则

| 规则 | 说明 |
|------|------|
| 每个项目至少产出一张模式卡 | 强制沉淀，避免做完就忘 |
| 避坑卡按需产出 | 没有明显坑可以不写，但鼓励主动记录 |
| 卡片版本化 | 同类场景出现新经验时，更新原卡片并标注版本 |
| 季度回顾 | 每季度检视卡片库，合并重复、淘汰过时、提炼更高阶模式 |
| 引用溯源 | 每张卡片必须标注来源项目，可追溯到原始评估数据 |
