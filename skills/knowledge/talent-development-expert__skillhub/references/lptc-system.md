# LPTC 学练考赛四阶闭环系统（详细模板）

> 来源：WORKFLOW.md §4.7
> 用途：项目实施阶段，构建学练考赛四阶双向闭环训战体系

## 人才培育三段论（前置框架）

培养即漏斗筛选：

| 阶段 | 核心命题 | 关键动作 | 淘汰机制 |
|------|---------|---------|---------|
| **选料** | 原材料品质决定成品质量 | 入口评估、能力基线测试、动机筛查 | 不适合者不入池 |
| **培育** | 分阶段实施，难度递增 | 按靶心能力设计阶梯路径 | 每阶段末位淘汰 |
| **评价** | 各阶段评估，优胜劣汰 | 多维评估（学+练+考+赛） | 不达标者降级或出池 |

## 四阶闭环总架构

```
┌──────────────────────────────────────────────────────────────────────┐
│                    学—练—考—赛 四阶闭环                                │
├──────────────┬─────────────┬──────────────┬──────────────────────────┤
│  学(Learn)   │  练(Practice)│  考(Test)    │   赛(Compete)            │
│  ≤10%时间    │  40%时间     │  30%时间     │   最终选拔+竞技展示       │
├──────────────┼─────────────┼──────────────┼──────────────────────────┤
│ 学习地图     │ 师徒带教     │ 通关考核     │ 奥运式集训                │
│ 读书会       │ 教练辅导     │ 资格认证     │ 行动学习路演              │
│ 大讲师       │ 在岗历练     │ 模拟实战     │ 方案竞技/答辩             │
│ 在线课程     │ AI虚拟角色   │ 行为检核     │ 标杆评选/金牌争夺          │
├──────────────┴─────────────┴──────────────┴──────────────────────────┤
│                        双向循环逻辑                                   │
│  正向：以赛促考 → 以考促练 → 以练促学                                 │
│  逆向：学中发现不足 → 倒逼练 → 练中暴露差距 → 倒逼考 → 考中发现问题     │
│        → 倒逼学（自动回流）                                           │
├──────────────────────────────────────────────────────────────────────┤
│                      LPTC时间配比（每层级重复）                        │
│  Learn(学) ≤10% │ Practice(练) 40% │ Test(考) 30% │ Check(评) 20%   │
└──────────────────────────────────────────────────────────────────────┘
```

## 四阶详解

### 学（Learn）| ≤10%

| 方法 | 适用场景 | 关键要点 |
|------|---------|---------|
| 学习地图 | 系统性知识体系构建 | 对靶心能力，明确"学什么→怎么学→学到什么程度" |
| 读书会 | 管理/思维类知识 | 每人输出读书笔记+行动计划 |
| 大讲师 | 标杆经验分享 | 内部高绩效者分享，每人15-20分钟TED式演讲 |
| 在线课程/微课 | 碎片化知识补充 | 每节≤15分钟，嵌入工作流，随学随用 |

### 练（Practice）| 40%

| 方法 | 适用场景 | 关键要点 |
|------|---------|---------|
| 师徒带教 | 新员工/转岗/技能操作 | 师父必须是靶心人才 |
| 教练辅导 | 管理/领导力行为改变 | 教练必须打过仗（§4.4 教练选拔标准） |
| 在岗历练 | 能力内化的主战场 | 真实任务+即时反馈+迭代改进 |
| AI虚拟角色 | 软技能反复练习 | 低风险、可重复、即时评分 |

### 考（Test）| 30%

| 方法 | 适用场景 | 关键要点 |
|------|---------|---------|
| 通关考核 | 技能/流程类 | 逐项考核，不过关不进入下一模块 |
| 资格认证 | 专业/技术/合规类 | 正式认证体系，与晋升/薪酬挂钩 |
| 模拟实战 | 综合能力检验 | 模拟真实业务场景，观察行为而非知识 |
| 行为检核 | 管理/领导力 | 上级+下属+同伴三方观察行为改变 |

### 赛（Compete）| 最终选拔 + 评（Check）20%

| 方法 | 适用场景 | 关键要点 |
|------|---------|---------|
| 奥运式集训 | 高潜/储备干部 | 封闭集训+高强度+排名淘汰 |
| 行动学习路演 | 业务攻坚类 | 小组攻克真实课题→向高管汇报→评委打分 |
| 方案竞技/答辩 | 管理/专业晋升 | 个人/团队方案PK，内外部评委团评审 |
| 标杆评选/金牌 | 全人群激励 | 技能大赛、最佳实践评选、金牌讲师/教练 |

## 双向循环机制

**正向循环**：赛 → 考 → 练 → 学（为了赢比赛→必须通过考→必须练到位→缺什么回去学）

**逆向循环**：学 → 练 → 考 → 学（学中发现不足→倒逼练→练中暴露差距→倒逼考→考中发现问题→倒逼学）

## LPTC 时间配比约束

| 环节 | 占比 | 设计约束 |
|------|:---:|---------|
| 学(Learn) | ≤10% | 每次不超过2小时连续听课；知识输入仅作为练的前置 |
| 练(Practice) | 40% | 主体时间。必须是真实任务/AI模拟/在岗实践 |
| 考(Test) | 30% | 贯穿全程，不只期末。每次考核结果触发"回学"或"升阶"决策 |
| 评(Check) | 20% | 赛后综合评估+教练反馈+IDP更新 |

## 漏斗层级 × LPTC 示例（高潜人才项目）

| 层级 | 学 | 练 | 考 | 评(赛) | 周期 | 留存率 |
|------|:--:|:--:|:--:|:--:|------|:---:|
| 入门（全员） | 2天课程 | 4周在岗 | 第4周考核 | 排名前50%进下一层 | 5周 | 100%→50% |
| 进阶（前50%） | 1天工作坊 | 8周项目 | 第8周路演 | 排名前30%进下一层 | 9周 | 50%→25% |
| 精通（前25%） | 外部研修 | 12周攻坚 | 第12周答辩 | 出池评估 | 12周 | 25%→出池 |

## 四阶质检门禁

| 阶段 | 通过标准 | 未通过动作 | 与下游关系 |
|------|---------|-----------|-----------|
| 学 | 知识测验≥80分 | 补充学习+重测（限1次） | 进入练的前置条件 |
| 练 | 仿真/在岗评分≥3分(5分制) | 教练辅导+针对性复练 | 进入考的前置条件 |
| 考 | 综合考核≥70分+行为指标过关 | 回退至练，聚焦薄弱项 | 进入赛的前置条件（优秀者） |
| 赛 | 评委评分≥75分或排名前50% | 根据表现分配方向 | 进入评，决定人才去向 |

## 实际运行示例（新任管理者项目）

1. 学（1天）：管理基础课+读书会 → 知识测验
2. 练（2周）：带团队实践，教练每月1对1辅导
3. 考（1天集中+持续）：模拟绩效面谈+360行为反馈
4. **分流**：考的优胜者 → 进入赛（路演/答辩），其余回练
5. 赛（1天）：向高管汇报管理实践案例 → 评委打分 → 评奖
6. 评（赛后1周）：综合评分 → 晋升推荐/继续培养/建议出池
