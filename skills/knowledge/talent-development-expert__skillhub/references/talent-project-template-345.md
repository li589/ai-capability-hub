## 三、设计：345 法则应用

### 3.1 三个设计原则自检

- [ ] **对比原则：** 项目设计中是否设置了对比机制（如前后测、班级 PK、标杆对照）来激发动机？
- [ ] **体验原则：** 是否有足够的体验式环节（而非纯讲授）？
- [ ] **输出原则：** 每个学习环节是否都有对应的输出要求？

### 3.2 四个设计思路落地

| 思路 | 落地设计 |
|------|---------|
| **完善认知结构** | 认知宽度：跨模块知识输入（如 HR 学财务/运营）<br>认知深度：专业领域深度研讨<br>认知路径：方法论 + 工具模板 |
| **在解决问题中提升** | 行动学习课题：每人/每组认领一个真实业务问题 |
| **兼顾共性与个性** | 共性：统一课程体系 + 统一课题方向<br>个性：IDP个人发展计划 + 选修模块 |
| **选育用留一体化** | 培养过程设置观察点，输出人才评估报告 |

### 3.3 五条主线选择（选 2-3 条为主线）

请勾选本项目的主线：
- [ ] **认知线：** IDP 计划 + 自我觉察工作坊 + 定期复盘
- [ ] **行动线：** 行动学习课题 + 业务攻坚 + 成果汇报
- [ ] **学习线：** 系统课程 + 读书会 + 案例研讨
- [ ] **辅导线：** 导师制 + 教练辅导 + 定期 1 对 1
- [ ] **评估线：** 360 评估 + 能力测评 + 绩效跟踪

## 四、运营：项目全周期推进

### 4.1 筹备期（开班前 3 个月）

| 事项 | 责任人 | 完成时间 | 交付物 |
|------|--------|---------|--------|
| 项目立项与预算审批 | - | - | 立项书 |
| 学员选拔与确认 | - | - | 学员名单 |
| 导师/讲师资源对接 | - | - | 师资清单 |
| 课程体系与课题方向确定 | - | - | 培养方案 |
| 开班方案设计 | - | - | 开班议程 |
| 物料与平台准备 | - | - | 物料清单 |

### 4.2 开班仪式（第一次集训）

**核心目标：** 点燃 5 条主线，建立班级共识

**建议议程（1.5-2 天）：**

1. 项目启动（高管参与，讲清战略意义）
2. 团队融合（破冰+班级文化共创）
3. 自我认知与 IDP 制定启动（认知线）
4. 行动学习课题破题与开题（行动线）
5. 班委选举与班级制度制定（自治基础）
6. 第一模块课程学习（学习线）

**注意：** 不必把所有线的起点都压在开班，可前置或延后，避免开班过于拥挤。

### 4.3 项目推动（集训之间的持续运营）

**月度运营节奏：**
- 每月 1 次线上/线下集中学习
- 每两周 1 次小组课题研讨
- 每月 1 次导师辅导
- 每月 1 份学习简报/月报

**关键抓手：**
- **班委自治：** 让学员成为项目推动者，而非被动接受者
- **输出倒逼：** 每次学习必有输出（笔记/总结/课件开发）
- **资源整合：** 联动业务部门、高管、外部专家

### 4.4 结业设计（半天）

| 环节 | 对应主线 | 内容 |
|------|---------|------|
| 课题成果汇报 | 行动线 | 各组展示行动学习成果，高管点评 |
| 学习成果展示 | 学习线 | 个人/团队学习产出展示 |
| 成长故事分享 | 认知线 | 学员分享成长与改变 |
| 人才评估反馈 | 评估线 | 项目组输出人才画像与发展建议 |
| 结业仪式 | 整体 | 证书颁发 + 高管寄语 + 下期预告 |

## 五、复盘：项目沉淀

### 5.1 复盘维度

| 维度 | 关键问题 | 结论/经验 |
|------|---------|-----------|
| 目标达成 | 项目目标是否达成？差距在哪？ | - |

| 运营效果 | 学员参与度如何？哪条线推动最顺/最卡？ | - |
| 业务价值 | 对业务绩效产生了什么实际影响？ | - |
| 人才输出 | 选拔出了哪些高潜人才？ | - |

- [ ] 项目全套资料归档（方案/课件/工具/成果）

## 六、学习策略对照表

根据培养内容选择匹配的学习方式：

| 内容类型 | 学习目标层级 | 推荐学习方式 |
|---------|-------------|-------------|
| 事实性知识 | 记忆 → 理解 | 课程、阅读、微课、测试 |
| 概念性知识 | 理解 → 运用 → 分析 | 案例研讨、小组讨论、沙盘 |
| 程序性知识（技能） | 运用 → 分析 → 评价 | 刻意练习、在岗训练、导师反馈 |
| 元认知知识（意识） | 评价 → 创造 | 体验式学习、轮岗、游学、教练 |

## 七、快速自检清单

启动项目前，对照检查：

- [ ] 项目有明确的业务发起人（不是 HR 自嗨）
- [ ] 需求经过战略解码，不是拍脑袋
- [ ] 目标可衡量，有业务关联
- [ ] 选定了 2-3 条主线，不贪多求全
- [ ] 每个学习环节都有输出要求
- [ ] 开班前预留了至少 3 个月筹备期
- [ ] 设计了学员自治机制（班委/小组）
- [ ] 结业不只是上课结束，有成果呈现
- [ ] 复盘和归档纳入了项目计划
- [ ] 培养过程同步做人才观察和选拔
