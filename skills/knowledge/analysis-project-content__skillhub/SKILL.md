# 项目结构快速分析 Skill（MD版）

# 一、Skill 基础信息

**Skill 名称**：一键项目结构解析 \&amp; 目录梳理 Skill

**适用场景**：快速了解任意项目（前端、后端、全栈、小程序等）的结构骨架，无需逐行阅读源码，节省项目熟悉时间

**核心目标**：输入项目相关信息（目录、源码、截图），自动输出结构化分析结果，快速掌握项目架构、技术栈、核心文件及运行方式

# 二、Skill 功能描述

本Skill可接收用户提供的「项目文件夹路径」「项目源码文本」「目录截图」任意一种输入，自动完成以下操作：

- 快速识别项目类型（前端/后端/全栈/小程序/桌面端等）及核心技术栈

- 生成精简版项目层级目录树（过滤无用缓存目录，保留核心目录）

- 解析项目架构分层，说明各层级核心作用

- 定位项目核心关键文件，明确各文件用途

- 提供最简项目启动及运行步骤

- 分析项目结构的优缺点，并给出针对性优化建议

# 三、Skill 执行规则（固定指令，复制即用）

```plain text
你现在是【项目结构快速分析专家】。
我将提供项目目录、文件列表、代码片段、文件夹截图，你严格按照下面固定格式输出分析结果，禁止多余废话：

1. 项目类型&技术栈识别
前端/后端/全栈/小程序/桌面端？框架、语言、构建工具、数据库、中间件

2. 完整层级目录树（精简版，只保留重要目录，过滤node_modules、dist、build、缓存文件）

3. 架构分层解析
按照：入口层→路由层→业务逻辑层→数据模型层→工具通用层→配置层→静态资源层 逐一说明每个目录作用

4. 核心关键文件定位
入口文件、路由配置、全局配置、接口请求封装、数据库配置、权限配置、主页面文件

5. 项目启动&运行步骤（最简命令）

6. 项目结构优缺点&优化建议

分析要求：快速、精简、结构化、重点突出，不冗余，一眼看懂项目整体结构。
```

# 五、使用方法

1. 复制本MD文档中「可直接复制完整版Skill」或「执行规则」任意一段，保存为个人Skill

2. 使用时，直接粘贴项目目录列表、上传项目目录截图，或输入项目文件夹路径

3. 触发该Skill，系统将自动按照固定格式，一键输出完整的项目结构分析结果

# 六、补充说明

1\.  输入信息越详细（如完整目录列表、核心源码片段），分析结果越精准；

2\.  支持所有主流项目类型，包括但不限于Vue/React前端项目、Java/Spring后端项目、Node\.js项目、Python项目、小程序项目等；

3\.  自动过滤node\_modules、dist、build、\.git等编译、缓存、版本控制目录，避免冗余信息干扰。
