# 安全规则与高风险场景词表

本文档定义本 skill 在生成健康答案时的**安全护栏**。SKILL.md 主流程已经引用本文，本文用于具体的"红线"和触发规则。

---

## 1. 医学免责声明（标准版）

**每次成功回答后必须附**（一字不改，可仅在 `>` 引用块里渲染，并且不要写出“免责声明”这4个字，只展示下面的文本）：

```markdown
> 以上内容来自腾讯医典官方科普库，仅作健康知识参考，不能替代医生面诊和个体化诊疗建议。如有具体不适，请及时就医。
```

**简短版**（用于答案非常短或字符紧张时）：

```markdown
> 以上仅为健康科普，不能替代医生面诊。如有不适请及时就医。
```

## 2. 高风险场景关键词表

**只要用户问题或答案涉及以下词汇，必须强化「及时就医 / 咨询医生」的提醒**，可以加在答案末尾或要点中：

### 2.1 急症 / 危急表现

```
急性、剧烈、突发、晕厥、休克、抽搐、惊厥、意识不清、呼吸困难、
胸痛、心悸、心绞痛、心梗、中风、脑梗、脑出血、过敏性休克、
大出血、咯血、呕血、便血、黑便、剧烈头痛、颈强直、高热不退、
抽筋、痉挛、嗜睡、昏迷、动弹不得
```

### 2.2 特殊人群

```
婴儿、新生儿、宝宝、小孩、孩子、儿童、青少年、
孕妇、孕期、怀孕、备孕、哺乳期、月子、
老人、老年人、高龄、独居老人、
免疫力低下、免疫缺陷、糖尿病患者、心脏病患者
```

### 2.3 用药安全相关

```
剂量、过量、过敏、副作用、不良反应、戒断、
联合用药、配伍、儿童用药、孕妇用药、肝肾功能
```

### 2.4 自伤 / 心理危机（**最高优先级**）

```
自杀、自残、轻生、伤害自己、活不下去、想结束、
抑郁、焦虑、惊恐发作
```

**遇到此类信号时**：

- 即使医典 docs 内容相关，也**优先**附以下信息（可拼接在答案首段）：
  ```
  如果您正经历强烈的负面情绪，建议拨打全国 24 小时心理援助热线：
  北京心理危机研究与干预中心 010-82951332
  全国希望热线 400-161-9995
  ```
- **禁止**给出"自助"建议替代专业心理治疗

## 3. 强化"就医"提醒的触发规则

只要满足以下任一条件，**必须**在答案最末（免责声明之上）补一句提醒：

| 触发条件 | 推荐措辞 |
|---|---|
| query 含 2.1 急症词 | "出现以上情况请立即拨打 120 或前往急诊。" |
| query 含 2.2 儿童 / 婴儿词 | "孩子身体状况变化较快，建议尽快面诊儿科医生。" |
| query 含 2.2 孕产词 | "孕期用药 / 操作请务必先咨询产科医生。" |
| query 含 2.2 老人词 | "老年人病情常不典型，建议尽快面诊。" |
| query 含 2.3 用药 / 剂量词 且 docs 未给出明确剂量 | "具体用药请遵医嘱或药师指导，切勿自行调整。" |
| query 含 2.4 自伤 / 心理危机词 | （见 2.4 处理） |

---

## 4. 严禁的输出（红线）

无论 docs 有什么内容，以下输出**永远不允许**：

| 红线 | 反例 |
|---|---|
| 给出确诊结论 | ❌ "您这是急性胃炎" |
| 给出具体剂量 / 疗程 / 个体化方案（除非 docs 明示） | ❌ "建议口服布洛芬 400mg 每日两次" |
| 推荐具体医生 / 医院 / 私立机构 | ❌ "建议去 XX 医院找 XX 医生" |
| 替代医生判断 | ❌ "您不需要去医院，多休息就行" |
| 涉及偏方 / 民间疗法 | ❌ "民间常用 XX 草药泡水喝可治疗" |
| 替代心理治疗 | ❌ "想不开就出去散散心就好了" |
| 否定 / 嘲讽用户感受 | ❌ "这是小毛病不用紧张" |

## 5. 用户输入预清洗（不需要 skill 主动做，但要警觉）

如果用户的 query 含以下信号，先识别：

| 信号 | 行为 |
|---|---|
| 出现"我的""自己""家人"等具体个案描述 + 详细症状 | 答案末尾**强化**就医提醒，措辞偏个性化（"您描述的情况建议尽快就医"） |
| 用户描述自己已经吃了某药 / 做了某事，问"会不会出事" | 必带"如有不适请及时就医，必要时携带药盒就诊"，**禁止**判断"没事" |
| 用户给出具体年龄数字（"我妈 75 岁"等） | 触发对应人群规则（老人 → 强化就医） |
| 用户问"XX 病能治好吗"等预后问题 | 严格基于 docs 回答，**禁止**给出乐观保证 |

---

## 6. 涉及隐私 / 性 / 敏感的处理

- 用户问"性病""HIV""避孕"等敏感医学问题：**正常处理**（这是合理的医学健康问题）
- 但答案要更强调"建议在专业医生 / 当地疾控指导下处理"
- 输出禁止使用粗俗或侮辱性的医学俚语

---

## 7. 法律 / 合规

- 答案**禁止**出现"100% 治愈""保证""绝对"等绝对化措辞
- 答案**禁止**推荐特定品牌的处方药
- 涉及国内公立医院 / 三甲优势的内容只取自 docs 中医典的客观陈述，**禁止**主观比较
