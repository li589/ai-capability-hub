# 外资研报查询

> 用一句话查高盛、大摩、摩根大通等外资机构研报，也可以让 AI 自己调用 MCP 深挖观点、验证数据和寻找分歧。

**这是一个 AI 投研助手，在对话框里说句话就能用。**

---

## 1、能做什么？

| 能力 | 说明 |
|------|------|
| **公司研报** | 返回符合查询条件的完整研报表，并按时间变化和不同分析视角梳理机构观点 |
| **条件查询** | 按公司代码、关键词、行业、标的地区、时间范围分页检索 |
| **语义查询** | 用自然语言找主题相关观点（如 Edge AI、中国 LLM 商业化） |
| **列表速览** | 只要标题 + 日期 + 机构 |
| **观点摘要** | 归纳共识、分歧、评级与目标价 |
| **闲聊 / 深度分析** | 围绕你的问题自主多轮检索：先找研报，再补财务、公告、股价或盈利预测，并主动寻找反方证据 |
| **行业日报** | 某日一个或多个行业 → 行业综合总结 + 重点标的 + 催化展望 + 研报列表 + 逐篇摘要；标题层级分明，研报观点缩进呈现 |
| **全市场日报** | 先拉当日全量，再按行业并行拆分，最后汇总为总文件 |
| **机构日报** | 先拉当日全量，再按高盛、摩根大通、摩根士丹利等发布机构分组；展示机构主题、评级动作与逐篇摘要 |

---

## 2、怎么用？

直接说需求即可，例如：

```
查 NET 近三个月外资研报，并梳理机构观点变化
Cloudflare 外资怎么看 Edge AI
高盛和大摩对铜价有什么分歧，谁的依据更扎实
NET 这轮上涨的逻辑还能成立吗，最大的风险是什么
列出昨天日本相关外资研报标题
外资怎么看中国 AI 基础模型
生成昨天全市场外资研报日报
生成昨天基础化工、有色金属的外资研报日报
生成昨天高盛和摩根大通的机构日报
```

关键信息不足时，助手只追问会实质改变答案的内容。闲聊未指定时间时会按问题采用合理窗口，不会为了形式完整反复追问。

如果只说「运行这个技能」或「外资研报查询」，助手会先展示五类入口：查研报、深度聊观点、行业日报、机构日报、全市场日报。需求已经明确时会直接执行，不重复展示菜单；只缺日期、行业或机构时，也只追问缺失项。

## 3、常用查法

| 你想… | 可以这样说 |
|------|------------|
| 某家公司 | `查 Cloudflare / NET 近三个月外资研报`（默认返回研报表、时间变化和不同视角） |
| 某个主题 | `外资怎么看存储短缺 / HBM 定价` |
| 深挖投资逻辑 | `从外资研报看，NET 的增长逻辑还能成立吗？请找反方证据` |
| 比较机构分歧 | `高盛和摩根士丹利对铜价有什么分歧，分歧来自哪里` |
| 跟踪观点变化 | `最近三个月外资对中国互联网的观点变了吗` |
| 某个地区 | `本周北美相关外资研报` |
| 只要目录 | `列出昨天有哪些外资研报` |
| 要结论 | `把 NET 相关外资观点总结一下` |
| 行业日报 | `生成昨天基础化工、有色金属的外资研报日报` |
| TMT 日报 | `生成昨天 TMT 外资研报日报`（自动展开电子、计算机、通信、传媒） |
| 全市场日报 | `分析 2026-08-09 的全市场外资研报` |
| 单机构日报 | `生成昨天高盛的机构日报` |
| 多机构日报 | `生成昨天高盛、摩根大通、摩根士丹利的机构日报` |
| 全部机构日报 | `生成昨天全部机构的外资研报日报` |

## 4、输出在哪？

- **公司查询 / 列表 / 摘要 / 闲聊**：默认在对话里看，不强制存文件  
- **行业/全市场日报**：会问保存位置；未指定则保存到当前工作空间
- **多行业日报**：同时生成分行业子文件和汇总总文件
- **机构日报**：生成分机构子文件与机构汇总总文件；全量数据只拉取一次

---

## 5、注意事项

- 日报 **只支持单日**；跨日请用条件/语义查询  
- 全市场日报会先用当日全量数据对账，再按行业拆分；跨行业重复研报在总数中会去重  
- 行业标签可能有交叉或串标签，报告会如实提示，不会静默删除  
- 外资接口没有发布机构筛选参数；机构日报先拉全量，再根据机构字段或标题前缀归一分组，不能用地区参数代替  
- 语义检索适合找观点，不保证某一天「一条不漏」  
- 公司研报查询默认使用股票代码完整分页，并用公司名称补漏；研报表之后还会梳理观点随时间的变化、不同机构视角以及共识与分歧  
- 只有标题、机构、日期和链接可核对的报告才会并入公司研报总表；只在正文中顺带提及公司的弱相关材料不会混入核心数量  
- 闲聊模式不会只搜一次就下结论。复杂问题会继续补财务、官方披露、盈利预测或市场表现，并主动查找与主流观点相反的证据  
- 回答会区分「官方事实」「机构预测」「多家机构共识」和「AI 推论」，证据不够时会明确说明  
- 基于标题与摘要归纳时，细节请点开原文  
- **“说人话”是所有输出的硬性标准，不是可选文风。** 模型会先理解英文研报，再用自然中文重新组织结论、原因和含义，而不是逐句翻译或把英文术语替换成中文术语。即使是标题列表，也会同时给出中文易懂标题；英文直译、数字堆砌、缩写墙和空泛行话必须重写  
- 结果仅供研究参考，不构成投资建议
