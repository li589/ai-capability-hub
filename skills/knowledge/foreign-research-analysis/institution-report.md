# 外资机构日报

用于生成单机构、多机构或全部机构的单日外资研报日报。成文同时遵守 [writing-style.md](writing-style.md)。

机构日报复用行业日报的视觉体系，但组织中心从「行业」改成「发布机构」。

---

## 一、接口限制与正确数据链路

`research_query` 没有发布机构筛选参数；`region` 指研报研究对象所属地区，不是发布机构所在地。

因此禁止用 `region` 筛高盛、摩根大通等机构，也不能假设 `keywords` 等于发布机构过滤。

正确流程：

1. 用 `research_query(type="oversea")` 拉取指定日期全量数据并完整翻页。
2. 从返回记录的机构字段或标题前缀识别发布机构。
3. 统一机构别名后分组。
4. 将每个机构的完整数据写入独立中间文件。
5. 每机构一个 subagent 读取中间文件、生成机构子日报；主 agent 只写总览并拼总文件。

常见别名示例：

| 统一名称 | 可识别写法 |
|----------|------------|
| 摩根大通 | JPMorgan、J.P. Morgan、JPM、摩根大通 |
| 摩根士丹利 | Morgan Stanley、MS、摩根士丹利 |
| 高盛 | Goldman Sachs、GS、高盛 |
| 花旗 | Citi、Citigroup、花旗 |
| 瑞银 | UBS、瑞银 |
| 巴克莱 | Barclays、巴克莱 |
| Bernstein | Bernstein |

无法可靠识别的记录进入「其他机构」，不得丢弃。

## 二、范围与并行

| 用户需求 | 执行方式 |
|----------|----------|
| 单机构日报 | 全量拉取后筛出该机构，主 agent 成文 |
| 多机构日报 | 全量只拉一次；分组后每机构一个并行 subagent |
| 全部机构日报 | 全量只拉一次；动态识别当日全部机构并并行分治 |

不得让每个机构子代理重复拉取全市场数据。主 agent 先完成一次数据获取和机构分组，子代理只读指派机构的数据文件。

输出目录：成文前询问用户希望保存的位置；未指定时使用当前工作空间根目录。目录不可写时告知用户并重新询问，不要回退到技能目录。

落盘结构：

```text
{输出目录}/
├── 外资机构日报_YYYY-MM-DD.md
├── 机构分组数据_YYYY-MM-DD/
│   ├── 摩根大通.md
│   ├── 摩根士丹利.md
│   └── 高盛.md
└── 机构日报_YYYY-MM-DD/
    ├── 摩根大通.md
    ├── 摩根士丹利.md
    └── 高盛.md
```

中间数据文件必须保留每篇研报的日期、机构、标题、链接和原始内容。

---

## 三、子代理调度

机构数为 1 时主 agent 直接写；机构数大于等于 2 时并行，单批建议不超过 8 个。

薄调度 prompt：

```text
你是「外资研报查询」子代理，只负责一个发布机构的日报。

依次 Read：
1. {skill_dir}/SKILL.md
2. {skill_dir}/writing-style.md
3. {skill_dir}/institution-report.md

派工：日期={YYYY-MM-DD}；机构={机构}
数据文件：{机构数据文件绝对路径}
写入：{机构子报告绝对路径}

只使用数据文件内的全部研报，N篇必须覆盖N篇，不再调用全市场查询。
结构固定为：机构观点总览 → 自然归纳的主题 → 重点标的 → 评级与预测调整 → 催化展望 → 研报列表 → 逐篇摘要。
严格遵守标题层级与缩进规则。

只返回：
OK | {机构} | {N}篇 | {绝对路径} | {一句话结论}
或 FAIL | {机构} | {原因}
不要写总文件，不要处理其他机构，不要再开 subagent。
```

## 四、层级与缩进

| 层级 | 写法 |
|------|------|
| L1 机构 | `## {机构}（N篇）` |
| L2 大节 | `### 机构观点总览` / `### 研报列表` / `### 逐篇摘要` |
| L3 主题或栏目 | `#### 1｜判断句` / `#### 重点标的` / `#### 评级与预测调整` / `#### 催化展望` |
| L4 标的或动作 | `##### 公司名` / `##### 上调评级` |
| L5 相关研报 | 有序列表；标题单独一行，观点另起一行并缩进 |

相关研报标准写法：

```markdown
1. **[{机构}｜{研报标题}]({链接})**

   {先说机构结论，再写依据、关键数字及其含义。}
```

禁止把主题、标的、评级动作和研报观点全部写成同级加粗正文。

## 五、机构子报告模板

```markdown
## {机构}（{N}篇）

### 机构观点总览

**总判断：** {概括该机构当天最关注什么，整体偏乐观、谨慎还是分化，以及最主要依据}

#### 1｜{主题判断句}

{1-2句解释该机构的核心看法。}

**相关研报观点总结**

1. **[{机构}｜{研报标题}]({链接})**

   {主张、依据、关键数字、这意味着什么。}

#### 2｜{另一主题判断句}

{按材料自然增加或减少主题，不设数量限制。}

#### 重点标的

##### {公司或资产1}

{一句话说明该机构为什么重点关注。}

1. **[{机构}｜{研报标题}]({链接})**

   {评级、目标价、盈利预测和依据。}

#### 评级与预测调整

##### 上调或正面动作

1. **[{公司｜动作}]({链接})**

   {写清评级或目标价从什么水平调整到什么水平，以及调整原因。}

##### 下调或谨慎动作

1. **[{公司｜动作}]({链接})**

   {调整内容及原因。}

> 没有明确评级或预测调整时，写「当日研报未披露明确评级或预测调整」，不得补写。

#### 催化展望

##### {事件或数据}

{时间、验证指标，以及该机构预期什么结果。}

1. **[{机构}｜{研报标题}]({链接})**

   {机构判断及依据。}

### 研报列表

| 序号 | 日期 | 研报标题 | 主要行业 | 主要标的/主题 | 评级或动作 |
|------|------|----------|----------|---------------|------------|
| 1 | YYYY-MM-DD | [标题](链接) | 电子 | 公司/主题 | 增持/未披露 |

### 逐篇摘要

#### 第1篇｜[{机构}｜{标题}]({链接}) · `YYYY-MM-DD`

{忠实跟随原文结构，记录核心结论、依据、关键数字、评级/目标价和风险。}

### 分组口径提示

{说明别名归一、无法识别或疑似机构归属异常；无异常则写“未发现明显机构归属问题”。}
```

要求：

- 主题按当日材料自然归纳，不预设数量。
- 每篇研报至少在一个主题下得到实质覆盖，并进入研报列表和逐篇摘要。
- 重点标的、评级调整和催化不得互相混写。
- 评级与目标价必须保留原值和新值；原文未披露时写「未披露」。
- 同一标的存在不同观点时，在主题或动作栏目中明确解释差异。

## 六、机构总文件

```markdown
# 外资机构日报｜YYYY-MM-DD

**研报唯一数：** {N}篇  
**发布机构数：** {M}家

## 今日机构观点总览

**总判断：** {概括机构间最重要的共识与分歧}

1. **{跨机构共识判断}**

   {哪些机构、共同依据是什么。}

2. **{机构分歧判断}**

   {哪些机构意见不同、差异来自哪里。}

## 机构导航

- [摩根大通（N篇）](机构日报_YYYY-MM-DD/摩根大通.md)
- [摩根士丹利（N篇）](机构日报_YYYY-MM-DD/摩根士丹利.md)
- [高盛（N篇）](机构日报_YYYY-MM-DD/高盛.md)

## 全部研报列表

| 序号 | 日期 | 机构 | 研报标题 | 主要行业 | 评级或动作 |
|------|------|------|----------|----------|------------|
| 1 | YYYY-MM-DD | 摩根大通 | [标题](链接) | 电子 | 增持 |

---

{按机构篇数从多到少拼接机构子报告；每个机构前空一行}
```

总文件中的全部研报列表按研报 ID 或链接去重。机构子报告中的列表只展示该机构研报。

## 七、质量检查

- [ ] 全市场数据只拉取一次且已完整翻页
- [ ] 全量唯一研报数与机构分组并集对账一致
- [ ] 每篇研报只归属一个发布机构；无法识别者进入其他机构
- [ ] 机构名称和别名已统一
- [ ] 标题层级和列表缩进符合 writing-style.md
- [ ] 评级与预测调整保留前后值及原因
- [ ] 研报列表覆盖全部结果
- [ ] 总文件拼接没有标题粘连

---

## 禁止

- 把 `region` 当发布机构所在地
- 用 `keywords=JPMorgan` 冒充机构全量筛选
- 每个机构重复调用全市场查询
- 只按英文简称匹配，导致同一机构被拆成多个组
- 静默丢弃无法识别机构的研报
