# 外资研报查询

多模式查询技能。细则按需 Read 子文件（渐进披露）。

## 最高优先级：所有输出必须说人话

**任何输出在动笔前都必须 Read [writing-style.md](writing-style.md)**，包括纯标题列表、公司研报、查询摘要、闲聊分析、行业日报和机构日报。检索准确但表达晦涩，仍视为不合格输出。

外资研报是英文材料，“说人话”绝不是逐句翻译成中文。必须先理解机构真正表达的判断，再按中文读者熟悉的逻辑重新组织和解释。用户读完后不应再自行翻译英文术语、猜测投行话术或拼接数字之间的关系。

输出前逐段检查：

1. 没看过原文的普通读者能否直接听懂？
2. 是否解释了「为什么」和「这意味着什么」，而不只是罗列数字、评级和术语？
3. 如果把这段话在晨会上念出来，是否自然，还是像英文直译或投行黑话？
4. 是否只是把英文词替换成中文词，却没有解释真实商业含义？

任何一项不通过，必须先重写再输出。用户没有要求时，不得为了显得专业而保留英文缩写、堆砌数据或使用空泛行业词。


| 模式            | 做什么                          | 详规                                                                                    |
| ------------- | ---------------------------- | ------------------------------------------------------------------------------------- |
| **公司研报**      | 完整研报表 + 时间变化 + 不同视角 + 共识分歧   | [company-query.md](company-query.md) + [writing-style.md](writing-style.md)           |
| **条件检索**      | 按时间/个股/关键词/行业/地区分页拉研报        | [reference.md](reference.md)                                                          |
| **语义检索**      | 英文自然语言找主题/观点相关外资研报           | [reference.md](reference.md)                                                          |
| **列表速览**      | 只要标题+日期+机构列表                 | 本文件「输出规范」                                                                             |
| **观点摘要**      | 查完后归纳机构立场、评级、关键论据            | 本文件「输出规范」                                                                             |
| **闲聊 / 深度分析** | AI 自主调用 MCP，多轮补证、找分歧与反方证据后回答 | [query-chat.md](query-chat.md) + [writing-style.md](writing-style.md)                 |

## 模式识别（优先级从高到低）

1. **机构日报**：明确「机构日报」「高盛/大摩/摩根大通日报」「按机构汇总」。先拉单日全量，再按发布机构分组
2. **行业日报**：明确「日报」「生成报告」「完整汇总某天外资研报」。指定行业则做行业日报；未指定行业或明确说全市场则按全部行业分治汇总
3. **列表速览**：「列出」「有哪些」「只要标题」「目录」
4. **公司研报**：明确「查/整理/返回某公司研报」，默认输出完整研报表，并从时间变化和不同视角梳理机构观点
5. **闲聊 / 深度分析**：针对公司或主题追问「为什么」「有何分歧」「逻辑成立吗」「风险是什么」。自主多轮检索后回答
6. **语义检索**：用户明确要找某主题相关研报，而非分析观点
7. **条件检索**：有明确关键词/行业/地区/日期范围，但不属于公司研报标准输出
8. **观点摘要**：在已有结果后要求简短总结，且不需要继续深挖


| 用户说法                            | 模式                        |
| ------------------------------- | ------------------------- |
| `查 Cloudflare / NET 最近外资研报`     | 公司研报：研报表 + 时间变化 + 不同视角    |
| `列出昨天亚太半导体相关外资研报标题`             | 列表速览 + 条件/语义              |
| `外资怎么看中国 AI 基础模型商业化`            | 闲聊 / 深度分析                 |
| `north_america 地区本周外资研报`        | 条件检索（region + 时间）         |
| `昨天基础化工和有色的外资研报日报`              | 多行业日报                     |
| `分析昨天的外资研报`                     | 全市场日报：先拉全量基准，再按行业并行分治     |
| `生成昨天高盛和摩根大通的机构日报`              | 多机构日报：全量拉取一次，再按发布机构分组     |
| `生成昨天全部机构的日报`                   | 全部机构日报                    |
| `外资怎么看 Cloudflare，这个逻辑最大的风险是什么` | 闲聊 / 深度分析：多轮 MCP 检索并查反方证据 |
| `高盛和大摩对铜价有什么分歧`                 | 闲聊 / 深度分析：机构观点对比          |
| `把上面结果总结成观点`                    | 观点摘要                      |


信息不足时只追问会实质改变结果的缺失项。闲聊模式时间模糊时采用 [query-chat.md](query-chat.md) 的默认窗口；日报未给日期时必须追问。

## 技能触发后的引导

### 用户只说「运行这个技能 / 外资研报查询」

使用下面的简洁引导语，不要先问输出路径：

```markdown
外资研报查询已就绪。你可以直接选择：

1. **查研报**：查公司时返回研报表并梳理观点；也可按关键词、行业、地区或主题检索
   - 例：`查 NET 近三个月外资研报，并梳理观点变化`
2. **深度聊观点**：AI 自主查研报、补数据、找分歧和反方证据
   - 例：`外资怎么看 Cloudflare Edge AI，最大的风险是什么`
3. **行业日报**：按一个或多个行业汇总某天研报
   - 例：`生成昨天基础化工、有色金属日报`
4. **机构日报**：按一个或多个发布机构汇总某天研报
   - 例：`生成昨天高盛、摩根大通机构日报`
5. **全市场日报**：某天全量研报按行业分治汇总
   - 例：`生成昨天全市场外资研报日报`

请直接告诉我想查或想聊的问题；日报再补充日期、行业或机构。
```

### 用户需求已经明确

不要重复展示菜单，直接执行。例如用户说「返回昨天有色研报列表」，直接查询，不再询问模式。

### 用户只缺少部分信息

只追问缺失项：

- 日报缺日期：`要生成哪一天的日报？例如昨天或 2026-08-10。`
- 行业日报缺行业：`要按哪些行业生成？例如基础化工、有色金属或 TMT。`
- 机构日报缺机构：`要看哪些机构？例如高盛、摩根大通；也可以选择全部机构。`
- 用户没有说明输出形态：结合动词判断；「只要标题/目录」默认列表；「查/整理某公司研报」默认公司研报标准输出；「怎么看/为什么/分析某公司或主题/比较」默认闲聊；「日报/生成报告/分析某日全市场研报」默认成文。

### 输出路径

仅日报成文需要确认路径。日期和范围明确后，一次性询问：

```markdown
将生成 {日期} 的{行业/机构/全市场}日报。请指定保存位置；如不指定，默认保存到当前工作空间。
```

查询、列表、摘要和闲聊默认不询问路径、不落盘。

## 工具路由

MCP 命名空间：`user-comein-brm`


| 意图          | 工具                     | 关键参数                                                                                  |
| ----------- | ---------------------- | ------------------------------------------------------------------------------------- |
| 精确条件 / 分页全量 | `research_query`       | 必填 `type: "oversea"`；可选时间、keywords、stockCode、market、industryName、region、page、pageSize |
| 主题语义 / 观点检索 | `searchForeignReports` | 必填 `query`（英文）、`filterImage`；可选 `start_time`、`topK`                                   |


**选用原则：**

- 有 ticker/明确公司名/要按日翻页 → 优先 `research_query`
- 开放主题、跨公司比较、事件影响 → 优先 `searchForeignReports`
- 可组合：先条件缩小集合，再用语义补漏；或语义找到线索后再用 stockCode 精确翻页
- 闲聊 / 深度分析不能停在一次检索；按 [query-chat.md](query-chat.md) 补财务、公告、市场表现和反方证据

完整参数、region 枚举、时间默认窗口 → [reference.md](reference.md)

## 执行清单

```
- [ ] 识别模式（上表）
- [ ] 补齐必要槽位：标的/主题、时间、输出形态（列表/摘要/闲聊/报告）
- [ ] 选对工具并设参（oversea / 英文 query）
- [ ] 分页时 pageSize=100，直到不足一页或暂无数据
- [ ] 按输出规范回复；公司研报走 company-query.md，闲聊走 query-chat.md，行业日报走 daily-report.md，机构日报走 institution-report.md
- [ ] 最终执行「说人话」检查；不自然、只堆数字或未解释含义的段落必须重写
```

### 分页规则（`research_query`）

- `page` 从 1 递增，`pageSize` 固定 100（最大值）
- 终止：返回空 / 条数 < 100 / 达安全上限（建议 100 页）
- 禁止假设存在本地 `.py` 脚本代查；必须手动调 MCP

### 语义检索规则（`searchForeignReports`）

- `query` 用**英文**，写明行业/公司/事件，避免「外资怎么看XXX」这类空泛中文
- `filterImage` 默认 `true`；仅用户明确要图表时才 `false`
- `topK` 默认不传或 10–20；上限 50

### 系统与路径

执行 shell 前确认 OS（当前多为 macOS）。  
默认保存到当前工作空间根目录。指定目录或工作空间不可写时，告知用户并重新询问路径，不要回退到技能目录。

## 输出规范

### 公司研报

查找明确公司或 ticker 的研报时，除非用户明确只要标题，否则必须同时交付：

1. 对应查询范围的研报列表，包含日期、机构、标题、评级/目标价变化和核心观点
2. 机构观点随时间的变化
3. 不同分析视角、机构共识与分歧

完整检索、去重、相关性和成文规则见 [company-query.md](company-query.md)。

### 列表速览

```markdown
## 外资研报列表（{时间范围} · {筛选条件}）

共 {N} 条

| # | 日期 | 机构 | 中文易懂标题 | 英文原题 | 标的 |
|---|------|------|--------------|----------|------|
| 1 | YYYY-MM-DD | 摩根大通 | [用自然中文概括研报主题和倾向](链接) | Original title | NET.US |
```

列表中的英文原题可以保留，但不得只展示英文标题。中文标题必须解释研报在讨论什么，不能逐字硬译。

### 观点摘要

```markdown
## 外资观点摘要：{主题/公司}

**检索范围：** {工具 + 关键条件 + 条数}
**总体立场：** {一句话}

### 共识
- ...

### 分歧 / 风险
- ...

### 评级与目标价（如有）
| 机构 | 评级 | 目标价/动作 | 要点 |
|------|------|-------------|------|

### 代表性研报
- "标题" (机构, 日期)
```

### 条件/语义检索（对话默认）

先给 **命中条数 + 筛选条件**，再按用户要的形态输出列表或摘要；不要无请求就生成日报。

## 示例

- `查 NET 近 3 个月外资研报` → 公司研报模式：完整分页并补漏，先列研报表，再梳理时间变化和不同视角
- `Cloudflare 外资怎么看 Edge AI` → 闲聊模式：先查外资研报，再补事实、分歧和反方证据
- `列出昨天 region=japan 的外资研报` → `research_query` + region + 单日
- `电子行业本周外资在看什么` → 语义检索为主，industryName 条件为辅
- `昨天基础化工、有色金属外资研报日报` → 每行业一个子报告，再拼总文件
- `分析 2026-08-09 的外资研报` → 全市场日报：全量基准 + 全行业分治 + 未分类兜底
- `生成昨天高盛、摩根士丹利机构日报` → 全量拉取一次 + 机构别名归一 + 每机构子报告
