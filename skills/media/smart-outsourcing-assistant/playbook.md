# Playbook：智能委外助手

## 场景 1：智能委外发货
**用户输入**："B产品 焊接工艺要委外，急单"
**执行过程**：
1. 取可委外清单 + 供应商绩效（近一年）
2. 急单 → 准交率优先排序
3. dry-run 预览 → 用户确认 → 自动生成委外单
**产出**：委外单（dry-run 预览 + 已生成确认）

## 场景 2：批量回货
**用户输入**：拍照回货单（含多条委外单）
**产出**：自动识别多单，按委外日期早的优先，自动选批量回货接口执行

## 场景 3：默认供应商沿用
**用户输入**："还是发给上次那家"
**产出**：沿用默认供应商重新生成委外单
