# 短视频内容审核模板

使用本模板来产出一整套发布前短视频内容审核报告：质检口径 + 文本层实质质检清单 + 画面声音层人工复核清单 + 特殊行业专项检查 + 总判定。按"通用规则+全5平台"默认口径套用再回填真实信息，每节后过质量检查。

> **默认口径档**（用户未指定平台/行业时按此套用再回填）：
> - 目标发布平台：抖音/视频号/小红书/B站/快手 全5平台通用规则，命中平台特化项单独标注
> - 行业品类：通用（命中医美/金融/教培/招商任一则加载专项红线库）
> - 资质状态：未确认（命中特殊行业则高危提示须办资质）
> - 风险等级：高危(封号级)/中危(限流级)/低危(扣分级)/提示(人工复核) 四档
> - 总判定：高危=0且中危=0→可发布；高危=0且中危>0→需修改后发布；高危>0→不建议发布

## 模板
```markdown
## 一、质检口径

- 目标发布平台：[抖音 / 视频号 / 小红书 / B站 / 快手]（多选，缺则全5平台通用）
- 行业品类：[通用 / 医美医疗 / 金融理财 / 教培 / 招商加盟 / 美妆 / 食品 / 家居母婴]
- 资质状态：[有(X证照) / 无 / 不确定]（特殊行业必填，影响"能不能发"）
- 是否带货：[是·品名+宣称功效+价格机制 / 否]
- 标题/封面文案：[文本]
- 画面/声音描述（可选）：[用户口述关键画面与声音]

## 二、文本层实质质检清单

逐条检出，每条8列。违禁词按语境判断非纯字面（"美白色连衣裙"的"美白"不算功敏感）。

| 编号 | 检查维度 | 风险描述+真实话术 | 平台依据 | 风险等级 | 修改建议(违规词→合规换词) | 处置后果 | 复检状态 |
|---|---|---|---|---|---|---|---|
| P-001 | [绝对化用语/医疗功效夸大/虚假宣传/诱导导流/恶意营销/夸张标题党/图文不符/价格虚假对比/特殊行业专项/平台通则] | ["全网最低价"(无依据绝对化承诺)] | [广告法第9条] | [高危/中危/低危] | ["违规词"→"合规换词"(语境适用：XXX可，禁XXX)] | [限流/扣分/封号] | [待修改/已修改/二次检测通过/申诉中] |
| P-002 | [维度] | [真实话术摘录] | [法律条款号/平台规则条文号] | [等级] | [违规词→合规换词] | [处置] | [状态] |

- 绝对化用语两档：明确禁用(国家级/最高级/最佳)直接高危；语境禁用(顶级/极品/第一/首个/独家/唯一)看语境——自我比较/固定用语/有依据客观陈述可用，无依据承诺判中危
- 风险描述必含真实话术原文摘录（来自输入），禁空泛描述
- 平台依据必引用具体出处（法律条款号"广告法第16条"或平台规则"蒲公英虚假不实类/视频号5.17.2/抖音第33条"），禁无依据判定
- 修改建议必"违规词→合规换词"成对样例，非泛泛"建议修改"

**质量检查：** 每条含真实话术原文+具体平台依据+成对修改建议；风险等级4档枚举禁模糊词；语境禁用词不直接判高危（看语境分中危或可用）；违禁词按语境判断非纯字面

## 三、画面/声音层人工复核清单

本技能是文本方法论，无法做二进制实质识别。以下为"需人工复核"提示项，不做实质判断，每项标"待人工复核"。

- [ ] 是否过度P图/前后对比暗示功效（视频号第15类制作缺陷/蒲公英过度P图类）
- [ ] 是否出现车牌/店铺门头/品牌logo/二维码/手机号（视频号暗限流触发项）
- [ ] 是否未成年出镜（<10周岁禁代言，不适宜品类禁出现未成年形象含表情包）
- [ ] BGM版权与音画同步（视频号声音制作缺陷类；禁用未授权流行歌）
- [ ] AIGC生成内容是否显著标识（视频号6.4/抖音2026.3治理）

**质量检查：** 5项固定清单齐全含AIGC标识；每项标"待人工复核"不计入分级判定；用户给画面描述则针对性补项；不强作二进制裁断（用户要画面识别见异常7）

## 四、特殊行业专项检查（若命中首批4行业，否则跳过本节）

仅当命中医美/金融/教培/招商任一才产出，否则走通用红线+差异提示。

### 医美/医疗
- 资质关：[有/无]医疗机构执业许可证 + 医疗广告审查证明（广告法46条·发布前审查）
  · 无→"根治/脱敏/治愈"等医疗功效宣称判高危禁发
- 内容关（7条绝对禁止逐项核）：
  - [ ] 说明治愈率或有效率
  - [ ] 与其他产品功效和安全性比较
  - [ ] 明示暗示成分为"天然"因而安全
  - [ ] 利用学术机构/行业协会/专业人士/患者形象推荐证明
  - [ ] 明示暗示可治疗所有疾病/适应所有症状/人群
  - [ ] 引起公众对健康状况产生不必要担忧恐惧
  - [ ] 含诱导性内容(热销/抢购/试用/家庭必备/免费治疗/无效退款/保险公司保险)

### 金融/理财
- 资质关：[有/无]持牌（银行/证券/期货/保险/基金）；无牌荐股/导流配资→拒
- 内容关：禁"保本/稳赚不赔/承诺收益X%/高息/内幕消息"（广告法25条）

### 教培
- 资质关：学科类[基本禁投·标部分待印证] / 非学科凭办学许可
- 内容关：禁"保过/升学率/名师押题/提分保证"（广告法24条）

### 招商/加盟
- 资质关：[有/无]商标注册证 + 品牌授权
- 内容关：禁"零风险/躺赚/月入十万"（广告法25条·投资回报保证）

**质量检查：** 仅命中首批4行业才产出；资质关与内容关分开判；资质未确认→高危提示须办资质（异常3）；学科类判高危须标【部分待印证】（异常9）

## 五、总判定 + 修改后复检指引

- 文本层：高危检出数 [N] ｜ 中危检出数 [M] ｜ 低危检出数 [K]
- 画面声音层：待人工复核项 [L]
- 总判定：[可发布 / 需修改后发布 / 不建议发布]
  - 高危=0 且中危=0 → 可发布
  - 高危=0 且中危>0 → 需修改后发布
  - 高危>0 → 不建议发布
- 发布前必办：
  - [ ] 高危项全部清零（高危检出数=0）
  - [ ] 补办资质（若特殊行业未确认）
  - [ ] 画面声音层5项逐项人工复核确认

**修改后复检指引**：按"修改建议"逐条改写后，重新跑一次质检复检；高危项全部清零（高危检出数=0）且资质齐全方可发布；中危项建议改但不强制。
```
