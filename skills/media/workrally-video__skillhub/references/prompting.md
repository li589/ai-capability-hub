# 视频生成提示词指南

## 核心原则

把提示词写成可在给定时长内拍出来的镜头说明。优先保证主体、动作和镜头三件事；风格、光线、声音和约束只在有帮助时添加。默认 10 秒内避免复杂叙事和频繁切镜。

## 文生视频公式

```text
[时长与画幅中的构图意图]。
[主体]在[时间/地点/环境]中，从[起始状态]开始。
[0–Xs：动作节拍 1；Xs–Ys：动作节拍 2；Ys–结束：收束状态]。
镜头：[景别 + 一种主要运镜 + 视角]。
画面：[光线、色彩、材质、风格]。
声音（仅在需要时）：[环境声/音效/准确台词与语气]。
保持：[身份、服装、空间、物体和运动连续性]；不要出现[少量具体禁项]。
```

简单动作不必机械分秒；只有多阶段动作、广告节奏或明确时长才使用时间轴。

示例：

```text
10 秒写实电影感短片。一名穿黄色雨衣的女孩站在雨夜公交站下，湿润路面映出蓝紫霓虹。0–3 秒，她低头看掌心的一只萤火虫；3–7 秒，萤火虫飞起，她抬头并跟随它向前一步；7–10 秒，萤火虫飞向街道深处，她停下微笑。中近景缓慢推进至近景，平视视角，镜头连续不切换。柔和侧逆光，细雨和自然衣料运动。保持人物面部、黄色雨衣和车站布局前后一致；不要额外人物，不要文字，背景不要闪烁。
```

## 单图生视频公式

图片已经定义外观和构图，提示词聚焦“怎么动”：

```text
以输入图片为首帧。保持[身份/产品/服装/Logo/背景布局]完全一致。
[主体]先[微动作]，随后[主要动作]，最终停在[结束状态]。
镜头[一种主运镜]，[前景/背景]只有[自然环境运动]。
运动符合真实物理，动作连续；不要改变[关键元素]，不要跳切、闪烁或生成额外物体。
```

示例：

```text
以输入图片为首帧。保持香水瓶的形状、标签文字、玻璃材质、液体颜色和桌面布局一致。瓶身起初静止，随后一束窄光从左向右缓慢扫过玻璃表面，折射高光随之移动；背景薄雾轻微流动，最后高光停在品牌标签上。镜头做极缓慢的微距推进，全程单镜头。运动克制、符合真实光学；瓶身不旋转、不变形，标签不改字，画面不跳切。
```

## 对白与声音

用户要求声音时才添加。对白写明准确文本和表演方式：

```text
角色用轻松、略带惊喜的普通话说：“原来春天已经到了。”口型与台词同步。环境声为轻风、树叶摩擦和远处自行车铃声，不要背景音乐。
```

若云端实际输出不支持声音，删除声音段，不要暗示一定会生成音轨。

## 常见失败与修正

- 动作混乱：减少动作数量，改成有先后顺序的 2–3 个节拍。
- 主体漂移：在末尾重复最关键的一致性锚点，而非重复全部描述。
- 镜头发疯：只留一种主运镜；把其他变化改成主体或环境运动。
- 图生视频重绘：缩短场景描述，强化“以输入图为首帧”和保持清单。
- 文字/Logo 变形：要求静止、正面可见、内容不变；不要同时让承载物大幅旋转。
- 背景闪烁：减少背景动态，仅保留一种低幅度环境运动。

## 提交前自检

- 内容能否在所选时长内自然完成？
- 主体、主要动作和结束状态是否明确？
- 是否只使用一种主要运镜？
- 时间轴是否连续、没有互相冲突的动作？
- 图生视频是否列出了必须保持不变的视觉锚点？
- 对白、声音和文字是否确由用户要求且内容准确？
- 是否删掉空泛形容词、重复质量词和冗长负面词？
