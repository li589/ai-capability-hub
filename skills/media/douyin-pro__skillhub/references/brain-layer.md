# 抖音短视频生产专家包 · 上游「大脑层」策略简报

> **版本**：v1.0 ｜ **规则基准**：2026.7.21 抖音安全与信任大会 + 2026.6.15 AI 合规池 + 2026.7.8 佣金新规
> **产出角色**：上游「大脑层」（创意策略师 策凌 / Celine）
> **一句话定位**：本简报是专家包的决策中枢——定方向、定选题、定合规红线，向下游管线输出**可机读**的策略字段；中游负责把策略落为优化脚本，下游负责 AI 配音 + 渲染出片。

---

## 0. 三层架构与大脑的职责边界

| 层级 | 角色 | 核心任务 | 输入 | 输出 |
|------|------|---------|------|------|
| 上游 大脑层 | 战略 + 合规闸门 | 定方向 / 定选题 / 定红线 | 平台规则、账号现状、商业目标 | 策略字段 + 合规闸门配置 |
| 中游 production | 脚本优化器 | 策略 → 优化脚本 / 标题 / 分镜 | 大脑策略字段 | optimized_script / shot_plan 等 |
| 下游 render | 渲染引擎 | 出片 | 中游生产字段 | 成片（配音 + 画面 + 数字人） |

**大脑的不可越界原则**：大脑不直接写最终口播稿、不画分镜、不调配音参数；它只定义"拍什么、为什么拍、哪些绝对不能碰"，并把结论转成结构化字段下传给中游。凡是需要"创作执行"的事，一律交下游。

## 1. 账号定位与人群锚定 —— 从「求量」转向「求质」

**提炼（源自「账号定位」模块）**：定位的老三问——"我是谁 / 给谁看 / 看什么"依然成立，但其底层假设已被 2026 新规推翻：**粉丝数量不再等于流量特权**。平台将"粉丝质量"纳入账号信用评级，单纯堆泛粉的旧打法失效。

**补充（2026 新规增量）**：

- **精准度 > 规模**：5000 精准垂类粉丝的商业价值 > 10 万泛粉；泛粉账号流量被持续稀释。
- **账号信用评级三因子**：精准度（标签契合度）、铁粉占比（高复访核心用户）、复访率（内容被反复回看的频次）。
- **定位决策表**（大脑产出 `account_positioning` 的依据）：

| 维度 | 泛粉定位（淘汰） | 精准定位（推荐） |
|------|----------------|----------------|
| 内容锚点 | 蹭热点、什么火跟什么 | 解决一类明确人群的固定痛点 |
| 人群描述 | "所有人" | 带职业/场景/矛盾的细分画像 |
| 人设语言 | 通用、无记忆点 | 有观点、可被收藏复访 |
| 质量目标 | 点赞量 | 收藏率 + 复访率 |

## 2. 选题规划与内容价值设计 —— 围绕「长效价值」做选题

**提炼（源自「选题规划」模块）**：选题的本质不是"追热点"，而是"预判用户会**收藏 / 复访**什么"。在新权重下，一条能被反复回看、被主动收藏的内容，远胜一条只换点赞的爆款。

**补充（2026 新规增量）**：算法已从"24 小时短期赛马"全面转向"**7 天长效价值考核**"，选题必须按周级价值来设计。数据权重排序（由高到低）：

> **收藏 > 复访 > 完播 > 点赞 > 评论**（点赞排最后）

**选题价值四象限**（大脑产出 `topic_direction` 的筛法）：

| 象限 | 特征 | 平台态度 | 策略建议 |
|------|------|---------|---------|
| 高收藏·高复访 | 教程/清单/避坑 | 推流友好 | 主力选题 |
| 高完播·低收藏 | 爽感/猎奇 | 仅过基础池 | 控制比例 |
| 高点赞·低复访 | 情绪共鸣 | 权重下降 | 谨慎使用 |
| 低完播·低互动 | 自嗨内容 | 冷启动即停推 | 砍掉 |

## 3. 爆款脚本模型 —— 黄金开头必须对齐冷启动生死线

**提炼（源自「脚本模型」模块）**：经典五段式（**钩子 → 痛点 → 方案 → 证据 → 行动**）依然有效。但 2026 新规把"开头"的权重**量化成了硬指标**，脚本模型必须让开头 3 秒服务于留存。

**补充（2026 新规增量）**：冷启动池（L1）三大生死线直接绑定脚本开头：

| 生死线指标 | 阈值 | 对应脚本动作 |
|-----------|------|-------------|
| 2 秒留存 | ≥ 70% | 第 1 句必须抛悬念/利益/反差，禁止"大家好我是…" |
| 3 秒留存 | ≥ 55% | 前 3 秒出现核心冲突或结果预告 |
| 5 秒完播 | ≥ 40% | 前 5 秒完成"问题—代价"建立，逼出继续看动机 |

**脚本模型适配建议**：
- 钩子前置：把"最大利益点 / 最强反差"压到 0-2 秒。
- 证据可视化：教程类用"前后对比"在 5 秒内呈现。
- 规避自说自话：任何"铺垫式"开场在新算法下会被直接停推。

## 4. 推荐机制与流量池战略 —— 兴趣探索 + 6 级生死线

**提炼 + 重写（源自「流量池 / 推荐机制」模块）**：推荐逻辑从"标签匹配"升级为"**兴趣探索**"（Wide&Deep + 双塔召回），系统会**主动发现用户未明说的需求**，而非被动按标签投递。冷启动也从"泛流量试探"改为"**精准小流量测试**"——只投 100-300 个精准标签用户，无泛流量。

**补充（2026 新规增量）**：6 级流量池中前三级的量化生死线（L4–L6 为进阶池，按长尾价值逐级放大，本文不虚构阈值）：

| 层级 | 曝光区间 | 核心考核指标 | 生死线 | 关键备注 |
|------|---------|-------------|--------|---------|
| **L1 冷启动池** | 100–300 / 0–24h | 2秒留存 / 3秒留存 / 5秒完播 | ≥70% / ≥55% / ≥40% | 任一不达标即**停推** |
| **L2 基础池** | 1000–5000 | 有效完播率 / 综合互动指数 | ≥35% / ≥10% | **纯 AI 批量流水线**内容在此被识别降权 |
| **L3 待推荐池** | 5000–30000 | 收藏率 / 复看率 / 关注转化 / 长评论质量 | ≥8% / ≥5% / ≥2% | **80% 创作者卡在这里** |
| L4–L6 进阶池 | 逐级放大 | 长尾价值 + 铁粉复访 | — | 长尾推流周期延长至 **7–14 天** |

**战略含义**：
- 旧逻辑"粉丝量 = 流量特权"已被推翻，新号靠精准内容也能拿到冷启动。
- 卡在 L3 是常态，破局点在于**拉升收藏率与复看率**（对应第 2 章选题设计）。
- 长尾推流拉长到 7–14 天，意味着一条好内容要按"周"经营，而非"日"冲量。

## 5. 引流与私域策略 —— 公域做厚，私域零碰

**提炼（源自「引流」模块）**：引流的重心从"把人导到私域"转向"**在公域沉淀铁粉**"。因为账号信用评级直接看铁粉占比与复访率，把人留在抖音内反而更划算。

**补充（2026 新规增量 · 红线级）**：**私域导流零容忍**——
- 禁止对象：手机号、微信号、二维码、以及**谐音变体**（如"薇♥""加 V""威新"）。
- 处罚阶梯：**一次违规关橱窗 7 天，两次永久封杀带货权限**。
- 合规替代：用"主页简介 + 粉丝群 + 直播间"做公域承接，不在视频/口播/字幕里出现任何导流信息。

## 6. 变现与带货合规 —— 门槛、费率、佣金分级

**提炼（源自「变现」模块）**：变现路径（橱窗 / 直播 / 星图 / 知识付费）的筛选在 2026 明显收紧，平台用"门槛 + 动态费率"倒逼合规与原创。

**补充（2026 新规增量）**：

- **带货门槛上调至 500 粉**；低粉号每周限挂 **2 条车**，万粉以上每天限 **10 条**。
- **技术费按账号月度评级动态收**：

| 评级 | 实际技术费率 |
|------|------------|
| A / B+ 级 | 返还（实际 < 10%） |
| B 级 | 10% |
| C 级 | 20% |
| D 级 | 40% |

- **达人佣金分级（2026.7.8）**，按合规 / 原创 / 转化 / 稳定性评级：

| 等级 | 佣金比例 |
|------|---------|
| A 级 | 6% |
| B 级 | 10% |
| C 级 | 13%–16% |
| D 级 | 最高 20% |

> 启示：高佣金（D 级）对应的是"高风险内容"，大脑应引导账号走 A/B 级合规原创路线，靠费率返还 + 稳定转化盈利，而非靠极限词冲 D 级高佣。

## 7. 投流（DOU+）策略 —— 为「已合规 AI 内容」加杠杆

**提炼（源自「投流」模块）**：DOU+ 是**放大优质内容的杠杆**，不是拯救劣质内容的救命稻草。投流前必须确认内容已通过 L2（基础池）自然验证。

**补充（2026 新规增量）**：
- 自 2026.6.15 起，**"AI 合规专属流量池"** 给"**已标注 + 人工二次修改**"的内容额外流量。
- 以下低质 AI 内容在投流与自然流中均被限流：**纯零修改 / 跨账号结构雷同 / 未授权开源 AI 素材**。
- 投流建议：只把"已通过标注闸门 + 人设闸门"的内容投 DOU+，且优先投给 L3 卡点内容做破圈，而非给冷启动兜底。

## 8. 全案操盘与数据飞轮 —— 7 天价值考核下的操盘节奏

**提炼（源自「全案操盘」模块）**：操盘从"日更冲量"转向"**周级价值经营**"。单条内容要看 7 天累计价值，而非发后 24 小时的瞬时数据。

**补充（2026 新规增量）**：
- 长尾推流周期延长至 **7–14 天**，意味着一条内容发布后第 3–7 天仍可能二次起量。
- 操盘周历（大脑给中游/下游的节奏约定）：

| 时间窗 | 动作 | 关注指标 |
|--------|------|---------|
| Day 0–1 | 发布 + 过冷启动生死线 | 2/3/5 秒留存 |
| Day 1–3 | 数据诊断，过 L2 | 有效完播 / 互动指数 |
| Day 3–7 | 拉升收藏复访，冲击 L3 | 收藏率 / 复看率 / 关注转化 |
| Day 7–14 | 长尾观察 + 二创复用 | 复访 / 铁粉沉淀 |

## 9. AI 生产合规闸门（本简报**新增章节**）

下游管线使用 **AI 配音（GPT-SoVITS / VoxCPM2 / CosyVoice）+ AI 混剪 + 数字人**，存在系统性合规风险。大脑层必须设立"**出厂前检查清单**"，每一段待渲染内容在交付下游前需逐闸通过。

### 9.1 六大闸门总览

| 闸门 | 判定标准 | 不通过处置 |
|------|---------|-----------|
| **标注闸门** | 发布页勾选官方 AI 标识 + 前 5 秒可见标识 ≥ 3 秒（小字/闪现无效） | **拦截**，禁止进入渲染 |
| **人设闸门** | 是否有人工二次修改痕迹（防零修改限流） | 退回中游二改 |
| **红线闸门** | 四类违规词扫描（稀缺逼单 / 虚假价格 / 售后承诺造假 / 虚假权威极限词） | **拦截**并标注命中词 |
| **导流闸门** | 私域信息零出现（手机号 / 微信 / 二维码 / 谐音变体） | **拦截**，强制替换 |
| **质量闸门** | 开头 3 秒留人能力（对齐 L1 生死线） | 退回中游重做钩子 |
| **矩阵闸门** | 跨账号结构不得雷同（防连坐） | 标记连坐风险，要求差异化改编 |

### 9.2 各闸门详细判定与处置

**① 标注闸门（强制，漏标处罚阶梯）**
- 判定：a) 发布页是否已勾选官方 AI 标识；b) 视频前 5 秒是否有**可见** AI 标识且持续 ≥ 3 秒（小字、闪现均无效）。
- 处置：漏标——**首次扣 20 分 + 下架限流**；二次封挂车 3 天；三次关橱窗 7 天。不通过则直接拦截，禁止进入下游渲染。

**② 人设闸门（拿 AI 专属流量池的门票）**
- 判定：是否存在人工二次修改（口播改写 / 画面调序 / 本地素材替换 / 文案本地化 / 数字人表情微调）。
- 处置：纯零修改内容无法进入"AI 合规专属流量池"且被限流 → 退回中游做二改后再过闸。

**③ 红线闸门（四类违规，命中即拦）**
- 判定：扫描以下四类——
  1. **稀缺逼单**："最后 X 单""错过再无"等制造虚假紧迫；
  2. **虚假价格**：虚高原价再打折、价格与链接不符；
  3. **售后承诺造假**："终身保修""无效全额退"等无法兑现承诺；
  4. **虚假权威 / 极限词**："最 / 第一 / 国家级 / 100% 有效"等。
- 处置：命中即拦截，标注命中词并给合规替换建议，不得在红线附近"打擦边球"。

**④ 导流闸门（零容忍，连坐级）**
- 判定：全场景禁止手机号、微信号、二维码、谐音变体（"薇♥""加 V""威新""❤"导流暗号）。
- 处置：**一次违规关橱窗 7 天，两次永久封杀带货权限** → 强制替换，不替换不出片。

**⑤ 质量闸门（对齐冷启动生死线）**
- 判定：开头钩子是否能在 2 秒内建立悬念 / 利益 / 冲突，支撑 2 秒留存 ≥ 70%、3 秒留存 ≥ 55%、5 秒完播 ≥ 40%。
- 处置：不达标退回中游重做"黄金 3 秒"，不靠后期剪辑补救。

**⑥ 矩阵闸门（防跨账号连坐）**
- 判定：同一主体跨账号发布时，分镜结构 / 话术节奏 / 画面序列不得雷同（"跨账号结构雷同"会被限流且可能连坐）。
- 处置：标记连坐风险，要求每账号做差异化改编（换钩子角度 / 换案例 / 换数字人形象）。

## 10. 大脑 → 中游 → 下游 衔接原则（字段对齐）

确保三层之间**字段可机读传递、语义对齐**，避免"大脑说东、中游做西、下游跑偏"。

### 10.1 大脑 → 中游（策略字段）

| 字段名 | 说明 | 类型 / 示例 |
|--------|------|------------|
| `account_positioning` | 账号定位 + 人设 + 信用评级目标 | JSON |
| `target_audience` | 目标人群画像（职业/场景/痛点） | JSON |
| `topic_direction` | 选题方向 + 价值锚点（收藏/复访导向） | list[JSON] |
| `script_model` | 指定爆款脚本模型（五段式 + 开头约束） | string |
| `traffic_pool_target` | 目标突破的流量池层级与生死线 | JSON |
| `compliance_gate` | 本次合规闸门配置（6 闸开关与阈值） | JSON |
| `monetization_path` | 变现路径 + 佣金/费率约束 | JSON |

### 10.2 中游 → 下游（生产字段）

| 字段名 | 说明 |
|--------|------|
| `optimized_script` | 优化后口播脚本（已过红线闸门） |
| `title_options` | 标题候选（≥ 3 条，含钩子变体） |
| `shot_plan` | 分镜计划（含景别/视角/焦点） |
| `video_duration` | 视频时长（秒） |
| `aspect_ratio` | 画幅（9:16 / 1:1 / 16:9） |
| `dubbing_method` | 配音方式（GPT-SoVITS / VoxCPM2 / CosyVoice） |
| `digital_human` | 数字人配置（形象 / 表情 / 口型） |
| `publish_platform` | 发布平台（抖音主端 / 抖音极速版等） |
| `ai_label_config` | AI 标识埋点（前 5 秒 ≥ 3 秒可见） |

### 10.3 三层字段流转示意

```
大脑层 ──account_positioning / topic_direction / compliance_gate──▶ 中游 production
                                                                    │
                                            optimized_script / shot_plan / dubbing_method
                                                                    │
                                                                    ▼
                                                          下游 render ──▶ 成片
                                                                    ▲
                              合规闸门在所有字段进入 render 前强制校验（第 9 章）
```

**对齐纪律**：
1. 中游必须消费大脑的 `compliance_gate`，不能自行放宽红线。
2. 下游渲染前必须回放第 9 章六闸，任一不通过即停渲。
3. `ai_label_config` 由大脑定义、中游落实、下游执行，三方字段名一致。

## 11. 本简报相对源技能的增量说明

### 11.1 提炼（对源「抖音运营专家 8 大模块」的蒸馏，非照抄）
- **账号定位**：保留"我是谁/给谁看/看什么"骨架，但把结论从"做人格化"提炼为"精准度 > 规模 + 信用评级三因子"。
- **选题规划**：把"追热点"提炼为"预判收藏/复访"，并用新数据权重重排优先级。
- **脚本模型**：保留五段式，但提炼出"开头 3 秒必须服务冷启动生死线"这一可执行约束。
- **流量池/推荐机制**：把"标签推荐"重写为"兴趣探索（Wide&Deep + 双塔召回）"，并提炼冷启动"精准小流量测试"逻辑。
