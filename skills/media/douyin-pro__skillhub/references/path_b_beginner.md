# Path B 新手指南 · 5 分钟出第一条免费视频

> 这份是**给第一次用的人**看的，主打"照着做就能跑通"。
> 想要完整参数、输入格式、排错表，看同目录的 `path_b_runbook.md`（技术手册）。

---

## 一、Path B 是啥？（30 秒看懂）

一条**不花一分钱**的抖音视频生产路线：

> 你给一段文字（选题 / 文案）→ 工具自动**配音**（微软免费语音）+ **做画面**（开源 HyperFrames）+ **烧字幕** → 吐出一个竖屏 MP4。

- ✅ **零云费**：不用买任何 API、不用开会员。
- ✅ **一条命令**：装好依赖后，一行命令出片。
- ⚠️ **要装点东西**：本机得装好几个免费工具（下面教你怎么装）。
- ⚠️ **画面是"文字+动画"风格**，不是真人实拍、也不是数字人说话（那是 Path A）。

---

## 二、你适合用 Path B 吗？

| 适合 | 不适合 |
|------|--------|
| 想快速出片、蹭热点 | 要真人/数字人出镜 |
| 不想花钱、不想配环境折腾 | 要电影级质感/品牌精修 |
| 做模板化、批量口播 | 要专属克隆声线（edge-tts 音色不可克隆） |

拿不准？要质感去 Path A，要快去 Path B。

---

## 三、先准备这些（一次性）

你只需要：一台电脑 + 能上网。软件全免费：

1. **Node.js ≥ 22**（HyperFrames 跑起来要它）→ https://nodejs.org
2. **FFmpeg**（合成视频用）→ 装法看下面
3. **Python ≥ 3.10**（配音脚本用，一般电脑都有）
4. **联网**（配音要连微软的免费语音服务）

---

## 四、第一步：装依赖（一条命令）

打开命令行，进到 skill 目录，运行：

```bash
python scripts/install_path_b_deps.py --auto
```

它会帮你：
- 装 `edge-tts`（配音）
- 装 `hyperframes`（画面渲染）
- 检测 / 尝试装 `ffmpeg`
- 下载 Chromium（渲染要的内核）
- 最后跑 `hyperframes doctor` 告诉你环境是否全绿

> 卡住或某步失败？脚本会给出手动安装指引，照着做就行。不想让它自动动系统，去掉 `--auto` 只做检测。

---

## 五、第二步：准备脚本（复制粘贴就行）

新建一个 `脚本.txt`，写你的口播文案，**空一行分一段**，每段 = 一个画面：

```text
三招让手机拍出电影感

第一招，找光源。逆光拍剪影，侧光出质感。
第二招，稳字当头。手抖就靠墙，或者上稳定器。
第三招，留白。画面别塞满，给主体呼吸的空间。
```

> 段首那行短句会自动当标题。想更精细（指定每段音色），用 JSON 格式，见 `path_b_runbook.md`。

---

## 六、第三步：一条命令出片

```bash
python scripts/path_b_build.py --input 脚本.txt --output final.mp4
```

然后去泡杯茶。它会依次：分段配音 → 生成画面 → 渲染 → 合成音频和字幕 → 生成 `final.mp4`。

完了在目录下就能看到 `final.mp4`，竖屏 1080×1920，带配音 + 字幕，直接发抖音。

---

## 七、你会得到什么

- `final.mp4`：竖屏短视频，已含 AI 配音 + 烧好的字幕。
- 全程**没有花钱**，没有上传任何素材到云端。

> 想改分辨率（比如横屏 1920×1080）？加 `--resolution 1920x1080`。
> 想换女声/男声？加 `--voice zh-CN-YunxiNeural`（男声）等，音色列表见 `path_b_runbook.md`。

## 八、新手最常问

**Q：跑出来没声音？**
A：多半是配音那步没连上微软服务（网络限制）。换能正常上网的环境再跑；或检查 `install_path_b_deps.py` 里 edge-tts 是否装好。

**Q：卡在渲染不动？**
A：第一次渲染要下载 Chromium，可能慢。也可以手动 `npx hyperframes browser ensure` 先下好。

**Q：字幕没烧上去？**
A：确认脚本正常生成了字幕文件；更细的排错看 `path_b_runbook.md` 的排错表。

**Q：这和 Path A 差在哪？**
A：Path A 能上数字人、专属声线、品牌精修，但要配环境/可能花钱；Path B 就是"免费快出文字口播视频"。两条路脚本互通。
