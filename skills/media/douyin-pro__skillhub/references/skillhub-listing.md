## 3. 详细描述 / Description

中文：
抖音短视频一站式生产体系。主理人「司远」调度三个角色走完三层流水线：上游大脑层（策远）按 2026.7.21 抖音新规定账号定位、选题方向、流量池战略与合规闸门；中游（润笔）调用 douyin-script-optimizer 做 10 维脚本提质、防同质化、配分镜与标题；下游（渲工）调用 video-render-engine 选 AI 配音（百炼 / GPT-SoVITS / VoxCPM2 / CosyVoice / edge-tts 免费）与渲染通道（剪映 / Remotion 可运行模板 / ffmpeg / 数字人）出片。v5.2 新增「混剪层」：对实拍素材用 autoclip 做 AI 高光提取与自动粗剪，输出标准片段再写口播。内置六闸合规（标注 / 人设 / 红线 / 导流 / 质量 / 矩阵），出片前自动拦截违规，降低下架风险。另可调用平台内置 AI 视频模型（HY-Video-1.5 文生视频 / YT-Video-2.0 图生视频 / YT-Video-HumanActor 单图驱动人像 / YT-Video-FX 图片特效）直出素材片段，回灌混剪层衔接下游。支持双路径：Path A 高质量自配、Path B 免费端到端（edge-tts + HyperFrames 零云费），可端到端、仅脚本、仅出片。

English:
An end-to-end Douyin short-video production system. Lead "Soren" orchestrates three roles across a three-layer pipeline: the upstream brain layer (Ceyuan) sets account positioning, topic strategy, traffic-pool strategy and a compliance gate per the 2026.7.21 Douyin rules; the midstream (Runbi) runs douyin-script-optimizer for 10-dimension script optimization, anti-homogenization, shot plan and titles; the downstream (Xuangong) runs video-render-engine to pick AI dubbing (Bailian / GPT-SoVITS / VoxCPM2 / CosyVoice / edge-tts free) and a render channel (Jianying / runnable Remotion template / ffmpeg / digital human) to produce the final video. v5.2 adds a montage layer: autoclip performs AI highlight extraction and auto-trimming on real footage, outputting standard clips for the script writer. A built-in six-gate compliance check (labeling / persona / red-line / diversion / quality / matrix) blocks violations before rendering. It can also invoke the platform's built-in AI video models (HY-Video-1.5 text-to-video / YT-Video-2.0 image-to-video / YT-Video-HumanActor single-photo human actor / YT-Video-FX image-effects) to generate source clips that feed back into the montage layer. Dual-path: Path A (high-quality, self-configured) and Path B (free end-to-end with edge-tts + HyperFrames, zero cloud cost). Supports end-to-end, script-only, and render-only modes.
