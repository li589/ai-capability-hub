# 首次跑通指南（Golden Path）

本指南假设你是第一次用本专家团，目标：从一句话需求得到一条**可发布的抖音成片**。

## 你会得到什么

- 上游：账号定位 + 选题方向 + 流量池目标 + 合规闸门配置
- 中游：优化口播稿 + ≥3 条标题 + 分镜计划（shot_plan）+ 质量分（score）
- 下游：成片文件（AI 配音 + 画面 / 数字人）+ 质量自检卡 + 六闸通过确认

## 步骤

1. 对主理人说（建议补充赛道 / 产品 + 商业目的，效果更好）：
   > 我要做一条抖音短视频，从选题到成片帮我走完三层流水线
   >
   > 补充：美妆个护新品牌，推一款控油洗发水，目标涨粉 + 带货

2. **大脑层（策远）** 产出策略字段 → 主理人向你看摘要并确认方向。
3. **中游（润笔）** 调 `douyin-script-optimizer`，产出优化稿 / 标题 / 分镜 / 质量分 → 主理人中转。
   - 若 `score < 7`，会自动回灌重跑（最多 2 次）直至达标。
4. **下游（渲工）** 出片前回放六闸；通过则选配音 + 通道合成成片，跑质量自检卡。
5. 主理人汇编：成片 + 各层摘要 + 合规闸门通过情况，交付给你。

## 排错（Troubleshooting）

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 中游质量分一直 < 7 | 选题太泛 / 痛点不强 | 让策远重新定更精准的选题方向，或手动补充 key_points |
| 下游停渲 | 六闸某一项不通过（AI 标识缺失 / 红线触碰等） | 看主理人返回的闸门状态，修正对应字段后重跑下游 |
| 想换配音 / 通道 | 默认 CosyVoice + 剪映 | 显式指定："用 GPT-SoVITS 配音走 Remotion" |
| 只要脚本不要片 | — | 用用法②，明确"优化完不出片" |
| 字段衔接报错 | 手写跳过了某层 | 严格按三层顺序，不要跨层直连 |

## 进阶用法

- **批量生产**：循环"选题 → 脚本"，渲染层可接剪映 / 数字人流水线。
- **规则更新**：大脑层策略基准见 `references/brain-layer.md`，随抖音新规同步（当前基准 2026.7.21）。
- **分段调用**：熟练后可单独调策远做选题、单独调润笔提质、单独调渲工出片，见 README「三种用法」。
