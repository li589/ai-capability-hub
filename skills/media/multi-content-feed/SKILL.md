# 全网内容出海信息源

## 简介

**全网内容出海信息源**是一款专为内容出海创作者设计的全平台爆款内容追踪工具。

通过红狐Hub API，你可以：
- 📊 每日自动扫描全平台内容出海Top50作品
- 🏷️ 基于API返回数据智能聚类题材方向
- 📈 生成包含平台标签、封面图、互动数据与创作洞察的可视化HTML日报
- 🔍 支持按平台、关键词、时间范围定向查询

## 功能特性

### 核心功能

| 功能模块 | 能力描述 |
|---------|---------|
| 爆款发现 | 从全平台内容出海中获取Top50作品 |
| 题材聚类 | 基于API返回数据自动聚类 |
| 全平台覆盖 | 支持公众号/抖音/视频号/小红书/快手/B站 |
