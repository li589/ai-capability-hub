# 🎬 社交媒体视频脚本生成

将 Obsidian 笔记转化为适配中国主流社交平台的视频脚本/图文笔记。

## 触发条件

用户提供笔记内容，要求生成视频脚本、科普内容、或社交媒体发布素材。

## 核心流程

### Step 1：提取笔记核心卖点

从笔记中提炼：
- **一句话钩子**：最吸引人的点（不是"做了什么"，而是"效果/结果"）
- **三个平台的切入角度**：各平台调性不同，角度要分开
- **身份标签**：用户是谁（如"不会写代码的造价师"），降低门槛

### Step 2：按平台算法设计脚本

三个平台的流量逻辑完全不同：

| 平台 | 算法核心 | 钩子策略 | 调性 |
|------|---------|---------|------|
| 抖音 | 完播率（前3秒决定生死） | 情绪冲击/悬念/反差 | 快节奏，每3秒一个信息点 |
| B站 | 点击率（标题×封面） | 差异化切角+踩坑共鸣 | 朋友分享感，不是课堂 |
| 小红书 | 收藏率（干货被收藏=推荐） | 痛点共鸣+"你能复制"的确定感 | 精致、有生活感 |

### Step 3：脚本结构模板

#### 抖音（2-3分钟竖屏）
```
0-3秒：钩子（大字覆盖+旁白，信息密度要高）
3-10秒：视觉冲击（展示效果）
10-20秒：对比反差（别人vs我）
20-40秒：怎么做到的（简化版）
40-70秒：效果轰炸（多个场景快切）
70-85秒：打消顾虑（费用/难度）
85-100秒：情感收尾
100-120秒：CTA（主页置顶/评论区）
```

#### B站（5-7分钟横屏）
```
Part 1（0:00-0:30）：开场钩子——亮身份+亮效果
Part 2（0:30-1:30）：为什么做——从痛点出发
Part 3（1:30-2:30）：效果展示——先让观众"想要"
Part 4（2:30-4:00）：怎么搭的——不贴代码，只展示界面
Part 5（4:00-5:10）：踩坑分享——3个经典坑，每个20秒
Part 6（5:10-6:00）：真实感受+CTA
```

#### 小红书（2-3分钟竖屏 或 6张图文）
```
图文版：
图1：封面（标题+工具图标）
图2：痛点页（用户共鸣）
图3：工具介绍页（三个免费工具）
图4：效果展示页（截图拼贴）
图5：搭建步骤页（4步卡片）
图6：教程入口页（收藏引导）

视频版：
0-5秒：钩子（痛点问题）
5-12秒：痛点共鸣（截图展示）
12-25秒：解决方案（三个工具）
25-50秒：效果展示（多场景）
50-70秒：打消顾虑（零成本）
70-100秒：情感收尾+收藏引导
```

### Step 4：平台专属配置

每个平台需要额外准备：
- **标题**（不超过20字，有差异化）
- **标签**（8-10个，混合大词和长尾词）
- **封面文字**（大字醒目，风格匹配平台调性）
- **发布文案**（描述文字，带emoji和CTA）
- **发布技巧**（时间、评论引导、互动策略）

## 钩子设计原则

**抖音**：前3秒必须有信息密度，不要叙事铺垫
- ✅ "我让AI帮我写了一年的日报"
- ❌ "早上8点，手机响了"

**B站**：标题要降低门槛+制造好奇
- ✅ "不会写代码的我，和AI一起搭了个系统"
- ❌ "从零搭建AI知识库"

**小红书**：痛点=收藏动力
- ✅ "你的笔记散落在五六个地方？"
- ❌ "每天收到AI推送"

## 常见错误

1. **第一版往往太"客气"**：需要加入流量思维，不是展示而是引流
2. **技术内容劝退**：非技术平台（抖音/小红书）不要贴代码、终端截图
3. **CTA 太弱**：不要只说"看主页"，要说"收藏这条以后用得上"
4. **调性不匹配**：B站可以稍硬核，抖音/小红书要轻松日常
5. **封面不够醒目**：小红书封面文字要大，抖音封面要有对比色

## 我能做 vs 用户要做

| 能做 | 不能做 |
|------|--------|
| 生成脚本文案 | 录制屏幕 |
| 生成封面图/图文笔记（Pillow/baoyu-infographic） | 剪辑视频 |
| 生成架构图 | 配音/BGM |
| 生成文字覆盖素材 | 实际发布 |

## 制作优先级建议

1. 🥇 小红书图文笔记（成本最低，长尾流量好，Canva 做图即可）
2. 🥈 抖音短视频（流量天花板最高，全程录屏+剪映）
3. 🥉 B站视频（制作最重，但搜索长尾价值大）

## 输出格式

脚本保存到 Obsidian：`🍺 二掌柜的酒铺/{YYYY}/{MM}/{YYYY-MM-DD}-视频脚本-{主题}.md`
（视频脚本是私人内容，放二掌柜的酒铺，不要放夜航船，不要 git push）

## 分镜表与素材清单

脚本写完后，必须额外生成一份 **详细分镜表**（也放二掌柜的酒铺），内容包括：

1. **素材总览**：列出所有需要的录屏、截图、图片素材
2. **逐秒分镜**：每个时间点的 画面+旁白+操作指引
3. **录屏清单**：具体要录哪几段屏幕，每段录什么、录多久
4. **制作清单**：checkbox 列表，方便打勾确认
5. **录屏技巧**：手机/电脑录屏设置、通知关闭、字体放大等

## 图片素材生成

**Pillow 生成的图片质量较差**，用户反馈"很一般"。更好的方案：

1. **提供 AI 图片生成 prompt**：为每张图写详细的英文 prompt，用户复制到 Midjourney/DALL-E/可灵/海螺AI 生成
2. **Pillow 只做兜底**：如果用户不想用 AI 生图，再用 Pillow 生成基础版
3. **中文文字问题**：AI 图片生成的中文经常乱码，建议用户用 Canva/美图秀秀 叠加文字层

## 模拟推送录屏

用户可能需要录屏 AI 推送通知的效果。发送模拟推送时注意：
- 延迟至少 **15秒**再发送（5秒/10秒会被覆盖通知）
- 发送后 **不要追加任何消息**，否则会覆盖通知显示
- 用 `sleep 15` + `send_message` 实现
