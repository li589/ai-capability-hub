# 使用须知

> 何时读本文件：用户触发本 skill 但必需输入缺失（没给视频附件/路径、文件不存在、或给的是链接而非本地文件）时，向用户展示本须知的「输入要求 + 关键前置条件」要点并停下，等用户补齐后重试。

## 输入要求

- **必需：本地视频文件的绝对路径**或视频附件（`.mp4/.mov/.mkv/.webm/.m4v/.avi` 等）。
- ❌ **不接受**：微信视频号分享链接、网页链接、在线视频 URL。请先把视频下载/保存到本地再提供。
- 上传方法（客户端若不能直接选视频文件，用复制+粘贴）：在电脑文件夹复制视频文件（⌘C）→ 回到对话框直接粘贴（⌘V）作为附件上传 → 发送「拆解这个视频」。

## 关键前置条件

- **模型须支持视觉**：纯文本模型看不到画面、无法拆解。**任何能读取图片的多模态/视觉模型均可，不限于具体型号**——你工具里没有以下型号也没关系，只要模型能读图就行。判断：模型名带 `vision`/`-V`/`-VL`/`4o`/`Gemini` 等通常支持；或直接发张图问它能否描述画面，能描述即可用。常见如 Kimi 视觉版 / Qwen-VL / GLM-4V / 豆包视觉版 / Claude 4.x / GPT-4o / Gemini 2.x 等；纯文本模型如 DeepSeek-V3/R1、GLM/Qwen/Kimi 纯文本版不可用。
- **需 ffmpeg + ffprobe**：缺失则脚本退出码 8。可用 `--install-ffmpeg` 自动安装（macOS 用 brew、Linux 用 apt、Windows 用 winget，均无需翻墙；winget 不可用时从 ffmpeg.org 下载解压并把 bin 加入 PATH）。
- **Whisper 转写可选（选装）**：未装会降级为画面推断（台词效果打折），但**不影响出报告**。Whisper 体积大、安装耗时，默认不强引导；用户主动要启用台词分析时，可用 `--install-whisper` 安装（macOS 优先 brew 装 whisper-cpp，其余 pip 国内镜像装 mlx-whisper/openai-whisper，Win/Mac 均支持、免翻墙）。
- **体积/时长上限**：单个视频 ≤ 500MB、≤ 15 分钟；超限请在本地压缩或裁剪关键片段后重传。

## agent 行为约定

必需输入缺失时（未给视频附件/路径、文件不存在、或给的是链接而非本地文件）：**先向用户展示本须知的「输入要求 + 关键前置条件」要点**（提炼关键几条即可，不必逐字照搬全文），再停下等用户补齐后重试，**不要在缺输入时强行跑脚本**。
