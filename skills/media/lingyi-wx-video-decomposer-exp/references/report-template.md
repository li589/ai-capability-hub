# 体验版视频拆解报告模板

agent 读取脚本输出的 manifest 后，按本模板撰写并渲染 Markdown 报告。模型中立：由 agent 当前配置的模型生成，skill 不内置 LLM。

报告小节标题只写文字本身，**不带 `Part X：` 之类前缀**。

## 目录

- 写作总则
- 报告结构（六节）：基本信息 / 结构拆解 / 内容归因分析 / 六维评分 / 总体评估 / 标签
- 降级规则速查

## 写作总则

- **严格照模板复刻，不得自由发挥。** 逐节、逐列照抄下方表格骨架，只把 `<占位符>` 替换为实际内容；**不得改各级标题文字、不得增删章节、不得把表格改成列表、不得增删表格列**。六节顺序固定：基本信息 → 结构拆解 → 内容归因分析 → 六维评分 → 总体评估 → 标签。
- **分节追加写入，收敛思考**：报告内容长，**禁止一次性 Write 全文**（思考模式下巨大 `content` 极易丢参导致「生成失败」）——先写标题+首节，再逐节追加。写文件时思考只列本节要点，不要在思考里复述整份报告。
- **结构拆解中段段数**：按脚本类型与实际结构取——**教程/制作型 ≤ 7、其余类型 ≤ 5**；多余细步骤合并到相邻段落功能下，不必每帧一行，避免表格过长挤爆单次写入。
- **本 skill 依赖模型的视觉能力：必须能 Read 图片。** 若读取帧/封面图被拦截（`does not support images` / `Content filtered`），说明是纯文本模型——**停止写报告**，按 SKILL.md 工作流第 5 步提示用户切换到支持视觉的模型，不要只凭元数据硬凑报告。
- 综合三类素材：**抽帧图片**（视觉）、**转写文本**（若有）、**元数据**（时长/分辨率/编码等）。
- 必须先用 Read 工具**逐张查看帧图片与封面图**，再下结论；不要凭空臆造画面内容。
- 若 `transcript_available=false`：凡涉及口播/台词的章节，明确写“本版本未启用本地转写，以下为画面推断”，不得伪造台词原话。
- 帧图片附带时间戳（由 manifest 的 `frames_interval_sec` 与序号、或 `frame_timestamps_sec` 推算），在“结构拆解”中引用时间戳增强说服力。
- 中文撰写，语气专业、可直接复用。

## 报告结构（六节）

```markdown
# 视频拆解报告：<标题>

## 基本信息

| 字段 | 内容 |
|------|------|
| 视频ID | <元数据 ID；无则用文件名 stem 并标 [推断]> |
| 标题 | <元数据内嵌标题；若无则根据画面/转写拟一个并标 [推断]> |
| 作者 | <元数据 author；无标“未知”> |
| 行业 | <根据画面/转写推断> |
| 平台 | 视频号 |
| 目的 | <带货/种草/涨粉/品牌曝光 等，[推断]> |
| 视频时长 | <HH:MM:SS> |
| 分辨率 | <宽x高> @ <fps>fps |
| 编码 | <视频编码 / 音频编码> |

**封面：**

![封面](<manifest.cover 绝对路径>)

> 封面来源：<manifest.cover_source>（embedded=内嵌封面，midframe=中段帧推断）

## 结构拆解

**脚本类型**：<emoji> <类型> — <一句话主题>

> 类型可标单一或组合类型（如 `口播/剧情种草型`、`场景植入型`、`开箱测评型`），前缀加一个贴切 emoji，后缀用 ` — ` 接一句主题概括（如「家常美食教程」「婆媳搞笑带货」）。**不再写「（中段应有 N 段）」**。

**判断依据**：

- <要点 1：人物/出镜/演示方式等画面特征>
- <要点 2：整体结构脉络，如「引子→步骤→成品」「冲突→反转→植入」>
- <要点 3：语言风格 / 受众偏好 / 节奏特征>
- <要点 4（可选）：其他支撑判断的画面或转写证据>

> 用**无序列表**逐条列出判断依据，每条一个要点，简洁直接；不要写成一段话。

| 序号 | 段落 | 起始秒 | 结束秒 | 段落功能 | Hook/CTA 类型 | 台词/画面 | 备注 |
|------|------|--------|--------|---------|---------------|----------|------|
| 1 | **Hook 段** | 0.0 | <X> | 抓注意力 | <钩子方式> | <画面+台词> | <备注> |
| 2 | **<中段段落功能名>** | <X> | <Y> | <段落功能> | — | <画面+台词> | <备注> |
| … | **<中段段落功能名>** | <Y> | <Z> | <段落功能> | — | <画面+台词> | <备注> |
| 末 | **CTA 段** | <Z> | <结束> | 转化引导 | <引导方式> | <画面+台词> | <备注> |

> 「段落」列填该段的**实际段落功能名**（如「备料预处理」「蛋卷制作过程」「反转高潮」），依据下方对照表选型并贴合视频实际命名，**不要写「中段1/中段2」这种序号占位符**。「段落功能」列填该段的功能归类（如「产品出场」「效果展示」）。中段段数按脚本类型与实际结构取：**教程/制作型 ≤ 7，其余类型 ≤ 5**；多余细步骤合并到相邻段落功能下，**不必每帧一行**。
>
> 「Hook/CTA 类型」列：Hook 段填钩子方式（利益/冲突/痛点提问/悬念/反差等）；中段填 `—`；CTA 段填引导方式（收藏/关注/购买/点击购物车/评论互动等）。起始/结束秒由 `frames_interval_sec`、`frame_timestamps_sec` 与转写内容推断；无法精确时给区间并标 `[推断]`。

## 内容归因分析

本地版无互动/销量数据，本节为**定性**归因（不带百分比、不带数据佐证列）。

| 排序 | 层 | 因素 | 详细描述 | 贡献度 |
|------|-----|------|---------|--------|
| 1 | 传播/内容/表现 之一 | <因素> | <结合画面与转写详细说明> | 高/中/低 |

- **可借鉴的策略**：<1–2 条可迁移套路>
- **不适用的场景**：<什么情况下不适用>
```

## 降级规则速查

| 素材状态 | 处理方式 |
| --- | --- |
| 有转写 + 有帧 | 完整六节，台词引用时间戳，封面图片展示 |
| 无转写 + 有帧 | 台词相关内容声明“画面推断”；其余段正常 |
| 封面内嵌提取失败 | 脚本自动回退中段帧，`cover_source=midframe`，封面说明按 midframe 注明 |
| 抽帧失败（脚本 exit 9） | 不应进入写作；向用户报错并附脚本 stderr |
