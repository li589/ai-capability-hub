# 报告取数：后端 markdown 直出

报告正文 = 后端返回的 `data.result.markdown`，`render_report.py` 定位该字段后原样写入 `--md-out`，不做二次拼装。「报告长什么样」由后端 markdown 决定。

## markdown 字段定位

`render_report.py` 只读取后端标准响应路径：

- `data.result.markdown`

该字段为空或不存在 → 退出码 23（未找到 markdown 字段）。

## 报告包含的小节（由后端 markdown 决定）

后端 markdown 是一份完整报告，通常含以下小节，供了解交付内容：

- **标题**：`# 视频号爆款脚本生成（N条）｜{最佳脚本标题}`
- **生成概览**：概览段落 + 行业/平台/投放类型/脚本类型/生成数量/最佳脚本元信息表
- **选题策略**：选题角度 / 脚本类型 / 预期分 / 策略来源 + 依据小字
- **脚本列表**：逐条脚本，含元信息表、Hook-中段-CTA 分段表、口播全文、六维质检评分、通过项/风险/优化建议/评估说明、脚本标签
- **评估汇总**：各脚本 × 六维评分横向总表，最佳行标 ⭐
- **整体优化建议**：跨脚本的优化清单

具体小节以后端实际返回为准；字段缺失由后端处理，本 skill 原样透传。
