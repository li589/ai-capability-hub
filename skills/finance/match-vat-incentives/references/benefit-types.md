# 优惠类型与候选路由

此文件用于生成候选项，不构成政策依据。每次回答仍须实时打开官方原文核验。

## 第一版覆盖范围

| 类型 | 常见触发事实 | 必须重点核验 |
| --- | --- | --- |
| 起征点或销售额门槛 | 小规模纳税人或自然人、月/季销售额 | 申报周期、全部销售额口径、特殊交易、适用期间 |
| 小规模减按征收 | 小规模纳税人、适用特定征收率的交易 | 交易是否被排除、预缴、开票、政策期限 |
| 免征增值税 | 农业、医疗、教育、金融、民生服务等特定交易 | 主体与交易定义、自产/外购、资格、价款口径、放弃免税 |
| 减按征收 | 旧货、住房租赁、二手车等特定交易 | 主体、标的、取得或交易时间、计税方法、执行期限 |
| 简易计税 | 一般纳税人的特定项目或历史项目 | 是否可选择、项目形成时间、征收率、进项处理 |
| 加计抵减 | 一般纳税人、特定行业或资格 | 名单/认定、计提基数、不得计提进项、出口、同类政策择优 |
| 即征即退 | 软件、资源综合利用、特定产品或服务 | 产品/服务范围、检测或资格、退税比例、资料和违法限制 |
| 留抵退税 | 一般纳税人、有期末留抵税额 | 行业或主体条件、增量/存量口径、信用、进项构成、欠税和风险限制 |
| 特定行业/项目 | 宣传文化、养老托育、住房租赁、重点群体等 | 专项定义、名单、地域、期间、收入核算和排除项 |

## 候选生成顺序

1. 先按 `vat_status` 生成身份型候选：小规模优惠或一般纳税人优惠。
2. 再按每项 `transaction` 生成交易型候选：免税、减按或简易计税。
3. 按行业和资格生成资格型候选：加计抵减、即征即退或专项优惠。
4. 用户提供进项或留抵数据时，生成进项侧优惠候选。
5. 对业务所属期过滤明显不覆盖的政策，但保留需要核验延续文件的候选。
6. 同时生成“容易误用”的相邻政策，用于解释排除原因。

## 超出第一版范围

出口退免税、零税率、进口环节、复杂跨境、不动产和建筑业复杂历史项目、需要地方自定标准的优惠，标记为专项核验。可以列出可能涉及的政策方向，但不得给出确定适用结论。

## 条件矩阵

对每项候选至少核验：

- 主体条件；
- 纳税人资格和计税方法；
- 交易或产品范围；
- 业务所属期和政策期限；
- 金额、比例或收入占比；
- 认定、名单、备案或核算要求；
- 排除条件；
- 与开票、进项抵扣、出口和其他优惠的交互；
- 办理及留存资料。

任何必要条件明确不满足时，状态为“明确不匹配”。必要条件未知时，不得高于“条件匹配”或“待资格确认”。
