# 估值透视

> ⚠️ **风险提示**：本 skill 输出仅供研究与学习参考，**不构成任何投资建议**。投资有风险，据此操作风险自担，请结合自身风险承受能力独立决策。

**Skill 分类**：估值分析 / 定价逻辑 / 投资决策

**适用人群**：中长线投资者、研究员、价值投资者、成长股投资者、行业分析用户

**适用场景**：当用户关心"这家公司应该怎么估值""现在贵不贵""还有没有重估空间"时，使用本技能给出结构化估值判断。

## 数据需求

本 skill 需要以下**数据维度**，由 AI 从通达信金融数据能力中按需获取：

| 数据维度 | 用途 |
|----------|------|
| 个股当前估值（PE / PB / PS / EV/EBITDA） | 当前估值水平判断 |
| 个股历史估值序列（近 3 年 PE / PB / PS / PCF） | 历史分位与中枢对比 |
| 行业估值排名与同业可比公司估值 | 横向对比与相对位置 |
| 财务三表（利润表 / 资产负债表 / 现金流量表） | 估值方法适配与盈利质量验证 |
| 市场一致预期 / 机构评级 / 目标价 | 预期差与重估空间判断 |
| 个股行情（市值 / 行业属性） | 估值对标基础 |

## 分析框架

### 第一步：先判断公司属于什么类型
常见类型：
- 高成长
- 稳健成长
- 周期
- 价值
- 平台型
- 金融类

不同类型应使用不同估值框架，不要简单套单一指标。

### 第二步：选择估值方法
- 高成长：PE、PEG、PS、EV/EBITDA
- 稳健成长：PE、PEG
- 周期：PB、周期中枢估值、盈利拐点
- 价值：PE、PB、股息率
- 平台型：PS、用户价值、分部估值
- 金融类：PB、ROE、分红能力

### 第三步：判断市场当前在交易什么
估值不是静态数字，而是预期的价格。
必须回答：
- 当前股价里已经反映了什么
- 市场在押注什么变化
- 哪些变量会导致重估
- 哪些变量会导致杀估值

### 第四步：判断估值所处位置
至少做三个对比：
- 历史纵向：当前估值 vs 近 3 年历史分位
- 横向比较：当前估值 vs 同行业可比公司
- 业绩匹配：估值与增速、盈利质量是否匹配

### 第五步：识别重估和杀估值触发因素
重估常见触发：
- 业绩超预期
- 新业务放量
- 行业景气改善
- 竞争格局优化
- 治理改善

杀估值常见触发：
- 增速下滑
- 周期见顶
- 竞争恶化
- 风险偏好下降
- 政策或监管打击

## 输出要求

- 必须明确公司类型和估值方法
- 必须说明当前估值是否合理
- 必须指出当前价格已计入的核心预期
- 必须给出重估或杀估值的关键条件
- 不要只给一个 PE 数字就下结论

## ⚠️ 数据准确性规范

**金融分析常见数据错误，必须规避：**

|#|常见错误|正确做法|
|---|---------|---------|
|1|金额单位混淆|成交额、市值等金额字段需明确原始单位（元/万元/亿元），输出前统一换算为"亿元"，禁止把原始值当成亿元直接使用。|
|2|股本单位混淆|总股本、流通股本注意区分"股"与"手"，输出前换算为"亿股"。|
|3|涨幅凭印象描述|涨跌幅必须用公式计算：(今收-昨收)/昨收×100%，禁止"大概涨了多少"。|
|4|把T+1数据当当日数据|资金流向等指标可能为上一交易日数据，不可描述为"今日主力净流入"。|
|5|高开/涨幅模糊描述|必须写明：如"高开3%（开盘6.87元，昨收6.54元）"，禁止写"高开明显"。|
|6|金融数据估算|禁止"大概""差不多"。所有数字必须计算后写出等于多少，不凭印象。|
|7|金额类数字必须逐位核实|看到大数字必须用计算器核实，不能凭印象估算。**凡是金额类数字，输出前必须验证一次。**|

**自检：输出报告前，逐项确认成交额、市值、股本、涨跌幅的单位是否正确换算。**

## 固定输出模板

1. 公司类型与估值方法
2. 当前估值水平
3. 市场预期拆解
4. 历史与行业对比
5. 重估或杀估值条件
6. 风险提示
7. 估值结论与投资建议
