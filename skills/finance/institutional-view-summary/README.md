# 观点梳理说明书

本目录是 `观点梳理` skill 的完整说明书，基于"观点对比智能体"原始提示词整理。

## 文件说明

- [SKILL.md](SKILL.md)：唯一执行说明，定义触发场景、输入识别、固定提示词、执行节奏、MCP 召回规则、输出目录、最终报告结构和质量红线。
- [user_guide.md](user_guide.md)：面向用户的一页式使用说明。

固定提示词（执行时按 `SKILL.md`"执行节奏"表即用即读、用完即卸，切勿一次性全部读入）：

- `01_检索关键词_纪要内资研报点评_提示词.txt`：将用户 query 转化为 5 组中文检索短语（纪要 / 内资研报 / 点评）
- `02_检索关键词_外资研报_提示词.txt`：将用户 query 转化为 5 组英文检索短语（外资研报）
- `03_生成器_提示词.txt`：基于召回底稿生成机构观点汇总表 + 共识与分歧总结

## 提示词与流程对应关系

| 步骤 | 用途 | 提示词文件 | 产出 |

| Query 改写（内资） | 生成中文检索关键词 | `01_检索关键词_纪要内资研报点评_提示词.txt` | 5 组中文查询短语 |
| Query 改写（外资） | 生成英文检索关键词 | `02_检索关键词_外资研报_提示词.txt` | 5 组英文查询短语 |

## 变量约定

填充提示词时统一替换：

- `{{target}}`：用户给出的研究对象（股票 / 行业 / 事件 / 宏观指标，或复合 query）
- `{{current_date}}`：当前日期，用于时效校验
- `{{timelimit}}`：观点时效下限；用户未指定时默认当前日期往前推 3 个月

本说明书是自包含版本，执行流程与质量校验以 `SKILL.md` 为准；最终输出格式仍以 `03_生成器_提示词.txt` 为准。如需把 `观点梳理` 注册为正式 skill，可直接采用本目录。
