# 观点梳理

> 给它一个研究对象——一只股票、一个行业、一条政策事件，甚至一个宏观指标，它自动翻遍纪要、内资研报、点评和外资研报，把"各家机构怎么看、共识在哪、分歧在哪"一次性串成一份可直接用的观点梳理报告。

**这是一个 AI 投研观点聚合助手，在对话框里给一个研究对象就能用，不用自己一家家翻研报、对纪要、理分歧。**

---

## 1、能做什么？

区别于"只看一家机构观点"或"只列研报标题"——观点梳理是一份**跨机构结构化观点报告**：先按研究对象改写检索关键词，再从纪要/内资研报/点评/外资研报四库召回，质量控制最多迭代 3 轮，最后输出机构观点汇总表和共识分歧分析。看的是**市场主流机构对同一对象的完整观点图谱**，而不是零散的单篇摘要。

具体来说，会自动做这几件事：

- **识别对象**：从 query 中提取股票/行业/事件/宏观指标，并识别观点类型（业绩点评、投资逻辑、配置建议等）
- **智能改写**：生成 5 组中文 + 5 组英文检索短语，提高召回覆盖率
- **分库召回**：纪要库、内资研报库、点评库、外资研报库分路检索，去重合并
- **质控迭代**：最多 3 轮重检，不达标则联网补充
- **汇总对比**：按机构输出观点表（发布日期倒序），再提炼共识与核心分歧

---

## 2、怎么用？

在对话框里给一个研究对象就行——

```
帮我对比一下贵州茅台各机构的最新观点
```

也可以指定时效或角度：

```
半导体行业近一个月券商投资逻辑汇总
碳酸锂板块机构观点有什么分歧
```

> **你只需准备**：一个研究对象（股票 / 行业 / 事件 / 宏观指标均可）。其余交给 AI。

---

## 3、多久跑一次？

**按需触发**，通常在跟踪个股/行业、准备投委会材料、梳理市场分歧、验证投资逻辑之前跑一次；标的出现重大事件（业绩、政策、价格拐点）时值得重跑刷新。

---

## 4、生成什么？

`**{研究对象}观点梳理_{日期}.md**` — 一份两部分结构的观点报告：

| 部分 | 内容 |
|:---|:---|
| 机构观点汇总表 | 按发布日期倒序，列：发布日期、机构名称、文档类型（路演纪要/研报/点评）、内容主题、核心观点 |
| 共识与分歧总结 | 开篇总述 → 机构共识（加粗小标题+数据）→ 核心分歧（对比不同阵营+量化差异） |

**仅以上两部分**，不含「投资要点小结」「研究对象确认」等额外章节；报告在「共识与分歧总结」结束后即收笔。

文档类型严格三选一：路演纪要 / 研报 / 点评

核心观点格式：`观点类型：**一句话提炼**` + 换行 + 详细论据（仅提炼句加粗，加粗后换行展示数据与事实）

机构覆盖目标：6 家以上券商及外资投行（不足则按实际数量输出）

---

## 5、输出在哪？

- 默认先在对话框完整输出报告，输出后会询问是否保存到资料库
- 用户确认保存时，报告写入 `{输出目录}/{研究对象}/观点梳理/{研究对象}观点梳理_{日期}.md`，首次运行自动逐级创建目录
- 用户也可在后续对话中随时要求保存

---

## 6、注意事项

- **歧义会先澄清**：简称、黑话、同名公司会先检索确认，不会望文生义
- **时效有门槛**：默认只收录近 3 个月观点，可指定更窄或更宽的时间窗
- **四库分路检索**：内资用中文短语，外资研报用英文短语，不混用
- **质控有迭代**：召回不达标最多重检 3 轮，仍不足则联网补充
- **观点全部有来源**：机构名称、观点内容、发布日期都来自检索，不编造
- **合规红线**：不引导披露未公开订单、未公告财务数据、内部目标或非公开信息
