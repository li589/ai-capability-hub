# 资讯查询 Skill

通过平安证券资讯知识库检索接口，根据用户的自然语言问题召回相关新闻、快讯与财经报道，
并整理为清晰、可读的回答。

## 何时使用

在用户意图落在「获取资讯/新闻/动态」时使用，例如：

- 「澜起科技最近有什么消息？」
- 「查一下科创芯片 ETF 的相关新闻」
- 「半导体板块最近有哪些报道？」
- 「长鑫科技申购的情况怎么样？」


## 前置条件

- 检查是否已经设置环境变量 `PINGAN_SKILL_APIKEY`（用于鉴权用的 API Key），如未设置，提示用户登录平安证券skill开放平台获取 https://stock.pingan.com/huodong/aiskill/skillPage/index.html#/
- 依赖 Python 库 `requests`。

## 如何调用

脚本为 `get_data.py`，通过命令行传参：

```bash
python scripts/get_data.py --question "用户问题" --top_k 5
```

参数说明：

- `--question`（必填）：用户的查询问题，直接透传用户原始诉求即可，可做适度的关键词归纳，
  例如把「澜起科技这几天涨这么多是因为啥」精简为「澜起科技 上涨 原因」，以提升召回质量。
- `--top_k`（可选，默认 5）：召回条数。用户想「多看几条」时可调大（如 10），
  只想要「最新一条/概览」时可调小（如 3）。


## 返回数据结构

脚本返回一个 **JSON 数组**，每个元素代表一条召回的资讯记录：

```json
[
  {
    "content": "{...一段被转义的 JSON 字符串...}",
    "score": 0.4,
    "title": "内容平台资讯_t7_483a7309",
    "metadata": {
      "path": "/profile_platform/knowledge-base/3/knowledge/document-detail?id=1462&kb_id=237",
      "description": "内容平台资讯_t7_483a7309"
    }
  }
]
```

关键点：**`content` 字段本身是一段 JSON 字符串，需要再次 `json.loads` 解析**，
解析后包含以下业务字段：

| 字段 | 含义 | 使用建议 |
| --- | --- | --- |
| `标题` | 资讯标题 | 展示为每条结果的主标题 |
| `描述` | 正文摘要 | 作为要点正文；可能为空 |
| `发布来源` | 发布渠道（如「同花顺7x24快讯」） | 标注来源 |
| `版权媒体` | 版权方媒体 | 与发布来源结合标注 |
| `日期` | 发布日期（YYYY-MM-DD） | 展示，并用于按时间排序 |
| `作者姓名` | 作者 | 有值时可标注，常为空 |
| `内容ID` | 资讯唯一 ID | 一般内部使用，不必展示给用户 |
| `副标题` / `副标题跳转链接` | 副标题及链接 | 有值时补充展示，常为空 |
| `版权类型` / `来源系统` | 内部分类字段 | 通常无需展示 |

外层字段中：`score` 为相关性得分（越高越相关，可用于排序或过滤低相关结果），
`title` 与 `metadata` 为知识库文档元信息，一般不直接展示给用户。

## 结果整理与回答

拿到数组后按如下方式组织回答：

1. 对每条记录，解析其 `content` 得到业务字段。
2. 建议按 `日期` 由新到旧排序（同日期可参考 `score` 排序），突出最新动态。
3. 可对明显偏离主题的低分结果（如 `score` 过低）做适当过滤或降权。
4. 用简洁的中文条目呈现，每条包含：标题、摘要要点、来源与日期。
5. 若多条资讯指向同一事件，做归纳总结而非逐条罗列。
6. 结尾可给出一句基于资讯的整体概述，但**只陈述资讯内容本身，不做买卖建议或投资判断**。


## 空结果处理

若返回为空数组或没有相关性较高的记录，如实告知用户「暂未检索到相关资讯」，
可建议用户换用更具体或更宽泛的关键词重试，切勿编造资讯内容。

## 错误处理

脚本出错时会向 **stderr** 打印形如 `{"error": "错误信息"}` 的 JSON 并以非零状态码退出。
常见错误及对用户的话术：

| 触发情形 | 脚本返回信息 | 建议向用户说明 |
| --- | --- | --- |
| 未设置 API Key | 缺少环境变量 PINGAN_SKILL_APIKEY | 配置缺失，请联系管理员 |
| HTTP 401 | 缺少 API Key。 | 鉴权失败，请联系管理员 |
| HTTP 403 | API Key 无效或没有权限。 | 无访问权限，请联系管理员 |
| HTTP 429（RATE_LIMIT_EXCEEDED） | 接口调用频率超限。 | 请求过于频繁，请稍后再试 |
| HTTP 429（DAILY_QUOTA_EXCEEDED） | 今日调用次数已达上限。 | 今日额度已用完，请明日再试 |
| HTTP 503 | 服务暂时不可用，请稍后重试。 | 服务临时不可用，请稍后重试 |

捕获到上述错误时，向用户给出**简洁、非技术性**的提示，不要把原始异常栈或 API Key 暴露给用户。

## 注意事项

- 所有对外展示的资讯均来自知识库检索结果，需**忠实于原文**，不添加未经验证的信息。
- 涉及具体涨跌幅、成交额、日期等数字时，直接引用返回数据，不要臆测。
- 本 Skill 仅提供资讯查询，**不构成任何投资建议**；如用户询问买卖决策，应说明这一点。
