# 相关技能与组合用法

本技能（会员体系搭建）与两个姊妹技能构成「私域用户运营」协同链：本技能搭**会员体系**，私域用户运营技能做**价值分层**，私域标签体系技能搭**标签底座**。三者互补，可独立用、也可串成完整 SOP。

## 边界划分

| 维度 | 本技能（会员积分体系） | 私域用户运营（分层+画像+触达） | 私域标签体系搭建 |
|---|---|---|---|
| 回答的问题 | 怎么发积分、设几级、配什么权益、算不亏本（会员忠诚度体系） | 谁是谁、值多少、该怎么对待（价值分层与触达） | 怎么搭一套不腐烂的标签资产（标签底座） |
| 产出 | 会员积分四件套（等级表+积分规则+权益矩阵+财务测算） | RFM 分层表 + 画像卡 + 触达策略表 | 标签体系四件套（架构+字典+治理+路线） |
| 会员等级的角色 | 等级是设计主体（定级货币/晋级/保级/降级） | 会员等级是事实标签枚举值（消费侧维度） | 会员等级是跨系统治理对象（不同源对齐） |
| 积分的角色 | 积分是设计主体（获取/消耗/财务测算） | 积分行为作为分层行为标签的来源 | 积分是行为统计 10 子域之一的埋点口径 |
| 独立可用 | 是 | 是 | 是 |

## 原语共享与咬合

- **等级门槛 ← 价值分层**：本技能第 2 步等级晋级门槛，可消费「私域用户运营」产出的 RFM/LTV 价值分层结果作分层依据（引用不重算），避免等级门槛拍脑袋。
- **会员等级 → 事实标签**：本技能产出的会员等级，作为「私域用户运营」画像卡的事实标签枚举值回填。
- **积分行为 → 标签原语**：本技能产出的积分行为（CONSUME/SIGN_IN/REVIEW 等 action_type 枚举），反哺「私域标签体系搭建」的行为统计子域口径作原语来源。

## 怎么组合

1. **先分层、再定会员等级、最后配权益触达（推荐完整 SOP）**：
   - 用「私域用户运营」技能做 RFM/LTV 价值分层，看清用户价值分布
   - 用本技能：把价值分层结果映射为会员等级门槛，设计积分规则与权益矩阵
   - 用「私域用户运营」触达策略表：按会员等级执行差异化触达（高等级低频高价值、长尾自动化）

2. **只搭会员体系（用户目标明确是「设计会员积分体系」）**：
   - 直接用本技能，四件套即可
   - 等级门槛可先按行业默认档，后续接价值分层校准

3. **已有会员体系、回头治理（通胀/负债/鸡肋/薅羊毛）**：
   - 用本技能诊断现有体系（兑换率<15%/沉淀率>85%/ROI<1/无有效期等异常）
   - 治理后把规整的会员等级与积分行为反哺给分层触达与标签体系技能

## 一句话区分用户该用哪个

- 用户说「帮我从0设计会员积分体系/定等级设权益/算积分汇率预算」 → 本技能（会员积分体系）
- 用户说「帮我把用户按价值分层、做差异化触达」 → 私域用户运营（分层+触达）
- 用户说「帮我搭一套标签底座/治理乱标签」 → 私域标签体系搭建
- 用户说「私域会员运营整体做一版」 → 三者串起来：分层 → 会员体系 → 触达
