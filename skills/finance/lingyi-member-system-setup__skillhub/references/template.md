# 会员体系搭建模板

使用本模板来产出会员体系四件套：会员等级成长表、积分获取消耗规则表、权益配置矩阵、积分财务测算表（+ 可选付费会员卡子表）。按行业选默认参数档填空，每张表后过质量检查。

> **三行业默认参数档**（按所属行业套用，再微调）：
> - **餐饮**（高频复购）：4-5 级 / 1 元=1 成长值+1 积分 / 90 天滚动保级 / 体验特权（升杯·赠饮·优先取餐·生日券）/ 预算营收 1%
> - **零售**（客单周期）：6 级 / 消费分+行为分（签到·打卡·评价·晒单·完善资料）/ 年制保级 / 价格+服务特权（会员价·2倍积分·育儿顾问）/ 营收 1.5%
> - **电商**（跨品类省钱）：无等级付费一卡通 149-199 元 / 品类返利 0.5%-2%（京豆式）/ 生态+售后特权（免邮·专享价·95折·180天只换不修·生活服务包）

## 四、积分财务测算表

### 核心测算

| 项目 | 公式 | 计划值 |
|---|---|---|
| 积分预算 | 固定比例法=营收×n% / 固定金额法 | [月5万/年60万] |
| 单积分价值 | = 总预算 / 总发放量 | [0.01元/分] |
| 总发放量(时间维度) | = 单日发放 × 365 × n(n=1.1-1.2容错) | [6000万分/年] |
| 总发放量(用户维度) | = 单人发放 × 总用户数 × n | [校验值] |
| 月度成本 | = 月度发放量 × 单积分价值 × 实际履行率 | [500万分×0.01×0.5=2.5万/月] |
| 目标兑换率 | 正常区间15%-30% | [20%] |
| 沉淀率 | = 1 - 兑换率 | [80%] |
| 财务计提成本 | = 沉淀积分 × 单积分价值 | [测算值] |
| 积分负债 | 合同负债科目(发分增/消耗减) | [账面值] |
| 单等级权益成本ROI | = 人均权益成本 / 人均贡献毛利 | [≥1续档/<1砍权益] |

### 7大运营指标（带警戒阈值）

| 指标 | 计划值 | 实际值 | 警戒 |
|---|---|---|---|
| 计划发放积分数 | [600万分/月] | - | 超预算×1.2预警 |
| 实际发放积分数 | - | - | 同上 |
| 积分兑换率 | [20%] | - | <15%获取易消耗难；>50%门槛过低 |
| 用户使用率 | [30%] | - | <20%权益吸引力不足 |
| 新增客单价 | [↑X%] | - | - |
| 复购率 | [↑X%] | - | - |
| 订单占比 | [X%] | - | - |

涉税与会计脚注：消费积分兑换礼品不征个税(财税〔2011〕50号)；签到/注册积分兑换视同销售计销项税；企业所得税积分对应收入递延至兑换或失效时确认；积分负债计入「合同负债」科目，收入分摊用相对公允价值法。

**质量检查：** 单积分价值有具体数值(禁"按市场行情")；月度成本三要素齐；兑换率落15%-30%；积分负债按合同负债科目(禁商户补偿误记收入)；数据薄用预算比法简化起步
