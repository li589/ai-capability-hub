## 1. 资产配置理论速查

| 理论 | 核心结论 | 在本 skill 的落地 |
|------|---------|------------------|
| 美林时钟 | 复苏股/过热商品/滞胀现金/衰退债 | TAA 战术偏离的宏观依据 |
| 均值-方差 | 分散化改善有效前沿 | `optimize_mean_variance` |
| 风险平价 | 等风险贡献比等金额更稳 | `optimize_equal_risk` |
| Black-Litterman | 市场均衡+主观观点融合 | `portfolio_rebalancer.py` |
| 生命周期理论 | 人力资本随年龄下降→权益递减 | `glide_path` 下滑曲线 |
| 核心-卫星 | 核心低成本贝塔+卫星超额 | `core_satellite` |

**经验法则**：
- 权益中枢 ≈ (100 − 年龄)% 或 (110 − 年龄)%（进取）
- 单一主动基金 ≤ 组合 15%；单一行业 ≤ 25%；单一主题 ≤ 20%
- 再平衡带宽 ±5%（相对目标比例），时间维度季度检视
- 股债相关性长期约 0~-0.3，是最便宜的分散来源

## 2. 组合管理实践

**构建顺序**（不可逆）：风险画像 → SAA → TAA 偏离 → 选基 → 建仓节奏 → 跟踪规则。

**建仓节奏**：
- 一次性资金：分 3-6 批，每周/双周一批，降低择时风险
- 定投：月定投优先发薪日后 1-2 日；止盈不止损（权益定投）
- 大额赎回预留：未来 6 个月确定性支出 → 货基/短债隔离

**持有期纪律**：
- 主动基金考察期 ≥ 2 个完整季度，不因单月排名调整
- 基金经理变更 → 立即检视（历史业绩归属前任）
- 规模 >150 亿的主动股基超额能力通常衰减；<1 亿有清盘风险

## 3. 基金评估要点

- **业绩看 3 年不看 3 个月**：近 1/2/3 年均在同类前 50% 才是真稳定
- **看风险调整后收益**：夏普/索提诺/卡玛优先于绝对收益
- **看回撤修复能力**：最大回撤幅度 + 修复天数；修复 >1 年说明风控弱
- **看经理稳定性**：任职 ≥3 年、管理规模适中、无频繁跳槽
- **看费率**：主动股基综合费率 >1.5%/年 偏高；同类选费率低者，长期复利差距显著
- **看机构持仓**：机构占比 30-70% 为佳（>80% 警惕机构赎回冲击）
- **滚动夏普**：连续 3 个月 <0 是质量恶化先行信号

## 4. 行为金融（客户沟通）

| 偏差 | 表现 | 应对话术方向 |
|------|------|------------|
| 损失厌恶 | 亏 1 万的痛 ≈ 赚 2 万的喜 | 先共情，再给数据，避免"早知如此" |
| 锚定效应 | 死等回本价 | 引导看"当前是否值得持有"而非"成本价" |
| 追涨杀跌 | 涨时加仓跌时赎回 | 给选择不给指令；提示分批纪律 |
| 过度自信 | 满仓单一赛道 | 用最大回撤历史数据具象化风险 |
| 近期偏差 | 用近 3 个月推未来 | 展示完整牛熊周期的同类表现 |
| 处置效应 | 卖盈持亏 | 提醒"卖出亏损基金≠承认失败" |

**沟通铁律**：不承诺收益、不预测短期涨跌、不制造紧迫感、亏损时先共情再分析。

## 5. 费用与税务

- **申购费**：场外通常 1.5%（1 折后 0.15%）；C 类份额免申购费但有销售服务费 0.4-0.8%/年，持有 <1 年选 C，≥1 年选 A
- **赎回费**：持有 <7 天惩罚性 1.5%；7 天-1 年约 0.5%；≥2 年多数免收 → 调仓时先查持有天数
- **转换**：基金转换通常比先赎后买省费用省时间
- **分红**：现金分红免税但降低净值；红利再投资免申购费
- **场内 ETF**：佣金约万 1-万 3，无印花税（基金层面）；注意折溢价
- **个人养老金账户**：每年 1.2 万额度内递延纳税，领取时 3% 单独计税

## 6. 合规红线与适当性

- **适当性匹配**：基金风险等级 > 客户风险承受等级时，必须警示并给出替代（`suitability_check`）
- **禁止行为**：承诺保本保收益、代客操作账户、推荐与画像明显不匹配的产品、诱导频繁交易
- **表述规范**：用"历史业绩不代表未来""数据仅供辅助参考，不构成投资建议"；收益数字必须带时间区间与基准
- **信息边界**：本 skill 为辅助工具，正式投顾业务需持牌；客户明确要求"替我操作"时必须拒绝并说明
- **数据诚实**：估算/降级/缺失数据必须明示，不得把降级数据当真实业绩展示
