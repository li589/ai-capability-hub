# 事件分析 Skill

## 功能描述

本技能用于对个股 / 行业重大事件进行专业解读，覆盖公告、业绩、政策、中标、合作、减持、解禁、重组、处罚等各类事件，客观判断事件利好 / 中性 / 利空、影响强度、传导路径、持续性及对公司 / 行业的实际作用，不主观预测涨跌，仅输出事件层面专业结论，适配 AI 诊股、公告解读场景。

## 使用方法

当用户询问股票公告、重大事件、利好利空、事件影响、政策事件、业绩事件、减持 / 中标 / 解禁影响时自动触发。

## 分析框架

> **核心原则**：严格按事件实质判断利好 / 利空，不主观放大；既讲正面，也讲不确定性；区分一次性与长期影响。

### 一、事件基本信息

#### 1. 关键内容
- **事件类型**：业绩类 / 政策类 / 业务类 / 资本类 / 风险类
- **发布主体**：公司 / 监管 / 行业 / 政府
- **核心内容**：事件关键信息、金额、比例、期限
- **发布时间**：最新公告 / 事件发生时间

#### 2. 事件类型分类

| 事件类型 | 具体事件 |
|---------|---------|
| **业绩类** | 业绩预告、财报、分红、回购 |
| **业务类** | 中标、签约、合作、投产、订单 |
| **政策类** | 行业新政、监管规则、补贴、限制 |
| **资本类** | 减持、增持、解禁、定增、重组 |
| **风险类** | 处罚、诉讼、亏损、违约、停产 |

本步骤所需数据来自接口返回的**公司公告与事件**及**互动问答记录**，包括公告日期、公告类型、公告主标题、公告内容、公告摘要、PDF 链接，以及投资者提问时间、问题内容、回答时间、回答内容、新闻来源等字段。

---

### 二、事件性质判断（核心：利好 / 中性 / 利空）

#### 1. 关键指标
- **方向**：利好 / 中性 / 利空
- **强度**：强 / 中 / 弱
- **市场共识**：一致认可 / 存在分歧

#### 2. 判断标准

**强利好：**
- 直接增厚业绩 / 打开成长空间 / 大幅改善经营
- 金额大、量级高、超市场预期

**中利好：**
- 对经营有正面帮助，但幅度一般
- 符合市场预期，无超预期增量

**中性：**
- 对业绩、经营无实质影响
- 常规公告、例行信息披露

**中利空：**
- 短期有压力，但不影响长期基本面
- 符合预期，无重大恶化

**强利空：**
- 直接损害业绩 / 合规风险 / 经营恶化
- 超预期恶化，影响长期逻辑

#### 3. 事件类型与性质对照

| 事件类型 | 强利好 | 中利好 | 中性 | 中利空 | 强利空 |
|---------|-------|-------|------|-------|-------|
| **业绩类** | 业绩预增超预期、大额分红回购 | 业绩符合预期 | 业绩持平 | 业绩略低于预期 | 业绩预亏、大幅下修 |
| **业务类** | 大额中标、重大合作落地 | 常规中标、合作意向 | 常规订单 | 订单取消 | 大客户流失 |
| **政策类** | 行业补贴、准入放宽 | 政策预期兑现 | 政策维持 | 补贴退坡 | 行业限制、监管趋严 |
| **资本类** | 大股东增持、定增成功 | 小额增持 | 常规解禁 | 减持计划 | 大额减持、违规减持 |
| **风险类** | 诉讼胜诉、处罚解除 | 风险澄清 | 常规披露 | 小额处罚 | 重大处罚、停产整顿 |

本步骤所需数据来自接口返回的**研报明细**及**机构调研记录**，包括研报日期、机构名称、标准评级、目标价、研究员、研报标题、调研时间、调研地点、接待人、参与对象、大事概要等字段，用于对比市场预期并判断事件是否超预期。

---

### 三、影响传导路径

#### 1. 关键维度
- **对经营**：订单 / 收入 / 市占率 / 竞争力
- **对财务**：营收 / 利润 / 现金流 / 估值
- **对行业**：格局 / 景气度 / 竞争规则
- **对股价**：短期情绪 / 中期基本面

#### 2. 传导逻辑

**直接影响：**
- 立即体现业绩 / 经营（如中标、回购）
- 金额、比例可量化，对财务影响明确

**间接影响：**
- 逐步落地，中长期见效（如合作、政策）
- 需后续执行、市场拓展才能兑现

**无影响：**
- 仅情绪波动，无基本面变化
- 常规信息披露，市场已有预期

本步骤所需数据来自接口返回的**研报明细**，从研报中判断事件对行业格局的影响。

---

### 四、事件持续性

#### 1. 持续类型

**一次性：**
- 单次事件，无后续影响（如一次性分红、单次中标）
- 影响仅体现在当期

**阶段性：**
- 影响持续一段时间（如合作项目执行期、政策有效期）
- 影响在特定周期内逐步体现

**长期性：**
- 改变长期基本面（如重组、重大技术突破、行业格局重塑）
- 影响持续多年，改变公司 / 行业长期逻辑

#### 2. 影响周期判断

| 持续类型 | 影响周期 | 典型事件 |
|---------|---------|---------|
| 一次性 | 1 个季度以内 | 单次分红、常规中标 |
| 阶段性 | 6-12 个月 | 合作项目、订单执行 |
| 长期性 | 1-3 年 | 重组、技术突破、政策红利 |

---

### 五、风险分析

#### 1. 风险类型

**落地风险：**
- 事件能否顺利执行（如合作项目能否落地、中标项目能否签约）
- 执行进度、验收标准存在不确定性

**兑现风险：**
- 业绩 / 订单能否如期兑现（如业绩承诺、订单交付）
- 市场环境变化导致兑现不及预期

**市场反应风险：**
- 利好兑现成利空（"买预期卖事实"）
- 利空超预期发酵（恐慌情绪蔓延）

#### 2. 风险等级

**低风险：**
- 事件确定性强，执行难度低
- 市场已有充分预期

**中风险：**
- 存在一定执行不确定性
- 市场反应可能存在波动

**高风险：**
- 事件执行难度大，不确定性高
- 可能引发市场剧烈反应

## 分析流程（COT）

### 第一步：数据获取

调用接口获取本次分析所需的全部数据，来源包括：
1. **公司公告与事件**（事件原文，核心数据源）
2. **互动问答记录**（市场对事件的关注与公司解释）
3. **研报明细**（市场预期，判断事件是否超预期）
4. **机构调研记录**（事件后机构关注度变化）

### 第二步：事件梳理

1. **明确事件类型**：业绩类 / 业务类 / 政策类 / 资本类 / 风险类
2. **提取核心信息**：金额、比例、期限、涉及主体
3. **确认发布时间**：最新公告 / 历史事件

### 第三步：性质判断

判定：**利好 / 中性 / 利空** + **强度（强 / 中 / 弱）**
- 对比市场预期：超预期 / 符合预期 / 低于预期
- 参考事件类型对照表，结合具体数据判断

### 第四步：影响分析

判断对经营、财务、行业、股价的传导路径：
- **直接影响** vs **间接影响** vs **无实质影响**
- 量化影响程度（如营收增厚 XX%、利润增加 XX 亿元）

### 第五步：持续性和风险判断

- **持续类型**：一次性 / 阶段性 / 长期性
- **影响周期**：短期 / 中期 / 长期
- **风险等级**：低 / 中 / 高

### 第六步：综合研判

- 给出事件核心结论与观察重点
- 提炼亮点与风险点
- 不预测涨跌，仅陈述事件客观影响

## 注意事项

1. **数据时效性**
   - 优先使用最新公告、官方原文
   - 注明事件 / 公告发布时间
   - 信息以公司 / 监管官方披露为准

2. **客观中立**
   - 严格按事件实质判断利好 / 利空，不主观放大
   - 既讲正面，也讲不确定性
   - 禁止"必涨""必跌"等绝对化表述

3. **区分一次性与长期**
   - 严禁把一次性利好当长期成长
   - 严禁把短期扰动当成长期利空

4. **逻辑自洽**
   - 影响结论必须与事件内容、数据匹配
   - 强度、持续性、传导路径前后一致

5. **市场预期**
   - 区分"符合预期"与"超预期"
   - 利好落地、利空出清要明确说明

## 示例分析

**用户输入**："拓维信息子公司中标人工智能算力服务项目，怎么解读"

**分析结果**：

```markdown
## 【拓维信息 (002261)】事件解读报告

**【事件名称】**：子公司中标人工智能算力服务项目  
**【发布时间】**：2026年2月28日

### 一、核心看点
公司中标**AI算力服务重大项目**，属于**中利好**事件，直接增厚短期订单与业绩，属于业务层面实质性利好，为阶段性影响、中长期持续贡献收入。

### 二、事件核心影响（正面 + 潜在风险）

**正面影响：**
1. **直接增厚业绩**：中标金额较大，直接带来新增订单与营收增量，预计对未来一期财报产生正面贡献
2. **强化业务地位**：验证公司AI算力业务竞争力，提升行业认可度与品牌影响力
3. **示范效应**：为后续算力项目拓展提供成功案例，有助于获取更多同类订单

**潜在风险/不确定性：**
1. **项目执行风险**：项目执行与验收存在一定周期，收入确认时点存在不确定性
2. **利润水平不确定**：订单利润水平受执行成本、竞争环境影响，存在小幅波动可能
3. **市场反应风险**：短期利好或存在资金兑现波动，需警惕"买预期卖事实"

### 三、综合解读

#### （一）事件基本信息
- 事件类型：业务类（中标项目）
- 核心内容：子公司中标区域人工智能算力服务项目
- 涉及数据：中标金额构成公司年度营收一定增量

#### （二）事件性质判断
- 多空方向：**利好**
- 影响强度：**中**
- 结论：**符合预期**（符合市场对公司算力业务的扩张预期，无显著超预期）

#### （三）影响传导路径
- 对经营：提升算力业务收入与市占率，强化AI业务布局
- 对财务：直接增厚未来一期营收与利润，改善现金流
- 对行业/股价：短期正面情绪催化，中期基本面支撑
- 结论：**直接影响**业绩与业务布局

#### （四）事件持续性
- 持续类型：**阶段性**
- 影响周期：**中期（6-12个月）**
- 结论：非一次性收益，可逐步兑现收入，对中期业绩形成支撑

#### （五）不确定性与风险
- 核心不确定性：项目执行进度与收入确认时点
- 风险等级：**低**
- 结论：风险可控，不影响核心投资逻辑

### 四、解读建议

**1. 核心结论**
本次中标为**实质性业务利好**，验证公司AI算力业务竞争力，对业绩与经营均有正面支撑，属于中性偏强利好。事件符合市场预期，不构成短期追涨依据，建议关注项目后续执行与同类订单拓展情况。

**2. 关键观察**
- 观察 1：项目后续合同签订与执行进度，收入确认时点
```
