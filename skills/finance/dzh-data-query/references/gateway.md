# 网络搜索与智能选股（gateway）

> 本文件用于高级显式工具模式。基础查询可以只向 `dzh-data-query` 传入完整 `query`，由服务端自动选择工具；需要精确控制工具和参数时再使用本文件。

## 适用场景

- **网络搜索**：查询网络上的最新财经资讯、新闻、公告，或需要实时舆情参考时
- **智能选股**：按涨跌幅、市值、财务指标、技术指标等多条件筛选股票

## 典型问题

- 最近有哪些关于比亚迪的财经报道？
- 帮我找涨幅大于1%且市值小于20亿的股票
- 筛选昨日成交量放量超3倍的小盘股
- 搜索茅台最新分析文章

## 推荐工具

### 1. data-gateway-webFinanceSearch — 财经资讯网络搜索

- 用途：搜索网络上的财经资讯，返回相关新闻摘要与来源链接
- 参数说明：
  - `query`：必填，字符串，搜索关键词或问句
  - `size`：可选，整数，返回条数，默认 10

```json
{"name": "data-gateway-webFinanceSearch",
 "params": {"query": "贵州茅台最新财经资讯", "size": 5}}
```

### 2. data-gateway-selectStocks — 智能选股

- 用途：根据用户自然语言描述的条件筛选 A 股股票
- 参数说明：
  - `query`：必填，字符串，用自然语言描述的选股条件，应尽量完整表达所有筛选维度
- 注意：此工具内部调用流式接口，自动处理 SSE 流；结果包含满足条件的股票列表、总数量和各单项条件命中情况

```json
{"name": "data-gateway-selectStocks",
 "params": {"query": "涨幅大于1小于2，市值小于20亿元的股票"}}
```

## 注意事项

- `data-gateway-webFinanceSearch` 结果已去除 `site` 字段，直接用于回答。
- `data-gateway-selectStocks` 的 `query` 应是完整句子，尽量包含所有筛选维度，避免条件遗漏。
- 智能选股工具不参与实体识别，`query` 传选股条件本身，不需要嵌入股票代码。
