# 券商行情查询 Skill

## 这个 Skill 做什么

查询实时/历史市场数据，覆盖 5 类场景：个股/股指/ETF 行情、板块行情、板块成分股、主力资金流向、历史 K 线。所有请求都通过 `scripts/get_data.py` 这一个脚本发出——每个接口对应一个固定的 `options` 子命令。

#### 任何时候都应该用这个 skill 实际查询，不要依赖训练知识回答股价、涨跌幅等具体数字。

## 环境准备

- 检查是否已经设置环境变量 `PINGAN_SKILL_APIKEY`（用于鉴权用的 API Key），如未设置，提示用户登录平安证券skill开放平台获取 https://stock.pingan.com/huodong/aiskill/skillPage/index.html#/
- 依赖 Python 库 `requests`。

## 基本调用格式

```bash
python scripts/get_data.py <options> [参数...]
```

## 参数一览

| options | 说明 |  必填参数 | 限制 |
|---|---|---|---|
| `quote` | 股票/股指/ETF 实时行情（支持批量） | `codes`（数组） | 同一接口按代码区分标的类型，最多同时查询5个股票/股指/ETF代码 |
| `sector` | 板块实时行情 | `sector_code`（单个） | — |
| `sector_stocks` | 板块成分股实时变动 | `sector_code`（单个） | `limit` 默认 5，范围 1～20 |
| `fundflow` | 主力资金流向 | `codes`（数组） | 最多 5 个代码 |
| `kline` | 历史 K 线数据（日线） | `code`（单个） | `last_n` 最大 50，不传默认最近 5 个交易日 |

代码格式统一为「市场代码 + 证券代码」，例如 `SH600519`、`SZ000001`，不要传裸代码或带点号的写法（如 `600519.SH`）。

## 1. quote — 股票/股指/ETF 实时行情查询

获取指定股票/股指/ETF 的实时行情，支持批量查询（最多同时查询5个）。

**请求参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `codes` | String[] | 代码列表，例如 `["SH600519", "SZ000001"]` |

**返回字段**（`items[]`，部分字段仅 ETF 才有）

| 字段 | 说明 |
|---|---|
| `code` / `name` | 代码 / 名称 |
| `price` | 最新价/点位（元/点） |
| `change` / `change_pct` | 涨跌额（元） / 涨跌幅（%） |
| `open` / `high` / `low` / `prev_close` | 今开 / 最高 / 最低 / 昨收（元） |
| `volume` / `amount` | 累计成交量（股） / 成交额（元），均自开盘起算 |
| `turnover_pct` | 换手率（%） |
| `pe_ttm` / `pb` | 滚动市盈率 / 市净率（倍） |
| `market_cap` / `circ_market_cap` | 总市值 / 流通市值（元） |
| `tracking_index` | 仅 ETF：跟踪指数代码（非名称） |
| `premium_rate` | 仅 ETF：折溢价率，正为溢价（%） |
| `fund_size` | 仅 ETF：基金规模/净资产（元） |
| `iopv` | 仅 ETF：基金份额参考净值（元） |
| `not_found` | 无效代码列表，部分失败时才出现 |

**调用示例**

```bash
python scripts/get_data.py quote --codes SH600519,SZ000001
```

`--codes` 用逗号分隔字符串传入，例如 `--codes SH600519,SZ000001`。

## 2. sector — 板块实时行情

获取单个指定板块（行业板块、概念板块）或指数的实时行情。

**请求参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `sector_code` | string | 板块代码 |

**返回字段**（`items[]`）

| 字段 | 说明 |
|---|---|
| `sector_code` / `sector_name` | 板块代码 / 名称 |
| `change_pct` | 板块整体涨跌幅（%） |
| `leading_stock_code` / `leading_stock_name` / `leading_stock_change_pct` | 领涨股代码 / 名称 / 涨跌幅（%） |
| `amount` | 板块成分股总成交额（元） |
| `stock_count` / `up_count` / `down_count` / `flat_count` | 成分股总数 / 上涨 / 下跌 / 平盘家数 |

**调用示例**

```bash
python scripts/get_data.py sector --sector_code PA90501002
```
> 板块代码参考下方 [板块代码列表]例如 `90501002` 表示半导体板块。

## 3. sector_stocks — 板块成分股实时变动

获取某板块下的成分股列表及基础行情，默认按涨幅字段倒序排列。

**请求参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `sector_code` | string | 板块代码 |
| `limit` | int | 返回条数，默认 5，范围 1～20 |

**返回字段**

顶层：`sector_code`、`sector_name`；`items[]` 内为成分股：

| 字段 | 说明 |
|---|---|
| `code` / `name` | 成分股代码 / 名称 |
| `price` | 最新价（元） |
| `change_pct` | 涨跌幅（%） |
| `amount` | 成交额（元） |

**调用示例**

```bash
python scripts/get_data.py sector_stocks --sector_code PA90501002 --limit 10
```

## 4. fundflow — 主力资金流向数据

获取股票/板块的资金流向数据，**最多支持 5 个代码**。

**请求参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `codes` | String[] | 最多 5 个，股票或板块代码 |

**返回字段**（`items[]`）

| 字段 | 说明 |
|---|---|
| `code` / `name` | 代码 / 名称 |
| `main_net_inflow` | 主力净流入（超大单+大单）（元） |
| `main_net_inflow_pct` | 主力净流入 / 成交额；成交额为 0 或负值时为 `null` |
| `super_large_net_inflow` / `large_net_inflow` | 超大单 / 大单净流入合计（元） |
| `amount` | 总成交额（元） |
| `not_found` | 无效代码列表，部分失败时才出现 |

**调用示例**

```bash
python scripts/get_data.py fundflow --codes SH600519,SZ000001
```

传入超过 5 个代码会在本地被直接拦截，报错「参数 codes 最多支持 5 个」，不会发起网络请求。

## 5. kline — 历史K线数据

获取单个股票的历史 K 线数据（日线，默认前复权）。

**请求参数**

| 参数 | 类型 | 说明 |
|---|---|---|
| `code` | string | 股票代码 |
| `last_n` | int | 取最近 N 个交易日，最大 180，不传默认取最近 5 个交易日 |

**返回字段**

`items[]`（通常一个 `code` 对应一项）：

| 字段 | 说明 |
|---|---|
| `code` / `name` | 股票代码 / 名称 |
| `period` | K 线周期，固定为 `day` |
| `adjust` | 复权方式，默认前复权 |
| `start_date` / `end_date` | 实际返回的起止日期 |
| `bars[]` | K 线数组，见下 |

`bars[]` 内每根 K 线：

| 字段 | 说明 |
|---|---|
| `date` | 交易日（YYYY-MM-DD） |
| `open` / `high` / `low` / `close` | 开 / 高 / 低 / 收盘价（元，已按 adjust 调整） |
| `change_pct` | 当日涨跌幅（%），首根为 `null` |
| `volume` / `amount` | 成交量（股） / 成交额（元） |

**调用示例**

```bash
python scripts/get_data.py kline --code SH600519 --last_n 20

# 不传 --last_n，网关默认取最近 5 个交易日
python scripts/get_data.py kline --code SH600519
```

---

每个子命令的参数和取值范围可以直接看帮助信息：

```bash
python scripts/get_data.py quote -h
python scripts/get_data.py kline -h
```
