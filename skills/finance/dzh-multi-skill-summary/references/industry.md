# 行业分析

## 功能描述

本技能用于对行业进行专业全景分析，核心聚焦「行业景气度、行业格局、政策与环境、投资机会、行业风险」五大核心维度，客观判断行业当前景气水平、发展趋势、核心投资逻辑及潜在风险，提炼可关注的细分领域与标的方向，不做具体个股荐股，仅输出行业层面专业结论，适配 AI 诊股、行业研究场景落地。

## 分析框架

> **核心原则**：机会与风险同步呈现，不弱化风险、不夸大亮点；不同类型行业判断标准差异化，不套用统一模板。

### 一、行业景气度（核心：判断行业当前冷暖）

#### 1. 关键指标
- 行业整体增速（营收 / 产值同比增速）
- 景气度核心指标（PMI、产能利用率、开工率、订单增速）
- 需求端（下游需求增速、需求结构变化）
- 供给端（产能扩张 / 收缩、库存水平）
- 盈利水平（行业平均毛利率、净利率变化）

#### 2. 判断标准

**高景气（值得重点关注）：**
- 行业增速 ≥ 15%，显著高于 GDP 增速
- 景气度指标向好（PMI > 50、产能利用率 ≥ 85%、订单增速 ≥ 20%）
- 需求旺盛、供给紧张，行业盈利持续提升

**中景气（稳健关注）：**
- 行业增速 5%~15%，与 GDP 增速持平或略高
- 景气度指标平稳（PMI 48~52、产能利用率 75%~85%）
- 供需平衡，盈利水平稳定

**低景气（谨慎关注）：**
- 行业增速 0%~5%，低于 GDP 增速
- 景气度指标偏弱（PMI < 48、产能利用率 65%~75%）
- 需求疲软、供给过剩，盈利水平承压

**衰退（警惕风险）：**
- 行业增速 < 0%，出现负增长
- 景气度指标恶化（PMI < 45、产能利用率 < 65%）
- 需求萎缩、库存高企，盈利大幅下滑

#### 3. 行业特性适配
- **成长型行业（AI、储能、创新药）**：高景气阈值可放宽至 20% 以上，重点看需求爆发节奏
- **成熟型行业（消费、家电、传统制造）**：中景气（5%~10%）即为优质，重点看盈利稳定性
- **周期型行业（钢铁、煤炭、有色）**：景气度随周期波动，重点看产能利用率、产品价格
- **防御型行业（医药、公用事业）**：低景气（0%~5%）仍具配置价值，重点看需求刚性

数据来源：研报明细（景气度分析）、机构调研记录（行业调研信息）、公司公告与事件（行业相关公告）。

### 二、行业格局与竞争态势

#### 1. 关键指标
- 行业集中度（CR3、CR5、CR10）
- 竞争格局类型（垄断、寡头、充分竞争、分散竞争）
- 龙头企业市占率及优势
- 行业壁垒（技术、资金、资质、渠道）

#### 2. 判断标准

**格局优质（投资确定性高）：**
- 行业集中度高（CR3 ≥ 60%），寡头 / 垄断格局
- 龙头企业优势明显，壁垒深厚，竞争压力小
- 行业盈利稳定性强，龙头溢价显著

**格局一般（投资需择机）：**
- 行业集中度中等（CR3 30%~60%），充分竞争格局
- 龙头与中小企业差距不大，竞争激烈
- 盈利水平分化，需关注优势企业

**格局较差（投资风险高）：**
- 行业集中度低（CR3 < 30%），分散竞争格局
- 无明显龙头，同质化竞争严重
- 盈利水平低且波动大，行业洗牌风险高

#### 3. 行业特性适配
- **技术密集型行业（半导体、AI）**：格局取决于技术壁垒，龙头技术优势决定集中度
- **资本密集型行业（新能源、化工）**：格局取决于产能规模，集中度随行业成熟提升
- **劳动密集型行业（纺织、轻工）**：格局分散，竞争以价格战为主，盈利波动大
- **政策导向型行业（军工、环保）**：格局受政策影响大，龙头企业多具备资质优势

数据来源：研报明细（行业格局分析）、公司概念题材与主营范围（各细分行业热点）。

---

### 三、政策与行业环境

#### 1. 关键指标
- 行业相关政策（支持性、限制性、监管性政策）
- 宏观经济环境（利率、通胀、消费能力对行业的影响）
- 产业链上下游环境（上游原材料价格、下游需求景气度）
- 技术迭代速度（技术突破、替代技术对行业的影响）

#### 2. 判断标准

**环境利好（支撑行业发展）：**
- 有明确政策支持（补贴、税收优惠、产业规划）
- 宏观环境适配（通胀温和、消费复苏、利率下行）
- 产业链上下游协同向好，技术迭代推动行业升级

**环境中性（无明显影响）：**
- 政策无重大调整，以维持稳定为主
- 宏观环境平稳，对行业无明显利好或利空
- 产业链上下游平衡，技术无重大突破

**环境利空（压制行业发展）：**
- 有限制性 / 监管性政策（限产、合规要求提升）
- 宏观环境不利（通胀高企、消费疲软、利率上行）
- 产业链上下游承压（原材料涨价、下游需求萎缩）

#### 3. 行业特性适配
- **政策敏感型行业（新能源、军工、医药）**：政策是核心影响因素，重点看政策导向
- **消费关联型行业（家电、食品饮料）**：重点看宏观消费能力、居民可支配收入
- **上游资源型行业（煤炭、有色）**：重点看原材料价格、下游行业景气度
- **科技型行业（AI、半导体）**：重点看技术迭代速度、研发投入强度

数据来源：公司公告与事件（政策相关公告）、互动问答记录（政策相关问答）、研报明细（政策与宏观环境分析）。

---

### 四、行业投资机会（核心：挖掘可关注方向）

#### 1. 关键指标
- 核心投资逻辑（政策催化、需求爆发、技术突破、格局优化）
- 重点细分领域（高景气细分、龙头主导细分）
- 投资主线（短期催化、长期成长）
- 潜在受益标的类型（龙头、细分龙头、成长型企业）

#### 2. 判断标准

**投资机会明确（优先关注）：**
- 有清晰的核心投资逻辑，且催化因素可落地（如政策落地、需求爆发）
- 存在 1-2 个高景气细分领域，增速显著高于行业平均
- 投资主线清晰，短期有催化、长期有成长

**投资机会一般（谨慎关注）：**
- 投资逻辑有支撑，但催化因素尚未落地
- 细分领域景气度分化，仅部分领域有机会
- 投资主线模糊，需等待明确信号

**投资机会有限（警惕配置）：**
- 无明确投资逻辑，催化因素缺失
- 行业整体景气度低，无高景气细分领域
- 长期成长逻辑薄弱，短期无催化

#### 3. 行业特性适配
- **成长型行业**：投资机会聚焦"技术突破 + 需求爆发"，优先关注细分龙头
- **成熟型行业**：投资机会聚焦"格局优化 + 盈利提升"，优先关注行业龙头
- **周期型行业**：投资机会聚焦"周期复苏 + 价格上涨"，优先关注产能优势企业
- **防御型行业**：投资机会聚焦"需求刚性 + 政策支持"，优先关注稳健型企业

数据来源：研报明细（细分领域机会分析）、公司概念题材与主营范围（投资热点、细分领域）。

---

### 五、行业风险提示

#### 1. 关键指标
- **景气度风险**：行业增速回落、需求不及预期、产能过剩
- **政策风险**：政策退坡、监管趋严、补贴取消
- **竞争风险**：价格战加剧、同质化竞争、行业洗牌
- **外部风险**：原材料价格波动、汇率波动、国际贸易摩擦
- **技术风险**：技术迭代加速、替代技术出现、研发投入不足

#### 2. 判断标准

**风险可控：**
- 核心风险为行业共性风险，发生概率低
- 行业龙头企业抵御能力强
- 风险对行业整体影响有限

**风险需关注：**
- 存在 1-2 项中等风险，可能影响短期行业景气度
- 部分细分领域受影响较大

**风险突出：**
- 存在多项重大风险，发生概率高
- 风险可能导致行业景气度大幅下滑、盈利恶化

#### 3. 行业特性适配
- **成长型行业**：重点警惕技术迭代风险、政策退坡风险
- **周期型行业**：重点警惕景气周期下行风险、产能过剩风险
- **出口型行业**：重点警惕汇率波动风险、国际贸易摩擦风险
- **资源型行业**：重点警惕原材料价格波动风险

数据来源：研报明细（行业风险提示）、公司公告与事件（行业风险舆情）。

## 分析流程（COT）

### 第一步：数据获取

获取本技能分析所需的全部数据，包含：
1. 研报明细（景气度、格局、投资逻辑、风险提示）
2. 机构调研记录（行业调研信息）
3. 公司公告与事件（政策与行业公告）
4. 互动问答记录（政策与竞争力相关反馈）
5. 公司概念题材与主营范围（细分领域热点）

### 第二步：指标梳理

1. **行业景气度**：统计行业增速、PMI、产能利用率、订单增速、盈利水平
2. **行业格局**：梳理 CR3/CR5、竞争格局、龙头企业优势、行业壁垒
3. **政策与环境**：分析政策导向、宏观环境、产业链上下游、技术迭代
4. **投资机会**：提炼投资逻辑、重点细分领域、投资主线
5. **行业风险**：汇总风险类型，按频次 / 权重排序

### 第三步：分维度逐项评估

按「行业景气度 → 行业格局 → 政策与环境 → 投资机会 → 行业风险」依次判断：
- 景气度：**高景气 / 中景气 / 低景气 / 衰退**
- 格局：**格局优质 / 一般 / 较差**
- 环境：**环境利好 / 中性 / 利空**
- 投资机会：**机会明确 / 一般 / 有限**
- 风险：**风险可控 / 需关注 / 突出**

### 第四步：行业特性适配

- 结合行业类型（成长 / 成熟 / 周期 / 防御），修正景气度、投资机会的判断标准
- 区分行业共性与个性，明确不同行业的核心关注重点
- 区分"行业整体"与"细分领域"，不混淆整体景气度与细分领域景气度

### 第五步：综合研判

- 汇总五大维度结论，判断行业整体投资价值（高 / 中 / 低）
- 提炼行业核心投资逻辑、重点细分领域，明确核心风险点
- 客观呈现行业发展趋势，不夸大机会、不弱化风险

### 第六步：输出结论

- 给出行业层面的投资建议、观察重点与风险提示
- 不荐股、不预测行业绝对涨幅，仅提供客观分析参考

## 注意事项

1. **数据时效性**
   - 优先使用近 1 个季度 / 半年的行业数据（增速、景气度、政策），重点参考权威机构（统计局、行业协会、头部券商）数据
   - 注明数据截止日期、数据来源，明确行业统计范围（如"国内储能行业""全球半导体行业"）
   - 如无最新行业数据，明确说明"近期无权威行业数据更新"或"行业数据滞后"

2. **客观中立**
   - 仅客观分析行业景气度、格局、机会与风险，不加入自身主观预判，不夸大投资机会
   - 避免绝对化表述（如"行业必涨""投资必赚""风险一定会发生"）
   - 机会与风险同步呈现，不弱化风险、不夸大亮点

3. **数据来源**
   - 行业数据来自统计局、行业协会、官方政策文件、头部券商行业研报
   - 景气度指标、行业集中度、增速等核心数据，均以权威渠道为准
   - 不引用非正规渠道的行业传言、未经证实的数据

4. **逻辑自洽**
   - 最终结论需与五大维度分析一致，如"高景气行业"需对应"投资机会明确""风险可控"
   - 如出现矛盾（如高景气但政策利空），需明确说明权衡逻辑与核心影响因素
   - 单一指标不做结论，多维度共振才给出明确投资机会判断

5. **行业适配**
   - 不同类型行业（成长 / 成熟 / 周期 / 防御）的判断标准差异化，不套用统一模板
   - 区分"行业整体"与"细分领域"，不混淆整体景气度与细分领域景气度
   - 结合行业特性，重点突出核心关注维度（如周期行业重点看景气周期，科技行业重点看技术迭代）

## 示例分析

**用户输入**："储能行业景气度怎么样，有哪些投资机会"

**分析结果**：

```markdown
## 【储能行业】行业分析报告

### 一、核心看点
储能行业当前处于**高景气阶段**，核心投资逻辑为海外户用储能需求爆发 + 国内政策支持，重点关注储能逆变器、储能电池细分领域，核心风险为原材料价格波动与行业竞争加剧。

### 二、行业亮点与投资机会

**核心亮点（支撑行业发展）：**
1. **景气度高企**：2026年一季度行业营收同比增速 38%，产能利用率 89%，订单增速 52%，需求持续旺盛
2. **政策持续利好**：国内出台储能补贴政策，海外多国推进能源转型，强制配储政策落地，推动行业规模化发展
3. **格局持续优化**：行业 CR3 提升至 58%，龙头企业技术与规模优势凸显，盈利水平持续提升

**投资机会（细分领域 + 逻辑）：**
1. **储能逆变器**：需求爆发 + 技术迭代，预计 2026 年增速 45% 以上，国内龙头出海优势明显，占据全球主要市场份额
2. **储能电池**：原材料价格回落，毛利率修复，头部企业产能扩张，受益于户用 + 大储双需求驱动
3. **储能系统集成**：下游需求放量，具备项目经验与渠道优势的企业，订单增速高于行业平均

### 三、综合分析

#### （一）行业景气度
- 核心数据：行业营收同比增速 38%，PMI 56.2，产能利用率 89%，订单增速 52%
- 景气周期：当前处于高景气上行阶段，未来 1-2 年仍将维持高增速，主要受益于海外需求爆发
- 结论：**行业景气度高**，需求旺盛、供给紧张，盈利水平持续提升

#### （二）行业格局与竞争态势
- 核心数据：行业 CR3 58%、CR5 72%，龙头企业市占率 28%，竞争格局为寡头竞争
- 格局特点：龙头企业具备技术、规模、渠道优势，行业技术壁垒较高，中小企业难以追赶
- 结论：**行业格局优质**，竞争压力中等，龙头溢价显著

#### （三）政策与行业环境
- 核心数据：国内政策支持（储能补贴、强制配储），海外政策利好（欧洲能源转型、美国税收优惠），宏观环境适配（全球能源结构转型），产业链上下游协同向好（电池原材料价格回落）
- 环境影响：政策推动行业需求释放，原材料价格回落降低企业成本，提升盈利水平
- 结论：**行业环境利好**，支撑行业持续高增长

#### （四）行业投资机会
- 核心数据：核心投资逻辑为"需求爆发 + 政策催化"，重点细分领域（储能逆变器、储能电池）增速 40% 以上
- 机会梳理：①储能逆变器：国内龙头出海；②储能电池：头部企业产能扩张；③系统集成：具备项目优势的企业
```
