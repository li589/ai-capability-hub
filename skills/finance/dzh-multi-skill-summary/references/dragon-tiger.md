# 股票龙虎榜分析

## 功能描述

本技能用于对股票龙虎榜数据专业解读，聚焦「上榜席位类型、买卖净额与力度、席位集中度、上榜原因」四大核心维度，结合个股体量、行业属性及市场情绪，客观判断机构 / 游资动向、资金进出强度、短期走势预期，不涉及基本面 / 技术面深层预测，仅输出龙虎榜层面专业结论，适配 AI 诊股场景落地。

## 分析框架

> **核心原则**：单一席位或单一数据不做结论，多维度共振才给出明确判断；结合个股市值、行业属性修正龙虎榜信号有效性。

### 一、上榜席位类型（核心：判断资金主体）

#### 1. 关键指标
- 买入 / 卖出前五席位类型（机构专用、游资席位、北向资金席位、普通席位）
- 机构席位数量（买入 / 卖出机构数）
- 知名游资席位识别（如赵老哥、章盟主等，仅供参考）

#### 2. 判断标准

**机构主导（强势信号）：**
- 买入前五席位中机构专用席位 ≥ 2 个
- 机构席位买入总额 > 卖出总额，机构净买入
- 无明显大额游资卖出

**游资主导（波动信号）：**
- 买入 / 卖出前五席位以游资席位为主（无机构或仅 1 个机构）
- 游资席位买卖金额占比高（> 60%）
- 席位换手频繁，买卖净额波动大

**多空分歧（震荡信号）：**
- 买入前五有机构 / 游资，卖出前五也有机构 / 游资
- 买卖净额绝对值小（< 成交额 5%）
- 机构与游资操作方向相反

**普通资金主导（弱势信号）：**
- 买入 / 卖出前五均为普通席位
- 无机构、知名游资参与
- 买卖金额小，上榜力度弱

#### 3. 行业 / 个股特性
- **大盘 / 蓝筹股**：机构席位参与度高，游资参与度低，机构净买入为强势信号
- **小盘 / 题材股**：游资席位主导，机构参与少，游资净买入易带动短期波动
- **次新股**：龙虎榜多为游资席位，机构介入少，短期波动剧烈
- **消费 / 金融股**：机构席位占比高，游资炒作概率低，龙虎榜信号更稳健

数据来源：龙虎榜交易明细（最近一个月上榜记录）

---

### 二、买卖净额与力度（核心：判断资金进出强度）

#### 1. 关键指标
- 龙虎榜总买入额、总卖出额
- 买卖净额（总买入 - 总卖出）及净额占当日成交额比例
- 单个席位最大买入 / 卖出额

#### 2. 判断标准

**资金强势流入：**
- 买卖净额为正，净额占当日成交额 > 5%
- 总买入额 > 总卖出额 1.5 倍以上
- 单个席位最大买入额 > 最大卖出额 2 倍以上

**资金温和流入 / 流出：**
- 买卖净额绝对值占当日成交额 2%~5%
- 总买入额与总卖出额差距不大（1~1.5 倍）

**资金强势流出：**
- 买卖净额为负，净额绝对值占当日成交额 > 5%
- 总卖出额 > 总买入额 1.5 倍以上
- 单个席位最大卖出额 > 最大买入额 2 倍以上

**资金平衡：**
- 买卖净额绝对值占当日成交额 < 2%
- 总买入额与总卖出额基本持平

#### 3. 行业 / 个股特性
- **大盘股**：买卖净额占成交额 3% 以上即为明显资金动作
- **小盘股**：买卖净额占成交额 5% 以上为强势资金动作，波动更大
- **题材股**：买卖净额波动大，结合席位类型判断有效性

数据来源：龙虎榜交易明细（净买入额占比、游资买入额占比、机构买入额占比）

---

### 三、席位集中度（核心：判断资金稳定性）

#### 1. 关键指标
- 买入前五席位金额占总买入额比例
- 卖出前五席位金额占总卖出额比例
- 最大单个席位买入 / 卖出占比

#### 2. 判断标准

**集中度高（资金集中，稳定性弱）：**
- 买入 / 卖出前五席位占比 > 80%
- 最大单个席位占比 > 40%
- 资金集中在 1-2 个席位，易出现短期获利了结

**集中度适中（资金稳健）：**
- 买入 / 卖出前五席位占比 50%~80%
- 最大单个席位占比 20%~40%
- 资金分布均匀，无单一席位主导

**集中度低（资金分散，力度弱）：**
- 买入 / 卖出前五席位占比 < 50%
- 最大单个席位占比 < 20%
- 资金参与分散，无明确主导力量

#### 3. 行业 / 个股特性
- **游资主导个股**：集中度高为常态，易出现短期暴涨暴跌
- **机构主导个股**：集中度适中更稳健，机构布局更分散
- **高位个股**：集中度高需警惕资金出逃
- **低位个股**：集中度高可能为资金吸筹信号

数据来源：龙虎榜交易明细（席位集中度计算）

---

### 四、上榜原因（核心：判断资金炒作逻辑）

#### 1. 关键指标
- 官方上榜原因（如涨幅偏离值达 7%、换手率达 20%、振幅达 15% 等）
- 上榜当日个股走势（涨停 / 跌停 / 震荡）
- 对应板块及市场情绪

#### 2. 判断标准

**强势上榜（可持续性强）：**
- 上榜原因：涨幅偏离值达 7%+、涨停且放量
- 对应板块同步走强，市场情绪向好
- 机构净买入，资金逻辑清晰（如业绩利好、政策催化）

**弱势上榜（可持续性弱）：**
- 上榜原因：跌停、跌幅偏离值达 7%+、放量杀跌
- 对应板块走弱，市场情绪低迷
- 机构净卖出，资金出逃明显

**震荡上榜（可持续性不确定）：**
- 上榜原因：换手率高、振幅大、无明显涨跌偏离
- 对应板块震荡，市场情绪平淡
- 多空分歧大，买卖净额平衡

#### 3. 行业 / 个股特性
- **题材股**：多因涨幅 / 换手率上榜，资金炒作逻辑为主，可持续性弱
- **蓝筹股**：多因涨幅 / 跌幅偏离值上榜，资金逻辑多为基本面 / 政策，可持续性强
- **次新股**：多因换手率 / 振幅上榜，资金炒作为主，波动剧烈

数据来源：龙虎榜交易明细（上榜原因、涨跌幅）；分钟级资金流向（主力净流入，交叉验证）

## 分析流程（COT）

### 第一步：数据获取

获取本次分析所需全部数据，包含：
1. **龙虎榜交易明细**（核心数据源）：最近一个月上榜记录，聚焦最新一条
2. **分钟级资金流向**（辅助验证）：主力资金净流入，与龙虎榜数据交叉验证
3. **北向资金个股持仓**（判断是否有北向席位）：核查北向资金持仓变化，判断机构认可度

### 第二步：指标梳理

1. **席位类型**：统计买卖前五机构 / 游资 / 普通席位数量及金额占比
2. **买卖净额**：计算总净额、净额占成交额比例、买卖倍数、最大单席金额对比
3. **集中度**：计算前五席位金额占比、最大单席占比
4. **上榜原因**：明确官方原因、当日走势、板块情绪背景

### 第三步：分维度逐项评估

按「上榜席位类型 → 买卖净额与力度 → 席位集中度 → 上榜原因」依次判断，每项给出明确结论：
- 席位类型：**机构主导 / 游资主导 / 多空分歧 / 普通资金主导**
- 买卖力度：**强势流入 / 温和流入 / 温和流出 / 强势流出 / 平衡**
- 集中度：**集中度高 / 适中 / 低**
- 上榜原因：**强势上榜 / 弱势上榜 / 震荡上榜**，可持续性 **强 / 一般 / 弱**

### 第四步：个股特性适配

- 结合市值大小修正信号有效性（大盘股机构主导更稳健，小盘股游资主导为常态）
- 结合市场情绪判断信号可持续性（弱势市场游资净买入有效性降低）

### 第五步：综合研判

- 汇总四大维度结论，判断整体资金意图：**吸筹 / 洗盘 / 出货 / 分歧**
- 提炼 3 个核心亮点、3 个核心风险点
- 预判短期走势（不预测绝对涨跌，仅判断波动方向与力度）

### 第六步：输出结论

- 给出龙虎榜层面的观察建议与风险提示
- 不荐股、不给出具体买卖点位，仅陈述资金客观动向

## 注意事项

1. **数据时效性**
   - 优先使用当日最新龙虎榜数据，明确标注上榜日期
   - 龙虎榜数据以交易所官方披露为准，注明数据截止时间
   - 如无最新龙虎榜数据，明确说明"近期未上榜"或"数据未更新"

2. **个股与行业对比**
   - 结合个股市值、行业属性判断龙虎榜信号有效性（如大盘股机构主导更合理）
   - 可对比同板块上榜个股的席位结构、买卖力度
   - 无板块对比时，说明仅基于个股自身龙虎榜数据判断

3. **客观中立**
   - 只陈述龙虎榜席位、金额、净额等客观数据，不预测绝对涨跌
   - 避免绝对化表述（如"龙虎榜机构买入必涨""游资主导必跌"）
   - 游资主导、集中度高、资金出逃等风险放在显著位置提示

4. **数据来源**
   - 龙虎榜所有数据均来自交易所官方披露（上交所、深交所龙虎榜公告）
   - 席位类型、买卖金额、上榜原因均以官方数据为准，不引用非正规渠道信息
   - 知名游资席位识别仅作参考，不作为核心判断依据

5. **逻辑自洽**
   - 最终结论需与四大龙虎榜维度分析一致
   - 如出现信号矛盾（如机构买入但净额为负、强势上榜但席位集中度低），需明确说明权衡逻辑与优先级
   - 单一席位或单一数据不做结论，多维度共振才给出明确判断

## 示例分析

**用户输入**："拓维信息龙虎榜怎么样"

**分析结果**：

```markdown
## 【拓维信息 (002261)】龙虎榜分析报告（上榜日期：2026年2月27日）

### 一、核心看点
今日因"日涨幅偏离值达7%"上榜，以游资 + 量化 + 北向资金联合主导，买卖净额 5.67 亿元（净买入极强），当日强势涨停，资金围绕"华为昇腾 + 算力租赁"逻辑集中抢筹，无机构席位参与，短期波动弹性大。

### 二、亮点和风险点

**亮点（资金机会）：**
1. **资金强势流入**：龙虎榜净买入 5.67 亿元，占当日成交额 16.87%，总买入是总卖出的 5.08 倍，资金抢筹力度极强。
2. **多类资金共振**：一线游资、量化资金、北向资金同步净流入，形成合力，市场认可度高。
3. **上榜逻辑清晰**：因涨停上榜，对应算力板块走强，华为昇腾催化明确，资金炒作逻辑顺畅。

**风险点（资金风险）：**
1. **机构缺席**：龙虎榜无机构专用席位参与，资金性质偏短期投机，持续性存疑。
2. **席位集中度高**：买入前五席位占总买入额 99.5%，最大单个席位占比 33.3%，短期获利了结风险大。
3. **游资主导**：中信证券东阳吴宁西路、国泰海通中山东路等游资席位主导，波动幅度或超预期。

### 三、综合分析

#### （一）上榜席位类型
- 核心数据：买入前五席位以游资 + 量化 + 北向为主导，机构席位 0 个；游资席位 2 个，量化席位 2 个，北向席位 1 个
- 席位分布：游资席位买入 3.36 亿元（占比 47.6%），量化席位买入 2.55 亿元（占比 36.1%），北向席位买入 0.88 亿元（占比 12.5%）
- 结论：**游资主导 + 量化助攻 + 北向加持**，无机构参与，短期投机属性明显

#### （二）买卖净额与力度
- 核心数据：总买入 7.06 亿元，总卖出 1.39 亿元，买卖净额 5.67 亿元，净额占当日成交额 16.87%
- 力度判断：总买入额是总卖出额的 5.08 倍；单个最大买入席位（中信证券东阳吴宁西路）2.35 亿元，是最大卖出席位的 7.7 倍
- 结论：**资金强势流入**，抢筹特征显著，资金态度坚决

#### （三）席位集中度
- 核心数据：买入前五席位占总买入额 99.5%，卖出前五席位占总卖出额 98.2%，最大单个席位占比 33.3%
- 集中度判断：资金高度集中在少数席位，分布极不均匀
- 结论：**集中度高**，短期资金稳定性弱，易出现"一日游"行情

#### （四）上榜原因
- 核心数据：官方上榜原因"日涨幅偏离值达7%"，当日个股涨停（+10.00%），成交量 33.6 亿元，换手率 8.17%
- 市场背景：算力租赁板块当日上涨 4.2%，华为昇腾"四位一体核心伙伴"定位获市场认可，DeepSeek 合作消息催化
- 结论：**强势上榜**，信号可持续性**一般**（机构缺席，游资主导）

### 四、策略建议

**1. 结论建议**
**重点关注**，资金合力抢筹信号明确，短期仍有冲高动力，但因机构缺席、游资主导，不建议追高，适合短线波段操作，快进快出。

**2. 关键观察**
- 观察 1：后续是否有机构席位接力买入，提升资金性质稳定性
- 观察 2：游资席位是否出现大规模卖出，警惕获利了结风险
- 观察 3：算力板块情绪是否延续，能否支撑个股持续走强

**3. 风险提示**
- **游资出货风险**：游资主导下短期波动可能加剧，回调幅度或超预期
- **集中度风险**：席位集中度高，单一游资席位卖出可能引发连锁反应
- **板块情绪风险**：若板块情绪走弱，无机构承接，股价可能快速回落
```
