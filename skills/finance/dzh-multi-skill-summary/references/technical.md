# 股票技术分析

## 功能描述

本技能用于对股票进行专业技术面诊断，聚焦「趋势、量价、支撑压力、技术指标」四大核心维度，结合个股盘子大小、行业属性，客观判断股价走势强弱、关键交易区间、短期多空信号，不涉及基本面分析，不预测绝对涨跌，仅输出技术面专业结论，适配 AI 诊股场景落地。

## 分析框架

> **核心原则**：单一信号不做结论，多维度共振才给出明确判断；结合个股盘子大小与行业属性修正信号有效性。

### 一、趋势分析（核心：判断股价运行方向）

#### 1. 关键指标
- 均线系统（5 日、10 日、20 日、60 日、120 日均线）
- 股价相对均线的位置
- 均线排列形态（多头 / 空头 / 缠绕）
- 趋势延续性（连续站稳 / 跌破均线时长）

#### 2. 判断标准

**强势多头趋势：**
- 股价持续站稳 20 日、60 日均线之上
- 均线呈 "5 日 → 10 日 → 20 日 → 60 日" 向上发散排列
- 回调不跌破 20 日均线，或跌破后快速收复

**震荡趋势：**
- 股价在 20 日均线与 60 日均线之间反复缠绕
- 均线无明确方向（既不向上发散，也不向下发散）
- 高低点震荡幅度在 15% 以内，无持续单边走势

**弱势空头趋势：**
- 股价持续运行在 20 日、60 日均线之下
- 均线呈 "5 日 → 10 日 → 20 日 → 60 日" 向下发散排列
- 反弹不突破 20 日均线，或突破后快速回落

#### 3. 行业 / 个股特性

| 类型 | 核心均线 | 特点 |
|------|---------|------|
| 成长股、题材股、小盘股 | 20 日、60 日均线 | 趋势切换快（1-2 周可反转），波动幅度大 |
| 蓝筹股、大盘股、消费股 | 60 日、120 日均线 | 趋势稳定性强，反转周期长（1-3 个月） |
| 周期股、资源股 | 60 日均线为核心 | 趋势跟随行业周期，量能对趋势支撑作用更强 |
| 庄股、妖股 | 均线参考意义减弱 | 重点看量价配合和短期高低点 |

**数据来源：** 本步骤所需数据（均线 MA 5/10/20/60/120 日数值、最新股价、涨跌幅、均线排布类型、压力位、支撑位）由接口一次性返回，包含实时行情快照与技术指标（均线 MA）及指数估值与支撑压力位三类数据。

### 二、量价配合（核心：判断走势的有效性）

#### 1. 关键指标
- 成交量（日 / 周成交量）、成交额
- 量价同步 / 背离关系
- 换手率（日换手率、周换手率）

#### 2. 判断标准

**健康上涨（有效上涨）：**
- 价涨量增：股价上涨时，成交量较前一日 / 5 日均量放大 10% 以上，换手率维持合理区间
- 放量突破：突破关键压力位时，成交量放大 30% 以上，收盘价站稳压力位

**弱势上涨（风险上涨）：**
- 价涨量缩：股价上涨，但成交量较前一日 / 5 日均量萎缩，换手率偏低
- 无量冲高：无明显放量，股价快速冲高后易回落，多为假突破

**健康回调（洗盘）：**
- 价跌量缩：股价回调时，成交量较前一日 / 5 日均量萎缩 20% 以上
- 缩量企稳：回调至关键支撑位，成交量缩至近期低位，止跌信号明显

**风险下跌（恐慌下跌）：**
- 价跌量增：股价下跌时，成交量较前一日 / 5 日均量放大 30% 以上
- 放量杀跌：跌破关键支撑位，成交量大幅放大，抛压沉重

#### 3. 换手率判断（按盘子大小区分）

| 市值规模 | 过热阈值 | 低迷阈值 |
|---------|---------|---------|
| 大盘股（市值 500 亿以上） | > 5% | < 1% |
| 中小盘股（市值 100-500 亿） | > 10% | < 2% |
| 小盘股（市值 100 亿以下） | > 15% | < 3% |

#### 4. 行业 / 个股特性
- **题材股、小盘股**：可容忍高换手率（15%-25%），量能波动大，短期量能决定走势
- **蓝筹股、消费股、白马股**：低换手、稳量能为健康状态（换手率 1%-3%），高换手需警惕顶部
- **次新股**：换手率普遍偏高（10%-30%），重点看量价同步性，无量下跌风险高

**数据来源：** 本步骤所需数据（成交量、成交额、换手率、5 日均量）由接口一次性返回，包含实时行情快照与技术指标（量能 VOL）两类数据。

---

### 三、支撑与压力位（核心：判断关键交易区间）

#### 1. 关键指标
- 近期高低点（近 1 个月、3 个月高点 / 低点）
- 均线支撑 / 压力（20 日、60 日、120 日均线）
- 前期成交密集区（筹码集中区域）
- 跳空缺口（向上缺口 / 向下缺口）

#### 2. 判断标准

**支撑位：**
- **定义**：股价下跌过程中，易企稳、止跌反弹的位置
- **有效支撑**：股价触及支撑位后，缩量止跌，快速反弹，连续 2 个交易日不跌破
- **无效支撑**：股价跌破支撑位，放量下行，支撑位转化为压力位

**压力位：**
- **定义**：股价上涨过程中，易受阻、回落的位置
- **有效突破**：股价突破压力位后，放量站稳（连续 2 个交易日收盘价在压力位之上），压力位转化为支撑位
- **无效突破**：股价突破压力位后，无量回落，未站稳，仍受压力位压制

#### 3. 优先级排序（从高到低）
**前期成交密集区 > 60 日 / 120 日均线 > 近期高低点 > 跳空缺口**

#### 4. 行业 / 个股特性
- **大盘股、蓝筹股**：支撑、压力区间窄（波动 ±2% 以内），突破 / 跌破后走势稳健，不易出现假突破
- **小盘股、科技股、题材股**：支撑、压力区间宽（波动 ±5% 以内），易出现假突破 / 假跌破，需结合量能判断
- **高波动个股（妖股、次新股）**：支撑压力位参考意义减弱，重点看量能和市场情绪

**数据来源：** 本步骤所需数据（系统计算压力位/支撑位、均线排布类型、MA20/MA60/MA120 动态支撑/压力参考、布林带 BOLL 上下轨区间参考、当日盘中高低价）由接口一次性返回，包含指数估值与支撑压力位、技术指标（均线 MA 及 BOLL）、实时行情快照三类数据。

---

### 四、技术指标信号（核心：辅助判断多空趋势）

#### 1. 关键指标（必选 3 个核心指标，适配所有个股）
- **MACD**（趋势型指标，判断长期多空）
- **KDJ**（震荡型指标，判断短期高低点）
- **RSI**（强弱型指标，判断走势强弱）

#### 2. 判断标准

**MACD（重点看零轴位置、金叉 / 死叉、背离）：**

| 信号 | 含义 |
|------|------|
| 零轴上方 | 多头主导，走势偏强 |
| 零轴下方 | 空头主导，走势偏弱 |
| 金叉（DIFF 上穿 DEA） | 短期看多信号，零轴上金叉强度 > 零轴下金叉 |
| 死叉（DIFF 下穿 DEA） | 短期看空信号，零轴下死叉风险 > 零轴上死叉 |
| 顶背离 | 股价创新高，MACD 未创新高，上涨乏力，警惕回落 |
| 底背离 | 股价创新低，MACD 未创新低，下跌动能衰竭，有望反弹 |

**KDJ（重点看超买超卖、金叉 / 死叉）：**

| 信号 | 含义 |
|------|------|
| KDJ > 80 | 超买区，短期回调风险高，可考虑减仓 |
| KDJ < 20 | 超卖区，短期反弹机会大，可关注低吸 |
| 金叉（K 线上穿 D 线） | 短期看多信号，超卖区金叉有效性更高 |
| 死叉（K 线下穿 D 线） | 短期看空信号，超买区死叉有效性更高 |

**RSI（重点看超买超卖、背离）：**

| 信号 | 含义 |
|------|------|
| RSI > 70 | 超买区，短期走势偏强但需警惕回调 |
| RSI < 30 | 超卖区，短期走势偏弱但有望反弹 |
| 顶背离 | 股价创新高，RSI 未创新高，上涨动能不足 |
| 底背离 | 股价创新低，RSI 未创新低，下跌动能衰竭 |

#### 3. 行业 / 个股特性
- **趋势行情（单边上涨 / 下跌）**：优先看 MACD、均线，KDJ、RSI 超买超卖信号参考意义减弱
- **震荡行情（横盘整理）**：优先看 KDJ、RSI，MACD 信号有效性低
- **高波动个股**：技术指标信号频繁，需结合量价、支撑压力综合判断，不单独依赖单一指标

**数据来源：** 本步骤所需数据（MACD 的 DEA/DIF/MACD 值、KDJ 的 K/D/J 值、RSI 的 RSI6/RSI12/RSI24 值，以及高级技术指标波段王等）由接口一次性返回，包含技术指标（MA/MACD/KDJ/RSI/BOLL/量能 VOL）与高级技术指标（波段王等）两类数据。高级技术指标支持波段王、九转序列、情绪转点等高级形态识别，涵盖 DBJJ（底部狙击）、TT（双突）、TS（九转）、XSDF（蓄势待发）、QXZD（情绪转点）、LDS（波段王）、ACY（涨跌动能）、ZLMC（主力脉冲）、QSZZ（趋势追踪）、SQDXH（神奇D信号）等多种指标，支持从分时实时到年线的多周期维度。

## 分析流程（COT）

### 第一步：信息采集

一次性获取以下全部数据：
- 实时行情快照：最新价、涨跌幅、成交量、换手率、总市值（判断盘子大小）
- 技术指标（均线 MA）：MA5、MA10、MA20、MA60、MA120
- 技术指标（MACD、KDJ、RSI）：各指标最新数值与走势
- 技术指标（量能 VOL）：近期成交量历史，含 5 日均量
- 指数估值与支撑压力位：均线排布类型（JunXianPaiBuLeiXing）、压力位（YaLiWei）、支撑位（ZhiChengWei）
- 高级技术指标（波段王等）：可选，提升分析深度

### 第二步：指标梳理

1. **趋势状态**：均线排列方向、股价相对均线位置（多头/震荡/空头）
2. **量价关系**：成交量 vs 5 日均量变化、换手率水平、量价同步 / 背离
3. **支撑压力**：核心支撑位、压力位（按优先级排序：成交密集区 > 60/120 日均线 > 高低点 > 缺口）
4. **技术指标**：MACD 零轴位置及金死叉、KDJ 超买超卖、RSI 背离信号

### 第三步：分维度逐项评估

按「趋势分析 → 量价配合 → 支撑压力 → 技术指标」依次判断：
- 每项给出明确结论（**强势 / 震荡 / 弱势**、**健康 / 一般 / 偏弱**、**支撑有效 / 压力偏大**、**看多 / 看空 / 中性**）
- 标注异常信号（如顶背离、放量杀跌、假突破等）

### 第四步：个股特性适配

- 结合个股盘子大小（大盘 / 中小盘 / 小盘）修正换手率、波动判断
- 结合行业属性（蓝筹 / 成长 / 题材 / 周期）修正均线参考周期
- 区分信号类型（趋势信号 / 震荡信号），匹配当前走势类型

### 第五步：综合研判

- 汇总四大维度结论，判断个股技术面整体强弱
- 提炼 3 个核心技术机会点、3 个核心技术风险点
- 明确短期走势预判（不预测绝对涨跌，仅判断强弱、区间）

### 第六步：输出结论

- 给出技术面观察建议、操作参考（不荐股、不给出具体买卖点位）
- 提示技术面风险，强调"技术分析仅供参考，需结合自身风险承受能力"

## 注意事项

1. **数据时效性**
   - 优先使用实时行情、最新 K 线、当日成交量、最新技术指标数据
   - 注明行情 / 指标截止时间
   - 如行情延迟、指标缺失，明确说明

2. **个股特性与行业对比**
   - 结合个股属性（大盘 / 中小盘 / 小盘、蓝筹 / 成长 / 题材）与行业波动特征判断
   - 参考同板块 / 同类个股走势规律
   - 无同类对比时，说明仅基于个股自身走势分析

3. **客观中立**
   - 只陈述技术信号、支撑压力、量价关系，不预测绝对涨跌
   - 避免绝对化表述（如"必涨""必跌""肯定突破"）
   - 技术风险提示放在显著位置，不夸大机会、不弱化风险

4. **数据来源**
   - 行情、K 线、成交量、技术指标均来自实时证券行情数据
   - 关键点位（支撑 / 压力）基于近 1~3 个月走势划定，明确标注依据
   - 不引用未经证实的盘面传言、小道消息

5. **逻辑自洽**
   - 最终策略建议需与趋势、量价、支撑压力、技术指标四大维度分析一致
   - 如出现信号矛盾（如趋势空头但指标金叉、趋势多头但量能萎缩），需明确说明权衡逻辑与优先级
   - 单一信号不做结论，多维度共振才给出明确判断

```markdown
## 【格力电器 (000651)】技术分析报告

### 一、核心看点
当前处于震荡企稳趋势，股价站稳 20 日均线，60 日线逐步走平，量能温和放大，MACD 出现金叉信号，下方支撑扎实，上方短期压力在 38 元附近。

### 二、亮点和风险点

**亮点（技术机会）：**
1. **趋势企稳**：股价持续站上 20 日均线，60 日线拐头向上，震荡底部逐步抬升，多头动能初步显现。
2. **量价健康**：反弹过程中温和放量，换手率维持 1.2%-1.5%（大盘股合理区间），回调缩量，资金承接较好。
3. **指标向好**：MACD 在零轴下方金叉，DIFF 逐步上穿零轴，KDJ 从超卖区向上修复，短期看多信号明确。

**风险点（技术风险）：**
1. **上方压力明显**：38 元附近为前期成交密集区，多次冲高未有效突破，阻力较大。
2. **趋势未完全反转**：尚未有效突破 60 日均线，仍处于箱体震荡格局，非强势多头。
3. **量能不足**：暂无持续放量（未较 5 日均量放大 30% 以上），突破压力位难度较高，易出现冲高回落。

### 三、综合分析

#### （一）趋势分析
- 核心状态：股价站在 20 日均线上方、60 日均线下方，均线呈缠绕状态
- 趋势方向：震荡
- 结论：震荡企稳，偏弱震荡

#### （二）量价配合
- 核心数据：近期温和放量，日换手率 1.2%-1.5%，量能较 5 日均量放大 15% 左右
- 量价关系：价涨量增、价跌量缩
- 结论：健康

#### （三）支撑与压力位
- 第一支撑位：34.5 元（20 日均线支撑）
- 第二支撑位：33 元（近期低点支撑）
- 第一压力位：38 元（前期成交密集区压力）
- 第二压力位：40 元（3 个月高点压力）
- 结论：下方支撑扎实，上方压力明显

#### （四）技术指标信号
- MACD：零轴下方金叉，DIFF 逐步上穿零轴，多头信号初步出现
- KDJ：45，中性偏低，从超卖区向上修复，无明显超买超卖
- RSI：52，中性区域，无顶背离 / 底背离
- 结论：短期看多信号，信号有效性一般（需量能配合确认）

### 四、策略建议

**1. 结论建议**
持股观望，可依托 34.5 元支撑位低吸，不追高，等待放量突破 38 元压力位后再考虑加大仓位。

**2. 关键观察**
- 观察 1：能否放量突破 38 元压力位，收盘价是否站稳
- 观察 2：回调是否守住 34.5 元支撑位，量能是否持续缩量
- 观察 3：MACD 能否持续维持多头信号，DIFF 是否顺利上穿零轴

**3. 风险提示**
- **无量冲高易回落**：追高可能面临短期回调风险
- **跌破核心支撑**：若跌破 34.5 元核心支撑位，震荡格局可能转弱，需及时控制仓位
- **大盘拖累风险**：大盘走弱或板块回调，可能带动个股破位，技术面信号失效
```
