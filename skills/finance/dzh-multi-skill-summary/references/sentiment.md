# 股票舆情分析

## 功能描述

本技能用于对股票进行全维度舆情量化分析，客观反映市场舆论态度、热度结构与风险等级，不主观荐股，仅做情绪与风险判断。

涵盖四大维度：
- **舆情来源分析**：发布渠道、传播路径分析
- **舆情情绪评估**：正面 / 中性 / 负面占比、情绪强度、相对行业情绪对比
- **舆情影响拆解**：对财务、经营、合规 & 声誉、投资者信心的影响
- **舆情应对和市场反馈**：上市公司的应对方式以及市场股价的真实反应

## 分析框架

### 一、舆情来源与传播路径分析

#### 1. 舆情来源分类（按可信度优先级选取核心内容）

**权威渠道（可信度：高）：**
- 政府监管部门（证监会、交易所等）公告
- 上市公司官方公告
- 官媒及权威财经媒体（央视财经、证券时报等）报道

**专业渠道（可信度：中高）：**
- 券商研报
- 行业垂直媒体
- 专业财经分析师观点

**大众渠道（可信度：中低）：**
- 自媒体（公众号、短视频平台）
- 股票论坛（股吧、东方财富网）
- 社交平台（微博、雪球）
- 新闻客户端

**其他渠道（可信度：需核实）：**
- 用户投诉平台
- 行业协会通报
- 第三方数据机构披露

#### 2. 传播路径分析

**首发渠道：**
- 明确舆情首次出现的平台、时间
- 判断首发主体（官方 / 媒体 / 个人）

**扩散路径：**
- 梳理舆情从首发渠道向其他渠道传播的顺序、速度
- 判断核心传播载体

**传播强度：**
- 通过阅读量、转发量、评论量、讨论量
- 判断舆情传播的广度与深度

#### 3. 行业特殊要点

| 行业 | 核心舆情类型 | 影响说明 |
|------|------------|---------|
| 金融 / 地产 | 监管公告、政策解读（权威渠道） | 传播最快、影响最大 |
| 消费 / 医药 | 用户投诉、产品质量（大众渠道） | 易快速发酵 |
| 科技 / 半导体 | 研发进展、专利纠纷、政策支持（专业渠道） | 主导舆论 |
| 周期 / 制造 | 产能、价格、供需（行业媒体） | 影响更直接 |

本维度分析所用数据来源：公司公告与事件、互动问答记录、公司概念题材与主营范围。

---

### 二、舆情内容分类分析

#### 1. 利好舆情（核心类型）

**经营利好：**
- 业绩预增、订单中标、产能扩张、产品提价、战略合作

**政策利好：**
- 行业扶持政策、税收优惠、补贴到位、资质获批

**技术利好：**
- 核心技术突破、专利获批、产品升级、研发成果落地

**其他利好：**
- 大股东增持、回购股份、股权激励、资产重组

#### 2. 利空舆情（核心类型）

**合规风险（高风险）：**
- 监管处罚、立案调查、违规担保、信息披露违规

**经营风险（中-高风险）：**
- 业绩暴雷、订单流失、产能过剩、产品滞销、亏损扩大

**负面事件（中风险）：**
- 安全事故、产品质量问题、投诉维权、高管违规

**其他利空（低-中风险）：**
- 大股东减持、解禁、诉讼纠纷、核心人员离职

#### 3. 中性舆情

公司日常经营公告（无明显利好利空）、行业常规资讯、无关八卦言论、中性市场评论，不影响市场情绪及公司经营。

本维度分析所用数据来源：研报明细、机构调研记录、互动问答记录（含监管问询与公司回函）。

---

### 三、舆情影响分析

#### 1. 对公司经营的影响

| 影响等级 | 判断标准 |
|---------|---------|
| 无实质影响 | 不涉及业务、业绩、合规 |
| 短期影响 | 影响短期情绪，不改变经营基本面 |
| 中长期影响 | 影响业务、订单、产能、合规、品牌 |

#### 2. 对财务的影响

| 影响等级 | 判断标准 |
|---------|---------|
| 无财务影响 | 舆情与财务无关 |
| 轻微影响 | 不影响利润、现金流 |
| 重大影响 | 可能导致亏损、罚款、资产减值 |

#### 3. 对合规与信誉的影响

| 影响等级 | 判断标准 |
|---------|---------|
| 无影响 | 不涉及监管与品牌 |
| 声誉影响 | 品牌口碑受损 |
| 合规影响 | 触及监管、处罚、整改风险 |

#### 4. 对投资信心的影响

| 影响等级 | 判断标准 |
|---------|---------|
| 无影响 | 市场情绪平稳 |
| 短期信心波动 | 短期情绪扰动，基本面不变 |
| 中长期信心动摇 | 基本面或治理层面存在实质风险 |

本维度分析所用数据来源：公司公告与事件（分析对经营/财务/合规影响）、互动问答记录（反映投资信心）、公司概念题材与主营范围（分析市场热度关联）。

---

### 四、舆情应对与市场反馈

#### 1. 公司应对

- **已公告回应**：通过官方公告主动披露或澄清（权威、有效）
- **已澄清**：通过互动易、媒体采访等渠道作出说明（有效）
- **无应对**：尚未回应，舆情持续发酵（需重点关注）

#### 2. 市场反馈

- **股价波动**：舆情发酵前后股价涨跌幅对比
- **成交量变化**：量能放大 / 缩减 / 平稳
- **机构观点变化**：研报评级调整、目标价变动

本维度分析所用数据来源：研报明细（关注近7日评级调整、目标价变动、机构态度转变）、机构调研记录（关注调研频次变化、调研机构级别）、公司公告与事件（关注是否有澄清公告、回应公告）。

## 分析流程（COT）

### 第一步：信息采集

一次性获取近 7 日舆情所需全部数据，包括：

1. 公司官方公告（权威渠道，最新公告）
2. 投资者互动问答（反映市场关注焦点与公司应对）
3. 券商研报（专业机构观点）
4. 机构调研记录（机构关注度）
5. 题材概念信息（市场热点关联）

### 第二步：清洗与打标

对采集的舆情数据进行分类标注：

1. **标注来源与可信度**
   - 权威渠道（监管公告、官方公告、权威媒体）→ 高可信度
   - 专业渠道（研报、行业媒体）→ 中高可信度
   - 大众渠道（自媒体、股吧、社交平台）→ 中低可信度，需核实

2. **标注情绪**：正面 / 中性 / 负面

3. **标注内容**：利好 / 利空 / 中性

4. **负面舆情风险等级**
   - 高风险：监管处罚、立案调查、重大亏损
   - 中风险：业绩下滑、高管违规、产品问题
   - 低风险：减持、解禁、市场传言

### 第三步：多维度分析

1. **舆情的核心内容**
   - 提取最重要的 3-5 条舆情
   - 按利好 / 利空 / 中性分类
   - 标注来源可信度

2. **情绪结构与强度**
   - 计算正面 / 中性 / 负面占比
   - 判断情绪强度（强正面 / 弱正面 / 中性 / 弱负面 / 强负面）
   - 与行业整体情绪对比

3. **舆情对企业的影响**
   - 对经营的影响：无 / 短期 / 中长期
   - 对财务的影响：无 / 轻微 / 重大
   - 对合规和声誉的影响：无 / 声誉受损 / 合规风险
   - 对投资者信心的影响：无 / 短期波动 / 中长期动摇

4. **公司应对有效性**
   - 是否及时回应
   - 回应内容是否充分
   - 是否有后续行动

### 第四步：综合研判

输出：舆情全貌、核心消息、风险等级、趋势判断、观察建议。

---

## 注意事项

1. **只陈述事实，不预测涨跌**
   - 仅做情绪与风险判断，不主观推荐买卖

2. **明确区分信息来源**
   - 官方公告 / 正规报道 / 未证实传言，必须清晰标注

3. **高风险负面必须前置提示**
   - 涉及监管处罚、立案调查等重大利空，放在报告最显著位置

4. **只分析当前真实可查的舆情**
   - 不凭主观印象下判断，所有结论需有数据支撑

5. **不夸大、不煽动、不情绪化**
   - 保持客观中立，避免放大市场恐慌或过度乐观

## 示例分析

**用户输入**："航天发展最近有什么消息吗"

**分析结果**：

```markdown
## 【航天发展 (000547)】舆情分析报告

### 一、核心看点
近期公司舆情以利好为主，核心围绕"天目一号"星座组网进展、商业航天政策红利及股价强势表现，同时存在短期业绩亏损与高波动风险，整体舆情热度高、权威信息支撑强。

### 二、亮点和风险点

**亮点（利好舆情）：**
1. **"天目一号"星座组网突破**：公司下属航天天目"天目一号"掩星星座一期22星已完成阶段组网，实现商业航天从技术研发到业务落地的跨越，为业绩增长提供新引擎。
2. **商业航天政策密集落地**：国家航天局商业航天司正式运作，多地出台支持政策，低轨卫星互联网进入密集组网阶段，行业景气度持续升温。

**风险点（利空舆情）：**
1. **行业竞争加剧**：商业航天赛道参与者增多，朱雀三号等竞品火箭回收试验推进，市场竞争压力增大，属于低风险负面。

### 三、综合分析

#### （一）舆情来源与可信度
- 主要来源：公司公告、深交所互动易、中国新闻网、科技日报同步发布
- 信息可信度：**高**（来源权威，多渠道交叉验证）
- 核心舆情："天目一号"掩星气象星座一期22星完成阶段组网，探测数据已接入中国气象局数值预报业务系统
- **结论**：舆情真实可信，航天发展是航天天目（重庆）核心参股方，主导星座研制、发射组网与商业化运营，为该项目核心实施主体

#### （二）舆情影响分析
- 对经营影响：**中长期积极**（星座组网完成后将逐步产生业务收入，商业航天政策红利持续释放，支撑长期发展）
- 对财务影响：**短期中性，长期积极**（当前仍处投入期，短期亏损；但星座组网完成后有望打开新增长空间）
- 对品牌合规影响：**无负面影响**
- 对投资信心影响：**短期提振，分歧仍存**（股价强势表现提振信心，但亏损基本面导致部分机构持观望态度）
- **结论**：舆情整体呈积极影响，长期利好明确，短期需关注基本面与股价的匹配度

#### （三）公司应对与股价影响
- 公司应对：**已公告回应**（发布住所变更公告、股票交易异常波动公告，及时披露经营进展）
- 应对效果：**有效**（信息披露及时，缓解市场疑虑，股价保持强势）
- 股价表现：**强势上涨**（2月25日涨停，近三个月涨幅超142%，成交量显著放大，资金关注度高）
- **结论**：舆情对股价短期提振作用明显，中长期影响取决于业绩兑现进度；公司应对措施及时有效，未出现舆情失控风险

### 四、策略建议

**1. 结论建议**
**重点关注**，商业航天赛道确定性强，"天目一号"星座组网为公司带来核心竞争力，政策红利持续释放；但需警惕短期高波动与业绩兑现不及预期风险。

**2. 关键观察事项**
- 观察1：公司是否披露"天目一号"星座后续组网计划及商业化进展
- 观察2：2026年一季报业绩预告是否有改善迹象
- 观察3：股价波动是否回归理性，成交量是否逐步稳定

**3. 风险提示**
- **业绩亏损风险**：公司尚未实现盈利，短期基本面支撑不足，可能影响股价稳定性
- **股价高波动风险**：近期成交额显著放大，短期波动加剧，可能出现回调
- **行业竞争风险**：商业航天赛道参与者增多，市场竞争加剧可能影响公司市场份额
```
