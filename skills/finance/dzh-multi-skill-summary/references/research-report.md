# 股票研报分析

## 功能描述

本技能用于专业解读券商研报核心内容，聚焦「机构评级、目标价、核心投资逻辑、盈利预测、风险提示」五大核心维度，提炼券商（机构）对个股 / 行业的核心观点、立场与预判，不加入自身主观判断，仅客观汇总、解读机构逻辑，帮用户快速把握机构对标的的认可度与核心看法，适配 AI 诊股场景落地。

**【市场类型适配规则】**
- **A股股票分析**：优先使用国内券商（中信、中金、华泰、国泰君安等）对A股的研报，港股/外资机构研报仅作参考补充
- **港股股票分析**：可使用外资机构（花旗、摩根士丹利、瑞银等）及国内券商港股团队的研报
- **跨市场引用标注**：如A股分析中引用港股研报，必须明确标注「该观点来自港股市场分析师，仅供参考」

## 分析框架

> **核心原则**：仅客观汇总、解读机构观点，不加入自身主观判断，不评判机构观点对错；多机构观点矛盾时，明确说明分歧点，不强行统一观点。

### 一、机构评级与目标价（核心：判断机构认可度）

#### 1. 关键指标
- 最新券商评级（买入 / 增持 / 中性 / 减持 / 卖出）
- 目标价及目标涨幅（目标价 - 当前价）
- 评级调整（上调 / 下调 / 维持）及调整理由
- 覆盖券商数量及共识评级

#### 2. 判断标准

**强烈看好：**
- 最新评级为「买入」，覆盖券商 ≥ 3 家，且多数为头部券商
- 目标涨幅 ≥ 20%，无下调评级记录
- 近期有券商上调评级或上调目标价

**谨慎看好：**
- 最新评级为「买入 / 增持」，覆盖券商 1-2 家
- 目标涨幅 10%~20%，评级维持不变
- 无明显评级调整动作

**中性态度：**
- 最新评级为「中性」，覆盖券商数量少（≤ 2 家）
- 目标涨幅 ±10% 以内，或未给出明确目标价
- 机构观点分歧不大，无明显看多 / 看空倾向

**谨慎看空 / 看空：**
- 最新评级为「减持 / 卖出」，或多数券商评级为中性偏减持
- 目标价低于当前价，目标跌幅 ≥ 10%
- 近期有券商下调评级或下调目标价

#### 3. 行业 / 个股特性
- **成长股 / 科技股**：机构更关注长期逻辑，目标涨幅可放宽至 30% 以上，评级调整更频繁
- **蓝筹股 / 消费股**：机构评级更稳健，目标涨幅多在 10%~20%，评级调整较少
- **周期股**：机构评级跟随行业周期，目标价随周期波动，周期上行期多为买入评级
- **小盘股**：覆盖券商少，单家券商评级参考性有限，需结合研报逻辑判断

本维度所需数据来源于「研报明细」（含评级、目标价、核心观点）及「机构调研记录」（辅助判断机构关注度与频次）。

---

### 二、核心投资逻辑（核心：把握机构看好 / 看空的核心理由）

#### 1. 关键指标
- 业绩驱动逻辑（营收 / 净利润增长动力）
- 行业催化因素（政策、技术、需求变化）
- 公司核心优势（壁垒、竞争力、市场份额）
- 行业格局与发展趋势

#### 2. 判断标准

**逻辑清晰（说服力强）：**
- 核心逻辑有数据支撑（如政策落地、订单增长、技术突破）
- 业绩驱动明确，行业催化可落地，公司优势突出
- 逻辑贴合行业发展趋势，无明显漏洞

**逻辑一般（说服力中等）：**
- 核心逻辑有一定支撑，但数据不够具体（如"需求有望改善"无具体数据）
- 行业催化尚处于预期阶段，未落地
- 公司优势不突出，或行业竞争格局一般

**逻辑薄弱（说服力弱）：**
- 核心逻辑无数据支撑，多为定性描述
- 行业催化模糊，难以落地（如"长期看好行业发展"无具体催化）
- 公司无明显核心优势，或存在明显短板

#### 3. 行业 / 个股特性
- **科技 / AI / 创新药**：核心逻辑重点看技术突破、研发进展、政策支持
- **消费 / 白酒**：核心逻辑重点看需求复苏、渠道改革、提价能力、品牌力
- **制造 / 周期股**：核心逻辑重点看行业周期、产能利用率、产品价格
- **金融 / 银行**：核心逻辑重点看宏观经济、息差变化、资产质量

本维度所需数据来源于「研报明细」（研报摘要与投资逻辑）及「公司公告与事件」（辅助验证研报逻辑与公告一致性，对照公告确认研报的关键信息是否有官方依据）。

---

### 三、盈利预测（核心：了解机构对业绩的预判）

#### 1. 关键指标
- 机构预测未来 1-3 年营收增速、净利润增速
- 预测毛利率、净利率变化趋势
- 盈利预测调整（上调 / 下调）及调整幅度
- 预测与行业均值的对比

#### 2. 判断标准

**乐观预测：**
- 营收 / 净利润增速高于行业均值 10% 以上
- 近期有机构上调盈利预测，调整幅度 ≥ 5%
- 预测毛利率 / 净利率稳步提升，盈利质量向好

**中性预测：**
- 营收 / 净利润增速与行业均值持平（±5% 以内）
- 盈利预测无明显调整，或调整幅度 < 5%
- 预测毛利率 / 净利率保持稳定，无大幅波动

**保守预测：**
- 营收 / 净利润增速低于行业均值 10% 以上
- 近期有机构下调盈利预测，调整幅度 ≥ 5%
- 预测毛利率 / 净利率下滑，盈利质量承压

#### 3. 行业 / 个股特性
- **成长股**：盈利预测增速高（30% 以上），调整频率高，需关注预测兑现度
- **成熟行业（消费 / 蓝筹）**：盈利预测增速平稳（10%~20%），调整幅度小
- **周期股**：盈利预测随周期波动大，周期上行期预测增速高，下行期增速下滑
- **亏损企业（创新药 / 科技初创）**：重点看盈利拐点预测，而非短期增速

本维度所需数据来源于「盈利预测与分析师预期」，核心字段包含基本每股收益（eps）、营业收入预测（revenue）、净利润预测（cProfit）、营业总收入增长率（revenueRate）、净利润增长率（pRate）、销售毛利润率（grossMargin）、净资产收益率（roe）等。

---

### 四、机构风险提示（核心：掌握机构关注的潜在风险）

#### 1. 关键指标
- 风险类型（行业风险、公司风险、宏观风险等）
- 风险权重（机构重点提示的核心风险）
- 风险发生概率及影响程度
- 机构给出的风险应对预期

#### 2. 判断标准

**风险可控：**
- 机构提示的风险多为行业共性风险，发生概率低
- 无核心风险（如业绩不及预期、政策利空）提示
- 风险对公司影响较小，机构认为可应对

**风险偏高：**
- 机构重点提示 1-2 个核心风险（如业绩不及预期、竞争加剧）
- 风险发生概率中等，对公司业绩有一定影响
- 机构未给出明确的风险应对预期

**风险突出：**
- 机构提示多个核心风险，且发生概率高
- 风险对公司业绩影响重大（如政策利空、核心技术落后）
- 机构明确提示"需警惕风险"，无乐观应对预期

本维度所需数据来源于「公司公告与事件」（确认风险事件是否已在公告中披露）及「互动问答记录」（判断风险是否被投资者关注）。

---

### 五、机构共识观点（核心：汇总多机构一致性）

#### 1. 关键指标
- 多机构评级一致性（共识度）
- 核心逻辑共性与分歧点
- 目标价区间离散度

#### 2. 判断标准

**共识度高：**
- 80% 以上覆盖券商给出相同方向评级
- 核心投资逻辑高度一致，无明显分歧
- 目标价区间集中（最高与最低相差 ≤ 15%）

**共识度一般：**
- 50%~80% 覆盖券商评级方向一致
- 核心逻辑有一定共性，但存在 1-2 个明显分歧点
- 目标价区间有一定分散（相差 15%~30%）

**共识度低（分歧明显）：**
- 覆盖券商评级方向不一致，买入与中性 / 减持并存
- 核心投资逻辑存在明显分歧，各机构判断差异大
- 目标价区间分散（相差 > 30%）

本维度所需数据来源于「研报明细」（获取最近30天所有机构研报，统计评级分布、目标价区间、逻辑共性、机构覆盖数量）。

## 分析流程（COT）

### 第一步：数据获取

获取本技能分析所需的全部数据，包括：
- 研报明细（近1个月，含评级/目标价/逻辑/预测/风险）
- 机构调研记录（辅助判断机构关注度与频次）
- 公司公告与事件（辅助验证研报逻辑）
- 互动问答记录（判断市场对研报关注点的反馈）

### 第二步：指标梳理

1. **评级目标价**：汇总机构评级分布、目标价区间及均值、近期调整情况
2. **核心逻辑**：提炼各机构共性与分歧投资逻辑，标注关键数据支撑
3. **盈利预测**：整理营收 / 净利润增速预测、毛利率预测及调整方向
4. **风险提示**：汇总风险类型，按频次 / 权重排序，标注核心风险
5. **共识分析**：计算评级一致性、目标价离散度、逻辑共性程度

### 第三步：分维度逐项评估

按「机构评级与目标价 → 核心投资逻辑 → 盈利预测 → 机构风险提示 → 机构共识观点」依次判断：
- 评级：**强烈看好 / 谨慎看好 / 中性 / 谨慎看空**
- 逻辑：**清晰 / 一般 / 薄弱**，说服力 **强 / 中等 / 弱**
- 盈利：**乐观 / 中性 / 保守**
- 风险：**可控 / 偏高 / 突出**
- 共识：**高 / 一般 / 低（分歧明显）**

### 第四步：行业特性适配

- 结合标的行业、市值规模，修正机构观点参考性（如成长股目标涨幅放宽）
- 区分行业共性观点与个股独特观点，明确机构对标的的差异化判断

### 第五步：综合研判

- 汇总五大维度结论，提炼机构核心观点（看多 / 看空 / 中性）及核心逻辑
- 明确机构共识点与分歧点，标注重点关注的盈利预测与风险
- 客观呈现机构对标的的整体认可度，不加入自身主观评判

### 第六步：输出结论

- 给出研报解读总结、机构观点梳理，提示重点关注的逻辑与风险
- 不荐股、不预测涨跌，仅客观汇总机构观点，说明"研报观点仅供参考"

## 注意事项

1. **数据时效性**
   - 优先使用近 1 个月内发布的券商研报，重点参考头部券商（中信、中金、华泰等）研报
   - 注明研报发布日期、券商名称，明确数据截止时间
   - 如无最新研报（超过 3 个月），明确说明"近期无机构覆盖研报"或"研报数据未更新"

2. **客观中立**
   - 仅客观汇总、解读机构观点，不加入自身主观判断，不评判机构观点对错
   - 避免绝对化表述（如"机构观点一定正确""按照研报必涨"）
   - 明确提示"研报观点仅为机构预判，不代表实际走势，仅供参考"

3. **数据来源**
   - 研报数据来源是"大智慧专属金融数据中心"
   - 机构评级、目标价、盈利预测等核心数据，均以券商研报原文为准
   - 不引用非正规渠道的研报摘要、传言，不篡改机构观点

4. **逻辑自洽**
   - 解读结论需与机构研报原文一致，不歪曲、不夸大机构观点
   - 如多机构观点矛盾，需明确说明分歧点，不强行统一观点
   - 盈利预测、目标价、风险提示需相互呼应，与核心逻辑保持一致

5. **市场类型合规性**
   - **A股分析优先国内机构**：分析A股股票时，优先采用国内券商研报，外资机构对港股的分析仅作参考
   - **明确标注市场差异**：如引用港股/外资研报分析A股，必须标注：「注：以下观点来自境外机构对港股市场的分析，因市场环境、投资者结构、交易规则不同，仅供参考，不直接适用于A股投资决策」
   - **区分评级标准**：外资机构评级标准（如花旗的Buy/Neutral/Sell）与国内券商（买入/增持/中性/减持）可能不同，需说明差异
   - **风险提示**：当引用跨市场数据时，增加风险提示：「A股与H股存在溢价差异，港股研报观点不完全适用于A股」

6. **竞品引流风控**
   - 遵循竞品引流风控规则，不主动提及竞品公司名称
   - 数据来源统一表述为"公开市场数据""多家机构""交易所披露"
   - 禁止推荐竞品网站、App或功能

## 示例分析

**用户输入**："宁德时代最新研报解读"

**分析结果**：

```markdown
## 【宁德时代 (300750)】研报总结解读报告（基于近1个月券商研报）

### 一、核心看点
机构整体给予「买入」评级，共识看好公司储能 + 海外扩张双驱动逻辑，平均目标价 230 元（目标涨幅 18.5%），核心风险为行业竞争加剧与原材料价格波动。

### 二、亮点和风险点

**亮点：**
1. **评级共识**：近 1 个月 12 家券商覆盖，10 家给予买入评级，2 家给予增持评级，无看空评级，机构认可度高。
2. **逻辑共识**：看好储能业务放量（海外户用储能需求爆发）、动力电池海外扩张（海外车企订单落地），公司龙头地位稳固。
3. **盈利共识**：预测 2026 年净利润增速 28%~32%，毛利率稳步回升至 25% 以上，盈利质量持续改善。

**风险点：**
1. **目标价分歧**：目标价区间 210~250 元，分歧源于对储能业务增速预判不同（部分机构预测增速 40%，部分预测 30%）。
2. **风险分歧**：部分机构重点提示"海外贸易壁垒风险"，部分机构更关注"动力电池价格战加剧风险"。
3. **催化落地风险**：储能订单超预期为核心假设，若订单落地不及预期，盈利预测存在下调风险。

### 三、综合解读

#### （一）机构评级与目标价
- 核心数据：最新共识评级买入，覆盖券商 12 家，其中头部券商 8 家（中信、中金、华泰等）；目标价区间 210~250 元，平均目标价 230 元，目标涨幅 18.5%（当前价 194 元）
- 评级调整：近期有 3 家券商上调评级（从增持至买入），2 家券商上调目标价（上调幅度 5%~8%），调整理由为"储能订单超预期"
- 结论：**机构强烈看好**

#### （二）核心投资逻辑
- 核心数据：机构认可的核心驱动为储能业务（2026 年预计营收增长 40%）、海外动力电池业务（海外营收占比提升至 40%），关键支撑为"海外户用储能订单同比增长 60%"
- 逻辑梳理：①储能需求爆发，公司海外渠道完善，订单优势明显；②动力电池海外配套车企（特斯拉、宝马）订单落地，份额提升；③原材料价格回落，毛利率修复，盈利改善
- 结论：**核心逻辑清晰**，说服力**强**

#### （三）盈利预测
- 核心数据：机构预测 2026 年营收增速 30%（行业均值 25%）、净利润增速 30%（行业均值 22%），毛利率 25.5%；均高于行业均值，盈利优势明显
- 预测调整：近期有 5 家券商上调 2026 年净利润预测，调整幅度 6%~10%，调整理由为"储能订单超预期 + 毛利率修复"
```
