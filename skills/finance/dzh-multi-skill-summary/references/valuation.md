# 股票估值分析

## 功能描述

本技能用于对股票进行全面的估值分析，涵盖四大维度：
- **估值水平评估**：市盈率、市销率、市净率、企业价值倍数等估值指标分析
- **财务健康度评估**：盈利能力、负债率、现金流、资产周转率等财务指标分析
- **经营护城河评估**：市场占有率、行业集中度、成本优势、研发投入、专利数量等竞争力分析
- **成长性与潜力评估**：收入增速、利润增速、市场空间、渗透率、政策导向等成长性分析

## 分析框架

> **核心原则**：不看绝对数字，看在行业内的相对位置；不同行业，判断标准完全不同，分析时必须标注行业特殊性。

四大维度：
- **一、估值水平**：P/E（含 PEG）、P/S、P/B、EV/EBITDA，均相对行业均值 + 历史分位判断，综合给出显著低估/适度低估/合理/适度高估/显著高估
- **二、财务健康度**：盈利能力（ROE/毛利率/净利率）、负债率与偿债能力、现金流结构、资产运营效率，综合给出优秀/良好/一般/较弱
- **三、经营护城河**：市场占有率与行业地位、竞争格局（CR3/CR5）、成本优势、研发与技术、品牌/渠道/用户壁垒，综合给出强/一般/弱护城河
- **四、成长性与潜力**：收入增速（含 CAGR）、利润增速、市场空间、政策导向，综合给出高成长/稳健成长/低成长

### 一、估值水平评估

#### 1. 市盈率（P/E）分析

**1.1 静态 PE / 动态 PE — 相对行业均值：**
- 低于行业均值 20% 以上：明显偏低
- 低于行业均值 10%~20%：适度偏低
- 行业均值 ±10% 以内：合理
- 高于行业均值 10%~20%：适度偏高
- 高于行业均值 20% 以上：明显偏高

**自身历史分位（近 5 年）：**
- 0~20% 分位：历史低位
- 20%~50% 分位：历史中低位
- 50%~80% 分位：历史中高位
- 80%~100% 分位：历史高位

**1.2 PEG 估值匹配度（相对成长）：**
- PEG < 0.8：估值显著低于盈利增速，低估
- PEG 0.8~1.2：估值与增速匹配，合理
- PEG 1.5~2.0：估值高于增速，偏贵
- PEG > 2.0：估值严重脱离成长，高估

**关键数据字段：**
- 估值指标（PE/PB/PS）：`peTtm`（市盈率TTM）、`pbMrq`（市净率MRQ）、`psTtm`（市销率TTM）
- 季报财务数据（PEG 计算）：`epsdiluted`（每股收益）、`parenetp`（净利润）
- 成长能力数据（PEG 计算）：`npgrt`（净利润增长率）、`tagrt`（营业总收入增长率）
- 计算：PEG = PE / npgrt（PE 使用 peTtm）

#### 2. 市销率（P/S）分析

**相对行业均值：**
- 低于行业 20%+：低估
- 行业均值 ±10%：合理
- 高于行业 20%+：高估

**行业差异：**
- 亏损股/未盈利企业：以 P/S 相对对比为核心估值依据
- 高增长行业（SaaS、创新药、AI 等）：允许高于行业，但需营收增速显著跑赢行业

**关键数据字段：**
- 估值指标（P/S）：`psTtm`（市销率TTM）
- TTM 财务指标（营业收入、净利润等，用于解释 P/S 变化原因）：`totbizinco`（营业总收入）、`parenetp`（净利润）
- 利润数据：`bizinco`（营业总收入）、`biztotcost`（营业总成本）

#### 3. 市净率（P/B）分析

**相对行业均值：**
- 低于行业 20%+：偏低
- 行业均值 ±10%：合理
- 高于行业 20%+：偏高

**搭配 ROE 相对水平判断：**
- ROE 高于行业 → 可支撑高于行业的 PB
- ROE 低于行业 → 高于行业 PB 则估值偏贵

**关键数据字段：**
- 估值指标（P/B）：`pbMrq`（市净率MRQ）
- TTM 财务指标（净资产收益率等，用于 PB 合理性判断）：`roediluted`（净资产收益率）、`roedilutedcut`（扣非净资产收益率）
- 盈利能力（ROE 用于 PB 合理性判断）：`roediluted`（摊薄净资产收益率）、`roeweighted`（加权净资产收益率）
- 财务指标：`naps`（每股净资产）

#### 4. 企业价值倍数（EV/EBITDA）

**优先用于**：重资产、周期股、有息负债高、微利/亏损企业

**判断标准**：完全以相对行业、相对历史分位为主：
- 低于行业均值：估值占优
- 高于行业均值：估值劣势

**关键数据字段：**
- 企业价值倍数相关数据：`evToEbitda`（企业价值/EBITDA倍数）、`evAmount`（企业价值元）

#### 5. 估值水平综合结论（统一口径）

根据以上 4 个指标相对行业 + 历史 + 成长的综合表现，给出唯一结论：
- **显著低估**：多数指标低于行业 20%+，且 PEG 合理
- **适度低估**：多数指标低于行业 10%~20%
- **估值合理**：多数指标在行业均值 ±10% 以内
- **适度高估**：多数指标高于行业 10%~20%
- **显著高估**：多数指标高于行业 20%+，或 PEG > 2

### 二、财务健康度评估

#### 1. 盈利能力

**1.1 净资产收益率（ROE）— 相对行业：**
- 高于行业均值 10%+：显著优秀
- 高于行业均值 0~10%：良好
- 低于行业均值 0~10%：一般
- 低于行业均值 10%+：偏弱

**特殊行业：**
- 银行/保险：看 ROE + 净息差/综合成本率，不单独看 ROE 高低
- 周期股：只看周期底部 ROE，顶部 ROE 无意义
- 科技/软件：允许短期 ROE 低，重点看毛利率 & 现金流

**银行特殊指标（银行股专用）：**

银行利润指标关键字段：`netinteinco`（净利息收入）、`netintebizinco`（中间业务净收入）、`inteinco`（利息收入）、`inteexpe`（利息支出）

**证券公司特殊指标（券商股专用）：**

证券利润指标关键字段：`netpouninco`（手续费净收入）、`netinvinco`（投资收益）、`netundeinco`（证券承销业务净收入）

**保险公司特殊指标（保险股专用）：**

保险利润指标关键字段：`earnprem`（已赚保费）、`payoexpe`（赔付支出）、`inveinco`（投资收益）

**企业通用利润指标（非银/非券商/非保险通用）：**

企业利润指标关键字段：`biztotinco`（营业收入）、`biztotcost`（营业成本）、`perprofit`（营业利润）、`totprofit`（利润总额）、`parenetp`（净利润）、`npcut`（扣非净利润）

**1.2 毛利率 — 相对行业：**
- 高于行业均值 10%+：强定价权
- 高于行业均值 0~10%：有优势
- 低于行业均值 0~10%：竞争力一般
- 低于行业均值 10%+：明显弱势

**特殊行业：**
- 消费/白酒/医药：毛利率是护城河核心指标
- 制造/加工：毛利率低正常，看费用率更重要

**1.3 净利率 — 相对行业：**
- 高于行业均值：盈利效率更强
- 低于行业均值：费用管控/成本劣势

**特殊行业：**
- 规模型行业（家电、汽车）：净利率低但周转快，属于正常模式

**关键数据字段：**
- 盈利能力：`roediluted`（摊薄净资产收益率）、`roeweighted`（加权净资产收益率）、`sgpmargin`（销售毛利率）、`snpmarginconms`（销售净利率）
- 利润数据：`biztotinco`（营业收入）、`biztotcost`（营业成本）、`parenetp`（净利润）
- 收益质量：`opanitotp`（经营活动净收益/利润总额）、`npcuttonp`（扣除非经常损益后的净利润/净利润）

#### 2. 负债率与偿债能力（相对行业）

**2.1 资产负债率：**
- 低于行业均值：财务更稳健
- 高于行业均值：杠杆更高，风险更大

**特殊行业：**
- 银行/地产/基建：天然高负债，必须看行业内相对水平
- 科技/消费：负债率显著高于同行即视为风险

**2.2 有息负债/总资产：**
- 低于行业均值：偿债压力更小
- 高于行业均值：利息负担更重

**特殊行业：**
- 重资产/周期：可接受略高，但必须匹配经营现金流

**关键数据字段：**
- 偿债能力：`zcfzl`（资产负债率）、`ldbl`（流动比率）、`sdbl`（速动比率）、`lxzfbs`（利息支付倍数）
- 资产负债表指标（有息负债占比）：`shorttermborr`（短期借款）、`longborr`（长期借款）、`totasset`（资产总计），计算有息负债/总资产

#### 3. 现金流结构（相对利润、相对同行）

**3.1 经营现金流净额/净利润：**
- 连续 3 年 > 行业均值：利润含金量高
- 连续 < 行业均值：利润虚高/回款差

**特殊行业：**
- 软件/SaaS：预收账款多，经营现金流通常远好于净利润
- 工程/建筑：经营现金流普遍差于净利润，看收现比

**3.2 自由现金流（FCFF）：**
- 长期为正且 > 同行均值：自我造血能力强
- 长期为负且差于同行：依赖外部融资

**关键数据字段：**
- 现金流量表：`mananetr`（经营活动产生的现金流量净额）、`invnetcashflow`（投资活动产生的现金流量净额）、`acquassetcash`（购建固定资产支付的现金）
- 计算自由现金流 = 经营现金流 - 资本支出
- 利润数据：`parenetp`（净利润），对比净利润与现金流，判断利润含金量

#### 4. 资产运营效率（相对行业）

**4.1 总资产周转率：**
- 高于行业均值：资产使用效率更高
- 低于行业均值：资产冗余/产能利用率低

**4.2 应收账款周转天数：**
- 低于行业均值：回款更快，话语权强
- 高于行业均值：赊销严重，话语权弱

**特殊行业：**
- ToG/基建/工程：回款普遍慢，只做同行相对比较

**关键数据字段：**
- 营运能力：`taturnrt`（总资产周转率）、`accrecgturndays`（应收账款周转天数）、`taturndays`（总资产周转天数）

**财务健康综合结论**：优秀 / 良好 / 一般 / 较弱

### 三、经营护城河评估

> **核心原则**：不看绝对数字，看在行业内的相对位置；不同行业，护城河来源完全不同，必须标注。

#### 1. 市场占有率 & 行业地位

**相对行业：**
- 行业前 2 + 市占率高于第二名 50%+：绝对龙头
- 行业前 3 + 市占率稳步提升：强地位
- 市占率 < 行业 CR3 均值：地位一般

**特殊行业：**
- 科技/半导体：市占率小幅领先就是巨大壁垒
- 消费：市占率稳定 >15% 即可视为强壁垒

**关键数据字段：**
- 公司基础信息：`compname`（公司全称）、`compintro`（公司简介）、`majorbiz`（主营业务）、`zjhlevel`（证监会行业）、`gicslevel`（GICS行业）
- 主营构成：`classname`（分类值）、`tcorebizincome`（本期主营业务收入）、`corebizincrto`（占主营业务收入比例）
- 研报明细（行业地位/市占率/竞争优势描述）：`titles`（研报标题）、`compname`（机构名称）、`reportdate`（研报日期）、`stdrating`（标准评级）、`stdratingsm`（评级说明）、`url`（研报原文链接）

#### 2. 行业竞争格局（CR3/CR5 相对历史）

**横向对比：**
- CR3 逐年提升：格局优化，龙头受益
- CR3 逐年下降：内卷加剧，盈利承压

**特殊行业：**
- 金融/白酒/家电：CR3 高，格局稳定
- 餐饮、服务业：CR3 天然低，看区域壁垒

**关键数据字段：**
- 研报明细（行业集中度）：`titles`（研报标题）、`compname`（机构名称）、`stdrating`（标准评级），从研报中提取行业竞争格局信息

#### 3. 成本优势（相对同行）

**相对行业：**
- 单位成本低于行业均值 5%+：明显成本壁垒
- 单位成本逐年下降且快于行业：效率优势扩大

**特殊行业：**
- 周期/化工/钢铁/光伏：成本是第一护城河
- 科技/品牌消费：成本不重要，不做核心判断

**关键数据字段：**
- 利润数据：`biztotcost`（营业总成本）、`bizinco`（营业总收入），计算单位成本 = 营业成本 / 营业收入

#### 4. 研发与技术（相对行业）

**4.1 研发费用率：**
- 高于行业均值：技术投入更强
- 低于行业均值且差距扩大：逐渐掉队

**特殊行业：**
- 半导体/AI/创新药：研发率必须显著高于行业才算有壁垒
- 消费/制造：研发率中等即可，不要求过高

**4.2 专利 & 技术壁垒：**
- 发明专利数量/质量高于同行：技术壁垒强
- 核心专利独家/垄断：强护城河

**特殊行业：**
- 医药/器械：专利 = 核心护城河
- 品牌消费：专利不重要

**关键数据字段：**
- 利润数据：`deveexpe`（研发费用）、`biztotinco`（营业收入），计算研发费用率 = 研发费用 / 营业收入
- TTM 财务指标：`deveexpe`（研发费用）
- 公司介绍：从 `compintro`（公司简介）中获取专利信息
- 公告数据：`mainTitle`（公告主标题）、`content`（公告内容）、`summary`（公告摘要），搜索"专利"、"知识产权"相关公告

#### 5. 品牌/渠道/用户壁垒（相对行业）

**相对行业：**
- 渠道数量/覆盖率高于同行
- 品牌溢价/复购率高于行业

**特殊行业：**
- 白酒/美妆/零食：品牌 > 一切
- ToB 制造：渠道/认证 > 品牌

---

### 四、成长性与潜力评估

#### 1. 收入增速

**高成长：**
- 营业收入增长率 > 20%

**稳健成长：**
- 营业收入增长率 10%-20%

**关键指标：**
- 连续 3 年复合增长率（CAGR）> 15%

**关键数据字段：**
- 成长能力：`tagrt`（营业总收入增长率）、`npgrt`（净利润增长率）、`bizinco`（营业收入增长率）
- 利润数据（多期，计算 CAGR）：`bizinco`（营业总收入）
- TTM 财务指标（滚动12个月，消除季节性波动）：`parenetp`（净利润）、`totbizinco`（营业总收入）、`sgpmargin`（销售毛利率）、`roediluted`（净资产收益率）、`totbizincoYoy`（营业收入同比）

#### 2. 利润增速

**高质量增长：**
- 净利润增长率 > 20%
- 且最好大于营收增速（体现规模效应或效率提升）

**关键数据字段：**
- 成长能力：`npgrt`（净利润增长率）、`parenetp`（归属母公司所有者净利润增长率）
- 利润数据（多期，计算净利润增速）：`parenetp`（净利润）

#### 3. 市场空间

**行业天花板：**
- 行业市场规模 > 万亿级（天花板高）

**渗透率：**
- 当前渗透率 < 20%，且处于快速提升期

**关键数据字段：**
- 研报明细（行业空间数据）：`titles`（研报标题）、`compname`（机构名称）、`analystname`（研究员），从研报中提取行业市场规模、渗透率等信息

#### 4. 政策导向

**行业增速：**
- 行业增速 > GDP 增速的 1.5 倍
- 且处于政策支持周期

**关键数据字段：**
- 公告数据：`mainTitle`（公告主标题）、`content`（公告内容）、`summary`（公告摘要），搜索"政策"、"补贴"、"支持"相关公告

## 分析流程（COT）

### 第一步：信息收集

根据用户提供的股票代码，通过接口获取以下数据：

1. **基础数据**
   - TTM 财务指标（估值指标：净资产收益率、每股收益、销售毛利率等）
   - 公司基础信息（行业地位、主营业务）
   - 主营业务构成
   - 资产负债表指标

2. **财务能力数据**
   - 盈利能力（ROE、毛利率、净利率）
   - 成长能力（营收增速、净利润增速）
   - 偿债能力（资产负债率、流动比率）
   - 营运能力（资产周转率、应收账款周转天数）
   - 资本结构分析
   - 收益质量分析

3. **利润表与现金流数据**
   - 利润表
   - 现金流量表
   - 季报财务数据（EPS、每股净资产等）
   - 财务指标数据

4. **研报和调研数据**
   - 券商研报
   - 机构调研记录

5. **公告与互动数据**
   - 公司公告（政策、研发、合作等）
   - 投资者互动（问答）

### 第二步：数据处理与计算

根据收集的数据，计算关键指标：

1. **估值指标计算**
   - PEG = PE / 净利润增长率
   - EV/EBITDA = (市值 + 有息负债 - 现金) / EBITDA

2. **财务指标计算**
   - 毛利率 = 毛利润 / 营业收入
   - 净利率 = 净利润 / 营业收入
   - 研发费用率 = 研发费用 / 营业收入
   - 自由现金流 = 经营现金流 - 资本支出

3. **成长指标计算**
   - 营收 CAGR = ((最新营收 / 3年前营收)^(1/3) - 1) * 100
   - 净利润 CAGR = ((最新净利润 / 3年前净利润)^(1/3) - 1) * 100

### 第三步：多维度分析

按照四大维度进行分析：

1. **估值水平评估**
   - 对比 P/E、P/S、P/B、EV/EBITDA 与行业均值
   - 计算 PEG，判断估值合理性
   - 综合判断：低估/合理/高估

2. **财务健康度评估**
   - 盈利能力：ROE、毛利率、净利率
   - 负债率：资产负债率、有息负债占比
   - 现金流：经营现金流、自由现金流
   - 资产周转：总资产周转率、应收账款周转天数
   - 综合判断：优秀/良好/一般/较差

3. **经营护城河评估**
   - 市场地位：市占率、行业排名
   - 竞争格局：行业集中度、竞争对手
   - 成本优势：单位成本趋势
   - 研发投入：研发费用率、专利数量
   - 综合判断：强护城河/一般护城河/弱护城河

4. **成长性与潜力评估**
   - 历史增长：营收增长率、净利润增长率
   - 市场空间：行业规模、渗透率
   - 政策支持：行业政策、补贴情况
   - 综合判断：高成长/稳健成长/低成长

### 第四步：综合研判

整合四大维度分析结果，生成综合研判：

1. **核心看点**：总结公司的核心竞争力和投资价值
2. **亮点和风险点**：亮点 2-3 个核心优势，风险点 2-3 个主要风险
3. **综合分析**：分别展开四大维度的详细分析，每个维度给出具体数据支撑和判断结论
4. **策略建议**：结论建议（买入/持有/观望/回避）、目标价位（如适用）、风险提示

## 注意事项

1. **数据时效性**
   - 优先使用最新一期财报数据
   - 注明数据截止日期
   - 如数据缺失，明确说明

2. **行业对比**
   - 尽量提供行业均值作为参照
   - 如无行业数据，说明仅做纵向对比

3. **客观中立**
   - 既要指出亮点，也要揭示风险
   - 避免绝对化表述（如"一定会涨"）
   - 风险提示放在显著位置

4. **数据来源**
   - 关键数据标注来源（如"根据 2024Q3 财报"）
   - 研报观点注明券商名称和日期

5. **逻辑自洽**
   - 最终结论需与四大维度分析一致
   - 如出现矛盾（如高估值但高成长），需明确说明权衡逻辑
