> 最后核实日期：2026-06-04。覆盖数据合规生命周期"后半段"——收集使用之后的环节。用于初判，复杂或高风险情形请咨询法务。

## 一、数据主体权利响应（DSR）

### 1.1 用户享有的权利

中国 PIPL（第44–50条）：知情、决定、限制/拒绝；查阅复制；可携带；更正补充；删除；要求解释处理规则。
欧盟 GDPR（Art.15–22）：访问、更正、删除（被遗忘）、限制处理、可携带、反对、免受仅自动化决策约束。

### 1.2 响应 SOP

```
第一步：接收与登记
   └─ 提供便捷请求入口；登记请求人、类型、时间
第二步：核验身份
   └─ 确认请求人即数据主体本人，防止冒用（核验手段与数据敏感度匹配）
第三步：评估请求
   └─ 是否属法定权利范围？是否有法定例外（如法定保存义务、涉他人权益、影响公共利益）？
第四步：执行
   └─ 查阅/复制：提供本人信息副本
   └─ 更正：核实后更正
   └─ 删除：删除或匿名化，并通知已对外提供的接收方
   └─ 撤回同意：停止基于该同意的处理（不影响此前已处理的合法性）
第五步：答复与留痕
   └─ 在法定时限内答复；拒绝须说明理由并告知投诉/救济途径；全程留痕
```

### 1.3 响应时限（参考）

- GDPR：原则上 **1 个月内**，复杂可延长至 3 个月并告知。
- PIPL：未规定统一天数，应"及时"响应；拒绝须说明理由。
- 建议平台内部设定统一 SLA（如 15 个工作日）。

### 1.4 撤回同意 / 拒绝营销的特别处理

撤回同意后须停止基于该同意的处理；营销拒绝/退订须立即生效且不可被其他入口绕过（详见 [marketing-platform-compliance.md](marketing-platform-compliance.md)）。

## 二、数据留存与删除

### 2.1 原则

- 最短必要期限：保存期限为实现处理目的所必要的最短时间（PIPL14、GDPR5）。
- 到期处置：保存期届满或目的实现后，应删除或匿名化。
- 法定保存义务优先：电商交易记录、财务、税务、网络日志等有法定最短保存期（如交易记录、商品服务信息通常不少于 3 年；网络日志不少于 6 个月），到期前不得删。

### 2.2 触发删除的情形（PIPL 第47条）

处理目的已实现/无法实现/不再必要；停止提供产品服务；保存期限届满；个人撤回同意；处理者违反法律或约定。技术上难以删除的，应停止除存储和必要安全保护外的处理。

### 2.3 落地要点

```
- [ ] 是否为各类数据定义了保留期限矩阵（区分业务/法定要求）？
- [ ] 是否有到期自动删除/匿名化机制？
- [ ] 账号注销后个人信息是否按期删除或匿名化？
- [ ] 备份、离线表、下游副本是否纳入删除范围？
- [ ] 删除/匿名化是否留痕可证明？
```

> 提示：哈希脱敏不等于删除，也不等于匿名化（仍是个人信息）。真正"删除"或"匿名化"要确保不可复原。

## 三、数据泄露 / 安全事件应急

### 3.1 应急 SOP

```
1. 发现与抑制：立即采取补救措施，阻断扩大（隔离、改密、下线）
2. 评估定级：泄露数据类型/规模/敏感度/可能后果
3. 通知监管：
   - 中国 PIPL57：立即通知履行个保职责的部门
   - GDPR33：知悉后 72 小时内通知监管机构
4. 通知个人：
   - PIPL：通知个人；若采取措施能有效避免危害可不通知个人，但部门要求通知的除外
   - GDPR34：高风险时通知数据主体
5. 记录与复盘：记录事件全过程、原因、处置、改进
```

### 3.2 通知内容（参考）

泄露的信息种类、原因、可能危害、已采取/拟采取的补救措施、个人可采取的减损措施、处理者联系方式。

### 3.3 自查

```
- [ ] 是否有书面数据泄露应急预案与责任人？
- [ ] 是否能在 72 小时内完成监管通知（涉欧盟）？
- [ ] 是否有事件分级与上报标准？
- [ ] 是否定期演练？
```

## 四、委托处理 / 对外提供 / 数据处理协议（DPA）

### 4.1 三种关系区分

| 关系 | 含义 | 关键合规动作 |
| :--- | :--- | :--- |
| 委托处理 | 受托方按委托方指示处理（如 SaaS、外包、云） | 签 DPA；受托方不得超范围处理、不得擅自再委托 |
| 对外提供 | 向独立第三方提供个人信息 | 单独同意 + 告知接收方信息 + 约束接收方 |
| 公开 | 向不特定公众披露 | 原则禁止，需单独同意且充分必要 |

### 4.2 委托处理协议（DPA）应包含

处理目的、期限、方式、个人信息种类、保护措施；受托方协助委托方响应主体权利与履行义务；安全事件通知义务；受托方不得超范围处理、未经同意不得再委托；委托关系解除后删除或返还数据；委托方对受托方的监督/审计权。（PIPL21、GDPR28）

### 4.3 对外提供前自查

```
- [ ] 是否取得单独同意？
- [ ] 是否告知接收方身份、联系方式、目的、方式、种类？
- [ ] 是否签署数据处理/共享协议？
- [ ] 接收方是否在境外（触发跨境，见 regulations.md「四、跨境数据传输」）？
- [ ] 是否做了影响评估（对外提供属 PIPL55 触发情形）？
```
