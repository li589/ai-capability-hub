# 数据合规法规速查

> 最后核实日期：2026-06-04。法规会修订、新规会出台，下方条款编号与阈值供初判参考；高风险或复杂情形以最新官方文本为准，并咨询法务/走合规评审。本文件不构成法律意见。

## 一、中国：个保法 / 数安法 / 网安法

### 个人信息保护法（PIPL）
- **合法性基础**（第13条）：①取得个人同意；②订立/履行合同必需，或按法定劳动规章/集体合同实施人力资源管理必需；③履行法定职责或义务；④应对突发公共卫生事件或紧急情况保护自然人生命健康和财产安全；⑤为公共利益实施新闻报道、舆论监督等在合理范围；⑥在合理范围处理已公开信息；⑦法律法规规定的其他情形。注意：**中国无 GDPR 式"正当利益"基础**，营销等场景通常需"同意"。
- **敏感个人信息**（第28–29条）：生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹，及不满14周岁未成年人信息。处理需**单独同意**（部分情形书面同意）、特定目的与充分必要性，并事前做个人信息保护影响评估。
- **告知-同意**（第14–18条）：处理前充分告知处理者身份、目的、方式、种类、保存期限、行权方式等；目的/方式/种类变更需重新取得同意；不得以拒绝非必要同意为由拒绝提供产品服务。
- **自动化决策**（第24条）：决策应保证透明度和结果公平公正，不得对交易价格等条件实行不合理差别待遇（即禁止大数据杀熟）；通过自动化决策做信息推送、商业营销，应同时提供不针对个人特征的选项或便捷的拒绝方式；对个人权益有重大影响的决策，个人有权要求说明并拒绝仅经自动化决策的方式。
- **对外提供**（第23条）：向第三方提供需告知接收方身份/联系方式/目的/方式/种类，取得单独同意，并对接收方处理活动有约束。
- **跨境传输**（第38–39条）：需通过①国家安全评估、②保护认证、③标准合同之一（见本文「四、跨境数据传输」），且向个人告知境外接收方信息并取得单独同意。
- **删除**（第47条）：处理目的实现/无法实现、停止提供服务、保存期限届满、个人撤回同意、违法处理等情形应主动删除；未删除的应停止除存储和必要安全保护外的处理。
- **数据泄露**（第57条）：发生或可能发生泄露、篡改、丢失的，应立即采取补救措施，并通知履行个人信息保护职责的部门和个人（采取措施能避免危害的可不通知个人，但部门要求通知的除外）。
- **影响评估**（第55–56条）：见 [impact-assessment.md](impact-assessment.md)。
- **个人权利**：知情、决定、限制或拒绝；查阅复制、可携带；更正补充；删除；要求解释说明规则（第44–50条）。
- **罚则**（第66–67条）：一般违法责令改正、警告、没收违法所得，可并处100万元以下；情节严重最高**5000万元或上一年度营业额5%**，并可责令停业、吊销许可；直接责任人10万–100万元，可禁业。

### 数据安全法（DSL）
- 数据分类分级保护（核心/重要/一般）；重要数据处理者需明确负责人和管理机构，定期风险评估并报备。
- 数据出境（重要数据）按相关规定进行安全评估。
- 违法处理可处罚款、停业整顿、吊销许可。

### 网络安全法（CSL）
- 网络运营者收集使用个人信息须合法正当必要、明示并经同意；关键信息基础设施（CII）重要数据**境内存储**，出境需安全评估。

## 二、电商平台高频法规（中国）

> 电商平台数据合规/安全负责人最常踩到的一组，营销触达、平台治理、个性化推荐类问题以本节为准。详细落地见 [marketing-platform-compliance.md](marketing-platform-compliance.md)。

| 法规 | 关键条款 | 核心要求 |
| :--- | :--- | :--- |
| 消费者权益保护法 | 第29条 | 经营者未经消费者同意或请求，或消费者明确拒绝的，**不得发送商业性信息**；收集使用须明示并经同意，确保信息安全 |
| 广告法 | 第43条 | 未经同意或请求不得以电子信息方式发送广告；发送的广告须**明示发送者真实身份和联系方式**，并提供**拒绝继续接收的方式（退订）** |
| 民法典 | 第1032–1034条 | 隐私权与个人信息保护；**不得以电话、短信、即时通讯、邮件、传单等方式侵扰他人私人生活安宁**（重复/高频骚扰即可能违法） |
| 电子商务法 | 第27条、第38条 | 平台须核验登记平台内经营者信息；对平台内经营者侵害消费者权益**知道或应当知道未采取必要措施的，承担连带责任**；负有建立规则、监测、处置的管理义务 |
| 通信短信息服务管理规定 | 第18条 | 未经用户同意或请求，**不得发送商业性短信息**；用户拒绝后应停止 |
| 互联网信息服务算法推荐管理规定 | — | 向用户提供**关闭算法推荐**或**不针对其个人特征的选项**；不得利用算法实施不合理差别待遇（杀熟）；保障用户知情与选择 |

## 三、欧盟：GDPR

- **处理合法性基础**（Art.6）：同意、合同必需、法定义务、重大利益、公共利益、**合法利益（legitimate interest，需做 LIA 平衡测试）**。直接营销可基于合法利益，但须提供随时反对（opt-out）。
- **特殊类别数据**（Art.9）：种族、政治观点、宗教、工会、基因、生物识别、健康、性取向——原则禁止处理，除非满足例外（明确同意等）。
- **数据主体权利**（Art.15–22）：访问、更正、删除（被遗忘）、限制处理、可携带、反对、免受仅自动化决策约束。响应通常 1 个月内。
- **跨境传输**（Chapter V）：充分性决定、SCCs 标准合同条款、BCRs 约束性公司规则、特定减损等。
- **问责与设计**：Privacy by Design/Default（Art.25）、记录处理活动 ROPA（Art.30）、高风险需 DPIA（Art.35）、必要时设 DPO（Art.37–39）、处理者协议 DPA（Art.28）、72 小时数据泄露通知监管 + 高风险通知个人（Art.33–34）。
- **罚则**（Art.83）：最高 2000 万欧元或全球年营业额 4%（孰高）。

## 四、跨境数据传输

> 2024-03-22《促进和规范数据跨境流动规定》对出境义务做了重大放宽，下方阈值为初判口径，以最新官方与所在地网信办为准。

三条合规路径，满足其一即可：①通过国家网信部门组织的安全评估；②按标准取得个人信息保护认证；③与境外接收方订立标准合同并备案。任一路径都要配套：单独同意、向个人告知境外接收方信息、事前个人信息保护影响评估。

2024 新规下的分级（不含重要数据时）：

| 情形 | 一般要求 |
| :--- | :--- |
| 履行合同必需（跨境购物/支付/差旅/签证等）、跨境人力资源管理必需、紧急情况保护生命健康 | 可**豁免**三条路径 |
| 自一年起累计向境外提供**不满10万人**非敏感个人信息 | 可**豁免** |
| 累计**10万–100万人**非敏感，或**不满1万人**敏感个人信息 | 标准合同备案 / 认证 |
| 累计**100万人以上**非敏感，或**1万人以上**敏感个人信息，或涉重要数据 | 安全评估申报 |

自贸区负面清单：自贸试验区可制定区内数据出境负面清单，清单外数据可免走上述机制（以各自贸区发布为准）。

操作提示：标准合同需在签署生效后 10 个工作日内向省级网信办备案；安全评估通过有效期一般 3 年，到期或情形变化需重新申报。

## 五、美国：CCPA/CPRA 及各州

- **CCPA/CPRA（加州）**：消费者享有知情、删除、更正、选择退出"出售/共享"、限制敏感个人信息使用的权利；需提供"Do Not Sell or Share My Personal Information"入口。
- **适用门槛（满足其一）**：上一年度全球年营收 > 2500 万美元；每年买卖/共享 10 万+ 加州消费者或家庭的个人信息；50% 以上年收入来自出售/共享个人信息。
- **敏感个人信息**：SSN、账户登录凭证、精确地理位置、种族、健康、性生活等，消费者可限制其使用。
- **罚则与私人诉权**：行政罚按违法次数计——**非故意违法每次最高 2500 美元；故意违法或涉及未成年人每次最高 7500 美元**（CPRA 后由加州隐私保护局 CPPA 执法，原 30 天整改宽限期已取消）。此外数据泄露场景消费者享有有限私人诉权（每位每次 100–750 美元或实际损失孰高）。
- **其他州**：弗吉尼亚 VCDPA、科罗拉多 CPA、康涅狄格 CTDPA 等，框架类似（告知、选择退出、数据最小化、DPA、敏感数据需同意或评估）。

## 六、阿里 / ICBU 内部规范

- **PII 数据分级与脱敏**：个人可识别信息须按规范哈希脱敏（SHA256）或区域隔离存储；精确匹配优先脱敏。注意：哈希脱敏数据仍是个人信息（见 [pii-data-tables.md](pii-data-tables.md) 术语章节）。
- **区域单元隔离**：CN/SG/US/DE 数据在对应区域项目空间处理，跨境遵循区域单元表机制；全量数据仅新加坡有哈希脱敏版本。
- **先评审后取数**：使用隐私敏感字段须先过合规评审，通过后申请离线 PII 表权限并贴评审链接。
- **最小必要 + 用途留痕**：申请须说明每个字段用途，内容将用于监管审计。
- 具体表与流程见 [pii-data-tables.md](pii-data-tables.md) 与 [review-process.md](review-process.md)。

## 七、法规匹配速查表

| 场景 | 优先适用 | 关键动作 |
| :--- | :--- | :--- |
| 收集中国用户个人信息 | PIPL | 告知-同意，敏感信息单独同意 |
| 收集欧盟用户个人信息 | GDPR | 合法性基础 + 数据主体权利保障 |
| 向买家发营销信息/短信/EDM | 消法29 / 广告法43 / 短信规定18 / 民法典1033 | 同意为基础、可退订、拒绝即停、控频次 |
| 平台治理商家数据行为 | 电子商务法27/38 | 建规则、可监测、能处置，避免连带责任 |
| 个性化推荐/自动化营销 | PIPL 24 / 算法推荐规定 | 提供关闭/不针对个人特征选项，禁杀熟 |
| 数据出境（中国→境外） | PIPL Art.38 + 2024跨境新规 + DSL | 按阈值判断豁免/标准合同/安全评估 + 单独同意 |
| 数据传出欧盟 | GDPR Chapter V | 充分性/SCCs/BCRs |
| 加州消费者数据 | CCPA/CPRA | 选择退出入口 + 删除/更正权 |
| 向第三方提供个人信息 | PIPL 23 / GDPR 28 | 单独同意 + DPA + 告知接收方信息 |
| 处理敏感/自动化决策/对外/跨境 | PIPL 55-56 / GDPR 35 | 先做影响评估（见 impact-assessment.md） |
| 数据泄露 | PIPL 57 / GDPR 33-34 | 补救 + 通知监管与个人（见 data-lifecycle.md） |
| 内部使用 PII 离线表 | 阿里内部规范 | 先评审、脱敏优先、区域隔离 |
