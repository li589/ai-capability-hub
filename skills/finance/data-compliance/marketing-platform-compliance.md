# 营销触达 / 平台治理 / 算法推荐 合规指引

> 最后核实日期：2026-06-04。面向电商平台数据合规/安全负责人与业务方。本文件用于初判，复杂或高风险情形请咨询法务。

覆盖：①营销触达法律原则（站内消息、短信、邮件 EDM、电话/外呼）；②平台对商家数据行为的治理责任；③个性化推荐与自动化营销决策；④ICBU 内部直销营销操作规范（EDM/电话/WhatsApp 的红线、圈客、疲劳度、披露、审批）；⑤营销退订名单（黑名单）的离线表与在线 DNC 接入。

## 一、营销触达合规

### 1.1 强制底线（无自主裁量空间）

| 要求 | 法律依据 | 说明 |
| :--- | :--- | :--- |
| 须有合法性基础（通常为同意） | 消法29 / PIPL13 | 未经同意或请求不得发送商业性信息；中国无"正当利益"基础，营销基本靠同意 |
| 必须提供退订/拒绝方式 | 广告法43 / PIPL24 | 每条营销信息须有便捷退订入口 |
| 拒绝后必须立即停止 | 消法29 / 短信规定18 | 用户明确拒绝后继续发即违法 |
| 不得侵扰私人生活安宁 | 民法典1033 | 重复、高频骚扰即使最初同意过也可能越界 |
| 明示发送者真实身份 | 广告法43 | 营销信息须可识别发送方 |

### 1.2 分渠道要点

- **站内消息工具**：买卖双方通常已有交易/问询关系，风险相对低；"可随时删除商家/关闭通知"就构成便捷退订。关键是删除后彻底不可再触达（堵后门），以及对删除前的高频群发设频次上限。
- **短信**：未经同意不得发商业短信（短信规定18）；须带退订（如"回 T 退订"）且退订有效。
- **邮件 EDM**：需同意基础 + 一键退订 + 明示发件人。注意场景四只讲"怎么取邮箱"，不代表"取到就能群发"。
- **电话/智能外呼**：受骚扰电话治理规范约束，需同意、可拒绝、控时段与频次。

### 1.3 平台可自主裁量的部分

具体频次阈值、冷却期时长、发送时段、是否分商家等级设不同上限、是否发送前提醒——法律没给死数字，平台可以基于买家体验自己定。但"未同意不得发、必须能退订、拒绝后必须停"是硬要求，没有裁量空间。

> 注意：法律层面没有统一死数字，不代表 ICBU 内部没有。ICBU 直销营销（用自有邮箱/电话/WhatsApp 触达买卖家）已经把这些"弹性"收成了内部强制阈值（见「四、ICBU 内部直销营销操作规范」4.3–4.5 的疲劳度/频次/时段）。这些内部阈值是公司给自己设的下限收口，通常严于或等于当地法律下限；当地法律更严时以更严者为准。本节说的"可自主裁量"主要针对平台治理场景下对商家行为的规则设计，别据此放宽 ICBU 自身直销触达的频次。

### 1.4 营销合规自查清单

```
- [ ] 营销对象是否有同意/请求基础？（无关系冷启动群发风险高）
- [ ] 每条营销信息是否有便捷退订/拒绝入口？
- [ ] 用户拒绝/退订后是否真正停止、且不可被其他入口绕过？
- [ ] 是否对单商家→单买家设频次上限与冷却期？
- [ ] 营销信息是否明示发送者身份？
- [ ] 含境外买家时是否叠加 GDPR(ePrivacy)/CAN-SPAM 评估？
```

## 二、平台治理责任（电子商务法）

### 2.1 平台的法定义务

平台经营者对平台内经营者（商家）处理买家数据的行为负有管理责任，和渠道无关——工具是平台提供的，平台就要管：

- 核验登记（电商法27）：核验、登记商家身份信息。
- 建立规则：制定平台内数据处理与营销行为规则。
- 监测发现：对商家滥用工具（如批量骚扰、违规收集买家信息）具备监测能力。
- 处置机制：对违规商家分级处置（提示→警告→限流→功能限制→封禁）。
- 投诉处理：受理买家投诉并及时处置。
- 避免连带责任（电商法38）：对商家侵害消费者权益"知道或应当知道未采取必要措施"的，承担连带责任。

### 2.2 平台合规机制建设清单

```
- [ ] 是否有平台内数据处理/营销行为规则并向商家公示？
- [ ] 是否对商家使用站内工具的行为有监测（频次、批量、异常）？
- [ ] 是否有买家投诉受理与处置闭环？
- [ ] 是否有违规商家分级处置规则并落地执行？
- [ ] 商家获取/使用买家 PII 是否经必要授权与最小化？
- [ ] 是否留存治理记录以证明已尽管理义务？
```

### 2.3 关键判断

监管与司法看的是平台有没有尽到管理义务，而不只是有没有给买家一个退出按钮。买家能"删除商家"是有效缓释，但不免除平台的监测与处置义务，也覆盖不了"删除之前"的骚扰。

## 三、个性化推荐 / 自动化决策（PIPL 24 + 算法推荐规定）

### 3.1 强制要求

- 提供选项：通过自动化决策做信息推送/商业营销，须同时提供不针对个人特征的选项或便捷拒绝方式；算法推荐服务须提供关闭算法推荐的选项。
- 禁止杀熟：不得对交易价格等交易条件实施不合理差别待遇（大数据杀熟）。
- 透明与可解释：决策应保证透明度与结果公平；对个人权益有重大影响的决策，个人有权要求说明并拒绝仅经自动化决策的方式。
- 事前评估：自动化决策属 PIPL 第55条影响评估触发情形，须先做影响评估（见 [impact-assessment.md](impact-assessment.md)）。

### 3.2 自查清单

```
- [ ] 是否提供关闭算法推荐 / 不针对个人特征的选项？
- [ ] 是否存在基于画像的价格/条件差别待遇？（杀熟红线）
- [ ] 对重大影响决策是否可解释、可人工干预、可拒绝？
- [ ] 是否已就自动化决策做个人信息保护影响评估？
```

## 四、ICBU 内部直销营销操作规范（EDM / 电话 / WhatsApp）

> 来源：《EDM、电话、WhatsApp营销规则 Direct Marketing Guidelines for EDM, Telephone Call and WhatsApp》。适用范围：GGS 直销销售及 GGS 第三方渠道商销售。这是 ICBU 销售实操营销时要落地的内部规则，比上文的法律原则更具体，回答 ICBU 销售/运营怎么合规营销时优先引用本节。本节 4.3–4.5 给出的疲劳度/频次/时段是 ICBU 内部强制阈值（对应上文 1.3"法律未给死数字"——内部已经收成了死数字）；当地法律更严时以更严者为准，别拿 1.3 的"可自主裁量"放宽这些数字。

### 4.0 七条营销红线（先看这个）

1. 营销优先走公司营销平台/产品；原则上禁止用公司邮箱或个人邮箱做营销。
2. 营销名单必须符合圈客规则（见 4.2），不得向不符合圈客规则的用户营销。
3. 用公司邮箱做 EDM 必须单点发送（一人一封），禁止明文群发。
4. EDM 内容（通常在 footer）必须含：①便捷、免费的退订方式；②公司名称、地址、联系方式。
5. 营销须符合发送疲劳度控制（频次上限）。
6. 电话 / WhatsApp 营销须满足充分披露，且在合理时段进行。
7. 特定营销（用第三方工具如 WhatsApp、采买数据营销）须先过数据合规 PIA 审批；涉及向合作方传输个人信息的，还须过三方管理流程（合作方尽调 DD + TIA 审批）。

### 4.1 什么算"营销"（定义，判断是否受本规范约束）

只要邮件/电话/消息中包含"营销"平台产品的表述即属营销，包含但不限于：含"You may also like / Just for you / Recommendation"等结构；含其他商品超链接；产品最新消息（如 RFQ 权益包、GGS 会员介绍）；特价促销；活动营销；邀请入会/成为国际站会员；系统邮件夹带营销元素。**仅含物流、订单信息的不算营销邮件。**

### 4.2 圈客规则（opt-in / opt-out + 退订名单）

各国法律都要求营销符合 opt-in 与 opt-out。ICBU 合规团队据此建了统一营销退订名单，营销前必须先核验目标用户是否在名单内。

- opt-in（选择加入）：须用户事先主动同意才能发营销。注册时收集联系方式（电话/邮箱）要有单独的营销授权才算有效——打包在一堆条款里，在很多国家视为未取得授权。
- opt-out（选择退出）：无需事前同意即可发，但必须提供有效退订机制；用户一旦退订，alibaba.com 全业务线都不得再发营销。

怎么落地：一是优先用站内营销平台（如天舟平台 for 买家、东风平台 for GGS），平台内置退订名单过滤；二是若用自己的公司邮箱/电话/WhatsApp，须用 CRM 检查该联系方式是否标记 opt-out（标记了就不能用该方式触达），用其他系统时须与运营、数据合规确认目标是否在退订名单内，确认不在才能营销。退订名单的具体接入见本文「五、营销退订名单（黑名单）接入」。

### 4.3 EDM 要求

- footer 主体信息（按法务建议统一用新加坡主体）：公司名 Alibaba.com Singapore E-Commerce Private Limited；地址 51 Bras Basah Road, #01-21 Lazada One, Singapore 189554；退订/联系邮箱 DataProtection@service.alibaba.com。
- 退订机制：必须含免费、清晰、醒目的退订入口（DPO 邮箱或页面退订），字号/位置/对比度合理可见，与营销正文有区分。
- 疲劳度阈值：站内用户 7 天 1 封、14 天内 2 封；站外用户 14 天 1 封。
- 其他：必须单点发送，禁止明文群发；禁止用非公司邮箱营销。

### 4.4 电话营销要求

- 除非法务另批，严禁预录音/自动语音外呼（如批准，仅限已就接听自动呼叫明确同意者）。
- 频次：同一目标消费者，同月不得就 1 个以上活动重复致电；同月不得致电 4 次以上（再拨须有合理间隔）。仅当"前次未接听"且"对方未挂断/未退订"时方可续拨。对方明确退订须从营销名单删除并加入统一退订名单。
- 合理时段：营业日当地时间 9:00–18:00。
- 充分披露（通话开始即说明）：推销员姓名、实体/组织（如 Alibaba.com）、致电目的、告知对方可选择是否继续通话；并告知可回拨的实体电话号码以便退订。
- Caller ID：须真实显示，不得隐藏或伪造；号码须可回拨，否则须口头告知替代号码。
- 通话录音：须告知并取得同意；对方继续通话即视为默示同意。
- 质量与边界：准确披露、不得虚假陈述、不得高压销售、不得索取付款相关信息（如银行账户）。
- 15 秒原则：未接电话响铃至少 15 秒或 4 声后才可挂断。
- 不主动挂断：不得主动挂断对方已接听的电话。
- 销售须持续更新退订名单，并与运营、合规团队共享营销名单与退订名单。

### 4.5 WhatsApp 营销要求

- 频次：同月不得就 1 个以上活动重复发消息；同月不得发 4 条以上（须有合理间隔）。仅当"前条消息无人回复"且"对方未退订"时方可续发。
- 合理时段：营业日当地时间 9:00–18:00。
- 充分披露（首条消息即说明）：发送人姓名、实体/组织、发送目的、告知对方可选择是否继续接收。对方不回复则不得重复发；对方明确退订须从名单删除并加入统一退订名单。
- 质量与边界：同电话营销（准确披露、不得虚假陈述、不得高压、不得索取付款信息），满足合理请求（提供注册地址/客服电话）。

### 4.6 审批与流程入口

| 流程 | 适用 | 入口 |

## 五、营销退订名单（黑名单）接入

> 来源：《营销名单接入技术文档》。ICBU 把原先分散在各业务线的营销黑名单/退订名单统一收口，提供离线匹配和在线过滤两种对接方式。营销前过滤目标名单，是圈客规则（4.2）的落地手段。

### 5.1 离线对接：统一名单维表

下游统一消费整合后的名单维表是 `icbu_security_tech.icbu_risk_marketing_blacklist_df`。主要字段：

| 字段 | 说明 |
| :--- | :--- |
| TYPE | 名单值类型：`email` / `mobile_phone_number` / `phone_number` / `ali_id` |
| VALUE | 名单值（对应类型的邮箱/手机号/电话/aliid） |
| SOURCE | 名单来源 |
| COMMENT | 说明/描述 |
| CREATOR / MODIFIER | 创建人 / 修改人 |
| GMT_CREATE / GMT_MODIFIED | 创建时间 / 修改时间 |

该维表整合的上游来源表：

| 来源表 | 分类 | 渠道 | 更新频率 |
| :--- | :--- | :--- | :--- |
| `icbutech.ump_operation_cn_blacklist` | ump 中国运营黑名单 | 邮件 | 每天自动 |
| `icbutech.ump_operation_useast_blacklist` | ump 美国运营黑名单 | 邮件 | 每天自动 |
| `icbutech.onepush_chn_black_list_privacy_di` | 网站营销黑名单 | 全渠道 | 每天自动 |
| `icbutech.s_mtn_auto_unsubscribe_info_privacy_onepush_app` | 网站退订名单 | 全渠道 | 每天自动 |
| `compliance_data.s_legal_privacy_marketing_tel` | 美国/香港监管黑名单 | 全渠道 | 每天自动 |
| `icbu_security_tech.icbu_pii_risk_hubspot_list_data_d` | hubspot | 全渠道 | 不定期手动导入 |

### 5.2 在线对接：DNC 名单过滤服务

实时过滤用「天一阁 sancus」DNC（Do Not Call）名单过滤服务，引入 sancus-client（groupId `com.taobao.datasecurity`，artifactId `sancus-client`）。

> 注意：本技能只记录到服务名与依赖坐标级别。具体 Maven 版本号、接口方法签名、入参/出参结构、鉴权与环境配置（日常/预发/线上）等落地细节本技能不全，须以《营销名单接入技术文档》原文与 sancus 服务方为准。接入前请直接查阅原始技术文档或联系服务 owner，不要凭本节信息臆测接口。

### 5.3 选型建议

批量营销名单清洗用离线维表；实时触达前校验用在线 DNC 服务。无论哪种，这些都是营销退订/黑名单（合规过滤用），不是用来做营销获客的 PII 源表；获客取数仍走 [pii-data-tables.md](pii-data-tables.md) 流程并遵守圈客规则。名单表属隐私数据，使用前按 [review-process.md](review-process.md) 申请权限。

## 六、跨法域提示

含境外买家时叠加：欧盟 GDPR/ePrivacy（直接营销原则上需 opt-in、可随时撤回）；美国 CAN-SPAM/CCPA（商业邮件须可识别、提供退订并及时生效，赋予限制使用与选择退出权）。建议按区域单独评估，必要时走合规评审。
