# 🔖 配置轮动

> ⚠️ 以上为资产配置与行业轮动的分析参考，不构成任何投资建议，不承诺收益；具体投资决策需结合个人风险承受能力独立判断。

## 一句话定位

解决「钱该怎么分配、下一阶段该超配哪个方向」，补齐投研能力矩阵中「资产配置 / 行业轮动」维度（对标万得 Alice 的行业轮动 / 战略基准 / 目标组合 / 战术叠加）。核心交付两层：**大类战略配置**（股/债/商品/现金/海外比例与方向）+ **行业轮动信号**（景气+估值+资金三维打分与超配/低配排序）。

## 数据需求

本 skill 需要以下**数据维度**，由 agent 从通达信金融数据能力中按需获取：

| 数据维度 | 用途 | 降级方案 |
|----------|------|----------|
| 宏观增长 / 通胀 / 利率 / 信用 | Step 1 象限定位 | 任一指标缺失则用可得指标交叉推断，标注口径 |
| 大类资产估值分位 / 股债性价比 | Step 2 配置比例 | 估值分位缺失则用绝对水平定性判断 |
| 行业景气 / 事件 / 传导受益 | Step 3 景气打分 | 用产业链与板块基础信息替代精细景气指标 |
| 行业 / 板块估值分位 | Step 3 估值打分 | 用相对估值指标替代历史分位 |
| 板块 / 行业资金流向 | Step 3 资金打分 | 外资流向不稳定时，以板块主力资金流替代 |

> 优先使用通达信 MCP 金融数据能力获取数据。所有数据缺失一律标注 `N/A` 并说明原因，**绝不编造数据或结论**。

## 使用流程

### Step 1：宏观环境定位（战略锚）
获取宏观与流动性数据，定位当前宏观象限（美林时钟：增长方向 × 通胀方向 → 复苏/过热/滞胀/衰退）。

### Step 2：大类资产战略配置
基于宏观象限 + 估值分位 + 风险平价，输出股/债/商品/现金/海外五类的「超配/标配/低配」方向与建议比例区间，并说明偏「进攻」还是「防御」。

### Step 3：行业三维轮动打分
对主要行业进行景气(40%) + 估值(30%) + 资金(30%) 三维打分，输出排名并映射信号：🟢 超配 / 🟡 标配 / 🔴 低配。

### Step 4：战术配置与组合拼接
大类方向决定仓位中枢，行业信号决定权益内超配/低配方向，输出「战略基准 + 战术叠加」两层。

### Step 5：生成配置报告（见输出模板）

## 📐 分析逻辑（场景专属推演链）

数据 → 分析 → 结论，必含以下推演：

1. 宏观数据 → 定位象限（如「增长回升 + 通胀温和 = 复苏」）
2. 象限 → 大类优劣顺序 → 战略超配 / 低配方向
3. 行业三维打分 → 景气上行且估值合理且资金流入 = 🟢 超配
4. 反向（景气下行 / 估值高位 / 资金流出）= 🔴 低配
5. 结论分级：🟢 超配 / 🟡 标配 / 🔴 低配，并给「进攻 / 防御」总基调

**结论分级标准（禁止模棱两可）**：
- 🟢 超配：三维均靠前，或宏观传导明确受益且估值未过热
- 🟡 标配：维度分化，无显著超 / 低配信号
- 🔴 低配：景气下行 / 估值高位 / 资金撤离至少两项触发

**相关性 / 集中度约束（风险平价）**：单一行业超配后组合行业集中度（按权重）**不得超过 40%**；利用股债低/负相关做风险平价，过度集中时自动下调最高分行业权重并提示分散。

**交叉验证**：景气（基本面）与资金（交易面）共振才给强信号，背离时降级为标配并提示。横向对比全市场中位、纵向对比自身历史区间。

|:----:|------|:----:|:----:|:----:|:----:|:----:|

### C. 逻辑依据
- 大类：宏观象限 → 资产顺序 → 当前偏[进攻/防御]的原因

## 降级策略

- 宏观指标缺失 → 用可得指标交叉推断象限，标注口径不确定
- 估值分位缺失 → 改用绝对水平定性判断，标注"分位暂缺"
- 行业景气/资金维度缺失 → 该维度计 0 并提示，信号降级
- 任意维度失败均不得编造数据，输出中明确提示
