# 券商点评日报

> 把分散的卖方点评，整理成可读的板块/行业/公司日报；也可以直接提问，按点评找答案。

**这是一个对话式研究助手：在进宝对话框里说一句需求即可，无需自行检索、分类或排版。**

---

## 1、能做什么？

核心价值是**从卖方 `comment`（点评/快评/段子）提炼产业事实与机构观点**，按主题聚类成结构化日报，而不是堆原文或做主观荐股。

会自动完成：

- **检索**：按日期、大板块、申万一级行业或公司代码拉取点评
- **区分**：客观事件与券商观点分开写，观点按机构分条
- **成文**：输出「今日总览 + 热点话题详析」；闲聊模式则直接对话回答

相对传统研报阅读：它追的是**当日/区间内卖方在聊什么、怎么推演、点了哪些标的**；不替代完整深度报告，也不编造点评里没有的结论。

---

## 2、怎么用？

**第 1 步**：打开进宝，在对话框说明要用本技能，并点明模式或范围，例如——

```
用券商点评日报技能，出一份今天的全面版
用券商点评日报技能，只看科技板块
用券商点评日报技能，按行业总结电力设备
用券商点评日报技能，把宁德时代近7天点评整理成公司版
用券商点评日报技能，闲聊：最近券商怎么看铜价
```

**第 2 步**：若未指定模式，助手会用白话确认；公司版会再确认日期范围。

**第 3 步**：助手检索点评、聚类话题并生成结果；日报以文档形式给出，闲聊默认在对话中直接回答。

> **你只需准备**：想看的范围（全面 / 大板块 / 行业 / 公司）或一个具体问题；公司版准备好代码或公司名，日期可稍后选。

| 模式 | 适合场景 | 怎么说 |
| --- | --- | --- |
| 全面版 | 全市场存档、看全貌 | 「全面版」「七大板块都做」 |
| 大板块 | 只要科技/周期等 | 「科技板块」「周期和制造」 |
| 按行业 | 申万一级或模糊行业名 | 「总结电力设备」「半导体行业点评」 |
| 按公司 | 单票或多票跟踪 | 「宁德时代公司版」「300750 近一周」 |
| 闲聊 | 随口问、可追问 | 「中金怎么看铜」「那目标价呢」 |

---

## 3、多久跑一次？

按需运行，无强制频率。盘后做全面版或板块版存档较常见；跟踪个股可按周或事件日再跑公司版。在进宝对话里再说一次即可重新生成。

---

## 4、生成什么？

**日报模式**通常生成：

- **`YYYY-MM-DD-券商[全面/板块/行业/公司]版日报….md`** — 主文档：总览 + 热点话题
- **底稿（可选保留）** — 如 `板块底稿/`、`行业底稿/`、`分页底稿/`，供复核；终稿以主文档为准

每个热点话题固定三块：

| 部分 | 含义 |
| --- | --- |
| 事件 | 可核实事实与关键数字 |
| 投资观点与推演 | 各机构观点分条，忠实于点评 |
| 核心个股 | 标的卡位与卖方给出的逻辑 |

**闲聊模式**：对话中直接给结论与证据要点，默认不落盘。

**长这样：**

```markdown
# 2026-08-04 券商全面版日报

## 一、今日总览
1. **科技板块**：光模块情绪受政策传闻扰动，卖方更强调海外产能与 InP 缺口……
2. **周期板块**：PTA 供给扰动与化纤提价并行讨论……

## 二、热点话题详析

## 科技

### 热点话题1: InP 衬底紧缺持续至 2028 年，26 年缺口率达 81%
- **事件**：……（关键数字与条件）
- **投资观点与推演**：
  - **（1）中金观点**：……
  - **（2）国盛观点**：……
- **核心个股**：
  - **标的A**：……
```

---

## 5、输出在哪？

在**进宝当前对话**中查看：日报会以 Markdown 文档形式交付（可按会话内文件/下载入口打开）；闲聊结论直接显示在对话气泡里。

常见文档命名示例：

- `2026-08-04-券商全面版日报.md`
- `2026-08-04-券商板块日报-科技.md`
- `2026-08-04-券商行业版日报-电力设备.md`
- `2026-08-04至2026-08-10-券商公司版日报-宁德时代.md`

---

## 6、注意事项

- 数据源是卖方点评流，可能混有快讯与段子，**不是**完整研报库。
- 「科技/周期」是大板块口径；「电子/电力设备」是申万一级行业，说法不同结果不同。
- 结论均来自检索到的点评；未见覆盖处会说明，不会编造目标价或评级。
- 快速模式已取消；需要完整文档请用全面/板块/行业/公司版，随口问用闲聊即可。
