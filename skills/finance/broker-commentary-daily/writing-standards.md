# 写作规范：事件与投资观点的总结表达（所有模式通用）

本文件解决"数字都在、但读不懂"的问题。适用于全面版、按行业总结版、按公司总结版；三者终稿格式对齐，仅数据范围不同。日报话题结构为三件套（事件 / 投资观点与推演 / 核心个股），**不输出原文点评摘录**；本规范只约束每一块**怎么写**。

## 第一原则：事实与观点严格分离

- **事件段只写事实**：谁、何时、发生了什么、关键数字、盘面反应——全部是可核实的客观信息。任何"这说明 / 这意味着 / 反映出"式的解读都不属于事件段。
- **投资观点段只总结券商**：这一段是**券商观点的提炼**，不是撰写者自己的分析。每一个判断、每一条逻辑、每一个前提或风险提示，都必须能在当日点评原文中找到出处。可以消化、重组、整合券商的表述，但不得替券商发明结论。

## 终稿禁止工程化/流程化元话语

终稿是给研究员阅读的研究报告，不是给 Agent 自己看的处理日志。跨板块去重、主归属选择、底稿合并等操作只能发生在后台，**不得以任何形式写进最终日报**。

禁止出现（含近似改写）：

| ❌ 禁止 | 为什么错 |
|---|---|
| 跨板块去重说明：详见【消费】… | 把内部去重流程展示给读者 |
| 与科技交叉，周期侧保留铜加工映射 | 工程归属备注，不是研究内容 |
| 主归属见制造板块 / 主归属建议科技 | 内部路由说明 |
| ××侧不重复展开 / 此处不另开独立话题 | 空壳占位说明 |
| 制造侧映射，主归属建议科技 | 底稿备注被误粘进终稿 |
| 本板块仅作交叉备注 / 仅保留总量层 | 处理说明，不是产业事实或券商观点 |
| 去向：附录线索（交叉引用科技） | 处理清单字段泄漏到正文 |

正确做法：

1. 选定主归属板块后，**只在该板块完整展开**；
2. 其他板块**直接删掉该话题**，不要留标题、不要写“详见别处”；
3. 若某板块删完后当日确实没有足够内容，保留板块标题并写一句正常业务说明即可，例如「当日该板块映射行业下无足够信息量的点评」——仍然不要提去重。

## 总原则：先消化，再表达

写每个话题前，先回答三个问题，答不出来就回去重读原文：

1. 客观上发生了什么？（一句话，纯事实）
2. 券商怎么解读这件事、逻辑链是什么？（有出处）
3. 券商之间的共识和分歧分别是什么？（有出处）

正文是这三个答案的展开，不是原文信息的搬运和串联。

## 今日总览：写成各板块的内容摘要

今日总览的任务是**节省读者阅读全文的时间**。读者只看总览，也应能掌握每个板块当天有哪些重要讨论、各家券商如何判断、机会与分歧落在哪里。它既不能遗漏主要内容，也不能写成话题标题的机械堆砌。

### 每个板块应形成一段有主次的摘要

每个板块通常写 3–5 句，按以下逻辑组织：

1. **总起**：用第一句概括该板块当天讨论的整体重心或共同背景；
2. **展开**：按重要性写清 2–4 个主要话题，每个话题至少用一个完整句子说明“发生了什么 + 券商怎么理解”，不能只报话题名；
3. **收束**：如原文存在明确共识、分歧或关注落点，用最后一句归纳；没有则不强行添加。

总览不是逐机构列观点的正文缩写。相同或相近的机构观点应在总览中合并为“券商普遍认为 / 通信团队主要判断”；只有真实分歧才分别说明。

### 覆盖与取舍

- 应覆盖该板块所有**重要话题**，使读者跳过正文仍不会漏掉当天主要讨论；低信息量、单条噪音和纯个股边角信息不进总览。
- 话题按重要性排序，而不是按底稿出现顺序排列。最重要的讨论放在开头，次要讨论用“此外 / 另一条讨论 / 与此同时 / 相比之下”等承接。
- 每个主要话题必须给出最低限度的解释：不能只写“关注光模块、存储、液冷”，而要写清券商为什么讨论、形成了什么结论。
- 数字只保留能改变理解的少数关键数字；公司名只保留事件主体或最具代表性的标的，禁止复制正文个股清单。
- 总览篇幅随信息量变化，不机械限制字数；目标是比正文明显短，但足以替代一次快速阅读全文。

### 如何写出阅读感

- 使用“总—分—总”或“先主后次”的自然叙述，不用分号把多件事压成一长句；
- 每句话只承担一个中心意思，句与句之间要有关系：验证、传导、对比、分歧或补充；
- 先写事实变化，再写券商解读；不要在同一句中频繁切换行业、公司和观点；
- 避免重复“聚焦、关注、主线、景气”等套话，直接写具体变化与判断。

### 正反示例

❌ 目录式堆砌：

> **科技板块**：光通信因 CSP 财报、三年长协与 InP 紧缺成为主线；存储侧出现 DRAM 涨价和 HBM 减配；算力租赁提价、液冷、电源、MLCC、电子布等方向亦获关注。

✅ 有阅读感的板块摘要：

> **科技板块**：今日科技讨论由北美云厂财报带动，券商普遍认为 AI 资本开支的回报正在得到验证，光互联订单预期因此重新上修。讨论重点进一步从光模块整机延伸到 InP 衬底、光芯片和测试设备，原因是这些上游环节的产能缺口更明确。存储方向则存在分化：通用 DRAM 涨价仍在延续，但 Rubin Ultra 的 HBM 减配传闻使资金重新评估存储在 AI 硬件中的价值占比。除此之外，算力租赁的提价和长期合同提供了较明确的业绩线索，而液冷、电源与 MLCC 更多处于订单和产能验证阶段。

第二种写法仍覆盖光互联、存储、算力租赁和 AIDC 配套，但通过共同背景、主次顺序和逻辑承接把它们组织成了一段内容摘要，而不是压缩目录。

## 话题的拆分与命名

### 拆分：一个话题只讲一条主逻辑，相关事件在话题内分点

- 一个热点话题只承载**一条明确的产业逻辑或核心结论**，但支撑这条逻辑可以包含多个彼此相关、相互验证的客观事件。
- 同一主题下有多个相关事件时，不要堆进一个超长段落；在「事件」下按 **（1）（2）（3）** 分点，每点只讲一个事件，并用简短事实标题标明主体或进展。
- 例如，AIDC 电力主题可分为「（1）英伟达入股电力开发商」「（2）美国电网负荷创新高」「（3）燃机与 SOFC 订单增长」。这些事件共同验证同一条供电约束逻辑，可以保留在一个话题内，但必须分开写。
- 若多个事件没有共同的核心逻辑，只是同属一个产业链或板块，则必须拆成不同热点话题，直接并列在板块下，**不要再套一层「一级主线 / 次主线」汇总标题**。
- 自查信号：如果无法用一句总起句说明这些事件为何属于同一主题，或者标题需要用"与 / 和 / 及"连接两个独立结论，就应该拆成两个话题。
- 例外：同一事件只有一组紧密相连的事实时，可继续写成一个完整段落，无需为了形式强行分点。

### 命名：标题要一句话说清"发生了什么"

- 话题标题按新闻标题写：**主体 + 具体进展/方向/量级**，读者只看标题就知道这条在讲什么。
- 标题中优先放入核心数字、时间或方向词（提价、落地、上修、超预期、拐点、订单、缺口、翻倍）。
- 标题是事实性概括，与事件段口径一致，不夹带撰写者判断。

| ❌ 言之无物 | ✅ 表达突出 |
|---|---|
| InP 衬底紧缺 | InP 衬底紧缺持续至 2028 年，26 年缺口率达 81% |
| NPO/CPO 架构演进 | NPO 获更多战略重视，成为可插拔向 CPO 过渡的桥梁 |
| 存储涨价 | 通用 DRAM 涨价延续，三星以 39% 份额重回第一 |
| 液冷散热订单 | 东方电热液冷模组下半年出货预计达 2000 套、ASP 约 1 万元 |
| 行业景气度提升 | （禁止使用，必须落到具体事件） |

## 事件：纯事实，讲清楚"发生了什么"

1. **先写事实性总起句**：用一句话概括本话题的共同事实背景与量级；总起句不得夹带撰写者判断。
   - ❌（罗列开头）"谷歌云 2026Q2 营收 248 亿美元、同比增 82%，营业利润率升至 35.6%，积压订单超过 5139 亿美元……"
   - ✅（事实性总起）"三大云厂季报集体超预期，并全部上调 2026 年资本开支指引。"
   - ❌（总起句夹观点）"三大云厂财报把'AI 投入见顶'的担忧直接证伪。"——"证伪"是判断；若为券商观点，放观点段。
2. **多个相关事件必须编号分点**：固定格式如下。每点使用完整句子，不写电报体；分点单位是“事件”，不是把每个数字拆成一条。

```markdown
- **事件**：AIDC 电力供给约束在资本、负荷和设备订单三个层面同时出现新进展。
  - **（1）资本事件**：英伟达拟向电力基础设施开发商 Lancium 投资最高 30 亿美元，交易后持股最高 30%。
  - **（2）电力负荷**：美国夏季电力负荷第四次刷新纪录，峰值达到 15.57 亿千瓦。
  - **（3）设备订单**：日立能源单季度新签电网订单 54 亿欧元，同比增长 28%。
```

3. **单一事件可不分点**：若一个话题只有一个核心事件及其紧密相连的数据，仍使用「事件：完整段落」即可，不要机械编号。
4. **数字分主次，只保留"论据数字"**：每个事件分点只保留理解该事件所需的关键数字；背景数字用括号带过或舍弃，避免一个分点再次变成数字墙。
5. **数字的加工只做"事实性对照"，不做解读**：允许同比/环比换算（"同比增 375%"可写"同比增近 4 倍"）、与指引/预期/历史水平的数值对照（"扣非利润 +89%，显著快于收入的 +39%"）；不允许"意味着云需求能见度排到 2028 年"这类推断——那是观点，放观点段且须有券商出处。
6. **多主体用总-分结构**：同一主题涉及多家公司/多个环节时，先总起，再按事件分点和重要性分述，不要平铺成流水账。
7. **盘面反应、资金流向属于事实**，可作为独立事件分点或写在事件段收尾（如"当日药明康德、凯莱英涨停；近一周公募对医药仍连续减仓"）。

## 投资观点与推演：按机构分条总结券商观点

固定格式——按机构分条列示，谁的观点就是谁的：

```markdown
- **投资观点与推演**：
  - **（1）[机构名]观点**：一句结论 + 支撑逻辑（消化后的表达，非原话搬运）。
  - **（2）[机构名]观点**：……
  - **（3）产业/匿名点评**：无明确机构署名时用此标注。
```

写作规则：

1. **每条 = 该机构观点的消化提炼**：先写该机构的核心结论，再写它的推演逻辑；语言重组成通顺叙述，禁止原话机械搬运，也禁止掺入该机构没说过的判断、测算或风险提示。边界一句话：**语言可以是你的，逻辑必须是券商的**。
2. **多家机构观点一致时可合并为共识条**（如"（1）中金/国盛共识："），并写明共识内容；观点冲突时分条呈现，让分歧一目了然，不要替券商调和。
3. **各家给出的可操作信息跟随对应机构条目**：目标价、盈利预测、增速指引、推荐组合等，写在给出它的机构名下，不得混到别家名下。
4. **排序按信息量**：观点最完整、最有增量的机构放前面；只是附和、无增量的可并入共识条，不必强行一家一条。
5. **补齐逻辑跳跃处的桥梁**：券商推理中默认的产业背景，可用半句话补全，让没跟踪该行业的读者能接上；补的必须仍是原文语境里的信息，不是自行脑补的机制。
6. **不要输出「原文点评摘录」**：观点已按机构分条消化提炼，终稿与底稿正文均不另附原文摘录块。

## 核心个股：回答"为什么是它"

每个标的一句话说清：**卡位**（在链条哪个环节）+ **弹性**（券商给出的订单/涨价/业绩映射）+ **锚**（券商给的估值或测算，若有）。禁止"受益于行业景气"式空话；个股逻辑同样必须来自点评原文。

## 完整示例（改写前 vs 改写后）

以药明康德中报为例。

改写前（数字流水账 + 转述拼接）：

> - **事件**：药明康德披露 2026 年半年报：上半年营收 288.97 亿元（同比 +38.93%），归母净利润 110.8 亿元（同比 +29.43%），扣非净利润 105.72 亿元（同比 +89.39%）；毛利率约 53.2%，同比提升约 9.4 个百分点。化学业务收入 249.9 亿元（同比 +53.3%），其中小分子 D&M 收入 149.9 亿元（同比 +72.7%），TIDES 收入 72.6 亿元（同比 +44.3%）。持续经营业务在手订单 664.3 亿元（同比 +25.2%）。公司全面上调 2026 年指引……
> - **投资观点与推演**：中金医药指出超预期主因 CRDMO 模式持续发力……招商医药从产业 β 角度指出……CXO 已从"订单恢复"进入"利润兑现+指引上修"阶段。

改写后（事件只写事实，观点只总结券商）：

> - **事件**：药明康德发布中报并大幅上调全年指引：上半年扣非净利润 105.72 亿元、同比 +89%，显著快于收入的 +39%；毛利率 53.2%，同比提升 9.4 个百分点。多肽（TIDES）收入 72.6 亿元、同比 +44%；在手订单 664.3 亿元、同比 +25%。全年收入指引由 513–530 亿元上调至 585–605 亿元（增速口径由 18–22% 上调至 35–39%），并提前启动常州新基地建设。当日药明康德、凯莱英 A 股涨停，康龙化成 +7.8%、昭衍新药 +5.4%；近一周公募对医药仍呈连续减仓。
> - **投资观点与推演**：
>   - **（1）中金观点**：超预期的来源是结构性的——CRDMO 模式下后期及商业化项目增加、产能效率提升，而非一次性因素；据此将全年 TIDES 收入增速指引由约 40% 上调至约 45%，A 股目标价上调 28.5% 至 167 元，维持跑赢行业。
>   - **（2）招商观点**：从供给端看，多肽、小核酸及新机制小分子的大药陆续进入商业化，具备能力与产能的中国头部 CDMO 供给偏紧；药明提前启动常州新基地、康龙拟投约 30 亿元扩产，扩产动作本身即是对后续订单的确认；推荐沿链条关注多肽产能（凯莱英）、大分子与 ADC CDMO（药明生物、药明合联）。
>   - **（3）国盛观点**：规模效应释放进一步验证行业景气，订单与指引同步上修显示中长期需求韧性。
>   - **（4）高盛交易台（盘面解读）**：当日 CRO 集体走强直接归因于药明各业务线业绩大幅超预期。

## 自查清单（每个话题写完过一遍）

- [ ] 今日总览是否覆盖了每个板块的所有重要讨论，同时剔除了低信息量边角内容？
- [ ] 每个板块是否写成有主次、有承接的内容摘要，而不是用分号串联话题名？
- [ ] 每个主要话题是否至少说清“发生了什么 + 券商怎么理解”？
- [ ] 总览里的判断是否来自券商观点，而不是撰写者自行判断？
- [ ] 每个话题是否只有一条主逻辑？无共同逻辑的事件是否拆成了不同话题？
- [ ] 标题是否写清了主体和具体进展/量级？还是言之无物的名词短语？
- [ ] 事件段是否只有事实？有没有混入"说明 / 意味着 / 反映出"式解读？
- [ ] 事件是否先有事实性总起句？涉及多个相关事件时是否按（1）（2）（3）分点，而不是堆成一个长段落？
- [ ] 每个事件分点是否只讲一个事件，并控制了关键数字、避免再次形成数字墙？
- [ ] 观点段是否按机构分条（（1）（2）……）？每条内容是否确属该机构、目标价等信息有没有挂错名下？
