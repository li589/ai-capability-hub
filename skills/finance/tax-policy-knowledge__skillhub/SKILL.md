# 财税政策知识库 v3.16.4

> 全量财税知识库 · 多维度风险指标模型 · 合规应对指引 —— 三大专业底座，全面、专业、可落地

---

## 快速开始

直接提问即可，无需任何命令：

```
"我是小规模纳税人，月销售额8万元，增值税怎么算？"
"主播带货收入怎么交个税？"
"用私人账户收公司款项有风险吗？"
"给我一份常年税务顾问服务协议模板"
```

## **小技巧**：说清具体场景（"月销售额8万"比只说"小规模纳税人"更精准）；补充所在地区可获得地方政策参考；一次只问一个问题。

## 专业底座：知识库 · 风险模型 · 合规指引

本技能以「全面、专业、可落地」为底座，三大支柱协同支撑企业合规与机构执业：

**① 全量财税知识库（全面）**

- 覆盖 **13 个税种 + 7 项地方税费 + 6 项社保费 + 新业态**，政策库自动联网更新，重大新规（增值税法实施、发票正负面清单等）即时同步。
- 每条结论标注政策依据并可溯源，区分国家 / 地方 / 行业口径，避免一刀切。

**② 多维度风险指标模型（专业）**

- 构建覆盖**全税种、全行业、全地区、全专题、全组合**的量化风险指标（**共 491 项**），自动评分定位高风险点，匹配风险等级与整改优先级。
- 覆盖虚开虚抵、阴阳合同、私户收款、税负异常、关联交易失当、新业态隐匿收入等典型场景；完整分类模型见下方「分类风险指标模型」。

**③ 合规应对指引（可落地）**

- 正负面清单明确红线与合规标准；七流一致（由五流合一扩展，新增收入流/成本流/人员流）交叉核对与分层整改步骤。
- 风险自查报告、合规建议、整改清单一键生成；配套真实案例画像与实操流程，照着做即可落地。

## 分类与双视角（企业合规指引 ↔ 税务师合规咨询）

本知识库按**双板块**组织，本包是贯穿两边的**共享核心入口（board=Shared）**：

- **板块 A · 企业合规指引（需求侧）**：企业/CFO/内审用于自身合规、风险自查、整改。问法如"我们行业有哪些税务风险""企业怎么做到七流一致"。
- **板块 B · 税务师合规咨询（供给侧）**：事务所/咨询机构用于承接与交付财税服务、执业风控。问法如"事务所怎么建三级复核""咨询项目怎么交付"→ 由 `tax-advisory-practice`（税务师合规咨询执业专题）承接。

> 两板块共享同一云端政策底座（税种政策/发票正负面清单/七流一致/风险指标/合同模板/合规报告），不重复建设；跨板块访问经索引引用。

## 典型应用场景

**小规模纳税人增值税**

> 问："月销售额8万，增值税怎么算？"
>
> 答：月销售额8万<10万，**免征增值税**（普票部分）。

**主播带货税收**

> 问："主播带货收入怎么交个税？"
>
> 答：直播带货佣金属于**劳务报酬所得**，由平台/MCN机构代扣代缴，预扣率相应税率区间，年度汇算后并入综合所得、实际税负相应税率区间。

**风险自查**

> 问："用私人账户收公司款项有风险吗？"
>
> 答：⚠️ **极高风险**：金税四期实现平台数据+银行流水+发票四流自动交叉比对。

**合同涉税条款审核**

> 问："这份销售合同有哪些涉税风险？"
>
> 答：从多种高发风险条款审查——兼营/混合销售是否分别核算、价外费用是否计税、是否存在阴阳合同/拆分合同、关联交易定价是否公允、工程政采补充合同是否规避招标。

**100+合同模板**

> 问："我要一份劳动合同模板"
>
> 答：提供标准版、高管版、技术岗版、销售岗版等多种劳动合同模板，含薪酬激励、保密、竞业限制等条款。

## 经营合规八大陷阱识别（企业侧刚需）

## 三流联动风险指标与自查应对（闭环实战）

在上方「分类风险指标模型」491 项体系基础上，本技能落地**三流联动（合同流 / 票据流 / 资金流 / 货物流 / 收入流 / 成本流 / 人员流）闭环自查体系**——聚焦可落地的 G1–G7 专项模型与「扫描 → 报告 → 应对 → 回写」前后闭环：

**① 三流联动专项模型（G1–G7 七组）**

- **G1 收入真实性 / G2 成本真实性 / G3 人员薪酬 / G4 税负利润 / G5 凭证链（四流一致）/ G6 时间序列异常 / G7 国际税合规**（合并营收≥7.5亿欧元适用：支柱二全球最低税15%、转让定价同期资料、国别报告）。
- 每项指标承载 **E1–E10 十要素闭环**（公式逻辑、参与数据、预警阈值、模型权重、数据源、关联业务表单、风险消除指引、自查报告模板、原始凭证、排除条件/免触发白名单），并采用**阈值双轨**（硬逻辑确定性规则 + 分位数分层偏离，拒绝一刀切常数阈值）。
- **组合联动降误报**：多条件同现（如空壳企业 + 资金回流 + 异常进项）才升级为高确信疑点，避免单一指标误报。

**② 数据采集风险自查分析报告**

- 按企业画像（小微商贸·轻量硬逻辑 / 中型制造·标准组合联动 / 跨国集团·G7+域E）自动选组，跑完指标后输出结构化报告：综合风险分（0–100）+ 红/橙/黄/绿等级 + 命中指标清单 + 组合联动证据包。

**③ 合规应对指引**

- 针对每项命中给出四段式应对：风险定性 → 政策依据 → 整改动作 → 留存凭证；虚受票、资金回流、私户收款、四流不一致等高频场景均有可直接套用的抗辩与整改话术。

**④ 完整示例（中型制造企业·年营收约 8000 万元）**

> 问："帮我做一次三流联动风险自查。"
>
> 答：自动选 G1–G6 共 22 项指标，命中 9 项（4 红 5 黄），综合风险分 **54.9 → 🟡 中（黄）**；组合联动命中「接受虚开嫌疑」「人员收入三表不联动」两组证据链，输出《数据采集风险自查分析报告》+《合规应对指引》，并给出 3 项优先整改动作。

## 重要提示与边界声明

**重要提示**

1. **计算结果仅供参考**：所有税额测算、优惠判断、风险评分均为辅助参考，**不构成税务申报、审计或法律意见**。
2. **专业事项请咨询执业人员**：税务筹划、争议解决、稽查应对等需结合企业实际，由执业税务师/律师量身定制。
3. **数据以官方为准**：政策时效性强，个案结论可能因地区、行业、时间而异；涉及重大利益请向主管税务机关或专业人士二次确认。

**边界（本技能不做的）**

- **不代办**：实时申报、缴款、退税、注销等需登录电子税务局的操作
- **不代理**：税务行政复议、诉讼、鉴证等需执业资质的法律事务
- **不跨域**：医疗、法律、投资理财建议等非财税问题
- **不担保**：政策时效与个案结论以税务机关/执业税务师最终认定为准

**服务说明**

- 每次提问都能获得完整闭环：智能问答 → 结构化结果 → 政策依据溯源 → 真实案例关联 → 实操辅导 → 反馈评价 → 合规报告

**隐私保护**

- 仅在本机生成随机匿名标识用于服务调用，不会采集任何设备信息或个人隐私数据。
