# 07-学生心理档案

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：心理,档案,辅导,跟踪

## 功能描述
帮助班主任建立学生心理健康台账与辅导记录，覆盖心理筛查结果、情绪行为观察、危机预警等级、个别辅导过程与转介记录。输出标准化心理档案字段与辅导记录表，便于动态跟踪和及时干预。

## 触发词
["07-学生心理档案", "心理档案", "心理辅导记录", "心理健康", "心理跟踪"]

## 使用方法
### 输入参数
- 用途：建立台账 / 个别辅导记录 / 危机预警跟踪
- 学生心理关注点：情绪、人际、学业压力、家庭变故等
- 是否已筛查（可选）

### 输出示例
【07-学生心理档案】
输出：①《学生心理档案》字段模板 ②《心理辅导记录表》③预警分级标准与示例。

## 适用场景
- 学期初心理筛查后建立关注台账
- 对情绪、行为异常学生的持续跟踪
- 心理危机"一生一档"管理要求

## 注意事项
- 心理档案属高度敏感信息，严格保密，仅限班主任与心理教师知晓
- 班主任以观察与陪伴为主，专业干预须转介学校心理教师或专业机构
- 发现自伤、伤人等高危信号须立即上报，启动危机干预流程
- 用语去标签化，避免给学生贴"问题学生"标签

**预警分级示例：**
- 黄（关注）：近期情绪低落、出勤下降，但无自伤意念 → 每周谈心1次，持续观察
