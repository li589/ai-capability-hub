# 01-班主任工作计划

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：计划,班主任,学期,带班

## 功能描述
帮助班主任制定学期、月、周工作计划，输出包含班级现状分析、带班目标、重点任务、月度安排与保障措施的结构化方案。支持按学段（小学/初中/高中）和班级实际学情（如纪律松散、学困生多、凝聚力弱）定制侧重点。

## 触发词
["01-班主任工作计划", "班主任计划", "学期计划", "带班计划", "班级工作计划"]

## 使用方法
### 输入参数
- 学段与班级：如"初二（3）班"
- 时间范围：学期计划 / 月计划 / 周计划
- 班级现状：纪律、学风、凝聚力、特殊学生等关键信息
- 重点目标（可选）：习惯养成、成绩提升、家校协同等

### 输出示例
【01-班主任工作计划】
输出一份完整《XX班 XXXX 学年 X 学期班主任工作计划》，含：
1. 班级现状分析
2. 本学期带班目标（德育/学风/班级建设）
3. 月度工作重点任务表
4. 保障措施（常规管理、家校沟通、班干培养）

## 适用场景
- 新学期开学前制定工作计划
- 月度/周工作梳理与汇报
- 学校要求提交书面班主任工作计划

## 注意事项
- 计划要可落地，避免空泛口号；任务需明确"做什么、谁负责、何时完成"
- 目标宜具体、可衡量（如"迟到率降至 5% 以内"）
- 需结合本班真实学情，不照搬通用模板
