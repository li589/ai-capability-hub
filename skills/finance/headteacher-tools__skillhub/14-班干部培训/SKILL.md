# 14-班干部培训

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：班干部,培训,学生干部,班委

## 功能描述
帮助班主任完成班干部的选拔、分工、职责界定与持续培养，输出班委架构图、岗位职责说明书、选拔流程、培训课件框架与月度成长复盘模板，培养一支能自治、肯服务的班干部队伍。

## 触发词
["14-班干部培训", "班干部", "班委培训", "学生干部", "班级自治"]

## 使用方法
### 输入参数
- 需求：选拔方案 / 职责分工 / 培训内容 / 复盘提升
- 班级规模与学段
- 现有问题（如"班委不主动""职责不清"）

### 输出示例
【14-班干部培训】
输出：①班委架构与职责表 ②选拔/轮换流程 ③首次培训大纲 ④月度复盘模板。

## 适用场景
- 新班组建或学期初班委换届
- 班委履职不力、职责混乱时重整
- 班干部能力提升常态化培训

## 注意事项
- 选拔重责任心与服务意识，而非仅成绩好
- 推行轮岗/竞选，让更多学生得到锻炼
- 班主任"扶上马送一程"，逐步放权，培养自治
- 避免班干部特权化，强调服务而非管理

## 附：班委职责与培训模板（可直接套用）

**一、班委架构与职责（示例）**
| 岗位 | 核心职责 |
|------|----------|
| 班长 | 统筹班级事务、传达通知、晨会组织 |
| 学习委员 | 作业收交、课代表协调、学风督促 |
| 纪律委员 | 课间/自习纪律记录与提醒 |
| 卫生委员 | 值日排班、卫生检查 |
| 文体委员 | 活动组织、两操带队 |
| 生活/心理委员 | 关注同学情绪、反馈异常情况 |

**二、选拔流程**
自荐/推荐 → 竞选演讲（1分钟） → 全班投票 → 试用期1月 → 正式聘任

**三、首次培训大纲**
1. 角色认知："班干部是服务者，不是特权者"
2. 工作方法：如何提醒同学而不引发抵触
3. 沟通技巧：向上（老师）汇报、向下（同学）协调
4. 应急处理：冲突、突发状况的第一反应

**四、月度复盘模板**
- 本月做得好的：____ 遇到的困难：____ 下月改进：____ 需要老师支持：____
