# 13-学生个别教育

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：个别教育,转化,学困生,行为偏差

## 功能描述
为班主任针对学困生、行为偏差生、内向孤僻生等特殊学生制定个别教育方案，包含问题诊断、成因分析、阶梯目标、具体措施与家校协同策略，输出可执行的"一生一策"方案与跟踪记录表。

## 触发词
["13-学生个别教育", "个别教育", "学困生转化", "行为偏差", "一生一策"]

## 使用方法
### 输入参数
- 学生类型：学困 / 行为偏差 / 内向孤僻 / 家庭困境
- 具体表现与成因线索
- 已尝试措施（可选）

### 输出示例
【13-学生个别教育】
输出：①问题诊断与成因分析 ②阶梯式教育目标 ③具体干预措施（校内+家庭）④跟踪记录表。

## 适用场景
- 学困生学业帮扶与信心重建
- 经常违纪、冲突多的行为偏差生转化
- 性格封闭、社交困难学生的融入引导

## 注意事项
- 先共情、先找亮点，再谈问题，建立信任是前提
- 目标小步递进，及时肯定微小进步，避免急于求成
- 多维度归因（家庭、同伴、学业、心理），不简单归咎学生
- 保护隐私，方案仅限相关教师知晓，不公开讨论

## 附：个别教育方案与跟踪表（可直接套用）

**一、"一生一策"方案框架**
- 学生画像：优势____ 困难____ 兴趣____
- 成因分析：学业____ 家庭____ 同伴____ 心理____
- 阶梯目标：近期（1月）____ 中期（1学期）____ 远期____
- 干预措施：
  - 校内：座位安排、结对帮扶、课堂正向关注
  - 家庭：每周一次亲子沟通建议、家长情绪支持
  - 心理：必要时转介心理教师

**三、示例（厌学学困生）**
- 诊断：基础薄弱+长期挫败感，归因"我不是读书的料"
- 近期目标：每天完成1项可完成的任务，重建胜任感
- 措施：降难度分层作业、安排热心同桌、每进步即表扬
- 跟踪：第2周主动交作业次数由1次升至4次，给予公开肯定
