# 09-学生评语撰写

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：评语,撰写,评价,期末

## 功能描述
帮助班主任撰写个性化、有温度的学生学期评语。根据学生特点（学业、性格、特长、进步点、待改进处）生成避免套话的评语，支持"鼓励型""中肯型""鞭策型"等不同语气，并可批量生成全班初稿供教师润色。

## 触发词
["09-学生评语撰写", "学生评语", "写评语", "期末评语", "班主任评语"]

## 使用方法
### 输入参数
- 学生特点：性格、学业表现、特长、典型事例
- 评语基调：鼓励 / 中肯 / 鞭策
- 字数要求（可选）

### 输出示例
【09-学生评语撰写】
输出一段 80-120 字个性化评语，含优点肯定 + 具体事例 + 期望建议，避免"该生听话"等套话。

## 适用场景
- 学期末操行评语撰写
- 学生成长手册、素质报告单填写
- 需要差异化、有温度的个体评价

## 注意事项
- 以具体事例支撑评价，避免空泛形容词堆砌
- 先扬后抑，肯定为主，改进建议要可操作、不带刺
- 保护自尊，不公开对比、不贴负面标签
- AI 生成后建议教师结合真实了解再润色，确保真实

---

## 附：评语结构与示例（可直接套用）

**评语公式：** 肯定亮点（1-2句） + 具体事例（1句） + 期望建议（1句）

**示例A（鼓励型·进步生）：**
"这学期你让老师刮目相看——数学从不及格到稳稳及格，背后是你每天坚持问问题的韧劲。如果课上能更勇敢地举手发言，你的自信会更足。保持这股劲，下学期期待你更大的突破！"

**示例B（中肯型·安静优等生）：**
"你沉静踏实，作业始终工整规范，是班里让人放心的孩子。美中不足的是集体活动中略显被动。试着多参与班级事务，你会发现自己比想象中更闪亮。"

**示例C（鞭策型·聪明但松懈生）：**
"你脑子灵、反应快，课堂上常有精彩发言，但作业偶尔敷衍、粗心丢分可惜。天赋需要自律来兑现，若能沉下心把基础打牢，你的潜力远不止于此。"
