# 05-家访记录表

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：家访,记录,表格,家校

## 功能描述
为班主任提供家访前的提纲设计、家长预约话术，以及规范化的家访记录表。覆盖普访、学困生家访、特殊家庭家访、突发事件家访等类型，输出可填写的记录字段与示例，保障家访有目的、有记录、有跟进。

## 触发词
["05-家访记录表", "家访", "家访提纲", "家访记录", "上门走访"]

## 使用方法
### 输入参数
- 家访类型：普访 / 学困生 / 特殊家庭 / 突发事件
- 学生情况与家访目的
- 需沟通的重点事项

### 输出示例
【05-家访记录表】
输出：①家访提纲（沟通要点）②家长预约话术 ③《家访记录表》模板 ④填写示例。

## 适用场景
- 学期初普访或重点学生家访
- 学生出现学业、行为、心理预警时上门沟通
- 学校要求的家访工作留痕与归档

## 注意事项
- 家访前与家长预约，避开用餐与休息时间，着便装、守时
- 多报喜、巧报忧，先肯定学生优点再谈问题，避免"告状式"
- 涉及家庭隐私须保密；不单独进入异性家长房间，注意安全
- 家访后须形成记录并跟进约定事项

**家访提纲示例（学困生类）：**
1. 肯定孩子在校的闪光点（如劳动积极、待人礼貌）
2. 说明近期学业下滑的具体表现与可能原因
3. 了解家庭学习环境与在家表现
4. 协商家校配合的具体做法（如固定作业检查时间）

**家长预约话术：**
"XX家长您好，我是孩子的班主任。想找个您方便的时间上门拜访，了解一下孩子在家的情况，也顺便聊聊在校表现。您看这周六上午或周日下午哪个时间方便？大概占用您半小时。"
