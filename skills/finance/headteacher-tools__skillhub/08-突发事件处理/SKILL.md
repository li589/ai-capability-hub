# 08-突发事件处理

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：突发事件,应急,处理,上报

## 功能描述
为班主任提供校园突发事件（学生意外伤害、突发疾病、校园欺凌、离家出走、极端情绪、公共卫生事件等）的标准处置流程与上报模板，明确"先处置、再上报、后跟进"的应急步骤，保障响应及时、程序合规、记录完整。

## 触发词
["08-突发事件处理", "突发事件", "应急", "意外处理", "校园事件上报"]

## 使用方法
### 输入参数
- 事件类型：伤害 / 疾病 / 欺凌 / 出走 / 情绪危机 / 其他
- 事发时间、地点、涉及人员
- 当前状况与已采取措施

### 输出示例
【08-突发事件处理】
输出：①该类事件的标准处置流程 ②即时上报模板（电话/文字）③事后记录与跟进表 ④注意事项。

## 适用场景
- 学生校内受伤、突发疾病第一时间处置
- 校园欺凌、冲突事件介入与上报
- 学生失联、情绪失控等紧急状况应对

## 注意事项
- 生命至上：先抢救、先止损，再按程序上报，不隐瞒、不拖延
- 第一时间通知校医、值班领导及学生监护人
- 保护现场与证据，避免不当传播扩大影响
- 事件处理后须心理安抚与跟踪，防止次生伤害

## 附：突发事件处置流程与上报模板（可直接套用）

**一、通用处置流程（黄金原则：救人→稳控→上报→记录）**
1. 现场处置：查看伤情/状况，呼叫校医与值班领导，必要时拨打120/110
2. 稳控现场：疏散围观、保护当事人、避免二次伤害
3. 即时上报：向政教处/校领导口头报告，同步通知监护人
4. 跟进处置：配合调查、留存记录、心理安抚
5. 复盘归档：填写事件报告，完善预防机制

**四、示例（学生课间意外受伤）**
