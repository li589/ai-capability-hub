# 03-班级活动策划

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：活动,策划,班会,实践

## 功能描述
为班主任策划主题班会、节日活动、社会实践、团队拓展等班级活动，输出包含活动目标、流程安排、人员分工、物料预算、安全预案与总结模板的完整方案，可按学段与活动主题（如"诚信教育""感恩""减压团建"）定制。

## 触发词
["03-班级活动策划", "班级活动", "活动策划", "主题活动", "班级团建"]

## 使用方法
### 输入参数
- 活动类型：主题班会 / 社会实践 / 节日活动 / 拓展团建
- 主题：如"诚信伴我行""减压赋能"
- 参与对象与时长：年级、人数、预计时长
- 场地与资源（可选）

### 输出示例
【03-班级活动策划】
输出一份《XX主题活动策划方案》：①活动目标 ②流程时间表 ③人员分工 ④物料清单 ⑤安全预案 ⑥活动总结模板。

## 适用场景
- 每月主题班会设计
- 学校布置的节日/专题活动
- 班级凝聚力建设、考前减压活动

## 注意事项
- 流程需有时间节点与负责人，避免现场混乱
- 校外/户外活动必须配套安全预案与家长知情同意
- 活动目标要与学生发展（德育/心理/协作）挂钩，不流于形式
