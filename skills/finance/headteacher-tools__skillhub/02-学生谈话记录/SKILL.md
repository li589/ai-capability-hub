# 02-学生谈话记录

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：谈话,记录,沟通,谈心

## 功能描述
为班主任提供学生个别谈心谈话的提纲设计与规范化记录表。按谈话目的（表扬鼓励、学业帮扶、行为纠偏、心理疏导、矛盾调解、生涯指导）生成针对性谈话要点，并输出可直接填写的记录表，方便后续跟踪与归档。

## 触发词
["02-学生谈话记录", "学生谈话", "谈心", "谈话记录", "个别谈话"]

## 使用方法
### 输入参数
- 学生基本情况：姓名、年级、主要问题或亮点
- 谈话目的：鼓励 / 学业 / 行为 / 心理 / 矛盾 / 生涯
- 谈话背景：近期事件或触发原因

### 输出示例
【02-学生谈话记录】
输出：①本次谈话提纲（3-5个核心问题）②规范化《学生谈话记录表》③后续跟进建议。

## 适用场景
- 学生出现成绩下滑、违纪、情绪异常时个别谈心
- 月度/学期定期谈心，建立成长跟踪
- 学校要求留痕的谈话工作

## 注意事项
- 谈话以尊重、倾听为前提，先共情再引导，避免训斥式
- 涉及隐私与心理问题时注意保密，必要时转介心理老师
- 记录需客观、具体，避免主观标签化用语
