# 04-学生档案管理

## 基本信息
- 版本：1.0.0
- 分类：班主任工具
- 标签：档案,管理,学生,成长

## 功能描述
帮助班主任建立系统化的学生电子档案，覆盖基本信息、学业轨迹、奖惩记录、家庭情况、特长与成长足迹等维度，输出标准化档案字段模板与使用示例，便于学期跟踪、评语撰写与家校沟通。

## 触发词
["04-学生档案管理", "学生档案", "班级档案", "成长档案", "学生信息管理"]

## 使用方法
### 输入参数
- 档案用途：学期跟踪 / 评语依据 / 转接交接 / 家校沟通
- 学段与班级
- 需包含的维度（可选）：学业、奖惩、家庭、心理、特长

### 输出示例
【04-学生档案管理】
输出一份《学生个人档案表》模板（含基本信息、学业、家庭、成长记录等字段）及填写示例。

## 适用场景
- 新接班级快速建立学生底册
- 学期末整理学生成长档案
- 为学生评语、个别教育提供数据支撑

## 注意事项
- 档案含家庭、心理等敏感信息，须严格保密、专人管理
- 记录客观，多用事实与数据，少主观评价
- 涉及家庭变故、特殊学生须重点关注并动态更新

## 附：学生个人档案表模板（可直接套用）

**《____班学生个人档案》**

| 维度 | 字段 |
|------|------|
| 基本信息 | 姓名、性别、出生、学号、座位号 |
| 学业情况 | 各学期总分/排名趋势、优势科、薄弱科 |
| 奖惩记录 | 时间、事项、等级 |
| 家庭情况 | 监护人、联系方式、家庭结构、教养方式 |
| 特长爱好 | |
| 身心健康 | 体质、心理关注点 |
| 成长足迹 | 关键事件、进步记录（按时间） |

**填写示例（节选）：**
- 学业情况：初一上总分 482（班排 28）→ 初一下 521（班排 15），数学为薄弱科
- 家庭情况：单亲家庭，随母，母亲务工繁忙，陪伴时间少
- 成长足迹：本学期主动担任值日组长，责任心明显增强
