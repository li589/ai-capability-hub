# 股票经营分析 Skill

## 功能描述

本技能用于对股票进行专业经营层面诊断，聚焦「行业地位、业务结构、核心竞争力、经营成长性、经营风险」五大核心维度，客观判断公司经营质量、护城河深浅、业务健康度与长期增长逻辑，不做股价预测，仅输出经营面专业结论，适配 AI 诊股场景落地。

## 使用方法

当用户询问股票经营状况、业务结构、行业地位、竞争力、护城河、经营风险、增长动力相关问题时自动触发。

## 分析框架

> **核心原则**：既要写经营亮点，也要揭示经营短板；不夸大护城河、不弱化经营风险；单一指标不做结论，多维度共振再判断。

### 一、行业地位与竞争格局

#### 1. 关键指标
- 行业排名（龙头 / 前三 / 中游 / 尾部）
- 市场占有率（市占率）
- 行业集中度（CR3/CR5）
- 行业竞争格局（垄断 / 寡头 / 充分竞争 / 分散）

#### 2. 判断标准

**龙头地位：**
- 行业排名前二，市占率行业第一
- 定价权、话语权强，行业规则制定者

**一线梯队：**
- 行业前三，市占率位居前列
- 具备较强竞争力，与龙头差距较小

**中游梯队：**
- 行业中游，市占率一般
- 无明显优势，跟随行业发展

**尾部梯队：**
- 行业排名靠后，市占率低
- 竞争力弱，易被市场淘汰

#### 3. 行业特性
- **消费 / 家电 / 白酒**：龙头效应极强，市占率越高壁垒越强
- **科技 / 半导体**：技术迭代快，市占率需结合技术实力判断
- **周期 / 制造**：市占率随周期波动，龙头抗风险能力更强
- **新兴行业**：格局未定，增速比市占率更重要

---

### 二、业务结构与营收构成

#### 1. 关键指标
- 主营业务收入占比
- 单一业务依赖度
- 海内外收入结构
- 毛利结构（高毛利 / 低毛利业务占比）

#### 2. 判断标准

**结构优质：**
- 主营业务突出，占比 > 70%
- 无单一业务过度依赖（单一占比 < 80%）
- 高毛利业务占比持续提升

**结构一般：**
- 主营业务清晰，占比 50%~70%
- 业务多元但无核心亮点
- 毛利结构平稳

**结构较差：**
- 业务分散，无核心主营
- 单一业务依赖过高（> 80%）
- 低毛利业务拖累整体盈利

#### 3. 行业特性
- **龙头企业**：主营高度集中，结构简洁高效
- **多元化企业**：关注协同效应，而非单纯多元
- **出口型企业**：海外收入占比高，需关注汇率与地缘风险
- **内需型企业**：国内收入为主，受宏观消费影响大

---

### 三、核心竞争力（护城河）

#### 1. 关键指标
- **品牌壁垒**：品牌知名度、溢价能力、用户忠诚度
- **技术 / 专利壁垒**：核心技术、专利数量、研发投入
- **成本 / 规模壁垒**：规模效应、成本优势、产能利用率
- **渠道壁垒**：渠道覆盖、渠道控制力、渠道效率
- **资质 / 政策壁垒**：行业准入资质、政策特许、牌照壁垒

#### 2. 判断标准

**护城河深厚：**
- 具备 2 项及以上核心壁垒
- 壁垒难以复制、难以替代
- 竞争对手短期无法追赶

**护城河一般：**
- 具备 1 项核心壁垒
- 壁垒有一定优势，但可被追赶

**无明显护城河：**
- 无核心壁垒
- 依赖价格战、行业红利，无长期优势

#### 3. 行业特性
- **消费**：品牌 + 渠道为核心壁垒
- **科技 / 制造**：技术 + 专利 + 规模为核心壁垒
- **医药 / 金融**：资质 + 政策为核心壁垒
- **周期**：成本 + 规模为核心壁垒

---

### 四、经营成长性与增长动能

#### 1. 关键指标
- 营收 / 利润连续增长能力
- 新业务 / 第二增长曲线
- 产能 / 订单 / 项目落地进度
- 产能利用率、开工率

#### 2. 判断标准

**高成长：**
- 营收 / 利润连续 2 年正增长，增速高于行业
- 新业务清晰，落地顺利
- 产能利用率高，订单饱满

**稳健成长：**
- 营收 / 利润平稳，增速与行业持平
- 有新业务储备，逐步推进

**成长乏力：**
- 营收 / 利润停滞或下滑
- 无新业务，依赖老业务
- 产能利用率低，订单不足

#### 3. 行业特性
- **新兴行业**：高增长为常态，重点看增速持续性
- **成熟行业**：稳健增长即为优质，不追求高增速
- **周期行业**：成长随周期波动，重点看底部复苏能力

---

### 五、经营风险与隐患

#### 1. 关键指标
- **客户 / 供应商集中度风险**：前五大客户/供应商占比
- **原材料 / 价格波动风险**：原材料成本占比、价格波动敏感度
- **政策 / 监管风险**：行业政策变化、监管趋严风险
- **产能过剩 / 项目烂尾风险**：在建工程、产能利用率
- **管理层 / 治理风险**：管理层变动、股权结构、治理问题

#### 2. 判断标准

**风险可控：**
- 无重大经营风险
- 风险为行业共性，公司抵御能力强

**风险需关注：**
- 存在 1-2 项中等经营风险
- 风险可能影响短期经营，但不致命

**风险突出：**
- 存在多项重大经营风险
- 风险可能导致经营恶化、业绩大幅下滑

#### 3. 行业特性
- **ToB 企业**：警惕客户集中度过高
- **上游资源型**：警惕原材料价格波动
- **教培 / 医药 / 互联网**：警惕政策监管风险
- **重资产企业**：警惕产能过剩、折旧压力

## 分析流程（COT）

### 第一步：数据获取

按「数据获取」一节的调用方式，向接口发送用户问句，一次性取回本次分析所需的全部数据，包括：公司基础信息（行业地位、主营业务、竞争力）、主营业务构成（营收拆分、毛利结构）、公司公告（新业务、订单、产能）、投资者互动（护城河、风险相关问题）、券商研报（行业格局、竞争力分析）、机构调研（经营层面关注）、题材概念（新业务方向与热点）等。

### 第二步：指标梳理

梳理行业地位、业务结构、竞争力、成长性、经营风险五大维度数据：
1. **行业地位**：排名、市占率、竞争格局
2. **业务结构**：主营占比、业务依赖度、毛利结构
3. **竞争力**：品牌、技术、成本、渠道、资质壁垒
4. **成长性**：营收利润增速、新业务、产能利用率
5. **经营风险**：集中度、原材料、政策、治理风险

### 第三步：分维度逐项评估

按顺序判断，给出明确等级：
- 行业地位：**龙头 / 一线梯队 / 中游梯队 / 尾部梯队**
- 业务结构：**结构优质 / 结构一般 / 结构较差**
- 竞争力：**护城河深厚 / 一般 / 无明显护城河**
- 成长性：**高成长 / 稳健成长 / 成长乏力**
- 经营风险：**风险可控 / 需关注 / 风险突出**

### 第四步：行业特性适配

结合行业属性（成熟 / 成长 / 周期 / 科技）修正判断标准：
- 成熟行业：稳健增长即为优质，不追求高增速
- 新兴行业：增速比市占率更重要
- 周期行业：重点看底部复苏能力

### 第五步：综合研判

- 提炼经营核心亮点（3 个）、核心风险（3 个）
- 给出整体经营质量评级
- 权衡矛盾信号（如龙头地位但成长乏力），明确说明逻辑

### 第六步：输出结论

- 客观陈述经营状况，给出观察建议
- 不荐股、不预测股价，仅输出经营面专业结论

## 注意事项

1. **数据时效性**
   - 优先使用最新年报、半年报、公司公告经营数据
   - 注明数据截止日期
   - 如无最新经营数据，明确说明

2. **行业对比**
   - 必须结合行业均值、行业格局判断经营质量
   - 无行业数据时，说明仅做公司自身纵向对比

3. **客观中立**
   - 既要写经营亮点，也要揭示经营短板
   - 不夸大护城河、不弱化经营风险
   - 避免绝对化表述

4. **数据来源**
   - 经营数据来自公司财报、公告、官方披露
   - 行业地位、市占率来自权威行业数据或券商统计
   - 不使用小道消息、非官方传言

5. **逻辑自洽**
   - 最终结论必须与五大经营维度一致
   - 如出现矛盾（如龙头地位但成长乏力），需明确说明权衡逻辑
   - 单一指标不做结论，多维度共振再判断

## 示例分析

**用户输入**："格力电器经营状况怎么样"

**分析结果**：

```markdown
## 【格力电器 (000651)】经营分析报告

### 一、核心看点
公司为空调行业绝对龙头，经营稳健、护城河深厚，但业务过度依赖空调、多元化进展缓慢，成长性偏弱，整体经营质量**稳健但缺乏弹性**。

### 二、亮点和风险点

**经营亮点：**
1. **行业龙头地位稳固**：空调行业市占率约 35%，常年第一，品牌壁垒极强
2. **渠道体系完善**：线下网点规模行业领先，渠道控制力与效率优势明显
3. **经营质量优异**：经营现金流持续为正，资产质量高，经营风险极低

**经营风险：**
1. **业务结构单一**：空调收入占比超 70%，行业下行压力大
2. **多元化进展缓慢**：光伏、储能、冰洗等新业务占比低，无明确第二增长曲线
3. **渠道转型滞后**：线上转型慢于美的等同行，增长动能不足

### 三、综合分析

#### （一）行业地位与竞争格局
- 核心数据：白电行业第二，空调行业第一，市占率约 35%，行业寡头竞争格局
- 结论：**龙头地位**

#### （二）业务结构与营收构成
- 核心数据：空调收入占比 > 70%，冰洗等其他业务占比低，海外收入占比约 15%
- 结论：**结构一般**，单一业务依赖度偏高

#### （三）核心竞争力（护城河）
- 核心数据：品牌壁垒（格力品牌溢价强）、渠道壁垒（线下网点密集）、规模成本壁垒（产能规模领先）
- 结论：**护城河深厚**

#### （四）经营成长性与增长动能
- 核心数据：近 3 年营收增速个位数波动，新业务（光伏/储能）收入占比 < 5%，无明确放量
- 结论：**成长乏力**
```
