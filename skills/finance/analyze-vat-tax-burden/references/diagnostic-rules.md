# 税负诊断规则

## 诊断路径

只在数据口径一致且关键勾稽无阻断错误时进行归因：

1. 比较应税销售额、应纳税额和综合申报税负率。
2. 比较一般计税与简易计税销售占比，识别计税方法结构变化。
3. 比较销项税率，识别不同税率销售结构或开票时点影响。
4. 比较进项抵扣贡献率、进项转出和期初/期末留抵，识别采购与抵扣时点影响。
5. 比较减免、加计抵减、预缴和留抵退税，分别说明税负口径与现金流口径影响。
6. 将数字变化与用户提供的业务事实核对，区分已证实原因和待证实原因。

## 表述约束

- 有数据且有业务证据：写“主要受到……影响”。
- 有数据但无业务证据：写“可能与……有关，需核查……”。
- 数据勾稽失败：写“当前差异可能由缺失栏次或口径不一致造成，暂不归因”。
- 不使用固定行业预警阈值，不声称掌握税务机关内部指标。
- 对比外部基准前核验主体、行业、地区、期间、计税方法和分母口径一致性；任一不一致时仅作背景参考。

## 常见信号与核查材料

| 信号 | 可能原因（不是结论） | 优先核查 |
|---|---|---|
| 销项税率上升 | 高税率业务占比提高、价税换算变化、确认时点变化 | 销售明细、税率分类、发票与合同 |
| 进项抵扣贡献下降 | 采购下降、发票未取得、抵扣时点延后、不可抵扣项目增加 | 采购明细、勾选确认、凭证状态 |
| 进项转出增加 | 用途改变、非正常损失、免税项目分摊 | 转出明细及计算底稿 |
| 期末留抵骤变 | 投资采购、季节性备货、销售下降、留抵退税 | 申报表、固定资产和采购台账 |
| 实缴与应纳差异 | 预缴、抵缴、缓缴、欠税或跨期支付 | 完税凭证、申报表、预缴台账 |
| 简易计税占比变化 | 项目结构变化或计税方法选择变化 | 项目清单、合同、适用政策依据 |

## 结论状态

- **数据异常**：关键结构或勾稽存在错误，影响结论。
- **波动需要解释**：指标发生变化，但证据不足或存在多个合理原因。
- **政策适用待核验**：结论依赖税率、资格、政策期限或地方执行口径。
- **暂未发现明显异常**：在已提供数据和既定口径内未发现异常；不得扩大为税务合规保证。
