# 监管处罚判例库（营销违规）

> **用途**：配合 `marketing-compliance-review` Skill 使用。审查营销材料时，可引用本库**同类型判例**，增强审查意见的权威性与说服力（在「审查依据」或「修改建议」中注明处罚文号即可）。
>
> **来源范围（强制）**：全部来源于**国家金融监督管理总局（NFRA，含原银保监会）及派出机构（地方监管局/监管分局）**公开行政处罚。不含证监体系（csrc.gov.cn）、媒体二传、企业自述。
>
> **使用边界**：本文件是处罚案例线索速查版，未随包附全量处罚决定书。写入正式意见书前，须通过处罚文号在监管部门公开渠道核验原文。

## 判例详述

### PC-1 平安人寿西安电销中心·承诺合同外利益及隐瞒重要情况
- **来源**：辽银保监罚决〔2023〕81号，辽宁银保监局，2023-07-19
- **主体 / 渠道**：平安人寿西安电话销售中心 / 电销
- **违规类型**：其他销售误导（含合同外利益）
- **违规事实（监管原文）**：在销售 P0600\* 号保险合同时，销售人员存在宣传内容与保险条款等不一致问题、未向投保人告知附加险保险费等内容；销售人员在销售录音中承诺向投保人赠送礼品。
- **违反 / 处罚**：《保险法》第 116 条；依第 161 条罚款 5 万元。
- **审查映射**：真实准确 + 公平诚信；宣传与条款不一致、承诺礼品（合同外利益）、未告知附加险保费 → 🔴。

### PC-2 众安财险·网销页面欺骗投保人
- **来源**：银保监会总会处罚（2021-07-19）
- **主体 / 渠道**：众安在线财产保险公司 / 自营网络平台 + 第三方平台
- **违规类型**：产品术语混淆与虚假宣传
- **违规事实（监管原文）**：上述自营网络平台宣传销售页面欺骗投保人的行为……上述第三方平台宣传销售页面欺骗投保人的行为。
- **违反 / 处罚**：《保险法》第 116 条；依第 161 条罚款 30 万（自营）+30 万（第三方），责任人员各罚 10 万。
- **审查映射**：真实准确；网销页面禁止欺骗/虚假宣传，自营与第三方渠道同等合规 → 🔴。

### PC-3 平安人寿山西代理人·微信朋友圈虚假宣传夸大收益
- **来源**：晋银保监罚决字〔2023〕5号，山西银保监局，2023-02-10
- **主体 / 渠道**：任娟（平安人寿山西分公司个人代理人）/ 微信朋友圈
- **违规类型**：误导性收益承诺
- **违规事实（监管原文）**：2020年11月至2021年10月期间，任娟在其个人微信朋友圈发布涉及平安财富金瑞年金保险、平安安心百分百两全保险等人身保险产品的虚假宣传信息。上述信息夸大保险责任或保险产品收益，混淆两全保险和意外保险的产品类型，片面表述两全保险产品的实际费率。
- **违反 / 处罚**：《保险法》第 131 条、《人身保险销售误导行为认定指引》第 5、6 条；依第 172 条警告并罚款 5000 元。
- **审查映射**：真实准确 + 公平诚信；夸大收益、混淆险种、片面费率 → 🔴。

### PC-4 平安人寿巴南中心支公司·违规宣传保险产品
- **来源**：巴南金管罚决字〔2025〕3号，国家金融监督管理总局巴南监管分局，2025-10-15
- **主体 / 渠道**：平安人寿巴南中心支公司（责任人牟科霖）/ 未披露
- **违规类型**：产品术语混淆与虚假宣传
- **违规事实（监管原文）**：主要违法违规事实：违规宣传保险产品。
- **违反 / 处罚**：《人身保险销售误导行为认定指引》第 5、6、9、11 条、《保险法》第 116 条；机构罚款 10 万，责任人警告并罚款 1 万。
- **审查映射**：真实准确；宣传内容须真实合规，人身险销售误导认定指引所列情形均禁 → 🔴。

### PC-5 泰康人寿辽阳代理人·未告知死亡给付关键条款
- **来源**：辽阳银保监分局（2021-06-15）
- **主体 / 渠道**：王建（泰康人寿辽阳中心支公司个人代理人）/ 线下
- **违规类型**：信息披露不充分
- **违规事实（监管原文）**：上述有 1 笔保单在投保时，在投保人明确告知不愿意让被保险人知情且被保险人签字均由投保人代签的情况下，个人代理人王建未向投保人告知"以死亡为给付保险金条件的合同，未经被保险人同意并认可保险金额的，合同无效"的有关规定。
- **违反 / 处罚**：《保险法》第 131 条；依第 172 条警告。
- **审查映射**：信息完整 + 真实准确；死亡给付同意规则须明示，代签情形须充分提示 → 🔴。

### PC-6 邮储银行浙江省分行·理财营销适当性缺失及未双录
- **来源**：浙金罚决字〔2024〕22号，国家金融监督管理总局浙江监管局，2024-08-08
- **主体 / 渠道**：邮储银行浙江省分行 / 网点线下推介
- **违规类型**：适当性管理缺失
- **违规事实（监管原文）**：向客户线下推介理财产品时未落实客户适当性管理要求，向客户销售高于其风险承受能力的理财产品；向风评超过一年有效期的客户销售理财产品；营销推介理财产品时存在未"双录"问题；在风险承受能力评估过程中误导投资者，导致风险承受能力评估结果失真。
- **违反 / 处罚**：《银行业监督管理法》第 21、46 条及审慎经营规则；罚款 140 万元。
- **审查映射**：适当性管理 + 风险提示；风险匹配、代销须双录、风评过程不可干预 → 🔴。

### PC-7 邮储银行如东县支行·代销分红险承诺固定收益
- **来源**：银保监罚决字〔2020〕2号，银保监会（总会），2020-03-09
- **主体 / 渠道**：邮储银行如东县支行 / 网点销售（可回溯）
- **违规类型**：误导性收益承诺
- **违规事实（监管原文）**：邮储银行如东县支行销售人员存在对分红型保险产品承诺固定收益的问题……销售人员介绍"这是一款收益保证型产品，2年不退保，且中途不领取，年化综合收益率可达3.2%-3.4%"，但实际该产品的分红是不确定的。
- **违反 / 处罚**：《保险法》第 131 条；依第 165 条罚款 30 万元（总行因可回溯制度执行不到位另罚 50 万）。
- **审查映射**：真实准确 + 风险提示；分红险分红不确定，禁止"保证收益""年化可达"表述 → 🔴。

## 与 Skill 的联动方式

1. **审查时引用**：在 `basis` / `suggestion` 字段中注明「同类违规见 PC-x（处罚文号）」，使意见书有监管判例背书。
2. **回归测试集（ground truth）**：本库 7 例违规原文可直接作 Skill 输入，验证召回率与定级稳定性（建议作为第二轮"困难集"补充）。
3. **补充要求**：新增判例须满足来源合规（金监总局及派出机构官方源），并完整填写六字段（来源/主体/类型/事实/法条/映射）。
