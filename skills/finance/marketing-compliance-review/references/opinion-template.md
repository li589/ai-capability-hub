# 金融营销宣传审查意见书（模板）

> 模板版本 v1.0.1 ｜ 适用：保险 / 银行 / 基金产品营销宣传材料审查
> 生成由 `scripts/generate_review.js` 自动完成，本文件说明结构供审查人填表。
> 生成的意见书末尾自动附带免责声明（AI 辅助、不构成法律 / 监管意见、不构成投资推荐）。

## 结构（5 段 + 封面）

**封面**：送审材料 / 送审类型 / 关联产品 / 送审部门 / 送审人 / 审查时间 / 审查结论 / 风险等级

**一、审查摘要**
- 发现问题：共 N 项（🔴 高风险 X / 🟡 中风险 Y / 🟢 低风险 Z）
- 核心问题一句话

**二、审查发现**（每个问题一段表格）
| 项目 | 内容 |
|---|---|
| 风险等级 | 🔴 高风险 / 🟡 中风险 / 🟢 低风险 |
| 审查维度 | 合法合规 / 真实准确 / 风险提示 / 信息完整 / 公平诚信 / 个人信息保护 |
| 原文摘录 | 「引用具体原文」 |
| 命中规则 | 禁用词库 - 类别；审查要点 - 条目 |
| 审查依据 | 《法律》第 N 条：要点（可多条） |
| 修改建议 | 具体、可执行的修改方案 |

**三、总体评估**
- 维度评分表：合法合规 / 真实准确 / 风险提示 / 信息完整 / 公平诚信 / 个人信息保护（每项 1–5 分）
- 综合意见

**四、整改要求**
| 序号 | 整改事项 | 风险等级 | 整改期限 | 责任人 |
- 高风险：即时 / 2 个工作日；低风险：下次送审前
- 整改后重新送审

**五、审批记录**
| 角色 | 姓名 | 意见 | 日期 |
| 审查人 | （AI 填充） | （见审查发现） | |
| 复核人 | （待填） | | |
| 审批人 | （待填） | | |

## 使用说明

1. 审查人填"审查发现"后，复核人确认；
2. 🔴 高风险问题必须全部整改后才能发布；
3. 终版意见书按你方流程归档（如机构自有知识库 / 合规系统）；本 Skill 不绑定特定知识库。
