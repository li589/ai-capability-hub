# 金融营销宣传审查规则

> 适用：银行 / 保险 / 基金等金融产品的宣传文案、广告海报、销售话术、培训课件、H5、短视频审查。
> 本文件为高频命中项速查版，不是完整法规库。正式结论须核对适用条款原文和当前效力状态。

## 一、审查维度（6 维）

| 维度 | 关注点 |
|---|---|
| 合法合规 | 是否违反广告法、保险法、消保法 |
| 真实准确 | 产品描述是否与条款一致 |
| 风险提示 | 是否充分、显著揭示风险 |
| 信息完整 | 必要信息是否完整披露 |
| 公平诚信 | 是否有误导、强制、歧视性内容 |
| 个人信息保护 | 是否违规收集 / 使用个人信息 |

## 二、禁用词库（命中即标注风险）

### 2.1 绝对化用语（广告法第 9 条禁止）→ 🔴
国家级、世界级、最高级、最佳、最大、第一、唯一、首个、首选、最好、顶级、最低、最、最具、最便宜、最新、最先进、最新技术、填补国内空白、绝对、独家、首家、最全、万能、100%、百分百、彻底、完全、首发、史无前例、前无古人。
> 除非有权威证明，否则一律判定高风险。

### 2.2 收益承诺类（保险营销高频违规）→ 🔴
保本、保底、保收益、保证收益、保证领取、稳赚不赔、零风险、无风险、收益率 XX%、年化收益 XX%、预期收益 XX%、比银行存款高、跑赢通胀、比理财产品好、买了就赚、躺着赚钱、睡后收入、送保障、免费保险。
> 金融产品不可承诺绝对 / 确定收益；不得与存款不当比较。

### 2.3 误导性表述 → 🟡
"确诊即赔"（未说明赔付条件）、"什么都保""全面保障"（过度承诺）、"有病也能买"（未说明健康告知）、"不限病种"、"续保无忧""保证续保"（短期险禁止）、"停售也能续"、"保险公司不会倒闭"、"理赔秒到账""急速理赔"、"最后一天""即将停售""限量抢购"（饥饿营销）。
> 另须注意**保单功能夸大**：用"避债""避税""资产隔离""不被查封""不用偿债""债务隔离""定向传承无争议"等包装保险，属对产品法律功能的误导性表述，命中即标 🟡（若同时结合收益承诺或针对特定人群诱导，升 🔴）。

### 2.4 品牌混用禁止 → 🔴
- 未经授权不得使用"腾讯推荐""微信官方""QQ专属"等集团品牌；
- 不得冒用银行、医院、政府等合作方名义背书；
- 集团内部不同子公司之间不得混用品牌。

### 2.5 特殊人群保护 → 🔴
- 不得诱导老年人购买不适当产品（消保法实施条例第 15 条）；
- 不得向未成年人推销不适当金融产品（消保办法第 34 条）；
- 不得利用弱势群体信息不对称诱导（侵害消费者权益行为处罚办法）。

### 2.6 个人信息保护（个保法）→ 🟡
- 未经同意收集手机号（第 13 条）；
- 默认勾选同意隐私政策（第 14 条）；
- 强制授权与业务无关信息（第 16 条）；
- "一键授权"获取通讯录等过度收集；
- 未提供撤回同意渠道（第 15 条）。

### 2.7 人身保险销售误导专项（依据《人身保险销售误导行为认定指引》保监发〔2012〕87号）

> 对应 87 号指引第六~九条；本地摘录见 `legal-corpus.md`，主映射见 `legal-mapping.md` 第 16 节。

#### 2.7.1 虚假 / 夸大宣传与欺骗（第六(一)(五)(六)）→ 🔴
- 夸大保险产品收益或保险责任范围，或对产品不确定收益作虚假/夸大宣传 → 🔴；
- 以"存款""利息""攒钱"等名义将保险产品宣传为存款/储蓄，混淆产品性质（与 2.10 银保话术混用并列，均 🔴）；
- 对保险公司股东、经营状况、过往经营成果作虚假/夸大宣传（如"央企背景""国资背书""连续盈利"等无据表述）→ 🔴；
- 将本公司产品说成别家、或将别家产品说成自家（冒用/混用机构名义）→ 🔴（与 2.4/2.7 品牌混用衔接）；
- 炒作产品停售或与其他公司产品不当对比 → 🔴（与 2.4 衔接）。

#### 2.7.2 隐瞒重要信息（第七(二)(三)(五)(六)(七)）→ 🔴 / 🟡
- 未说明免除保险人责任条款（免责条款）→ 🔴；
- 未明确说明退保费用扣除及退保后客户可能遭受的损失（退保损失）→ 🔴；
- 万能险/投连险未说明仅收取各项费用、投资账户不承诺保底收益（万能/投连费用与收益不确定性）→ 🔴；
- 未说明交费期间、交费方式及未按期交费的后果（欠费/失效）→ 🟡；
- 未说明健康保险产品等待期（观察期）及免责约定 → 🔴；
- 未说明犹豫期及犹豫期内投保人可无条件解除合同的权力（犹豫期）→ 🟡（87 号列"隐瞒重要情况"；审查中不得仅作 🟢 优化建议，至少 🟡）。

#### 2.7.3 诱导与阻碍行为（第八 / 第九(二)(四)）→ 🔴
- 诱导投保人终止原有保险合同、购买新保单以弥补退保/收益损失（诱导退旧买新）→ 🔴；
- 阻碍投保人履行如实告知义务，或诱导投保人不履行如实告知（阻碍告知）→ 🔴；
- 阻碍投保人接受回访，或诱导投保人不接受回访、不配合回访（阻碍回访/可回溯）→ 🔴。

### 2.10 隐性误导与边界模糊识别 → 🟡 / 🔴 / 🟢

> 本节处理**非教科书式违规**：表述本身不含明确禁用词，但通过语境/排版/选择性披露产生误导效果或合规优化空间。审查时须结合**整体呈现方式**（字号/位置/配色/视觉权重）综合判断。

#### 银保话术混用 → 🔴
- 用"账户""存""利息""存款""攒钱""零钱放进去"等银行术语包装保险产品，使消费者误认为存款/理财 → 🔴；须在显著位置标明"保险产品/非存款/不保本"。
- 用"养老钱""教育金""压岁钱"等生活场景暗示保险为储蓄替代品，未明确区分 → 🟡。

#### 收益前置、风险后置 → 🟡（无风险提示则升 🔴）
- 大字号/高亮展示"历史收益/过往业绩/近一年涨幅 XX%"，而将"不代表未来收益""市场有风险""过往业绩不预示未来表现"以小字/脚注/折叠区呈现 → 🟡。
- 完全未提示任何风险或不确定性 → 升 🔴（归入 2.2 收益承诺类或 2.3 误导性表述）。

#### 选择性披露 → 🟡
- 只展示最优区间/最高档演示利益，不展示保底或不利情形 → 🟡。
- 展示历史最优业绩但不展示同期基准/同类平均 → 🟡。

#### 边界模糊 — 真实优惠 vs 虚假紧迫
- 明确标注真实起止时间、限量数量、有据可查的"限时/特惠/活动价"属合规促销，不应判违规 → **🟢 合规**。
- 无真实依据的"最后一天""即将停售""仅剩 X 份""错过不再有"→ 归入 2.3/2.4 饥饿营销 → 🔴。

#### 边界模糊 — 业绩表述
- "近一年净值增长 XX%""历史业绩优异""连续 N 年正收益"须配套：
  - 显著位置的"过往业绩不代表未来收益"免责声明；
  - 产品类型明确标识（基金/保险/理财）；
  - 若涉及演示利率须标明"假设/示例/不确定"。
  缺上述任一要素 → 🟡；若同时暗示未来可复制该业绩 → 升 🔴。

#### 合规优化建议（🟢 低风险）
- 材料整体合规、仅个别表述可更严谨时，以 🟢 低风险"优化建议"输出：
  - 建议补充风险提示措辞的规范范例；
  - 建议调整字号对比使关键披露更显著；
  - 建议增加"非存款/不保本"等必要声明。
- 🟢 不计入问题项数、不阻断发布，仅供送审方参考提升质量。
- ⚠️ 边界：法定必须披露项（犹豫期、观察期、退保损失、万能/投连费用、免责条款、回访/可回溯）一旦"未披露/隐瞒"，属 87 号指引认定之"隐瞒重要情况"，**不得降级为 🟢 优化建议**，至少 🟡；隐瞒免责条款/退保损失/观察期等核心项直接 🔴。

## 三、逐项审查要点（命中即标注风险）

| 条目 | 审查点 | 风险 |
|---|---|---|
| 2.1 产品信息准确性 | 名称/备案一致、承保方清晰、保障责任与条款一致、免责披露、保费/缴费/时限准确 | 命中即标 |
| 2.2 收益描述合规 | "保本/保收益/稳赚"→🔴；分红/万能未标"不确定"→🔴；演示收益中档≤4.5%→🟡；未提示"过往业绩不代表未来"→🟡；与存款/理财不当比较→🔴 | 见左 |
| 2.3 绝对化用语 | "最/第一/唯一/首家/国家级"→🔴；"万能/100%/全面/彻底"→🟡 | 见左 |
| 2.4 饥饿营销误导 | "限时/最后一天/即将停售/限量"→🔴；"秒杀/抢购"→🟡；保险描述"送/免费/白送"→🔴 | 见左 |
| 2.5 健康告知核保 | "有病也能买/无需体检"→🔴；隐藏健康告知→🔴；简化核保误导→🟡 | 见左 |
| 2.6 续保条款 | 短期健康险承诺"保证续保"→🔴；未标"非保证续保"→🟡 | 见左 |
| 2.7 品牌背书 | 未经授权用"腾讯/微信官方"→🔴；冒用银行/医院/政府→🔴；暗示无实据合作→🔴 | 见左 |
| 2.8 信息披露 | 未显著标产品名/承保方→🟡；无条款查阅方式→🟡；无客服/投诉渠道→🟢；无必要免责→🟡 | 见左 |
| 2.9 特殊人群 | 诱导老年人→🔴；涉未成年人营销（原则禁止）→🔴 | 见左 |
| 2.10 隐性误导与边界模糊 | 银保话术混用/收益前置风险后置/选择性披露/业绩表述缺免责/合规优化→见下 | 见下 |
| 2.7 人身险误导专项（87号指引） | 虚假夸大/退保损失/万能投连费用/观察期/犹豫期/诱导退旧买新/阻碍回访告知→见 2.7 | 见左 |

## 四、风险分级与处置

| 等级 | 标准 | 处置 |
|---|---|---|
| 🔴 高风险 | 违反法律强制性规定 | 必须修改，禁止发布 |
| 🟡 中风险 | 违反监管指引 / 内部规范 | 建议修改 |
| 🟢 低风险 | 表述优化建议 | 可选修改 |

## 五、审查依据索引（精确法条见 `legal-mapping.md`）

> ⚠️ 写「审查依据」时**禁止区间引用**，一律查 `references/legal-mapping.md` 取精确条号。以下为高频法规速记（精确措辞与条号以 legal-mapping.md 为准）：

- 《广告法》第 4、9、28 条 — 虚假/误导宣传、绝对化用语禁止、虚假广告定义
- 《保险法》第 17、116、131 条 — 免责条款提示说明、欺骗投保人/承诺合同外利益等禁止行为
- 《银行保险机构消费者权益保护管理办法》（2022 第 9 号）第 10、12、18、29、34–39、43 条 — 适当性、信息披露、营销信息规范、个保、处罚
- 《保险销售行为管理办法》（2023 第 2 号）第 17、19、21、22、25、26、31 条 — 销售宣传、停售炒作、适当性、新型产品提示、条款提示、可回溯
- 《商业银行代理保险业务监管指引》第 32、34、35、36 条 — 宣传资料、重要事项告知、混淆/收益承诺禁止、送保险/停售诱导禁止
- 《互联网保险业务监管办法》第 11、12、14、15、17 条 — 销售管理、披露、详情页要素、营销宣传、默认勾选禁止
- 《个人信息保护法》第 13–17 条 — 同意前提、明确同意、撤回、禁止强制、告知义务
- 《消费者权益保护法》第 20、26 条 — 真实全面宣传、格式条款显著提示
- 国办发〔2015〕81 号 — 金融消费者八项权利
- 《人身保险销售误导行为认定指引》（保监发〔2012〕87号）第六~九条 — 欺骗/夸大宣传、隐瞒重要情况、阻碍告知与回访、诱导退旧买新等误导行为认定（本地摘录见 `legal-corpus.md`，主映射见 `legal-mapping.md` 第 16 节）
