# 股票财务分析 Skill

## 分析框架

> **核心原则**：所有指标优劣判断必须以行业均值为基准，结合行业特性差异化判断，不依靠单一指标下结论，多维度共振判断。

### 一、盈利能力

#### 1. 关键指标
- 净资产收益率（ROE）
- 毛利率
- 净利率
- 扣非净利润增速

#### 2. 优劣判断标准（以行业均值为基准）

**净资产收益率（ROE）：**
| 等级 | 标准 |
|------|------|
| 优秀 | 高于行业均值 10% 以上 |
| 良好 | 高于行业均值 0~10% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 较弱 | 低于行业均值 10% 以上 |

**毛利率：**
| 等级 | 标准 |
|------|------|
| 优秀 | 高于行业均值 10% 以上 |
| 良好 | 高于行业均值 0~10% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 较弱 | 低于行业均值 10% 以上 |

**净利率：**
| 等级 | 标准 |
|------|------|
| 优秀 | 高于行业均值 10% 以上 |
| 良好 | 高于行业均值 0~10% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 较弱 | 低于行业均值 10% 以上 |

**扣非净利润增速：**
| 等级 | 标准 |
|------|------|
| 优秀 | 增速高于行业均值 15% 以上 |
| 良好 | 增速高于行业均值 0~15% |
| 一般 | 增速与行业均值偏差 ±10% 以内 |
| 较弱 | 增速低于行业均值 10% 以上或负增长 |

#### 3. 行业特殊要点
- **科技 / 创新药 / AI**：允许短期 ROE、净利率偏低，重点看毛利率和扣非增速
- **消费 / 白酒 / 美妆**：毛利率是核心壁垒，高于行业均值 15% 以上为优秀
- **制造 / 周期股**：毛利率普遍偏低，重点看净利率和周期底部盈利状态
- **银行 / 金融**：不看毛利率，重点看 ROE 和净息差

---

### 二、偿债能力

#### 1. 关键指标
- 资产负债率
- 有息负债 / 总资产
- 流动比率

#### 2. 优劣判断标准（以行业均值为基准）

**资产负债率：**
| 等级 | 标准 |
|------|------|
| 优秀 | 低于行业均值 10% 以上 |
| 良好 | 低于行业均值 0~10% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 警惕 | 高于行业均值 10% 以上 |

**有息负债 / 总资产：**
| 等级 | 标准 |
|------|------|
| 优秀 | 低于行业均值 10% 以上 |
| 良好 | 低于行业均值 0~10% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 警惕 | 高于行业均值 10% 以上 |

**流动比率：**
| 等级 | 标准 |
|------|------|
| 优秀 | 高于行业均值 20% 以上 |
| 良好 | 高于行业均值 0~20% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 警惕 | 低于行业均值 10% 以上 |

#### 3. 行业特殊要点
- **银行 / 地产 / 基建**：天然高负债，高于行业均值 15% 以上才需警惕
- **科技 / 消费 / 轻资产**：高于行业均值 10% 以上即视为杠杆偏高
- **重资产 / 周期股**：允许适度高负债，重点看利息保障倍数
- **成长型公司**：短期流动比率偏低可接受，重点看有息负债增速

---

### 三、现金流质量

#### 1. 关键指标
- 经营现金流净额
- 净利润现金含量（经营现金流 / 净利润）
- 自由现金流

#### 2. 优劣判断标准（以行业均值为基准）

**经营现金流净额：**
| 等级 | 标准 |
|------|------|
| 优秀 | 连续 3 年为正，增速高于行业均值 10% 以上 |
| 良好 | 连续 3 年为正，增速与行业均值持平 |
| 一般 | 偶尔为负，整体为正 |
| 较差 | 连续 2 年为负或大幅波动 |

**净利润现金含量：**
| 等级 | 标准 |
|------|------|
| 优秀 | ≥120% 且高于行业均值 20% 以上 |
| 良好 | 100%~120% 且与行业均值持平 |
| 一般 | 70%~100% |
| 较差 | ＜70% 且低于行业均值 10% 以上 |

**自由现金流：**
| 等级 | 标准 |
|------|------|
| 优秀 | 连续 3 年为正，增速高于行业均值 |
| 良好 | 连续 2 年为正，整体平稳 |
| 一般 | 偶尔为负，无持续缺口 |
| 较差 | 连续 2 年为负，存在现金流缺口 |

#### 3. 行业特殊要点
- **软件 / SaaS**：净利润现金含量 ≥150% 为优秀
- **工程 / 建筑 / ToG**：回款慢，连续 3 年为正即视为良好
- **科技 / 研发型**：自由现金流短期为负可接受，重点看经营现金流
- **消费行业**：净利润现金含量 ≥100%、收现比 ≥90% 为良好

---

### 四、运营效率

#### 1. 关键指标
- 总资产周转率
- 应收账款周转天数
- 存货周转天数（存货占比高行业适用）

#### 2. 优劣判断标准（以行业均值为基准）

**总资产周转率：**
| 等级 | 标准 |
|------|------|
| 优秀 | 高于行业均值 10% 以上 |
| 良好 | 高于行业均值 0~10% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 低效 | 低于行业均值 10% 以上 |

**应收账款周转天数：**
| 等级 | 标准 |
|------|------|
| 优秀 | 低于行业均值 10% 以上 |
| 良好 | 低于行业均值 0~10% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 偏慢 | 高于行业均值 10% 以上 |

**存货周转天数：**
| 等级 | 标准 |
|------|------|
| 优秀 | 低于行业均值 10% 以上 |
| 良好 | 低于行业均值 0~10% |
| 一般 | 与行业均值偏差 ±10% 以内 |
| 偏慢 | 高于行业均值 10% 以上 |

#### 3. 行业特殊要点
- **零售 / 快消**：存货周转为核心，低于行业均值 15% 以上为优秀
- **工程 / ToG**：应收账款天数普遍偏长，低于行业均值 10% 以上即为良好
- **轻资产 / 科技**：重点看总资产周转率和应收账款周转
- **重资产 / 制造**：重点看固定资产周转率和总资产周转率

## 分析流程（COT）

### 第一步：数据采集

调用接口获取分析所需的全部数据（参见「数据获取」一节）。返回结果包含以下类别数据：

- **盈利能力分析**：ROE、毛利率、净利率等盈利指标
- **成长能力分析**：扣非净利润增速、营收增速
- **偿债能力分析**：资产负债率、流动比率、速动比率、利息保障倍数
- **营运能力分析**：总资产周转率、应收账款周转天数、存货周转天数
- **综合财务指标**：利润表、资产负债表、现金流量表关键数据（一般企业）
- **银行类利润指标**（银行类公司适用）：净利息收入、中间业务净收入、净利润
- **证券类利润指标**（证券类公司适用）：手续费净收入、投资收益、归母净利润
- **保险类利润指标**（保险类公司适用）：已赚保费、投资收益、归母净利润
- **现金流量表**：经营活动现金流净额、购建长期资产支付的现金
- **收益质量分析**：扣非净利润/净利润、经营活动净收益/利润总额
- **资本结构**：资产负债率、股东权益比率、权益乘数
- **TTM 财务指标**：滚动 12 个月净利润、毛利率、ROE、经营现金流
- **单季财务数据**：单季净利润、营业总收入、毛利率

行业财务均值数据（板块财务，待上线）上线前，暂时基于公司历史数据纵向对比。

### 第二步：指标计算

```python

# 盈利能力（优先用盈利能力接口已算比率；单位为 % 的字段勿再除 100 重复换算）
roe_diluted = profitability.roediluted              # 摊薄净资产收益率(%)
roe_weighted = profitability.roeweighted            # 加权净资产收益率(%)
gross_margin_pct = profitability.sgpmargin          # 销售毛利率(%)
net_margin_pct = profitability.snpmarginconms         # 销售净利率(含少数股东权益)(%)
# 若需从利润表手算：毛利率 ≈ (profit.biztotinco - profit.biztotcost) / profit.biztotinco；净利率 ≈ profit.parenetp / profit.biztotinco（注意 bizinco 与 biztotinco 口径）
deduct_growth = growth.npcut                        # 扣非净利润增长率(%)

# 偿债能力（资产负债率在偿债能力分析接口中无单独字段，取自资本结构或综合财务）
debt_ratio = capital_structure.zcfzl                # 资产负债率(%)；或 finance.assliabrt
current_ratio = solvency.ldbl                       # 流动比率(%)，PrdCwCznlfxVo
# 有息负债占比近似：仅 shorttermborr + longborr；全口径可能含应付债券等，需结合附注
interest_bearing_debt_ratio = (balance.shorttermborr + balance.longborr) / balance.totasset

# 现金流质量
operating_cf = cashflow.mananetr
cash_content = operating_cf / profit.parenetp * 100   # 净利润现金含量(%)
free_cf = operating_cf - cashflow.acquassetcash        # 近似自由现金流：经营现金流净额 - 购建长期资产支付的现金

# 营运效率
total_asset_turnover = operation.taturnrt             # 总资产周转率(次)
accounts_receivable_days = operation.accrecgturndays  # 应收账款周转天数(天)
inventory_days = operation.invturndays                  # 存货周转天数(天)
```

### 第三步：分维度逐项评估

按盈利能力、偿债能力、现金流质量、运营效率依次判断：
- 每项给出：**优秀 / 良好 / 一般 / 较弱 / 警惕 / 低效** 等级
- 标注明显优于或劣于行业的指标
- 识别连续 3 期趋势（上升 / 下降 / 平稳）

### 第四步：行业特性适配

- 按行业属性修正判断（高负债、高投入、周期属性等）
- 区分是公司个体问题，还是行业共性问题

### 第五步：综合研判

- 汇总四大维度结论，给出整体财务健康等级
- 提炼 1~3 个核心亮点、1~3 个核心风险点
- 判断财务是否支撑当前估值与成长逻辑

### 第六步：输出结论

- 给出财务层面的观察建议与风险提示
- 不荐股、不预测涨跌，只做财务健康度判断

## 注意事项

1. **数据时效性**
   - 优先使用最新一期财报数据（年报 > 季报 > 半年报）
   - 必须注明数据截止日期
   - 若数据缺失、异常或未披露，明确标注说明

2. **行业对比**
   - 所有指标优劣判断必须以行业均值为基准
   - 无行业均值时，说明仅做公司自身历史纵向对比
   - 必须结合行业特性差异化判断（重资产 / 轻资产 / 周期 / 金融 / 消费）

3. **客观中立**
   - 既要提炼财务亮点，也要揭示财务风险
   - 不使用绝对化表述（如"业绩一定好转""财务绝对安全"）
   - 高负债、现金流差、盈利下滑等风险放在显著位置提示

4. **数据来源**
   - 关键财务数据标注来源（如"根据 2024 年年报""行业均值"）
   - 不使用未经核实的网传数据、估算数据
   - 同比 / 环比 / 行业对比数据必须真实可追溯

5. **逻辑自洽**
   - 最终财务结论必须与盈利、偿债、现金流、运营四大维度一致
   - 若出现矛盾信号（如盈利高但现金流差、负债高但利息保障强），必须明确说明权衡逻辑
   - 不依靠单一指标下结论，必须多维度共振判断
