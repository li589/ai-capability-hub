# 国自然标书框架与写作指南

本文档详细说明国自然标书的标准框架结构、字数要求、格式规范，并提供各部分的详细写作指导和模板。

---

## 写作总原则

### 核心要求
1. **逻辑清晰**：从问题→方法→预期结果，逻辑链条完整
2. **重点突出**：创新点和关键科学问题必须醒目
3. **论据充分**：文献引用充分、前期基础扎实
4. **表达准确**：科学术语规范，避免模糊表述
5. **格式规范**：符合国自然最新格式要求
6. **语言精练**：遵循 [tone.md](tone.md) 的精简表达原则，避免近义词堆砌、用具体动作替代抽象套话、删除冗余表述

### 写作策略
- **先重后轻**：优先完成立项依据和研究方案（占80%权重）
- **分步完成**：每部分完成后征求用户反馈，再进入下一部分
- **多轮迭代**：初稿→反馈→修改→定稿
- **文献支撑**：所有论断都要有文献或数据支持

---

## 渐进式写作流程

```
（一）立项依据（最重要）
     - 研究意义
     - 国内外研究现状（文献调研）
     - 本研究切入点
    ↓
（二）研究内容（按研究逻辑组织）
     - 研究目标和研究内容
     - 拟解决的关键科学问题
     - 研究方案及可行性分析
     - 特色与创新之处
     - 年度研究计划
    ↓
（三）研究基础（申请人自己完成）
     - AI提供填写指导
     - 检查清单和质量把控
```

每完成一部分，暂停并询问用户：
- "这部分内容是否满意？"
- "需要调整哪些方面？"
- "是否需要补充更多文献支持？"

## 各部分详细要求
** 国自然项目申请书主要包含以下部分（按填写顺序）：

### （一）立项依据

**字数要求：** 3000-4000字，注意标注好引用的参考文献

**核心问题：** 为什么要做这个研究？研究的科学技术价值如何？

**⚠️ 文献调研集成（MCP工具使用）：**

在撰写立项依据全部内容时，应使用已配置的 MCP 工具进行文献调研：

**MCP 调研步骤：**
1. 确定检索关键词（核心关键词、方法关键词、限定词）
2. PubMed 文献检索（主题词、时间范围、文献类型、影响因子）
3. 学术搜索引擎补充检索（Semantic Scholar、Google Scholar等）
4. 文献筛选和整理（精读20-30篇核心文献，分类整理）
5. 文献引用格式化（标准格式：作者. 文章标题. 期刊名. 年份;卷(期):页码.）

**内容结构：**
```
1. 研究意义（800-1000字）
   - 完整连贯的一段，涵盖疾病负担、科学问题、研究价值
   - 使用MCP工具获取最新流行病学数据、治疗现状数据

2. 国内外研究现状及分析（1800-2200字）
   - 围绕研究主题，按照从大到小、逐渐聚焦的逻辑顺序展开
   - 以整段整段的逻辑递进方式呈现
   - 使用MCP工具检索相关研究文献

3. 参考文献（400-600字，含文献列表）
```

#### 1. 研究意义

**写作要点：**
- 开门见山，直接说明研究对象和重要性
- 结合最新数据（发病率、死亡率、经济负担等）
- 指出本研究的重大意义
- **全段保持连贯，不分小节**

**⚠️ 使用MCP工具调研：**
- 检索最新流行病学数据（发病率、死亡率、患病人数）
- 检索最新治疗方案及其疗效数据（缓解率、生存期等）
- 确保所有数据引用最新权威文献

**写作模板：**

```markdown
### 研究意义
参考写法如下（可以根据实际情况更改）：
[疾病/问题]是[领域]的重大挑战，全球约[数字]人群受其影响，我国患病人数达[数字]，对个人健康、家庭生活和社会经济造成巨大负担[引用]。当前[治疗方法]虽有一定进展，但仍存在[不足1、不足2]等问题，患者[预后指标]仍不理想[引用]。[指出？？的发病机制不明了]。深入研究[具体机制]，对于[核心价值，如：发现新靶点/开发新策略/改善预后]具有重要意义。
```
**注意：** 最后一句简洁点明研究意义即可，避免重复表述"科学价值"与"临床意义"、"理论依据"与"治疗策略"等近义词堆砌。

#### 2. 国内外研究现状及分析

**写作核心原则：**
- **从大到小、逐渐聚焦**：围绕研究主题，按照从宏观到微观、从领域到具体问题的逻辑顺序展开
- **整段递进**：减少无关紧要的分段，以完整段落呈现逻辑递进关系
- **层层推进**：每一段承上启下，自然过渡到更聚焦的主题

**⚠️ 使用MCP工具调研文献：**
- 按核心主题、具体科学问题分层检索文献
- 优先检索近3-5年的高水平期刊文献
- 每段需引用5-8篇代表性文献

**写作模板（三层递进结构）：**

> **说明：** 领域宏观背景已在"研究意义"部分阐述，此处直接从核心主题的研究进展开始，避免重复。

```markdown
### 国内外研究现状

**（第一层：核心主题研究进展）**
在[核心主题]方面，近年来研究取得重要进展。[作者]等[引用1]采用[技术]发现[发现1]，提示[机制假说]。[作者]等[引用2]进一步证实[发现2]，揭示了[作用关系]。国内学者在此领域也有重要贡献，[作者]等[引用3]报道了[发现3]，[作者]等[引用4]阐明了[发现4]。这些研究表明[核心主题]在[过程]中具有重要作用，但关于[更深层问题]的认识仍不充分。

**（第二层：聚焦具体科学问题）**
针对[具体科学问题]，目前研究相对有限。已有研究主要集中在[已研究方面]，[作者]等[引用5]发现[发现5]，[作者]等[引用6]报道了[发现6]。然而，关于[未解决问题1]、[未解决问题2]的研究尚不深入，[具体未知]仍不清楚。此外，现有研究多采用[传统方法]，缺乏[新技术/新视角]的系统探索，这制约了对[问题]的深入理解。
⚠️ **[此处可穿插申请人前期发现]** 我们前期研究发现[关键发现]（图X），初步提示[假说]，为本研究提供了重要线索[引用自己文献]。

**（第三层：现有不足与本研究切入点）**
综上所述，尽管[领域]研究取得一定进展，但在[具体方向]仍存在明显空白：（1）[不足1]；（2）[不足2]；（3）[不足3]。
⚠️ **[此处可穿插申请人预实验结果]** 基于上述问题，我们前期开展了预实验，发现[预实验结果]（图X），证实[关键假设]的可行性。
基于上述研究现状和不足，本研究拟采用[方法/技术]，从[角度]切入，系统研究[内容]，阐明[机制]，以期填补[空白]，为[领域]提供新认识和新策略。
```

> **📋 申请人前期成果穿插说明：**
> 
> **需提供的材料：**
> 1. **前期发表论文**：与本课题相关的已发表文献（用于第二层，展示研究积累）
> 2. **预实验数据**：支持科学假说的关键实验结果，附图片及简要说明（用于第二层或第三层）
> 3. **图片格式**：高清图片，标注清晰，统一编号（如"图1 申请人前期研究基础"）
>
> **穿插时机：**
> - **第二层末尾**：引用自己已发表的相关工作，展示研究积累
> - **第三层中间**：展示预实验结果，证明"此路可行"
>
> **⚠️ 若申请人暂无前期成果：**
> - AI将根据研究假说**模拟生成**合理的预实验结果描述
> - 模拟内容将明确标注实验方法、预期结果和结论
> - 申请人可按照模拟内容指导，实际开展预实验获取真实数据
> - 获得真实数据后，替换模拟内容即可

**写作要点：**
- 每段600-800字，保持段落完整性
- 直接从核心主题研究进展开始，不重复"研究意义"中的宏观背景
- 段与段之间用承上启下的过渡句连接
- 文献引用自然融入论述，每段引用5-8篇代表性文献

**文献引用要点：**
- ✅ 引用最新文献（近3-5年为主）
- ✅ 引用高水平期刊（Nature, Science, Cell 及专业顶刊）
- ✅ 引用国内外平衡（体现国际视野和本土研究）
- ✅ 适当引用申请人自己的工作（体现前期基础）
- ❌ 避免过度引用单一课题组
- ❌ 避免引用已过时的研究
- ❌ 避免堆砌文献，每篇引用都要有作用
- ⚠️ **论证服务性原则**：引用每篇文献时，落脚点必须服务于自身研究主题。从"该文献为我的研究提供了什么论据"出发提炼引用价值，而非原样搬运他人的具体靶点或方案。弱化他人研究中与自身研究方向形成竞争的结论（如具体靶点、干预策略），将其价值限定在支持共性认知的层面（如"进一步支持了OXPHOS在耐药中的关键地位"），为自身研究的独特定位留出空间。

#### 3. 参考文献
- 按在正文中出现的顺序编号
- 采用国自然标准引用格式
- 格式示例：[作者]. [文章标题]. *[期刊]*. [年份];[卷]([期]):[页码].
- 引用数量：30-50篇，以近5年为主

**格式要求：**
- 标题：黑体，四号字
- 正文：宋体，五号字
- 行距：固定值20磅
- 参考文献：宋体，小五号字

---

### （二）研究内容

**说明：** 此部分按研究工作自身逻辑撰写，无固定提纲。以下是建议的组织方式和各要素的要求。

**总体要求：** 逻辑清晰，层次分明，全面展现研究设计

#### 建议的写作顺序和要素

##### 1. 研究目标和研究内容

**研究目标（300-500字）**
- 3-5个具体、可量化的目标
- 目标之间有逻辑递进关系
- 每个目标一句话，简洁明确

**写作模板：**

```markdown
## 研究目标

本研究旨在通过[方法/技术]，探讨[科学问题]，具体目标如下：

1. **阐明[对象1]的[特征/机制]**
   采用[技术1]，分析[样本/模型]中[对象1]的[特征]，揭示其[变化规律]。

2. **探讨[对象2]在[过程]中的作用及机制**
   通过[技术2]，研究[对象2]对[过程]的影响，阐明其[作用机制]和[信号通路]。

3. **验证[对象3]作为[应用]的价值**
   利用[模型/样本]，评估[对象3]对[结局]的[作用]，探索其作为[靶点/标志物]的潜力。

4. **建立[方法/模型]，为[应用]提供技术支撑**
   整合[数据/技术]，构建[预测模型/评估体系]，为[临床应用]奠定基础。
```

**研究内容（1200-1800字）**
- 3-4个研究内容，对应研究目标
- **格式要求：融合叙述式**——不要将"研究对象""研究方法""具体内容""预期结果"作为独立标签拎出来，而是将对象、方法、分组、检测指标等自然融合在叙述中
- 每个内容模块先用1-2句话概述研究思路和意义（承接上文逻辑），再按实验任务分小节（(1)(2)(3)...），每小节融合叙述实验目的、对象、分组、方法和检测指标
- 逻辑顺序根据课题需要灵活安排（如从人到动物到细胞，或从表型到机制到应用）

**写作模板：**

```markdown
## 研究内容

### 内容一：[标题]

[1-2句概述本部分的研究背景和意义，说明为什么需要做这部分研究。]
（1）[子任务标题]
[融合叙述研究对象、样本来源/分组标准、实验方法和检测指标。]
（2）[子任务标题]
[融合叙述分析方法和预期关联。]
（3）[子任务标题，如有]
[融合叙述外部验证或补充实验。]

### 内容二：[标题]

[1-2句概述，承接上文逻辑。]
（1）...
（2）...

[同上格式]

### 内容三：[标题]（对应目标3）

[同上结构]

### 内容四：[标题]（对应目标4）

[同上结构]
```

##### 2. 拟解决的关键科学问题（500-700字）

- 2-3个核心问题
- 用疑问句表述
- 高度凝练，体现创新性
- 关键科学问题是标书的核心和灵魂

**写作模板：**

```markdown
## 拟解决的关键科学问题

### 问题1：[核心问题1]？

[背景铺垫，100字]。因此，阐明[问题1]是理解[现象/机制]的关键。

### 问题2：[核心问题2]？

[背景铺垫，100字]。解决此问题将揭示[机制]，为[应用]提供依据。

### 问题3：[核心问题3]？（可选）

[背景铺垫，100字]。回答此问题有助于[意义]。
```

**优秀示例：**

> **问题1：肝癌肿瘤微环境中免疫细胞亚群的异质性特征及其与免疫治疗响应的关系是什么？**
>
> 肿瘤微环境异质性是导致免疫治疗响应差异的重要因素，但HCC中免疫细胞亚群的精细分类、功能状态及其与治疗响应的关联尚不清楚。阐明这一问题是实现患者精准分层的前提。

##### 3. 拟采取的研究方案及可行性分析（3000-4000字）

**3.1 技术路线（500-800字 + 流程图）**

流程图要求：
- 清晰展示研究步骤
- 使用标准流程图符号
- 关键节点明确标注
- 图片清晰，可读性强

**技术路线流程图要素：**
```
研究对象/样本
    ↓
技术方法1 → 获得数据1
    ↓
技术方法2 → 获得数据2
    ↓
技术方法3 → 获得数据3
    ↓
数据整合与分析
    ↓
结果验证
    ↓
机制阐明 / 应用验证
```

**写作模板：**

```markdown
## 技术路线

本研究采用"[策略]"的技术路线，具体如下：

**第一阶段：[阶段名称]**
- 研究对象：[描述]
- 主要技术：[技术1]、[技术2]
- 预期产出：[数据/结果]

**第二阶段：[阶段名称]**
- 基于第一阶段结果，采用[技术3]进行[分析]
- 预期产出：[数据/结果]

**第三阶段：[阶段名称]**
- 整合前两阶段数据，利用[方法]进行[分析]
- 验证关键发现，采用[独立样本/模型]
- 预期产出：[最终结论]

整个技术路线逻辑清晰，层层递进，可行性强。
```

**3.2 研究方法（1500-2000字）**
- 详细描述每个关键技术
- 包含：原理、步骤、参数、质控
- 说明技术的适用性和优势
- **注重前沿技术的引入**：除常规或必须使用的实验技术外，应主动关注并融入该领域近年来涌现的前沿实验技术（如单细胞组学、空间转录组、代谢流示踪、AI辅助结构预测等），以体现研究方案的先进性和竞争力
- 统计分析方法

**写作模板：**

```markdown
## 研究方法

### 方法1：[技术名称]

**原理：** [简述技术原理，50-80字]

**具体步骤：**
1. [步骤1]
2. [步骤2]
3. [步骤3]
4. 数据采集与分析：[分析方法]

**技术优势：** 该技术能够[优势1]，相比传统方法[优势2]，适合本研究的[需求]。

**质量控制：** 设置[对照]，每个样本[重复次数]，确保数据可靠性。

### 方法2：[技术名称]

[同上结构]

### 方法3：[技术名称]

[同上结构]

### 数据统计与分析

**统计方法：** 采用[软件]进行统计分析，连续变量用[检验方法]，分类变量用[检验方法]，P<0.05为差异有统计学意义。

**生物信息学分析：** 采用[工具/平台]进行[分析内容]，参数设置为[具体参数]。
```

**3.3 可行性分析（1000-1500字）**

**写作模板：**

```markdown
## 可行性分析

### 1. 研究基础可行性

**前期工作基础：**
申请人团队前期已在[领域]开展系列研究，发表SCI论文[数量]篇（代表性成果包括[期刊1]、[期刊2]），已建立[技术/模型/数据库]，为本研究奠定了坚实基础。

具体前期工作包括：
- 已完成[前期工作1]，获得[数据/结果]
- 已建立[模型/方法]，验证了[可行性]
- 已积累[样本/资源]，保证本研究的[需求]

### 2. 技术方法可行性

**技术掌握情况：**
申请人团队已熟练掌握本研究所需的关键技术，包括[技术1]、[技术2]、[技术3]。其中：
- [技术1]已成功应用于[前期研究]，获得可靠数据
- [技术2]已建立标准操作流程，重复性好
- [技术3]通过与[合作单位]合作，可顺利完成
```

## 常见问题与解决方案

**Q1：文献引用不够怎么办？**
A：使用 MCP 工具补充检索，扩大检索范围，增加相关主题文献。

**Q2：创新点不够突出怎么办？**
A：明确与现有研究的区别，强调"首次"、"新技术"、"新发现"。

**Q3：可行性论证不足怎么办？**
A：补充前期工作数据，详细说明技术掌握情况，增加合作支撑。

**Q4：字数超标怎么办？**
A：精简文献综述，删除次要细节，保留核心内容。

**Q5：逻辑不够清晰怎么办？**
A：用"因此"、"综上"等连接词，增加小标题，使用编号列表。
