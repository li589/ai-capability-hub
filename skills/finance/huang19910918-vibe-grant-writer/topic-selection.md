# 选题指导模块

本模块帮助申请人在没有明确选题时，基于研究方向和兴趣，生成创新性、可行性强的候选课题，并进行初步评估。

## 选题的重要性

> **选题决定成败！** 一个好的选题是国自然成功的50%。

**好选题的标准：**
- ✅ **创新性**：有新意，不是简单重复
- ✅ **科学性**：科学问题明确，逻辑严密
- ✅ **可行性**：3年内能完成，技术路线清晰
- ✅ **重要性**：有科学意义和应用价值
- ✅ **适配性**：符合申请人的研究基础和条件

## 选题流程

### 步骤 1：收集申请人信息

通过询问，收集以下信息：

1. **研究方向/领域**
   - 专业领域（如肿瘤学、心血管、神经科学等）
   - 具体研究对象（如某种疾病、分子、细胞类型）
   - 感兴趣的研究方向

2. **前期研究基础**
   - 已发表的相关论文
   - 已有的实验数据
   - 掌握的技术方法

3. **申请项目类型**
   - 青年项目（强调创新和培养）
   - 面上项目（要求更深入系统）

4. **个人偏好**
   - 偏向基础研究还是转化研究？
   - 偏向机制探索还是技术开发？
   - 期望的研究深度

### 步骤 2：热点和前沿调研

基于用户提供的研究方向，使用 **WebSearch** 进行调研：

#### 调研内容

1. **最新研究热点**
   - 搜索关键词："[领域] + 2024 + hot topics"
   - 搜索关键词："[领域] + emerging trends"
   - 查看 Nature, Science, Cell 等顶刊近期发表

2. **未解决的科学问题**
   - 搜索关键词："[领域] + unsolved questions"
   - 查阅综述文章（Review）
   - 关注评论性文章（Perspective, Commentary）

3. **新技术新方法**
   - 单细胞测序、空间转录组
   - 类器官、CRISPR筛选
   - AI/机器学习应用
   - 多组学整合分析

4. **国自然资助趋势**
   - 查看往年资助项目
   - 分析高频关键词
   - 了解优先资助方向

#### 调研输出

整理以下信息：
- 3-5个研究热点领域
- 2-3个新兴技术
- 若干未解决的科学问题

### 步骤 3：生成候选选题

基于调研结果和用户信息，生成 **5 个候选选题**。

#### 选题生成策略

**策略 1：热点 + 新技术**
```
示例：利用单细胞测序技术解析[疾病]的[细胞]异质性及其与[表型]的关系
```

**策略 2：经典问题 + 新视角**
```
示例：从[新角度]探讨[经典问题]在[疾病]中的作用机制
```

**策略 3：交叉学科**
```
示例：整合[领域A]和[领域B]，探讨[对象]在[过程]中的作用
```

**策略 4：转化导向**
```
示例：基于[机制研究]，开发[疾病]的[诊断/治疗]新策略
```

**策略 5：前期基础延伸**
```
示例：基于前期发现的[X]，进一步探讨其在[Y]中的功能及机制
```

### 步骤 4：初步评估和比较

生成候选选题后，进行初步评估：

#### 评估维度

1. **创新性评分（0-10分）**
   - 研究角度新颖性
   - 方法技术创新性
   - 预期发现的突破性

2. **可行性评分（0-10分）**
   - 技术方法可实现性
   - 样本/资源可获得性
   - 时间安排合理性
   - 前期基础支撑度

3. **重要性评分（0-10分）**
   - 科学意义
   - 应用/临床价值
   - 学科影响力

4. **竞争力评分（0-10分）**
   - 研究热度（适中为佳）
   - 竞争对手情况
   - 独特优势

### 步骤 5：用户选择和调整

向用户展示候选选题和评估结果，询问：

1. **是否有感兴趣的选题？**
2. **需要调整哪些方面？**
   - 研究深度
   - 技术方法
   - 研究范围
3. **是否需要生成更多候选？**

根据反馈，调整和优化选题。

### 步骤 6：选题细化

用户初步选定选题后，进行细化：

#### 细化内容

1. **完善科学问题**
   - 从2-3个问题细化为更具体的表述
   - 确保问题之间的逻辑关系

2. **明确研究内容**
   - 将研究内容分解为3-4个模块
   - 每个模块的具体任务和方法

3. **设计技术路线**
   - 初步绘制技术路线图
   - 明确各步骤的逻辑关系

4. **识别关键技术**
   - 列出必须掌握的技术
   - 评估技术难度和获取途径

5. **评估资源需求**
   - 样本量估算
   - 主要试剂耗材
   - 仪器设备需求
   - 大致经费预算

## 选题原则和技巧

### 原则 1：避免过热和过冷

**过热领域：**
- ❌ 竞争激烈，容易被抢先
- ❌ 评审标准高
- 示例：某个刚发表在 Nature/Cell 的热点机制

**过冷领域：**
- ❌ 重要性不够
- ❌ 难以引起评审兴趣
- 示例：小众的、应用价值不明确的基础问题

**✅ 适中领域：**
- 有一定研究基础，但未充分解决
- 重要性明确，有上升趋势
- 有独特切入点

### 原则 2：量力而行

**青年项目：**
- ✅ 研究内容不要过多（3-4个即可）
- ✅ 技术难度适中（避免需要大量新技术）
- ✅ 强调创新思路，可行性要足够
- ❌ 不要过度追求"高大全"

**面上项目：**
- ✅ 研究内容可以更系统（4-5个）
- ✅ 可以涉及更多技术方法
- ✅ 强调深度和系统性
- ✅ 需要更强的前期基础

### 原则 3：突出特色

**找到独特角度：**
- 别人研究 A，你研究 A 的亚型
- 别人用方法 X，你用方法 Y（更优）
- 别人研究某疾病，你研究该疾病的特殊阶段

**利用独特资源：**
- 特殊样本（罕见疾病、特殊人群）
- 独家技术（专利方法、新模型）
- 合作优势（与国际团队合作）

### 原则 4：前瞻与务实平衡

**前瞻性：**
- 关注新兴技术（单细胞、空间组学、AI）
- 关注前沿问题（未被充分研究）
- 适当超前布局

**务实性：**
- 确保3年能完成
- 技术可实现
- 结果可预期

## 选题案例分析

### 案例 1：优秀选题

**题目：** 基于单细胞空间转录组解析肝癌免疫微环境异质性及其对免疫治疗响应的预测研究

**为什么优秀：**
1. **热点 + 新技术：** 肿瘤免疫（热点）+ 单细胞空间组学（新技术）
2. **临床转化：** 免疫治疗响应预测有明确应用价值
3. **创新点清晰：** 空间分辨的单细胞分析是创新
4. **可行性强：** 技术已成熟，样本可获得

**评分：**
- 创新性：9/10
- 可行性：8/10
- 重要性：9/10
- 综合：8.7/10

### 案例 2：需改进选题

**题目：** XX蛋白在XX疾病中的表达及其临床意义

**问题：**
1. ❌ 创新性不足（简单的表达研究）
2. ❌ 研究深度不够（未涉及机制）
3. ❌ 临床意义不明确

**改进方向：**
- 增加机制探索（XX蛋白如何发挥作用？）
- 引入新技术（单细胞、组学）
- 明确应用价值（作为治疗靶点？诊断标志物？）

**改进后题目：** XX蛋白调控XX通路影响XX疾病进展的机制及其作为治疗靶点的研究

### 案例 3：过于宏大的选题

**题目：** XX疾病的发病机制和干预策略研究

**问题：**
1. ❌ 范围过大，3-4年难以完成
2. ❌ 科学问题不聚焦
3. ❌ 难以突出创新点

**改进方向：**
- 聚焦某个具体机制环节
- 明确研究对象（某个分子/通路/细胞类型）
- 缩小研究范围

**改进后题目：** XX细胞通过XX机制促进XX疾病进展及其干预研究


## 选题常见问题

**Q1：选题太新，担心评审专家不认可？**
A：适当引用最新文献，强调重要性和前瞻性；同时确保可行性，提供 Plan B。

**Q2：选题与前期工作关系不大，会减分吗？**
A：不一定。关键是论证为什么这个新方向值得做，以及申请人有能力做。可以强调技术方法的延续性。

**Q3：担心被抢先怎么办？**
A：选择细分方向，强调独特角度；加快进度，争取预实验数据；设置备选方案。

**Q4：选题太依赖某个新技术，风险大吗？**
A：需要有技术可行性论证（已有成功案例、合作支持）；设置备选技术路线。

**Q5：如何平衡创新性和可行性？**
A：核心内容（研究内容1-2）可行性要高；拓展内容（研究内容3-4）可以更创新、探索性强。

## 选题检查清单

选题确定前，检查：

- [ ] 科学问题明确、具体、重要
- [ ] 有明显创新点（2-3个）
- [ ] 3年内可完成主要内容
- [ ] 有前期基础或相关经验
- [ ] 技术方法可实现
- [ ] 样本/资源可获得
- [ ] 预期成果合理（3-5篇SCI）
- [ ] 有临床或应用价值
- [ ] 与申请人研究方向匹配
- [ ] 不与在研项目重复
