# 知命 · 八字综合分析（Pay Skill）

## 产品介绍（可对外展示）

**一句话**：基于完整生辰（含阴阳历与性别）生成结构化八字综合解读——格局、五行、事业与情感节奏；古籍理论 + 规则引擎白盒，供文化研究与自我认知参考。

**方法与优势（与站内引擎一致）**：

1. **精确排盘**：公历/农历（阳历/阴历）与闰月、时辰、性别、可选出生地真太阳时；历法不同结构不同，须用户明确。
2. **书房派 + 盲派双轨**：穷通调候、子平格局、神煞纳音、刑冲合会 + 做功、干支效率、串宫压运、十天干取象；张力如实呈现。
3. **经典与案例**：注入 **《穷通宝鉴》《子平真诠》《滴天髓》** 等结构化知识，以及约 **1000 例** 真实案例归纳，减少空话。
4. **算法白盒 + 模型解读**：规则引擎先断局（格局/红灯/特征等可溯源），大模型引用而非推翻；可标注「穷通云 / 子平云 / 盲派云」等依据。
5. **懂当下**：支持婚姻状态等分流，降低一刀切建议。

**定位**：传统文化研究与自我觉察工具。不提供改运开光，不承诺事件预测或投资收益，不替代专业咨询。

**计费与交付**：按次付费（测试价 0.10 元/次，以配置为准）；交付 `content` 报告正文；**不解锁** dongcha.fun 站内权益。

**免责声明**：内容由知命分析引擎生成，仅供文化参考与自我认知，不构成投资、职业、婚姻、健康或法律等重大决策的建议或保证。同一生辰可有多种合理解读，请理性参考。

## 功能与交付

根据用户**完整生辰**生成 **Markdown 综合分析报告**：格局、五行、十神、事业财运、感情倾向与建议等。

## 必填信息（向用户收集齐全后再请求）

| 信息 | 对应字段 | 说明 |
|---|---|---|
| 出生年、月、日 | `birth_year` `birth_month` `birth_day` | 整数 |
| 出生时 | `birth_hour` | **0–23** 整点（24 小时制） |
| 性别 | `gender` | `male`/`female` 或 `男`/`女` |
| **阴阳历** | `is_lunar` 或 `calendar_type` | **必须明确**，见下文 |

可选：`birth_city`、`is_leap_month`（仅农历闰月）、`marital_status`。

本 Skill **不需要** `target_year`（那是流年 Skill 用的）。

**缺任一项必填 → 接口 400，不要猜测补全阴阳历或性别。**

## 阴阳历（极重要）

与站内 `/api/birth-chart/generate` 一致：

| 用户说法 | 传参 | `birth_year/month/day` 填什么 |
|---|---|---|
| 阳历 / 公历 | `is_lunar: false` 或 `calendar_type: "solar"` / `"公历"` / `"阳历"` | **公历**年月日 |
| 阴历 / 农历 | `is_lunar: true` 或 `calendar_type: "lunar"` / `"农历"` / `"阴历"` | **农历**年月日（服务端转公历后排盘） |
| 农历闰月 | `is_lunar: true` 且 `is_leap_month: true` | 农历日期 + 闰月 |

- **阳历与阴历是两套八字结果**，省略历法等于乱排，**禁止默认猜公历**。
- 用户未说明阴阳历 → **先问清楚**再调用本接口。

## 付费前置检查

确认已安装 `weixinpay`；否则提示不支持并终止。

## 工作流程

### 第一步：请求资源

`POST https://bz.dongcha.cyou/api/skillpay/comprehensive`

**公历/阳历示例：**

```json
{
  "birth_year": 1990,
  "birth_month": 5,
  "birth_day": 15,
  "birth_hour": 10,
  "gender": "male",
  "is_lunar": false,
  "birth_city": "北京",
  "marital_status": ""
}
```

**农历/阴历示例：**

```json
{
  "birth_year": 1990,
  "birth_month": 4,
  "birth_day": 21,
  "birth_hour": 14,
  "gender": "female",
  "is_lunar": true,
  "is_leap_month": false,
  "birth_city": "广州"
}
```

### 第二步：处理 402

保存 `WeixinPay-Required` 与 `X-Out-Trade-No`，完成微信支付。

### 第三步：支付成功后必须重试

- Body 与第一步完全一致（含 `is_lunar` / `gender` 等）
- Header：`X-Out-Trade-No`、`WeixinPay-Required`

成功：`code=SUCCESS`，报告在 `content`。生成可能需 30–90 秒。

### 第四步：异常

| 情况 | 处理 |
|---|---|
| 400 | 按 `detail` 补齐字段（常见：未传阴阳历、性别、时辰） |
| NOT_PAID | 稍后原样重试 |
| FULFILL_FAILED | 同一 `out_trade_no` 再试，勿重复支付 |
| already_fulfilled | 返回缓存 |

## 注意事项

1. 阴阳历、性别、年月日时均为必填  
2. 支付后必须带单号重试  
3. 付费不解锁网站账号权益  
4. 输出仅供参考，不作命运承诺
