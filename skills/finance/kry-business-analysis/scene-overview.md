# 经营分析场景总览

## 场景体系

本技能预制 12 个经营分析场景，按组织层级覆盖总部、区域、门店三级需求。每个场景包含完整的数据计划、报告模板和 ECharts 图表配置，AI 根据用户意图自动匹配并生成富数据报告。

## 组织层级

| 层级 | 角色              | 数据视角              | 可用场景           |
| ---- | ----------------- | --------------------- | ------------------ |
| 总部 | 品牌老板/CEO/总监 | 全品牌汇总 + 门店排行 | S1~S4, S7, S10~S12 |
| 区域 | 区域经理/督导     | 辖区门店对比          | S4~S5              |
| 门店 | 店长/值班经理     | 本店深度分析          | S6~S12             |

## 使用方式

### 自动触发
用户表达意图时，AI 自动匹配最佳场景：

```
用户："帮我看看昨天的经营数据"        → S1 经营日报
用户："门店排行，按营业额"            → S4 门店排行榜
用户："分析一下这周菜品表现"          → S7 菜品经营分析
用户："后厨效率怎么样"               → S9 运营效率分析
用户："美团外卖佣金收了多少"          → S11 外卖/团购分析
```

### 主动指定
用户可直接指定场景编号或名称：

```
用户："生成S2经营周报"
用户："出一份月度经营总结"
用户："给我生成门店排行报告"
```

### 自定义周期
用户可指定任意时间范围：

```
用户："6月1号到15号的菜品分析"
用户："上个月的财务对账"
用户："最近30天门店排行"
```

## 报告输出格式

每个场景生成的报告包含：

1. **HTML 富报告**（主输出）
   - ECharts 可交互图表
   - 响应式布局，适配不同屏幕
   - 统一品牌风格（渐变头部、白底卡片）

2. **Markdown 分析摘要**（辅助输出）
   - 核心指标一览
   - AI 洞察与建议
   - 异动预警清单
