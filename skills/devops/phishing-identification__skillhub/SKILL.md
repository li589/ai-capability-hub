# 钓鱼识别训练

Use when 用户需要学习识别钓鱼邮件和短信，了解常见钓鱼特征、链接检测和举报渠道。

## 描述

本 Skill 提供钓鱼攻击的识别和防范训练，涵盖钓鱼邮件/短信/网站的典型特征识别、可疑链接的安全检测方法、常见钓鱼场景模拟训练、被钓鱼后的补救措施，帮助用户建立防钓鱼的安全意识和识别能力。

## 重要限制

- 钓鱼手法持续演进，不可能覆盖所有新型攻击
- AI生成的钓鱼内容越来越逼真
- 识别能力需要持续训练维持
- 不提供钓鱼攻击的制作方法
- 企业级钓鱼防护需要专业安全团队

## 能力

- 分析邮件/短信的钓鱼特征
- 检测可疑链接的真伪
- 模拟常见钓鱼场景进行训练
- 指导被钓鱼后的紧急补救
- 设置邮件安全过滤规则
- 建立日常防钓鱼习惯

## 执行步骤

1. **特征识别**：检查发件人/内容/链接/附件的异常
2. **链接检测**：不点击，先验证URL真伪
3. **信息核实**：通过官方渠道验证消息真实性
4. **安全操作**：不在可疑页面输入任何信息
5. **举报处理**：向平台/机构举报钓鱼内容
6. **补救措施**：如已中招立即修改密码等

## 输出原则

- "不确定就不点击"是黄金法则
- 域名是最关键的识别点
- 任何要求提供密码/验证码的消息都可疑
- 通过官方APP/官网进入而非点击链接
- 紧迫感+威胁是钓鱼的核心特征

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| 用户已点击了链接 | 未输入信息则关闭页面、清除缓存；已输入则立即改密码 |
| 用户不确定是否钓鱼 | 不点击链接，通过官方渠道直接查询 |
| 高仿真钓鱼难以辨别 | 教授域名精确核对方法 |
| 企业邮件被钓鱼 | 立即报告IT部门 |

## FAQ

**Q: 如何快速判断链接是否安全？**
A: ①不点击，先看URL（悬停/长按）；②检查域名拼写（baiducom.xx≠baidu.com）；③看协议（http不如https但https也不保证安全）；④用VirusTotal等工具检测URL；⑤最安全：不点链接，直接打开官方APP操作。

**Q: 最常见的钓鱼场景有哪些？**
A: 冒充银行（"您的账户异常"）、冒充快递（"包裹派送失败"）、冒充平台（"账号即将封禁"）、冒充领导/同事（"帮我转个账"）、假中奖/红包、冒充客服退款。共性：都要你点链接或提供信息。

**Q: 点了钓鱼链接但没输入信息有事吗？**
A: 风险较低但不是零。仅点击不输入信息的情况下：关闭页面、清除浏览器缓存、运行杀毒软件扫描。如果链接下载了文件不要打开，直接删除。

**Q: 如何举报钓鱼？**
A: ①邮箱内标记为"钓鱼邮件"；②短信转发至12321举报；③向被冒充的官方机构报告；④向工信部/网信办举报；⑤在反诈中心APP举报。

## 最佳实践

- 永远不点邮件/短信中的链接，直接去官方APP
- 检查发件人完整邮箱地址（不仅看显示名）
- 安装浏览器反钓鱼插件
- 重要操作只通过官方APP进行
- 定期进行钓鱼识别自测训练
- 对任何要求提供密码/验证码的消息保持怀疑
- 企业邮件设置DMARC/SPF验证

## 不适用场景与常见误用

### 不适用场景
- 企业安全意识培训方案设计
- 钓鱼攻击的技术分析和溯源
- 安全产品（反钓鱼系统）开发
- 渗透测试中的社会工程学

### 常见误用
- 看到"官方"字样就信以为真
- 认为熟人发来的就安全（账号可能被盗）
- 以为有https就是安全网站
- 只关注内容不检查发件人和链接

## 安全与隐私

- 已被钓鱼请立即修改密码并联系平台
- 不收集用户任何登录信息
- 不提供钓鱼攻击的制作方法
- 建议定期更新反钓鱼安全知识
- 企业内被钓鱼请立即报告IT安全团队
