# 情绪管理困难学生支持策略卡

## 行为画像
- 容易因小事爆发（哭闹 / 顶撞 / 摔东西）。
- 也可能表现为长期低落、回避、易哭。
- 课堂学习被情绪反复打断。
- **重要**：以上为教育层面观察，长期 / 严重情况需专业心理评估。

## 课堂 6 招
1. **情绪温度计**：桌角放红 / 黄 / 绿三色卡，让他"自报"情绪。
2. **暂停卡**：约定"安全角"或一张可起身离座 5 min 的卡片。
3. **稳定座位伙伴**：选择性格温和的同学。
4. **降低公开压力**：少叫他公开发言，多用纸条问答。
5. **结构化预告**：换课、换教师、换流程提前告知。
6. **赞赏具体行为**：表扬他"今天用安全角而不是哭"，而非"你表现好"。

## 作业 4 调
- 灵活时长（情绪不好时延后但不取消）。
- 关注进步而非完美。
- 不在情绪激动时催促 / 训斥。
- 提供"备份任务"（如不愿写作文可先画思维导图）。

## 危机预案
- 学生出现自伤、伤人、躯体化症状，**立即**按学校危机流程通知班主任 / 心理老师 / 家长。
- 不在公开场合处理情绪危机。
- 与心理老师建立"绿色通道"。

## 红线
- 不诊断（"她有抑郁") / 不评判（"她太娇气"）。
- 不在同伴面前讨论她的情绪问题。
- 不强行让其表达 / 平静。
- 不威胁惩罚（"再哭就……"）。
