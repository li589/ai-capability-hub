# 默认审查策略

> skill-vetter-optimized 的默认行为规则

---

## 触发规则

### 必须审查的情况

| 情况 | 是否隔离 | 说明 |
|------|---------|------|
| 首次安装来源不明的 skill | ✅ 必须 | ClawHub/GitHub/其他第三方 |
| 任何要求凭证/密钥的 skill | ✅ 必须 | 直接拒绝，无需深入分析 |
| 任何 eval/exec 动态代码执行 | ✅ 必须 | 除非能证明是工具自身用途 |
| 任何 curl\|bash / wget\|sh | ✅ 必须 | 直接拒绝 |
| 任何修改系统文件的 skill | ✅ 必须 | 除非明确管理员授权 |
| 从非官方渠道安装 | ✅ 必须 | 官方 = SkillHub openclaw-skill-* |
| 星标 < 100 的 GitHub skill | ⚠️ 建议 | 低社区验证 |

### 可以跳过审查的情况

| 情况 | 条件 |
|------|------|
| 官方 SkillHub 技能 | openclaw-skill-* 前缀，1000+ 星 |
| 已知可信作者的常规更新 | 版本变化极小 |
| 用户明确要求快速审查 | 仅限 LOW 风险场景 |
| 纯文档类 skill | 仅 .md 文件，无代码 |

---

## 裁决规则

| 风险等级 | 裁决 | 动作 |
|----------|------|------|
| 🟢 LOW | ✅ 可安全安装 | 直接执行 |
| 🟡 MEDIUM | ⚠️ 谨慎安装 | 通知用户，确认后执行 |
| 🔴 HIGH | ⚠️ 需人工审查 | 输出完整报告，明确要求用户批准 |
| ⛔ EXTREME | ❌ 拒绝安装 | 告知用户拒绝原因，拒绝执行 |

---

## 隔离规则

| 情况 | 是否隔离 |
|------|---------|
| HIGH 及以上红标 | ✅ 必须隔离 |
| 首次审查陌生 skill | ✅ 必须隔离 |
| 已知官方 skill 常规复审 | ⚠️ 可不隔离 |
| 用户要求快速审查 | ⚠️ 可简化 |

---

## Docker 沙箱规则

- 必须使用 `--rm`（容器退出即销毁）
- skill 目录必须映射为只读（`:ro`）
- 优先使用本地 `skill_vet.py`，避免容器内网络获取
- 容器内无网络（Alpine 镜像默认无网络）

---

## 记录规则

- 每次审查完成后，结果追加到 `records/vetting-log.md`
- 拒绝安装的记录用红色标注（❌）
- 谨慎安装的记录用黄色标注（⚠️）
