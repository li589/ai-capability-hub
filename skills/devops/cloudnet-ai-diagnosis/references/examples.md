## 🏪 案例：连锁门店WiFi故障快速排查

### 场景背景

| 项目       | 详情                 |
| -------- | ------------------ |
| **业务场景** | 某知名咖啡连锁品牌，全国500+门店 |
| **角色**   | 区域IT运维工程师 - 张工     |
| **痛点**   | 门店WiFi问题频发，人工排查效率低 |

### 问题描述

**用户反馈**：
> "北京朝阳区某门店顾客反馈店内WiFi网速很慢，部分设备无法连接，影响顾客体验和移动支付使用。"

### 解决方案

#### 输入样本（用户在 WorkBuddy 中输入）：

```
北京朝阳区的星巴克朝阳门店 iPad上网很慢，MAC地址是 AA-BB-DD-EE-FF-11
```

#### 执行过程：

1. **信息提取** ✅
   - 场所名：北京朝阳区的星巴克朝阳门店
   - 设备信息：iPad（MAC: AA-BB-DD-EE-FF-11）
   - 故障时间：当前时间（2026-06-11 15:30）

2. **场所查询** ✅
   ```
   调用: cloudnet-mcp.getallshopsanddevofuser
   结果: 找到场所 ID = shop_20260611001
   ```

3. **执行诊断** ✅
   ```bash
   mcporter call cloudnet-mcp.executeStaDiagnosis \
     clientInfo:"AA-BB-DD-EE-FF-11" \
     shopId:"shop_20260611001" \
     faultTime:"2026-06-11 15:30:00" \
     timezone:"Asia/Shanghai"
   ```

4. **AI 分析输出** ✅ （见下方结果）

---

### 📊 输出结果

#### **诊断结果摘要**
> ⚠️ **检测到异常**：该iPad设备当前无线连接质量较差，综合评分 **62/100**（正常应≥85）。主要原因为信道干扰严重 + AP负载过高。

#### **问题根因分析**

##### 🔴 核心问题1：信道干扰严重（影响度：高）
- **当前信道**：CH6 (2.4GHz)
- **信道利用率**：**89%** ⚠️（阈值：<70%）
- **同频AP数量**：8个邻居AP在同一信道
- **干扰底噪**：-78dBm（正常值：-95dBm以下）

**技术解读**：  
该门店位于商业密集区，周边2.4GHz频段拥堵严重。您的AP与周边8个无线网络竞争同一信道资源，导致：
- 数据重传率升高至 **28%**（正常<10%）
- 平均延迟增加至 **120ms**（正常<50ms）
- 有效吞吐量下降至 **8Mbps**（理论值54Mbps）

##### 🟠 次要问题2：接入用户数过多（影响度：中）
- **当前在线终端数**：**47台** ⚠️（建议上限：30台）
- **AP CPU占用率**：78%
- **内存使用率**：82%

**技术解读**：  
午间高峰时段，单AP承载过多并发连接，造成资源争抢和调度延迟。

##### 🟡 潜在问题3：信号强度不足（影响度：低）
- **RSSI信号强度**：-68dBm（边缘临界值）
- **设备位置**：距离AP约25米，隔2面墙

---

#### 💡 建议解决措施（按优先级排序）

##### **🚨 立即执行（预计5分钟见效）**

**方案A：调整信道至 CH11 或 CH1**
```bash
# 登录Cloudnet管理平台执行
# 推荐操作路径：无线配置 → 射频设置 → 手动信道选择
# 选择 CH11 或 CH1（需先扫描确认哪个信道更空闲）
```
**预期效果**：
- 信道利用率降至 <40%
- 重传率降至 <12%
- 吞吐量提升至 **25Mbps+**

**方案B：启用负载均衡**
```bash
# 配置建议：
- 开启 "基于用户数的负载均衡"
- 单AP最大接入数设为 25 台
- 超出用户自动引导至相邻AP
```

##### **⏰ 本周内优化（预计30分钟）**

**方案C：调整发射功率**
- 当前功率：100%
- 建议调整为：**70-80%**
- 目的：减少对周边网络的干扰，改善信噪比

**方案D：部署5GHz优先策略**
```bash
# 在AC上启用Band Steering功能
# 引导双频终端优先连接5GHz频段
# 预期效果：2.4GHz压力降低60%+
```

##### **📅 下月规划（长期方案）**

**方案E：增加AP覆盖密度**
- 当前：1台AP覆盖整个门店（约200㎡）
- 建议：增加1-2台AP，实现无缝漫游
- 预算估算：约 ¥3000-5000/台
