# 课堂可视化辅助工具示例

## 1. 任务卡 / 任务清单
桌面贴一张：
```
今天我要：
[ ] 1. 读完第 3 段
[ ] 2. 完成 5 道选择
[ ] 3. 收作业
```
做完一项划掉一项，完成感肉眼可见。

## 2. 情绪温度计
桌角小卡：
- 绿 我状态好
- 黄 我有点不舒服
- 红 我需要暂停一下
学生不必说话，翻牌即可。

## 3. 安全角 / 暂停卡
教室一角放：地毯 + 1-2 本绘本 + 一张"我休息 5 分钟就回来"卡。
约定：举牌即可起身，不需说话；归位后老师不追问。

## 4. 时间可视化
- 番茄计时器：低段用沙漏 / 视觉计时器。
- 任务条：把 1 节课画成 9 段 ×5 min 的彩条。

## 5. 关键词预告板
本节课关键词提前写在黑板侧面。

## 6. 笔记支架
低段 / 弱基础学生用"填空式笔记"。

## 7. 信号手势
约定：摸鼻子 = 注意力回收；拍两下桌 = 全班安静；拇指朝上/朝中/朝下 = 自评听懂程度。

## 8. 学习伙伴卡
固定的"成长伙伴"配对，可视化贴在课表旁。

## 9. 进步存折
A6 小本，每周教师写一句进步事实 + 学生自评一句。

## 10. 沟通暗号
和情绪困难学生之间约定一个"我撑不住了"的暗号——保护他不需要在同伴面前求助。
