# 语言能力较弱学生支持策略卡

## 行为画像
- 听力 / 表达 / 阅读 / 写作中至少一项明显弱于同龄人。
- 课堂上常需更多反应时间。
- 普通话 / 汉字基础与班级有差距。
- 可能为多语家庭、随迁子女、少数民族学生、跨地区跨方言学生。

## 课堂 6 招
1. **关键词双语 / 图示**：黑板写出关键词，配图。
2. **语速放慢、停顿明显**。
3. **重要指令 2 遍**（一次口头 + 一次黑板字）。
4. **思考时间**：提问后给至少 5-10 秒。
5. **多模态作答**：可画图、可口述、可录音。
6. **同伴翻译**（在尊重的前提下，让懂双语的同学帮忙）。

## 作业 4 调
- 朗读音频版课文（家庭可重复听）。
- 书写量适度减少，重视"理解"先行。
- 写作前给 1-2 个范例支架。
- 阶段性目标"先理解、再表达"。

## 家校 4 个建议
- 家庭语言不必强制改为普通话——多语家庭对孩子语言发展是优势。
- 共读图画书 / 短文（家长读、孩子复述）。
- 鼓励孩子用熟悉语言先表达，再过渡到普通话。
- 与教师共享学生在家中的语言习惯。

## 红线
- 不公开评价"普通话不标准"。
- 不让该生在朗读 / 听写环节"垫底"被全班听见。
- 不歧视家庭语言 / 方言 / 民族文化。
- 与家长沟通时，必要时提供翻译或多语支持。
