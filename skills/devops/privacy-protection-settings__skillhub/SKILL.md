# 隐私保护设置

Use when 用户需要减少手机和APP的隐私泄露，了解各平台隐私设置和最小授权原则。

## 描述

本 Skill 提供个人隐私保护的设置指导，涵盖手机系统级隐私设置、常用APP的隐私权限管理、最小授权原则的实践方法、各社交平台的隐私加固、隐私泄露的检测和补救，帮助用户在享受数字服务的同时最大限度保护个人隐私。

## 重要限制

- 不同手机系统和APP版本设置路径可能不同
- 隐私保护和功能便利性需要平衡
- 无法完全消除数字足迹
- 不涉及企业级数据保护方案
- 各平台隐私政策可能随时变更

## 能力

- 指导手机系统级隐私设置
- 审查和优化APP权限配置
- 说明各社交平台的隐私设置方法

- 指导浏览器和搜索的隐私保护

## 执行步骤

1. **权限审查**：检查所有APP的权限授予情况
2. **最小授权**：关闭非必要的权限（定位/通讯录/麦克风等）
3. **系统设置**：调整手机系统级隐私选项
4. **社交加固**：加固社交媒体的隐私设置
5. **浏览安全**：设置浏览器和搜索隐私保护
6. **定期审查**：建立定期检查和维护机制

## 输出原则

- 最小授权：不需要的权限一律不给
- "使用时授权"优于"始终允许"
- 社交平台默认设置通常是最不隐私的
- 平衡便利性和安全性
- 定期审查比一次性设置更重要

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| 关闭权限后APP不能用 | 评估是否真正需要该APP |
| 不知道哪些权限可以关 | 提供权限-功能对应关系 |
| 发现信息已泄露 | 指导补救措施 |
| 用户觉得太麻烦 | 提供最关键的3-5项设置 |

## FAQ

**Q: 哪些权限最应该限制？**
A: 优先限制：①定位（改为"使用时"或关闭）；②通讯录（非通讯APP不需要）；③麦克风和摄像头（可能被窃听窃拍）；④短信（可能读取验证码）。这四项是隐私泄露最高风险的权限。

**Q: APP说不给权限就不能用？**
A: 多数情况是"要挟"。根据规定，APP不得以不同意非必要权限为由拒绝提供核心服务。如外卖APP要通讯录权限就不合理。可投诉到工信部/网信办。

**Q: 如何检测隐私是否已泄露？**
A: ①收到精准推销电话/短信；②注册过的平台发来垃圾邮件；③在haveibeenpwned.com检查邮箱是否在数据泄露中；④使用隐私检测工具扫描手机。

**Q: 关闭广告追踪有用吗？**
A: 有一定效果。iOS设置"限制广告追踪"，Android关闭"个性化广告"。但不能完全阻止追踪（还有指纹追踪等技术）。建议同时使用隐私浏览器和广告拦截插件。

## 最佳实践

- 新装APP时仔细审查权限请求
- 定位权限设为"使用时"而非"始终"
- 不常用的APP及时卸载
- 关闭个性化广告推荐
- 使用浏览器无痕模式浏览敏感内容
- 注册不重要的服务时使用专用邮箱
- 定期清理APP缓存和浏览历史

## 不适用场景与常见误用

### 不适用场景
- 企业数据保护和合规（GDPR等）
- 隐私保护技术研发
- APP隐私合规审计
- 政府监控和取证技术

### 常见误用
- 给所有APP开放所有权限图省事
- 只设置一次不持续维护
- 认为"我没什么隐私"而不在意
- 过度限制导致正常功能无法使用

## 安全与隐私

- 隐私设置建议来自公开的最佳实践
- 不收集用户的设备和APP信息
- 不针对具体APP做商业推荐
- 隐私保护是持续过程需定期维护
- 发现严重隐私侵权可向网信办投诉
