# 相关技能与组合用法

本技能与 4 个姊妹技能构成「私域用户运营」触达链路：本技能做**触达动作落版**（具体怎么发），姊妹技能分别产**分层/标签/生命周期/承接**（对谁做、怎么进来）。四者互补，可独立用、也可串成完整 SOP。

## 边界划分

| 维度 | 本技能（触达编排） | 分层触达策略 | 标签体系构建 | 生命周期旅程 | 公私域联动方案生成 |
|---|---|---|---|---|---|
| 回答的问题 | 对谁走哪个触点+配什么话术+什么时候发+会不会被折叠封号 | 谁是谁值多少+怎么按价值分配触达资源 | 怎么搭不腐烂的标签资产底座 | 用户走到哪+下一动作往哪引 | 用户从哪来+沉淀到哪+怎么持续触达 |
| 产出 | 触达编排四件套(触点编排+话术+频次+合规校验) | RFM分层表+差异化触达策略表 | 标签体系四件套(架构+字典+治理+路线) | 阶段分层表+旅程图+阶段运营策略表 | 触点地图+承接链路图+渠道优先级+承接期SOP |
| 分层的角色 | 纯消费引用(有则用,无则兜底) | 分层是主体(RFM算分) | 标签是治理对象+架构主体 | 阶段是主体(时间轴) | 不做分层(做承接) |
| 频次/合规 | 主体(感知企微官方规则★) | 触达频次按LTV段位量化 | 治理SOP含刷新节奏 | 阶段转换条件 | 承接期SOP状态化 |
| 独立可用 | 是 | 是 | 是 | 是 | 是 |

## 原语共享

- **分层口径**：本技能消费的 RFM/生命周期阶段来源自「分层触达策略」「生命周期旅程」技能，引用不重算。
- **3档价值×5阶段生命周期兜底框架**：本技能内置兜底（高/中/低×引入→成长→成熟→休眠→流失），粗糙版，正式分层转对应姊妹技能。
- **企微触点枚举**：本技能的1v1/朋友圈/群发/社群触点与「公私域联动方案生成」触点地图一致，承接技能做"进来"，本技能做"进来后的触达动落版"。

## 怎么组合

1. **先分层、再触达编排（推荐完整 SOP）**：
   - 用「私域用户分层触达策略」把用户按 RFM 分价值分层（产「对谁做」分层表）
   - （可选）用「生命周期旅程」叠生命周期阶段，交叉成阶段×价值矩阵
   - 用本技能：按分层结果编排触达动作四件套（对谁走哪个触点+话术+频次+合规）

2. **只做触达编排（用户已有分层）**：
   - 直接用本技能，消费已有分层数据产出四件套
   - 标签体系/分层本身是上游，按需后续接

3. **承接后触达（新客进来马上触达）**：
   - 用「公私域联动方案生成」跑承接期 SOP（新客7天+首购+跨触点编排）
   - 成熟期/沉睡召回的触达动作落版用本技能（承接期 SOP 止于首购后复购预埋，之后用本技能）

4. **标签乱要治理后再触达**：
   - 用「私域标签体系搭建」盘点治理标签字典
   - 治理后用本技能，按规整标签做精准触达编排

## 一句话区分用户该用哪个

- 用户说「帮我把用户按价值分层/做差异化触达策略」→ `私域用户分层触达策略`（先分层）
- 用户说「帮我搞清用户走到生命周期的哪阶段/防流失前置」→ `用户生命周期旅程`
- 用户说「帮我搭私域标签体系/治理乱标签/做标签字典」→ `私域标签体系搭建`
- 用户说「帮我梳理公私域触点/画承接链路/做新客承接SOP」→ `公私域联动方案生成`
- 用户说「我已有分层客户，帮我对哪拨人走哪个触点配什么话术什么时候发会不会被折叠」→ **本技能（触达编排）**
- 用户说「私域整体做一版」→ 串联：分层（分层触达）→ 阶段（生命周期）→ 标签底座（标签体系）→ 承接（触点承接）→ 触达动作落版（本技能）
