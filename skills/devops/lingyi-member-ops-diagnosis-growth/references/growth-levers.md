# 会员运营诊断与增长建议 · 存量增长杠杆库

> 适用 skill：`lingyi-member-ops-diagnosis-growth`
> 作用：为"增长建议"段提供**可操作的存量增长杠杆库**和**诊断异常 → 增长动作映射表**。**增长段必读本文件**，保证增长杠杆由诊断结论推导而来、含五要素，不写成口号。
> 边界声明：本文件的"增长"仅指**存量会员增长**（复购 / 留存 / 生命周期跃迁 / 沉睡召回），**不含拉新获客**（与 industry-reference-map §5.3"不要只追求拉新"立场一致）。

## 0. 怎么用这份文件

1. 先完成诊断（八维评分 + 六类根因 + P0/P1/P2）。
2. 从"诊断异常 → 增长动作映射表"（§2）按诊断出的根因 / 低分维度找到对应的增长杠杆类别。
3. 从"八大存量增长杠杆库"（§1）选取具体杠杆，按五要素填充：`杠杆 / 对应人群 / 预期方向 / 验证方式 / 依赖条件`。
4. 预期值给**方向性区间**（参考 §3 口径与基准），不给确定数字；实际提升需结合真实数据与执行验证。
5. 每条杠杆必须能追溯到某个诊断异常（异常→动作），不能脱离诊断空给。

## 1. 八大存量增长杠杆库

| 杠杆 | 解决什么诊断问题 | 典型适用人群 | 验证方式举例 |
|---|---|---|---|
| **分层精准运营** | 无分层、同质化运营、触达低效 | 全量会员分新客/活跃/潜力/高价值/沉睡/流失 | 分层前后 A/B 对比触达转化率 |
| **权益体系优化** | 兑换率低、权益感知弱、装饰性机制 | 活跃+潜力会员 | 兑换率/券核销率前后对比 |
| **复购提升** | 无复购触发、复购率不升 | 首购后会员 | 小人群 A/B 测试复购触发 |
| **召回与防流失** | 沉睡率高、流失未预警 | 沉睡会员 | 召回率 A/B 对比 |
| **生命周期跃迁** | 阶段单一、用户不上行迁移 | 潜力→高价值会员 | 阶段跃迁率追踪 |
| **触点链路梳理** | 触点各自为战、身份未打通、行为断层 | 全量会员 | 跨触点转化漏斗追踪 |
| **内容活动体系化** | 仅节日促销、日常无节奏 | 全量会员 | 内容贡献活跃率追踪 |
| **数据基础建设** | 无看板、口径不一、无法持续优化 | 全量会员（底座） | 看板驱动决策次数 |

### 1.1 分层精准运营
把同质化全量运营改成差异化触达。先建分层（RFM 或生命周期：新客/活跃/潜力/高价值/沉睡/流失），口径固定并动态更新，各层用不同内容/权益/触达。
- **预期方向**：触达转化率方向性提升、活跃率方向性回升。
- **依赖**：会员行为/交易/活跃数据可导出；分层口径跨部门对齐。

### 1.2 权益体系优化
积分从"兑换小礼品"升级为绑定复购/服务/身份的成长机制；权益审计（保留/替换/升级）；会员日机制；测权益成本 ROI。
- **预期方向**：兑换率/券核销率方向性提升、权益成本 ROI 改善。
- **依赖**：积分获取/消耗/兑换数据、权益成本口径。

### 1.3 复购提升
按人群/周期设计复购触发条件（首购后 N 天、品类周期）、加购升级机制、转化漏斗优化。
- **预期方向**：复购率/复购频次方向性提升。
- **依赖**：订单或行为数据、复购周期口径。

### 1.4 召回与防流失
沉睡召回策略（分层召回触达）、召回率追踪、流失阈值定义与预警。
- **预期方向**：召回率方向性提升（参考 5%–15% 常见区间，见 member-metrics）、沉睡率下降。
- **依赖**：沉睡定义口径、触达通道可用。

### 1.5 生命周期跃迁
设计阶段转换触发（新客→活跃→潜力→高价值），驱动用户向上迁移，而非停留某层。
- **预期方向**：阶段跃迁率提升、高价值会员占比提升。
- **依赖**：阶段定义与转换条件可量化、行为数据驱动。

### 1.6 触点链路梳理
打通身份、画触点地图、补承接断点、公私域联动。
- **预期方向**：跨触点转化率方向性提升、行为断层减少。
- **依赖**：各渠道用户标识可对接、触点负责人协同。

### 1.7 内容活动体系化
月度栏目 + 任务 + 互动 + UGC 节奏，与生命周期/权益联动，减少对节日促销的依赖。
- **预期方向**：内容贡献活跃率提升、日常活跃可持续性改善。
- **依赖**：内容/活动资产、排期资源。

### 1.8 数据基础建设
统一口径、搭健康度看板、标签治理、固定复盘机制（这是其他杠杆的底座）。
- **预期方向**：看板驱动决策、指标口径统一可下钻。
- **依赖**：数据字段可取、BA/数据支持。

## 2. 诊断异常 → 增长动作映射表（增长段核心）

> 这是把诊断与增长串起来的关键。诊断出某维度低分/某根因 → 查表选增长杠杆 → 按五要素填充。

| 诊断异常信号（维度/根因） | 根因归类 | 对应增长杠杠 | 预期方向（给区间不给定数） |
|---|---|---|---|
| 无分层、新客/沉睡同质化运营（用户资产/生命周期低分） | 策略 | 分层精准运营 | 触达转化率、活跃率方向性提升 |
| 积分兑换率低、权益感知弱（权益体系低分） | 转化/内容 | 权益体系优化 | 兑换率/券核销率方向性提升 |
| 复购率不升、无触发机制（转化复购低分） | 转化 | 复购提升 | 复购率/复购频次方向性提升 |
| 沉睡率高、流失无预警（转化复购/数据标签低分） | 转化/系统 | 召回与防流失 | 召回率方向性提升（参考5%-15%）、沉睡率下降 |
| 阶段单一、用户不上行迁移（生命周期低分） | 策略 | 生命周期跃迁 | 阶段跃迁率、高价值占比提升 |
| 触点各自为战、身份未打通（触点链路低分） | 系统 | 触点链路梳理 | 跨触点转化率方向性提升 |
| 仅节日促销、日常无内容（内容活动低分） | 内容 | 内容活动体系化 | 内容贡献活跃率、日常活跃改善 |
| 无看板、口径不一、无法优化（数据标签低分） | 数据/系统 | 数据基础建设 | 看板驱动决策、口径统一 |
| 活跃高但续费/价值释放弱（转化复购低分） | 策略/转化 | 复购提升+权益优化（续费绑定） | 续费率/CLV 释放方向性提升 |
| 无固定诊断迭代节奏（组织SOP低分） | 执行 | 数据基础建设（含复盘机制） | 动作沉淀为SOP、复盘频率稳定 |

## 3. 增长目标口径与预期写法（量化，禁模糊）

增长预期必须**可量化、可解释**，给方向区间不给确定数字。指标口径统一引用 [member-metrics.md](member-metrics.md)：

| 增长指标 | 默认口径 | 参考基准（仅判方向，非好坏结论） |
|---|---|---|
| 复购率提升 | 期内购买≥2次会员数 ÷ 期内购买会员数，对比前后 | 快消/零售 20%–40% 常见 |
| 召回率 | 召回成功数 ÷ 召回触达数 | 5%–15% 常见 |
| 兑换率 | 期内兑换积分 ÷ 期内可获得积分 | 20%–50% 常见 |
| 券核销率 | 核销券数 ÷ 发放券数 | 15%–40% 常见 |
| 留存率改善 | cohort 第N期仍活跃数 ÷ 首期cohort数，看趋势 | 看趋势比看绝对值重要 |
| 触达转化率 | 转化数 ÷ 触达成功数 | 看渠道分拆 |
| 阶段跃迁率 | 期内从低阶升到高阶的会员数 ÷ 期初低阶会员数 | 看趋势 |

**预期写法范例**：
- ✅ 合格："对近90天沉睡会员发分层召回触达，预计召回率 5%–15% 方向区间，用 A/B 验证。"
- ✅ 合格："积分权益重构绑定复购后，兑换率预期方向性提升（基准 20%–50% 区间，具体看品类），前后对比验证。"
- ❌ 不合格："提升用户体验"（口号，无杠杆/人群/验证）。
- ❌ 不合格："复购率提升 30%"（给确定数字，无验证方式，过度承诺）。
- ❌ 不合格："增强会员粘性"（模糊词）。

## 4. 增长假设 If/Then 写法

每条增长杠杆配套一个可验证假设，结构 = `If [对某人群做某动作]，Then [预期指标方向区间]，验证方式 [A/B / 前后对比 / 小范围测试 / cohort 追踪]`。

范例：
- If 对首购后 30 天未复购会员发品类复购触达，Then 复购率方向性提升，验证方式 A/B 测试。
- If 把续费干预从"到期前提醒"升级为按风险分层提前触达，Then 续费率方向性提升，验证方式 续费前/后对比。
- If 打通门店-企微-小程序身份做会员去重，Then 可经营规模明确化、跨触点转化率方向性提升，验证方式 去重前后转化漏斗对比。

> 假设不等于承诺。所有 Then 的预期都是方向性区间，需真实数据验证；不验证就当成果即违背"不把假设写成事实"底线。

## 5. 边界与避坑

1. **增长不含拉新**：本文件所有杠杆都是存量经营，靠复购/留存/跃迁/召回增长，不靠多拉新用户。用户要拉新转对应技能。
2. **增长不承诺确定数字**：只给杠杆识别与可验证假设，参考基准仅判方向（低/中/高），非好坏结论；是否达标以本业务历史值与目标为准。
3. **杠杆必须由诊断推导**：脱离诊断空给"8 大杠杆全套"等于没诊断。每条杠杆要能追溯到某个维度低分/某根因（查 §2 映射表）。
4. **不与兄弟技能越界**：增长杠杆只给方向与验证，不写完整等级/积分/活动规则（交会员体系搭建/活动策划类技能）。
5. **底座先行**：若诊断出"数据标签/组织SOP"极低（无看板、无口径），增长第一步往往是"数据基础建设"——先有度量能力再谈增长，否则增长无法验证。
