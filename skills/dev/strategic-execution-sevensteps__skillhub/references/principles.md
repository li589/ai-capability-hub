# 防坑指南与导入路线

## 六盏红灯：战略常见误区

### 🚫 红灯1：工具迷恋症
"我们会用波特五力分析过了" ≠ 战略思考做完了。框架是工具，不是答案。一个简洁的判断比一份堆满框架的报告有价值一百倍。别让分析报告替你决策。

### 🚫 红灯2：数据淹没
数据驱动 ≠ 数据淹没。关键洞察往往来自少量关键数据，而不是一百页 Excel。如果数据没有改变你对问题的理解，那它只是噪音。**先有假设，再用数据验证**——不是让数据替你生成假设。

### 🚫 红灯3：完美主义陷阱
追求完美方案会错过机会窗口。区分两类决策：
- **可逆决策**（试点、小规模投入）→ 快做、快试、快调
- **不可逆决策**（重资产投入、品牌改名）→ 慢想、多推演、多视角验证

### 🚫 红灯4：战略悬浮
不考虑组织能力的战略只是 PPT。三问：
1. 现有团队能执行这个战略吗？（能力匹配）
2. 执行这个战略对谁有利、对谁不利？（政治阻力）
3. 如果我是执行层，听完战略我知道明天做什么吗？（可拆解性）

### 🚫 红灯5：忽视组织政治
战略落地是政治过程，不是纯理性的。财务 VP 觉得预算被砍是威胁、销售 VP 觉得新方向会动他的地盘——方案就推不动。核心利益相关方要**提前一对一沟通**，而不是在会上让他们"表态"。

### 🚫 红灯6：线性外推
"去年增长 30%，明年继续 30%"——但去年条件明年还存在吗？市场规模有天花板吗？增长是在吃存量红利还是真正在创造新价值？

**一句话检验：** 如果战略放在三年前同样成立，那它大概率不是战略，而是惯性。

## 快速自检清单（5分钟战略体检）

在帮用户诊断时，逐一检查：

- [ ] 我们的增长假设是什么？这些假设今年还成立吗？
- [ ] 现在做的事情里，哪一件如果今天从零开始我们不会做？为什么还在做？
- [ ] 团队关起门吵架的时候，吵的是"怎么做"还是"做什么"？（前者是健康的）
- [ ] 如果只做一件事能让公司三年后活得好，那件事是什么？
- [ ] 一线员工知道公司的战略重点吗？问三个人看答案是同一个吗？

## 导入建议：别一上来就全套上

| 阶段 | 时间 | 做什么 | 成功标志 |
|------|------|--------|---------|
| 试水 | 1-2个月 | 先搞一场战略解码会（第四步），选一个业务单元试点 | 团队说"这个方法有用" |
| 落地 | 3-6个月 | 加上目标分解（第五步）+执行跟踪（第六步） | 月度跟踪会正常开，硬仗有进展 |
| 闭环 | 6-12个月 | 补上复盘（第七步），走完第一个完整循环 | 年底复盘能说出"今年哪些仗打赢了、为什么" |
| 深化 | 1-2年 | 补上洞察（第二步）+定略（第三步）+组织准备（第一步） | 战略制定有章法、有深度 |
| 优化 | 持续 | 引入业务分型、战略止损、季度校准等进阶机制 | 体系能自我迭代、自我进化 |
