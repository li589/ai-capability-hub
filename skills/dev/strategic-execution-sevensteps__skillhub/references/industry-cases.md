# 行业案例库：8大热门行业战略落地场景

以下每个行业给出**典型痛点→常见切入→真实场景→解决路径→典型产出**五段结构。

---

## 1. AI/大模型行业

**典型痛点**：技术迭代以周为单位，年初方向Q2就过时。产研想做平台、销售想打垂直场景、投资人想看 SOTA——三个人三个方向。公司同时在跑5个项目，没有一个是主航道。

**常见切入**：第四步战略解码（锁定当下最值得打的仗）+ 第六步季度校准（高频环境适配）

**典型场景**：某AI应用创业公司，30人，CEO技术出身。年初定了"做企业级AI Agent平台"，Q1过完团队已经跑偏三个方向——产品在做开源工具，销售在推轻量Chatbot，CTO在研究新推理框架。钱烧得快，没人说得清到底在打什么仗。

**解决路径**：半天战略解码会 → 三个方向用"市场窗口×团队能力"矩阵排序 → 锁定一场硬仗"Q2-Q3集中打金融行业智能客服" → 设定失败标准"Q3签约客户不到5家立即切换" → 其他方向降级为探索。

**典型产出**：1张年度硬仗清单 + 季度校准机制 + 明确的止损条件。

---

## 2. SaaS/企业服务

**典型痛点**：PLG和SLG双线作战但节奏对不齐。产品按双周迭代，销售按季度背指标，客户成功在中间被撕裂。产品路线图被大客户牵着走，小客户需求排不上。

**常见切入**：第五步目标分解（业务分型：成熟产品线用BSC+OGSM，新功能探索用OKR）

**典型场景**：某B轮SaaS公司，120人，ARR 3000万。两条产品线——核心HR SaaS（成熟，贡献80%收入）和AI招聘助手（新业务，还在PMF阶段）。问题出在用同一套KPI管两种业务：AI招聘团队被要求按季度背收入，结果拼命接定制项目，离PMF越来越远。

**解决路径**：业务分型 → HR SaaS线用BSC+OGSM稳基本盘 → AI招聘线转纯OKR，关键结果从"收入"改成"周活客户数+NPS"。

**典型产出**：两套并行的目标体系 + 跨部门月度对齐会。

---

## 3. 跨境电商/品牌出海

**典型痛点**：多市场并行运营，总部和海外团队"战略衰减"——总部定的品牌定位，到当地变成"什么好卖卖什么"。库存、物流、营销三座大山，跨部门协同靠微信群吼。

**常见切入**：第四步战略解码（明确主攻和防守市场）+ 第六步月度跟踪（跨境核心难题是"看不见"）

**典型场景**：某消费电子出海品牌，200人，年GMV 5亿。CEO战略很清楚——美国打品牌（高毛利）、东南亚走量（高周转）。但月度经营会上，美国团队报"投了多少红人营销"，东南亚团队报"出了多少单"，两种语言对不上。

**解决路径**：战略解码会定调 → 美国硬仗Owner(CMO)+三个里程碑"品牌搜索量↑50%、TikTok自然流量>30%、客单价↑20%" → 东南亚硬仗Owner(COO)+核心指标"库存周转45→30天、物流成本18%→12%" → 月度用红黄绿统一语言。

**典型产出**：两场硬仗各自OGSM表 + 跨市场统一月度看板。

---

## 4. 新消费/新零售

**典型痛点**：从"跑马圈地"转向"精耕细作"但管不过来。创始人产品/营销出身擅长0-1，开了30家店之后每家店服务水平开始分化，总部看不清哪家店出了问题。

**常见切入**：第六步执行跟踪（月跟踪+店长红黄绿看板）+ 第七步季度复盘（快节奏纠偏）

**典型场景**：某新茶饮品牌，300人，全国80家门店。新店开到第6个月业绩开始下滑，因为创始人亲自盯不过来了。区域经理管5-8家店，靠每周巡一次店+Excel，发现下滑已经是两个月后。

**解决路径**：轻量店长日报（3个核心指标：日流水/客诉率/新人带教完成率）→ 收银系统+小程序自动采集 → 区域经理红黄绿看板，连续3天红灯自动预警 → 月度门店会标准议程。

**典型产出**：门店红黄绿看板 + 问题门店从"发现晚2个月"变成"3天内预警"。

---

## 5. 智能制造/硬科技

**典型痛点**：研发周期18-36个月，技术路线选错两年后才发现。工厂按产能排产、销售按客户承诺交货、研发按技术理想做产品——三个时钟永远对不上。

**常见切入**：第四步资源配置（硬仗优先级排序+研发投入取舍）+ 第五步目标分解（长周期研发拆成可跟踪里程碑）

**典型场景**：某工业机器人公司，150人，B轮。三个产品方向——协作机器人（确定性高、增速稳）、移动机器人（市场大但竞争激烈）、核心零部件（壁垒高但周期长）。钱只够重点打一个，三个VP各执一词。

**解决路径**：资源配置专题会 → 用"技术壁垒×市场增速×团队能力"三维矩阵打分 → 协作机器人必打(60%资源) → 核心零部件创造条件再打(25%资源，先完成一项关键技术验证) → 移动机器人维持不扩 → 每季度校准。

**典型产出**：资源分配共识 + 季度校准机制 + 每个方向明确的"晋升标准"和"降级标准"。

---

## 6. 产业数字化/企业服务

**典型痛点**：帮传统行业数字化，但自己的管理还是传统的——Excel管项目、微信群对齐、靠PM个人能力撑交付质量。项目型收入来钱快但不可复制，产品型收入有未来但短期扛不住营收指标。

**常见切入**：第一步组织准备（核心团队共识诊断）+ 第三步战略制定（业务设计——到底做产品还是做项目）

**典型场景**：某工业互联网平台，80人，A轮。CEO一直说"我们是产品公司"，但80%收入来自定制化项目。团队撕裂成两派：产品派觉得应该砍项目专注SaaS，项目派觉得没有项目收入活不到产品成熟。

**解决路径**：先做团队共识诊断 → 匿名问卷发现3个VP有2个"嘴上同意做产品公司、心里觉得不现实" → 把模糊争议变成三个选项摆上桌 → 团队选"项目养产品"但加退出标准：24个月后产品收入占比不到40%则启动转型 → 从假对齐变成真共识。

**典型产出**：高管战略共识度报告 + 业务设计清晰 + 退出机制。

---

## 7. 金融科技

**典型痛点**：合规压倒一切，创新节奏被监管锁死。技术团队想快速迭代，合规团队要求每个功能都过三道审批。既要满足央行/证监会合规要求，又要在用户增长上跑过互联网对手——两条线天生冲突。

**常见切入**：第四步战略解码（区分"必须有"的合规硬仗和"想要有"的业务创新硬仗）+ 第五步目标分解（合规指标和业务指标分轨管理）

**典型场景**：某金融科技公司，200人，B轮，主营智能投顾和信贷科技。监管新规要求所有算法模型可解释，技术团队需要6个月重构，但业务团队说等不了——用户流失在加速。两套目标打架，没人说了算。

**解决路径**：战略解码会 → 明确"合规重构"为今年第一硬仗（不可妥协），"用户增长"降为第二硬仗 → 合规硬仗用BSC年度目标，业务创新硬仗用OKR每月迭代 → 在季度校准会上评估合规重构进度是否允许业务加速。

**典型产出**：合规硬仗OGSM + 业务创新OKR + 双轨月度评审机制。

## 8. 医疗健康

**典型痛点**：销售周期长（6-18个月），产品迭代慢（器械/新药），政策依赖度高（集采/目录准入）。销售签合同→客户交付→回款，三段时间差大，现金流预测像算命。

**常见切入**：第三步战略制定（业务设计——自营还是合作？KA还是广泛覆盖？）+ 第六步执行跟踪（长周期需要更强的里程碑可视化和预警机制）

**典型场景**：某医疗器械公司，120人，B轮，专注外科手术机器人。一台设备从线索到装机平均14个月，每年能跑的通路有限。BD团队说需要铺设更多渠道，研发团队说应该聚焦打磨产品等爆发——资源争夺激烈，但双方都说不清哪种选择的ROI更高。

**解决路径**：战略制定专题 → 用"客户分级×市场密度×支付能力"三个维度做市场细分 → 锁定5个标杆医院（头部三甲，6个月内装机）+ 10个培育医院（省会三甲，12-18个月）→ 设置6个月强制评估点：标杆医院装机低于3台立即切换策略。

**典型产出**：市场分级地图 + 标杆医院攻坚OGSM + 6个月强制评估机制。

## 怎么用案例库

当用户说出自己的行业和痛点时：
1. 先匹配最接近的行业案例
2. 找出对应"常见切入"步骤
3. 按"解决路径"的模式给出定制化方案
4. 参考"典型产出"明确交付物

如果用户的行业不在这8个里面，按五段结构（痛点→切入→场景→路径→产出）自行类比推演，过程如下：
- 先问用户 2-3 个问题定位行业特征（核心矛盾是什么？客户决策周期多长？监管强度多高？）
- 根据回答判断与哪个已有行业最接近，以此为基底调整
- 保持五段式输出结构不变
