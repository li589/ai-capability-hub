# 战略落地七步法 · 详解

## 整体架构

```
┌──────────────────────────────────────────────────────┐
│  第一步：组织准备（前置安检）                            │
│  团队共识 · 人才盘点 · 文化适配                         │
└──────────────────────────────────────────────────────┘
                        ↓
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│ 第二步    │ 第三步    │ 第四步    │ 第五步    │ 第六步    │ 第七步    │
│ 我们在哪 │ 去哪儿+怎么去│ 今年打什么│ 每人干什么│ 真在推进吗│ 打得怎么样│
│ (洞察)  │ (定略)    │ (解码+资源)│ (分解)   │ (执行)   │ (复盘)   │
└──────────┴──────────┴──────────┴──────────┴──────────┴────┬─────┘
                        ↓
┌──────────────────────────────────────────────────────┐
│  第七步复盘结果 → 回流第一步，螺旋迭代                    │
└──────────────────────────────────────────────────────┘

底层支撑：动力系统（3R） + 能力系统 + 信息系统
节奏体系：年度大循环 / 季度中循环 / 月度小循环
```

## 第一步：组织准备——战略启动前的三道安检

| 维度 | 内容 |
|------|------|
| **核心问题** | 我们的组织准备好了吗？ |
| **主力方法论** | 吕守升 3R+3S（前置化）+ BLM 人才/组织维度（3S = Shared Vision共享愿景 / Structure组织架构 / System制度流程，3R = Responsibility责权 / Review考核 / Reward激励） |
| **关键角色** | CEO + HR负责人 + 战略负责人 |
| **典型节奏** | 战略季启动前，1-2周完成 |

**三道安检：**

**① 核心团队共识诊断**
- 战略共识度测评：高管团队对方向、优先级、路径的理解一致吗？
- 信任度评估：团队能坦诚争论吗？
- 角色清晰度：谁拍板、谁执行、谁参谋，边界清楚吗？
- 输出：高管团队战略共识度报告

**② 关键人才盘点**
- 战略需要什么样的核心人才？（领军人物、技术专家、操盘手）
- 现有多少？缺口多大？怎么补？（内部培养 / 外部招聘 / 借调 / 调整战略范围）
- 输出：战略人才盘点地图

**③ 文化适配性评估**
- 文化支持战略方向吗？
- 要创新但文化零容错 → 战略注定失败
- 要效率提升但文化大锅饭 → 推不动
- 输出：文化-战略适配性评估报告

**触发场景：** "我们准备启动新战略，先看看团队和组织准备好了没有"

## 第二步：洞察诊断——我们在哪？

| 维度 | 内容 |
|------|------|
| **核心问题** | 现状是什么？差距在哪？机会在哪？ |
| **主力方法论** | BLM（市场洞察+差距分析）+ 秦杨勇环境扫描工具箱 |
| **关键角色** | 战略部 + 各业务负责人 |
| **典型节奏** | 每年Q4启动，2-3周完成 |

### 思维武器：三把手术刀

**① 第一性原理：剥离表象**
- "销量下滑是因为竞品降价" → 真问题可能是：价值主张不再独特
- "团队执行力不行" → 真问题可能是：方向本身不可执行
- 操作：连续追问5个"为什么"，直到触及本质

**② 系统思维：看清结构**
- 每一个问题背后都有增强回路和调节回路
- 关键操作：找杠杆点——哪个小变化能撬动最大改变？
- 警惕：头痛医头、脚痛医脚

**③ 批判性思维：挑战假设**
- "我们一直是这样做的" → 这个假设今天还成立吗？
- "行业老大就是这么干的" → 他们的前提条件和你一样吗？
- 警惕：确认偏误、幸存者偏差、归因错误

### 四个动作

**① 差距分析（起点）**
- 业绩差距：实际业绩与目标的差距
- 机会差距：市场存在但没抓住的机会

**② 外部环境扫描**
- 宏观：PESTEL（政治、经济、社会、技术、环境、法律）
- 产业：波特五力、行业关键成功因素、市场规模与增速
- 竞争：主要竞争对手、各自优劣势、最新动向
- 客户：需求变化、未被满足的需求、痛点

**③ 内部环境扫描**
- 资源盘点：财务、技术、品牌、渠道、数据
- 能力评估：擅长什么？不擅长什么？
- 组织健康度：流程效率、组织活力、人才密度

**④ 横向协同识别**
- 识别跨部门天然卡点：哪些问题任何单一部门解决不了？
- 这些卡点即后续"跨部门硬仗"候选池

**输出物：** 差距分析报告、内外部环境扫描报告、SWOT矩阵、跨部门卡点清单

### 数据采集管线

执行时使用 `web_search` + `web_fetch` 自动采集，按以下结构化模板输出。

**搜索策略：**

1. **政策**：`web_search "{行业}+最近政策+国务院|发改委|工信部 site:gov.cn"`
2. **产业**：`web_search "{行业}+市场规模+增长率+趋势 2024|2025"`
3. **竞品**：`web_search "{行业}+头部企业+竞争格局+排名"`
4. **交叉验证**：每个维度至少搜 2 次，用不同关键词组；对矛盾数据标注差异并优先采信官方来源（gov.cn/公司官网/行业白皮书）

**政策分析模板**：来源（国务院/发改委/工信部官网）+ 政策名称 + 发布时间 + 核心内容 + 对行业影响（机遇/挑战/应对建议）

**产业全景模板**：市场规模与增长率 + 产业链结构 + 技术成熟度 + 趋势判断（短期1年/中期3年/长期5年）

**竞品分析模板**：多竞品对比表（核心产品/目标市场/技术路线/定价/优劣势）+ 差异化机会

## 第三步：战略制定——我们去哪儿？怎么去？

| 维度 | 内容 |
|------|------|
| **核心问题** | 3-5年后要成为什么样？靠什么赢？ |
| **主力方法论** | BLM（战略意图+业务设计+创新焦点）+ BSC顶层战略地图 |
| **关键角色** | CEO + 高管团队 |
| **典型节奏** | 每年Q4，1-2次战略务虚会 |

### 四个动作

**① 战略意图**
- 愿景：终极追求是什么？
- 3-5年战略目标：规模、行业地位、核心指标
- 战略主题：关键标签（如"数字化转型""全球化""第二曲线"）

**② 业务设计**
- 客户选择：服务谁？不服务谁？
- 价值主张：提供什么独特价值？
- 盈利模式：怎么赚钱？
- 业务范围：哪些自己做？哪些合作/外包？
- 战略控制点：护城河是什么？

**③ 创新焦点**
- 现有业务怎么深化？
- 新业务/新机会怎么探索？
- 第二曲线在哪里？

**④ 顶层战略地图**
- BSC战略地图可视化：财务→客户→内部流程→学习成长

**输出物：** 战略规划报告（3-5年）、顶层战略地图、战略主题清单（3-5个）

### 附加工具：方向未定时的决策增强

**① 多方案生成与比较**

强制生成至少3个有实质性差异的备选方案，AI 在对比时使用以下标准：
- **权重**：由 AI 根据行业特征建议默认值，用户可调整。以百分比形式填写，6维总和 = 100%
- **打分**：1-10 分制，1=极弱/极差，10=极强/极优

| 评估维度 | 权重 | 方案A | 方案B | 方案C |
|---------|:--:|------|------|------|
| 市场吸引力（规模/增速） | 20% | | | |
| 竞争格局（集中度/差异化空间） | 20% | | | |
| 团队匹配度（现有能力覆盖度） | 20% | | | |
| 资源投入（资金/人才/时间） | 15% | | | |
| 战略协同（与现有业务协同度） | 15% | | | |
| 风险可控性（可逆程度+失败成本） | 10% | | | |
| **加权总分** | 100% | | | |

**② 情境推演**

为选定方向构建三种情境：

| 情境 | 触发条件 | 应对策略 | 早期预警信号 |
|------|---------|---------|------------|
| 🌞 乐观情境 | 市场增速超预期 / 竞品反应迟钝 | 加速投入、抢占份额 | 客户获取成本持续下降 |
| 📊 基准情境 | 市场按预期增长 / 竞争格局稳定 | 按计划推进、定期校准 | — |
| 🌧️ 悲观情境 | 需求萎缩 / 技术路线突变 / 价格战 | 收缩防线、保现金流 | 续约率连续2季下滑 |

**③ 战略叙事框架**

```
困境（面临什么挑战？）
  → 洞察（看到了什么别人没看到的？）
   → 方向（所以选择去哪？）
    → 行动（首先做什么、今年打哪几场仗？）
     → 愿景（打赢之后会变成什么样？）
```

对不同听众调整重点：给董事会讲逻辑（数据+推演+风险预案）；给团队讲意义；给投资人讲增长。

**利益相关方对齐清单：**

| 谁 | 他们关心什么 | 可能反对什么 | 沟通策略 |
|----|------------|------------|--------|
| CEO | 长期价值 | 变革速度 | 用情景推演证明不动的风险 |
| 核心高管 | 资源/权力分配 | 自身利益受损 | 提前一对一、解决顾虑再上会 |
| 中层 | 执行难度 | 工作量增加 | 用试点小胜证明可行 |
| 一线员工 | 饭碗/工作内容 | 不知道怎么做 | 给工具、给培训、给信心 |

## 第四步：战略解码与资源配置——今年打什么？钱够不够？

分为两个子步骤：战略解码（确定年度硬仗）和资源配置（为硬仗配粮草）。

### 第四步A：战略解码——确定年度硬仗

| 维度 | 内容 |
|------|------|
| **核心问题** | 今年必须打赢哪几场仗？ |
| **主力方法论** | 秦杨勇五步法（三级解码）+ 吕守升战略解码会 + BSC各级战略地图 |
| **关键角色** | 战略部 + 各部门负责人 + 全体高管 |
| **典型节奏** | 每年12月-次年1月，2-3场工作坊 |

**四个动作：**

**① 公司级解码**
- 将3-5年战略翻译成年度战略主题和目标
- 输出公司级战略地图、平衡计分卡、行动计划表
- 确定年度硬仗清单（3-5场必须打赢的仗）

**② 业务级解码**
- 各业务单元承接公司战略，输出业务级图卡表

**③ 部门级解码**
- 各职能部门承接，必须有具体行动计划

**④ 跨部门硬仗组**
- 识别"任何单一部门打不赢的仗"
- 每场硬仗指定Owner（不一定是高管，可以是中层牵头人）
- 成立虚拟攻坚小组，Owner直接向战略委员会汇报

**输出物：** 三级战略图卡表、年度硬仗清单（含Owner、成员、目标、里程碑）

### 第四步B：资源配置——为硬仗配粮草

> ⚠️ 没有资源配置的战略解码，本质上是愿望清单。

**四个动作：**

**① 预算对齐**——每场硬仗需要多少预算？总盘子多大？不够就延后或缩小规模

**② 人力对齐**——需要多少人？现有人力覆盖多少？缺口来源：招聘/内部转岗/外包/降低目标

**③ 精力对齐**——CEO能盯几场硬仗？只能盯2场，另3场成功率天然就低

**④ 优先级排序**——重要性×可行性矩阵：

| | 可行性高 | 可行性低 |
|---|---|---|
| **重要性高** | 必打 🥇 | 创造条件再打 |
| **重要性低** | 顺手打 | 不打 ❌ |

**输出物：** 战略资源配置表（预算+人力）、硬仗优先级排序、资源缺口及应对方案

## 第五步：目标分解——怎么落到每个人头上？

| 维度 | 内容 |
|------|------|
| **核心问题** | 每个人具体干什么？ |
| **主力方法论** | OGSM + 吕守升PPC个人绩效合约 + OKR（创新型业务） |
| **关键角色** | 各部门负责人 + 全体员工 |
| **典型节奏** | 每年1月，2-3周完成 |

### OGSM 一页纸模板（各字段说明）

| 字段 | 英文 | 说明 | 示例 |
|------|------|------|------|
| **Objective 目的** | 定性描述 | 我们要达成什么？一句话，有方向感 | "成为华东区市场份额第一的XX服务商" |
| **Goal 目标** | 定量指标 | 怎么衡量达成？含数值+时间 | "ARR突破5000万，2026年12月" |
| **Strategy 策略** | 做什么 | 靠什么达成目标？3-5个策略方向 | "①大客户直销 ②渠道伙伴计划 ③产品标准化" |
| **Measure 衡量** | 怎么算完成 | 每个策略的关键指标+目标值 | "签约10家年付50万+客户；渠道贡献30%收入" |

**输出物：** 部门OGSM表、团队/个人OGSM或PPC合约、OKR清单（创新型业务）

### 业务分型匹配

| 业务类型 | 推荐分解工具 | 节奏 |
|---------|------------|------|
| 成熟核心业务 | BSC + OGSM，全套 | 年度目标+季度跟踪 |
| 成长型业务 | OGSM + OKR混合 | 季度目标+月度跟踪 |
| 探索/创新业务 | OKR为主 | 月度目标+双周迭代 |
| 职能支持部门 | 部门战略地图 + OGSM | 跟随业务节奏 |

### 四层分解

**① 部门级OGSM** — 承接部门战略地图，转化为一页纸OGSM

**② 团队级OGSM** — 上层Strategy = 下层Objective，一层一层往下传

**③ 个人级OGSM/PPC** — 每个人的目标、策略、衡量标准

**④ PPC个人绩效合约PK会** — 公开陈述、相互挑战，不是派任务是公开承诺

### 绩效评审模板

**绩效打分办法：**

| 等级 | 分值区间 | 说明 |
|------|---------|------|
| S（卓越） | 95-100 | 远超预期 |
| A（优秀） | 85-94 | 超出预期 |
| B（良好） | 70-84 | 符合预期 |
| C（合格） | 60-69 | 基本达标 |
| D（待改进） | <60 | 未达标 |

> **强制分布 vs 绝对标准**：上表为建议参考。是否强制比例分布取决于企业文化和阶段：
> - **适用强制分布**：大公司、业务成熟、需要拉开差距做末位优化
> - **适用绝对标准**：创业公司、创新业务、以能力密度而非排名驱动——已取消强制分布的企业（参考近年 Google/Microsoft 等取消强制排名的趋势）推荐此方式
> - 建议做法：先用绝对标准打分，若结果过于集中（全员A/B）则说明标准设定或评估文化有问题，再从诊断入手而非硬套比例

→ 绩效指标与硬仗结果直接挂钩，避免"战略往东、KPI往西"

### 硬仗结果→绩效得分映射表

每场硬仗的完成度按以下规则折算个人绩效得分。多场硬仗取加权平均（权重 = 硬仗对部门目标的贡献度 %）。

| 硬仗完成度 | 对应绩效等级 | 折算系数 | 说明 |
|:--------:|:----------:|:------:|------|
| ≥120%（远超目标） | S | 1.2 | 超预期达成，给予跳级激励 |
| 100%-119% | A | 1.0 | 完成并超出，正常满额绩效 |
| 85%-99% | B | 0.85 | 基本完成，正常绩效 |
| 70%-84% | C | 0.7 | 部分完成，触发改进计划 |
| <70% | D | 0.5 | 未达标，启动复盘与问责 |

**使用示例**：某员工关联2场硬仗——硬仗A完成度105%（权重60%）、硬仗B完成度90%（权重40%）。加权完成度 = 105%×60% + 90%×40% = 99% → 对应等级 B，折算系数 0.85。

> 硬仗Owner对硬仗完成度数据负责，PMO在月度跟踪会上核实，季度校准会上公开确认，确保数据公信力。

## 第六步：执行落地——怎么确保真在推进？

| 维度 | 内容 |
|------|------|
| **核心问题** | 进展如何？有什么问题？需要什么支持？ |
| **主力方法论** | 吕守升执行跟踪 RIDER-E（Report报告 / Inspect检查 / Decide决策 / Execute执行 / Review复盘 — End-to-End闭环）+ 秦杨勇战略管理循环 + BSC报告系统 |
| **关键角色** | 战略PMO + 各硬仗Owner + 各部门负责人 |
| **典型节奏** | 月度跟踪 + 季度校准 |

### 四个机制

**① 战略PMO机制**
- 成立战略项目办公室（SPO/PMO）：跟踪进度、协调资源、预警风险、组织会议
- PMO是服务+推动部门，不是权力部门

**② 三层节奏体系**

| 层级 | 内容 | 频率 | 规则 |
|------|------|------|------|
| 月度小循环 | 硬仗进度会 | 每月 | 只看进度、找问题、协调资源；不换方向 |
| 季度中循环 | 战略校准会 | 每季 | 环境变了吗？硬仗还打吗？可微调 |
| 年度大循环 | 完整复盘 | 每年 | 第七步，全流程走一遍 |

**月度进度会标准议程：**
1. 每场硬仗Owner汇报：进度（红黄绿灯🔴🟡🟢）、核心问题、需要什么支持
2. 跨部门协调：卡在哪？谁来解决？
3. 风险预警：提前一个月看下个月可能出问题的地方
4. 行动决议：谁、做什么、哪天交

**③ 战略止损机制**
- 每场硬仗立项时就定"失败标准"——什么情况下承认打不赢、撤
- 季度校准会固定议题："哪些硬仗该停？"
- 叫停不是失败，是释放资源给更有希望的方向

**④ 信息系统支撑**
- 战略看板：硬仗进度、关键指标、风险预警，可视化
- 数据自动采集，减少人工填报

**输出物：** 月度/季度战略跟踪报告、战略数据看板、风险预警清单

## 第七步：复盘总结——打得怎么样？明年怎么改？

| 维度 | 内容 |
|------|------|
| **核心问题** | 哪些做对了？哪些做错了？明年怎么改进？ |
| **主力方法论** | 吕守升RIDER评估更新 + BLM复盘逻辑 + 秦杨勇战略回顾会 |
| **关键角色** | 全体高管 + 各部门负责人 |
| **典型节奏** | 每年1月（春节前） |

### 四个动作

**① 硬仗评议会**
- 每场硬仗逐一复盘：打赢了吗？为什么赢/输？
- 不是算账追责，是学习改进
- 标准三问：①目标达成了吗？②如果重来一次，哪一步会做不同？③教训对明年意味着什么？

**② 个人述职会**
- PPC完成情况评估、能力成长评估
- 与激励、晋升、发展挂钩

**③ 企业年度总结大会**
- 全年战略执行回顾、表彰先进、传递信心
- 不是批评大会，是动员大会

**④ 回流机制**
- 复盘结论 → 输入下一年第二步（洞察诊断）
- 首个R（Research）和最后一个R（Review）首尾相连
- 螺旋式迭代

**输出物：** 年度硬仗复盘报告、年度战略执行总结、下一年改进方向

## 附录：战略报告生成规范

### 报告架构（9大模块，3大板块）

```
┌──────────────────────────────────────────┐
│         公司战略规划报告                     │
├──────────────────────────────────────────┤
│  封面页 + 目录页 + 执行摘要                 │
├──────────────────────────────────────────┤
│  外部环境分析（蓝色调标题/表头）              │
│  ├── 模块1：国家政策内容与分析               │
│  ├── 模块2：产业洞察（技术动态与趋势）        │
│  └── 模块3：竞争对手产品分析                 │
├──────────────────────────────────────────┤
│  内部环境分析（绿色调标题/表头）              │
│  ├── 模块4：公司内部业务梳理                 │
│  ├── 模块5：解决方案及产品                   │
│  └── 模块6：技术研发战略规划                 │
├──────────────────────────────────────────┤
│  战略落地（橙色调标题/表头）                 │

│  ├── 模块8：销售及研发预算规划               │

├──────────────────────────────────────────┤

└──────────────────────────────────────────┘
```

### 生成流程

1. **需求确认**：确定公司名、行业、规划周期、竞品等（引导用户回答关键问题）
2. **数据采集**：按第二步中的"数据采集管线"搜索策略自动 `web_search` + `web_fetch` 采集政策、产业、竞品数据
3. **分析撰写**：按9大模块结构化输出，内外结合推导
4. **报告输出**：默认输出为 **Markdown 文件**写入 workspace（文件名格式：`{公司名}_战略规划报告_{YYYY-MM-DD}.md`）；用户要求在线文档时，使用腾讯文档 Skill 创建智能文档。

- [ ] 9大模块全部覆盖
- [ ] 外部环境有数据支撑，非纯主观判断
- [ ] 内部环境有现状基线
- [ ] 关键举措可追溯到内外部分析结论
- [ ] 预算规划与关键举措一一对应
- [ ] 绩效指标可量化、可考核
- [ ] 政策引用标注来源和日期
- [ ] 产业数据标注出处
- [ ] 竞品信息交叉验证
