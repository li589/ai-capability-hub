一、核心功能说明
本Skill实现智能体自我迭代闭环，包含4大核心能力：
1. 规则迭代：自动生成行为规则，后续对话强制生效
2. 代码自动修改：AI自动优化自身代码，无需人工干预
3. 闭环自动迭代：每20轮对话自动复盘、评分、优化
4. 迭代评分：每次迭代打1-10分，低评分自动二次优化

二、完整可用指令清单（直接输入即可触发）
1.  龙虾迭代        # 手动执行一次完整迭代（规则+代码+评分）
2.  持续迭代        # 开启自动进化（每20轮对话自动迭代）
3.  停止迭代        # 关闭自动进化，保留当前迭代状态
4.  查看迭代规则    # 查看当前生效的行为规则（迭代后自动更新）
5.  清空迭代        # 重置所有迭代数据，恢复初始状态
6.  查看迭代评分    # 查看所有迭代版本的评分、时间和说明
7.  强制优化代码    # 手动触发二次代码优化（解决评分低/代码异常）

三、注意事项
1.  首次运行会自动备份原始代码，优化失败会自动恢复，避免Skill崩溃
2.  迭代评分<6分时，系统会自动触发二次优化，确保迭代质量
3.  自动迭代开启后，每3秒检测一次对话次数，每20轮触发一次迭代
4.  所有迭代规则会注入系统提示，后续对话严格遵守，无需额外设置
5.  若出现代码异常，可输入「强制优化代码」或「清空迭代」恢复
