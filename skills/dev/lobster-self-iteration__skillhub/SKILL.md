# 自我迭代Skill
## 版本：v1.0
## 核心定位：让智能体实现真正的自我迭代，越用越强

---

## 一、Skill概述
本Skill整合**规则迭代、代码自动修改、闭环自动迭代、迭代评分**四大核心能力，无需人工干预代码修改和规则配置，实现从对话复盘→问题发现→优化升级→规则生效的全闭环，让龙虾智能体在使用过程中持续进化，适配更多场景需求。

### 核心优势
1.  全自动化：无需人工修改代码、配置规则，迭代过程全自动完成
2.  稳定性强：内置代码备份、容错机制，优化失败自动恢复，避免Skill崩溃
3.  可干预性：支持手动触发迭代、优化代码、查看评分，兼顾自动化与手动控制
4.  效果可见：迭代评分系统实时反馈进化质量，评分历史可追溯

---

## 二、核心功能详细说明
### 1. 规则迭代（基础核心）
- 触发方式：手动执行「龙虾迭代」、自动迭代触发
- 功能逻辑：每次迭代会读取最近15轮对话，分析优点、问题，生成3-6条新行为规则
- 生效机制：新规则自动存入记忆，通过beforeChat钩子注入系统提示，后续所有对话严格遵守
- 查看方式：输入「查看迭代规则」，可查看当前生效规则及对应迭代版本

### 2. 代码自动修改（进阶核心）
- 触发方式：每次迭代自动触发、手动输入「强制优化代码」触发
- 功能逻辑：AI读取自身Skill代码，生成可直接替换的优化代码片段，自动定位替换对应函数，不破坏核心配置
- 安全机制：首次运行自动备份原始代码，优化失败自动恢复备份，避免代码异常
- 优化重点：修复语法错误、简化冗余逻辑、提升运行稳定性，不改变原有核心功能

### 3. 闭环自动迭代（自动化核心）
- 触发方式：输入「持续迭代」开启，「停止迭代」关闭
- 运行规则：每3秒检测一次对话次数，每20轮对话自动执行一次完整迭代（复盘→评分→优化→生效）
- 运行状态：开启后后台持续运行，不影响正常对话，可随时手动停止

### 4. 迭代评分系统（质量保障）
- 评分逻辑：每次迭代由AI按「规则合理性、代码优化实用性」打1-10分，标注评分说明
- 二次优化：评分<6分时，系统自动触发二次优化，确保迭代质量不达标时及时修正
- 历史查询：输入「查看迭代评分」，可查看所有迭代版本的评分、时间、评分说明，清晰掌握进化效果

## 三、完整指令清单（含使用场景）
| 指令名称       | 触发输入       | 功能说明                                  | 使用场景                                  |
|----------------|----------------|-------------------------------------------|-------------------------------------------|
| 手动迭代       | 龙虾迭代       | 手动执行一次完整迭代（规则+代码+评分）    | 需立即优化龙虾表现时                      |
| 开启自动迭代   | 持续迭代       | 开启每20轮对话自动迭代                    | 长期使用，希望龙虾持续进化时              |
| 关闭自动迭代   | 停止迭代       | 关闭自动迭代，保留当前迭代状态            | 无需持续迭代，避免资源占用时              |
| 查看规则       | 查看迭代规则   | 查看当前生效的行为规则及迭代版本          | 想了解龙虾当前遵守的迭代规则时            |
| 重置迭代       | 清空迭代       | 重置所有迭代数据，恢复初始状态            | 迭代出现异常，需重新开始进化时            |
| 查看评分       | 查看迭代评分   | 查看所有迭代版本的评分历史                | 想了解龙虾进化质量、跟踪优化效果时        |
| 强制优化       | 强制优化代码   | 手动触发二次代码优化                      | 代码异常、评分过低，需手动修正时          |
