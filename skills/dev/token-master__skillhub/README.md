# Token-Efficient Dev

> 企业级 AI 编程 Token 成本控制规范

## 一句话说明

在 AI 辅助开发、调试、重构、审查时，自动执行 Token 节流协议：**功能不变、质量不降、冗余清零、Token 减半**。

## 你为什么需要它

- **上下文窗口紧张**：大项目里 AI 动辄加载一堆无关文件，有效上下文被浪费
- **重复输出严重**：多轮调试时，AI 不断复述已经确认过的代码和方案
- **ROI 不清晰**：花了大量 Token，得到的却是冗余解释和过度实现
- **返工成本高**：缺乏前置方案确认，导致反复修改、多次重写

本 Skill 会在这些场景自动介入，让 AI 只读取必要上下文、只输出最小有效改动、只说用户真正需要的信息。

## 核心能力

### 1. 输入节流
- 精准限定读取范围，不加载无关文件
- 清理历史对话，只保留需求原文、已确认方案、关键约束
- 按需启用工具，不唤醒无关集成和知识库

### 2. 输出节流
- **Diff 优先**：小改动只输出 Diff，不输出完整文件
- **续写不重复**：分段生成时直接接续，不复述前文
- **最小可行实现**：不引入未指定的抽象、工具类、扩展接口
- **精简说明**：只保留根因 + 修复方案

### 3. 流程管控
- 复杂任务先输出极简大纲，确认后再编码
- 子 Agent 并行数上限 3 个
- 单次关键校验，避免反复全量重审

## 适用场景

✅ 编写、修改、调试、重构、审查代码  
✅ 多模块开发、复杂重构、新增功能  
✅ 上下文窗口紧张、重复输出风险高的任务  

❌ 大量教学讲解  
❌ 长文档创作  
❌ 非代码类创意任务  

## 使用方式

Skill 被调用后自动生效，无需手动配置。你只需正常描述开发需求，AI 会按照以下协议执行：

1. **先问清边界**（复杂任务）：输出极简执行大纲，等你确认
2. **只读必要上下文**：不加载无关文件
3. **Diff 优先输出**：小改动只给改动部分
4. **自检后交付**：通过质量门才返回结果

> 同样的逻辑、同样的质量、更少的 Token、更高的 ROI。

本 Skill 不牺牲代码正确性和可维护性，只压缩无效上下文和冗余表达。
