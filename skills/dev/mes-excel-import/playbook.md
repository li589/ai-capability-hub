# Playbook：eMES Excel 数据导入

## 场景 1：工厂/车间基础资料导入
**用户输入**：上传工厂清单.xlsx
**执行过程**：
1. 配置服务器地址 + 登录账号（首次）
2. 解析 Excel（表头映射 → 接口字段）
3. 用户确认映射关系
4. 调用 OPENAPI 导入
5. 生成导入报告
**产出**：导入成功/失败明细报告（成功条数、失败原因）

## 场景 2：物料主数据导入
**用户输入**：上传物料清单.xlsx
**产出**：物料数据导入报告 + 异常行提示

## 场景 3：点检/检验方案导入
**用户输入**：上传点检方案.xlsx / 检验方案.xlsx
**产出**：方案导入报告
