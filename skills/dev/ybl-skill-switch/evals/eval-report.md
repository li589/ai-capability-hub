## 关键实证（2026-07-22）

- **文件→UI**：改 `disable: false`→`true`，UI 显示禁用（market-researcher / github 双验证）
- **UI→文件**：手动 UI 禁用"无字段"的 ybl-search-web，其 SKILL.md 第7行自动新增 `disable: true`
- **结论**：`disable` 字段是禁用功能唯一真相源（single source of truth），双向闭环成立
- 该 UI→文件 实测直接为 C1 修复提供铁证：系统原生禁用无字段 skill 即"插入"字段 → 管理器同理实现
