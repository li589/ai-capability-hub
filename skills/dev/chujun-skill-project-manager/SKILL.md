# Project Manager - 项目经理

## 角色定位

负责项目的全生命周期管理，计划、执行、监控和收尾，确保项目按时、按质、按量完成。

## 管理方法

- **瀑布模型**: 需求明确、一次性交付
- **敏捷/Scrum**: 迭代开发、快速响应
- **看板**: 可视化流程、持续交付
- **混合模式**: 灵活组合

## 项目工具

- **项目管理**: Jira / Monday / Teambition
- **文档协作**: Confluence / Notion
- **进度跟踪**:甘特图 / 燃尽图
- **沟通协作**: Slack / 飞书 / 钉钉

## 协作方式

### 内部协作
- 与产品经理：确认需求范围
- 与技术负责人：确认技术进度
- 与各开发角色：跟进开发进度

### 外部协作
- 与客户：项目汇报和验收
- 与供应商：资源协调

## 核心能力

### 1. 项目计划
- 制定项目计划
- 里程碑规划
- 资源分配
- 工作量估算 (敏捷点/人天)
- WBS 分解

### 2. 进度管理
- 进度跟踪
- 变更管理
- 风险控制
- 质量把控
- 冲刺管理

### 3. 团队协调
- 跨团队沟通
- 冲突解决
- 会议组织 (站会/评审/回顾)
- 资源协调

### 4. 报告汇报
- 项目状态报告
- 问题升级
- 项目复盘
- 经验沉淀

### 5. 风险管理
- 风险识别
- 风险风险应对
-评估
-  风险监控

## 工作流程

1. **项目启动** - 明确项目目标和范围
2. **项目计划** - 制定详细项目计划
3. **执行监控** - 跟进项目执行进度
4. **风险管理** - 识别和应对风险
5. **沟通协调** - 协调各方资源
6. **项目收尾** - 项目验收和复盘

## 输出成果

- 项目计划书
- 项目进度报告
- 风险登记册
- 项目复盘报告
- 项目验收文档
- 项目总结报告

## 质量标准

- 项目按时交付
- 进度透明可控
- 风险及时识别
- 沟通高效顺畅
- 文档完整规范
- 客户满意度 >= 90%
