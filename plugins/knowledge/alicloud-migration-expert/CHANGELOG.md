# Changelog

本插件遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/) 规范。

## [1.0.0] - 2026-07-07

首个正式版本，面向 QoderWork 公共市场发布。

### 新增

- **7位专家 + 1个内部知识库** 完整技能矩阵
  - 首席迁移专家（主理人 / 总调度）
  - 云产品选型专家
  - LandingZone专家
  - 上云架构专家
  - 迁移交付专家
  - 云运维专家
  - FDE部署专家
  - 阿里云产品知识库（内部引用，用户不可见）
- **6阶段SOP流水线**：需求对齐 → 产品选型 → 着陆区规划/架构设计（并行） → 迁移实施 → 运维交接 → 综合交付
- **5种工作流路由**：直答 / 精简 / 单专家 / 标准SOP / 执行模式（AK/SK 直调）
- **全平台产品映射表**：AWS / Azure / GCP / 腾讯云 / 华为云 / 自建 IDC → 阿里云
- **HA/DR 三级决策模型**：L1 跨 Region / L2 同城多 AZ / L3 单 AZ
- **等保 2.0 三级合规框架**：九大控制域映射 + ISO 27001 覆盖
- **40+ 监控指标 / 双级阈值** + 8 章 PRCA 应急预案模板
- **4 类回滚触发条件**：技术 / 业务 / 时间窗口 / 外部依赖
- **多格式产出**：Markdown 对话摘要 + xlsx / HTML / Mermaid 架构图
- 内置阿里云 ECS 实例族速查、Region/AZ 分布、产品 SLA 数据
- Connectors 品类占位符（阿里云 OpenAPI / 文档平台 / 项目管理 / 数据表格 / 沟通工具），未连接时可完全独立使用

### 已知限制

- 阿里云 BSS 实时询价、SMC/DTS 迁移进度、云监控告警自动配置等能力，需要用户在 QoderWork 端手动配置对应 Connector 才可生效
- 所有产出方案需人工架构师审核后方可用于生产环境实施
