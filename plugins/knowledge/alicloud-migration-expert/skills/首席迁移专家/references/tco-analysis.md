# TCO对比分析模板

本模板用于Phase 6综合交付阶段，主理人汇总各阶段数据，完成源平台与阿里云的TCO（总拥有成本）对比分析。

---

## 1. 计算模型

### 核心公式

```
TCO = 一次性投入 + N × 年度运营成本

一次性投入 = 迁移工具费用 + 迁移人力成本 + 数据传出费用 + 并行运行费用
年度运营成本 = 计算资源年费 + 存储资源年费 + 网络带宽年费 + 许可费用年费 + 运维人力年费
```

### 默认参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 对比周期N | 3年 | 用户可自定义 |
| 折扣率 | 按阿里云官网折扣 | 包年包月通常有折扣 |
| 通胀率 | 0% | 保守计算不计入 |
