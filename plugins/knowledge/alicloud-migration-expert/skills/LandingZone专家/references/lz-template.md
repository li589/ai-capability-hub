# Landing Zone模板（Landing Zone Template）

## 文档说明

本文档定义了Landing Zone xlsx文件的13个Sheet的详细结构、字段定义和填写指导。每个Sheet的设计均遵循阿里云最佳实践和企业级治理要求。

---

## Sheet 1: 账号体系

### 字段定义

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 账号ID | 文本 | 自动生成 | 阿里云账号UID |
| 账号名称 | 文本 | 是 | 格式：{公司缩写}-{用途}-{环境}，如 acme-workload-prod |
| 账号类型 | 枚举 | 是 | 主账号/控制/日志/安全/财务/网络/运维/业务 |
| OU归属 | 文本 | 是 | 资源目录下的组织单元路径 |
| 职责描述 | 文本 | 是 | 该账号承担的核心职责 |
| 管辖资源范围 | 文本 | 是 | 该账号下允许部署的资源类型 |
| 管理员 | 文本 | 是 | 账号管理负责人 |
| 备注 | 文本 | 否 | 补充说明 |

### 填写指导

- 主账号仅用于组织管理和计费，不部署任何业务资源
- 业务账号按环境隔离：prod（生产）、staging（预发）、dev（开发）、test（测试）
- 每个OU下的账号数量建议不超过20个，超过时需拆分OU
- 账号名称必须全局唯一且遵循命名规范

## Sheet 2: RAM用户组与策略

### 字段定义

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 用户组名 | 文本 | 是 | 英文命名，如 Admin、Dev、Ops |
| 职责描述 | 文本 | 是 | 用户组的职责范围 |
| 适用账号 | 文本 | 是 | 该用户组在哪些账号下生效 |
| 系统策略 | 文本列表 | 是 | 绑定的系统策略列表 |
| 自定义策略 | 文本列表 | 否 | 绑定的自定义策略列表 |
| 权限边界 | 文本 | 否 | 权限边界策略（如有） |
| MFA要求 | 枚举 | 是 | 强制/推荐/不要求 |
| 会话时长 | 数值 | 是 | 登录会话最大时长（小时） |

### 填写指导

- Admin用户组必须启用权限边界策略，限制其不能删除核心安全配置
- 所有管理类用户组（Admin/Ops/Network/Security）必须强制MFA
- 开发和测试用户组通过标签条件限制只能操作对应环境的资源
- 审计用户组使用ReadOnlyAccess，不授予任何写权限

## Sheet 3: VPC与网络规划

### 字段定义

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| VPC名称 | 文本 | 是 | 格式：vpc-{业务}-{环境}-{region} |
| Region | 文本 | 是 | 所在Region，如 cn-hangzhou |
| AZ列表 | 文本列表 | 是 | 可用区列表，如 cn-hangzhou-h, cn-hangzhou-i |
| VPC CIDR | CIDR | 是 | VPC主CIDR，如 10.1.0.0/16 |
| 辅助CIDR | CIDR列表 | 否 | 辅助CIDR块（扩展用） |
| 子网列表 | 子表 | 是 | 每个子网的CIDR、用途、AZ |
| 路由表规则 | 子表 | 否 | 自定义路由规则 |
| CEN接入 | 布尔 | 是 | 是否接入CEN云企业网 |
| NAT网关 | 枚举 | 是 | 不需要/共享型/增强型 |
| 备注 | 文本 | 否 | 补充说明 |

### 子网子表字段

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 子网名称 | 文本 | 是 | 格式：subnet-{用途}-{az} |
| CIDR | CIDR | 是 | 子网CIDR |
| AZ | 文本 | 是 | 所在可用区 |
| 用途 | 枚举 | 是 | App/DB/Mgmt/DMZ |
| 关联路由表 | 文本 | 否 | 绑定的路由表名称 |

### CIDR分配逻辑

1. 确定VPC总数和最大规模
2. 从10.0.0.0/8中选择VPC级别的/16分配
3. 每个VPC内按AZ和用途进一步划分子网
4. 应用子网使用/22（1022个IP），数据库子网使用/24（254个IP）
5. 管理子网使用/24，DMZ子网使用/26
6. 记录所有CIDR分配，确保无重叠

## Sheet 4: 标签体系

### 字段定义

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 标签键 | 文本 | 是 | 标签Key，如 env、project |
| 值域范围 | 文本列表 | 是 | 允许的值列表 |
| 必填/选填 | 枚举 | 是 | 必填/选填 |
| 适用资源类型 | 文本列表 | 是 | ECS/RDS/OSS/SLB/VPC等 |
| 用途说明 | 文本 | 是 | 该标签的用途 |
| 合规关联 | 文本 | 否 | 关联的合规要求 |

### 填写指导

- 标签键统一使用小写英文+连字符格式
- 必填标签建议控制在5-7个，过多会影响资源创建效率
- env标签的值域固定为 prod/staging/dev/test/sandbox
- 通过标签策略（Tag Policy）自动校验新建资源的标签合规性

## Sheet 9-13: 迁移模式专属Sheet

以下Sheet仅在migration（迁移）模式下生成：

### Sheet 9: 源端资源清单

从源端环境解析得到的资源列表，包括VPC、ECS、RDS等所有关键资源。

### Sheet 10: VPC映射

源VPC到目标VPC的映射关系，每个源VPC必须有一条映射记录，决策列可选值为：迁移、弃用、合并。

### Sheet 11: 子网映射

源子网到目标子网的CIDR对照表，记录每个子网的用途变更说明。

### Sheet 12: CIDR冲突报告

检测源端与目标端CIDR重叠的情况，列出冲突项和处置建议（重新分配/使用NAT/使用代理）。

### Sheet 13: 迁移优先级排序

基于业务依赖关系分析，建议的迁移批次排序，包含优先级评分（1-100）和批次分组。
