# 六阶段迁移计划模板

> 本文档为迁移交付专家的补充参考，提供各层资源的详细迁移阶段检查清单和时间甘特图结构。

---

## 1. 阶段总览

```
┌─────────┐  ┌──────────┐  ┌────────────┐  ┌──────┐  ┌──────┐  ┌────────┐
│ 摸底评估 │→│ 预建目标端 │→│ 数据/配置同步 │→│ 验证  │→│ 割接  │→│ 回滚预案 │
│ Phase 1  │  │ Phase 2   │  │  Phase 3    │  │ Ph.4 │  │ Ph.5 │  │  Ph.6  │
│ 1-2周     │  │ 1-2周     │  │  1-4周      │  │ 1周  │  │ 1天  │  │ 贯穿全程│
└─────────┘  └──────────┘  └────────────┘  └──────┘  └──────┘  └────────┘
```

## 2. 各阶段详细检查清单

### 阶段1：摸底评估（1-2周）

**目标**：全面了解源端现状，识别迁移风险与依赖关系。

#### 网络层检查清单

- [ ] 盘点源端网络拓扑（VPC/子网/路由表/安全组）
- [ ] 记录源端专线/VPN配置与带宽
- [ ] 梳理跨VPC/跨地域通信需求
- [ ] 记录安全组规则数量与复杂度
- [ ] 评估公网IP/NAT网关/EIP使用情况
- [ ] 确认源端DNS解析记录清单

#### 计算层检查清单

- [ ] 盘点ECS实例规格、数量、操作系统版本
- [ ] 记录ECS自定义镜像清单
- [ ] 盘点ACK集群配置（节点池/Pod规格）
- [ ] 记录函数计算FC函数清单与触发器配置
- [ ] 评估应用启动时间与依赖服务

#### 存储层检查清单

- [ ] 盘点ESSD云盘规格与使用量（已用/总量）
- [ ] 盘点OSS Bucket清单与存储量
- [ ] 盘点NAS文件系统与挂载点
- [ ] 评估数据增长率（日增量/周增量）
- [ ] 记录快照策略与备份计划

#### 数据库层检查清单

- [ ] 盘点RDS实例规格、引擎版本、参数配置
- [ ] 记录数据库账号与权限矩阵
- [ ] 盘点Redis实例规格与内存使用率
- [ ] 盘点MongoDB副本集/分片集群配置
- [ ] 评估数据库连接数峰值与慢查询统计
- [ ] 记录存储过程/触发器/定时任务清单

#### 中间件层检查清单

- [ ] 盘点Kafka/RocketMQ Topic与消费组
- [ ] 盘点Nacos配置中心命名空间与配置项
- [ ] 盘点Elasticsearch集群索引与分片
- [ ] 记录消息队列积压量基线

#### 应用层检查清单

- [ ] 梳理应用配置项（连接串/密钥/白名单）
- [ ] 记录应用间调用关系图
- [ ] 盘点定时任务与批处理作业
- [ ] 评估应用对IP/域名的硬编码情况

---

### 阶段2：预建目标端（1-2周）

**目标**：在阿里云创建所有目标资源，确保基础设施就绪。

- [ ] 创建目标VPC/子网/路由表（与源端网段不冲突）
- [ ] 配置安全组规则（迁移源端规则）
- [ ] 建立专线/VPN/云企业网连通
- [ ] 创建目标ECS实例（规格映射确认）
- [ ] 创建目标RDS/Redis/MongoDB实例
- [ ] 创建目标OSS Bucket / NAS文件系统
- [ ] 创建目标中间件实例
- [ ] 配置RAM子账号与权限策略
- [ ] 配置云监控告警策略（迁移阶段基础告警）

**关键产出**：目标端资源清单表（实例ID + 内网IP + 规格 + 状态）

---

### 阶段3：数据/配置同步（1-4周）

**目标**：将源端数据完整同步至目标端，保持增量追平。

#### 网络层

- [ ] 同步安全组规则至目标端
- [ ] 验证专线/VPN连通性与带宽
- [ ] 测试跨VPC通信

#### 数据库层

- [ ] 创建DTS迁移任务（全量+增量）
- [ ] 启动全量数据迁移
- [ ] 全量完成后确认增量追平
- [ ] 同步RDS参数组配置
- [ ] 同步数据库账号与权限
- [ ] 同步白名单配置

#### 存储层

- [ ] 使用ossimport/rsync同步OSS数据
- [ ] 使用rsync同步NAS文件系统
- [ ] 创建ESSD快照并恢复到目标端

#### 中间件层

- [ ] 同步Kafka/RocketMQ Topic与消费组配置
- [ ] 同步Nacos配置项
- [ ] 同步ES索引模板与映射

---

### 阶段4：验证（1周）

**目标**：确认目标端数据完整性与功能正确性。

- [ ] 数据行数对比（源端 vs 目标端所有表）
- [ ] Checksum校验（核心表100% + 非核心表抽样20%）
- [ ] 应用联调测试（核心链路端到端）
- [ ] 读写功能验证（CRUD全场景）
- [ ] 性能基准测试（目标端 vs 源端对比）
- [ ] 安全验证（账号权限/白名单/加密）
- [ ] 灾备验证（主备切换/故障切换）

**关键产出**：验证报告（通过/不通过 + 问题清单）

---

### 阶段5：割接（1天）

**目标**：在割接窗口内完成流量切换。

详细步骤参见「割接步骤手册」，此处仅列关键检查点：

- [ ] 确认DTS增量延迟 < 5s
- [ ] 确认数据校验报告全部通过
- [ ] 确认所有参与人员就位
- [ ] 执行停止源端写入
- [ ] 执行最终数据一致性确认
- [ ] 执行连接串/DNS切换
- [ ] 执行灰度验证（10% → 50% → 100%）
- [ ] 确认全量切换成功
- [ ] 通知相关方割接完成

---

### 阶段6：回滚预案（贯穿全程）

**目标**：确保任何阶段出现问题都可以安全回滚。

- [ ] 各层回滚步骤已编写并评审
- [ ] 回滚触发条件已定义（4类）
- [ ] 回滚决策人已确认
- [ ] 回滚演练已完成（至少桌面推演1次）
- [ ] 源端资源保留策略已确认（≥7天）
- [ ] DNS TTL已预设为60s

## 4. 里程碑与交付物

| 里程碑 | 时间点 | 交付物 | 评审方 |
|--------|--------|--------|--------|
| M1: 摸底完成 | 阶段1结束 | 资源盘点报告 + 风险评估 | SA + 客户 |
| M2: 环境就绪 | 阶段2结束 | 目标端资源清单 + 连通性测试 | FDE + 迁移工程师 |
| M3: 同步完成 | 阶段3结束 | DTS同步状态 + 增量延迟报告 | 迁移工程师 |
| M4: 验证通过 | 阶段4结束 | 验证报告（数据+功能+性能） | QA + 客户 |
| M5: 割接完成 | 阶段5结束 | 割接执行记录 + 监控截图 | 项目经理 + 客户 |
| M6: 项目收尾 | 割接后7天 | 复盘报告 + 源端释放确认 | 项目经理 + Ops |

## 5. 风险登记模板

| 风险ID | 风险描述 | 影响层 | 概率 | 影响 | 缓解措施 | 负责人 |
|--------|----------|--------|------|------|----------|--------|
| R-01 | DTS增量同步延迟过高 | 数据库 | 中 | 高 | 提前启动同步，预留缓冲时间 | 迁移工程师 |
| R-02 | 割接窗口不足 | 全局 | 中 | 高 | 精简割接步骤，预演多次 | 项目经理 |

| R-04 | 网络连通性故障 | 网络 | 低 | 高 | 双通道冗余（专线+VPN） | 网络工程师 |
