# 阿里云上云迁移专家团

7 位 AI 专家协作完成阿里云上云迁移全流程：需求对齐、产品选型与映射、着陆区规划、目标架构设计、迁移实施、运维交接与 FDE 前置部署。内置 6 阶段 SOP 流水线、全平台产品映射表（AWS/Azure/GCP/腾讯云/华为云/自建 IDC → 阿里云）、HA/DR 三级决策模型、等保 2.0 三级合规框架、40+ 监控指标体系、4 类回滚触发条件和 8 章 PRCA 应急预案模板。支持对话中 Markdown 快速摘要 + 正式文档（xlsx/HTML/Mermaid 架构图）双格式输出。

> **免责声明：** 本插件辅助专业迁移决策，不替代人工评审。所有产出方案应由具备阿里云迁移经验的架构师审核后方可用于生产环境实施。

## 适用角色

- **云迁移架构师** — 快速生成目标架构方案、HA/DR 矩阵和 Mermaid 拓扑图，内置阿里云产品 SLA 数据
- **售前/解决方案工程师** — 一键产出产品映射表 + TCO 对比分析 + 完整迁移方案，用于客户汇报
- **迁移交付工程师** — 获取六层迁移分项方案、割接步骤手册和回滚触发条件清单
- **运维工程师** — 生成监控告警配置清单（40+ 指标）、应急预案和巡检 SOP
- **项目经理** — 通过 6 阶段 SOP 自动编排，每阶段有明确产出物和时间排期

## 快速命令

| 命令 | 说明 |
|------|------|
| `@首席迁移专家` | 主理人入口：描述迁移需求，自动路由到合适的工作流（直答/精简/完整 SOP） |
| `@云产品选型专家` | 上传源平台资源清单，生成阿里云产品映射表 + 成本估算 |
| `@LandingZone专家` | 描述组织结构和合规要求，生成 Landing Zone 规划（13 sheet xlsx） |
| `@上云架构专家` | 提供业务需求和性能基线，生成目标架构 + HA/DR 矩阵 + Mermaid 图 |
| `@迁移交付专家` | 提供架构方案，生成六层迁移计划 + 割接步骤 + 回滚预案 |
| `@云运维专家` | 提供迁移后资源清单，生成监控告警 + 应急预案 + 巡检 SOP |
| `@FDE部署专家` | 提供着陆区方案，生成 FDE 环境部署方案 + 自检清单 |

## 技能详情

| 技能 | 详细说明 |
|------|---------|
| 首席迁移专家 | 主理人/总调度：4 维度需求对齐（范围/约束/架构/团队）、5 种工作流路由、6 阶段 SOP 编排、跨专家上下文传递、Phase 6 TCO 汇总 |
| 云产品选型专家 | 4 级输入优先级（AK/SK > Excel > 架构图 > 截图）、5 层输出结构、全平台映射、3 层成本估算、阿里云定价 API 实时询价 |
| LandingZone专家 | 13 sheet xlsx 标准输出（RAM/VPC/标签/安全基线/合规/成本/路线图）、等保 2.0 三级九大控制域映射、ISO 27001 覆盖 |
| 上云架构专家 | 8 项必备输入、5 类产出物、HA 三级模型（L1 跨 Region/L2 同城多 AZ/L3 单 AZ）、阿里云产品 SLA 数据、Mermaid 拓扑图 |
| 迁移交付专家 | 「资源类型 × 迁移阶段」双轴交叉（6 层 × 6 阶段）、4 类回滚触发条件（技术/业务/时间窗口/外部依赖）、甘特图排期 |
| 云运维专家 | 5 大类 40+ 监控指标（双级阈值）、8 章 PRCA 应急预案、日/周/月巡检 SOP、迁移阶段特别关注指标、培训方案 |
| FDE部署专家 | FDE 6 类部署组件（网络/资源/工具链/权限/监控/文档）、FDE vs Ops 职责边界、环境自检 33 项 checklist |
| 阿里云产品知识库 | 内部知识库（用户不可见）：ECS 实例族速查、Region/AZ 分布、产品 SLA、BSS OpenAPI 定价调用方法、迁移工具矩阵 |
