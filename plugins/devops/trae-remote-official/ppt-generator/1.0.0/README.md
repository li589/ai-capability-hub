# PPT Generator

这是一个 TRAE Plugin，用于根据用户提供的文档、图片、链接或文字需求，生成精美的单文件 HTML 演示文稿。

中文展示名称：**高质量 PPT**

## 能力

- 规划演示文稿的叙事结构与页面节奏
- 从内置布局库中选择适合的版式
- 使用多套风格规范完成视觉设计
- 为图片搜索、生成与排版提供完整流程
- 最终输出可直接打开的单文件 HTML 演示文稿

## 使用

安装插件后，可直接提出类似需求：

- “帮我做一份关于某主题的 PPT。”
- “把这个文档整理成一份演示文稿。”
- “使用某种风格生成一份单文件 HTML 幻灯片。”

本插件不包含 MCP Server、Connector、外部依赖或凭据。
