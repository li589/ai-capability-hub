# 估值表 Excel 规范（表结构 · 视觉 · 质控）

---

## 一、公式规范

1. 所有派生值写为引用输入单元格的 Excel 公式，禁止硬编码计算结果。
2. openpyxl 生成时写 `cell.value = "=E7/C7"`，禁止写 `cell.value = 0.687`。
3. 唯一允许硬编码的为原始输入数据（营收、净利、股价等）；每个硬编码值加批注注明来源。
4. 公式使用相对引用或混合引用，禁止循环生成时绝对引用导致区间锁死。
5. 分母可能为零或负数时，用 `=IFERROR()` 或 `=IF()` 包裹，输出 "N/A"。
6. 同一工作表中同一原始数据禁止重复录入；后续引用指向首次录入单元格。

## 二、表结构与视觉规范

### 表头区（第 1–3 行）

```
第1行：[分析标题] · 可比公司估值表
第2行：[公司名(代码)] • [公司名(代码)] • …
第3行：截至 [日期] | 单位：人民币亿元(A股) / 港币亿元(港股)，每股与比率除外
```

- 标题分隔符使用全角间隔号 `·`（U+00B7）。
- A股+港股混排时在第3行注明汇率与取值日期。

### 视觉默认

优先级：用户明示格式 > 上传模板 > 团队规范 > 本默认。

| 项目 | 默认值 |
|------|--------|
| 字体 | 宋体 / Times New Roman；数据 11pt、表头 12pt |
| 加粗 | 区块标题、公司名、统计标签 |
| 区块标题行 | 深蓝底 `#17365D` + 白色加粗字，整行铺满 |
| 列表头 | 浅蓝底 `#D9E1F2` + 黑色加粗字，居中 |
| 数据行 | 白底；公式黑字，硬编码输入蓝字 |
| 统计行 | 浅灰底 `#F2F2F2` + 黑字，标签左对齐 |

配色限定：全表仅用深蓝、浅蓝、浅灰、白四色。模板另有规定时从模板。

精度约定：

| 类型 | 格式 | 示例 |
|------|------|------|
| 百分比 | 1 位小数 | 12.3% |
| 倍数 | 1 位小数 | 13.5x |
| 金额 | 无小数、千分位 | 69,632 |

无边框、居中、列宽行高统一。

### 数值格式代码（openpyxl number_format）

| 数据类型 | 格式代码 |
|----------|----------|
| 百分比 | `'0.0%'` |
| 倍数 | `'0.0"x"'` |
| 金额（亿元） | `'#,##0'` |
| 每股数据 | `'0.00'` |
| 增速 | `'0.0%'` |

## 四、构建流程

### 执行步骤

1. **搭结构** — 建表头，定单位与日期，约定颜色。
2. **取数** — 按 TDX 工具路由表拉取；原始数据录入蓝字，来源写入批注。
3. **建公式** — 先计算比率，再计算倍数，再常识校验。
4. **加统计** — 复制统计公式到各列，核对区间范围。
5. **质控** — 常识校验、验公式引用、查错误值、对标基准。
6. **补文档** — 批注、来源、方法、日期戳。

### 批注规范

每个蓝字输入单元格加批注，格式二选一：

- **有来源**：`TDX 返回，贵州茅台600519 营收，查询日 2026-07-22` / `2025 年报，巨潮资讯，第 65 页` / `卖方一致预期目标价均值，TDX 返回`
- **是假设**：`毛利率按同业中位数假设 45%，公司未披露分部` / `预测 EPS 采用 TDX 一致预期 T+1 均值`

禁止模糊批注如"来自网络""数据来源不详"。

### 常识校验规则

| 校验项 | 正常范围 |
|--------|----------|
| 利润率序 | 毛利率 > EBITDA 利润率 > 净利率 |
| EV/Revenue | 0.5–20x |
| EV/EBITDA | 8–25x |
| PE | 10–50x（随增速浮动） |
| 增速-倍数关系 | 高增速对应高倍数 |
| ROE-PB 关系 | 高 ROE 对应高 PB |
| 股息率-PE 关系 | 高股息率通常对应低 PE |

### 常见错误

| 错误 | 后果 |
|------|------|
| 混用市值与企业价值 | 倍数计算错误 |
| 分子分母用不同期间 | 指标无意义 |
| 硬编码派生值 | 输入变更时静默失效 |
| 硬编码输入无批注 | 无法追溯来源 |
| 纳入商业模式不同的公司 | 伪可比 |
| 对百分比取算术平均 | 应使用中位数 |
| 使用过期数据未披露 | 误导判断 |
| PE 取负值未标注 | 亏损公司混入有效统计 |
| 混淆 TTM 与年报数据 | 时间口径不一致 |

## 五、Sanity Check 清单

### 5.1 取数阶段

| # | 检查项 | 通过标准 | 不通过处理 |
|---|--------|----------|------------|
| 1 | 报告期一致性 | 所有公司取自同一报告期 | 禁止混用；前期数据须批注时滞 |
| 2 | 币种一致性 | 统一币种或已按明示汇率换算 | 表头注明汇率及取值日期 |
| 3 | 年报 vs 快报 | 优先经审计年报 | 快报加批注 `[未审计]` |
| 4 | TTM vs 年度口径 | TTM 须四季完整 | 不完整时降级年报口径并注明 |
| 5 | 数据源一致性 | 同一指标所有公司取自相同源 | 禁止跨源混用（无覆盖除外） |
| 6 | 市值基准日 | 同一交易日收盘价 | 禁止不同日期混用 |

### 5.2 建公式阶段

| # | 检查项 | 通过标准 | 不通过处理 |
|---|--------|----------|------------|
| 1 | 利润率序关系 | 毛利率 > EBITDA > 营业利润率 > 净利率 | 违反时检查录入或解释特殊原因 |
| 2 | 增速-倍数匹配 | 高增速→高 PE/PEG | 反向时批注解释 |
| 3 | ROE-PB 匹配 | 高 ROE→较高 PB | 显著偏离须解释 |
| 4 | 分子分母一致性 | 同一主体、同一口径 | 禁止合并/母公司混用 |
| 5 | 无循环引用 | openpyxl 写入后无 circular reference 警告 | 修正引用链 |
| 6 | 负值保护 | 所有除法有 IF/IFERROR 保护 | 补充容错包裹 |

### 5.3 统计阶段

| # | 检查项 | 通过标准 | 不通过处理 |
|---|--------|----------|------------|
| 1 | 样本量 | 有效公司数 ≥ 4 | < 4 时禁止四分位数，仅列中位数和极值 |
| 2 | 极端值影响 | 排除/保留异常值后中位数变动 < 15% | 变动 > 15% 时在报告中讨论 |
| 3 | 统计范围正确 | 仅含公司数据行，不含表头/空行/统计行自身 | 修正公式范围 |
| 4 | 排除值已标注 | 按异常值规范标注并灰显 | 补充标注 |
| 5 | 四分位数合理 | Q1 < Median < Q3 | 全等时说明样本同质性 |

### 5.4 最终签核

全部检查通过后，在工作表末尾或独立 Sheet 记录：

```
Sanity Check 完成日期: [YYYY-MM-DD]
执行版本: excel-methodology v2.0
数据截止日: [YYYY-MM-DD]
异常值处理: [已排除N个/已标注N个]
来源一致性: [已逐点标注来源]
```
