# 金融数据规范

## 一、源选择

以当前会话实际可用的金融 MCP 为准，不假设任何源一定在线。在线几个用几个，按覆盖特长分工取数。

| 数据域 | 首选源 | 备选 |
|--------|--------|------|
| 实时行情 / 量价 / 技术指标 | 通达信 | iFinD、东财 |
| 三表（利润 / 资产 / 现金流） | iFinD | 东财、dataSupplement |
| 一致预期 / 目标价 / 评级 | iFinD | 东财 |
| 龙虎榜 / 资金流 / 融资融券 | 东财 | dataSupplement |
| 行业 / 宏观 / 板块 | iFinD | WebSearch |
| 公告 / 新闻 | iFinD | 东财、WebSearch |

一个金融 MCP 都没检测到 → 告知用户 → 降级至 dataSupplement / WebSearch，逐点标来源。

---

## 二、数据字典（12 域）

每个域是一个"应当整取"的数据块，不要只取一两个字段。

| 域 | 核心字段 |
|----|---------|
| 1 行情 | 最新价、涨跌幅、开高低收、成交量/额、换手率、52周高低、总市值/流通市值 |
| 2 估值 | PE(TTM)、PB、PS、EV/EBITDA、股息率、PEG、**各指标近3-5年历史分位（必取）** |
| 3 利润表 | 营收、毛利、毛利率、三费、营业利润、归母净利、扣非净利、EPS、营收/净利同比增速 |
| 4 资产负债表 | 总资产、总负债、股东权益、货币资金、应收、存货、有息负债、资产负债率、流动/速动比率、商誉 |
| 5 现金流 | 经营/投资/筹资现金流净额、FCF、经营现金流/净利润、CapEx |
| 6 比率 | 盈利(ROE/ROA/ROIC/净利率)、成长(营收增速/净利增速/3年CAGR)、偿债(负债率/利息保障)、营运(周转率) |
| 7 资金筹码 | 主力净流入、北向持股、龙虎榜、融资融券、大宗交易 |
| 8 股东 | 前十大股东、机构持仓比例、股东户数变化、解禁、质押 |
| 9 分红股本 | 历史分红率、回购、增发/配股、股本变动 |
| 10 一致预期 | 未来1-3年营收/净利/EPS预期、目标价、评级分布、近期调整 |
| 11 公告新闻 | 定期报告、重大公告、业绩预告/快报、行业政策（标来源+日期） |
| 12 行业宏观 | 行业规模/增速、市占率、行业估值中位数、上下游价格、GDP/CPI/PMI |

## 三、分场景必取清单

任务开始前按清单一次性取全，缺项标 `[MISSING]`。

| 场景 | 最小数据集 |
|------|-----------|
| Step 2 行业全景 | 域12 + 域1(行业指数) + 域2(行业中位数) + 域6(成长对比) |
| Step 3 竞争格局 | 域3(营收/净利/毛利率) + 域6(四类比率) + 域1(市值) + 域2(PE/PB/EV) |
| Step 4 估值表 | 域2(全套+分位) + 域3(营收/净利/EBITDA) + 域10 + 域1(市值/EV) + 域6(ROE/增速) |
| Step 5 主题选股 | 域6(筛选) + 域2 + 域7 + 域1(动量) + 域10(增速) |

## 四、呈现规则

取回的数据怎么用：

| 规则 | 对 | 错 |
|------|----|----|
| 整块落表 | 取回 15 个字段，全部落表展示 | 取回 15 个字段，只提一个 PE=25x |
| 给多期 | 营收 2022/2023/2024/Q1'25 | 营收 358亿（只给最新一期） |
| 带增速 | 营收 358亿（+18% YoY） | 营收 358亿 |
| 带坐标 | PE 25x（72%分位，同业中位 18x） | PE 25x |
| 标缺失 | 一致预期缺 2026 年 `[MISSING]` | 直接跳过不提 |
| 标来源 | 数据来源：iFinD，截至 2025-07-25 | 无标注 |
| 分事实/预测 | 2024A 营收 vs 2025E 一致预期 | 混在一起不区分 |

禁止：
- 取回一堆只用两个
- 估值只给单值不给分位和同业对比
- 没源编数或假装数据不存在
- 连了多源只用一个不标注来源
