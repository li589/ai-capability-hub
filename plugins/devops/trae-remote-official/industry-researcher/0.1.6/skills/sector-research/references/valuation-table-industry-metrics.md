# 行业指标选择表

## 决策矩阵

| 研究问题 | 聚焦指标 | 略过 |
|---|---|---|
| 谁被低估 | PE、PB、PEG、市值、EV/EBITDA | 运营细节、增长指标 |
| 谁最高效 | 毛利率、净利率、FCF 利润率、资产周转 | 规模、绝对金额 |
| 谁增长最快 | 营收增速%、盈利 CAGR、量增 | 利润率、杠杆比率 |
| 谁最会造血 | FCF、FCF 利润率、FCF 转化率、资本开支强度 | EBITDA、PE |

## 分行业指标与公式

### 半导体/电子

| 维度 | 内容 |
|---|---|
| 必备 | 营收增速、毛利率、研发占比、PE(TTM) |
| 可选 | 产能利用率、国产替代率、在手订单、EV/EBITDA |
| 略过 | 存货周转（非重点时）、股息率 |
| 标杆倍数 | PE 30–80x；PB 4–12x |
| 异常阈值 | PE > 100x 且营收增速 < 30% 判定异常；毛利率 > 80% 需解释 |
| 合理范围 | 研发占比 10–25%；毛利率 30–60%；超出须批注说明 |
| 专用公式 | 国产替代率 = 国内设备采购额 / 总设备采购额；研发强度 = 研发费用 / 营收 |

### 新能源/制造

| 维度 | 内容 |
|---|---|
| 必备 | 净利率、ROE、资产周转率、市占率 |
| 可选 | ROA、出货/装机量、单位成本、EV/EBITDA |
| 略过 | 互联网/SaaS 类指标、研发占比（除电池材料外） |
| 标杆倍数 | PE 15–45x；PB 2–8x |
| 异常阈值 | PE > 60x 且 ROE < 10% 判定异常；净利率 > 25% 需解释 |
| 合理范围 | 资产周转率 0.5–1.5x；资产负债率 40–70%；超出须说明 |
| 专用公式 | 单瓦/单吨利润 = 净利润 / 出货量；产能利用率 = 实际产量 / 设计产能；资本开支强度 = 资本开支 / 营收；单位成本 = 营业成本 / 产量 |

### 银行/金融

| 维度 | 内容 |
|---|---|
| 必备 | ROE、ROA、净息差、PB |
| 可选 | 不良率、拨备覆盖率、核心一级资本充足率、信贷成本率 |
| 略过 | 毛利率、EBITDA、PE（银行不适用传统 PE） |
| 标杆倍数 | PB 0.4–1.2x；股息率 4–8% |
| 异常阈值 | PB > 1.5x 或 < 0.3x 需解释；ROE > 18% 需验证 |
| 合理范围 | ROE 8–15%；净息差 1.5–2.5%；不良率 0.8–2.0%；超出须解释 |
| 专用公式 | PB-ROE 回归估值（禁止使用 PE）；净息差 = 利息净收入 / 平均生息资产；信贷成本率 = 当期计提拨备 / 平均贷款余额；不良率 = 不良贷款余额 / 贷款总额；拨备覆盖率 = 贷款损失准备 / 不良贷款余额；拨贷比 = 贷款损失准备 / 贷款总额 |

### 消费/白酒

| 维度 | 内容 |
|---|---|
| 必备 | 营收增速、毛利率、净利率、PE(TTM) |
| 可选 | 吨价、预收款/合同负债、经销商数、PS |
| 略过 | 重研发/重资本开支类指标、EV/EBITDA |
| 标杆倍数 | PE 20–50x；PS 5–15x（高端白酒） |
| 异常阈值 | PE > 60x 且营收增速 < 15% 判定异常；毛利率 < 50%（白酒）需解释 |
| 合理范围 | 白酒毛利率 70–95%；净利率 25–50%；预收款环比降超 30% 需关注 |
| 专用公式 | 吨价 = 营收 / 销量(吨)；经销商回款指标 = 预收款变动额 / 当期营收；渠道效率 = 营收 / 经销商数量；合同负债覆盖率 = 合同负债 / 季度营收；费用率 = (销售费用 + 管理费用) / 营收 |

### 创新药/医药

| 维度 | 内容 |
|---|---|
| 必备 | 营收增速、研发投入、毛利率、PE(TTM) |
| 可选 | 管线数、临床阶段、License-out 收入、PS |
| 略过 | 早期无收入公司的资产周转率、股息率 |
| 标杆倍数 | PE 25–60x（已盈利）；PS 5–20x（未盈利用 PS） |
| 异常阈值 | PE > 80x 且管线均处于临床前需解释；研发占比 > 100%（烧钱期）单列处理 |
| 合理范围 | 研发占比 15–50%；毛利率 60–85%；净利率为负须标注亏损期 |
| 专用公式 | 研发回报率 = (营收 - 扣除研发后成本) / 累计研发投入；管线价值 = rNPV 模型（不在表内计算，附注引用） |

### 地产/物业

| 维度 | 内容 |
|---|---|
| 必备 | NAV 折价率、PB、合同销售额增速、净负债率 |
| 可选 | 土储面积、融资成本、物业在管面积、物业收缴率 |
| 略过 | PE（地产利润确认滞后，PE 失真）、研发占比 |
| 标杆倍数 | PB 0.3–1.0x（开发商）；PE 15–35x（物业） |
| 异常阈值 | PB > 1.5x 需解释；净负债率 > 100% 标注高杠杆风险 |
| 合理范围 | 净负债率 50–100%；开发商毛利率 15–30%；物业毛利率 25–40% |
| 专用公式 | NAV 折价率 = (NAV - 市值) / NAV；净负债率 = (有息负债 - 现金) / 净资产；融资成本 = 利息总支出 / 平均有息负债；土储倍数 = 土储可售面积 / 年销售面积 |

### 互联网/科技

| 维度 | 内容 |
|---|---|
| 必备 | 营收增速、MAU/DAU、ARPU、PS 或 PE |
| 可选 | 用户获取成本(CAC)、LTV/CAC、经调整净利润、FCF |
| 略过 | PB（轻资产无意义）、资产负债率、存货周转 |
| 标杆倍数 | PE 20–50x（盈利期）；PS 3–15x（成长期） |
| 异常阈值 | PS > 20x 且营收增速 < 20% 判定异常；PE > 80x 需增速支撑 |
| 合理范围 | 毛利率 40–70%；销售费用率持续上升需关注获客效率 |
| 专用公式 | ARPU = 营收 / 平均月活用户数；LTV = ARPU × 用户生命周期月数 × 毛利率；经调整净利润 = 净利润 + 股权激励 + 一次性损益；经调整 PE = 市值 / 经调整净利润；CAC = 销售费用 / 新增用户数；LTV/CAC 比值直接计算 |

### 军工

| 维度 | 内容 |
|---|---|
| 必备 | 营收增速、净利率、在手订单、PE(TTM) |
| 可选 | 合同负债增速、预付款变动、研发占比、PEG |
| 略过 | 股息率、PB（军工资产重估难）、EV/EBITDA |
| 标杆倍数 | PE 35–70x；PEG 1.0–2.0x |
| 异常阈值 | PE > 90x 且营收增速 < 20% 判定异常；净利率 > 20% 需验证 |
| 合理范围 | 净利率 5–15%；应收账款周转天数 90–180 天；合同负债持续下降需关注 |
| 专用公式 | 订单保障倍数 = 在手订单 / 近12月营收；合同负债覆盖率 = 合同负债 / 近4季营收；预付款变动率 = (本期预付款 - 上期预付款) / 上期预付款；应收账款周转天数 = 365 × 平均应收账款 / 营收 |

### 汽车/零部件

| 维度 | 内容 |
|---|---|
| 必备 | 营收增速、毛利率、净利率、PE(TTM) |
| 可选 | 销量增速、单车利润、市占率、EV/EBITDA |
| 略过 | 研发占比（除智能驾驶外）、PB |
| 标杆倍数 | PE 15–40x（整车）；PE 20–50x（零部件） |
| 异常阈值 | PE > 60x 且销量增速 < 15% 判定异常；毛利率 > 35%（整车）需解释 |
| 合理范围 | 整车毛利率 15–25%；零部件毛利率 20–40%；资产负债率 50–70% |
| 专用公式 | 单车利润 = 净利润 / 销量；单车营收 = 营收 / 销量；市占率 = 公司销量 / 行业总销量；研发强度（智能驾驶）= 研发费用 / 营收 |

### 环保/公用事业

| 维度 | 内容 |
|---|---|
| 必备 | 股息率、ROE、PB、资产负债率 |
| 可选 | 在建工程占比、运营产能、吨处理成本、EV/EBITDA |
| 略过 | 营收增速（公用事业增速低但稳定，非核心）、PEG |
| 标杆倍数 | PE 10–25x；PB 1.0–2.5x；股息率 3–6% |
| 异常阈值 | PE > 30x 需解释；股息率 < 2% 不符合板块特征 |
| 合理范围 | ROE 8–15%；资产负债率 50–70%；在建工程/总资产 > 30% 需关注资本开支压力 |
| 专用公式 | 单位处理成本 = 运营成本 / 处理量；产能投产率 = 运营产能 / (运营产能 + 在建产能)；EBITDA 利润率 = EBITDA / 营收；股息率 = 每股股利 / 股价；在建工程占比 = 在建工程 / 总资产 |

### 传媒/游戏

| 维度 | 内容 |
|---|---|
| 必备 | 营收增速、净利率、PE(TTM)、PS |
| 可选 | 月流水、付费率、ARPPU、版号储备数 |
| 略过 | PB（轻资产）、资产周转率、股息率 |
| 标杆倍数 | PE 20–50x；PS 3–10x |
| 异常阈值 | PE > 60x 且营收增速 < 20% 判定异常；净利率 > 40% 在游戏外的传媒中需解释 |
| 合理范围 | 游戏毛利率 60–80%；销售费用率 15–35%；研发占比 10–30% |
| 专用公式 | ARPPU = 月流水 / 付费用户数；付费率 = 付费用户 / MAU；用户获取成本 = 销售费用 / 新增用户数；版号储备价值为定性指标，作为批注辅助判断 |

## 选择规则

1. 按标的行业查对应小节，"必备"全部纳入。
2. "可选"按数据可得性纳入；若无法获取，在批注中注明"数据不可得，已略过"。
3. "略过"禁止纳入（除非用户明确要求）。
4. 跨行业标的取两个行业必备列并集。
