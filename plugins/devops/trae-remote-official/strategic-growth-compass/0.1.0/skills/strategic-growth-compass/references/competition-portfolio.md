# 竞争机制与产品组合

当问题涉及竞品分析、外部事件影响、跨产品线传导、生态反应、产品组合或资源重构时读取本文件。

## 1. 竞争范围与对象

按客户任务区分：

- **直接竞品**：同一客户、同一任务、相近交付方式。
- **间接竞品**：产品形态不同，但争夺同一预算、时间或入口。
- **替代方案**：人工、自建、开源、外包、DIY 或不做。
- **潜在进入者**：拥有相邻资产、渠道或平台能力，进入成本较低。
- **生态参与者**：可能同时是供应商、渠道、伙伴和竞争者。

先明确分析服务于定位、定价、产品组合、生态、防御、市场进入还是季度响应，避免形成无目的竞品全景。

## 2. 战略比较

优先比较：

- 目标客户、核心任务、价值主张和品类定义。
- 产品组合、定价包装和商业模式。
- 技术与产品能力及其可持续性。
- 分发渠道、默认入口和合作伙伴。
- 开放/封闭策略、API、开发者、内容和应用生态。
- 收入成本逻辑、资本和补贴能力。
- 数据、品牌、网络效应、切换成本和关键控制点。
- 发布节奏、合作、组织投入和其他近期战略信号。

招聘、社交讨论、社区热度和合作线索只能作为战略信号，不自动等于既定计划或市场成功。事实取证按 `official-source-retrieval.md` 和 `research-evidence.md` 执行。

价格和性能只在版本、定义、测试条件、服务层级、币种和生效时间能够对齐时排序或计算倍数；否则保留绝对值与条件，标明不可直接比较。

## 3. 竞争传导

对重要动作建立机制链：

`竞品动作 → 客户预期/成本/渠道/生态规则变化 → 受影响任务 → 焦点产品线暴露 → 收入/成本/留存/品牌/能力影响 → 可选响应`

常见机制包括能力或体验基线提高、价格锚点变化、免费层扩张、默认入口占据、开放生态扩大供给、套件捆绑、网络效应增强、许可证或监管变化，以及对人才、资本、伙伴和预算的争夺。

除直接替代外，检查二阶影响：

- 上游能力是否改变应用或内容的生产成本。
- 是否形成新的开发者、Agent 或分发入口。
- 是否增强竞品生态供给或跨产品数据反馈。
- 是否通过捆绑影响原本不直接重叠的业务。
- 竞争者对我方响应最可能采取什么反制。

## 4. 产品线覆盖

竞争影响分析先建立内部覆盖登记：

1. 提取用户明确点名的公司、业务和产品线。
2. 用用户材料和权威产品目录、财报或正式披露建立相关产品组合清单。
3. 为每条产品线标记客户任务、战略角色、直接/二阶关联和信息状态。
4. 形成 `已分析 / 低相关但保留 / 信息不足 / 明确排除` 的覆盖判断。
5. 正文可以合并相近产品线，但不能以篇幅或知名度替代覆盖判断。

建议使用：

| 产品线 | 竞品动作 | 客户任务 | 直接/二阶机制 | 方向与严重度 | 时间窗口 | 领先信号 | 调整条件 | 响应选项 |
|---|---|---|---|---|---|---|---|---|

严重度综合暴露范围、替代强度、经济影响和反应时间，不使用无依据的精确评分。

## 5. 产品组合与资源含义

按实际战略角色判断各业务或产品线：

- 增长引擎。
- 利润与现金引擎。
- 战略控制点。
- 能力与未来期权。
- 防御、迁移或退出对象。

评估客户与能力协同、收入成本协同、渠道复用、品牌影响、内部竞争、产品蚕食、管理复杂度和机会成本。结论应说明投资、维持、验证、收缩、整合或退出，以及资源从哪里释放、向哪里集中。

外部竞品事件可以触发组合复核，但不能单独构成退出依据。退出或整合需结合内部使用、留存、收入、战略客户、服务与迁移成本、能力重叠、替代成熟度和客户风险。

## 6. 竞争结论

最终回答：

- 对手真正改变了什么竞争规则，而不只是增加了哪些功能。
- 哪些产品线面临直接威胁、二阶影响或进攻机会。
- 应选择差异化、跟进、防御、合作、迁移还是不响应。
- 最小充分响应是什么，哪些动作属于过度跟随。
- 哪些领先信号会提高、降低或反转当前判断。
