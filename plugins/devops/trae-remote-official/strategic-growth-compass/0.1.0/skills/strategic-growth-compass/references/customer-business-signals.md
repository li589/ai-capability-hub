# 客户与经营信号综合

当战略判断依赖客户需求、产品行为、商业承诺、留存、收入成本或内部经营表现时读取本文件。目标是把用户提供的内部材料转化为战略证据，不开展详细需求拆解或用户体验研究。

## 目录

1. 信号范围
2. 输入盘点与口径
3. 客户证据综合
4. 产品与经营数据
5. 交叉验证
6. 战略信号输出

## 1. 信号范围

按任务选择相关输入：

| 信号类型 | 典型输入 | 能回答的问题 |
|---|---|---|
| 客户表达 | 访谈、问卷、支持工单、NPS/CSAT、产品评价 | 客户认为哪些任务、痛点和障碍重要 |
| 产品行为 | 激活、使用频次、功能采用、漏斗、分群、留存、流失 | 客户实际如何使用，价值是否持续产生 |
| 商业承诺 | 销售管道、赢单/丢单、预算、合同、试点、续约、扩张 | 谁愿意付费，采购条件和价值强度如何 |
| 经营表现 | 收入、价格、折扣、毛利、服务成本、渠道、交付与支持 | 商业模式和规模化约束是否成立 |
| 资源与能力 | 人员、资本、算力、渠道、合作伙伴、交付容量 | 公司能否在窗口期内兑现战略选择 |

用户数据是本次分析基准。外部资料可以核验或补充，但不静默替换内部定义与事实。

## 2. 输入盘点与口径

先建立轻量输入地图：

| 数据或材料 | 对象/分群 | 期间 | 指标或样本定义 | 当前状态 | 能支持什么判断 |
|---|---|---|---|---|---|

检查：

- 用户、客户、付费方和受益方是否为同一主体。
- 公司、产品线、地域、渠道和客户分层是否混用。
- 累计与期间、注册与活跃、试用与付费、合同与管道是否区分。
- 百分比是否能够回到绝对值、分母和样本规模。
- 数据是否存在选择偏差、幸存者偏差、渠道偏差或观察窗口过短。
- 指标变化是否可能来自定义、埋点、价格、渠道或产品版本变化。

数据不足时先说明能够判断的范围，不用行业经验填补内部事实。

## 3. 客户证据综合

围绕客户分层和高价值任务组织材料：

1. **说了什么**：态度、偏好、痛点和意向。
2. **做了什么**：使用、迁移、替代、放弃和重复行为。
3. **付了什么**：预算、价格、合同、试点和采购承诺。
4. **是否留下**：留存、续费、扩张、推荐和服务负担。

这些证据不是机械等级，但承诺成本越高，通常越接近真实需求。普通兴趣不能自动等同于购买意愿，单一大客户也不能自动代表整个市场。

综合时：

- 将相似反馈按客户分层、任务、场景和购买角色归类。
- 区分高频意见、少数高价值信号和结构性阻碍。
- 保留反例与矛盾，不把少量定性材料推广为所有客户。
- 把客户要求与解决方案建议分开；先确认任务和价值，再讨论能力形式。
- 对丢单、流失和不采用同时检查产品、价格、渠道、交付、信任与采购条件。

## 4. 产品与经营数据

根据战略问题选择分析方式：

- **趋势**：观察方向、拐点和持续性，同时核对绝对值与基数。
- **分群与队列**：比较不同客户、渠道、版本、地域和获取时期，避免平均值掩盖结构差异。
- **漏斗**：定位从接触、激活、采用、付费到续费的主要损失环节。
- **贡献与归因**：识别增长或下降由哪些产品线、客户和价格/用量因素驱动；没有实验或充分控制时保持为解释假设。
- **异常**：检查突变是否来自真实经营变化、季节性、口径变更或数据质量。
- **单位经济**：在数据允许时检查贡献毛利、获客回收、留存、服务成本和规模效应。

只计算会改变战略判断的指标，不把经营复盘扩展为独立数据分析项目。

## 5. 交叉验证

将客户表达、产品行为、商业承诺和经营结果放在一起判断：

| 组合 | 可能含义 | 战略处理 |
|---|---|---|
| 表达强、行为强、付费强 | 需求与价值获得多维支持 | 评估规模化经济性与能力约束 |
| 表达强、行为弱 | 兴趣未转化为持续价值 | 检查激活、交付、替代方案和表达偏差 |
| 行为强、付费弱 | 使用价值存在但价值获取不足 | 检查客户结构、定价、免费层和付费方 |
| 付费强、留存弱 | 成交不等于持续价值 | 检查承诺过度、交付成本和产品适配 |
| 外部机会强、内部信号弱 | 市场空间未必适配公司 | 优先验证客户与能力，不直接规模化 |

如果信号冲突会改变推荐，形成条件情景或最小验证动作；不要通过挑选单一有利数据消除冲突。

| 战略命题 | 客户证据 | 行为/经营证据 | 反证或缺口 | 对选择的影响 | 下一验证 |
|---|---|---|---|---|---|
