# 小红书爆款图文笔记生成专家

***

## 1. 目录结构

生成后的笔记目录：

```
<work-dir>/<report-name>/
├── index.html              ← 主页（iPhone 预览外壳）
├── post/
│   └── rednote-post.html   ← 内容页（由 iframe 加载）
└── images/
    └── *.jpg/png           ← 所有图片统一存放（含正文转图）
```

***

## 2. 决策流程

```
用户想法
  │
  ├─ ① 选题：定场景 + 核心关键词           →（按下方路由表打开对应 references/S*.md）
  │
  ├─ ② 六要素（互相咬合，共用核心关键词）
  │     ├─ 主题：给谁看+解决什么+什么形式
  │     ├─ 标题：≤20字，前5字核心词，选真人「起手式」写 ★  → §3.2
  │     ├─ 封面图片：选封面套路（竖版更占屏，非强制；原图/截图也行）★  → §3.3
  │     ├─ 正文：≤500写正文区 / >500拆多张文字图    → §3.4
  │     ├─ 图片：≤18张                    → §3.5
  │     └─ 标签：≤10，6+3+1                       → §3.6
  │
  ├─ ③ 场景爆款特征：打开对应 S*.md 套用该场景的标题/封面/正文/图文打法 ★
  │
  ├─ ④ 风险词自查                    → §5
  │
  └─ ⑤ 模板注入（机械步骤，不改）                  → §6
```

> 按上述决策逻辑顺序执行即可，不需要额外使用 TodoWrite 工具管理流程。

## 3. 笔记构成通用规则（选题 / 标题 / 封面 / 正文 / 图片 / 标签）

> 六要素必须互相咬合：主题定核心关键词 → 标题/封面/正文首段/tag 共用这批词，形成**埋词闭环**。六者不咬合 = 系统打错标 = 没流量。

### 3.1 选题 & 主题

一句话锁定：**给谁看 + 解决什么 + 什么形式**。

- 先判断属于哪个**场景**（种草/测评/科普/情绪/探店/电商/穿搭/美妆/美食…）→ 按 §2 路由表打开对应 `references/S*.md` 对号入座，不同场景打法不同。
- 主题越垂直越好：「早八人 5 分钟通勤妆」优于「化妆教程」。
- 抽出 1-2 个**核心关键词**（如「油皮定妆」），贯穿标题/正文首段/封面大字/tag。

### 3.2 标题——决定"点不点进来" ★

**硬规则**：≤ **20 字**（汉字/字母/数字/符号/emoji 均计 1 字）；核心关键词尽量靠前（信息流标题会折叠，露出的是前半句），但**要说人话**——先读起来自然，再顺手把关键词放前面。

**核心心法：像一个真人当下的脱口而出，而不是被打磨过的文案。**
翻真实的小红书信息流会发现：爆的标题往往是**没修饰、带情绪、甚至话说一半**的——`上班15分钟已经想下班了` `26岁，男，没谈过恋爱正常吗` `新来的领导是我之前的相亲对象…` `女生们审美，1还是2啊啊啊啊`。它们能点进去，不是因为"写得好"，而是因为**像一个活人在自言自语 / 在问你 / 在吐槽**。

写标题前先自问：**这话我发到自己朋友圈会不会被说"太用力"？** 会，就是文案腔；不会，才像真人。

**判断 AI 感 vs 真人感（这是本轮重点）**：

| <br /> | AI 感 / 文案腔（要避开）  | 真人感（要的）                            |
| ------ | ---------------- | ---------------------------------- |
| 句式     | 工整、对仗、信息完整       | 口语、松散、可以话说一半                       |
| 情绪     | 克制、正确、像旁白        | 直给、上头、带语气词（啊/救命/谁懂/…）              |
| 目的     | 让你"了解一个卖点"       | 让你"想接话/想投票/想看下文"                   |
| 例子     | `这家咖啡馆居然藏在居民楼三楼` | `就为这一口，我又跑了半座城…` / `这家谁带我来的，我要谢谢他` |

> ⚠️ 连"具体的小发现""反差意外"这类方向，如果写得太齐整（每句都主谓宾完整、都有个漂亮结论），照样是 AI 感。**宁可口语、不完整、有情绪，也不要工整、正确、无波澜。**

**真人标题的 8 种常见"起手式"**（各场景侧重见对应 `references/S*.md`，示例尽量贴近真实信息流）：

| 起手式            | 为什么像真人       | 真实感示例                            |
| -------------- | ------------ | -------------------------------- |
| **自嘲 / 自曝**    | 承认自己不完美，反而亲切 | `140斤了还是不肯好好穿搭啊` `又双叒失败了`    |
| **情绪脱口而出**     | 带语气词，像当下反应   | `谁懂啊，为这口味道单程俩小时` `这也太上头了`      |
| **提问 / 投票求同好** | 直接邀请你接话      | `1 还是 2 啊啊啊姐妹们` `26岁没谈过恋爱正常吗`    |
| **话说一半 / 悬念**  | 用省略号勾着，想看下文  | `新来的领导是我之前的相亲对象…` `拆了快递之后我沉默了` |
| **反差 VS / 打脸** | 落差感强，一眼有戏    | `父母以为的 vs 我实际吃的` `以为会踩雷，结果我连去三天`  |
| **反向 / 吐槽**    | 不夸而是损，稀缺又好笑  | `劝退帖，这玩意儿真别买` `那些种草了但后悔的东西`       |
| **过程感 / 打卡**   | 有时间、有连载感     | `打卡第30天` `退坑三个月又爬回来了！`   |
| **一句大实话 / 观点** | 有态度、不端着      | `租房没必要买洗碗机` `xxx全过程实录`      |

技巧：多用第一人称口语（我/居然/结果/其实/谁懂）；**敢用语气词和省略号**（啊/啦/…）；一个标题只留一个钩子；数字用阿拉伯数字更醒目；emoji 点缀即可、别堆；**允许"没有明显卖点"的纯情绪/纯提问标题**——真实信息流里它们占很大比例。避免绝对化与叫卖词（见 §5）。

### 3.3 封面——决定"停不停下滑动" ★

封面是爆款第一生产力，约 **80% 的点击由它决定**。

**规范**：竖版更占屏更吸睛（**推荐**而非强制，如 3:4 / 1080×1440，横版/方图/原图比例都可以）；**很多真实爆款封面就是一张没加字的实拍图，或一张手机截图**，不一定要做"设计感大字报"；若加字，够大够清晰即可；低饱和/日常滤镜比样板间更耐看；文字**不遮挡主体/人脸**。

**核心判断**：这个场景的人，滑到什么会停？——**要么被画面本身勾住（好看/诱人/有反差），要么被一句话戳中（好奇/共鸣/想接话）。** 别为了"精致"牺牲真实感。

**封面 AI 感 vs 真人感**：

| | AI 感 / 营销号感（要避开） | 真人感（要的） |
|---|---|---|
| 底色 | 深色/黑色/克莱因蓝+白色大字（像付费课程海报） | 浅色/白底/米色/截图原色（像备忘录/便签/手机截图） |
| 排版 | 居中对称、装饰线、角标齐全、设计感强 | 随意、偏左对齐、或干脆就是一张原图不加字 |
| 元素 | 渐变、光效、3D 字体、多色 emoji 堆叠 | 单色文字、手写字、截图水印、拍糊的实拍 |
| 典型 | "深蓝底+白色粗体标题+红色角标'干货'" | "备忘录截图""offer 邮件截图""手写清单拍照" |

**真实信息流里的 7 种封面套路**（各场景侧重见对应 `references/S*.md`）：

1. **实拍原图直出**：一张最诱人/最出片/最有现场感的真实照片，**不加字或只角标一两个字**。美食、穿搭、旅行、生活、健身现场最常见，真实感最强。
2. **人物出镜+标题**：真人正脸/半身/上身，信任感强，美妆穿搭健身必备。
3. **前后 / 左右对比**：Before/After 分屏，减脂、改造、妆效、变装的杀手锏。
4. **纯文字观点卡 / 金句卡**：浅底+一句大白话观点或情绪（像备忘录/记事本那样），情绪、职场、影视观点、知识干货首选。生图时必须遵守以下视觉规范：
   - **卡片感**：画面是一张浮在纯色/渐变背景上的**圆角矩形卡片**，不是满屏铺色
   - **底色**：卡片底色用暖白/奶白/浅米/纸质纹理；外围背景可以是柔和纯色或渐变（粉白、浅橙、淡蓝等）
   - **文字对齐**：**居中**为主；文字上下留白均匀，视觉重心在画面中央
   - **字体感**：圆润/手写感/可爱感，不要标准粗黑体；像手机便签app里打出来的字
   - **关键词高亮**：1-2 个关键词用**色块底色**突出（如红底白字、绿底黑字的小方块），其余文字保持深灰/黑色
   - **装饰**：可加引号「❝❞」、小表情贴纸、角落日期水印，保持随意感；**禁止**装饰线、渐变光效、角标胶囊
   - **文字量**：30字以内，呼吸感极强；整体像"手机备忘录截图"而不是"课程海报"
5. **截图卡**：聊天记录 / 评论 / 弹幕 / 热搜 / 评分 / 数据面板截图直接当封面——**真实感和好奇感极强**，情绪、职场、影视、游戏、八卦类高频（如"和领导的聊天记录""豆瓣评分截图""出货结算页"）。
6. **清单式/九宫格**：多产品/多角色/多穿搭平铺，合集、盘点、测评用。
7. **场景氛围图**：探店/旅行/家居，靠氛围光影出片。


### 3.4 正文——决定"看不看完 + 互不互动"

小红书按 CES 权重推荐，**完播率极其重要**，正文结构要"留人"。但\*\*"留人"不等于"套模板"\*\*——真实爆款正文的形态非常松散，硬套五段式反而是最重的 AI 感来源。

#### 3.4.A 三种真实正文形态（不要默认走"干货金字塔"）★

翻真实信息流会看到，正文至少存在下面 3 种同样能爆的形态，**先根据主题选形态，再落笔**：

| 形态         | 长度        | 结构                                           | 适用                       | 真实示例句式                                      |
| ---------- | --------- | -------------------------------------------- | ------------------------ | ------------------------------------------- |
| **① 短吐槽型** | 10-80 字   | **一到两句真人当下反应**，无分点无 CTA            | 情绪/娱乐/八卦/热点吐槽/生活碎片       | "真的没想到，还有这种造福观众的神出现"                        |
| **② 叙述型**  | 200-800 字 | **大段自然文字**，概念/干货嵌进个人经历，段落用空行分开 | 情绪共鸣/职场心理/影视评论/成长感悟/深度种草 | "我以前在一家外企干了五年，晚上经常失眠…" |
| **③ 半干货型** | 150-500 字 | **短开场 + 短编号列表**，每条 1 句话不带副标题冒号说明，收尾一句大白话     | 攻略/工具清单/科普干货/避坑指南        | "1. 把'麻烦您了'换成'靠你了' / 2. 把'不着急'换成具体节点"       |

#### 3.4.B 正文的真人感 vs AI 感 ★★

对齐 §3.2 标题的做法，明确列出正文里必须规避的 AI 腔特征：

| 维度      | AI 腔 / 运营腔（要规避）                                          | 真人感（要的）                                          |
| ------- | -------------------------------------------------------- | ------------------------------------------------ |
| 段落标题    | 📍场景引入 / 🧠概念 / 💡例子 / 🛠应用 / 💬提问 这类**功能标签式 emoji 小标题** | **尽量不用**段落 emoji 标题；emoji 只在句中做情绪点缀（😅🥲🥹…）     |
| 分点      | "记住 3 点：1⃣ … 2⃣ … 3⃣ …"，每条还带副标题冒号+说明                     | 编号可用，长篇干货可以分点，但每条尽量一句话说完；也可以完全不分点、只用空行断句                |
| 结尾      | "评论区聊聊👇" / "点赞收藏关注三连"                                   | 一句感慨 / 一句大白话总结 / 一句感叹或分享或求助，**绝不喊"评论区聊聊👇"这种模板句** |
| 对仗句     | 每句主谓宾完整、工整对仗、像旁白                                         | 长短句混合；允许口语、话说一半、语气词（啊/啦/…）、破折号——                 |
| 概念/干货位置 | "🧠 概念名称+定义：心理学上有个概念叫……"独立成章节                            | 概念**嵌进故事/例子**里，不单独拎出来解释                |
| 人称视角    | 大量"你"（"你有没有过""你会发现"），教学腔                                 | 更多用"我"——讲自己的事；偶尔用朋友群聊里聊天式的（"有没有人懂那种感觉啊"） |
| 具体细节    | "举个例子……"这种通用假设                                           | 有时间、地点、数字、当事人的具体经历（"外企干了五年""每月房租3800"）           |
| 修饰词     | 绝绝子/yyds/宝藏/绝了/巨/超（堆砌感叹词）                                | 白描（"挺不错的""还行""是真的合我胃口"），偶尔一两个词就够                 |

**一条硬规矩**：写完通读一遍，问自己「**这段话我发到朋友圈会不会被说'太用力'？**」——会 = AI 腔，改；不会 = 过。

#### 3.4.C 长度分叉与呈现载体 ★

正文既可以完全放"正文区"，也可以整段做进图片、正文区留白或只写一句悬念。**根据字数和形态自由选**：

```
情况 A：短吐槽型（≤80 字）
  → 一句话直接写正文区，可以完全不做正文图。

情况 B：叙述型 / 半干货型，正文 ≤ 500 字
  → 直接写进正文区（--body），口语化分段。
    这是绝大多数小红书笔记的形态。

情况 C：正文 > 500 字
  → ① 保留完整 Markdown 原文给用户留存；
    ② 把正文拆成【多张 3:4 图片】，每张一屏可读，每张文字大小一致；
    ③ 【第一张图开头必须有】"全文 XX 字 · 阅读需 X 分钟" 小字样式，
       放在主标题上方，用小号灰字，模拟真实爆款的"预读提示"；
    ④ 正文区可选：
       · 完全不留字（正文内容全走图，正文区留空或仅贴 1-3 行总结摘要）
```

> ⚠️ 多张图而非长图：小红书逐张滑动浏览，多张拼接图完播率、可读性都优于一张被压缩的长图（文字卡默认用竖版画布，便于阅读）。
> **写作要点**：口语化（多用"我"、短句、语气词）；分段用空行断句；前置真实反应；带具体到可验证的细节（时间/地点/数字/人物）。emoji 规范见 §3.4.B。

### 3.5 图片

> 硬规则：**≤18 张**。推荐竖版（如 3:4 / 1080×1440），横版/方图/原图比例亦可。技术：≥720×960，单图 ≤32MB，支持 PNG/JPG/JPEG/WEBP，支持 GIF/Live Photo。

**图片只有4种来源**：

| 来源            | 何时用                 | 处理方式                               | 注意                        |
| ------------- | ------------------- | ---------------------------------- | ------------------------- |
| **① 用户已上传实拍** | 用户提供实拍/原图           | 直接复制进 `images/`，**优先做封面**（真实感最强）   | 尊重原图，勿过度美化失真              |
| **② AI 生成**   | 缺图/示意图/氛围图/带留白的封面底图/金句卡 | 用 GenerateImage 生成，见 §3.5-C        | 写清用途/风格/构图 |
| **③ 网络搜索**    | 需参考图/氛围图且无原图        | 检索下载进 `images/`，**仅作示意**，见 §3.5-B  | ⚠️版权：不可作商业主图/冒充自拍；交付标注来源  |
| **④ 正文转图**    | 正文 >500 字触发         |  自动拆成多张 3:4 文字图追加 | 见 §3.4                    |

> **来源优先级**（真实感/合规）：真实原图 > AI 生成 > 网络图。

***

#### 3.5-A 首图/封面底层逻辑（最重要，先定这个）★

- **选首图口诀**：真实原图选「最诱人/最出片/信任感最强」的一张；用户自备的文字卡选「最戳人的一句话」；无论哪种，**第 1 张一定最用心**（封面重要性见 §3.3）。

#### 3.5-B 网络搜图搜什么（无原图时的示意/氛围图）

- **搜什么**：画面干净、主题明确的图（自拍、产品特写、场景照、风景氛围），便于后期排字。
- **构图关键词**：优先「高清、大色块、强对比、单一主体、简洁背景」；细节太密的图缩成缩略图会糊。可按「场景展示 / 效果对比 / 信息清单」三类需求找。
- **版权规避**：优先无版权商用图库（Unsplash / Pexels 类）或自己实拍；**避免搬运带水印图、明星肖像、品牌 LOGO**；**网络图不可作商业主图/冒充自拍**，交付时标注来源。带货类尽量真实实拍。

#### 3.5-C AI 生成图：一次性交付完整成品 ★

**核心原则：走 AI 生图就整张全包给 AI，不要"一半 AI 生成 + 一半人工/工具后期叠字"。禁止用代码/PIL/Canvas 等工具生成封面图片或卡片，所有带文字的封面/金句卡必须 AI 一次性整图输出；长文拆图场景可用代码排版。** 

> ⚠️ AI 生成的图片自带水印，**无需任何去除处理**。图片生成工具返回成功即可信赖，无需额外校验文件是否存在。

- **每一张图都需要有用，不要漫无目的地生成，生图是有成本的。**
- **生成什么**：核心元素控制在 **1-2 个**并整合进一个场景（如"春季穿搭"只需"穿风衣站在浅色墙前的人"），不堆砌。
- **prompt 六要点**（一次讲完，别拆两轮）：
  ①**比例**：竖版 3:4（规范见 §3.5）
  ②**主体**：1-2 个核心元素 + 场景描述 + 人物 + 光线/材质
  ③**配色**：一个主色 + 一个强调色，避免 3 种以上饱和色；浅底深字或深底亮字对比要强，但**优先浅色/白色底**（真人感更强，深色底容易像营销号海报）
  ④**同篇风格统一**：固定「风格锚定词 + 色调方向」，多张时构图/主体单独调

#### 3.5-D 编排节奏

> 第 1 张=封面（最用心，选 §3.5-A 打法）→ 中间内页按逻辑推进（步骤/细节/对比/效果）→ 末张可选收尾（清单/合规引导/长图正文）。各场景建议张数与封面套路见对应 `references/S*.md`。

### 3.6 标签——≤10 个，且要"选得好"

> 小红书 **35%-50% 流量来自搜索**，tag 是被搜到的入口，也是系统给笔记打标、匹配人群的依据。最优区间 **6-10 个**（脚本超 10 会截断）。

**组合公式（6+3+1）**：

| 类型          | 数量  | 作用           | 举例（美妆）        |
| ----------- | --- | ------------ | ------------- |
| **核心垂类词**   | 2-5 | 精准定位主题，决定人群池 | #油皮护肤 #新手化妆   |
| **泛流量热门话题** | \~3 | 蹭大话题曝光       | #变美 #好物分享     |
| **长尾精准词**   | 若干  | 覆盖具体搜索需求     | #早八通勤妆 #学生党平价 |
| **品牌/活动词**  | 1-2 | 蹭品牌/活动/节点    | #双十一必买        |

> 口诀：**泛词吃曝光，垂词定人群，长尾稳搜索，品牌蹭热点。**
> **找热门 tag**：搜索框下拉联想 / 话题广场看参与量 / 爆款笔记反查 / 数据工具（千瓜蒲公英）/ 蹭节点。选词三连问：**够不够热？准不准？搜不搜得到？**
> **埋词闭环**：tag 与标题、正文首段、封面文字共用同一批核心关键词。避坑：不堆无关热门词、不全用超大泛词、不与正文脱节。

## 5. 平台风险词规则

> 2026 年 AI 审核升级：机器+人工双重校验，**谐音、拼音、符号替换、拆字变体均可识别**，旧规避法已失效。处罚三档：绝对违禁（限流/删除）＞敏感词（压权重）＞行业限制词。

| 类别                 | 典型违禁词                                      | 安全替代                     |
| ------------------ | ------------------------------------------ | ------------------------ |
| **跨平台导流（第一红线）**    | 微信、加V、扣我、主页链接、淘宝/天猫/京东、二维码、"XX App 搜"、同名抖音 | 站内不出现站外指向；联系方式只走官方私信     |
| **极限词/绝对化**（广告法9条） | 最、第一、顶级、国家级、100%、销量冠军、永久、唯一、绝对             | "口碑不错""回购率高""很多人回购"      |
| **医疗/功效宣称**        | 祛痘、美白、淡斑、瘦身、生发、抗敏、修复屏障、7天见效                | "提亮肤色""改善肤质"；只描述肤感，不承诺疗效 |
| **诱导互动**           | 点赞、收藏、关注、评论区扣1、求赞求收藏                       | 用内容自然引导，不喊话要数据           |
| **诱导抢购/虚假营销**      | 秒杀、抢爆、错过不再有、万人疯抢、恭喜中奖、全民免单                 | 如实描述活动，不编造稀缺/中奖          |
| **迷信与违禁品类**        | 转运、旺财、算命、开光；医美细节、烟草、境外博彩                   | 迷信话术删除；违禁品类不碰            |
| **种草夸大词（软限流）**     | 绝绝子、yyds、必入、闭眼买                            | 客观体验描述                   |

## 6. 模板注入步骤（机械骨架，不改执行方式）

> ⚠️ **直接执行脚本，不需要读取或理解脚本以及模板 HTML 内容。** 模板文件由脚本自动处理，阅读它只会浪费上下文且无任何帮助。

### Step 1: 创建目录

```bash
bash <skill-dir>/scripts/new-post.sh <report-name> <your-work-dir>
```

- `<skill-dir>`：本 skill 所在目录 · `<report-name>`：笔记 slug（如 `summer-cafe-2026`）· `<your-work-dir>`：工作目录（建议 `/workspace`）。

### Step 2: 准备图片

将所有图片复制到 `<work-dir>/<report-name>/images/`。来源判定与生成规范见 §3.5。

### Step 3: 注入内容

```bash
bash <skill-dir>/scripts/inject-content.sh <post-dir> \
  --title "标题文字" \
  --body "正文内容" \
  --tags "标签1,标签2,标签3" \
  --images "img1.jpg,img2.jpg,img3.jpg"
```

> **注入完成即交付。** 不启动本地服务器、不截图验证、不打开浏览器预览。交付物是 HTML 文件本身。
