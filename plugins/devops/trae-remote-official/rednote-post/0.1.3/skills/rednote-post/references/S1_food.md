# S1 · 美食探店 · 爆款特征与图文特征

> 覆盖：探店（餐厅/咖啡/甜品）· 食谱教程 · 零食好物 · 饮品DIY · 厨房好物
> 使用姿势：参考下方「标题起手式」写得像真人分享 + 选定「封面套路」排版（这两步决定点击率）→ 补正文/tag/配图 → 回 SKILL.md §4 校验通用逻辑、§5 过风险词、§3.5 定图片来源与首图。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**

## 爆款特征（这个场景靠什么火）

- **食欲是第一生产力**：封面/配图的诱人度直接决定点击，拉丝/爆浆/汁水/倒饮特写是杀手锏，成品必须占画面主体、色泽鲜亮。半夜刷到引发食欲的「流口水式」封面点击最高。
- **探店走「氛围+全实用信息」，食谱走「可复制」**：探店给全地址/人均/营业时间，攻略型最易被收藏转发；食谱给「用量·火候·料比·工具」精细到可原文照搬，收藏率普遍高于点赞率。
- **2026 趋势（可蹭）**：①复合风味爆发——「酸甜解腻/酸甜酥脆/坚果香」等风味词高增长；②古法/传统美食走红（#古法美食主理人 #传统美食）；③健康化诉求——「干净天然、0添加、高纤维」成卖点，但不得医疗化。
- **性价比与猎奇驱动零食/饮品**：人均价格锚点 + 尝鲜合集转化高。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像真人当下脱口而出，别写探店文案。探店可用「情绪/反差」`谁懂啊，为这一口单程俩小时` `这家谁带我来的我要谢谢他` `以为会踩雷，结果连去三天`；食谱用「自曝/过程感」`第7次翻车后我终于悟了` `随手做的，居然比外面还好吃`；也可反向吐槽`让人毫无食欲的一顿，但我爱`。避开"宝藏！人均XX出片"这类广告腔，允许纯情绪、话说一半。 |
| **封面 ★** | ①**成品高饱和特写**（拉丝/爆浆/汁水瞬间）；②**合集九宫格/拼图**（多道成品+大字如"5个超简单甜品"）；③探店用**场景氛围出片图**（少文字、暖调统一）；④反差/悬念封面配大字。首图逻辑见 SKILL §3.5-A。 |
| **正文** | 探店：第一人称找到它 → 招牌单品体验（带真实肤感/味觉细节）→ **地址/人均/营业时间/避坑** → 一句大实话收尾；食谱：用料表（精确用量）→ 分步骤（可复制）→ 火候/料比关键技巧 → 一句自评收尾；地址、清单可以放到图片里承载。 |
| **图片** | 6-12 张。探店：环境/招牌/菜单/细节，多出片图；食谱：成品大图+分步拼图（步骤角标）；零食饮品：单品+ASMR特写。真实实拍优先。 |
| **tag** | 地域词（#广州美食 #上海探店）+ 品类（#咖啡馆/#家常菜/#烘焙）+ 泛词（#周末去哪儿/#美食分享）+ 2026热词（#古法美食主理人）+ 长尾（#平底锅美食 #减脂餐食谱）。 |

## ⚠️ 禁区

- 不夸大"全城最好吃/第一名"（极限词，见 SKILL §5）。
- 食品不宣称保健功效（减脂餐不说"瘦身/降糖/降三高"）。
- 探店如实描述排队/踩雷，不编造"网红同款"或未真实到店的探店；商业合作走蒲公英报备，禁站外/私下交易导流。

## 一句话组合示例

`谁懂啊，为这一口单程俩小时`（标题）+ 场景氛围出片封面 + 正文给全地址人均避坑 + 6-9 张出片图 + #广州美食 #广州咖啡馆 #探店。
