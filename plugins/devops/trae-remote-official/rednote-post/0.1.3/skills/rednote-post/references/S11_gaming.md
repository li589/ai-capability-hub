# S11 · 游戏 · 爆款特征与图文特征

> 覆盖：手游/端游攻略 · 角色养成/抽卡 · 游戏安利 · 二次元 · 电竞 · 游戏日常
> 使用姿势：参考「标题起手式」写得像玩家自己发的 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**

## 爆款特征（这个场景靠什么火）

- **攻略即工具书**：新手养成优先级、配队、抽卡规划、卡关求解——可收藏、可复用，收藏率极高。玩家把小红书当"比搜索引擎更靠谱"的攻略库。
- **情绪共鸣**：吐槽策划、晒出货/非酋惨状、入坑退坑心路、对角色的情感投射（"老公/女儿"式养成），玩家借游戏讲自己的生活。
- **求助帖互动强**：新手求带、"这个池子值不值得抽"、账号规划求评估——评论区热闹，算法友好。
- **安利靠视觉**：角色立绘、限定时装、家园/染色二创空间，女性向/二次元尤其倚重。
- **圈层认同 + 二创**：cos、同人、名场面二创，圈子归属感强。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像玩家在群里发言，别写宣发稿。可用「求助」`新号入坑这三个先养谁啊救命😭`；「晒成就/抽卡」`十连双黄，我今天欧皇本皇`；「吐槽/避坑」`别抽了别抽了，血泪劝你别` `策划你清醒一点，这版本改了个啥`；「心路/共鸣」`退坑三个月又爬回来了…`；干货可「数字+收益」`模拟宇宙通关难点，3步拿满奖励`。核心词放前 16 字（搜索黄金位），emoji 1-2 个即可。 |
| **封面 ★** | ①**角色立绘/限定时装大图**（安利种草首选，视觉冲击强）；②**游戏截图/出货结算页**（真实感强，晒卡/晒成就）；③**攻略表格/配队信息图**（收藏率高）；④**纯文字吐槽/求助卡**（纯色+大字语义钩子）；⑤**对比/反差图**（养成前后、非酋vs欧皇）。主色≤3 种。 |
| **正文** | 一句真人当下反应/求助/吐槽开场（"这本命角色终于抽到，等了半年"）→ 主体二选一：干货分点（配队/词条/步骤，**每条一句大白话**）或情绪叙事（吐槽/心路/复盘）→ 一句大实话收尾。核心词（游戏名/角色名）在首句自然带出便于搜索。 |
| **图片** | 3-9 张：立绘、游戏截图、配队/养成表、出货截图。首图定生死。 |
| **tag** | 游戏名+版本（#原神 #星穹铁道 #绝区零 #王者荣耀）+ 品类词（#二次元 #国乙 #女性向游戏 #手游攻略 #角色养成 #抽卡 #电竞）+ 场景情绪（#游戏日常 #新手攻略 #零氪玩家 #退坑 #晒卡 #欧皇）+ 玩法（#配队攻略 #模拟宇宙 #cos #二创）。 |

## ⚠️ 禁区（重点）

- **未成年保护是高压线**：不向未成年提供/寻求陪玩陪聊、代练代打（八部门已列为不良信息，顶格处罚）；不做"包赢段位/保证上分"等诱导性承诺。
- **导流红线**：正文/图片/简介不得出现手机号、微信、QQ、二维码、第三方水印、站外链接；不引导站外或线下交易；评论区暗示加好友引私域会限流甚至封号。
- **代充/代练/账号交易**：禁止站外支付话术（"加微信转账""私信付款"）、禁演示未报备虚拟商品；账号买卖属违规交易。
- **私服/外挂/破解**：外挂、私服、破解、加速器、辅助脚本等黑灰产内容明令禁止。
- **色情擦边导流**：以角色/擦边引流被严打，可封禁私信群聊直至封号。
- **绝对化/敏感词**：全网第一、最强等触发限流（见 SKILL §5）；AI 生成内容须标识。
- 游戏服务类（虚拟商品/服务）经营需完成平台**报白**并合规上架。
