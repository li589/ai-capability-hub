# S7 · 情绪共鸣 · 爆款特征与图文特征

> 覆盖：情绪表达 · 治愈解压 · 人生感悟 · 扎心文案 · emo/共鸣
> 使用姿势：参考「标题起手式」写得像真人分享 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**
> ★ 本场景以「金句大字报封面」为主战场，重点看 SKILL §3.5-A 的选首图口诀与 §3.3 的「纯文字观点卡 / 金句卡」封面套路。**本 skill 内不生产文字卡图片**，两条路径二选一：① 用户上传自制图；② 走 AI 生图整张一次性出成品（含全部文字，见 §3.5-C）。禁止半生成半调整。

## 爆款特征（这个场景靠什么火）

- **评论区就是内容的一部分**：抛开放式问题、留共鸣/争议点，靠评论权重（长评论权重更高）冲流量。
- **BFD 法则**：唤起信念（Belief）、放大感受（Feeling）、满足渴望（Desire）；顺应人性（慕强/好奇/焦虑/共情）。说中用户心事，引发「这不就是我」的转发。
- **克制的美学**：极简封面 + 一句扎心金句，比堆信息更有穿透力；封面文案可直接截图保存。
- **2026 高热趋势（可蹭）**：治愈感/松弛感/氛围感/反焦虑、「低能量生活」「下班恢复」持续高热；情绪从私密转为公开自嘲式表达（#有一种悲伤 #如果忧郁是一种天赋 高增长）；「能量场」崛起（#高能量 #家是我的能量场 #100件恢复能量的小事）；「草台班子」消解内耗。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像深夜一个人的自言自语，别写鸡汤金句体。可用「情绪脱口而出」`上班15分钟已经想下班了` `突然就很想哭，也没什么大事`；「一句大实话」`成年人的崩溃，都是静音的` `原来长大就是慢慢习惯失望`；「提问/求同好」`是不是每个人都有个删不掉的人`。避开对仗工整的"金句模板"（越像语录越假），越口语越像活人。 |
| **封面 ★** | ①**纯文字大字报**（黑底白字/莫兰迪/治愈渐变，一句金句字体极大铺满画面，无多余元素）——这是本场景首选，成品由用户自制或走 AI 生图整张一次性出（含全部文字，见 §3.5-C）；②**真人 IP 出镜+痛点大字报**（自信人物占主体+醒目情绪标题）。2026 可用「维纳斯带冷调」蓝粉紫渐变。 |
| **正文** | **叙述型为主，不套五段式**。第一句戳心（一句自言自语式的真话，不写金句体）→ 大段自然叙述里带自己的具体经历（时间/场景/身体反应），概念/道理**嵌进故事**里说，不做独立小标题；段落靠空行断句。也可以走「短吐槽型」——全文只有 1-2 句真人当下反应。 |
| **图片** | 1-3 张，重氛围不重信息（纯色文案图/情绪场景图/渐变金句图）。 |
| **tag** | 情绪词（#情绪价值 #治愈系文案 #自我疗愈 #emo #松弛感 #反内耗）+ 人群词 + 2026热词（#富养前额叶 #能量场 #100件恢复能量的小事 #草台班子）+ 泛词。 |

## ⚠️ 禁区

- 不传播过度负能量/极端情绪、不贩卖焦虑、不毒鸡汤（易限流违规）。
- 严禁「福利诱惑/强制互动」话术（恭喜获奖、点击领取、转发三三子、一键三连领福利）。
- 不迷信话术（转运/开光，见 SKILL §5）；金句/文案图涉他人作品防侵权；AI 生成须标注。
- 情绪类引流至私域/知识付费 + 刷量互动属严重违规。

## 一句话组合示例

`成年人的崩溃，都是静音的`（标题）+ 极简纯文字大字报封面 + 正文故事化情绪+开放式提问 + #治愈 #成年人的世界 #情绪价值。
