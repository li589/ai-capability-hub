# S10 · 影视娱乐 · 爆款特征与图文特征

> 覆盖：影视剧/电影/综艺安利 · 剧评追剧 · 明星/CP · 娱乐观点 · 观后感
> 使用姿势：参考「标题起手式」写得像真人在追剧群里发言 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**

## 爆款特征（这个场景靠什么火）

- **情绪共鸣 > 信息告知**：不是"介绍一部剧"，而是"说出你看剧时的心情"。低粉爆文里提供情感/精神价值的占比极高，影视是"活人感"最吃香的赛道之一。
- **讨论本身就是消费**：看剧→上小红书吐槽/磕CP/找同好，评论区是内容的一半。抛开放式问题、留争议点，靠评论权重冲流量。
- **二创与长尾解读**：人物动机、隐喻拆解、台词细节考据，能让一部剧穿越播出周期持续被讨论。
- **热点捆绑**：热播剧自带百万级话题池，借当期话题标签是流量放大的杠杆。
- **形式**：追剧repo/剧评以图文为主——截高能桥段+经典台词+直给感受，门槛低、直观。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像在追剧群里脱口而出，别写影评腔。可用「情绪脱口而出」`救命第8集我哭到停不下来` `谁懂啊这段男二眼神我原地失恋`；「提问/求同好」`是只有我觉得女主其实没错吗` `这剧怎么没人看，我先替它急了`；「反差/打脸」`本以为烂剧随便刷，结果第3集看愣住`。避开"必看神剧/全网最好看/年度第一"这类绝对化营销词（易限流，见 SKILL §5）。 |
| **封面 ★** | ①**名场面/剧照拼图**（高能桥段、角色特写多宫格）；②**纯文字观点卡**（一句大白话观点铺满，如"第8集封神了"）；③**弹幕/评论/热搜/评分截图**当封面（客观背书+好奇感强，见 §3.3 截图卡）；④**台词卡**（剧照+台词字幕）。3 秒内让人读懂"讲哪部、跟我啥关系"。 |
| **正文** | **叙述型或短吐槽型为主**。开场一句真人当下反应（"真的没想到""救命这也太上头了"），主体三选一：剧情复盘 / 人物CP解读 / 观点输出（观点是高赞关键）；穿插台词/名场面截图；结尾抛一个真诚的开放问句留争议点。热点吐槽也可直接走"短吐槽型"（全文 1-2 句）。 |
| **图片** | 3-9 张：剧照、名场面截图、台词卡、评分/热搜截图。**注意版权，见禁区**。 |
| **tag** | 剧名话题（#剧名 #剧名追剧repo #剧名剧评）+ 行为词（#追剧 #剧评 #观后感 #电视剧推荐 #综艺推荐）+ 情感词（#磕CP #嗑到了 #神仙演技 #名场面 #经典台词）+ 泛娱乐（#追剧搭子 #今天追剧了吗）+ 当期热点词。 |

## ⚠️ 禁区

- **版权是最高频雷区**：搬运/剪辑他人影视片段、盗用剧照/明星摄影作品，未经授权即侵权，带营利目的更易被判定；图片带他人水印也可能违规。用自己拍摄的屏摄+明显个人评述更安全。
- **明星隐私 / 人身攻击**：不发未授权的个人行程住址私生活；不侮辱、辱骂、造谣诽谤艺人。
- **虚假信息 / 造谣**：不散布未经证实的八卦、不捏造事实抹黑。
- **拉踩引战**：不恶意对比贬低他人作品/艺人、不挑动粉丝对立（属恶意诱导，见 SKILL §5）。
- **绝对化营销词**：全网第一、年度最佳、必看神剧等触发限流。
- **剧透**：关键结局剧透请标"含剧透慎入"，否则易招负面互动拉低权重。
- **AI 内容须标识**：AI 生成文案/图按平台要求标注"（AI创作）"。

## 一句话组合示例

`救命第8集我哭到停不下来`（标题）+ 名场面拼图或评分截图封面 + 正文情绪钩子+桥段复盘+抛问题 + #剧名 #追剧 #名场面。屏摄自评、不搬运、不剧透未提醒。
