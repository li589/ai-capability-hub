# S5 · 生活分享 · 爆款特征与图文特征

> 使用姿势：参考「标题起手式」写得像真人分享 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**

## 爆款特征（这个场景靠什么火）

- **真实氛围 + 代入感 + 具象化的美好生活憧憬**：第一人称叙事、真实生活痕迹比精修更打动人；改造前后的强反差感引发向往与收藏。
- **可执行信息**：好物清单、改造前后对比、收纳方法给全（含预算/渠道），才会被收藏转发。
- **视觉美感门槛高（家居赛道同质化严重）**：需打造统一个人风格「你展示的是你的家」，配色统一、留白合理。
- **2026 趋势**：家居从「关注风格」转向「具体功能需求」——智能家电高增长（空调/洗烘/智能家居），适宠/适童/适老场景涌现。滤镜优先「日常系」（奶杏/浅夏），反「样板间」保留真实感。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像真人碎碎念自己的生活，不喊麦。可用「真实小情绪/场景」`一个人住久了，最爱的居然是这个角落` `搬家后才懂，这几样是真好用`；或「反差/自曝」`改造前我都不好意思拍`。避开"必看！秒变高级！省2万"这类叫卖，量化数字可自然带在正文。 |
| **封面 ★** | ①**改造前后对比拼图**（脏乱 vs 温馨）；②**数字量化价值**大字（省钱/翻倍）；③**场景氛围出片图**（生活/家居空间，色调统一）；合集用九宫格。竖图更占屏（非强制），主体突出留白干净。 |
| **正文** | 一句生活现场感开场（"合租三年终于把自己房间收拾成想要的样子"）→ 清单式罗列（好物/步骤逐条含用法+渠道，**每条一句大白话**）→ 前后对比或量化结果 → 一句松弛感自评收尾。营造"租房也能幸福"的松弛感。 |
| **图片** | 6-9 张：氛围图、好物实拍、前后对比、细节。真实户型/生活痕迹优先，反"样板间"。 |
| **tag** | 生活垂类词（#家居好物 #收纳整理 #出租屋改造）+ 泛词（#生活分享 #好物分享 #断舍离 #家的样子）+ 长尾（#小户型收纳 #厨房收纳神器 #智能家居好物）。 |

## ⚠️ 禁区

- 家居家装不夸大"永不磨损/绝对防水/0甲醛"，环保等级如实（见 SKILL §5）。
- 好物合集不用极限词、不虚假种草；编造虚假体验（"月薪3千住五星"实为广告）属违规。
- 好物合集/家居种草若为软广须蒲公英报备，不得对效果做保证性承诺；带货禁站外导流。

**叠加好物测评/带货时（跨品类打法）**：合集测评→结论/红黑榜前置+真实使用对比+自费声明；带货种草→第一人称真实体验+抛痛点→用法→场景，评论区置顶渠道指引；禁极限词与虚假稀缺、禁微信/二维码/淘宝导流，商单报备。详见 SKILL §2 末尾。
