# S12 · 健身运动 · 爆款特征与图文特征

> 覆盖：减脂增肌 · 居家健身 · 跑步/瑜伽/普拉提 · 运动装备 · 身材管理 · 运动饮食
> 使用姿势：参考「标题起手式」写得像真人打卡/自曝 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**
> ⚠️ 本品类是功效宣称/极限词的高危区，标题与正文必须用"个人体感/亲测"话术，红线见文末。

## 爆款特征（这个场景靠什么火）

- **前后对比 = 最强信任货币**：真实数字化成果（"1个月 130→115"）+ 前后/左右对比图，是点击与收藏的最大动力。
- **计划可复制、低门槛**：数字化拆解（"3步养成马甲线""6个动作"）+ 场景标签（宿舍/办公室久坐/租房）让人"对号入座、照着做"。
- **反焦虑成为新爆点（2026 趋势）**：从"极端节食、苦大仇深"转向"健康、可持续、体态改善、力量训练、瘦子增重"；反焦虑叙事（"我没饿肚子""为健康不为取悦谁"）本身更打动人、也更合规。
- **痛点钩子**：圆肩驼背/久坐/假胯宽等具体痛点 + 正向激励或负面警示（"千万别这么练"）撬动点击。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像真人打卡/自曝，别写产品文案。可用「自曝/过程感」`打卡第30天，胯宽居然回来了` `瘦了20斤才敢来分享…`；「痛点/人群」`梨形姐妹看过来，瘦腿真有救` `经常侧睡圆肩驼背，跟练这几个`；「反问/悬念」`天天练还是不瘦？可能错在这`；「负面警示」`跑步千万别这么跑，膝盖废了才懂`。**规避功效承诺**（高效燃脂/轻松瘦/7天见效），换成"个人体感/亲测"。 |
| **封面 ★** | ①**前后/左右对比图**（中间白色粗体标数字，减脂身材管理杀手锏）；②**身材成果钩子图**（马甲线/小蛮腰实拍，激发"我也想要"）；③**动作分解图**（分步示范+序号，突出可操作）；④**计划表大字报**（训练/饮食搭配表）；⑤**场景健身照**（宿舍/居家/户外跑步，代入感强）。清透干净、少浓妆滤镜。 |
| **正文** | 一句真实自曝/踩坑开场（"腰突两年，之前找的教练都让我更疼"，规避硬广感）→ 点破 2-3 个常见误区 → 干货方案分步/分动作/分餐（**每条一句大白话**，核心价值可复制）→ 个人真实体感+数据佐证（体重/围度/心率）→ 一句大实话收尾、**不催单、不制造身材焦虑**。 |
| **图片** | 6-12 张：前后对比、动作分解、计划表、场景实拍、餐食图。真实拍摄 > 精修。 |
| **tag** | 趋势词（#生活化减脂 #体态改善 #力量训练 #瘦子增重）+ 通用（#健身 #减脂 #减脂打卡 #居家健身 #马甲线 #瑜伽 #普拉提 #跑步 #减脂餐 #身材管理）+ 痛点长尾（#圆肩驼背 #假胯宽 #梨形身材 #宿舍健身）。 |

## ⚠️ 禁区（该品类最严）

- **严禁功效承诺 / 绝对化**：快速减脂、高效瘦身、一周瘦十斤、7天见效、永不反弹、100%有效、根治、最/第一/顶级——一律违规（广告法+平台，见 SKILL §5）。换成"配合作息，体态看起来更轻盈""个人坚持后有明显体感"。
- **"黑五类"重灾区**：虚假宣传减肥/壮阳/丰胸/增高功效的产品服务，账号可被永久冻结、清退。
- **医疗/伪专业**：无资质别伪装医生/营养师；禁"临床验证/杀菌/疗效"等医疗词；医疗器械类需资质。
- **极端节食/健康风险**：不宣扬催吐、极端断食等危害健康内容；不做身材焦虑营销（平台已抑制）。
- **未报备商单 / 伪素人**：品牌寄样、佣金带货须走蒲公英报备并标 #品牌合作；伪装素人自发种草处罚最重。
- **站外引流**：不引导加微信/QQ/跳淘宝。
