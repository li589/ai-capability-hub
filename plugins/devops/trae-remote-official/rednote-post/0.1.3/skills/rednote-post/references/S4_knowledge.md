# S4 · 知识科普 / 干货 · 爆款特征与图文特征

> 覆盖：技巧清单 · 成分/原理科普 · 避坑指南 · 教程步骤 · 领域入门 · 数码家电测评
> 使用姿势：参考「标题起手式」写得像真人分享 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**
> ★ 数码家电/技巧类**横评测评**在此垂类：叠加测评时看 SKILL §2 末尾「跨品类打法」+ 本文禁区。

## 爆款特征（这个场景靠什么火）

- **收藏导向 + 被搜索命中**：信息密度高、可存档、可复用，收藏比点赞更能体现干货价值，收藏权重直接推流量。核心词自然靠前便于被搜到，但标题要像"分享心得"而非"关键词罗列"。
- **一眼知道能学到什么**：大字报封面点明「学到啥」，降低点击成本。
- **常青长尾 > 短期爆款**：靠搜索持续吃长尾流量数月到一年。
- **2026 趋势**：信息爆炸下用户要「做减法」（#前额叶 等「脑养生/反信息轰炸」话题高热），干货要用精简表达为用户「减负」，不做堆砌轰炸。含「野路子/信息差」类词收藏率显著更高。
- **结尾抛「你还想看哪方面」**引评论，≥8 字含场景的长评论权重是短评论 3 倍。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像真人分享一个刚搞懂的点，别写关键词罗列。可用「自曝/过程感」`研究了一整晚，才发现原来这么简单` `走了三年弯路，早知道就好了`；或「反常识/求同好」`一直以为的做法，居然是错的` `这事没人告诉我，我自己踩明白了`。避开"必看！翻倍！天花板"这类堆词，数字/人群自然带。 |
| **封面 ★** | **「大字报」为王**——白/浅底或深底+大标题（≥36pt、占画面 1/3 以上），核心结论居中，副标题点人群/数量；也可「数字+分类」型（如"3原理·2食谱·9措施"）。文字占比 ≤30-40%、留白干净、前几字最大最清晰。**本 skill 内不生产文字卡图片**，用户自制或走 AI 生图整张一次性出（含全部文字，见 §3.5-C）。 |
| **正文** | **半干货型或叙述型二选一**。可以是「短开场（一句你踩过的坑）+ 短编号（每条一句大白话，**不带副标题冒号+说明**）+ 一句大实话收尾」；也可以整段叙述把知识点嵌进个人故事；数字化的清单/步骤可用图片承载；带货可自然点评+引导评论区拿链接（合规），不硬销。 |
| **图片** | 4-9 张：大字报+知识图卡/思维导图/步骤图/表格截图，可加"这步超重要"手写体标注。 |
| **tag** | 垂类知识词（#知识科普 #学习方法）+ 泛词（#干货分享 #自我提升 #涨知识 #建议收藏）+ 长尾场景词（下拉词挖掘，如 #Excel技巧教程 #时间管理方法）。 |

## ⚠️ 禁区

- 理财/健康类忌承诺收益或疗效（见 SKILL §5）；医疗科普禁未认证建议（"治疗/3天见效/100%有效/降三高"），替换为"科学研究表明""支持…健康"。
- 不做绝对化断言（"一定/必然/100%有效"）。
- 原创性保持 60% 以上，AI 辅助内容须标注；知识付费账号刷量属严重违规可封号。

**叠加数码家电横评时（跨品类打法）**：结论前置（红黑榜/推荐排序）+对比表可视化+**自费/非广告声明**；单篇聚焦 ≤2 个核心卖点，禁拉踩抹黑与误导性对比，参数/样张真实，商单走蒲公英报备。详见 SKILL §2 末尾。
