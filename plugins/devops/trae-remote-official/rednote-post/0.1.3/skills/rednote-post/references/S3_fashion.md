# S3 · 穿搭时尚 · 爆款特征与图文特征

> 覆盖：女装 · 男装 · 鞋靴 · 箱包 · 配饰 · 内衣家居服
> 使用姿势：参考「标题起手式」写得像真人分享 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**

## 爆款特征（这个场景靠什么火）

- **上身效果 + 场景适配**驱动决策，真人全身出镜信任感最强，服装主体是画面重点。
- **身份认同 > 单纯身型**：2026 核心逻辑从「别人用什么→我是谁」，服饰主打「自我取悦/向内关照」，讲整体气质适配，「先有性格、再有风格」。身材/人群标签仍是精准引流利器（比如 梨形/苹果型/155小个子/微胖/高个进标题与 tag）。
- **2026 趋势（可蹭）**：①**Softfit 柔系穿搭**——强调「面料即气场」、流线剪裁、低饱和松弛感色系（棕/杏/白）；②**本命穿搭/气质测试**——#色彩测试 #气质类型测试 #穿得像自己；③商业笔记收藏同比增长明显，针织衫/毛衣、内搭、银饰、包挂高增速。
- **一衣多穿/多场景搭配**卡点转化高。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像真人晒穿搭、发牢骚，别写文案。可用「自嘲/自曝」`140斤了还是不肯好好穿搭啊` `155的我找这条裤子找了好久`；「提问/求同好」`1还是2啊姐妹们审美在线的来` `是只有我觉得这配色意外好看吗`；「反差」`被问了三次链接的一件外套`。避开"显瘦10斤！小个子必入天花板"这类叫卖，身材/人群词自然带在句中。 |
| **封面 ★** | ①**人物全身出镜**带场景（咖啡馆/街角/镜面自拍），主体居中占比高；②**前后变装对比**；③OOTD 九宫格。右上可贴"显瘦·遮肉·垂感"标签，低饱和松弛色系。标签置图片角落避免遮挡主体。 |
| **正文** | 一句穿搭当下的真实感开场（"梨形+150的我这次终于没翻车"）→ 身高体重前置 → 版型如何修饰/遮肉（带具体身体反馈）→ 面料材质 → 适合场合 → 多场景搭配 → 一句大实话自评收尾。 |
| **图片** | 6-9 张：正面/侧面全身、细节（腰线/面料肌理/纽扣/刺绣）、多场景/多搭配组合。 |
| **tag** | **必带身材/气质长尾词**（#微胖穿搭 #梨形穿搭 #小个子穿搭）+ 品类（#连衣裙 #针织衫搭配）+ 2026热词（#Softfit #高智穿搭 #本命穿搭 #色彩测试）+ 泛词（#OOTD #每日穿搭）。 |

## ⚠️ 禁区

- 不用"显瘦20斤"等绝对化夸张（见 SKILL §5）。
- 尺码/材质如实描述，不夸大；避免身材焦虑营销与拉踩其他品牌。
- 内衣家居服以体感+场景叙事为主，避免露骨表达。
- 带货须蒲公英报备；禁站外导流；「伪素人」批量同质化种草会被判违规限流。

**叠加带货种草时（跨品类打法）**：第一人称真实上身体验+抛痛点（遮肉/显高）→版型卖点→多场景，评论区置顶尺码/链接指引；禁极限词与虚假稀缺，禁微信/二维码/淘宝跨平台导流，商单走蒲公英报备。详见 SKILL §2 末尾。
