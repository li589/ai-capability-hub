# S2 · 美妆护肤 · 爆款特征与图文特征

> 覆盖：护肤（水乳/精华/面膜/防晒）· 彩妆（底妆/眼妆/唇妆）· 香氛 · 美发 · 身体个护
> 使用姿势：参考「标题起手式」写得像真人分享 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**
> ★ 护肤/彩妆是**测评横评**主战场，也是**带货种草**高频垂类：叠加测评/带货时看 SKILL §2 末尾「跨品类打法」+ 本文禁区。

## 爆款特征（这个场景靠什么火）

- **信任门槛最高**：真实上脸/前后对比最能建信任；主动写「不适合谁」反而转化更高。伪造使用体验会被判违规。
- **效果可视化 + 精准人群痛点 + 搜索承接**：正文前 100 字自然埋核心词（肤质/痛点）便于被搜到，但标题本身要说人话、别像投放文案。
- **肤感+场景 > 成分堆砌**：用户要的是「用起来什么感觉、什么场合用」，不是参数流水账。
- **2026 趋势（可蹭）**：①彩妆声量过半；②从「悦己」向「愈己」递进，形成「情绪×美学×功效」心智三角，功效不再是唯一论据；③增长赛道——颈部护理、洗发护发、身体润肤、**男士护肤**（增速超大盘）。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像跟闺蜜吐真话，别写投放文案。可用「自曝/情绪」`油皮的我终于不用中午补妆了` `踩了三年雷才发现问题在这一步`；「反差/意外」`买来随便试试的，结果成了本命`；「提问/求同好」`是只有我涂这个显白吗姐妹们`。避开"封神/亲测有效｜XX作弊器/黄皮救星"这类广告腔堆叠，允许口语、话说一半。 |
| **封面 ★** | ①**人物出镜/上脸特写**（信任感强，美妆必备）；②**前后对比**（素颜→伪素颜、塌→立体）；③**大字报**核心卖点（≥30% 占比，粗体圆润字）。右上贴卖点标签（≤6 字，如"不搓泥·不闷痘"），低饱和背景。 |
| **正文** | 一句真实感开场（"油皮8月的通勤妆糊到怀疑人生"）→ 肤感/妆效实测（带具体细节：几点糊、脱在哪、余温多久）→ 用法+周期 → 适合什么肤质/场合 → 一句大实话自评（含小缺点）收尾。 |
| **图片** | 6-9 张：上脸前后、质地推开、包装、使用场景。实拍优先，禁 AI 伪实拍。 |
| **tag** | 核心垂类词（#油皮护肤 #底妆 #口红试色）+ 泛词（#变美 #好物分享）+ 2026热词（#男士护肤 #原生美学）+ 长尾（搜索量>5000且笔记数<10000为佳，如 #干皮不卡粉 #油痘肌早八）+ 品牌词。 |

## ⚠️ 禁区（本场景红线最严）

- **严禁医疗/功效宣称**：祛斑、美白、淡斑、祛痘、生发、抗敏、修复屏障、7天见效、立刻见效、根治。合规替换：「提亮肤色感」「养护方案」「急救→护养」「维稳/强韧」。
- **防晒尤其严**：不能说「美白/防止黑色素/祛斑」，只说"提亮肤色感、清爽不油"。
- **美发**：不承诺"生发/防脱根治/白发变黑"。
- 极限词"最/第一/100%/永久"一律禁用（见 SKILL §5）；商业合作走蒲公英报备；AI 生成内容须声明。

**叠加测评/带货时（跨品类打法）**：做多款横评→结论前置+对比表+**自费声明**，禁拉踩抹黑与误导性对比，样张真实拍摄；做带货种草→第一人称真实体验+抛痛点→肤感→场景，禁虚假稀缺（秒杀/疯抢）与站外私域导流（微信/二维码/淘宝）。详见 SKILL §2 末尾。

## 一句话组合示例

`油皮的我，终于不用中午补妆了`（标题）+ 上脸特写封面贴"不搓泥·不闷痘" + 正文肤感实测+通勤场景+一个小缺点 + #油皮防晒 #油皮护肤 #夏日防晒。全文不出现"美白/防黑"。
