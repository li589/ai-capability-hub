# S6 · 旅行出行 · 爆款特征与图文特征

> 覆盖：旅行攻略 · 民宿酒店 · city walk · 户外露营 · 周边游
> 使用姿势：参考「标题起手式」写得像真人分享 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**

## 爆款特征（这个场景靠什么火）

- **强收藏**：行程表/地图/交通/预算给全，可直接照抄的攻略最易被收藏转发。
- **出片是敲门砖**：最出片的一张风景/机位决定点击；带人物/团照增强真实感。
- **真实体验 > 堆流量**：用户信任真实体验，境内游决策依赖综合体验；在地叙事/地域文化穿透力强、长效。
- **2026 趋势（可蹭）**：**「旅行兴趣班」爆发**——告别打卡式旅行，转向「边玩边学」（学拓染、打银饰、烧玻璃），#旅游兴趣班 #成年人旅行兴趣班 高热，主打松弛感与深度人文；地域文化在地叙事（潮汕/南洋等）承载共同记忆。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像真人分享一段真实旅程，不喊麦。可用「真实小发现/意外」`临时改的行程，结果玩得最尽兴` `本来只想拍照，结果学了门手艺`；或「过程感/求助感」`第一次一个人出远门，记点大实话`。避开"保姆级！绝美无人！照抄不踩雷"这类堆词，目的地可自然带在句中。 |
| **封面 ★** | ①**最出片风景一张**（少文字，胶片/清透色调统一）；②**"普通照片→大片"对比**；③带人物/团照增真实感；攻略型可叠"保姆级攻略"角标。高饱和、构图对称（庭院俯拍/美食特写）。 |
| **正文** | 一句在地感/真实动机开场（"上海周末想跑远一点，就订了这趟车"）→ **行程表/交通/住宿/人均预算/必去清单/避坑**（结构化信息可以进图）→ 一句真实感受收尾。在地人视角+具体价格/时间强化专业度。 |
| **图片** | 9-18 张（内容多可用满）：风景机位、地图、行程清单图、美食住宿；出片风景+氛围人像+实用信息图混排。 |
| **tag** | #XX旅游攻略（长尾强）+ 地域词 + 泛词（#旅行 #周末去哪儿 #亲子游）+ 玩法词（#citywalk #露营）+ 2026热词（#旅游兴趣班）。标签 5-10 个不堆砌。 |

## ⚠️ 禁区

- 不编造"绝美无人/全网独家"（极限词，见 SKILL §5）。
- 门票/交通/人均成本如实标注，不误导（禁"月薪3千住五星"式虚构价格体验）。
- 旅游/民宿种草软广须报备；涉及安全出行不发布未经证实的危险建议。

## 一句话组合示例

`临时改的大理行程，结果玩得最尽兴`（标题）+ 最出片风景封面 + 正文行程表+预算+避坑 + #大理旅游攻略 #云南旅行 #旅行攻略。
