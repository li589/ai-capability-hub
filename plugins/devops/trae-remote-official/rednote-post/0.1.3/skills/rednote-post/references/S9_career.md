# S9 · 职场 / 学习 · 爆款特征与图文特征

> 覆盖：效率工具 · 职场技能 · 考证学习 · 简历面试 · 模板资源
> 使用姿势：参考「标题起手式」写得像真人分享 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**

## 爆款特征（这个场景靠什么火）

- **可复制、能马上用**：即用工具/模板/清单，收藏与转发率高；靠「信息差变现 + 可落地 SOP」。
- **3C 内容模型**：Context 场景（可代入生活情境）+ Conflict 冲突（痛点 vs 解决方案）+ Climax 高潮（数据可视化/案例对比，如"月薪8000如何实现月入2万"）。
- **身份代入**：打工人/大学生/考研人等身份前置，精准戳中人群；强搜索属性，布局核心词/长尾词/疑问词三类关键词表。
- **文件预览提升收藏**：模板截图、工具界面拼图让人「想存下来」。
- **数据规律**：含「行业黑话+利益承诺」或「失败经验+数据支撑」的标题表现突出，含「野路子」类词收藏率显著提升；善用「损失厌恶」（对损失敏感度是获得的 2 倍）。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像真人分享自己踩过的坑、用顺手的工具，不喊麦。可用「真实过程/自曝」`走了不少弯路，才找到这几个真好用的` `以前手动做半天，现在几分钟搞定`；或「意外发现」`用了才发现，免费的居然比付费还顺手`。避开"必备！神器！月入过万"这类夸张承诺，工具、数量可自然带在句中。 |
| **封面 ★** | ①**清爽浅色文字卡**——白/米/浅灰底+深色大字（像备忘录/手写便签截图，真人感强）；②**真实截图卡**——offer 截图、聊天记录、笔记本页面、薪资对比表截图直接做封面（好奇感+可信度）；③**工具截图拼图**（2×N 网格，每张标工具名）。⚠️ 避免深色底+白色大字的"营销号大字报"，这是最重的 AI 感来源。 |
| **正文** | **叙述型或半干货型二选一，不套五段式**。开场先讲自己的具体经历/踩坑（"我以前在XX干了X年…"），把痛点铺出来；工具/方法可以编号列，但**每条一句大白话**，不带副标题冒号+段落说明；心理学概念/方法论**嵌进例子**里说，不做"🧠 概念定义"独立章节；结尾一句大白话总结或一个真诚的开放问句。 |
| **图片** | 4-9 张：教程图、模板图、工具界面截图、思维导图（Canva/黄油相机做信息长图）。 |
| **tag** | 身份词（#职场干货 #大学生 #考研）+ 工具词（#效率工具）+ 泛词（#打工人 #自我提升 #副业 #干货分享）+ 长尾（#新媒体运营涨粉SOP #面试技巧职场新人）。 |

## ⚠️ 禁区

- 工具/资源不涉及盗版、破解、跨平台导流下载（见 SKILL §5）。
- 极限词/绝对化承诺（"效率翻10倍/一键搞定一切/月入过万必成/100%上岸"）触广告法与虚假宣传红线。
- 诱导互动（一键三连/求点赞/求收藏/求关注）与私域导流（私信领取资料/进群）禁用。
