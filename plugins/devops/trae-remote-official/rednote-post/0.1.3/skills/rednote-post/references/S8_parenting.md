# S8 · 母婴亲子 / 萌宠 · 爆款特征与图文特征

> 覆盖：孕产 · 育儿经验 · 儿童好物 · 启蒙教育 · 养宠日常 · 宠物好物
> 使用姿势：参考「标题起手式」写得像真人分享 + 选定「封面套路」排版 → 补正文/tag/配图 → 回 SKILL.md §4、§5、§3.5。 **⚠️ 落正文前必读 SKILL §3.4.B 真人感对比表，段首不用 emoji 功能标签、不喊"评论区聊聊"、概念嵌进故事而非独立成章。**

## 爆款特征（这个场景靠什么火）

- **信任极重要，真实记录 > 硬测评**：真实经验 + 避坑最能打，靠共鸣与实用建立「过来人/铲屎官」人设；图文笔记占比高（约 70%），重「真实记录+情绪代入」。
- **真实场景 > 精修**：孩子/宠物的真实反应、前后对比最动人；一家三口甜蜜合影是经典构图。
- **场景化+答案型**：直接回应「宝宝不爱吃饭怎么办」「辅食怎么搭」等疑问词，承接搜索。
- **人群词精准引流**：#新手妈妈 #科学育儿 #养猫日常 等长尾稳定进人。
- **2026 趋势**：育儿从「吃穿」向「起居出行」全域延展，孕妈情绪被前置（孕期情绪、产后修复），收藏增长明显；萌宠靠「拟人化人设+反差萌+情绪陪伴」。

## 图文特征（示例参考，非固定模板）

| 要素 | 打法 |
|---|---|
| **标题 ★** | 像真人妈妈/铲屎官碎碎念，不喊麦。可用「真实自曝/过程感」`踩了一圈坑，才总结出这几条` `辅食做了半年，最省心的是这样`；萌宠口语化/故事化（`养它之前真该看看这篇` `人类幼崽今天又...`）。避开"必看！一次备一周！赢在起跑线"这类叫卖与焦虑话术。 |
| **封面 ★** | ①**真实场景/前后对比**（孩子/宠物真实画面、使用前后）；②生活场景+短文案叠字；③萌宠常用深色背景+黄色高亮短文案凸显主体。暖调、自然光、主体居中占 2/3。 |
| **正文** | 一句真实场景/身份开场（"娃第三次咳嗽半夜，我又翻出这个"）→ 真实使用经验（有具体细节：月龄、场景、身体反应）→ 避坑清单/好物逐条（**每条一句大白话**）→ 一句实话收尾、**不制造育儿焦虑**。 |
| **图片** | 6-9 张：真实场景实拍、成长连拍、好物细节、前后对比。真实 > 精修。 |
| **tag** | 人群词（#新手妈妈 #科学育儿 #养猫日常 #养狗日常）+ 品类（#宝宝辅食）+ 泛词（#带娃 #人类幼崽 #遛狗）+ 长尾（#6个月宝宝辅食 #无盐辅食）。 |

## ⚠️ 禁区（重点）

- **严禁焦虑营销**："再不买孩子就输在起跑线""不用就落后"这类话术。
- **奶粉/辅食禁用**：接近母乳、优于母乳、替代母乳、增强智力、赢在起跑线、防过敏（无临床报告）。
- **母婴用品禁用**：医用级、灭菌、百分百无甲醛、防辐射、根治红屁屁；替换为「符合标准/天然原料」。
- 母婴/宠物用品不宣称「促进发育/增强免疫/根治」；不承诺、不制造育儿/养宠焦虑（见 SKILL §5）。

## 一句话组合示例

`踩了一圈坑，才总结出这几条`（标题）+ 真实场景/前后对比封面 + 正文真实经验+避坑清单 + #新手妈妈 #科学育儿 #母婴好物。全文无焦虑话术与功效承诺。
