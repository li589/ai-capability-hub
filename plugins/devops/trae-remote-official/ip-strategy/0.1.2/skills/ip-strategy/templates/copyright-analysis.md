# 著作权登记与侵权分析模板

## 适用场景
- 著作权/软件著作权登记材料准备
- 作品独创性分析
- 著作权侵权判定（实质性相似分析）

## 必要输入信息

| 字段 | 说明 | 是否必须 |
|------|------|---------|
| 作品内容/描述 | 需要保护或被侵权的作品 | 必须 |
| 作品类型 | 文字/美术/音乐/软件/视听等 | 可默认推进（根据内容判断） |
| 被控侵权作品 | 对比对象 | 侵权分析场景必须 |
| 创作过程说明 | 创作时间、独立创作证据 | 登记场景建议提供 |

## 分析框架

### 一、作品认定

**法定作品类型（著作权法第3条）：**
- 是否属于文学、艺术和科学领域的智力成果
- 是否具有独创性
- 是否能以一定形式表现

**独创性判断：**
- 独立创作（非复制）
- 创造性高度（最低创造性标准）
- 区分思想与表达

### 二、侵权分析（实质性相似 + 接触）

**接触要件：**
- 直接接触证据（访问记录、合作关系）
- 合理推定接触（已公开发表、同行业、时间先后）

**实质性相似判定：**
- 思想/表达二分法：只保护表达，不保护思想
- 对比方法：抽象-过滤-比较法（AFC test，软件类）/ 整体观感法（文字美术类）
- 相似部分是否属于受保护的独创性表达
- 排除公有领域/必要场景/有限表达

### 三、权利归属与权利内容

| 情形 | 权利归属规则 |
|------|-------------|
| 个人创作 | 创作者享有著作权 |
| 职务作品 | 一般职务作品：作者享有著作权，单位优先使用；特殊职务作品：单位享有除署名权外的著作权 |
| 委托作品 | 约定优先；无约定归受托人 |
| 合作作品 | 共同享有，协商一致行使 |
| AI生成内容 | 当前法律框架下存在争议，需个案分析 |

### 四、结论与建议

**登记建议：**
- 作品类型认定
- 登记材料清单
- 权利归属声明建议

**侵权结论：**
- [高风险]：构成实质性相似且有接触证据
- [中风险]：部分相似，接触证据间接
- [低风险]：仅思想层面相似或属于公有领域表达

**维权路径：**
- 行政投诉（版权局）
- 民事诉讼（赔偿 + 停止侵权）
- 刑事自诉/公诉（情节严重时）
