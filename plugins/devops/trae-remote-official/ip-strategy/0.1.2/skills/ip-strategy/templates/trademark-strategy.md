# 商标确权与维权策略模板

## 适用场景
- 商标注册申请前的近似检索与可注册性分析
- 商标异议/无效宣告/撤三攻防策略
- 商标侵权判定与维权方案

## 必要输入信息

| 字段 | 说明 | 是否必须 |
|------|------|---------|
| 拟注册/争议商标 | 文字/图形/组合描述 | 必须 |
| 指定商品/服务类别 | 尼斯分类号 + 具体项目 | 必须（注册场景） |
| 引证商标/在先权利 | 对方商标信息 | 异议/侵权场景必须 |
| 使用证据 | 商标使用情况描述 | 撤三答辩场景必须 |

## 分析框架

### 一、近似判定

**文字商标近似：**
- 字形比对（笔画结构、排列方式）
- 读音比对（汉语拼音、外文发音）
- 含义比对（词义、观念）
- 整体印象与显著部分

**图形商标近似：**
- 构图要素
- 表现形式
- 整体视觉效果

### 二、混淆可能性评估

| 考量因素 | 分析要点 |
|----------|---------|
| 商标近似度 | 整体近似 vs 部分近似 |
| 商品/服务类似度 | 相同/类似群组、关联商品 |
| 在先商标知名度 | 注册时间、使用范围、宣传投入 |
| 相关公众注意力 | 一般消费者 vs 专业购买者 |
| 实际混淆证据 | 是否已发生市场混淆 |

### 三、策略建议

**注册策略：**
- 可注册性结论：建议注册 / 建议修改 / 高风险不建议
- 修改方向（如需）
- 类别布局建议（核心类 + 防御类）

**异议/无效攻击策略：**
- 法律依据选择（相对理由 vs 绝对理由）
- 证据准备清单
- 时间节点把控

**撤三答辩策略：**
- 使用证据类型梳理
- 证据链完整性评估
- 补证方向

### 四、风险等级

- [高风险]：与在先商标构成近似且指定类似商品，混淆可能性大
- [中风险]：存在部分近似因素，但有区分要素
- [低风险]：差异明显，混淆可能性小

## 检索支撑

- `get_article`：商标法第30条（近似驳回）、第33条（异议）、第44-49条（无效/撤三）
- `get_law_list`：商标审查审理指南
- `search_case`：商标近似/混淆判例
