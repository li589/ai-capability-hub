# 专利侵权与FTO分析模板

## 适用场景
- 专利侵权比对：判断某产品/方法是否落入特定专利保护范围
- FTO分析：评估拟实施技术方案是否存在侵权风险

## 必要输入信息

| 字段 | 说明 | 是否必须 |
|------|------|---------|
| 目标专利号或权利要求文本 | 分析对象 | 必须 |
| 被控产品/待实施方案描述 | 技术实现细节 | 必须 |
| 分析类型 | 侵权比对 / FTO | 可默认推进（根据上下文判断） |
| 相关产品市场 | 技术领域和产品类别 | 建议提供 |

## 分析框架

### 一、权利要求解读

- 逐项拆解独立权利要求的全部技术特征
- 确定保护范围边界词（"包括""由...组成""基本由...组成"）
- 标注功能性限定特征（需结合说明书解释）

### 二、逐特征比对表

| 序号 | 权利要求技术特征 | 被控方案对应特征 | 比对结论 |
|------|-----------------|-----------------|---------|
| 1 | ... | ... | 相同/等同/缺少 |

### 三、侵权判定规则

**全面覆盖原则：**
- 被控方案包含权利要求全部技术特征 → 字面侵权
- 缺少任一技术特征 → 不构成字面侵权

**等同原则（逐特征判断）：**
- 手段基本相同
- 功能基本相同
- 效果基本相同
- 本领域技术人员无需创造性劳动即可联想

**禁止反悔原则：**
- 审查过程中放弃的技术方案不得再通过等同纳入

### 四、结论与建议

侵权分析结论分级：
- [高风险]：构成字面侵权，全部技术特征一一对应
- [中风险]：部分特征等同，存在侵权可能
- [低风险]：缺少关键技术特征或存在明确区别

FTO建议：
- 规避设计路径（替代哪些技术特征可跳出保护范围）
- 无效可能性评估（是否存在影响新颖性/创造性的现有技术）
- 许可谈判建议（如规避成本过高）
