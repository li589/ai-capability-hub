# 商业秘密保护方案模板

## 适用场景
- 商业秘密保护体系建设
- 商业秘密侵权分析（员工跳槽、竞业限制纠纷）
- 保密制度/竞业限制协议审查

## 必要输入信息

| 字段 | 说明 | 是否必须 |
|------|------|---------|
| 保密信息描述 | 需要保护的技术信息或经营信息 | 必须 |
| 保护场景 | 体系建设 / 侵权维权 / 协议审查 | 可默认推进（根据上下文判断） |
| 泄密渠道/行为描述 | 侵权场景需提供 | 侵权分析场景必须 |
| 现有保密措施 | 已采取的保护措施 | 建议提供 |

## 分析框架

### 一、商业秘密构成要件（三性认定）

| 要件 | 判断标准 |
|------|---------|
| 秘密性 | 不为公众所知悉；不能从公开渠道容易获得 |
| 价值性 | 具有商业价值，能为权利人带来竞争优势 |
| 保密性 | 权利人已采取合理保密措施 |

### 二、保密措施合理性评估

合理保密措施清单：
- 物理隔离（门禁、上锁、分区管理）
- 信息分级（密级标注、访问权限分层）
- 协议约束（保密协议、竞业限制协议）
- 技术措施（加密、水印、DLP系统）
- 制度规范（保密制度、离职审计流程）
- 人员管理（保密教育、涉密人员清单）

### 三、侵权行为认定

**法定侵权行为（反不正当竞争法第9条）：**
- 以盗窃、贿赂、欺诈、胁迫、电子侵入等不正当手段获取
- 披露、使用或允许他人使用以上述手段获取的商业秘密
- 违反保密义务或违反权利人保密要求
- 明知或应知上述行为仍获取、披露、使用

**举证要点：**
- 权利人：证明秘密性 + 保密措施 + 被告有接触可能
- 被告：证明通过合法渠道获得或独立研发

### 四、竞业限制条款审查

| 审查要点 | 合规标准 |
|----------|---------|
| 主体范围 | 高管、高级技术人员、负有保密义务人员 |
| 期限 | 不超过 2 年 |
| 经济补偿 | 按月支付不低于离职前12个月平均工资的30%（各地标准有差异） |
| 地域范围 | 合理限定 |
| 行业范围 | 具体明确，不得过于宽泛 |
| 违约金 | 合理（过高可调整） |

### 五、策略建议

**保护体系建设：**
- 信息识别与分级方案
- 保密制度框架
- 协议体系（入职/在职/离职）
- 技术防护措施建议
- 应急响应预案

**侵权维权路径：**
- 证据保全（公证/行为保全申请）
- 行政投诉（市场监督管理局）
- 民事诉讼（侵权赔偿）
- 刑事报案（情节严重，侵犯商业秘密罪）
