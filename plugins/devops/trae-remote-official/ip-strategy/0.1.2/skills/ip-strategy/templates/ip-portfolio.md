# 知识产权布局规划模板

## 适用场景
- 企业知识产权布局策略制定
- 专利组合分析与补强建议
- 技术领域知识产权竞争态势评估
- IP许可/转让策略

## 必要输入信息

| 字段 | 说明 | 是否必须 |
|------|------|---------|
| 企业/产品描述 | 核心业务和技术方向 | 必须 |
| 现有IP资产 | 已有专利/商标/版权情况 | 建议提供 |
| 布局目标 | 防御/进攻/许可/上市准备 | 可默认推进（默认：综合保护） |
| 目标市场 | 国内/海外目标区域 | 建议提供 |

## 分析框架

### 一、IP资产盘点

| 类型 | 盘点维度 |
|------|---------|
| 专利 | 数量、类型、技术领域分布、法律状态、到期时间、权利要求覆盖度 |
| 商标 | 注册类别、核心品牌覆盖度、防御注册情况、续展状态 |
| 著作权 | 软件著作权、作品登记情况 |
| 商业秘密 | 保护体系成熟度评估 |
| 域名 | 品牌相关域名覆盖情况 |

### 二、竞争态势分析

- 核心技术领域的专利分布（主要申请人、技术路线）
- 竞争对手IP布局特点
- 技术空白区识别（可布局方向）
- 潜在侵权风险识别

### 三、布局策略建议

**专利布局策略：**
- 核心专利：保护基础技术方案
- 外围专利：覆盖实施变形和改进方案
- 防御专利：阻止竞争对手绕过
- 储备专利：面向未来技术方向

**商标布局策略：**
- 核心类别注册
- 防御性类别扩展
- 海外目标市场提前布局

**综合建议：**
- 优先级排序（高/中/低）
- 预算分配建议
- 时间节点规划（优先权期限、续展日期等）

### 四、风险预警

- 现有布局的薄弱环节
- 即将到期/需续展的权利
- 可能的侵权风险点
- 竞争对手动态需关注的方向

## 输出格式

报告使用 Markdown 结构化输出，包含：
- 现状评估（已有资产概览）
- 差距分析（缺什么）
- 布局建议（按优先级）
- 行动路线图（时间 + 责任 + 预算估算）

## 检索支撑

- `get_law_list`：目标技术领域相关法规
- `search_article`：知识产权布局相关法律依据
- `get_article`：专利法第42条（保护期限）、商标法第39-40条（有效期/续展）
