# 域名争议投诉与应诉模板

## 适用场景
- 域名抢注投诉（UDRP / CNDRP）
- 域名争议应诉
- 域名与商标权冲突分析

## 必要输入信息

| 字段 | 说明 | 是否必须 |
|------|------|---------|
| 争议域名 | 完整域名（如 example.com） | 必须 |
| 投诉人商标信息 | 商标名称、注册号、注册日期、核定商品 | 投诉场景必须 |
| 域名注册信息 | 注册人、注册日期 | 建议提供 |
| 域名使用情况 | 当前指向内容、历史使用记录 | 建议提供 |
| 立场 | 投诉方 / 应诉方 | 必须 |

## 分析框架（UDRP三要件）

### 一、与商标的混淆性相似

判断标准：
- 域名主体部分（去除通用顶级域）与商标是否相同或混淆性相似
- 添加通用词/地理名/描述性词汇不影响混淆性认定
- 不同顶级域名后缀不影响混淆性认定

### 二、权利或合法利益

**被投诉人可主张的合法利益：**
- 在收到争议通知前已善意使用或可证明准备使用
- 以该域名为人所知（即使未取得商标权）
- 非商业性合理使用或合理评论

**投诉人举证方向：**
- 被投诉人无商标权或服务标记
- 被投诉人与投诉人无许可/授权关系
- 被投诉人未以该域名建立合法知名度

### 三、恶意注册和使用

**恶意情形（UDRP第4(b)条）：**
- 注册目的为向商标持有人或竞争者出售
- 阻止商标持有人以域名形式反映其商标
- 以干扰竞争者业务为目的
- 利用域名吸引用户至其网站牟利（制造混淆）

**善意抗辩方向（应诉时）：**
- 注册在先（早于商标注册/使用日期）
- 通用词/描述性词汇的合理使用
- 评论/批评的合理使用
- 独立善意使用

## CNDRP 特殊规则

中国互联网络信息中心域名争议解决办法（适用.cn/.中国等域名）与 UDRP 的主要差异：
- 投诉时效：域名注册之日起 2 年内
- 举证标准：投诉人需证明"注册或使用域名"具有恶意（"或"而非"和"）
- 处理机构：中国国际经济贸易仲裁委员会域名争议解决中心等

## 输出结构

### 投诉书框架
1. 当事人信息
2. 争议域名
3. 投诉依据（逐一论证三要件）
4. 所请求的救济（转移/注销）
5. 证据清单

### 应诉答辩框架
1. 当事人信息
2. 针对三要件的逐一答辩
3. 反向域名劫持主张（如适用）
4. 证据清单
