# 试卷分析方法（P1）

基于经典测验理论（CTT），适合班级/年级规模的日常考试。方法为默认口径，可据数据选更合适方法，但需说明理由与解释口径。

> IRT（项目反应理论）需大样本（通常 200+），不适合单班日常考试，默认不用。

## 0. 总分分布形态

- 先给**通俗结论**：分布是否健康、是否利于分层、高低分段是否异常堆积（结合直方图、及格线附近人数、标准差解读）
- 偏度、峰度是**可选的量化佐证**——当分布形态是这次分析的关注点、或形态明显异常需要坐实时再给，并**用一句话翻译**（如"轻微左偏，高分段略有堆积"），不要只甩"偏度 -0.059"这种老师看不懂的裸数字

## 1. 题目难度 P

- 默认：`P = 题目平均得分 / 题目满分`（客观题即答对率）
- P 越大题目越易；P 越小越难
- 适宜范围随考试性质不同：选拔性考试偏中等偏难，水平性考试可偏易，**不硬编码 0.3–0.7 为唯一标准**，需结合考试类型解读
- 报告每题 P 值 + 分布

## 2. 题目区分度 D

- **高低分组法 D**（默认）：按总分排序，取高分组（前 27%）和低分组（后 27%），`D = 高分组得分率 − 低分组得分率`。这是最直观、老师最好理解的区分度指标
- **题总相关 point-biserial r_pb**（可选深化）：题得分与校正总分的相关系数，是心理测量更严谨的区分度度量。**命题质量复盘、教研建档、或 D 与直觉背离需交叉印证时展开**；日常"哪题要改"用 D 即可，不必逢题都算两个指标
- 解读先给通俗结论再带值——如"这道题好生差生都做得差不多，几乎没有区分作用（D 只有 0.15 左右）"，而非只列系数
- 判别参考：D ≥ 0.4 优、0.3–0.4 良、0.2–0.3 尚可、< 0.2 差，**负值/近零最需警惕**（题目、答案或评分标准可能有问题）

## 3. 题目质量分级

综合 P 和 D 给出参考分级（优/良/可/待改进），并说明依据。负区分度、极端难度且低区分的题目提示命题改进方向。

## 4. 题目得分率排序

- 按每题得分率排序，定位高失分题（得分率最低的一批）
- 结合分值看"失分贡献"（低得分率 × 高分值最值得关注）

## 5. 整卷信度

- **Cronbach α**（多值/部分给分）或 **KR-20**（二值计分）为主指标，通常给这一个就够下结论
- 先给通俗结论：如"整卷内部一致性良好（比如 α 在 0.85 上下），测量结果可信"，再带阈值参考（≥0.7 可接受 / ≥0.8 好 / ≥0.9 优）；题目数少时 α 天然偏低，需说明
- **分半信度（Spearman-Brown）是可选的交叉验证**——命题质量复盘、需要坐实信度稳健性时再补，与 α 接近即互相印证
- **信度与命题缺陷联动**（有价值时给）：若存在负区分/近零区分题，可指出"剔除这些低质题后信度预计可提升到 X"，让结论可操作
- 缺 scipy 也可用 numpy 直接按公式算

## 6. 错题识别与错因分析

数据来源：逐题得分（判断对错/失分）或试卷图片+作答（模型识别）。

错因分层（关键）：

- **可由作答直接判断**：计算错误、漏答、答非所问、抄错、格式/单位错
- **需教学上下文推测**（标注"待验证"）：知识点未掌握、审题习惯、解题策略、时间分配

输出：错题清单（题号/考点/失分）、错因归类与占比、薄弱考点定位。个体错题与群体高频错题分开看。

## 7. 知识点/题型掌握（需题目-知识点映射）

- 按知识点聚合相关题目：**不只给得分率，默认下钻到"题数 / 分值占比 / 加权难度 / 平均区分度 / 平均点二列"多指标**，这样既看掌握程度也看该知识点的命题质量
- 题型维度（选择/填空/解答）同样按上述多指标聚合对比，定位哪类题型学生表现弱
- 定位班级层面薄弱知识点 + 个人层面薄弱知识点
- 一题多考点时按映射权重分摊，说明处理方式
- 无映射时：只输出高失分题，不生成知识点结论

## 8. 按分析目的选指标（不是清单越长越好）

**指标的价值在于支撑一个教学决策，不在数量。** 据用户到底想解决什么，选相应深度，别为凑"专业感"堆一堆老师看不懂的系数：

| 用户想干什么 | 给到什么就够 |
|------------|------------|
| 快速看这份卷难不难、哪几题有问题 | 难度 P、高低分组 D、高失分题清单 + 一句话结论 |
| 讲评课备课（重点讲哪里） | 上面 + 知识点得分率排序、错因归类、题型强弱 |
| **命题质量复盘 / 教研建档**（最深）| 再加 r_pb、分半信度、偏度峰度、知识点/题型多指标下钻、判别标准附录 |

- **能力是储备好的**（这些都会算），但**展开到哪层由分析目的定**，模型自己判断，不必每次全上
- 无论深浅，**先给通俗结论、再带指标值**（学 §附录的写法）；专业术语的定义统一放末尾附录，不在正文里逐个解释打断阅读
- 命题缺陷题（过易/过难/低区分/负区分）无论深浅都要点出来并给改进方向——这是试卷分析最有决策价值的部分

## 9. 判别标准表（写进报告附录，让结论可复核）

涉及专业指标的报告，末尾附一个"分析方法与判别标准"小节，列出用到的口径、阈值**和一句通俗解释**（让不懂心理测量的老师也能看懂每个指标在说什么），便于复核：

| 指标 | 通俗说法 | 计算/口径 | 判别参考 |
|------|---------|----------|---------|
| 难度 P | 这题多好得分 | 平均得分 / 满分 | 越大越易；过易 ≥0.85、过难 <0.30（结合考试性质）|
| 区分度 D | 能不能拉开好生差生 | 高低 27% 分组得分率差 | ≥0.4 优 / 0.3–0.4 良 / 0.2–0.3 可 / <0.2 差 / 负值异常 |
| 点二列 r_pb | 答对这题和总分高不高的关联 | 题得分与校正总分相关 | 与 D 同向；近零或负值需查 |
| 信度 α / 分半 | 整卷打分稳不稳、可不可信 | Cronbach α（或 KR-20）/ Spearman-Brown | ≥0.7 可接受 / ≥0.8 好 / ≥0.9 优 |

> 阈值为默认参考，可据考试性质调整并说明；不硬套。只在报告实际用到某指标时才在附录解释它，不堆没用到的。

## 输出要求

每项记录方法、样本范围、适用条件与局限、数据来源。校验时注意逐题得分之和应与整卷总分一致（见 validate 脚本）。
