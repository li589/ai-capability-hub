# 成绩分析方法（P0）

方法参考，非封闭清单。据数据条件选择，存在更合适方法可用，但需说明理由、适用条件与局限。

## 1. 描述统计

常用：均值、中位数、众数、标准差、变异系数(CV)、偏度、峰度、四分位数(Q1/Q3)、极差。

解读原则：

- 集中趋势：均值易受极值影响，偏态分布同时看中位数
- 离散程度：标准差看绝对波动，CV 看相对波动（跨科目/跨班比较用 CV）
- **判断"两极分化"不能只看标准差**，要看分布形态：直方图是否双峰、高低分段占比。标准差大也可能是均匀分散
- 偏度：正偏（右拖尾，低分聚集）/ 负偏（左拖尾，高分聚集）

## 2. 分布分析

- 频率分布：按分数段（如 0-59/60-69/70-79/80-89/90-100）统计人数与占比
- 直方图看形态，箱线图看离群与四分位
- 需要时用正态性检验（Shapiro-Wilk，小样本适用）辅助判断，但教学结论以分布形态为主

## 3. 比率指标

- 优秀率、及格率、低分率：阈值**优先用用户/学校口径**；无则用默认并显式标注（如百分制及格60、优秀85）
- 明确分母是否含缺考
- 多组比较时比率要配合绝对人数，避免小样本比率误导

## 4. 学生与群体分层

- 默认五档：优秀 / 良好 / 达标 / 临界 / 预警（阈值可自定义）
- 输出各档人数、占比、典型特征
- "临界生"（略低于及格/优秀线）对教学干预最有价值，单独标注
- 用中性表达，不用"差生"
- **有分数线/目标线场景（如高三上线）**：按线分层（上线/临界/线下），临界生用"线下 N 分内"的帮扶口径圈定；再按帮扶策略二分——**单科突破型**（某科显著低于自身均值，补该科即大幅提分）vs **均衡薄弱型**（各科均衡偏低，需系统补基础）。**"距自身均值%"比全年级 z-score 更直观**，且可据此预测"补到自身均值后的总分"，直接指导排课。
- **分层帮扶名单是"活水"而非静态**：建议配"动态进出"机制——定期小测后更新名单、过线者转巩固、名额让给下一拨临界生，避免给一份跑一次就作废的死名单。

## 5. 群体对比（班级/专业/年级/科目）

方法据数据选择：

- 描述性对比：均分、及格率、分布并列（永远先给这个）
- 差异是否"显著"需推断统计时：
  - 两组：独立样本 t 检验（近似正态）或 Mann-Whitney U（偏态/有序）
  - 多组：单因素 ANOVA（+ 事后 Tukey HSD）或 Kruskal-Wallis
  - 同一批学生多次：配对 t / Wilcoxon / 重复测量
- **只报 p 值不够**，要给效应量（Cohen's d、η²）或均值差，说明差异实际大小
- 跨科目对比先标准化（满分不同不能直接比原始分）
- 样本 < 30 提示"样本偏小，结论仅供参考"；缺 scipy 时给描述性对比并说明未做检验

## 6. 异常与需关注对象（单次横向）

- 群体内离群：IQR 法（Q1-1.5×IQR 以下）或稳健 Z 分数（基于中位数和 MAD）
- 个体偏科：某科相对该生其他科的偏离
- 群体分布异常：某班某科整体明显偏离年级
- 异常 = "需要关注"，不等于错误或能力结论
- 避免用固定阈值机械贴标签；输出需关注名单时**列全所有符合条件的学生**（不截断），每人标注关注维度（几科不及格/偏科/临界）+ 简短建议

## 7. 教学问题诊断

从统计结果落到教学层面：哪个模块/班级/群体存在短板、可能与什么教学环节相关。区分事实、判断、假设（见 diagnostic-guidelines.md）。鼓励给出解释性推断与可落地建议，交教师判断。

## 8. 默认分析清单（有数据就做，别只算一遍均分）

单班/单次成绩分析，**默认覆盖以下视角**（除非用户只要快速摘要）：

- 各科描述统计 + 强弱排序（均分/中位/标准差/三率）
- 总分分布（直方图）+ 分层（五档人数占比）
- **各科分数段分布**（哪科高分段/低分段集中）
- **性别对比**（有性别字段时）：分性别均分/中位/差距
- **偏科识别到具体学生**：列出偏科学生 + 偏弱科目 + 与均分差距
- **拔尖名单**（全部达标者）+ **需关注名单**（全部，带原因）
- **重点关注名单列全，但不铺全体流水明细**：完整成绩老师本就有，报告抄全员 N 行是冗余；只给决策对象名单（预警/临界/偏科/拔尖）。仅当教师内部使用、单班人数较少（≤约 50）且用户明确要求时，才附完整排名。

不要因"够用了"就停在均分和及格率；多视角、列全重点名单是默认预期。

## 输出要求

每个分析记录：方法、样本范围（含排除的缺考等）、适用条件与局限、数据来源。
