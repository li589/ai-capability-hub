# 课程目标达成分析（P1）

用于高校/职教课程质量评价（如工程教育认证的课程目标达成度）。

## 必备输入

缺任一项则无法计算，应列出所需材料并降级：

1. **课程目标定义**：目标列表及每个目标的达成阈值（如 0.7）
2. **考核项-目标映射**：每个考核环节/题目支撑哪些目标
3. **考核权重**：各考核环节在总评/各目标中的权重
4. **各考核项成绩**：学生在各考核项的得分

## 计算方法（常用）

课程目标 i 的达成度（班级层面）：

```
达成度_i = Σ(支撑目标i的考核项  平均得分率 × 该项对目标i的权重) / Σ权重
```

- 得分率 = 平均得分 / 满分
- 权重来自映射表，需归一化说明
- 也可先算个体达成度再取均值，说明采用哪种口径
- 达成度与阈值比较，判断是否达成

## 输出

- 各课程目标达成值 + 是否达成（对照阈值）
- 未达成目标清单
- 贡献不足的考核项（哪些环节拉低了目标）
- 数据覆盖与权重局限说明

## 注意

- 权重、阈值、映射**优先用用户/学校提供**；无则不臆造，向用户索取
- 达成度是评价口径结果，非因果结论
- 不同认证体系口径不同，说明所采用口径
