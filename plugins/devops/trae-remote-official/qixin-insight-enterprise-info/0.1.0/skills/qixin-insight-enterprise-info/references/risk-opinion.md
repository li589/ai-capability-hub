# 司法经营风险与负面舆情

## 司法与经营风险体检

适用请求：

- “看一下诉讼、处罚和经营异常”
- “司法与经营风险体检”
- “简版风险报告”
- 合作准入、供应商引入、法务复核、风控体检、尽调预审。

默认必查：

- 主体解析。
- 工商照面。
- 被执行、失信、限高。
- 行政处罚。
- 经营异常、严重违法。

按命中补查：

- 立案、开庭、法院公告、裁判文书、终本。
- 税务异常、欠税、重大税收违法。
- 股权冻结、股权出质、动产抵押、破产清算。

风险关注等级建议：

- `低关注`：主体清晰，关键维度本次未返回明显关注事项。
- `中关注`：存在轻中度事项、历史事项或需要补充核验的记录。
- `较高关注`：存在执行、处罚、经营异常、税务异常或近期集中案件等需要风控/法务复核的事项。
- `高关注`：命中失信、限高、严重违法、重大税收违法、破产清算、注销吊销等高度关注事项。

输出必须包含代表性事实、影响说明、待核验事项、数据来源和免责声明。不要输出最终合作决定。

## 司法记录判断口径

不要因“有案件”自动提高风险等级。优先判断：

- 企业身份：原告、申请人、被告、被申请人、被执行人、失信被执行人、第三人。
- 案由：是否涉及合同履约、付款、产品质量、金融借款、票据、担保、破产清算等。
- 金额：是否大额，是否可能影响履约或偿付能力。
- 时间：是否近期集中发生。
- 状态：是否未结、执行中、未履行、已结案或已履行。
- 集中度：是否多起同类案件集中出现。
- 场景相关性：是否与当前合作内容直接相关。

企业主要作为原告、案件多为维权类或知识产权类、案件分散且多为历史已结案时，不应单独导致升档。

## 负面舆情扫描

适用请求：

- “最近有没有负面舆情”
- “近 30/90 天负面新闻”
- “负面新闻有多少，是否重复转载”
- 品牌、公关、法务、商务、采购、合作准入中的声誉扫描。

默认参数：

- 默认时间窗：近 90 天；用户说“近期”可按 90 天；用户说“最近一个月”按 30 天。
- 先用启信慧眼新闻或舆情类接口获取底稿。
- 只有平台允许联网搜索且用户需求包含新闻/舆情外部核验时，才补充外网搜索。

硬性规则：

- 只输出负面舆情数量、质量、事件清单、去重说明和出处。
- 不输出舆情风险评级。
- 不调用合作风险排查类聚合风险接口替代舆情扫描。
- 事件级去重：同一事件的转载、摘编、标题变体、来源重复应归并。
- 区分事实负面、争议报道、历史旧闻、转载放大、同名误伤。

负面判定优先看：

- 行政/司法/监管处罚报道。
- 安全、质量、环保、税务、劳动、消费者投诉等实质事件。
- 经营危机、债务违约、重大纠纷、停产停业。
- 高可信来源的原创报道优先；自媒体转载或标题党只能作为弱信号。
