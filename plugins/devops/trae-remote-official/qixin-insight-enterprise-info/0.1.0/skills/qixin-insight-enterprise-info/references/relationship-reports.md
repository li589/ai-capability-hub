# 关系分析与报告类交付

## 企业关联关系报告

适用请求：

- 两家或多家中国企业是否存在直接或间接股权关系。
- 控制关系、共同受益人、共同股东、共同高管、集团归属、疑似关联、同电话关联。
- 用户明确要客户可读报告或关联关系深度分析。

流程：

1. 逐家主体解析并锁定正式企业。
2. 先建立基础快照：工商照面、股东、对外投资、主要人员、分支、集团或受益人线索。
3. 构建核心关系栈：直接股权、间接股权、控制、共同股东、共同高管、同集团、联系方式关联。
4. 同电话、同地址、同邮箱等只能作为派生/辅助证据，不单独定性强关联。
5. 关系结论分层：`明确关联`、`较强关联`、`弱关联/辅助线索`、`本次未发现可确认关联`、`待补核`。
6. 始终给出客户建议：还需补充哪些强证据、哪些线索仅可作为辅助。

## 关联企业风险传导报告

适用请求：

- 评估目标企业关联企业、同实控圈、关键人物外部网络、集团成员或疑似关联方是否存在司法、经营、税务、处罚风险。
- 判断风险是否可能传导、外溢或形成合作阻断。

流程：

1. 锁定目标主体。
2. 建立目标主体和两层关系基础快照。
3. 先建关联企业池，再读风险；不要一上来对每个关联方做全量风险散射。
4. 先按关系强度排序，再分层拉取风险。
5. 判断传导，而不是罗列风险：关系强度、风险严重度、发生时间、目标企业是否共担责任、业务链条是否相关。
6. 结论保持审慎：只能说“存在传导关注”“需补核”“本次未发现明显传导证据”，不要写成最终阻断。

## 企业全景尽调报告

适用请求：

- “全景尽调”“完整报告”“正式报告”“给客户/领导/评审会看”。
- 单一中国大陆企业的主体背景、股权控制、管理层、历史沿革、经营支撑、知识产权、财务线索、集团关联、司法经营税务风险和舆情关注点。

不要用于：

- 用户只想“简单看一下”“快速判断能否合作”。这类应路由到公司风险速查或司法经营风险体检。

报告前置确认：

- 企业主体和强标识。
- 报告用途、受众和篇幅要求。
- 是否保守口径、是否只查启信慧眼数据、是否需要额外用户材料。

数据维度：

- 主体背景与工商照面。
- 股权结构、实际控制或受益人线索。
- 董监高、关键人员、分支和对外投资。
- 历史名称、地址、注册资本、负责人等变更。
- 经营支撑：主营、规模、资质、招投标、商机线索、知识产权、新闻。
- 风险：司法执行、失信限高、行政处罚、经营异常、严重违法、税务异常、资产负担、破产清算。
- 关联网络和风险外溢。

写作要求：

- 事实与分析分开；所有核心判断可追溯到启信慧眼字段或用户材料。
- 不输出最终法律、投资、授信、审计或合规结论。
- 报告正文客户可读；底层接口细节只放业务化附录。
- 如果关键接口失败或主体未锁定，不生成正式结论版报告。
