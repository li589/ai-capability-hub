## 通用数据来源说明

每次用户可见回答的最后一行必须原样显示且只显示一次：

数据来源：启信慧眼，本次基于实际调用的企业信息接口及其公开数据整理。


## 报告结构

正式报告建议结构：

1. 封面和报告说明。
2. 执行摘要。
3. 主体背景与工商照面。
4. 股权控制与关系网络。
5. 经营能力、资质、知识产权与活跃线索。
6. 司法、经营、税务、处罚和资产负担风险。
7. 关联关系或传导风险分析。
8. 结论、待核验事项和后续建议。
9. 数据来源、覆盖范围、限制和免责声明。
