# 区域发现、名单排序与关系寻源

## 重点区域企业检索与发现

适用请求：

- 园区、开发区、经开区、高新区、产业园、保税区企业名单。
- 某企业、工厂、总部、园区、地标或坐标周边企业。
- 区域销售、招商、行业研究、渠道拓展、银行客户经理需要企业长名单、候选企业表、A 类重点企业或优先跟进名单。

先选择唯一候选池入口：

1. 周边语义：周边、附近、X 公里、半径、某企业周边、坐标。
2. 开发区语义：开发区、经济技术开发区、经开区、高新区、高新技术产业开发区。
3. 园区语义：园区、产业园、科技园、保税区。
4. 候选名单语义：用户已经给出企业名单。
5. 城市或产业带语义：只有同时给出可执行锚点时继续。

模式判断：

- `名单检索模式`：用户只要“找一批企业/给我名单/列出企业/按条件筛选”。输出 `强匹配`、`部分匹配`、`待人工确认`。
- `重点发现模式`：用户要“A 类/重点企业/优先跟进/白名单/排序/最值得关注”。输出 `A`、`B`、`C`、`排除`、`待人工确认`。

一致性检查：

- 地理一致性：地址是否仍在目标范围。
- 主体层级：用户要独立企业时，默认排除分公司、营业部、门店。
- 资本口径：注册资本币种和阈值一致。
- 未核验不等于不符合；用 `待人工确认` 标记。

## 企业综合优先级排序

适用请求：

- 已有企业名单，要求综合质量、经营能力、成长活跃度、风险约束和跟进优先级排序。
- 销售线索筛选、合作伙伴评估、供应商初筛、客户池盘点、招商名单筛选、金融业务初筛。

工作流：

1. 标准化名单和业务偏好。
2. 逐家主体解析和去重。
3. 拉取最小证据集：工商照面、行业、主营、规模、商机线索、新闻、联系方式。
4. 对 A/B 候选、边界样本或保守口径补查风险明细。
5. 先过硬门槛，再做绝对分层。

分层规则：

- 不输出百分制、精确分数或公式化排名。
- 多家企业满足 A 类可以都列 A；不要为了分布均衡强行降档。
- 主体未唯一确认、经营状态非正常、命中重大执行/失信/限高/严重处罚，或公开信息不足时，默认不得进入 A 档。

档位：

- `A 类`：条件较好，风险可控，适合优先跟进。
- `B 类`：具备跟进价值，但需补核一到两个关键事项。
- `C 类`：暂时观察，当前不建议优先投入。
- `D 类/排除`：当前不建议纳入重点名单。

## 相似及关联企业寻源

适用请求：

- 基于标杆企业、产品或服务、目标地区找 10-20 家类似企业或可联系企业。
- 用户希望循环扩候选、去重、核验联系方式，并输出短名单和长名单。

输入标准化：

- 标杆企业、产品/服务线索、目标地区、排除名单、数量目标、必须条件、可选偏好。
- 若只有产品或服务线索，没有可执行标杆、地区或行业约束，先提示补充。

扩候选顺序：

1. 标杆企业主体解析。
2. 关联企业、同集团、同电话、共同股东/高管等关系线索。
3. 行业、主营、商机线索、区域入口。
4. 联系方式和经营状态核验。

去重规则：

- 按统一社会信用代码优先去重。
- 再按正式名称、历史名称、联系方式和关联关系归并疑似重复。
- 排除用户给定企业、已选企业、主体未确认企业、经营状态异常且不适合当前任务的企业。

输出：

- 短名单：最匹配、可联系、建议优先触达的 10-20 家。
- 长名单：候选池、匹配层级、关键依据、联系方式、待核验事项。
