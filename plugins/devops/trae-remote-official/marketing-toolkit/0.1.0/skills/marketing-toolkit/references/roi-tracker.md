# 营销分析与衡量

## 北极星指标选择

指标太多等于没有指标。先选定一个北极星指标作为全队对齐的焦点，其他指标作为辅助。

按业务类型选择：

| 业务类型 | 北极星指标 | 为什么选它 | 不选什么 |
|---------|----------|----------|---------|
| SaaS / 订阅 | 净收入留存率（NRR） | 存量客户的增购和流失直接反映产品价值 | 不选 MRR——新签也能撑高 MRR，但掩盖流失 |
| 电商 / 零售 | 复购率 | 首次购买靠投放就能拉，复购靠产品力 | 不选 GMV——促销打折也能冲高 GMV |
| 内容 / 社区 | 核心行为渗透率 | 活跃不等于有价值，核心行为（发布/互动）才是 | 不选 DAU——打开不算参与 |
| B2B 企业服务 | 销售合格线索数（SQL） | 只有销售认可的线索才进入管道，比 MQL 更接近收入 | 不选线索总量——量大但质量低会拖垮销售效率 |
| App / 工具 | 次日留存率 | 用没用是第一天就知道的事 | 不选下载量——下载不等于使用 |

**选择三原则**：
- **反映核心价值**：用户体验到产品价值的行为，不是虚荣指标
- **领先于收入**：北极星指标的变化应能预测 3-6 个月后的收入变化
- **可被团队影响**：团队做什么都不能改变的数字，不适合做北极星

## 归因模型

归因回答的核心问题："一次转化，功劳该记在哪个营销触点上？" 没有完美模型，只有"最匹配你业务决策需求"的模型。与其记忆模型分类，不如从"当前要做什么分析决策"反查该用哪个模型——下表按分析目的组织，每种目的对应的模型、适用条件、误用盲区一并列出。

### 按分析目的选择归因模型

| 分析目的 | 适用模型 | 适用条件 | 误用盲区 |
|---------|---------|---------|---------|
| 渠道拉新诊断（识别谁在制造第一次接触） | 首次触点归因（First-Touch） | 品牌建设期，需验证认知渠道价值 | 完全忽略后续触点推进作用；评估中段内容营销会严重低估 |
| 临门促成分析（识别谁直接促成转化） | 末次触点归因（Last-Touch） | 决策链路短（电商 / 消费 App），多数平台默认 | 系统性压低上游渠道（内容、SEO、品牌广告）贡献，不宜用于预算分配 |
| 短链路简单场景的均值估算 | 线性归因（Linear） | 触点少、链路短 | 教育性内容与转化性广告权重相同，对两者都不公平 |
| 长决策链预算分配 | 时间衰减归因（Time-Decay） | B2B 长决策链，越近转化权重越高 | 低估早期品牌建设的长期复利，品牌广告效果常滞后数月才显现 |
| 精细化功劳还原 | 自定义 / 多触点归因（Custom / Multi-Touch） | 有数据基础设施支撑，可按阶段角色配权（如触达 40%、认知 25%、转化 35%） | 数据量不足时强行自定义会引入噪音 |

### 归因落地的两个前提

模型选定后，归因能否跑准取决于两个数据前提，二者缺一，再精细的模型也是空转：

**转化事件定义**：在分析工具中明确"什么算一次转化"——表单提交、注册、下单、付款，每个事件配置感谢页到达或事件追踪，口径需全公司统一。

**触点标记（UTM）**：所有营销链接统一打 UTM 参数（source / medium / campaign / content / term），命名规则全小写 + 下划线，未标记的流量无法归因。格式示例：`?utm_source=douyin&utm_medium=info_ad&utm_campaign=618_promo`（UTM 命名规范详见 SKILL.md）。

> 模型选择非一次性决策：建议每季度复盘一次触点分布（首次触达渠道、末次促成渠道、完整旅程触点数量），据此校准所选模型是否仍匹配当前业务链路。

## 营销漏斗指标

用户从第一次接触品牌到成为推荐者，经历多个阶段。按"认知层 / 转化层 / 经营层"三个阶段分组追踪指标。每个指标附诊断意义——指标本身没有意义，能驱动决策才有意义。

### 认知层

让目标人群看到你的内容，建立初步印象，并进一步理解你的价值。

**触达规模** — 诊断"你的内容触达了多大的人群面"
- 曝光量：内容被展示的总次数——衡量投放和内容分发的基础覆盖面
- 品牌词搜索量：用户主动搜索品牌名的频次——被动曝光不算认知，主动搜索才是认知建立的标志
- 声量份额（SOV）：你在行业信息流中的发声量占比——低于竞品说明存在感不足，需加码内容产出或投放
- 网站访问量：自然搜索 + 付费推广带来的流量——反映各渠道的引流能力

**兴趣激发** — 诊断"触达之后，他们是否愿意了解更多"
- 点击率（CTR）：从看到内容到点击进入的比例——低于行业基准说明标题或素材不够吸引
- 互动率：点赞、评论、转发的综合比率——反映内容引发反应的能力
- 跳出率（Bounce Rate）+ 页面停留时长：用户点进来是立刻走了还是停留阅读——高跳出率说明落地页和广告承诺不匹配
- 线索收集量：表单提交、资料下载、试用注册等微转化动作——这是从"感兴趣"到"愿意被联系"的分水岭

**常用工具**：百度统计 / Google Analytics、各社媒平台后台、广告投放平台仪表盘、邮件平台数据、表单提交追踪

### 转化层

推动潜在客户做出购买决策（下单、预约、注册）。

**意向转化** — 诊断"从感兴趣到采取了什么行动"
- 目标转化率：完成关键动作（注册/下单/预约）的访客占比——这是漏斗效率的核心诊断点，低于同类页面基准即需逐环节排查（不同页面类型基准差异大，参见 conversion-optimization.md 的转化率基准表，不要用统一阈值一刀切）
- 逐级转化率：从内容下载→Demo 申请→试用→付费的各级转化率——哪一级衰减最严重就重点改哪一级
- 获客成本（CAC）：获取一个新客户的营销花费；单线索成本（CPL）：获取一条线索的营销花费——不分渠道拆解就无法判断哪个渠道在亏钱

**成单质量** — 诊断"转化进来的客户值不值"
- SQL 占比：销售认可的合格线索占营销线索的比例——低于 30% 说明线索质量和销售期望脱节
- 平均签约周期：从首次接触到签约的平均天数——周期拉长说明培育环节或销售跟进出问题
- 客单价分布：新客户的金额分布——如果集中在低客单，需要调整获客渠道或定价策略

**常用工具**：CRM 系统、广告平台转化追踪、百度统计 / GA4 目标

### 经营层

让客户持续使用、降低流失，并转变为品牌的自发传播者。

**客户健康度** — 诊断"客户用得好不好，会不会走"
- 净收入留存率（NRR）：现有客户本月贡献收入 vs 上月——≥100% 说明增购覆盖了流失，是 SaaS 最核心的健康指标
- 客户留存率：留存客户占总客户的比例——需配合流失率一起看，两者互为镜像
- 流失率（Churn）：流失客户占总客户的比例——持续上升是危险信号，需结合分群排查是哪类客户在走
- NPS 趋势：净推荐值的变化方向比绝对值更重要——连续 3 个月下滑是危险信号

**口碑放大** — 诊断"客户是否在帮我们传播"
- 推荐获客数：通过老客户推荐带来的新客户数量——可直接归因到口碑效果，是成本最低的获客方式
- 客户证言 / 案例参与度：客户愿意公开背书的意愿——高参与度说明产品体验超出预期
- 平台评分：大众点评 / 知乎 / 应用商店等平台的评分——需定期监控，差评响应速度直接影响转化
- 复购率 / 增购率：老客户再次购买或升级套餐的比例——衡量客户生命周期价值是否被充分挖掘

**常用工具**：CRM、产品分析工具、客户调研、调研工具、推荐计划后台、评论平台、社交聆听

## 核心 KPI 体系

月度向高层汇报用的指标集，按"产出指标 / 获取指标 / 效率指标"三类组织。每类指标回答管理层最关心的一个问题。

### 产出指标

回答"营销花了钱，产出了什么"。

- 营销来源收入：可直接归因到营销活动的收入，需区分直接转化和辅助影响两种口径
- 营销 ROI：整体和分活动的投入产出比——按 ROI 排序决定哪些活动加码、哪些砍掉
- 管道贡献金额：营销线索进入销售管道的金额总量——衡量营销的"蓄水"能力
- 营销来源客户数：本期通过营销渠道获取的新客户数量
- MQL→SQL 转化率：营销合格线索被销售接受的比例——衡量市场和销售对齐度，低于 30% 说明两端脱节

### 获取指标

回答"获客的效率和成本怎么样"。

- 获客成本（CAC）：获取一个新客户的平均营销花费，需分渠道拆解——不分渠道的 CAC 是个无效数字
- CAC 回收周期：新客户带来收入覆盖 CAC 所需的月数——超过 12 个月需警惕商业模式可持续性
- 单线索成本：营销花费 ÷ 线索数——区分 MQL 和 SQL 两个口径，后者更能反映线索质量
- 线索到客户转化率：从线索到成单的漏斗总效率——低于 2% 说明线索质量或销售跟进有问题
- 分渠道获客成本：各渠道 CAC 拆解——最贵渠道和最便宜渠道差距超过 3 倍需优化渠道组合

### 效率指标

回答"营销投入的整体产出效率"。

- CLV : CAC 比值：客户终身价值与获客成本的比值——低于 3:1 说明获客模式不可持续
- 营销支出占营收比：衡量营销投入的合理性——需与行业基准和增长阶段匹配，早期可偏高
- 营销人效：营销团队人均贡献的收入——衡量团队效率，持续下降需排查编制或流程问题
- 增购收入占比：从现有客户获得的增购/续费收入占总收入比——衡量存量经营能力，健康值 20%+

### 分渠道 KPI

各渠道详细指标和基准值见各自专题文件：
- **邮件** KPI（open rate / CTR / conversion / unsubscribe）→ [lifecycle-touch.md](lifecycle-touch.md)
- **社媒** KPI（engagement rate / follower growth / reach）→ [channel-playbook.md](channel-playbook.md)

**付费数字广告**（百度 / 巨量引擎 / 腾讯广告 / Google / LinkedIn / Facebook）：看钱的效率——CPC（单次点击花多少）、CTR（点击率高不高说明素材行不行）、单次转化成本（花多少钱买一个转化）、ROAS（每花 1 块收回几块）、展示份额 Impression Share（你在竞拍中拿到了多少比例的展示）、质量度（百度推广）/ 质量得分 Quality Score（Google Ads 1-10 分，低于 5 分说明素材和落地页要改）

**内容营销**：看长期复利——自然搜索流量（有没有在涨）、关键词排名（多少词进了前 10、多少进了前 3）、平均页面停留（内容留不留人）、内容带来的线索（有多少人因为内容找上门）、内容下载量（白皮书 / 指南被下载多少次）、外链数（多少高质量域名引用了你）

**活动营销**（线上直播 / 线下展会）：看投入产出——注册数（有多少人报名）、到场率（报名的人来了多少——低于 40% 说明标题和实际不符）、单参会成本（活动总花费 ÷ 实际到场人数）、参会者转化率（来了的人有多少最终成单）、会后互动率（活动结束后还有多少人和你保持互动）

## 分析工具配置

工具不是越多越好，而是要确保每个工具都在正确配置、持续产生可信数据。与其按工具品类罗列清单，不如沿"数据从产生到可用"的链路来配置——数据先被**采集**、再进入**分析**、最终跨源**打通**，任何一环缺失都会让下游指标失真。

### 采集端：确保每一次行为都被正确记录

采集是所有分析的地基，数据没采准，后面看得再细也是错的。
- **UTM 参数标记**：所有营销链接统一打 source / medium / campaign / content / term，命名全小写 + 下划线，未标记流量无法归因（规范详见 SKILL.md）
- **转化目标与事件埋点**：三类转化都要配——页面型（感谢页到达）、事件型（按钮点击）、金额型（订单价值）
- **各渠道原生数据后台**：抖音企业号、小红书蒲公英、微博数据中心提供第一手互动、覆盖、粉丝增长数据，是社媒侧的采集源头

### 分析端：把记录的数据变成可决策的洞察

同一批数据，按不同分析问题分工到不同工具里看。
- **网站与用户行为**：百度统计（国内） / Google Analytics（出海）做基础流量与转化目标追踪；需要深度行为分析时上神策数据 / GrowingIO / 友盟+
- **社交媒体表现**：国内用蝉妈妈 / 飞瓜数据 / 新榜，海外用 Hootsuite / Sprout Social，追踪互动率、覆盖人数、粉丝增长、网站引流
- **付费广告效率**：百度推广（百度广告）、巨量引擎（抖音 / 今日头条广告）、腾讯广告（朋友圈 / 公众号广告），出海用 Google Ads / LinkedIn Campaign Manager / Facebook Ads Manager，追踪 CPC、CTR、ROAS、转化率
- **邮件触达**：国内用阿里云邮件推送 / 腾讯企业邮，海外用 Mailchimp / HubSpot / Klaviyo，追踪打开率、点击率、转化率、收入
- **用户反馈**：问卷星 / 腾讯问卷 / Typeform，追踪 NPS、CSAT（客户满意度评分）、CES（客户费力度）

### 打通端：跨源串联出完整的客户旅程

单个工具只能看到旅程的一段，打通才能看到全貌。
- **CRM / 线索追踪**：国内用纷享销客 / 销售易 / 探迹，海外用 HubSpot / Salesforce / Pipedrive，串联线索来源、转化率、成单金额
- 把网站分析与 CRM 接通，才能回答"网站访客何时变成了付费客户"——未打通时看到的是"页面级"转化率，打通后才是"客户级"

### 百度统计 / Google Analytics 配置要点

配置不是一次性动作，是"先采、再看、再连、再校"的循环。每一层解决一个问题。

1. **先采：UTM 参数 + 转化目标**
   - 所有活动链接统一打标——没打 UTM 的流量进来就是一锅粥，分不清谁是谁
   - 参数：source、medium、campaign、content、term，命名规则全小写+下划线（详见 SKILL.md UTM 章节）
   - 三类转化目标都要配：页面型（感谢页到达）、事件型（按钮点击）、金额型（订单价值）

2. **再看：受众画像 + 分层看板**
   - 开启人口统计与兴趣数据——不看受众画像，你的"目标用户"就停留在想象里
   - 看板分三层节奏：每天扫流量和核心转化（有没有异常）、每周比分渠道表现（谁在拖后腿）、每月算全漏斗 ROI（钱花得值不值）

3. **再连：CRM 打通**
   - 把分析平台和 CRM 接上——网站访客什么时候变成了付费客户，这个答案只有打通后才能拿到
   - 没打通时你看到的转化率是"页面级"的，打通后才是"客户级"的

4. **再校：跨工具对账**
   - 同一个转化，邮件平台记一笔、广告后台记一笔、分析平台记一笔——三个数字对不上是常态，关键是搞清楚差在哪
   - 时区设置先对齐——广告后台用 UTC、分析平台用本地时间是经典的对账陷阱

## 数据质量底线

在采信任何指标之前，先确保数据本身是可信的——基于不可信数据做的决策，比没有数据更危险。数据不会主动说自己错了，它只会"说谎"。识别下面几类最常见的"数据说谎"场景，就能在采信前拦住绝大多数错误结论。

### 场景一：口径不一，同一件事被数出两个答案

全公司对"线索""转化""活跃"的定义若不统一，各部门的数字就永远对不齐。UTM 命名不规范是最常见的"数据脏源"——同一渠道写成 "Email" 和 "email" 会被系统判为两个渠道，大小写混用、参数遗漏都会污染源头。采信前先确认：定义是否统一？所有链接是否都打了 UTM？

### 场景二：多头记账，一次转化被算成好几次

同一转化事件常被多个工具各记一次——CRM 记一笔、广告后台记一笔、分析平台记一笔，不做去重或指定单一数据源，数字能差出 2-3 倍。跨工具对账时要确认同一转化在邮件平台、广告后台、网站分析中是否吻合、差异原因是否已知（邮件数据可能滞后 24 小时）。

### 场景三：窗口错配，功劳归属被时间偷偷改写

不同平台的归因 / 转化窗口若不一致，同一转化在各平台的功劳归属会完全不同。巨量引擎、腾讯广告、百度各有自己的点击回传时间窗和转化归因周期（且多为可配置），激活 / 转化事件超出回传窗口就会被丢弃、无法归因；网站分析工具的回溯周期又和广告后台不同。对账前必须先拉齐各平台的窗口设置。（出海场景补充：GA4 关键事件回溯期默认"获客类转化 30 天、其他所有转化 90 天"，均可在归因设置中调整，不要与 Google Ads 的转化窗口口径混用）

### 场景四：埋点失效，数据"看起来在跑其实早断了"

转化追踪代码在页面改版后极易失效——约 80% 的追踪失效发生在页面改版之后，建议改版后必跑一遍转化验证。时区设置错配是另一个隐形陷阱：广告后台用 UTC、分析平台用本地时间，对账前先确认所有工具在同一时区下运行。

> **采信前的最后一问**：当前数字有没有历史基线可对比？没有参照系的指标无法判断好坏。本期是否有外部因素干扰（平台宕机、广告账户异常、节假日效应）？先排除干扰，再下结论。
