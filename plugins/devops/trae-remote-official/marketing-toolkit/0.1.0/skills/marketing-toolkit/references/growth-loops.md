# 增长循环框架

增长循环是可自我强化的营销飞轮——上一周期的产出成为下一周期的输入。与线性漏斗不同，循环不会"用完"，只会加速或减速。

## 三种核心循环

按驱动来源分为三类，根据业务模式选择主循环。

### 推荐循环（Referral Loop）

老用户带来新用户，新用户再带来更多新用户。

**触发条件**:
- 产品价值明确，用户愿意用自身信誉背书
- 推荐摩擦足够低（一键分享 / 自动生成邀请链接）
- 双方均有奖励（推荐人和被推荐人各得什么）

**放大杠杆**:
- [ ] 奖励对双方是否都有吸引力？
- [ ] 分享路径是否超过 2 步？超过则砍到 2 步以内
- [ ] 被推荐人的首次体验是否流畅？首次体验差 = 推荐人信誉受损 = 循环断裂

**关键指标**:
- 裂变系数（K-factor）= 平均每用户邀请数 × 邀请转化率；K > 1 时循环自增长
- 推荐带来的新用户占比
- 推荐用户 LTV vs 自然用户 LTV

### 内容循环（Content Loop）

用户使用产品产生内容，内容吸引新用户，新用户再产生更多内容。

**触发条件**:
- 产品能产出可被传播的内容（数据报告 / 模板 / 作品 / 评价）
- 内容对潜在用户有独立价值（不依赖产品也能看懂）
- 内容生产成本低于分发成本（用户自发传播 > 付费推广）

**放大杠杆**:
- [ ] 用户产出内容的质量是否有下限保障？低质内容会驱逐高质量用户
- [ ] 内容是否可被搜索引擎 / 社媒平台索引？
- [ ] 高绩效内容是否获得更多曝光？推荐流 / 热门榜 / 精选

**关键指标**:
- 月活中产出内容的比例
- 内容带来的自然流量占总流量比例
- 单条内容的平均分享次数（被分享 / 被引用次数）

### 病毒循环（Viral Loop）

产品使用过程本身就是传播过程——用的时候自然被别人看到。

**触发条件**:
- 产品有天然的多人协作或公开展示场景（文档协作 / 表单收集 / 落地页 / 带水印的分享）
- 非用户看到产品时能理解"这是什么"，不需要额外解释
- 未注册用户看到产品到注册的路径 < 2 分钟

**放大杠杆**:
- [ ] 产品使用中是否有自然的对外曝光点？水印 / 协作邀请 / 公开链接
- [ ] 未注册用户看到产品时的理解成本是否够低？
- [ ] 注册门槛是否可以进一步降低？免注册试用 → 一键注册

**关键指标**:
- 每用户平均带来的曝光次数
- 曝光到注册的转化率
- 裂变系数（K-factor）= 每用户带来的新用户数

## 循环选择

按业务类型匹配主循环：

| 业务类型 | 主循环 | 原因 |
|---------|--------|------|
| SaaS / 工具 | 病毒循环 | 产品使用天然有协作和分享场景 |
| UGC 平台 / 社区 | 内容循环 | 用户产出内容是核心资产 |
| 电商 / 消费品 | 推荐循环 | 复购和口碑驱动，推荐奖励可直接撬动 |
| B2B 企业服务 | 推荐循环 | 决策周期长，同行推荐是最高效的信任建立方式 |

## 搭建步骤

1. **确定主循环**：按上方表格匹配业务类型，选定一个主循环
2. **画出循环链路**：用户做 X → 产生 Y → Y 被 Z 看到 → Z 成为新用户 → Z 做 X
3. **找断裂点**：链路中哪一步转化率最低？那一步就是优先优化的地方
4. **设指标**：为循环中每一步设定一个转化率指标，按周追踪
5. **加速循环**：每月针对最低转化率环节做一次实验

## 循环健康度诊断

循环会随时间衰减。每月检查以下信号：

- 裂变系数（K-factor）是否连续 2 个月下降？
- 循环带来的新用户占比是否低于总新增的 20%？
- 推荐用户 / 内容用户的 LTV 是否趋近自然用户？趋近 = 循环质量在下降

任一信号出现，说明循环需要重新设计或优化断裂点。
