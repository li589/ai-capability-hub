# 品牌规范指南

## 写作规范

### 品牌声音

品牌声音是所有对外输出的基调。我们的声音有三个核心特质，覆盖"说什么"和"怎么说"两个层面。每次写文案时以此为准绳。

**说清楚**

读者打开你的文案是为了解决问题，不是为了欣赏文采。每个段落读完，他应该知道下一步该做什么。

- 优先用具体步骤和动作描述，不用抽象概念堆砌
- 主动语态为主，主语明确
- 看得见的地方放具体数字

**有行动**

每段内容收尾时，读者知道下一步该干什么。文案不是信息展示，是引导行动。

- CTA 具体且可执行
- 降低行动门槛，给明确路径
- 把"你"当作默认称呼

**可信赖**

用真实数据和客户故事代替空洞承诺。知道自己能做什么，不夸大；承认不足，但不自我贬低。

- 用客户的原话做证言，不替他们润色到失真
- 第一次提及品牌 / 产品名用全称，后续可用简称
- 不用「赋能 / 闭环 / 抓手 / 链路」这类内部行话

### 语气调节

声音是固定的，语气随场景调整。按"用户引导 / 销售沟通 / 公开回应 / 内部同步"四类场景匹配语气：

| 场景 | 语气方向 | 调节要点 |
|------|---------|---------|
| 用户引导（教程、帮助文档、新手引导） | 清晰、耐心、鼓励 | 步骤分明，配时间预期，遇复杂操作给安抚 |
| 销售沟通（邮件、跟进、报价） | 专业但不端着 | 直入价值，用数字说话，不套近乎 |
| 公开回应（社媒、公告、危机公关） | 正式但不冰冷 | 态度优先于解释，共情先行，不回避问题 |
| 内部同步（周报、会议纪要、文档） | 精确、简洁、不啰嗦 | 结论先行，数据和事实驱动，去掉修饰词 |

### 落笔前的四道自检

声音和语气定了方向，具体落笔时还有四个高频翻车点。与其记 DO/DON'T 清单，不如每写完一段，按下面四个维度自问一遍——问题往往就藏在这四处。

**语态与主语**：主语是"人"还是"物"？"你可以 3 步完成"优于"该功能可被使用"。坚持主动语态、主语明确，被动句和物做主语都会拉远和读者的距离。

**句子长度**：有没有一句挤了超过 40 字？读的人会喘不上气直接跳过。短句优先，一段超过 4 行就考虑拆分。

**用词**：有没有混进「赋能 / 闭环 / 抓手 / 链路」这类内部行话？内部说可以，对外说就是黑话。同理不要自创中英混写缩写——读者不会去查你造的词。多用数字少用形容词，"提升 30%"比"大幅提升"有信息量。

**称呼与证言**：有没有用第二人称"你"？它比"用户""客户"更有对话感。证言是否保留了客户原话的口语感，而不是润色到像广告文案？品牌名首次出现用全称、后续用简称，避免反复全称造成阅读负担。

**还要绕开两类"万能句"**：一是"你值得拥有""让生活更美好"这类什么产品都能套的句式，等于没说；二是把标题堆关键词堆到语句不通，搜索引擎能解析，但人会反感。

## 合规规范

### 中国广告法合规要点

在中国做营销，广告法合规是底线。以下高危词在任何对外文案中**禁止使用**：

**极限词（绝对化用语）**
- 「最 / 第一 / 唯一 / 顶级 / 极品 / 最佳 / 最好 / 最优 / 最强 / 最先进」
- 「国家级 / 世界级 / 全网第一 / 行业领先 / 排名第一」
- 「绝无仅有 / 前无古人 / 史无前例 / 万能 / 100%」

**虚假承诺类**
- 「保证 / 包过 / 必赚 / 稳赚不赔 / 零风险」
- 「治愈 / 根治 / 药到病除」（非医疗产品禁用）
- 「免费」（如非真正免费，需注明条件）

**误导性表述**
- 不得利用国家机关、国家机关工作人员名义做背书
- 不得使用医疗机构、医生、专家名义做非医疗产品背书
- 涉及数据需标明来源和统计口径

**行业特殊限制**
- **医疗 / 保健品**：不得表示功效、安全率，不得利用患者形象
- **金融 / 理财**：不得承诺收益，不得使用"保本保息"等表述
- **教育培训**：不得承诺升学率 / 通过率，不得利用升学做出明示暗示
- **房地产**：不得以项目到达时间表示距离，不得承诺升值

### 直播带货合规

- **价格**："原价"必须是 30 天内真实交易价；"全网最低价"等绝对化用语禁止使用，价格承诺须有真实交易依据
- **功效**：口播同样受广告法约束，口头承诺与详情页须一致
- **库存**：宣称"仅剩 XX 件"须与实际一致，虚构紧迫感属虚假宣传
- **食品 / 保健品**：不得宣称治疗功效，须标注"不能代替药物治疗疾病"
- **录屏留档**：直播回放保存至少 6 个月
- **主播资质**：食品、医疗、金融类须持证主播讲解

### 各平台广告审核规则

| 平台 | 审核重点 | 常见驳回原因 |
|------|---------|-------------|
| 微信朋友圈 | 落地页一致性 | 文案与落地页不符、诱导分享 |
| 抖音 / 巨量引擎 | 视频真实性 | 夸大效果、前后对比过度、极限词 |
| 小红书 | "软广"标识 | 未标注"赞助"、绝对化用语、医美违规 |
| 百度搜索 | 资质合规 | 行业资质缺失、落地页打不开、承诺表述 |
| 微博 | 话题合规 | 蹭热搜违规、抽奖未公证、涉政敏感 |

### 无障碍

无障碍不是慈善，是让更多人能用你的产品——包括视障用户、老年用户和临时受伤的用户。以下是基于 WCAG 标准的最低要求：

- 图片必须有 alt text——读屏软件靠它"看到"图片内容
- 视频必须有字幕——大量用户在静音环境浏览，听障用户也需要
- 表单字段必须有 label 标签——placeholder 不算，placeholder 会在输入时消失
- 按钮不能纯图标——除非配 aria-label，否则读屏软件无法识别
- 色对比度 ≥ 4.5:1（正文）/ 3:1（大号文字）——对比度太低，弱视用户看不见
- 所有交互元素可通过 Tab 键访问——不是所有人都能用鼠标

### SEO 基础

SEO 的本质是让搜索引擎理解你的页面内容，从而在相关搜索中展示给用户。以下是技术层面的最低要求：

- 每个页面有唯一的 title 标签（30-60 字符）——title 是搜索引擎判断页面主题的第一信号
- meta description 每页唯一（80-150 字符），含目标关键词——它出现在搜索结果摘要里，影响点击率
- URL 用短横线分词，不用下划线或中文——搜索引擎对短横线分词的解析最准确
- 图片文件名含关键词，alt text 描述图片内容——图片搜索也是流量来源
- 每个页面只有一个 H1，标题层级递进（H1 → H2 → H3）——层级混乱会让搜索引擎无法理解页面结构
- 内链用描述性锚文本，不用"点击这里"——"点击这里"对搜索引擎没有任何语义信息

## 决策流程

如果文案 / 设计拿不准是否符合品牌规范，走以下三步：

1. **对照规范**：检查本文件的 DO/DON'T 清单和声音特质，同时翻阅已批准的同类物料找参照
2. **确认定夺**：@品牌负责人或市场负责人确认，不要自己拍板
3. **留档复用**：确认结果记录在文档评论区，下次遇到类似情况有据可查
