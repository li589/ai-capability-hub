# SEO 内容策略框架

SEO 不是写完文章再加关键词，而是在选题阶段就按搜索需求规划内容。内容满足搜索意图，排名自然来。

## 搜索意图分类

每个关键词背后是不同的搜索意图，内容形态必须匹配意图，否则排名上不去。

| 意图 | 用户在找什么 | 适合的内容形态 | 示例 |
|------|------------|-------------|------|
| 信息型 | 了解某个概念或问题 | 教程、科普、百科 | "什么是留存率" |
| 商业型 | 对比方案、找最佳选择 | 测评、对比、榜单 | "报表工具哪个好" |
| 交易型 | 准备购买，找具体产品 | 产品页、定价页、试用页 | "XX报表工具价格" |
| 导航型 | 找特定网站或页面 | 品牌词落地页 | "XX官网" |

**核心原则**：商业型和交易型关键词离收入最近，优先做。信息型流量大但转化远，用来建品牌权威。

## 主题集群

不要零散写文章。用集群模型组织内容：

1. **选一个核心主题**（pillar）：你希望占领的大词，搜索量大且覆盖面广（如"用户留存"）
2. **围绕核心拆子主题**（cluster）：核心主题下的具体问题（如"留存率怎么算""留存和流失的区别""如何提升次日留存"）
3. **子主题全部链向核心主题**，核心主题也链回每个子主题

集群结构的SEO价值：搜索引擎能识别你在某个主题上的深度，整组页面的排名会互相带动。

## 关键词研究

### 选词标准

一个好关键词要同时满足三个条件：

| 条件 | 判断方法 | 达标线 |
|------|---------|--------|
| 搜索量够 | 月搜索量 | 中文 100+ / 英文 500+ |
| 竞争可控 | 搜索结果前 10 名的页面权重 | 有 2-3 个比你弱的页面 |
| 意图匹配 | 搜索这个词的人会买你的东西吗 | 能映射到产品功能或价值 |

三个条件缺一不可。只有搜索量没有购买意图的词，流量再大也不值钱。

### 内容缺口分析

找到竞品有排名、你没有的词：

1. 列出 3-5 个竞品的域名
2. 用SEO工具（百度站长/爱站/5118）拉他们的排名词
3. 和你的排名词对比，找出差集
4. 按搜索量和意图优先级排序，逐个补内容

## 页面SEO检查

每篇内容发布前，检查以下要素：

| 要素 | 规则 |
|------|------|
| title 标签 | 含目标关键词，30-60 字符，前置关键词 |
| meta description | 80-150 字符，含关键词，给出点击理由 |
| URL | 短横线分词，含关键词，不用日期和参数 |
| H1 | 全页唯一，和 title 标签不同但相关 |
| 标题层级 | H1→H2→H3 递进，不跳级 |
| 图片 | 文件名含关键词，alt text 描述图片内容 |
| 内链 | 正文链向 2-3 篇相关文章，用描述性锚文本 |
| 首 100 字 | 目标关键词出现在正文前 100 字 |

## 技术SEO底线

内容再好，技术不过关也排不上。每月检查一次：

- **收录**：在搜索引擎输入 site:你的域名，核心页面是否都在
- **速度**：首屏加载 2 秒内，超过 3 秒每多 1 秒转化降 7%
- **移动端**：移动端可用性测试无报错
- **死链**：无 404 页面，旧 URL 做 301 跳转
- **结构化数据**：产品页加 Product Schema，文章页加 Article Schema

## 内容更新策略

SEO 内容不是发完就不管了。旧文章的排名会随时间下滑。

**更新优先级**：
- 排名在第 5-15 名的页面：小幅更新即可冲进前 5，投入产出比最高
- 排名在第 2-4 名的页面：补充竞品有但你没有的内容模块
- 排名在第 20 名以后的页面：大改或重写，否则没有流量价值

**更新动作**：
- 刷新过时的数据和案例
- 补充新的子话题（搜索引擎喜欢"内容更新"信号）
- 优化 title 标签和 meta description 提升点击率
- 加新的内链指向新发布的文章
