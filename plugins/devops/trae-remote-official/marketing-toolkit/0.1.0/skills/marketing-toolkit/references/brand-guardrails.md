# 品牌视觉护栏

AI 图片生成后对照本文件校验尺寸与配色。以下规范统一所有品牌物料的视觉标准。

## 常用 AI 生成图片尺寸速查

| 用途 | 平台 / 场景 | 尺寸（px） | 比例 | 注意事项 |
|------|------------|-----------|------|---------|
| 社媒封面 | 小红书首图 | 1242×1660 | 3:4 | 文字占比≤30%，字号≥60px |
| 社媒配图 | 小红书内页 | 1080×1440 | 3:4 | 与首图风格一致 |
| 短视频封面 | 抖音竖版 | 1080×1920 | 9:16 | 安全区：顶部120px、底部180px |
| 短视频封面 | 抖音横版 | 1920×1080 | 16:9 | 知识类长内容用 |
| 社媒配图 | 抖音/朋友圈方形 | 1080×1080 | 1:1 | 朋友圈转发用 |
| 公众号封面 | 微信公众号 | 900×383 | 2.35:1 | 标题文字不要压在底部 60px |
| 信息流广告 | 社交信息流横版 | 1200×627 | 1.91:1 | 安全区内不放关键信息 |
| 落地页 Hero | 官网首屏 | 1920×600 | 16:5 | 文字叠加区背景做暗化处理 |
| 朋友圈广告 | 微信朋友圈 | 1080×1920 | 9:16 | 前 3 秒信息要在安全区内 |
| Banner | 通用横幅 | 1920×480 | 4:1 | 两侧留白，适配不同屏幕宽度 |

**安全区原则**：各平台 UI 会遮挡顶部和底部区域，关键文字和 Logo 不要放在遮挡区内。

## 色彩

### 主色
- 品牌主色（HEX）用于 Logo、标题、主 CTA 按钮
- 深色变体用于悬停状态和深色背景

### 辅助色
- 2-3 个辅助色，用于图标、分节标签、数据可视化
- 辅助色之间保持足够区分度（色相差 ≥ 30°）

### 中性色
- 灰阶序列：背景白 → 浅灰 → 中灰 → 深灰 → 文字黑
- 文字色与背景对比度 WCAG AA ≥ 4.5:1

### 配色语义
全篇一致，同一颜色在不同位置含义相同：
- 绿色 = 推荐 / 正面 / 达标
- 黄色 = 警告 / 待关注
- 红色 = 危险 / 负面 / 不达标
- 品牌色 / 中性色 = 强调

## 数据可视化配色

- 用主色 + 辅助色构建图表色板，避免纯红 / 纯绿（色盲不友好）
- 顺序型数据用同色系深浅渐变，分类型数据用不同色相
- 数据系列不超过 7 条，超过时分组或聚合
- 关键数据点用主色高亮，辅助数据用中性灰弱化
- 推荐工具色板：Tableau 10、ColorBrewer、AntV 配色方案
- 暗色模式下降低饱和度 10-20%，避免荧光感

## 字体

**中文字体**
- 标题：思源黑体 / 苹方 Bold
- 正文：思源黑体 / 苹方 Regular，字号 14-16px（网页端）
- 备用：系统中文字体栈

**英文字体**
- 标题：Inter / Helvetica Bold
- 正文：Inter / Helvetica Regular，字号 15-18px（网页端）
- 代码：JetBrains Mono / Fira Code

**AI 生成图片字体注意**：AI 图片生成工具对中文文字渲染不稳定，复杂中文标题建议生成后用设计工具叠加文字，不要依赖 AI 直接输出中文文案。

## Logo

- 最小使用尺寸：宽 120px（网页）/ 32px（favicon）
- 安全间距：Logo 四周留白不小于 Logo 高度的 50%
- 不可变形、不可改色、不可加投影
- 深色背景使用反白版本

## 暗色模式适配

- 背景色：不用纯黑（#000），用深灰（#121212 或 #1A1A1A）
- 文字色：不用纯白（#FFF），用浅灰白（#E0E0E0 或 #F5F5F5）
- 主色：适当提亮（明度 +10%），保证暗色背景上的辨识度
- 辅助色：降低饱和度，避免荧光感
- 阴影：减少使用，暗色模式下用边框或微妙高光替代
- 图片：增加轻微透明度（0.9-0.95），减少亮色图片的突兀感
