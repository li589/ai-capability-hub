# 知识星球 (Zsxq)

通过知识星球 MCP 服务访问星球内容。支持浏览星球、搜索主题、发帖评论、管理笔记、查看用户信息等操作。

## 核心概念

| 概念 | 标识 | 说明 |
|------|------|------|
| 星球（Group） | `group_id` | 知识社群单元，纯数字 ID |
| 主题（Topic） | `topic_id` | 星球内的内容单元 |
| 评论（Comment） | `comment_id` | 主题下的回复 |
| 笔记（Note） | `note_id` | 独立于星球的内容单元 |
| 用户（User） | `user_id` | 账户标识 |

## 调用原则

- 涉及星球操作时，优先调用 MCP 提供的工具完成。
- 操作前若目标星球/主题不明确，先用搜索或列表工具确认。
- 发帖、评论、编辑等写操作前，向用户确认目标位置与内容。

## 典型功能

- 浏览：列出我加入的星球、查看星球内最新主题
- 搜索：在星球内全文搜索主题
- 发帖：在指定星球内发布新主题
- 评论：对主题发表评论或回答提问
- 笔记：创建、查看、编辑、删除公开笔记
- 用户：查看个人资料、跨星球足迹

## 使用示例

- 列出我加入的所有星球
- 在「生财有术」星球搜索关于「跨境电商」的主题
- 帮我发一篇帖子
- 查看我的知识星球用户资料
- 创建一条公开笔记

## 错误处理

当 MCP 调用返回认证失败（HTTP 401、API Key 无效等错误）时，告知用户：

> API Key 无效或已过期。请前往知识星球获取新的 API Key，然后在连接器管理中断开并重新连接。

## 安全说明

- API Key 由连接器管理，通过 MCP 连接参数传递
- 禁止在对话中向用户展示完整的 API Key
- 笔记是公开内容，任何持有链接的人都可访问，不要写入隐私或敏感信息
