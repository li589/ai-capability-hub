# 人物特稿公众号爆款 · Reference

## 0. 一句话总纲

> **一个具体的人在一个具体的时刻做的一件具体的事 × 让读者"看见"这个人 × 一个能沉下来的作者姿态 = 人物特稿类爆款的最大公约数。**

人物特稿是所有品类里**最考验作者功力**的类型。写砸了是"XX 的故事你需要知道"式的百度百科；写好了是**读者读完后好像认识了这个人一辈子**。

## 0.1 教材级参考账号

如果需要更直观的对照，下列账号在**人物特稿类**长期是行业公认的头部标杆，可作为学习范本：

- **主流特稿媒体**：三联生活周刊、南方人物周刊、GQ 报道、人物、每日人物
- **深度人物调查**：谷雨实验室、真实故事计划、正面连接、极昼工作室
- **文化人物 / 艺术家**：单读、界面文化、看理想
- **商业人物**：中国企业家杂志、晚点 LatePost、界面 · 财联社·财富中文网
- **讣告 / 追忆**：三联生活周刊（讣告栏目在读者中口碑很好）、人物、新周刊

## 1. 选题

### 1.1 五种典型题面

人物特稿的选题门类多样，但常见的题面几乎都可以落到以下五种：

| 题面     | 内涵                        | 典型场景                     |
| ------ | ------------------------- | ------------------------ |
| 事件人物型  | 因为一件新闻，某个人物走到台前            | 突发事件里的关键当事人 / 大众议题里的具体人 |
| 长期跟踪型  | 持续跟着一个人物很久，凝结成一篇          | 一个手艺人 / 一个村庄的领头人 / 一个学者   |
| 讣告 / 追忆型 | 一位公众人物去世后 48-72h        | 作家 / 演员 / 科学家 / 公共知识分子    |
| 时代切片型  | 通过一个小人物折射一个更大的社会切面        | 快递员的一年 / 女工的三十年         |
| 商业人物型  | 一家公司背后的关键决策者              | 创始人 / 高管 / 关键员工          |

### 1.2 增量视角

人物特稿的增量视角**几乎全部来自采访深度和采访质量**：

- **一手采访型**：作者亲自见过人物本人，且做了足够长时间的采访
- **深度关系型**：作者和采访对象之间已经建立了信任，能拿到别人拿不到的话
- **多方交叉型**：不只采访人物本人，还采访了她 / 他的同事、家人、朋友、对手
- **档案型（讣告）**：用生平作品 / 已公开访谈 / 已公开文字，重新拼一个立体的人

### 1.3 需要绕开的选题

- 没有一手采访的"人物评论"（本质是二手信息剪贴）
- 靠外貌 / 私生活消费真人的稿子
- 把公众人物的家人 / 未成年子女作为主角
- 编造对话 / 编造细节 / 编造心理活动
- 讣告类里过度演绎逝者"未说出口"的话

## 2. 文风

### 2.1 定位

> **一个安静的、见过世面的、听得进不同版本的作者，在把这个人讲给你听——但作者本人几乎不出场。**

人物特稿的定位是**作者退到人物之后**。作者出场太多是"作者秀"，作者完全隐身是"档案"，理想位置是：**作者的镜头非常稳，但作者本人的呼吸你几乎听不到**。

### 2.1.1 先分场景：公众号版 vs 严肃媒体版（关键）

上面"作者隐身"是**三联 / 人物 / GQ 那套严肃特稿媒体**的调性，稳、克制、有距离。但**公众号个人号 / 大众向账号不是这个路子**——读者刷手机，太克制的稿子像人物小传，翻两屏就走。按 query 先判定落在哪一档：

- **严肃媒体 / 机构官号**：走上面的隐身定位，作者退到人物之后。
- **公众号个人号 / 大众向**：**作者要明显在场**。第一人称评论、带态度的判断、一两句想被截图的金句、对人物命运的感慨，都该有。参照的是"一个有观点的主理人在给你讲这个人"，不是"一份中立档案"。这一档服从主纲 §1.4「共鸣优先于正确」，克制让位于可读性。

> 一句话：**没被 query 明确指向严肃媒体，就默认按公众号版写——让作者站到台前。**

### 2.2 关键词

- **有细节** —— 只讲你能看到 / 听到 / 触到的东西
- **有克制** —— 情绪最重的地方话最少
- **有多方** —— 至少一个对立面的声音
- **有距离** —— 不俯视、不仰视、不评价、不代言

### 2.3 例外情况

- **商业人物型**里，作者可以稍微出场做行业判断
- **时代切片型**里，作者可以适度出场做时代观察
- **讣告 / 追忆型**里，作者可以出场表达"逝去"这个事实带来的重量，但不代逝者说话

## 3. 结构与独门招（示例 · 需按 query 灵活选择）

> ⚠️ 下面是人物特稿类稿子常见的赢法示例。**事件人物 / 长期跟踪 / 讣告追忆 / 时代切片 / 商业人物**各子题材侧重不同，具体按 query 灵活选择、灵活泛化。

### 独门招 1（示例）· 一个具体动作开场

**动作**：稿子第一段直接落在**这个人在某一刻正在做的一件具体的事**——"她正把最后一件行李装进车""他站在讲台上，讲义翻到第 37 页""老人把那本 1982 年出版的书从架上取下来"。**不做背景铺垫，不做身份介绍**。

**为什么这类常奏效**：人物特稿最怕开头"XX，男，X 岁，籍贯 X，是 XX 领域的重要人物"这种百科腔。**一个具体动作 = 一个立起来的人 = 读者立刻愿意跟着走**。

**变形空间**：
- 事件人物型可以从"事件发生那天她在做什么"开场
- 讣告追忆型可以从"她 / 他生前反复做的一个动作"开场
- 商业人物型可以从"她 / 他做某个关键决定的那一刻"开场

### 独门招 2（示例）· 前三段完成"这个人到底是谁"

**动作**：**前三段之内**，让读者知道：（1）这是谁；（2）她 / 他为什么值得写；（3）这篇稿子将要给一个什么样的画像。**不啰嗦、不神秘、不迂回**。

**为什么这类常奏效**：读者的耐心在人物特稿里比其他任何品类都短——你写得再美，前三段没让她知道"这是谁 & 为什么值得读"，她就滑走。**前三段是特稿的生死线**。

### 独门招 3（示例）· 一个能"被记住"的日常动作 / 私人细节

**动作**：全篇至少找一个**只属于这个人**的日常细节——一个手势、一个口头禅、一件穿旧的衣服、桌上摆的一个东西、一段每天固定的路线。这个细节要**极小、极具体、极不可替代**。

**为什么这类常奏效**：读者不会记住这个人的成就，会记住这个人手边那本翻烂的书 / 那把用了二十年的椅子 / 那句挂在嘴边的话。**私人细节 = 立体感 = 人物立起来的关键**。

**变形空间**：
- 讣告追忆型：找一个"她 / 他生前反复出现的动作或物件"——写者的书桌、演员的一句台词、科学家的一支笔
- 事件人物型：找一个"事件发生那天她 / 他身上的一个小物件"——一件外套、一部手机、一封没寄出的信
- 商业人物型：找一个"她 / 他和她 / 他的公司一起长起来的物件"

### 独门招 4（示例）· 引语克制到"最锋利的那句就够"

**动作**：全篇采访录音可能几十小时，但**只留下人物最锋利、最能立起她 / 他的那几句原话**。每一句原话都独占段落，前后留白。**不复述、不解释、不上下追加**。

**为什么这类常奏效**：**大段引语 = 采访偷懒的信号**；**短句原话独占段 = 作者做了取舍**。取舍就是特稿的手艺。

**变形空间**：
- 讣告追忆型：全篇结尾常用**逝者本人的一句原话**收束——出处清楚，不加解释
- 事件人物型：可以用当事人的一句被反复引用但没被真正听懂的话做锚点
- 商业人物型：可以用一句"她 / 他在最难的时候说过的话"做全篇转折

### 独门招 5（示例）· 至少一个对立面 / 一个不同的声音

**动作**：稿子中间**至少出现一个对立面的声音**——不同意她 / 他的同事、不欣赏她 / 他作品的评论者、和她 / 他有过冲突的前同事、一位反对她 / 他判断的学者。**这个声音要认真给，不做稻草人处理**。

**为什么这类常奏效**：人物特稿最怕单一叙事。**多方声音 = 稿子的立体感 = 读者的可信度 +10 = 作者的位置从"粉丝"升到"记者"**。

**注意**：写对立面时**要给对方一个完整、公允的位置**——不当稻草人打，不阴阳怪气。这一条是特稿的伦理护栏。

### 独门招 6（示例）· 结尾用一个动作 / 一个物件 / 一句原话收束

**动作**：结尾**不写"XX 的故事仍将继续"**这种废话。用一个**具体动作 / 一个物件 / 一句她 / 他自己的原话**收束。**用一个画面代替一个总结**。

**为什么这类常奏效**：读者读完人物特稿的期待不是"知道结论"，是**"这个人在我心里立住了"**。**一个画面 = 一个能被读者带走的记忆锚点**。

**变形空间**：
- 讣告追忆型：常用逝者生前一句原话收（出处标清楚）
- 事件人物型：常用"事件之后她 / 他仍在做的日常动作"收
- 时代切片型：可以从个人升到时代，但升维要克制
- 商业人物型：可以用一个决策的"未完成状态"收（"她仍在等 X 的最终裁决"）

## 4. 排版

### 4.1 常见参数

| 项目   | 参数           |
| ---- | ------------ |
| 正文字号 | 15-16 px     |
| 行距   | 1.75-1.9     |
| 段落长度 | 1-3 行，情绪段常独占段 |
| 段间距  | 单空行，转场处双空行     |
| 分级标题 | 长文常用一到二级标题     |

### 4.2 视觉锚点

- **短句引语独占段** 承担"人物原话高光"
- **章节小标题**（如果稿件较长）承担时间 / 场景切换
- **黑白 / 低饱和人物照** 承担审美主视觉

**倾向避开**：花哨小图标、彩色分割线、动图表情——人物特稿类**视觉越沉，人物越立**。

### 4.3 三段流水线

```
一个动作开场 —— 前三段建立"这是谁 & 为什么值得读"
中段推进 —— 场景 × 引语 × 多方 × 私人细节
静结尾 —— 一个动作 / 一个物件 / 一句原话
```

## 5. 图文

### 5.1 常见的图种

1. **人物肖像** —— 尽量用授权的、有神的照片；老照片和当下照片交替是常用手法
2. **场景照 / 工作照** —— 承担"她 / 他每天在做什么"的具体感
3. **作品图 / 手稿 / 物件** —— 讣告追忆型常用，承担"这个人留下了什么"
4. **档案图** —— 报纸、书刊页、旧照片，承担时代坐标

### 5.2 图片使用倾向

- **人物肖像必须是真人真实图** —— 按 SKILL.md §1.2「真人图硬规则」执行：联网抓官方 / 新闻媒体 / 授权图，图注注明来源。**开篇首图不允许用 AI 概念图垫底。**
- **不消费遗容 / 病榻 / 家属崩溃**类照片；未成年子女 / 家人无明确同意不放。
- 除人物本人肖像外，可用作品 / 手稿 / 物件、档案图、工作场景照——同样以真实公开图为准。

### 5.3 涉及逝者的处理

- 讣告追忆稿的照片选择偏向**生前状态好的、精神的、有识别度的**——避开病态、憔悴、正在受苦的画面
- 涉及具体家属（尤其未成年子女、老年父母）的照片，通常需要明确同意

## 6. 子风格横向对比

| 子风格       | 用途        | 文风              | 结构                | 特点              |
| --------- | --------- | --------------- | ----------------- | --------------- |
| 事件人物型      | 突发事件后 3-14 天 | 冷静、克制、多方声音     | 一个动作-事件里的位置-背景-回响 | 前三段建立"谁 & 为何值得读"|
| 长期跟踪型      | 长期项目沉淀    | 慢、深、贴近          | 场景-场景-场景-回响      | 私人细节密度是命门        |
| 讣告 / 追忆型   | 逝世后 48-72h | 沉、慢、留白、有档案感    | 一个动作-生平-作品-一句原话  | 逝者原话收束是特色       |
| 时代切片型      | 长期报道 / 观察 | 半人物半社会、克制       | 一个人-场景-时代-回响     | 从个人升到时代要克制      |
| 商业人物型      | 公司事件 / 财报后 | 半记者半分析师、有节制    | 一个决定-过程-代价-未完成时收 | 结尾常用"未完成状态"     |

## 7. 伦理红线

- **不编造对话 / 不编造心理活动 / 不编造细节**——特稿最重要的红线
- 涉及**未成年子女、家属、无关第三方**的隐私要谨慎，能不出现就不出现
- 涉及**家庭内部冲突、感情线、经济纠纷**的私人事项，除非当事人主动谈且同意刊出，尽量不写
- **对立面声音要公允**——不做稻草人、不阴阳怪气
- **引语的每一句都要有出处**（本人受访 / 公开发言 / 已公开文本），不缝合、不断章
- **讣告类稿件**：不代逝者说话，不演绎"她 / 他没说出口的想法"，不消费遗容 / 病榻 / 家属崩溃
- **AI 图不用在人物肖像位置**
- **敏感当事人（受害者、未成年、精神障碍者）**参照主流媒体处理规范，化名 / 面部处理 / 保留细节
- 商务合作稿（尤其是商业人物 / 品牌人物合作）在开头或结尾明示

## 8. 一句话收束

> **人物特稿的核心供给是"一个具体动作开场 + 一个能被记住的私人细节 + 一句锋利的原话 + 一个公允的对立面 + 一个画面式的结尾"；镜头要稳——至于作者出不出场，看场景：严肃媒体版隐身，公众号版则站到台前带观点（见 §2.1.1）。**
