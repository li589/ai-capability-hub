# 时尚生活公众号爆款 · Reference

## 0. 一句话总纲

> **一种明确的生活方式主张 × 具体到能买 / 能穿 / 能布置的选品和搭配 × 有品味的视觉 = 时尚生活类爆款的最大公约数。**

时尚生活是**"审美即价值"**的类型——读者不是来找信息，是来**校准审美 + 找到值得下单的具体物品**。稿子讲得再好，读者拿不到"具体的 SKU / 具体的搭配思路"，就不算完成任务。

## 0.1 教材级参考账号

如果需要更直观的对照，下列账号在**时尚生活类**长期是行业公认的头部标杆，可作为学习范本：

- **时尚风格**：黎贝卡的异想世界、YOHOGIRL 优阁女生、Voicer、Nowre 现客
- **穿搭 / 单品**：石榴婆报告、随易 Suyi、Miumiu-Miu 系列、AMY 张
- **家居 / 生活方式**：一条、日食记（家居栏目）、好好住、生活周刊
- **美妆 / 护肤**：抹茶美妆、大嘴博士、程十安、蕊姐微整形（专业向）
- **精品消费 / 品牌**：LADYMAX、界面时尚、时尚芭莎（数字栏目）


## 1. 选题

### 1.1 三条选题主线

时尚生活稿的选题几乎都可以落到以下三条主线里：

| 主线   | 内涵                        | 典型主题                     |
| ---- | ------------------------- | ------------------------ |
| 场景型 | "在 X 场景里应该怎么穿 / 用 / 布置"    | 通勤穿搭 / 出差好物 / 春季衣橱换季     |
| 单品型 | "这个具体的东西为什么值得"            | 一支口红拆到成分 / 一个包型的历史 / 一张沙发的选购  |
| 主张型 | "这一季 / 这个夏天，我们相信 X"        | "夏天就是要穿裙子""极简才是自由""审美要慢下来" |

### 1.2 增量视角

时尚生活的增量视角**门槛比大家想的高**：

- **审美型**：作者本人有明确的审美取向和识别度
- **信息型**：一手价格 / 一手渠道 / 一手上身效果
- **深度型**：品牌 / 单品 / 材料 / 工艺的深挖
- **对比型**：多个价位 / 多个品牌 / 多种身材的横评

### 1.3 需要绕开的选题

- 一稿千号的品牌通稿改写
- 只有产品图 + 卖点文案的软广式内容
- 假装"素人推荐"的商务合作稿
- 没有实拍 / 上身图的"种草文"

## 2. 文风

### 2.1 定位

> **一个比你时髦一点、又不端着的朋友，在她家客厅里给你翻她的衣橱 / 化妆台 / 好物清单。**

时尚生活稿的定位既不是杂志编辑（太远、太权威），也不是导购（太急、太商业）——是**审美稍高、乐意分享、有识别度**的朋友。

### 2.2 关键词

- **有主张** —— 每一篇都能提炼出作者的一句审美立场
- **有细节** —— 材质、剪裁、色号、克重、光泽度
- **有场景** —— 每一个单品都能挂到具体场合
- **有节制** —— 不夸大功效、不虚构"素人体验"

### 2.3 例外情况

- **精品消费 / 品牌深度**里，作者可以退到编辑位置，更冷静、更学术
- **家居生活方式**里，作者的私宅本身就是叙事线，"我"要出场
- **美妆护肤**里，涉及成分和功效时要更严谨，靠近科普类的边界处理

## 3. 结构与独门招（示例 · 需按 query 灵活选择）

> ⚠️ 下面是时尚生活类稿子常见的赢法示例。**穿搭 / 单品 / 家居 / 美妆 / 品牌**各子题材侧重不同，具体按 query 灵活选择、灵活泛化。

### 独门招 1（示例）· 开头先立一个"生活方式主张"

**动作**：稿子开头**先给一句明确的立场**——"我今年不再买 XX 了""秋天的第一件衣服，应该是……""极简的家不是空，是留白"。**主张要短，要能被读者复述**。

**为什么这类常奏效**：时尚生活读者的转发动机是"表达自己认同的一种活法"。**主张 = 读者的自我标签 = 转发文案**。

**变形空间**：
- 精品消费向可以用一个"数据反差"代替主张（"过去五年这个包型溢价 3 倍"）
- 品牌深度可以用一个"品牌历史点位"代替主张
- 单品拆解可以用一个"体感反差"代替主张（"我以为它会……结果它……"）

### 独门招 2（示例）· 每一个单品都挂一个场景

**动作**：讲每一个单品时，**不只说材质和风格**，而是**明确挂到一个具体场景**——"周三下班后临时被叫去吃饭穿这件""周六下午在家看书套这件""见客户但天气冷可以叠这件"。**场景越具体，转化越高**。

**为什么这类常奏效**：时尚生活的核心供给不是"这件很好看"，是"你什么时候可以穿它 / 用它 / 摆它"。**没有场景的单品 = 没有购买路径**。

**变形空间**：
- 家居向的"场景"是空间和时段（"卧室早晨的第一缕光""客厅晚上的独处两小时"）
- 美妆向的"场景"是妆容目的（"约会不带口红拿它抵""开会一支上手""夜晚小酌不脱妆的哪支"）
- 精品消费向的"场景"是长期用途（"未来五年都不会淘汰的那种"）

### 独门招 3（示例）· 用材质 / 剪裁 / 成分级细节代替感受

**动作**：讲一件东西好在哪里时，**避免只用"高级""舒服""质感"这种感受词**。落到**材质 / 剪裁 / 成分 / 克重 / 手感**级的具体描述——"18mm 桑蚕丝，垂坠感很直""烟酰胺 5% + 温和渗透基质""落地灯的光斑呈椭圆而不是圆点"。

**为什么这类常奏效**：**感受词是所有账号都在写的话——细节是能识别作者的部分**。细节 = 专业度 = 差异化 = 读者觉得这个作者"真的懂"。

**变形空间**：
- 美妆护肤在做成分细节时，注意**成分 ≠ 疗效**，避免走到医学诊断的边界
- 家居写"实测细节"（承重、耗电、噪音）比写"高级感"更有说服力
- 品牌深度可以做到"工艺细节 + 品牌历史点位"的双重深度

### 独门招 4（示例）· 分层价位 / 分层体型 / 分层预算

**动作**：给推荐时**主动分层**——"如果你预算 500 以内""如果你预算 3000+""如果你身高 155 以下""如果你是梨形身材"。**每一层给 1-2 个具体选择**。

**为什么这类常奏效**：时尚生活的最大痛点是**"这博主推的我根本用不上"**。主动分层 = 让不同的读者都能对号入座 = 完读率 + 收藏率。

**变形空间**：
- 家居向分层是"户型 × 预算"两轴（"50 平以下 + 预算 2 万")
- 美妆向分层是"肤质 × 场景"两轴（"敏感肌通勤妆")
- 单品深度可以只做"平替 / 中位 / 顶配"三档

### 独门招 5（示例）· 主动说"这件我不推荐"

**动作**：稿子中间或结尾**明确说出一件你测过但不推荐的东西**——"这件我上过身，但我不会推荐给你，原因是……"

**为什么这类常奏效**：时尚生活稿最大的信任危机是**"你是不是收了钱都推"**。主动说不推荐一件 = 立刻让读者觉得剩下的推荐可信 = **反向背书**。

**注意**：说"不推荐"时要说清楚**为什么**，避免变成对品牌的人身攻击或不实指控。

### 独门招 6（示例）· 结尾给一个"这一季 / 这一年"的审美主张

**动作**：结尾**从这一篇的具体推荐升到一个更大的审美观察**——"这个秋天我想少买一件，多穿几次""家的样子最终还是要靠时间养出来"。让读者读完带走一个可以自我认同的姿态。

**为什么这类常奏效**：时尚生活稿的读者转发理由分两层——一层是"我要种草这件"，另一层是"我认同这种活法"。**结尾的审美主张负责第二层**。

## 4. 排版

### 4.1 常见参数

| 项目   | 参数                    |
| ---- | --------------------- |
| 正文字号 | 15-16 px              |
| 行距   | 1.75-1.9              |
| 段落长度 | 1-3 行                 |
| 图文占比 | **图占重量的 50-70%**，图比字重  |
| 分级标题 | 一到二级都常见               |

### 4.2 视觉锚点

- **大图 / 高质量单品图** 承担审美主视觉
- **上身图 / 场景图** 承担"能不能想象自己穿它"
- **加粗单品标题** 承担导航
- **购买信息卡**（品牌 / 系列 / 价位 / 渠道）承担"能不能找到它"

### 4.3 三段流水线

```
主张一句话 —— 立场先立
中段推进 —— 单品 × 场景 × 分层
结尾主张 —— 升到审美 / 生活方式
```

## 5. 图文

### 5.1 常见的图种

1. **单品图** —— 干净背景、正 / 侧 / 细节三面
2. **上身 / 使用 / 空间图** —— 场景化、有环境
3. **对比图** —— 平价 vs 精品、这一款 vs 那一款
4. **细节特写** —— 材质、缝线、光泽、成分标
5. **品牌 / 历史资料图** —— 精品消费和品牌深度稿常用

### 5.2 图片使用倾向

- **图必须清晰、色准**——时尚生活稿的图不清晰几乎等于交白卷
- **实拍 > 官图**——尤其是穿搭 / 家居 / 美妆，实拍的可信度远高于品牌官图
- **P 图克制**——过度磨皮 / 过度调色会破坏可信度
- **AI 图**在这一类里**慎用**——尤其是不能用来伪造上身图、家居实拍图、试色图
- **每张图配一句说明**——说清是哪件、什么场景、什么价位

### 5.3 涉及人像的处理

- 出镜模特 / 自己出镜时，注意**是否已获得肖像使用同意**
- 用他人的街拍图时，尽量选**面部不清晰或已授权**的
- 用明星街拍时，注意**版权和授权**问题

## 6. 子风格横向对比

| 子风格     | 用途       | 文风                | 结构                | 特点             |
| ------- | -------- | ----------------- | ----------------- | -------------- |
| 穿搭 / 单品 | 每季 / 每月推 | 有主张、有场景、分层        | 主张-单品×场景-分层-审美  | 上身图 + 材质细节是命门 |
| 家居 / 生活方式 | 装修 / 换季 / 好物 | 半随笔半选品、慢、有画面感    | 家的样貌-单品-实测-审美  | 空间图占绝对重量      |
| 美妆护肤     | 换季 / 新品  | 成分派 or 体感派选一种、克制  | 主张-成分-实测-分层     | 忌把化妆品讲成药      |
| 精品消费 / 品牌 | 品牌活动 / 硬广 | 半编辑半评论、冷静、有历史坐标  | 品牌切入-单品-工艺-升维  | 商务性最强，声明要清楚   |
| 综合好物 / 清单 | 大促 / 换季 / 特辑 | 半清单半点评、有个人取向      | 清单-每件挂场景-总结    | 忌纯堆料，要有作者取向  |

## 7. 伦理红线

- **商务合作稿必须在开头或结尾明示**——"广告""合作""品牌邀约"字样清楚可见
- 不虚构"素人推荐"包装商务合作
- 涉及成分 / 疗效 / 医学效果的表述**参考广告法和相关规范**——不做疗效承诺、不写"根治""立竿见影"这类表述
- 不使用未经授权的他人肖像（街拍、明星、路人）
- **AI 图**不用来伪造"素人上身图""素人家居实拍""素人试色"
- 涉及未成年人的搭配 / 家居内容，避开成人化的性化表达
- 不做基于种族 / 身材 / 年龄的贬低性表达（"胖女孩别穿""过了 30 就不能……"）

---

## 8. 一句话收束

> **时尚生活稿的核心供给是"一个能被复述的主张 + 每一件都挂到具体场景 + 材质级细节 + 分层选择 + 一句可以自我认同的活法"；主动说'不推荐'比多推 10 件更可信。**
