# 美食旅行公众号爆款 · Reference

## 0. 一句话总纲

> **一个真的去过 / 吃过的现场 × 有画面感的私人叙述 × 落到"你也可以去"的具体信息 = 美食旅行类爆款的最大公约数。**

美食旅行是**"到场率决定可信度"**的品类。作者没到过 / 没吃过 / 没试过，任何漂亮词都无用；作者真的到了、真的吃了，一句朴素话也是硬通货。

## 0.1 教材级参考账号

如果需要更直观的对照，下列账号在**美食旅行类**长期是行业公认的头部标杆，可作为学习范本：

## 1. 选题

### 1.1 三条选题主线

美食旅行稿几乎都可以归到以下三条主线：

| 主线   | 内涵                        | 典型主题                     |
| ---- | ------------------------- | ------------------------ |
| 目的地型 | "去 X 地，应该怎么吃 / 玩 / 住"       | 城市攻略 / 一日游 / 一周游         |
| 单店 / 单菜型 | "这家店 / 这道菜为什么值"          | 一家老店的故事 / 一种地方吃法的深挖    |
| 生活方式型 | "关于食物 / 旅行，我最近相信 X"        | 慢旅 / 独游 / 家门口的三公里美食 / 断舍离行囊 |

### 1.2 增量视角

美食旅行的增量视角**门槛特别硬——必须"真的到场"**：

- **一手到场型**：作者亲自去、亲自吃、亲自试
- **深度挖掘型**：一家店的手艺 / 一道菜的来历 / 一个地方的风土
- **私人路线型**：作者本人的独特路线 / 独特品味
- **本地视角型**：本地人推荐给本地人的名单，不是给游客的名单

### 1.3 需要绕开的选题

- 网上抄一堆图 + 抄一堆点评做出"XX 十大必吃 / 必去"（一稿千号的重灾区）
- 假装"素人推荐"的商务合作稿
- 没有实拍图的探店 / 攻略
- 只吹不客观的餐厅稿 / 目的地稿

## 2. 文风

### 2.1 定位

> **一个刚从那儿回来、还没洗风尘的朋友，在你家沙发上和你讲她这一趟看到什么、吃到什么、错过什么。**

美食旅行稿的定位既不是官方推介（太假），也不是攻略搬运工（太空）——是**刚从现场回来的朋友**。

### 2.2 关键词

- **在现场** —— 作者身在其中，能闻到味道、听到声音、感到温度
- **有画面** —— 让读者仿佛看到菜色、看到街道、看到那盏灯
- **有取舍** —— 明说值不值、爱不爱、要不要去
- **落到操作** —— 什么时段去、多少钱、怎么点、怎么坐车、注意什么

### 2.3 例外情况

- **深度美食向**（人物 / 传统 / 手艺）可以退到记录人视角，作者少出场
- **孤独 / 独游主题**里，作者本人的心境就是叙事线，"我"要出场
- **城市生活 / 本地探店**要有**本地人识别度**——不是游客视角的"必吃十家"

## 3. 结构与独门招（示例 · 需按 query 灵活选择）

> ⚠️ 下面是美食旅行类稿子常见的赢法示例。**目的地攻略 / 单店探店 / 深度美食 / 旅行随笔 / 本地生活**各子题材侧重不同，具体按 query 灵活选择、灵活泛化。

### 独门招 1（示例）· 从一个感官细节开场

**动作**：稿子第一段直接给一个**具体感官细节**——一口食物的温度、一条街的声音、一间店的灯光、一段路的味道。**不介绍地点背景，不铺垫要去哪儿**。

**为什么这类常奏效**：美食旅行读者点开的第一秒就在筛"这作者真的去过吗"。**一个只有到场才能写出的感官细节 = 立刻通过筛选**。

**变形空间**：
- 深度美食向可以从"手艺的动作"开场（老板揉面的三个动作）
- 单店探店可以从"那家店的一个特别小的物件"开场（一把用了三十年的木勺）
- 旅行随笔可以从"作者自己的一个心境时刻"开场

### 独门招 2（示例）· 感官描写落到"能被想象"的层面

**动作**：写食物时，**避开"好吃""香""醇厚""层次丰富"这些万金油词**。落到**具体的口感 / 具体的温度 / 具体的对比**——"外壳咬下去有类似炸虾片的脆声""汤是那种能挂在勺子背面停两秒的稠""这个味道让我想起某年冬天奶奶炖的猪肚"。

**为什么这类常奏效**：**万金油词是所有账号都在写的话——具体感官描写是能识别作者的部分**。可想象性 = 到场证据 = 转发理由。

**变形空间**：
- 旅行景观描写可以用"参照物"（"这条巷子的宽刚好一辆自行车加一个人")
- 声音描写可以做到"分层"（"底下是海浪，中间是海鸟，最上层是远处的钟")
- 温度 / 光线描写在旅行稿里是被低估的资源

### 独门招 3（示例）· 每一站 / 每一家都挂"实用信息卡"

**动作**：讲完一家店 / 一个景点，紧跟一个**紧凑的实用信息块**——地址、营业时间、人均、招牌、预约方式、避坑提醒。放在正文里，或用引用块 / 灰底卡包起来。

**为什么这类常奏效**：美食旅行稿最大的价值不在情绪，而在**"我要去的时候能不能真的用上"**。信息卡 = 收藏率 = 长尾流量。

**变形空间**：
- 单店探店的信息卡可以更细（推荐点法 / 忌讳点法 / 拍照位置）
- 目的地攻略的信息卡可以做成大表格
- 深度美食稿如果不适合放信息卡，可以在文末统一列一个"信息小抄"

### 独门招 4（示例）· 主动说"这个我不推荐"

**动作**：稿子中间或结尾**明确说出一家 / 一个你去过但不推荐的地方**——"这家网上评分很高，但我不会推荐给你，原因是……"

**为什么这类常奏效**：美食旅行稿最大的信任危机是**"你是不是收了钱都推"**。主动列出"不推荐" = 让剩下的推荐可信 = 反向背书。

**注意**：说"不推荐"时要说清具体原因（口味 / 服务 / 卫生 / 环境），避免变成对商家的人身攻击或不实指控；涉及具体食安、卫生问题的指控要格外谨慎。

### 独门招 5（示例）· 一个只有到过的人才知道的"暗知识"

**动作**：稿子里至少埋一个**只有真的到过 / 真的懂**才知道的信息——"其实招牌菜不是 X 是 Y""周三上午来才能吃到刚出锅的""老板娘只对本地人开放一个隐藏菜单""这条路走到底比大门口那条路安静得多"。

**为什么这类常奏效**：**暗知识 = 稀缺信息 = 作者的核心资产**。读者转发的隐藏动机是"我朋友都不知道这个"。

**变形空间**：
- 深度美食：一道菜的**做法暗知识**（这个菜要用两种不同油温处理）
- 单店探店：一家店的**点法暗知识**（老板会为熟客留哪个部位）
- 目的地攻略：一条路 / 一个时段 / 一个玩法的**动线暗知识**

### 独门招 6（示例）· 结尾给一个"关于旅行 / 关于吃"的私人观察

**动作**：结尾**不写"总之欢迎大家来 XX 玩"**这种废话。给一个**私人化的、可以被读者带走的观察**——"这几年我越来越觉得，好的旅行不是去了多少地方，是……""吃这件事最贵的其实不是钱，是……"

**为什么这类常奏效**：美食旅行读者的第二层转发理由是"我认同这种活法"。**私人观察 = 生活方式的表达 = 高层次的转发**。

## 4. 排版

### 4.1 常见参数

| 项目   | 参数                    |
| ---- | --------------------- |
| 正文字号 | 15-16 px              |
| 行距   | 1.75-1.9              |
| 段落长度 | 1-3 行                 |
| 图文占比 | **图占重量的 50-70%**，图比字重  |
| 分级标题 | 目的地攻略 / 探店常用二级标题     |

### 4.2 视觉锚点

- **大图 / 场景图 / 菜品图** 承担审美主视觉
- **实用信息卡 / 灰底块** 承担地址 / 营业时间 / 人均
- **加粗店名 / 菜名** 承担导航
- **地图 / 动线图** 在多点位攻略里几乎必备

### 4.3 三段流水线

```
感官开场 —— 一个只有到场才能写出的细节
中段推进 —— 单店 / 单站 × 感官描写 × 信息卡
结尾观察 —— 一句私人化的关于吃 / 关于旅行的想法
```

## 5. 图文

### 5.1 常见的图种

1. **菜品图 / 场景图** —— 到场证据，图占重量比字大
2. **人物图** —— 手艺人、老板、同行的朋友、当地人
3. **街景图 / 环境图** —— 建立地方氛围
4. **实用图**：菜单、门牌号、路线截图、票据
5. **地图 / 动线图** —— 多点位攻略必备

### 5.2 图片使用倾向

- **图必须是实拍**——美食旅行稿里，图库图和 AI 图**几乎是可信度的自杀开关**
- **图有拍摄时间戳感**（拍摄时间、天气一致性）会增加可信度
- **人物出镜要有肖像同意**——尤其是手艺人 / 老板 / 服务员 / 路人的正脸
- **儿童 / 少数群体**的拍摄要征得同意
- **每张图配一句说明**，说清是什么、在哪、什么时候

### 5.3 涉及国境 / 敏感区域的处理

- 涉及边境地区、宗教场所、军事设施等的图片和内容要慎重
- 涉及少数民族地区、宗教场所的描写要**尊重当地风俗**
- 涉及野生动物 / 特殊动物制品的**尽量避免**，避开"猎奇消费"倾向

## 7. 伦理红线

- **商务合作稿必须在开头或结尾明示**——"广告""合作""品牌邀约"字样清楚可见
- 不虚构"素人推荐"包装商务合作
- 不使用未经授权的他人图片（他人游记图、店家官图注意版权和授权）
- **AI 图 / 图库图不用来伪造"我在现场"的证据**——这是美食旅行稿最严重的诚信问题
- 未成年 / 手艺人 / 普通路人的正脸出镜，尽量征得同意
- 少数民族 / 宗教场所 / 军事敏感区域的描写谨慎、尊重
- 具体食安 / 卫生问题的指控要基于可验证事实，避免不实评价
- 野生动物 / 特殊动物制品 / 保护植物的猎奇性内容避免
- 涉及"人均消费"数字要如实，不夸大也不刻意压低

## 8. 一句话收束

> **美食旅行稿的核心供给是"一个只有到场才能写出的感官细节 + 一个暗知识 + 每站挂实用信息卡 + 一句关于吃 / 关于旅行的私人观察"；到场率决定可信度。**
