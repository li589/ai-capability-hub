# 财经财富公众号爆款 · Reference

## 0. 一句话总纲

> **一手数据 × 敢下判断的观点 × 读者能拿去用的动作 = 财经财富类爆款的最大公约数。**

财经财富类读者是所有品类里**动机最重的**——他们要么在等一个决策、要么在等一个校验。稿子给不了其中之一，就白读。

## 0.1 教材级参考账号

如果需要更直观的对照，下列账号在**财经财富类**长期是行业公认的头部标杆，可作为学习范本：

- **宏观 / 政策解读**：智本社、饭统戴老板、经济观察报（观察家专栏）、瞭望智库
- **公司 / 行业深度**：晚点 LatePost、中国企业家杂志、财新周刊、36 氪深度
- **投资 / 二级市场**：格隆汇、聪明投资者、雪球（部分头部作者）
- **个人财富 / 理财**：起朱楼宴宾客、越女读财、简七读财
- **商业观察 / 消费**：刀法研究所、增长黑盒、消费界、窄播


## 1. 选题

### 1.1 时间窗口

财经财富类内容的时间敏感度**极高**，但比科技类更看**事件性**：

| 窗口     | 时间          | 内容类型               | 典型风格       |
| ------ | ----------- | ------------------ | ---------- |
| 事件窗口   | 0-48h       | 政策 / 财报 / 突发的第一层解读 | 快讯 / 观点型   |
| 深度窗口   | 3-14 天      | 公司深度 / 行业推演        | 深度调查型      |
| 沉淀窗口   | 30 天+       | 复盘 / 长逻辑 / 历史坐标    | 宏观思辨型      |
| 长青窗口   | 无时效         | 理财常识 / 个人财富方法      | 个人理财型      |

### 1.2 增量视角

财经财富稿的**增量视角**比任何品类都硬——没有一手就不上桌：

- **一手数据型**：财报没披露的、行业没算清的、公开数据我重算的
- **一手采访型**：CEO / 高管 / 一线员工 / 离职员工的直接原话
- **模型型**：用一个可复用的分析框架给出别人没给的结论
- **场景型**：把宏观数字翻译成"你今年会怎么样"的私人化叙事

### 1.3 需要绕开的选题

- 通稿改写（这一类里最容易被识别）
- 只有"未来可期""值得关注"这种无信息量的判断
- 没有数据支撑的荐股 / 荐基（有合规风险）
- 只讲情绪的"暴富故事""财富自由日记"

## 2. 文风

### 2.1 定位

> **一个懂行、见过市场、敢下判断、但不吹牛的分析师，在饭桌上和你分享他的看法。**

财经财富稿的定位不是学者，也不是股神——是**懂行的朋友**。学者太远，股神不可信，懂行的朋友刚好。

### 2.2 关键词

- **可核查** —— 每一个数字都能追到公开来源
- **有判断** —— 不骑墙，说得清"我认为 A 而不是 B"
- **有边界** —— 明说这个判断的前提假设是什么
- **有节制** —— 不夸大、不承诺回报

### 2.3 定位的例外情况

- **深度调查稿**（公司 / 行业深度）里，作者可以完全退到记录人位置
- **政策解读稿**里，作者可以强出场，把政策条款翻译成读者能理解的话
- **个人理财稿**里，作者的经历本身就是叙事线，"我"要出场

## 3. 结构与独门招（示例 · 需按 query 灵活选择）

> ⚠️ 下面是财经财富类稿子常见的赢法示例。**宏观解读 / 公司深度 / 二级市场 / 个人理财**各子题材侧重不同，具体按 query 灵活选择、灵活泛化。

### 独门招 1（示例）· 一个数据反差开场

**动作**：开头三句话内给出一组**读者会瞪大眼睛**的数据反差——同比、环比、同行对比都行，重点是"这个数字和大家的第一直觉不一样"。

**为什么这类常奏效**：财经读者对"反直觉数据"的兴奋度远高于故事和情绪。**一个精确数字 + 一个反直觉方向 = 立刻建立信任**。

**变形空间**：
- 宏观稿：可以用一个跨年度对比
- 公司深度：可以用一个"营收增长但净利润下滑"的剪刀差
- 个人理财：可以用一个"平均值 vs 中位数"的分层反差

### 独门招 2（示例）· 一句话结论前置，再回来论证

**动作**：**开头 400 字之内明确给出结论**——"我认为 X 而不是 Y"——然后花剩下 80% 的篇幅回来一层一层论证。

**为什么这类常奏效**：财经读者读文章不是来"跟着作者思考"，是来**校验作者的结论和自己的判断是否一致**。结论前置 = 让读者立刻知道要不要读下去 = 提高完读率。

**变形空间**：
- 深度调查稿相反——**结论一般压到最后**，因为过程本身就是价值
- 政策解读稿可以在开头给出"这条政策对哪几类人利好、哪几类人不利好"的分层判断
- 个人理财稿常在开头就给出可执行的动作（"如果你符合 X 情况，可以考虑做 Y"）

### 独门招 3（示例）· 公开信息交叉印证一个未公开事实

**动作**：把**多个公开来源的碎片**（财报数据、招股书、招聘启事、专利、诉讼、供应商名单、地方招商公告等）**拼成一个别人没拼出的结论**。每一步都给来源，每一步都是公开信息。

**为什么这类常奏效**：这是财经深度稿最有威力、也最合规的做法——**不用非公开信息，靠公开信息的拼图能力**产生独家结论。这条也是"敢说 vs 合规"的最佳解。

**示例语感**：
> ……根据 XX 公司 2025 Q2 财报的应收账款科目，其应收账款周转天数从 45 天增加到 87 天。
> 同期，我们在 XX 招聘平台上看到该公司销售岗招聘数量下降 60%。
> 交叉这两组公开数据……

### 独门招 4（示例）· 一个可复用的分析框架

**动作**：稿子中段给出一个**可以被读者带走复用的分析框架**——三层模型、四象限图、五个校验问题都行。框架要有名字、有结构、能画出来。

**为什么这类常奏效**：财经读者的一个隐藏诉求是**"我下次遇到类似情况怎么办"**。一次性结论没有复利价值，一个可复用的框架有。**框架是财经稿的高转发资产**。

**变形空间**：
- 宏观稿：政策三层拆解框架
- 公司深度：护城河 / 增长 / 治理三点校验
- 二级市场：估值 / 业绩 / 情绪三面校验
- 个人理财：收入 / 储蓄 / 投资 / 保障四账户

### 独门招 5（示例）· 明说"这个判断的前提假设"

**动作**：给出结论之后，用一段专门说明**这个判断在什么前提下成立、什么前提下不成立**。前提假设明说清楚。

**为什么这类常奏效**：财经读者最反感的是"事后诸葛亮"和"永远正确的模糊话"。**主动说明前提假设 = 作者不怕被证伪 = 作者可信度 +10**。

**示例语感**：
> 这个判断成立的前提是：（1）无风险利率维持在 2% 以下；（2）该行业的政策取向不发生反向变化；（3）龙头公司的市占率不出现快速集中。
> 如果其中任何一条被证伪，我这篇的判断就要重新做。

### 独门招 6（示例）· 结尾给一个"能拿去用"的动作 / 一个明确不给的动作

**动作**：结尾**不写"让我们拭目以待"**这种废话。要么给一个**读者能真的拿去用的动作**（个人理财稿典型），要么明确说明**这类分析不构成任何具体投资建议**（二级市场稿典型）。

**为什么这类常奏效**：财经读者对结尾的期待非常明确——"我读完这篇能做什么"。**给动作或明确不给动作**，都比模糊结尾好。

## 4. 排版

### 4.1 常见参数

| 项目   | 参数              |
| ---- | --------------- |
| 正文字号 | 15-16 px        |
| 行距   | 1.7-1.8         |
| 段落长度 | 1-3 行           |
| 分级标题 | 一到二级（正文长时候用）    |
| 数据块  | 用引用块 / 表格 / 图表卡 |

### 4.2 视觉锚点

- **表格** 承担多期数据对比、多公司横评
- **柱状 / 折线 / 饼图** 承担趋势、结构、占比
- **加粗数字** 承担关键读数（营收、增速、市占率）
- **引用块** 承担政策原文 / 高管原话

**倾向避开**：花哨的信息图、卡通配图、动图 GIF——财经类**视觉越简洁，可信度越高**。

### 4.3 三段流水线

```
一个反直觉数据开场 —— 结论前置
中段论据 —— 数据 + 交叉印证 + 框架
结尾 —— 一个动作 或 一个免责说明
```

## 5. 图文

### 5.1 常见的图种

1. **数据图表** —— 折线、柱状、饼图、表格
2. **公司 / 产品实拍** —— 财报页截图、产品截图、门店照片
3. **文档截图** —— 财报页、政策文件页、招股书页
4. **示意图** —— 商业模型、行业链路、资金流向

### 5.2 图片使用倾向

- **每张数据图必须标数据源**——Wind、Choice、公司财报、国家统计局、行业协会、券商研报都要写清楚
- **图表色彩克制**——建议不超过 3-4 种主色
- **数据轴不掐头去尾造视觉错觉**——这是财经稿最容易翻车的地方

### 5.3 合规向的注意

- **二级市场类稿件**：正文里出现具体股票代码 / 具体基金代码时，通常在开头或结尾附合规声明（"本文观点不构成投资建议""投资有风险，入市需谨慎"）
- **涉及未上市公司估值** 的判断，尽量标明估值来源和时间点
- **涉及具体从业人员** 的判断，遵循公开可查证的信息，避免推测其私人财务或家庭

## 6. 子风格横向对比

| 子风格          | 用途       | 文风              | 结构                | 特点               |
| ------------ | -------- | --------------- | ----------------- | ---------------- |
| 宏观 / 政策解读    | 政策发布后 24-72h | 半学者半分析师、结论前置    | 反差数据-结论-三层拆-预判  | 前提假设明说是命门         |
| 公司深度调查        | 公司大事件后   | 半记者半分析师、克制、多源印证 | 现场/数据切入-拼图-判断-回响 | 交叉印证是命门          |
| 二级市场观点        | 财报 / 事件驱动 | 有判断、有节制、有免责     | 结论-数据-框架-免责       | 合规声明必备           |
| 个人理财            | 无时效       | 半朋友半顾问、我出场      | 一个场景-方法-动作     | 落到具体动作，忌炫富        |
| 商业观察 / 消费     | 现象观察     | 半观察半推演、有画面感     | 现象-数据-背后驱动-推演  | 允许一定文学化，别抢干货     |

## 7. 伦理红线

- **禁止**荐股 / 荐基的具体买入卖出建议（合规红线）
- **禁止**使用非公开信息（内幕、未披露财务、盗取的商业机密）
- **禁止**在稿件里做"稳赚不赔""保证收益"的承诺
- **禁止**给具体从业人员的私人事项（家庭、财产、婚姻）做未经证实的判断
- **禁止**改动 / 掐头去尾数据轴造视觉错觉
- 数据来源尽量明示
- 商务合作稿（尤其是券商 / 基金 / 上市公司合作）在开头或结尾明示

---

## 8. 一句话收束

> **财经财富稿的核心供给是"一手数据 + 敢下判断 + 明说前提 + 给动作或给免责"；能被复用的分析框架比一次性结论更贵。**
