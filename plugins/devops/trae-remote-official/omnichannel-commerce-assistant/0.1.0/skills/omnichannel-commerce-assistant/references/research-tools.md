# Research and tool guidance

## Source order

Prefer:

1. user-provided exports and operating records;
2. official platform, regulator, tax, logistics, or marketplace documentation;
3. primary company filings, announcements, product pages, and direct competitor pages;
4. reputable research with disclosed method and date;
5. secondary commentary for context only.

Search snippets are discovery aids, not final proof.

Use public research instead of mock data whenever the question concerns observable market, platform, category, bestseller, competitor, policy, or trend information. Mock rows are never external evidence.

## Bounded workflow

1. State the business decision the research must change.
2. Write three to five evidence questions at most.
3. Set market/site, source preference, freshness need, and stop condition.
4. Batch related searches and open only the strongest sources.
5. Record claim, source, publication/effective date, applicable market/site, and caveat.
6. Stop when the recommendation no longer changes.

Use current sources for platform rules, fees, schedules, regulations, product availability, market facts, and competitor pages. Prefer official sources for high-impact rules. For a material market claim, seek one independent corroboration when practical.

## China content-commerce intelligence sources

Use third-party commercial intelligence only when it materially improves bestseller, creator, content, brand, or competitor analysis. Relevant services may include Feigua Data, Chanmama, and Newrank (official domains can be discovered from `feigua.cn`, `chanmama.com`, and `newrank.cn`). Keep vendor names and URLs secondary to the evidence question; do not make a vendor the organizing framework of the analysis.

Search with the primary platform/site, category, period, and required ranking or account view. Access may require login or a paid plan; public web results may expose only landing pages, help pages, reports, or snippets.

Open the official-domain result when possible. Record the exact platform, list name, category filter, statistical period, update date, ranking metric, and sample/coverage note. Distinguish observed page values from search snippets and from analyst inference.

Treat vendor data as directional intelligence, not audited platform truth. Do not equate account/content influence with product sales, or estimated sales with merchant settlements. Cross-check decision-critical findings with official platform pages, direct account/product pages, another independent source, or the user's own data. Never bypass login, paywalls, CAPTCHAs, or access controls; if ranking detail is inaccessible, cite only what is public and state the limitation.

## Files and browsers

- Preserve originals and inspect workbook sheets, headers, units, dates, and formulas before analysis.
- Assume users will attach files when intended. Request a re-upload only if the prompt explicitly refers to a missing file or dataset required for the requested operation.
- Use browser inspection only when page-level evidence is necessary and authorized.
- Keep signed-in account work read-only unless a specific mutation is explicitly authorized.
- Never bypass access controls, CAPTCHAs, rate limits, or platform terms.
- If a tool is unavailable, continue with a public source or labeled uncertainty. Mention an export or screenshot as an optional follow-up rather than stopping to request one; never simulate tool results.

## Evidence notes

For each external claim, retain the exact fact used, why it matters, source URL/title, date, and scope. Separate fact from inference. Do not cite a source that supports only an adjacent claim.
