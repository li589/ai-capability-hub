# 精美 PPT

“精美 PPT”是一套面向专业演示文稿的视觉设计 Skill。它帮助模型先判断沟通目标和审美方向，再把字体、颜色、密度、间距、图像行为和页面构图组织成可复用的设计系统。

## 能力

- 创建或优化工作汇报、咨询研报、教学课件、活动演示和可复用模板。
- 从参考图片或已有 PPT 中提炼视觉语言，而不是机械复刻单页。
- 提供咨询研报、正式工作汇报、社区党建、艺术市集、编辑画册和历史教学六类风格配方。
- 对页面上下空间、标题与正文间距、信息密度、小字号和重复卡片化等常见问题给出明确修正原则。
- 在 JavaScript 环境中建议使用 PptxGenJS，并提供单行数字保护和跨渲染器安全图片裁剪辅助脚本。

## 使用方式

安装插件后，可以直接提出任务，例如：

- “做一套高信息密度的咨询研报 PPT。”
- “把这套工作汇报改得更严谨，减少装饰并提升密度。”
- “参考这张图建立一个新的 PPT 视觉系统。”
- “用 PptxGenJS 制作一套可复用的历史教学模板。”

Skill 会先选择最接近的风格配方，再根据内容决定页面结构。配方提供审美方向和约束，但不会把模型锁死在固定模板中。

## 运行依赖

插件本身只包含 Skill，不包含 MCP、Connector、账号认证或外部服务。基础设计指导没有第三方运行依赖。

生成 `.pptx` 时可按环境选用 PptxGenJS。`scripts/raster-fit.mjs` 需要 Node.js 与 Sharp，用于在加入幻灯片前预裁剪图片；`scripts/pptx-text-guards.mjs` 无第三方依赖，用于降低短数字和短代码被自动换行的风险。LibreOffice 仅在需要跨应用渲染检查时使用，并非每次生成的必需项。

## 数据与隐私

插件不包含网络连接、遥测、真实凭据、令牌或私钥。用户提供的 PPT、图片和内容由当前运行环境及其权限策略处理。

## 已知限制

- 字体、图表、视频和 OOXML 图片裁剪在不同演示软件中可能存在差异。
- 若目标环境缺少指定字体，应选择可用替代字体并检查文字换行。
- 风格配方不能替代对内容真实性、引用来源和业务数据的核验。
