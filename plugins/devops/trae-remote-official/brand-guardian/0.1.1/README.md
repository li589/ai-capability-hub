# brand-guardian

Brand Guardian 是一个统一的品牌策略与治理 Skill。它帮助团队从业务目标和用户认知出发，完成品牌定位、命名与口号、信息架构、品牌声音、渠道文案、视觉方向、品牌焕新和一致性治理，并把策略转化为可以评审或执行的交付物。

## 核心能力

- **品牌定位**：明确优先用户、核心问题、品牌承诺和差异化，提炼品牌应在用户心中占据的类别、角色或使用情境。
- **命名与信息体系**：让品牌名、口号、价值主张和核心信息围绕同一个用户认知展开，避免堆叠互不关联的功能卖点。
- **品牌基础系统**：制定品牌目的、愿景、使命、价值观、人格、语气和关键信息等基础框架，并根据任务实际需要选择交付范围。
- **品牌表达与文案**：撰写或优化品牌文案、网站文案、公众号、小红书、短视频脚本等内容，保留不同渠道的表达习惯，并减少生硬、空泛的 AI 写作痕迹。
- **视觉方向**：给出配色、字体、版式、标志使用和视觉语言建议，让视觉表达服务于品牌定位，而不是套用固定风格。
- **品牌焕新与演进**：处理品牌升级、重塑、迁移和延展，说明哪些资产保留、哪些调整，以及如何分阶段推进。
- **一致性与治理**：审查跨渠道品牌表达，识别定位、视觉、语气和信息不一致的问题，并提供修正方向。
- **品牌保护**：根据任务需要提供商标、资产使用、声誉风险和品牌监测方面的策略建议。

## 工作方式

1. 明确品牌目标、优先用户、使用场景和报告读者。
2. 对多交付物任务分别定义用途、渠道和可用所需内容。
3. 需要调研时，先形成明确的品牌判断，再保留真正影响决策的证据。
4. 确定品牌应占据的用户认知，再发展命名、口号、信息架构和渠道表达。
5. 完成内容和渠道化改写后，再生成报告或可视化。

事实、战略判断和示例文案会被区分处理。市场第一、唯一、最好等事实性领先声明需要证据；“用户的第一本账”一类表达若描述的是品牌在用户生活中的角色，而不是市场排名，可以作为定位语言使用。

## 常见交付物

- 品牌诊断与核心判断
- 目标用户与品牌定位
- 品牌名、口号和信息架构
- 品牌人格、声音与语气规范
- 视觉方向和品牌表达原则
- 品牌焕新或重塑方案
- 公众号、小红书、短视频、网站等渠道内容
- 品牌一致性审查与修正建议
- 面向评审和决策的 HTML 品牌报告

在 TRAE 环境中，需要 HTML 报告时使用内置 `html-report` 完成页面呈现；只有当一张紧凑的图能明显帮助理解时，才使用内置 `dynamic-ui` 补充会话内可视化。图表只能使用内容中已有且有依据的数字，概念关系使用卡片、矩阵或其他定性图形表达。

## 使用示例

安装插件后，直接描述品牌任务即可：

```text
我们准备推出一款面向自由职业者的财务工具。请先判断品牌应该占据什么用户认知，再给出定位、名称、口号和核心信息。
```

```text
这个品牌已经运营八年，现在准备加入 AI 能力。请制定渐进式品牌焕新方案，说明哪些资产保留、哪些调整，以及如何维护老用户的信任。
```

```text
请审查这组官网、公众号和小红书文案，找出品牌声音不一致的地方，并给出统一后的表达。
```

```text
根据这份品牌定位，写一篇公众号文章、一篇小红书笔记和一个 30 秒视频脚本。
```

## 开源基础

本插件以开源 Brand Guardian 框架和 Humanizer 写作方法为内部参考，并在统一的 `brand-guardian` Skill 中完成路由和整合。相关许可证保存在：

```text
skills/brand-guardian/licenses/
```
