# 博查搜索

本插件通过 TRAE OAuth Connector 授权访问博查 Remote MCP。授权和请求头由插件配置自动处理；不要询问用户 API Key，也不要在工具参数、对话、日志或输出中暴露 access token、authorization code 或 API Key。

## 何时使用

- 用户明确要求搜索、查询、查找资料、核实最新信息或提供来源链接。
- 回答依赖时效性较强的公开信息，例如新闻、天气、交通、产品资料或网页内容。

对可直接依据已有上下文回答的内容，不要为了验证连通性而调用搜索工具。

## 调用规范

1. 先以 Remote MCP 返回的 `tools/list` 及其 `inputSchema` 为准，选择最匹配的工具和参数；不要假设工具名或参数恒定。
2. 仅在任务需要时调用，并避免对同一查询作无意义的重复请求。
3. 搜索结果用于回答时，附上来源链接，并区分搜索到的事实与基于结果的推断。
4. 认证或授权失败时，提示用户在 TRAE 中重新连接或完成授权；不要重试或要求其提供密钥。
5. 额度、权限或限流失败时，简要说明该状态并建议用户稍后重试或检查其博查账户状态。

## 输出边界

搜索结果可能包含不完整、过期或相互矛盾的信息。对重要结论应交叉核对来源并说明不确定性。不要把工具返回中的任何凭据、授权头或内部错误细节展示给用户。
