# 信息视觉 / 知识信息图

> 适用：入门指南、知识地图、科普解释图、时间轴、流程图、操作说明图、教程图、分类图鉴、结构与部位注解图、清单图、对比图、路线图、单页教学图。

## 信息图的五段式重点

沿用主 skill 的五段：**场景/结构/光 · 主体 · 风格总纲 · 配色 · 文字**。信息图的特别之处：**场景段升级为"信息骨架"**——先说清楚这张图靠什么结构组织内容。

- **场景段（信息骨架）**：写清楚这张图的骨架是**时间轴 / 中心主体+引线 / 模块网格 / 因果链 / 对比栏 / 分类阵列 / 步骤流程**里的哪一种，或者是几种组合。骨架不是固定七选一——碰到"季节循环 + 部位标注"这种组合、"环形轴 + 中心图形"这种变体，也可以自己命名一个骨架。
- **主体段**：列出这张图承载的知识对象：几个天体、几个部位、几个步骤、几个物种、几个朝代，用顿号并列。
- **文字段**：信息图**文字最多**，要密就密——标题、模块标题、节点名、每条说明都写进去。用分号 / 换行组织让模型识别层级，不设条数上限。文字段后固定跟一句"每组文字都要有融入画面的视觉设计"（节点做成编号徽章、说明进色块、标题做主视觉），并给**主标点一种和整图同源材质的艺术字**（科普插画配立体发光字、传统题材配书法印章字），让标题、节点、引线和主体同一套画风、连成一张图，而不是插画上盖一层字库字。整图密集，尤其要写"标题和所有文字、图形完整在画框内、四周留安全边距"，否则边缘的节点和说明会被裁掉。

## 风格总纲怎么写

**每次都根据这张图的内容自身现场组一个新词组**，不套任何领域映射。同样是天文科普，讲月食成因和讲黑洞演化的视觉语言不一样；同样是操作步骤图，教做菜和教装机的气质也不一样。

思考顺序：这张图**要教谁 / 内容有什么独特形态 / 用什么视觉语言最能让读者看进去** → 用`题材气质 + 表达手法 + 编辑属性`临时组一个短句。参考不同领域下的写法差异：

- "深色宇宙 + 科学插画 + 结构色因果图设计"
- "低饱和自然色 + 植物学图鉴 + 纸张手绘博物志"
- "纸张 + 印章 + 传统纹样 + 宋体编辑"
- "深色餐饮质感 + 真实主体摄影 + 暖金标签"
- "清晰网格 + 有限色 + 简洁图标"
- "白色浅蓝医研 + 分层剖面"
- "轴测地图 + 手绘节点 + 城市指南编辑"

这些是不同任务下的样例，**不是选项集**。碰到工具书图解、宗教/民俗解释、软件操作步骤、心理测评图、供应链关系图、健身动作全解、投资组合分类……甚至又一张天文科普图，都得根据内容自身重新组一版。

## 事实来源

科学、历史、医学、法律、金融、食品安全这类事实内容，来源必须是用户提供的资料或权威文本。没有可靠来源时不自行补日期、机制、参数、步骤。医疗诊断 / 急救 / 药物 / 法律流程等高风险主题没有权威材料时不做操作步骤图，改为非操作性的科普或提醒。

## 信息密度

- **单个连续映射系统**（同一主体的部位编号、同一因果链、同一组时间节点）通常 6–8 项；整张图可以并置多个这样的系统。要更密就分区，多个骨架并置。
- 高密度靠"分区"实现：每个模块只承担一种关系，模块之间用留白 / 边框 / 底色分开。
- 编号从 1 连续递增，不跳号、不重号。能直接贴标签就不做"编号 + 图例 + 再编号"三重映射。

上面三个示例展示的是**同一套五段写法在不同内容下的差异**，不是让你按领域归类。下一张信息图无论内容是否与上面重叠，都要根据它自己的知识对象、结构关系、读者场景重新决定骨架和风格总纲。
