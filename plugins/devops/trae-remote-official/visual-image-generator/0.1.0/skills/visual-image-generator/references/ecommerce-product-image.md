# 电商产品图

> 适用：电商首页主图、销售封面、详情页首屏、功效卖点图、促销图、社交媒体商品图。

## 电商图的五段式重点

沿用主 skill 的五段：**场景/材质/光 · 产品 · 风格总纲 · 配色 · 文字**。电商图的关键在**产品段的精确度**和**文字段的密度**。

- **产品段**要具体到型号、材质、附件（"哑光 316L 不锈钢保温杯和配套杯盖""磨砂精华瓶和滴管"），有参考图时补一句 `严格还原参考图中的瓶型 / 颜色 / 标签`。
- **文字段**同时承担品牌名、卖点、价格、促销机制，条数比海报多。要密就密——大促图可以列十几条卖点 + 机制 + 价格。文字段后固定跟一句"每组文字都要有融入画面的视觉设计"，并给**主标点一种艺术字形态**；卖点、价格、机制天然要做成标签胶囊 / 高亮块 / 角标，不能白字直接叠图。电商竖版图尤其容易把主标顶到最上沿被裁，**必须写"标题和所有文字完整在画框内、上下留安全边距"**。
- **治打印感（电商产品必须实拍还原，融合走场景化路线）**：让主标做成**场景里的立体物件**（悬浮亚克力字、金属立牌、灯箱字），材质和光影跟产品、背景一致；卖点标签用和产品呼应的材质（科技品用发光边框、护肤品用玻璃磨砂胶囊、食品用牛皮纸标签）；主体与文字层叠、投影落到同一平面，而不是产品照片上平铺一层字。

## 风格总纲怎么写

**每次都根据当前这件产品的具体情况现场组词组**，不套任何品类映射。同一件保温杯，做礼盒装、做户外场景、做办公桌氛围，风格总纲写法就不一样。同一支精华，走医研路线、走成分党路线、走高奢感路线、走国货新锐路线，词组也完全不一样。

思考顺序：这件产品此刻要**卖给谁 / 卖点是什么 / 用什么视觉语言最能被这类人接住** → 用`题材气质 + 表达手法 + 编辑属性`三个信号临时组一个短句。比如：

- "暖白影棚 + 简洁产品摄影 + 极简产品编辑"
- "深黑桌面 + 声波光环 + 科技编辑"
- "实验室玻璃质感 + 成分可视化 + 医研编辑"
- "夏日水花碎冰 + 高亮产品摄影 + 清爽杂志感"
- "牛皮纸礼盒 + 产地手绘 + 暖色杂志编辑"
- "大促几何色块 + 促销编辑 + 超大价格锚点"

这几个是不同任务下的例子，**不是可选项**。碰到宠物粮、汽配、母婴辅食、家电清洁、二奢包、盲盒潮玩、老字号食品、SaaS 数字商品……都自己现组，别把上面任何一个拿来套。

## 参考图使用

传多张参考图时说明各自职责（一张产品还原、一张风格、一张配色），不要求一张图既还原又借鉴。

碰到新品类，照示例的**写法习惯**（产品段具体、文字段密集、五段完整）自己组一版，别照示例的**风格方向**去套。

## 多渠道

一次要多个尺寸时不出一张万能图：首页主图（方形）文字条数少一半，只留品牌 + 一个核心卖点 + 价格；详情页首屏（竖版）可以放更多卖点；横版 Banner 产品放一侧、文字放另一侧。改的只是文字段的密度和排布语气，前四段基本一致。
