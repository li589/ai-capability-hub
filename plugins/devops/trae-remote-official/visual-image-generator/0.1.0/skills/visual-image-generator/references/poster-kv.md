# 海报 / KV / Banner

> 适用：文化活动、展览、演出、招聘、发布会、社区活动、品牌主视觉、横版 Banner。

## 海报的五段式重点

沿用主 skill 的五段：**场景/材质/光 · 主体 · 风格总纲 · 配色 · 文字**。海报的胜负手在**第三段风格总纲**，它一句话决定这张海报的字体、版式、装饰、氛围。

## 风格总纲怎么写

**每次都根据当前这张海报现场组一个新词组**，不套任何题材映射。同样是音乐现场海报，独立厂牌的地下 Livehouse 和大型音乐节的视觉语言完全不同；同样是招聘海报，互联网大厂和独立设计工作室的气质也不一样。

思考顺序：这张海报要打动谁 / 观众在看到它之前脑子里有什么参照 / 用什么手法最能超预期 → 用三个信号临时拼一个短句：

- **题材气质词**：戏剧的、朋克的、学院的、街头的、山林的、诗意的、工业的、庙堂的、地下的、赛博的……(不设列表,想到什么写什么)
- **表达手法词**：摄影 / 插画 / 手绘 / 拼贴 / 剪影 / 拓印 / 水墨 / 3D 渲染 / 版画 / 丝网……(同上,自由发挥)
- **编辑属性词**：编辑设计 / 网格排版 / 杂志感 / 印刷感 / 型录感 / 剧场版式……

组合出来的短句是**这张海报独有的**，不重复。例如：`废墟纹理拓印结合朋克手写编辑`、`高山冷调纪实摄影 + 徽章式户外海报`、`未来实验室体积光 + 瑞士网格轻 3D`——这些是不同任务下的例子,不是可选清单。

## 文字与融合

一行列完 4–7 条:主题名 + 副标 + 日期时间 + 地点 + 票价或备注。长句拆短,日期用 `08.16 SAT 20:30` 紧凑格式。要更多信息就往下加,不设上限。

融合的关键(治打印感):① 场景段点明**整张海报的媒介**(做旧丝网印刷 / 水彩插画 / 版画 等),主标用**同源材质**的艺术字;② 让文字变成图形——把日期做成超大艺术数字、把英文重复铺成背景肌理、竖排标题、做旧描边英文块;③ 主标和主体**穿插叠压**,别上图下字两层皮。

## 示例（不同题材看写法差异，不是让你从中挑一个）

```text
独立音乐现场"深夜噪音"Livehouse 演出海报；整张是做旧丝网印刷海报，地下现场舞台、黑白人群剪影、撕纸与半调网点颗粒；朋克实验编辑设计；红黑米白配色；文字："深夜噪音""灰盒乐队 × 逆流""08.16 SAT 20:30""预售 ¥88 / 现场 ¥108""东岸 LIVEHOUSE"，主标"深夜噪音"做成撕纸做旧喷漆手写字压在红色撕纸块上、与舞台剪影穿插，"08.16"做成超大做旧数字，每组文字都要有融入画面的视觉设计（信息用做旧标签、票价用高亮块）；所有文字完整在画框内，四周留安全边距，不贴边、不裁切。
```

上面四个示例题材完全不同，媒介、风格总纲、主标艺术字和文字设计都是围绕每张图独有的题材临时组合的。**即使下一张海报和上面某个例子题材相同**（也是"独立音乐现场"，也是"社区公益"），也必须根据它自己独特的情绪、场地、受众重新组一版，不要拿现成的搬。
