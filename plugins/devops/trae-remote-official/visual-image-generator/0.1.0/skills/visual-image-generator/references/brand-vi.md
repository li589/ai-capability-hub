# 品牌 VI / Logo / IP

> 适用：Logo、品牌标志、视觉识别系统、门头、包装、数字产品图标、导视、IP 与吉祥物。

## 品牌 VI 的五段式重点

沿用主 skill 的五段：**场景/材质/光 · 主体 · 风格总纲 · 配色 · 文字**。品牌 VI 的关键在**一张图只承担一件事**——要么核心标志 + 一个触点，要么三种响应式状态，要么单一包装。完整手册分开多张生成。

- **场景段**：写实际触点（咖啡豆袋、App 图标、门店门头、包装罐身），或写纯色展示背景。
- **主体段**：讲清楚标志的构成——字标气质、图形符号、独特资产（一条曲线、一个切角、一枚印章）。
- **文字段**：一般 2–3 条：品牌中文名 + 英文名 + slogan（可选），不生成成分表、地址、伪包装小字。字标本身就是核心设计、尤其不能板正——**让字标和图形符号长成一体**（笔画即图形、字嵌进器物或包装材质），用和整体同源的材质艺术字，别把字标当现成字库摆上去；标志和文字完整在画框内、留安全边距。

## 风格总纲怎么写

**每次都根据这个品牌自身现场组一个新词组**，不套任何品类映射。同样是精品咖啡，主打产地故事的和主打第三空间氛围的完全不一样；同样是儿童教育，蒙氏体系和 STEAM 编程的视觉语言也不一样。

思考顺序：这个品牌**想被谁认出 / 想传递什么态度 / 用什么形式最不像同品类竞品** → 用`题材气质 + 表达手法 + 编辑属性`临时组一个短句。参考不同品牌下的写法差异：

- "牛皮纸编辑 + 产地手绘 + 暖色杂志感"
- "极简 App 图标 + 几何标志系统 + 清爽金融编辑"
- "手绘插画品牌 + 活泼图标系统 + 暖色插画编辑"
- "极简精品品牌 + 纸质包装编辑 + 丝绒烫金"
- "野外摄影 + 徽章式标志 + 自然纹理编辑"
- "宋体标志 + 印章 + 纸墨编辑"

这些是不同品牌下的样例，**不是可选项**。碰到宠物医院、独立书店、精酿啤酒、地方文旅 IP、SaaS 产品……或者又一个精品咖啡品牌，都得根据这个品牌自己的态度重新组一版，别照上面搬。

## 示例

```text
牛皮纸咖啡豆袋近景与暖色台面；一条由等高线与烘焙曲线合并的折线穿过"山屿"二字构成完整标志，豆袋正面印着完整标志、英文名、产地路径与烘焙刻度；牛皮纸编辑感结合产地手绘；墨绿、岩灰、奶油白与烘焙铜色配色；文字："山屿咖啡""MOUNT ISLE""海拔到风味"，字标"山屿"做成手写山形笔画字、与等高线融为一体，每组文字都要有融入画面的视觉设计；标志和所有文字完整在画框内，四周留安全边距，不贴边、不裁切。
```

```text
奶油色纯色背景与柔光；一枚圆形吉祥物是抱着小书的小狐狸，旁边是儿童场馆入场牌与任务卡上的吉祥物变体；手绘插画品牌结合活泼图标系统；奶油白、暖橙、森林绿配色；文字："阅光森林""READING FOREST""小狐狸的第一本书"，字标"阅光森林"做成圆润手绘童趣字、笔画带小树叶装饰，每组文字都要有融入画面的视觉设计；标志和所有文字完整在画框内，四周留安全边距，不贴边、不裁切。
```

上面两个示例只展示"一张图承载一件事 + 具体标志构成"的写法，不指向任何品类结论。下一个品牌无论是不是咖啡、是不是儿童场馆，都必须根据这个品牌自己的态度和差异化重新组风格总纲。
