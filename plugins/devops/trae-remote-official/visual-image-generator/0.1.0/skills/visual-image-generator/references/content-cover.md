# 内容平台封面

> 适用：小红书封面、公众号首图、视频缩略图、小说与电子书封面。

## 内容封面的五段式重点

沿用主 skill 的五段：**场景/材质/光 · 主体 · 风格总纲 · 配色 · 文字**。内容封面的胜负手在**主体段有没有"这一篇才有"的证据**和**风格总纲是否贴合这一篇的情绪**。

- **主体段**：要有一个具体物件、一个具体动作、一组具体符号（五张便签、一个空椅子、一双沾泥的鞋）。不写"漂亮的女生""职场人物""美食场景"这种通用画面。
- **文字段**：条数根据篇幅需要来定——小红书结论/清单可以多列几条要点，视频缩略图两行以内更冲击，小说封面只有书名 + 作者。**治打印感**：主体段点明整张封面的媒介，主标用同源材质的艺术字，并让标题和主体穿插叠压、关键词做成超大字或高亮块，别白字平铺在空白处。封面标题极易被顶到四角贴边，**必须写"标题和所有文字完整在画框内、留安全边距"**。

## 风格总纲怎么写

**每次都根据这一篇的具体情绪现场组词组**，不套任何平台/题材映射。同样是小红书结论型帖子，讲职场真相和讲穿搭清单的视觉语言不一样；同样是小说封面，两本悬疑小说也各有各的气质。

思考顺序：这一篇最独特的**视觉证据是什么 / 读到标题的人应该有什么感觉 / 用什么形式最能传递这个感觉** → 用`题材气质 + 表达手法 + 编辑属性`临时组一个短句。参考不同题材下的写法差异：

- "结论型信息封面 + 纸张便签编辑感"
- "戏剧性动作摄影 + 悬念时刻编辑 + 明暗分离"
- "雾景纪实 + 类型化印章 + 断裂手写"
- "飘逸衬线 + 柔光摄影 + 水彩类型封面"
- "金属切角 + 体积光 + 极简未来封面"
- "宋体 + 传统纹样 + 纸张碑刻感"

这些是不同选题下的样例，**不是选项集**。碰到播客封面、纪录片海报、电子书折页、纪实专栏、AI 工具评测这类内容，甚至碰到同样题材的下一篇，都得根据当前这一篇的独特点重新组。

## 示例

```text
浅米色纸张背景与柔光；一只手正在把五张彩色便签重新排序，便签上写着"加班""关系""成长""选择""边界"；结论型信息封面结合纸张便签编辑感；米白、深灰与亮红配色；文字："30岁后""5个职场真相""越早知道越好"，主标"5个职场真相"做成粗黑手写重点字、关键词用红色高亮，每组文字都要有融入画面的视觉设计；标题和所有文字完整在画框内，四周留安全边距，不贴边、不裁切。
```

```text
雾中旧码头，七根系船桩沿透视线延伸，前六根有编号 1 到 6，最远处只剩断绳和一盏灯，水面倒影出现一个岸上没有的人影；类型化雾景编辑结合印章式类型符号；雾灰、冷蓝与暖黄灯光配色；文字："第七码头""林雾 著"，主标"第七码头"做成断裂错位的悬疑手写字、笔画像被雾侵蚀，作者名做成印章样式，每组文字都要有融入画面的视觉设计；标题和文字完整在画框内，四周留安全边距，不贴边、不裁切。
```

```text
夜色中的街边小店与暖黄灯光，一位穿围裙的老板正把热汤端上桌；戏剧性动作摄影结合悬念时刻编辑；暖橙、深棕与霓虹粉配色；文字："凌晨三点的这碗面""为什么让所有人排队"，主标"凌晨三点的这碗面"做成霓虹发光手写字、副标压在半透明深色条里，每组文字都要有融入画面的视觉设计；标题和文字完整在画框内，四周留安全边距，不贴边、不裁切。
```

上面三个示例展示的是**同一套五段写法在不同情绪下的差异**，不是让你按题材去归类。下一篇即便同样是"小红书结论型"或者"悬疑小说"，也要根据它自己独特的视觉证据重新组风格总纲、主标艺术字和文字设计。
