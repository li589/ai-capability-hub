# 视觉图像生成路由

判断任务是否属于视觉类**单图生成**，路由到对应 reference，用 `GenerateImage` tool 单次出图。如果没有 `GenerateImage` tool，则向用户要求获取生图模型的 API 和 key。

## 何时调用

最终交付物本身是一张视觉图片：海报 / 广告 KV / Banner / 电商主图 / 内容平台封面（小红书、公众号、视频号、播客等）/ 小说封面 / 视频封面 / 品牌 VI / 知识信息图（步骤、流程、时间轴、图鉴、结构注解、教程等）。

## 何时不调用

图像只是文章、公众号 / 小红书推文、PPT、视频、报告里的**内嵌配图或示意图**，交给上层写作 / 排版 skill。判定锚点：**用户要拿走的是这张图本身，还是包含它的那份文档 / 演示 / 视频**。（信息图与 dynamic-ui 的边界见 description：带"生成"即走本 skill 出图。）

## Prompt 怎么写才好

**先立一个总原则:整张图是"一件用统一媒介做出来的设计作品",不是"一张照片 + 后期盖上去的文字"。** 文字打印感、贴图感的根因就是"照片"和"字库字"是两种料,天然贴不到一起。所以优先让画面走**插画 / 绘画 / 版画 / 水彩 / 水墨 / 蜡笔 / 拼贴 / 做旧印刷**这类媒介,主标和文字用**同一种媒介"画"出来**(水墨图配书法飞白、水彩插画配手写蜡笔字、做旧印刷配撕纸做旧字)。确实要用实拍照片时,必须让文字和场景发生关系——叠压主体、承接画面光影、贴合材质,而不是老实待在空白区。

一张图的 Prompt 用**五段短句**写完,段与段之间用分号或句号分开。**只写要什么**,不写"避免、不要、禁止"。

1. **场景 / 材质 / 光**:讲清楚在哪、什么质感、什么光,并**点明整张图的媒介**(水彩插画 / 版画 / 做旧印刷海报 / 水墨 等)。写实感来自具体名词:具体地点、具体材质、具体光的时间。
2. **主体**:讲清楚画面里有什么。多物件用顿号并列,不写位置和大小。写具体型号、颜色、动作,不写"漂亮的""高端的"。
3. **风格总纲**:**一个自造的短词组**给这张图定气质,模型会自己推出版式、装饰、氛围。不管题材新旧、也不管是否似曾相识,**每张图都当场重新组一个词组**——同题材下一张也不例外。构造法:`题材气质 + 表达手法 + 编辑属性`,例如"深夜巷道摄影结合霓虹编辑设计""浮世绘线条与现代排版拼贴""潮湿雨林纪实结合博物馆图鉴排版"。追求准确、不追求正确。**这一段最重要**。reference 里出现的所有词组都是"某次任务下的样例",看写法逻辑,不要照搬到下一次。
4. **配色**:三到四个具体颜色词并置,用顿号或"与"连接。写具体色:"宣纸米黄、青花蓝、朱印红与墨黑";不写抽象词"高级感""复古"。
5. **文字**:所有要出现的字用一行列完,格式 `文字:""""""`,**紧跟一句"每组文字都要有融入画面的视觉设计,和画面同一种媒介质感,不是直接把字打在图上"**。不逐组指定处理方式(那样又变套模板),让模型自己给每组配色块 / 标签 / 层级 / 排布。**主标单独点明一种"带材质、和画面同源"的艺术字形态**(见下方硬约束)。此外,让**文字本身也成为图形**——挑一两个手法用上:超大艺术化数字或日期、重复文字铺成背景水印肌理、竖排文字、做旧描边英文块、印章徽章角标、主体与文字穿插叠压。信息图 / 电商促销 / 内容封面**要密就密,不设上限**。

## 硬约束(每条都要正向写进 Prompt)

这些是 badcase 的重灾区,靠"不提"根本防不住,必须在 Prompt 里正向落地:

- **四周留安全边距、所有文字和主体完整在画框内**:生图默认会把大标题顶到画面最上沿、把主体裁掉一半。所以 Prompt 结尾固定加一句 `主标题、主体和所有文字完整居中在画框内,四周留出安全边距,不贴边、不裁切`。这是正向要求留白,不是负向排除。
- **主标是"带材质、和画面同源"的艺术字**:中文字形不吃"编辑设计""科技编辑"这类抽象风格词,不给具体形态就 100% 回落系统黑体/宋体、变成打印感。所以文字段里给主标点明一种**带肌理、和画面同一种料**的艺术字——金箔书法(配壁画/水墨)、撕纸做旧粗黑(配做旧印刷)、手写蜡笔圆体(配水彩插画)、霓虹灯管(配夜景)、立体切割发光(配科技)、毛笔飞白(配国风)等,按这张图的媒介和风格总纲选一个同源的。**只写艺术字的长相和材质,不写"宋体""黑体"这种系统字名。**
- **文字长在画面里,不是盖在画面上**:主标和主体穿插叠压、装饰元素(涂鸦、飞溅、爪印、纹样)把文字和主体连成一片,避免"上半张照片 + 下半张白底文字"这种两层皮的版式。

## 尺寸

Prompt 只写方向。工具调用侧挑一个 `image_size`：

- 竖版 → `portrait_4_3`（3:4）或 `portrait_16_9`（9:16）；用户明确要 4:5 用 `"1600x2000"`。
- 横版 → `landscape_4_3` 或 `landscape_16_9`。
- 方形 → `square`。
- 其他非常规比例用 `"宽x高"`。
