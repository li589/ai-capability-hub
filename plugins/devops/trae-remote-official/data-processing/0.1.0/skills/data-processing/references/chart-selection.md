# 图表选择决策树

根据数据特征和用户意图选择图表类型。选好后参考"数据格式要求"列准备数据 JSON。

## 决策逻辑

```
用户想展示什么？
├── 随时间的变化趋势 → line（折线图）
├── 不同类别的对比 → bar（柱状图）
├── 各部分占整体的比例 → pie（饼图）
├── 两个变量的关系 → scatter（散点图）
├── 单变量的分布情况 → histogram（直方图）
├── 多组数据的分布差异 → boxplot（箱线图）
├── 多个维度的综合对比 → radar（雷达图）
├── 两个维度的交叉密度 → heatmap（热力图）
├── 各阶段的转化 → funnel（漏斗图）
├── 层级结构的占比 → treemap / sunburst
└── 流量的流向 → sankey（桑基图）
```

## 图表类型 × 数据格式要求

chart_render.py 接收的 JSON 数据必须符合以下格式：

| 图表类型 | chart_type值 | x_axis | y_axis | JSON数据格式示例 |
|---------|-------------|--------|--------|----------------|
| 折线图 | `line` | 时间/分类列名 | 1~N个数值列名 | `[{"月份":"1月","收入":5000,"支出":3000}]` |
| 柱状图 | `bar` | 分类列名 | 1~N个数值列名 | `[{"部门":"技术","人数":50,"薪资":20000}]` |
| 饼图 | `pie` | 名称列名 | 1个数值列名 | `[{"品类":"电子","销售额":156000}]` |
| 散点图 | `scatter` | 数值列名(X) | 1个数值列名(Y) | `[{"身高":170,"体重":65}]` |
| 直方图 | `histogram` | 数值列名 | (不需要) | `[{"分数":85},{"分数":92}]` |
| 箱线图 | `boxplot` | (不需要) | N个数值列名 | `[{"数学":85,"语文":90,"英语":78}]` |
| 雷达图 | `radar` | 指标列名 | N个系列列名 | `[{"指标":"速度","产品A":8,"产品B":6}]` |
| 热力图 | `heatmap` | 行分类列名 | 列分类列名 | `[{"行":"周一","列":"9点","值":50}]`（第3列为值） |
| 漏斗图 | `funnel` | 阶段列名 | 1个数值列名 | `[{"阶段":"浏览","人数":10000}]` |
| 树图 | `treemap` | 名称列名 | 1个数值列名 | `[{"品类":"电子","销售额":156000}]` |
| 旭日图 | `sunburst` | 名称列名 | 1个数值列名 | `[{"品类":"电子","销售额":156000}]` |

## 选择建议

- 数据有**时间列** → 优先考虑 line
- 分类 ≤ 8 个且关注**占比** → pie
- 分类 > 8 个或关注**绝对值对比** → bar
- 想看两个**数值变量的关系** → scatter
- 想看**数据分布**是否正态/偏态 → histogram
- 多组数据想对比**分布差异**（中位数、离群值）→ boxplot
- 想**多维度综合评分** → radar
- 数据量大时折线图/柱状图自动启用 dataZoom 滑块

## 多图表仪表板

当用户说"做个看板"时，组合多种图表：
- 顶部放 KPI 指标卡（从数据中提取关键统计值）
- 主体放 2-4 个互补图表（趋势+对比+占比）
- 使用 `--dashboard` 模式调用 chart_render.py

## 场景化推荐示例

### 员工/HR数据分析
数据特征：有部门(分类)、满意度/薪资/加班(多数值)、是否离职(分组标记)

推荐组合：
- **pie**：各部门人数占比
- **bar**：各部门离职率/满意度/加班对比
- **scatter**：加班时长 vs 满意度（按离职状态分色）— 揭示"加班越多满意度越低"
- **radar**：部门综合画像（人数/满意度/薪资/加班/离职率标准化到同一尺度）

散点图使用场景：当你想展示**两个数值变量之间是否存在关系**时用散点图。特别是：
- X轴和Y轴都是数值列
- 想看是否存在正相关/负相关/聚类
- 有分组标记（如在职/离职）可以用不同颜色区分

雷达图使用场景：当你想**在多个维度上对比几个实体**时用雷达图。特别是：
- 有3-8个指标维度
- 要对比2-5个实体（如部门、产品、时间段）
- 指标尺度不同需要标准化

### 销售/电商数据分析
数据特征：有时间(月份)、品类(分类)、销售额/数量(数值)

推荐组合：
- **line**：月度销售趋势（多系列对比各品类）
- **bar**：品类销售额排名
- **pie**：各品类销售额占比

### 运营数据看板
数据特征：有渠道/阶段(分类)、UV/PV/转化率(数值)

推荐组合：
- **funnel**：用户转化漏斗（浏览→加购→下单→支付）
- **bar**：各渠道流量对比
- **line**：日/周趋势

### 财务/成本数据
数据特征：有科目/部门(分类)、金额(数值)、时间(月份)

推荐组合：
- **treemap**：费用科目占比（层级结构）
- **line**：月度成本趋势
- **bar**：部门预算vs实际对比
