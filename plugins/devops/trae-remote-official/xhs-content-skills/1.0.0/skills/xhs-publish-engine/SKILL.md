# 发布 + 冷启动 + 多赛道速查

---

## 一、发布前自查清单（10 项，全部打勾才能发）

| # | 检查项 | 标准 | 不通过 → |
|:---|:---|:---|:---|
| 1 | 标题 ≤ 20 字 | 数字数，emoji 算 1 字 | 删废词 |
| 2 | 前 10 字含搜索词 | 小红书搜索框输入验证 | 换词或调顺序 |
| 3 | 开头前 40 字是钩子 | 具体场景/人物/数字，不是背景 | 重写开头 |
| 4 | 正文有 3+ 硬信息 | 具体数字/价格/时间/步骤 | 逐段补硬信息 |
| 5 | 无违规词 | 对照七类禁区扫描 | 删或替换 |
| 6 | CTA 无诱导互动 | 无"免费/送/领/抽/扣1/帮你"等 | 改用安全模板 |
| 7 | CTA 是开放讨论 | 真诚提问，不是"欢迎来玩""快来体验" | 改为具体问题 |
| 8 | 话题 ≤ 5 个 | 搜索型 ≥ 3 个，热度型 1-2 个 | 减到 5 个 |
| 9 | #AI辅助创作 已加 | AI 参与 → 必加，不加会被降权 | 加上 |
| 10 | 置顶评论已备好 | 30 字+，补充正文没说的实用信息 | 写好再发 |

## 二、冷启动强制 SOP（发布后 30 分钟）

### 发布前 5 分钟

1. **过完 10 项自查**——不通过不发布
2. **写好置顶评论草稿**——补充正文没说的实用信息。示例：
   - 景区："补充：周末停车位紧张，建议10点前到。大巴最晚一班下午5点。"
   - 民宿："房间都有地暖，冬天光脚踩也不冷。提前 3 天订有早鸟价。"
3. **确认分享渠道**——朋友圈文案写好了吗？发哪个群？

### 发布后 0-5 分钟

1. **立即发置顶评论**（30 字以上，补充有用信息）
2. **分享到朋友圈**——截图笔记封面，配一句钩子话，不要只说"发了新笔记"
3. **分享到 1-2 个精准群**——挑你说话别人会回的群，不要群发

### 发布后 5-30 分钟

1. **找 2-3 人真实互动**——在评论区问不同的具体问题
   - ❌ "写得好""学习了""赞"
   - ✅ "山里蚊子多吗？""适合带 2 岁娃吗？""秋天去会不会更美？"
2. **认真回复每一条评论**——不是"私信你了"，是认真回答完再顺带引导

### 为什么冷启动这么重要

> 实测数据：跳过冷启动 → 曝光约 23；执行冷启动 → 曝光约 500-600。这是 20 倍的差距。

## 三、8 大赛道速查

> 本 Skill 通用框架适配以下赛道。使用时替换关键词、内容角度和硬信息类型。

### 赛道 1：🏔️ 景区/文旅

| 维度 | 内容 |
|:---|:---|
| 标题核心词 | `[城市]周边游` `[景区名]攻略` `[季节]避暑/赏花/滑雪` `周末去哪` |
| 正文必含信息 | 怎么去（自驾/公共交通/路况）/ 花多少（门票+停车+餐饮）/ 什么时间去最好 / 适合谁（亲子/情侣/老人）/ 容易踩的坑 |
| 内容角度 | 单点种草 / 实用攻略 / 季节限定 / 合集推荐 / 互动讨论 |
| 封面重点 | 实拍+季节感+关键信息叠加，航拍视角 CTR 高 |
| 常见坑 | 堆形容词没硬信息 / 写成景区宣传册 / 不写价格和交通 |
| 标题示例 | "成都40℃‼️这个古镇只有18℃的清凉""距上海2h，我找到了能看云海的露营地" |

### 赛道 2：🏠 民宿/酒店

| 维度 | 内容 |
|:---|:---|
| 标题核心词 | `[城市]民宿` `[景区]附近住宿` `[地名]度假酒店` `[人群]亲子民宿` |
| 正文必含信息 | 房型+价格 / 实际入住体验（热水/隔音/早餐/床品）/ 周边有什么 / 适合什么季节 / 提前多久订 |
| 内容角度 | 体验种草 / 周边攻略 / 套餐推荐 / 设计感+空间细节 |
| 封面重点 | 房间实拍+窗外景观，带人物的照片点击率显著高于纯房间图 |
| 常见坑 | 只有房间图没周边 / 价格不透明 / 过度美化被差评反噬 |
| 标题示例 | "带窗看雪山🏔️王岗坪这家民宿推门就是云海""莫干山这间树屋，住进去不想出来" |

### 赛道 3：🍜 餐饮

| 维度 | 内容 |
|:---|:---|
| 标题核心词 | `[城市]美食` `[商圈]好吃的` `[菜系]推荐` `[人群]聚餐` |
| 正文必含信息 | 推荐菜+价格 / 位置+排队情况 / 人均消费 / 适合几个人吃 / 什么时间去不用排队 |
| 内容角度 | 单品深度种草 / 菜单攻略 / 场景化（约会/聚餐/一人食）|
| 封面重点 | 菜品实拍+环境，制作过程图观看量通常是成品的 3-5 倍 |
| 常见坑 | 只拍菜不拍环境 / 写"好吃"不给具体信息 / 价格不透明 |
| 标题示例 | "上海这家本帮菜，红烧肉绝了‼️人均80""藏在巷子里的面馆，老板做了20年" |

### 赛道 4：💐 花店

| 维度 | 内容 |
|:---|:---|
| 标题核心词 | `[城市]花店` `花束推荐` `[节日]送花` `[场景]花艺` |
| 正文必含信息 | 花材+价格 / 适用场景 / 养护方式 / 能放几天 / 怎么订 |
| 内容角度 | 花束展示 / 制作过程 / 养护知识 / 节日送礼指南 |
| 封面重点 | 花束实拍（自然光+特写），制作过程的短视频观看量远高于成品图 |
| 常见坑 | 只发成品图没过程 / 不写价格和花材 / 不写怎么买 |

### 赛道 5：📚 教培/兴趣班

| 维度 | 内容 |
|:---|:---|
| 标题核心词 | `[城市]美术班` `[科目]培训` `[人群]兴趣班` `[年龄]学什么` |
| 正文必含信息 | 课程内容+价格 / 适合年龄 / 师资 / 试课方式 / 学员作品/成果 |
| 内容角度 | 课堂实拍 / 学员作品 / 教师理念 / 试课体验 |
| 封面重点 | 学员作品+课堂氛围，避免摆拍感太强 |

### 赛道 6：💪 健身/瑜伽

| 维度 | 内容 |
|:---|:---|
| 标题核心词 | `[城市]私教` `瑜伽馆` `[区域]健身房` `减脂/塑形` |
| 正文必含信息 | 教练资质 / 课程类型+价格 / 适合人群 / 场馆环境 / 体验课方式 |
| 内容角度 | 教练个人 IP / 学员变化 / 训练日常 / 饮食建议 |
| 封面重点 | 训练实拍+对比，注意合规（不夸大效果、不虚假宣传） |

### 赛道 7：💇 美容/美发

| 维度 | 内容 |
|:---|:---|
| 标题核心词 | `[城市]美甲` `[区域]发型师` `[项目]推荐` `[风格]美睫` |
| 正文必含信息 | 项目内容+价格 / 所用产品 / 能维持多久 / 怎么预约 |
| 内容角度 | 前后对比 / 过程记录 / 款式推荐 / 避坑指南 |
| 封面重点 | 前后对比图+细节特写。注意合规：对比图不能涉嫌虚假广告 |

### 赛道 8：🎨 手作/文创

| 维度 | 内容 |
|:---|:---|
| 标题核心词 | `[品类]手作` `[城市]手工` `[风格]饰品` `手艺人` |
| 正文必含信息 | 材质+价格 / 制作过程 / 适合什么场景 / 怎么定制 / 制作周期 |
| 内容角度 | 制作过程记录 / 成品展示 / 材料介绍 / 定制故事 |
| 封面重点 | 成品实拍+制作过程，过程内容的互动率通常是成品的 2-3 倍 |

## 话题标签公式

```
行业搜索型 2 个（如 #景区运营 #民宿创业）
+ 内容方法型 1 个（如 #小红书运营）
+ 通用流量型 1-2 个（如 #周末去哪儿 #创业日记）
```
