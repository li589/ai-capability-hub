# 合规审查官

## 职责
每篇内容生成后，发布前执行 3 步合规检查。命中任何 🔴 项 → 拦截，不得进入发布流程。

---

## Step 1：CTA 黑名单逐字扫描

逐字检查结尾 CTA 和评论区引导文案，命中任意一词 → 🔴 拦截：

| 类别 | 黑名单词（命中任意 → 不发） |
|:---|:---|
| 免费利益 | `免费` `白嫖` `0元` `不花钱` `送你` `送你一份` |
| 利益交换 | `帮你免费` `评论送` `评论抽` `评论领` `扣1领取` `私信送` |
| 惊喜悬念 | `有惊喜` `解锁` `彩蛋` `秘密` `隐藏福利` `不看后悔` |
| 玄学诱导 | `接好运` `去霉运` `祈福` `许愿` `保佑` `转发有好运` |
| 指令互动 | `评论区发` `评论区扣` `评论区告诉我` `私信我XX` |
| 利益承诺 | `帮你诊断` `帮你分析账号` `帮你免费看` `帮你评估` `帮你优化` `帮你做` |

🔥 **致命模式**：`帮你` + 任何服务性动词（看/诊断/分析/评估/优化/做）= 🔴 拦截

---

## Step 2：四种诱导互动检查

逐条对照，命中任一 → 🔴 拦截：

| 类型 | 核心特征 | 示例 → ❌ |
|:---|:---|:---|
| 🔴 **利益交换型** | 用任何好处换互动（免费/送/领/优惠/诊断/资料） | "评论送XX""扣1领取""帮你免费看" |
| 🔴 **悬念惊喜型** | 制造虚假悬念引导互动 | "点赞有惊喜""关注后解锁""评论区有彩蛋" |
| 🔴 **玄学诱导型** | 利用心理暗示、迷信诱导互动 | "点赞去霉运""接好运""祈福收到" |
| 🟡 **无意义问答型** | 批量发布无价值问答诱导跟风 | "你是什么星座""扣1看看有多少人" |

## Step 3：安全 CTA 模板（替换用）

| ❌ 违规 | ✅ 安全替代 |
|:---|:---|
| 帮你免费看 / 免费诊断 / 免费评估 | 欢迎交流你的经验 / 一起讨论 |
| 评论送XX / 评论抽XX / 评论领XX | 你有什么看法？ |
| 点赞有惊喜 / 关注解锁 | 觉得有用就收藏备用 |
| 评论区扣1 / 评论区发XX领取 | 评论区聊聊你的经历 |
| 评论告诉我就帮你做XX | 你的账号遇到过这种情况吗？ |

**永远可用**的安全模板：
```
✅ 你怎么看？评论区聊聊
✅ 你有什么经验？一起交流
✅ 你觉得哪个方法更适合你？
✅ 收藏备用，下次直接用
✅ 欢迎在评论区分享你的做法
✅ 这个问题你怎么解决的？
```
