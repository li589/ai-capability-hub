# 封面策略

> 标题让人想点，封面让人停下来。两个配合 = CTR 最大化。

## 封面三原则

1. **0.8 秒传递信息**：用户刷信息流极快，封面必须一眼看懂。模糊=划走
2. **文字+图片组合最优**：纯图 CTR 低，纯大字没人看，组合效果最好
3. **和标题互补**：标题说结果 → 封面说场景。标题提问题 → 封面给线索。不要重复

---

## 4 种封面类型

| 类型 | 适合内容 | 设计要点 | 示例场景 |
|:---|:---|:---|:---|
| **大字报** | 干货/观点/教程 | 核心信息放大，≤8 个字，强对比色 | "OTA 一年抽走你 23%" |
| **对比图** | 改造/测评/案例 | 左右或上下对比，差异肉眼可见 | Before/After 内容效果 |
| **实景+文字叠加** | 种草/探店/攻略 | 实拍图为主，叠加 1 行关键信息 | "推开窗看到的是贡嘎雪山" |
| **数据卡片** | 案例/行业分析 | 核心数字放大占 50% 面积 | "核销率 64%""获客成本 6 元" |

---

## 封面文字检查清单

- [ ] 封面文字 ≠ 标题文字（避免重复，互补引流）
- [ ] 无导流信息（微信/二维码/手机号/公众号名）
- [ ] 无极限词（"最""第一""100%""唯一"）
- [ ] 无促销词（"免费""送""限时""扫码""抢"）
- [ ] 文字在手机预览中清晰可读（不是只有大屏看得清）

## 素材管理

### 素材来源分级

| 级别 | 来源 | 处理策略 |
|:---|:---|:---|
| ⭐⭐⭐⭐⭐ | 自己/运营方实地拍摄 | 直接使用，多角度多景别，原图直出 |
| ⭐⭐⭐⭐ | 客户/商家提供未发布素材 | 直接可用，确认未在任何平台出现过 |
| ⭐⭐ | 客户提供已使用素材 | **必须改造**：裁剪重构/调色换风格/叠加信息层/混合编排 |
| ⭐ | 网图搬运 | 不推荐，查重风险高 |
| ❌ | AI 生成图片 | 不推荐，平台可识别，权重最低 |

### 二手素材改造策略

```
客户给的素材已经发过朋友圈/其他平台？必须改造：

├─ 裁剪重构：同一张图换构图（16:9 → 3:4，全景 → 特写）
├─ 调色换风格：冷暖色调翻转、滤镜重置
├─ 叠加信息层：加地理位置标签、时间戳、路线标注
├─ 混合编排：3 张旧素材 + 1 张截图/数据图/文字卡（增加原创信息密度）
└─ 重组叙事：素材顺序打乱，重新编排故事线
```
