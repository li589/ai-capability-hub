#  内容评分卡

## 职责
内容生成后，预估 CES 得分和发布效果，给出格式类型建议。

---

## Step 1：格式类型判定

根据内容类型选择合适的格式：

| 内容类型 | 优先格式 | 理由 |
|:---|:---|:---|
| 案例故事 | 第一人称案例故事 | CES 54，最高效 |
| 痛点+解决 | 痛点+方法拆解 | CES 17-32 |
| 互动/观点 | 短观点+提问 | 互动率最高 |
| ❌ 清单/教程 | 禁止 | CES 5-12，收藏率为0 |
| ❌ 行业概览 | 禁止 | CES 5-6，最低效 |

**核心规则**：每篇必须有一个"我"、一个具体时间点、一个具体数字结果。

---

## Step 2：内容质量快检（≥ 7 项通过才能发）

- [ ] 前 40 字是具体场景（时间+人物+困境）
- [ ] 用第一人称叙事
- [ ] 有至少 1 处"出乎意料的数据"或"踩过的坑"
- [ ] 全文 550字至650 字
- [ ] ≥ 3 个硬信息点（具体案例数据）
- [ ] 每个段落有"读者能带走的东西"
- [ ] CTA 是二选一提问
- [ ] 去掉 CTA 后正文仍有价值

---

## Step 3：CES 预估

```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```

CES 参考基准：

| 格式类型 | CES 基准 | 头部作品 CES |
|:---|:---:|:---:|
| 案例故事 | 30-60 | 80+ |
| 痛点+方法 | 15-35 | 50+ |
| 互动观点 | 10-20 | 40+ |
| ❌ 清单/教程 | 5-12 | 20（天花板） |

---

## Step 4：关键词验证

写完后逐项检查：

| 关键词 | 最少出现次数 |
|:---|:---:|
| 小红书 | 3 次 |
| 核心业务词（如景区/餐饮/民宿） | 2 次 |
| 行业关键词 | 1 次 |
| 地域词 | 1 次 |

> 不达标 → 补到场景描述或用户原话里，不硬塞。

---

## Step 5：发布时间建议

| 优先级 | 时间 | 说明 |
|:---:|:---|:---|
| 🥇 | 周四 20:00 | 数据最佳 |
| 🥈 | 周二 20:00 | 备选 |
| 🥉 | 周六 10:00 | 周末休闲流量 |
| ❌ | 周一 | 忙，划走率高 |
