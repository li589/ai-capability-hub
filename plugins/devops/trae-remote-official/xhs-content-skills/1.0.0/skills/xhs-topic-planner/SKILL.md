# 选题策划

> 确定写什么、写给谁、解决什么问题。这一步不做好，后面都是白写。

## 选题三问（写任何笔记前先回答）

1. **写给谁？**——一个具体的人，不是"所有人"。"上海周末想出去但不知道去哪的上班族" > "游客"
2. **TA 在搜什么？**——打开小红书搜这个词，下拉联想词就是 TA 的真实需求
3. **TA 看完能带走什么？**——一个信息/一个方法/一个判断/一个冲动？如果没有，这篇不值得写

## 五类选题方向（按目标分类）

| 目标 | 做什么 | 示例选题 |
|:---|:---|:---|
| 🔍 **搜索承接** | 攻略/教程/回答具体问题 | "XX景区门票怎么买最划算" |
| 🤝 **信任建设** | 案例/过程/个人理念 | "我们帮一个古镇从0做到排队的全过程" |
| 💬 **引发互动** | 话题/投票/征集/算账 | "你去年被OTA抽走了多少佣金？算一下" |
| 📸 **场景种草** | 体验/场景/故事/第一人称 | "推开窗就是云海，这家民宿绝了" |
| 💰 **转化引导** | 对比/算账/方案展示 | "自己发小红书 vs 找代运营，真实成本对比" |

## 关键词万能公式

```
每篇笔记：1 个主关键词（标题前 10 字） + 2-4 个辅助词（正文自然融入） + 1-2 个热点词（蹭平台流量）
```

**主关键词** = 品类词 + 场景词 + 地域词（三选二组合）
- 景区：`[城市]周边游` `[景区名]攻略` `[季节]避暑圣地`
- 民宿：`[城市]民宿推荐` `[地名]度假民宿` `[景区]附近住宿`
- 餐饮：`[城市]美食推荐` `[菜系]探店` `[商圈]好吃的`

**关键词验证方法**：
1. 在小红书搜索框输入你的词
2. 看下拉联想词——你的词出现在联想词里吗？
3. 看搜索结果前 20 条——你的标题结构和它们像吗？
4. 如果答案都是"否"——换词

## 笔记简报模板（写正文前必填）

```
📋 笔记简报

- 核心问题：这篇要回答读者的哪个问题？
- 目标读者：谁会停下来看？（具体画像：年龄+身份+痛点+场景）
- 主关键词：1 个（放标题前 10 字）
- 辅助关键词：2-4 个（正文自然融入，禁止生硬堆砌）
- 硬信息点（≥3 个）：具体数字/价格/时间/步骤/地名
- 情绪转折：至少一处"出乎意料"或真实感受
- 素材需求：需要什么图？（实拍/截图/数据/对比）已有吗？
- 差异化点：和别人有什么不同？
```
