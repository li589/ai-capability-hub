# industry-panorama-research

行业全景研究插件。以自包含方式完成完整或定向行业研究，覆盖宏观政策、市场规模、产业链、竞争格局、重点企业与趋势机会风险六大维度，产出带可点击来源、交互图表和可独立阅读摘要的研究报告。

## 核心能力

- **完整研究**：一次性运行六个研究维度，输出包含核心结论、行业概览、六章正文、结论与展望和可点击参考资料的全景报告。
- **定向研究**：只运行用户点名的维度（两个及以上），不扩张为全套，仍完成报告撰写与关键核查。
- **单维度研究**：只运行对应包内研究步骤，再完成报告撰写和核查。
- **来源可追溯**：正文事实绑定引用编号，参考资料标注实际发布者、原始机构与日期，支持点击跳转。
- **自适应可视化**：内嵌 ECharts 按数据用途自动选图（趋势、比较、构成、关系、区间），HTML/CSS 承载产业链、时间线、竞争矩阵等业务结构图。
- **资料缺口透明**：专题资料不足以形成判断时明确标注 `INSUFFICIENT` 并保留已确认的有限事实，不强行补凑。

## 研究维度

| 维度 | 说明 |
| --- | --- |
| 宏观与政策环境 | 只保留会改变行业需求、供给、成本、准入或竞争的外部因素，政策条款以主管机关原文为准 |
| 市场规模测算 | 先定义市场再展示数据，区分实际值、跟踪统计、估算与预测，不混拼口径 |
| 产业链分析 | 识别决定价值、成本、供给与风险的关键环节，用证据连接相邻环节 |
| 竞争格局分析 | 先明确竞争发生在哪个市场，再比较真正可比的参与者和壁垒 |
| 重点企业研究 | 用可核实的经营、产品或商业化事实比较代表企业，通常三至五家 |
| 趋势、机会与风险 | 把已确认事实综合为有条件的判断，说明成立条件与观察信号 |

## 工作流程

研究按九个专业阶段推进，但只有五个基础联网研究维度创建并行任务，其余步骤由主 Agent 直接完成。

1. **研究规划** — 解析行业、地域、时间与边界，必要时做一次轻量行业发现，生成研究计划与参数卡。
2. **宏观与政策环境分析** — 并行任务。
3. **市场规模测算** — 并行任务。
4. **产业链分析** — 并行任务。
5. **竞争格局分析** — 并行任务。
6. **重点企业研究** — 并行任务。
7. **趋势、机会与风险研判** — 主 Agent 综合前五项已核实事实，不新增搜索。
8. **研究报告撰写** — 确定性脚本组装草稿，主 Agent 只写核心结论、行业概览与结论展望。
9. **关键事实与引用核查** — 一次性终检完成引用整理、机械检查、`report.md`、`report.html` 与交付上下文生成。

## 产物

- `report.html` — 主要阅读版，自包含 HTML，内嵌 ECharts 交互图表与 HTML/CSS 结构组件。
- `report.md` — Markdown 可编辑版。
- 管理摘要 — 可独立阅读，先说明研究范围与总体判断，再按影响用户判断的主题组织主要发现。

## 使用方式

完整研究：

```text
使用 industry-research 对我指定的行业做一份完整研究。
```

定向研究：

```text
使用 industry-research 研究 {行业} 的市场规模和竞争格局。
```

插件会在当前工作目录的 `work/` 下创建研究目录，完成联网研究、报告撰写与核查，最终交付 HTML 报告与 Markdown 可编辑版。
