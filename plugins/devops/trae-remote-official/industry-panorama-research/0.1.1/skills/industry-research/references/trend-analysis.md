# 趋势、机会与风险研判内部步骤

本步骤由主 Agent 直接执行，不创建内部任务。把已确认事实综合为有条件的判断，不把预测写成必然，也不复述前序专题。

## 执行模式

- **后置综合模式**：完整研究或已有基础专题的组合研究。一次读取 `<WORK_DIR>/plan.md`、`<WORK_DIR>/trend-context.md` 和 `<SKILL_ROOT>/references/visualization.md`；不得读取包含未核实发现线索的 `research-card.md`。
- **定向专题模式**：用户只要求趋势、机会或风险。一次读取 `<WORK_DIR>/plan.md`、`<WORK_DIR>/research-card.md`、`<SKILL_ROOT>/references/source-selection.md` 和 `<SKILL_ROOT>/references/visualization.md`，有限搜索后直接成稿。

## 执行

- 未完成时回复只能包含工具调用；不使用 `TodoWrite`，不调用 `LS`、`mkdir`，不复述输入、来源选择过程、工具结果或写作计划。专题稿直接在 `Write` 参数中形成，不先把正文输出到主对话。
- 后置综合模式只用 `plan.md` 确认研究范围、时间和问题边界，不得把其中的待核实问题、假设或规划发现当作事实；把 `trend-context.md` 中的事实、数字、单位、日期、来源和引用视为已经确认的输入。不读取完整专题稿，不调用 WebSearch 或 WebFetch，不重新判断来源身份，不重新计算或纠正前序数字。读完输入后的下一步必须直接写稿。
- 定向专题模式的发现阶段最多并行两次搜索；只有核心问题仍未回答时才进行一次不重复的补充搜索，两批合计最多打开六个页面。达到限制或核心问题已回答即停止，最后一批页面返回后的下一步必须直接写稿。
- 每个结论按“已确认事实 → 分析推断 → 条件或观察信号”表达。机会说明受益对象、成立条件和观察信号；风险说明触发条件、影响路径和可能的缓释因素。
- 不复述前五章内容，只保留支撑判断所需的最短事实锚点。不要为了满足数量补趋势、机会、风险、来源或维度；只输出证据足以支持且对决策有意义的内容。
- 无法形成可靠判断时写 `INSUFFICIENT: 现有证据不足以形成可靠的趋势、机会与风险判断`。

## 输出

一次写完 `<WORK_DIR>/notes/trends.md`。第一段用一到两句说明最重要的未来判断、成立条件和观察信号。除标题、事实引用和文末 `## 参考资料` 外，不规定章节数量、顺序或表达模板；技术、应用、商业化、融资、出口、区域或监管变化确有独立证据时使用有业务含义的三级标题。只有资料缺口会明显改变判断时才保留局部 `> 资料边界：...`。

已有输入自然形成趋势、比较、区间、时间线、链路或矩阵时，按统一可视化规则选择一次载体；不能立即确定时使用表格或正文。最多包含两个图表或结构图，不新增搜索、计算或补数。

写完只运行：

```bash
python3 "<SKILL_ROOT>/scripts/validate_note.py" \
  --input "<WORK_DIR>/notes/trends.md"
```

检查失败时不重新研究，只按完整错误列表集中修正一次并复检一次；仍失败就结束，不继续编辑。完成后只返回两到三句业务摘要。
