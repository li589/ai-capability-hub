# 关键事实与引用核查内部步骤

本步骤由主 Agent 直接执行，只运行一次确定性终检，不创建新的审稿 Agent，不联网、不重新阅读六份专题稿，也不进行开放式全稿审阅。

## 唯一命令

调用前把占位符替换为真实绝对路径，只运行：

```bash
python3 "<SKILL_ROOT>/scripts/finalize_report.py" \
  --work-dir "<WORK_DIR>"
```

程序一次完成：

- 把 `editorial.md` 中的核心结论、行业概览和结论与展望安全合并到 `draft.md`；局部编辑缺失或不能安全合并时保留确定性组装稿。
- 删除未使用参考资料并连续编号，不增加事实、URL 或计算。
- 检查正文引用、参考资料、图表和结构图是否能够正式发布。
- 从报告一级标题生成包含用户研究主题的 Markdown 和 HTML 文件名，不生成 `report.md` 或 `report.html`。
- 生成自包含 HTML、`delivery-context.md` 和内部 `review.md`，并把两个实际交付文件名写入交付上下文。
- 验证主题化 HTML 非空且包含 HTML 文档声明。

命令成功后立即结束，不再读取完整报告、重新核查、重新发布或修改专题。命令失败时不搜索、不让专题返工、不手写替代报告；总入口根据 `review.md` 说明当前尚不能交付。

`PASS`、`PASS_WITH_LIMITS` 和 `BLOCKED` 只允许写入内部 `review.md`，不得在完成回复、进度或最终回复中输出或解释。局部资料不足、图表较少、三级标题较少或轻微措辞不阻断报告。
