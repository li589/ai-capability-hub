# 法律文书生成模板

## 重要：文书输出方式

法律文书的最终输出**必须联合 `docx` skill**生成正式 .docx 文件，不能仅以 markdown 文本形式输出。

流程：本 Skill 负责文书内容的法律专业性（结构、用语、法条引用），`docx` skill 负责排版和文件生成。

**格式来源**：本模板中的诉讼文书结构严格参照最高人民法院发布的《民事诉讼文书样式》（来源：https://www.court.gov.cn/susong.html ），确保格式符合法院受理标准。

## 二、各文书结构规范（依据最高人民法院诉讼文书样式）

### 2.1 民事起诉状（公民提起民事诉讼用）

```
                    民事起诉状

原告：×××，男/女，××××年××月××日生，×族，
      ……(写明工作单位和职务或职业)，住……。
      联系方式：……。

法定代理人/指定代理人：×××，……。
委托诉讼代理人：×××，……。

被告：×××，男/女，××××年××月××日生，×族，
      ……(写明工作单位和职务或职业)，住……。
      联系方式：……。

诉讼请求：
一、……
二、……
三、本案诉讼费用由被告承担。

事实和理由：
……

证据和证据来源，证人姓名和住所：
……

此致
××××人民法院

附：本起诉状副本×份

                              起诉人（签名）
                              ××××年××月××日
```

**【说明】（依据《民事诉讼法》第一百二十条、第一百二十一条）**：
1. 起诉应当向人民法院递交起诉状，并按照被告人数提出副本。
2. 原告应当写明姓名、性别、出生日期、民族、职业、工作单位、住所、联系方式。
3. 原告是无民事行为能力或者限制民事行为能力人的，应当写明法定代理人信息，括注与原告的关系。
4. 被告是法人或者其他组织的，应当写明名称、住所等信息。另起一行写明法定代表人/主要负责人及其姓名、职务。
5. 原告在起诉状中直接列写第三人的，视为申请追加。是否通知第三人参加诉讼，由人民法院审查决定。

**起草要点**：
- 诉讼请求必须具体、明确、可执行（金额精确到元/分）
- 事实部分客观陈述，按时间线组织，引用证据编号
- 法律依据引用具体条文编号
- 管辖法院需符合法定/约定管辖规则

×××因与×××……（写明案由）一案，贵院已立案受理

### 2.4 民事答辩状（公民对民事起诉提出答辩用）

```
                    民事答辩状

答辩人：×××，男/女，××××年××月××日生，×族，
        ……(写明工作单位和职务或职业)，住……。
        联系方式：……。

法定代理人/指定代理人：×××，……。
委托诉讼代理人：×××，……。

对××××人民法院（××××）……民初……号×××（写明案由）
一案的起诉，答辩如下：

……（写明答辩意见）。

证据和证据来源，证人姓名和住所：
……

此致
××××人民法院

附：本答辩状副本×份

                              答辩人（签名）
                              ××××年××月××日
```

**【说明】（依据《民事诉讼法》第一百二十五条）**：
1. 被告应当在收到起诉状副本之日起十五日内提出答辩状。
2. 被告在中华人民共和国领域内没有住所的，应当在收到起诉状副本后三十日内提出答辩状。

**起草要点**：
- 逐条回应原告诉讼请求（认可/否认/部分认可）
- 明确区分"认可"与"否认"的事实
- 提出己方的事实版本和法律依据

一、……
二、……

上诉理由：
……

此致

附：本上诉状副本×份

                              上诉人（签名或者盖章）

**【说明】（依据《民事诉讼法》第一百六十四条至第一百六十六条）**：

2. 不服裁定的，在裁定书送达之日起十日内向上一级人民法院提起上诉。
3. 上诉状应当通过原审人民法院提出，并按照对方当事人人数提出副本。
4. 有新证据的，应当在上诉理由之后写明证据和证据来源。

### 2.6 财产保全申请书（诉前/仲裁前）

```
                    申请书

申请人：×××，男/女，××××年××月××日出生，×族，
        ……(写明工作单位和职务或者职业)，住……。
        联系方式：……。

被申请人：×××，……。

请求事项：
查封/扣押/冻结被申请人×××的……
（写明保全财产的名称、性质、数量或数额、所在地等），
期限为×年×月×日。

事实和理由：
……（写明诉前/仲裁前申请财产保全的事实和理由）。

申请人提供……（写明担保财产的名称、性质、数量或数额、
所在地等）作为担保。

此致
××××人民法院

                              申请人（签名或盖章）
                              ××××年××月××日
```

**【说明】（依据《民事诉讼法》第一百零一条第一款）**：
1. 利害关系人因情况紧急，不立即申请保全将会使其合法权益受到难以弥补的损害的，可以在提起诉讼或者申请仲裁前向被保全财产所在地、被申请人住所地或者对案件有管辖权的人民法院申请采取保全措施。
2. 申请诉前保全的，应当提供担保。申请诉前财产保全的，应当提供相当于请求保全数额的担保。
3. 申请有错误的，申请人应当赔偿被申请人因保全所遭受的损失。

### 2.7 强制执行申请书

```
                    申请执行书

申请执行人：×××，男/女，××××年××月××日出生，×族，
            ……(写明工作单位和职务或者职业)，住……。
            联系方式：……。

被执行人：×××，……。

申请执行人×××与被执行人×××……（写明案由）一案，
××××人民法院（或其他生效法律文书的作出机关）
（××××）……号民事判决（或其他生效法律文书）已发生法律效力。
被执行人×××未履行/未全部履行生效法律文书确定的给付义务，
特向你院申请强制执行。

请求事项：
一、……（写明请求执行的内容）。
二、……

此致
××××人民法院

附：生效法律文书×份

                              申请执行人（签名或盖章）
                              ××××年××月××日
```

**【说明】（依据《民事诉讼法》第二百三十六条至第二百三十八条）**：
1. 申请执行人向人民法院申请强制执行的内容，必须为生效法律文书确定的给付义务。
2. 申请执行的期间为二年（从法律文书规定履行期间的最后一日起计算）。
3. 向被执行人住所地或者被执行财产所在地人民法院申请执行。

## 三、文书生成流程

### Step 1: 信息收集

生成文书前必须确认的要素（信息不足则用 `[待补充]` 占位，不阻塞生成）：

| 文书类型 | 必须信息 | 可默认/占位信息 |
|----------|----------|----------------|
| 起诉状 | 原被告基本信息、案由、诉讼请求、关键事实 | 证据编号、管辖法院（可根据规则推导） |
| 反诉状 | 原案案号、反诉请求、事实和理由 | 证据编号 |
| 答辩状 | 案号、原告诉请内容、答辩要点 | 具体证据 |
| 上诉状 | 原审法院及案号、原审判决内容、上诉请求和理由 | 新证据 |
| 财产保全 | 申请人/被申请人信息、保全标的、事实和理由、担保 | 具体担保物 |
| 执行申请 | 生效法律文书信息、未履行内容、请求事项 | — |
| 再审申请 | 原审案号判决内容、再审事由（第200条哪一项）、请求和理由 | 新证据 |
| 仲裁申请 | 申请人/被申请人信息、劳动关系事实、仲裁请求 | 具体证据清单 |
| 律师函 | 委托人、收函方、事由、诉求、期限 | 律所信息 |
| 法律意见书 | 委托方、分析范围、背景事实 | — |

### Step 2: 法条检索

通过 pkulaw MCP 检索相关法条，确保文书中引用的法律依据准确。

### Step 3: 文书起草

按照对应文书结构规范撰写内容。严格遵循最高人民法院文书样式的格式要求。

### Step 4: 生成 docx 文件

**必须调用 `docx` skill**，将文书内容输出为正式的 .docx 文件。要求：
- 字体：正文宋体小四，标题黑体小二
- 行距：1.5倍行距
- 页边距：上下2.54cm，左右3.17cm（A4标准）
- 页码：底部居中
- 首行缩进：2字符

## 四、文书用语规范

| 应使用 | 避免使用 |
|--------|----------|
| 原告/被告/答辩人/上诉人/申请人 | 我/对方/他们 |
| 依据《XX法》第X条之规定 | 按照法律规定 |
| 诉请/请求贵院判令 | 希望/要求 |
| 事实和理由 | 原因/为什么 |
| 综上所述 | 总之/所以 |
| 特此函告/此致 | 就这样/结尾 |
| 不服……判决/裁定 | 觉得判得不对 |
| 生效法律文书确定的给付义务 | 该给的钱 |
