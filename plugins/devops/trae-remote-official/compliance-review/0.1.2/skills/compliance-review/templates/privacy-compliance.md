## 一、合法性基础检查（PIPL 第13条）

| 序号 | 合法性基础 | PIPL条款 | GDPR对应条款 | 是否适用 | 合规状态 | 风险等级 |

| 2 | 订立或履行合同所必需 | 第13条第1款第2项 | Art.6(1)(b) | | | |
| 3 | 履行法定职责或义务所必需 | 第13条第1款第3项 | Art.6(1)(c) | | | |
| 4 | 应对突发公共卫生事件/紧急情况 | 第13条第1款第4项 | Art.6(1)(d) | | | |
| 5 | 为公共利益实施新闻报道/舆论监督 | 第13条第1款第5项 | — | | | |

**核心法条参考：**

## 三、敏感个人信息特别检查（PIPL 第28-32条）

| 审查项 | 审查要点 | 适用法条 | 合规状态 | 风险等级 |
|--------|----------|----------|----------|----------|
| 敏感信息识别 | 是否准确识别所处理的敏感个人信息类型 | PIPL第28条 | | |
| 必要性评估 | 是否具有特定目的和充分必要性 | PIPL第28条第2款 | | |
| 单独同意 | 是否取得个人的单独同意 | PIPL第29条 | | |
| 影响评估 | 是否事前进行个人信息保护影响评估 | PIPL第55条 | | |
| 未成年人保护 | 处理不满14周岁未成年人信息是否制定专门规则 | PIPL第31条 | | |

**敏感个人信息类型清单：**
- 生物识别信息（人脸、指纹、虹膜、声纹等）
- 宗教信仰
- 特定身份（如未成年人）
- 医疗健康信息
- 金融账户信息
- 行踪轨迹信息
- 不满14周岁未成年人的个人信息

   - 整改建议：[具体整改措施]
   - 整改期限：[建议完成时间]
   - 责任部门：[建议负责的部门]

### 整改优先级路线图
