```
[广告内容整体合规性一句话结论]

审查范围:
- 广告主体：
- 广告媒介：（电视/网络/户外/印刷等）
- 商品/服务类别：
- 广告形式：（图文/视频/直播/信息流等）
- 发布渠道：
```

## 一、绝对化用语检查（广告法第9条）

### 1.1 禁用绝对化用语清单

| 类别 | 禁用词示例 | 是否出现 | 位置 | 风险等级 |
|------|-----------|----------|------|----------|
| 最高级表述 | 最佳、最好、最优、最先进、最大、最低 | | | [高风险] |
| 第一类表述 | 第一、排名第一、全国第一、唯一 | | | [高风险] |
| 极限表述 | 极品、极致、顶级、顶尖、终极、王牌 | | | [高风险] |
| 绝对表述 | 绝对、百分百、100%、万能、全能 | | | [高风险] |
| 独占表述 | 独家、独创、首个、首创、首选、仅此一家 | | | [中风险] |
| 权威表述 | 国家级、世界级、全球级 | | | [中风险] |

**适用法条：**
- 《广告法》第9条第3项：不得使用"国家级"、"最高级"、"最佳"等用语
- 处罚：罚款20万元以上100万元以下（《广告法》第57条）

### 1.2 其他第9条禁止内容

| 审查项 | 禁止内容 | 是否涉及 | 风险等级 |
|--------|----------|----------|----------|
| 国家象征 | 使用国旗、国徽、国歌或相似元素 | | [高风险] |
| 政府机关 | 使用国家机关、国家机关工作人员名义或形象 | | [高风险] |
| 社会稳定 | 妨碍社会安定、损害公共利益 | | [高风险] |
| 歧视内容 | 含有民族、种族、宗教、性别歧视内容 | | [高风险] |
| 淫秽低俗 | 含有淫秽、色情、赌博、迷信、暴力内容 | | [高风险] |
| 未成年人 | 损害未成年人身心健康 | | [高风险] |

## 二、虚假广告检查（广告法第28条）

| 审查项 | 虚假广告认定标准 | 适用法条 | 是否涉及 | 风险等级 |
|--------|-----------------|----------|----------|----------|
| 商品/服务不存在 | 广告宣传的商品或服务实际不存在 | 第28条第2款第1项 | | [高风险] |
| 性能虚假 | 商品性能、功能、产地、规格等与实际不符 | 第28条第2款第2项 | | [高风险] |
| 证明材料虚假 | 使用虚构、伪造的科研成果、统计资料、调查结果 | 第28条第2款第3项 | | [高风险] |
| 效果虚假 | 虚构商品使用效果 | 第28条第2款第4项 | | [高风险] |
| 承诺虚假 | 以虚假的商品说明、实物照片等引人误解 | 第28条第2款第5项 | | [高风险] |

**数据引用规范检查：**

| 审查项 | 要求 | 合规状态 | 风险等级 |
|--------|------|----------|----------|
| 数据来源 | 引用的数据是否标明出处 | | [中风险] |
| 数据时效 | 引用数据是否为最新有效数据 | | [中风险] |
| 对比基准 | 对比广告是否明确对比基准和条件 | | [中风险] |
| 实验证明 | 效果宣称是否有实验/检测报告支撑 | | [高风险] |

**处罚风险：**
- 《广告法》第55条：处广告费用3-5倍罚款，无法计算的处20-100万元
- 两年内有三次以上违法行为或有其他严重情节：处广告费用5-10倍罚款，无法计算的处100-200万元
- 情节严重的，可吊销营业执照

## 三、特殊商品广告限制

### 3.1 医疗广告（广告法第16条）

| 审查项 | 禁止内容 | 是否涉及 | 风险等级 |
|--------|----------|----------|----------|
| 疗效保证 | 表示功效、安全性的断言或保证 | | [高风险] |
| 治愈率 | 说明治愈率或有效率 | | [高风险] |
| 对比其他 | 与其他药品、诊疗方法进行比较 | | [高风险] |
| 代言推荐 | 利用广告代言人推荐 | | [高风险] |
| 科研引用 | 利用医药科研单位等名义作证明 | | [高风险] |

### 3.2 药品广告（广告法第16条）

| 审查项 | 禁止内容 | 是否涉及 | 风险等级 |
|--------|----------|----------|----------|
| 处方药 | 处方药在大众媒体发布广告 | | [高风险] |
| 功效断言 | 含有不科学的功效断言 | | [高风险] |
| OTC标识 | 非处方药广告是否标明OTC标识 | | [中风险] |
| 忠告语 | 是否包含"请按药品说明书或在药师指导下购买和使用" | | [中风险] |

### 3.3 保健食品广告（广告法第18条）

| 涉及疾病 | 涉及疾病预防、治疗功能 | | [高风险] |
| 代言人 | 利用广告代言人推荐 | | [高风险] |

## 四、广告代言人合规（广告法第38条）

| 审查项 | 审查要点 | 适用法条 | 合规状态 | 风险等级 |
|--------|----------|----------|----------|----------|
| 使用体验 | 代言人是否使用过该商品/接受过该服务 | 第38条第1款 | | [高风险] |
| 虚假推荐 | 是否存在虚假的推荐或证明 | 第38条第1款 | | [高风险] |
| 未成年人 | 是否使用不满10周岁的未成年人作代言人 | 第38条第2款 | | [高风险] |
| 医疗药品 | 医疗、药品、医疗器械、保健食品广告不得使用代言人 | 第16/18条 | | [高风险] |
| 违法记录 | 代言人是否存在因代言虚假广告被处罚未满三年 | 第38条第3款 | | [高风险] |
| 劣迹艺人 | 代言人是否存在违法失德行为 | 市场监管总局相关规定 | | [高风险] |
