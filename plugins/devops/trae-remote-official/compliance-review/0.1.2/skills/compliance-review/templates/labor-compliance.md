# 劳动用工合规审查模板

## 审查报告格式

```
[劳动用工合规整体评估一句话结论]

风险等级: [高风险 / 中风险 / 低风险]

审查范围:
- 用人单位：
- 员工规模：
- 用工形式：（全日制/非全日制/劳务派遣/外包等）
- 审查事项：（招聘/在职管理/薪酬/解除终止/社保等）
- 所在地区：
```

## 一、劳动合同签订合规（劳动合同法第10-17条）

| 审查项 | 审查要点 | 适用法条 | 合规状态 | 风险等级 |
|--------|----------|----------|----------|----------|
| 书面合同 | 建立劳动关系是否在1个月内签订书面合同 | 第10条 | | [高风险] |
| 必备条款 | 是否包含全部法定必备条款（9项） | 第17条 | | [中风险] |
| 合同期限 | 固定期限/无固定期限/以完成一定工作任务为期限的选择是否合法 | 第12-14条 | | [中风险] |
| 无固定期限 | 连续订立两次固定期限后是否应签无固定期限合同 | 第14条 | | [高风险] |
| 试用期 | 试用期期限是否超过法定上限 | 第19条 | | [高风险] |
| 试用期工资 | 试用期工资是否不低于约定工资的80%且不低于最低工资 | 第20条 | | [高风险] |
| 竞业限制 | 竞业限制期限是否超过2年、补偿金是否约定 | 第23-24条 | | [中风险] |
| 服务期 | 服务期约定是否仅限于专项培训情形 | 第22条 | | [中风险] |

**法定必备条款清单（第17条）：**
- 用人单位名称、住所和法定代表人
- 劳动者姓名、住址和身份证号码
- 劳动合同期限
- 工作内容和工作地点
- 工作时间和休息休假
- 劳动报酬
- 社会保险
- 劳动保护、劳动条件和职业危害防护
- 法律法规规定应当纳入的其他事项

| 加班工资 | 工作日/休息日/法定节假日加班费是否按150%/200%/300%支付 | 《劳动法》第44条 | | [高风险] |
| 特殊工时 | 综合计算工时制/不定时工作制是否经审批 | 《关于企业实行不定时工作制和综合计算工时工作制的审批办法》 | | [中风险] |
| 年休假 | 是否按工龄依法安排年休假（5/10/15天） | 《职工带薪年休假条例》 | | [中风险] |
| 未休年假补偿 | 未安排年休假是否支付300%日工资报酬 | 《职工带薪年休假条例》第5条 | | [高风险] |
| 女职工假期 | 产假/哺乳假是否符合法定标准 | 《女职工劳动保护特别规定》 | | [高风险] |

## 审查结论格式

```
## 审查结论

### 总体合规评估
[对劳动用工合规状况的整体评价]

### 合规差距分析

#### [高风险] 高风险问题（共 X 项）
1. [问题] — 违反 [具体法条] — 法律后果：[可能面临的处罚/赔偿]
   - 整改建议：[具体整改措施]
   - 整改期限：[建议完成时间]
   - 责任部门：[人力资源/法务/行政]

#### [中风险] 中风险问题（共 X 项）
1. [问题] — 涉及 [法条] — 建议：[优化措施]

#### [低风险] 低风险/建议优化（共 X 项）
1. [问题] — 参考 [最佳实践] — 建议：[改进方向]

### 处罚与赔偿风险提示
- 未签书面合同：支付双倍工资（最长11个月）
- 违法解除：支付2N经济赔偿金
- 未依法缴纳社保：补缴+滞纳金，可能面临行政处罚
- 拖欠工资：加付50%-100%赔偿金

### 整改优先级路线图
1. [紧急整改事项 — 1周内]
2. [重要整改事项 — 1个月内]
3. [持续优化事项 — 3个月内]
```

[免责声明] 本劳动用工合规审查仅供参考，不构成正式法律意见。劳动法规的适用可能因地区、行业、企业规模等因素存在差异，各地劳动仲裁和司法裁判口径可能不同。建议在涉及具体劳动争议或重大用工调整前咨询专业劳动法律师。
