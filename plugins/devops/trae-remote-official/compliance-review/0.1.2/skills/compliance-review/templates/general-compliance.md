   - 整改建议：[具体整改措施]
   - 整改期限：[建议完成时间]
   - 责任部门：[具体部门]

#### [中风险] 中风险问题（共 X 项）— 限期整改
1. [问题] — 涉及 [法条] — 建议：[优化措施]

#### [低风险] 低风险/建议优化（共 X 项）— 持续完善
1. [问题] — 参考 [最佳实践] — 建议：[改进方向]

### 处罚风险汇总
| 合规领域 | 违法类型 | 适用罚则 | 罚款/处罚区间 | 其他后果 |
|----------|----------|----------|--------------|----------|
| | | | | |

### 整改优先级路线图
1. [紧急整改 — 1周内]：直接威胁经营存续或可能触发刑事责任的问题
2. [重点整改 — 1个月内]：面临行政处罚或重大民事赔偿风险的问题
3. [常规整改 — 3个月内]：存在合规隐患但暂未被监管关注的问题
4. [持续优化 — 6个月内]：与最佳实践的差距，提升合规管理水平
