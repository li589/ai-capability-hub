# 数据来源解析标准

本标准规定股票研究工作流中数据来源的获取方式、优先级和质量要求。

## 来源分类

### 1. 公司原始文件
- 定期财务报告（年报/季报/中报）
- 招股说明书、配股/增发文件
- 管理层讨论与分析（MD&A）
- 股东信/投资者日材料
- 官方新闻稿/公告

### 2. 市场数据
- 实时/历史行情（价格、成交量）
- 指数成分和权重
- 期权/衍生品数据
- 融券/做空数据
- ETF 持仓和资金流

### 3. 共识与研究
- 卖方盈利预测共识
- 卖方研究报告（需标注分析师和日期）
- 行业研究报告

### 4. 宏观与行业
- 政府统计数据（GDP、CPI、PMI 等）
- 央行货币政策
- 行业协会数据
- 上下游产业链数据

### 5. 新闻与事件
- 权威财经媒体报道
- 监管机构公告
- 行业会议/电话会议纪要

## 来源质量规则

### 时效性要求

| 数据类型 | 陈旧阈值 | 处理方式 |
|---------|---------|---------|
| 行情价格 | 当日收盘 | 标注截至时间 |
| 财务数据 | 最近一期 | 参照财报披露节奏 |
| 共识估计 | 30天 | >30天标 [STALE] |
| 行业数据 | 90天 | >90天标 [STALE] |
| 宏观数据 | 按发布频率 | 使用最新期 |

### 标注格式

```
来源：[公司名称] [报告类型] [报告期], p.[页码]
来源：[分析师], [券商], [日期], "[报告标题]"
来源：[数据提供商], 截至 [YYYY-MM-DD]
来源：[媒体名称], [发布日期], "[标题]"
```

### 冲突处理

当不同来源的数据冲突时：
1. 优先使用一级来源（公司原始文件）
2. 标注差异并解释可能原因
3. 对分析结论的影响做敏感性说明

## 财务数据时效性：动态确定报告期

获取基本面数据时，必须根据**当前日期**判断目标公司**此刻能拿到的最新一期财报**，而不是默认拉取年报。不同市场披露节奏不同：

- **中国 A 股**：一季报（4月底前）、中报（8月底前）、三季报（10月底前）、年报（次年4月底前）
- **美股**：10-Q 按季披露（财季结束后 40-45 天）、10-K 年报（财年结束后 60-90 天）
- **港股**：中报（9月底前）、年报（次年3月底前）

**核心逻辑**：先确认"此刻能拿到的最新一期财报是什么"，再去获取数据。

## 数据获取工作流

### 首选实时通道：金融 MCP（多源自适应）

本插件可接入通达信 / 东方财富 Choice / 同花顺 iFinD 三个金融 MCP，**连了哪几个由用户决定**——以当前会话**实际可用的金融 MCP 工具**为准，在线几个用几个，一个都没有则明确告知用户后走公开来源兜底。源选择、覆盖/特长、降级细则见 [financial-data-spec.md](financial-data-spec.md)。

对于 **A股 / 港股 / 基金 / 指数**，任一在线源即可取实时行情、估值倍数、核心财务、技术指标与资金流，不依赖模型记忆或臆测；**美股仅当同花顺 iFinD 在线时走 MCP**，否则走公司 IR / SEC EDGAR / 联网搜索。

**获取优先级**：`金融 MCP` → `公司原始文件` → `交易所/监管/官方公开数据` → `联网搜索（兜底）`。

### 步骤 1：确定所需数据类别
根据分析任务确定需要哪些类别的数据。

### 步骤 2：按优先级获取
A股/港股/基金/指数的定量数据先经金融 MCP 获取，再用一级来源（公司原始文件）校验明细；美股及金融 MCP 未覆盖字段从最权威来源开始，逐级补充。

### 步骤 3：交叉验证
关键数据点至少两个独立来源确认（如金融 MCP + 财报原文）。

### 步骤 4：标注与记录
- 每个数据点标注来源和时间（如"金融 MCP，截至 [时间戳]"）
- 记录未能获取的数据（标注 [MISSING]）
- 标注假设和估计值

## 禁止行为

- 编造财务数据或指标
- 使用未标注来源的定量数据
- 将假设/估计伪装为事实
- 忽略数据陈旧性不做标注
- 在不同来源冲突时只取对论点有利的数据
