# 金融数据规范（数据字典 · 必取清单 · 披露纪律）

本规范解决两个高频问题：**（1）该向金融 MCP 要哪些数据（取全）；（2）拿回来的数据必须怎么呈现（用足）**。
本文件**与具体数据供应商无关**——不管数据来自通达信、东方财富还是同花顺，营收就是营收、PE 分位就是 PE 分位。"怎么调 MCP、字段叫什么名"由插件框架封装，本文件不涉及。

---

## 一、多源自适应与降级（先判断"能用哪些源"）

本插件可能接入三个金融数据 MCP，但**具体连了哪几个由用户自行决定**。模型**不得假设某个源一定在线**，必须按当前会话**实际可用的金融 MCP 工具**来判断。

### 覆盖 / 特长参考

| 源 | 覆盖市场 | 相对特长 |
|---|---|---|
| **通达信 MCP** | A股 / 港股 / 指数 | 实时行情、量价、资金流、技术指标 |
| **东方财富（妙想 Choice）** | A股为主，多资产多维度 | 龙虎榜、资金流向、研报/评级聚合、投研 |
| **同花顺 iFinD** | 股票 / 基金 / 宏观 / 新闻公告 / 债券 / **港美股** / 指数板块 | F10、公告新闻、港美股、宏观、机构级三表 |

### 源选择四原则

1. **探测优先**：以当前会话里**实际存在的金融 MCP 工具**为准，不假设、不臆测某个源一定可用。
2. **在线全用**：连了几个就用几个。多个同时在线时**交叉验证 + 取长补短**——行情/量价优先通达信，机构级三表/一致预期/港美股/宏观优先 iFinD，龙虎榜/资金流优先东方财富。多源数据打架时按 [source-resolution.md](source-resolution.md) 的冲突处理，并标注差异。
3. **按覆盖选源**：
   - **A股 / 港股 / 基金 / 指数**：任一在线源即可取数。
   - **美股**：**仅当同花顺 iFinD 在线**时走 MCP；未连 → 走公司 IR / SEC EDGAR / 联网搜索。
   - **债券 / 宏观 / 行业板块**：优先 iFinD。
4. **降级要明说**：**一个金融 MCP 都没检测到时，必须明确告知用户"未检测到已连接的金融数据 MCP，以下数据来自公开来源兜底"**，再回退到公司 IR / 交易所 / 监管 / 联网搜索，且逐点标注来源。**绝不因为源没连就凭记忆编数或假装数据不存在。**

## 二、金融数据字典（该向 MCP 要什么）

按数据域列出机构研究常用字段。**每个域都是一个"应当整取"的数据块**——不要只问一两个孤立数字。字段答什么问题、怎么用，见备注。

### 域 1 · 行情与交易
| 字段 | 说明 / 用途 |
|---|---|
| 最新价 / 涨跌幅 | 当前定价基准 |
| 开高低收、成交量、成交额、换手率 | 量价关系、活跃度 |
| 52周高低、区间涨跌幅 | 位置感、动量 |
| 总市值 / 流通市值 | 规模、可比口径 |
| 振幅、量比、委比 | 盘中活跃与多空力量（盯盘用） |

### 域 2 · 估值（务必带"历史分位"，不要只给当前值）
| 字段 | 说明 / 用途 |
|---|---|
| PE(TTM) / PE(动) | 盈利估值；与自身历史、同业对比 |
| PB / PS / PCF | 不同盈利状态下的补充口径 |
| EV / EBITDA | 剔除资本结构的可比估值 |
| 股息率 | 收益型定价 |
| **各估值指标的历史分位（近 3-5 年百分位）** | 判断"贵/便宜"的核心，**必取** |
| PEG | 成长与估值匹配度 |

### 域 3 · 利润表（至少近 3 年 + 最新一期，成长看趋势）
营业总收入、营业收入、营业成本、毛利、毛利率、销售/管理/研发/财务费用、营业利润、利润总额、归母净利润、扣非归母净利润、EPS、**营收/净利同比增速**。

### 域 4 · 资产负债表
总资产、总负债、股东权益、货币资金、应收账款、存货、有息负债、资产负债率、流动比率、速动比率、商誉。

### 域 5 · 现金流量表
经营性现金流净额、投资性现金流、筹资性现金流、自由现金流(FCF)、**经营现金流/净利润（含金量）**、资本开支(CapEx)。

### 域 6 · 财务比率（四大类，别只报一个 ROE）
| 类 | 字段 |
|---|---|
| 盈利能力 | ROE、ROA、ROIC、净利率、毛利率 |
| 成长能力 | 营收增速、净利增速、3年 CAGR |
| 偿债能力 | 资产负债率、流动/速动比率、利息保障倍数 |
| 营运能力 | 存货周转、应收周转、总资产周转 |

### 域 7 · 资金与筹码（A股尤其重要）
主力/超大单净流入、北向资金持股、龙虎榜（游资/机构席位）、融资融券余额、大宗交易。

### 域 8 · 股东与持仓结构
前十大股东 / 流通股东、机构持仓比例（基金/社保/QFII）、股东户数变化、限售解禁时间与规模、股权质押比例。

### 域 9 · 分红与股本
历史分红率与股息、分红方案、回购、增发/配股、股本结构变动。

### 域 10 · 一致预期与评级（卖方共识）
未来 1-3 年营收/净利/EPS 一致预期、目标价共识、评级分布、近期评级/预期调整。

### 域 11 · 公告、新闻与事件
定期报告、重大事项公告、业绩预告/快报、行业政策、财经要闻（须标来源与日期）。

### 域 12 · 行业与宏观（iFinD 强项）
行业规模与增速、行业内排名/市占率、行业估值中位数、上下游价格、相关宏观指标（GDP/CPI/PMI/利率）。

## 三、分场景必取清单（不同任务的"最小数据集"）

任务开始前先按清单把数据**一次性取全**，别边写边零散补数导致遗漏。缺项标 `[MISSING]`。

| 场景 / Skill | 必取数据集（最小） |
|---|---|
| **深度报告 / 首次覆盖 / 多空推介 / IC memo** | 域1行情 + 域2估值(含分位) + 域3-5三表(近3年+最新期) + 域6四类比率 + 域7资金 + 域8股东 + 域10一致预期 + 域11关键事件 + 域12行业对标 |
| **tear-sheet 速览** | 域1行情 + 域2估值(核心+分位) + 域3利润表关键行(营收/净利/增速) + 域6盈利能力 + 域8前十大股东 + 域9股息 + 域11近期事件 |
| **DCF / 三表建模** | 域3-5三表(近3-5年，逐项) + 域6比率 + 域9股本 + CapEx/FCF历史 + 域10一致预期(校准假设) |
| **comps 相对估值** | 标的 + 每一家 peer 的：域2全套估值 + 市值/EV + 域3营收净利EBITDA + 域6ROE/增速（逐家逐项，多次查询） |
| **技术面研判** | 域1行情 + 多周期量价 + 均线/MACD/KDJ/RSI/布林 + 域7资金流 + 支撑压力位 |
| **盯盘 / 异动归因** | 域1行情(含振幅量比) + 域7资金/龙虎榜 + 域11当日公告新闻 + 同板块联动 |
| **财报解读 / 前瞻** | 域3-5当期三表 + 同比环比 + 域6比率变化 + 域10一致预期(对比超/不及) + 指引 |
| **竞争格局 / 行业综述** | 域12行业规模格局 + 各主要公司域2/域6横向对比 + 市占率 + 域7(可选) |

## 四、数据完整披露纪律（拿回来必须怎么用）

**根问题：MCP 一次返回一大块结构化数据，模型只摘 1-2 个数写进正文、其余丢弃。** 以下为强制呈现规则：

1. **结构化落表，不要只摘单点**：取回的数据块**整块落成表格/时间序列**呈现，不得只在正文引用一两个数字就把其余数据丢掉。财务、估值、比率、股东等天然是表格数据。
2. **时间序列给多期**：财务与估值指标至少给**近 3 年 + 最新一期**，让读者看趋势，而非单一时点。
3. **必带同比 / 环比**：任何增长类指标（营收、净利、现金流）呈现时**同时给同比（环比）增速**，只给绝对值不合格。
4. **估值 / 倍数必带对比坐标**：估值指标必须给**历史分位**（自身纵向）和**同业中位数对比**（横向），只报一个"PE=25倍"没有意义。
5. **覆盖度披露**：数据密集型报告（深度报告/首次覆盖）在数据区标一句**数据覆盖度**（如"三表近3年完整，一致预期缺2026年 `[MISSING]`"），让读者知道哪些齐、哪些缺。
6. **来源与时效**：每个定量数据点标来源 + 时间戳；>90天标 `[STALE]`、缺失标 `[MISSING]`（细则见 [source-resolution.md](source-resolution.md)）。
7. **区分事实与判断**：历史数=事实、预测数/一致预期=第三方假设、模型输出=分析师假设，分别标注，不得混同。

### 禁止行为
- 一次取回大量字段却只用其中一两个，其余弃之不用。
- 财务/估值只报单期单值，不给时间序列、不给同比、不给对比坐标。
- 因某个数据源未连接就凭记忆编数，或假装数据不存在而不做 `[MISSING]` 标注。
- 用户明确连了多个源却只用一个、不做交叉验证。
