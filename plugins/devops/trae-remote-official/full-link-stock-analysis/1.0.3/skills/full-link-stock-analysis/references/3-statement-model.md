# 三表联动财务模型

> **计算与交付**：三张表与勾稽校验用 Markdown 表格承载即可（**不依赖 Excel/Python 等重环境**，避免装环境出错）；**最终交付形态遵循主入口 SKILL.md「交付路由表」**（成品报告走 `report-page`/`doc-page`，作为组合链路中间件时向父报告输出，不单独另起文件；轻量问答用对话/Markdown），不再由本 skill 自行决定。历史数据优先通过金融 MCP 获取，以公司财报原文校验明细。

## 关键原则（先读）

1. **三表必须勾稽**：利润表净利润→资产负债表未分配利润；现金流量表期末现金→资产负债表货币资金；三表通过净利润、折旧、营运资本、资本开支相互咬合。
2. **历史=事实，预测=假设**：预测年份的每个驱动假设显式列出。
3. **数据溯源**：历史三年数据标来源与时间戳。

## 模型结构

### 预测期
通常 3-5 年。列出关键驱动假设：营收增速、毛利率、费用率、资本开支/营收、营运资本周转天数、税率、分红率。

## 勾稽校验（必须全部成立）

- [ ] 资产 = 负债 + 权益（每年平衡）
- [ ] 期末未分配利润 = 期初 + 净利润 − 分红
- [ ] 现金流量表期末现金 = 资产负债表货币资金
- [ ] 经营现金流中的折旧 = 利润表/固定资产折旧
- [ ] 营运资本变动与资产负债表应收/存货/应付变动一致

## 输出结构

1. 关键驱动假设表
2. 利润表 / 资产负债表 / 现金流量表
3. 勾稽校验清单（逐项打勾或标记不平原因）
4. 关键比率趋势（利润率、ROE、资产负债率、周转率）
