# 投资决策备忘录（IC Memo）

> **交付形态**：投委会材料属正式文档，结构要完整、数字要自洽。按主入口 SKILL.md「交付路由表」的硬规则，IC memo 属叙事型深度报告，**必须走 `report-page` 产出独立 HTML 文件**（需分页/打印/DOCX 导出时走 `doc-page`），**不得**用裸 Markdown 段落交付。**计算过程不依赖 Excel/Python 等重环境**（用 Markdown 表格承载即可）。综合本 session 内已完成的分析（DCF/Comps/竞争格局/财务等），数据溯源沿用各来源标注。

## 工作流

### Step 1：收集输入
从用户或本 session 既有分析中汇总：公司概况、行业背景、历史财务、估值结论（DCF/Comps）、竞争地位、催化事件、风险因素、仓位与目标价。缺失关键项应向用户确认，不臆造。

### Step 2：备忘录结构

**一、执行摘要**（半页）
- 一句话推荐：买入 / 增持 / 中性 / 减持 / 卖出
- 目标价、当前价、上行/下行空间
- 核心逻辑 3 条 + 主要风险 3 条

**二、公司概况**
- 业务描述、产品/服务、客户与市场
- 竞争定位、管理层

**三、行业与市场**
- 市场规模与增速、竞争格局、结构性趋势、政策环境

**四、投资论点**（核心）
- 3-5 条支柱逻辑，每条给证据
- 价值驱动：营收增长 / 利润率扩张 / 估值重估 / 分红

**五、财务与估值**
- 历史表现（营收、利润、现金流、ROE）
- 估值结论：DCF 内在价值 + Comps 相对位置，交叉验证
- 目标价推导

**六、催化路径**
- 未来 3-12 个月潜在催化（财报、新品、政策、并购）及时间点

**七、风险因素**
- 按严重度×概率排序，每条给出对冲/缓释思路
- 明确"证伪信号"（什么发生了论点就错）

**八、仓位建议**
- 建议仓位大小、建仓节奏、止损位、目标价分批止盈

**九、结论与建议**
- 明确结论：买入/观望/回避 + 关键前提条件

### Step 3：输出格式
- 交付形态按主入口「交付路由表」硬规则：走 `report-page`（需分页/DOCX 导出时 `doc-page`），产出独立文件，不裸吐 Markdown
- 财务与估值用表格呈现（不只是文字）
- 表格数字须自洽（估值桥、目标价、上行空间前后一致）

## 重要原则

- **平衡呈现多空**：诚实列出 bear case，不淡化风险，可信度优先
- **数字必须勾稽**：目标价、上行空间、估值倍数前后一致
- 缺失输入向用户询问，不对目标价/仓位做无依据假设
- 每份 memo 结尾附**免责声明**："本备忘录仅供内部研究讨论，不构成投资建议"

## 质量检查

- [ ] 执行摘要含明确评级与目标价
- [ ] 投资论点每条有证据
- [ ] 估值 DCF 与 Comps 交叉验证
- [ ] 风险含证伪信号
- [ ] 仓位建议含止损/止盈
- [ ] 多空平衡，数字自洽
- [ ] 免责声明
