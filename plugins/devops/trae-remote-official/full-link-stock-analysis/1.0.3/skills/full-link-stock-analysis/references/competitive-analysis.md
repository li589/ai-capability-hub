# 竞争格局与产业链分析

> **计算与交付**：分析用文字框架 + Markdown 表格承载即可（**不依赖 Excel/Python 等重环境**）；**最终交付形态遵循主入口 SKILL.md「交付路由表」**（成品报告走 `report-page`/`doc-page`，作为组合链路中间件时向父报告输出，不单独另起文件；轻量问答用对话/Markdown），不再由本 skill 自行决定。市占率、财务对比等数据优先通过金融 MCP 获取，第三方市场规模数据走联网搜索并标注机构与方法。

## 分析工作流

### Step 0：确定行业定义性指标
先明确这个行业「拼什么」——是规模、技术、渠道、成本、还是牌照？选出 3-5 个行业关键成功要素（KSF）。

### Step 1：市场背景
- 市场规模（TAM/SAM）与增速，标注来源与口径
- 行业生命周期阶段（导入/成长/成熟/衰退）
- 需求驱动因素

### Step 2：行业经济学（Porter 五力）

| 五力 | 强度(高/中/低) | 关键判断依据 |
|---|---|---|
| 现有竞争者 rivalry | | |
| 新进入者威胁 | | |
| 替代品威胁 | | |
| 供应商议价力 | | |
| 客户议价力 | | |

### Step 3：标的公司画像
业务模式、产品线、客户结构、市占率、核心竞争力。

### Step 4：竞争对手地图
列出主要玩家（含标的），横向对比：

| 公司 | 市占率 | 营收规模 | 增速 | 毛利率 | 核心优势 | 主要短板 |
|---|---|---|---|---|---|---|

### Step 5：定位可视化
用两个关键维度（如"规模 × 增速"或"价格 × 质量")定性描述各玩家象限位置。

### Step 6：产业链上下游
- **上游**：关键供应商/原材料，议价能力，成本占比
- **下游**：主要客户/应用领域，需求景气度
- 标的在产业链中的**价值捕获位置**（微笑曲线哪一端）

### Step 7：横向对比与护城河
护城河类型评估（是否具备、强弱）：
- 无形资产（品牌/专利/牌照）
- 转换成本
- 网络效应
- 成本优势
- 规模效应

### Step 8：战略与综合结论
- 标的的相对竞争地位（领先/跟随/挑战者/利基）
- 竞争格局演化趋势对标的的影响
- 对投资论点的支撑或证伪

## 输出结构

1. 行业竞争格局概览
2. Porter 五力表
3. 竞争对手对比表
4. 产业链上下游图（文字描述）
5. 护城河评估
6. 竞争地位结论
