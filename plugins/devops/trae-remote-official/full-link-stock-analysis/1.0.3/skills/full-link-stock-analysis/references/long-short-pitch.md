# 多空投资推介（Long/Short Pitch）

> 衔接深度研究层。综合本 session 内的估值（DCF/Comps）、竞争格局、财务、催化与技术面分析，形成一份有明确立场的推介。数据溯源沿用各来源标注。**立场明确但必须诚实呈现反方逻辑。**

## 推介结构

### 1. 一句话论点（Thesis in one line）
明确方向（做多/做空）+ 核心逻辑 + 目标空间。
例："做多 XX，因 A/B/C 三重驱动被市场低估，12 个月看 XX% 上行。"

### 2. 立场与关键数据
| 项目 | 内容 |
|---|---|
| 方向 | 做多 / 做空 |
| 当前价 | |
| 目标价 | |
| 上行/下行空间 | |
| 建议持有期 | |
| 信心等级 | 高/中/低 |

### 3. 核心论点（3-5 条支柱）
每条论点结构化呈现：
- **论点**：一句话主张
- **证据**：数据/事实支撑（带来源）
- **市场认知差**：为什么市场还没定价 / 定价错了

### 4. 催化路径
未来 3-12 个月能让论点兑现的催化事件与时间点：
| 催化 | 预计时间 | 影响方向 | 观测指标 |
|---|---|---|---|

### 5. 估值支撑
- 多头：DCF 内在价值 / Comps 低估 → 目标价
- 空头：估值泡沫 / 盈利不可持续 → 下行目标
- 给出 bull / base / bear 三情景目标价

### 6. 反方逻辑（必写）
诚实列出**对立面最强的 2-3 条理由**（做多则写 bear case，做空则写 bull case），并逐条回应为何仍坚持本方立场。

### 7. 风险与证伪信号
- 主要风险（按概率×影响排序）
- **证伪信号**：出现什么就该止损/反转判断

### 8. 仓位建议
建议仓位、建仓节奏、止损位、分批止盈目标。

## 纪律

- 立场鲜明，但**必须包含反方逻辑**，不做单边鼓吹
- 每条论点有证据与来源，认知差要具体
- 三情景估值，避免单点目标价
- 明确证伪信号，体现风控意识
- 做空推介额外提示：融券成本、逼空风险、政策限制
- 结尾免责声明："本推介为研究观点，不构成投资建议，市场有风险，决策需谨慎"
