# 事件与异动归因

> 面向「事件/资讯」层。行情/资金/龙虎榜数据的取数与数据源优先级以 `rules/financial-data-spec.md` 为准，公告与新闻走联网搜索并标注来源。**归因是概率判断，需区分"确证"与"推测"。**

## 使用场景

- "这票今天为什么大涨/大跌"
- 解读龙虎榜、资金流向、板块联动
- 突发公告/新闻对股价的影响与持续性判断

## 分析框架

### 1. 异动事实描述
先用 MCP 拉取客观数据，标时间戳：
| 维度 | 数据 |
|---|---|
| 价格异动幅度 | |
| 成交量/量比 | |
| 板块/同行是否联动 | |
| 资金流向（主力净流入/出） | |
| 龙虎榜席位特征（如可得） | |

### 2. 归因分层（关键：区分确证 vs 推测）
- **确证驱动**：有明确公告/新闻/数据支撑（如财报超预期、中标、政策落地）——附来源链接
- **板块/主题驱动**：整个板块联动，个股是 beta——对比板块涨幅
- **资金/情绪驱动**：无明显基本面消息，游资/主力行为——标"推测，待核"
- **技术驱动**：突破关键位引发跟风——结合技术面

### 3. 持续性判断
- 驱动因素是**一次性事件**还是**趋势性变化**？
- 是否改变基本面/投资逻辑，还是纯情绪脉冲？
- 资金是否有持续性（连续净流入 vs 单日冲高）？

## 输出结构

1. 异动事实表（带时间戳）
2. 归因分层：确证因素 / 推测因素分开列，各标来源与可信度
3. 持续性评估：脉冲 or 趋势
4. 对投资逻辑的影响：是否需要调整基本面看法
5. 风险提示

## 纪律

- **严格区分事实与推测**：无来源的原因一律标"推测/待核实"，不编造利好利空
- 每条消息附来源与时间
- 不因单日异动就翻转长期结论，注明脉冲属性
- 龙虎榜/资金数据标数据口径与时间
- 结尾免责声明："事件归因仅供参考，不构成投资建议"
