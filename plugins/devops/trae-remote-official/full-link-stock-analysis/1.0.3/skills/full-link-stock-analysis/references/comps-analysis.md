# 可比公司估值分析

> **计算与交付**：估值倍数的计算过程用 Markdown 表格承载即可（**不依赖 Excel/Python 等重环境**，避免装环境出错）；**最终交付形态遵循主入口 SKILL.md「交付路由表」**（成品报告走 `report-page`/`doc-page`，作为组合链路中间件时向父报告输出，不单独另起文件；轻量问答用对话/Markdown），不再由本 skill 自行决定。倍数与财务数据优先通过金融 MCP 获取，逐家逐项查询，取不到标 `[MISSING]`。

## 核心理念

相对估值回答的是「**在市场当前定价体系下，这只票相对同行贵还是便宜**」。它不给内在价值，而给相对位置。选对可比组、用对倍数是关键。

## 数据获取（金融 MCP 每次仅查单个品种）

对标的公司与每一家 peer，分别调用 MCP 获取：市值、EV、营收、净利润、EBITDA、增速、P/E、P/B、EV/EBITDA、ROE。**多家对比必须拆成多次独立调用**后汇总。行业级中位数可直接问（如「半导体行业PE中位数」）。

## Section 1：选择可比公司组（5-10 家）

选 peer 的维度（按优先级）：
1. **同业务/同行业**（最重要）
2. **相近规模**（市值同量级）
3. **相似增长与盈利特征**
4. **相同市场/地域**

列出入选理由与排除理由，避免"凑数"。遵循 **5-10 家原则**：太少无统计意义，太多稀释可比性。

## Section 4：倍数选择框架

先问「**我在回答什么问题**」，再选倍数：
- **盈利稳定的成熟公司** → P/E、EV/EBITDA
- **高成长/尚未盈利** → EV/Sales、PEG
- **重资产/金融** → P/B、P/TBV
- **现金流型** → EV/FCF、股息率
- **行业特定** → 互联网看 P/S+用户指标；地产看 P/NAV；银行看 P/B+ROE

## Section 5：相对估值结论

1. 标的当前倍数 vs peer 中位数/均值的**溢价/折价幅度**
2. 溢价/折价**是否合理**（用增速、盈利质量、ROE 差异解释）——高增长理应享溢价，反之折价
3. 隐含估值：`目标价 = peer 中位倍数 × 标的对应财务指标`
4. 与 DCF 结果交叉验证（如同时做了 DCF）
