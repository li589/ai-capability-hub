# 盯盘与持仓监控

> 面向「实时盘面」层。**这是观察性监控，不是自动交易，不构成投资建议。**
>
> **取数**：本文只说明「盯盘要看哪些数据、怎么组织呈现」；**具体查哪个金融 MCP、多源优先级与降级兜底，一律以 `rules/financial-data-spec.md` 为准**（A股/港股/指数/基金逐个品种查询，行情/量价优先通达信，资金流/龙虎榜优先东方财富）。

## 使用场景

- 盘中看某只股票/自选组合"现在什么情况"
- 监控关键价位（支撑/压力/止损位）是否触发
- 捕捉盘面异动（急涨急跌、放量、封板/开板）
- 组合层面的当日盈亏与暴露概览

### 2. 异动识别

- **价格异动**：急涨急跌（短时间大幅波动）、涨跌停封板/开板
- **量能异动**：突然放量、量比骤增
- **相对异动**：跑赢/跑输大盘或板块的幅度
  按"事实描述 + 可能原因待核"呈现，原因需结合资讯层核实，不臆测。

## 输出结构

1. 监控时间戳（必须显示，盘中数据时效性强）
2. 单票/组合实时快照表
3. 异动清单（如有）
4. 关键位触发提示
5. **观察性提示**：仅陈述盘面事实与需关注点，不下"买/卖"指令

## 纪律

- **每次输出必须带数据时间戳**，盘面数据 `[STALE]` 阈值应更严（分钟级）
- 只做观察与提示，绝不代替用户决策、不发出交易指令
- 异动"原因"必须标注为待核实，不编造利好利空
- 结尾免责声明："盘面监控仅供参考，不构成投资建议，据此操作风险自担"
