# DCF 现金流折现估值

> **计算与交付**：FCF 预测、WACC、终值、敏感性等计算过程用 Markdown 表格承载即可（**不依赖 Excel/Python 等重环境**，避免装环境出错）；**最终交付形态遵循主入口 SKILL.md「交付路由表」**（成品报告走 `report-page`/`doc-page`，作为组合链路中间件时向父报告输出，不单独另起文件；轻量问答用对话/Markdown），不再由本 skill 自行决定。所有财务数据优先通过金融 MCP 获取，取不到标 `[MISSING]`。

## 概述

本技能为单只股票构建 DCF 估值，遵循投行标准流程但以文字+表格呈现。核心信条：**每个数字都可追溯、每个假设都显式、结论必须落到目标价与安全边际**。

## 关键约束（先读）

1. **数据溯源**：历史财务、股价、股本等来自 MCP 或公司财报原文，每个关键数字标来源与时间戳。
2. **假设透明**：增长率、利润率、WACC、永续增长率等全部显式列出并给出依据，不做隐藏假设。
3. **区分事实与判断**：历史数=事实；预测数=分析师假设，须标注。
4. **不确定就标注**：缺失数据标 `[MISSING]`，陈旧数据（>90天）标 `[STALE]`。
5. **A股/港股/基金/指数**任一在线金融 MCP 即可取数；**美股**仅当 iFinD 在线时走 MCP，否则走公司 IR / SEC EDGAR / 联网搜索。

## DCF 工作流（10 步）

### Step 1：数据获取与校验
通过 MCP 获取标的：最新股价、总股本、总市值、近 3-5 年营收/净利润/经营现金流/资本开支/折旧摊销、净债务、Beta。**逐项标来源**。缺失项列出并向用户确认或标 `[MISSING]`。

### Step 2：历史分析（3-5 年）
计算历史营收增速、毛利率、营业利润率、净利率、FCF 利润率、ROIC。识别趋势与波动，作为预测锚点。用表格呈现：

| 指标 | FY-3 | FY-2 | FY-1 | FY0 | 均值/趋势 |
|---|---|---|---|---|---|

### Step 3：营收预测（5-10 年）
基于历史增速、行业空间、公司指引，给出**逐年营收增长率假设**（显式列出依据）。建议分阶段：高增长期 → 过渡期 → 成熟期。

### Step 4：经营成本与利润率
预测毛利率、营业费用率，推导各年营业利润（EBIT）。利润率假设须说明扩张/收缩理由。

### Step 5：自由现金流（FCF）计算
逐年计算：`FCF = EBIT×(1-税率) + 折旧摊销 − 资本开支 − 营运资本变动`。列出每一分项。

### Step 6：WACC 计算
- 股权成本（CAPM）：`Ke = Rf + β×(Rm−Rf)`，列出无风险利率、Beta、市场风险溢价来源
- 债务成本 `Kd`（税后）
- `WACC = E/V×Ke + D/V×Kd×(1−t)`
显式列出资本结构权重。

### Step 7：折现
逐年 FCF 按 WACC 折现：`PV = FCF_t / (1+WACC)^t`。列折现因子表。

### Step 8：终值（TV）
两种方法交叉验证：
- 永续增长法：`TV = FCF_n×(1+g) / (WACC−g)`，g 需 ≤ 长期 GDP 增速并说明依据
- 退出倍数法：`TV = EBITDA_n × 行业 EV/EBITDA 倍数`
折现回现值。

### Step 9：企业价值 → 股权价值 → 每股价值
`EV = ΣPV(FCF) + PV(TV)` → `股权价值 = EV − 净债务` → `每股内在价值 = 股权价值 / 总股本`。

### Step 10：敏感性分析
以 **WACC × 永续增长率** 做 5×5 网格（Markdown 表），展示每股价值区间；再做 WACC × 终值倍数一组。给出估值区间而非单点。

## 输出结构

1. **估值摘要**：当前价 / 内在价值 / 上行空间 / 评级建议
2. **核心假设表**（增长、利润率、WACC、g、税率）
3. **FCF 预测表**（逐年分项）
4. **WACC 计算表**
5. **现值与 EV→股权价值桥**
6. **敏感性分析表**（WACC × g）
7. **结论**：目标价区间 + 安全边际 + 关键风险 + 假设脆弱点
