# 技术面分析

> 行情/量价/指标数据的取数与数据源优先级以 `rules/financial-data-spec.md` 为准。**只采用业界公认的主流技术方法**，明确不做缠论、江恩、精确波浪数浪等有争议、易过拟合的方法。技术面仅作择时与风险参考，不单独构成投资建议。

## 分析框架

### 1. 趋势判断（道氏理论 + 均线）
- **道氏理论**：识别当前处于上升趋势（高点、低点均抬高）/ 下降趋势（高点、低点均下移）/ 震荡。判断主要趋势、次级回调。
- **均线系统**：MA5/MA10/MA20/MA60/MA120。看多头排列（短期在上）/ 空头排列 / 缠绕。均线拐头、金叉死叉。
- 结论：当前趋势方向与所处阶段。

### 2. 动能指标
| 指标 | 读数 | 信号 |
|---|---|---|
| MACD（DIF/DEA/柱） | | 金叉/死叉/背离 |
| KDJ | | 超买(>80)/超卖(<20)/金叉死叉 |
| RSI(6/12/24) | | 超买(>70)/超卖(<30) |
- 重点关注**顶背离/底背离**（价创新高但指标未创新高 → 动能衰竭警示）。

### 3. 波动与通道
- **布林带（BOLL）**：价格相对上中下轨位置，开口/收口（波动率放大/收敛）。
- 触及上轨的超买、下轨的超支撑参考。

### 4. 量价关系
- 放量突破 vs 缩量突破（放量突破更可靠）
- 量价背离（价涨量缩 → 上涨乏力）
- 换手率与量能变化

### 5. 支撑与压力
- 前高/前低、密集成交区、整数关口
- 均线支撑压力（如 MA60 支撑）
- 缺口位置

## 输出结构

1. **趋势结论**：方向 + 阶段（上升/下降/震荡，初期/中期/末期）
2. **指标一览表**（MACD/KDJ/RSI/BOLL）
3. **量价评估**
4. **关键支撑压力位表**
5. **择时参考**：技术面偏多/偏空/中性；关注的突破/破位信号
6. **风险提示**

## 纪律

- 所有指标读数标数据时间（盘中/收盘、日期）
- 技术面结论用"倾向/参考"措辞，明确其滞后与概率属性
- 不预测精确点位与时间，不喊"必涨必跌"
- **不使用**缠论、江恩角度线、精确波浪数浪等争议方法
- 结尾免责声明："技术分析仅供参考，不构成投资建议，市场有风险"
