# 公司一页纸速览（Tear Sheet）

> **交付形态**：速览天然是"一页纸"，内容组织紧凑即可；**交付形态遵循主入口 SKILL.md「交付路由表」**——速览属轻量输出，默认用对话/Markdown 讲清即可；仅当用户明确要"一页纸报告/正式速览"时才走 `report-page` 产出单页 HTML，不由本 skill 自行另起文件。**不依赖 Excel/Python 等重环境**。所有数据优先通过金融 MCP 获取，一次查询即可覆盖行情/财务/估值主干，缺失项标 `[MISSING]`。

## 用途

Tear Sheet 是研究的**入口速览**：让读者在一页内抓住这家公司「是谁、赚不赚钱、贵不贵、谁在持有、最近发生了什么」。不做深度论证，只做高信息密度的事实浓缩。

## 数据获取

对标的调用 MCP 获取：现价、涨跌幅、市值、市盈率、市净率、52 周高低、成交量、近三年营收净利、ROE、股息率等。个股速览通常一次综合查询即可，逐项标来源与时间戳。
