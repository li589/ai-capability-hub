# 经营汇报合成（复盘 + 结论 + 建议）

覆盖能力项：**形成经营汇报** + **复盘与结论提炼** + **行动建议生成**

## 分析目标

将趋势分析、结构拆解、异常识别的发现**交叉印证、归类、合成**，产出一份可直接用于经营例会的汇报文档。

## Insight 四层分类

每一条发现按分析深度归入对应层级：

| 层级 | 类型 | 回答的问题 | 示例 |
|---|---|---|---|
| L1 | 描述性 (Descriptive) | 发生了什么？ | "3月营收 420 万，环比-12%" |
| L2 | 诊断性 (Diagnostic) | 为什么发生？ | "主因华南区 A 客户暂停订单，贡献-32万" |
| L3 | 预测性 (Predictive) | 接下来会怎样？ | "若 A 客户未恢复，Q2 累计缺口预计达 96 万" |
| L4 | 处方性 (Prescriptive) | 应该做什么？ | "建议本周内与 A 客户确认恢复时间表" |

**报告质量标准**：一份合格的经营汇报至少覆盖 L1-L3，优秀的汇报覆盖全部四层。只有 L1 的报告是"数据搬运"不是"分析"。

## 合成逻辑

```
趋势发现 ──┐
            ├── 交叉验证 → 去重归类 → 四层分类 → 行动建议
结构发现 ──┤
            │
异常发现 ──┘
```

关键原则：
- 多视角交叉印证 → 置信度升级为"高"
- 单一视角孤证 → 标注"[待验证]"
- 矛盾发现并列呈现，不强行统一

## 报告结构模板

### 一、核心结论（Executive Summary）

用 3-5 句话回答：
- 本期整体业绩如何？（对比目标 / 对比上期）
- 最大的亮点是什么？
- 最大的风险/问题是什么？
- 需要管理层决策的事项是什么？

**格式要求**：不看后续章节也能在 30 秒内抓住全貌。

### 二、目标达成总览

| 指标 | 目标 | 实际 | 达成率 | vs 上期 | vs 去年 | 判断 |
|---|---|---|---|---|---|---|
| 营收 | 500万 | 420万 | 84% | -5% | +8% | ⚠️ 落后 |
| 毛利率 | 35% | 37.2% | — | +2.2pp | +1.5pp | ✅ 超预期 |
| 新客数 | 200 | 180 | 90% | +12% | +25% | 基本达标 |

### 三、趋势章节

- 核心指标走势图（含同比基线）
- 拐点标注与解读
- 增长率分级判断

### 四、结构章节

- 业务构成拆解（按最关键维度）
- 增量归因（增长/下降各归谁）
- 集中度风险提示

### 五、问题清单

按影响度排序，每个问题含：
```
问题N [级别]: 一句话描述现象
  - L1 描述: 数据事实
  - L2 诊断: 可能原因（需确认的标注[待验证]）
  - L3 预测: 不处理会怎样
  - 影响范围: 对总目标的拖累量化
```

### 六、行动建议与实施路线

每条建议需满足 **SMART 原则**：具体、可量化预期效果、有负责方向、有时限。

```
建议1 [高优 | 7天内]: 与华南区负责人确认 A 客户订单暂停原因
  - 触发依据: 3月华南营收环比-32%（问题清单#1）
  - 预期效果: 若能恢复，可补回 4pp 达成率缺口（约 20 万/月）
  - 负责方向: 销售VP / 华南区总

建议2 [中优 | 14天内]: 梳理 Top 3 涨幅原材料品类，启动供应商竞价
  - 触发依据: 成本 MoM 连续 3 月加速上升（问题清单#2）
  - 预期效果: 控制毛利率继续下滑，预计节省 5-8 万/月
  - 负责方向: 采购部
```

**实施路线图**（当建议 ≥ 3 条时）：

| 阶段 | 时间 | 动作 | 预期效果 |
|---|---|---|---|
| 立即 | 7 天内 | 确认 A 客户 + 成本 Top 3 品类 | 止血 |
| 短期 | 30 天内 | 供应商竞价 + 新客拓展方案 | 缺口收窄 |
| 中期 | 90 天内 | 客户结构优化 + 产品组合调整 | 结构改善 |

## 交付格式指引

| 场景 | 推荐格式 | 重点章节 |
|---|---|---|
| 经营例会（15分钟） | PPT / HTML | 一+二+五+六 |
| 数据底稿留档 | Excel | 含明细、透视表、公式 |
| 老板快速阅读（2分钟） | 1 页摘要 | 一 + Top 3 建议 |
| 团队复盘讨论（1小时） | 完整报告 | 全部章节 |
| 周报/日报 | 精简版 | 一+二+关键变化 |

## 复盘结论提炼原则

1. **先说结论，再给证据** — "本月落后于目标的核心原因是华南区客户流失"
2. **量化到位** — 不说"有所下降"，说"环比-12%，绝对值减少 48 万"
3. **归因明确** — 区分"内因（执行问题）"与"外因（市场/政策/季节）"
4. **对比基准清晰** — 显式声明对比的是目标/上期/去年同期/行业均值
5. **不过度推断** — 数据说明相关性，因果关系需业务确认
6. **层级完整** — 至少覆盖 L1→L2→L3，争取覆盖 L4

## 质量自检清单

完成报告前逐项确认：
- [ ] Executive Summary 30 秒内能让人抓住全貌？
- [ ] 所有数字可追溯到原始数据？
- [ ] 时间口径（MTD/YTD/MoM/YoY）在每个数字旁显式标注？
- [ ] 问题清单按影响度排序？
- [ ] 行动建议满足 SMART（具体+可量化+有负责人+有时限）？
- [ ] 是否标注了所有"[待验证]"和"[低置信度]"的部分？
- [ ] Insight 至少覆盖 L1-L3 三层？
- [ ] 百分比变化旁有绝对值？
- [ ] 图表有标题、有单位、有时间范围？
