# 关键问题识别（异常检测）

覆盖能力项：**关键问题识别**

## 分析目标

从数据中找出**偏离常态**的信号——可能是数据质量问题、业务异常、或需要管理层关注的风险点。在经营分析场景中，核心是找到"为什么这个月的数不对"。

## 核心方法

| 方法 | 适用场景 | 说明 |
|---|---|---|
| 统计离群检测 | 数值型指标 | 3σ / IQR / Z-Score |
| 突变检测 | 同环比剧烈变化 | 变动 > 预设阈值（如 ±20%） |
| 数据质量扫描 | 所有字段 | 空值率/重复率/格式异常 |
| 业务规则异常 | 有明确业务阈值 | 如"单月成本增幅 > 15% 需告警" |
| 趋势偏离 | 与预测/目标的偏差 | 实际值显著偏离趋势线 |

## 风险分级标准

| 级别 | 触发条件 | 经营分析场景示例 |
|---|---|---|
| **CRITICAL** | 可能影响经营决策的严重偏离 | 单月亏损、核心品类营收断崖下跌、目标达成率 < 40% |
| **WARN** | 偏离常态但尚可解释 | 成本环比 +15%、某区域连续 2 月下滑、毛利率异常波动 |
| **INFO** | 轻微偏离，仅作记录 | 个别品类小幅波动、季节性正常回落 |

## 标准工作流

1. **建立基线** — 为核心指标计算正常范围（历史均值 ± 阈值）
2. **扫描偏离** — 逐指标检查当期值是否超出基线
3. **关联上下文** — 偏离是否能用已知事件解释（促销、季节、政策变化）
4. **分级标记** — 按 CRITICAL/WARN/INFO 分级
5. **归因假设** — 对 CRITICAL 级别给出可能原因的假设（需用户验证）

## 经营分析场景的"问题清单"模板

最终输出应形成一个清晰的问题列表：

```
问题1 [CRITICAL]: 3月华南区营收环比-32%
  - 偏离基线: 历史月均波动 ±8%
  - 可能原因: A客户订单暂停 / 竞品促销冲击（需确认）
  - 影响范围: 拖累全国达成率 4pp
  - 建议动作: 与华南区负责人确认 A 客户状态

问题2 [WARN]: 原材料成本连续 3 月环比上升
  - 偏离基线: 1月+5%, 2月+8%, 3月+12%（加速趋势）
  - 可能原因: 供应商涨价 / 采购量增加带来的品类结构变化
  - 影响范围: 毛利率季度下降 1.2pp
  - 建议动作: 梳理 Top 3 涨幅品类，评估替代供应商
```

## 判断原则

- **不替业务做决策** — 只标记异常 + 给出假设，不直接说"这是错的要改"
- **区分数据问题 vs 业务问题** — 录入错误和真实经营异常分开处理
- **优先 CRITICAL** — 问题清单最多 5 个 CRITICAL，超出按影响度截取
- **可解释性** — 每个标记都要说明"为什么我认为这不正常"
- **样本不足时降级** — 少于 3 个月数据无法建立稳定基线，明确标注
