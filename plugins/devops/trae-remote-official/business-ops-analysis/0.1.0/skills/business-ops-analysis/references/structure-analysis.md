# 结构拆解与目标完成度

覆盖能力项：**业务结构拆解** + **目标完成度分析**

## 分析目标

回答"这些数字内部是怎么组成的"——整体由哪些部分构成、各部分贡献如何、与目标的差距在哪。

## 核心方法

| 方法 | 适用场景 | 说明 |
|---|---|---|
| 占比分解 | 营收/成本/利润按维度拆分 | 算每部分份额及变化 |
| 维度交叉透视 | 地域×产品线、渠道×客户类型 | 找结构性机会/风险 |
| 因子贡献度排名 | 增长/下降归因 | Top N 贡献、帕累托分析 |
| 同期结构对比 | 本期 vs 上期的结构变化 | 占比升降标注 |
| 目标达成率 | 实际 vs 目标 | 按维度拆解到最小颗粒度 |
| 集中度风险 | 单一因子占比过高 | CR3/CR5/HHI 指数 |
| 增量归因 | 增长从哪来/下降归谁 | 各维度对总量变化的贡献额 |

## 增量归因方法

当总量发生变化时，拆解"增量从哪来"：

```
总增量 = Σ(各维度增量)
维度贡献率 = 维度增量 / 总增量 × 100%
```

示例：营收环比增长 50 万
- 华东区贡献 +80 万（160%）← 主要驱动
- 华南区贡献 -30 万（-60%）← 拖累项

## 标准工作流

1. **识别可拆维度** — 扫描数据，列出所有可分组列（部门/产品/地域/渠道/客户类型）
2. **确定拆分优先级** — 按"对决策影响最大"原则选 Top 2 维度
3. **分组聚合** — GROUP BY 计算各维度的汇总值
4. **计算占比与排名** — 每组份额、Top N、累计贡献度
5. **增量归因** — 计算各维度对总量变化的贡献
6. **目标对照**（如有目标值）— 计算达成率，标注低于阈值的维度
7. **结构变化** — 与上期对比，标注占比变动 > 3pp 的维度

## 目标完成度分析

### 时间口径

| 口径 | 公式 | 用途 |
|---|---|---|
| MTD 达成率 | 本月已完成 / 月目标 | 月中进度预警 |
| YTD 达成率 | 年初至今累计 / 年目标 | 年度大盘追踪 |
| 时间进度比 | MTD达成率 / (已过天数/总天数) | 判断是否 on-track |
| Year End 预估 | YTD实际 + 剩余月份×近期月均 | 全年落地预测 |

### 核心公式

```
达成率 = 实际值 / 目标值 × 100%
时间进度比 = 达成率 / 时间消耗率
  - > 1.0 → 超预期
  - 0.8 ~ 1.0 → 正常
  - < 0.8 → 落后，需预警
缺口 = 目标值 - 实际值
追赶所需增速 = 缺口 / 剩余期数 / 近期均值 - 1
```

### 输出要求

- 各维度达成率排名（由低到高，聚焦短板）
- 达成率 < 60% 的**标红 + 单独归因**
- 时间进度比判断是否 on-track
- Year End 预估：按乐观/基准/悲观三档
- 缺口量化 + 追赶难度评估（"需要后续月均增长 X% 才能达标"）

## 输出结构

每个拆解维度应输出：
- 维度名称
- Top N 贡献者：名称 + 值 + 占比 + vs 上期变动
- 增量归因：对总量变化的贡献额和贡献率
- 集中度判断：是否过度集中（Top 2 > 70% 标注风险）
- 目标达成（如有）：达成率 + 时间进度比 + 缺口

## 判断原则

- **维度过多时**：只挑最关心的 2 个，避免组合爆炸
- **多表关联失败**：key 不匹配时明确告知，不强行 join
- **百分比 vs 绝对值**：同时给出，避免"占比高但绝对值小"的误导
- **结构集中风险**：Top 2 占比 > 70% 时主动提示
- **目标缺失时**：用上期同值或历史均值作为参考基准，明确标注

## 经营分析场景示例

- "华东区贡献营收 45%（225万），本月占比下降 3pp，增量归因：对总量下降贡献 60%"
- "A 产品线 YTD 达成率 52%，时间进度比 0.69，Year End 预估仅达 78%，需后续月均+35%"
- "Top 3 客户贡献 78% 收入（CR3=78%），客户集中度风险偏高，建议拓展新客"
- "MTD 第15天达成率 42%，时间进度比 0.84，略低于正常节奏但尚可追赶"
