# 趋势分析（同比与环比）

覆盖能力项：**同比与环比分析**

## 分析目标

回答"这些指标随时间怎么变化"——上升/下降/平稳/周期波动，以及关键拐点出现在什么时候。

## 时间口径定义

| 口径 | 含义 | 典型用途 |
|---|---|---|
| MTD (Month to Date) | 本月第1天到今天 | 月中进度追踪 |
| YTD (Year to Date) | 本年第1天到今天 | 年度目标进度 |
| MoM (Month over Month) | 本月 vs 上月 | 短期动量 |
| YoY (Year over Year) | 本月 vs 去年同月 | 消除季节性 |
| QoQ (Quarter over Quarter) | 本季 vs 上季 | 中期趋势 |

分析前**必须**与用户确认使用哪种口径，不同口径结论可能完全不同。

## 核心方法

| 方法 | 适用场景 | 说明 |
|---|---|---|
| 同比（YoY） | 有完整年度数据 | 消除季节性影响，看真实增长 |
| 环比（MoM/WoW） | 月度/周度数据 | 看短期动量、加速/减速信号 |
| 滑动平均 | 日度或高频数据 | 剥离噪声，看长期信号 |
| 拐点检测 | 增长曲线明显改向 | 标注 slope change point |
| 季节性识别 | 周/月/季/年周期 | 区分"正常波动"与"异常下跌" |
| 增长率分级 | 所有指标 | 将变化幅度映射为业务判断 |

### 增长率分级标准

```
> +20%    → 高增长（标注驱动因素）
+5% ~ +20% → 正增长
-5% ~ +5%  → 基本持平
-20% ~ -5% → 下降（需关注）
< -20%    → 大幅下降（需预警）
```

## 环比增长率计算参考

```sql
WITH monthly AS (
  SELECT
    DATE_TRUNC('month', date) AS month,
    SUM(revenue) AS revenue
  FROM transactions
  GROUP BY 1
)
SELECT
  month,
  revenue,
  LAG(revenue, 1) OVER (ORDER BY month) AS prev_month,
  LAG(revenue, 12) OVER (ORDER BY month) AS same_month_last_year,
  ROUND((revenue - LAG(revenue,1) OVER (ORDER BY month))
    / LAG(revenue,1) OVER (ORDER BY month) * 100, 1) AS mom_pct,
  ROUND((revenue - LAG(revenue,12) OVER (ORDER BY month))
    / LAG(revenue,12) OVER (ORDER BY month) * 100, 1) AS yoy_pct
FROM monthly
ORDER BY month DESC;
```

## 标准工作流

1. **识别时间字段** — 确认哪一列是时间，颗粒度为日/周/月
2. **识别度量字段** — 用户关心的核心指标（营收/订单量/成本/利润等）
3. **确认时间口径** — MTD/YTD/MoM/YoY/自定义区间
4. **基础描述统计** — min/max/mean/median/数据起止范围
5. **可视化** — 线图呈现走势，叠加滑动平均线和同比基线
6. **拐点标注** — 找出 1-3 个最重要的变化拐点，标注时间和变化幅度
7. **同比/环比计算** — 按确认口径计算，标注增长率分级

## 输出结构

每个指标应输出：
- 趋势方向：上升/下降/平稳/波动
- 变化幅度：如 "+23.5% YoY"（附绝对值）
- 增长分级：高增长/正增长/持平/下降/大幅下降
- 关键拐点：日期 + 变化描述 + 可能关联事件
- 置信度：高/中/低

## 判断原则

- **少于 3 个时间点**：无法做趋势判断，标注"数据不足"
- **预测**：只做短期保守外推，必须标注置信区间
- **节假日/异常日**：识别但不剔除，交给报告合成环节决定处理方式
- **季节性 vs 结构性**：明确区分"每年这个月都跌"与"今年特有的下降"
- **量价关系**：营收变化时必须同时看量（订单数/用户数）和价（客单价/ARPU）

## 经营分析场景示例

- "本季度营收环比增长放缓（MoM: +3% → +1% → -2%），3 月出现拐点"
- "客单价 YoY +12%（从 85 元到 95 元），但订单量 YoY -8%，量价出现剪刀差"
- "成本 MoM 连续 3 个月上升（+5% → +8% → +12%），斜率加速，需预警"
- "MTD 营收 320 万，按日均推算月末约 480 万，vs 目标 500 万差距 4%"
