# 能力缺口评估与类比案例

## Capability Gap Assessment（能力审计）

在最终确认推荐前，审计公司是否有能力执行每项推荐动作:

| 推荐动作 | 所需能力 | 公司具备? | 缺口弥补方式 | 弥补周期 |
|---------|---------|-----------|------------|---------|
| [路线图中的动作] | [具体技能/资源] | ✅ 有 / 🟡 可获取 / 🔴 难获取 | [招聘/外包/合作/培训] | [周/月] |

### 常见能力缺口检查清单

- **语言能力**: 团队中是否有人能用目标市场语言商务沟通?
- **监管经验**: 是否曾在类似合规体系中完成过申报?
- **本地市场认知**: 是否有团队成员有当地实地经验?
- **资金可用性**: 推荐预算是否真的存在（非理论预算）?
- **管理带宽**: 谁将 own 这个市场——有具名人选吗?
- **技术就绪度**: 产品能否在声明时间线内完成适配?

### 降级规则

- 任何标记 🔴 的动作必须提供替代路径，否则该市场推荐降级
- 单个市场 >3 项 🔴 → 公司尚未准备好进入该市场 → 增加"Prerequisites"前置清单
- 若用户未提供足够信息判断能力，列出需确认的问题清单后暂停

## Analogous Case Reference（类比案例引用）

对每个目标市场，引用至少 1 个相关先例:

```
先例: [公司名] 于 [年份] 通过 [模式] 进入 [市场]
结果: [成功/失败/转型] — [1 句关键数据]
核心教训: [1 句，该先例最重要的经验]
与用户的差异: [1 句，用户情况与先例有何根本不同]
```

### 引用标准

- 优先选择: 同行业 + 同目标市场 + 近 5 年内
- 次选: 同行业 + 类似市场特征（如都是高监管新兴市场）
- 末选: 不同行业但面对相同结构性挑战（如同样的牌照壁垒）
- 若确实无先例: 明确声明"无已知直接先例"并解释使用的类比逻辑

### 使用方法

类比案例不是装饰，而是校准工具:
- 用成功案例校准"合理的时间线和投入量级"
- 用失败案例识别"用户可能重蹈的覆辙"
- 用差异分析说明"为什么这次可能不同"
