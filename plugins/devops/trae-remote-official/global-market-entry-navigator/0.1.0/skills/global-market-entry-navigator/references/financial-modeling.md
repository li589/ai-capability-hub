# 财务建模与投资决策

## Bottom-Up 成本估算

每国预算必须逐项拆解：

```
Per-country budget = Σ line items:
├── 法律/实体设立: 注册费 + 律师顾问费（小时×费率）
├── 合规/认证: 单SKU认证费 × 产品数 + 时间缓冲
├── 团队: 人数 × 月度全成本 × 月数
├── 本地化: 字数 × 单价 + 设计适配 + 技术集成
├── 库存/运营资金: 单位成本 × 初始订单量 + 物流
├── 营销/GTM: 渠道 CAC × Phase 1 目标客户数
└── 不可预见: 上述合计 × 15-20%
```

禁止用"¥300-800万"单行范围。必须展示每行计算。

## Unit Economics 模型

对每个 GO 市场必须输出：

```
收入模型:
- Phase 1 目标客户数: [X] × 漏斗转化率 [%] = 付费客户
- ARPU: $[X]/月 或 $[Y]/笔 × 频次
- Phase 1 结束时 MRR: $[Z]

成本结构:
- 单客/单笔可变成本: [拆解]
- 毛利率: [%]
- 月度固定成本 (burn): [来自 Investment Summary]

Break-Even 分析:
- 盈亏平衡客户数 = 固定成本 ÷ (ARPU - 单客可变成本)
- 盈亏平衡时间: 基于增长轨迹推算
- 回收期: CAC ÷ 月度单客毛利

Sensitivity 表:
| 场景 | CAC | ARPU | 留存率 | 回收期(月) | Break-even(月) |
|------|-----|------|--------|-----------|---------------|
| 基线 | $X | $Y | Z% | A | B |
| 悲观(CAC +30%) | | | | | |
| 悲观(ARPU -20%) | | | | | |
| 悲观(留存 -10pp) | | | | | |
| 联合最差 | | | | | |
```

若基线 break-even 超 36 个月，必须明确标注并解释为何仍推荐 GO（战略价值/期权价值），或降级为 No-Go。

## Exit Cost Matrix（退出成本矩阵）

对每个市场计算"失败预算"——在各 Gate 退出的最大损失：

```
| 阶段 | 累计支出 | 可回收 | 沉没(不可回收) | 退出成本 | 总损失 |
|------|---------|--------|--------------|---------|--------|
| Gate 1 失败(M6) | $X | $Y(库存/设备) | $Z | $W(遣散/违约/注销) | $Z+$W |
| Gate 2 失败(M12) | | | | | |
| Gate 3 失败(M18) | | | | | |
```

退出成本必须包含:
- 员工遣散费（按当地劳动法最低标准）
- 合同/租约提前终止违约金
- 实体注销周期和费用（部分国家需 12-24 个月注销）
- 税务清算要求
- 对其他市场的声誉影响（定性: 无/轻微/显著）

## 决策红线

- **Gate 1 Loss Cap**: 若 Gate 1 不可回收损失超过公司年营收 5%，必须缩减 Phase 1 范围直至满足
- **Break-even Cap**: 基线 break-even >36 月需要额外论证或降级
- **Combined worst case**: 若联合最差场景显示永远无法盈利，强制 No-Go
