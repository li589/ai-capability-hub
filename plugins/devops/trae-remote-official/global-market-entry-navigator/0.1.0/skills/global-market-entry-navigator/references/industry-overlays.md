# 行业自适应调整

本文件定义各行业在使用通用框架时的特殊调整。执行时按用户所属行业加载对应 overlay。

## SaaS / 数字产品

**权重调整**: 政策合规 10% → 15%（数据驻留是硬约束），本地化 5% → 10%（集成生态）

**核心约束**: 数据驻留法规（GDPR / PDPL / LGPD / PIPL / DPDP）

**额外检查项**:
- 目标市场云基础设施可用性（AWS/Azure/GCP region 是否存在）
- 延迟要求与最近 region 的距离
- 本地集成生态（支付网关/HR系统/ERP 对接）
- PLG (Product-Led Growth) 可行性 vs 企业销售必要性

**Unit Economics 关键指标**: LTV:CAC > 3:1 方可 GO

**Cost model 重点**: CAC/LTV 逐市场对比、回收期

## 实体 / 消费品

**权重调整**: 渠道 15% → 20%（线下渠道是命脉），政策合规 10% → 15%（认证周期是时间约束）

**核心约束**: 产品认证 + 到岸成本

**额外检查项**:
- 物流基础设施（仓储/末端配送/退货）
- 产品认证要求 + 当地测试实验室
- 进口关税/VAT/GST 对定价竞争力的影响
- 零售渠道集中度和上架要求
- 分期付款渗透率对客单价的影响

**Unit Economics 关键指标**: 到岸后毛利率 > 30% 方可 GO

**Cost model 重点**: 到岸成本拆解 (CIF + duty + VAT + 渠道利润)

**Landed Cost 拆解模板**:
```
工厂出厂价 (FOB)
+ 国际运费 + 保险 (= CIF)
+ 进口关税 (按 HS Code)
+ 进口 VAT/GST
+ 本地物流到仓
+ 平台佣金/渠道加价
+ 退货损耗 (按品类%)
= 终端零售价
→ 毛利率 = (零售价 - 上述全部) / 零售价
```

## 金融服务

**权重调整**: 政策合规 10% → 25%（牌照是关键路径），市场规模 25% → 20%

**核心约束**: 监管牌照类型、申请周期、资本金要求

**额外检查项**:
- 逐一列出每种所需牌照（名称/发牌机构/周期/费用/资本金）
- 区分沙盒/试点 vs 正式牌照
- 现有支付轨道（移动货币/银行基础设施/卡网络）
- AML/KYC 要求逐国差异
- 外汇管制对跨境业务的影响

**Unit Economics 关键指标**: Take rate × 交易量 vs 固定合规成本 → break-even volume

**Cost model 重点**: 牌照申请成本 + 时间线 + 合规基础设施持续投入

**牌照比较表模板**:
```
| 牌照类型 | 发牌机构 | 获取周期 | 费用 | 最低资本金 | 适用性 |
```

## 医疗健康 / 受监管产品

**权重调整**: 政策合规 10% → 25%（注册路径是约束），市场规模 25% → 20%

**核心约束**: 注册审批周期（决定 time-to-revenue）

**额外检查项**:
- 注册路径差异（互认协议 vs 全套申报）
- 当地临床数据要求 vs 国际数据接受度
- 产品分类差异（同一产品在不同国家可能分属食品/保健品/药品）
- 医保报销和定价管制
- 上市后监测(PV)要求

**Unit Economics 关键指标**: Time-to-revenue (注册周期) vs 资金消耗速率

**Cost model 重点**: 注册文件准备 + 审批费用 + 上市后合规维护

**特别警告**:
- Novel Food / Novel Drug 类申报周期可达 18-36 个月——这不是"风险"而是"确定性延迟"
- 必须区分"统一框架"下各成员国的执行差异（如 EU Directive 下各国落地不同）
- 产品配方可能需要逐国调整（各国允许成分/剂量上限不同）
