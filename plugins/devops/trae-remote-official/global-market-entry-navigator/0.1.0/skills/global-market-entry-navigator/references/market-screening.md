# 市场筛选与机会评分

## 7 维度评分框架

对每个候选市场，独立评估以下维度（1-5 分制）：

| 维度 | 核心指标 | 必需数据点 |
|------|---------|-----------|
| 市场规模与增长 | TAM/SAM/SOM, CAGR (3-5年), 历史趋势 | 行业报告、政府统计、分析师估算 |
| 客户需求与行为 | 需求驱动力、购买旅程、使用模式、支付意愿 | 消费者调研、类比产品采纳率 |
| 竞争格局 | 市场集中度(HHI)、Top5 玩家+份额、进入壁垒、差异化空间 | 竞品融资/收入/用户量/产品缺口 |
| 定价与支付 | 价格基准、价格弹性、支付方式、分期预期 | 可比产品定价、支付方式渗透率 |
| 渠道结构 | 线上/线下占比、核心分销商/平台、合作伙伴生态、渠道利润率 | 电商渗透率、平台 GMV 份额、分销商画像 |
| 政策与合规 | 牌照要求、产品认证、数据驻留、外资持股限制 | 监管机构网站、法律先例、合规成本估算 |
| 本地化要求 | 语言复杂度、文化适配、技术适配（集成/标准） | 本地化成本估算、时间线预测 |

## 评分标尺

- 5 = 高度有利，壁垒极低
- 4 = 有利，挑战可控
- 3 = 中性 / 信号混合
- 2 = 挑战大，壁垒显著
- 1 = 极其困难，近乎不可行

## 默认权重与行业调权

```
默认权重:
- 市场规模与增长: 25%
- 客户需求匹配: 20%
- 竞争格局: 15%
- 定价与支付: 10%
- 渠道可达性: 15%
- 政策合规: 10%
- 本地化: 5%
```

**调权规则**: 当行业特征要求时，明确声明 (a) 调了哪项, (b) 调了多少, (c) 为什么。调权后总和仍须 = 100%。

## 加权评分计算

```
Country Score = Σ (维度权重 × 维度评分)
```

## 必须遵守

- 不允许单国分析，至少 2 国对比
- 每个评分必须有 1-2 句数据支撑的理由
- 不允许笼统化（"亚洲""中东"不是市场，国家才是）
- 总分相近时（差距 <0.3），必须标注"极为接近"并分析哪些假设变化会翻转排序

## CAGE 距离修正（多国对比时施加）

在完成 7 维度加权评分后，根据出发国与目标国之间的"距离"施加修正：

| CAGE 维度 | 低距离 (0) | 中距离 (-0.2) | 高距离 (-0.5) |
|-----------|-----------|--------------|--------------|
| 文化 | 共享语言或商务文化 | 可学习的差异 | 根本性文化鸿沟(语言+宗教+商务习惯全不同) |
| 行政 | 有 FTA/互认/法系相近 | 法系不同但规则透明 | 外资限制严/无贸易协定/制裁风险 |
| 地理 | <4h 时差, 直飞通达 | 4-8h, 物流可控 | >8h, 冷链/时效/供应链响应受限 |
| 经济 | GDP/capita 差 <3x | 差 3-10x | 差 >10x(定价/支付体系根本不同) |

```
Adjusted Score = Raw Score + Σ(各维度修正值)
```

规则:
- 仅当对比中包含不同文化圈/经济体时施加（如 3 国全在东南亚则不必）
- 修正后若排序翻转，必须标注"CAGE 修正导致排序变化"
- 轻量输出不展开 CAGE 细节，仅标注修正后分数

## 单国模式调整

当路由判定为"单国深评"时：
- 不输出对比矩阵（无对比对象）
- 7 维度逐项展开为 2-3 句分析（而非 1 行评分）
- CAGE 不适用（无第二国对比），改为列出"与出发国的关键差异 Top 3"
