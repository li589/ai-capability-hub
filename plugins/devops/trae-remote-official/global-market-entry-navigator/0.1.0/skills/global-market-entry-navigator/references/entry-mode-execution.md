# 进入模式与执行路线图

## 进入模式决策矩阵

| 模式 | 适用场景 | 典型周期 | 资金需求 | 控制权 |
|------|---------|---------|---------|--------|
| 直接出口/电商 | 低监管壁垒、数字产品 | 1-3 月 | 低 | 高 |
| 当地经销商/分销 | 实体产品、已有渠道网络 | 3-6 月 | 低-中 | 中 |
| 战略合作/合资 | 监管要求、市场准入壁垒 | 6-12 月 | 中 | 共享 |
| 本地子公司 | 长期承诺、数据驻留需求 | 6-18 月 | 高 | 完全 |
| 收购 | 抢时间、获取现有客户 | 6-24 月 | 极高 | 完全 |
| 授权/加盟 | 可扩展模型、品牌驱动 | 3-9 月 | 低 | 低-中 |

## 模式选择决策树

```
是否有硬性监管准入要求（牌照/本地实体/数据驻留）?
├── 是 → 是否可通过合作伙伴满足?
│   ├── 是 → 战略合作/合资（速度优先）
│   └── 否 → 本地子公司（或收购持牌实体）
└── 否 → 产品是否需要本地交付/安装/售后?
    ├── 是 → 经销商/分销（验证期） → 后续自建
    └── 否 → 直接出口/电商（最快验证 PMF）
```

## 分阶段路线图模板

每个推荐市场必须输出:

```
Phase 0: 验证期 (M1-M6)
├── 目标: 验证 PMF 假设、获取首批客户/LOI
├── 关键里程碑: [具体、可衡量]
├── 预算: [来自 Investment Summary Phase 1]
└── 🚦 Go/No-Go Gate 1: [量化条件]
    ├── 通过 → Phase 1
    └── 未通过 → 退出（参见 Exit Cost Matrix Gate 1）

Phase 1: 建立期 (M7-M12)
├── 目标: 建立可持续运营
├── 关键里程碑: [具体]
└── 🚦 Go/No-Go Gate 2: [量化条件]

Phase 2: 规模化 (M13-M18+)
├── 目标: 扩张和盈利验证
└── 🚦 Go/No-Go Gate 3: [量化条件]
```

Gate 条件必须量化（如: ARR ≥ $500K, 毛利率 > 60%, NPS ≥ 40）。

## 即时行动计划（首 30 天）

格式:

| Day | 行动 | 负责角色 | 产出物 | 关键依赖 |
|-----|------|---------|--------|---------|
| D1-D5 | [具体行动] | [角色] | [可交付物] | [前置条件] |
| ... | | | | |

要求:
- 5-8 项具体行动
- 精确到日期范围
- 每项有明确的"Done"标准
- 收到报告当天就能启动第一项

## 合作伙伴具名要求

对每个"找合作伙伴"的推荐:
- 列出 3-5 家具名候选组织（附 1 句选择理由）
- 标注应联系的角色层级（如"Head of International BD"）
- 给出替代发现渠道（行业展会/协会/加速器名称）

对每个"去认证"的推荐:
- 命名 1-2 家认证机构和测试实验室
- 给出预估周期和费用范围
