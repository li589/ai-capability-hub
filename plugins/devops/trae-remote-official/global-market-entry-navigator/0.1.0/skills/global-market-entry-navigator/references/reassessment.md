# 市场再评估框架（Stay / Pivot / Exit）

## 触发条件

用户已在某市场运营，表达以下意图之一：
- "继续投入还是退出？"
- "这个市场还值得做吗？"
- "进去半年了效果不好，怎么办？"
- "市场环境变了，要不要调整？"

## 用户需提供的输入

执行前确认以下信息（缺失则追问）：
- 进入该市场多长时间
- 已投入总金额
- 当初的核心假设/预期 KPI
- 当前实际运营数据（收入/客户数/增速/关键指标）
- 触发再评估的原因（KPI 未达标/外部变化/战略调整）

## 评估框架

### 1. 原始假设验证表

| 维度 | 进入时假设 | 当前实际 | 偏差方向 | 可修正? |
|------|-----------|---------|---------|--------|
| 市场规模 | [原假设] | [实际] | 高估/低估/符合 | 是/否 |
| 客户需求 | ... | ... | ... | ... |
| 竞争 | ... | ... | ... | ... |
| ... | | | | |

### 2. Gate KPI 达成率

对照进入时设定的 Gate 条件（来自原始路线图）：
- Gate 已通过: 列出达标项
- Gate 未通过: 列出未达标项 + 偏差幅度
- 总达成率: X/Y 项通过

### 3. 决策矩阵

| 条件组合 | → 判定 |
|---------|--------|
| Gate 达成率 >70% + 正向势头 + 竞争窗口未关闭 | **Stay** (继续按计划执行) |
| Gate 达成率 40-70% + 部分假设被证伪但市场本身有潜力 | **Pivot** (调整模式/客群/渠道) |
| Gate 达成率 <40% + 核心假设被证伪 + 无翻转信号 | **Exit** (止损退出) |
| 外部不可控变化(政策/制裁/战争) 导致原模型失效 | **Exit** 或 **暂停等待** |

### 4. Pivot 选项（若判定 Pivot）

常见调整方向：
- 缩小规模: 从全国 → 聚焦 1-2 城市
- 换渠道: 线下 → 线上 / 直销 → 经销
- 换客群: 大企业 → SMB / B2C → B2B
- 换模式: 自营 → 合作/白标/OEM
- 换产品: 全线 → 单爆品验证

每个选项给出: 调整成本 + 预期效果 + 验证周期

### 5. Exit 执行清单（若判定 Exit）

- [ ] 客户通知与服务延续安排
- [ ] 员工遣散（当地法定通知期 + 遣散费）
- [ ] 合同/租约提前终止
- [ ] 实体注销流程启动（标注预计周期）
- [ ] 税务清算
- [ ] 可保留资产清单（商标/域名/分销商关系/数据）
- [ ] 对其他市场的影响评估
- [ ] 再进入条件（什么变了才考虑回来）

## 输出格式

BLUF 第一行: "判定: [Stay/Pivot/Exit]，核心理由: [1 句]"
然后按上述 5 步结构展开。总输出控制在 2,500 tokens 以内。
