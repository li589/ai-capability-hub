# 数据形式与附件识别

用户常直接上传附件而不说明结构。先按“扩展名 + 内容特征”快速判定数据形式，再对照该类的首要核对点，之后才进入领域模块。识别与盘点直接做。

## 快速判定

| 形式 | 常见扩展名 | 识别特征 | 首要核对点 |
|---|---|---|---|
| 通用表格 | `.csv` `.tsv` `.xlsx` | 一行一条观测，可能是受试者/事件/标本/孔/时间点 | 一行代表什么；长表还是宽表；主键与连接基数；缺失编码（空/NA/-99/999）；日期格式与时区；分隔符与字符集；Excel 多 sheet 与合并单元格 |
| 统计软件数据/输出 | `.sav` `.por` `.dta` `.sas7bdat` `.rds` `.RData` `.omv` `.spv` `.mplus` `.out` | 数据集、语法、日志、模型摘要或输出对象 | 软件与版本；权重/标签/缺失编码；语法和模型设置；输出是否对应当前数据；告警、收敛、随机起点与复现种子 |
| CDISC SDTM | `.xpt` `.csv` | 两字母域名（DM/AE/LB/VS/EX），变量 `--` 前缀 | USUBJID 唯一；`--DTC` ISO8601；受控术语；观测层非分析层 |
| CDISC ADaM | `.xpt` `.csv` | ADSL（一行一受试者）、BDS（PARAM/AVAL/CHG/BASE） | 到 SDTM 的可追溯性；分析标志（ANL01FL）；基线定义（ABLFL）；分析集（ITTFL/SAFFL） |
| REDCap 导出 | `.csv` + 数据字典 | 字段名小写下划线，`___` 多选拆列，`_complete` 状态 | 是否附数据字典；raw vs label；纵向/重复测量结构；分支逻辑造成的结构性缺失 |
| 测序原始 | `.fastq(.gz)` `.fq` | 4 行一记录（@名/序列/+/质量） | 单端/双端（R1/R2 配对）；质量编码（Phred+33/64）；平台；接头污染 |
| 比对 | `.bam` `.cram` | 二进制，需 `.bai/.crai` 索引 | 参考基因组版本（hg19/GRCh38 坐标不可混）；是否排序；@RG 读组；CRAM 参考可得性 |
| 变异 | `.vcf(.gz)` `.bcf` | `##header` + INFO/FORMAT | 版本；`##reference`；单/多样本；GT/DP/GQ/AD；normalization；gVCF vs VCF |
| 表达矩阵 | `.csv` `.tsv` `.txt` | 基因×样本整数/浮点矩阵 | 原始 counts vs 归一化（TPM/FPKM/CPM，差异分析需原始 counts）；基因 ID 体系；批次信息 |
| 单细胞 | `.h5ad` `.h5` `.mtx`+`barcodes/features.tsv` | AnnData/HDF5 或 10x 稀疏矩阵 | `X` 层是原始/归一化/log1p；obs/var 元数据；QC 指标（线粒体%/nGene/nUMI）；是否已去空液滴 |
| 质谱 | `.mzML` `.raw` `.mzXML` | XML 开放格式（HUPO-PSI） | MS 级别（MS1/MS2）；正/负离子；是否 centroided；保留时间；原始 vs 转换 |
| 流式 | `.fcs` | FCS 3.x，含 TEXT/DATA 段 | 版本；$PnN/$PnS 通道与标记；补偿矩阵（$SPILLOVER）；是否已补偿/变换；事件数 |
| 医学影像 | `.dcm` | DICOM header + 像素 | 去标识（PHI 风险高）；模态（CT/MR/US）；窗宽窗位；像素间距/层厚；Series/Study 层级 |
| 显微成像 | `.tif` `.ome.tif` | OME-TIFF 含 OME-XML | 通道/z-stack/时间维；像素物理尺寸（µm/px）；位深；金字塔分层 |
| 全片扫描 | `.svs` `.ndpi` | 金字塔多分辨率大文件（GB 级） | 放大倍数（20x/40x）；MPP；需 OpenSlide 类库；不能整图入内存 |
| 板式检测 | `.csv` `.xlsx` | 8×12/16×24 板布局，含表头噪声行 | 板布局（样本/标准品/空白/对照映射）；qPCR 的 Ct/Cq 与扩增曲线；标准曲线与定量方法；技术重复；孔位→样本对应表 |

## 附件盘点动作

1. 逐个列出文件、大小、格式判定与置信度；无法确定的标记待确认，不臆断。
2. 找**配对与元数据**：R1/R2、`.bai/.crai`、10x 三件套、板布局映射表、数据字典、样本清单——缺失就明确指出，不自行编造。
3. 表格类先判定“一行代表什么”、长/宽表、主键、连接基数和缺失编码；建立变量名、标签、类型、单位、允许值、时间属性、来源与派生规则的数据字典草案。
4. 影像与 DICOM 含 PHI 的，交付前提示去标识。
5. 把识别结果映射到对应领域模块，进入具体分析。

## 公共数据库与多模态任务

- 下载前建立“要求—模态—队列—文件”覆盖表，逐项核对单细胞、TCR/BCR、空间/成像、bulk、临床结局、突变/CNV 等必需信息；一个数据集只能覆盖其中一部分时，不得声称支持全部任务。
- 记录数据库、项目/队列/样本/运行编号、访问日期、原始下载 URL、访问限制、文件大小与校验和；区分原始数据、作者处理数据和二次汇总。
- 核对同一受试者的基线/治疗中/治疗后样本、重复活检和跨模态样本能否通过稳定 ID 连接；连接不可靠时不要把不同个体拼成纵向或多模态样本。
- 大文件先估算磁盘、内存、传输时间和参考资源；下载中断可续传，但恢复后须核对大小/校验和，不能仅以命令退出码判断完整。
- 若关键模态不可得，选择能形成一致研究设计的补充数据集，或缩小可交付范围并把缺失项标为“受阻”；不得用无关代理数据悄然替代。

## 大/特殊文件处理

- 超大二进制（BAM/CRAM/FASTQ/WSI/mzML）：读头部、索引、样本表即可完成盘点，避免全量解析。
- 专有格式（`.svs`/`.raw`/`.fcs`）：说明需要的读取库与依赖，不假装已解析内容。
- 仅有截图、PDF 表格或统计输出：先解释可见内容，但标记为二手呈现；若要复算或判断模型是否正确，需原始数据、语法/设置和软件版本。

## 常见结构陷阱

- 事件表行数当患者数；宽表误当长表；合并单元格与多级表头破坏解析；
- 缺失编码（-99/999/空串）被当真实值；日期无时区或混用格式；
- 参考基因组/注释版本不一致；raw counts 与归一化矩阵混用；
- 技术重复当独立生物学重复；板边缘效应与孔位映射错配。
