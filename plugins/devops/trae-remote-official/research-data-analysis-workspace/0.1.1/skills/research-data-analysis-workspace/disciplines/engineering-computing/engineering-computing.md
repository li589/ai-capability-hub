# 工程与计算科学数据分析

承接顶层[科研数据助手](../../SKILL.md)。当前使用宏观骨架，不预设具体工程标准、系统架构、基准数据集或算法栈。

## 分析骨架

1. 明确系统边界、工程目标、实验/仿真/运行设计、分析单位和评价指标。
2. 盘点传感器、日志、测试、仿真、标注或软件实验数据，记录版本、配置、时间和依赖。
3. 检查采样、同步、漂移、故障码、重复运行、数据泄漏、训练/测试边界和测量不确定性。
4. 根据任务选择统计比较、可靠性、优化、预测、检测、仿真或算法评测，不预设具体模型。
5. 验证基线、公平比较、消融/敏感性、误差分解、复跑一致性和适用工况。
6. 交付数据与配置快照、代码、环境、指标表图、失败案例、限制和复现说明。

## 待扩展接口

- `system_and_design`：系统、工况和实验设计；
- `data_and_quality`：日志、传感器、仿真或标注数据规则；
- `metrics_and_methods`：指标、基线和方法；
- `validation`：测试边界、复跑、压力与稳健性；
- `delivery`：代码、配置、模型和报告。

在接口未细化前，执行顶层全学科骨架并避免加入未经确认的领域硬阈值；不要向用户说明模块开发状态。
