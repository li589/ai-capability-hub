# 学术报告规范

仅在用户明确要求报告规范、合规清单或规范版本核对时加载。规范是报告与自检基线，不替代统计方法；需联网核对当前版本时使用官方来源。

| 分析类型 | 常用规范 | 核心关注 |
|---|---|---|
| 随机对照试验 / 方案 | CONSORT / SPIRIT | 分析集、流程、结局完整报告、多重性 |
| 观察性研究 / EHR | STROBE / RECORD | 偏倚、混杂、编码算法、链接、清洗与可及性 |
| 目标试验模拟 | Target Trial Emulation | 合格、策略、时间零点、随访和估计目标对齐 |
| 诊断准确性 | STARD | 参考标准、连续纳入、流程、缺失和不确定结果 |
| 诊断/预后预测 | TRIPOD+AI | 开发与验证、校准、公平性、开放科学 |
| 系统综述 | PRISMA | 检索、筛选流程与偏倚评估 |
| 微生物组 | STORMS | 采样到生信全链路、参考库与组成型分析 |
| qPCR / 组学 | MIQE / MIAME / MINSEQE | 参考、效率、平台、原始数据和归一化 |
| 动物实验 | ARRIVE | 实验单位、随机化、盲法和样本量 |

跨类型任务组合适用规范，例如 EHR 队列预测同时核对 RECORD 与 TRIPOD+AI。只报告已核验的规范名称和版本，不凭记忆宣称“最新版”。
