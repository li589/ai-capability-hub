# 生物医药科研数据通用分析核心

适用于所有已触发的生物医药科研数据任务。先保护原始数据与科学问题，再清洗、选择方法、计算和解释；不要从想得到的结论反推处理规则。

## 一、冻结范围与数据字典

在处理数据前确认并记录：

- 研究问题、设计（实验/观察、横断/纵向、配对/重复测量）、目标人群/样本、分析单位、时间零点与随访；
- 暴露/处理、主要与次要结局、协变量、分层/聚类/批次、权重、删失和派生变量；
- 每个变量的名称、含义、角色、类型、单位、允许值/范围、缺失编码、时间属性、来源、派生规则和敏感级别；
- 表之间的主键、外键、连接基数以及“一行代表什么”。不要把事件、孔、细胞、图像、重复测量行数当作独立样本量。

先在内部建立紧凑的数据字典草案；无法判断的字段标记“待确认”，不要凭名称强行解释。只有用户明确要求数据字典，或关键字段定义会影响结论时，才把相关部分放入交付物；不要把全量字段表塞入主报告。研究问题或主要结局未给出时，先做不依赖该选择的盘点与质控，再提出最少必要问题。

## 二、分析状态与处理约束

### 状态链

将数据处理拆成明确状态，避免把“发现问题”误写成“已经清洗完成”：

1. `raw`：只读输入；
2. `profiled`：只增加质量标记，不改变记录；
3. `adjudication_pending`：隔离无法自动裁定的记录；
4. `derived`：只执行有依据的删除、修正或派生；
5. `analysis_population`：按当前证据形成一个明确标注的主口径，必要时同时形成保留/排除等条件性口径。

标记不等于处置，候选映射不等于已验证映射，隔离不等于删除，`derived` 也不自动等于唯一正确的最终分析集。仍有影响纳入、暴露、结局或时间零点的未决事项时，将主结果称为“当前证据下的保守口径”或“条件性分析”，并给出影响方向或场景差异；不得因此暂停整个任务。

任何改变记录数或独立分析单位数的步骤，都在分析记录中说明前后口径、`rows`、`units`、`events`、移除/隔离数量和待裁定数量，供结果解释使用。

以下状态清单仅是内部事实源示例，不作为主报告模板：

```json
{
  "states": [
    {"name": "raw", "rows": 100, "units": 98},
    {"name": "deduplicated", "parent": "raw", "rows": 99, "units": 98,
     "removed_rows": 1, "removed_units": 0}
  ],
  "report_state": "deduplicated",
  "pending_decisions": 2,
  "analysis_population_final": false,
  "report_generated_from_manifest": true,
  "state_metrics_recomputed": true
}
```

### 单一事实源

- 所有状态计数、描述统计、图表和正文事实由同一分析对象生成；不在展示层手工维护第二套数字。
- 每次删除、隔离或合并后重新计算记录数、唯一分析单位、事件、缺失和异常；不得用“上一状态人数减去记录数”推算新人数。
- 可精确计算时不用“约”。日期差须声明自然日或含端点口径；正文中的极值和示例从当前状态逐项重算。
- 在状态清单中指定 `report_state`；正文不得混用 raw 与 derived 状态的分母，跨状态比较须明确标注。

### 质量问题与处置

**重复**：分别识别完全重复、主键重复、重复测量、生物重复和技术重复。报告 `duplicate_groups`、`rows_in_duplicate_groups`、`redundant_rows` 和实际动作。完全重复先声明比较列；主键冲突没有来源优先级或源系统裁定时，保留或整组隔离，不默认取首行/末行。

**缺失**：区分结构性不适用、未测、失访、无效编码、意外缺失和未知。证据不足时使用 `unknown`；不默认缺失即正常/未暴露，不默认均值填补、完整案例或整列删除。结构性不适用单独报告，不计入“存在质量问题的记录”或异常告警总数。插补和特征处理在训练折内拟合。

**异常值**：先区分错误、流程伪影、真实极端值和高影响点。只有违反已定义规则的记录进入异常计数；未经验证的候选映射进入待复核项。不得因显著性或拟合改善删除真实观测。

**样本质量**：按设计检查样本流、映射、组间平衡、批次/中心/操作者、测量范围、对照、失访和有效样本量。关键问题使目标不可识别时停止该主分析。

### 内部记录

分别维护原始问题台账、实际变更日志和派生数据标记；三者默认仅用于内部验证。用户明确要求时单独交付机器可读文件，不把规则矩阵、逐条记录、严重度分解或文件清单复制进主报告。

### 未决语义的非阻塞处理

- 先交付不依赖业务裁定的结构、缺失、重复、范围、时间关系和可用性结论。
- 对可能改变记录的事项默认保留原值并加标记；对可能改变统计结论的事项给出少量有科学意义的场景或敏感性结果。
- 待确认项写成“补充后可提高何种判断的确定性”，不得写成“确认后才继续分析”。用户只要求质控时，不擅自把后续组间比较当作当前任务的完成条件。
- 最终交付明确区分已完成结果、条件性结果和当前不能推出的结论，但必须包含对用户原始问题的直接回答。

## 三、描述统计与图形

- 始终报告总样本数、独立分析单位数、各分析实际 `n`/事件数与缺失分母。
- 变量名和标签保持语义明确：`analysis_n` 表示进入该分析的人数，`event_n` 表示事件数，`missing_n` 表示缺失数；不得用 `n_outcome` 等模糊字段混装事件数与可分析人数。
- 连续变量按分布和目的给均值±标准差或中位数[IQR]，并展示分布；分类变量给 `n/N (%)`；时间到事件给随访与事件。
- 配对、重复测量、分层、聚类或批次数据用与设计一致的摘要，不把下层观测混在一起。
- 基线表主要用于描述，不以逐项显著性检验决定混杂调整。
- 数据图由真实数据和确定性代码生成；图表与统计表必须来自同一分析版本。具体规则见[可视化、作图与生图](visualization-and-figures.md)。

## 四、按设计选择统计方法

先写目标估计量，再按结局类型、组数/时间点、独立性、分布、删失/竞争风险、聚类/重复测量和协变量选择方法。不要通过遍历方法寻找显著结果。

| 目标与设计 | 常用起点 | 必查项 |
|---|---|---|
| 两独立组连续结局 | 均值差回归/Welch t；必要时稳健或秩方法 | 分布、方差、离群、效应量与 CI |
| 配对/前后连续结局 | 配对差或配对/混合模型 | 配对完整性、时间效应、回归均值 |
| 多组/重复测量连续结局 | 线性模型、混合效应、GEE | 计划对比、层级、相关结构、多重性 |
| 分类结局/率 | 风险差/比、比值比模型；配对/聚类用对应模型 | 分母、稀疏格、过度离散、绝对效应 |
| 计数结局 | Poisson/负二项或相应混合模型 | 暴露时间、过度离散、零膨胀 |
| 时间到事件 | KM/累积发生、Cox/参数或灵活模型 | 时间原点、删失、PH、竞争风险、绝对风险 |
| 相关/关联 | Pearson/Spearman 或回归 | 非线性、离群、重复测量、混杂、范围限制 |
| 诊断/预测 | 设计对应的性能与验证方法 | 泄漏、拆分、校准、阈值、临床效用 |

### 假设检验与分组差异

- 报告效应量、方向、置信区间、实际分母和精确 `p` 值；不要只写“显著/不显著”。
- 假设不满足时优先使用与估计目标一致的稳健标准误、变换、广义/混合模型、置换或秩方法，而不是机械套用“正态性检验通过才可分析”。
- 预先定义检验族并控制多重比较；区分主要、次要、探索性和敏感性分析。
- 亚组差异用交互项或直接对比检验；不要以“A 组显著、B 组不显著”推断两组效应不同。
- 非显著不等于等效或无效；等效/非劣需预设界值与相应设计。

### 相关、回归与模型诊断

- 相关不代表因果或一致性。方法比较用 Bland–Altman、ICC 或等价性方法。
- 回归调整变量依据研究设计、时间顺序和领域知识，不依据单变量 `p` 值逐步筛选。
- 检查函数形式、残差/拟合、共线性、影响点、过拟合、聚类/重复测量、缺失和验证边界；报告稳健性分析。
- 不把高 `R²`、AUC 或拟合优度当作因果、校准、泛化或科学正确性的证明。
- 不因工具可以计算就把关联任务扩展为预测任务。ROC、数据驱动 cutpoint、分类准确率或“预测效度”只有在研究问题和验证设计支持时才报告。

## 五、信度、效度与潜变量

- 先确认量表版本、语言/文化适配、计分方向、反向题、分量表、适用人群和缺失计分规则。
- 内部一致性至少给系数、区间、题目数和模型假设；不要只凭 Cronbach α 判定单维性，适用时补充 McDonald ω。
- 重测/评分者信度选择并完整说明 ICC 类型与置信区间；分类评分用适当的 kappa/一致率。
- 探索性因子分析与验证性因子分析分开；报告提取/旋转、类别题处理、拟合指标、载荷、交叉载荷与独立验证。不要在同一数据上反复修模后称为确认性。
- 聚合、区分、准则和已知组效度需对应外部证据与预设假设。
- LPA/LCA/聚类综合信息准则、似然比检验、分类不确定性、类别大小、稳定性、可解释性和复现性；不要按最想要的类别数或单一指标选择。后续回归需考虑分类误差，数据驱动类别必须标为探索性并验证。

## 六、结果解释

按以下顺序写：

1. 数据和质量事实；
2. 估计量、效应/性能、区间和实际分母；
3. 与研究问题对应的统计解释和实际/临床意义；
4. 不能推出的结论；
5. 设计、测量、缺失、偏倚、模型、外推和复现局限；
6. 预设分析与探索/敏感性分析的一致或冲突。

不要把 `p<0.05` 写成“结果重要”或“假设为真”，不要把 `p>0.05` 写成“完全没有差异”，不要把组间基线不显著写成随机化或无混杂的证明。用户提供的统计表、截图或软件输出只能解释其中可见且可核验的内容；缺少原始数据、语法、版本或设置时明确限制。

## 七、最低可复现记录

按任务需要保存输入来源、数据字典、清洗与样本流、分析计划/偏离、代码或计算记录、参数与随机种子、软件环境和结果表图。正式交付按[复现与报告](reproducibility-and-reporting.md)执行。
