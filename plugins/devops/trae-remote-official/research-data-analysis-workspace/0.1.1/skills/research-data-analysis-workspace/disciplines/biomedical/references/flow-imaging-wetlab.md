# 流式、成像与湿实验

## 通用实验设计

先区分实验单位、生物重复、技术重复和下层观测。孔、细胞、视野或图像通常不是独立生物重复。

- 记录样本来源、处理、剂量、时间、板位、批次、操作者和仪器；
- 评估处理组在板、批次、时间和操作者上的随机化或平衡；
- 保留阴性、阳性、载体、未染、单染、同型或基准样本等适用对照；
- 预设失败实验、重复实验和技术重复聚合规则；
- 盲法、解盲时点和人工判读修改需要留痕；
- 单位转换、背景扣除、归一化和低于检出限处理不得静默完成。

## 流式细胞术

- 保存原始事件文件、面板、仪器设置、补偿/解混矩阵和门控版本；
- 依次核对时间稳定性、碎片、单细胞、活细胞及目标群体；
- 门控阈值参考适用对照，不因组别结果移动门线；
- 报告父群、分母、事件数和低事件数不稳定性；
- 自动聚类/降维结果需映射回样本层，并用可解释标记和独立证据确认；
- 跨批次比较需有桥接对照或可解释的标准化策略。

结果知情后改变门控应有独立规则并留痕；若原始文件、补偿信息或样本映射缺失到无法核验关键群体，须明确标注受影响结论的局限。

## 显微与病理成像

- 保留原图、元数据、像素尺寸、通道、曝光/扫描参数和预处理版本；
- 训练/验证拆分按患者、动物、切片来源或实验批次进行，禁止相邻 patch 泄漏；
- 分割、去背景、去卷积、阈值、人工修订和排除区域可追溯；
- 评估饱和、漂移、焦外、拼接、压缩和批次染色差异；
- 图像级特征聚合到正确实验单位，使用层级结构处理重复视野；
- 展示代表图时说明选择规则，且不得用代表图替代全样本量化。

## 板式与其他湿实验

- 检查板位效应、边缘效应、标准曲线、动态范围、空白和对照稳定性；
- 技术重复合并前检查离散度和预设失败规则；
- 浓度反算、检出限、定量限和超范围样本处理需记录；
- qPCR 等相对定量需说明参考基因、校准样本、效率假设和批次；
- 动物/细胞实验说明窝、笼、培养批次、传代、克隆或供体层级；
- 只要统计推断目标是供体/动物，不能用孔数或细胞数替代其样本量。

## 最低交付

实验设计表、样本/板/批次映射、原始文件索引、QC 与失败规则、处理参数、聚合层级、排除记录、主结果与批次/门控/分割敏感性分析。
