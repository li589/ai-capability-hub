# 生理信号、神经解码与时间序列

适用于心电（ECG）、光电容积（PPG）、心率变异（HRV）、脑电（EEG）、连续血压/血氧、可穿戴与监护仪，以及 Neuropixels/神经元放电与行为等随时间采样的信号及其逐段特征。核心是**采样与预处理可追溯、分析单位不混淆、方法间可比性明确**。

## 身份与设计

- 记录设备/导联/通道、采样率、单位、时间戳与时区、分段规则；不同设备或算法（如 PPG 专利法 vs ECG 金标准）得到的同名指标不可直接混用比较，须先做方法一致性评估（Bland-Altman、ICC）；
- 明确**分析单位**：同一受试者的多段/多时窗信号不是独立样本，患者内多段须用混合效应或聚合到个体层，禁止把段数当样本量；
- 病例/对照、干预前后、监护过程不同阶段（如血透透析前/中/后）与设备批次是否混杂需核对。

## 预处理与质量

- 记录从原始波形到分析特征的完整链路：滤波、基线漂移去除、去伪迹、R 波/搏动检测、异常搏动剔除、重采样与分段；
- QC 指标（信号质量指数、伪迹比例、缺失/丢包）区分预设阈值与数据驱动阈值，低质量段的排除规则需前置并留痕；
- 非平稳信号在分段与去趋势上敏感，DFA 等方法的窗长范围、拟合区间（α1 短程 / α2 长程）、去趋势阶数须显式记录，改动会改变结果。

## 统计推断

- 时间序列/非线性指标（DFA α、样本熵、频域 LF/HF）先在段级计算再按设计聚合，推断在个体或分组层进行；
- 方法比较（如 PPG 与 ECG 估计房颤/HRV 指标）用一致性/等价性分析，不用单纯相关系数冒充一致；
- 过程性动态（透析全程、昼夜节律）用重复测量/混合模型或轨迹方法，说明时间相关结构；
- 声明多重比较（多导联、多时窗、多指标）与效应量、不确定性。

## 神经活动与行为解码

- 先生成 session/probe/animal/region 清单，逐项执行预设纳入阈值；保存纳入状态和排除原因，不用最终解码成绩反向筛选数据；
- 冻结事件对齐点、分析窗、bin 宽、good-unit 定义、脑区映射、trial 条件与类别编码；神经矩阵须保留 trial、session、animal、probe 和 region 标识；
- 随机逐 trial 的 5 折仅回答同 session 内的可解码性。若目标是跨 session/动物泛化，按 session/动物分组拆分；同一 session 的 trial 不得跨泛化验证边界；
- 置换检验在与原设计相同的分组/分层内打乱标签，保存全部 null 分布；比较多个脑区时控制多重性；
- 运动残差化、z-score、神经元筛选和超参数必须在每个训练折内拟合并应用到测试折，禁止先用全数据残差化再交叉验证；
- “残差化后性能下降”只支持运动信息与选择解码共享方差，不单独证明神经活动不存在独立选择编码；同时报告前后性能、配对差、区间、置换/自助法和敏感性。

## 最低交付

- 设备/采样/通道与时间基准；原始波形到特征的处理与 QC/排除记录；
- 分段与聚合层级、分析单位声明；
- 方法间一致性结果（若涉及跨方法比较）；
- 指标结果、效应量、不确定性与敏感性（窗长/去趋势/阈值）。
- 神经解码另交付数据清单、事件对齐矩阵说明、拆分键、null 分布、运动特征和残差化前后结果。

## 报告规范

心率变异及相关生理信号分析按 **ESC/NASPE HRV 测量标准（Task Force）** 报告：明确采样率、记录时长与分段长度、时域/频域/非线性指标的计算定义、伪影与异常搏动处理，跨设备或跨算法比较须说明可比性前提。
