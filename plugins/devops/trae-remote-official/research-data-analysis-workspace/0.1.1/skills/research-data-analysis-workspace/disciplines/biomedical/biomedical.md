# 生物医药数据分析（学科模块）

承接顶层[科研数据助手](../../SKILL.md)的生命与健康科学路由。本模块已经细化。只读取当前问题需要的参考文件，不把内部 SOP、状态记录或模块名称展示给用户。

## 执行原则

- 把用户请求先转成简短的内部分析契约：研究设计、独立分析单位、关键时间点、主要变量/比较、估计目标和交付物。定义不足时采用保守口径或并列场景，继续完成所有可靠部分并在同一轮交付最终结果；待确认事项只说明影响，不得成为暂停、正式分析集或文件交付的门槛。
- 普通 CSV/TSV/XLSX 直接盘点行列、主键、分析单位、缺失、重复、范围和时间逻辑；只有格式陌生、多文件关系不清或属于领域专用格式时，再读取[数据形式与附件识别](references/data-intake.md)。
- 所有生物医药任务读取[通用分析核心](references/analysis-core.md)，再按下表加载最少必要的领域模块。不要为了显得全面而运行无关方法。
- 数据处理遵循“发现问题—判断依据—形成派生副本—从该状态计算结果”。不能裁定的问题保留原值并标记；所有报告数字、表和图来自同一分析状态。
- 分析阶段完成设计匹配、模型诊断、敏感性分析与开发/验证评估；这些是统计方法的一部分，不是产物生成后的检查流程。
- 交付时读取[复现与报告](references/reproducibility-and-reporting.md)，直接生成用户要求的产物，写出后不再检查或预览。

## 质量优先级

当时间、数据或篇幅需要取舍时，按以下顺序保证质量：

1. **正确性**：变量语义、分析单位、分母、时间顺序、数据状态、公式与报告数字一致；任何会改变结论的错误优先修正。
2. **专业性**：方法匹配设计和估计目标，处理依赖、混杂、泄漏、缺失与多重性，报告效应量和不确定性，并遵守因果、预测和临床解释边界。
3. **全面性**：覆盖回答研究问题所需的最短证据链及会改变结论的敏感性分析；不以方法数量、章节数量或审计细节充当全面。

视觉表达沿用顶层规则。本模块不为提高美观度增加额外分析、装饰或报告篇幅。

## 六类常见任务的最小充分 SOP

以下是默认分析顺序，按数据和研究问题裁剪，不逐项抄入主报告。

### 1. 临床队列质控与可用性

1. 先确定一行代表患者、就诊还是事件，并分别计算记录数、唯一患者数、完全重复、主键重复和冲突组。
2. 按变量角色汇总缺失和允许值；把结构性不适用与意外缺失分开，分别报告问题单元、受影响记录和患者数；编码来源不明时只给候选映射，不覆盖原值。
3. 以时间零点为中心检查结局、暴露和随访顺序；日期倒置先称时间逻辑不一致，不自动推断偏倚类型或删失规则。
4. 只在证据充分时去除完全重复或执行确定性转换；其余问题在派生副本中保留标记。主键冲突无法裁定时保留冲突组，或同时给出“全部保留/整组排除”的条件性口径，不能为了生成单一数据集擅自选行。
5. 主报告必须在本轮给出队列可用性、关键计数、问题对分析的影响、当前可用范围和明确结论；另交付处理后数据。待确认事项可作为后续信息需求，但不写“确认后继续”，逐行台账留在内部或条件性附件。

### 2. 观察性治疗效果比较

1. 定义目标人群、治疗策略、比较组、时间零点、随访、结局方向和目标效应；定义不足时退回关联性分析。
2. 先画清时间顺序：只用治疗前信息识别混杂，主分析排除明确的治疗后变量、中介和碰撞点。
3. 先给未调整结果，再用设计与领域知识预先确定的回归、标准化、加权或匹配方法估计调整效应；不按单变量显著性筛协变量。
4. 加权或匹配前固定 ATE、ATT、ATC 或可匹配人群效应；报告实际分母、绝对和相对效应、置信区间、平衡、overlap、权重公式/截尾和有效样本量，不能把 ATT 结果按 ATE 解释。
5. 用合理替代规格或未测量混杂敏感性分析判断稳健性；敏感性指标的方向和区间端点须匹配当前效应定义，无法可靠计算时宁可不报；结论明确识别假设和不能推出的因果含义。

### 3. 随机对照试验主分析

1. 对齐随机分组、实际治疗、停药、脱落、结局可评估与各分析集人数，主要结论优先使用预设 ITT 口径。
2. 二分类主要终点至少报告各组 `n/N`、风险差和一个相对效应及区间；先固定“治疗相对对照”和结局方向，使 RD、RR、OR 及文字解释保持同一对比；完整案例只能称可评估病例分析，不能无说明地称 ITT。
3. 时间到事件结局冻结事件、时间原点和删失，报告 KM 曲线及 number at risk，并给相对效应与有解释价值的绝对风险；随访充分性用反向 KM 等合适方法，不比较混合了事件与删失的观察时间分布来证明疗效。
4. 将主要分析、缺失/脱落敏感性和方案偏离分析分开，说明结果是否一致。
5. 报告聚焦样本流、主要终点、随访结局、不确定性和局限；不推断数据中没有提供的安全性或机制结论。

### 4. 临床量表信效度与关联

1. 先按数据字典确定构念、预期维度、计分范围、反向题和缺失计分规则，再生成总分或分量表分数。
2. 描述总分与条目分布，检查题总相关；内部一致性不只报告 Cronbach α，适用时同时给 McDonald ω 及区间。
3. 因子分析与样本量和量表设计相匹配；小样本或同一数据上的结构探索只表述为探索性，不宣称确认性验证。
4. 效度、组间差异和结局关系分别报告效应量、区间、实际分母及必要协变量，不把相关写成因果或预测验证；用户只问关联时，不额外寻找 ROC、AUC 或“最佳界值”，同一样本上的探索结果也不能充当预测验证。
5. 结论区分量表可靠性、结构证据、外部效标关系和可推广性，不用单个系数概括全部测量质量。

### 5. 小 RNA / RIP-seq 结果复现

1. 冻结序列/转录本/基因粒度、样本与文库、reads 长度、注释身份、链方向、过滤顺序、归一化分子/分母、零值和阈值规则；`total_reads`、`aligned_reads` 与其他可用库大小不能在无依据时互换。
2. 先做库级 QC；按既定长度和 siRNA 身份过滤后，再用排除项正确的库级分母计算 RPM 与 fold change。
3. 对每个蛋白或条件分别筛选，再在用户要求的序列级求交集；严格区分 `>` 与 `≥`，WT 为零时使用预先说明的可复核规则，阈值边界记录不能被零值规则自动放宽。
4. 主结果保持 siRNA 粒度，映射到基因后再与论文基因级 benchmark 比较；多对一映射不会自动增加唯一基因数，外部数量也不作为调参目标。
5. 报告各阶段数量、共同集合、仅本次/仅参考结果、差异原因与 mock/离线数据边界，保留复现契约和计算记录。

### 6. 诊断模型开发与独立验证

1. 确认目标人群、预测时点、索引检验/候选特征、参考标准、开发与验证队列；按患者去重和拆分。
2. 排除预测时点之后才获得的变量；缺失处理、异常值规则、变换、特征选择、模型和阈值全部只在开发数据中确定。
3. 先建立单指标基准，再建立最小充分联合模型；控制候选参数复杂度，不用验证集反复选择变量或调参。
4. 锁定流程后在独立验证队列报告 AUC 及区间、校准曲线/截距/斜率、Brier 或适用指标；单指标与联合模型的配对比较必须使用同一批完整病例，分别列出开发、验证及各模型实际分母。
5. 阈值表至少给敏感度、特异度、阳性预测值、阴性预测值、区间和分母；筛查阈值依赖目标敏感度、患病率与误判代价，条件不足时呈现权衡而非宣称唯一最佳值。
6. 若模型包含标准化或其他变换，交付可应用的原尺度公式或全部预处理参数；正则化模型不默认附加经典标准误、P 值和置信区间，AUC 差异不显著也不证明模型等效或某变量是主要驱动。
7. 对关键缺失、极端值和队列差异做敏感性说明，结论限定在验证人群与当前参考标准；即使当前验证集全对，也不写成“完美分类”或泛化性已获证明。
