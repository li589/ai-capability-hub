# 通用与跨学科科研数据分析

承接顶层[科研数据助手](../../SKILL.md)。当任务跨多个学科、属于方法学研究或暂时无法可靠归类时使用。

## 分析骨架

1. 冻结研究问题、设计、分析单位、数据版本、主要变量/比较和交付物。
2. 建立文件清单、数据字典、主键关系、样本流与处理血缘。
3. 检查缺失、异常、重复、测量误差、依赖结构、泄漏和可识别性。
4. 依据问题与数据选择描述、推断、预测、探索或混合分析，并声明假设。
5. 执行主分析、诊断、稳健性/敏感性和必要验证。
6. 交付结果、区间或不确定性、图表、代码/计算记录、环境、限制与完成状态。

跨学科任务把各学科的分析单位、质量规则和验证要求显式对齐；冲突时以研究问题和证据链为准，不拼接互不兼容的结论。
