# 因果、生存、诊断与预测

## 观察性因果

因果措辞前必须明确干预、比较策略、目标人群、时间零点、随访、结局和估计量。若这些要素无法定义，退回关联性分析。

重点检查：

- 暴露、协变量和结局的时间顺序；
- 混杂变量来自设计与领域知识，不依据单变量显著性筛选；
- 不调整明确的中介、碰撞点或暴露后的变量，除非估计目标要求且已说明；
- immortal-time、选择、检测、逆向因果和 informative censoring 风险；
- positivity/overlap、权重极端值、匹配后平衡和有效样本量；
- 识别假设不可由拟合优度证明，需在报告中单列；
- 使用替代规格、负对照、截尾/权重策略或未测量混杂分析评估稳健性。

倾向评分是设计工具而非质量徽章。匹配、分层、加权或调整的选择必须服务于目标估计量。

使用权重时先写目标总体，再写逐组公式、稳定化、归一化、截尾和方差估计。ATE、ATT、ATC 权重不能互换；治疗组权重恒为 1 且治疗组加权风险等于粗风险通常对应 ATT，不得标成 ATE。报告分组权重范围与有效样本量，单个 `common_support=true` 不能替代分布、尾部和有效信息量。敏感性指标也须复用同一效应方向：保护性 RR 的 E-value 需先转换到有害方向并使用最接近零效应的置信区间端点；公式或适用性不确定时不输出该指标。

用 EHR/RWD 估计干预效应时，优先按**目标试验模拟（Target Trial Emulation）框架**显式写出协议：合格标准、干预策略、分配、时间零点（与合格、干预、随访起点对齐以避免 immortal time）、随访、结局与因果对比，再映射到观察性数据的克隆-删失-加权或克隆-加权实现；报告对照 STROBE，常规/EHR 数据另对照 RECORD。

## 生存与时间到事件

开始前冻结：时间原点、事件、竞争事件、删失、左截断、重复事件和最长随访。

- 生存曲线需报告风险集和随访范围；
- 比例风险仅是特定模型假设，不满足时考虑时间交互、分段效应或其他估计目标；
- 不只报告相对效应；按问题补充绝对风险、风险差、限制平均生存时间或指定时点估计；
- 竞争风险下区分病因特异风险与累积发生目标；
- 时间依赖暴露/协变量不得错误地固定为基线值；
- 数据驱动的 cutpoint 必须标为探索性并进行独立验证。

## 诊断准确性

区分索引检验、参考标准与临床用途。检查目标疾病谱、纳入路径、验证偏倚、部分核实、解释盲法和不可判定结果。

报告应包含适当分母下的敏感度、特异度及区间；预测值必须连同患病率/场景解释。阈值若由当前数据优化，不得同时声称为无偏验证性能。多类别、连续或配对检验应使用与设计一致的方法。报告对照 **STARD 2015**（参考标准、连续纳入、2×2 与流程图、缺失与不确定结果）。

## 临床预测模型

预测与因果解释分开。建模前定义预测时点、预测窗、目标人群和部署场景。

- 数据按患者、中心或时间等独立单位拆分，禁止同一对象泄漏到训练和验证；
- 同一患者的多次活检、时间点、图像、细胞或组学样本必须进入同一折；报告拆分单位、分组键以及各折患者数，而非只报样本行数；
- 所有预处理、特征选择、缺失处理和调参仅在训练折内学习；
- 同时评价区分度、校准与临床相关的效用，不只给单一 AUC；
- 样本量与事件量评估应考虑候选参数复杂度，而非固定口号；
- 内部验证用于乐观校正，外部/时间/地理验证用于可迁移性；
- 同一数据集上的留一法、随机切分或已发表 signature 比较均不是独立外部验证，不得以“独立验证”命名；
- 类别不平衡处理不能替代对校准和决策阈值的评价；
- 模型更新、阈值选择和亚组性能需预先界定或标为探索。
- 比较单指标与联合模型时，两者必须在同一批病例上成对计算；若缺失模式不同，先限定共同分析集，再报告各自未配对的补充结果。不能拿不同分母的 AUC 做 DeLong 等配对比较。
- 验证集中因缺失而排除的记录和事件需显式列出，分类表中的 TP、FP、TN、FN 之和必须对应所报验证分母。
- 标准化、插补、编码和阈值均须给出可部署参数或原尺度公式；只给标准化系数而不给开发集均值/标准差不可复现。
- L1/L2 等惩罚模型的经典标准误、Wald P 值和置信区间通常不能直接套用；若需要推断，使用有明确依据的方法或改用与分离风险相匹配的可解释模型，并说明估计对象。
- AUC 差异不显著不等于性能等效，也不能单独证明某变量是“主要驱动”；全对、小样本 AUC=1 或 H-L P>0.05 也不能证明校准、泛化或临床可用性。

回归或机器学习预测模型的报告对照 **TRIPOD+AI（2024）**：数据来源与人群、开发与验证分开、区分度与校准、公平性/亚组、开放科学与可获得性；开发和验证在同一研究时须清晰区隔。
