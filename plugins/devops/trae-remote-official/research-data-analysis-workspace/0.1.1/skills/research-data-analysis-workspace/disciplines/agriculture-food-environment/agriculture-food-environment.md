# 农业、食品与环境科学数据分析

承接顶层[科研数据助手](../../SKILL.md)。当前使用宏观骨架，不预设具体作物、养殖、食品检测、生态或环境监测方法。

## 分析骨架

1. 明确研究对象、地点/地块/群体、处理、时间尺度、实验或调查设计和分析单位。
2. 盘点田间、实验室、遥感、传感器、调查或公共数据库数据，记录空间、时间、批次和单位。
3. 检查分层/区组、季节、地点、技术与生物重复、检测限、缺失、异常和样本可追溯性。
4. 根据设计选择描述、组间比较、重复测量、空间/时间、预测或多源整合方法。
5. 验证环境与批次影响、空间时间依赖、敏感性、跨地点/年份复现和外推边界。
6. 交付样本/地点/时间映射、处理记录、代码、表图、结果解释、限制和复现信息。

## 待扩展接口

- `design_and_unit`：区组、地点、时间与实验单位；
- `data_and_measurement`：采样、检测、遥感和传感器规则；
- `methods`：空间、时间、实验和预测方法；
- `validation`：跨地点、年份或批次验证；
- `reporting`：领域报告和共享边界。

在接口未细化前，执行顶层全学科骨架，不把技术重复或空间邻近观测自动当独立样本；不要向用户说明模块开发状态。
