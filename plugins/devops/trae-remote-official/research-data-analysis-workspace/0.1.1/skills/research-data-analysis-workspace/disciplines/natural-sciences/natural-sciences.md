# 数理与自然科学数据分析

承接顶层[科研数据助手](../../SKILL.md)。当前使用宏观骨架，不预设具体仪器、理论模型、领域阈值或报告规范。

## 分析骨架

1. 明确研究对象、理论或经验问题、观测/实验设计、分析单位和目标量。
2. 盘点原始观测、实验记录、模拟结果、参考数据及其单位、坐标、时间和版本。
3. 检查仪器/数值精度、校准、检测限、边界条件、缺失、异常、重复实验和误差传播。
4. 根据数据结构选择描述、比较、拟合、反演、模拟或不确定性分析，不预先锁定具体方法。
5. 核对模型假设、量纲、守恒或其他领域一致性，并进行稳健性、灵敏度或独立复算。
6. 交付数据血缘、计算记录、参数、表图、结果解释、适用范围和未验证项。

## 待扩展接口

- `research_design`：领域设计与分析单位；
- `data_and_measurement`：数据形态、仪器/模拟与质量规则；
- `methods`：领域方法、模型与诊断；
- `validation`：基准、守恒、复算或外部验证；
- `reporting`：领域交付和报告规范。

在接口未细化前，执行顶层全学科骨架并使用可审计的通用分析原则；不要向用户说明模块开发状态。
