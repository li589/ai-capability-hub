# 社会、行为与经济管理数据分析

承接顶层[科研数据助手](../../SKILL.md)。当前使用宏观骨架，不预设具体调查、实验、计量、金融或管理研究范式。

## 分析骨架

1. 明确研究问题、理论构念、研究设计、观察单位、时间范围、目标人群和估计目标。
2. 盘点调查、实验、行政、交易、平台、文本或面板数据，记录抽样、权重、编码和数据来源。
3. 检查构念测量、量表/指标定义、样本选择、缺失、极端值、重复记录、层级与时间依赖。
4. 根据设计选择描述、测量、比较、回归、面板、因果、预测或文本分析，不按显著性筛选规格。
5. 核对模型假设、聚类/分层、权重、稳健标准误、多重性、替代规格和外部有效性。
6. 交付变量字典、样本流、代码、表图、效应/性能、不确定性、解释边界和复现记录。

## 待扩展接口

- `construct_and_design`：构念、设计、样本和估计目标；
- `data_and_sampling`：抽样、权重、面板与数据来源；
- `methods`：测量、计量、行为、预测或文本方法；
- `validation`：稳健性、外部有效性与可重复性；
- `reporting`：领域表图和报告规范。

在接口未细化前，执行顶层全学科骨架；不得把预测相关性自动改写为政策或因果结论，也不要向用户说明模块开发状态。
