# 市场情报雷达

**Market Intelligence Radar**  
持续看见变化，提前判断影响。

## 简介

面向企业战略、产品、市场和研究人员，持续跟踪竞争对手、产品、市场、技术、政策和生态变化，将分散动态转化为具有优先级的情报、风险与机会信号。

Continuously tracks competitors, products, markets, technologies, policies, and ecosystem developments, turning fragmented updates into prioritized intelligence, risks, opportunities, and actionable implications.

## 适用角色

- 竞争情报、企业战略和产品战略人员
- 市场研究和行业研究人员
- 产品负责人和创业者

## 核心能力

- 配置监测对象、关键词和信息源
- 维护竞争对手档案
- 追踪产品发布、功能、价格和商业化变化
- 追踪融资、组织、合作、市场、技术和政策变化
- 聚类去重、识别新增变化、分级情报重要性
- 分析影响，生成周报、月报和重点预警

## 能力边界

本插件不负责完整行业全景研究、企业整体战略规划、舆情危机处置、私人信息监控、单纯新闻聚合或自动执行商业决策。

## 能力形态与依赖

- Skill：主要能力载体，位于 `skills/market-intelligence-radar/`
- MCP：不涉及
- Connector：不涉及
- 脚本：仅使用 Python 3 标准库，无需安装第三方依赖
- 外部研究、报告与动态 UI 能力由宿主运行时按需提供
