# 采购分析

`analyze-procurement` 是面向采购与供应链决策的 TRAE 插件。插件围绕采购、供应商、原材料价格、库存和供给数据，识别成本变化、供应风险和降本机会。

## 适用角色

- 采购经理
- 采购分析人员
- 供应链负责人
- 品类经理
- 计划人员
- 制造与零售业务人员

## 主要能力

- 整理采购明细并分类费用与原材料
- 计算月均采购单价、最高价和最低价
- 比较供应商报价差异
- 拆解采购数量与价格影响
- 分析原材料价格趋势与成本波动
- 评估供应商集中度和供应稳定性
- 识别异常采购与库存协同问题
- 输出可执行的降本机会清单

## 能力边界

本插件不负责自动选择供应商、代替采购谈判、执行供应商法律与合规审查、建设仓储物流或生产排程系统，也不对未来价格作确定性承诺。所有关键采购结论均应结合企业审批、质量、法务、合规和财务流程复核。

## 使用方式

在 TRAE 中安装插件后，直接描述采购决策问题并提供已有的采购订单、报价单、供应商资料、库存、需求或物流数据。插件会按任务需要选择分析路线并输出决策建议与执行材料。
