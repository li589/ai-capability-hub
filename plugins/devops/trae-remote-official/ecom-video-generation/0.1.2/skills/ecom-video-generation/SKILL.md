# 电商短视频生成专家

## 0. 五条核心原则

| #      | 原则                                                                                 | 展开        |
| ------ | ---------------------------------------------------------------------------------- | --------- |
| **R1** | **一次判定,一路走到底**:开头判定"纯剪辑"还是"纯生成",判定后尽量不切换(生→剪→生 = 主体漂移 + 成本翻倍)                      | §1.2      |
| **R2** | **卖点叙事化**:参数包进骨架 A/B 再输送,单条 15s 聚焦 1-3 个卖点                                         | §3、§4     |
| **R3** | **视听双轨**:① 字幕可选(质感/ASMR/情感片可不用),用则全片风格一套,尽量模型直出;② 音频三层都设计(人声语气·环境音·BGM),别只靠模型默认背景音 | §6、§8     |
| **R4** | **7 秒前回收钩子**:视觉爆点或情绪爆点二选一,过了 7s 完播易崩                                               | §4        |
| **R5** | **文字零错字**:全文不允许出现错别字;品牌名称、产品型号、成分名更要逐字核对                                         | §6.4      |

***

## 1. 工作流总览

```
① 需求解析 → ② 路径判定 → ③ 叙事策略 → ④ 分镜脚本(md) → ⑤ 视频 prompt → ⑥ 交付
产品×人群×目标  剪辑 vs 生成  骨架A/B+品类卖点  逐镜分镜         每段一条prompt   落地+归档
```

### 1.1 需求解析(①)

拆成 3 个槽位,用合理默认补齐,开头标注"默认假设"一行。

| 槽位 | 说明                   | 默认               |
| -- | -------------------- | ---------------- |
| 产品 | 品类、卖点 1-3 条、价格带      | 从上下文/上传图猜;猜不出问一次 |
| 人群 | 性别、年龄、身份、痛点          | 按品类取主力人群         |
| 目标 | 认知(宣传)/兴趣(种草)/转化(带货) | 默认"转化-带货"        |

> **目标决定音画基调**:转化=强节奏卡点、含字幕;种草=生活流、中速;认知=情绪 BGM 主导、可无字幕。详见 §8.0。

### 1.2 路径判定(②)—— R1

判定一次,后续不再讨论。**不确定默认走纯生成**。

| 情况                          | 路径      | 动作            |
| --------------------------- | ------- | ------------- |
| 已有素材,只需重排+字幕+BGM            | 纯剪辑     | ffmpeg/剪映一次剪完 |
| 素材来自不同拍摄源需拼接                | 纯剪辑     | ffmpeg 无缝拼接   |
| 需要 AI 新画面(表演/产品动态/场景/静图动态化) | 纯生成(默认) | 视频模型 + 字幕直出   |

#### 1.2.1 生成路径"一次到位"三条(R2)

1. 单段时长顶格 —— 目标 15s 就 `duration=15`,不拆 3×5s。
2. 一条 prompt 多镜头 —— 7-12 镜写进同一条,用 `Shot 1: … Shot 2: …`。
3. 字幕写进 prompt —— 见 §6.5。
4. 没有明确要求的时候，**默认竖屏**。

#### 1.2.2 模型选择

1. 如果用户自带 API/AK(优先使用用户的):写入 workspace 的 `.env`,Key 不明文回显。
2. 否则，使用内置 `GenerateVideo`(默认兜底)。

### 1.3 时长-分段

- ≤15s → 按 R2 一次到位。
- 16-22s → 先压到 15s,压不下再拆 15 +(X-15)。
- \>22s → 顶格拆(15+15+…),避免均分。段间一致性靠:同一参考图作主体锚点、后段以前段末帧作首帧、美学母体(配色/材质/光比/风格词)照抄。

1. 先定骨架(§4)、再从品类文档选 3-5 个高占比卖点。

4. 表里没有的类目 → 回退近邻类目,并在摘要标注。
5. 合规敏感类目(滋补/防晒/口腔/母婴)→ 先读品类文档"叙事禁区"。

## 3. 分镜脚本(④)

### 3.1 15 秒段落参考指标

| 项     | 参考                                                 |
| ----- | -------------------------------------------------- |
| 镜头数   | 骨架 A:9-12 镜(单镜 1.0-2.5s) / 骨架 B:5-8 镜(单镜 2.0-5.0s) |
| 分镜表字数 | 1500-2000 字                                        |
| 视觉重点  | 每 3 秒 ≥1 个 ★(可截图当封面的画面),15s 内 ★≥5                  |
| 高潮点位  | ≤第 7 秒出现钩子回收/反转/卖点爆点(R4)                           |
| 单镜信息量 | 8 项,见 §3.3 的列                                      |
| 视觉一致性 | 全表锚定同一美学母体(配色/材质/光比),不跳戏                           |

> 字幕规范见 §6 · 真人背景规范见 §7 · 音频规范见 §8。总时长 >15s 时按 §1.3 拆段,每段各自满足上表。

### 3.2 分镜脚本落成 md 文件(只写三段)

分镜建议落成 md(下游剪辑/生成模型的首选消费源,对话上下文易丢)。

- **命名**:`<产品>_分镜_<版本>.md`;长视频每段 `_S01.md`。
- **只写三部分,别塞其他**:
  1. **视频主要目标**:一句话说清"产品 × 人群 × 目标(转化/种草/认知)× 骨架 × 时长",不超过 2-3 行。
  2. **分镜表格**:逐镜表(§3.3),含视听路线(含字幕/无字幕)、音频策略一行。
  3. **视频 prompt**:整段 prompt(§5),多镜头写在同一条 `Shot 1: … Shot 2: …`。

### 3.3 逐镜表格(建议每列每镜填写)

| 列     | 规范                                                              | 示例                                 |
| ----- | --------------------------------------------------------------- | ---------------------------------- |
| 镜号    | S01-01 起                                                        | S01-03                             |
| 时长    | 精确 0.1s                                                         | 1.8s                               |
| 景别与视角 | 景别 + 机位角度                                                       | 微距特写,对准电源键                         |
| 运镜    | 运镜 + 速度 + 方向                                                    | 稳定,焦点落接口内部                         |
| 光影    | 方向 + 色温 + 光比 + 光质                                               | 45°侧逆光,3200K,2:1,柔光                |
| 色彩    | 主色 + 辅色 + 色调                                                    | 银灰+暖金,冷暖对比                         |
| 主体动作  | 具体、单一                                                           | 电源灯呼吸式渐亮                           |
| 道具/环境 | 前中背三层写清;真人镜列 ≥3 个可辨识元素 + 背景动态(见 §7)                             | 前景大理石台+量勺 / 中景达人+罐 / 背景史密斯架,远处有人训练 |
| 音频三层  | ① 人声(有无对白/语气)② 环境音(场景音+音效点)③ BGM 节点;成套配置见 §8                    | (人声)冷冷"就这?"/(环境)街道人流+车鸣/(BGM)钢琴渐入  |
| 屏显字幕  | 可空。含字幕路线按 §6 五类写(文案+时机+样式+动效+音效);无字幕路线留空或只填 slogan               | 【数据】`"15D"`·3.5s·正中·弹入+"叮"         |
| 视觉重点  | ★ = 封面级                                                         | ★                                  |

> 建议全表 ★≥5;音频三层尽量每镜写全;字幕走含字幕路线则覆盖钩子/数据/CTA 三类,走无字幕路线则保持"要么全无、要么全统一"。

## 4. 叙事骨架

### 4.1 骨架 A:产品展示型(测评/利益/ASMR/变装)

快切、平行、卖点罗列。**9-12 镜,单镜 1.0-2.5s**,配含字幕路线。

例如一个15s的片段：

```
镜1 1.5s 钩子   极近景/低角度仰拍   ★  字幕①钩子(痛点/悬念/反常识)
镜3 1.8s 卖点1  微距特写            ★  字幕②数据卖点1
镜5 2.5s 卖点3  低角度侧逆光/缓抬   ★  字幕②卖点3 或 ③背书
镜7 2.0s 高潮   内部微距/捕捉快动作 ★  字幕②核心数据爆点(7 秒高潮镜)
镜8 1.0s 收尾   全景顶部            ★  字幕④CTA(点+利益+紧迫)
—— 15s / 8-12 镜 / ★≥5 / 字幕覆盖①②④
```

### 4.2 骨架 B:剧情叙事型(情感礼品/溯源/反转)

线性、起承转合、情绪弧。**5-8 镜,单镜 2.0-5.0s**。产品作"情绪触发器",不罗列参数。

例如一个15s的片段：

```
镜1 2.5s 起·铺垫  特写/推镜       ★  字幕①悬念(时间/地点/心声)
镜3 3.0s 承·揭示  特写/平摇       ★  字幕③背书(品牌/情感tag)
镜4 3.0s 承·冲击  特写/手持微晃   ★  字幕⑤情绪tag(泪目/颤抖,面部特写非产品)
镜5 2.5s 转·推进  过肩/慢推       ★  两主体互动(戴戒/递物/拥抱)
镜6 1.5s 合·定格  中景/缓拉焦外   ★  字幕④品牌slogan(替代硬CTA)
—— 15s / 5-8 镜 / ★≥5 / 字幕覆盖①③④
```

骨架 B 的取向:情绪爆点镜给面部特写而非产品;7 秒高潮是情绪反转不是视觉爆点;对白+环境音+BGM 情绪节点成对出现;结尾用品牌 slogan/情感 tag 而非"小黄车立减"。


### 4.3 钩子模板

| 场景      | 钩子画面             | 台词/字幕          |
| ------- | ---------------- | -------------- |
| 剧情/情感   | 悬念动作特写(手贴礼盒/举戒指) | "手给我,闭上眼睛"     |
| 变装/试穿   | 极致平凡起手(素颜+沾颜料的手) | 屏显"白色"         |
| 测评      | 疑问前置字幕 + 产品全景    | "这个很火的到底好不好用?" |
| 利益/带货   | 价格锚点 + 产品硬切      | 大字幕"3.9元包邮"    |
| 感官/ASMR | 感官特写 + 撕包装音效     | 无口播,全声音        |
| 溯源/故事   | 场景直入 + 人物出镜      | "刚下火车来看娃"      |

## 5. 视频 prompt 编写(⑤)

### 5.1 七维骨架 + 映射

```
[主体] + [详细动作] + [场景/环境] + [光线/色调] + [镜头运动] + [视觉风格/画质] + [约束条件]
```

| 分镜列     | Prompt 位置          |
| ------- | ------------------ |
| 景别与视角   | \[主体] 镜头参数         |
| 运镜      | \[镜头运动]            |
| 光影 / 色彩 | \[光线/色调]           |
| 主体动作    | \[详细动作]            |
| 道具/环境   | \[场景/环境]\(含 §7 背景动态) |
| 音频三层    | 独立段,按 §8 写         |
| 屏显字幕    | 独立段,按 §6.5 写       |
| 视觉基因    | \[视觉风格/画质] + \[约束条件] |

### 5.2 素材绑定语法

| 目的   | 写法                             |
| ---- | ------------------------------ |
| 主体一致 | `以 <图片1> 为主体,保持产品外观/logo/配色一致` |
| 首帧引导 | `以 <图片1> 作为起始画面`               |
| 风格参考 | `参考 <图片1> 的色调与光影`              |
| 严格编辑 | `严格编辑 <视频1>,只做以下修改:…`          |
| 分段接续 | `以 <视频前段> 末帧作首帧,光线/色调/风格一致`    |

### 5.3 常见返工点

| 反模式                    | 违反    |
| ---------------------- | ----- |
| 抽象堆砌("高级感"不落参数)        | §5.1  |
| 冲突指令(静止+冲刺)/ 一镜 >2 种运动 | §5.3  |
| 把 15s 拆多次 5s 再拼        | R2    |
| 真人镜写"纯色墙/棚拍",背景全静      | §7    |
| 让模型不出字幕再 SRT 烧录        | R3    |
| 不管品类/目标都套同一段 BGM       | §8.0  |

## 6. 屏显字幕规范

> **R3 要点**:① 字幕**可选**(质感片/ASMR/情感片可不用);② 一旦使用,建议全片字体族/主色/位置/动画锁一套;③ 字幕最好由模型直出,尽量不后期烧录。

### 6.0 用不用字幕(先判一次)

判定后写进表头"视听路线",全片保持一致。

- **目标是转化带货 + 投信息流** → 走"含字幕"(70% 静音播放,字幕是主信息通道)。
- **品牌/形象/艺术叙事,或走高级质感/情感/感官** → 走"无字幕或极简字幕(≤2 条)"。
- **拿不准** → 默认不含字幕。

**无字幕/极简的典型场景**:珠宝情感片、女装质感试穿片、生鲜纯纪录溯源、ASMR、家居空间片、高端 3C 品牌片。心智:当画面+表演+音频已承担 70% 信息量,字幕就是污染物。

### 6.1 五类字幕

字幕是独立于口播的第二叙事层。给出不同类型的字幕出现形式,一段中不要求全部出现,在用户需求的基础上适当加上能增加亮点的字幕。

| 类型           | 位置      | 内容                                   |
| ------------ | ------- | ------------------------------------ |
| ① 钩子         | 0-2s    | 痛点问句 / 悬念 / 反常识数据                    |
| ② 数据卖点       | 核心镜 3-7 | 具体数字+单位+品牌,避免"高蛋白"这类模糊词              |
| ③ 信任背书       | 中后段     | 品牌/成分/资质/产地/销量/口碑                    |
| ④ CTA/slogan | 末镜      | 骨架A:指令+利益+紧迫 / 骨架B:品牌 slogan 或情感 tag |
| ⑤ 氛围/口播同步    | 全片      | 口播关键词高亮,不必逐字                         |

### 6.2 风格一致性(字幕"乱"的解药)

字幕多半是"每镜换字体/颜色/位置/动画"。表头一次锁定 5 项、全片复用。**注意:字幕不可以遮挡产品**。

| 锁        | 建议                             |
| -------- | ------------------------------ |
| L1 字体族   | 全片 1 种(骨架 A 可"标题+正文"固定配对)      |
| L2 主色板   | ≤2 色(主色+强调色);质感片建议 1 色         |
| L3 位置    | 每类字幕固定一个位置(钩子上、卖点中、背书下、CTA 下半) |
| L4 动画    | 全片 1 种主动画(或"主+副"两种),见 §6.3     |
| L5 描边/阴影 | 描边粗细/颜色/阴影/底板全片统一              |

### 6.3 动效与音效(解决"出现太呆板")

**动效——入场+停留+出场,三段都设计**:

- **入场**(0.2-0.4s):弹入放大 / 上滑淡入 / 逐字打字 / 模糊转清晰。
- **停留**(1-2s):可加"轻微呼吸缩放"或关键词"跳一下高亮",避免全程死板。
- **出场**(0.2-0.5s):缓淡出 / 下滑消失,避免硬切消失。

风格与情绪匹配:带货快剪用"弹入放大+关键词跳色"(有冲击);质感/情感片用"缓淡入+缓淡出"(柔和)。同一支片入场动画建议只用 1-2 种(呼应 L4)。

**音效——关键字幕配一声,强化记忆**:关键字幕(钩子/数据爆点/CTA)出现时**配一个短音效**,让静音用户也有"节奏感"。音效需要克制(只在核心信息强调)、和 BGM 风格类似(更和谐)。写进 prompt 示例:`镜4 数据字幕弹出瞬间配一声清脆"叮",前 0.1s 背景音量降 6dB 反衬`。质感/情感片除末镜 slogan 外一般不加字幕音效。

### 6.4 文案原则

- **品牌名/型号/成分名零容错(R5)**:写完后逐字回查,若用户给了官方写法则严格照搬(大小写·空格·标点),不确定时主动向用户确认,绝不凭记忆猜测。
- 一屏一句,单句 ≤12 字,超了拆两屏。
- 数字/单位/品牌名用英文引号原样包裹(见 §6.5),让模型别改。
- 避免绝对化/夸大("最好""根治""秒变");功效类(滋补/防晒/口腔/母婴)避免"增肌X斤""美白X度",参考 B7/B9 禁区。
- CTA 带紧迫感(骨架 A):"仅限今日""前100名""最后X件"。
- 出现时机比口播提前半拍,让静音用户先看到。
- 把全片字幕按序读一遍能读懂"钩子→卖点"完整链路。

### 6.5 写进 prompt 的四要素

每条字幕写清 **文案 + 时机 + 位置 + 样式(含动画+音效)**:

```
镜1(0-2s):上1/3 出现 "<钩子≤12字>",粗黑体大字号白底黑边,
  whoosh划入+低频"咚",停留1.5s后缓淡出
镜4(6-8s):正中出现 "<数据卖点≤12字>",数字黄色加粗,
  弹入放大+一声"叮"(前0.1s降6dB),停留2s
镜8(13-15s):下方全屏 "<CTA三要素>",红黄对比闪烁3次+上扬"叮咚"
```

关键 token 保真:英文引号包裹并声明"按引号内文字渲染";超 8 字的品牌名可拆两条;出片后逐帧核对,错字只重生成该段。

## 7. 真实场景锚定(反 AI 空盒子 + 背景动态)

> **何时用**:分镜里有真人出镜(达人/模特/用户实测)时参考。纯产品/微距/ASMR 可标"无真人"跳过。
> **两个目标**:① 背景要"真"(§7.1 反空盒子)· ② 背景要"活"(§7.2 动态层)。

### 7.1 背景要"真":3+1 元素法

AI 达人视频最容易露馅的是背景——不写具体元素,模型就默认给纯色渐变墙,观众 0.5 秒识破。真人镜建议给足 **3 个可辨识元素 + 1 个光源**:

```
[场所类型] + [3 个可命名的道具/家具/纹理] + [1 个光源方向与色温]
```

- 场所具体到房间/场地:`商用健身房` / `复古咖啡馆`,而非"室内"。
- 道具能命名:`史密斯架 + 镜面墙 + 哑铃架`,而非"简洁家具"。
- 光源带方向色温:`上午侧窗光 45° 打入,4000K`,而非"柔和光"。

**建议避免的写法**(会触发空盒子):纯色/渐变背景、简洁/极简背景、无限延伸空间、棚拍空间、单独的"浅景深虚化"(可补成"虚化的书架")。但如果是质感的宣传片,是可以出现这种背景的,需要灵活根据用户意图和合适的场景判断。

### 7.2 背景要"活":动态层(解决"背景太静")

AI 成片常见问题是主体在动、背景像照片一样冻住。建议每个场景挑 **1–2 个背景动态元素**写进 prompt,让画面"呼吸"。四类可选:

| 动态类型 | 举例                          |
| ---- | --------------------------- |
| 人物动态 | 背景虚化人流走动 / 邻桌客人交谈 / 远处训练的人  |
| 自然动态 | 纱帘轻飘 · 树影摇曳 · 风吹发丝衣角 · 水面波光 |
| 光影动态 | 光斑缓移 · 明暗呼吸 · 屏幕微闪 · 烛光跳动   |
| 粒子动态 | 尘埃浮动 · 蒸汽升腾 · 水汽 · 飞絮/花瓣    |

**写法**:动态元素放"低速、局部",成功率高;避免整屏剧烈运动。示例:

```
背景:复古咖啡馆,虚化的邻桌客人轻声交谈(缓慢),窗边纱帘随风微飘,
      午后光斑在木桌上缓慢移动;主体保持清晰,背景动态低速不抢焦
```

> 前景也可加一次"虚焦物体划过"(如路人/蒸汽)制造层次,一支片用 1 次即可。

### 7.3 分品类环境模板

| 品类       | 场所          | 3 个可辨识元素           | 光源        | 可选背景动态        |
| -------- | ----------- | ------------------ | --------- | ------------- |
| 健身/运动    | 商用健身房       | 深蹲架 + 镜面墙 + 哑铃架    | 顶部 LED 冷白 | 远处有人训练、镜面反光晃动 |
| B1 女装    | 家居窗边/咖啡馆/街角 | 落地窗纱帘 + 木地板 + 藤椅画框 | 侧窗光 + 光斑  | 纱帘微飘、树影、发丝随风  |
| B2 男装    | 办公室/街景/洋房   | 显示器 + 玻璃隔断 + 皮沙发   | 顶灯/黄昏斜阳   | 车流虚影、路人穿行     |
| B9 美妆    | 化妆间/梳妆台     | 镜灯珠 + 瓶罐 + 化妆棉     | 环形光 4000K | 镜灯微闪、水汽       |
| B9 母婴/宠物 | 客厅/儿童房/草坪   | 沙发抱枕 + 玩具 + 爬行垫/地毯 | 窗光 + 暖顶灯  | 孩子/宠物走动、窗外树影  |
| B7 食品    | 厨房/餐桌/阳台    | 灶台锅 + 木台餐具 + 窗台绿植  | 窗光 + 暖射灯  | 蒸汽升腾、油花跳动     |
| B3 3C    | 书桌/电视柜/办公桌  | 电脑键盘 + 台灯 + 书本     | 台灯 + 屏幕光  | 屏幕微闪、窗外车流     |

### 7.4 写进 prompt 的三条

1. **正向声明**:`背景是真实的 XX 场景,含 A/B/C 三个具体元素`。
2. **动态声明**:`背景有 X 元素在缓慢运动`(§7.2),避免整屏静止。
3. **反向约束**:约束列写 `避免纯色渐变背景、避免棚拍空盒子`;并保留"生活痕迹"(散落日常物、墙纸接缝、地面反光)增强真实感。

## 8. 音频设计引擎

> **定位**:品类无关的音频方法论——怎么把音频设计得"多变、且能调动购买欲"。
> **对应 R3**:人声语气 · 环境音 · BGM 三层都建议设计,别只靠模型默认背景音。
> **核心心智**:音频"单一"的根因,是没先按商业目标和 query 情绪选风格,默认套了同一段 BGM。音频要随片而变。

### 8.0 先按"商业目标 + query 情绪"选风格

音频风格由两个输入共同决定,别一上来就套 BGM。

**商业目标定"功能骨架"**:

| 目标        | 音频服务于    | 三层权重(起点,可调)                     | 节奏                |
| --------- | -------- | ------------------------------- | ----------------- |
| 转化-带货(默认) | 抓人→证明→催单 | BGM 40 · 人声 40 · 环境 20          | 快,90-130 BPM,音画卡点 |
| 兴趣-种草     | 沉浸→共鸣    | BGM 35 · 人声 35 · 环境 30          | 中,75-100 BPM      |
| 认知-品牌     | 审美→记忆    | BGM 45-50 · 环境 30-40 · 人声 10-20 | 慢,60-85 BPM,情绪弧   |

> 同品类、目标不同,音频就该不同:女装带货快剪用节拍卡点,女装品牌质感片用极简钢琴。

**query 情绪词定"风格皮肤"**:从 query 和产品场景抓 1-2 个情绪/场景词,映射到具体乐器/BPM,别写"轻音乐"这种空词。

> **以下表格仅为示例参考,实际需要根据品类、目标人群、场景氛围灵活设置——乐器组合、BPM 区间都不是硬性规则,可以跨行组合,也可以在示例外自创。**

| query/场景情绪信号 | 风格皮肤(举例)           | BPM     |
| ------------ | ------------------ | ------- |
| 甜/少女/约会/治愈   | 清新流行·木吉他·钟琴        | 90-110  |
| 酷/飒/街头/机能    | trap·电子鼓机·低频 bass  | 100-130 |
| 高级/质感/氛围/极简  | 钢琴独奏·大提琴·氛围 pad    | 60-80   |
| 燃/爽/开箱/真香    | 鼓点 build-up + drop | 110-140 |
| 温情/亲子/礼物/陪伴  | 弦乐·钢琴+弦乐·暖民谣       | 65-90   |
| 食欲/鲜/香/爆汁    | 环境音为主,BGM 极淡或无     | ASMR 逻辑 |
| 科技/参数/性能     | 合成器电子·脉冲音效点        | 115-130 |
| 国风/匠作/溯源     | 古琴·尺八·民乐+现场音       | 60-80   |

> **落地**:分镜表头"音频策略"一行写死结论,如
> `音频策略:目标=转化带货[强钩子+卖点音效点+CTA] · query="夏日椰子水"→清新流行110BPM+开罐ASMR`

### 8.1 三层音频架构(每镜写的字段)

**人声(Voice)——先三选一**:

- **有对白**(达人开口):转化/测评/教程。金句前置,口条自然(§8.3)。
- **纯 OS 心声**:剧情/情感/溯源。内心自语感,低音量慢速。
- **无对白**(靠画面+环境音+BGM):质感/试穿/品牌/ASMR。此时加厚环境音与生理音(§8.3)补信息。

**环境音(Ambient/SFX)——音频"多变"最省力的一层**:换场景就换环境音。每镜写 2-3 个可辨识环境音词;关键音效点单独标镜次+时机+音效名+dB。

```
环境音: 家居窗边 · 风声+纱帘摩擦+远处鸟鸣
音效点(镜3·2.5s): 裙摆"沙沙"加重 3dB
```

**BGM——写清 4 项**:风格(乐器/参考+BPM) + 情绪 + 入点/淡出时点 + 关键情绪节点。

```
BGM: 清新流行(110BPM,木吉他+钟琴,无歌词) · 轻快悦己 · 0s入3s到-16dB · 镜4副歌与卖点卡点 · 镜8 CTA收
```

三条取向:① 风格匹配目标——带货片就该用强节拍流行/卡点,不算掉价;质感/情感片才避开套路 BGM。② BGM 至少 1 次动态起伏(淡入/副歌/停顿/淡出),全程一个音量=听觉疲劳。③ 带中文歌词的曲子带货可用(助记),剧情/情感片避免(抢戏)。

### 8.2 五个"调动购买欲"的情绪杠杆

写全三层是基础,下面五个让人"有观看欲、购买欲"。按片子性质挑用,不必全上。

- **① 开场音频钩子(前 3 秒)**:音效炸点(开罐"嘶"/撕包装)、或口播金句前置(第一句就是痛点/价格锚)、或 BGM 冷启爆点(静音 0.3s→一个鼓点砸下)。
- **② 音画卡点**:镜切、卖点弹出、产品亮相踩在鼓点上。转化快剪尤其依赖。
- **③ 静音留白→爆点炸开**:爆点前骤停 0.3-0.8s(全断),再让爆点音炸出,张力翻倍。
- **④ 声音记忆点**:埋一个可复用听觉锚——品牌音效/口播金句/被放大的特色音(爆汁/拉丝/喷雾"啵")。
- **⑤ 情绪音量曲线**:全片音量有呼吸。注意方向——情感/私语场景高潮句可降 3dB 做私语感;带货片高潮应加重上扬,别降。

### 8.3 自然口条(消除 AI 机器味)

AI 人声默认播音腔:每字停顿等长、无换气、尾字上扬。要"像人",把下面写进 prompt。

| 维度 | 播音腔(避免) | 自然口条                |
| -- | ------- | ------------------- |
| 换气 | 一句不换气   | 每 8-12 字一次自然换气      |
| 停顿 | 每字等长    | 关键词前 0.2-0.3s 微停    |
| 尾字 | 上扬有力    | 自然下沉、气音收尾           |
| 迟疑 | 从头顺到尾   | 情感片可有 1-2 次"呃…"思考停顿 |
| 音量 | 整段均匀    | 见 §8.2⑤ 情绪音量曲线      |

示例:`女声25-30,达人语气;每句1次换气,"25g"前0.3s微停;尾字气音收尾;比BGM高6dB;避免播音腔`。

**无对白也写"生理音"**:质感/试穿片走无对白时,保留呼吸/衣物摩擦/脚步——"人真实存在"的最强信号。

```
人声: 无对白 · 镜2转身呼气(-24dB)/镜4微笑吸气(-27dB)/镜5衣物摩擦(-22dB)
```

### 8.4 静音法则(反过度设计)

音频不是越满越好。常用静音位:情感反转前全断 0.5-1s;数据卖点字幕前 BGM 降 6dB+"叮";质感片末镜 slogan 时 BGM 淡出只留环境音;ASMR 片可全程无 BGM 只留环境特写。
