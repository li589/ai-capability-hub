# B8 珠宝奢品医药 · 品类卖点与叙事参考

> 覆盖 5 个类目:黄金彩宝银饰 · 翡翠玉石 · 木作文玩收藏 · 时尚饰品 · 茶具

## 板块共性

- **强属性**: **高客单 + 悦己/文化双价值 + 强信任链需求**
- **首选叙事**: **剧情/情感反转**(情感礼品) / **溯源故事**(工艺传承)
- **叙事禁区**:
  - 别只讲克重和折扣(容易掉价)
  - 别做塑料合成感(高客单必须真实工艺 + 材质细节)
- **叙事推荐**: 设计与工艺 + 消费场景 + 品牌/文化价值

---

## 逐类目卡片

### 黄金彩宝银饰

- **品类定性**: **"悦己+文化"双重价值叠加**的高客单复合型品类
- **Top 卖点**:
  - 设计与工艺 **22.7%** ← 首选核心镜
  - 消费场景
  - 品牌价值
  - 工艺传承
- **AI 建议**(4 条):
  - 优化消费场景(生日/求婚/节庆)
  - 强化品牌价值
  - 强化工艺传承
  - 用户声音 AI 挖掘 + 抖音直接拍摄
- **叙事骨架**: **骨架 B 慢切 6–8 镜**;剧情/情感反转("礼盒→揭示→泪目→戴上")
- **7 秒高潮点**: 打开礼盒的**第一帧钻戒/项链的强光反射**+ 收礼人面部表情特写
- **参考实证**: 你上传的 27 秒求婚剧情片就是本类目的标准打法

### 翡翠玉石

- **品类定性**: **文化 + 信任**双驱动
- **Top 卖点**:
  - 设计与工艺 **25.0%**
  - 文化深度
  - 信任链
- **AI 建议**:
  - **强化文化深度**(玉文化/雕工典故)
  - **完善信任链**(证书/开料现场/大师背书)
- **叙事骨架**: 骨架 B + 溯源故事(开料/雕琢现场)
- **叙事禁区**: 严禁夸大"升值""投资"表达

### 木作文玩收藏

- **品类定性**: **材质叙事**主导
- **Top 卖点**:
  - 材质特性 **25.4%**
  - 性价比 **12.7%**
  - 工艺与制作技术 **12.7%**
- **AI 建议**: 围绕材质特性、工艺技术、性价比展开;抖音直播带货 + 用户端图文 AI 创作
- **叙事骨架**: 骨架 B + 溯源故事(木料切面/包浆演变/雕刻过程)
- **7 秒高潮点**: 木材切面的**第一次抛光反光**

### 时尚饰品

- **品类定性**: **"视觉搭配 + 情绪悦己 + 个性表达"**为核心的消费逻辑
- **Top 卖点**:
  - 设计与特种造型
  - 佩戴体验与实用性
  - 情绪悦己
- **AI 建议**: 场景化 + 内容化;普通素人 + 手作小众 + 不同风格并存
- **叙事骨架**: 骨架 A 快切(可以走变装/试穿:素人→精致款);单价低时用利益前置
- **区别于黄金**: 时尚饰品走**快节奏时尚**,黄金彩宝走**慢节奏情感**,不要混用打法

### 茶具

- **品类定性**: **材质 + 仪式感**
- **Top 卖点**:
  - 材质与工艺
  - 设计美学
  - 文化价值
  - 使用体验
  - 品牌与仪式感
- **AI 建议**: 提升内容质量 + 优化视频呈现 + 提升用户互动
- **叙事骨架**: 骨架 B 慢切 + 溯源故事(泡茶仪式感/袅袅茶烟/木案陈设)
- **7 秒高潮点**: 茶汤入杯的**第一缕蒸汽升腾**

## 使用示例(黄金彩宝银饰实战)

某品牌钻戒品牌片 15 秒,按本表:

| 镜号 | 内容 | 叙事场景 |
|---|---|---|
| 镜1 | 悬念:男主手贴礼盒(暧昧不明) | 起 |
| 镜2 | 女主困惑近景(疑问式) | 起 |
| 镜3 | **礼盒打开+钻戒强光反射(设计与工艺)** ★ | 承 |
| 镜4 | 女主泪目呼吸颤抖特写 ★ | 承 |
| 镜5 | 戴戒过肩镜头(消费场景) | 转 |
| 镜6 | 相视大笑缓拉焦外 + 品牌 slogan | 合 |

> **说明**: 高客单珠宝**不要**放"点小黄车立减",收尾用品牌 slogan 或情感 tag(如"最好的,留给最值得的")。
