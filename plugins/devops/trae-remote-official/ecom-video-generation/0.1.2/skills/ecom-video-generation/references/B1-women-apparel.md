# B1 女装 · 品类卖点与叙事参考

> 覆盖 6 个类目:短袖T恤/Polo · 休闲裤 · 居家服/睡衣 · 连衣裙 · 衬衫 · 背心/吊带
> 数据来自抖音电商 45 类目 AI 视频案例卡实证。使用时:先从下表选定类目,再把 **Top 卖点** 直接填进 §4 分镜表的"主体动作+道具"列,把 **叙事要求** 作为 §4.2 表头元数据的"视觉基因锚定"依据。

## 板块共性(所有女装通用)

- **目标人群**: 女性悦己消费,决策以"自我感受"为标准
- **共性卖点结构**: 基础细节 / 面料材质 / 上身修饰 / 穿搭场景 / 版型工艺
- **首选叙事**: **变装/试穿**(强穿搭反差)为主, 测评(材质证明)为辅
- **叙事禁区**: 避免堆砌属性参数,少用商品硬广口播
- **叙事推荐**: 场景化(通勤/居家/约会)+ 风格化(甜酷/温柔/复古)+ 生活化(真实穿搭 Vlog)

## 逐类目卡片

### 女装-短袖 T 恤/Polo

- **品类定性**: 国内服装市场受众覆盖面最广的**基础品类**
- **Top 卖点(占比)**:
  - 基础细节 **32.9%** ← 首选核心镜
  - 面料材质 **24.1%**
  - 上身修饰 **16.5%**
  - 穿搭场景 **15.2%**
  - 版型工艺 **8.9%**
  - 推荐率 / 实用功效 各 3.5%
- **AI 结合建议**:
  - 精准选品(用 AI 拉品类爆款趋势)
  - 爆款潜力款打造(参考头部素材复用)
  - 差异化卖点挖掘(基础款要在"细节+场景"上做微创新)
- **叙事骨架**(默认): 骨架 A 快切 9–12 镜,镜 3 打细节微距→镜 4–5 材质证明→镜 6–7 上身效果

### 女装-休闲裤

- **品类定性**: 场景多元、风格切换频繁
- **Top 卖点**: 属性细节 **29.8%** / 面料材质 / 松紧工艺 / 穿着与搭配 / 版型设计
- **AI 结合建议**: 场景化 + 风格化 + 生活化,3 个方向叠加
- **叙事骨架**: 骨架 A;可用变装/试穿做"一裤三穿"卡点

### 女装-居家服/睡衣

- **品类定性**: 区别于其他服装品类——**以"自我感受"为决策标准**
- **Top 卖点**: 质感细节 **28.2%** / 材质 **19.7%** / 舒适度 / 场景 / 设计
- **AI 结合建议**: **在使用场景中配合人物口播**(不是纯产品展示)
- **叙事骨架**: 骨架 B 慢切 6–8 镜(生活流感);Vlog 感强于卖点罗列

### 女装-连衣裙

- **品类定性**: 高情绪价值、强场景绑定
- **Top 卖点**: 版型细节 **35.7%** ← 首选核心镜 / 面料 / 上身效果 / 场景 / 风格
- **AI 结合建议**: **拍摄场景要与连衣裙风格强绑定**(度假裙-海边 / 通勤裙-写字楼 / 约会裙-咖啡馆)
- **叙事骨架**: 骨架 A,镜 3 版型俯拍→镜 4 转身 360°→镜 5 场景漫步

### 女装-衬衫

- **品类定性**: **商务与休闲双兼容**,正式与舒适双平衡
- **Top 卖点**: 质感细节 **27.27%** / 面料 **19.7%** / 版型 / 场景 / 搭配
- **AI 结合建议**: 主播口播展示 + 卡点素材
- **叙事骨架**: 骨架 A + 部分卡点变装(通勤衬衫 vs 休闲衬衫双场景)

### 女装-背心/吊带

- **品类定性**: 正在完成**从基础款到可外穿的结构性升级**
- **强调关键词**: 可搭配、可内搭、可外穿、可通勤、可居家
- **Top 卖点**: 属性功能 **25.49%** / 上身效果 **21.57%** / 材质 / 搭配 / 版型
- **AI 结合建议**: 人物剧情 + 更多场景 + 多风格穿搭
- **叙事骨架**: 骨架 A 快切多场景卡点(1 件吊带的 4 种穿法)

## 使用示例(填法演示)

假设用户要拍"某品牌纯棉短袖 T 恤",按本表:

| 镜号 | 卖点填充(直接抄本表) | 叙事场景 |
|---|---|---|
| 镜3 | **基础细节**(领口/袖口/下摆微距) | 变装-前置 |
| 镜4 | **面料材质**(手指搓面料+纤维特写) | 测评 |
| 镜5 | **上身修饰**(30° 侧身+腰线) | 变装/试穿 |
| 镜6 | **穿搭场景**(通勤/咖啡馆) | 变装/试穿 |
| 镜7 | **版型工艺**(拉伸回弹测试) | 测评-高潮 |

> **注意**: 单条 15s 视频只输送 **1–3 个卖点**。占比最高的两条(基础细节 + 面料材质)优先放核心镜(镜 3–7),其他卖点做字幕或副线。
