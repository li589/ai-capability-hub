# B4 家居家装 · 品类卖点与叙事参考

> 覆盖 5 个类目:家具(沙发/床垫/餐桌)· 家纺(四件套/被芯/枕头)· 灯具照明 · 家装建材(瓷砖/地板/五金)· 家居软装(窗帘/地毯/挂画)
> 使用时:先从下表选定类目,再把 **Top 卖点** 直接填进 §4 分镜表的"主体动作+道具"列,把 **叙事要求** 作为 §4.2 表头元数据的"视觉基因锚定"依据。

## 板块共性(所有家居家装通用)

- **强属性**: **中高客单 + 场景强绑定 + 悦己+改善家庭生活**
- **共性卖点结构**: 材质工艺 / 使用体验 / 场景搭配 / 空间效果 / 售后安装
- **首选叙事**: **场景改造**(前后对比空间感)/ **测评**(材质工艺细节)/ **溯源**(工厂/工艺传承)
- **叙事禁区**:
  - 别做"虚假样板间"(过度装修观众识破)
  - 别只讲价格(掉价,家居用户看重品质)
  - 别忽视安装/售后(高客单类必须给信任背书)
- **叙事推荐**: 真实户型 + 生活痕迹 + 材质微距 + 前后对比

## 逐类目卡片

### 家居-家具(沙发/床垫/餐桌)

- **品类定性**: **高客单 + 长决策周期 + 强空间感**
- **Top 卖点**:
  - 材质工艺(实木/皮质/乳胶) ← 首选核心镜
  - 舒适度/人体工学
  - 尺寸空间适配
  - 造型/颜值
- **AI 结合建议**:
  - 材质微距(纹理/皮质纹路/木纹)
  - 使用场景生活流(全家坐沙发看电视 / 一家人围坐餐桌)
  - **避免"完美样板间"**(生活痕迹是真实感来源:抱枕微乱 / 遥控器 / 水杯)
- **叙事骨架**: 骨架 B 慢切 5–8 镜,镜 1–3 生活场景,镜 4–6 材质细节
- **7 秒高潮点**: 材质微距特写(实木纹理 / 皮质光泽)+ 使用瞬间(一屁股坐下+回弹)

### 家居-家纺(四件套/被芯/枕头)

- **品类定性**: **中客单 + 悦己+触感驱动**
- **Top 卖点**:
  - 材质(纯棉/天丝/真丝) ← 首选核心镜
  - 触感/亲肤
  - 花色设计
  - 工艺(支数/密度/走线)
- **AI 结合建议**:
  - ASMR 感官(手抚过面料 / 抖开床单)
  - 微距材质(纤维/绣线/织密度)
  - 睡眠场景(入睡瞬间/晨起阳光)
- **叙事骨架**: 骨架 A + ASMR;镜 3 抖开床单慢镜头,镜 5 手抚触感,镜 7 铺床成品
- **7 秒高潮点**: 抖床单的慢动作展开 + 光线穿透纤维的透光感

### 家居-灯具照明

- **品类定性**: **中客单 + 氛围驱动 + 强场景绑定**
- **Top 卖点**:
  - 光效(色温/亮度/无频闪) ← 首选核心镜
  - 造型设计
  - 智能功能(APP/调光/定时)
  - 安装便捷
- **AI 结合建议**:
  - 光效可视化(暗环境 → 灯亮 → 空间氛围)
  - 前后对比(冷白光 vs 暖黄光,同一空间氛围反差)
  - 场景切换(阅读/影音/入睡三种模式)
- **叙事骨架**: 骨架 A + 场景切换;镜 1 黑暗,镜 2 一开灯瞬间空间点亮
- **7 秒高潮点**: 一按开关空间从暗到亮的**光效爆点**

### 家居-家装建材(瓷砖/地板/五金)

- **品类定性**: **高客单 + 强决策 + 长周期**——观众多为装修中的家庭
- **Top 卖点**:
  - 材质工艺(耐磨/耐脏/防滑)
  - 花色纹理
  - 环保等级(E0/E1)
  - 安装/售后
- **AI 结合建议**:
  - **极端测试**(倒酱油/划刀痕/泼水看清洁难度)
  - 大面积铺装效果(整屋铺完的空间感)
  - 环保证书/资质背书
- **叙事骨架**: 骨架 A 测评型;镜 3–5 极端测试,镜 6 整屋铺装,镜 7 清洁前后对比
- **7 秒高潮点**: 极端测试的"通过瞬间"(污渍一抹就掉 / 刀划无痕)
- **叙事禁区**: 严禁夸大"永不磨损""绝对防水",触发平台合规

### 家居-家居软装(窗帘/地毯/挂画)

- **品类定性**: **中低客单 + 悦己+搭配驱动 + 强晒物属性**
- **Top 卖点**:
  - 造型颜值 ← 首选核心镜
  - 材质触感
  - 搭配百搭度
  - 场景氛围
- **AI 结合建议**:
  - **场景改造前后对比**(空房 → 加软装 → 完成)
  - 多风格搭配(一件软装配 3 种风格)
  - 生活场景植入(不做纯产品展示)
- **叙事骨架**: 骨架 A + 场景改造;镜 1 空房或旧场景,镜 3–6 添加软装过程,镜 7 完成对比
- **7 秒高潮点**: 完成态空间的第一帧(窗帘垂落 / 地毯铺开 / 挂画上墙)

## 使用示例(填法演示)

假设用户要拍"某品牌乳胶枕头 15s 短视频",按本表:

| 镜号 | 卖点填充(直接抄本表) | 叙事场景 |
|---|---|---|
| 镜1 | 【钩子】颈椎不适清晨僵硬痛点 | 痛点前置 |
| 镜3 | **材质**(手指按压乳胶回弹微距) | ASMR-测评 |
| 镜5 | **触感**(手抚过枕面) | ASMR |
| 镜6 | **人体工学**(侧睡/仰睡姿势模拟) | 场景 |
| 镜7 | **睡眠场景**(晨起阳光+舒展) ★ 高潮 | 生活流 |
| 镜8 | 【CTA】价格+限时字幕 | 收尾 |

> **注意**: 家居家装类**真人出镜时严禁纯色墙背景**(§4.11 反 AI 空盒子),必须给真实户型:客厅/卧室/餐厅+具体家具道具+窗光。
