# B2 时尚综合 · 品类卖点与叙事参考

> 覆盖 18 个类目:男装(T恤/休闲裤/牛仔裤/衬衫/短裤)·日用百货(居家饰品/收纳工具/锅具/家务工具/厨房小工具/日常护理)·女鞋 / 男鞋 · 时尚箱包 · 眼镜 · 内衣裤袜(文胸/女士内裤/袜子)

## 板块共性

- **两条主线并存**: 男装/女鞋走"场景搭配+性价比",日用百货走"精准功能+生活美学"
- **首选叙事**: 变装/试穿(服饰鞋履) / 测评(日用工具) / 利益/带货(白牌快消)
- **叙事禁区**: 别只堆参数;男装尤其忌"AI 味"过重(生硬机器口播)

## 男装类(5 类目)

### 男装-T 恤/Polo 衫

- **品类定性**: 刚需属性突出、人群覆盖广的**男装基础品类**
- **Top 卖点**: 版型细节 **23.9%** / 面料 / 场景 / 品牌 / 上身
- **AI 结合建议**(4 个方向,重要):
  - 内容结构(节奏+镜头)
  - 内容呈现(素材+运镜)
  - **内容情感**(减少 AI 感,加入人物表达)
  - 内容场景(通勤/健身/居家)
- **叙事骨架**: 骨架 A;必须搭配真人口播避免"塑料感"

### 男装-休闲裤

- **Top 卖点**: 面料材质 / 松紧工艺 / 穿着与搭配 / 版型细节
- **AI 建议**: **多视角讲料**(纤维微距 + 手感演示)+ 注重橱窗场景
- **叙事骨架**: 骨架 A,镜 3 面料微距+手指搓拉

### 男装-牛仔裤

- **Top 卖点**: 面料设计 / 工艺设计 / 品质 / 服务
- **AI 建议**: 内容场景优化(工装/机车/复古)+ AI 素材优化(避免同质化)
- **叙事骨架**: 骨架 A;可用溯源故事讲"洗水工艺"

### 男装-衬衫

- **品类定性**: **商务与休闲场景双兼容,正式与舒适双平衡**
- **Top 卖点**: 面料材质 **21.59%** / 上身效果 / 版型 / 场景 / 工艺
- **AI 建议**: 强调**面料柔软亲肤**、减少属性堆砌
- **叙事骨架**: 骨架 A,前半场景切换后半材质微距

### 男装-短裤

- **品类定性**: **功能与设计双驱动**的基础品类
- **Top 卖点**: 属性细节 **26.76%** / 面料 **19.72%** / 实用功能 **14.08%** / 版型 **11.27%**
- **叙事骨架**: 骨架 A;运动/居家/沙滩多场景快切

## 日用百货类(6 类目)

### 日用百货-居家饰品

- **Top 卖点**: 实用功能 **22.81%** / 功能与美观 **19.3%** / 文化与品牌 **14.03%** / 设计感 **7.62%**
- **AI 建议**: **场景体验升级/增强/丰富**(空间氛围搭建)
- **叙事骨架**: 骨架 B 慢切,展示"物+空间+光线"的三体关系

### 日用百货-收纳整理工具

- **Top 卖点**: 功能实测 / 设计风格 / 工艺做工 / 属性调节
- **AI 建议**: **避免过度依赖"装"**(避免虚假摆拍),要有实测过程
- **叙事骨架**: 骨架 A,镜 5-6 必须有"塞满-合上"的效果对比

### 日用百货-锅具/刀具/砧板

- **品类定性**: **厨房刚需品类**
- **Top 卖点**: 锅具功能 **21.28%** / 材质 / 工艺 / 场景
- **AI 建议**: **创意制作过程**(用户声音+创意+制作三段式)
- **叙事骨架**: 骨架 A + ASMR 感官(食物入锅"呲"声)

### 日用百货-家务工具

- **品类定性**: **从"纯功能类"向"生活美学品"升级**
- **Top 卖点**: 实用功能 **30.49%** / 高性价比 **15.85%** / 生活美学
- **AI 建议**: 生活美学升级(工具进入客厅场景)
- **叙事骨架**: 骨架 A,镜 7 高潮=前后清洁对比

### 日用百货-厨房小工具

- **Top 卖点**: 精确定位功能与效果 **27.27%** / 内容创作场景
- **AI 建议**: **用户声音 AI 挖掘 + AI 结合内容创作**
- **叙事骨架**: 骨架 A;必须有"痛点-工具-解决"三段可视化

### 日用百货-日常护理

- **Top 卖点**: 产品效果 / 材质面料 / 使用体验 / 设计工艺 / 品质保障
- **AI 建议**: 视频内容生产可利用 AI,但保留真人使用镜头
- **叙事骨架**: 骨架 A + 部分骨架 B(生活流)

## 鞋类(2 类目)

### 女鞋

- **品类定性**: **悦己消费 + 场景细分**,内容驱动
- **Top 卖点**: 舒适度 / 时尚感 / 耐用性 / 场景组合 / 标签组合
- **AI 建议**: **标签组合 + 场景组合**(通勤+甜辣 / 度假+法式 组合出片)
- **叙事骨架**: 骨架 A,可用变装/试穿做"一双鞋 N 种搭配"

### 男鞋

- **品类定性**: **注重舒适化 + 性价比功能属性突出**
- **Top 卖点**: 材质与透气性 **20.4%** / 舒适度 / 性价比 / 实用属性
- **AI 建议**: 强化实用属性 + 强化性价比 + 关注标签组合
- **叙事骨架**: 骨架 A + 测评(踩水/挤压/透气烟雾)

## 时尚箱包 / 眼镜(2 类目)

### 时尚箱包-单肩包/斜挎包

- **Top 卖点**: 工装细节 **34%** / 花纹风格 **32%** / 面料材质 **22%** / 优惠 **12%**
- **AI 建议**: 结合**多场景**(旅行/通勤/骑行/city walk)+ 多维度呈现
- **叙事骨架**: 骨架 A,快切多场景

### 眼镜-成品太阳镜

- **品类定性**: **区别于近视眼镜,时尚搭配属性**
- **Top 卖点**: 设计 **27.78%** / 材质 **23.61%** / 明星同款
- **AI 建议**: 时尚模特展示 + 户外光影
- **叙事骨架**: 骨架 A + 变装/试穿(戴上前后气场对比)

## 内衣裤袜(3 类目)

### 内衣-文胸

- **品类定性**: **舒适化升级**
- **Top 卖点**: 舒适透气 / 无钢圈 / 情感感知 / 复购驱动
- **AI 建议**: **强化情感感知 + 构建复购驱动内容**(避免露骨)
- **叙事骨架**: 骨架 B 慢切,人物剧情+材质微距

### 内衣-女士内裤

- **品类定性**: **贴身刚需**
- **Top 卖点**: 健康保暖 **16.67%** / 视觉化场景 / 素材质量
- **AI 建议**: 视觉化(产品+场景结合)+ 素材质量优先
- **叙事骨架**: 骨架 B,材质微距+情境氛围,忌硬广

### 内衣-袜子

- **品类定性**: **功能+礼盒**
- **Top 卖点**: 功能性 / 材质 / 舒适度 / 性价比
- **AI 建议**: **功能达升级 + 强化性价比表达**,礼盒场景
- **叙事骨架**: 骨架 A + 利益前置(礼盒 X 元包邮)
