# B3 3C 数码家电 · 品类卖点与叙事参考

> 覆盖 6 个类目:手机 / 平板 / 笔记本 · 智能穿戴(手表/耳机)· 摄影摄像 · 家用大电(冰箱/洗衣机/空调)· 厨房小电(空气炸锅/破壁机/咖啡机)· 生活电器(扫地机/吸尘器/电吹风)
> 使用时:先从下表选定类目,再把 **Top 卖点** 直接填进 §4 分镜表的"主体动作+道具"列,把 **叙事要求** 作为 §4.2 表头元数据的"视觉基因锚定"依据。

## 板块共性(所有 3C/家电通用)

- **强属性**: **高客单 + 强参数决策 + 长决策周期**——用户看视频后不会立即下单,更多是加购+比价+看测评
- **共性卖点结构**: 核心性能参数 / 使用体验 / 场景适配 / 外观工艺 / 售后服务
- **首选叙事**: **测评/对比**(参数证明)为主,**场景生活流**(使用体验)为辅
- **叙事禁区**:
  - 别做"魔幻炫技"过度合成画面(3C 用户对 AI 味极敏感)
  - 别夸大参数("续航 30 天""吸力最强"等触发平台合规)
  - 别做"参数流水账"(单条 15s 只推 1–2 个核心参数)
- **叙事推荐**: 参数可视化(用视觉动作代替口播念参数)+ 前后对比 + 场景痛点解决

## 逐类目卡片

### 3C-手机/平板/笔记本

- **品类定性**: 高客单 + 强性能对比 + 换机周期长
- **Top 卖点**:
  - 核心性能(芯片/内存/屏幕/续航) ← 首选核心镜
  - 影像/拍摄能力(手机专属)
  - 外观工艺(边框/重量/手感)
  - 使用场景(办公/游戏/创作)
- **AI 结合建议**:
  - 参数视觉化(不念参数,给"1 秒开 20 个 App"的动作)
  - 竞品对比要合规(不点名,用"友商 A"或"上一代")
  - 影像样张要真实(AI 生成的样张一眼假,建议贴真机拍)
- **叙事骨架**: 骨架 A 快切 9–12 镜,镜 3–5 参数视觉化,镜 6–7 场景应用高潮
- **7 秒高潮点**: 性能爆点视觉化(游戏帧率 / 剪辑导出速度 / 电量剩余%)

### 3C-智能穿戴(手表/耳机)

- **品类定性**: 中低客单 + 冲动决策 + 强搭配属性
- **Top 卖点**:
  - 佩戴舒适度 / 外观颜值
  - 核心功能(健康监测 / 降噪 / 通话)
  - 续航能力
  - 场景匹配(运动/通勤/睡眠)
- **AI 结合建议**: 场景化生活流 + 佩戴细节微距 + 情侣/家庭双人镜
- **叙事骨架**: 骨架 A + 变装/换搭思路(一天多场景切换手表/耳机)
- **7 秒高潮点**: 佩戴瞬间特写 + 屏幕点亮/降噪开启的视听爆点

### 3C-摄影摄像

- **品类定性**: 高客单 + 强专业属性 + 决策慎重
- **Top 卖点**:
  - 画质/成像能力 ← 首选核心镜
  - 便携性 / 稳定性
  - 视频规格(4K/60P/log)
  - 使用场景(vlog/婚礼/运动)
- **AI 结合建议**: 真实样张为王,禁止 AI 合成"假样片";可用 AI 做"操作教程"和"参数对比"
- **叙事骨架**: 骨架 A 测评型,前 3s 出样张,后 12s 拆参数
- **7 秒高潮点**: 样张前后对比(手机 vs 相机 / 关防抖 vs 开防抖)

### 家电-家用大电(冰箱/洗衣机/空调)

- **品类定性**: **高客单 + 强场景绑定 + 家庭决策**——决策人往往是家庭中的女性
- **Top 卖点**:
  - 容量/尺寸 / 空间适配 ← 首选核心镜
  - 核心黑科技(变频/除菌/风冷)
  - 使用便捷(APP 联动/一键洗涤)
  - 静音/节能
- **AI 结合建议**:
  - 场景痛点前置(装不下 / 洗不干净 / 电费贵)
  - 参数可视化(冰箱塞满食物 / 洗净度前后对比 / 电表数字)
  - 强化"信任链"(能效等级/权威认证)
- **叙事骨架**: 骨架 A + 家庭生活场景;镜 3–5 场景痛点,镜 6–8 解决方案
- **7 秒高潮点**: 前后对比(装满冰箱 / 白衬衫从黄到白 / 电费单)

### 家电-厨房小电(空气炸锅/破壁机/咖啡机)

- **品类定性**: **中客单 + 悦己+晒物属性 + 冲动决策**
- **Top 卖点**:
  - 使用效果(食物成品颜值)
  - 便捷/操作简单
  - 清洁便捷
  - 颜值/摆家造型
- **AI 结合建议**: **ASMR 感官叙事**(食物制作过程)+ 前后对比(生食 vs 成品)
- **叙事骨架**: 骨架 A + ASMR 感官(切食材/放入/成品出锅)
- **7 秒高潮点**: 成品出锅的第一帧(拉丝/爆汁/滴油)+ 音效
- **叙事禁区**: 别做"魔法瞬间"合成(生食秒变熟食观众一眼识破)

### 家电-生活电器(扫地机/吸尘器/电吹风)

- **品类定性**: **中客单 + 解决痛点驱动**
- **Top 卖点**:
  - 清洁效果(前后对比) ← 首选核心镜
  - 吸力/风力参数
  - 便捷性(重量/续航/自动)
  - 静音
- **AI 结合建议**: **前后对比 + 极端场景挑战**(倒一堆面粉/头发看能不能吸干净)
- **叙事骨架**: 骨架 A 快切,3s 出脏乱现场,4–7s 清洁过程,8s+ 洁净对比
- **7 秒高潮点**: 清洁完成的洁净地面/头发状态特写

## 使用示例(填法演示)

假设用户要拍"某品牌无线吸尘器 15s 短视频",按本表:

| 镜号 | 卖点填充(直接抄本表) | 叙事场景 |
|---|---|---|
| 镜1 | 【钩子】家里角落堆着头发+灰尘 | 痛点前置 |
| 镜3 | **清洁效果**(吸头贴地缝,头发瞬间吸走特写) | 测评-微距 |
| 镜5 | **吸力参数**(吸起一枚硬币视觉证明) | 参数视觉化 |
| 镜6 | **便捷性**(单手提起+挂墙充电) | 场景生活流 |
| 镜7 | **前后对比**(脏乱地板 vs 洁净地板) ★ 高潮 | 测评-高潮 |
| 镜8 | 【CTA】价格+限时字幕 | 收尾 |

> **注意**: 3C/家电类**单条 15s 视频最多推 2 个卖点**(比服装/食品更少),因为参数需要视觉化时间。3 个及以上卖点强制拆段。
