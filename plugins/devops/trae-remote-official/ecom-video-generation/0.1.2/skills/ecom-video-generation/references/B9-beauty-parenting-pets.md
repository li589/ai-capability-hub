# B9 美护亲子萌宠 · 品类卖点与叙事参考

> 覆盖 12 个类目:童鞋 · 面部洗护 · 防晒 · 面部彩妆 · 唇部彩妆 · 玩具 · 生活用纸 · 衣物清洁 · 家庭环境清洁 · 宠物生活 · 染发烫发洗护 · 口腔护理

## 板块共性

- **强属性**: 效果可视化 + 健康意识觉醒 + 高复购
- **首选叙事**: **测评**(效果对比) / **变装/试穿**(彩妆前后)
- **叙事禁区**:
  - 医疗类严禁夸大功效
  - 童品严禁引发焦虑话术
  - 效果类必须"真实感 > 精修感"
- **叙事推荐**: 前后对比 + 敏感人群适配 + "即拍即用"实拍感

## 逐类目卡片

### 童鞋

- **品类定性**: **健康 + 成长**
- **Top 卖点**: 健康与护足功能 **21.74%** / 品牌调性 / 场景与人群
- **AI 建议**: 优化场景与人群 + 优化产品功能描述 + 优化品牌调性
- **叙事骨架**: 骨架 B + 溯源故事(工艺+研发背书)
- **叙事禁区**: 避免焦虑话术("再不买孩子就……")

### 面部洗护

- **品类定性**: **清洁护肤消费领域核心品类**
- **Top 卖点**: 护肤功能 **20%** / 敏感肌专用 / 效果可视化
- **AI 建议**(重要):
  - **功能卖点画面需体现"效果是用出来的"**(不是塑料合成)
  - 使用"**即拍即用**"的产品引导语
- **叙事骨架**: 骨架 A + 测评(泡沫细腻度 + 卸妆前后)
- **7 秒高潮点**: 泡沫爆发 / 卸妆棉从彩妆脏到干净的对比

### 防晒用品

- **品类定性**: **季节性 + 功效复合 + 合规要求高**
- **Top 卖点**: 核心防晒功效 / 香味 / 美白 / 性价比
- **AI 建议**: 合规内容 + 场景化(海边/通勤/户外运动)
- **叙事骨架**: 骨架 A + 测评(紫外线笔照射对比)
- **叙事禁区**: 严禁"防止黑色素""美白祛斑"等违规

### 面部彩妆

- **品类定性**: **潮流迭代快 + 内容驱动 + AIGC 助力**
- **Top 卖点**: 质地与妆效表现 **26.39%** ← 首选核心镜
- **AI 建议**: AIGC 助力内容创作;快速跟风爆款妆容
- **叙事骨架**: 骨架 A + 变装/试穿(素颜→精致)
- **7 秒高潮点**: 上妆完成的第一帧 + 卡点音效

### 唇部彩妆

- **品类定性**: **情绪色彩 + 冲动消费**,潮流迭代快
- **Top 卖点**: 质地与妆效 / 持久性 / 设计与功能 / 沉浸式场景
- **AI 建议**:
  - **提升 AI 生成沉浸式场景**
  - 布局端**增加美学镜头**
- **叙事骨架**: 骨架 A + 变装/试穿;镜 3 唇部微距质地上色

### 玩具

- **品类定性**: **情绪价值 + 教育功能 + IP 驱动**
- **Top 卖点**: 实际功能体验 **26.67%** / 情感反馈 / 用户为中心
- **AI 建议**: 升级情感反馈 + 以用户为中心 + IP 联动
- **叙事骨架**: 骨架 B 剧情(孩子拆盒+惊喜+互动)+ 剧情/情感
- **7 秒高潮点**: 孩子看到玩具的**惊喜表情特写**(不是玩具本身)

### 生活用纸

- **品类定性**: **快消家庭刚需**
- **Top 卖点**: 功能与多用途 / 安全与质感 / 便利与设计 / 健康工艺
- **AI 建议**: 用户提问 AI 回答 + 千川 AI 生成
- **叙事骨架**: 骨架 A + 利益前置(囤货性价比)
- **7 秒高潮点**: 抽纸柔软度测试(揉团弹开)

### 衣物清洁

- **品类定性**: **刚需 + 高复购 + 快速迭代**
- **Top 卖点**: 去污去渍效果 / 贴身安全温和性 / 记忆点 / 表达优化
- **AI 建议**: 强化记忆点 + 优化表达 + 能力协同
- **叙事骨架**: 骨架 A + 测评(顽固污渍前后对比)
- **7 秒高潮点**: 污渍消失瞬间(慢镜 + 音效)

### 家庭环境清洁

- **品类定性**: **化学 + 机械双技术**清洁平台
- **Top 卖点**: 高效去污 / 便捷省心 / 虚拟创意展示
- **AI 建议**:
  - 强化"**化学+机械双技术**"卖点
  - 运用 AI 实现**虚拟创意展示**(污渍拟人化对抗等)
- **叙事骨架**: 骨架 A + 测评(喷雾-静置-擦拭 三段)

### 宠物生活

- **品类定性**: **从"养活"向"养好"升级**,精致养宠人群
- **Top 卖点**: 美毛/护肤/健康管理功能 **21.0%** / 精致养宠场景
- **AI 建议**: 宠物洗护 AI 助宠 + 日常洗护 AI 应用
- **叙事骨架**: 骨架 B 慢切 + 溯源故事(宠物 Vlog 感)
- **7 秒高潮点**: 宠物洗浴后蓬松抖毛慢镜

### 染发烫发洗护

- **品类定性**: **高复购个护**
- **Top 卖点**: 染烫效果 **22.12%** / 操作便捷 **19.82%** / 品牌调性
- **AI 建议**: AI 精准做营销产品画像;千川 AI 帮品牌 0-1 流量突破
- **叙事骨架**: 骨架 A + 变装/试穿(染前染后前后对比)+ 测评

### 口腔护理

- **品类定性**: **国民健康意识觉醒 + 适应驱动**
- **Top 卖点**: 防护维护 **35.02%** ← 首选核心镜 / 品牌情感表达
- **AI 建议**:
  - 多个内容方向存在明显机会
  - **加强品牌情感表达**
- **叙事骨架**: 骨架 A + 测评(牙渍/口气可视化)
