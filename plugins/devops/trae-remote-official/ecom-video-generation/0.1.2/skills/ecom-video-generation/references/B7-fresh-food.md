# B7 鲜食生活 · 品类卖点与叙事参考

> 覆盖 8 个类目:水果蔬菜 · 休闲食品 · 水饮冲调 · 传统滋补 · 海鲜水产 · 低温肉蛋 · 粮油干货/方便速食 · 鲜花园艺

## 板块共性

- **强属性**: 强季节性 + 产地直供 + 兴趣驱动
- **首选叙事**: **溯源故事**(产地故事) / **ASMR 感官**(食欲感官)
- **叙事禁区**:
  - 别搞"AI 味"过重的合成画面(食品要真实感)
  - 别忽视合规(功效类品类严禁夸大表达)
- **叙事推荐**: 使用场景 + 食用方式 + 产地信息 三条并行

## 逐类目卡片

### 水果蔬菜

- **品类定性**: **"强季节性+产地直供+兴趣驱动"**高频消费类目
- **Top 卖点**:
  - 口感风味独特
  - 使用场景与食用方式
  - 产地信息
- **AI 建议**: 用户搜索 AI 推荐;强化"使用场景/食用方式"
- **叙事骨架**: 骨架 B 慢切 + 溯源故事(果园/农户人物)+ ASMR 感官(切开汁水)
- **7 秒高潮点**: 果肉切开的第一滴汁水 / 咬下去的清脆声

### 休闲食品

- **品类定性**: **情绪解压 + 分享属性**
- **Top 卖点**:
  - 健康配料与成分
  - 风味口感
  - 产地工艺
  - 品牌价值
- **AI 建议**:
  - 提升品牌价值
  - **降低"AI 味"**(避免合成感,保留真实感)
  - 提升内容价值
- **叙事骨架**: 骨架 A 快切 + ASMR 感官(撕包装+咀嚼+舔手指)
- **7 秒高潮点**: 撕开包装 + 拉丝/爆汁/掉渣特写

### 水饮冲调

- **品类定性**: **快消刚需品类**
- **Top 卖点(占比)**:
  - 原料与成分 **20%**
  - 口味风格 **18.89%**
  - 价格 **18.89%**
  - 功效价值 **16.67%**
  - 包装与品牌
- **AI 建议**: 结合商品信息 + 用户标签 匹配场景生成
- **叙事骨架**: 骨架 A 快切 + ASMR 感官(开罐/倒饮/杯壁凝露)
- **7 秒高潮点**: 开罐"啵"声 + 冲调翻腾 + 冰块碰撞

### 传统滋补

- **品类定性**: **强信任属性 + 节点波动明显 + 合规要求严**的健康消费类目
- **Top 卖点**: 原料产地与品质 **20.0%** / 功效合规管控 / 用户提问式内容
- **AI 建议**:
  - 用户提问 AI 回答式结构
  - **功效合规管控**(严格避免绝对化用语)
  - 强化产地信任链
- **叙事骨架**: 骨架 B + 溯源故事(药材原产地/工艺传承)
- **叙事禁区**: 严禁"治愈""根治""替代药物"等违规表达

### 海鲜水产

- **品类定性**: **产地供应链驱动**
- **Top 卖点**: 产品品质 / 产地与供应链 / 消费人群 / 季节性
- **AI 建议**: 供应链升级 + 季节性内容
- **叙事骨架**: 骨架 B + 溯源故事(渔港/捕捞现场/冰鲜运输)
- **7 秒高潮点**: 活虾跳跃 / 蟹钳挥舞 / 冰壳敲碎

### 低温肉蛋

- **品类定性**: **鲜食保存**,属鲜食生活范畴
- **Top 卖点(共占比接近)**:
  - 原料品质安全 **18.4%**
  - 口感风味 **18.4%**
  - 工厂规模化生产 **18.4%**
- **AI 建议**(3 个方向): 内容优化 / 选品选图 / 投放优化
- **叙事骨架**: 骨架 B + 溯源故事(工厂+溯源码)
- **叙事禁区**: 别做过度食物精修(要真实感)

### 粮油干货-方便速食

- **品类定性**: **家庭基础品类**
- **Top 卖点**: 口感风味独特 **17.5%** / 产地信息 / 场景化
- **AI 建议**: 强化产地信息 + 强化场景化(单人晚餐/办公室/宿舍)
- **叙事骨架**: 骨架 A + ASMR 感官(泡面翻腾+撕料包)
- **7 秒高潮点**: 沸水入桶+料包爆开

### 鲜花园艺

- **品类定性**: **内容驱动 + 情绪价值**
- **Top 卖点**: 视觉表达 / 产品详情 / 场景化
- **AI 建议**: AI 可优化视频表达 + 丰富产品详情
- **叙事骨架**: 骨架 B 慢切 + 变装/试穿(空瓶→满花的空间变身)
- **7 秒高潮点**: 剪枝入瓶的第一朵完成瞬间
