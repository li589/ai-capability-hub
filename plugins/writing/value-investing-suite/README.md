# 价值投资研究套件

一套面向价值投资者的研究工作台，把巴菲特、芒格、段永平、李录四位大师的方法论系统化为 14 个可调用技能，覆盖公司深度研究、财报精读、行业筛选、持仓管理与思维工具五大场景。套件内置精确金融计算与报告审计的 Python 工具（`decimal` 精确估值、市值/估值验算、三情景估值、报告数据抽检、A股行情、雪球大V抓取），强制"关键数据两源交叉验证、计算一律走工具不心算"，并贯彻信息丰富度分级（A/B/C）与反 AI 研究偏见机制。移植并适配自开源项目 [AI Berkshire](https://github.com/xbtlin/ai-berkshire)（xbtlin/ai-berkshire）。

> **免责声明：** 本套件用于投资研究与学习，不构成任何投资建议。所有分析基于公开信息与 AI 推理，可能存在数据滞后或错误；AI 能输出的"置信度"不等于投资的真实确定性。任何买卖决策请自行独立判断并自担风险，关键数据请自行核实。

## 适用人群

- **个人价值投资者** —— 用统一框架研究公司、跟踪持仓、复盘组合，避免情绪化决策
- **卖方/买方研究员** —— 快速搭建公司深度报告、行业全景、财报点评的初稿骨架
- **投研内容创作者** —— 用四大师视角产出结构化、有观点、可复盘的研究稿

## 快捷指令

| 指令 | 说明 |
|------|------|
| `/四大师投研` | 对一家公司做巴芒段李七模块综合分析，输出买入/观望/回避+价格区间 |
| `/投研团队` | 四个子 Agent 并行研究一家公司，主控汇总成含评分与操作建议的最终报告 |
| `/管理层研究` | "买股票就是买人"——追踪言行一致性、资本配置、诚信度纵深研究 |
| `/财报精读` | 读一手财报：看变化、听管理层语气、挖附注，判超/符/低于预期 |
| `/行业研究` | 产业链全景扫描+全球公司扫描+各环节头部四大师分析+组合配置 |
| `/行业漏斗筛选` | 从全市场30-60家逐层漏斗精选到终选3家 |
| `/去劣筛选` | 7条硬指标+3条豁免，快速排除非一流公司（支持行业/指数批量） |
| `/买入Checklist` | 巴菲特买入前六道闸门+镜子测试，判通过/未通过/灰色地带 |
| `/组合复盘` | 单仓位体检+集中度/相关性/机会成本/压力测试+调仓建议 |
| `/论文追踪` | 买入后纪律系统：建立投资论文并按季追踪健康度 |
| `/论文漂移检测` | 对比两份论文快照，分清事实变化/价格变化/措辞变化 |
| `/新闻脉搏` | 股价异动时10分钟快速归因，判价值事件还是情绪波动 |
| `/段永平问答` | 以段永平的思维和语言风格回答投资/商业/人生问题 |

## 技能

| 技能 | 说明（含内置方法论） |
|------|------|
| 四大师投研 | 七模块顺序框架：数据收集→生意本质(段)→护城河(巴)→逆向风险(芒)→管理层→文明趋势(李)→估值与安全边际；含三情景估值+反向DCF |
| 投研团队 | 四角色并行（商业/财务/行业/风险），含联网预检、四维评分、Bull/Bear论点、分层操作建议 |
| 管理层研究 | 承诺vs兑现追踪、资本配置逐笔评分、困难时期品格推断、利益相关方态度、侧面验证 |
| 财报精读 | 一手资料优先、现金流质量、MD&A语气分析、附注异常信号检测、beat/meet/miss判定 |
| 行业研究 | 投资逻辑链验证、产业链全景图、全球公司分层扫描(Tier1-4)、卡脖子环节识别 |
| 行业漏斗筛选 | 四层漏斗（扫描→5硬指标→精细分析→四大师终选3家），每层留留/弃记录 |
| 去劣筛选 | 7条去劣指标+3条豁免规则（战略投入期/主动低利润率/高周转薄利），宁可漏网不可误杀 |
| 买入Checklist | 六道闸门（能力圈/好生意/护城河/管理层/安全边际/纪律）+镜子测试+快速否决清单 |
| 组合复盘 | 机会成本排序（预期回报×确定性）、相关性风险共振、极端情景压力测试 |
| 论文追踪 | 5句话核心论文+可验证假设+红线清单+估值锚点+健康度评分公式 |
| 论文漂移检测 | 5固定维度Improved/Unchanged/Weakened判定，证据驱动，只在事实变化时承认漂移 |
| 新闻脉搏 | 四维并行侦察+加权归因表+性质判断（价值事件/情绪波动/真因不明） |
| 段永平问答 | 段永平第一人称，投资信仰/生意模式/不为清单/能力圈/企业文化完整思想体系 |
| 财务数据规范（内部） | 数据源优先级、两源交叉验证规范、复权规则；捆绑 financial_rigor / report_audit 等 Python 工具 |

## 连接器（可选增强）

| 能做什么 | 无连接器时 | 连上后增强 |
|---------|-----------|-----------|
| 研究报告输出 | 写入本地 Markdown 文件，对话给链接 | 连**文档平台**后自动发布为在线文档 |
| 报告归档与检索 | 本地文件按公司名管理 | 连**知识库**后归档进团队知识库并建索引 |
| 数据补充 | 靠联网检索公开数据源 | 连**行业数据**（企查查/雪球）后补充工商股权、大V观点 |
| 异动通知 | 报告写本地 | 连**沟通工具**后把归因结论推送到指定群 |
| 持仓/审视提醒 | 报告内写下次审视时间 | 连**日程效率工具**后自动创建提醒 |

> 所有技能在没有连接器的情况下均可完整使用。连接器详情见 CONNECTORS.md。
