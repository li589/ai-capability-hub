# 公司新闻脉搏：股价异动快速归因

对 `$ARGUMENTS` 进行最近新闻侦察与异动归因。**这不是深度投研，是情报快速响应**——目标10分钟内回答："这家公司最近发生了什么？股价异动真因是什么？要不要重审投资论文？"

> QoderWork 适配：源框架的多 Agent 团队，用 **Agent 工具启动4个 general-purpose 子 Agent 并行侦察**（同一条消息并行调用），或直接用 WebSearch/WebFetch。可用 `xueqiu_scraper.py` 抓大V发言（见 [财务数据规范](../财务数据规范/SKILL.md)）。开工前运行 `date`。

## 适用场景
持仓/关注股票大涨大跌（触发线：单日±5%、一周±10%）；财报后异动想快速搞清市场在反应什么；看到新闻标题不确定是噪音还是信号。**不适用**：完整投研（用 [投研团队](../投研团队/SKILL.md)）、财报深读（用 [财报精读](../财报精读/SKILL.md)）、长期论文跟踪（用 [论文追踪](../论文追踪/SKILL.md)）。

## 第一步：确认参数
澄清（如未提供）：公司名（必填）、时间窗口（默认14天，财报季缩到7天）、股价异动（涨/跌幅度+时间，选填）、关注侧重（公司/监管/行业/情绪，默认四方平均）。用户只说公司名时先反问，**不要默默假设**。

## 第二步：信息可得性分级
A级（大盘股/覆盖广/财报季）→重点降噪和归因，过滤重复转述二手新闻；B级（中小盘）→标准模式，每条关键事件附1-2独立信源；C级（港股小票/新上市/冷门）→"扫盲模式"，可能找不到能解释异动的新闻，**这个结论本身就有价值**（可能是技术性/资金面而非基本面）。

## 第三步：四维并行侦察
**在同一条消息中并行启动4个子 Agent**（或依次用 WebSearch），角色与侦察内容：

**① 公司事件**：官方公告（披露易/SEC/巨潮）、财报与业绩指引、管理层动作（变动/增减持/回购/分红/激励）、重大业务事件（新品/并购/剥离/大客户大订单）、资本运作（再融资/可转债/ADR/回A）、诉讼与合规。每条标注：日期/来源链接/一句话摘要/与异动相关性（高中低）。

**② 监管与政策**：行业监管（新规/罚款/整改/牌照）、跨境政策（中美关系/关税/出口管制/数据安全）、税收、反垄断、特殊行业政策（集采/双减/三道红线/平台规制）、货币外汇。每条标注：日期/来源/直接影响程度（直接/间接/无关）。重点：是否有政策黑天鹅刚落地。

**③ 行业与竞争对手**：直接对手（3-5个，逐个查财报/产品/价格战/人事）、产业链上下游（价格/产能/订单）、行业整体（景气度/出货量/需求信号）、替代品威胁、行业指数表现（该公司跑赢/跑输/同步）。关键判断：**是公司个体事件还是整个行业的beta波动？**

**④ 市场情绪与卖方/大V**：卖方评级变动（高盛/摩根/中金目标价）、机构持仓变化（13F/港股通/北上资金）、做空数据、大V观点（可用 `xueqiu_scraper.py` 抓段永平 user_id `1247347556` 等最近相关发言，仅在该公司是段永平/李录关注标的时调用）、传言小作文、技术面信号。关键判断：**基本面驱动还是情绪/资金面驱动？**

每个子 Agent 输出：核心发现3-5条、完整事件时间线表（日期倒序：日期/事件/来源/与异动相关性/持续性）、本维度归因结论（能否解释异动+置信度）、数据缺口声明。严格区分事实与推测。**联网失败禁止用训练知识冒充。**

## 第四步：主控综合归因报告（重点是"判断"不是"研究"）
1. **一句话归因**（30-60字：主因+次因+性质判断）
2. **完整事件时间线**（合并4维，日期倒序：日期/维度/事件/来源/归因权重🔴高🟡中⚪低）
3. **异动归因表**（候选解释/证据/反证/置信度/持续性）
4. **性质判断（核心结论，打勾其一）**：□价值事件（基本面真实变化，需重审论文）□情绪/技术波动（基本面无变化，是资金面/beta，可视为机会或噪音）□真因不明（找不到匹配异动幅度的事件——**最危险**，可能市场抢跑或漏了信息源）□混合
5. **各维度侦察摘要**（每维3-5条+归因贡献度）
6. **行动建议**（是否触发 [论文追踪](../论文追踪/SKILL.md) 重审 / [财报精读](../财报精读/SKILL.md) / [管理层研究](../管理层研究/SKILL.md) / 调仓提示 / 仅观察）
7. **接下来7-30天跟踪清单**（待披露事件/待跟踪指标/关键观察信号）
8. **信息缺口声明**（诚实列没解决的疑点，宁可标"不确定"不用推测填满）

## 第五步：保存报告
写入本地报告（建议 `{公司名}-news-{YYYYMMDD}.md`）。

## 关键原则
快胜过全（10-15分钟给归因判断，不陷入深度分析）；归因优先于罗列（判断哪个事件配得上这次异动，做减法）；诚实面对"不明"（比硬凑因果链更有价值）；不预设立场（不因持仓就倾向"是情绪波动没事"）；区分催化剂和巧合（看影响量级是否匹配）；尊重信息可得性；不替用户做决策。报告用中文，**结尾标注"研究学习用途，非投资建议"**。
