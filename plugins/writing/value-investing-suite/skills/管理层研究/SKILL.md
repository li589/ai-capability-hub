# 管理层纵深研究：买股票就是买人

对 `$ARGUMENTS` 进行管理层深度研究。支持输入 `公司名` 或 `人名 公司名`。

> "买股票就是买人。找到你信任的人，然后长期持有。"——段永平
> "评估管理层，要看他们在没人看着的时候做什么。"——巴菲特

> 取数、验算遵循 [财务数据规范](../财务数据规范/SKILL.md)。QoderWork 适配：源框架的多 Agent 并行收集，用 Agent 工具启动多个 general-purpose 子 Agent 并行检索（同一条消息并行调用），或直接用 WebSearch/WebFetch。开工前运行 `date`。

## 设计理念
本技能是 [四大师投研](../四大师投研/SKILL.md) 第五步管理层评估的**深化版**。当标准研究中管理层评分不确定（★★★或以下）、或管理层是核心投资逻辑时使用。AI 无法和管理层吃饭，但可通过公开信息追踪言行一致性、分析资本配置回报、从困难时期决策推断品格、侧面验证。

## 第一步：识别关键管理层并并行收集
确认关键人物（CEO/董事长、CFO、创始人、实际控制人、其他关键高管），填任期/背景/持股。**注意区分"谁在做决策"和"谁的名字在头衔上"**（如黄峥之于拼多多）。启动并行检索：①CEO公开发言与预测（股东信/电话会/采访/社交媒体）②资本配置决策（并购/回购/分红/新业务）③治理结构与薪酬 ④侧面验证（员工/客户/行业口碑）。

## 第二步：CEO能力圈评估
**2.1 战略眼光**：提取CEO过去5年判断/预测，对比实际结果（时间/判断/实际/准确度✅❌）。关键问题：有无超前于市场的正确判断？大家看好时是否保持冷静？是跟随还是独立思考？
**2.2 执行能力**：战略到落地、组织能力、危机处理、迭代速度（维度/评估/证据）。

## 第三步：诚信度评估（最重要）
> 巴菲特："正直、智慧和精力。如果没有第一种，后两种会害死你。"

**3.1 承诺vs兑现追踪**：从过去3年财报会/股东信/采访提取**具体承诺**，逐条对比兑现情况（时间/承诺/场合/兑现/评价✅⚠️❌）。兑现率统计：>80%优秀｜60-80%合格｜40-60%令人担忧｜<40%严重问题。
**3.2 困难时期表现**：搜索历史重大危机（暴跌/miss/监管/竞争），分析应对——主动沟通还是躲避？归因内部还是甩锅？做困难但正确的事还是短期讨好市场？
**3.3 对利益相关方态度**（股东/员工/客户/供应商/监管：尊重-忽视-利用，附证据）。李录："对利益相关方的态度决定企业长期生命力。"

## 第四步：资本配置能力（巴菲特最看重）
**每赚一块钱，管理层能变成多少钱？**
- 并购记录（时间/标的/金额/逻辑/事后回报/评分1-5）
- 回购记录（时间/金额/均价/当时PE/事后回看/评分）——用 `verify-valuation` 校验回购时与当前估值
- 分红记录（年份/金额/分红率/同期FCF/可持续性）
- 新业务投资（时间/领域/累计投入/当前状态/回报/评分）
- 资本配置评分（并购纪律/回购时机/分红合理性/新业务/现金管理/综合，1-5）

巴菲特标准：有好机会时果断投资，没有时积极回购/分红，永远不做高价并购。

## 第五步：治理结构评估
**5.1 股权结构**（AB股/超级投票权？创始人持股？VIE？独董独立性？大股东增减持？+风险评估）
**5.2 薪酬合理性**（高管/总薪酬/占净利润比/同行对比/是否合理）——激励是否与长期股东利益一致？
**5.3 关联交易**（关联方/内容/金额/是否公允/风险）

## 第六步：侧面验证（注意：取决于公开可搜索内容，标注来源与可得性）
**6.1 员工视角**（Glassdoor/知乎等公开评价：企业文化/管理层评价/工作强度/薪酬/前景）
**6.2 客户/商家视角**（App Store评分、消费者投诉、商家论坛）

## 输出要求
1. 综合评分表（战略眼光/执行/诚信/资本配置/治理，1-5星）+ 一句话管理层结论
2. 所有判断附证据来源；侧面信息标注可得性
3. 明确回答：这个管理层值得托付10年吗？最大的人的风险是什么？
4. 报告用中文，风格直接；**结尾标注"研究学习用途，非投资建议"**
5. 写入本地报告文件（建议 `{公司名}-management-{YYYYMMDD}.md`）
