# 组合管理：从「研究公司」到「管理组合」

对 `$ARGUMENTS` 执行投资组合审视与优化。支持比例清单、股数@成本清单，或「我的持仓」（读已保存的组合文件）。

> "分散投资是对无知的保护。如果你知道自己在做什么，分散就没有意义。"——巴菲特
> "我这辈子见过的真正好机会，十个手指就数得完。"——李录

> 取数、验算遵循 [财务数据规范](../财务数据规范/SKILL.md)。QoderWork 适配：每个持仓并行取最新数据用 Agent 子 Agent 或 WebSearch。开工前运行 `date`。

## 第一步：解析持仓
标准化为表（标的/代码/持仓量/成本价/现价/市值/占比/盈亏）。只有比例没金额则按比例分析。检查是否有已保存的组合文件，有则读取更新。

## 第二步：获取最新数据
为每个持仓并行获取：当前股价与估值（PE/PB/股息率）、最近季度关键财务变化、近期重大事件、分析师一致预期（前瞻PE/目标价）。用 `verify-valuation` 校验估值。每个持仓标注信息丰富度A/B/C，C级结论标低置信度。

## 第三步：单仓位体检
| 标的 | 当前PE | 买入逻辑是否变化 | 论文健康度 | 仓位建议 |
每个持仓回答：①如果今天没持仓，还会在当前价格买入吗？②如果明天不能交易，持有5年舒服吗？③买入论文还完整吗？段永平："如果你不想持有一只股票10年，那就一天也不要持有。"

## 第四步：组合层面分析
**4.1 集中度**（第一大持仓<40%？前三大50-80%？总数5-15只？现金10-30%？）。李录标准：3-5只核心前3占80%+（但要求每只研究透彻）。巴菲特：核心不超10只。
**4.2 相关性检查**（识别隐性关联，如腾讯+快手同属中国互联网监管共振、英伟达+台积电AI供应链同向）。检查清单：>50%仓位暴露同一主题/行业？同一国家/货币？中美关系恶化亏多少？全球衰退亏多少？
**4.3 机会成本分析**（巴菲特核心思维——每块钱放在回报最高处）：所有持仓按"预期年化回报×确定性"排序。预期回报估算用 `three-scenario`：简化公式≈FCF Yield+预期增速。**关键问题**：排名最后的持仓预期回报是否高于现金（无风险利率~4%）？不是则应卖出换现金。
**4.4 压力测试**（全球衰退/中美冲突升级/利率飙升/科技泡沫破裂：假设+组合影响+最大回撤）。定性+粗估：哪些持仓受冲击最大？整体能否承受？是否需对冲？

## 第五步：优化建议
**5.1 调仓建议**（动作/标的/当前占比/建议占比/理由：加仓/减仓/清仓/新建仓/不动）
**5.2 寻找替代标的**：若有"不如现金"的仓位或现金过高，建议用 [行业研究](../行业研究/SKILL.md) 或 [买入Checklist](../买入Checklist/SKILL.md) 系统筛选，而非本技能内直接推荐个股。
**5.3 现金管理**（当前现金占比/建议占比/理由）。巴菲特：找不到好机会时，现金是最好的仓位。

## 第六步：输出组合报告
结构：一、组合概览（持仓表+饼图描述）二、单仓位体检 三、组合分析（集中度/相关性/机会成本/压力测试）四、调仓建议 五、下次审视时间和关注重点。
**结论必须明确回答**：①组合整体健康度（优秀/良好/需调整/问题严重）②最应该做的一件事（加仓X/减仓Y/不动）③当前最大风险。

## 第七步：保存组合文件
写入本地组合文件（最新持仓表+本次审视日期结论+调仓记录追加+下次审视提醒）。

## 关键原则
每块钱都有机会成本；集中不是风险，无知才是；现金是一种仓位；组合层面>个股层面；定期审视（每季度一次）但不过度交易。报告用中文，**结尾标注"研究学习用途，非投资建议"**。
