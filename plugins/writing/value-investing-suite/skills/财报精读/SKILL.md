# 财报精读：一手资料深度解读

对 `$ARGUMENTS` 进行财报精读。支持 `公司名 季度`（默认读最近一期）。

> "我从不看卖方研报，只读原始财报。"——李录　"我每天读500页。"——巴菲特

> 取数、验算遵循 [财务数据规范](../财务数据规范/SKILL.md)。QoderWork 适配：源框架的多 Agent 并行获取原文，用 Agent 工具启动子 Agent 或用 WebSearch/WebFetch 抓取一手材料（可用浏览器连接器打开 IR 页面/披露易/EDGAR）。开工前运行 `date`。

## 前置：资料可得性评级
A级=获取到完整原文（10-K/年报/电话会纪要），正常全流程｜B级=仅部分原文或第三方汇总，标注"非原始来源"，降低附注分析权重｜C级=仅新闻和数据网站摘要，聚焦核心财务变化，跳过附注挖掘，标注"一手资料不足"。

## 第一步：获取一手资料
并行获取：①财报原文（IR页面/SEC EDGAR/港交所披露易/巨潮）②电话会纪要/录音（Seeking Alpha/IR/雪球）③致股东信 ④投资者日材料。无法获取完整原文时按 财务数据规范 用标准数据源拼凑，但必须标注"非原始财报，来自第三方汇总"，关键数据两源误差>1%须标记。

## 第二步：核心财务数据提取与验证
**2.1 利润表**（指标/本期/上期/YoY/管理层指引/是否达标）：总收入及分部拆解、毛利润率、经营利润率（区分GAAP/Non-GAAP）、净利润（注意非经常损益）、EPS（基本vs稀释）。
**2.2 现金流表（巴菲特最看重）**：经营现金流/净利润比（>100%佳，<80%警惕）、资本开支构成（维护vs扩张）、自由现金流、回购分红、期末现金。
**2.3 资产负债表健康度**：现金+短投 vs 有息负债、净现金趋势、应收账款周转天数（是否放松信用冲收入）、存货周转天数、商誉及无形资产占比（减值风险）。
**数据验证**：用工具校验（按 财务数据规范 定位 `{TOOLS}`）——`cross-validate` 收入/净利润、`verify-market-cap`、`verify-valuation`。

## 第三步：管理层讨论精读（MD&A）
这是巴菲特和李录花最多时间的部分。**不是看数字，是听管理层怎么说。**
**3.1 语气分析**：🟢坦诚（主动承认问题、给具体原因）🟢清晰（战略具体、有量化目标）🔴模糊（"我们相信/长期来看"无实质）🔴转移（回避直接问题）🔴归因外部化（全怪宏观/行业）。
**3.2 承诺追踪**：从上期财报/电话会提取具体承诺，与本期对比（✅达标/❌未达标/⚠️部分）。段永平："看管理层靠不靠谱，看他以前说的话做到了没有。"
**3.3 关键问题识别**：从Q&A提取分析师最尖锐问题及回答质量（1-5，是否回避）。

## 第四步：附注与隐藏信息挖掘
**4.1 必查附注**：关联交易条款是否公允；股权激励稀释效应；或有负债（诉讼/担保）；会计政策变更；分部信息（好业务补贴坏业务？）；客户/供应商集中度。
**4.2 异常信号**：应收账款增速>收入增速（塞渠道）；存货增速>收入增速（积压）；经营现金流<净利润且差距扩大（利润质量存疑）；资本化开支突增（美化利润）；非经常收益占比突升。

## 第五步：与历史数据对比
**5.1 趋势分析**（至少4个季度或3年年报时间序列）：利润率改善还是恶化？收入增速加速还是减速？现金流质量升还是降？资本开支强度增还是减？
**5.2 与管理层指引对比**（指标/此前指引/实际/偏差/解读）。

## 第六步：输出精读报告
结构：一、核心数据速览（一页表格）二、本期最重要的3个变化（<500字）三、管理层语气与承诺追踪 四、附注隐藏信息 五、关键问题（Q&A精选）六、与投资论文的关系（如有持仓）七、结论：这份财报改变了什么？
**结论必须明确回答**：①超预期/符合/低于预期？（不能说"基本符合"然后两面话）②对投资论文影响：强化/无影响/削弱/破裂 ③下一个催化剂？④已持有的话该加仓/持有/减仓？

## 第七步：保存与抽检
写入本地报告（建议 `{公司名}-earnings-{期间}.md`）。按 [财务数据规范](../财务数据规范/SKILL.md) 用 `report_audit.py` 执行数据抽检准出流程。

## 关键原则
读原文不读摘要；看变化不看绝对值；听语气不只听内容；查附注不只看正文；给结论不做汇总。报告用中文，**结尾标注"研究学习用途，非投资建议"**。
