# 四大师投研：巴菲特-芒格-段永平-李录 综合分析框架

对用户给定的公司（`$ARGUMENTS`）进行系统化投资研究分析。

> 本技能取数、验算、审计一律遵循内部知识库 [财务数据规范](../财务数据规范/SKILL.md)：关键数据两源交叉验证，误差>1%须标记；所有计算用工具验算禁止心算。
> QoderWork 适配：源框架提到的 Task/Agent/WebSearch 等能力，在本环境用 WebSearch/WebFetch 联网检索、用浏览器连接器抓取页面、用 Bash 运行工具、用 Write 落地报告。开工前先运行 `date` 确认今天日期，作为"最新数据"基准并写在报告开头。

## 前置步骤：AI研究偏见自觉（必须执行）

评估该公司的"AI可研究性"，识别数据偏见：

| 等级 | 特征 | AI研究陷阱 | 应对策略 |
|------|------|-----------|---------|
| A级（信息充裕） | 上市多年、券商覆盖多、报道密集 | 共识过强，输出趋同市场定价，alpha有限 | 重点做反面检验：聪明人为什么不买？被忽略的风险？ |
| B级（信息适中） | 上市1-3年、覆盖有限、部分需推算 | 用"合理推测"填补空白，虚假确定性 | 每个推算数据标注置信度，区分"有据推算"和"凭空填充" |
| C级（信息稀缺） | 新上市/冷门/新兴市场，几乎无覆盖 | 因资料不足过度保守，误判"看不清=不好" | 用第一性原理提问，从有限信息提取商业本质 |

**C级公司第一性原理四问**：①客户是谁？为什么付钱？有无替代？②复购靠什么驱动？③对手拿100亿能复制吗？④管理层关键决策反映了什么判断力和价值观？

**偏见自查清单**：我的"确定性"来自生意本质还是资料数量？资料减半结论会变吗？输出是否与市场共识雷同、信息优势在哪？

将信息丰富度评级写入报告开头，并在结论中区分"AI研究置信度"与"实际投资确定性"。

## 第一步：数据收集

按 [财务数据规范](../财务数据规范/SKILL.md) 联网收集：①收入结构（分部收入/增速/毛利率）②近5年财务（收入/净利润/毛利率/经营利润率/FCF/现金）③竞争格局④商业模式与护城河⑤技术能力⑥管理层⑦行业前景（TAM）⑧风险因素⑨当前估值（市值/PE/PS/PEG/EV/Revenue）⑩多空核心论点。

**数据交叉验证（必须用工具，禁止心算）**——按 财务数据规范 定位 `{TOOLS}` 后执行：市值验算 `verify-market-cap`、关键数据 `cross-validate`（对收入/净利润/现金分别执行）、估值指标 `verify-valuation`。工具输出直接嵌入报告附录"关键数据交叉验证记录"。若工具报 ❌ 偏差过大，必须排查原因才能继续。

常见错误防范：市值单位（港币亿/人民币亿/美元亿易漏零）；FCF口径；债务口径（是否含经营租赁）；持股比例（AB股经济权益≠投票权）。

## 第二步：生意本质 — 段永平「对的生意」
一句话定义生意本质；收入结构拆解（图表）；5年盈利能力趋势；商业模式画布（一次性 vs 订阅/复购？硬件 vs 软件 vs 平台？）；生态粘性/客户锁定；毛利率与同行对比并解释；经营杠杆。**段永平式追问**：这门生意好在哪？一句话是什么？

## 第三步：护城河评估 — 巴菲特「经济护城河」
| 护城河类型 | 验证方法 |
|-----------|---------|
| 品牌/定价权 | 能否不损失销量提价？ |
| 转换成本 | 客户迁移成本多高？ |
| 网络效应 | 用户越多产品越好吗？ |
| 规模效应 | 规模带来的成本优势多大？ |
| 技术/专利壁垒 | 领先几年？能否被复制？ |

分析护城河趋势（过去5年变宽/变窄，未来5年预判）。**巴菲特式追问**：10年后护城河还在吗？什么能摧毁它？

## 第四步：逆向思考与风险清单 — 芒格「反过来想」
列"可能失败的所有路径"（路径/概率/影响表）；历史类比；跨学科分析（网络效应/技术采纳曲线/竞争博弈）；偏误自查（叙事/锚定/幸存者偏差）；收集空方论点。**芒格式追问**：我最可能在哪里犯错？聪明人为什么不买/做空？

## 第五步：管理层评估 — 段永平「对的人」+ 巴菲特「诚信」
CEO关键决策复盘（时间/决策/结果/评分表）；资本配置能力（研发回报/并购成功率/回购时机）；股东利益一致性（持股/薪酬/减持）；组织能力；企业文化。**段永平式追问**：CEO退休后公司还能保持竞争力吗？（管理层是核心逻辑或评分≤★★★时，建议接力用 [管理层研究](../管理层研究/SKILL.md) 做纵深。）

## 第六步：行业与文明趋势 — 李录「文明演进框架」
是否处于"文明级范式转移"；历史技术革命类比；TAM增长曲线与天花板；产业价值链位置；技术路线风险；客户/供应商集中度。**李录式追问**：20年后回看，这是"这个时代的标准石油"还是"昙花一现的3Com"？

## 第七步：估值与安全边际 — 巴菲特「内在价值」+ 段永平「对的价格」
当前市场定价（估值指标表，**工具验算**）；反向DCF（当前股价隐含什么增长预期）；三情景估值（**必须用工具** `three-scenario`，禁止心算）；与自身历史估值对比；与同行对比。**段永平式追问**：如果股市明天关闭5年，你愿意以这个价格持有吗？

## 第八步：综合决策备忘录
| 维度 | 结论 | 信心度 |
|------|------|--------|
| 生意质量（段永平）／护城河（巴菲特）／管理层／最大风险（芒格）／文明趋势（李录）／估值 | | |

最终决策表（空仓者/持仓者/卖出信号/加仓信号）+ 四位大师的模拟点评（引用格式）。

## 输出要求
1. 所有分析有数据支撑并附来源；关键数据用 Markdown 表格
2. 每个模块末尾有对应大师"追问"
3. 结论明确，不回避买入/观望/回避建议；估值给出具体价格区间
4. 报告开头含"信息丰富度评级"（A/B/C）和"AI研究局限性声明"
5. 报告结尾区分"AI分析置信度"（取决于资料量）与"投资确定性"（取决于生意本质）
6. C级公司末尾列"需要一手验证的问题清单"
7. 报告使用中文，风格直接犀利；评分用★（1-5，无半星）；估计值注明"估计"；**结尾标注"本报告为研究学习用途，非投资建议"**

## 数据抽检（准出流程）
报告写入文件后，按 [财务数据规范](../财务数据规范/SKILL.md) 用 `report_audit.py` 执行 extract → 取数核验 → verdict。【准出】全部偏差≤1%可发布；【打回】任意点>1%修正后重审。
