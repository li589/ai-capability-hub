# 投研团队：四角色并行分析框架

对用户给定的公司（`$ARGUMENTS`）做团队化投资研究。

> 取数、验算、审计遵循 [财务数据规范](../财务数据规范/SKILL.md)。
> QoderWork 适配：源框架的 TeamCreate/TaskCreate/多 Agent 在本环境用 **Agent 工具启动 4 个 general-purpose 子 Agent 并行研究**（在同一条消息中并行调用），每个子 Agent 完成后把完整报告返回，由你（主控）汇总。开工前先运行 `date` 确认今天日期。

## 第一步：展示团队框架
| 角色 | 职责 | 分析框架 |
|------|------|----------|
| 主控（你自己） | 统筹、汇总研判、输出最终报告 | 四大师综合 |
| 商业分析师 | 商业模式 & 护城河 | 段永平视角 |
| 财务分析师 | 财务报表 & 估值 | 巴菲特视角 |
| 行业研究员 | 行业格局 & 竞争态势 | 芒格视角 |
| 风险评估师 | 风险评估 & 管理层研判 | 李录视角 |

## 第一步半：AI研究偏见评估
先评估信息丰富度（A/B/C），并据此调整研究策略：A级重点做反面检验和非共识视角；B级推算数据标注置信度；C级转"第一性原理模式"聚焦商业本质核心问题。**关键提醒**：资料多≠确定性高，AI输出置信度≠投资真实确定性。将评级告知每个子 Agent。

## 第一步¾：联网能力预检（关键，避免子 Agent 静默退化）
后台子 Agent 若无法联网，会退化成仅凭训练知识作答却输出"看起来完整"的伪研究——这是最危险的失败模式。启动子 Agent 前先确认联网检索可用；每个子 Agent 的 prompt 必须写明：**若联网失败禁止伪装**，须在报告顶部醒目标注「⚠️ 未能联网，基于训练知识（截止日期X），置信度降级」并如实告知主控。

## 第二步：定义四个研究任务
为每个子 Agent 准备任务说明（subject + 详细要求）：

**任务1 商业模式（段永平视角）**：核心生意定义、收入结构拆解；平台/产品飞轮；护城河逐一验证（品牌/转换成本/网络效应/规模/技术）；为各方创造的独特价值；业务矩阵协同；段永平"好生意"标准（差异化/定价权/可持续优势）。

**任务2 财务与估值（巴菲特视角）**：近3-5年营收/净利/经营利润趋势；ROE/ROA/毛利率/经营利润率；现金流（经营/自由/资本开支）；资产负债表健康度；估值（PE/PS/PB/EV，历史+同业对比）；安全边际。**金融严谨性验证（必须用工具，禁止心算）**：`verify-market-cap`、`verify-valuation`、`cross-validate`、`three-scenario`（按 财务数据规范 定位 `{TOOLS}`），工具输出嵌入报告。

**任务3 行业与竞争（芒格视角）**：行业规模与增长/渗透率；竞争格局与对手份额；核心竞争者威胁逐个分析；细分赛道格局；行业趋势（技术/政策/新进入者）；产业链上中下游价值分配。

**任务4 风险与管理层（李录视角）**：管理层（能力圈/诚信/战略/资本配置/历史决策质量）；监管风险；竞争风险；业务风险；宏观风险；治理结构（股权/关联交易/回报政策）；长期确定性（10年后会怎样，什么能颠覆商业模式）。

## 第三步：并行启动 4 个子 Agent
**在同一条消息中并行调用 4 次 Agent 工具**（subagent_type: general-purpose）。每个子 Agent 的 prompt 模板：
```
你是{公司名}投研团队中的"{角色中文名}"，从{大师名}视角分析{公司名}。
请完成：{任务subject}
具体要求：{任务description}
研究方法：联网搜索最新公开信息（财报/行业报告/新闻）；财务数据必须来自两个独立来源，
按 财务数据规范 执行（美股macrotrends+stockanalysis；港股aastocks+macrotrends；A股东方财富+巨潮），
两源误差>1%须标记；关键数据标注来源。
联网失败禁止伪装：若无法联网，报告顶部醒目标注"⚠️未能联网，基于训练知识，置信度降级"并如实告知。
输出要求：报告详尽，Markdown表格呈现关键数据，每个维度有明确结论和评分，末尾给该维度总体结论。
```

## 第四步：接收报告并跟踪进度
向用户实时展示进度（哪些完成/进行中），每收到一份展示核心要点 3-5 条，等全部 4 份到齐。

## 第五步：主控综合最终报告
1. **一句话结论**（50-100字，是否值得投资+核心逻辑）
2. **四维评分总表**（维度/框架/1-5星/核心判断）+ 综合评分 X/5
3. **核心数据速览**（近2年关键指标对比表）
4. **各维度分析摘要**（每维度3-5条最重要发现）
5. **投资论点**：🟢看多逻辑5-7条 / 🔴看空逻辑5-7条
6. **巴菲特买入前Checklist**（10个核心检查项，逐一评估）
7. **最终投资建议**：定性判断表 + 分层操作建议（激进/稳健/保守→建议+价格区间）+ 关键催化剂（加仓/减仓信号各3-5条）
8. **总结段落**（100-200字）

## 第六步：保存与抽检
写入本地报告文件。按 [财务数据规范](../财务数据规范/SKILL.md) 用 `report_audit.py` 执行数据抽检准出流程。

## 重要注意事项
1. 4个子 Agent 必须并行启动 2. 数据准确性，关键数据交叉验证 3. 结论明确，给买入/观望/回避和价格区间 4. 所有分析有数据支撑 5. 反偏见：汇总时评估各 Agent 是否受限于资料充裕度、是否与共识过度趋同；最终报告含"信息丰富度评级"和"AI研究局限性声明" 6. 信息稀缺时宁可留白标"数据不足"，不用推测填满 7. 报告用中文，**结尾标注"研究学习用途，非投资建议"**。

## If Connectors Available
If **文档平台** is connected：可把最终报告及四个视角分报告自动发布为在线文档目录。
If **知识库** is connected：可归档进团队知识库并建立公司索引。
If no connectors available：默认写入本地工作目录 Markdown 文件（建议按公司名建子目录，含4个视角+最终报告）并给出链接。
