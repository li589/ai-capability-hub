# 投资论文追踪：买入后的纪律系统

对 `$ARGUMENTS` 执行投资论文追踪检查。

> "买入只是开始。真正的工作是持有期间的持续跟踪。"——李录
> "当事实改变时，我就改变想法。你呢？"——凯恩斯

> 取数、验算遵循 [财务数据规范](../财务数据规范/SKILL.md)。QoderWork 适配：数据收集用 WebSearch/子 Agent。开工前运行 `date`。论文文件建议存本地工作目录。

## 第一步：判断操作模式
检查是否已存在该公司的论文文件：不存在→**建立论文**模式；存在→**追踪检查**模式；找不到但用户表示已有→询问路径。

---

## 模式A：建立投资论文

**A0 数据收集**：获取当前股价、估值（PE/PB/股息率）、最新财报核心数据。若已有 [四大师投研](../四大师投研/SKILL.md) 或 [投研团队](../投研团队/SKILL.md) 报告优先读取。用 `verify-valuation` 校验估值。

**A1 核心论文（200字以内写清）**：
```
我以 ___元 买入 ___公司，因为：
1. 这门生意的本质是___，我理解它的赚钱方式
2. 它的护城河是___，而且在变宽/稳定
3. 管理层___，值得信赖的原因是___
4. 当前价格相当于内在价值的___折，安全边际来自___
5. 即使我错了，下行风险可控，因为___
```
**5句话写不完整=论文本身有问题**，说明买入决策不够清晰。

**A2 核心假设清单**（把论文拆成可验证假设，通常3-7个）：# / 核心假设 / 验证方式 / 验证频率 / 当前状态🟢。太少=思考不深，太多=不够聚焦。

**A3 红线清单**（触发任一=必须重新评估）：# / 红线条件 / 严重程度 / 触发后动作。例：管理层诚信问题（致命→立即清仓）、核心业务连续2季下滑（严重→减仓50%重评）、护城河被明确突破（严重→启动深研考虑退出）、监管根本性改变商业模式、管理层大规模非计划减持（警告→调查）。段永平："卖出只有三个理由：买错了、基本面变了、找到更好的。"

**A4 估值锚点**（股价/PE/市值/内在价值估算/安全边际：买入时/乐观/中性/悲观）。

**A5 保存论文**：写入本地论文文件（建立日期+买入价格仓位+核心论文+假设清单+红线清单+估值锚点+追踪记录表初始为空）。

---

## 模式B：追踪检查

**B1 读取现有论文**（核心论文/假设清单/红线清单/上次记录）。
**B2 收集最新数据**（最新财报/近期重大事件/当前股价估值/内部人交易）。
**B3 逐条检查核心假设**（# / 假设 / 上次状态 / 最新证据 / 当前状态 / 变化）。状态：🟢成立/🟡边际弱化/🔴受损/⚫破裂。
**B4 红线检查**（# / 红线 / 是否触发 / 证据）。任一触发→醒目标注+明确行动建议。
**B5 估值更新**（股价/PE(TTM)/内在价值/安全边际：买入时/上次/当前/变化）。
**B6 输出追踪报告**：一、论文健康度评分（满分10）二、核心假设检查结果 三、红线检查结果 四、本期关键变化（<500字）五、估值更新 六、结论与行动建议 七、下次检查关注重点。

**健康度评分公式**：健康度 = 10 − (⚫破裂×3) − (🔴受损×2) − (🟡弱化×1) − (红线触发×5)，最低1最高10。
| 评分 | 含义 | 动作 |
|:----:|------|------|
| 9-10 | 论文比买入时更强 | 考虑加仓 |
| 7-8 | 核心成立个别边际弱化 | 继续持有 |
| 5-6 | 1-2假设受损核心未变 | 持有但提高警惕 |
| 3-4 | 多个假设受损基础动摇 | 考虑减仓 |
| 1-2 | 红线触发或核心破裂 | 强烈建议卖出 |

**结论必须明确回答**：①论文还完整吗？（完整/边际弱化/受损/破裂）②该怎么做？（加仓/持有/减仓/清仓）③下次检查时间。
**B7 更新论文文件**：本次检查记录追加到追踪记录表（检查日期/健康度/核心变化/动作建议）。

## 关键原则
买入前就写好卖出条件；论文要具体到可验证（"ROE>25%且趋势稳定"而非"公司很好"）；红线触发就行动，最怕"再等等看"；论文破裂≠股价下跌（跌30%不一定卖，论文破裂才卖）；诚实面对错误。报告用中文，**结尾标注"研究学习用途，非投资建议"**。
