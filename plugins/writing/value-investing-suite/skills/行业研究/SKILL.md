# 行业投资研究：产业链全景扫描 + 四大师个股分析

对 `$ARGUMENTS` 行业进行系统化产业链投资研究。

> 取数、验算、审计遵循 [财务数据规范](../财务数据规范/SKILL.md)。QoderWork 适配：源框架多 Agent 全球扫描，用 Agent 工具启动子 Agent 并行检索或 WebSearch/WebFetch。开工前运行 `date`。

## 第一步：投资逻辑链构建与验证
**1.1 画出逻辑链**（箭头链路：底层趋势A→需求B→瓶颈/刚需C→受益产业链D）
**1.2 逐环节验证**（环节/核心假设/验证方式/数据来源），对每个箭头提出质疑并找证据
**1.3 寻找"已发生的验证事件"**：已签约/已落地的真实商业事件（采购协议、政策文件、行业报告），而非预测。

## AI研究偏见自觉：行业研究的特殊陷阱
| 偏见 | 表现 | 应对 |
|------|------|------|
| 成熟行业偏好 | 传统行业资料多，看起来"更确定" | 确定性来自商业模式非研报数量 |
| 新兴行业低估 | 新行业资料少，分析偏保守 | 用"终局思维"而非"当前数据"判断 |
| 龙头偏好 | 大公司资料多，天然倾向推荐龙头 | 小公司可能风险回报比更好 |
| 上市偏好 | 只扫上市公司遗漏关键未上市玩家 | 必须搜未上市公司，标"IPO候选" |
| 英文偏好 | 低估中国/亚洲玩家 | 必须中英文都搜 |

## 第二步：产业链全景图绘制
**2.1 结构**（上游原材料/加工→中游核心设备/系统集成/研发→下游运营/终端→辅助检测/维护/金融工具）用代码块文本图
**2.2 每环节生意特征**（商业模式/毛利率区间/竞争格局/壁垒类型/周期性）
**2.3 标记"卡脖子环节"**：供给最紧、替代最难、利润率最高——往往是最佳标的所在。

## 第三步：全球上市公司扫描
搜索该行业所有上市公司：美股（NYSE/NASDAQ）、A股、港股、其它国际市场（日韩欧澳）、行业ETF、关键未上市公司。对每家收集：中英文名、代码交易所、市值、一句话描述、是否纯正标的、所属环节。按环节分类成表，再按确定性分层：Tier1（大市值纯正龙头）/Tier2（中市值细分龙头）/Tier3（小市值高弹性）/Tier4（多元化中有相关业务）。

## 第四步：各环节头部四大师分析
对每环节 Tier1/Tier2 公司执行（Tier3/4 简评）：
- **生意本质（段永平）**：一句话定义+收入结构+毛利净利趋势+现金流特征+追问"这是好生意吗"
- **护城河（巴菲特）**：五类护城河评分★1-5+证据+追问"10年后还在吗"
- **风险（芒格）**：最可能怎么失败+最坏情景估值+聪明人为什么不买
- **管理层（段永平+巴菲特）**：CEO+关键决策+持股+简评A/B/C
- **估值快照**：PE/PS/EV/EBITDA+同环节对比+贵/合理/便宜
- **推荐度**：★1-5（★★★★★核心/★★★★卫星/★★★观察/★★期权/★不推荐）

## 第五步：行业级风险评估（芒格检查清单）
**5.1 系统性风险**（逻辑链某环节被证伪/替代技术/政策黑天鹅/需求周期回调/估值泡沫破裂：概率/影响/应对）
**5.2 历史类比**（类比行业/最终赢家在哪环节/多数投资者赚还是亏/启示）
**5.3 偏误自查**（叙事/锚定/从众）

## 第六步：文明趋势判断（李录框架）
底层趋势是"文明级范式转移"还是"阶段性热潮"？历史技术革命类比？10-20年后终局？哪个环节最可能赢家通吃？哪个最可能被颠覆？

## 第七步：投资组合配置建议
**7.1 推荐组合**（核心50-60%/卫星25-35%/期权5-15%/ETF替代：标的+环节+核心逻辑）
**7.2 买入/卖出信号**（加仓/减仓/清仓条件）
**7.3 主题仓位上限建议**

## 第八步：综合决策备忘录
行业总评表（逻辑链验证程度/最佳环节/最宽护城河/最大风险/文明趋势定位/整体估值：结论+信心度）+ 四位大师模拟点评。

## 输出要求
所有分析有数据支撑附来源；产业链全景用文本图；每环节至少分析2-3家头部；全球扫描尽可能完整；每家标注信息充分度A/B/C；结论明确给具体标的/仓位/价格区间；每模块末尾有大师追问；写入本地报告（建议 `{行业名}-industry-{YYYYMMDD}.md`）；报告用中文，**结尾标注"研究学习用途，非投资建议"**。
