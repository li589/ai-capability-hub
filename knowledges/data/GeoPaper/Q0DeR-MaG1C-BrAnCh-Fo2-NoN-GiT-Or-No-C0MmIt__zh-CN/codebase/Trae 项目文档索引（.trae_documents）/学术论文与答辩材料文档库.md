# 学术论文与答辩材料文档库

## 概述 <!-- category:overview -->
集中管理基于 Hyper-TCDF 模型的旱涝急转-滑坡灾害链研究相关的论文草稿、PPT 答辩材料、开题报告及中山大学毕业论文模板生成脚本。

## 架构设计 <!-- category:architecture_design -->
模块按内容类型划分为四个目录：`Paper/` 存放论文各版本（.docx/.pdf/.tex 及 LaTeX 中间文件）、`PPT/` 存放答辩 PPT 与提纲、`src/` 存放研究过程中的参考资料与中间稿、`生成脚本/` 提供 Python 脚本自动生成符合中山大学规范的 Word 论文模板。依赖方向单向：Python 脚本通过 `python-docx` 读取大纲并输出标准化模板，不反向依赖其他子目录；PPT 提纲与论文提纲相互参照，共同围绕 Hyper-TCDF 模型展开。

## 技术栈 <!-- category:tech_stack -->
Python + python-docx 用于生成符合中大规范的 Word 论文模板；LaTeX（.tex/.aux/.log）辅助论文排版；PowerPoint 模板（.pptx）统一答辩风格。

## 编码规范 <!-- category:coding_conventions -->
- 论文版本采用 V1.0/V2.0/... 与中文初稿并存的双命名策略，便于区分迭代阶段。
- 所有中文文档严格遵循中山大学本科毕业论文写作与印制规范（A4、宋体小四、1.5倍行距、首行缩进两字符）。
- PPT 提纲以“第N页：标题 + 页面内容建议 + 讲稿”三段式结构组织，便于逐页撰写与演练。

## 配置与命令 <!-- category:unique_setup_and_commands -->
运行 `Doc/生成脚本/generate_thesis_template.py` 可自动生成《基于因果AI的旱涝急转灾害链识别与机制分析_论文模板.docx》，该脚本内置中山大学页边距、字体（宋体/黑体）、行距、标题层级等格式规范，无需额外配置。
