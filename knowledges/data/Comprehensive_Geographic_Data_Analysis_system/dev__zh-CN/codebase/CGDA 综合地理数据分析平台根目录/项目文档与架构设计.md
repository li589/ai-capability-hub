# 项目文档与架构设计

## 概述 <!-- category:overview -->
综合地理数据平台的文档集合，涵盖技术栈、后端架构、工作流编排、部署说明及各类工程决策纪要。

## 架构设计 <!-- category:architecture_design -->
本模块为纯文档目录，按主题组织 Markdown 文档与绘图脚本：
- `Draw/TechStack.py` 使用 matplotlib 生成 Web GIS 架构图（客户端层/后端服务层/数据存储层/外部数据源四列网格布局），输出 PNG 至 `Draw/output/`。
- 核心架构文档 `后端架构设计.md` 定义三层架构（前端 Vue3+MapLibre、后端 FastAPI+Celery、Python 算法包）及存储抽象层（LocalFileSystemAdapter / MinIOAdapter）、格式转换层（COG/PNG/Parquet/manifest）、ComfyUI 式 DAG 工作流编排与调度执行流程。
- `技术栈.md` 以表格形式记录各层级选型与当前状态，并约定 `Env/Python312` 运行时与 `start.bat`/`launch.py` 启动方式。
- 其余 `.md` 文件为工程决策纪要、任务清单、数据源对照、性能基线等过程文档，无代码依赖关系。

## 技术栈 <!-- category:tech_stack -->
matplotlib + FancyBboxPatch 绘制架构图；Markdown 文档为主，配合 PDF 导出（技术介绍.pdf、技术栈.pdf）；架构图由 Python 脚本生成而非静态图片。

## 编码规范 <!-- category:coding_conventions -->
- 架构图采用四列网格布局（X=[1.0,4.3,7.6,10.9]）与固定组件尺寸（W=2.8, H=1.3），通过 draw_comp/draw_arrow 函数统一绘制组件与连线。
- 文档以「现状 vs 路线图」分离描述，明确标注哪些能力已落地、哪些仅规划，避免将未来设计误作当前实现。
- 所有技术选型文档均包含「当前状态」列，区分目标架构与实际落地程度，以代码与本表对照为准而非任务清单。

## 配置与命令 <!-- category:unique_setup_and_commands -->
运行 `Doc/Draw/TechStack.py` 可重新生成架构图（需 matplotlib 中文字体 SimHei/Microsoft YaHei）；文档本身无需构建，直接阅读 Markdown。
