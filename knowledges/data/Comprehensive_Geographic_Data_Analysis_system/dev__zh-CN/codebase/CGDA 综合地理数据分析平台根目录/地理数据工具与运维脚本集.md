# 地理数据工具与运维脚本集

## 概述 <!-- category:overview -->
面向地理空间数据的下载、同步、扫描、校验与一次性分析脚本集合，支撑多源遥感数据集的远程发现、本地组织与质量验证。

## 架构设计 <!-- category:architecture_design -->
本模块为扁平脚本集合，按功能划分为若干独立可执行 Python 文件，无包级依赖关系：
- 数据发现与规划：`remote_data_scanner.py` 通过 FileBrowser API 扫描 Win11/NAS 两个 Cloudflare 隧道服务器，生成 `reports/scan_report_*.json` 和 `download_candidates.json`；`analyze_checkpoint.py` 消费检查点 JSON 输出分类统计。
- 数据下载：`download_curated.py`（精选清单）、`download_resumable.py`（断点续传 HTTP Range）、`download_remaining.py`、`download_small.py`、`download_smap_*` 等按场景拆分，统一写入 `I:\Geograph_DataSet\` 目录树。
- 数据同步：`SyncData.py` 基于 paramiko SSH + ThreadPoolExecutor 实现双向并发同步，支持 fast/hash 冲突策略与失败重试。
- 数据校验与验证：`verify_all_datasets.py`、`verify_bounds.py`、`verify_layers_api.py`、`verify_overlays_api.py`、`verify_point_query.py` 调用核心 `UniversalDataReader` 对 I:\Geograph_DataSet\ 下各格式（GeoTIFF/NetCDF/HDF5/MAT/CSV）做统计与坐标检查，结果落 `reports/dataset_verification*.json`。
- 项目工作流：`run_project_omega.py` 串联 DataPreprocessor/SpatialAligner/UniversalDataReader 完成 Omega 反演演示流程。
- 辅助排查：`inspect_*`、`audit_overlay_assets.py`、`export_overlay_assets.py`、`rename_chinese_dirs.py`、`reorganize_local_data.py`、`merge_file.py` 等一次性工具。
- 产物目录：`reports/` 存放所有 JSON/CSV/日志报告，`ComplexityCompus/` 存放复杂度分析中间件，`test_data/` 存放测试夹具。
依赖方向单向：脚本 → Code/algorithms/providers/Python/data_access（导入 UniversalDataReader 等核心读取器），不反向依赖主业务代码。

## 技术栈 <!-- category:tech_stack -->
Python 3.12 + 标准库 urllib/ssl/json/pathlib；地理数据处理依赖 rasterio、netCDF4、h5py、scipy.io、geopandas、pandas、numpy；SSH 同步使用 paramiko；进度条使用 tqdm；Cloudflare 隧道作为远程文件访问代理（Win11 E盘/NAS Z盘）。

## 编码规范 <!-- category:coding_conventions -->
- 每个脚本均为独立可执行入口，顶部包含 `#!/usr/bin/env python3` 和多行 docstring 说明用途与用法，通过 `if __name__ == "__main__":` 分支解析命令行参数。
- 远程服务器配置集中定义在模块级 `SERVERS` 字典（如 `remote_data_scanner.py`、`download_curated.py`），包含 base_url、username、password、label 等字段，便于扩展新源。
- 所有产出报告统一写入 `Tools/reports/` 目录，文件名采用 `{prefix}_{YYYYMMDD_HHMMSS}.{ext}` 时间戳命名模式，便于版本追溯。
- 数据路径统一使用 Windows 原始字符串 `r"..."` 并指向 `I:\Geograph_DataSet\` 根目录，避免转义问题。
- 错误处理采用 try/except 捕获异常并记录 traceback，同时通过 `sys.stdout.reconfigure(encoding="utf-8")` 强制 UTF-8 输出以兼容 Windows PowerShell。
- 大文件操作优先使用分块/窗口读取（rasterio window、h5py chunked），避免一次性加载导致 OOM，并在报告中记录有效像素比例与 NaN 占比。

## 配置与命令 <!-- category:unique_setup_and_commands -->
运行前需确保 `I:\Geograph_DataSet\` 本地数据根目录存在；远程服务器通过 Cloudflare Tunnel 暴露（`https://win11file.personaltunnel.dpdns.org` / `https://nasfile.personaltunnel.dpdns.org`），需在 `download_curated.py` 或 `remote_data_scanner.py` 中配置用户名密码；SSH 同步需在 `SyncData.py` 的 CONFIG 中填写密钥路径或密码；Windows PowerShell 脚本 `reorganize_datasets.ps1` 用于本地目录重组；批量下载通过 `python remote_data_scanner.py scan --quick` 生成清单后 `python download_resumable.py` 按需下载。
